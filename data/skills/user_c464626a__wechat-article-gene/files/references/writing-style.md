# 公众号文章写作规范（Writing Style Guide）

适用于企业营销 / 观点输出型公众号图文，目标：让读者读完并行动（留言 / 转发 / 咨询）。

## 篇幅与节奏

- 全文 1200~1800 字（手机上约 4~5 分钟阅读量），观点型文章宁短勿长
- 每段 1~3 句话，一段一个信息点；段落之间用空行制造呼吸感
- 大标题（h2）分 4~6 个章节，每章 200~400 字
- 章节用「一、二、三」中文序号，标题写结论或悬念，不写分类词（如"背景介绍"是差标题）

## 标题公式（文章大标题）

从以下模式中选择，必须含具体冲突或数字：

- 「XX 变了：A，你却 B」→ 例：流量入口变了：客户在问 AI，你的公司却不在答案里
- 「投了 12 年广告的老朋友，上个月停投了」（故事反差型）
- 「90% 的企业还不知道的 XX」（信息差型）
- 避免：抽象名词堆砌、无具体对象的判断句

## 开头 150 字（生死线）

用「真实场景对话」开场，不用概念开场：

1. 一个具体的人（老朋友 / 客户 / 同行）+ 一个具体困境
2. 用引用块呈现他的一句原话（带情绪）
3. 抛出一个反问，让读者自查（例：「你最近一次买东西，是先打开百度，还是先问 AI？」）
4. 结尾一句话点破趋势：「这就是今天所有 XX 正在面对的一次静悄悄的迁徙」

## 中段结构模板

```
一、痛点已成事实（场景 + 2~3 个数据佐证 + "这意味着什么"一句话点破）
二、拆解背后逻辑（把复杂机制翻译成"朴素规则"，用编号列表）
三、给出方法（N 步法，每步含：做什么清单 + "这一步的核心目的"一句话）
四、结果对比（先动手的人得到什么 / 观望的人失去什么）
五、业务引导（公司能提供什么，分服务卡片列出）
```

## 金句规则

- 每 300 字左右必须有一句「加粗金句」，读者只扫加粗也能看懂全文逻辑
- 金句结构：对比式（"不是 A，而是 B"）或判断式（"AI 推荐谁，谁就有商机"）
- 关键词用黄色高亮底纹（复制页中 `<span style="background:#fff7d6...">`），全文不超过 8 处

## 数据使用

- 每篇 2~4 个数据即可，多则淹没重点
- 数据必须标注量级来源写法（"超 6 亿用户"），数字用加粗强调色
- 数据紧跟一句"翻译"：把数据换算成读者的切身利害

## 结尾（最后 100 字）

- 互动引导：一个开放问题（"你的行业是？你的客户从哪来？"）
- 行动引导：在看 / 转发给具体的人（"转发给那个还在投搜索引擎广告的老朋友"）
- 品牌落款一行（© 公司名 · 一句话 slogan）

## 语气

- 像跟同行朋友聊天，不用"赋能""抓手"等空词
- 允许口语化转折（"聊都不聊你""上不了台面"），制造亲近感
- 企业业务介绍放在最后一章，前四章只讲价值不讲产品

## 叙述口味轮换（同一 skill 连续产出多篇时必读）

连续多篇用同一套路会被读者识破，每篇换一种叙述视角：

- 观察者体：第三人称讲客户故事（首篇默认）
- 自述体：第一人称"我"讲自己的经历（第二篇换用）
- 对话体：全篇问答 / 采访推进
- 清单体：观点 + 编号清单，弱化故事

## 单一比喻贯穿法（需求"逻辑性 + 轻松易懂 + 直击痛点"时首选）

结构 = 用一个读者都懂的生活事物当"主线比喻"，全篇沿着它走到底，每章都是上一章的必然推论：

```
① 比喻开场（传话游戏 / 买菜砍价 / 装修队 / 点外卖）
② 映射到读者处境（"你的项目就是一场传话游戏"）→ 痛点一：需求走样
③ 解释为什么现状如此（大公司结构决定必须传话）→ 痛点二：钱花冤枉
④ 给出解法（有人把传话链拆了：一人+AI）→ 把比喻收掉（"第一棒和最后一棒是同一个人"）
⑤ 落到自家业务（"我们就是干这个的"）
```

要点：
- 比喻必须生活化、全员可懂，全文出现 4~6 次，每次出现都推进逻辑
- 每章配一句"金句卡"（深色卡），金句用比喻语言而非口号（"传着传着就变了味"）
- 章节标题用「一、二、三、四」陈述句，不做问答式
- 结尾互动提问也复用比喻（"你上一个项目，需求被传了几层？"）
- 配图按新结构重新映射：封面=比喻主角，图2=痛点映射，图3=解法，图4=业务

## 可读性检查（写完自查 5 条，防"生硬费劲"）

1. 有没有连续 3 句以上短句轰炸？→ 长短句交替，给读者喘气的空当
2. 是不是句句都在下结论？→ 金句降密度，读者读 3~4 段才应碰到一处加粗
3. 小标题是不是都是"提问-回答"式？→ 换成口语化陈述句（"需求是怎么'走样'的"）
4. 有没有用叙事代替论证？→ 讲一个具体项目怎么走完的，比列 3 个论点顺
5. 结尾是否又回到了"服务卡片堆砌"？→ 试试一句话身份自白（"我是你项目里唯一需要记住的联系人"）

真实教训：自述体如果写成"三笔账"答辩稿（满篇短句+句句金句+问答式小标题），读者反馈"生硬、费劲"；改成连贯讲一个客户项目怎么走完的，流畅度立即可感知。
