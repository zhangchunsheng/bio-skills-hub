# 微信公众号文章创作

## 概述

为企业和个人创作可直接发布的微信公众号图文：文章 + 配图 + 预览页 + 公众号编辑器复制专用页。产出一套完整的交付目录，让用户复制粘贴即可发布。

## 工作流（按顺序执行）

### 第 1 步：写作

加载 `references/writing-style.md` 并按规范撰写：

- 全文 1200~1800 字，标题用冲突式/数字式公式
- 开头 150 字用"真实场景对话"开场（具体的人 + 引用块原话 + 反问）
- 中段按五段模板：痛点事实 → 背后逻辑 → N 步方法 → 结果对比 → 业务引导
- 每 300 字一句加粗金句，关键词黄色高亮（全文不超过 8 处），数据 2~4 个
- 业务介绍只放最后一章，前文只讲价值
- 产出 `article.md`（含图片引用位置）

### 第 2 步：配图

加载 `references/image-guide.md` 并按规范用 ImageGen 生成 4 张图（1536×1024）：

- `01-cover.png` 封面（单一强主体 + 顶部留暗区叠标题）
- `02-xxx.png` 痛点章插图（对比叙事）、`03-xxx.png` 方法章插图（步骤递进）、`04-cta.png` CTA 插图（赢输对比）
- **每个 prompt 结尾必须加 "no text, no words, no letters"**
- 同篇文章所有图统一风格族和色系（紫-蓝-青 + 金点缀）
- 生成后逐张 Read 检查（乱码文字、跳戏元素），不合格重生成
- 存入文章目录 `images/`

### 第 3 步：预览页

制作 `preview.html`：本地查看最终图文效果的排版页（可用 class 集中样式，仅本地浏览）。

### 第 4 步：公众号复制专用页

加载 `references/wechat-html-spec.md`，基于 `assets/wechat-template.html` 模板制作 `wechat.html`。核心铁律：

- 复制区内 **100% 内联样式**（公众号粘贴时剥离 `<style>` 和 class）
- 复制按钮用 **Clipboard API 直接写入 HTML**（避免页面背景混入剪贴板导致灰底）
- 页面底色纯白；工具条 `user-select: none`
- 图片位置用**虚线占位框**并标注对应文件名（公众号禁止外链图片，必须手动上传）
- CTA 卡用纯色不用渐变

### 第 5 步：交付

用 present_files 展示 `wechat.html`（优先）、`article.md`、4 张配图。交付说明中必须包含发布操作步骤（复制 → 粘贴 → 上传图片占位 → 设置封面 2.35:1 → 预览 → 群发），以及"若粘贴后出现灰底，用 Chrome 无痕窗口打开复制"的排查提示。

## 输出目录结构

```
<article-dir>/
├── article.md          # 文章源文（markdown）
├── preview.html        # 本地排版预览
├── wechat.html         # 公众号复制专用页（全内联样式）
└── images/
    ├── 01-cover.png
    ├── 02-xxx.png
    ├── 03-xxx.png
    ├── 04-cta.png
    └── v1/             # 替换图片时的旧版备份
```

## 扩展：转视频号

若用户要求把文章转成视频号内容：压缩为 60~90 秒脚本（3 秒钩子开场 → 痛点 → 数据 → 方法压缩版 → 评论区资源钩子 CTA），产出逐镜分镜表（时间码 + 画面 + 台词 + 屏幕大字）与 9:16 素材；可用现有配图经 VideoGen 生成动态片段作为插播画面。
