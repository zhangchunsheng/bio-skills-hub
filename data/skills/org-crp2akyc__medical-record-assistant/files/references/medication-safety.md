# 常见药物不良反应与相互作用提示

> ⚠️ 本文件仅做药物知识科普，所有信息以药品说明书为准。不构成用药建议或处方。

---

## 读写原则

在分析病历时，若发现用户提及正在服用的药物，遵循以下原则：

1. **只做科普，不做建议**：仅提供药物说明书级别的公开信息，不评价当前用药方案的合理性
2. **标注信息来源**：所有药物信息以国家药品监督管理局（NMPA）批准的最新版说明书为准
3. **遇到危险信号即刻提醒**：检测到严重药物相互作用时，提醒"请立即咨询医生或药师"
4. **不确定时保守处理**：无法确认的药物相互作用，回复"请在用药前咨询医生或药师"

---

## 常见药物-实验室检查干扰

以下药物可能影响检查结果，分析时需提示用户：

| 药物类别 | 可能影响的检查 |
|----------|---------------|
| 阿司匹林/NSAIDs | 血小板功能↓、可能隐血阳性 |
| 华法林 | PT/INR 延长（预期效果） |
| 糖皮质激素 | 血糖↑、白细胞↑ |
| 利尿剂（氢氯噻嗪） | 尿酸↑、血糖↑、钾↓ |
| 他汀类降脂药 | ALT/AST 可能↑、CK 可能↑ |
| 抗生素（头孢类） | 可能肌酐↑（假性） |
| 口服避孕药 | 血脂可能↑ |
| 维生素 C 大剂量 | 尿糖假阳性 |

## 严重药物不良反应信号

分析中发现以下药物组合或表现时，标记为 👆 需警惕：

| 药物/组合 | 风险信号 | 提示内容 |
|-----------|---------|---------|
| 华法林 + NSAIDs | 出血风险显著增加 | "华法林与布洛芬等止痛药合用会增加出血风险，请咨询医生" |
| ACEI/ARB + 保钾利尿剂 | 高钾血症 | "这两类药物合用可能使血钾升高，需定期监测电解质" |
| 他汀类 + 大环内酯类抗生素 | 横纹肌溶解风险 | "克拉霉素等抗生素与他汀类药物合用可能增加肌肉损伤风险" |
| 二甲双胍 + 造影剂 | 乳酸酸中毒风险 | "使用含碘造影剂前需暂停二甲双胍，请遵医嘱" |
| 多种镇静药物合用 | 呼吸抑制 | "多种镇静药物合用可能过度抑制呼吸" |

## 常见药物副作用与检查异常关联

| 药物类别 | 常见副作用 | 可能出现的检查异常 |
|----------|-----------|--------------------|
| 糖皮质激素 | 水钠潴留、血糖升高、骨质疏松 | 血糖↑、血钾↓、白细胞↑ |
| 他汀类降脂药 | 肝功能异常、肌肉疼痛 | ALT↑、CK↑ |
| ACEI 类降压药 | 干咳、高钾血症 | 血钾↑、肌酐↑（起始阶段） |
| 质子泵抑制剂（奥美拉唑等） | 长期使用 | 维生素 B12↓、可能影响钙吸收 |
| 甲氨蝶呤 | 骨髓抑制、肝损伤 | 白细胞↓、血小板↓、ALT↑ |
| 胺碘酮 | 甲状腺功能异常、肺纤维化 | TSH 异常（↑或↓） |

---

## 中草药与检查异常

| 中药/提取物 | 可能的检查干扰 |
|-------------|---------------|
| 甘草制剂（大量长期） | 血钾↓、血压↑ |
| 何首乌（未炮制/过量） | ALT/AST 显著↑ |
| 含马兜铃酸药材 | 肌酐↑、肾功能受损 |

> 分析时若用户提及在服中草药/保健品，提示"请告知医生你在服用的所有药物和保健品，包括中草药"。
