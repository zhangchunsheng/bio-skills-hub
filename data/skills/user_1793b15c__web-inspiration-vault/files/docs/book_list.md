# 需要哪些书 —— 按"缺口"列，不按"推荐书单"列

原则：这个技能 80% 是工程问题（已解决），**剩下 20% 是审美判据问题**。
所以下面每一本都对应一个**具体的、现在做不好的点**，而不是泛泛的"好书推荐"。
不需要全买，按优先级取前 3 本即可。

---

## P0 · 直接决定 4 套模板的视觉质量

### 1. 《Refactoring UI》— Adam Wathan & Steve Schoger
**补的缺口**：`styles/*/style.json` 里那些"签名手法"现在是我凭经验写的，需要成体系的判据。
**为什么是它**：两位作者就是 Tailwind CSS 的作者，全书是"如何把界面做好看"的**操作手册**——
配色如何选、字号阶梯如何搭、留白如何给、层级如何用阴影和明度而不是靠边框。
**直接产出**：极简 / 科技两套模板的 `signature_moves` 与 `forbidden` 清单可以照它重写一遍。
> 备注：这本书没有中文正式版，网上流通的是 PDF/网页版。如能搞到，价值最高。

### 2. 《The Elements of Typographic Style》— Robert Bringhurst（中文版《字体排印风格要素》）
**补的缺口**：`extract_rhythm()` 里的"排版节奏"目前是**统计**（众数间距、最大圆角），
不是**判据**。字号比例该不该是 1.25 还是 1.618？行高多少算合理？版心多宽最舒服？
**为什么是它**：排版界的圣经，给的是可计算的规则（字号阶梯、行高与字宽的关系、版心比例）。
**直接产出**：把"节奏提取"从"记录原页数值"升级为"判断原页数值是否专业"——
这一步做出来，卡片会多一个"排版体检"维度，比现在只报参数有价值得多。

### 3. 《The Visual Display of Quantitative Information》— Edward Tufte
**补的缺口**：你提到的财务场景（月度经营复盘"一页纸"、项目展示页）现在还没有骨架模板。
**为什么是它**：数据可视化与一页纸信息密度的底层原则（数据墨水比、图表垃圾、微缩图表）。
跟"极简风"的克制美学天然同源，也是"一页纸"能站得住的理论依据。
**直接产出**：`styles/` 之外新增 `skeletons/onepager_report.html.j2` 的设计依据。

## P1 · 让配色从"频次统计"升级为"配色体系"

### 4. 《配色设计原理》— 奥博斯科编辑部（或《COLOR DESIGN BOOK》）
**补的缺口**：现在选 `primary` / `accent` 靠的是"饱和度 + 频次 + 色相差异 > 25°"，
是启发式，不是配色理论。为什么某些组合好看、某些刺眼，没有依据。
**为什么是它**：日系配色方法论，讲清色相环、明度/饱和度三角形、配色类型的分类，
**正好是"自动归类到预设风格"需要的那套分类学**。
**直接产出**：`classify_style()` 里的硬编码权重（0.26 / 0.18 这些数字）可以换成有依据的规则。

### 5. 《中国传统色》— 郭浩 / 李健明
**补的缺口**：如果做国风/财务场景模板，需要一套**本土色板参照系**，
现在的配色角色命名（primary/accent）是西式的。
**为什么是它**：色名 + 色值 + 出处，可直接做成模板的可选色板库。
**优先级**：仅当你确定要做国风模板时才需要，否则可跳过。
