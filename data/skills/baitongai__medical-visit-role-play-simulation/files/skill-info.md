# Skill Info

## Skill Name
医药行业合规能力测评（营销端）

## Description
医药行业合规能力测评（营销端）模块一-政策解读能力A-E。在对话框中逐题呈现130道题目（覆盖五大政策板块），用户以文本输入作答，完成后自动生成8维度分析报告（总分评级、板块明细、能力雷达评分、合规风险等级、个人能力画像、学习建议、错题解析）。触发词：合规测评、合规能力测评、政策解读能力测评、医药合规考试。

## Introduction

本技能在医药合规培训领域提供交互式 HTML 合规能力测评能力，覆盖五大政策板块共 130 道题目。

医药行业合规能力测评（营销端）旨在通过在线测评方式评估医药营销人员的合规政策解读能力，完成测评后自动生成包含 8 个分析维度的综合报告，为培训部门和营销团队提供合规能力的量化评估工具。

核心能力：

- 交互式测评：生成自包含 HTML 测评页面，支持单选/多选题在线作答
- 五板块覆盖：医药反腐合规指引、学术拜访规范、医药代表管理办法、RDPAC行业准则、医保集采与数字化推广
- 8 维度报告：总分评级、各板块明细、正确率图表、能力雷达图、合规风险等级、个人能力画像、学习建议、错题解析
- 图表可视化：Chart.js 堆叠柱状图、环形图、能力雷达图
- 错题解析：按板块筛选，显示原题、用户选择、正确答案及政策原文

应用场景：

- 医药营销人员合规政策解读能力自测
- 企业内部合规培训效果评估
- 合规考试准备与模拟练习
- 培训部门能力摸底与学习计划制定
