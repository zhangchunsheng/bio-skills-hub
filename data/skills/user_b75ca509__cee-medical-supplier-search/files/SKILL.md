# 宁波中东欧医药交易(集采)平台 - 供应商搜索

## 概述

本技能用于在宁波中东欧医药交易(集采)平台（globalmedsource.cn）上搜索供应商（企业）信息。通过直接请求平台开放的店铺列表接口（无需登录、无需 MCP 连接器），根据企业名称关键词检索供应商基本信息及核心商品列表。

## 触发条件

**仅在以下条件同时满足时触发此技能：**

1. **平台关键词匹配**：用户消息中包含以下关键词之一（不区分大小写）：
   - "宁波中东欧医药交易"
   - "中东欧医药交易"
   - "中东欧医药集采"
   - "中东欧医药平台"
   - "globalmedsource"
   - "宁波中东欧"
   - "中东欧医药"

2. **意图匹配**：用户表达了查找、搜索、查询某家企业/供应商信息的意图。

**不触发的场景：**
- 用户未提到上述平台关键词时
- 用户只是泛泛询问医药行业信息时
- 用户询问的是其他医药平台时

## 前置条件

无需任何 MCP 连接器，直接请求平台开放接口即可。需要本机 Python 3 环境（标准库 urllib，无第三方依赖）。

## 工作流程

### 步骤 1：验证企业关键词

从用户消息中提取企业名称关键词。判断关键词是否足够清晰：

**关键词不清晰的情况：**
- 关键词为空或仅包含通用词（如"公司"、"企业"、"供应商"）
- 关键词过短（少于2个字符）
- 关键词仅为行业类别词（如"医药"、"器械"、"药品"）而非具体企业名称

**关键词不清晰时**，向用户说明并引导提供更准确的关键词：
> "请提供更具体的企业名称关键词，例如公司全称或名称中的核心词（如'康达'、'medical'等），以便在宁波中东欧医药交易(集采)平台上精确查找。"

**关键词清晰时**，继续步骤 2。

### 步骤 2：运行脚本搜索供应商

运行技能目录下的 Python 解析脚本，直接请求平台开放的店铺列表接口获取数据。

**脚本路径：** `scripts/search_suppliers.py`

**运行方式（通过 Bash 工具执行）：**

```bash
python3 "<技能目录>/scripts/search_suppliers.py" "<用户的企业关键词>" 5
```

其中：
- 第一个参数：用户的企业名称关键词（必须）
- 第二个参数：每页数量（可选，默认 5）

脚本会请求 `https://globalmedsource.cn/mall/MallStores/storeList?page=1&limit=5&keyword=<关键词>&search_type=Supplier`，将返回的 HTML 页面解析为结构化 JSON，并输出到标准输出。

**注意事项：**
- 技能目录即本 SKILL.md 所在的 `~/.workbuddy/skills/cee-medical-supplier-search/`
- 运行前先确认脚本文件存在，若不存在请从 SKILL.md 所在目录定位
- 脚本依赖 Python 标准库（urllib、json、re），无需安装第三方包

### 步骤 3：处理搜索结果

解析返回的 JSON 数据，根据 `data.matched` 字段判断是否匹配成功。

#### 情况 A：匹配成功 (matched: true)

生成一份精美的 HTML 企业报告并展示给用户。报告包含供应商基本信息、企业简介和核心商品列表（含图片）。

**生成步骤：**

1. 读取技能目录下的 HTML 模板文件：`assets/report_template.html`
2. 将模板中的 `__REPORT_DATA_PLACEHOLDER__` 替换为 API 返回的完整 JSON 数据（直接插入原始 JSON 对象，不要加引号）
3. 将生成的 HTML 文件保存到工作区目录下，文件名格式为 `supplier_report_<关键词>_<时间戳>.html`
4. 使用 `present_files` 工具将 HTML 文件展示给用户

**HTML 模板说明（`assets/report_template.html`）：**

模板为自包含 HTML 文件，内含 CSS 样式和 JavaScript 渲染逻辑，无需额外依赖。模板中有一个 `REPORT_DATA` 变量，用于接收脚本输出的完整 JSON 数据并自动渲染为可视化报告。模板支持多个供应商（`suppliers` 数组），每个供应商渲染为一个报告卡片。

报告包含以下板块：
- **企业头部**：店铺 Logo、公司名称、平台标签
- **企业基本信息**：联系人、联系电话、联系邮箱、联系地址、供应商ID
- **企业简介**：店铺介绍文本
- **核心商品列表**：商品图片、商品名称（含图片）

同时用简短文字向用户概述搜索结果要点（如"已找到 XX 公司，共 N 个核心商品"），然后呈现 HTML 报告。

#### 情况 B：未匹配 (matched: false)

向用户说明未找到匹配的供应商，并建议更换关键词：

> "在宁波中东欧医药交易(集采)平台上未找到与「{keyword}」匹配的供应商。请尝试更换关键词，例如使用企业全称或名称中的其他核心词重新搜索。"

#### 情况 C：API 错误

如果返回错误（code 非 0），向用户说明：
> "搜索过程中遇到问题：{错误信息}。请稍后重试或更换关键词。"
