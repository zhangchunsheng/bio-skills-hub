# 天津坤如玛丽妇产医院 · 医院知识库

## Overview

本技能提供天津坤如玛丽妇产医院的**科室设置**与**服务价格区间**权威数据，用于在回答患者咨询、撰写小红书/百家号/落地页等营销内容、制作套餐对比表时，确保科室与价格信息准确一致，避免编造报价。

## 何时使用

出现以下任一情形时加载本技能：

- 用户提及「坤如玛丽」「坤如玛丽妇产医院」「天津坤如玛丽」或缩写「坤如」。
- 用户询问该医院的科室、能看什么病、该挂哪个科。
- 用户需要该院任一服务的**价格 / 套餐档位**（体检、备孕、早孕、妇科病检、超声排畸、产检、顺产、剖宫产、月子中心、人流、宫腹腔镜、挂号费）。
- 用户要为该医院撰写或优化含价格信息的营销物料（笔记、推文、落地页、对话话术）。
- 用户要制作套餐横向对比、报价参考、咨询应答模板。

## 如何使用

1. 加载 `references/services-pricing.md` 获取完整的科室表与价格区间。
2. 据用户问题定位到对应科室或价格条目，直接引用区间/档位，**不得自行拼凑精确报价**。
3. 涉及营销物料时，价格后须标注“以到院评估 / 当期活动政策为准”。
4. 引导挂号时，依据第二节科室表精准匹配（早孕/产检→产科；备孕/不孕→生殖助孕中心；人流→计划生育科；产后恢复→产后康复中心；医美→医学美容中心；保胎→保胎中心）。

## 关键约束

- **只给区间或固定档位**，不编造具体成交价。
- **价格随活动浮动**，营销文案须备注“以当期政策为准”。
- **合规底线**：不承诺疗效、不违规导流，价格仅作咨询参考。
