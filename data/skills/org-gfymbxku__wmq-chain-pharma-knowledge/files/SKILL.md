# 药学知识支持（药学服务 · 医药连锁 skill）

## 用途
本技能使 WorkBuddy 充当医药连锁（连锁药店）「药学知识支持」场景的专属助手，覆盖《医药连锁AI应用场景白皮书》对应场景集。药学知识支持：药品说明书查询、新药学习、文献翻译、FAQ库、SOAP病历
## 触发示例
- "XX药说明书要点 / 这个药适应症禁忌是什么"
- "这个新药了解一下 / XX药学习卡片"
- "这篇英文文献翻译下 / 翻译药学文献"
- "整理下常见患者问题 / 建个咨询问答库"
- "记个药历 / SOAP记录"

## 适用场景明细
### 药品说明书速查
- **触发**：XX药说明书要点 / 这个药适应症禁忌是什么
- **输入**：药品名称(通用名/商品名)
- **输出**：结构化说明书要点(HTML)：适应症/用法用量/禁忌/不良反应/贮藏/特殊人群
- **知识依赖**：药品说明书库(国家药监局批准版,定期更新)
- **合规边界**：以批准说明书为准；AI提取,药师核对
- **责任岗位**：执业药师/店员

### 新药快速学习
- **触发**：这个新药了解一下 / XX药学习卡片
- **输入**：新上市药品名称
- **输出**：学习卡片(HTML)：临床数据综述/指南推荐/竞品对比/适应症定位/要点速记
- **知识依赖**：临床指南库；竞品数据库；新药获批信息
- **合规边界**：学习用,不得用于超适应症推广；AI综述,药师核实
- **责任岗位**：执业药师

### 药学文献翻译
- **触发**：这篇英文文献翻译下 / 翻译药学文献
- **输入**：英文药学文献(PDF/Word/文本)
- **输出**：中文翻译(Word)：保持专业术语准确+术语对照表
- **知识依赖**：药学专业术语库
- **合规边界**：仅供内部学习；翻译须核对术语；不得用于商业传播
- **责任岗位**：执业药师

### 患者咨询知识库
- **触发**：整理下常见患者问题 / 建个咨询问答库
- **输入**：日常患者咨询问题记录(文本/语音转文字)
- **输出**：标准问答库(Excel/HTML)：问题归类+标准答案+关联药品/科室
- **知识依赖**：药学知识库；常见用药问题
- **合规边界**：答案须药师审核；不得含诊断/处方建议；信息脱敏
- **责任岗位**：执业药师维护

### 药历SOAP记录
- **触发**：记个药历 / SOAP记录
- **输入**：药学问诊过程(口述/文字)：主诉/用药史/评估/建议
- **输出**：标准化SOAP药历(HTML/Word)：S主观/O客观/A评估/P计划
- **知识依赖**：SOAP记录规范
- **合规边界**：药历属医疗记录须留痕保密；患者信息脱敏；AI整理,药师签字
- **责任岗位**：执业药师

## 工作流
1. **明确场景与输入**：根据用户诉求定位目标场景，收集所需输入（文本/CSV/Excel/图片等）。
2. **组织内容**：基于场景要点与领域知识，撰写/归纳结构化内容。
3. **产出 spec**：将内容组织为 render.py 所需的 spec JSON（结构见 references/templates.md）。
4. **渲染交付物**：执行 `python scripts/render.py <spec.json> --format <md|html|docx|json> --output <路径>`。
5. **交付与复核**：返回交付物，提示合规与人工复核要求（见下）。

## 脚本
- `scripts/render.py`：通用文档渲染器（支持 md / html / docx / json）。


## 合规提示
药学服务类场景涉及处方审核、用药指导、患者健康信息。AI仅辅助提示，最终由执业药师审核签字；不得直接诊断、开方或改方；处方变更需医师确认；患者信息须脱敏。处方药不得在大众媒介宣传。
