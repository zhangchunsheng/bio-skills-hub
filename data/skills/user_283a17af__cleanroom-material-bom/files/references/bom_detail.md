> 配套 `cleanroom-material-bom` 技能。12 节点，每节点含：目的 / 输入 / 步骤要点 / 审核清单 / 实战经验（用户补充）。

## 节点 1 · 设计提量与 BOM 编制

**目的**：把图纸/清单转为可执行的物料清单（BOM），作为后续备料、请购、核销、结算的基准。

**输入**：招标图/施工图/深化图、工程量清单、工艺节点图、设备接口图、招标文件。

**步骤要点**
- 编制**三版 BOM**（版本留痕）：
  - V1 招标图 BOM：投标/清单口径，用于报价与中标测算。
  - V2 施工图 BOM：深化设计后，用于实际备料与请购（主用版）。
  - V3 变更后 BOM：设计变更/签证后刷新，用于结算量差。
- 提量层级：专业 → 系统 → 设备/主材/附件辅材。
- **易漏项**（重点复核）：
  - 设备基础、预埋件、支吊架、减震台座。
  - 附件与辅材：阀门、法兰、软接、密封垫、螺栓、接头。
  - 管线翻弯/标高差带来的额外长度。
  - 专业接口：医气开孔与装饰墙面、电气桥架与暖通风管共架。

**实战经验（现场反馈）**
- **土建实际情况与图纸不符是最大偏差来源之一**。典型场景：铅防护手术室的顶部梁的数量和走向（横跨/半跨/搭边）与图纸差异大，导致铅板用量与理论计算值出现明显差距。BOM 提量阶段须预留"现场校核"环节，尤其涉及防护类材料时。
- **模数起订量常被忽视**：
  - 石膏板、硅酸钙板等板材按整块起售（常见规格 2.4m×1.2m 或 2.44m×1.22m），理论面积须向上取整至整块数。
  - 线管通常按整支起售；电线按整卷起售；电缆按整米且有最低起订量；大口径无缝钢管整管通常在 12–14 米，切割后很难刚好满足现场走向理论值——会多出一小段或少一小段。
- **不同专业提量侧重差异**：ICU 偏重医气终端密度与设备带长度；实验室偏重通风柜排风量与给排水点位；洁净手术部偏重装饰面板拼缝与铅防护展开面积。

**审核清单**
- [ ] 三版 BOM 是否齐备并标注版本与日期？
- [ ] 设备/材料的附件、辅材是否纳入？
- [ ] 单位是否统一（米/平米/台/套），避免换算错误？
- [ ] 专业接口冲突是否在备注标注并提前拉通？
- [ ] 模数起订量（板材整块/线管整支/电线整卷/电缆最低起订）是否已计入？

**配套模板**：五大专业材料品类 / 规格 / 选型与质控要点见 `templates/专业材料技术要点.md`（提炼自行业通用技术手册，脱敏），用于提量时核对材料技术参数与封样送检基准。

## 节点 2 · BOM 审核与量差平衡

**目的**：在备料前发现图纸量、清单量、经验量之间的偏差，避免多买/少买。

**输入**：图纸量、招标清单量、同类项目经验工程量。

**步骤要点**
- **三方核对**：图纸量 vs 清单量 vs 经验工程量（同类项目类比）。
- **常见错漏类型**：
  - 量算错（单位换算、小数点）。
  - 规格漏项（附件/辅材未单列）。
  - 专业接口冲突（开孔/点位重复或遗漏）。
  - 品牌指定不清（影响单价与货期）。
- **平衡原则**：以图纸为准；清单差异走澄清/变更，不擅自挪用量。

**实战经验（五种差异成因与追责机制）**

量差成因分为五类，处置方式不同：

| # | 成因 | 说明 | 追责方式 |
|---|------|------|---------|
| ① | 正常调量 | 外部增补/变更、公司赠送 | 正常流程，不追责 |
| ② | 班组原因 | 施工班组乙供转甲供等班组自身原因 | 通报对应部门与负责人 |
| ③ | 项目原因 | 现场丢失、损毁、损耗过大等 | **项目经理被追责和处罚**（项目部管理失当） |
| ④ | 预算原因 | 预算量漏算、少算 | 通报预算/结算部门及对应负责人 |
| ⑤ | 图纸原因 | 施工图与现场条件不符、漏画、错画等 | 通报设计部及对应负责人 |

> **关键**：第③类（项目管理失当）处罚最重，直接追责项目经理；第②④⑤类为部门级通报与负责人追责。所有差异须说明具体原因，不可笼统归入"正常调量"。

**审核清单**
- [ ] 图纸量与清单量差异 >5% 的项是否逐条复核？
- [ ] 经验工程量是否用于交叉验证异常项？
- [ ] 差异处置（澄清/变更/接受）是否留痕？
- [ ] 差异成因是否按五类归类？第③类是否已触发项目经理追责流程？

## 节点 3 · 损耗率与备料系数

**目的**：在净用量基础上算备料量，既要够用又不积压。

**公式**
```
备料量 = 净用量 × (1 + 损耗率) + 工艺余量
```
- 损耗率：材料在搬运、切割、安装中的合理损耗。
- 工艺余量：端头、翻弯、试压吹扫等不可回收损耗（部分材料单列）。

**步骤要点**
- 各材料损耗率按 `templates/损耗率经验区间表.md` 取定（按项目校准）。
- **长周期 / 定制件不宜过量备料**：资金占压 + 版本风险（设计变更即废）。
- 易损/易盗件可适度上浮，但须审批。

**实战经验（系数法取值规则）**
详见 `templates/损耗率经验区间表.md`（已用历史底稿回填各专业 340+ 条目）。核心原则：

- **定制件/设备类**：系数 = 1（无损耗，按实际需求数采购）
- **板材类（电解钢板/玻镁彩钢板/PVC墙布等）**：1.03–1.16 视工艺而定
  - 电解钢板（定制版）：1（无损耗）；玻镁彩钢板机制 1.03 / 手工 1.06
  - PVC墙布最高达 1.16（含拼缝/阴阳角/包柱等复杂造型损耗）
  - 瓷砖分不对缝 1.03 / 两边对缝 1.04 / 四边对缝 1.05
- **管材类**：镀锌钢管/无缝钢管 1（按中心线长度计，不含损耗，管件另计）
- **线缆/网线**：电线 1.16 / 网线 1.16 / 控制线 1.08 / 电力电缆 1.04
- **保温类**：橡塑保温 1.03 / 铝皮保护层 1.2
- **辅材类（乙供辅材）**：管件标注"/"，含量随管材规格变化，详见管件含量测算表

> ⚠️ **重要**：以上数值为行业通用基准，每个新项目须结合施工工艺（预制化 vs 现场加工）、现场条件重新确认。

**审核清单**
- [ ] 损耗率是否取自最新校准表？
- [ ] 长交期/定制件是否控量？
- [ ] 备料量是否经限额审批？

## 节点 4 · 甲供 / 乙供 / 甲指乙供划分

**目的**：依合同界面明确"谁买、谁验、谁保管、谁担责"，避免推诿与超供争议。

**依据**：招标文件、合同界面划分、清单编制说明。

**三种模式**
- **甲供**：甲方采购，乙方负责收货、验收、保管；超供损耗责任须书面界定；余料退甲或结转须约定。
- **乙供**：乙方采购，须报品牌/封样/送检，资料随货移交。
- **甲指乙供**：甲方指定品牌/厂家，乙方签约采购；质量责任链条不因其"指定"转移，须书面明确。

**实战经验（主辅材划分惯例）**
详见 `templates/甲供乙供划分表.md`（已用历史底稿回填六大专业分类）。核心规律：

- **通用型辅材（所有专业共用）**：吊杆/角码/拉爆/膨胀螺丝/枪钉自攻螺丝/电焊条/防锈漆/防火涂料/硅胶/结构胶/发泡剂/美纹纸 等 → 全属辅材
- **装饰专业主材**：龙骨体系（轻钢/方管）、铅板/硫酸钡水泥、基层板（硅钙/硅酸钙/玻镁）、各类装饰面板（贴板/拼板/挂板/焊接类）、乳胶漆、地材（PVC/橡胶）、门窗细部
- **暖通专业主材**：水管（镀锌/无缝/UPVC）、风管（镀锌/复合）、设备（风机/机组/盘管/水箱）、阀门/风口/过滤器
- **强弱电专业主材**：线管/桥架/布线（电线电缆）/灯具插座/配电设备/弱电机柜
- **给排水专业主材**：管道（不锈钢/PPR/UPVC/铸铁）/洁具/阀门/保温
- **医气专业主材**：管道（铜管/不锈钢管/UPVC）/设备（吊塔/吊桥/减压箱/汇流排/设备带）

> 辅材的界定原则："包含但不限于"，仅供参考，不作为双方主辅材结算依据。具体以合同界面为准。

**审核清单**
- [ ] 每项物资供应方式是否明确无歧义？
- [ ] 甲供超供/损耗责任是否书面界定？
- [ ] 甲指乙供质量责任链条是否理清？
- [ ] 主辅材划分是否参照了最新的主辅材划分明细表？

## 节点 5 · 物料编码与分类体系

**目的**：统一编码，使 ERP 建账、出入库、盘点、跨项目结转口径一致，避免"同名不同物"。

**编码维度（通用方案）**
```
专业(暖通/装饰/给排水/电气/医气/医疗设备)
 - 类别(设备/主材/辅材/附件)
   - 规格(型号/参数)
     - 品牌档次(国产一线/二线/进口)
```
例：`HVAC-设备-MAU-A1`（暖通-设备-净化空调机组-国产一线）。

**实战经验**
- 按常规通用编码即可（专业-类别-规格-档次四维），无需过度复杂化。
- 关键是编码在 BOM 编制阶段即赋予（节点 1），随 BOM 版次同步更新。
- 同一实物跨项目编码不变，便于结转与复用识别。
- 档次维度用通用口径（A1/A2/B1/B2/C1），不含真实商号。

**审核清单**
- [ ] BOM 每行是否都有唯一编码？
- [ ] 编码维度是否覆盖专业/类别/规格/档次？
- [ ] 跨项目复用物料编码是否一致？

## 节点 6 · 请购计划与批次拆分

**目的**：依施工节奏与货期，把 BOM 拆成多批请购，平衡"不待料"与"不积压"。

**输入**：V2 施工图 BOM、施工进度计划、`常用材料设备货期表`（见 Skill 1 模板）。

**步骤要点**
- 倒推：进场节点 − 货期 = 申请日。
- 批次拆分依据：
  - 关键路径/长交期项**优先、早请**。
  - 现货标准品**随用随请**，减少仓储与资金占压。
  - 同批到货量受现场仓储容量约束。
- 避免：一次到货占满场地/资金；或拆太碎导致多次运费与验收人力。

**实战经验（批次节奏与约束）**
- **批次节奏不强制固定频率**，由项目经理在现场把控仓储空间与场地条件。
- **大致范围**：同类材料允许申请 2–5 次，超出会被处罚。
- **运费优化**：尽量凑齐一车发货，节省运费（尤其异地项目运费占比显著时）。
- **长交期预警**：参考 Skill 1 的货期表，>56 天项须提前锁定产能。

**审核清单**
- [ ] 每批请购是否对应明确施工节点？
- [ ] 长交期项申请日是否早于进场 ≥1.5–2 倍货期？
- [ ] 批次量是否在仓储容量内？同类材料申请次数是否在 2–5 次范围内？
- [ ] 是否尽量凑齐整车发货？

## 节点 7 · 到货验收与入库

**目的**：到货物资"规格对、数量对、资料全、外观好"才入账，杜绝不合格流入。

**四要素核验**
1. 规格型号（对照 BOM 编码与请购单）。
2. 数量（清点/过磅/点数）。
3. 随附资料（合格证、CMA/CNAS 检测报告、说明书、原厂授权）。
4. 外观/包装（破损、锈蚀、淋雨）。

**不合格处置**
- 退换 / 降级使用（须审批并留痕）/ 索赔。
- 所有处置记录入台账，关联合同与请购单。

**实战经验（三级审批层级）**
到货问题按严重程度分级处理：

| 层级 | 处理范围 | 参与部门 |
|------|---------|---------|
| 一级 | 一般质量问题（外观瑕疵、数量小误差、资料不全补寄等） | 质检部 + 项目部 |
| 二级 | 中等问题（规格不符、批量缺陷、需退换货等） | 采购部 + 工程管理部 |
| 三级 | 特别重大问题（成套设备不合格、安全隐患、重大索赔等） | 公司层面（高层介入） |

> 大部分日常验收在一级解决， escalate 到二/三级的属于少数但须有明确的升级标准与记录。

**入库建账**
- 按物料编码入账，分区存放（参考 Skill 1 节点 8 仓库布置）。
- 台账字段：编码、名称、规格、批次、数量、库位、到货日期。

**审核清单**
- [ ] 四要素是否逐项核验并签认？
- [ ] 不合格是否按层级处置留痕？
- [ ] 入库是否按编码建账、库位清晰？

## 节点 8 · 领用与限额核销

**目的**：按 BOM 备料量限额发料，过程核销，识别超领。

**限额领料**
- 发料上限 = BOM 备料量（节点 3 算出）。
- 超限额领料须审批，并触发量差预警（节点 12）。

**实战经验（三人签字制）**
- **领料必须三人签字**：班组授权人 + 材料员 + 项目经理。
- 项目经理根据项目进度与每日消耗量，据实评估班组可领数量。
- 无项目经理签字的领料单无效——这是核心控制点。

**核销三栏**
- 已领 / 已用 / 结存，按 BOM 行核销。
- 结存 = 备料 − 已领；完工结存转节点 11 余料退库。
- 防范两风险：
  - **惰性强忘签单**：出入库不走流程，台账失真。
  - **监守自盗模仿代签**：冒领材料须靠签字原件+定期盘点双控。

**审核清单**
- [ ] 领料是否 ≤ 限额？超领是否审批？
- [ ] 是否三人签字齐全（班组授权人+材料员+项目经理）？
- [ ] 核销三栏是否账实同步？

## 节点 9 · 过程盘点与账实核对

**目的**：定期盘点，账实吻合，及时发现异常。

**节奏**：按月/季度，关键物料加密。

**差异成因（重点排查）**
- 损耗超限（施工浪费、工艺不当）。
- 丢失（保管不善、被盗）。
- 串料（专业间混用未核销）。
- 漏签单（惰性，出入库未走流程）。

**实战经验（差异容忍度）**
- **计数类材料（个/台/套/组）**：原则上不允许有差值，须账实完全一致。
- **计量类材料（米/平方米）**：允许极少量误差（受测量精度与切割尾料影响），但超出合理范围须逐条归因。

**纠偏**
- 超领：补审批、补单、责任界定。
- 丢失：报损、追责、保险理赔路径。
- 串料：补核销、内部调拨单。

**审核清单**
- [ ] 盘点是否覆盖全部库位与在用未出库物料？
- [ ] 差异是否逐条归因并处置？
- [ ] 计数类材料是否零差异？计量类误差是否在极小范围内？

## 节点 10 · 变更与 BOM 版本管理

**目的**：设计变更必有量差，须重算 BOM 并签证，避免"口头变更"扯皮。

**流程**
- 变更指令 → BOM 重算（V2→V3）→ 量差清单 → 签证/补充协议。
- 每版 BOM 标注：版本号、日期、变更项、量差（增/减）。

**实战经验（完整变更审批链路）**
变更不是单一部门决定，须走完整链路：

```
项目部(牵头确定变更事宜)
    ↓
设计部(确认可行性)
    ↓
结算部(核定图纸材料量和型号)
    ↓
采购部(核实材料的起订量、价格 — 须明确是否含税含运)
    ↓
结算部(再次核定量、价 → 得出成本和利润)
    ↓
工程管理部(综合评定是否执行该变更/增补)
    ↓
项目部(签订签证)
```

- **时效要求**：
  - 正常情况：一周内出结果（每部门 1–2 天）。
  - 加急情况：工程管理部专人协调，1–2 天内完成。
- **关键控制点**：采购部核实价格时必须明确**是否含税、是否含运费**——这是常见争议源头。

**留痕要点**
- 版本链完整：V1→V2→V3 可追溯。
- 每次变更关联原图号/指令号，便于结算对账。
- 口头变更一律补书面，否则不纳入量差。

**审核清单**
- [ ] 变更是否都刷新了对应 BOM 版本？
- [ ] 量差是否走了签证/补充协议？
- [ ] 版本链是否完整可追溯？
- [ ] 价格是否明确含税/含运状态？
- [ ] 是否在时效窗口内完成？

## 节点 11 · 余料退库与跨项目结转

**目的**：完工余料不浪费，可再用则结转，不可再用则合规处置。

**可再用判定（三标准）**
- 外观完好 / 功能正常 / 配件齐全（同 Skill 1 节点 10）。

**实战经验（结转路径）**
余料处理按以下优先级路径：

1. **统计上报**：将有余料统计好（规格型号、数量、外观照片），发给工程管理部。
2. **调拨优先**：工程管理部核实是否有近期在建项目需要同类材料 → 有则走调拨单流程。
3. **出售回收**：无调拨需求则考虑作价出售/回收（找废品收购渠道）。
4. **废料处理**：再无法利用则与其他废料一起走废料处理流程。

> 注意：每一步都须有书面记录（照片+清单+审批单），残值回收入账。

**废料处置**
- 合规回收/处置，残值回收入账。
- 危废（如含油保温、化学制剂）须走专门合规路径。

**审核清单**
- [ ] 余料是否清点并按三标准判定？
- [ ] 可再用是否先报工程管理部核查调拨可能？
- [ ] 废料是否合规处置、残值入账？
- [ ] 每步是否有书面记录与审批？

## 节点 12 · 结算与量差分析

**目的**：用实际用量复盘 BOM，分因量差，形成结算与经验校准依据。

**量差分析口径**
```
量差 = 实际用量 − BOM 备料量
```
- **设计量差**：变更导致（节点 10 签证量）。
- **施工量差**：损耗/浪费/丢失（节点 3/9）。
- **供应量差**：短装/超装（节点 7）。

**实战经验（与节点 2 量差平衡联动）**
- 结算量差分析与节点 2 的 BOM 审核**采用同一套五类成因分类法**（正常调量/班组原因/项目原因/预算原因/图纸原因），保持口径一致便于追溯。
- **报告结构建议**：
  1. 总览（总备料量 / 总实际用量 / 总量差 / 差异率%）
  2. 分专业量差表（暖通/装饰/电气/给排水/医气/设备）
  3. 分因汇总（设计/施工/供应三类占比）
  4. 异常项明细（差异率超阈值项逐条列因）
  5. 损耗率对比（模板基准 vs 实际 → 校准建议）
  6. 结论与改进建议

**结算依据**
- BOM 版本链（V1/V2/V3）+ 签证 + 出入库台账。
- 损耗率复盘：实际损耗率 vs 模板基准，校准回 `templates/损耗率经验区间表.md`。

**审核清单**
- [ ] 实际用量是否有完整出入库台账支撑？
- [ ] 量差是否按 设计/施工/供应 三分因？
- [ ] 是否与节点 2 五类成因法联动？
- [ ] 损耗率是否回灌校准模板？

## spec 字段说明（供 generate.py）

```json
{
  "project": {"name": "脱敏项目名", "code": "PRJ-001", "date": "2026-07-20"},
  "bom": {
    "version": "V2施工图",
    "rows": [
      {"trade":"暖通","code":"HVAC-01","name":"净化空调机组","spec":"MAU+AHU",
       "unit":"台","net_qty":2,"loss_rate":0,"supply":"乙供",
       "flag":"长交期/大金额","lock":"投标后即锁","note":""}
    ]
  },
  "variance": {
    "rows": [
      {"trade":"电气","name":"阻燃线缆","unit":"米",
       "bom_qty":3090,"actual_qty":3250,"cause":"施工损耗超限"}
    ]
  }
}
```
- `bom.rows[].loss_rate`：小数（0.03 = 3%），生成器算 `备料量 = net_qty×(1+loss_rate)`。
- `supply`：甲供 / 乙供 / 甲指乙供。
- `variance.rows[]`：用于节点 12 量差分析，`cause` 填 设计/施工/供应 三分因之一。
