# 医疗净化工程物料与 BOM 管控

把"医疗净化工程的物料与 BOM"从设计提量到竣工结算的全链路，转化为可复用的**结构化交付物与节点 SOP**。覆盖六个专业（暖通、装饰、给排水、电气、医气、医疗设备），聚焦"量、编码、损耗、核销、版本、余料、量差"，与 `cleanroom-procurement-lifecycle`（采购执行）互补不重复。

## 何时使用

- 用户要生成：**BOM 编制表 / 物料编码分类表 / 甲供乙供划分表 / 损耗率经验区间表 / 限额领料核销单**。
- 用户描述工程物料场景，需要按节点给出流程与产出：设计提量、BOM 审核、损耗备料、甲供乙供划分、物料编码、请购批次、到货验收入库、限额核销、盘点账实、变更版本、余料退库、结算量差。
- 触发词参考：`工程物料`、`BOM 编制`、`物料编码`、`损耗率`、`备料系数`、`甲供乙供`、`甲指乙供`、`限额领料`、`物料核销`、`余料退库`、`量差分析`、`洁净工程物料管控`。

## 工程物料与 BOM 管控节点 SOP（设计提量 → 结算量差）

与采购执行技能不同，本技能盯"物"本身——"买什么、买多少、怎么管、剩多少、差多少"：

1. **设计提量与 BOM 编制**：按招标图/施工图/变更三版编制 BOM，层级 专业→系统→设备/材料/附件辅材，注意设备基础、预埋、附件易漏。
2. **BOM 审核与量差平衡**：图纸量、清单量、经验工程量三方核对，查漏项/重复/单位错/专业接口冲突。
3. **损耗率与备料系数**：备料量 = 净用量 ×(1+损耗率) + 工艺余量；各材料损耗率按经验区间取定，长周期/定制件不宜过量备料。
4. **甲供 / 乙供 / 甲指乙供划分**：依合同界面界定责任边界与交接检、资料流转。
5. **物料编码与分类体系**：建立专业-类别-规格-档次统一编码，支撑 ERP 建账、出入库、盘点与跨项目结转。
6. **请购计划与批次拆分**：依施工进度 + 货期表 + 仓储容量拆批请购，控占压与运费。
7. **到货验收与入库**：到货核验四要素（规格/数量/资料/外观），不合格处置留痕，按编码入库建账。
8. **领用与限额核销**：限额领料、授权专人双签+经理加签，按 BOM 行核销已领/已用/结存。
9. **过程盘点与账实核对**：定期盘点，差异成因含损耗超限、丢失、串料、漏签单。
10. **变更与 BOM 版本管理**：变更→BOM 重算→量差签证，版本留痕避免口头变更争议。
11. **余料退库与跨项目结转**：完工余料退库，三标准判可再用，结转公司库存或废料合规处置残值入账。
12. **结算与量差分析**：实际用量 vs BOM 备料量做损耗率复盘，分设计/施工/供应量差，BOM 版本链+签证+台账作结算依据。

> 各节点深入检查清单、审核要点与决策逻辑见 `references/bom_detail.md`。

## 程序化生成

`scripts/generate.py` 从一份 JSON 项目简述生成 BOM 编制表与量差分析，并做备料量/合计校验：

```bash
python3 scripts/generate.py --demo --out output_demo
python3 scripts/generate.py --spec my_project.json --out output
python3 scripts/generate.py --validate my_project.json
```

spec 结构（详见 `references/bom_detail.md` 末尾"spec 字段说明"）：

```json
{
  "project": {"name": "某三甲医院洁净手术部项目", "code": "PRJ-001", "date": "2026-07-12"},
  "bom": {"version": "V2施工图",
    "rows": [
      {"trade":"暖通","code":"HVAC-01","name":"净化空调机组","spec":"MAU+AHU","unit":"台",
       "net_qty":2,"loss_rate":0,"supply":"乙供","flag":"长交期/大金额","lock":"投标后即锁","note":""},
      {"trade":"电气","code":"ELE-12","name":"阻燃线缆","spec":"WDZ-YJY","unit":"米",
       "net_qty":3000,"loss_rate":0.03,"supply":"乙供","flag":"","lock":"","note":"按回路长度+损耗"}
    ]},
  "variance": {"rows":[
     {"trade":"电气","name":"阻燃线缆","unit":"米","bom_qty":3090,"actual_qty":3250,"cause":"施工损耗超限"}
  ]}
}
```

## 使用步骤

1. 先问清项目画像（医院等级、科室、洁净度、合同界面、工期），不凭空填数。
2. 按用户需要选择交付物：要 BOM→填 `bom`；要编码→填 `coding`；要划分→填 `split`；要损耗→填 `loss`；要核销→填 `issue`。
3. 用 `generate.py` 产出，或指导用户直接复写 `templates/` 空白表。
4. 金额、合同、供应商具体信息以实际项目数据为准；输出中**仅用档次、不用真名、不写成交价**。

## 实战方法论速查（节选自 bom_detail）

> 全节点一句话结论速查；完整检查清单、审核要点与决策逻辑见 `references/bom_detail.md`。

| 节点 | 一句话方法论 |
|------|--------------|
| 1 设计提量 | 招标图/施工图/变更三版 BOM；层级 专业→系统→设备/材料/附件；易漏设备基础/预埋/附件 |
| 2 量差平衡 | 图纸量/清单量/经验量三方核对；查漏项/重复/单位错/专业接口冲突 |
| 3 损耗备料 | 备料量=净用量×(1+损耗率)+工艺余量；长周期/定制件勿过量 |
| 4 甲供乙供 | 甲供收货保管+超供责任；乙供报品牌封样送检；甲指乙供定厂家乙方签约 |
| 5 物料编码 | 专业-类别-规格-档次统一编码；支撑 ERP/盘点/跨项目结转 |
| 6 请购批次 | 施工节点+货期+仓储容量拆批；关键路径优先、长交期早请 |
| 7 到货验收 | 四要素核验（规格/数量/资料/外观）；不合格退换降级留痕；按编码入库 |
| 8 限额核销 | 限额领料+授权专人双签+经理加签；按 BOM 行核销已领/已用/结存 |
| 9 盘点账实 | 定期盘点；差异因损耗超限/丢失/串料/漏签单 |
| 10 变更版本 | 变更→重算→量差签证；版本留痕(V1/V2/V3)防口头变更 |
| 11 余料退库 | 三标准判可再用；结转公司库存或废料合规残值入账 |
| 12 结算量差 | 实际vs BOM备料做损耗复盘；分设计/施工/供应量差；版本链+签证+台账结算 |

- **损耗率基准（通用经验区间）**：线缆/线管 2%–5%、阀门管件 1%–3%、装饰板材 3%–8%、保温 3%–5%、管材 2%–4%——详见 `templates/损耗率经验区间表.md`（已脱敏回填 258 条 / 10 专业系数法基线，含定制件损耗率=1.00 等，按项目须重新校准）。
- **单位换算**：硫酸钡按 3:1/4:1/5:1 配比换算体积比与每立方重量；轻钢龙骨/方管龙骨按间距与墙高换算 m/㎡；乳胶漆按遍数与部位换算 kg/㎡ 与 L/㎡——详见 `templates/单位换算表.md`。
- **甲供乙供边界**：以招标文件/合同界面/清单编制说明为准；甲供物资乙方负责收货、验收、保管，超供损耗责任须书面界定；甲指乙供质量责任链条不因其"指定"而转移（主辅材分类基准见 `templates/甲供乙供划分表.md`）。
- **核销逻辑**：已领 ≤ 备料量（限额）；超领须审批并触发量差分析；结存 = 备料 − 已领，完工结存转余料退库（节点 11）。

## 与采购生命周期技能的关系

- `cleanroom-procurement-lifecycle`（Skill 1）：采购**执行**视角——买、比价、合同、付款、货期、加急、仓库/盘点/余料/资料/维保。
- 本技能（Skill 2）：物料**本体**视角——量、编码、损耗、甲供乙供、核销、版本、量差。
- 衔接点：Skill 1 节点 2/4 的 BOM 与货期表，是 Skill 2 节点 1/6 的输入；Skill 1 节点 8/9/10 的仓库/盘点/余料，是 Skill 2 节点 7/8/9/11 的深化。

## 能力边界

本技能专注于物料本体管理与 BOM 编制，以下事项**不在覆盖范围内**：

| # | 不做什么 | 说明 |
|---|---------|------|
| 1 | 不替代 ERP 系统 | 本技能产出 markdown 文档，不直接对接 ERP/MES/WMS；编码规则可导出但需手工建账 |
| 2 | 不做财务结算 | 量差分析仅到"实际 vs BOM"层面，不含金额/单价/合同价核算（归成本部 skill） |

| 4 | 不提供真实损耗率数据 | 损耗率经验区间为行业通用参考，具体项目须按实测回填校准 |
| 5 | 不处理质量争议 | 材料不合格/降级使用的判定与处置走质检+商务流程 |

## 常见误区与 FAQ

**Q1：BOM 里的损耗率可以直接用模板里的数字吗？**
A：`templates/损耗率经验区间表.md` 中的 258 条数据是**行业通用基线参考**，不是你项目的真实损耗率。不同施工管理水平、工艺方式、材料批次差异很大。正确做法：首版按经验区间估算，施工过程中按实际领料消耗回测校准，最终以实测值为准。

**Q2：甲供材料乙方还要管吗？**
A：要管。甲供物资虽然甲方采购，但乙方负责**收货验收、保管、发放、盘点**。超供部分的责任边界必须在合同中书面界定（谁承担额外费用），否则结算时容易扯皮。甲指乙供同理——甲方指定厂家，但签约和质量责任仍在乙方。

**Q3：量差分析里的"成因"只有三类够用吗？**
A：`generate.py` 默认支持「设计 / 施工 / 供应」三种成因分类。实务中大部分量差确实可以归入这三类：
- **设计量差**：图纸变更、漏项、参数调整 → 需签证支撑
- **施工量差**：损耗超限、浪费、丢失、工艺变更 → 回灌校准损耗率
- **供应量差**：短装、超装、规格偏差 → 关联到货验收记录

如果遇到跨类复杂场景（如"设计变更导致施工返工再叠加供应短装"），可在备注栏补充说明。

**Q4：备料量算多了怎么办？**
A：备料量偏多是常见情况，尤其是首次接触的项目。关键动作：① 完工余料及时退库（节点 11）；② 将实际用量反算回损耗率，更新经验区间表；③ 下次同类型项目用校准后的损耗率，逐步收敛准确度。宁可首次略多备料保工期，也不要因少料停工——加急成本远高于多备几根线管的占用成本。

**Q5：物料编码一定要按你的格式吗？**
A：模板提供的「专业-类别-规格-档次」四层编码是通用推荐格式，不是强制的。如果你的公司已有 ERP 编码体系，直接沿用即可。本技能的价值在于**确保每个物料有唯一标识且贯穿 BOM→请购→入库→领料→核销全链路**，编码格式本身可以适配现有系统。

**Q6：generate.py 提示"supply 非法"怎么办？**
A：`supply` 字段只接受三个值：「甲供」「乙供」「甲指乙供」。检查 JSON 中是否写了其他文字（如"自采""总包供"等）。如果你们公司有第四种供应方式，可以把该行 supply 留空或写备注，不影响 BOM 编制表的生成。

**Q7：单位换算容易出错的地方有哪些？**
A：最容易出错的三类换算：
- **硫酸钡/防护涂料**：配比（3:1/4:1）是体积比，不是重量比，需先查密度再换算每平米用量
- **龙骨/方管**：报价按"根"或"米"，但施工按"㎡墙面"计算，需根据间距×墙高折算
- **乳胶漆/涂料**：桶装按 L 或 kg，涂刷按 ㎡ 计算，需考虑遍数（底漆一遍+面漆两遍=三遍总量）

详见 `templates/单位换算表.md` 的完整对照表。

## 合规边界（必守）

- **脱敏**：项目名用"某 X 级医院净化项目"等；供应商仅标"国产一线/二线/进口高端"等档次，不写真实商号、联系人、合同价、内部额度。
- **不提供违规方案**：串标、围标、回扣、规避招投标、虚增量差套取材料等一律不生成。
- **国标依据**：引用 GB50333、GB51039、GB50751 等时注明版本年号。
- **资质与验收**：医疗净化强依赖净化工程专业承包/机电安装资质与验收规范，决策前建议核对当地卫健/住建要求。
- 本技能内容均为脱敏后的行业通用方法论，不承载任何原任职单位的专有商业数据。
