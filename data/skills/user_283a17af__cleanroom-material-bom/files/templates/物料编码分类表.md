# 物料编码分类表（医疗净化工程）

> 用途：建立统一物料编码规则，支撑 ERP 建账、出入库、盘点与跨项目结转。
> 关联 SOP 节点：节点 5（物料编码与分类体系）。
> 脱敏：档次维度用通用口径（国产一线/二线/进口高端），不含真实商号。

## 编码规则（待补：按你司/项目实际规则填写段长、分隔符、分类字典）
```
建议结构：专业 - 类别 - 规格 - 档次
示例：HVAC-设备-MAU-A1  →  暖通-设备-净化空调机组-国产一线
```
- **专业段**：暖通 HVAC / 装饰 DEC / 给排水 PLM / 电气 ELE / 医气 MGS / 医疗设备 MED
- **类别段**：设备 / 主材 / 辅材 / 附件
- **规格段**：型号或参数简称
- **档次段**：A1 国产一线 / A2 国产二线 / B 进口高端

## 跨项目一致性约定
- 同一实物跨项目编码不变，便于结转与复用识别。
- 档次维度用通用口径，不绑定具体商号，采购时再映射到具体品牌。

## 填写要点
- 编码在 BOM 编制阶段即赋予（节点 1），随 BOM 版本同步。
- 分类字典应覆盖本项目全部专业与类别，避免"同名不同物"。
