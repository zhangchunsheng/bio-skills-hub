# 甲供 / 乙供 / 主辅材划分表（医疗净化工程）

> 用途：明确每项物资"谁买 / 谁验 / 谁保管 / 谁担责"，并给出主材 / 辅材分类基准，支撑 BOM 备料与合同界面核对。
> 关联 SOP 节点：节点 4（甲供 / 乙供 / 甲指乙供划分）。
> 数据来源：行业通用底稿脱敏回填（主辅材划分明细 2021 版）。不含真实商号 / 项目名 / 价格。
> ⚠️ 辅材"包含但不限于"，仅供参考，**不作为双方主辅材结算依据**；具体以合同界面为准。

---

## 一、三种供应方式界面

| 模式 | 谁采购 | 收货 / 验收 / 保管 | 关键风险点 | 书面约定要点 |
|------|--------|-------------------|-----------|-------------|
| **甲供** | 甲方 | 乙方负责收货、验收、保管 | 超供 / 损耗责任、余料处置 | 超供损耗责任须书面界定；余料退甲或结转须约定 |
| **乙供** | 乙方 | 乙方 | 品牌 / 质量 / 资料移交 | 须报品牌 / 封样 / 送检，资料随货移交 |
| **甲指乙供** | 乙方（甲方指定品牌 / 厂家） | 乙方 | 质量责任链条 | "指定"不转移质量责任，须书面明确 |

---

## 二、通用型辅材（所有专业共用）

吊杆、吊杆用角码、拉爆、膨胀螺丝、各类枪钉 / 自攻螺丝、螺杆螺母、电焊条、防锈漆、防火涂料、水泥钉、所有硅胶 / 结构胶（含装饰面美缝硅胶）、发泡剂、美纹纸等。

> 凡未在下文各"主材"项中点名、且属施工中消耗 / 连接 / 固定用途的材料，原则上归入通用型辅材。

---

## 三、主辅材划分明细（按专业）

### 1. 装饰专业
- **主材**
  - 龙骨体系：轻钢龙骨（吊顶主 / 副 / 三角 / T 型 / 边龙骨；墙面天地 / 竖 / 穿心龙骨）；钢制焊接镀锌方管龙骨及所有主副龙骨挂钩、连接件。
  - 铅防护：铅板、硫酸钡水泥。
  - 基层板：硅钙板（水泥板）、硅酸钙板、玻镁板、钢丝网、清漆（部分基层板需处理）。
  - 装饰面板：贴板类（铝塑板 / 索洁板 / 树脂板 / 无机预涂板 / PVC 墙布 / 冰火板 / 洁净铝板）；拼板类（手工 / 机制玻镁彩钢板 / 快装板）；挂板类（电解钢板 / 彩钢板）；焊接类（电解钢板）。
  - 涂料：乳胶漆。
  - 饰面砖：各类墙地砖、大理石窗台板、门槛石、瓷砖阳角条。
  - 地面：PVC 卷材、橡胶卷材、防水涂胶 / 卷材。
  - 门窗细部：各类门 / 窗（只含玻璃，成品成套窗户除外）；门窗洞口各面层包边包角材料（如不锈钢包边，不锈钢为主材）。
- **辅材**：通用型辅材 + 贴板用双面胶 / 结构胶（指定品牌）/ 万能胶 / 清漆 / PVC 墙布胶；拼板用铝型材（外圆柱 / 阴角圆弧及塑料底座 / 三维节点 / T 型铝 / 地槽铝 / H 型铝 / L 型铝）/ 木方 / 镀锌方管 / 角钢；挂板用螺杆螺母；焊接用电焊条；涂料用腻子粉 / 胶水 / 刷子；饰面砖用水泥 / 沙 / 瓷砖胶 / 勾缝剂 / 美缝剂 / 堵漏王；地面用自流平水泥 / 界面剂 / 胶；门窗用基层板（木芯板 / 九厘板 / 免漆板）。

### 2. 暖通专业
- **主材**
  - 暖通水管：镀锌钢管、无缝钢管、UPVC 排水管；管道阀门（各类水阀 / 金属软接 / 橡胶软接 / 水过滤器）；保温（橡塑 / 铝箔橡塑 / 岩棉）。
  - 风管：镀锌风管、复合风管；风管阀门及风口（各类风阀 / 风口 / 过滤器）；保温（橡塑 / 铝箔橡塑 / 岩棉）。
  - 设备及其他：新风机 / 排风机 / 排风箱 / 换气扇 / 模块机 / 螺杆机 / 组合式空调机组 / 风机盘管 / 膨胀水箱 / 散热水箱。
- **辅材**：通用型辅材 + 管材管件（三通 / 弯头 / 直接 / 大小头 / 转接头）/ 生料带 / 麻丝 / 支吊架 / 抗震支架 / 木托 / U 型卡 / 防锈漆 / 标志色；阀门用法兰片及垫片 / 螺杆螺母；保温用万能胶 / 保温棉胶带 / 缠绕膜；风管用角钢法兰 / 三元乙丙密封垫 / 铆钉 / 帆布软接；设备用减震垫 / 减震器 / 支吊架。

### 3. 强弱电专业
- **主材**
  - 基础施工：强弱电线管；线槽 / 桥架（含三通 / 弯头）。
  - 布线：强弱电电线、电缆。
  - 灯具 / 插座 / 等电位：各类灯具、开关插座、等电位接地箱。
  - 设备类：UPS、配电箱、自控柜、弱电机柜、交换机、配线架等。
- **辅材**：通用型辅材 + 线管用接线盒 / 锁扣 / U 型卡 / 骑马卡 / 支吊架；线槽桥架用连接件 / 跨接线 / 螺丝螺母 / 支吊架；布线用电缆头 / 电胶带 / 水晶头 / 线标；灯具插座用底盒；设备用支吊架 / 标签纸等打标耗材。

### 4. 给排水专业
- **主材**
  - 给水管道：不锈钢管、PPR 给水管、纯水用软管；给水保温（橡塑 / 岩棉保温管）。
  - 排水管道：UPVC 管、HDPE 管、铸铁管。
  - 给排水器具：洁具（洗手盆 / 拖把池 / 小便器 / 蹲便器 / 马桶 / 洗婴池 / 刷手池 / 污洗池 / 地漏）；配套配件（水龙头 / 下水管 / 角阀 / 脚踏阀 / 软管 / 不锈钢地漏）。
- **辅材**：通用型辅材 + 管道管件（直接 / 三通 / 四通 / 弯头 / 大小头 / 转接头 / 法兰片 / 法兰密封垫 / 专用支撑架 / 吊件）；支吊架；保温用万能胶 / 保温胶带；管道胶水；洁具用生料带 / 堵漏王 / 结构胶 / 美缝硅胶 / 洁具支架。

### 5. 医气专业
- **主材**
  - 管道及阀门：各类医气阀门、医用不锈钢管、医用铜管、废气排放 UPVC 管。
  - 设备：吊桥、吊塔、医气减压箱、医气报警箱、医气汇流排、设备带、输液导轨。
- **辅材**：通用型辅材 + 管道管件（直接 / 三通 / 四通 / 弯头 / 大小头 / 转接头 / 法兰片 / 法兰密封垫 / 专用支撑架 / 吊件）；支吊架；焊条（铜焊条 / 不锈钢焊条）；阀门管道连接用法兰片 / 密封垫 / 球头球母。

## 四、使用要点
- 提量与备料时，先按本表判定每项"主材 / 辅材"，再叠加 `损耗率经验区间表.md` 的系数法算备料量。
- 供应方式（甲供 / 乙供 / 甲指乙供）须与合同界面逐条核对，避免超供争议与责任推诿。
- 辅材界定"包含但不限于"，实际结算以合同为准；本表仅作 BOM 编制时的分类基准。
