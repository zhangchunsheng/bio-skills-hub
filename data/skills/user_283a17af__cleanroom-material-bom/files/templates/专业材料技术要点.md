# 各专业技术材料选型与质控要点（BOM 编制 / 提料 / 封样参考）

> **用途**：本表为医疗净化工程**各专业技术材料**的品类、常用规格、选型与质控要点速查，供 BOM 编制、设计提料、请购技术参数填写、进场报验与封样送检时参考。
> **来源与脱敏**：内容提炼自行业通用《净化工程专业技术》手册（装饰 / 暖通 / 电气 / 医用气体 / 给排水五大专业），已脱敏、去企业个性参数，仅作方法示范；落地须按本项目施工图、招标技术要求与现行规范（GB 50333、GB 50751、GB 51039 等，注明版本年号）校准。

## 二、暖通专业

| 材料类别 | 常用品类与规格 | 选型 / 质控要点 |
|---------|--------------|----------------|
| 净化空调机组 | 组合式：新风机组（MAU）、循环机组（RAU）、自取新风（AHU）；按水系统分两管制 / 四管制；功能段（混合 / 过滤 / 表冷热 / 加湿 / 出风） | 壁板、风机、密封性高于普通中央空调；两管制（夏冷冬热同季单模）为主，四管制（冷热独立）用于高标科室 |
| 空气过滤器 | G4 初效（≥5μm，效率 90%）；F8 中效袋式（≥0.5μm，85%）；H13 亚高效（≥0.5μm，95%，仅新风段）；送风天花 / 高效风口配 H14 级高效过滤器 | 初效段压差设定≈180Pa、中效≈250Pa、高效≈300Pa 报警更换；亚高效一般仅集中新风段配置 |
| 净化镀锌风管 | 镀锌层≥80g/㎡，角钢法兰（严禁纵向楞，避免积尘）；拼接缝打胶，吊装前内壁清洗、两端密封 | 区别于普通中央空调共板法兰；严密性要求高（中压风系统） |
| 保温材料 | 橡塑保温板 / 管（B1 级，风管及≥DN100 水管）；离心玻璃棉（A 级，蒸汽管） | 防火等级按规范；接缝严密减少冷桥 |
| 风系统部件 | 防雨百叶、防虫网、电动密闭阀、70℃ 防火阀、风量调节阀、定风量阀、消声器 / 消声弯头、帆布软接（三防布） | 防火阀跨防火墙 / 楼板 200mm 内安装；软接减振伸缩 |
| 冷热源 | 风冷模块 / 螺杆机（供水 7℃ / 回水 12℃，制热 45 / 40℃）、水泵、定压补水 / 膨胀水箱、软水器；直喷式（氟利昂）仅非净化区 | 净化区冷热源一般接大楼中央空调；直喷式温度波动大，不用于净化空调 |
| 水系统管材与配件 | ≥DN65 无缝钢管（焊接）；≤DN50 镀锌钢管（丝扣）；阀门（三通 / 二通 / 蝶阀 / 闸阀 / Y 滤 / 软接 / 止回 / 压力表温度计排气阀） | 同程式（水力稳定、能耗略高）/ 异程式（省管材、支管加调节）；旁通阀供检修切换 |
| 自控元件 | DDC / PLC 控制器、温湿度 / 风速 / 风压传感器、压差开关、变频器、断路器、接触器、热继电器 | 强弱电分离；传感器按安装位（回风 / 送风 / 供回水）选型 |

## 三、电气专业

| 材料类别 | 常用品类与规格 | 选型 / 质控要点 |
|---------|--------------|----------------|
| 接地系统 | TN-S 三相五线（L1 黄 / L2 绿 / L3 红 / N 蓝 / PE 黄绿双色） | 保护接地 PE 独立；净化工程强电标准接地制式 |
| 强电设备 | 总 / 分配电柜（双电源自动切换）、电缆（WDZ 低烟无卤阻燃，YJY / BYJ 等）、桥架（镀锌 / 喷涂）、KBG 线管、包塑金属软管 | 配电箱编号 / 功率 / 回路须与设计系统图一致；电缆型号识读（WDZB-YJ(F)E、WDZB-BJY 等） |
| 二类医疗场所电源 | 手术室 / ICU 采用 IT 隔离电源系统（隔离变压器，单相常用 3.15 / 6.3 / 8 / 10kVA）；UPS 应急电源（间温 15–30℃） | IT 系统防电击；UPS 应急时间按规范分区要求；独立房间 + 分体空调 |
| 弱电系统 | 网络 / 电话 / 呼叫 / 背景音乐 / 监控 / 门禁 / 医用气体报警 / 探视；主机、分机、桥架、线管、线缆 | 多系统共用桥架 / 线管，与强电分管或分槽；气体报警联动 |

## 四、医用气体专业

| 材料类别 | 常用品类与规格 | 选型 / 质控要点 |
|---------|--------------|----------------|
| 气体种类 | 氧气、医用空气、医用真空（负压吸引）、笑气、二氧化碳、氮气、氩气 | 终端制式德标 / 英标 / 美标；不同气体插头不得互换 |
| 气源设备 | 液氧储罐（常用 3 / 5m³）、分子筛制氧、真空泵（水环 / 油旋片）、空压机、汇流排（1+1 / 2+2 / 5+5 等）、气体终端、设备带（铝合金，宽 200×高 55）、气体面板、二级稳压箱、阀门箱、报警箱 | 液氧贮氧量大、浓度≥99.5%、压力 0.8MPa；真空废气须灭活排放；汇流排保不间断供气 |
| 管材与焊接 | 脱脂铜管（氧焊）、脱脂不锈钢管（氩弧焊）；废气排放管可用镀锌 / PVC | 进入洁净手术部的气体管道做导静电接地，接地电阻≤10Ω；脱脂处理防燃爆 |

## 使用衔接

- **BOM 编制（Skill 2 节点 1/2）**：本表对应"专业→系统→设备 / 材料 / 附件辅材"层级中的**材料品类与规格**列，作为提量与技术参数填写底稿；设备基础、预埋、附件易漏项须同步计入。
- **甲供乙供（节点 4）**：材料档次（国产一线 / 进口高端）与封样送检要求据此明确；具体商号一律不写。
- **损耗率（节点 3）**：各材料损耗率经验区间见 `templates/损耗率经验区间表.md`（装饰板材 3%–8%、保温 3%–5%、管材 2%–4% 等），与本表品类对应取定。
- **进场报验（Skill 3 节点 2）**：需复试材料（保温 / 线缆 / 给水管 / 防水 / 饰面板 / 阀门等）报验时同步留样，复试报告归入材料复试核查要录。
