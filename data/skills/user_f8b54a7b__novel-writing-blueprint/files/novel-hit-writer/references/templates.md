# Markdown 模板库（含字段定义）

所有交付物落盘到 `./novel/<作品名>/`。每个模板字段下方标注**字段定义**与**约束**。

---

## 模板一：爆款基因表 `gene_table.md`

```markdown
# 爆款基因表：《{{作品名}}》

| 字段 | 值 | 字段定义 |
|------|----|----------|
| 情绪标签(emotion_tag) | {{主情绪，唯一}} | 全本情绪设计方向，只能一个 |
| 题材与风格(genre) | {{题材}} | 世界观与语境 |
| 主角设定(protagonist) | {{性别+身份+处境}} | 读者代入锚点 |
| 最大反差(contrast_point) | {{表面↔真实}} | 爽点/张力来源，必须成立 |
| 核心冲突(core_conflict) | {{一句话矛盾}} | 贯穿全本的主线引擎 |
| 章节数(chapters) | {{整数}} | 节奏预算 |

## 备注(notes)
- {{用户附带的其他有效信息}}

## 状态
- [ ] 6 项已确认，可进入规划阶段
```

**字段约束**：emotion_tag 唯一；contrast_point 须成立；core_conflict 撑满全本；任意项为"建议值"需显式标注待确认。

## 模板三：章节正文 + 质量报告 `chapter.md`

```markdown
# 第 {{N}} 章 《{{章名}}》

> 情绪定位：{{压/小扬/爆}} ｜ 钩子类型：{{类型}} ｜ 字数：{{n}}

{{正文，2200-2800 字}}

---

## 质量报告
| 指标 | 结果 | 说明 |
|------|------|------|
| 字数 | {{pass/fail}} | {{n}} |
| 前 50 字 | {{pass/fail}} | {{}} |
| 前 20% 冲突 | {{pass/fail}} | {{}} |
| 对话占比 | {{pass/fail}} | {{x%}} |
| 结尾钩子 | {{pass/fail}} | {{类型}} |
| 钩子轮换 | {{pass/fail}} | 与上章不同 |
| 金句 | {{位置}} | {{摘录}} |
| 18 项自查 | {{x/18 通过}} | {{fail_count>=3 则退回}} |

```

**字段定义**：情绪定位/钩子类型同上；金句位置标注在正文第几段；质量报告由 `validate_chapter.py` + `quality_check.py` 输出填充。

## 模板四：节奏反馈 `feedback.md`

```markdown
# 节奏反馈报告（第 {{k*5}} 章）

## 本段概览
- 情绪曲线实际 vs 计划：{{偏差}}
- 钩子类型分布：{{}}
- 爆点密度：{{每 3 章是否都有推进}}

## 数据趋势（有后台则填）
- 完读率：{{}}
- 追读率：{{}}
- 评论关键词：{{}}

## 后续 5 章调整建议
- {{增/减什么、调哪个人物、改哪类钩子}}

## 预警
- [ ] 连续 3 章完读下降 → 回退大纲阶段
```

**字段定义**：k 为第几轮 5 章（1,2,3…）；爆点密度代理指标在无后台时使用；预警项触发即暂停生产。
