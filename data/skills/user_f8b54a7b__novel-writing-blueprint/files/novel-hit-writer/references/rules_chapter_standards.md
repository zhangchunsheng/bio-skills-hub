# 逐章硬标准（含平台变量）

章节不是"写完就算"。每章交付前必须满足以下硬标准。数值为番茄默认，非番茄平台按变量调整。

## 硬标准清单

| 指标 | 番茄默认 | 说明 | 平台变量 |
|------|----------|------|----------|
| 字数 | 2200-2800 | 低于 2200 扩充，高于 2800 精简 | 起点 3000-4000 / 晋江 2000-3000 |
| 前 50 字 | 含动作/冲突/悬念至少一项 | 黄金位置 | 通用 |
| 前 20% 内容 | 必须出现即时冲突 | 不能慢热 | 通用 |
| 对话占比 | 35%-45% | 用引号内字符数 / 总字数估算 | 言情可上调至 50% |
| 结尾钩子 | 必须有，且不与上一章同类型 | 钩子类型见下 | 通用 |
| 钩子轮换 | 不得连续两章同类型 | 防读者麻木 | 通用 |

## 钩子类型（轮换池）

1. 信息揭示（抖出秘密/真相）
2. 危境预警（危险逼近）
3. 反差展示（人设/实力反差）
4. 倒计时（期限压迫）
5. 人物登场（关键人物出现）
6. 悬念断点（"就在这时……"类，慎用，避免每章用）

## 校验口径（供 `scripts/validate_chapter.py`）

- 字数：统计中文字符数（去除空格/标点可配置）。
- 前 50 字：命中动作词库 / 冲突词库 / 悬念标记（？、难道、竟、忽然、原来…）任一即合规。
- 对话占比：引号内字符 / 总字符，落在区间即通过。
- 钩子轮换：本章钩子类型须与传入的上一章钩子类型不同。

## 衔接

本标准由 `validate_chapter.py` 自动检查，结果进质量报告。不通过项列出具体修改点后退润色。
