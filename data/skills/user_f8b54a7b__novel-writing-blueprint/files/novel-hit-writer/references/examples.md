# 3 个真实案例示例

以下案例按本 Skill 流程走通，展示"6 问 → 规划 → 第一章 → 质量报告"的端到端样子。案例设定取自原文档方法论，扩写为可用样例。

---

## 案例一：打脸爽文

### 6 问基因表
| 字段 | 值 |
|------|----|
| 情绪标签 | 打脸爽文 |
| 题材 | 都市现实 |
| 主角 | 女性，前豪门弃妇 |
| 反差 | 被虐后觉醒反杀（表面柔弱弃妇 → 隐藏身份大佬） |
| 核心冲突 | 复仇雪恨 |
| 章节数 | 50 章 |

### 适合方向
前夫看不起她，婆家羞辱她，离婚后靠隐藏身份翻盘。前三章必须把"羞辱、反击、身份悬念"全部打出来。

### 黄金开篇（冲突前置型，前 50 字）
> 婆婆把离婚协议甩在她脸上："顾家丢得起这人，你这种货色也配进顾家？"她低头看着脚尖，没人看见她嘴角那抹冷笑。

### 第 1 章片段（压）
> 结婚三年，她住的是客房，吃的是剩饭。今天这场寿宴，全家人当着宾客的面，把她的礼服泼了红酒。"扫地出门吧。"前夫说得轻描淡写。她没哭，只是把那张被踩过的股权代持协议，悄悄折好塞进了袖口。

### 质量报告（摘要）
字数 2450 ✅｜前 50 字含冲突 ✅｜对话占比 41% ✅｜钩子：反差展示（股权协议）✅｜18 项 17/18 通过（缺金句，补一句"她等的不是离婚，是这天。"后交付）

## 案例二：追妻火葬场

### 6 问基因表
| 字段 | 值 |
|------|----|
| 情绪标签 | 极致虐恋 |
| 题材 | 现代言情 |
| 主角 | 双主角 |
| 反差 | 男主醒悟太晚（表面冷漠掌控 → 失去后才知深爱） |
| 核心冲突 | 爱情阻碍（误会与骄傲） |
| 章节数 | 100 章 |

### 适合方向
前期误会要狠，中期追悔要痛，后期复合不能太轻易。每个情绪单元让读者在"虐"和"想看他后悔"之间来回拉扯。

### 黄金开篇（悬念钩子型，前 50 字）
> 她把婚戒放在他书桌那刻，手机弹出一条消息："移植手术成功，受捐者生命体征平稳。"他盯着那行字，第一次发现她的血型，他从来没问过。

### 第 1 章片段（压）
> "你以为用辞职就能威胁我？"他冷笑。她没解释，只是把那份攒了两年假条的离职单轻轻放下。门合上的声音很轻，他却忽然觉得，这屋子空了一块，再也填不回来。

### 质量报告（摘要）
字数 2380 ✅｜前 50 字含悬念 ✅｜对话占比 44% ✅｜钩子：信息揭示（血型/移植）✅｜18 项 18/18 ✅（金句："这屋子空了一块，再也填不回来。"）

## 案例三：系统流爽文

### 6 问基因表
| 字段 | 值 |
|------|----|
| 情绪标签 | 脑洞系统 |
| 题材 | 都市现实 |
| 主角 | 男性，外卖员 |
| 反差 | 隐藏大佬装萌新（表面底层外卖员 → 系统傍身的逆袭者） |
| 核心冲突 | 成长突破 |
| 章节数 | 100 章 |

### 适合方向
主角开局够低，系统奖励够直观，打脸对象够讨厌。每 3 章至少完成一次小逆袭，让读者不断获得正反馈。

### 黄金开篇（人设立体型，前 50 字）
> 站长把差评单拍他桌上："这个月第五单了，不想干滚蛋。"他低头赔笑，脑里却响起一声：[叮——逆袭系统绑定，当前积分：0。]

### 第 1 章片段（压→小扬起点）
> 暴雨天，他摔在泥里，餐盒全洒。差评跳出来的瞬间，系统提示：[触发任务：获得十位路人点赞，奖励"神级车技"。]他抹了把脸爬起来——这是他第一次，想把命攥回自己手里。

### 质量报告（摘要）
字数 2520 ✅｜前 50 字含动作+系统钩子 ✅｜对话占比 38% ✅｜钩子：人物登场（系统音）✅｜18 项 16/18（形容词略多，删 2 处后交付；金句："想把命攥回自己手里。"）
