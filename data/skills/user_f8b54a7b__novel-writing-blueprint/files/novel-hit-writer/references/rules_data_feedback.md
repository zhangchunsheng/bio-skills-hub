# 每 5 章数据反馈规则

真正做网文不能闭门写到完结。读者数据会说话。每完成 5 章做一次节奏报告与数据反馈，用数据调后续。

## 反馈触发

- 每累计 5 章，运行一次节奏复核，产出节奏报告（见 `templates.md` 的 `feedback`）。
- 数据源：平台后台的完读率、追读率、评论关键词；无后台时用"章节钩子有效性 + 情绪密度"代理指标。

## 四类调整动作

| 信号 | 动作 |
|------|------|
| 爆点密度低 | 后续章节增加爆点（提前兑现反差/打脸） |
| 某类钩子完读率高 | 后续提高该钩子类型使用频率 |
| 某个配角评论区讨论热烈 | 适当增加该配角戏份 |
| 连续 3 章完读下降 | 回退大纲阶段，调整后续规划 |

## 节奏报告字段

- 本 5 章情绪曲线实际 vs 计划偏差。
- 钩子类型分布与轮换健康度。
- 爆点密度（每 3 章是否都有小逆袭/推进）。
- 完读/追读趋势（有数据则填，无则标"代理指标"）。
- 后续 5 章调整建议（具体：增/减什么、调哪个人物）。

## 红线

连续 3 章完读下降信号 → **暂停生产**，回大纲阶段复盘，不硬写扩大损失。这与 SKILL.md 边界处理一致。
