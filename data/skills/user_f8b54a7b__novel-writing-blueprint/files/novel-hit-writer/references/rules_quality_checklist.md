# 18 项质量自查清单

每章结束跑 `scripts/quality_check.py`。**任 3 项以上不通过 → 退回润色，不硬交付。** 清单与脚本项一一对应。

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 字数达标 | 2200-2800（按平台变量） |
| 2 | 前 50 字合规 | 含动作/冲突/悬念至少一项 |
| 3 | 前 20% 即时冲突 | 前 20% 出现冲突事件 |
| 4 | 对话占比达标 | 35%-45% |
| 5 | 结尾有钩子 | 末段存在钩子 |
| 6 | 钩子非连续重复 | 与上一章钩子类型不同 |
| 7 | 无低效开头 | 非天气/起床/长篇外貌/世界观/自我介绍式 |
| 8 | 形容词密度不过高 | < 15% |
| 9 | 四字词密度不过高 | 无连续 3+ 四字词 |
| 10 | 角色说话方式差异化 | 主要角色语言标签可区分 |
| 11 | 无情绪直述堆砌 | 无"XX地说"式堆砌 |
| 12 | 含金句 | ≥1 句可摘录短句 |
| 13 | 主角人设一致 | 与人物档案/前文无打架 |
| 14 | 核心冲突贯穿 | 本章推进核心冲突 |
| 15 | 有情绪推进 | 非"平"，情绪有变化 |
| 16 | 信息密度够 | 无大段冗余说明 |
| 17 | 钩子类型轮换 | 落在 6 类轮换池且非连重复 |
| 18 | 符合情绪曲线 | 本章情绪定位与曲线一致 |

## 退回逻辑

```
fail_count = 不通过项数
if fail_count >= 3:
    状态 = "退回润色"
    输出 = 不通过项的具体修改点列表
else:
    状态 = "可交付"（建议项仍提示优化）
```

## 注意

- 第 13、14、18 项依赖跨章上下文（人物档案、情绪曲线、前文），脚本做启发式检测，最终以人审为准。
- 清单可随平台/题材扩展，扩展后同步更新 `quality_check.py` 的 `CHECKS` 定义。
