# CTD 临床部分医学撰写要点

> 供 `drug-medical-prelaunch` Skill 在 P4(注册申报医学支持) 环节引用。
> 用途：给 CTD 临床部分(M2.5 临床综述 / M5 临床研究概要)的医学撰写框架。
> 注：本文件只给医学撰写框架，注册流程主责 RA(见 SKILL §8 边界声明)。

## 1. CTD 临床部分结构

### 1.1 M2.5 临床综述（Clinical Overview）
- 性质：对临床数据的**批判性综合分析**，不是数据罗列
- 长度：通常 50-100 页
- 核心要求：展示对临床数据的深度理解和医学判断

### 1.2 M2.5 章节框架
```
1. 产品概述（适应症/药理类别/作用机制/剂型）
2. 适应症概述（疾病背景/现有治疗/未满足需求）
3. 临床开发概要（开发计划/研究列表/研究设计汇总）
4. 生物药剂学概述（BA/BE/食物影响，与药学协同）
5. 临床药理学概述（PK/PD/群体PK/特殊人群PK）
6. 有效性概述
   6.1 主要有效性研究（逐研究呈现：设计/人群/终点/结果）
   6.2 次要有效性研究
   6.3 药效-剂量关系
   6.4 不同亚群有效性（年龄/性别/种族/肝肾功能）
   6.5 有效性的综合分析
7. 安全性概述
   7.1 暴露程度（总暴露人数/暴露时长/剂量范围）
   7.2 不良事件汇总（总体/常见/严重/导致停药）
   7.3 特定不良事件分析（机制相关/靶点相关/已知风险）
   7.4 实验室检查异常
   7.5 生命体征/ECG/体检异常
   7.6 特殊人群安全性
   7.7 安全性综合分析
8. 有效性-安全性综合评价
9. 利益-风险综合评估
10. 上市后计划（RWE/PASS/风险管理）
```

### 1.3 M5 临床研究概要（Clinical Summary）
- 性质：临床研究结果的**结构化整合呈现**，比 Overview 更数据化
- 长度：通常更长，以表格为主
- 与 M2.5 的区别：M5 是"数据整合"，M2.5 是"数据解读"

### 1.4 M5 章节框架
```
1. 生物药剂学研究概要（BA/BE）
2. 临床药理学研究概要（PK/PD/群体PK）
3. 临床有效性概要（按研究呈现 + 综合分析表）
4. 临床安全性概要（暴露/不良事件/严重事件/实验室异常）
5. 上市后经验（如有境外上市数据）
6. 文献参考
```

## 2. 医学撰写核心要求

### 2.1 数据呈现原则
- 每个结论须有数据支撑（研究名/样本量/结果/统计量）
- 不利数据不能隐藏，但可以解释（数据透明是合规要求）
- 亚组分析须预设(preregistered) vs 事后(post-hoc)分别标注
- 间接对比须标注局限

### 2.2 利益-风险评估
```
利益-风险 = 利益(有效性证据强度 × 临床获益大小) 
          - 风险(安全性信号严重性 × 发生频率 × 可管理性)
          + 未满足需求(现有治疗不足程度)
          - 替代方案(竞品的相对优势)
```
- 须给出明确的利益-风险结论，不只是描述
- 须说明风险管理计划(上市后监测/PASS/说明书警示)

## 3. 说明书医学内容审定要点

### 3.1 关键章节医学依据
| 说明书章节 | 医学审定要点 |
|---|---|
| 适应症 | 每个适应症须有获批研究支撑；措辞须与获批范围一致 |
| 用法用量 | 剂量须有 PK/PD 和 III 期数据支撑；剂量调整须有依据 |
| 禁忌 | 须基于安全性数据(严重不良事件/已知风险) |
| 不良反应 | 须与临床研究安全性数据一致；频率分级(十分常见/常见/少见/罕见) |
| 注意事项 | 须覆盖临床试验中发现的需特别关注的安全性信号 |
| 特殊人群 | 孕妇/哺乳/儿童/老年/肝肾功能不全的数据或缺失说明 |
| 药物相互作用 | 须基于 DDI 研究和 PK 数据 |

### 3.2 说明书措辞红线
- 禁止超出获批范围(适应症/人群/用法)的表述
- 禁止暗示未经数据支撑的优势(如"优于所有现有治疗")
- 禁止省略重要安全性信息(即使对推广不利)
- 措辞须与审评沟通确认一致

## 4. 发补回复医学准备

### 4.1 常见发补类型
- 临床数据补充(亚组分析/长期随访数据/特定人群数据)
- 安全性补充(特定不良事件的详细分析/暴露量补充)
- 统计分析补充(敏感性分析/不同统计方法验证)
- 说明书修订(措辞调整/安全性信息补充)

### 4.2 回复框架
```
1. 发补问题复述
2. 补充数据/分析（完整呈现，非选择性引用）
3. 结论（直接回答发补问题，不绕弯）
4. 依据溯源（数据来源/研究名称/表格编号）
```

## 5. 常见陷阱
- M2.5 写成数据罗列而非批判性分析 → 审评员看不到医学判断
- 不利数据隐藏或淡化 → 审评发现后信任崩塌
- 说明书措辞超出获批范围 → 合规风险
- 亚组分析不标注预设/事后 → 统计学质疑
- 利益-风险评估只描述不给结论 → 审评无法判断
