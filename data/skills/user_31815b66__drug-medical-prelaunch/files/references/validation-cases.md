## 案例 1 · 卡度尼利单抗（康方 AK104，PD-1/CTLA-4 双抗）CDP 医学输入

### 1. 元数据头
- 分析对象：卡度尼利单抗注射液（Cadonilimab，AK104，商品名：开坦尼）
- 开发阶段：已附条件获批（2022-06），本案例聚焦"后续适应症 CDP 医学输入"
- 分析视角：上市前医学 · 临床开发策略输入（P2）+ 竞品分析（P7）/ 资深模式
- 数据截至：2026-07
- 证据等级总览：L1（NMPA 批件 + 企业里程碑）+ L2（临床年度进展）

### 2. 执行摘要
- 🔍 全球**首个获批的 PD-1/CTLA-4 双特异性抗体**，2022-06 附条件批准用于含铂化疗失败的 r/m 宫颈癌。
- 🔍 后续适应症布局：一线宫颈癌 sNDA 2024-04 受理（AK104-303）、一线胃癌 2024-01 受理（💭 企业披露）。
- 💭 关键临床 COMPASSION-03（NCT04982237 随机对照进行中）为宫颈癌扩展提供支撑；单臂 II 期缺乏随机对照是首发获批的固有局限。
- 🔍 全球首创双免疫检查点双抗，差异化在于"一药双靶点"潜在减毒（高剂量伊匹木单抗毒性限制其应用，本品在保持活性下安全性较好）。

### 3. 主体（聚焦 P2 / P7）
- **P2 临床开发策略输入**：
  - 适应症选择：首发选"含铂失败 r/m 宫颈癌"（未满足需求大、单臂可批）→ 拓展一线全人群（AK104-303 随机对照，🔍 企业公告）。
  - 对照药选择：一线宫颈癌对照为"含铂化疗 ± 贝伐珠单抗"（标准治疗），合理（💭 设计推断）。
  - 终点：主要终点 OS/PFS（💭 待文献确认具体终点）。
- **P7 竞品分析**：同类双抗/联合（PD-1 + CTLA-4 联合如 O+Y）为间接对照；本品优势=单一分子双阻断、潜在更好安全窗。⚠️ 间接对比局限：人群/终点不同，不得宣称"优于联合方案"。
- **P1 领域全景**：宫颈癌后线免疫治疗空白大，含铂失败患者选择少（💭 流行病学待补）。

### 4. 关键结论与行动建议
- 医学定位："双靶点协同、潜在更优安全窗的差异化双抗"。
- 建议：跟踪 AK104-303 读出以支撑一线全人群标签；准备与 O+Y 的间接对比证据包（须标局限）。

### 5. 不确定性·待核实清单
- ⚠️ 待核实：AK104-303 主要终点与具体设计（💭 仅知为随机对照一线宫颈癌，建议查 ClinicalTrials.gov NCT04982237）。
- ⚠️ 待核实：胃癌一线 sNDA 研究代号与终点（💭 企业披露未给研究号）。
- ⚠️ 待核实：单臂 II 期 ORR/OS 具体数值（未公开披露，待临床数据公开后补充 💭）。

### 6. 信息来源与证据等级
- 🔍 康方生物里程碑页 / 2024-04-24 新闻（sNDA 受理），L1。
- 🔍 NMPA 附条件批准（2022-06），L1。
- 💭 《中国临床肿瘤学年度研究进展.2023》COMPASSION-03，L2。

## 案例 2 · 德曲妥珠单抗（T-DXd，优赫得）上市前 RWE 布局与竞品分析

### 1. 元数据头
- 分析对象：注射用德曲妥珠单抗（Trastuzumab deruxtecan，T-DXd，优赫得）
- 适应症：HER2+ 乳腺癌 / HER2 低表达乳腺癌 / HER2+ 胃癌（中国已获批多适应症）
- 分析视角：上市前医学 · 上市前 RWE 布局（P5）+ 竞品分析（P7）/ 资深模式
- 数据截至：2026-07
- 证据等级总览：L1（NMPA/企业公告）+ L2（CSCO 指南/研究）

### 2. 执行摘要
- 🔍 2023-02-21 中国首发获批（HER2+ 乳腺癌），后陆续获批 HER2 低表达乳腺癌（2023-07）、HER2+ 胃癌（2024-08，DESTINY-Gastric06）等。
- 🔍 DESTINY-Gastric06（中国 II 期）：确认 ORR 28.8%，mPFS 5.7 个月（🔍 阿斯利康 2024-08 新闻）。
- 💭 竞品维迪西妥单抗（RC48）C008：胃癌 ORR 24.4%，mOS 7.9 个月——二者头对头缺失，只能间接对比。
- 🔍 HER2 低表达（IHC 1+/2+ ISH-）为 T-DXd 开拓的全新人群，是核心差异化。

### 3. 主体（聚焦 P5 / P7）
- **P5 上市前 RWE 布局**：单臂/II 期获批后，须补真实世界疗效与安全性（尤其 ILD 间质性肺病这一黑框相关信号）；外部对照可用历史化疗队列；自然史研究 HER2 低表达真实人群分布（支撑定位）。
- **P7 竞品分析**：T-DXd vs RC48 vs T-DM1（胃癌二线阴性）。⚠️ 间接对比局限：研究人群（HER2 阈值/线数）不同，不得宣称"优于 RC48"；胃癌头对头缺失。
- **P8 证据路线图**：HER2 低表达、NSCLC（HER2 突变 2024-10）等拓展窗口。

### 4. 关键结论与行动建议
- 定位："跨癌种、覆盖 HER2 低表达的 ADC 标杆"。
- 建议：上市前即规划 ILD 真实世界登记与 HER2 低表达自然史研究；准备与 RC48 的间接对比证据（标局限）。

### 5. 不确定性·待核实清单
- ⚠️ 待核实：T-DXd 各适应症精确批准文号与日期（💭 企业/新闻披露年份，建议查 NMPA）。
- ⚠️ 待核实：DESTINY-Gastric06 中位 OS 与 ILD 发生率具体值（💭 新闻仅给 ORR/mPFS，建议查原文）。

### 6. 信息来源与证据等级
- 🔍 阿斯利康中国新闻（2024-08-13，胃癌获批 + DG06 数据），L1。
- 💭 CSCO 胃癌指南 2022（引用 DESTINY-Gastric01 ORR 51% vs 14%），L2。
- 🔍 NMPA 批准时间线（2023-02 首发），L1。

## 案例 3 · 替雷利珠单抗（百济 Tislelizumab）注册申报医学支持（美欧）

### 1. 元数据头
- 分析对象：替雷利珠单抗注射液（Tislelizumab，TEVIMBRA，百泽安）
- 适应症：食管鳞状细胞癌（ESCC）二线 / 非小细胞肺癌（NSCLC）
- 分析视角：上市前医学 · 注册申报医学支持（P4）/ 资深模式
- 数据截至：2026-07
- 证据等级总览：L1（FDA/EC 批准 + 企业公告）+ L2（RATIONALE 302）

### 2. 执行摘要
- 🔍 美国 FDA 2024-03 批准 ESCC 二线（基于 RATIONALE 302，全球随机开放试验，ITT 达主要终点）。
- 🔍 欧盟 EC 2024-04 批准 3 项 NSCLC 适应症（一线鳞癌/非鳞癌 + 二线）。
- 🔍 设计特点：IgG4 改造减少 FcγR 结合（差异化机制叙述）。
- 💭 美欧申报的境外数据适用性：RATIONALE 302 为 MRCT，含多区域人群，可支持 FDA/EMA（符合 ICH E5 种族考量）。

### 3. 主体（聚焦 P4）
- **P4 注册申报医学支持**：
  - M2.5 临床综述逻辑链：ESCC 二线 unmet need → RATIONALE 302 设计（vs 研究者选择化疗）→ 主要终点 OS 显著 → 安全性可接受 → 获益风险正向。
  - 说明书医学审定：ESCC 二线剂量 200mg q3w（💭 参照同类 PD-1，建议查 FDA label）；禁忌/警告须含免疫相关 AE。
  - 特殊路径：FDA 常规批准（非加速），因 OS 为主要终点（🔍 企业公告）。
- **境外数据适用性（呼应 drug-reg 闸门3）**：MRCT 含中国以外人群，种族敏感性已内部论证；境内已获批 14 项适应症（💭 企业披露）。

### 4. 关键结论与行动建议
- 医学证据包完整，OS 硬终点支撑常规批准。
- 建议：发补预案聚焦 MRCT 各区域一致性；说明书中美欧对齐（label alignment）。

### 5. 不确定性·待核实清单
- ⚠️ 待核实：FDA label 具体剂量与警告语（💭 推断 200mg q3w，建议查 FDA 说明书）。
- ⚠️ 待核实：RATIONALE 302 具体 HR/中位 OS 数值（💭 仅知"显著"，建议查原文）。

### 6. 信息来源与证据等级
- 🔍 百济神州/FDA/EC 批准新闻（2024-03/04），L1。
- 🔍 RATIONALE 302（NCT03430843）设计披露，L2。
- 💭 企业披露国内 14 项适应症，L3。
