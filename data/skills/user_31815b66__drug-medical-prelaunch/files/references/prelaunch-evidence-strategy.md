# 上市前证据策略指南

> 供 `drug-medical-prelaunch` Skill 在 P2(临床开发策略)、P5(上市前RWE布局)、P8(证据路线图) 环节引用。
> 用途：统一上市前证据生成的策略框架，避免证据碎片化和缺口遗漏。

## 1. 临床开发计划（CDP）医学输入框架

### 1.1 CDP 核心要素
```
CDP = 适应症选择 + 目标人群 + 对照选择 + 终点设计 + 统计计划 + 样本量 + 时间线
```

### 1.2 适应症选择策略
- **首发适应症**：选最快获批路径（未满足需求大 + 证据门槛相对清晰 + 临床可行）
- **拓展路径**：首发获批后按优先级拓展（大适应症→特殊人群→联合用药）
- 决策依据：流行病学(患者池) + 现有治疗(未满足需求) + 竞品布局(时间窗口) + 临床可行性(入组难度)

### 1.3 对照药选择
| 对照类型 | 适用场景 | 要点 |
|---|---|---|
| 阳性对照(标准治疗) | 有标准治疗的领域 | 优效/非劣效设计；对照药选择须是当前标准(SOC) |
| 安慰剂对照 | 无标准治疗/辅助治疗 | 伦理审查关键；需有抢救方案 |
| 剂量对照 | 剂量探索(II期) | 确定最优剂量窗口 |
| 外部对照(RWE) | 罕见病/单臂试验 | 用RWE做历史基线，须论证可比性 |

### 1.4 终点设计
- **主要终点**：注册所需，须与监管沟通确认可接受性
  - 临床终点(直接测量临床获益：OS/PFS/主要不良事件)
  - 替代终点(间接：血压/血脂/生物标志物) → 须论证与临床结局的关联
- **次要终点**：补充主要终点，支撑说明书 claim
- **探索性终点**：为后续适应症拓展铺路
- **关键提醒**：替代终点获批后可能被要求补上市后确证性研究(附条件批准)

## 2. 上市前 RWE 布局

### 2.1 RWE 在上市前的用途
| 用途 | 说明 | 举例 |
|---|---|---|
| 外部对照 | 单臂试验用RWE做历史/外部基线 | 罕见病无标准治疗，用既往队列做对照 |
| 疾病自然史 | 证明疾病严重性和未满足需求 | 罕见病自然史研究支撑临床价值论证 |
| 现有治疗格局 | 为试验设计提供真实诊疗参照 | 真实世界中患者怎么治的、达标率多少 |
| 终点替代验证 | 验证替代终点与临床终点的关联 | 用RWE证明生物标志物与结局相关 |
| 流行病学 burden | 支撑产品临床价值论证 | 疾病负担数据用于申报和准入预输入 |

### 2.2 上市前 RWE 设计要点
- 数据源选择：医院电子病历 / 登记研究 / 医保数据库 / 登记平台
- 偏倚控制：选择偏倚、混杂因素、测量偏倚
- 可比性论证：外部对照与试验人群的可比性(人群特征/诊疗标准/随访期)
- 局限标注：RWE 结论须显式标注局限(详见 SKILL §7 闸门3)

### 2.3 上市后 RWE 预布局
上市前就识别"注册研究能解决什么、还会缺什么"：
```
注册研究覆盖 → 上市后还缺什么 → 预布局 RWE 计划
  疗效(RCT)     → 真实世界有效性 → 上市后 RWE 有效性研究
  安全性(RCT)   → 大人群长期安全 → 上市后安全性登记/PASS
  主要人群      → 特殊亚群       → 上市后亚组 RWE
  短期终点      → 长期结局       → 上市后长期随访 RWE
```

## 3. 证据缺口分析与路线图

### 3.1 证据缺口识别
```
证据缺口 = 申报所需证据 - 现有/计划中的证据
```
逐维度检查：
- 疗效证据：主要终点够不够？亚组数据有没有？
- 安全性证据：样本量够不够暴露罕见不良事件？长期安全性？
- 特殊人群：儿童/孕妇/老年/肝肾功能不全？
- 竞品对比：有没有 head-to-head？没有怎么补？
- 真实世界：RCT 结果在真实诊疗中能否复制？

### 3.2 证据生成路线图（3-5 年）
| 时间段 | 证据类型 | 目的 | 衔接 |
|---|---|---|---|
| 上市前 | 注册 RCT(III期) | 获批 | → 申报 |
| 上市前 | 上市前 RWE(外部对照/自然史) | 辅助申报 | → 申报补充 |
| 上市当年 | IV期/PASS | 法规要求/安全性确证 | → 上市后医学 |
| 上市 1-2 年 | RWE 有效性补充 | 真实世界证据 | → 准入支持/竞品对比 |
| 上市 2-3 年 | IIS 适应症探索 | 新适应症 | → 再注册 |
| 上市 3-5 年 | 长期结局 RWE | 长期获益证据 | → 生命周期管理 |

### 3.3 竞品时间窗口
- 识别同类竞品的临床进展阶段(临床前/I/II/III/申报/获批)
- 估算我们的获批时间 vs 竞品获批时间 → 独占窗口
- 独占窗口内要完成：循证积累 + KOL 建设 + 指南纳入 + 品牌心智

## 4. 常见陷阱
- 只关注注册研究，忽略 RWE 布局 → 上市后证据不足，准入被动
- 终点设计不考虑临床实操 → 入组困难/数据外推性差
- 证据缺口识别太晚 → 上市后临时补，节奏混乱
- 外部对照不做偏倚控制 → 审评质疑可比性
- 竞品时间窗口误判 → 独占期被压缩
