# 医药小红书爆款生成器

## 这个技能解决什么问题

医药/健康品类商家做小红书时面临三个核心痛点：

1. **不知道哪些词会违规** — 一句"治疗""100%有效"可能直接限流或下架
2. **不懂小红书爆款结构** — 通用模板套到医药品类，要么不火，要么被举报
3. **生成的内容不像人话** — 一眼 AI 味，用户划走

本技能把医药合规话术 × 小红书爆款结构 × 去 AI 味表达三者打包，让商家在 30 秒内拿到可发布的笔记初稿。

## 输入参数

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 产品名 | 是 | 产品/服务名称 | "维生素 D3 软胶囊" |
| 核心卖点 | 是 | 1-3 个核心功效/特点 | "促进钙吸收、无腥味、儿童可用" |
| 目标人群 | 是 | 主要受众标签 | "新手妈妈 / 久坐上班族 / 中老年" |
| 内容类型 | 否 | 测评 / 科普 / 避雷 / 种草 / 对比 | 默认"种草" |
| 文风 | 否 | 专业科普型 / 闺蜜分享型 / 焦虑宝典型 | 默认"闺蜜分享型" |
| 平台 | 否 | 小红书 / 抖音 / 视频号 | 默认"小红书" |

如果用户没提供，自动追问一次；如果只给了产品名，按"核心卖点 = 用户常见搜索词"、"目标人群 = 通用人群"兜底。

## 执行步骤

1. **读 references/medical-banned-words.md**，确保生成时自动避开禁用词
2. **读 references/viral-templates.md**，根据用户选的"内容类型"套对应模板
3. **读 assets/tone-presets.md**，按用户选的"文风"调整语气与句长
4. **读 assets/cover-formulas.md**，生成 3 个标题候选（数字型 / 悬念型 / 对比型）
5. **生成正文** — 每段控制在 3-4 行，用 emoji 分章节，结尾必带"评论区蹲蹲"互动话术
6. **生成 5-8 个标签** — 1 个核心大词 + 2 个长尾词 + 2 个情绪词 + 1-2 个垂类词
7. **输出配图建议** — 封面必须有"3 字以内主标题 + 1 个对比/数字元素"

## 文风预设

### 文风 1：闺蜜分享型（默认）
- 句长：3-15 字为主，偶尔长句
- 语气：第一人称、感叹词、"姐妹们"、"真的"
- 禁用：第一人称复数、强营销词、长段落
- 示例开头："姐妹们！挖到宝了！"

### 文风 2：专业科普型
- 句长：10-25 字为主
- 语气：客观、引用数据/文献、列点
- 禁用：感叹号、营销话术
- 示例开头："中国营养学会建议成人每日 VD 摄入 400IU，但 80% 的人都缺。"

### 文风 3：焦虑宝典型
- 句长：5-15 字
- 语气：担忧、对比孩子前后变化、妈妈视角
- 禁用：绝对化用语、刺激消费话术
- 示例开头："我家娃之前挑食、个儿慢…"

## 标题公式（每次必给 3 个）

| 公式 | 结构 | 示例 |
|------|------|------|
| **数字型** | 数字 + 痛点 + 解决方案 | "吃了 3 个月，孩子变化让我惊呆" |
| **悬念型** | 反常识结论 | "医生从来不给自己娃补这东西" |
| **对比型** | Before/After 强对比 | "补之前 vs 补之后，孩子最大变化" |

## 合规要点（核心壁垒）

医药类笔记必须规避：

1. **医疗功效承诺** — 治疗、根治、痊愈、治愈率
2. **绝对化用语** — 最、第一、唯一、100%、国家级
3. **数据虚假** — 编造"95% 用户""医生推荐"（无来源）
4. **诱导就医** — "不去医院"、"不用看医生"
5. **迷信/伪科学** — "包治百病"、"祖传秘方"

合规话术替换表见 `references/medical-banned-words.md`。
