# 医药小红书合规话术库（核心壁垒）

## 一、绝对禁止词（直接限流/下架）

| 禁用词类型 | 禁用示例 | 合规替代 |
|------------|----------|----------|
| **医疗功效承诺** | 治疗、根治、治愈、痊愈、治愈率、消炎、止痛 | "对 XX 有帮助"、"有助于"、"辅助调理" |
| **绝对化用语** | 最、第一、唯一、首选、特效、100%、国家级、顶级 | "较好的"、"常见的"、"很多用户的" |
| **虚假数据** | 95% 有效、医生都在用、专家推荐（无来源） | 引用具体文献/指南名称 + 数据 |
| **诱导就医** | 不用去医院、不用看医生、自己在家治 | "请遵医嘱"、"具体情况咨询医生" |
| **迷信/伪科学** | 包治百病、祖传秘方、灵丹妙药 | 不写；用现代医学/营养学表达 |

## 二、高风险词（按平台审核严格度分级）

### 🔴 P0 红线（用了直接下架）
- 治疗 / 根治 / 治愈
- 100% 有效 / 100% 安全
- 最 / 第一 / 唯一
- 祖传 / 秘方
- 无副作用 / 零风险
- 替代药物 / 替代治疗

### 🟡 P1 需谨慎（易限流）
- 排毒 / 排湿 / 排寒
- 增强免疫力（无来源时）
- 抗氧化 / 抗衰老（功效类）
- 调节内分泌
- 改善睡眠 / 助眠（无证据时）
- 保护肝脏 / 保护心脑血管

### 🟢 P2 相对安全（合规写法）
- 补充营养
- 维持健康
- 日常保健
- 辅助 / 配合
- 含 XX 成分

## 三、合规话术替换表（高频对照）

| 不合规 | 推荐替换 |
|--------|----------|
| "治疗 XX 病" | "对 XX 引起的 XX 症状有帮助" |
| "根治 XX" | "长期使用可辅助维持" |
| "100% 有效" | "多数用户反馈" |
| "医生推荐" | "中国营养学会《XX 指南》建议" |
| "无副作用" | "通常耐受性良好，特殊人群请遵医嘱" |
| "包治百病" | ❌ 直接删 |
| "排毒养颜" | "促进新陈代谢" |
| "消炎" | "缓解不适" |
| "降三高" | "辅助维持健康水平" |
| "减肥" | "配合运动和饮食管理" |

## 四、合规话术"安全句式"模板

### 营养补充类
- ✅ "本品含 XX 成分，按推荐量摄入有助于..."
- ✅ "适合 XX 人群作为日常营养补充"
- ❌ "吃了能治疗 XX"

### 保健功能类
- ✅ "有助于维持 XX 健康"
- ✅ "辅助改善 XX 状态"
- ❌ "消除 XX 问题"

### 医疗器械类
- ✅ "请仔细阅读说明书或在医务人员指导下使用"
- ✅ "禁忌内容详见说明书"
- ❌ "用了就好"、"包好"

## 五、平台特殊规则（小红书）

| 规则 | 说明 |
|------|------|
| **医疗类账号需资质** | 个人号慎发医疗器械/药品，企业号需医疗资质 |
| **不可用患者案例** | 不能用"治愈案例"、"康复分享"作为卖点 |
| **不可对比医院** | 不能说"比去医院管用" |
| **不可暗示疗效** | "吃了 3 天感觉好多了" 也不行（属疗效暗示） |
| **必须标来源** | 引用数据/文献必须标出处 |
