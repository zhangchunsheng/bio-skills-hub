# 小红书爆款笔记结构模板库

## 模板 1：种草型（默认）

**适用场景**：保健品/营养品/日用品
**结构**：痛点引入 → 个人体验 → 成分/功效拆解 → 适用人群 → 互动结尾

```
🌿 痛点开场（1-2 句）
[描述用户痛点，建立共鸣]

📦 开箱/初体验（2-3 句）
[真实使用感受]

🔬 成分/功效（3-5 句）
[拆解为什么有效，引用指南/数据]

👨‍👩‍👧 适用人群（1-2 句）
[明确谁适合]

💬 互动结尾（1 句）
"姐妹们还有什么想了解的，评论区蹲蹲～"
```

### 实战示例（维生素 D3）
```
🌿 我家娃 2 岁体检，医生说 VD 摄入不够

📦 试了 3 款软胶囊，最终锁定这款：无腥味、滴剂设计、孩子不抗拒

🔬 中国营养学会建议 0-3 岁每日 400IU，这款每滴刚好 400IU，不用算

👨‍👩‍👧 适合：母乳宝宝、挑食娃、北方冬天晒不到太阳的娃

💬 姐妹们还有啥补营养的烦恼，评论区聊聊～
```

## 模板 2：测评对比型

**适用场景**：同类产品多、品牌想突出差异化
**结构**：背景 → 测评维度 → 多产品对比 → 推荐 → 选购建议

```
📌 测评背景（1-2 句）
[为什么测评、测了几款]

⚖️ 测评维度（列表）
- 维度 1
- 维度 2
- 维度 3

🏆 多产品横评（表格/分点）
[每款产品的优缺点]

✅ 我的选择（1-2 句）
[最终推荐及理由]

💬 互动结尾
```

## 模板 3：科普型

**适用场景**：教育用户、建立信任
**结构**：惊人数据/事实 → 原理拆解 → 实操建议 → 互动

```
💡 惊人数据开场（1 句）
[反常识数据/事实]

📚 原理拆解（3-5 句）
[用通俗语言讲清楚]

✅ 实操建议（2-3 句）
[给出 1-3 个可执行动作]

💬 互动结尾
"你们平时是怎么补 XX 的？评论区交流～"
```

### 实战示例（维生素 D）
```
💡 80% 的人都缺 VD，但很多人不知道

📚 VD 是脂溶性维生素，晒太阳可合成，但北方冬天、孕妇、母乳宝宝都很难靠晒太阳补够。中华医学会建议成人每日 400IU

✅ 实操建议：
1. 北方/孕妇/儿童建议额外补充
2. 选滴剂比胶囊方便
3. 随餐吃吸收更好

💬 你们每天晒多久太阳？评论区聊聊～
```

## 模板 4：避雷型

**适用场景**：竞品对比、品牌信任建立
**结构**：踩坑经历 → 错误示范 → 正确选择 → 选购避坑点

```
🚫 踩坑经历（2-3 句）
[讲之前买错的经历]

❌ 错误示范（1-2 句）
[为什么不行]

✅ 正确选择（2-3 句）
[现在用什么]

📝 选购避坑点（列表）
[给读者 3-5 个避坑提示]

💬 互动结尾
```

> ⚠️ 注意：避雷型不要直接点名竞品（可能被告），用"之前买的某款"代替。

## 模板 5：场景化型

**适用场景**：特定场景下使用某产品
**结构**：场景描述 → 产品使用 → 解决什么问题 → 场景延伸

```
🛋️ 场景 1（2-3 句）
[如：加班到 11 点，腰酸背痛]

🛋️ 场景 2（2-3 句）
[如：睡前想放松]

🛋️ 场景 3（2-3 句）
[如：周末健身完]

📦 用的什么（2 句）
[产品介绍]

💬 互动结尾
```

## 通用爆款元素（每篇必备）

| 元素 | 说明 | 示例 |
|------|------|------|
| **emoji 分段** | 每段开头 1 个 emoji | 🌿 📦 🔬 |
| **短段落** | 单段 ≤ 4 行 | 不要长段落 |
| **数字量化** | 1 个数据点 | "吃了 3 个月"、"1 天 1 滴" |
| **互动结尾** | 必带问句 | "评论区蹲蹲"、"姐妹们冲" |
| **前后对比** | 1 个对比 | "之前 vs 现在" |
| **第一人称** | 真实感 | "我家娃"、"我老公" |

## 标题公式速查

| 公式 | 结构 | 适用 |
|------|------|------|
| **数字型** | 数字 + 痛点 + 方案 | "吃了 3 个月，娃变化惊呆" |
| **悬念型** | 反常识结论 | "医生从不给自己娃补这" |
| **对比型** | Before/After | "补之前 vs 补之后" |
| **人群型** | 人群 + 痛点 | "新手妈妈必看：VD 怎么补" |
| **疑问型** | 反问 + 答案 | "为什么医生总让我补 VD？" |
| **避雷型** | 警示 + 方案 | "补 VD 3 大误区，你中几个？" |

## 标签公式

每篇 5-8 个标签：
- 1 个核心大词（流量大）
- 2 个长尾词（精准）
- 2 个情绪词（互动）
- 1-2 个垂类词（赛道）

**示例**：
- 核心：#母婴好物
- 长尾：#维生素D补充 #宝宝营养
- 情绪：#新手妈妈焦虑 #科学育儿
- 垂类：#儿童保健品 #母婴测评
