# 医药小红书爆款生成器 · xhs-medical-blowup

> 30 秒生成可发布的医药类小红书爆款笔记，**自动规避广告法违规词**。

## 解决什么问题

医药/保健品商家做小红书最头疼的 3 个问题：

1. ❌ 不知道哪些词会违规 → 一句"治疗"就限流
2. ❌ 不懂爆款结构 → 套模板还是没人看
3. ❌ 内容一眼 AI 味 → 用户秒划走

## 核心功能

- ✅ **合规话术库**：内置医药广告法禁用词 + 合规替换表
- ✅ **爆款结构模板**：种草 / 测评 / 科普 / 避雷 / 场景化 5 种
- ✅ **文风预设**：闺蜜分享 / 专业科普 / 焦虑宝典型 3 种
- ✅ **标题公式**：数字型 / 悬念型 / 对比型 等 6 种
- ✅ **封面公式**：5 种爆款封面视觉模板
- ✅ **标签库**：按"流量+长尾+情绪+垂类"四维组合
