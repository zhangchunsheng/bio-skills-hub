# 文风预设详细规范

## 文风 1：闺蜜分享型（默认 / 推荐）

**适用人群**：25-35 岁女性用户、宝妈、白领
**心理模型**：朋友推荐、真实分享、值得信任

### 语言特征
- 第一人称（"我"、"我家娃"、"我老公"）
- 感叹词（"姐妹们！"、"真的绝了"、"挖到宝"）
- 短句为主（3-15 字）
- 偶尔口语化语气词（"啊"、"哎"、"嘛"）

### 句长分布
| 句长 | 占比 |
|------|------|
| 3-8 字 | 40% |
| 9-15 字 | 35% |
| 16-25 字 | 20% |
| 25 字以上 | 5% |

### 段落规则
- 单段 ≤ 4 行
- 段间空一行
- 每段开头 emoji

### 开头模板（任选 1）
- "姐妹们！我挖到宝了！"
- "真的，不是标题党..."
- "我家娃之前一直 XX，直到..."
- "姐妹们冲！XX 我已经回购 X 次了"

### 结尾模板（必带）
- "姐妹们评论区蹲蹲～"
- "有用的话记得收藏哦～"
- "有问题评论区问我～"
- "冲！冲！冲！"

### 禁用表达
- ❌ 长段落、长句
- ❌ 营销话术（"限时"、"错过等一年"）
- ❌ 营销号语气
- ❌ 过度修辞

### 实战示例（VD）
```
姐妹们！我家娃之前挑食、个儿长得慢，儿保医生让补 VD。

试了 3 款软胶囊，最终锁定这款：无腥味、滴剂设计、娃不抗拒。

中国营养学会建议 0-3 岁每日 400IU，这款每滴刚好 400IU，不用算。

北方冬天、母乳宝宝、挑食娃，真的可以试试！

姐妹们还有啥补营养的烦恼？评论区蹲蹲～
```

## 文风 2：专业科普型

**适用人群**：高知女性、医生/营养师背景用户
**心理模型**：权威感、信任感、信息价值

### 语言特征
- 第三人称 / 客观视角
- 引用数据/文献/指南
- 列点呈现
- 无感叹词

### 句长分布
| 句长 | 占比 |
|------|------|
| 10-20 字 | 50% |
| 21-30 字 | 35% |
| 30 字以上 | 15% |

### 段落规则
- 单段 ≤ 5 行
- 重要信息加粗
- 数字加粗

### 开头模板
- "中国营养学会《XX 指南》指出..."
- "最新研究显示..."
- "XX% 的人都存在 XX 问题，但..."

### 必备元素
- 1 个权威数据来源
- 1 个指南/文献引用
- 1 个可执行建议

### 禁用表达
- ❌ "姐妹们"、"挖到宝"
- ❌ 感叹号
- ❌ 第一人称强烈情绪

### 实战示例（VD）
```
中国营养学会《中国居民膳食营养素参考摄入量》建议：
- 0-3 岁：每日 400 IU
- 4-10 岁：每日 400 IU
- 成人：每日 400 IU
- 孕妇/哺乳期：每日 400-800 IU

但调查显示，我国人群 VD 缺乏率高达 80% 以上，主要原因：
1. 日照不足（北方冬天、长期室内办公）
2. 母乳 VD 含量低
3. 防晒过度

建议补充方式：
1. 婴儿出生后数日即开始补 VD
2. 选滴剂方便控制剂量
3. 随餐服用吸收更好
```

## 文风 3：焦虑宝典型

**适用人群**：新手妈妈、育儿焦虑人群
**心理模型**：寻求解决方案、缓解焦虑

### 语言特征
- 第一人称（"我家娃"、"当妈后"）
- 担忧语气
- 对比前后变化
- 求推荐、求经验

### 句长分布
| 句长 | 占比 |
|------|------|
| 5-15 字 | 50% |
| 16-25 字 | 35% |
| 25 字以上 | 15% |

### 段落规则
- 单段 ≤ 4 行
- 时间线表达（之前 → 现在）

### 开头模板
- "我家娃之前一直 XX..."
- "当妈后才懂 XX 有多难..."
- "娃 XX 那段时间我真的快焦虑疯了..."
- "求求 XX 妈妈试试..."

### 结尾模板
- "希望帮到同样焦虑的妈妈们～"
- "评论区有没有同款娃，聊聊～"
- "姐妹们冲，互相打气～"

### 实战示例（VD）
```
我家娃之前挑食、睡不踏实、长得也慢…

儿保医生说 VD 摄入不够，但补什么、怎么补完全没头绪。

试了好几种，最后锁定了一款滴剂：无腥味、娃不抗拒、剂量精准。

补了 2 个月，娃吃饭香了、老实说睡得也踏实了。

当妈后才懂，选对补剂真的能少走很多弯路。

求求同款娃的妈妈试试，希望帮到你们～
```

## 文风选择决策树

```
用户场景 → 文风选择
├── 保健品/营养品 → 默认"闺蜜分享型"
├── 母婴育儿 → "焦虑宝典型"
├── 营养学/医学背景 → "专业科普型"
├── 美妆护肤 → "闺蜜分享型"
├── 中老年健康 → "专业科普型"
└── 不确定 → "闺蜜分享型"
```

## 文风混用建议

一篇笔记**只用 1 个主文风**，但可在不同段落切换：
- 开头：主文风
- 中段（数据/原理）：可切换"专业科普型"短段
- 结尾：回到主文风

避免在一句话内混用 2 种文风。
