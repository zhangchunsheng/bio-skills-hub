# 首图 prompt（Canva / AI 生图用）

> SkillHub 卡片首图决定 80% 转化率。建议用 Canva 模板或 AI 生图工具，按以下规格生成。

## 主推首图方案（推荐）

### 规格
- 尺寸：**1080×1440**（小红书主推荐比例 3:4）
- 或：**1080×1080**（朋友圈/通用卡片 1:1）
- 格式：PNG / JPG
- 大小：< 2 MB（平台要求）

### 视觉风格
- **背景**：浅蓝/薄荷绿渐变（医药健康行业色）
- **主标题字号**：超大粗体（占画面 30%）
- **配色**：高饱和撞色（蓝 + 橙 / 蓝 + 黄）
- **风格**：简洁卡片风，去除冗余编号标签，仅保留分类标签
- **emoji**：1-2 个装饰（不用满屏）

### 文案层级（从上到下）

| 位置 | 内容 | 字号 |
|------|------|------|
| 顶部标签 | "小红书爆款" | 小 |
| 主标题 | "医药商家专用" | 超大 |
| 副标题 | "30 秒生成可发布的合规笔记" | 中 |
| 卖点图标 | 3 个并排（合规 / 爆款 / AI） | 中 |
| 底部 CTA | "输入产品名 → 输出笔记" | 小 |

## Canva 实操（无 AI 工具时）

### 步骤
1. 打开 Canva（网页/App 都行）
2. 搜索模板："小红书封面"、"公众号头图"、"Skill 卡片"
3. 选 1 个简洁卡通风模板（避免插画风、信息图风）
4. 修改文案：
   - 主标题：`医药商家专用`
   - 副标题：`30 秒出小红书爆款 + 自动规避违规`
   - 标签：`小红书爆款 · 医药合规`
5. 改配色：浅蓝/薄荷绿底 + 蓝橙撞色
6. 导出 PNG / JPG

### 推荐字体
- 中文：思源黑体 Heavy / 站酷高端黑 / OPPO Sans Heavy
- 英文：Inter Black / Poppins Bold
- 字号比：主标题 96-120px、副标题 36-48px、标签 24-28px

## 备选首图方案（差异化路线）

### 方案 B：真人使用场景
- 一位妈妈/运营人员，拿着手机看小红书笔记
- 旁边显示"30 秒前还是空白"的对比
- 风格：暖色调 + 生活化

### 方案 C：数据驱动型
- 大数字：`30 秒` `5 种模板` `100% 合规`
- 简洁背景 + 强对比字
- 适合吸引 B 端商家

### 方案 D：类比工具型
- 把本 Skill 类比为"医药版剪映"或"小红书 PS"
- 简单 1 句话定位
- 适合吸引 C 端小白用户

## 不要做什么（避坑）

| ❌ 别做 | 原因 |
|---------|------|
| 用代码截图 | 非技术用户看不懂 |
| 信息塞满 | 失去焦点 |
| 浅色字+浅色底 | 看不清 |
| 过度 PS 修图 | 不像工具 |
| 长英文标题 | 中文用户抵触 |
| 引用竞品 logo | 侵权风险 |
