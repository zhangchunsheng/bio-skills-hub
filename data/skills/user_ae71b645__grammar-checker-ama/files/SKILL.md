# AMA 语法检查器（Grammar Checker - AMA）

> **关于 "AMA"**：此处的 AMA 指 *American Medical Association*（美国医学会），即《AMA 风格手册》(AMA Manual of Style)，是医学英语写作中广泛使用的规范标准，并非 "Ask Me Anything"。源码与文档均围绕该风格手册的语法规则展开。

一款面向医学英语写作的专项语法检查工具，依据《AMA 风格手册》的要求检测常见问题（目前聚焦于被动语态检测）。

**注意**：本工具检查的对象是**英文文本**。由于 AMA 风格手册本身是针对英文医学写作的规范，因此检测逻辑与被动语态特征词均保留英文原文，不会对中文语法进行处理。

## 用法

```bash
python scripts/main.py --text "Your text here"
```

## 参数

| 参数 | 类型 | 默认值 | 是否必填 | 说明 |
|-----------|------|---------|----------|-------------|
| `--text`, `-t` | 字符串 | - | 是 | 需要检查的英文文本 |

## 功能特性

- 被动语态检测（基于常见被动语态短语，如 "was performed"、"were analyzed" 等）
- 面向 AMA 风格的合规性提示

> **文档修正说明**：源版本 SKILL.md 中提到的"AMA style compliance"（AMA 风格合规）与"Medical terminology validation"（医学术语校验）为泛化描述，但经核对 `scripts/main.py` 实际代码后发现，脚本目前**只实现了被动语态检测**这一项检查，并没有独立的医学术语校验逻辑或更广泛的风格合规评分机制。为避免误导用户，本次翻译已将"功能特性"部分调整为如实反映当前代码能力，其余为规划中但尚未实现的功能。

## 输出

打印被动语态检测结果，包括：

- 若检测到被动语态短语，逐条列出对应的短语提示；
- 若未检测到，则提示"未发现被动语态问题"。
