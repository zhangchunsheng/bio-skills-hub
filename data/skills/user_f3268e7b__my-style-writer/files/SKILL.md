# 我的风格文章创作 (my-style-writer)

## 概述

此技能实现三个核心能力：

1. **风格学习与分析** — 扫描用户在文章库中的 Markdown 文章，提炼独特的写作风格档案
2. **替身式创作** — 基于风格档案，以用户的口吻和风格进行文章创作
3. **公众号 HTML 模板输出** — 套用用户指定的 HTML 模板，填充内容后输出最终排版文章

## 目录结构

所有文件均位于技能目录内部，无需在外部维护：

```
~/.workbuddy/skills/my-style-writer/    ← 本技能根目录
├── SKILL.md                            ← 当前文件
├── scripts/
│   └── analyze_style.py                ← 风格分析脚本
├── references/
│   └── style-profile.md                ← 风格档案（由分析阶段生成/更新）
├── article-library/                    ← 文章库（用户手动放入 .md 历史文章）
│   └── *.md                            ← 用户历史文章（Markdown 格式）
├── templates/                          ← HTML 模板目录（用户放入公众号排版模板）
│   └── wechat-template.html            ← 默认模板
└── assets/                             ← 技能资产（备用）
```

> 技能根目录路径：`~/.workbuddy/skills/my-style-writer/`

## 工作流程

### 阶段一：风格学习与分析

当用户要求"学习我的风格"或"分析我的写作 DNA"时执行。

**前置条件：** 用户已将历史文章（.md 文件）放入技能目录下的 `article-library/` 子目录。

**步骤：**

1. **扫描文章库：** 读取技能目录下 `article-library/` 中所有 `.md` 文件。

2. **逐篇分析：** 对每篇文章进行多维度的风格特征分析，关注以下维度：

   - **用词偏好** — 高频词汇、惯用口语词、行业术语、语气词、连接词的使用模式
   - **句式结构** — 句子长度分布（短句/长句比例）、句式变化、排比与对偶的使用
   - **段落节奏** — 段落长度习惯、分段频率、段落间的逻辑连接方式
   - **语气语调** — 正式/口语化程度、第一/第二/第三人称使用习惯、自嘲/调侃/犀利/温和的倾向
   - **修辞手法** — 比喻、反问、设问、对比、列数据等手法的使用偏好
   - **叙事视角** — 个人经历叙述 vs 客观分析的比例、"我/我们/你"的使用模式
   - **情感表达** — 情绪词的分布（正面/负面/中性）、情感递进方式、金句密度
   - **结构组织** — 标题编号习惯（一/1/①）、是否使用导语、结尾风格、emoji 使用模式
   - **引用习惯** — 数据引用方式、外部来源标注、案例使用偏好

3. **生成风格档案：** 综合分析结果写入 `references/style-profile.md`，包含：

   - 风格总体定位（一句话概括）
   - 各维度的详细特征描述
   - 高频词汇表
   - 句式模板
   - 写作注意事项（避免哪些表达）

4. **向用户展示分析摘要**，确认风格档案的准确性。

### 阶段二：替身式创作

当用户提供主题并要求"用我的风格写文章"时执行。

**步骤：**

1. **读取风格档案：** 先读取 `references/style-profile.md`。如果档案不存在或不完整，先告知用户需要执行阶段一。

2. **理解创作需求：**
   - 文章主题与核心观点
   - 目标读者与发布平台
   - 字数要求
   - 是否需要配图（配图位置标记）
   - 其他特殊要求

3. **参考原文：** 如有需要，从 `article-library/` 中挑选 1-2 篇与当前主题最相关的文章作为风格参考，但不直接搬运内容。

4. **以风格档案为基础创作：**
   - 严格遵循风格档案中的特征描述
   - 模仿语调、节奏、用词习惯
   - 保持句式结构和段落节奏一致
   - 使用档案中记录的高频词汇和句式模板

5. **内容生成后，套用 HTML 模板**（见阶段三）。

### 阶段三：HTML 模板套用

**步骤：**

1. **选择模板：** 从技能目录下的 `templates/` 中选择 HTML 模板。如果用户未指定具体模板，默认使用 `templates/wechat-template.html`。

2. **解析模板占位符：** 识别模板中所有的 `{{占位符名称}}` 标记。

3. **填充内容：**
   - `{{文章主标题}}` → 填入文章标题
   - `{{作者}}` → 填入用户笔名
   - `{{日期}}` → 填入当前日期
   - `{{引导语内容}}` → 填入文章导语（如有）
   - `{{二级标题}}` / `{{正文段落内容}}` 等 → 按文章结构逐段填充
   - 图片占位符保留，标记为「此处插入配图」
   - 未使用的模板区块可删除或保留为空

4. **输出文件：** 将填充后的 HTML 保存到当前工作区目录，命名为 `article-{主题关键词}-{日期}.html`。

5. **向用户展示：** 使用 `present_files` 展示生成的 HTML 文件。

## 使用须知

1. **文章库管理：** 用户将历史文章（.md 格式）放入技能目录下的 `article-library/` 子目录。文件名建议使用 `YYYY-MM-DD_平台_标题.md` 格式以便管理。
2. **模板管理：** 用户将公众号 HTML 排版模板放入技能目录下的 `templates/` 子目录。模板使用 `{{占位符}}` 语法标记可填充位置。技能已内置一个默认模板 `templates/wechat-template.html`。
3. **风格更新：** 当文章库新增文章后，重新执行阶段一以更新风格档案，使风格模拟更加精准。
4. **隐私保护：** 文章库和风格档案均为本地存储，不会上传到任何外部服务。
