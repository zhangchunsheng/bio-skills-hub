# 医学科学可视化AI视频生成

## 核心能力

本Skill提供医学科学可视化AI视频生成的全流程AI生成指导，覆盖从创意构思、Prompt工程、工具链选择、生成执行到后期优化的完整工作流。

## 方法论基础

基于ReelMind/Flux Pro/Runway Gen-4的AI科学可视化生成方法论。核心技法：科学准确性四约束（形态/比例/颜色/交互必须基于真实数据）、微观到宏观的尺度过渡叙事（细胞→组织→器官→人体）、多模态参考融合（电子显微镜图+示意图+3D模型作为参考输入）、分层渲染策略（先骨架后细节逐层叠加）。Prompt公式：科学主体+微观环境+运动机制+渲染风格+标注需求。

## 风格特征

显微级细胞渲染（细胞器/蛋白质/膜结构）、3D解剖分层展示（骨骼→肌肉→血管→皮肤逐层）、分子动力学模拟（蛋白质折叠/药物结合）、半透明材质+发光边缘、冷色调（蓝/青/紫）科技感配色、标注与图解叠加、微观到宏观尺度过渡

## 工作流

1. 科学需求分析：确定可视化目标、目标受众（专家/学生/公众）、科学准确性要求
2. 参考资料收集：电子显微镜照片、X射线晶体学数据、医学插画参考
3. 脚本设计：按科学逻辑构建视觉叙事（如信号通路→细胞响应→组织变化）
4. 多模态融合：上传显微镜图/3D模型/示意图作为AI生成参考输入
5. Prompt编写：科学主体+微观环境+运动机制+渲染风格+标注
6. 分层生成：先骨架后细节，逐层叠加生成
7. 标注叠加：后期添加文字标注、箭头、比例尺等科学注释

## Prompt工程规范

### 基础公式
```
科学主体（细胞/分子/器官） + 微观环境（细胞基质/血管腔/细胞膜） + 运动机制（扩散/分裂/折叠） + 渲染风格（半透明3D/发光边缘/冷色调） + 科学标注
```

### 进阶公式
```
主体(细胞类型/分子名称/解剖结构) + 环境(细胞外基质/血流/组织微环境) + 运动(细胞分裂/蛋白质折叠/药物结合动力学) + 渲染(体积渲染/半透明材质/冷色科技蓝青紫调) + 景别(显微级/亚细胞级/分子级) + 参考(基于电子显微镜图/PDB结构数据) + 标注(关键结构文字注解)
```

### 美学控制词库
- 景别：远景/全景/中景/近景/特写/微距/极远景
- 视角：平视/俯视/仰视/第一人称/无人机视角/低角度
- 运镜：推/拉/摇/移/跟/固定镜头/缓慢推进/手持微晃
- 光照：自然光/逆光/侧光/柔光/霓虹灯/黄金时刻/蓝调时刻
- 镜头：35mm/50mm/85mm/广角/变形宽银幕/浅景深
- 时间控制：慢动作/延时/实时/120fps/240fps

## 质量检查清单

- [ ] 视频时长是否符合目标平台要求
- [ ] 画面比例是否正确（9:16/16:9/2.35:1）
- [ ] 主体外观在多镜头间保持一致
- [ ] 色调与光照在全部镜头间统一
- [ ] 字幕无错别字且时间轴对齐
- [ ] 音频与画面同步（口型/动作/转场）
- [ ] 品牌元素（Logo/字体/色号）准确
- [ ] 导出分辨率不低于1080P
- [ ] 前3秒有明确Hook/吸引点
- [ ] 结尾有清晰的CTA（如适用）
- [ ] 运动描述无冲突（避免多动叠加超过2种）
- [ ] 风格标签统一（无多风格混用）
