# 医学科学可视化AI视频生成

## 简介
专为医学与科学可视化设计的AI视频生成技能，覆盖细胞动画、解剖展示、分子模拟、手术演示等类型。

## 适用场景
本Skill适用于需要快速、高质量生成医学科学可视化AI视频生成场景的用户。

## 技能特色
显微级细胞渲染（细胞器/蛋白质/膜结构）、3D解剖分层展示（骨骼→肌肉→血管→皮肤逐层）、分子动力学模拟（蛋白质折叠/药物结合）、半透明材质+发光边缘、冷色调（蓝/青/紫）科技感配色、标注与图解叠加、微观到宏观尺度过渡
