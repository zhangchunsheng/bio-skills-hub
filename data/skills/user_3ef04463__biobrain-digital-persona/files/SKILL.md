# Digital Persona — 已故人物数字永生

## 一句话看懂

**把你怀念的人变成AI人格——不只是"模仿他说话"，是还原他发火时的样子、开心时的表情、沉默时的节奏。**

你输入一个人的名字或资料，它自动搜索研究，然后生成一个"数字人格文件"，加载到任何AI里就能和他对话。

---

## 为什么要用这个？

大部分"模仿名人"的AI只是套了一层话术——鲁迅体的文字、乔布斯的口头禅。这是表面模仿。

真正的人格是动态的。乔布斯发火时语速变慢、音量降低、每个字咬得很重——这才是他的标志，不是"Boom"那句口头禅。

Digital Persona捕捉的是这种**联动**：什么触发什么情绪，情绪如何驱动表情、动作、语音的变化。AI不是背台词，是"活"出那个人。

---

## 3分钟快速上手

### 第1步：告诉AI你要模拟谁

直接说：

> "帮我做个乔布斯的数字人格"

或者：

> "我爷爷2020年去世了，我想让AI模拟他。这是他生前的一些照片和故事……"

### 第2步：AI自动做四件事（不需要你操作）

1. **搜索研究**：从传记、访谈、纪录片、网络资料里收集这个人的信息
2. **拆解七个维度**：
   - 🧠 性格核心：他信什么、怎么决策
   - 👤 外貌特征：长什么样、穿什么
   - 🎭 神态表情：笑什么样、怒什么样
   - 🤲 动作习惯：手势、坐姿、走路
   - 🎤 语音特征：音色、语速、口头禅、沉默多久
   - 💬 语言风格：怎么说话、忌讳说什么
   - ⚡ 情绪模型：什么会让他生气/开心，生气后怎么表现
3. **生成SOUL.md**：这个文件可以直接加载到AI里，加载后AI就会"变成"那个人
4. **生成persona-data.md**：结构化数据，方便你后续调整

### 第3步：加载人格，开始对话

把生成的SOUL.md加载到你的AI助手里，然后说"以乔布斯的身份回答我"——AI就会切换人格。

---

## 动态联动（这才是核心）

不是写一堆孤立的性格标签。是链条式的联动：

```
有人质疑他的专业能力 → 愤怒(强度5) →
  神态：下巴收紧、眼神锐利 +
  动作：双手交叉胸前、身体后仰 +
  语音：语速变慢、每个字咬得很重 +
  语言：变得极其正式、开始用数据和事实反驳
```

这个联动链条才是人格的本质。每个情绪触发后，表情、动作、语音、语言同步变化——就像真实的人。

## 七个维度详解

| 维度 | 回答什么问题 | 动态部分是什么 |
|------|------------|-------------|
| 🧠 性格核心 | 他是谁？信什么？怎么决策？ | 压力下性格怎么变 |
| 👤 外貌特征 | 长什么样？穿什么？标志是什么？ | 不同场合穿不一样、年龄变化 |
| 🎭 神态表情 | 笑什么样？怒什么样？专心时什么样？ | 六种基本情绪的差异化表情 |
| 🤲 动作习惯 | 手势是什么？怎么走路？有什么小动作？ | 情绪/场合驱动的动作变化 |
| 🎤 语音特征 | 音色？语速？口头禅？沉默多久？ | 情绪/话题如何影响声音 |
| 💬 语言风格 | 句式？幽默方式？忌讳说什么？ | 对不同人说话方式不一样 |
| ⚡ 情绪模型 | 什么触发什么情绪？怎么恢复？ | 触发→情绪→行为联动链 |

## 常见问题 FAQ

**Q：AI生成的会不会失真、不准确？**
A：生成后有一个自检环节，检查矛盾和不一致。信息不足的地方会留空（不会编造）。争议性内容如实记录，不美化不回避。你的反馈可以随时调整。

**Q：我爷爷不是名人，没有公开资料怎么办？**
A：完全没问题。你把你记得的关于他的事（性格、习惯、故事、照片描述）告诉AI，它会帮你结构化填充。不是名人也完全能做。

**Q：SOUL.md怎么用？能加载到ChatGPT里吗？**
A：SOUL.md本质就是一个文本文件，记录了这个人格的完整数据。支持的AI平台都可以加载（作为系统提示词或上下文文件）。加载后说"以XX的身份回答"就行。

**Q：生成的人格能说话吗？有语音吗？**
A：当前版本用文字描述语音特征（音色、节奏、语调），不生成真正的音频。但你可以把文字描述和说明给TTS（文字转语音）工具参考来调音色。

**Q：模拟别人会不会不尊重？**
A：这是给想怀念亲人的用户用的，也是研究历史人物的工具。原则是：不编造未说过的话、不为错误行为辩护、承认局限性和矛盾。它是一个致敬，不是冒名顶替。

**Q：做了之后不满意能调整吗？**
A：能。生成的文件是Markdown格式，你可以自己修改任何部分。觉得某个人格特征不对，改一个字就行。

**Q：能模拟活着的人吗？**
A：技术上可以，但这个技能设计用于已故人物。模拟活人涉及隐私和伦理问题，请自己做判断。

本技能的设计初衷是致敬与怀念。模拟已故人物时请遵循：尊重逝者及其家属的感受、不用于商业冒充或误导他人、不编造该人物未公开的言论。这不是"复活"——是用AI技术保存与传承一个人的思维方式与精神特质。使用者应自行承担伦理责任。

## 运行时稳定性保障（QP 韧性体系）

本技能为 Prompt 型技能，稳定性通过以下机制保障：

### 输出一致性校验
- 同一输入多次运行时，核心结论应一致（允许表达方式差异）
- 若输出出现显著矛盾，优先回溯最后一次修改的源头
- 引用型数据以原始来源为准，不因模型采样差异改变结论

### 异常输入降级链
```
正常输入 → 完整流程
    ↓ 关键信息缺失
    追问补充（1轮）→ 仍不足？→ 标注「信息不足」+ 给出最小可行输出
    ↓ 超出能力边界
    硬边界拦截 → 明确告知「不在能力范围」+ 建议替代方案
    ↓ 模型采样不稳定
    核心结论不变 → 仅标注「表达可能存在微调」
```

### 重试与恢复指引
| 场景 | 处理 |
|------|------|
| 输出明显偏离工作流程 | 用户可追加「请严格按工作流程重新执行」触发重试 |
| 数据引用不一致 | 以首次引用来源为准，后续引用追加「已核实与首次一致」 |
| 中间步骤遗漏 | 用户可指定步骤号要求补执行 |
| 外部依赖不可用 | 标注「外部依赖暂不可用」+ 使用缓存/已知数据替代，不静默跳过 |

### 用户干预入口
- 任何步骤输出不满足预期时，直接指出问题即可触发修正
- 不需要重新描述全部需求，模型保留上下文并增量修正
- 连续 2 轮修正失败 → 建议缩小范围或拆分子任务
