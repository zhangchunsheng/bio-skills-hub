# 效率基准

## 基准数据集

### 1. Doench 2014 数据集

**规模**：针对人类 CD33、CD13 和 GFP 基因的 1,841 个 gRNA

**细胞系**：HL-60、KBM-7、K562

**读出方式**：流式细胞术（敲除效率）

**关键发现**：
- GC 含量最佳范围：40-60%
- 第 20 位（NGG 近端）偏好 G
- Poly-T 序列降低效率

### 2. Doench 2016 数据集

**规模**：覆盖 9 个基因的 2,389 个 gRNA

**改进点**：
- 多种细胞类型（A375、K562、iPSC）
- 多样化的基因组背景
- 更高通量的筛选

**性能指标**：
- 排名前 5% 的向导：切割效率 >80%
- 排名后 20% 的向导：效率 <10%
- "高活性"评分阈值：>0.6

### 3. Wang 2014（Dropout 筛选）

**发表文献**：Wang T 等人，"Genetic screens in human cells using the CRISPR-Cas9 system"，Science 2014

**方法**：全基因组规模敲除筛选

**细胞系**：A375、KBM7、K562、Raji、Jiyoye

**验证**：6,000+ gRNA 深度测序

### 4. Hart 2015（泛癌症）

**发表文献**：Hart T 等人，"High-Resolution CRISPR Screens Reveal Fitness Genes and Genotype-Specific Cancer Liabilities"，Cell 2015

**关注点**：各癌症类型中的必需基因

**细胞系**：12 种癌细胞系

## 向导 RNA 设计规则

### 高效率向导检查清单

- [ ] GC 含量：40-60%
- [ ] 无 Poly-T（连续 3 个以上的 T）
- [ ] 第 20 位：优选 G
- [ ] 第 19 位：优选 C
- [ ] 无强二级结构（ΔG > -5 kcal/mol）
- [ ] 避免 4 个以上相同核苷酸连续出现
- [ ] 检查靶点是否存在常见 SNP

### 低效率警示信号

1. GC < 30% 或 > 70%
2. 同聚物序列（AAAA、GGGG）
3. 第 20 位为 A 或 T
4. 预测存在发夹结构
5. 靶向重复区域
6. 种子区存在多个错配

## 建议

1. **初步设计**：对候选靠前的向导使用 DeepCRISPR
2. **文库构建**：使用 Doench '16 追求速度
3. **关键应用**：使用 GUIDE-seq 进行验证
4. **高通量场景**：可接受 70% 的计算预测准确率
