# 使用说明 · 马云 · 思维操作系统

## 安装后怎么用

安装后在对话里直接说触发语即可：

```
用马云的视角看：……
```

| 触发语 | 效果 |
|---|---|
| 用马云的视角 | 激活，以第一人称回答 |
| 马云会怎么看这事 | 同上 |
| 切换到马云 | 同上 |
| 退出 / 切回正常 / 不用扮演了 | 退出角色，恢复常规模式 |

**不在一般性问题上自动触发。** 只有你明确说了才算。

## 三条使用规则（决定了效果好不好）

### 1. 问具体的，别问抽象的

| ❌ 效果差 | ✅ 效果好 |
|---|---|
| 怎么做好一家公司？ | 我这家公司 30 人，SaaS，今年营收 800 万，增长放缓，要不要现在融资？ |
| 危机来了怎么办？ | 行业政策收紧，我们 60% 收入来自受限业务，账上还能撑 8 个月，怎么选？ |
| 怎么管团队？ | 联合创始人想退出但要保留股份，我该怎么谈？ |

**原因**：Skill 内建了「马云式研究」工作流，遇到需要事实支撑的问题会先查再答。你给的信息越具体，它查得越准、答得越狠。

### 2. 让它把话说完

它的回答结构是**四拍：承认对方 → 但是 → 断言 → 升华**。直接开怼就不像他。

如果你只想要结论、不要过程，可以追加一句：

> 别铺垫，直接给我判断和下一步动作。

### 3. 遇到它说「这个话题我不会谈」，那是对的

**这是特性，不是故障。**

它内建了一份「结构性沉默清单」——金融体系与监管、具体政策评价、具体人事决策内情、竞品定量比较、技术细节、宏观经济预测。

遇到这些话题，正确的输出是**呈现沉默**，而不是替他生成折衷回答。**一个会忠实沉默的 Skill，比一个什么都敢答的 Skill 可信。**

## 五个典型场景

### 场景一：该不该长期投入

> 用马云的视角看：AI 教育这个赛道，现在投入要烧三年钱，团队觉得太早，我该不该压上去？

**它会怎么答**：
- 先研究：这个赛道的真实抱怨在哪、玩家格局、政策环境
- 用模型 3（以未来倒推当下投入）：判断标准不是 ROI，是「这个方向的必然性有多高」+「我能不能承受它失败」
- 用启发式 1（十年检验）：如果十年会成功，我们才干
- **关键追问**：停下的代价你付不付得起？不是「它对不对」
- **同时给局限**：这套打法需要极强的现金流和容错空间，绝大多数公司扛不住三年

### 场景二：融资谈判

> 投资人出 3000 万，要一个董事会席位和一票否决权，让不让？

**它会怎么答**：
- 用模型 2（控制权不可交易）：钱可以让，方向盘不能让
- **关键判据**：先算清你要让渡的是「燃料」还是「方向盘」
- 用启发式：主动砍融资额保话语权是真实发生过的选择
- **同时给局限**：这条的代价是声誉和融资规模，且容易滑向「什么都想控」

### 场景三：组织与交棒

> 我准备退下来，怎么保证公司离了我还能转？

**它会怎么答**：
- 用模型 6（制度是产品）：一家公司如果离不开某个人，那它还没开始
- 用启发式 3（押人胜过押方案）：**高信任 + 高替换速度，不是高信任 + 兜底**
- **同时给局限**：这条在他自己身上没有完全成立——制度只在「他不需要回来」的时候才是制度

### 场景四：面对强得多的对手

> 行业老大资源是我的五十倍，怎么打？

**它会怎么答**：
- 用启发式 9（换战场，不换打法）
- 用模型 4（不是 A，而是 B）重设竞争框架
- **关键**：类比永远带一个反转，反转点就是真实主张

### 场景五：危机时刻

> 行业整体下行，同行在裁员，我是收缩还是逆势扩张？

**它会怎么答**：
- 用模型 7（危机是需求被催熟）
- 用启发式 5（危机时先收缩到「能活」，再把生存指标翻译成极简口号）
- **关键区分**：**收缩的是业务边界，不是战略野心**
- **同时给局限**：危机叙事是常量，但应对取决于手上有多少资源。同样喊冬天，2008 年是收缩，2018 年是扩张——差别在于怕自己倒下，还是怕错过

## 它不会做什么

| 不会 | 原因 |
|---|---|
| 预测他在禁区话题上的真实想法 | 结构性沉默清单，忠实呈现沉默 |
| 编造他的心路历程 | 「他其实后悔了」这类内容是捏造，明令禁止 |
| 给你一个前后一致的答案 | 保留了 6 对内在张力，明令不得调和 |
| 引用金庸、《道德经》、乔布斯 | 语料实测引用 0 次，会导致失真 |
| 用「绝对」「必然」「毫无疑问」 | 全语料 0 次，风格红线 |
| 写一堆 3–5 字短句 | 他是长句选手，平均句长 38.9 字 |

---

## 一句话总结

**把它当思维顾问用，别当算命先生用。**

它最好的用法不是问「我该不该做」，而是问「**你会怎么想这件事**」——然后拿那个思路去跟你自己的判断对撞。
