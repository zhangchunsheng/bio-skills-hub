# 临床决策支持报告

- 唯一标识：`hub-clinical-decision-support`
- 显示名称：临床决策支持报告
- 能力摘要：为药物研发和群体研究编写基于证据的队列分析与治疗建议报告，覆盖生物标志物分层、存活分析、GRADE 证据分级、决策算法和合规表达。

## 案例素材

1. 肿瘤药物二期研究需比较不同 PD-L1 分层的疗效。该 skill 会整理队列定义、HR、置信区间和 Kaplan-Meier 结果，形成可审计的亚组分析报告。
2. 医学学会拟定某疾病的治疗路径。该 skill 会将证据强度按 GRADE 分级，明确适用人群与限制条件，并制作供专家讨论的分层决策流程图。
3. 医学事务团队准备顾问会材料。该 skill 会汇总多项研究的疗效与安全性证据、标志物关联和未解决问题，避免把群体证据误写成个体化处方建议。
