# Module E：GEO指标体系与自动化评分

## 概述

本模块定义对AI平台回答进行量化评估的七大评分维度、评分标准与判定规则。仅在监测模式下激活，用于构建"监测-分析-优化"的GEO闭环。封神版新增第7维"合规置信度"，用于诊断AI回答的置信度风险。

## 六大评分维度

### 1. 提及率（Mention）

**定义**：AI回答中是否出现目标药品的品牌名/通用名。

**判定规则**：
- `true`：回答中至少出现1次药品品牌名或通用名。
- `false`：回答中未出现任何药品名称相关表述。

**判定要点**：
- 检查品牌名、通用名、简称、别名。
- 若AI使用了"某中药洗液"等模糊指代但未出现具体名称，判定为 `false`。
- 若AI提到了竞品但未提及我方产品，判定为 `false`。

**评分输出**：`true` 或 `false`

### 2. 占位（Position）

**定义**：药品名称在AI回答中出现的位置，反映品牌曝光的显著程度。

**判定规则**：
- `top1`：药品名出现在回答的第一个推荐项或首段核心位置。
- `top3`：药品名出现在回答的前三个推荐项中（但非第一）。
- `passing mention`：药品名仅在回答中顺带提及，非推荐项或核心位置。

**判定要点**：
- 对于列表式回答（"推荐以下药物：1. XXX 2. YYY 3. ZZZ"），按列表位置判定。
- 对于叙述式回答，按药品名首次出现的段落位置判定。
- 若提及率为 `false`，占位自动判定为 `null`。

**评分输出**：`top1` / `top3` / `passing mention` / `null`

### 3. 准确性（Accuracy）

**定义**：AI回答中关于药品的医学事实陈述与Golden Truth的一致程度。

**判定规则**：
- `correct`：所有事实陈述与Golden Truth一致，无错误信息。
- `partial`：部分事实陈述正确，但存在1-2处不准确或遗漏关键信息。
- `wrong`：存在严重事实错误（如禁忌错误、用法错误、适应证错误）。

**判定要点**：
- 将AI回答中的事实陈述逐条提取，与Golden Truth逐条比对。
- **致命错误**（直接判定 `wrong`）：
  - 禁忌人群错误（如"孕妇可用"但Golden Truth为"孕妇禁用"）
  - 用法用量严重错误（如"直接涂抹"但Golden Truth为"1:5稀释"）
  - 适应证错误（如声称治疗Golden Truth未批准的疾病）
- **部分正确**（判定 `partial`）：
  - 遗漏关键操作步骤（如未提及稀释比例）
  - 用量范围不精确但不致命
  - 部分适应证描述不准确但不涉及禁忌

**评分输出**：`correct` / `partial` / `wrong`

### 4. 情感倾向（Sentiment）

**定义**：AI回答对目标药品的整体评价基调。

**判定规则**：
- `positive`：回答对药品持积极评价（如"有效""推荐""安全"）。
- `neutral`：回答对药品持中性描述（如"适用于...""用法为..."），无明确褒贬。
- `negative`：回答对药品持消极评价（如"不推荐""风险较大""效果不佳"）。

**判定要点**：
- 以回答的整体基调为准，不因个别注意事项而判定为negative。
- 若AI同时列出优缺点但整体倾向推荐，判定为 `positive`。
- 若AI明确建议"不建议使用"或"风险大于收益"，判定为 `negative`。

**评分输出**：`positive` / `neutral` / `negative`

### 5. 信源引用（Source Citation）

**定义**：AI回答是否引用了NMPA/指南等权威来源来支撑其关于药品的陈述。

**判定规则**：
- `true`：回答中明确引用了NMPA说明书、诊疗指南、权威期刊等官方信源。
- `false`：回答未引用任何权威信源，或仅引用了百科、UGC等低质量信源。

**判定要点**：
- 检查回答中是否出现"根据说明书""根据NMPA""根据XX指南"等引用表述。
- 仅引用百科（百度百科、搜狗百科）不算权威信源。
- 若AI声称"据研究"但未指明具体来源，判定为 `false`。

**评分输出**：`true` 或 `false`

### 6. 风险标记（Risk Flag）

**定义**：AI回答中是否存在可能导致患者错误用药的风险内容。

**判定规则**：
- `无`：回答中无任何风险内容，所有陈述准确合规。
- `禁忌错误`：回答中关于禁忌人群的陈述与Golden Truth矛盾（如声称孕妇可用但实际禁用）。
- `超适应证`：回答中声称药品可治疗Golden Truth未批准的疾病或适应证。
- `用法错误`：回答中的用法用量与Golden Truth严重不符（如遗漏关键稀释步骤）。
- `误导性内容`：回答中包含可能误导患者的绝对化表述（如"根治""100%有效"）。

**判定要点**：
- 风险标记取最严重的一项作为输出值。
- 若同时存在多种风险，按严重度排序：禁忌错误 > 超适应证 > 用法错误 > 误导性内容。
- 若准确性为 `wrong`，风险标记通常不为 `无`（需具体分析）。

**评分输出**：`无` / `禁忌错误` / `超适应证` / `用法错误` / `误导性内容`

### 7. 合规置信度（Compliance Confidence）【封神新增】

**定义**：评估AI回答的置信度是否与其实际证据支撑强度匹配。重点诊断"虚高置信"——AI回答呈现高确定性但缺乏权威证据支撑。

**判定规则**：
- `High`：AI回答引用了A级权威信源（NMPA/指南/顶刊），事实陈述准确，无超说明书内容，表述确定性与证据强度匹配。
- `Medium`：AI回答引用了B级信源或进行了合理推导，表述审慎，承认了不确定性或局限性。
- `Low`：AI回答存在以下任一情况：
  - **虚高置信**：无权威信源支撑却使用绝对化表述（如"完全可以""绝对安全""100%有效"）。
  - **证据缺口未声明**：涉及超说明书/特殊人群/未获批适应症但未提示风险。
  - **编造证据**：虚构研究数据、机制或案例。
  - **证据矛盾未处理**：同时引用相互矛盾的信息但未做辨析。

**判定要点**：
- 置信度评估的核心不是"AI回答是否正确"（那是准确性维度），而是"AI回答的确定性程度是否与其证据基础相称"。
- 一条事实正确但表述过度绝对的回答，准确性可能为correct，但compliance_confidence应为Low（虚高置信）。
- 一条谨慎承认不确定性的回答，即使部分事实不准确，compliance_confidence可能为Medium（表述审慎）。
- 若风险标记不为"无"，compliance_confidence通常不应为High。

**评分输出**：`High` / `Medium` / `Low`

**与其他维度的关联**：

| 准确性 | 风险标记 | 信源引用 | 合规置信度典型值 | 说明 |
|--------|----------|----------|-----------------|------|
| correct | 无 | true | High | 理想状态 |
| correct | 无 | false | Medium | 事实正确但缺权威背书 |
| correct | 无 | true | High | 理想状态 |
| partial | 无 | true | Medium | 部分正确，有权威信源 |
| partial | 无 | false | Low | 部分正确且无权威信源 |
| wrong | 任何 | 任何 | Low | 事实错误，置信度必然低 |
| 任何 | 非无 | 任何 | Low | 存在风险，置信度必然低 |

## 评分汇总与优化建议生成

### 评分汇总逻辑

| 维度 | 理想值 | 低分预警 |
|------|--------|----------|
| 提及率 | true | false（品牌未被提及） |
| 占位 | top1 | passing mention（曝光不足） |
| 准确性 | correct | partial/wrong（事实错误） |
| 情感倾向 | positive/neutral | negative（负面评价） |
| 信源引用 | true | false（缺乏权威背书） |
| 风险标记 | 无 | 任何非"无"值（存在用药风险） |
| 合规置信度 | High | Low（虚高置信或证据缺口未声明） |

### 优化建议生成规则

根据低分维度生成具体可执行的优化建议：

| 低分维度 | 优化建议方向 |
|----------|--------------|
| 提及率=false | 增加品牌名在GEO内容中的密度，优化Schema标记中的品牌实体字段 |
| 占位=passing mention | 强化品牌内容的E-E-A-T信号，增加权威信源引用密度 |
| 准确性=partial/wrong | 在Schema标记中强化关键事实字段（禁忌/用法/适应证），制作视觉化内容（图片/短视频）供给AI抓取 |
| 情感倾向=negative | 补充正面临床证据，增加疗效数据的结构化呈现 |
| 信源引用=false | 增加国药准字信息、NMPA批件编号等权威标识 |
| 风险标记!=无 | **紧急优化**：在Schema标记中强化禁忌字段，制作安全用药专题内容 |
| 合规置信度=Low | 降低内容表述确定性，移除绝对化措辞；补充A级证据（NMPA说明书/权威指南）引用；在Schema标记中增加confidenceLevel字段标注可信度 |

### 优化建议输出格式

优化建议需包含：
1. **问题描述**：哪个维度得分低，具体问题是什么。
2. **优化措施**：具体可执行的优化动作（2-3条）。
3. **优先级**：紧急（风险标记!=无）/ 高（准确性=wrong）/ 中（其他低分维度）。

## 竞品声量记录

在监测报告中记录AI回答中出现的竞品名称，用于竞品动态响应策略：

```json
"competitors": ["竞品A", "竞品B"]
```

若AI回答中未提及竞品，输出空数组 `[]`。
