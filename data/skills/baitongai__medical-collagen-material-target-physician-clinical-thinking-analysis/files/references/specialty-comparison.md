# 专科对比与MDT协同规则（胶原领域专属·终版）

## 一、专科对比矩阵

研究胶原临床思维时，必须明确以下科室的思维差异及MDT协同逻辑：

### 皮肤科

- **核心思维差异**：聚焦损容性皮肤病的美观结局（如痤疮瘢痕、黄褐斑），优先选择无创/微创胶原应用
- **胶原应用偏好**：外用胶原敷料、胶原喷雾剂，关注美观改善和色素沉着
- **评估指标**：VSS评分、患者PRO（瘙痒/疼痛VAS评分）、色素沉着评估
- **MDT协同逻辑**：痤疮瘢痕患者需联合皮肤科（激光治疗）+整形科（胶原填充），每4周评估一次VSS评分

### 整形美容科

- **核心思维差异**：聚焦术后瘢痕预防和功能恢复，优先选择长效胶原植入材料
- **胶原应用偏好**：胶原植入剂、胶原膜，关注瘢痕抑制和形态维持
- **评估指标**：VSS评分、瘢痕宽度测量、患者满意度PRO
- **MDT协同逻辑**：双眼皮术后瘢痕患者需联合整形科（减张治疗）+皮肤科（胶原外用），每2周评估一次瘢痕增生情况

### 烧伤科

- **核心思维差异**：聚焦大面积创面的愈合速度和功能恢复，优先选择高粘附性胶原敷料
- **胶原应用偏好**：胶原海绵、胶原凝胶，关注创面闭合速度和感染控制
- **评估指标**：创面愈合率（每周提升≥10%为有效）、渗液量、感染发生率
- **MDT协同逻辑**：大面积烧伤患者需联合烧伤科（清创植皮）+整形科（胶原修复），每月评估创面愈合率

### 骨科

- **核心思维差异**：聚焦软骨损伤的修复和长期关节功能，优先选择注射型胶原材料
- **胶原应用偏好**：注射型胶原、胶原支架，关注软骨再生和关节功能恢复
- **评估指标**：MRI软骨修复分级、Lysholm评分（提升≥10分为有效）、关节活动度
- **MDT协同逻辑**：膝关节软骨损伤患者需联合骨科（关节镜清理）+康复科（功能锻炼），每3个月评估Lysholm评分

### 内分泌科

- **核心思维差异**：聚焦基础疾病控制（如血糖管理），为胶原应用提供基础条件
- **胶原应用偏好**：不直接使用胶原，但管理胶原应用的基础条件（血糖控制、营养支持）
- **评估指标**：空腹血糖（目标<11.1mmol/L方可使用胶原）、糖化血红蛋白
- **MDT协同逻辑**：糖尿病足患者需联合内分泌科（血糖控制）+创面修复科（胶原换药），每周评估血糖和创面愈合情况

## 二、层级差异对比

### 三甲医院 vs 县域医院 vs 社区

| 维度 | 三甲医院 | 县域医院 | 社区 |
|------|---------|---------|------|
| 胶原知识储备 | 全面，覆盖各类胶原剂型 | 基础，主要使用海绵/敷料 | 有限，仅了解外用敷料 |
| 剂型可及性 | 全剂型可及 | 海绵/膜/敷料为主 | 仅外用敷料 |
| 红旗征识别率 | >85% | 42%-60% | <30% |
| MDT协同能力 | 强，可跨科室联合 | 弱，仅限本科室内 | 无，依赖上转 |
| 政策执行差异 | DRG分组精细，特例单议申报率58% | 分组较粗，申报率32% | 不涉及DRG |

## 三、跨学科MDT协同决策流程

```
复杂胶原应用场景识别
  │
  ├─ 大面积烧伤后瘢痕 → 烧伤科（清创植皮）+ 整形科（胶原修复）
  ├─ 糖尿病足合并骨髓炎 → 创面修复科（胶原换药）+ 内分泌科（血糖控制）+ 骨科（骨处理）
  ├─ 面部复杂创面 → 整形科（形态修复）+ 皮肤科（胶原外用）+ 口腔颌面外科（如涉及口腔）
  ├─ 关节软骨缺损 → 骨科（关节镜/胶原支架）+ 康复科（功能锻炼）
  └─ 慢性创面伴多重基础病 → 创面修复科牵头 + 相关科室联合评估
  │
  ▼
MDT讨论确认胶原使用方案
  │
  ├─ 胶原剂型选择（依据创面类型、深度、渗液量）
  ├─ 疗程制定（急性2-4周，慢性4-8周，按指南推荐）
  ├─ 疗效评估计划（明确评估工具、频率、达标标准）
  └─ 转诊/随访安排（明确转诊指征、随访间隔）
  │
  ▼
方案执行与动态评估
```
