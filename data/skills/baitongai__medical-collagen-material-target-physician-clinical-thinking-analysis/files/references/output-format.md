# 学术输出格式规范与使用示例（胶原领域专属·终版）

## 一、通用输出结构详细规范

### 摘要（300字以内）

概括研究背景、核心方法（三层谱系框架）、主要结论（本底思维vs政策改装思维差异，标注证据强度）、研究价值（对规培/政策/CDSS的启示）。

### 关键词

示例：医用胶原蛋白；临床思维；DRG；耗材集采；政策影响；循证红旗征

### 一、引言

- 研究背景：胶原类材料在相关科室的临床应用现状
- 研究目的：厘清本底思维与政策改装思维的差异
- 研究意义：对规培/政策/CDSS的价值
- 标注研究设计的合理性

### 二、研究方法

- 研究设计类型
- 研究对象（科室、层级、地域）
- 数据来源（公开数据库/文献/政策文件）
- 分析方法（三层谱系框架）
- 偏倚风险评估工具（NOS/AMSTAR 2/ROBINS-I）
- 标注伦理审批情况

### 三、研究结果

#### 3.1 三层谱系本底思维（量化结果）

- 西方认知偏倚发生率（5类偏倚：可获得性/确认/过早终止/归因/保守）
- 协和专科深挖层量化指标（创面分型评估率、胶原适配选择率、VSS/Lysholm评估率）
- 基层循证红旗征识别率
- 标注证据强度

#### 3.2 政策侵入分析（平衡呈现）

- 政策对本底思维的改写（DRG/医保目录/集采/反腐）
- 正反影响平衡呈现
- 政策耦合偏倚发生率
- 区域执行力差异
- 标注证据强度

#### 3.3 专科/层级/地域差异

- 不同科室的思维差异（皮肤科/整形科/烧伤科/骨科/内分泌科）
- 不同职称/地域医生的思维差异
- MDT协同决策逻辑
- 标注证据强度

#### 3.4 实证交叉验证

- HQMS/卫生统计年鉴数据的交叉验证结果
- 标注证据强度

### 四、讨论

- 研究结果的解释
- 与现有研究的异同
- 政策启示（平衡呈现正反建议）
- 临床启示（规培/CDSS/MDT）
- 研究局限性

### 五、结论

- 核心结论，标注证据强度等级（强/中/弱）
- 明确适用范围

### 六、利益冲突披露

- 按ICMJE标准披露所有研究者的学术任职
- 标注无商业资助
- 标注AI辅助生成内容

### 七、引用谱系

- 按用户要求的格式标注（默认GB/T 7714-2015）
- 一级来源占比≥70%
- 包含所有指南、政策、学术文献的来源

### 八、研究局限

包含六项必含局限：样本、地域、病种、时间、方法、文化

### 九、伦理审批声明

- 标注伦理委员会审批号
- 数据存储与销毁规则（5年存储，到期安全销毁）

### 公允性声明

```
本研究为独立公允研究，未接受任何商业机构资助，
符合ICMJE、COPE学术规范，结论不受商业利益影响，
仅用于学术讨论。
```

## 二、可视化规则

- **核心框架**：用流程图呈现"西方层→协和层→基层层→政策改装层"的三层谱系关系，标注量化阈值
- **政策影响**：用森林图对比"本底思维"与"政策改装思维"的决策流程差异，标注区域执行力差异
- **专科差异**：用雷达图对比不同科室的思维特征权重（如美观结局权重、功能恢复权重、创面愈合速度权重）
- **所有图表**：标注数据来源、证据强度等级，不得出现商业Logo，不得包含未公开数据

## 三、使用示例

### 用户输入

> 帮我生成一份关于"DRG 2.0对三甲医院烧伤科胶原类材料决策影响"的政策研究报告大纲，用于卫健委卫生政策研讨，引用格式用GB/T 7714。

### AI执行流程

1. **输出《胶原思维研究假设清单》**：假设"复杂创面需走DRG特例单议""DRG下医生新增'费用预判'决策步骤""政策耦合偏倚表现为防御性处方"，等待用户确认

2. 用户确认后，按S模块规定的结构生成45分钟政策研究报告大纲，包含三层谱系分析、DRG对胶原决策的正反影响、与整形科的思维差异、政策优化建议

3. **执行VL2校验**：确保政策分析平衡（既提特例单议的合理偿付，也提申报流程复杂性的副作用）、偏倚分析全面（区分原生确认偏倚与政策耦合的防御性处方偏倚）

4. **执行VL3校验**：按GB/T 7714格式标注所有来源，一级来源（医保局政策、中华医学会烧伤分会指南、核心期刊研究）占比≥70%

5. **执行VL4校验**：确保数据匿名化，无患者隐私泄露风险

6. **执行VL5校验**：模拟"烧伤科主任医师"和"卫生政策研究员"的评审意见，优化大纲内容

7. **执行VL6校验**：标注所有结论的证据强度等级，明确适用范围

8. **输出最终报告大纲**，附带引用谱系、研究局限声明、公允性声明

## 四、与商用版的核心边界

| 维度 | 本公允研究版 | 商用MSL版 |
|------|------------|----------|
| 立场 | 完全公允，无商业利益关联 | 医药企业立场，服务于合规医学沟通 |
| 用途 | 学术研究、医学教育、政策制定 | MSL拜访、KOL沟通、商业推广 |
| 核心约束 | 学术严谨性、引用合规、伦理合规 | RDPAC合规、NMPA适应症限制 |
| 数据使用 | 仅公开学术/政策数据，严禁内部数据 | 可使用企业内部医学数据（需合规审批） |
| 输出内容 | 论文、课件、政策报告、方法论文档 | 拜访脚本、CRM记录、合规自检表 |
| 验证重点 | 逻辑平衡性、来源可追溯、伦理合规 | 合规合法性、信息准确性、商业目标对齐 |
| 政策分析 | 平衡呈现正反影响，无倾向性 | 侧重政策对产品可及性的积极影响 |
