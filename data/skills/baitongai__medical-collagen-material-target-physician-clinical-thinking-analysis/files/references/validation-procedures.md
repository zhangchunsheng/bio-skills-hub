# 验证层详细操作规程（VL1-VL6·胶原领域终版）

## VL1：前置校验·假设确认

**动作**：输出《胶原思维研究假设清单》，列出本次研究的核心假设，标注假设的证据强度。

**假设清单格式**：
```
# 胶原思维研究假设清单
## 假设1：[假设陈述]
- 证据强度：[强/中/弱]
- 来源：[文献/政策文件/专家共识]
## 假设2：[假设陈述]
- 证据强度：[强/中/弱]
- 来源：[文献/政策文件/专家共识]
...
```

**示例假设**：
- "慢性创面治疗中，医生对胶原类材料的确认偏倚发生率为28%"（中等证据，基于单中心队列研究）
- "DRG耗材打包后，胶原使用率在中西部县域下降12%"（中等证据，基于2025年医保局公开数据）
- "重组人源化胶原蛋白的过敏发生率≤0.5%，低于动物源胶原蛋白"（强证据，基于多中心RCT）

**要求**：
- 必须等待用户回复"确认"后方可生成后续内容
- 若用户修正假设，需同步更新所有相关内容

**阻断规则**：若用户未明确以下四项必填参数，暂停执行并提示补充：
1. 研究亚专科
2. 研究设计类型
3. 研究层级
4. 目标受众

## VL2：学术严谨性校验·偏倚风险评估

**动作**：用以下工具评估研究偏倚风险，输出《偏倚风险评估报告》：

| 研究设计类型 | 评估工具 | 关键评估维度 |
|-------------|---------|-------------|
| 队列研究 | 纽卡斯尔-渥太华量表（NOS） | 选择、可比性、暴露/结局 |
| 系统评价/Meta分析 | AMSTAR 2 | 方法学质量、证据可靠性 |
| 非随机研究 | ROBINS-I | 混杂、选择、分类、偏离、缺失、测量、报告 |

**偏倚风险评估报告格式**：
```
# 偏倚风险评估报告
## 评估工具：[NOS / AMSTAR 2 / ROBINS-I]
## 评估结果
| 维度 | 评分/等级 | 说明 |
|------|----------|------|
| ... | ... | ... |
## 总体偏倚风险：[低/中/高]
## 敏感性分析（如偏倚风险为高）：[分析结果]
## 结论适用范围调整：[基于评估结果限定的适用范围]
```

**要求**：
- 检查逻辑自洽性：前后结论是否矛盾
- 检查偏倚分析平衡性：是否同时呈现胶原应用的获益与风险
- 检查结论适度性：是否存在过度推断
- 检查适用范围：是否明确限定

**阻断规则**：若偏倚风险为高，需补充敏感性分析或限制结论适用范围后方可继续

## VL3：引用合规性校验·来源可追溯

**动作**：核对所有数据、观点的来源，按用户要求的格式标注。

**校验清单**：
1. 一级公开来源占比≥70%
2. 所有引用可溯源（附DOI/URL/文件号）
3. 标注AI辅助生成内容的位置
4. 按用户指定引用格式标注（默认GB/T 7714-2015）

**来源分级标准**：

| 级别 | 定义 | 示例 |
|------|------|------|
| 一级来源 | 原始研究、政策原文、官方统计数据 | RCT论文、国家医保局文件、HQMS数据 |
| 二级来源 | 综述、指南、专家共识 | 中华医学会烧伤分会指南、Cochrane综述 |
| 三级来源 | 教材、科普、媒体报道 | 仅作为背景参考，不可作为核心论据 |

**阻断规则**：若存在以下情况，需补充标注或删除相关内容：
- 来源不明
- 引用格式错误
- 使用违规来源（未公开商业数据、未脱敏临床数据）

## VL4：伦理合规性校验·数据安全/隐私保护

**动作**：核查以下内容，符合《涉及人的生物医学研究伦理审查办法》《数据安全法》《个人信息保护法》：

### 校验清单

1. **数据匿名化**：
   - 是否包含可识别的医生姓名、医院名称、患者信息
   - 若使用访谈数据，是否以研究ID替代真实身份（如Collagen-2026-001）

2. **知情同意**：
   - 若使用访谈数据，是否获得受访者知情同意
   - 是否说明研究目的、数据用途、存储期限

3. **隐私保护**：
   - 是否符合个人信息处理规则（最小必要原则）
   - 是否去除所有间接可识别信息（如罕见胶原不良反应+小城市=可能识别个体）

4. **数据存储**：
   - 是否明确存储期限（5年）
   - 是否说明到期后安全销毁方式

**阻断规则**：若不符合伦理要求，需删除敏感内容，补充伦理声明

## VL5：同行评议模拟·ICMJE标准

**动作**：模拟2-3位ICMJE标准的领域专家评审意见，输出《同行评议模拟报告》。

### 模拟专家设定

| 专家编号 | 模拟身份 | 资质描述 |
|---------|---------|---------|
| 专家A | 三甲医院烧伤科/整形科主任医师 | 15年创面修复经验，中华医学会烧伤/整形外科分会委员 |
| 专家B | 卫生政策研究员 | 长期研究DRG/DIP耗材分组对临床决策的影响，发表政策研究论文20+篇 |
| 专家C | 《中华整形外科杂志》/《中华烧伤杂志》审稿人 | 10年审稿经验，熟悉ICMJE/COPE规范 |

### 评议报告格式

```
# 同行评议模拟报告
## 专家A（三甲医院烧伤科/整形科主任医师）
### 肯定意见
- [研究亮点，如：三层谱系框架清晰，政策分析平衡，量化指标可操作性强]
### 质疑意见
- [需改进之处，如：中西部基层数据不足，结论外推需谨慎]
### 修改建议
- [如：补充县域医院胶原诊疗能力的调研数据]

## 专家B（卫生政策研究员）
...

## 专家C（《中华整形外科杂志》审稿人）
...

## 修改响应
- 针对每位专家意见的修改措施
- 未采纳意见的理由说明
```

**要求**：根据模拟评议意见修改研究成果，直至通过"虚拟同行评议"

## VL6：结果普适性分级·证据强度标注

**动作**：按证据强度分级规则标注所有研究结论，明确适用范围。

### 标注格式

在每个核心结论后标注：
```
[结论内容]（证据强度：[强/中/弱]；适用范围：[具体范围]）
```

### 证据强度分级标准

| 等级 | 依据 | 推广范围 |
|------|------|---------|
| 强证据 | 多中心RCT、Meta分析、全国代表性队列研究 | 可推广至全国 |
| 中等证据 | 单中心队列研究、病例对照研究 | 适用于特定区域/层级医院 |
| 弱证据 | 病例系列、专家共识、质性访谈 | 需后续实证研究验证 |

**阻断规则**：若未标注证据强度等级，需补充标注后方可输出。弱证据结论必须标注"需后续实证研究验证"，不得作为强证据推广。
