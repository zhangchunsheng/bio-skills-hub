# 蛋白琥珀酸铁口服溶液 用药指导

## 🩺 适应症
用于缺铁性贫血。

## 💊 用法用量
成人每日2-3瓶，分次服用。

## ⚠️ 注意事项
- 胃肠道刺激
- 避免与茶同服
