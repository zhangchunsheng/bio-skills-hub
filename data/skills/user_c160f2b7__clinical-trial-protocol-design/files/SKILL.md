# Clinical Trial Protocol Design（临床试验方案设计 I–IV 期）

## Overview

本技能将用户提供的适应症、药物/器械特征、研发阶段等输入，转化为高度专业、结构完整、可操作的临床试验方案草案（Protocol Draft）。核心能力覆盖：研究分期与设计类型选择、随机化与盲法设计、终点指标设定、统计假设与样本量估算、安全性评估与伦理考量。

**输出定位**：产出仅供内部讨论的方案草案（Protocol Draft），以 `[ ]` 标注待确认/待填数据的位置。**不构成最终临床方案**，必须经合格统计师、医学专家与法规团队审核后方可使用。

## Workflow Decision Tree

```
用户输入（适应症/药物特征/研发阶段等）
    │
    ├── 信息不足（缺少分期/适应症/对照/终点）──→ Phase 0：主动追问关键信息
    ├── 信息足够 ───────────────────────────→ Phase 1：设计决策
    │                                          ├─ 确定研究分期与设计类型（加载 study-design-guide）
    │                                          ├─ 确定随机化与盲法（加载 randomization-blinding）
    │                                          ├─ 确定终点指标与统计假设（加载 statistics-sample-size）
    │                                          └─ 核对法规与伦理要求（加载 regulatory-framework）
    │
    ├── 需要数值计算（样本量）────────────→ 运行 scripts/sample_size_calculator.py
    │
    └── Phase 2：按方案输出框架生成草案
         └── Phase 3：合规标注（[ ]占位 + 免责声明）
```

## Phase 0：信息收集（必要时）

当用户仅提供疾病领域或药物名称时，**主动追问**以下关键信息（一次最多 3–4 个问题，勿轰炸）：

1. **试验分期**：I / II / III / IV 期（决定设计类型与样本量量级）
2. **目标适应症**：疾病阶段、人群特征（如是否一线/后线治疗）
3. **药物特征**：作用机制（如为创新机制，I 期需重点设计首次人体剂量爬坡）
4. **对照现状**：标准治疗（SoC）是否存在、有无已上市同类药
5. **效应预期**：预期效应量、优效/非劣效/等效需求
6. **监管路径**：申报地区（NMPA / FDA / EMA），是否全球多中心

信息仍不足时，用合理的默认假设并**明确标注假设**，不要臆造关键参数。

## Phase 1：设计决策

按顺序完成以下设计决策，每一步的详细依据分别加载对应 reference：

### 1. 研究分期与设计类型

加载 `references/study-design-guide.md`。

- 判断研究分期（I/II/III/IV）及其核心目标（耐受性/初步疗效/确证疗效/上市后研究）
- 选择设计类型：平行组、交叉、析因、篮式/伞式/平台（如适用）
- 确定检验框架：**优效性 / 非劣效性 / 等效性**，并给出选择理由

### 2. 随机化与盲法

加载 `references/randomization-blinding.md`。

- 选择随机化方法：简单、区组、分层、动态（最小化法），说明分层因素与区组大小
- 选择盲法：开放、单盲、双盲、双模拟、三盲，说明设盲对象与偏倚控制逻辑
- 设计揭盲条件与应急揭盲程序

### 3. 终点指标与统计假设

加载 `references/statistics-sample-size.md`。

- 设定主要终点（定义、测量方法、评估时点）、关键次要终点（层级/多重性策略）、探索性终点
- 用统计学语言构建原假设 H0 与备择假设 H1
- **样本量估算**：需要数值计算时运行 `scripts/sample_size_calculator.py`（支持率/均数、平行/配对、优效/非劣效/等效、脱落率调整），并在方案中说明关键参数与依据
- 明确分析人群：FAS / PPS / SS

### 4. 法规与伦理核对

加载 `references/regulatory-framework.md`。

- 核对 ICH-GCP、NMPA（2020 GCP/2023 注册管理办法）、FDA 21 CFR、EMA 等要求
- 确保受试者保护措施完备（知情同意、隐私保护、风险最小化）

## Phase 2：方案输出框架

按以下框架生成方案摘要或完整草案，**各节必须包含实质内容而非空标题**：

1. **方案标题与方案号**：自动生成占位符，如 `[方案名称]`、`[方案号：XXXX-XXX-XX]`
2. **研究分期与整体设计**：一句话设计描述（如"随机、双盲、安慰剂对照、平行组、优效性设计"）
3. **研究背景与立题依据**：基于用户输入合理推演（疾病负担、未满足需求、机制合理性），引用文献处标注 `[参考文献]`
4. **研究目的**：主要目的 / 次要目的 / 探索性目的（动词开头，可测量）
5. **试验人群**：目标适应症、关键入选/排除标准概括（完整标准以 `[ ]` 标注待定）
6. **研究治疗与对照**：试验药/器械、对照（阳性药/安慰剂）、给药方案（剂量、频次、疗程）、合并用药限制
7. **随机化与盲法**：方法、分层因素、区组大小、设盲对象、揭盲条件、应急揭盲程序
8. **终点指标**：主要终点（定义+测量+时点）、关键次要终点（层级策略）、探索性终点
9. **统计假设与分析计划**：H0/H1、样本量（参数+公式/软件+脱落率调整后例数）、检验策略（α、单双侧、多重性校正）、分析人群（FAS/PPS/SS）与主要分析方法
10. **安全性评估**：AE 收集、SAE 报告时限与流程、安全性指标（实验室/生命体征/ECG）、暴露调整发生率
11. **数据监查与质量控制**：DMC/DSMB 设立条件（大型确证性/长期试验建议设）、数据管理、盲态审核
12. **伦理考虑与受试者保护**：知情同意流程、隐私与数据保护、风险-获益评估
13. **参考文献或法规依据**：简要列出

## Phase 3：标注与约束（必做）

- 不确定的数值、待确认项一律用 `[ ]` 标注，如 `[预设脱落率 20%，需按研究现场经验确认]`
- 无法确定的数值优先引用文献或公认标准；无法引用时用合理假设并明确标注
- 方案结尾固定附免责声明：*"本方案草案仅供内部讨论，不构成最终临床方案，须经合格统计师、医学专家与法规团队审核后方可使用。"*

## 语言与风格规范

- 使用规范临床研究术语（如"随机分配""双盲""主要终点""全分析集"），不混用口语
- 语言科学、精确、客观；统计表述用标准符号（α、β、δ、σ、n）
- 保持受试者安全第一的伦理立场

## Resources

### scripts/

- `sample_size_calculator.py` — 样本量计算器（纯 Python 标准库，零依赖）。支持：
  - 指标类型：**均数（连续性）**与**率（二分类）**
  - 设计类型：平行组（两样本）、配对设计
  - 检验框架：优效性、非劣效性、等效性
  - 输出：每组例数、总例数、考虑脱落率后的调整例数
  - 用法示例见脚本 docstring；计算结果写入方案"样本量估算"节
