# 研究分期与设计类型选择指南（Study Design Guide）

> 加载时机：Phase 1 设计决策第 1 步。用于确定研究分期、整体设计类型与检验框架，并给出设计依据。

## 1. 研究分期定义与核心目标

| 分期 | 核心目标 | 典型设计 | 样本量量级 | 关键产出 |
|------|----------|----------|-----------|----------|
| I 期 | 耐受性、安全性、药代动力学（PK）/药效学（PD）、最大耐受剂量（MTD）/推荐 II 期剂量（RP2D） | 剂量爬坡（3+3、改良 Fibonacci、贝叶斯 CRM/BLRM）、开放标签 | 20–80 例 | MTD/RP2D、剂量-暴露-效应关系 |
| II 期 | 初步疗效信号、进一步安全性、剂量-效应选择 | 单臂 Simon 两阶段、随机对照（II 期概念验证）、随机停药 | 50–300 例 | 初步疗效证据（ORR/PFS 等）、PoC 判定、III 期设计依据 |
| III 期 | 确证疗效与安全性，支持注册申报 | 随机、双盲、对照、多中心；优效或非劣效 | 数百–数千例 | 确证性证据（主要终点达标）、获益-风险结论 |
| IV 期 | 上市后研究：长期安全性、真实世界疗效、扩展适应症 | 观察性队列、实用性随机试验（PCT）、上市后安全性监测（PV） | 视目的而定 | 罕见 AE 信号、真实世界证据（RWE） |

**设计依据写法**：每个分期选择必须说明理由，例如：
> "选择随机、双盲、安慰剂对照、平行组、优效性设计：本研究为确证性 III 期研究，该设计为注册申报的黄金标准，可控制选择偏倚与测量偏倚，优效性框架用于证实试验药在主要终点上显著优于安慰剂。"

## 2. 设计类型（Parallel / Crossover / Factorial / Adaptive）

### 2.1 平行组设计（Parallel Group）
- **适用**：大多数 II/III 期确证性研究；病程慢性、治疗周期长、存在残留效应或治愈性治疗
- **优点**：简单直接、结果解释清晰、不受残留效应影响
- **缺点**：需较大样本量、受试者间变异大

### 2.2 交叉设计（Crossover）
- **适用**：I 期 PK/BE 研究；慢性稳定疾病（如高血压、哮喘）短疗程疗效比较
- **前提**：治疗无治愈性、无残留效应（需洗脱期）、病程稳定
- **优点**：自身对照，样本量小（受试者内比较），可消除受试者间变异
- **缺点**：存在残留效应与周期效应风险、脱落影响大、不适用急性/进展性疾病

### 2.3 析因设计（Factorial）
- **适用**：多因素/联合用药评估（如 2×2 析因验证单药与联合）
- **优点**：一个试验回答多问题、可评估交互作用
- **缺点**：交互作用存在时解释复杂、需样本量更大

### 2.4 篮式/伞式/平台设计（Basket / Umbrella / Platform）
- **适用**：肿瘤精准治疗时代，按生物标志物/靶点分层的探索性试验
- **注意**：多为探索性质，确证性结论仍需独立 III 期验证

### 2.5 适应性设计（Adaptive Design，如适用）
- 群体序贯（Group Sequential）、样本量再估计、主方案（Master Protocol）
- 必须在方案中预设规则、控制 I 类错误膨胀（如 α 消耗函数），并咨询统计师与法规专家

## 3. 检验框架：优效 / 非劣效 / 等效

### 3.1 优效性（Superiority）
- **H0**：试验药与对照无差异（δ ≤ 0）；**H1**：试验药优于对照
- **适用**：对照为安慰剂；或预期试验药疗效明确优于活性对照
- 证据强度最高，为注册首选框架

### 3.2 非劣效性（Non-inferiority）
- **H0**：试验药劣于对照（差值 ≥ Δ，Δ 为非劣效界值）；**H1**：试验药不比对照差超过 Δ
- **适用**：对照为标准治疗且疗效已确证，试验药具有其他优势（安全性更好、依从性更好、成本更低、给药便利）
- **关键**：**Δ 的合理确定**——通常取对照药历史疗效的下界（如保留 ≥50% 对照效应的 CI 下界），须有文献依据；Δ 过宽会掩盖真实劣效，过窄则样本量巨大
- **前提（生物恪守，assay sensitivity）**：必须能证明对照在本试验中有效，否则非劣效结论无意义

### 3.3 等效性（Equivalence）
- **H0**：|δ| ≥ Δ（等效界值）；**H1**：|δ| < Δ
- **适用**：生物等效性（BE）研究、仿制药、某些生物类似药
- 采用**双侧检验**（两个单侧检验 TOST），α 通常取双侧 0.05（每个单侧 0.025）

### 3.4 选择决策要点
1. 对照为安慰剂 → 优效性（除非伦理不允许使用安慰剂）
2. 对照为标准治疗，试验药有附加优势 → 非劣效性
3. 无标准治疗且疾病可自愈 → 优效 vs 安慰剂或单臂 + 历史对照
4. 判断"附加优势"时要诚实：若试验药既无疗效优势也无依从性/安全性优势，非劣效设计缺乏正当性

## 4. 设计要素速查

| 要素 | 常见选择 | 备注 |
|------|----------|------|
| 对照 | 安慰剂 / 阳性药 / 剂量对照 / 历史对照 | 阳性药须为指南推荐 SoC |
| 随机分组比例 | 1:1 / 2:1 / 3:1 | 确证性研究多为 1:1 |
| 中心 | 单中心 / 多中心 | 确证性须多中心（通常 ≥10–20 家） |
| 访视安排 | 筛选 / 基线 / 治疗期 / 随访 | 时点与终点测量严格对应 |
| 治疗周期 | 依适应症而定 | 肿瘤常用"至疾病进展/毒性" |

## 5. 常见设计错误（避免）

1. 探索性 II 期采用确证性 III 期的过大样本与冗长流程（浪费资源）
2. III 期采用开放标签（未合理设盲，偏倚不可控）
3. 非劣效界值拍脑袋设定，无文献/监管依据
4. 交叉设计用于可能治愈或急性病（残留效应风险）
5. 主要终点过多或事后更换（多重性失控）
