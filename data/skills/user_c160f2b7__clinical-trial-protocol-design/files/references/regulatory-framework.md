# 法规框架与伦理要求指南（Regulatory Framework）

> 加载时机：Phase 1 设计决策第 4 步。用于核对监管要求、伦理原则与受试者保护措施。

## 1. 国际协调会议：ICH-GCP E6(R2)

**ICH E6(R2) 综合附录**（2016 年采纳，R3 草案推进中）是临床试验设计、实施、记录、报告的全球标准。

核心原则（ICH E6 第 2 节）：
1. 试验须符合《赫尔辛基宣言》伦理原则、GCP 与适用法规
2. 风险-获益评估须充分且可接受
3. 受试者的权利、安全与健康优先于科学与社会利益
4. 试验药物应有充分的非临床与临床信息支持
5. 试验须有科学严谨的设计（Protocol 定义）
6. 试验须按已批准方案实施并获得 IRB/IEC 批准
7. 知情同意须自由给予、记录在案
8. 质量保证与质量控制（QA/QC）贯穿全程
9. 记录须准确、完整、可追溯（ALCOA+）
10. 试验结果报告须准确、完整、无偏

**R2 关键新增**：基于风险的质量管理（RBQM）、质量源于设计（QbD）、关键数据与关键流程的确定、供应商监督。

## 2. NMPA（中国）监管框架

| 文件 | 要点 |
|------|------|
| 《药物临床试验质量管理规范》（GCP，2020 年 7 月施行，2020 年第 57 号公告） | 与 ICH E6(R2) 接轨；含研究者、申办者、伦理委员会职责；药物警戒要求 |
| 《药品注册管理办法》（2020 年）及配套《化学药品注册分类及申报资料要求》（2020 年第 44 号） | 注册分类决定研发路径；IND（临床试验申请）与 NDA 申报要求 |
| 《药物临床试验期间安全信息评估与管理规范》（2021 年） | SUSAR 快速报告、DSUR 年度报告 |
| CDE 技术指导原则 | 各适应症/各分期指导原则（如肿瘤、心血管、儿科）；《以患者为中心的药物临床试验设计技术指导原则》（2023） |
| 《医疗器械临床试验质量管理规范》（2022 年） | 器械试验的分期（可行性/确证性）与风险管理 |
| 人类遗传资源管理条例（2023 修订） | 涉及中国人类遗传资源的国际合作试验须审批/备案（重要！全球多中心须注意） |

**中国临床试验登记**：药物临床试验登记与信息公示平台（chinadrugtrials.org.cn），IND 获准后须登记。

## 5. 伦理原则与受试者保护

### 5.1 核心文件
- 《赫尔辛基宣言》（WMA，2013 修订）：受试者利益优先、独立审查、知情同意、弱势人群保护
- 《贝尔蒙报告》（美国）：尊重人、有利、公正三原则
- ICH E6 第 2 节：见上文

### 5.2 知情同意（Informed Consent）
- **要素**：研究目的与程序、风险与获益、替代治疗、自愿性与退出权、保密性、赔偿安排、联系信息
- **流程**：研究者（获授权）向受试者充分说明 → 充分时间考虑 → 签署知情同意书（ICF）→ 一式两份
- **特殊人群**：未成年人（法定监护人+儿童同意）、认知障碍者（法定代理人）、紧急情况下（紧急知情同意程序）、孕产妇、囚犯
- 知情同意过程须记录，受试者须留一份副本

### 5.3 隐私与数据保护
- ICH-GCP：受试者隐私保护贯穿全程，病例记录保密
- 中国：《个人信息保护法》（PIPL）、《数据安全法》；涉及健康医疗数据的处理须合法合规
- 欧盟：GDPR（临床试验数据为敏感数据，须有法律依据如科学研究豁免）
- 美国：HIPAA（受保护健康信息）
- 数据去标识化/假名化、访问控制、数据保留期限

### 5.4 风险最小化
- 排除标准严控高风险人群
- 剂量爬坡安全规则（如 3+3 的 DLT 定义与停止规则）
- 中期安全监查与停止规则（DMC/DSMB）
- 应急揭盲程序、抢救预案

## 6. 方案中法规部分的写法

1. **法规符合性声明**：逐条列出本方案遵循的法规与指南（含版本年份）
2. **伦理审批流程**：方案提交 IRB/IEC 批准 → 中国须在启动前获伦理批件；国际多中心须获各中心伦理批准
3. **注册登记**：方案获批后于相应平台登记（中国：药物临床试验登记平台；美国：ClinicalTrials.gov；EU：CTIS）
4. **安全报告要求**：SAE 报告时限（中国：申办者获知 SAE 后 15 天内报告国家局与伦理；死亡或危及生命 7 天；SUSAR 快速报告规则）、DSUR 年度报告
5. **人类遗传资源（中国境内样本）**：涉及国际合作须先获批/备案，方案中注明

## 7. 常见错误（避免）

1. 忽略中国人类遗传资源审批要求（全球多中心常见踩坑）
2. SAE 报告时限/流程表述与当地法规不一致
3. 知情同意流程未涵盖弱势人群或紧急情况条款
4. 隐私保护仅一句"保密"，未落实数据保护法具体要求
5. 法规文件引用无版本/年份（如把已废止的 2001/20/EC 当现行）
