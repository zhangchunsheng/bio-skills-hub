# 统计假设与样本量估算指南（Statistics & Sample Size）

> 加载时机：Phase 1 设计决策第 3 步。用于构建统计假设、设定终点指标、估算样本量、确定检验策略与分析人群。
> 数值计算：运行 `scripts/sample_size_calculator.py` 获得精确结果，本文件提供公式与参数选取依据。

## 1. 终点指标设定

### 1.1 主要终点（Primary Endpoint）
- **原则**：直接反映临床获益；客观、可测量、可重复；监管机构认可
- **定义要素**：测量指标 + 测量方法/仪器 + 评估时点/窗 + 处理规则（如提前退出、缺失）
- 常见示例：
  - 肿瘤：无进展生存期（PFS）、总生存期（OS）、客观缓解率（ORR）
  - 心血管：心血管死亡+非致死性心梗+卒中复合终点（MACE）
  - 感染：临床治愈率、病毒学应答
  - 慢病：血压/血糖较基线的变化值、症状量表改善
- 复合终点须说明组分、组分的相对权重、首事件分析法

### 1.2 关键次要终点（Key Secondary）
- 按**层级（Hierarchical / Gatekeeping）**排列，仅在主要终点达成后按序检验
- 层级外的次要终点结果视为支持性/探索性，结论需谨慎表述

### 1.3 探索性终点（Exploratory）
- 生物标志物、机制相关指标、亚组分析、健康经济学指标
- 结果仅作假设生成，不用于确证

### 1.4 多重性策略（Multiplicity Control）
- 主要终点唯一 → 无需校正
- 多个主要/次要终点 → 层级检验、Bonferroni/Holm 校正、Hochberg 等（须预设）
- 中期分析 → α 消耗函数（O'Brien-Fleming 等）

## 2. 统计假设构建（统计学语言）

### 2.1 通用符号
- δ：真实处理效应（试验组 − 对照组）
- Δ：非劣效/等效界值（margin）
- α：I 类错误率（假阳性），通常双侧 0.05
- β：II 类错误率；把握度（Power）= 1 − β，通常 ≥ 0.80，确证性 ≥ 0.90
- σ：结局的标准差（均数类）；p：事件率（率类）

### 2.2 检验框架假设表述

| 框架 | H0 | H1 | 检验 |
|------|----|----|------|
| 优效（Superiority） | δ ≤ 0 | δ > 0 | 单侧 α 或双侧 α/2（惯例报告双侧 p<0.05 即单侧 0.025） |
| 非劣效（NI） | δ ≤ −Δ | δ > −Δ（即差不超过 Δ） | 单侧 α（通常 0.025） |
| 等效（Equivalence） | \|δ\| ≥ Δ | \|δ\| < Δ | TOST 两个单侧检验，各 α/2 |

示例（非劣效）：
> H0：试验药在主要终点上的效应至少比阳性对照差 Δ（即 δ ≤ −Δ）；H1：试验药不比阳性对照差超过 Δ（δ > −Δ）。检验水准：单侧 α = 0.025。若主要终点差值 95% 置信区间下限大于 −Δ，则非劣效成立（CI 法等价于单侧检验）。

## 3. 样本量估算

### 3.1 均数类（连续性结局）

**两样本平行、优效/非劣效**（每组 n）：

```
n = 2 × (Z_{1−α} + Z_{1−β})² × σ² / δ²
```

- δ：预期组间均数差（非劣效时 δ = Δ 界值）
- σ：结局标准差（来自文献/既往研究/II 期数据）
- 双侧 α 用 Z_{1−α/2}，单侧用 Z_{1−α}

**配对设计（均数差，如交叉设计的阶段差）**：

```
n = (Z_{1−α} + Z_{1−β})² × σ_d² / δ²
```

- σ_d：配对差的变异（注意与 σ 区分，通常 σ_d < σ√2）

**等效（两样本均数，TOST）**：

```
n = 2 × (Z_{1−α/2} + Z_{1−β})² × σ² / Δ²   （假设真实效应为 0）
```

### 3.2 率类（二分类结局）

**两样本平行、优效**（每组 n）：

```
n = (Z_{1−α} + Z_{1−β})² × [p1(1−p1) + p2(1−p2)] / (p1 − p2)²
```

- p1：试验组预期事件率；p2：对照组预期事件率

**两样本平行、非劣效**：

```
n = (Z_{1−α} + Z_{1−β})² × [p1(1−p1) + p2(1−p2)] / (p1 − p2 + Δ)²   （p1−p2+Δ 为有效差异）
```

**率差检验亦可用**（各自率的方差直接相加，同上式）。

### 3.3 生存类（时间-事件结局）
- 需基于事件数（events）而非例数：所需事件数
  ```
  E = 4 × (Z_{1−α} + Z_{1−β})² / ln(HR)²   （两组等比例）
  ```
- 例数 = 事件数 / 预期事件率（须考虑入组期与随访期长度）
- 软件：PASS / nQuery / R（powerSurvEpi、gsDesign）；方案中注明软件与版本
- 本技能计算器未含生存类（因需入组模式假设），涉及生存终点时**必须引用专业软件估算**，本技能给出逻辑框架

### 3.4 脱落率调整
```
n_adjusted = n / (1 − dropout_rate)
```
- 脱落率：依据既往试验经验预设，常见 10%–25%，方案中明确标注假设来源

### 3.5 参数选取要求（写入方案）
1. 每个参数注明来源（文献、既往研究、II 期数据、临床共识、合理假设）
2. 用 `[ ]` 标注待确认参数
3. 给出计算软件/公式依据（本技能脚本输出可作为参考计算）

## 4. 检验策略

- **显著性水平**：α = 0.05（双侧）/ 0.025（单侧）；非劣效界值检验通常单侧 0.025
- **把握度**：确证性 ≥ 0.90（常规 0.90）；探索性可 0.80
- **单侧/双侧**：优效与 NI 用单侧假设+双侧 CI 报告；等效必须双侧
- **多重性校正**：见 1.4，全部预设
- **CI 法 vs p 值法**：监管审评偏好效应量 + 置信区间报告

## 5. 分析人群定义（Analysis Sets）

| 人群 | 全称 | 定义 | 适用 |
|------|------|------|------|
| **FAS** | Full Analysis Set（全分析集，ITT 的忠实体现） | 所有随机化且至少接受一次治疗/有一次基线后数据的受试者；按随机分组分析 | 主要疗效分析（ICH E9 推荐为确证性首选） |
| **PPS** | Per-Protocol Set（符合方案集） | FAS 中依从方案者（完成治疗、无重大方案违背、主要终点可评估） | 敏感性分析；评估 ITT 与 PP 结论一致性 |
| **SS** | Safety Set（安全集） | 所有至少接受一次试验治疗的受试者，按实际接受治疗分组 | 安全性分析 |
| mITT | Modified ITT | ITT 的变体（如仅限至少接受一次治疗者） | 具体定义须写清 |

- 原则：**主要分析用 FAS（ITT 原则）**；PPS 作为敏感性分析；两组结论一致增强证据可信度
- 方案违背的定义与处理（排除/纳入）须在 SAP 中预设

## 6. 主要分析方法

- 连续结局：ANCOVA（调整基线）/ t 检验 / 秩和检验；报告 LS 均值差与 95% CI
- 二分类：Cochran-Mantel-Haenszel（分层）/ 卡方 / Fisher 精确；报告率差与 95% CI 或 RR/OR
- 生存：Kaplan-Meier + log-rank + Cox PH；报告 HR 与 95% CI
- 缺失数据处理：预设（LOCF 已不推荐；倾向多重填补 MI、混合模型 MMRM）
- 协变量：分层因素作为协变量纳入模型；敏感性分析验证

## 7. 常见错误（避免）

1. 样本量参数无来源、拍脑袋（审评必被质疑）
2. 非劣效界值无依据（最常见缺陷）
3. 忽略脱落率或脱落率假设不现实
4. 多重终点无校正策略
5. 把探索性终点当主要结论
6. 生存研究用率公式估算（错误量级）
