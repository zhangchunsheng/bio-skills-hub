# 随机化与盲法设计指南（Randomization & Blinding）

> 加载时机：Phase 1 设计决策第 2 步。用于选择随机化方法、盲法设计，并解释偏倚控制逻辑。

## 1. 随机化的目的

消除**选择偏倚**（selection bias），使已知与未知预后因素在组间均衡可比，为统计推断提供概率基础（随机化检验的前提）。随机化**不等于**随意分配——必须有不可预测性、可核查性（audit trail）。

## 2. 随机化方法

### 2.1 简单随机化（Simple / Unrestricted）
- 如抛硬币、随机数字表、计算机生成序列
- **优点**：实现简单、不可预测
- **缺点**：小样本下组间例数可能失衡、重要基线协变量可能不均衡
- **适用**：大样本；作其他方法的底层机制

### 2.2 区组随机化（Blocked / Permuted Block）
- 将受试者按区组（如区组大小 4/6/8）分配，保证组间例数随时平衡
- **关键参数**：区组大小必须保密（防猜测下一例分组），常使用**变区组大小**（如 4 与 6 随机交替）
- 分层因素多时区组大小需相应减小（避免层内区组过大）

### 2.3 分层随机化（Stratified）
- 先按重要预后因素分层，层内再行区组随机
- **常用分层因素**：研究中心、疾病分期、基线严重程度、年龄组、生物标志物状态
- **原则**：分层因素不宜过多（≤3–4 个），否则层内样本过少；确证性研究至少按研究中心分层
- 注意：分层因素应与预设的亚组分析一致，避免事后分层

### 2.4 动态随机化（Dynamic / Minimization，最小化法）
- 按已入组受试者的协变量分布动态调整分配概率，使各因素整体均衡
- **优点**：小样本多因素时均衡性优于分层区组
- **缺点**：分配可预测性略增、需中心化交互系统（IWRS）实时计算
- **适用**：II 期小样本、多中心协变量平衡要求高的研究

### 2.5 实施细节（写入方案）
- 随机序列由独立统计师/第三方（非设盲人员）生成，密封保存
- 分配隐匿（allocation concealment）：使用中央随机系统（IWRS/IXRS）或顺序编号不透光密封信封；**分配隐匿与盲法分开陈述**
- 随机清单严格保密，仅授权人员可访问，留存完整审计轨迹

## 3. 盲法设计

### 3.1 盲法类型

| 类型 | 设盲对象 | 说明 |
|------|----------|------|
| 开放标签（Open-label） | 无 | 无法设盲时（如器械手术 vs 药物、明显 AEs 差异），仍需盲态终点评估（BEO） |
| 单盲（Single-blind） | 受试者 | 较少单独使用 |
| 双盲（Double-blind） | 受试者 + 研究者/评估者 | 金标准；试验组与对照组须外观一致（双模拟） |
| 双模拟（Double-dummy） | 同上 | 试验药与对照剂型/外观不同时，制备安慰剂使两组各服一份活性+一份安慰剂 |
| 三盲（Triple-blind） | 受试者 + 研究者 + 统计师/数据管理人员 | 进一步减少分析偏倚 |

### 3.2 盲法选择逻辑
1. 主要终点为**主观评估**（如量表评分、症状缓解、影像学判读）→ 强烈建议双盲；无法双盲时至少**独立盲态终点评估（BEO）**
2. 客观终点（如全因死亡）→ 开放标签可接受，但仍是次优
3. 试验药与对照外观差异大 → 使用双模拟技术
4. 器械研究：受试者/评估者盲（如 sham 手术对照）、操作者不盲
5. 中期分析存在时：需**设盲统计师**（independent statistician）执行，结果不透露给执行团队

### 3.3 揭盲条件与应急揭盲程序（Unblinding）
- **计划内揭盲**：达到研究终点后、数据库锁定前（如适用）
- **计划外（应急）揭盲**：仅当受试者安全需要时（SAE 处理需知悉组别、紧急救治需要）
- **程序要求**：
  - 应急揭盲包/系统（IWRS 应急揭盲功能）随研究启动
  - 揭盲记录：时间、人员、理由、处理过程，全部留痕
  - 揭盲者与受试者一般即退出双盲治疗（除非方案另有规定）
  - 统计师在最终分析前对揭盲情况汇总报告，评估盲态完整性（blind integrity）
- **禁止**：以好奇心为由揭盲、揭盲信息泄露给评估者

## 4. 偏倚控制逻辑（写入方案依据）

| 偏倚类型 | 控制手段 |
|----------|----------|
| 选择偏倚 | 随机化 + 分配隐匿 |
| 测量/观察偏倚 | 双盲或盲态终点评估（BEO） |
| 实施偏倚（组间差异处理） | 双盲、双模拟、标准治疗方案（SoC 统一） |
| 随访偏倚（组间脱落差异） | 严格的随访程序、ITT 原则分析、脱落率监控 |
| 分析偏倚（post hoc） | 预设统计分析计划（SAP）、盲态数据审核 |

## 5. 常见错误（避免）

1. 只写"随机双盲"不写具体方法、分层因素、区组大小（不具操作性）
2. 把分配隐匿误认为盲法（两者机制不同，须分别设计）
3. 应急揭盲流程缺失或权限不清
4. 双盲试验两组药品外观/气味/包装不一致且未用双模拟
5. 区组大小固定且写进方案（可预测下一例分组）
