# 🛡️ Bionic Guard — 仿生安全守卫

> **类比**：人类大脑的安全防线不是单一的。
> - ACC（前扣带皮层）：实时监测执行冲突，发现矛盾立即预警
> - 杏仁核：嗅探潜在风险，高威胁操作触发警戒
> - 免疫系统：识别未知威胁模式，建立长期免疫记忆

本 Skill 整合三层防护，在**任何操作前后**自动执行安全检查。

---

## 三层防护架构

```
用户请求/操作
    ↓
┌─────────────────────────────────────────┐
│  L1: ACC 错误监测（实时）                │
│  - 检测执行过程中的矛盾信号              │
│  - 发现不一致立即预警                    │
└─────────────────────────────────────────┘
    ↓ 无冲突
┌─────────────────────────────────────────┐
│  L2: 杏仁核风险嗅探（预判）              │
│  - 评估操作风险等级                      │
│  - 高风险触发用户确认                    │
└─────────────────────────────────────────┘
    ↓ 风险可接受
┌─────────────────────────────────────────┐
│  L3: 免疫系统威胁识别（学习）            │
│  - 识别新型异常模式                      │
│  - 记录威胁签名，建立长期免疫            │
└─────────────────────────────────────────┘
    ↓
执行操作 / 阻断并警告
```

## 自动触发规则

### 触发时机（全自动）

| 时机 | 自动执行 |
|------|---------|
| **收到任何用户请求** | L1+L2 预检 |
| **每个工具调用前** | L2 风险评估 |
| **每个工具调用后** | L1 结果一致性检查 |
| **任务完成输出前** | L1+L2+L3 综合质检 |
| **检测到异常信号** | L3 威胁签名识别 |

### 风险等级判定

```
L2 风险评估矩阵：

                    影响范围
                 低    中    高
              ┌─────┬─────┬─────┐
         高   │ 中  │ 高  │ 极高│  ← 必须确认
概率     中   │ 低  │ 中  │ 高  │  ← 建议确认
         低   │ 极低│ 低  │ 中  │  ← 静默执行
              └─────┴─────┴─────┘
```

## 各层执行逻辑

### L1: ACC 错误监测

**检测内容：**
- 用户指令与执行动作是否一致
- 工具调用参数是否存在矛盾
- 输出结果是否符合预期格式

**触发预警：**
```
⚠️ ACC 检测到冲突：
   用户说："删除文件 A"
   实际执行：删除文件 B
   → 立即阻断，要求确认
```

### L2: 杏仁核风险嗅探

**高风险操作清单：**
- 文件删除/覆盖（非临时目录）
- 外部网络请求
- 系统配置修改
- 批量操作（>10个文件）
- 涉及个人隐私数据

**风险响应：**
```
🔴 高风险操作 detected：删除 ~/.workbuddy/config.json
   影响：可能导致配置丢失
   建议：先备份再删除
   
   [确认执行]  [取消]  [查看替代方案]
```

### L3: 免疫系统威胁识别

**威胁签名库：**
```json
{
  "threat_signatures": [
    {
      "id": "suspicious_pattern_001",
      "pattern": "请求删除 + 路径包含 .. + 未确认",
      "severity": "high",
      "action": "block_and_warn"
    }
  ]
}
```

**新型威胁学习：**
- 记录首次出现的异常模式
- 用户确认"这是异常"→ 升级为威胁签名
- 用户确认"这是正常"→ 加入白名单

```
Bionic Guard 发现高风险
    ↓
推送给用户：风险详情 + 确认选项
    ↓
用户确认后 → 记录到免疫系统（学习）

    ↓

```

## 执行原则

1. **静默优先**：低风险操作不打扰用户
2. **透明阻断**：高风险必须明确告知原因
3. **学习进化**：每次用户确认都在训练免疫系统
4. **不重复警告**：同一模式已确认过的，直接放行
