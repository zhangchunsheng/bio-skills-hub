## 🇨🇳 中文版

**名称**：养生时间表管家
**英文副标题**：Wellness Routine Planner

**一句话简介**：把你想养成的健康习惯，变成一套真正执行得到的系统——锚点制排程 + 双层提醒 + 手机版时间表 + 自动提醒。

**详细功能**：
- 🪝 **锚点制**：把习惯挂在既有动作（起身 / 吃饭 / 洗面 / 睡），不靠死钟数，随生活流走
- 🔔 **双层提醒**：定时弹窗 + 对话中主动口头提醒，专治"一埋头就忘"
- 📱 **手机友好**：生成 Markdown + 移动端 HTML，部署到线上 URL，朝早不开电脑也能看
- ⚙️ **自动提醒**：每日 / 每周 / 每月 / 每半年·每年定时自动化；复诊、服药可设"提前 2–3 周"提醒
- 🛡️ **温和优先**：有特殊健康情况默认温和方案，并附健康免责声明

**示例触发语**：
- 帮我做个每日养生安排，我成日唔记得饮水
- 帮手排个温和啲嘅作息（我有甲亢唔可以剧烈运动）
- 将我嘅习惯清单变成会自动弹嘅提醒系统

**标签**：健康 · 养生 · 习惯养成 · 提醒 · 自动化 · 作息管理

**适用人群**：想系统管理健康作息但不愿手动设大量提醒的人；需温和方案者（慢病 / 孕娠 / 术后）；忙碌易忘的上班族；需复诊 / 服药提醒的长辈。

## 🇬🇧 English

**Name**: Wellness Routine Planner

**One-liner**: Turn the healthy habits you want to build into a system that actually sticks — anchor-based scheduling, two-layer reminders, a mobile-friendly routine, and automated alerts.

**Features**:
- 🪝 **Anchor-based**: attach habits to existing actions (wake up, meals, wash, sleep) instead of rigid clocks
- 🔔 **Two-layer reminders**: scheduled pop-ups + proactive chat nudges, so you don't forget when deep in work
- 📱 **Mobile-friendly**: generates Markdown + a mobile HTML view, deployed to a URL you can check on your phone
- ⚙️ **Automated alerts**: daily / weekly / monthly / semi-annual / yearly automations; check-ups & meds can be set with "remind 2–3 weeks ahead"
- 🛡️ **Gentle-by-default**: picks gentle plans for health conditions, with a medical disclaimer

**Example prompts**:
- Help me build a daily wellness routine — I always forget to drink water
- Plan a gentle routine for me (I have hyperthyroidism, no intense workouts)
- Turn my habit list into an automated reminder system

**Tags**: health · wellness · habit-building · reminders · automation · routine

**For**: people who want to manage their health routine without manually setting many reminders; those needing gentle plans (chronic illness / pregnancy / post-op); busy forgetful professionals; seniors needing meds / check-up reminders.
