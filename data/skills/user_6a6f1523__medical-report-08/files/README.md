# 旅游攻略生成器

## 功能介绍
输入目的地和出行需求，生成完整旅游攻略，含每日行程、景点推荐、美食地图、住宿交通建议、费用明细，说走就走不踩坑。

## 使用方法
把你的旅行需求发给AI，例如：
- 「帮我做一个成都3天2晚的旅游攻略，预算2000，主打吃」
- 「厦门5天4晚自由行，两个人，预算5000，喜欢拍照和海边」
- 「北京周末2日游，带老人孩子，不要太赶」

需要提供的信息：
- 目的地
- 出行天数
- 预算范围
- 出行人数和构成（情侣/亲子/独自/朋友）
- 旅行偏好（美食/景点/拍照/休闲/文化）

## 输出内容
- 费用预估明细（人均）
- 每日详细行程安排
- 必去景点推荐（含门票/开放时间/Tips）
- 当地美食推荐（特色菜/餐厅/美食街）
- 住宿建议（不同价位）
- 交通指南
- 实用Tips和行李清单

## 适合人群
旅游爱好者、自由行游客、亲子游家庭、情侣出行、出差顺便玩的人
