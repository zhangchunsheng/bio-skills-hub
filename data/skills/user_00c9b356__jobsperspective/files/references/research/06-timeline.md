## 一、青年时期与苹果早期 (1955-1985)

| 日期 | 事件 | 意义 |
|------|------|------|
| **1955年2月24日** | 出生于旧金山，生父Abdulfattah Jandali，生母Joanne Schieble。出生后被Paul和Clara Jobs收养 | 被收养的经历塑造了他的"被选中感"和归属焦虑 |
| **1960年** | 搬到山景城（后来的硅谷） | 在硅谷成长，接触电子学 |
| **1968年夏天** | 13岁打电话给Bill Hewlett获得HP暑期工作 | 🔴 **思想转折点**：塑造"公司即员工"的认知，学会主动出击 |
| **1969年** | 结识Steve Wozniak | 因电子学、Bob Dylan和恶作剧结缘 |
| **1972年** | 制造并销售"蓝盒子"电话黑客设备 | 🔴 **思想转折点**："小东西可以控制大东西"——Apple的种子 |
| **1973年** | 进入里德学院，秋季退学，留在校园旁听 | 旁听书法课→后来Mac字体设计 |
| **1974年** | 在雅达利工作，前往印度"寻求觉悟" | 🔴 **思想转折点**：禅宗和东方哲学影响极简美学 |
| **1976年4月1日** | Apple Computer Inc.成立 | 与沃兹和Ron Wayne注册 |
| **1977年4月17日** | Apple II在西海岸计算机展引起轰动 | Apple成为个人计算革命象征 |
| **1978年5月17日** | 女儿Lisa出生，Jobs拒绝承认父女关系 | 个人品格争议的开始 |
| **1979年12月** | 在Xerox PARC首次看到GUI | 🔴 **思想转折点**：10分钟内确信"所有计算机将来都会这样工作" |
| **1980年12月12日** | Apple上市，Jobs净资产超2亿美元 | |
| **1981年初** | 接管Macintosh项目，Jef Raskin被迫离开 | 展示了夺取控制权的模式 |
| **1983年1月** | 《时代》杂志抨击Jobs，"计算机"成为年度人物 | 🔴 **思想转折点**：此后一生对记者心存不信任 |
| **1983年4月** | 用"卖糖水还是改变世界"说服Sculley加入 | 后来证明这是他最严重的用人失误 |
| **1984年1月24日** | Macintosh发布——"你好，我是Macintosh" | 产品发布模式的典范 |
| **1985年5月** | 🔴 **重大转折**：董事会站在Sculley一边，剥夺Jobs所有行政职权 | 被驱逐——Apple最著名的"放逐"事件 |
| **1985年9月17日** | 从Apple辞职，创立NeXT | 开始12年"荒野期" |

## 二、NeXT、Pixar与蛰伏期 (1986-1996)

| 日期 | 事件 | 意义 |
|------|------|------|
| **1986年** | 养母Clara去世。找到生母Joanne和姐姐Mona Simpson | 身世探索 |
| **1986年1月30日** | 以1000万美元收购Lucasfilm计算机部门，成立Pixar | 🔴 **关键决策**：进入动画领域 |
| **1988年10月12日** | NeXT Cube发布 | 定位高等教育，获好评但商业失败 |
| **1989年4月30日** | 关闭Pixar所有硬件业务 | 学会战略撤退 |
| **1991年3月** | 裁减近一半Pixar员工，收回员工股份 | 最困难的管理决策 |
| **1991年3月18日** | 与Laurene Powell在优胜美地举行婚礼 | 禅宗导师Kobin Chino主持 |
| **1991年5月** | Pixar与迪士尼签约制作计算机动画长片 | 《玩具总动员》起步 |
| **1993年2月** | NeXT裁员300人，停止硬件业务，更名NeXT Software | 🔴 **思想转折点**：Jobs职业生涯最低谷，学会妥协 |
| **1995年** | 将重心从NeXT转向Pixar | 战略转移 |
| **1995年11月29日** | Pixar上市，《玩具总动员》上映 | Jobs身价15亿，超过Apple第一任期 |
| **1996年12月** | Apple以4亿美元收购NeXT | 🔴 **历史性转折**：Jobs回归Apple的跳板 |

## 三、重建苹果 (1997-2004)

| 日期 | 事件 | 意义 |
|------|------|------|
| **1997年7月** | Gil Amelio被罢免，Jobs成为临时CEO | 距破产仅90天 |
| **1997年秋** | 启动"Think Different"广告 | 🔴 **思想转折点**："营销是关于价值观" |
| **1997年** | 将350个产品砍到4个（2×2矩阵） | 🔴 **关键决策**：聚焦=生存 |
| **1998年5月6日** | iMac发布 | Apple复兴的第一步 |
| **2000年1月5日** | 正式成为CEO，去掉"临时"头衔 | |
| **2001年3月24日** | Mac OS X发布（基于NeXT技术） | NeXT遗产开花结果 |
| **2001年5月19日** | 首批Apple零售店开业 | 进入零售领域 |
| **2001年10月23日** | iPod发布——"1,000 songs in your pocket" | 🔴 **关键决策**：进入消费电子 |
| **2003年4月28日** | iTunes Music Store上线 | 改变音乐产业 |
| **2003年秋** | 确诊胰腺癌，拒绝手术9个月 | 🔴 **致命决策**：RDF的阴暗面 |
| **2004年8月** | 接受手术切除胰腺肿瘤 | |

## 四、大苹果时代 (2005-2011)

| 日期 | 事件 | 意义 |
|------|------|------|
| **2005年6月6日** | 宣布从PowerPC转向Intel处理器 | 重大架构转型 |
| **2005年6月12日** | Stanford毕业演讲——"Stay Hungry. Stay Foolish." | 🔴 **思想浓缩**：三个故事定义人生哲学 |
| **2006年1月24日** | Disney以74亿美元收购Pixar，Jobs加入Disney董事会 | Jobs成为Disney最大个人股东 |
| **2007年1月9日** | 🔴 **iPhone发布**——"An iPod, a phone, and an Internet communicator" | 人类历史上最伟大的产品发布会 |
| **2007年** | 公司从"Apple Computer Inc."更名为"Apple Inc." | 反映业务方向转变 |
| **2008年3月6日** | 宣布App Store开放第三方开发者 | 🔴 **关键决策**：应用经济诞生 |
| **2009年1月** | 宣布病假6个月 | 健康危机公开化 |
| **2009年4月** | 在田纳西州接受肝移植手术 | 距死亡仅数周 |
| **2009年8月3日** | Google CEO Eric Schmidt因Android离开Apple董事会 | 🔴 **思想转折点**：Jobs感到被背叛 |
| **2010年1月27日** | iPad发布——"苹果做过的最大的事" | 🔴 **关键决策**：创造新品类 |
| **2010年6月** | iPhone 4"天线门"——Jobs举行新闻发布会回应 | 罕见的公关危机处理 |
| **2011年1月** | 宣布新的病假，没有设定结束日期 | |
| **2011年3月2日** | 病假中仍登台发布iPad 2 | 最后的产品发布 |
| **2011年6月6日** | 🔴 **最后一次主题演讲**——WWDC发布iCloud | 虚弱但坚持登台 |
| **2011年6月7日** | 出席库比蒂诺市议会会议公布"飞船"总部 | 最后一次公开露面 |
| **2011年8月24日** | 辞去CEO职务："那一天到来了。" | Tim Cook继任 |
| **2011年10月5日** | ⚰️ 在家中去世，家人陪伴 | 享年56岁 |
| **2011年10月24日** | Walter Isaacson授权传记出版 | 40次采访的成果 |
