# 商品图片品牌基因与视觉规范提取

## 适用场景

面向品牌、电商与产品设计团队，用于营销素材、商品视觉、网页、界面、图表或演示设计中的“商品图片品牌基因与视觉规范提取”任务。

这个 Skill 是独立业务工作流，不是原能力的改名副本。它必须围绕当前中国业务场景完成从信息确认、执行到交付检查的闭环。

## 开始前需要的信息

- 设计目标、受众、渠道和尺寸
- 品牌规范、文案、数据和可用素材
- 交付格式、技术约束和版权边界

- 与“商品图片品牌基因与视觉规范提取”直接相关的现状、历史结果和失败案例

信息不足时先列缺口和影响。涉及价格、时间、案例、资质、平台规则、经营结果或外部发布时，不自行补写。

## 执行流程

1. 明确本次“商品图片品牌基因与视觉规范提取”的业务目标、使用对象、成功标准和停止条件
2. 整理与商品图片品牌基因、视觉规范提取直接相关的事实、数据、素材、约束和待确认信息
3. 把任务拆成商品图片品牌基因、视觉规范提取等可检查模块，确定优先级、负责人和依赖
4. 依据原能力边界执行：品牌基因样式提取原子技能。根据商品图片与用户品牌基因参数（主色、字体、平台、地区、语言），提取统一的品牌视觉语言（Brand DNA），输出结构化 brandGeneJson 供下游原子技能消费。品牌基因提取、brand gene extract、brand DNA、品牌视觉定义、品牌调性提取、brand style extraction、visual id
5. 生成设计规范与制作包，同时列出事实依据、风险、缺口和人工确认项
6. 按照目标、事实、可执行性、合规和交付完整性做发布前复核
