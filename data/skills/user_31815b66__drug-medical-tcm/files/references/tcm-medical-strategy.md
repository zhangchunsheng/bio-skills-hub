# 中成药医学策略与证据缺口地图（M2）

> 本文件供本 skill 在「医学策略与病证结合定位(M2)」环节引用。
> 用途：把循证盘点（M3）翻译成可执行的医学策略——定位、缺口、价值主张、生命周期、年度计划。

## 1. 病证结合医学定位（基于循证）

- **定位陈述模板**（病证结合）：
  ```
  针对 [目标病证 + 目标锚点证型]，
  [产品名] 的医学定位是 [功效类别 + 剂型 + 注册分类]，
  核心科学价值在于 [证候改善 + 西医双终点获益]，
  当前最佳证据等级 [L1a/L1b/...]，锚点证型依据 [指南/共识/典籍]。
  ```
- 定位须由 M3 证据全景图反推，**不得凭空定位**；定位与证据等级必须可回溯。

## 2. 证据缺口地图（策略引擎）

按"目标定位 vs 现有证据"逐维找缺口，形成证据生成优先级：

| 缺口维度 | 表现 | 证据生成动作（→M4） |
|---|---|---|
| **锚点证型缺 RCT** | 仅 L3/L4 支撑 | 规划病证结合 RCT（双终点） |
| **缺长期安全性** | 尤注射剂/含毒药材 | IV期/PASS/登记研究 |
| **缺特殊人群** | 老年/糖尿病/肾功/儿童 | 亚组 RWE / 真实世界登记 |
| **缺西医终点** | 只有证候积分 | 补双终点 RWE |
| **缺经济学** | 无成本效果 | HEOR 模型（→M6） |
| **缺路径/指南** | 未进指南路径 | 指南/共识推动（→M7） |

- 每个缺口标：优先级（高/中/低）+ 所需研究类型 + 预计周期 + 资源。
- 缺口地图是年度医学计划与证据生成预算的输入。

## 3. 医学价值主张（三价值）

1. **科学价值**：证候 + 西医双获益（来自 M3 最佳证据）；差异化来自方剂特色/质量壁垒。
2. **患者价值**：依从性（口服 vs 注射）/ 可及性（基药/医保）/ 生活质量（PRO）。
3. **经济价值**：成本效果（总治疗成本下降 / 减少住院）→ 由 M6 HEOR 支撑。

> 价值主张须有证据锚定，不得用"治未病""调理"等作疗效承诺（合规红线，见 `tcm-medical-compliance.md`）。

## 4. 生命周期医学策略（PLC）

| 阶段 | 医学重点 |
|---|---|
| **上市前** | CDP 医学输入、方案审阅、说明书拟定、上市前 RWE、KOL 观念培育（→M9，深度转 drug-medical-prelaunch） |
| **上市期** | 首发锚点证型循证传播、MSL 双轨启动、医学应答库、IV 期/PASS 启动 |
| **成长期** | 扩证型证据、RWE 补充、指南/路径推动、HEOR 完善 |
| **成熟期** | 全证型+基层广阔市场医学教育、长期安全性登记、再评价、路径深化 |
| **衰退期** | 证据归档、安全性持续监测、循证复盘 |

- **经典名方特例**：免 II/III 期 → 上市即循证薄弱，医学部须立即规划上市后循证补充路径（RWE/再评价）。
- **中药注射剂特例**：强监管 + 长期 PV 权重高，安全性研究贯穿全生命周期。

## 5. 年度医学计划框架

- **KOL 覆盖**：Tier1/2/3 双轨（中医师/西医师）覆盖目标与频率。
- **证据生成**：缺口地图驱动的在研/在筹研究清单 + 里程碑。
- **学术影响指标**：指南/共识参与数、路径纳入、学术会议医学内容产出、HCP 触达、医学应答量。
- **资源配置**：人力/预算/外部 CRO/统计/发表支持。
- **协同接口**：给市场（核心信息包）、准入（HEOR 证据）、销售（培训医学内容）、合规（MLR 输入）的接口清单。

## 6. 输出物
- 医学策略书（定位 + 缺口地图 + 价值主张 + PLC + 年度计划）+ 证据生成优先级清单。
- 标注：每条策略回溯到 M3 证据格；缺口标优先级与计划。
