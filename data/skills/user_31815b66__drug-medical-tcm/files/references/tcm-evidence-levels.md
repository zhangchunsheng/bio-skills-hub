# 中成药循证证据分级（自定义 · 现代循证 + 传统经验并用）

> 本文件是 `references/foundation.md` 的参考之一，供本 skill 在「循证分级(M3)」「病证结合定位(M2)」「核心医学信息(M5/M10)」环节引用。
> 用途：统一中成药证据的评级口径——**中成药不能只看 RCT，须"病证结合"：现代循证 + 传统经验 + 典籍溯源三轨融合评级。** 医学部既"读证据"更"生证据"，故本文件兼含证据生成类型。

## 1. 证据等级总表（病证结合）

| 等级 | 定义 | 典型证据 | 在医学策略中的权重 |
|---|---|---|---|
| **L1a** | 高质量 RCT | 随机双盲多中心、符合 CONSORT、病证结合双终点（证候积分 + 西医指标）、样本量充足 | 锚点证型首选证据；可独立支撑定位 |
| **L1b** | 较可靠研究 | 单中心 RCT / 高质量前瞻性 RWE（注册登记研究）/ 高质量 meta 分析 | 可支撑次强证型 |
| **L2** | 观察性研究 | 队列研究 / 病例对照 / 回顾性真实世界 / 非随机对照 | 支持性证据，单用不立锚点；缺双终点降此级 |
| **L3** | 经验与共识 | 名老中医经验（系统整理）/ 专家共识 / 中西医结合诊疗指南 | 定位与话术底稿，非疗效确证 |
| **L4** | 典籍与病例 | 经典名方溯源（伤寒论 / 温病条辨等，标朝代·方剂出处）/ 病例系列 / 个案 | 立题依据，仅作定位背书 |
| **L5** | 未证实 | 观点 / 厂商单一材料 / 无对照经验 | 标 💭，不得作定论 |

## 2. 病证结合证据的特殊要求

- **双终点强制**：中成药证据须同时报告「中医证候积分（TCM syndrome score）」与「西医生化 / 临床终点」，缺一项视为证据不完整（L2 处理）。
- **安慰剂说明**：中成药 RCT 常用"模拟剂"而非空白对照，须注明模拟剂设计，否则效应量存疑。
- **不下西医病名结论**：证据表述须对应"证型"（如气滞血瘀证），不得仅以西医终点下"治疗 XX 病"结论用于推广。
- **证候量表可溯源**：采用的证候积分量表须注明出处与信效度（如《中药新药临床研究指导原则》相关量表，见 `tcm-syndrome-scales.md`）。
- **长期安全性权重**：中成药（尤其注射剂 / 含毒药材）的长期安全性证据在等级评估中权重更高，缺长期安全性须标缺口。

## 3. 证据生成类型（医学部"生证据"·M4 用）

| 类型 | 适用场景 | 设计要点 | 证据产出等级 |
|---|---|---|---|
| **病证结合 RCT（双终点）** | 锚点证型确证、核心定位 | 主要终点=证候积分+西医指标；模拟剂对照；CONSORT；样本量基于证候效应量 | L1a |
| **前瞻性 RWE（登记研究）** | 真实世界疗效/安全性、长期随访 | 前瞻登记、预设终点、偏倚控制、数据源 HIS/登记库 | L1b |
| **回顾性真实世界** | 已上市品种快速证据、卫生决策 | 回顾队列/病例对照、明确入排、敏感性分析 | L2 |
| **IIT / IIS（研究者发起）** | 机制探索、亚组、真实场景 | 医学监查、数据质量、预注册、发表策略 | L1b–L2（依设计） |
| **IV 期 / PASS** | 上市后安全性（尤其注射剂/含毒药材） | 安全性终点预设、信号检测、PSUR | L2（安全性） |
| **名老中医经验整理** | 立题、定位底稿、共识基础 | 系统整理（德尔菲/共识法）、可溯源 | L3（非疗效确证） |
| **典籍研究** | 经典名方立题、现代衔接 | 出处朝代、方剂溯源、现代药理印证 | L4（立题依据） |
| **Meta 分析** | 证据合成、指南推动 | 纳入标准、I²、偏倚评估、亚组 | L1b（依纳入质量） |

## 4. 输出标注规范

每条证据在报告 / 全景图中须标：
`研究/典籍名 · 设计 · N= · 关键终点(证候+西医) · 年份 · 等级(L1a–L5) · 来源`
示例：`XX 颗粒治疗胸痹 RCT · 随机双盲多中心 · N=480 · 心绞痛发作减少+证候积分改善 · 2023 · L1a · 中华心血管病杂志`

查不到的格子标 💭 待核实，不得编造有效率或样本量。

## 5. 与化药证据体系的差异（速记·仅对比校准）

- 化药：单成分 → 靶点 → RCT 终点 → 指南推荐，等级链清晰，研究设计标准化。
- 中成药：复方多靶点 → 证候 + 西医双终点 → RCT/RWE + 典籍/经验并用，须自定义 L1a–L5 且强制双终点；安慰剂须用模拟剂。
- **医学含义**：中成药"锚点证型"的确定比化药"锚点人群"更依赖证据完整度（双终点+典籍+共识），缺口更大，证据生成优先级须更显式标缺口；经典名方因免 II/III 期临床，上市后循证补充是医学部核心任务。
