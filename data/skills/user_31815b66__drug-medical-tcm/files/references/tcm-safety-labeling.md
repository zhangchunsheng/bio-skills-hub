# 安全性与说明书管理（M8 · 医学部 PV 重心）

> 本文件供本 skill 在「安全性与说明书管理(M8)」环节引用。
> 用途：中成药医学部对安全性的主责——药物警戒、说明书安全完善、中西药相互作用、风险沟通。近年监管重点推动中成药说明书【不良反应/禁忌/注意事项】从"尚不明确"向具体化完善。

## 1. 药物警戒（PV）基础

- **不良反应收集**：自发报告（医院/企业/监管）、文献、RWE/PASS（M4）、登记研究。
- **信号检测**： disproportionality（如 PRR/ROR）、贝叶斯方法；信号须可追溯、可复核。
- **定期安全性报告**：PSUR / 定期获益-风险评估报告(PBRER)，按法规周期提交。
- **风险最小化**：沟通计划、用药指南、黑框警告（如适用）。
- **数据校准**：PV 数据须以不良反应监测中心/说明书原文为准，标 🔍；企业自发报告须注明来源与局限。

## 2. 说明书安全完善（监管重点）

- **现状**：大量中成药说明书【不良反应】【禁忌】【注意事项】原标"尚不明确"；近年监管推动具体化。
- **完善路径**：
  1. 汇总上市后 RWE/PASS/文献的安全性数据（M4/M8-1）。
  2. 与最新版说明书比对，列出"可具体化"的条目（AE 类型/发生特征/高危人群）。
  3. 含毒药材（附子/马钱子/雄黄/朱砂等）须显式提示禁忌与监测，不得淡化。
  4. 通过变更申请修订说明书，标注版本日期。
- **医学纪律**：推广物料/医学沟通引用安全性，须与**最新版说明书**一致；说明书仍"尚不明确"者，不得自行补充安全性结论。

## 3. 中西药相互作用管理

- **已知相互作用**：如含麻黄（血压升高/影响降压药）、含甘草（低钾/影响利尿剂）、含鞣质（影响铁/酶）、含金属离子（影响抗生素吸收）等——须查说明书与文献，标证据等级。
- **联合用药安全前置**：任何中西联合方案（M7-§3）须先完成相互作用评估，已知风险明示，禁止隐瞒。
- **HCP 沟通**：向医师传递"可联用/须监测/禁忌联用"的分级建议，锚定证据。

## 4. 风险沟通策略（non-promotional）

- **对象分级**：监管（定期报告）/ 医院药学（用药安全）/ HCP（处方警示）/ 患者（用药教育）。
- **内容边界**：风险沟通为科学交流，非推广；须平衡"不淡化风险"与"不制造不必要恐慌"。
- **含毒药材**：明确禁忌人群（孕妇/肝肾功能不全/长期用药）、监测指标、疗程限制。
- **合规衔接**：风险沟通内容标注"供 MLR/PV 审校参考"，不替代合规与监管申报。

## 5. 安全性在医学策略中的位置

- **证据缺口联动**：长期安全性缺失 → 列入 M2 证据缺口地图 → M4 生成 IV期/PASS。
- **注射剂特严**：中药注射剂不良反应风险权重高，PV 与说明书监测贯穿全生命周期，急性过敏/热原须重点。
- **定位背书**：安全性数据也是"质量与可及"价值主张的一部分（尤其基药/基层场景）。

## 6. 输出物
- 药物警戒计划（信号/报告/风险最小化）+ 说明书安全完善建议（逐条）+ 中西相互作用分级表 + 风险沟通方案。
- 标注：数据来源、版本日期、💭 待核实项、合规边界。
