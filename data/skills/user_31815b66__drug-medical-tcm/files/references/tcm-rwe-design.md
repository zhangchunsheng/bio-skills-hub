# 中成药 RWE 方案模板（真实世界研究设计 · 医学部证据生成）

> 本文件供本 skill 在「证据生成(M4)」「HEOR(M6)」「路径推动(M7)」环节引用。
> 用途：把"我要补一个中成药的真实世界证据"变成一份可评审、可注册、可发表的研究方案骨架。病证结合双终点是前提。

## 1. RWE 研究类型选择

| 类型 | 何时用 | 设计 | 证据等级 |
|---|---|---|---|
| **前瞻性登记研究** | 长期疗效/安全性、锚点证型确证 | 预设终点、连续入组、定期随访 | L1b |
| **回顾性队列** | 已上市快速证据、医保/路径决策 | 历史数据提取、明确入排 | L2 |
| **病例对照** | 罕见安全性信号、特殊人群 | 病例/对照匹配 | L2 |
| **横断面** | 处方行为/辨证准确率/证候分布快照 | 单时点调查 | L2（描述性） |
| **自身前后对照** | 真实场景疗效感知 | 治疗前后配对 | L2（弱） |

## 2. 方案核心模块（必填）

### 2.1 研究目的与假设
- 主要目的（一句话）+ 科学假设（H0/H1）。
- 对应证据缺口（来自 M2 证据缺口地图，注明补哪类证型/哪类终点）。

### 2.2 研究设计
- 设计类型（上表选择）+ 多中心/单中心 + 前瞻性/回顾性。
- 对照设置：无对照 / 历史对照 / 平行对照（同类中成药或西药）；间接对比须标局限。

### 2.3 目标人群（病证结合）
- **西医诊断** + **中医证型**（必须，如"冠心病稳定型心绞痛，气滞血瘀证"）。
- 入排标准：含辨证纳入标准（证候积分阈值）、合并证型处理、特殊人群（老年/糖尿病/肾功）。
- 样本量：基于主要终点（证候积分效应量）估算 + 脱落率；注明把握度与 α。

### 2.4 干预与暴露
- 中成药名称/剂型/剂量/疗程（与说明书一致）；联合用药记录（中西联用须记全，见 M7）。
- 真实世界"真实"程度标注：是否限定用法、是否允许合并治疗。

### 2.5 终点（病证结合双终点·强制）
- **主要终点**：证候积分改善（量表见 `tcm-syndrome-scales.md`）+ 至少 1 个西医临床/生化终点。
- **次要终点**：生活质量(PRO，如 SF-36 / 中医生存质量量表)、安全性、卫生经济学指标（M6）。
- **安全性终点**：不良反应（按 CTCAE 或 说明书术语）、严重不良事件、含毒药材监测。

### 2.6 数据来源与采集
- 数据源：医院 HIS / 电子病历 / 专科登记库 / 医保数据库 / 患者自报(PRO app)。
- 变量字典：人口学、诊断、证型、用药、终点、合并症、费用。
- 数据质量：溯源、稽查、缺失值处理。

### 2.7 偏倚控制
- 选择偏倚：入排透明、多中心。
- 信息偏倚：终点盲法评估（证候积分尽量盲法/量表标准化）。
- 混杂控制：多元回归 / 倾向评分匹配(PSM) / 工具变量；标注局限。

### 2.8 统计分析计划（SAP）
- 主要/次要终点分析方法、亚组（证型/年龄/合并症）、敏感性分析、缺失处理、多重性。
- 效应量 + 95%CI + P 值；不得只报 P。

### 2.9 伦理与注册
- 伦理委员会审批 + 知情同意（回顾性可豁免情形须注明）。
- 研究注册：ClinicalTrials.gov / 中国临床试验注册中心 / 中药临床试验登记；预注册优先。

### 2.10 发表与数据透明度
- 发表计划、 authorship、数据可获取性、负面结果亦发表。

## 3. 病证结合 RWE 特别提示

- **证型必须可操作**：证候判定用标准化量表（§2.5 + `tcm-syndrome-scales.md`），不可靠辨证=证据失效。
- **双终点缺一不可**：缺证候或西医任一 → 证据等级降 L2，并标缺口。
- **模拟剂/对照透明**：如用历史对照，须标选择偏倚风险。
- **长期安全性权重高**：注射剂/含毒药材品种，安全性终点须充分暴露。
- **与医保/路径衔接**：RWE 若服务医保谈判或路径推动，终点须含卫生经济学指标（见 `tcm-heor.md`）。

## 4. 输出物（方案交付清单）
- 研究方案书（含 SAP）+ 病例报告表(CRF)草样 + 变量字典 + 伦理材料 + 注册证明 + 发表计划。
- 每份标注"供医学/方法学审校"，不替代统计与法规专业审查。
