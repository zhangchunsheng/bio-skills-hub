# 内置基础模块（foundation.md · 本 skill 自带）

> 本文件合并自「中成药医学分析体系」的共享临床与校准知识，随本 skill 一同发布。
> 目的：让本 skill **完全自包含、可独立运行**，无需安装任何其他 skill 或外部依赖。

## §1 中成药临床档案提取框架（医学部视角）

给定中成药 / 治疗领域，提取以下基础临床档案（各角色 skill 按需取用，深度由各角色展开）：

1. **基本信息与定位**：通用名 / 商品名 / 企业 / 剂型 / 规格 / 批准文号 / 中成药分类（1–4 类 / 经典名方 3 类 / 同名同方 4 类）+ 一句话定位（中医科学价值 ∩ 临床定位）。
2. **方解与作用特点**：君药 / 臣药 / 佐药 / 使药；组方来源（经典名方 / 经验方 / 现代研发 / 医院制剂）；功效类别（扶正 / 祛邪 / 调和等）。
3. **功能主治与循证三件套**：按 `references/tcm-evidence-levels.md` 强制罗列——
   - ① **功能主治（说明书原文·中医术语）**：证型 + 病证（如"活血化瘀，用于胸痹心痛，气滞血瘀证"），**必须原文**，不得西医化改写。
   - ② **现代研究证据**：关键 RCT / RWE / 药理研究（研究名·设计·样本量·关键终点·年份·证据等级 L1a–L5），**双终点（证候+西医）缺一不可**。
   - ③ **指南 / 共识 / 典籍依据**：指南名·机构·年份·推荐级别 / 共识名·机构·年份·核心建议 / 典籍出处·朝代·方剂来源。
   - 任一缺失标 💭 待核实，禁止用单源 / 厂商材料替代独立循证。
4. **用法用量与特殊人群**：剂量、疗程、佐使配伍禁忌、孕妇 / 儿童 / 年老体弱注意。
5. **安全性（医学部重点）**：不良反应（说明书原文·近年细化要求）、禁忌、相互作用、中西药联用注意、含毒药材提示、PV 基础。
6. **注册审批与在研（基础）**：中药注册分类（1–4 类 / 经典名方 3 类）、专利、在研（深度由注册角色 skill 展开）。

## §2 数据校准规则（强制 · 所有输出必须遵守）

本体系输出的每条关键数据都必须可溯源、可校验。严格执行以下 5 条：

- **来源分级标注**：每条关键数据标可信度——🔍 已查证（药典 / 说明书·NMPA 备案 / 国家医保局目录 / 不良反应监测中心 / 中医药学会官网 / 核心文献）、💭 推测或不确定（模型推断或单一非权威来源）。禁止把 💭 当 🔍 呈现。
- **关键事实交叉校验**：批准文号、医保类别、说明书安全性、指南推荐级别等，须至少 2 个独立来源一致方可写为确定；不一致或仅单源时标「待核实」。
- **时效校准**：循证 / 医保 / 路径 / 审批 / 在研状态必须 WebSearch 取最新，并标注「截至 YYYY-MM」，不得沿用旧记忆（中成药指南与医保目录变动频繁）。
- **口径校准**：流行病学 / 患者数注明统计口径（中国 / 区域、确诊 / 估测、证型分布）；经济学模型注明假设与付费方视角；估算项显式标「估算」。
- **禁止编造**：任何无法溯源的数据标「待核实」，不得生成看似合理但无来源的数字（尤其是证候有效率、市场份额、处方量、KOL 立场）。

## §3 专利 FTO 基础框架（中成药侧重）

- **专利类型核查**：处方专利 / 工艺专利 / 剂型专利 / 用途专利的到期日与地域覆盖。
- **经典名方不授予专利**：古代经典名方（3 类）处方已公开，靠商业秘密与质量工艺保护，无化合物专利悬崖。
- **独家品种保护**：独家处方中成药常靠处方保密 + 工艺专利 + 质量标准构建壁垒，非传统专利悬崖逻辑。
- **FTO 分析要点**：是否落入他人有效专利权利要求（尤其改良型新药的工艺 / 剂型专利）。
- **数据校准**：专利号、到期日须以专利数据库（CNIPA / 智慧芽等）为准，标 🔍；不得凭记忆给专利号。

## §4 完整性规则（防偷懒 · 强制）

- 临床档案各维度查不到内容时保留空字段并标「待核实（💭）」，禁止删除维度或以「无 / 暂略」跳过。
- 禁止编造批准文号、临床数据、价格、获批状态填充空字段。
- 不存在 ≠ 可删：确无公开信息时写明「未检索到公开 {X} 信息（💭）」，而非不输出该维度。
- 结构顺序不可因内容多寡重排或省略。
- **中成药特别项**：功能主治必须保留中医术语原文，禁止用西医病名替代或"翻译"；证候 / 病证维度不得省略。

## §5 医学部边界规则（科学交流 vs 推广 · 强制）

- **non-promotional 原则**：本 skill 产出均为医学科学内容（科学交流 / 医学信息），**不直接产出 promotional 推广物料**。任何推广转化（DA / 推广话术 / 会议推广内容）须转 `drug-market-tcm` 并过 MLR。
- **科学交流边界**：MSL 拜访、医学教育、HCP 医学应答、学术会议医学内容均为科学交流，可讨论 on-label 与（限科学场景的）off-label，但不得含促销意图、不得承诺商业利益。
- **off-label 规则**：超功能主治 / 超西医诊断的讨论，仅限 MSL 科学场景，且须标注"超说明书·仅供科学讨论"；严禁进入推广渠道。
- **典籍 / 经验边界**：典籍与名老中医经验仅作立题与定位背书，不作疗效确证（见 `tcm-evidence-levels.md`）。
- **安全性一致性**：医学沟通的安全性信息须与最新版说明书一致；不得自行补充或淡化。
- **合规衔接**：医学内容须标注"供 MLR 审校参考"，不替代合规 / 法务审查。
