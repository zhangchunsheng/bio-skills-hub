# 证候量表与病证结合定位工具（医学部核心方法）

> 本文件供本 skill 在「病证结合定位(M2)」「循证分级(M3)」「RWE 终点(M4)」环节引用。
> 用途：把"证型"从定性描述变成可测量、可比较、可入研究的科学变量——这是中成药医学证据成立的命脉。

## 1. 为什么证候必须"可测量"

- 中成药证据**强制双终点**：证候积分（中医） + 西医指标。证候若不可量化，双终点失效，证据降 L2。
- 证候量表须**有出处、有信效度**，否则研究不可被指南/监管接受。
- 主流量表来源：《中药新药临床研究指导原则（试行）》、中华中医药学会各专科量表、SF-36 等普适量表的中医生存质量衍生版。

## 2. 常用证候积分量表速查（示例·非穷举）

| 证型/领域 | 代表性量表 | 适用病种举例 | 备注 |
|---|---|---|---|
| **血瘀证** | 血瘀证证候积分表（舌质紫暗/脉涩/固定刺痛等条目） | 冠心病/脑梗死/糖尿病血管并发症 | 常与西医终点(血流变/影像学)配对 |
| **气虚证** | 气虚证量表（神疲/乏力/气短/自汗等） | 慢性心衰/慢阻肺/肿瘤辅助 | 注意与"虚劳"鉴别 |
| **阴虚证** | 阴虚证量表（五心烦热/口干/盗汗等） | 糖尿病/更年期/干燥综合征 | 与阳虚对举 |
| **阳虚证** | 阳虚证量表（畏寒/肢冷/倦怠等） | 慢性肾病/甲减/心衰 | 与阴虚对举 |
| **痰湿证** | 痰湿证量表（体胖/苔腻/胸闷等） | 代谢综合征/脂代谢紊乱 | 与血瘀常共病 |
| **肝郁证** | 肝郁量表（情志/胁胀/善太息等） | 抑郁/功能性胃肠/月经不调 | 含情绪条目 |
| **脾胃证** | 脾胃气虚/湿热量表 | 消化系统疾病 | 消化系统专病 |
| **证候综合(生存质量)** | 中医生存质量量表 / 脏腑辨证量表 | 多病种 | 可作次要 PRO 终点 |

> ⚠️ 上表为**方法学示例**，具体量表须以最新版指导原则与专科共识为准，引用时标全称+机构+年份，不得凭记忆给量表名。

## 3. 量表选择四问

1. **病种匹配**：该量表是否在本治疗领域被验证过？（查文献/指导原则）
2. **信效度**：是否有 Cronbach α / 效度报告？无信效度量表不得作主终点。
3. **可操作性**：条目是否临床可采集（舌脉能否标准化录入）？是否盲法友好？
4. **双终点配对**：证候量表能否与预设西医终点形成"病证结合"主终点？

## 4. 病证结合定位的医学判定流程（M2/M3 用）

```
① 取说明书功能主治原文（证型+病证）
   ↓
② 列出所有适用证型（一个品种常多证型）
   ↓
③ 对每个证型，检索并填入"病证结合证据全景图"：
   研究(名/设计/N) / 等级(L1a-L5) / 证候积分改善 / 西医终点 / 指南推荐 / 共识地位
   ↓
④ 判定"锚点证型"：六维最满（尤其 L1a + 双终点 + 指南）者
   ↓
⑤ 缺口标注：哪些证型只有 L3/L4（典籍/经验）→ 列为证据生成优先（M4）
   ↓
⑥ 输出：病证结合医学定位陈述（锚点证型 + 证据等级 + 缺口与生成计划）
```

## 5. 锚点证型判定规则

- **首选**：有 L1a RCT + 双终点 + 指南推荐（≥1 权威指南）的证型。
- **次选**：L1b（单中心 RCT / 高质量 RWE）+ 双终点，指南弱推荐。
- **谨慎**：仅 L3/L4（共识/典籍/经验）支撑的证型 → 仅作定位背书，不得独立支撑推广定位；须规划上市后循证补充。
- **禁止**：无任何循证（仅厂商材料 L5）→ 不得定为锚点，标 💭 待核实。

## 6. 多证型品种的处理

- 多证型中成药：每个证型独立走 §4 流程，形成"首批锚点 / 二批证据次强 / 三批待证据"优先级矩阵。
- 避免"一个传播语打所有证型"：医学定位须分证型表述，差异来自证据等级与终点不同。
- 经典名方：免临床→循证常薄弱，上市时多证型证据多为 L3/L4，医学部须立即规划 RWE/再评价（M4）。

## 7. 输出物
- 病证结合证据全景图（每证型一格）+ 锚点证型判定 + 证据缺口与生成优先级清单。
- 标注：量表出处、信效度、双终点完整性；查不到标 💭。
