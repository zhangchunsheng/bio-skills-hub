# 中西医结合路径与指南推动（M7）

> 本文件供本 skill 在「中西医结合路径与指南推动(M7)」环节引用。
> 用途：把中成药的病证结合证据，转化为可进入的指南、共识、临床路径与中西医结合诊疗方案——这是中成药医学部影响可及与支付的主战场。

## 1. 中医优势病种识别

- **定义**：在某一疾病/证型上，中成药（病证结合）相较西医单用有循证或典籍支撑的优势定位。
- 识别依据：M3 证据全景图（锚点证型的 L1a/L1b 证据）+ 典籍出处 + 专家共识。
- 输出：优势病种 / 优势证型清单（注明证据等级与缺口）。
- 常见优势方向（示例）：慢性病管理（稳定期调理）、西医治疗不耐受/禁忌人群、联合减毒增效、改善证候相关生活质量。

> ⚠️ 优势病种为方法学示例，具体须以最新指南/循证为准；不得宣称"优于西医"无 head-to-head 证据。

## 2. 指南 / 共识推动

### 2.1 参与路径
- **发起/参与撰写**：以医学部证据（M3）与 RWE（M4）为基础，联合学会/专委会发起或参与专家共识、中西医结合指南。
- **证据包提交**：向指南制定组提交病证结合证据全景图 + 经济学证据（M6）+ 安全性数据（M8）。
- **推荐级别争取**：目标——锚点证型获"推荐/强推荐"，次强证型获"可考虑"。

### 2.2 指南/共识撰写要点
- 推荐须有证据等级标注（L1a–L5）+ 推荐级别（如 GRADE / 专家共识级）。
- 中成药推荐须写明"功能主治对应证型"，不得脱离说明书。
- 典籍/经验仅作背景，不作推荐唯一依据。
- 中西联合用药须有相互作用安全性评估（见 §4 + M8）。

### 2.3 数量与质量底线（对齐上市后医学铁律）
- 目标治疗领域须系统检索指南/共识 ≥5 篇；不足须标"该领域仅检索到 N 篇（💭 可能遗漏）"。
- 每篇标：全称 + 机构 + 年份 + 推荐级别 + 对本品的地位。

## 3. 中西联合用药医学依据

- **机制依据**：中西医结合路径的核心——中成药在某环节"增效/减毒/改善证候"。
- **循证依据**：中西联用的 RCT/RWE（双终点）+ 安全性（相互作用）。
- **安全性前置**：联合前须查中西药相互作用（M8-F3），已知风险须在方案中明示；禁止隐瞒相互作用。
- **联合方案证据包**：机制 + 循证 + 安全性 + 适用人群（病证结合），供路径与推广(转市场)使用。
- **边界**：联合推荐须锚定说明书功能主治与西医诊断，不得超功能主治做西医化关联。

## 4. 诊疗路径与准入推动

- **临床路径**：推动中成药进入病种临床路径（中西医结合版），明确"在路径哪一步、对哪类证型使用"。
- **路径证据需求**：为市场部"支付场景地图"提供"进路径/进指南"的医学证据（协同接口）。
- **医保/基药衔接**：路径纳入是医保谈判与基药遴选的有利证据（M6）；医学部提供路径与循证支撑。
- **可及影响**：路径/指南纳入直接提升合理处方率与支付可及（与市场支付场景地图联动）。

## 5. 输出物
- 优势病种/证型清单 + 指南共识推动计划 + 中西联合证据包 + 路径纳入证据包。
- 标注：证据等级、推荐级别、相互作用安全性、待核实项（💭）。
