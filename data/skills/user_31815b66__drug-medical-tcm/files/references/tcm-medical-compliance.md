# 中成药医学部合规边界（科学交流 vs 推广 · 最高门槛）

> 本文件供本 skill 在「医学信息与教育(M5)」「核心医学信息(M10)」「边界(§8)」环节引用。
> 中成药医学合规门槛**高于化药**：功能主治是中医术语，任何"西医化表述"都要有可追溯依据；且医学部内容须严格 non-promotional。
> 本文件所有内容须标注"供 MLR/合规审校参考"，不替代合规 / 法务审查。

## 1. 科学交流 vs 推广（铁律）

| 维度 | 科学交流（医学部·non-promotional） | 推广（市场部·promotional） |
|---|---|---|
| 目的 | 传递科学信息、回应医学问询 | 影响处方行为 |
| 内容 | on-label 证据 / 限场景 off-label 科学讨论 | 双轨推广信息（过 MLR） |
| 边界 | 无促销意图、无商业承诺 | 须标"待 MLR 审核" |
| 责任 | 医学部 | 市场部 + 合规 |

- 本 skill 产出**全部为科学交流内容**；任何 promotional 转化须转 `drug-market-tcm` 并过 MLR。

## 2. 五条不可逾越的医学红线

| 红线 | 禁止行为 | 合规做法 |
|---|---|---|
| **① 超功能主治做西医关联** | 把功能主治"证型"自行翻译成"消炎/抗菌/降压/降糖"等西医功效用于医学传播 | 西医话术**严格锚定说明书功能主治原文**（证型+病证），延伸须有 RWE/指南依据 |
| **② "治未病"作治疗承诺** | 将调理/预防宣传成"治疗 XX 病""治愈" | 治未病/调理仅作健康理念，不得疗效承诺 |
| **③ 超出说明书安全性信息** | 宣称"无副作用""绝对安全"，或隐瞒禁忌/不良反应 | 须同步呈现说明书安全性（含毒药材显式提示） |
| **④ 典籍/经验当疗效确证** | 单引《伤寒论》或名老中医经验声称"疗效确切" | 典籍/经验仅作立题与定位背书，疗效须 L1–L2 或共识支撑 |
| **⑤ 医学内容变推广** | 在 MSL/医学教育中加入促销话术、商业承诺、超功能主治推荐 | 科学交流保持 non-promotional；推广转化转市场部过 MLR |

## 3. "西医化表述"校准流程（强制）

> 西医师科学交流最容易踩线。任何把中医功能主治转述为西医语言的内容，走以下流程：

```
① 取说明书功能主治原文（证型 + 病证）
   ↓
② 判断：转述是否等同原文语义？
   ├─ 是（如"活血化瘀"→"改善微循环"，有药理研究支撑）→ 可转述，标注依据
   └─ 否（如凭空加"抗菌"）→ 禁止
   ↓
③ 转述须有 L1–L2 药理 / 临床证据 or 专家共识支撑
   ↓
④ 标注"供 MLR 审校参考" + 证据出处
```

- 没有对应证据的西医化表述 → **一律不输出**。
- "限西医诊断 / 限功能主治"品种 → 西医场景必须显式对应诊断与功能主治。

## 4. off-label 医学沟通规则

- 超功能主治 / 超西医诊断的讨论，**仅限 MSL 科学场景**（学术拜访、医学讨论），且须标注"超说明书·仅供科学讨论"。
- 严禁进入推广渠道 / 会议推广 / DA。
- 中西联合用药的 off-label 组合须先完成相互作用安全性评估（见 `tcm-safety-labeling.md` §3）。

## 5. 典籍与经验的定位边界

- 典籍 / 名老中医经验 **不作疗效确证**，作「立题与定位依据」和「专家共识底稿」。
- 医学教育可讲方解与典籍背景，但疗效主张须 L1–L2 或共识支撑。
- 经典名方"免临床"≠"疗效确证"，循证须补（M4）。

## 6. 安全性与 PV 合规

- 安全性信息须与最新版说明书一致；不得自行补充或淡化（含毒药材显式提示）。
- PV 数据使用须符合数据隐私与不良反应报告法规。
- 风险沟通为科学交流，非推广，平衡风险透明与避免过度恐慌。

## 7. 输出纪律

- 本 skill 产出的任何医学内容、核心信息、MSL 要点，**必须**标注「non-promotional · 供 MLR 审校参考」，不替代合规审查。
