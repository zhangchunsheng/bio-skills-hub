# 药物经济学与价值证据（M6 · HEOR）

> 本文件供本 skill 在「药物经济学与价值证据(M6)」环节引用。
> 用途：为医保谈判、基药遴选、路径准入提供卫生经济学证据——中成药价值不只在疗效，还在"证候改善带来的生活质量+总成本下降"。

## 1. HEOR 证据类型

| 类型 | 缩写 | 用途 | 中成药注意点 |
|---|---|---|---|
| **成本效果分析** | CEA | 单位健康产出成本 | 健康产出须含证候改善（PRO） |
| **成本效用分析** | CUA | QALY 增量成本(ICER) | 用中医生存质量量表/ SF-36 算 QALY |
| **预算影响分析** | BIA | 付费方年度预算 | 基药/广阔市场放量下的预算 |
| **真实世界成本效果** | RW-CEA | 医保/路径决策 | 结合 M4 RWE 的真实成本 |

## 2. 模型设计要点

- **视角**：付费方（医保）/ 卫生体系 / 社会，须明示。
- **人群**：病证结合（西医诊断+中医证型），与目标定位一致。
- **循环/周期**：Markov 状态（如稳定期/急性加重/并发症），周期与时限标注。
- **参数来源**：疗效来自 M3 最佳证据（双终点）；成本来自医保支付价/公示价；效用来自量表。
- **假设透明**：折扣率、转换比、缺失处理须明示，标 💭 若不确定。
- **敏感性分析**：单因素 + 概率（PSA），展示不确定性。

## 3. 中成药特有挑战

- **证候效用量化**：证候改善如何折算 QALY——须用验证过的量表（见 `tcm-syndrome-scales.md`），否则效用被质疑。
- **对照选择**：与西医标准治疗 / 同类中成药 / 最佳支持治疗对比；间接对比标局限。
- **长期获益**：中成药常改善生活质量与减少急性事件，模型须捕获长期价值。
- **真实世界成本**：基药/基层可及降低总治疗成本，RWE 证据尤重要。

## 4. 医保谈判证据包

- **结构**：临床价值（M3 证据）+ 经济价值（ICER/BIA）+ 患者价值（可及/依从/生活质量）+ 预算影响。
- **定位**：医学部提供证据包，定价与谈判执行归准入（接口）；医学不决谈判底线。
- **数据校准**：ICER/成本须可复核，模型假设与付费方视角标注；查不到标 💭。

## 5. 基药遴选证据

- 基药遴选重"防治必需、安全有效、价格合理、使用方便、中西药并重"。
- 中成药优势：基药占比高、基层必配、可及性强；医学部须提供循证（M3）+ 卫生技术评估(HTA)证据 + 基层适用性证据。
- 民族药（2023 医保约 93 个 🔍）同样适用本框架。

## 6. 输出物
- HEOR 模型报告骨架（视角/人群/循环/参数/假设/敏感性）+ 医保谈判证据包 + 基药遴选证据包。
- 标注：模型假设、数据源、付费方视角、💭 待核实、不替代专业药经/准入决策。
