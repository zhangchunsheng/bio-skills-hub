## 适用边界（强制 · 纯中成药医学部）

> **本 skill 仅服务于「纯中成药（含民族药）医学部」**，分析对象严格限定为：
> - 中成药 / 中药品种（含古代经典名方、同名同方、独家品种、中成药注射剂等）
> - 民族药（藏药、蒙药、维药等；2023 版医保目录含民族药约 93 个 🔍）
> - 中成药治疗领域 / 病证结合医学定位 / 中成药循证与证据生成
>
> **明确排除**（不由本 skill 分析，如涉及请转对应 skill）：
> - ❌ 化学药 / 生物制品的医学分析 → 用 `drug-medical-postlaunch` / `drug-medical-prelaunch`
> - ❌ 纯市场推广策略与执行 → 用 `drug-market-tcm`
> - ❌ 纯销售执行 / 纯准入谈判 / 纯注册申报 → 分别用 `drug-sales` / `drug-access` / `drug-reg`
> - ❌ 纯合规审查 / 广告法执行 → 用 `drug-compliance`
>
> 文中出现的「化药」字样，**仅作对比校准语境**（如证据体系差异、研究设计差异、HEOR 口径差异），并非分析对象。

## 质量与输出规范（强制 · 医药行业严肃性要求）

本 skill 所有对外分析与交付**必须**遵守以下规范，否则视为不合格输出。

### 一、固定输出格式
每次生成分析报告 / 清单 / 建议书，严格按以下结构产出（缺项用「—」或「不适用」占位，不得省略章节）：
1. **元数据头**：分析对象（中成药 / 中药品种 / 治疗领域）、功能主治（证型+病证原文）、分析视角、数据截止日期、证据等级总览
2. **执行摘要**：3–5 条核心结论（每条标注 🔍 / 💭）
3. **主体**：按本 skill 工作流分节展开
4. **关键结论与行动建议**：可执行的 next-step（尤其证据生成计划、路径推动、说明书修订）
5. **不确定性 / 待核实清单**：集中列出所有未查实、有分歧、口径不清的内容
6. **信息来源与证据等级**：列出依据来源（指南 / 法规 / 官网 / 文献）及 🔍 / 💭 标注

### 二、不确定性标注与防幻觉（最高优先级）
- **🔍 已查证**：经官方文件 / 权威数据库 / 检索 / 工具确认的事实。
- **💭 推测**：凭记忆、推断或未能完全核实的内容，**必须**标注 💭，不得伪装成确定事实。
- **⚠️ 待核实**：任何无法查实、存在版本差异、口径不一或有争议的内容，**必须**显式标注「⚠️ 待核实」并说明缺口，**严禁编造、补全或给出确定性结论**。
- 数值 / 政策 / 价格 / 时限类内容**必须**标注口径与时效（如「国家医保 2023 版」「截至 2026-07」）。
- 引用指南 / 法规 / 共识须写明发布机构、版本与年份。
- 触发词含「最新 / 当前 / 现在 / 指南更新 / 对比 / vs」等时效词时，**必须先检索再作答**，不得凭记忆直接给结论。
- 禁止任何虚构数据、虚构文献、虚构法规条款；不确定时宁可少说、标清，不可编满。

### 三、证据分级（输出中随附 · 中成药自定义）
- L1a 高质量 RCT（随机双盲多中心·病证结合双终点·CONSORT）
- L1b 单中心 RCT / 高质量前瞻性 RWE
- L2 队列 / 病例对照 / meta / 回顾性真实世界
- L3 名老中医经验（系统整理）/ 专家共识 / 中西医结合诊疗指南
- L4 典籍溯源（伤寒论 / 温病条辨等）/ 病例系列
- L5 观点 / 未证实信息（须标注 💭 或 ⚠️ 待核实）
- **中成药强制双终点**：证候积分 + 西医指标，缺一项降为 L2 处理。

# 中成药医学分析（医学部同事使用）
从医学(Medical Affairs)视角，对中成药/中药品种/治疗领域做结构化分析，把中医临床价值（功能主治·证型·方解）转化为可生成的证据、可传递的医学信息与可进入的路径。本 skill 内置知识库，强制数据校准与医学信息框定。

## 1. 概述
回答"中成药的医学策略怎么定、病证结合定位(循证)怎么定、锚点证型的医学证据够不够、循证缺口在哪、RWE方案怎么设计(证候量表)、KOL怎么分层(中医/西医)、MSL拜访要点、HEOR/药物经济学证据怎么搭、怎么推动进指南/路径、中西联合用药的医学依据、说明书安全性怎么完善、药物警戒怎么做、上市前医学要做什么、核心医学信息(弹药包)给市场/准入"——
一个 Skill 扮演"中成药医学专家团"，按需调取医学洞察/循证/证据生成/医学信息/HEOR/路径推动/安全/上市前等专长。

**核心创新——病证结合证据驱动医学定位**：医学部既要"读证据"更要"生证据"。传统医学定位靠单点研究，本 Skill 从**病证结合证据强度分布**出发，用循证确定"锚点证型"的医学依据（证据等级+双终点+指南+共识+典籍），反哺市场部的双轨推广定位；同时医学部**主动生成证据**（RWE/IIT/IV期/PASS）填补缺口，推动中成药进入指南与路径。不是市场的写手，不是销售的传声筒，是连接中医循证与临床实践的医学中枢。

**内置共享知识**：本 Skill 内置基础模块（foundation.md）（中成药临床档案/校准规则/中成药循证分级/证候量表/RWE方案/路径指南/HEOR/安全说明书/医学合规边界）——临床档案(功能主治证型/方解/安全性/循证三件套)、数据校准规则(🔍/💭)、references 知识库。不重复这些基础内容，需要时直接 Read 调用。

## 2. 两轮工作机制（防遗漏·防编造）

> 本 Skill 将信息采集和分析编写严格分离为两轮。**第一轮只采集事实，不写分析。** 第二轮在锁死的事实基础上做医学分析。所有输出前再用 §10 关键事实核查做第三道验证。

### 2.0 入口判断（执行任何轮次前）
- 未给出明确品种/治疗领域时，先追问，绝不凭空分析。
- 先判断"这件活归不归医学部"（见 §8 边界声明）：非医学的(如纯推广执行/纯销售业绩/纯准入谈判)不深做，只指路或给接口清单。
- **中成药入口特判**：用户给的是西医病名时，须先映射回"对应中成药功能主治的证型"，不得直接用西医病名人群做医学定位。
- **科学交流 vs 推广边界**：本 skill 产出均为 non-promotional 医学内容；任何 promotional 转化（推广物料/DA）须转市场部并过 MLR。

### 2.1 第一轮：结构化事实采集

#### 2.1.0 信息源处方（去哪查 + 怎么判断源够不够好）

**信息源质量阶梯**：

| 级别 | 定义 | 典型来源 | 适用字段类型 |
|---|---|---|---|
| **L1 监管/法定** | 有法律效力的官方数据 | NMPA 中保办/药典委员会、国家医保局目录、招采平台、药品说明书(NMPA备案版)、不良反应监测中心 | 功能主治、注册分类、医保类别、说明书安全性 |
| **L2 专业数据平台** | 结构化药品/循证数据库 | 药智数据(yaozh.com)、中医药循证数据库(如中医药循证评价平台)、ClinicalTrials.gov/中药临床试验登记、中药材天地网 | 厂家注册、研究登记、临床试验、价格 |
| **L3 同行评审文献** | 发表的研究/指南/共识原文 | 中华系列期刊、中国中西医结合杂志、中医杂志、PubMed、学会官网、Cochrane | 循证证据、指南推荐、专家共识、RWE |
| **L4 行业报告** | 第三方咨询/研究机构 | 中药大品种科技竞争力报告、弗若斯特沙利文(HEOR)、中商产业 | 市场规模(交叉验证)/药物经济学背景 |
| **L5 企业官方** | 企业公告/年报/官网 | 企业年报、官方新闻稿、医学信息应答库 | 销售额、管线进展、医学活动动态 |
| **L6 媒体/聚合** | 行业媒体/百科/公众号 | 39健康、微信公众号、百度健康百科 | 仅作线索，不作为结论来源 |

**各字段类型的来源处方**（中成药医学侧重）：

| 字段类别 | 必须覆盖的来源 | 最低源数量 | 为什么 |
|---|---|---|---|
| **功能主治/证型** | L1(说明书/NMPA) + L3(方剂学/临床指导原则) | ≥2 | 中医术语一字之差就是错配 |
| **循证证据(研究/指南/共识)** | L3(期刊原文/学会官网) | ≥1原文 + ≥1次级确认 | 标题/作者/年份/推荐级别/双终点一个不能少 |
| **安全性/说明书** | L1(说明书原文/不良反应监测) + L3(监测报告) | ≥2 | 涉及 PV 与法律风险 |
| **KOL观念** | L3(指南/共识署名专家) + L5(企业医学活动) | ≥1 + 标注💭 | 观念须可追溯，不得编造 KOL 立场 |
| **医保/路径/指南** | L1(国家医保局/学会官网) + L3(指南原文) | ≥2 | 路径与医保直接影响医学策略 |
| **HEOR/药物经济学** | L3(已发表药物经济学研究) + L4(模型报告) | ≥1 + ≥1方法学确认 | ICER/成本效果须可复核 |

**处罚规则**：
- L6 来源作为定论呈现 → 降级为 💭 并在分析中标风险
- 仅单源 + 未标💭 → 视为违反校准规则（§6）
- 功能主治/注册分类/说明书安全性 三个字段**只用L4-L6源** → 不通过第一轮，必须回头补采L1/L3源

#### 2.1.1 采集模板（必填字段，分 6 大类 · 中成药医学适配）

**A. 品种与临床基础**
| 序号 | 字段 | 查证来源 | 校准要求 |
|---|---|---|---|
| A1 | 通用名/拼音名 | NMPA批件/说明书 | 须与说明书一致 |
| A2 | 药品类别 | NMPA注册信息 | **中成药**（注明 1-4 类/经典名方 3 类） |
| A3 | 方解与功效类别 | 说明书+references/foundation.md §1 | 君/臣/佐/使 + 扶正/祛邪/调和 |
| A4 | 剂型与给药途径 | 说明书 | 注射剂/口服/外用等（安全性权重不同） |
| A5 | **功能主治（说明书原文·证型+病证）** | 药智说明书/药典 | **必须原文**，不得西医化改写 |
| A6 | 用法用量/疗程/特殊人群 | 说明书 | 注明孕妇/儿童/年老体弱注意 |

**B. 循证证据库（病证结合·强制双终点）**
| 序号 | 字段 | 查证来源 | 校准要求 |
|---|---|---|---|
| B1 | 关键研究（研究全名+设计+NCT/登记号+期刊+年份） | 期刊/ClinicalTrials.gov/中药临床试验登记 | 至少列最关键的1-3个，标 L1a-L5 |
| B2 | 指南推荐（指南全称+机构+年份+推荐级别+具体地位） | 学会官网/中华系列 | **禁止只写"XX指南推荐"** |
| B3 | 专家共识/典籍依据（全称+机构+年份 / 典籍出处+朝代） | 学会官网/万方/典籍 | 典籍仅作定位背书，非疗效确证 |
| B4 | 关键终点（证候积分 + 西医指标，效应量+CI+p） | 已发表研究原文 | **双终点缺一不可** |
| B5 | 安全性证据（不良反应/禁忌/相互作用/含毒药材） | 说明书+监测报告+文献 | 罗列发生率>5%的AE+特殊警告 |

**C. 竞品医学情报**
| 序号 | 字段 | 查证来源 | 校准要求 |
|---|---|---|---|
| C1 | 同名同方/独家竞品（医学定位与证据对比） | NMPA/CDE/文献 | 罗列品名+企业+证据等级 |
| C2 | 间接竞品（同病证西药/不同中成药机制） | 指南/文献 | 机制与证据对比 |
| C3 | 竞品循证缺口对比 | 文献综述 | 标注局限 |

**D. KOL 与观念**
| 序号 | 字段 | 查证来源 | 校准要求 |
|---|---|---|---|
| D1 | 领域 KOL 清单（Tier1/2/3，中医师/西医师分列） | 指南/共识署名+学会任职 | 标注学术方向与观念立场，来源可追溯 |
| D2 | 当前 KOL 观念（对本品/病证结合的定位认知） | 医学活动/文献/访谈 | 标 💭 若未直接核实 |
| D3 | 未满足的医学教育需求 | 领域洞察+活动反馈 | 标注缺口 |

**E. 政策与路径（医学影响）**
| 序号 | 字段 | 查证来源 | 校准要求 |
|---|---|---|---|
| E1 | 医保类别（甲/乙/谈判/基药）与限定支付 | 国家医保局最新版目录 | 标入保年份+是否基药+限定 |
| E2 | 指南/路径/共识纳入状态（本品/同类） | 学会官网/指南原文 | 是否已进指南/路径/共识 |
| E3 | 医保谈判/基药遴选的医学证据需求 | 医保局/药经报告 | 标注所需 HEOR/循证类型 |

**F. 安全性与 PV 基础**
| 序号 | 字段 | 查证来源 | 校准要求 |
|---|---|---|---|
| F1 | 现行说明书安全性（不良反应/禁忌/注意事项原文） | NMPA备案说明书 | 须最新版，注明版本日期 |
| F2 | 已知风险信号/黑框警告/含毒药材 | 说明书+监测中心 | 显式呈现，不得淡化 |
| F3 | 中西药相互作用已知信息 | 说明书+文献 | 标注证据等级 |

#### 2.1.2 缺口可见化规则
采集模板中每个字段必须填以下三者之一：
| 标记 | 含义 | 条件 |
|---|---|---|
| ✅ 值 | 已查证并填写 | 至少 1 个来源查实 |
| ⬜ 待采集 | 该字段存在但尚未查到 | 知道该查但没找到——让不可见缺口变可见 |
| ❌ 不适用 | 该字段对此品不适用 | 如"无注射剂"→A4 填"N/A" |

**禁止行为**：字段不写≠不存在。模板有字段但只填部分，剩余必须标⬜。

#### 2.1.3 校准置信度分级
| 置信度 | 标记 | 条件 | 示例 |
|---|---|---|---|
| **高置信** | ✅✅ | ≥2 个独立来源一致 | NMPA说明书+药典双重确认功能主治 |
| **中置信** | ✅⚠️ | 1 个来源，或来源间有时效/口径差异 | 单篇 RWE 报告 |
| **低置信** | ❓ | 模型推断/记忆/单一非权威 | "据称某专家支持"来自通稿 |

**中/低置信字段**在分析编写时须标注风险。

#### 2.1.4 防遗漏自检（采集完成后执行）
1. ❓ 功能主治写的是原文证型+病证，还是被西医化了？
2. ❓ 关键研究的双终点（证候+西医）都列了吗？缺一项降 L2 处理了吗？
3. ❓ 指南/共识写了全称+机构+年份+推荐级别吗？还是只写"XX推荐"？
4. ❓ 安全性信息与最新版说明书一致吗？含毒药材提示了吗？
5. ❓ KOL 清单标了来源与 Tier 吗？有没有编造立场？
6. ❓ 竞品医学对比标注了局限（间接对比）吗？
7. ❓ 医保/路径状态写了年份与限定吗？
8. ❓ HEOR/药物经济学证据标了模型假设与口径吗？

### 2.2 第二轮：分析编写（基于锁死事实）
1. 第一轮采集通过后，字段标记完成，⬜项 ≤5 个方可进入。
2. 以锁死的事实地基调用本 skill 自带 中成药循证分级+证候量表+路径指南+HEOR+安全说明书+医学合规。
3. 按 §3-§5 走完整分析流程（活动簇 × 角色 × 上下文 → 9簇产出 → 输出格式）。
4. 分析层不得修改采集层的事实，只能引用。
5. 分析中引用的数据须能回溯到采集模板的具体字段编号（如 A5 功能主治、B4 双终点）。

### 2.3 第三轮：关键事实终查
输出前执行 §10 核查清单，与采集模板交叉核对。

### 簇M1 医学洞察与情报
1. **治疗领域医学全景**（见 drug-medical-postlaunch L1 思路 + 中成药适配）：
   - 疾病负担与流行病学（标注中国/区域口径，含证型分布）。
   - 诊疗路径（从最新指南提取治疗阶梯，标注中成药切入的证型节点）。
   - 患者旅程（含"辨证准确率"与"中成药处方率"两层特有关卡）。
   - 未满足需求（临床/患者/系统，按证型优先级排序）。
2. **竞品医学情报**：同名同方/独家/间接(西药)的医学定位与证据对比（标注局限）。
3. **双轨KOL观念洞察**：中医师（辨证体系/方解认同/典籍信任）vs 西医师（功能主治认知/循证需求/支付顾虑）。
4. **政策医学影响**：中成药集采/基药/医保限定对医学策略的影响（与 `drug-market-tcm` 支付场景联动，医学部提供证据支撑）；指南/路径更新趋势。
5. **情报系统搭建**：竞品循证/指南更新/KOL观念/安全性信号的常态化监测机制。

---

### 簇M2 医学策略与病证结合定位（见 `references/tcm-medical-strategy.md`）
1. **病证结合医学定位**：以循证确定锚点证型的医学依据（调用 M3 证据全景），定位须基于最满的证据格子。
2. **证据缺口地图**：当前证据 vs 目标定位的缺口（哪类证型缺 RCT？缺长期安全性？缺特殊人群？），形成证据生成优先级。
3. **医学价值主张**：科学价值（证候+西医双获益）+ 患者价值（依从/可及/生活质量）+ 经济价值（成本效果，M6 支撑）。
4. **生命周期医学策略（PLC）**：上市期→成长期→成熟期→衰退期；经典名方免临床→上市后循证补充；中药注射剂→强安全监管与长期 PV。
5. **年度医学计划**：KOL覆盖 / 证据生成 / 学术影响指标 / 资源配置（输入 M4/M5/M7）。

---

### 簇M3 循证证据体系与分级（见 `references/tcm-evidence-levels.md`）
1. **中成药L1a-L5分级**：调用循证分级，逐条证据定级。
2. **病证结合证据全景图**（M3 核心）：
   - 按 **病证 × 证型亚组 × 关键终点(证候+西医)** 三维交叉建表。
   - 每格标注：研究原文(名/设计/N) / 证据等级 / 样本量 / 证候积分改善 / 西医指标 / 指南推荐级别 / 专家共识地位。
   - **锚点证型判定**：六维最满（尤其 L1a + 双终点 + 指南）的证型即锚点；查不到标 💭 待核实。
3. **双终点强制校验**：缺证候或西医任一终点 → 降 L2，并标缺口。
4. **典籍/经验定位边界**：典籍与名老中医经验仅作立题与定位背书，不作疗效确证（与市场合规红线一致）。

### 簇M4 证据生成（研究设计与执行）（见 `references/tcm-rwe-design.md` + `references/tcm-syndrome-scales.md`）
> 医学部核心增值：主动补证据缺口，而非只读证据。
1. **病证结合RCT双终点设计**：主要终点=证候积分 + 西医指标；模拟剂对照；样本量/统计假设（调用 `tcm-rwe-design.md` §2）。
2. **RWE方案设计**（M4 重点）：真实世界研究目的/设计(前瞻登记/回顾队列)/数据源(HIS/登记库)/证候量表与PRO选择(调用 `tcm-syndrome-scales.md`)/偏倚控制/分析计划。
3. **IIT/IIS管理**：研究者发起研究的医学监查、数据质量、发表策略。
4. **IV期/PASS**：上市后安全性研究（尤其注射剂/含毒药材品种），输入 M8 PV。
5. **登记研究/registry**：中成药长期疗效与安全性真实世界登记。
6. **名老中医经验整理**：系统整理（德尔菲/共识法）形成专家共识底稿（L3），非疗效确证。
7. **典籍研究**：经典名方溯源与现代研究衔接（立题依据）。
8. **发表策略**：研究注册(ClinicalTrials.gov/中药试验登记) + 发表计划 + 数据透明度。

---

### 簇M5 医学信息与教育（双轨）（见 `references/tcm-medical-compliance.md` 边界）
1. **双轨MSL（中医师/西医师）**：
   - 中医师MSL：方解/辨证体系/典籍与现代研究衔接的科学交流。
   - 西医师MSL：功能主治锚定+双终点证据+安全性+支付场景的科学交流。
   - 均须 non-promotional，锚定说明书功能主治；off-label 仅限科学场景并标注。
2. **HCP医学应答（MI）**：响应西医"功能主治依据"与中医"方解依据"问询，双轨应答模板，标注证据等级。
3. **KOL管理**（衔接 M1-D）：Tier 分层 + 观念地图 + 科学信息传递（领域全景 + 核心信息组合）。
4. **学术会议医学内容**：全国中西医结合会/中医科室会/西医科室会/卫星会的医学内容（双轨分版），非推广物料。
5. **医学教育**：辨证培训/循证沙龙/病例讨论（科学交流，非推广）。

---

### 簇M6 药物经济学与价值证据（见 `references/tcm-heor.md`）
1. **HEOR 证据生成**：成本效果(CEA)/成本效用(CUA, QALY)/预算影响(BIA)模型设计，标注假设与口径。
2. **医保谈判证据**：为谈判提供药物经济学与价值证据（临床价值+经济价值+患者价值），定价执行归准入。
3. **基药遴选证据**：基药遴选所需的循证与卫生技术评估(HTA)证据包。
4. **真实世界成本效果**：结合 M4 RWE 的成本效果证据。
5. **价值证据包（给准入/市场）**：基于 M1 未满足需求 + M3 证据对比的价值论证。

---

### 簇M7 中西医结合路径与指南推动（见 `references/tcm-pathway-guideline.md`）
1. **中医优势病种识别**：本品功能主治对应的优势病种/优势证型（循证+典籍支撑）。
2. **指南/共识推动**：参与/发起指南与专家共识撰写，推动中成药(病证结合)证据进入推荐。
3. **中西联合用药医学依据**：中西药联用的机制/循证/安全性依据（相互作用须查 F3），形成联合方案证据包。
4. **诊疗路径与准入**：推动中成药进入临床路径、中西医结合诊疗方案，影响可及与支付。
5. **路径证据需求对接**：为支付场景地图（市场部）提供"进路径/进指南"的医学证据。

---

### 簇M8 安全性与说明书管理（见 `references/tcm-safety-labeling.md`）
1. **药物警戒（PV）**：不良反应收集/信号检测/定期安全性报告(PSUR)/风险最小化。
2. **说明书安全完善**：推动【不良反应】【禁忌】【注意事项】从"尚不明确"向具体化修订（近年监管重点）；含毒药材须显式提示。
3. **中西药相互作用管理**：已知/潜在风险识别、标注证据等级、HCP沟通。
4. **风险沟通**：与监管/医院/患者的风险沟通策略（non-promotional）。
5. **医学合规衔接**：安全性信息须与最新版说明书一致；推广物料引用安全性须同步呈现（市场合规红线）。

---

### 簇M9 上市前医学接口（深度转 `drug-medical-prelaunch`）
> 批件到手前的医学预研。中成药特点：经典名方免临床→循证弱须规划补充；独家/创新药→需自建循证；中药注射剂→强监管。
1. **CDP医学输入**：临床开发计划的医学视角（病证结合终点设计）。
2. **试验方案医学审阅**：证候量表选择/双终点设定/对照设计。
3. **说明书拟定**：功能主治(证型+病证)与安全性条款拟定。
4. **上市前RWE布局**：为上市后循证与路径推动预研。
5. **KOL观念培育（上市前）**：合规内的学术播种，与医学协同。
6. **launch readiness（医学）**：医学信息包/MSL培训/医学应答库/KOL锁定。

> 每个簇产出前，先核对输入是否齐全（品种信息/循证/竞品/生命周期/安全性）；缺项先列"请补充"，不硬编。

## 8. 医学职能边界三档（关键创新）

| 档 | 含义 | drug-medical-tcm 做法 | 项目 |
|---|---|---|---|
| ① 医学独占/主导 | 医学主责 | 深做，独立产出 | 病证结合医学定位(M2)、循证分级(M3)、证据生成(M4)、医学信息与教育(M5)、HEOR(M6)、路径指南推动(M7)、安全性与说明书(M8)、上市前医学(M9) |
| ② 医学协同接口 | 医学参与、非主责 | 只给接口清单/医学输入 | 推广内容医学审校(→市场+合规)、医保谈判药经证据(→准入)、销售培训医学内容(→销售)、注册里程碑医学支持(→drug-reg)、推广合规MLR(→合规) |
| ③ 非医学边界 | 医学不主责 | 外置/指路 | 纯推广执行(→市场)、纯销售业绩(→销售)、纯准入谈判(→准入)、纯财务战略、纯广告法执行(→合规) |

**关键切分说明**：
- **医学 vs 市场**：医学做"病证结合证据→核心医学信息(弹药包)"，市场做"证据到双轨推广信息的转化"。医学不直接出推广物料；市场调用医学产出的证据与核心信息，转化须过 MLR。
- **医学 vs 准入**：医学做"价值证据与药物经济学证据包"，准入做"医保谈判/集采投标执行与定价底线"。医学提供 ICER/成本效果证据，准入决策。
- **医学 vs 销售**：医学做"MSL科学交流 + 销售培训医学内容"，销售做"终端覆盖与业绩执行"。
- **科学交流 vs 推广**：MSL/医学教育活动为 non-promotional，严格隔离 promotional 内容；off-label 仅限科学场景。
- **医学 vs 合规**：医学提供科学内容输入，合规/MLR 审查归合规角色；医学产出标注"供 MLR 审校参考"，不替代合规审查。
