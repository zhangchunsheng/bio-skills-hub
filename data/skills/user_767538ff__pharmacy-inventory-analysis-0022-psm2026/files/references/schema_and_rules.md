## 2. 阶段1 清洗规则
- **删除**：仅当 `帐存数量`、`实存库房数量`、`实存药房数量` 三项**均为显式数值 0** 才删除。
  空白或非数值视为「未知」，保留（避免误删数据缺失的真实记录）。
- **标红**：逐行比对 `盘前进价` 与 `盘后进价`，仅当 `|盘前 − 盘后| > THRESHOLD`（默认 0.01）整行标红。
  本数据集 91 行两价不同，但差异均 ≤ 0.01，属四舍五入噪声，故按阈值标红行数为 0。
- 输出保留标题合并、表头、全部列；新增「序号」列（row 顺排）。

## 3. 阶段2 实盘数量计算（优先级）
统一公式：**实盘数量 = 实存库房数量 × P + 实存药房数量**

| 优先级 | 规则 | P 取值 | 示例 |
|---|---|---|---|
| A | 特殊药品固定系数（按名称关键词） | 见下表 | 开塞露 10×20+11=211 |
| B | 库房单位 == 药房单位 | 1（直接取另一非零方） | 99151 炉甘石 30瓶+0→30 |
| C | 单位不同且规格含包装数量 | 从规格提取 | 84181 1×12+0=12；99442 17×30+4=514 |
| D | 规格无包装数量 | 默认 10（每盒10支/瓶） | 35422 苯海拉明 14×10+4=144 |

### 特殊药品系数表
| 关键词 | P |
|---|---|
| 开塞露 | 20 |
| 硫酸亚铁颗粒 | 10 |
| 蛇毒血凝酶 | 5 |
| 浓氯化钠 | 5 |
| 依诺肝素 | 5 |

### 规格包装数量提取（规则 C）
正则优先级：
1. `*` 之后数字+单位：`*(\d+(\.\d+)?)(粒|支|片|…)` → `1.74g*12粒`→12，`50ug*60揿`→60，`2ml:1mg*30支`→30
2. `数字+单位+/或(`：`100片/瓶`→100
3. 兜底：首个 `数字+单位`

**注意单位集合**需覆盖：`粒|支|片|袋|包|个|枚|丸|贴|组|瓶|揿|喷|吸|板|颗|泡|张`。
体积/质量单位（ml/g）**不计入**包装数量——此类应落到规则 D（默认10）。
例如 `10g`、`30ml` 规格无包装数，按默认每盒10 处理。

## 4. 阶段3 差异分析
- 差异数量 = 实盘数量 − 帐存数量
- 差异金额 = 差异数量 × 盘后进价（保留到分）
- **盘盈表**：差异数量 > 0，按差异金额**降序**
- **盘亏表**：差异数量 < 0，按差异金额**升序**
- **相符表**：差异数量 = 0
- 盘点准确率 = 相符品种数 ÷ 总品种数 × 100%
- 工作表：盘点差异总表 + 盘盈表 + 盘亏表 + 相符表 + 盘点汇总

## 5. 阶段4 负数记录隔离
- 源数据中存在 **18 行实盘数量 < 0**（如 99442 ZA25312 实盘=−1、99987 氯化钠 实盘=−110）。
- 这些几乎都是「账实同为负」，疑似录入/系统溢出错误（负数库存不可能存在）。
- 单独导出为 `负数实盘记录.xlsx`，并**从差异分析剔除**后重算（盘盈/盘亏/相符/准确率随之变化）。
- 注意：18 行里 17 行原本在「相符」（差=0），1 行在「盘亏」，故剔除后盘亏−1、相符−17。

## 6. 阶段5 进销存填表
目标模板 `盘点数据.xlsx` 为竖向表单（A列=字段名，B列=值）。
进销存表 `进销存数据.xlsx` 为**分组多层表头**（统计时间在第4行；列名分布在第6~8行），并有「合计」行。

### 字段映射
| 模板字段 | 来源 |
|---|---|
| 盘点时间 | 进销存「统计时间 … 至 YYYY-MM-DD」的截止日（或「盘点时间」字段） |
| 期初金额 | 进销存「期初-售价金额」合计 |
| 入库金额 | 进销存「申领入库-售价金额」合计 |
| 销售金额 | 进销存「销售-售价金额」合计 |
| 调拨金额 | 「入库-调拨入库售价金额」合计 − 「出库-调拨出库售价金额」合计 |
| 报损金额 | 进销存「报损-售价金额」合计 |
| 盘点品种总数 | 剔除负数后的盘点行数 |
| 账面总金额 | Σ(帐存数量 × 盘后进价) |
| 实盘总金额 | Σ(实盘数量 × 盘后进价) |
| 账实相符品种数 | 相符行数 |
| 账实相符率 | 相符÷总数×100 |
| 差异金额 | 实盘总−账面总 |
| 差异率 | 差异金额÷账面×100 |

### 进销存列定位技巧
- 用 `_find_jxc_col`：拼接第6~8行同列文本，按关键词（期初/申领入库/销售/调拨入库/调拨出库/报损/售价金额）定位列。
- 用「合计」行做交叉校验：合计行对应列值应与对数据行求和一致（差异应 < ¥0.5）。

### 已知数据质量问题（务必向用户提示）
1. **负数实盘**：如上，已隔离未计入。
2. **盘后进价为负**：个别行差异数量>0 但差异金额为负（源数据异常进价），计算如实保留。
3. **售价 vs 进价口径不一致**：进销存各项金额取自**售价金额**；账面/实盘总金额因盘点表仅含**进价**，只能按进价估算。若报告要求统一为售价，需补充售价字段后重算。
4. **差异率可能很大**：本例 188.79% 并非错误——913 行相符已证单位一致（如复方甘草片 帐存=实盘=1808），净差异 +134 万几乎全来自少数高价盘盈（如 99935 注射用卡瑞利珠单抗 帐存5/实盘50 × ¥2576.64 = +¥115,948.80），盘亏仅 −¥8,405。报告时应优先复核高价盘盈记录。
