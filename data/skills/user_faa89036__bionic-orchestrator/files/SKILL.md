# 🎼 Bionic Orchestrator — 仿生编排系统

> **类比**：人类大脑的执行控制系统。
> - 工作记忆：临时保存关键上下文，防止信息丢失
> - 内心独白：任务间隙的自我反思和场景预演
> - 任务调度：根据复杂度选择执行策略

本 Skill 在**任务全生命周期**自动管理执行过程。

---

## 三层编排架构

```
任务开始
    ↓
┌─────────────────────────────────────────┐
│  L1: 工作记忆管理                        │
│  - 初始化任务上下文                      │
│  - 每步执行后更新状态                    │
│  - 防遗忘机制                            │
└─────────────────────────────────────────┘
    ↓
执行中
    ↓
┌─────────────────────────────────────────┐
│  L2: 任务调度                            │
│  - 根据复杂度选择策略                    │
│  - 协调各 Skills 执行顺序                │
│  - 异常处理和回退                        │
└─────────────────────────────────────────┘
    ↓
执行间隙/完成后
    ↓
┌─────────────────────────────────────────┐
│  L3: 内心独白                            │
│  - 静默自我反思                          │
│  - 复盘优化                              │
│  - 发现通用规律                          │
└─────────────────────────────────────────┘
    ↓
任务结束 → 推送学习系统
```

## 自动触发规则

### 触发时机

| 时机 | 自动执行 |
|------|---------|
| **任务开始** | L1 初始化工作记忆 |
| **每步执行后** | L1 更新状态 + L2 调度下一步 |
| **遇到决策分支** | L3 内心独白权衡 |
| **任务完成后** | L3 复盘 + L1 归档 |
| **对话超过20轮** | L1 防遗忘标签 |

## L1: 工作记忆管理

### Buffer 结构

```json
{
  "session_id": "2026-04-16-12-30",
  "task_title": "任务简短标题",
  "status": "in_progress | completed | aborted",
  "intent": "用户的原始意图",
  "constraints": ["约束1", "约束2"],
  "decisions": [
    {
      "step": 1,
      "action": "做了什么",
      "reason": "为什么这么做",
      "alternative": "放弃了什么选项",
      "ts": "时间戳"
    }
  ],
  "artifacts": ["产出文件路径"],
  "open_questions": ["未解决的问题"]
}
```

### 防遗忘机制

```
对话超过20轮时，自动附加：
[WM] 当前任务：{task_title} | 状态：{status} | 关键：{top2_constraints}
```

## L2: 任务调度

### 复杂度对应策略

| 复杂度 | 激活 Skills | 输出要求 |
|--------|------------|---------|
| **C1** | 仅 Orchestrator | 秒级执行，无框架 |
| **C2** | + Guard + Cognition | 输出框架 |
| **C3** | + Reasoning | 详细推理过程 |
| **C4** | + Swarm + 其他 | 全链路 |

### 异常处理

| 情况 | 处理 |
|------|------|
| 任务类型模糊 | 按 C3 保守处理 |
| Skill 加载失败 | 跳过，继续链路 |
| 用户推翻判断 | 记录到 habit-store |

## L3: 内心独白

### 标准独白流程

```
[1] 任务是什么？最核心要解决的是什么？
[2] 我对这个问题的置信度是多少？
[3] 有哪些可能的路径？各有什么风险？
[4] 我遗漏了什么信息？
[5] 如果我错了，最可能错在哪里？
[6] 最简洁的方案是什么？
[7] 用户会如何评估这个结果？
```

### 复盘独白（任务完成后）

```
[复盘] 刚才的输出有什么可以改进？
  1. [发现的问题]
  2. [下次可以更好的地方]
  → 如有高价值发现，推送 dream-memory
```

### 输出控制

**核心原则：内心独白绝对不在回复中展示。**

| 独白结果 | 处理方式 |
|---------|---------|
| 找到更好方案 | 直接采用，不解释过程 |
| 发现自己错了 | 自然修正，不说"我重新想了想" |
| 发现重大遗漏 | 补全内容，不提独白过程 |
| 发现通用规律 | 静默推送 habit-loop / dream-memory |

## 联动机制

```
Bionic Orchestrator 管理任务执行
    ↓
每步推送给 Guard：安全检查
    ↓
复杂时推送给 Reasoning：推理验证
    ↓
完成后推送给：
  - Habit Loop：习惯检测
  - Evolution Engine：策略评分
  - Dream Memory：高价值内容固化
```

## 执行原则

1. **静默管理**：用户只看到结果，不看到编排过程
2. **状态透明**：工作记忆记录完整决策链
3. **持续反思**：每个任务都是学习机会
4. **优雅降级**：部分失败不影响整体执行
