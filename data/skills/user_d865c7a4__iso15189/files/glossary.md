# Glossary — ISO 15189:2022 Accreditation (术语表)

Every key term across the 23 chapters, alphabetical by English name. Format: **English (中文)** — definition [chapter/clause].

**Acceptance (受理)** — CNAS's formality/eligibility screening of a submitted application before assigning an assessment team; ends in a 受理/不受理 decision with reasons.

**access authority (访问权限)** — role-based rights to enter/edit/release/amend/configure (Ch 17)

**accreditation (认可)** — third-party attestation that a conformity assessment body (e.g., a medical laboratory) demonstrates competence, impartiality, and consistent operation; voluntary and distinct from mandatory practice licensing (Ch1)

**Accreditation Criteria (认可准则)** — CNAS-CL01《检测和校准实验室能力认可准则》(≈ISO/IEC17025, general labs); CNAS-CL02《医学实验室质量和能力认可准则》(等同采用ISO15189:2022) — the core criteria medical labs are assessed against.

**Accreditation Rules (认可规则)** — CNAS-RL01《实验室认可规则》: top-tier rules governing how CNAS accredits any laboratory (testing/calibration/medical); CNAS-RL02《能力验证规则》 governs PT/EQA requirements.

**air-pressure gradient (气压梯度/压差)** — monitored Pa differential preventing backward amplicon flow (Ch 16)

**alert interval / critical interval (警示区间/危急值)** — an examination result range signaling immediate risk to the patient requiring urgent clinical action; commonly implemented domestically as a 危急值 (critical value) list (Ch1)

**Alternative EQA assessment (无EQA时的替代评估)** — When no commercial EQA/PT scheme exists for a test, labs must use inter-laboratory comparison, certified reference materials, or collaborative/research PT, typically ≥2×/year, as an equivalent evidentiary substitute (Ch 5)

**amplicon contamination (扩增产物污染)** — dominant molecular risk driving facility design (Ch 16)

**Annex 1 / 附表1 (授权签字人一览表)** — table of authorized signatories: name, position/title, education, years of relevant experience, authorized signing scope, specimen signature.

**Annex 2 / 附表2 (申请检验(检查)能力范围表)** — bilingual (CN/EN) scope-of-accreditation table: item name (CN+EN), method/technology principle, standard/reference, discipline classification code.

**Annex 3 / 附表3 (认可准则和应用要求自查表)** — clause-by-clause self-assessment checklist against every CNAS-CL02 (+ applicable Axxx) clause: 符合/不符合/不适用 + evidence document reference.

**Annex 4 / 附表4 (能力验证计划/实验室间比对结果汇总表)** — one row per applied item: PT/EQA scheme, provider, round, date, result (满意/不满意), or documented alternative.

**Annex 5 / 附表5 (实验室人员一览表)** — full personnel roster (superset of Annex 1 signatories): role, title, education, years of experience, training/competency record.

**Annex 6 / 附表6 (实验室开展检验(检查)项目清单)** — complete current test menu (superset of Annex 2), flagging which items are included in the current application.

**Application Form (医学实验室质量和能力认可申请书)** — the primary CNAS submission document: lab identity, site(s), application type (初次/复评审/扩项/变更), criteria applied against, declarations of compliance/impartiality/confidentiality.

**Application Notes (应用说明)** — CNAS-CL02-Axxx series: discipline-specific interpretive notes attached to CNAS-CL02 (e.g. 临床血液体液、临床化学、临床免疫、临床微生物、分子诊断、输血医学、POCT); each applied test item must be tagged to exactly one discipline so the matching Axxx note + matching specialty assessor apply.

**audit trail (审计追踪)** — attributable, time-stamped record of data actions (Ch 17)

**Authorization (授权)** — a formal grant of permission to perform a defined task (sampling, testing, result release, system access) issued only after competence has been demonstrated, not merely after training attendance (clause 6.2.3).

**Authorized Signatory (授权签字人)** — staff member formally authorized to sign test reports within a defined scope (授权签字范围); scope must not exceed personal qualification/experience even if within the lab's overall accredited scope.

**backup and restore (备份与恢复)** — periodic backup with tested recovery (Ch 17)

**biological reference interval (生物参考区间)** — interval derived from the distribution of values in a reference population (often central 95%), replacing the older term "reference range"; may be self-established, verified-from-transfer, or directly adopted (Ch1)

**Biological reference interval (生物参考区间)** — Range of values expected in a defined reference population; adopted intervals must be locally verified (n=20 rule: ≤2/20 outliers acceptable) or independently established if no suitable published interval exists (Ch 5, clause 7.3.5)

**calibration (校准)** — a two-step operation: first establishing the relationship between reference quantity values and indications (with uncertainty), then using that relation to obtain a result from an indication; distinct from calibration verification/adjustment (Ch1)

**Calibration program (校准计划)** — the lab's scheme for calibration/verification with intervals set by risk, use frequency, stability, and manufacturer guidance rather than a single fixed default (clause 6.5.1).

**Clinical decision limit (临床决定值)** — A guideline/evidence-sourced cutoff (e.g., troponin 99th percentile) used instead of a "normal range" for tests like tumor markers or therapeutic drug monitoring, with documented rationale (Ch 5)

**clinical gene-amplification laboratory (临床基因扩增检验实验室)** — physically-partitioned PCR lab regulated by 卫办医政发〔2010〕194号 (Ch 16)

**Comparability of results (结果可比性)** — Requirement that the same test performed on different instruments/sites/methods (including POCT vs. central lab) agree within a defined bias limit, checked at least twice yearly (Ch 5, clause 7.3.6.3)

**Competence requirements (岗位能力要求)** — documented education, qualification, training, technical knowledge, skills, and experience a role must have before being authorized to perform an activity (clause 6.2.2).

**confidentiality (保密性)** — clause 4.2: legally enforceable commitment to manage confidentiality, at all levels (including committees, contractors, external bodies), of information obtained/created through lab activities, covering both paper and electronic records (Ch2)

**Continuing education and professional development (继续教育和专业发展)** — ongoing, planned CE activity for staff beyond initial training, tracked against a training plan (clause 6.2.4).

**data integrity (数据完整性)** — data complete, unaltered, traceable across lifecycle (Ch 17)

**downtime contingency plan (信息系统应急预案)** — procedures maintaining service during system failure (Ch 17)

**Environmental condition control (环境条件控制)** — monitoring/recording of conditions (temperature, humidity, power, biosafety zoning) that could invalidate results or affect required measurement quality (clause 6.3.2).

**Equipment acceptance testing (设备验收试验)** — pre-use verification that equipment meets specified performance requirements, distinct from calibration; repeated after relocation/major repair (clause 6.4.2).

**Equipment records / equipment file (设备档案)** — the mandated record set per item: identity, manufacturer/model/serial, contact, receipt/service dates, condition on receipt, verification and performance records, maintenance/repair/modification history (clause 6.4.7, ten elements).

**Equipment status labeling (设备状态标识)** — visual tagging (commonly a three-colour system: usable/restricted/out-of-service) showing an item's calibration/verification status (interpretive practice under clause 6.4.3–6.4.5).

**examination (检验)** — the set of operations having the object of determining the value or characteristic of a property of a sample; the standard's precise term for the analytical process, to be used consistently instead of colloquial synonyms (Ch1)

**external quality assessment / EQA (室间质量评价)** — evaluation of participant performance by means of interlaboratory comparison; broader than 能力验证 (proficiency testing, PT), which is a formal statistical subset (Ch1)

**External Quality Assessment / Proficiency Testing (室间质量评价/PT, EQA)** — Periodic testing of blind samples via an accredited scheme (ISO/IEC 17043-equivalent), performed by routine staff with routine methods, scored typically by z-score (|z|≤2 satisfactory), with root-cause investigation required for unsatisfactory results (Ch 5, clause 7.3.6.2)

**externally managed system (外部管理的信息系统)** — vendor/off-site system under lab responsibility via agreement (Ch 17)

**Externally provided products and services (外部提供的产品和服务)** — the umbrella category covering referred testing, consultation opinions, calibration/maintenance services, reagents/equipment, and support services (IT, cleaning, waste disposal); lab retains full responsibility for ISO 15189 conformance regardless of outsourcing (clause 6.8.1).

**four functional areas (四个功能分区)** — reagent-prep, specimen-prep, amplification, product-analysis (Ch 16)

**Guidance Documents (指南, CNAS-GL series)** — non-mandatory practical guidance (method validation/verification, measurement uncertainty, biological reference intervals) supporting CL02 implementation.

**harm (危害)** / **hazard** / **risk (风险)** — harm: physical injury or damage to health/property/environment; risk: function of the probability of harm occurring and its severity — foundational vocabulary for the standard's risk-based thinking (Ch1)

**impartiality (公正性)** — clause 4.1: the lab shall carry out activities impartially, organize/manage itself to safeguard impartiality, and continually identify and mitigate risks to impartiality arising from activities, relationships, or personnel (Ch2)

**Incompatible activities (不相容活动)** — lab activities that must be physically/procedurally separated to prevent cross-contamination, classic example: PCR pre-/post-amplification zoning (clause 6.3.2, 解读 example).

**information system (信息系统/LIS)** — all hardware/software handling lab data end-to-end (Ch 17)

**information-system validation (信息系统验证)** — proof the system handles data correctly before use and after change (Ch 17)

**Informed consent (患者知情同意)** — Explicit signed consent beyond routine implied consent, required for HIV testing, genetic testing, invasive collection procedures, and research use of samples (Ch 5)

**Intermediate check (中间检查)** — a check performed between full calibrations (e.g., QC trend review, verification checks) to sustain confidence in calibration status (interpretive content under 6.5).

**Internal Quality Control (室内质量控制, IQC)** — Ongoing statistical monitoring (Westgard multirules: 1_3s, 2_2s, R_4s, 4_1s, 10x) of control materials at ≥2 levels per run/24h to detect errors before patient result release (Ch 5, clause 7.3.6.1)

**Irreplaceable sample (不可替代样本)** — Unique/high-value samples (CSF, bone marrow, intra-operative frozen tissue) that fail rejection criteria but may still be tested with a documented report caveat rather than automatic rejection (Ch 5)

**laboratory activities (实验室活动)** — clause 5.3: activities under the accredited scope must meet the standard's requirements wherever performed — main site, off-site, temporary/mobile facility, or by staff elsewhere (e.g., patient's home) (Ch3)

**laboratory director (实验室主任)** — the individual(s) with defined competence and delegated responsibility/authority for the laboratory's services; duties may be delegated to named, competent designees but ultimate accountability is not fully transferable (Ch1, Ch3 §5.2)

**legal entity (法律实体)** — clause 5.1: the medical laboratory, or the legal entity of which it is a defined part, must be legally responsible for its activities (e.g., practice license, business registration) (Ch3)

**Limit of Blank / Detection / Quantitation (空白限/检出限/定量限, LoB/LoD/LoQ)** — Analytical sensitivity parameters established via replicate blank and low-level sample measurements (CLSI EP17-style, commonly n≥60 each), required for validation of LDT/modified methods (Ch 5)

**limit of detection (最低检出限, LoD)** — lowest reliably detected concentration; core molecular validation parameter (Ch 16)

**Lot acceptance testing / lot-to-lot verification (批号验收/批间验证)** — parallel testing of a new reagent lot against the current lot (or controls) before releasing the new lot for clinical use (clause 6.6.2).

**Measurement uncertainty (测量不确定度, MU)** — Quantitative expression of doubt about a result, determined per quantitative procedure; pragmatic top-down formula u_c = √(u(imprecision)² + u(bias)²), expanded uncertainty U = k·u_c (k=2 for ~95% CI) (Ch 5)

**medical laboratory / clinical laboratory (医学实验室/临床实验室)** — a laboratory examining materials from the human body for diagnosis, prevention, monitoring, treatment, or health assessment, possibly including advisory/consultative services and POCT sites under its management (Ch1)

**metrological traceability (计量学溯源性)** — property of a measurement result whereby it can be related to a reference through a documented, unbroken chain of calibrations, each contributing measurement uncertainty (Ch1)

**Metrological traceability (计量溯源性)** — an unbroken chain of calibrations linking a patient result to SI units, a reference material, or a reference measurement procedure; where no higher-order reference exists, traceability to the manufacturer's own reference system is acceptable if documented (clause 6.5.2).

**next-generation sequencing (二代测序, NGS)** — sequencing needing validated bioinformatics pipeline, coverage/depth QC (Ch 16)

**no-template control (无模板对照, NTC)** — control detecting master-mix cross-contamination (Ch 16)

**Nonconformity, major/minor (严重不符合项 / 一般不符合项)** — assessment findings classified by severity; severity determines the closure deadline and whether a follow-up on-site visit (跟踪检查) is required before accreditation can be granted.

**objectives and policies (目标和方针)** — clause 5.5: top management establishes, communicates, and ensures implementation of measurable quality objectives and policies, with periodic review against real performance data (Ch3)

**On-site Assessment (现场评审)** — the on-site stage of accreditation: opening meeting → document/record review, staff interviews, witnessed testing → closing meeting presenting findings including nonconformities (不符合项).

**patient-related requirements (患者相关的要求)** — clause 4.3: lab must ensure accessible services meeting patient needs, including urgency of care, advisory input on test selection/interpretation, and a patient complaint mechanism (Ch2)

**PCR operator certificate (PCR上岗证)** — mandatory personnel qualification under 194号 (Ch 16)

**Personnel records (人员记录)** — the complete personnel file: qualification certificates, job description, competence/training/CE records, performance reviews, incident/exposure/immunization history (clause 6.2.5).

**point-of-care testing / POCT (即时检测)** — examination performed near/at the site of the patient whose result may change patient care; remains under the medical laboratory's oversight even when operated by non-laboratory staff (Ch1)

**process (过程)** — a set of interrelated/interacting activities using inputs to achieve an intended result; underlies the process-approach organization of the whole standard (Ch1)

**Proficiency Testing / External Quality Assessment (能力验证 PT / 室间质量评价 EQA)** — external inter-laboratory result-comparison programs; satisfactory participation is required for every applied test item, or a documented alternative (实验室间比对、留样再测) where no scheme exists.

**quality indicator (质量指标)** — a measurable metric expressing the degree to which quality characteristics meet requirements (e.g., TAT compliance rate, sample rejection rate); requires targets, monitoring, and management review (Ch1)

**Reagent/consumable inventory management (试剂耗材库存管理)** — FIFO/FEFO stock rotation, expiry tracking, minimum-stock policy, and storage-condition monitoring (clause 6.6.3).

**Reagent/consumable records (试剂耗材记录)** — the lot-level record set: identity, manufacturer, lot/batch number, receipt/expiry/in-service/withdrawal dates, condition on receipt, verification and performance records (clause 6.6.6).

**Reassessment (复评审)** — renewal-cycle assessment conducted before certificate expiry, following essentially the same process as initial application.

**Resource adequacy (资源充分性)** — the principle that a lab must determine, provide, and demonstrate the personnel, facilities, equipment, reagents/consumables, and services needed to perform its scope of testing (Ch 4).

**Retrospective impact assessment (既往结果回顾性评估)** — required review of prior results when equipment is later found defective, to decide whether result recall/reissue is needed (clause 6.4.5, linked to 8.7).

**risk management (风险管理)** — clause 5.6 (new in 2022 edition): documented process to identify and mitigate risks to patients across the whole pre-examination/examination/post-examination pathway, using probability × severity assessment (Ch3)

**Risk-based thinking (基于风险的思维)** — 2022-version emphasis requiring labs to identify risks to patient results at every process stage and act to minimize/prevent recurrence, replacing older standalone "preventive action" clause (Ch 5)

**run controls (阴/阳性对照、无模板对照、内标)** — positive, negative, no-template, internal controls per run (Ch 16)

**sample (样品) vs. specimen (标本)** — 标本 is the discrete portion of body material as originally collected; 样品 is one or more parts taken from a specimen and prepared for examination — a distinction affecting SOP wording for chain of custody (Ch1)

**Sample collection facilities (患者样品采集设施)** — space for specimen collection designed for patient privacy, comfort, safety and to avoid adversely influencing result quality (clause 6.3.5).

**Sample rejection criteria (标本拒收标准)** — Documented, discipline-specific conditions (mislabeling, wrong container/anticoagulant ratio, hemolysis, clotting, insufficient volume, transport delay/wrong temperature) that trigger rejection and requester notification (Ch 5)

**Service agreement (服务协议)** — a documented, periodically reviewed understanding (internal SLA or external contract) defining scope, turnaround time, and acceptance/rejection criteria for lab activities provided to users or by referral labs (clause 6.7.1).

**Sigma-metric QC design (西格玛质控设计)** — σ = (TEa − |bias|) / CV; used to right-size IQC rule stringency and frequency per test rather than applying uniform QC to all analytes (Ch 5)

**structure and authority (结构和权限)** — clause 5.4: lab activities must be organized/managed to safeguard impartiality; requires documented interrelationships, named authorities for MS development, corrective action, and stop-work decisions (Ch3)

**Supplier evaluation and reevaluation (供方评价与再评价)** — criteria-based selection, monitoring, and periodic reassessment of external providers, risk-tiered by criticality, with an approved-provider list maintained (clause 6.8.2).

**Surveillance Assessment (监督评审)** — periodic post-accreditation on-site checks during the validity period (标准4年一周期) confirming continued compliance.

**Turnaround time (周转时间, TAT)** — Defined target time from sample receipt/collection to result release per test/urgency tier; must be monitored with compliance data and corrective action on misses (Ch 5)

**turnaround time / TAT (检验周转时间)** — interval between test request/sample receipt and result release; monitored per test/urgency category as a quality indicator (Ch1)

**uni-directional workflow (单向工作流程)** — one-way people/material/air flow, pre- to post-amplification (Ch 16)

**validation (确认)** — confirmation through objective evidence that requirements for a specific intended use have been fulfilled; required for lab-developed tests (LDTs) or modified manufacturer methods (Ch1)

**Validation of examination procedures (检验程序的确认)** — Establishing performance characteristics from scratch for laboratory-developed (LDT), modified, or off-label-use procedures; covers a fuller parameter set including MU, analytical specificity, LoB/LoD/LoQ (Ch 5, clause 7.3.3)

**verification (证实/验证)** — confirmation through objective evidence that specified requirements have been fulfilled; required for unmodified manufacturer methods before first clinical use (Ch1)

**Verification of examination procedures (检验程序的验证)** — Confirming an unmodified procedure adopted from a manufacturer/published/reference source achieves its claimed performance before clinical use; lighter evidentiary burden than validation (Ch 5, clause 7.3.2)
