## Core Idea
Chapter 8 applies the general ISO 15189:2022 clauses (5 structure, 6 resources, 7 process, 8 management system) to the haematology discipline (routine blood-cell analysis, coagulation, ESR, morphology/blood-film review, reticulocytes, and special tests such as Hb electrophoresis/G6PD). The chapter's recurring theme: morphology is the discipline's unique risk — instrument flags alone cannot substitute for a validated, competency-assured microscopic review chain, so CNAS assessors specifically probe the personnel-competency → review-rule-validation → IQC/EQA → sample-retention audit trail as one connected accountability line.

## Discipline-Specific Requirements

**人员 (Personnel)**
- Lab must appoint a haematology group leader (专业组长) with discipline-specific qualifications/title and years of haematology experience, holding technical authority over method selection and morphology sign-off, distinct from the general lab director [clause 6.2].
- Staff performing microscopic blood-film/morphology review must have documented, morphology-specific competency assessment (image/slide-based practical test), not only general sign-off [6.2.5].
- Tiered qualification: routine analyzer operators < manual-morphology reviewers < report signers, each with rising title/experience thresholds; report signers require senior title plus multi-year haematology morphology experience.
- New staff serve a supervised probation period before independent morphology reporting; all morphology staff undergo periodic (commonly annual) re-assessment via reference-slide panels or inter-observer comparison [6.2.6].

**设施与环境 (Facilities & Environment)**
- Biosafety practice for blood specimen handling; dedicated, ergonomically lit microscope workstations for smear review to reduce reading error [6.3.2].
- Environmental monitoring (temperature logs for reagent/specimen storage), and separation of clean vs. specimen-handling areas.

**设备与试剂 (Equipment & Reagents)**
- Haematology analyzers verified/calibrated before use with traceability to manufacturer reference; backup instrument/method required for service continuity [6.4.2].
- Precision (repeatability) verified on installation and periodically for WBC/RBC/Hb/PLT/MCV using replicate testing.
- Carryover (携带污染率) verified against acceptance limit using high-then-low sample sequence.
- Inter-instrument/method comparability required when multiple analyzers or backup instruments are used: defined minimum paired-sample count spanning the measuring range, defined frequency, with correlation/bias acceptance criteria [6.4.7].
- Reagent lot-to-lot verification (new vs. old lot, using controls/patient samples) before clinical release [6.5.1]; Wright-Giemsa stain quality checked against control slides for each batch [6.5.2].

**检验前 (Pre-examination)**
- EDTA-K2/K3 tube fill-volume and mixing requirements; rejection for clots/under-fill/wrong tube.
- Citrate (1:9) coagulation tube fill-volume tolerance (±10%); rejection for under/over-fill, hemolysis, clots.
- CBC on EDTA whole blood: stable at room temperature for a limited window, longer refrigerated; blood film should be made soon after collection to avoid morphological artifact.
- ESR specimens must be tested within a short window after collection to avoid falsely altered results.

**检验中 (Examination)**
- New method validation (precision, accuracy, reportable range, reference interval) documented before clinical use [7.3.3].
- Laboratory must establish and locally validate a blood-cell-analyzer morphology review/reflex ("复检") rule set referencing internationally recognized criteria before adoption, and periodically re-verify (e.g., after major instrument/software change) [7.3.5].

**检验后 (Post-examination)**
- Two-tier report review (检验者 initial + 审核者 senior review), especially for abnormal/morphology reports [7.5].
- Morphology description required in report whenever review-rule criteria trigger manual smear review.
- Tested specimens and reviewed blood smears retained for a defined minimum period to allow retrospective/clinician-requested review.

**质量保证 (Quality Assurance)**
- Internal QC (IQC): analyzers ≥1×/day using 2-3 control levels (normal/abnormal high/low), Levey-Jennings/Westgard evaluation; coagulation tests QC'd on each working day; manual differential quality checked via periodic inter-observer comparison [7.4].
- EQA/PT: enrollment for all reported parameters (blood routine, coagulation, morphology via image-based PT), ≥2×/year; where no formal EQA exists, alternative inter-laboratory/split-sample comparison required [7.4].
- Critical values (危急值) list specific to haematology (e.g., extreme WBC/Hb/PLT abnormalities, blasts on peripheral smear) with defined notification timeliness and read-back confirmation.

## Frameworks Introduced
- **Blood-cell-analyzer morphology review/reflex rules (血细胞分析复检规则)**: laboratory establishes criteria — instrument flags, critical-value thresholds, first-time/demographic triggers — for escalating an automated CBC result to manual smear review, referencing internationally recognized consensus criteria (ISLH-style rule sets). When to use: every CBC result, continuously. How: adopt published criteria as a starting point, then run a local validation study (defined sample size, comparing manual-review outcomes against rule-triggered flags, tracking false-negative rate for critical morphology) before clinical use, and re-verify after major instrument/software changes [7.3.5].
- **Personnel competency tiering for morphology (形态学人员分级授权)**: routine operator → morphology reviewer → report signer, each tier requiring progressively higher qualification/experience and a practical (slide/image-based) competency test rather than theory alone. When to use: whenever staff independently identify or sign off cell morphology. How: define tier criteria in the quality manual, assess via direct observation/slide panels, re-assess periodically (e.g., annually) [6.2.5-6.2.6].

## Key Concepts
- **专业组长 (discipline group leader)** — designated technical authority for haematology, distinct from the general lab director, responsible for method decisions and morphology sign-off oversight. [6.2]
- **形态学复检规则 (morphology review/reflex rules)** — locally validated criteria for escalating automated results to manual microscopy. [7.3.5]
- **携带污染率 (carryover rate)** — cross-contamination between sequential samples on an analyzer; verified against an acceptance limit at installation and periodically. [6.4.7]
- **室内质控 (IQC)** — daily internal QC using multi-level controls with Levey-Jennings/Westgard rules. [7.4]
- **室间质评 (EQA/PT)** — external proficiency testing, ≥2×/year, covering all reported parameters including morphology recognition. [7.4]
- **危急值 (critical value)** — result requiring urgent, time-bound clinician notification with read-back confirmation.
- **比对 (comparability study)** — periodic paired-sample comparison across instruments/methods to confirm interchangeability. [6.4.7]
- **留样再检 (sample/slide retention)** — retaining tested blood specimens and reviewed smears for a defined period to enable re-analysis/review. [7.5]
- **批号验证 (lot-to-lot verification)** — parallel testing of new vs. old reagent/stain lot before clinical release. [6.5.1]

## Mental Models
- Use the "instrument flag is a question, not an answer" model when reviewing CBC results: any flag or review-rule trigger requires a validated human morphology decision, not automatic acceptance of the analyzer's differential.
- Use tiered authorization when assigning morphology work: never let a junior operator sign a report requiring senior-tier competency, even under time pressure.
- Treat comparability/carryover/precision verification as a lifecycle (install → periodic → after-maintenance), not a one-time gate, mirroring the equipment-lifecycle model used across other disciplines.
- When no formal EQA channel exists for a special test (e.g., Hb electrophoresis), default to a documented alternative comparison rather than skipping quality assurance.

## Anti-patterns
- **Adopting international review-rule criteria (e.g., 41-rule consensus) without local validation**: rules calibrated to another population/instrument may miss the lab's own critical morphology; a citable nonconformity if adopted verbatim without a validation study.
- **Signing morphology reports without a documented competency record**: even experienced-seeming staff must have a traceable assessment file; its absence is a standard finding during on-site review of the audit trail.
- **Single qualified morphology reviewer with no backup**: creates a TAT bottleneck and single point of failure; requires cross-training additional staff.
- **Treating blood-film preparation timing as flexible**: delayed smear-making distorts cell morphology (echinocytes, degeneration) and undermines the entire review-rule chain.

## Reference Tables

**Personnel competency tiers**
| Tier | Scope | Assessment method |
|---|---|---|
| Routine analyzer operator | Sample loading, instrument operation, basic QC | Standard 6.2 competence assessment |
| Morphology reviewer | Manual differential, RBC/platelet morphology | Practical slide/image-based test + periodic re-assessment |
| Report signer | Final sign-off on morphology reports | Senior title + multi-year experience + documented ongoing requalification |

**Equipment/method verification cycle**
| Activity | Trigger/frequency |
|---|---|
| Precision (repeatability) verification | Installation + periodic (e.g., scheduled interval) |
| Carryover verification | Installation + periodic |
| Calibration verification | Every defined interval (e.g., 6 months), after major maintenance/repair |
| Inter-instrument/method comparability | Periodic (e.g., ≥2×/year), minimum paired-sample count across measuring range |
| Reagent/stain lot verification | Every new lot, before clinical release |

**QC/EQA and sample-stability summary**
| Item | Requirement |
|---|---|
| IQC frequency | ≥1×/day, multi-level controls, Westgard/Levey-Jennings |
| EQA/PT frequency | ≥2×/year, all reported parameters incl. morphology PT |
| Critical value notification | Defined short timeliness window + read-back confirmation |
| CBC (EDTA) stability | Short room-temp window; longer if refrigerated |
| Blood film preparation | As soon as possible after draw to avoid artifact |
| Coagulation specimen | Citrate 1:9, fill-volume tolerance ±10% |
| Sample/slide retention | Defined minimum period post-report for re-review |

## Worked Example
*(Representative scenario, reconstructed from typical CNAS haematology nonconformity patterns — not a page-verified book case.)* An on-site assessment traced the haematology audit trail sequentially: group-leader qualification file → morphology reviewer competency records → IQC Levey-Jennings charts → EQA certificates → review-rule validation report → sample/slide retention log. Two gaps surfaced: (1) a morphology reviewer's competency file lacked a documented practical assessment (only a training attendance sheet), and (2) the lab had adopted international review-rule criteria without a local validation study. Both were raised as nonconformities under clause 6.2 (competence) and 7.3.5 (review-rule validation) respectively; corrective action required a retrospective practical assessment for the reviewer and a defined-sample-size local validation study comparing manual review outcomes against rule-triggered flags before continued use of the criteria.

## Key Takeaways
- Morphology competence must be practically assessed and tiered — theory training or tenure alone is insufficient documentation.
- Any adopted review/reflex rule set (international or in-house) must be locally validated and periodically re-verified, not used verbatim.
- Equipment precision, carryover, calibration, and comparability form a continuous lifecycle, not a one-time installation check.
- IQC and EQA must cover every reported parameter, including morphology, with a documented alternative when formal EQA is unavailable.
- Specimen/slide retention and blood-film timing directly protect the validity of the entire morphology review chain.
