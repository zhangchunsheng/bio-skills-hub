# Chapter 20: Worked Examples of the Application Form and Annexes (医学实验室认可申请书及附表填写范例)

## Core Idea
Chapter 20 takes every filling rule stated abstractly in Chapter 19 (§19.5-19.7) and shows it applied to a concrete sample laboratory, field by field. The organizing logic is traceability: the application form declares *who* is applying and *for what standard*; Annex 1 (附表1) and Annex 5 (附表5) declare *who* is competent to do the work and sign for it; Annex 2 (附表2) and Annex 6 (附表6) declare *what* is being tested (applied subset vs. full menu); Annex 3 (附表3) declares *how* compliance with every criterion clause is evidenced; Annex 4 (附表4) declares *proof* that results are externally verified. A correctly filled package is one where every item, person, and clause reference is mutually consistent across all six annexes.

## Process / Form Walkthrough

### 质量和能力认可申请书 (Main Application Form)
Fields and filling rules: **实验室名称/地址** — Chinese (and English) name and address of every site must exactly match the registered legal-entity/practicing-license documents; multi-site labs must list each site with its role (主场所/固定场所). **联系人** — a reachable contact with phone/email. **申请类别** — one of 初次申请/复评审/扩项/变更 must be selected (the worked sample selects 初次申请, first-time application). **申请认可依据的准则** — CNAS-CL02 plus every relevant CNAS-CL02-Axxx application note must be ticked to match the disciplines declared in Annex 2; ticking a note for a discipline with no corresponding Annex-2 items (or vice versa) is an internal inconsistency assessors will flag. **实验室简介** — establishment date, staffing, department structure, scope summary. **声明** — signed/stamped declaration of information accuracy and commitment to CNAS rules, impartiality, and confidentiality, signed by the legal representative/technical head with date.

### 授权签字人一览表 (Annex 1 / 附表1)
One row per authorized signatory: 姓名 (name), 职务/职称 (position/professional title), 学历/专业 (education/major), 从事相应专业工作年限 (years of relevant experience), 授权签字领域/项目范围 (authorized signing scope — specific items/disciplines), 签名样式 (specimen signature). Filling rule: the signing scope listed must fall strictly inside what that individual is personally qualified and experienced for; it is *not* automatically the lab's whole accredited scope. Every signatory here must also appear in Annex 5's full roster.

### 附表2 申请检验(检查)能力范围表 (Scope of Accreditation Table, bilingual)
Columns: 序号, 检验/检查项目名称 (Chinese name), 英文名称 (English name, standardized terminology), 检验方法/技术原理 (method/technology principle, e.g., 化学发光免疫分析法/PCR荧光探针法), 标准/依据 (reference standard or SOP), 专业/学科分类 (discipline code aligned to the CNAS-CL02-Axxx groupings). Filling rule: each item needs *both* language names, a real method actually validated/verified and in routine use (matching Ch.19's eligibility requirement), and exactly one discipline code — this code is what routes the item to the correct Axxx note and correct specialty assessor. Items are grouped by discipline in the worked example (临床化学, 临床免疫, 临床血液体液, 临床微生物 sub-tables) so the table's structure mirrors the assessment team's own specialty breakdown.

### 附表3 认可准则和应用要求自查表 (Self-Assessment Checklist)
Columns: 准则条款号 (clause number, referencing CNAS-CL02/ISO 15189:2022 numbering, e.g. 4.x/5.x/7.x), 条款内容摘要 (brief requirement summary), 实验室自查结果 (符合/不符合/不适用), 证明材料/文件编号 (evidence document/record reference). Filling rule: every clause of CL02 *and* every clause of each applicable Axxx note must get an entry — none skipped; any "不适用" must be justified; every "符合" must cite a real, retrievable document/record number, because this table is the assessors' starting map for what to pull and verify on-site.

### 附表4 能力验证计划/实验室间比对结果汇总表
Columns: 专业/项目 (discipline/item), 能力验证计划提供者 (PT/EQA provider, e.g., 国家卫生健康委临床检验中心), 计划编号/批次 (scheme/round ID), 参加日期 (date), 结果 (满意/不满意), and — where no scheme exists for an item — the alternative method used (实验室间比对/留样再测/参考物质比对). Filling rule: every single item on Annex 2 must appear here exactly once; a missing item, or an unsatisfactory result without documented corrective action, is treated as serious grounds to reject that scope item.

### 附表5 实验室人员一览表 (Personnel Roster)
Columns: 姓名, 性别/出生年月, 岗位/职务 (e.g., 技术负责人/质量负责人/授权签字人/检验员), 职称, 学历/学位/专业, 参加工作时间/从事本专业年限, 培训考核情况. Filling rule: must list *all* staff performing or supervising in-scope work, not only signatories; must stay internally consistent with Annex 1 (signatories are a subset); part-time/multi-site staff must have their actual working location(s) flagged.

### 附表6 实验室开展检验(检查)项目清单 (Full Test Menu)
Columns: 序号, 项目名称, 标本类型, 检测方法, 是否为申请认可项目 (Yes/No flag), 完成检测的场所 (if multi-site). Filling rule: this is the *complete* current menu — a superset of Annex 2 — so assessors can confirm the applied-for subset is a faithful, non-cherry-picked selection and that non-applied items are still transparently disclosed (supporting impartiality) rather than hidden.

## Frameworks Introduced
- **Applied-scope traceability chain**: 附表6 (full menu) ⊇ 附表2 (applied items, 1:1 name/method match) ↔ 附表4 (PT coverage, 1:1) ↔ 附表3 (clause evidence, per Axxx discipline) ↔ 附表1 (signatory authority) ⊆ 附表5 (full roster). When filling any one annex, cross-check it against this chain before submission — the most common self-inflicted problem is breaking one of these links (e.g., an Annex-2 item absent from Annex 4).
- **Discipline-code routing**: every Annex-2 item's discipline classification code determines which CNAS-CL02-Axxx note governs it and which specialty assessor reviews it on-site. Use this when unsure which application note's clauses apply to a given test method.
- **Personal-vs-lab scope principle**: an individual's authorized signing scope (Annex 1) is always bounded by *personal* qualification/experience, never simply inherited from the lab's overall accredited scope (Annex 2). Apply this whenever assigning or reviewing signatory authority.

## Key Concepts
- **English item name (英文名称)** — mandatory bilingual field in Annex 2 required for CNAS's bilingual accreditation scope certificate; must use standardized terminology.
- **Discipline classification code (专业/学科分类)** — the Annex-2 field linking each item to a CNAS-CL02-Axxx application note and a specialty assessor.
- **符合/不符合/不适用 (Conforms/Nonconforming/Not applicable)** — the three permissible self-check outcomes in Annex 3; "不适用" always requires written justification.
- **满意/不满意 (Satisfactory/Unsatisfactory)** — the two PT/EQA result outcomes recorded in Annex 4.
- **授权签字范围 (Authorized signing scope)** — the personally-bounded subset of the lab's scope a given signatory may sign reports for (Annex 1).
- **是否为申请认可项目 (Applied-for flag)** — the Annex 6 field distinguishing accreditation-applied items from the lab's other routine items.
- **实验室间比对/留样再测 (Inter-lab comparison / retained-sample retesting)** — the accepted Annex-4 alternative when no PT/EQA scheme exists for an item.

## Mental Models
- Think of the six annexes as one relational database, not six independent forms: every "key" (item name, person name, clause number) must resolve identically wherever it recurs.
- Use the discipline code in Annex 2 the way a filing system uses a folder label — it's the single field that determines which application note and which assessor touches that row.
- When filling Annex 1, think "can this specific person defend this specific item under questioning," not "is this item inside the lab's overall accredited scope" — the two are different tests.

## Anti-patterns
- **Mismatched names/methods between Annex 2 and Annex 6**: an item's Chinese/English name or method differing between the applied-scope table and the full menu creates doubt about which is the "real" method actually in use.
- **Discipline code that doesn't match the ticked application notes on the main form**: causes the wrong specialty assessor to be assigned or an ungoverned item to slip through.
- **Annex 3 entries marked 符合 without a real evidence reference**, or clauses silently skipped: assessors treat this as a red flag prompting deeper on-site scrutiny.
- **Annex 4 missing an Annex-2 item, or showing 不满意 with no documented corrective action**: treated as serious grounds to reject that specific scope item.
- **Signatory's Annex 1 scope exceeding their personal experience/qualification**: fails even if the lab as a whole is competent in that area.
- **Annex 5 roster inconsistent with Annex 1** (a listed signatory missing from the full roster, or vice versa): undermines confidence in the personnel data as a whole.

## Worked Example — filling Annex 2 (附表2) for one item
Scenario: the sample lab adds "血清肌酐" (Serum Creatinine) to its applied scope.
1. **序号**: assign the next sequential row number within the 临床化学 (Clinical Chemistry) discipline block.
2. **中文名称**: "血清肌酐" — must match the name used in Annex 6's full menu exactly, character-for-character.
3. **英文名称**: "Creatinine, Serum" (or the lab's CNAS-consistent standardized English term) — must not be a literal ad hoc translation.
4. **检验方法/技术原理**: "酶法" or the specific technique actually validated (e.g., enzymatic method on the lab's chemistry analyzer) — must match what Annex 3's method-validation evidence and the routine SOP describe.
5. **标准/依据**: cite the actual reference method/instrument manual or in-house SOP number used for validation.
6. **专业/学科分类**: "临床化学" — this single code determines that CNAS-CL02-Axxx (临床化学检验领域应用说明) governs this row and that a clinical-chemistry specialty assessor will review it.
7. Cross-check before submission: confirm "血清肌酐" also appears in Annex 4 with a 满意 PT result (or documented alternative) and in Annex 6 flagged 是否为申请认可项目 = 是 (Yes) — any mismatch here is what the traceability chain (see Frameworks) is designed to catch.

## Key Takeaways
- Every annex is a view onto the same underlying dataset (people, items, clauses) — fill them so the same entity looks identical everywhere it appears.
- Bilingual, discipline-coded item naming in Annex 2 is not cosmetic — the discipline code is the operational key that assigns the correct application note and assessor.
- Annex 1's signing scope is a per-person qualification test, distinct from the lab's overall accredited scope in Annex 2.
- Annex 3 is not a formality — every clause needs a real, checkable evidence reference, because it is literally the assessors' on-site verification checklist.
- Annex 4 must give 1:1, item-level proof of external result verification for everything the lab is asking to be accredited for.
