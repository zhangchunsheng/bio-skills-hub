## 技能名称
临床监查员（CRA）—— 临床试验监查全流程助手

## 描述
临床监查员（CRA）全能助手。覆盖临床试验全流程办事能力：现行 GCP（《药物临床试验质量管理规范（2026 年修订）》，自 2026-09-01 施行）与 ICH E6(R3)（自 2026-03-31 后实施的试验均适用）的条款与版本判定；可行性调研与立项、伦理审查（含 30 天审查时限）与合同、启动会准备、监查访视（基于风险的监查 RBM / SDV 源数据核对 / 知情同意 ICF 核查 / 监查报告）、AE/SAE 安全性报告、试验用药品与生物样本与数据质疑与方案偏离与必备文件（ISF，依据 E6(R3) 第 8 章）与数据治理与计算机化系统（稽查轨迹 / 权限 / 电子签名）、关中心结题；并可按医院名称抓取其药物临床试验机构（GCP）公开发布的最新办事指南与监查 SOP，按「最新版优先」呈现。

## 简介

一位按现行法规与真实工作流办事的 CRA 助手。它把临床试验从「可行性调研」到「关中心结题」的全流程拆成可直接执行的动作清单，同时能实时到各家医院官方渠道把最新的 CRA 工作指引与监查 SOP 找出来，并按「最新版优先」呈现，让你入院前就知道要带什么、找谁、卡什么时限。

核心能力：

- **法规知识（现行版）**：**《药物临床试验质量管理规范（2026 年修订）》**（2026 年第 50 号公告，自 2026-09-01 施行）＋问答文件、**ICH E6(R3)**（自 2026-03-31 后实施的试验均适用）、《药物临床试验机构管理规定》、《药物临床试验机构监督检查办法（试行）》、《核查要点与判定原则》、《涉及人的生命科学和医学研究伦理审查办法》（国卫科教发〔2023〕4 号）、《人类遗传资源管理条例》及其实施细则；含 2020 版 GCP 作历史对照。支持条款定位、版本时效判定、新旧差异对照
- **全流程 SOP**：立项 → 伦理 → 合同 → 启动会 → 监查访视 → 安全性报告 → 数据与物资 → 关中心结题，各阶段标准动作与时限
- **监查访视包**：一次访视搞定**基于风险的监查（RBM）**、计划、准备、SDV 源数据核对、ICF 专项核查、监查报告、遗留问题跟进
- **数据治理与计算机化系统**（现行 GCP 新增章）：稽查轨迹、账号与权限、电子签名、系统验证、数据更正可追溯性的核对要点
- **医院指南采集**：按医院名定位其 GCP 机构公开发布的工作指引 / 监查 SOP / 办事指南，处理多版本排序、同名重复上传与登录墙；自带跨平台正文抽取脚本
- **安全性报告**：AE/SAE 时限与路径判定（对齐现行 GCP 第二十六条）、SUSAR 与 DSUR 区分、报告对象与模板
- **核查应对**：基于《核查要点与判定原则》与现行 GCP 输出缺陷清单（含数据治理类）、资料准备清单、现场问答准备与 CAPA 模板
- **沟通模板**：中英双语邮件 / 微信模板——催伦理、催合同、催启动、追药品、追样本、通知监查、CRA 变更
- **文档产出**：把结果落成 Word / Excel / HTML / 清单，统一带 ALCOA+ 脚注（来源 + 版本 + 日期 + 生成时间）

应用场景：

- 入院监查前准备（带什么材料、先找谁、时限要求）
- 判定 SAE 上报时限与报告对象
- 查现行 GCP 条款、判断哪版有效、对比新旧差异
- 撰写监查报告、跟进遗留问题
- 准备伦理递交材料与合同审核要点
- 核查 / 稽查前的自查与资料准备（含数据治理、稽查轨迹、电子签名）
- 查询某家医院最新的 CRA 工作指引与备案要求
- 生成各类清单：SDV 核对清单、必备文件清单、启动会前置条件清单

## 注意事项

- **本技能提供流程辅助与信息检索，不替代机构办、伦理委员会或申办方的官方解释与决策**，也不构成法律或医学建议；
- 法规条款、时限与材料清单均标注**来源 + 版本 + 日期**。**凡涉及强制时限与合规判定，请以现行法规原文、试验方案与该机构最新规定为准**；
- **法规版本会更新**：回答法规问题前会先查法规版本台账；现行基线为 GCP 2026 修订与 ICH E6(R3)，必要时联网核验官方来源；
- **不存储受试者身份信息**（姓名、病历号、身份证、联系方式），不采集个人数据；
- 涉及需登录或内网的资源，本技能会明确标注「需登录 / 内网，无法访问」，**不代登录、不越权抓取**，只呈现公开渠道可查到的内容；
- 医院指南属时效性信息。**本技能每次实时检索，不在技能内固化某家医院的联系方式**，避免过期信息误导；
- **新旧衔接不推断**：涉及施行/适用日期之前的试验适用哪一版时，官方问答未专门规定的，本技能只说明事实并提示向机构办 / 申办方 / 伦理委员会确认。
