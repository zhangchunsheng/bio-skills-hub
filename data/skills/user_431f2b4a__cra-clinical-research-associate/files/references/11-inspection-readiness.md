# R1 · 核查应对包

## 一、准备阶段（核查前）

1. **范围确认**：核查对象（机构/专业组/项目）、依据（《药物临床试验核查要点与判定原则》**现行版本**、《药物临床试验机构监督检查办法（试行）》**现行版本**、**GCP 2026（含第五章数据治理）**、**E6(R3)（必备文件第 8 章等）**）、时间与形式。
2. **资料准备清单**：ISF 齐备性与版本一致性、ICF 签署、源数据可溯源、AE/SAE 记录与上报、药品与样本记录、数据质疑闭环、合同与伦理批件。
3. **一致性自查**：CRF ↔ 源文件 ↔ 数据库 ↔ 监查报告，四处对齐。
4. **模拟问答**：准备高频问题与标准答法（见下）。

## 二、常见缺陷清单（分类）

| 类别 | 典型缺陷 |
|---|---|
| 知情同意 | 先检查后签署；版本错误；签字/日期缺失；更新后未重新知情 |
| 源数据 | 不可溯源；修改无痕迹；ALCOA 不符；源文件缺失 |
| CRF 与数据 | CRF 与源文件不一致；质疑长期未闭环 |
| **数据治理**（GCP 2026 新增章） | **稽查轨迹**缺失/不可读；共享账号或权限与授权分工表不符；**电子签名**不合规；数据更正无留痕；系统未验证；备份/故障应急缺失；系统间传输的电子数据（含元数据）无经验证流程 |
| 试验用药品 | 温控缺失/超温未处理；账实不符；破盲记录不全 |
| 安全性 | SAE 漏报/超期；判定不当；随访缺失；**未按 GCP 2026 第二十六条向伦理审查委员会直接书面报告 SAE** |
| 文件 | ISF 不齐（**依据 E6(R3) 第 8 章**）、版本失效、培训记录缺失、授权分工表不符 |
| 监查 | 报告超期；遗留问题未闭环；未按监查计划执行；**未体现基于风险的监查（RBM）逻辑** |

## 三、现场问答准备

- 覆盖：方案关键点、入排执行、知情同意流程、AE/SAE 判定与上报、药品管理、数据流程、监查执行。
- 原则：**据实作答、不推测、不承诺**；不确定时说"我去核对后回复"并记录。

## 四、CAPA 模板

```
【问题】<核查发现的缺陷描述>
【依据】<核查要点条目 / 法规条款 / 机构规定>
【根因分析】<为什么发生：流程？培训？人力？工具？>
【纠正措施】<立即纠正动作 + 责任人 + 期限>
【预防措施】<防止再发的机制：SOP 修订 / 培训 / 核查点前置>
【验证方式】<如何证明已闭环>
```

## 五、输出形态

- 核查准备清单（分级：必备 / 建议 / 可选）
- 常见缺陷自查表（Y/N + 风险等级）
- 现场问答准备与模拟问答脚本
- CAPA 模板（可交付）

## 边界与红线

- 只做**判定辅助 + 给依据**，**不替用户下"是否构成缺陷"的最终结论**——终裁归监管/机构。
- 不指导隐瞒、规避核查或伪造材料。
- 发现重大合规风险 → 触发**受试者守护红线**，明确提示上报与整改路径。
