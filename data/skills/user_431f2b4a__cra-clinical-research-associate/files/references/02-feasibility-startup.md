# W1 · 可行性调研与立项

## 一、可行性调研 / 中心选择

**评估维度（逐项给判断依据，不替用户拍板）：**

| 维度 | 关注点 | 需要向谁确认 |
|---|---|---|
| 疾病与病人量 | 目标适应症患者量、门诊/住院比例 | 科室 PI / 研究护士 |
| 入组潜力 | 历史类似试验入组速度、竞争试验数量 | PI / 机构办 |
| 研究者意愿与经验 | 是否有 GCP 经验、是否有足够人力 | PI |
| 设备与资质 | 检验科资质、影像、样本处理能力、专业组备案 | 机构办 / 相关科室 |
| 合规与条件 | 伦理效率、合同周期、是否需遗传办 | 机构办 / 伦理 |

**输出**：可行性调研评估表（维度 / 现状 / 风险 / 待确认项），必要时生成调研表草稿。

## 二、立项

**标准动作：**
1. 先读该院**最新立项流程**（→ `references/10-hospital-guide.md`），按院准备材料。
2. 常见材料骨架（**以该院清单为准**）：立项申请表、方案摘要、研究者简历与 GCP 证书、CRA/CRC 备案材料（委托函、GCP 证书、简历、学历证明、身份证复印件，均按院要求盖章）、保险或经费预算证明。
3. 提交 → 机构办资格审查 → 取得《立项审批表》。
4. 记录**联系人、邮箱、递交方式与时限**（多家机构要求先平台提交电子版、再交纸质）。

## 三、监查计划（常被忽略，但多院在启动会前要求提交纸质版）

**计划应包含：**
- 监查频率与首次监查时点（多数机构要求**首例受试者入组后**首次监查）
- **基于风险的监查（RBM / RBQM）** 要点：关键数据、关键流程、已识别的风险点与对应监查动作
  - **依据（现行）**：GCP 2026 第四十条（基于风险、**符合目的、与复杂性和风险相称**）、第四十一条（**监查和数据管理是主要的质量控制活动**；稽查独立于常规监查）、第四十二条（申办者应进行**风险管理**）；ICH E6(R3) 以 RBQM 为核心。
- 监查方式（现场 / 中心化 / **远程**——远程须经方案或监查计划允许）、每次访视的核查范围
- 报告与跟进机制（报告时限、提交对象、遗留问题闭环）
- 与机构办/伦理的沟通机制
- 数据治理相关安排：稽查轨迹、账号与权限、电子签名、系统验证（见 `references/07-data-supplies.md` 子模块 6）

## 输出形态

- 可行性评估表 / 中心选择建议（含风险与待确认项）
- 立项材料清单（标注"院内要求"或"通用口径"）
- 监查计划草稿（可交机构办）

## 边界

- 只给**标准动作与清单**，不引具体医院要求（引 `references/10-hospital-guide.md`），不自造法规条款（引 `references/01-gcp-knowledge.md`）。
- 中心选择属**商业与科学判断**，只给评估框架与依据，**不替用户下最终结论**。
