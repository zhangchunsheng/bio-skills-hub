# R2 · 沟通模板库

CRA 真实主战场是沟通——催伦理、催合同、催启动、追药品、追样本、追质疑。本技能提供**直接可用的中英双语模板**，并按院校/机构语境调整语气。

## 模板库

参考 `references/shared/communication-templates.md`（含 10+ 场景的中英模板）。覆盖：

| 场景 | 关键要点 |
|---|---|
| 伦理递交跟进 | 项目名 + 方案号 + 递交日期 + 请求进度 + 致谢 |
| 伦理批件催办 | 说明时间压力与影响，礼貌但明确 |
| 合同推进 | 明确卡在哪个环节、需要谁做什么 |
| 启动会安排 | 候选时间、参会人、需机构提供什么 |
| 药品/物资催办 | 需求清单 + 期望到货时间 |
| 样本寄送跟进 | 样本类型、批次、温控要求、接收确认 |
| 数据质疑催复 | 质疑编号清单 + 期望回复时限 |
| 监查预约 | 拟访视日期、需准备资料、请确认 |
| 监查报告提交 | 按院内命名与提交方式 |
| CRA 变更通知 | 原/新任 CRA、交接安排、请机构配合备案 |
| SAE 通知（如适用） | 事件概要、报告路径与时限（**注意隐私**） |

## 生成规则

1. **先取语境**：若已知道项目/医院/联系人，直接带入；未知则留占位符 `[项目名称]` 并提示可替换。
2. **语言**：默认中文；涉外申办方或用户要求时出中英双语。
3. **语气**：专业、礼貌、明确；**目标导向**（说清"需要对方做什么 + 期望时间"）。
4. **简洁**：一封信一个诉求，正文不超过 5 段。
5. **不写入受试者可识别信息**。

## 输出形态

- 主题行（Subject）
- 正文（可直接复制）
- 抄送建议
- 可选：更温和 / 更正式两个版本

## 边界

- 只产**沟通文本**，不产生新事实（不替用户编造进度或承诺）。
- 涉及 SAE/合规事项的表述，先由 `references/06-safety-reporting.md` / `references/01-gcp-knowledge.md` 确认路径再落笔。
