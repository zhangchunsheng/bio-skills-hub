# 共享底座

本文件是本技能的**单一事实源**。其余参考文件不重复维护清单与时限，一律引用这里。

> **法规基线（2026-09-12 起）**：现行中国 GCP 为 **《药物临床试验质量管理规范（2026 年修订）》**（2026 年第 50 号公告，**自 2026-09-01 施行**；2020 版公告已废止）；ICH **E6(R3)** 自 **2026-03-31 后**实施的试验均适用。凡涉及版本时效，以 `references/shared/regulation-ledger.md` 为准。

## 1. 三档分源定义

回答任何一条结论时，必须归入且只归入下列一档，并显式标注：

| 档位 | 定义 | 例 |
|---|---|---|
| **法规强制要求** | 来源于**现行**中国《药物临床试验质量管理规范（2026 年修订）》、ICH E6(R3)、《药物临床试验机构管理规定》《药物临床试验机构监督检查办法（试行）》《核查要点与判定原则》、《涉及人的生命科学和医学研究伦理审查办法》（国卫科教发〔2023〕4 号）、《人类遗传资源管理条例》及其实施细则等 | "研究者获知 SAE 后应立即向申办者和伦理审查委员会书面报告" |
| **医院机构规定** | 某家医院机构办/伦理委员会发布的办事指南、SOP 中的要求（来自采集技能） | "某院要求监查报告 5 个工作日内提交" |
| **行业惯例** | 无明确法规/机构依据，但业内普遍做法 | "监查前一周预约" |

**冲突时的效力顺序**：法规强制 > 医院机构规定 / 本地约定 > 行业惯例。机构/公司要求**严于**法规 → 照办；**低于或异于**法规 → **以法规为准并警示**。

## 2. 事实卡结构（跨技能统一数据格式）

各模块之间传递事实时，统一用下列"事实卡"，避免各写各的：

```
【事实卡】
- 结论：<一句话结论>
- 档位：法规强制 / 医院机构规定 / 行业惯例
- 来源：<法规名称+条款号 | 医院名称+文件标题+链接>
- 版本：<版本号 / 发布日期>
- 时效：现行 / 待核验 / 已知过期
- 适用范围：<通用 | 某院 | 某项目>
- 待确认：<无 | 需向机构办/伦理/sponsor 确认什么>
```

## 4. 使用规则

- 回答法规问题前，**先查 `references/shared/regulation-ledger.md`**：若台账标记"待核验"或用户问"最新"，先联网核实版本，再作答。
- 引用时限/清单时，**默认附"以现行法规与方案为准"**，不得把通用口径说成方案规定。
- 找不到依据时，直说"未检索到对应条款/文件"，**不臆造条款号与时限**。
