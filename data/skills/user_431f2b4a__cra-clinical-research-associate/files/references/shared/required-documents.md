# 临床试验必备文件清单（通用骨架）

> **依据（重要）**：**ICH E6(R3) 第 8 章「必备文件」**。《药物临床试验质量管理规范（2026 年修订）》**已删除原「必备文件管理」章**，官方问答明确"相关内容具体执行参照 **E6(R3) 中文版**"。因此：**清单本身继续有效，但引用依据应挂 E6(R3)，不要再挂 2020 版 GCP 的必备文件章节。**
>
> 用途：帮助 CRA 快速核对"该有什么"。**具体份数与名称以本机构《必备文件目录》与方案为准。**

## 一、按保存方分组

**研究者 / 中心（ISF，研究者文件夹）**
- 研究者简历（CV）、GCP 培训证书、执业资质
- 授权分工表（Delegation Log）、培训记录
- 方案及其修正案、研究者手册（IB）及更新
- 伦理批件、知情同意书（ICF）各版本、伦理递交与审查记录
- 试验用药品（IP）接收/发放/回收/销毁记录、温控记录
- 生物样本采集、运送、温控、销毁记录
- 源文件、CRF、数据质疑与回复
- AE/SAE 记录与上报凭证
- 受试者筛选与入组登记、访视记录
- 监查记录（监查访视登记、监查报告/跟进函）
- 方案偏离记录与上报
- 沟通记录（与申办方/CRO 的往来函件）

**申办方 / CRO（TMF，试验主文件夹）**
- 方案、IB、ICF 模板、CRF
- 合同与财务协议、保险证明
- 法规事务文件、监管批件
- 监查计划、监查报告、跟进函
- 安全性报告（SUSAR、DSUR、年度报告）
- 统计与分析文件、最终报告
- 中心关闭与归档文件

**机构办公室 / 伦理委员会（行政夹、伦理夹）**
- 立项材料、立项审批表
- 合同（三方协议）
- CRA/CRC 备案材料（委托函、GCP 证书、简历、学历证明、身份证复印件）
- 伦理递交信、审批件、年度进展报告
- 遗传办（如涉及）批件/备案

## 二、按阶段核对（CRA 视角）

| 阶段 | 关键齐备项 |
|---|---|
| 立项 | 立项资料、CRA 备案材料、委托函 |
| 伦理 | 递交信、方案/ICF、审批件 |
| 合同 | 三方协议、经费预算、保险 |
| 启动前 | IP/物资到位、首款、培训记录、启动会材料 |
| 进行中 | 源文件、CRF、ICF、AE/SAE、药品与样本记录、监查报告 |
| 结题 | 数据清理、锁库、IP 销毁、归档清单、经费结算 |

## 三、使用提示

- 各院对**份数、命名、递交方式**要求不同 → 取该院最新办事指南（`references/10-hospital-guide.md`）。
- 归档保存年限：药物临床试验通常至试验终止后 5 年、器械 10 年（**以本机构规定为准**）。
