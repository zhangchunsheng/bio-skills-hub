# W2 · 伦理审查与合同签署

## 一、伦理审查

> **法规依据（现行）**：《涉及人的生命科学和医学研究伦理审查办法》（**国卫科教发〔2023〕4 号**，国家卫生健康委等四部门 2023-02-18 印发）。要点：伦理审查委员会**应在受理材料后 30 天内**开展伦理审查并出具审查意见，情况紧急的应及时审查；**多机构研究可适用简易程序**（参与机构对牵头机构审查意见的确认）。GCP 2026 修订亦要求伦理审查委员会的工作应符合卫生健康主管部门有关规定，并加强对**特殊群体、知情同意、严重持续不依从**问题的审查。

**标准动作：**
1. 取该院**最新伦理递交要求**（→ `references/10-hospital-guide.md`）：份数、格式、递交方式、审查会议时间。
2. 准备递交材料骨架（**以该院清单为准**）：伦理递交信、方案、知情同意书（ICF）、研究者手册（IB）、CRF、研究者资质、保险证明、招募材料。
3. 跟进审查进度、领取**伦理批件**，核对批件信息（方案版本号、ICF 版本、有效期）。
4. 修正案：及时递交并取得批准，**未获批前不得执行**。
5. 年度/定期报告：按伦理要求提交进展与安全性更新。
6. **多中心项目**：优先确认能否走**简易程序/审查结果互认**（依 〔2023〕4 号办法），可显著压缩周期——但**以该院伦理委员会是否采纳为准**。

**关键红线：**
- 受试者**签署的 ICF 版本必须与伦理批准的现行版本一致**；版本更新后须重新知情同意（符合条件时）。
- **伦理批件在合同签订之前**是常见要求；合同签署通常须在取得伦理批件后进行。

## 二、合同（三方协议）

**标准动作：**
1. 确认模板来源：**有些医院用申办方/CRO 模板，院方不提供**（需先核实该院规定）。
2. 与 PI 洽谈 → 机构办审核 → 定稿。
3. 与伦理并行推进可行，但**签订须在伦理通过之后**（以该院流程为准）。
4. 核对要素：试验名称与方案号、双方/三方主体、经费预算与支付节点、保险、知识产权、终止与赔偿条款、协议有效期。

**输出**：合同要素核对表 + 待确认条款清单。

## 三、遗传办（人遗办 HGRAC）备案

**触发条件**：涉及**人类遗传资源**采集、保藏、利用、对外提供（含国际合作）的试验。

**依据（现行）**：《中华人民共和国人类遗传资源管理条例》＋《**人类遗传资源管理条例实施细则**》（**科学技术部令第 21 号**，2023-05-26 公布，**自 2023-07-01 起施行**，共七章七十八条）。

> **关键定义**：人类遗传资源信息指"利用人类遗传资源材料产生的**人类基因、基因组数据**等信息资料"，**不包括临床数据、影像数据、蛋白质数据和代谢数据** —— 判断是否需要办理时先按此界定。

**标准动作：**
1. 判断是否需要**审批 / 备案 / 事先报告**：
   - **为取得上市许可、在临床医疗卫生机构开展国际合作临床试验、且人类遗传资源材料不出境的 → 不需要批准，但应在开展前向科技部备案**（实施细则第三十二条）；属探索性研究部分则需申请国际科学研究合作行政许可。
   - 向境外提供或开放使用人类遗传资源信息的 → 需**事先报告并提交信息备份**；符合特定情形（如人数 > 500 例的外显子组/基因组测序信息资源等）需**安全审查**。
   - **多中心研究不得拆分申请**；组长单位通过伦理审查后即可由申办方或组长单位申请/备案（第三十四条）。
2. 准备：申请/备案材料、方案与知情同意书（含人遗条款）、合作方材料；**须通过已备案伦理委员会的伦理审查**。
3. 与伦理、机构办、申办方同步推进——**这是最容易卡进度的环节，宜早启动**。
4. 审批/备案有效期届满后 6 个月内，应共同向科技部提交合作研究情况报告。

## 输出形态

- 伦理递交材料清单（标"院内要求/通用口径"）
- 合同要素核对表 + 风险条款提示
- 遗传办办理路径与时间线

## 边界

- 只给流程与清单；具体模板与递交要求取该院最新指南。
- 合同**法律条款**的最终判断归法务；本技能只做要素核对与风险提示，并给出"该找谁确认"。
