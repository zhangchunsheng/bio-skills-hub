# W3 · 启动会准备

## 一、前置条件核对（逐项确认，缺一项即提示）

常见前置条件（**以该院最新要求为准，多数机构要求"齐备才可启动"**）：

| # | 前置条件 | 确认方式 |
|---|---|---|
| 1 | 伦理批件已取得 | 核对批件与现行方案/ICF 版本 |
| 2 | 遗传办文件（如涉及）已取得 | 见 `references/03-ethics-contract.md` |
| 3 | 合同/三方协议已签署、**首款到账凭证** | 财务或机构办确认 |
| 4 | 试验用药品/器械已完成省局备案（如适用） | 机构办 / 药房 |
| 5 | 试验物资到位（CRF、温度计、离心机耗材等） | 现场清点 |
| 6 | 研究者培训已完成、授权分工表已签 | 核对名单与实际参研人员 |

## 二、启动会材料与内容

**材料**：方案摘要、IB/研究者手册更新、ICF、CRF 与填写指南、源文件与 ALCOA 要求、AE/SAE 报告流程、试验用药品管理与温控、生物样本流程、监查计划、授权分工表、签到表。

**培训内容**：方案关键点（入排、终点、给药）、知情同意流程、源数据与 CRF 一致性、AE/SAE 判定与上报时限与路径（**含 GCP 2026 第二十六条"立即向申办者和伦理审查委员会书面报告所有 SAE"**）、方案偏离定义、原始记录要求、药品与样本管理、**数据治理要求（稽查轨迹、账号一人一号与权限、电子签名，依 GCP 2026 第五章）**。

## 三、启动会执行与留档

1. 确认参会人员（PI、研究者、护士、药师、CRC、CRA）。
2. 组织培训 → 答疑 → 签署**授权分工表**与**培训记录/签到表**。
3. 留档：签到表、培训记录、授权分工表、会议纪要（含未决问题与责任人）。
4. 未决问题列入跟进清单（可交由 M2 待办跟踪）。

## 输出形态

- 启动会前置条件核对表（Y/N + 未满足项的解决路径）
- 启动会材料清单与培训提纲
- 启动会记录模板

## 边界

- 只出标准动作与清单；院内具体要求取 `references/10-hospital-guide.md`。
- 只提示"条件是否齐备"，**是否可启动由机构与 PI 决定**——给路径不代庖。
