# O1 · 文档产出

## 职责

把上游技能产出的**结果**转成用户可直接使用的文件。**只做呈现，不产生任何新事实。**

## 输出格式选择

| 场景 | 建议格式 |
|---|---|
| 流程说明、报告正文 | Word（.docx） |
| 清单、对比表、逐项打勾表 | Excel（.xlsx） |
| 快速查看、网页分享 | HTML |
| 聊天内即时查看 | Markdown（直接回复） |

**默认**：先用文字（Markdown）给结果；用户要文件时再问要哪种格式。**不主动追问，不增加摩擦。**

## ALCOA+ 脚注（强制）

每份产出物**必须**在末尾附脚注，使其符合稽查档案要求：

```
---
来源：<法规/医院指南/公司模板 的名称与链接>
版本：<版本号 / 发布日期>
生成时间：<YYYY-MM-DD HH:MM>
说明：本文件由 AI 辅助生成，内容需经 CRA 复核后使用；不替代机构官方解释与伦理/机构决策。
```

> 多来源融合的产出（如 院内要求 + 公司模板），脚注须**逐项标注来源**，不能只给一条笼统脚注。

## 复用现有能力

优先复用运行环境已有的文档/表格能力生成 .docx / .xlsx；需要网页时直接写 HTML。
**若相关能力不可用（未安装 / 调用失败），降级为 Markdown 直接回复，并说明"可复制到 Word/Excel 使用"，不要因此中断交付。**

## 边界

- **不产生新事实**：不改数、不补内容、不调整判定结论。
- 不在产出中写入受试者可识别信息。
- 产出完成后提醒用户核对内容是否准确。
