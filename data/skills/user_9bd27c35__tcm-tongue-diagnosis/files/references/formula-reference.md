# 常用经方速查与辨证要点

## 1. 甘草泻心汤（《伤寒论》第158条）

**组成**：生甘草、黄芩、黄连、干姜、半夏、大枣、人参/党参
**主治**：寒热错杂痞，心下痞硬而满，干呕，心烦不得安
**加减要点**：
- 热象重（点刺>0.1）：黄芩黄连可增至9g/6g
- 寒象重（齿痕深+苔白滑）：干姜可增至9g
- 脾虚甚（齿痕>0.3+气血亏）：党参增至15g
- 湿重（苔腻>0.3）：加茯苓15g

## 2. 参苓白术散（《太平惠民和剂局方》）

**组成**：人参/党参、白术、茯苓、山药、莲子肉、白扁豆、薏苡仁、砂仁、桔梗、甘草
**主治**：脾虚湿困证，食少便溏，四肢乏力，面色萎黄
**加减要点**：
- 湿重：加厚朴9g、陈皮12g
- 寒象：加干姜6g
- 食欲差：加神曲12g、山楂10g
- 腹胀：加木香6g

## 3. 补中益气汤（《内外伤辨惑论》）

**组成**：黄芪、人参/党参、白术、炙甘草、当归、陈皮、升麻、柴胡
**主治**：脾胃气虚，中气下陷
**使用时机**：舌苔退后方可介入，过早升提可能导致上壅

## 4. 半夏泻心汤（《伤寒论》第149条）

**组成**：半夏、黄芩、黄连、干姜、人参/党参、大枣、甘草
**主治**：寒热错杂之痞证

## 5. 附子理中丸 / 四逆辈（禁忌提醒）

**适应症**：纯寒证（齿痕深+寒热指数明显负值+无点刺+无口疮史）
**禁忌症**：任何点刺指数>0或有口疮反复发作史，**禁用附子、干姜大剂量**
