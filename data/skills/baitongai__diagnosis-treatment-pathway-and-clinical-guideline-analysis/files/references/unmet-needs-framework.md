# 未满足临床需求识别框架

## Safdar 分类法

将未满足的临床需求分为五个维度：

### 1. 治疗空白（Therapeutic Gap）

- **定义**：尚无标准治疗方案或指南推荐的临床场景
- **识别方式**：查找指南中标注"尚无标准方案""正在探索中""证据不足"的节点
- **示例**：特定罕见突变亚型无靶向药、某种分期组合无明确推荐方案
- **商业价值**：极高 — 首个进入空白领域的药物享有先发优势

### 2. 疗效不足（Efficacy Gap）

- **定义**：现有标准治疗方案疗效不充分（缓解率低、PFS/OS 短）
- **识别方式**：分析现有方案的 ORR、PFS、OS 数据，识别疗效天花板
- **示例**：铂耐药卵巢癌、难治性 SCLC、KRAS G12C 经治患者
- **商业价值**：高 — 疗效提升是说服医生换药的最强动力

### 3. 安全性问题（Safety Gap）

- **定义**：现有方案毒副作用显著，影响患者依从性或治疗连续性
- **识别方式**：分析现有方案的不良反应谱（≥3级 AE 发生率）
- **示例**：含铂方案的肾毒性/神经毒性、免疫治疗的 irAE
- **商业价值**：中-高 — 安全性是差异化定位的重要维度

### 4. 便利性问题（Convenience Gap）

- **定义**：给药方式不便（频繁住院、输液时间长、口服依从性差）
- **识别方式**：分析现有方案的给药频率、给药方式、治疗周期
- **示例**：从每周输液改为每 3 周或每 4 周给药、皮下注射替代静脉输液
- **商业价值**：中 — 便利性是患者和医生换药的现实因素

### 5. 成本问题（Cost Gap）

- **定义**：现有方案经济负担重或医保覆盖不足
- **识别方式**：分析年治疗费用、医保报销比例、患者自付比例
- **示例**：罕见病天价药、需长期用药但未纳入医保
- **商业价值**：视场景而定 — 在医保谈判和准入场景中尤为重要

## 产品策略锚点

### 锚点识别流程

1. 梳理诊疗路径中每个决策节点
2. 对每个节点评估五维需求缺口
3. 结合产品特征，匹配可切入的锚点
4. 设计医学叙事方向

### 叙事方向模板

| 需求缺口类型 | 叙事方向示例 |
|-------------|-------------|
| 治疗空白 | "填补 XX 亚型无标准治疗的空白" |
| 疗效不足 | "相比现有标准方案，显著延长 PFS/OS" |
| 安全性问题 | "在保持疗效的同时，显著降低 X 级 AE" |
| 便利性问题 | "每 4 周一次给药，大幅减少就医次数" |
| 成本问题 | "相比现有方案，年治疗费用降低 X%" |

### 策略锚点优先级评估

| 评估维度 | 权重 | 说明 |
|---------|------|------|
| 市场规模 | 30% | 该缺口对应的患者数量 |
| 竞争强度 | 25% | 竞品覆盖该缺口的情况 |
| 证据支持 | 20% | 产品数据支撑该叙事的强度 |
| 临床接受度 | 15% | 医生对该缺口重要性的认知 |
| 医保/准入 | 10% | 医保覆盖对商业化路径的影响 |
