# 错题档案卡 Word 排版规范（作者长期记忆格式）

> 本规范由作者长期记忆中的排版偏好固化而来，是所有「错题档案卡」Word 文档必须严格遵守的红线。生成任何卡片（单题 / 批量）前先读此文件。

## 1. 页面设置
- 上、下、左、右页边距：**均为 1.27 cm（窄边距）**
- 纸张：A4（默认）

## 2. 段落格式
- 段后间距：**0 磅**
- 段前间距：0 磅（标题可随层级微增，正文统一 0）
- 行距：**1.25 倍（多倍行距）**

## 3. 字体规范
- **正文**：宋体（SimSun / 宋体），默认字号 **小四（12pt）**
- **标题**：
  - 一级标题（如「错题档案卡」「一、归因诊断」）：黑体（SimHei / 黑体），**三号（16pt）**
  - 二级标题（如「改编1【__法】」「二、靶向改编题」）：黑体，**四号（14pt）**
- 表格内文字：宋体，**五号（10.5pt）**

## 4. 禁用项（红线，违反即不合格）
- **禁止全角空格（　 / U+3000）**：Word 中会渲染为可见方框。一律用半角空格或制表符。
- **禁止表格「网格线 / Table Grid」样式**：表格须用**无边框**或**仅保留下边框（底部单线）**的简洁样式，不出现「方格」效果。
- **中文双引号**统一用「」（而非直引号 ""），与作者其他文档风格一致。

## 5. 卡片结构（逐卡顺序）
1. 原题（题干+选项/设问，附参考答案）
2. 学生错答（错选 X / 答成 Y）［预测模式标注「预测错因」］
3. 考查（知识点 / 教材位置 / 核心素养 / 学业质量水平）
4. 一、归因诊断
5. 二、靶向改编题（改编1/2/3 同格式）
6. 三、教学建议
7. 四、防再错微检测（1题）

- **单题模式**：一张卡即一个文档。
- **批量模式**：所有卡合并为**一个文档**，卡与卡之间用**分页符**隔开，便于单独打印；文档末尾加「班级错因分布小结」页。

## 6. 文件命名
- 单题：`错题档案卡_题号或知识点_YYYYMMDD.docx`
- 批量：`错题档案卡_班级_测验名_YYYYMMDD.docx`

## 7. 生成方式建议
优先调用 WorkBuddy 的 Word/DOCX 能力（如 `docx` / `word-docx` skill 或 python-docx）生成真正的 `.docx`，不要把 Markdown 直接改名。
生成后**自检五条**：①页边距=1.27cm ②段后=0磅 ③行距=1.25倍 ④无全角空格 ⑤表格非网格线。任一条不满足即重写。
