# 四维归因模型（详细版）

> 配套 `SKILL.md` 第四节。用于把"学生做错了"转化为"可靶向矫治的错因"。

---

## 一、四维总览与判定逻辑

| 维度 | 本质提问 | 典型信号 |
|:---|:---|:---|
| **K 知识维度** | "他到底知不知道这个知识？" | 空白、张冠李戴、两个概念混说 |
| **T 思维维度** | "他知道知识，但怎么想错了？" | 凭直觉答、因果倒置、不会迁移 |
| **C 能力维度** | "他会，但没做对？" | 看错条件、读错图、提取不出信息 |
| **P 心理维度** | "是状态/习惯带偏了？" | 一看就会的题错、被旧题套路带偏 |

**K 与 T 的边界（易混，务必分清）**：
- **K1 概念混淆** = 两个**都教过**的相似概念分不清（如 生长素 vs 生长激素、基因频率 vs 基因型频率）。属"知识组织错误"。
- **T1 迷思概念** = 根深蒂固的**前概念/生活直觉**与科学冲突（如"蛋白质进入线粒体必须主动运输""高温让酶永久失活"）。属"认知结构错误"，更难纠。

**集体错 vs 个别错**：
- 错答比例高（如 >40%）→ 优先怀疑 **K（教学没讲透）或 T1（教材/常识误导）**；
- 个别错 → 优先怀疑 **C（粗心/读图）或 P（状态）**。

---

## 二、各维度子类详解

### K 知识维度
- **K1 概念混淆**：易混概念辨析失败。常见对：生长素/生长激素、基因工程/蛋白质工程、消毒/灭菌、种群密度/丰富度、原生质体/原生质滴、排卵/冲卵。
- **K2 概念缺失/模糊**：核心概念未建立或表述不规范（如不会用"选择透过性""负反馈"等术语）。
- **K3 知识断层**：跨模块未联通（如细胞呼吸与生态系统能量流动、光合作用与ATP）。

### T 思维维度
- **T1 迷思概念**：前概念冲突（见 misconception-bank.md）。
- **T2 逻辑推理断裂**：因果链中断，不会"由果溯因"（如只知结论不知机制）。
- **T3 知识迁移失败**：不能把知识移到新情境（换件"马甲"就不会）。
- **T4 模型建构/读解错误**：概念图、流程图、遗传图解、坐标曲线构建或读错。

### C 能力维度
- **C1 审题失误**：漏看关键词/限制条件/隐含信息（陈东旗建 2.2）。
- **C2 图表误读**：坐标、系谱、结构模式图、流程读错（陈东旗建 2.3）。
- **C3 信息提取失败**：长文本/新情境中抓不住关键。
- **C4 实验设计缺陷**：变量控制、对照设置、结果预测错误。

### P 心理维度
- **P1 思维定势**：被旧题套路带偏（"见到XX就选XX"）。
- **P2 习惯粗心**：计算、抄写、选项看错。
- **P3 考场焦虑**：紧张致简单题失误。
- **P4 畏难弃答**：遇长题干/开放题直接放弃。

## 三、归因决策树

```
学生错答
 ├─ 完全空白/胡答 ──────────────► K（先补知识）
 ├─ 写了但概念张冠李戴 ────────► K1 概念混淆
 ├─ 凭感觉答、与常识相反 ──────► T1 迷思概念
 ├─ 懂知识点但因果说反/说断 ──► T2 逻辑断裂
 ├─ 原题会、换情境就不会 ──────► T3 迁移失败
 ├─ 图/表/遗传图解读错 ───────► C2 图表误读 或 T4 模型错误
 ├─ 漏看"不正确""至少"等词 ──► C1 审题失误
 ├─ 长题干抓不住重点 ──────────► C3 信息提取
 ├─ 实验变量/对照设错 ─────────► C4 实验设计
 ├─ 一看就会的题错、看错选项 ──► P2 粗心 或 P3 焦虑
 └─ 被旧题带偏 ───────────────► P1 思维定势
```

## 四、SOLO / DOK 错因对应（用于定改编层级）

| 原错答所处 | 说明 | 改编应推至 |
|:---|:---|:---|
| 前结构 P | 完全不会、无关回答 | U→M 先补基础 |
| 单点 U | 只提取到单一信息即错 | M→R 建联系 |
| 多点 M | 多信息但不会整合 | R 建系统联系 |
| 关联 R | 能整合但迁移弱 | E 推新情境 |
| 拓展 E | 高阶也会错（罕见） | 精修表述/限定条件 |

**DOK 对应**：K 类错多落在 DOK-1/2；T/C 类错多落在 DOK-2/3；改编高阶题推至 DOK-3/4。

## 五、归因示例

**原题**（陈东旗建例1）：生态学研究中方法与研究目的不相符的是
D. 用标志重捕法调查达乌尔黄鼠的丰富度（正确答案D，学生错选B/C）

**诊断**：
- 错因主类：**K1 概念混淆**（种群密度 vs 丰富度；样方法适用对象混淆）
- 错因定位：学生机械记"样方法调查植物密度"，未区分"种群密度"与"群落丰富度"；混淆标志重捕法调查对象。
- 迷思概念：无典型前概念，属教材概念组织不清。
- SOLO/DOK：原错答 M → 改编推至 R。
- 知识模块：选必2《生物与环境》概念2.1 种群。

**改编方向**：K1 → 用**条件变换法/题型变换法**强化"方法—对象—目的"三元辨析。
