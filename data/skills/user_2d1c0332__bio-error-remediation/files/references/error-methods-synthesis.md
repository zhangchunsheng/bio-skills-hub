## 一、归因方法谱系（为什么会错）

### 1.1 本技能四维归因（知识主轴）
- **K 知识维度**：概念混淆 K1 / 概念缺失 K2 / 知识断层 K3
- **T 思维维度**：迷思概念 T1 / 逻辑断裂 T2 / 迁移失败 T3 / 模型错误 T4
- **C 能力维度**：审题失误 C1 / 图表误读 C2 / 信息提取失败 C3 / 实验设计缺陷 C4
- **P 心理维度**：思维定势 P1 / 习惯粗心 P2 / 考场焦虑 P3 / 畏难弃答 P4
> 完整决策树见 `attribution-framework.md`。

### 1.2 国内其他归因框架（互补，不冲突）
- **错误类型四分类（数学迁移·波利亚/戴再平）**：知识性错误、逻辑性错误、策略性错误、心理性错误——与本技能 K/T/C/P 高度同构，可并行标注。
- **诊断性归因「四步法」**（一线教师统计：坚持深度归因者同类错误率↓约70%）：
  ① 标注错误类型（概念混淆/计算错误/实验设计缺陷等）→ ② 复述正确思路 → ③ 分析根源（知识盲点/思维误区）→ ④ 建立预防措施（专题突破/思维模型）。
- **三级错题分析系统**：一级=错误类型（记忆遗漏/理解偏差/运用失误）；二级=追溯知识漏洞或思维误区；三级=制定针对性补救方案（aixue365）。
- **高考表述题八大失分点**（sxzd360）：问题角度判断不准、研究主体描述不明、前提条件考虑不充分、逻辑关系不清、专业术语不准、概念理解不到位、答题要点不全、题干信息不全。
- **阅卷规范视角四类不规范**（xzbu 阅卷分析）：审题不规范、语言表述不规范（口语化/术语错）、书写不规范（字迹/错别字）、答题区域不规范（答串位置）。

### 1.3 国际归因/分类视角
- **Slip vs Mistake vs Misconception**：粗心失误（slip）、能力性错误（mistake）、根深蒂固的错误概念（misconception）——三者矫治策略完全不同，misconception 需概念转变而非单纯练习。
- **概念转变四条件（Posner et al., 1982）**：① 对原有概念不满；② 新概念可理解；③ 新概念合理；④ 新概念有效。矫治必须走完四步，否则只是"记住答案"。
- **Newman 错误分析（迁移至理科）**：读题→理解→转化→加工技能→编码→疏忽，逐环定位断点在哪一阶。

## 二、改编/变式方法谱系（把错点变命题资源）

### 2.1 本技能八法（核心）
因果变换 / 信息载体变换 / 题型变换 / 设问方向变换 / 情境变换 / 条件变换 / 非良构化 / 难度调控。详见 `adaptation-playbook.md`。

### 2.2 国内「一题多变」实践范式（补充弹药）
- **巩固基础型**（book118 案例）：如"神经纤维兴奋传导"由图形判定→结合电流表偏转绘曲线，多表征联动。
- **提高思维灵活性型**：如伴性遗传基因频率，由常染色体公式→伴性特例（男性 Y 无对应基因）→极值法能量流动计算，逼出条件敏感性。
- **提高应变能力型**：食物链"最多/最少消耗"用极值法在最长/最短链与 10%/20% 效率间切换。
- **逆向变式**：把原题"结论"当条件，反推"前提"（习题课教学模式探究，2025）。
- **综合变式**：跨章节整合（细胞呼吸+光合作用+ATP 合成），逐步升难。
- **开放性问题**：自主设计实验验证假设、对争议观点（如基因编辑伦理）批判性分析。
- **模型驱动四阶**（xhedu 神经-体液调节）：信息提取→模型匹配→逻辑推理→规范表达；配"四要素写作法"强制写全（具体激素而非"相关激素"）。

### 2.3 错例教学资源化的两条经典路径（aixue365《错题资源的开发和利用》）
- **例题变式**：把错题改编为例题，设计问题串/姊妹题，让学生观察—归纳—类比—推理。
- **错题辨析**：鼓励学生互助讲题、上台做"小老师"解析自己的错，训练表达与批判思维，效果常优于教师反复讲。

## 三、错题管理学（学生端：错题本怎么用）

### 3.1 结构与模板
- **三栏纵向分栏（清北学生通用）**：左栏原题+错误做法 / 中栏遮答案重做区 / 右栏错误原因+知识点+同类题变式。
- **康奈尔笔记改良版**：主栏（题目/错答/正解）｜线索栏（核心考点/关键词/错因）｜总结栏（规律/易错提醒/联想）。
- **三级错题本（哈六中名师）**：A 类知识性错误（如 ATP 中"A"含义）、B 类理解性错误（兴奋传导方向）、C 类应用性错误（能量计算）。
- **错题三步法**：① 精准记录（题干关键词+错答"化石"+正解+归因）② 科学归类（按模块/题型/薄弱点，用活页）③ 定期复盘（周末盖答案重做→月考前专题→高三总复习组"终极集"）。

### 3.2 复盘与"毕业"机制
- **间隔重做周期**：当天 → 三天后 → 周测前（间隔重复，对应艾宾浩斯遗忘曲线）。
- **毕业机制**：连续两次复习完全掌握且能讲清 → 标记"已掌握"移出重点区，错题本应"越来越薄"。
- **主动出题**：经典错题自己改编或想"还能怎么考"，为最高层次学习。
- **避坑**：只抄题不分析、答案太详细无自己的话、整理完不看、过度美化、只收"不会的"不收"蒙对的"（蒙对也是盲区）。

### 3.3 生物学科专属技巧
- 图文并茂：亲手画细胞结构/过程图/系谱图/曲线并标易错点；
- 构建概念网络（如种群密度调查方法对比表）；
- 实验专题单列（目的/原理/步骤/结论规范、对照与实验组逻辑、试剂作用）；
- 遗传"套路"模块化：显隐判断→基因定位→写基因型→算概率，总结"无中生有为隐性"等突破口。

## 四、学法谱系（学生端：怎样通过错题真提分）

### 4.1 学习科学"四大基石"（《Make It Stick》/认知心理学）
- **检索练习（Retrieval Practice / 提取练习 / 测试效应）**：合上书重写/自测，比反复阅读强数倍；错题重做即典型检索。
- **间隔重复（Spaced Repetition）**：按遗忘曲线递增间隔（当天→2天→1周→2周→1月），Anki 可自动化。
- **交错练习（Interleaving）**：混合不同题型/章节，迫使识别"该用哪招"，优于长时间单块（blocking）。
- **双编码（Dual Coding）**：文字+图像（思维导图/流程图/标图），双通道强化记忆。

### 4.2 进阶认知策略
- **精细化（Elaboration）**：把新知识与旧知建立多层连接（如"水的概念图"六要素）。
- **生成（Generation）**：先尝试产出（哪怕错），再学正解，比直接给答案记得牢——与 Productive Failure 同源。
- **反思（Reflection）**："我怎么想到这方法的？哪步易错？有无更优思路？"形成个性化思维档案。
- **元认知（Metacognition, Flavell）**：计划—监控—评估三环；"错题诊断模型"三层（分类标签→思维路径→解决方案）即元认知外化。
- **成长型思维（Growth Mindset, Dweck）**：把"我不会"重构为"我还没会（not yet）"；庆祝错误、视挣扎为神经可塑性在建新连接；表扬过程而非天赋。
- **合意困难（Desirable Difficulties, Bjork）**：短期更吃力（如交错、检索、隔时）反而带来长期更强留存——解释为何"轻松刷题"效果差。

### 4.3 费曼技巧
- 把错题对应概念用大白话说给初学者听，卡住处即真盲区；讲通即真懂。

## 五、教法谱系（教师端：怎样把错例变课堂资源）

### 5.1 错例资源化理念
- **错例教学 / 以错促学 / 融错课堂 / 容错课堂**：把学生错误当作最优质教学资源（波利亚"蘑菇成堆生长"）。
- **容错—纠错—反思三策略**（邱学华建构主义 + 波普尔试错渐进）：思维性容错（课堂提问引导批判）、操作性容错（实验错误中修正探究）、习得性容错（习题纠错巩固）。
- **将错就错 / 错例辨析**：让学生互讲错题、当小老师，表达与批判思维训练效果常优于教师反复讲。
- **例题变式集中突破**：一道母题串联多道错点（如细胞呼吸装置题的问题串①~⑤）。

### 5.2 概念转变教学（矫治迷思概念的主力）
- **CLIS 五阶段（Driver & Oldham, 1986）**：引出前概念→引发认知冲突→建构新概念→应用巩固→评价。
- **POE 策略（预测-观察-解释）**：先让学生预测，再做实验观察，最后解释，专破迷思（如细胞多样性统一性）。
- **5D 教学模型（何媛等, 2025）**：迷思探查 Deplore→迷思肯定 Demonstrate→冲突否定 Deny→概念建构 Design→迷思瓦解 Destroy（以"光合作用与能量转化"为例）。
- **论证式概念转变（图尔敏模型）**：前概念→问题情境→形成主张→反驳/辩护→完善主张→新情境，发展推理与批判思维。
- **认知冲突法 / 启发式 / 多媒体模型 / 情境模拟探究**（多篇）：用三维动画、虚拟实验、生态灾难模拟等让抽象概念可视化，在探究中颠覆前概念。

### 5.3 分层与个性化补救
- **知识图谱筛查 + 错题回溯**（edueva 学困生策略）：用思维导图/问卷星标注"掌握/模糊/不懂"，统计常错题型分类匹配资源；学困生主攻"基础必背+理解应用"保底层。
- **小组异质互助**：优等生带动学困生，交叉组合开展不同层次互学。

## 六、诊断工具箱（精准定位错因）

- **二段式诊断测验（Two-tier Diagnostic Test, Treagust）**：第1层选答案，第2层写推理理由；大幅降低猜测，直接区分"真懂"与"蒙对"，是生物迷思概念研究最常用工具（Lim & Poo, 2021 用其诊断光合与呼吸，发现43类迷思）。
- **概念图诊断（Novak, 基于 Ausubel 同化理论）**：让学生自建概念图，连线标签暴露知识组织方式与错点；交叉连接（cross-links）反映整合深度。AI 时代可与智能错题本对接生成认知诊断报告。
- **开放式问题 + 面对面访谈**（刘恩山）：用自己的话解释概念，揭示前概念。
- **概念卡通（Concept Cartoons）**：把对立观点画成对话，引发讨论与辨析。
- **错题标签系统**：给每道错贴 K/T/C/P 或"概念混淆/逻辑缺失/应用偏差"标签，聚合出班级共性薄弱模块。
- **Commit & Toss / Card Sort / 反思日记**等形成性评估小工具（coggle 汇总）。

## 七、生物高频迷思概念与易错点清单（矫治靶标）

> 来源：搜索整理的高考误区、GCSE 常见迷思、二段式诊断研究文献。改编/归因时优先锁定这些靶标。

### 7.1 细胞与代谢
- 植物只在白天呼吸、只进行光合作用；植物"吃土壤"；呼吸=呼吸运动（breathing≠respiration）。
- 原核生物无线粒体→不能有氧呼吸；无叶绿体→不能光合（蓝藻/硝化细菌反例）。
- 线粒体"创造"能量（能量不能创生，只转换，ATP 为能量通货）。
- 酶是"活"的（酶不存活，只变性失活）；所有细胞都有细胞核（成熟红细胞无）。
- 病毒有细胞结构、能独立生活、遗传物质都是 RNA（噬菌体为 DNA）。

### 7.2 遗传与进化
- 自然选择=进化（进化是结果，自然选择是机制；个体不"需要"就进化）。
- 显性=常见；基因突变一定产生等位基因（原核/病毒无等位基因）。
- 自交=自由交配；单倍体=含1个染色体组（未经历受精即单倍体）。
- 种群=物种；物种丰富度=种群密度。

### 7.3 稳态与调节
- 纯体液调节误判为神经调节；忽略题干关键条件（如"下丘脑受损"）。
- 逻辑跳步：从刺激直接到效应，省略中间环节；表述模糊写"相关激素"。

### 7.4 生态
- 能量沿食物链"被吃"方向（箭头实为能量传递方向，相反）；生物量沿链累积（实际递减）。
- 能量传递效率 10%~20% 指同化量比值而非摄入量；富营养化致死主因是分解者耗氧。

### 7.5 实验
- 变量控制不清、对照与实验组逻辑乱；专业术语错别字（G/C 不分）；答题出界、答串位置。
- 质壁分离不能证明死活；预实验不能降低误差只能减少浪费；观察有丝分裂选分生区（解离后死亡）。

## 八、学习科学前沿（理论底座）

- **Productive Failure / 有效失败（Manu Kapur）**：先给学生"跳一跳够不着"的复杂问题（约35-40分钟尝试、必然失败），激活先备知识、暴露知识缺口、提升学习动机，再由教师对比学生尝试与规范解进行"巩固阶段（consolidation）"教学。53项研究元分析显示：精心设计的"先失败再教"效应量可达传统讲授的近2倍（高保真达3倍）。机制=激活(activation)+缺口觉知(awareness)+情感(affect)+组装(assembly)。**对本题的启示**：改编题可设计"刻意让学生先错"的阶梯，再对照正解。
- **合意困难（Bjork）**：检索、间隔、交错、生成等"短期更费力"的条件带来长期更强学习。
- **概念转变理论（Posner 1982; Driver 1985; Chi 本体论类别错误）**：迷思概念具经验性/隐蔽性/顽固性，需认知冲突+重构；Chi 指出生物常见"把过程当物质"的本体论错位。
- **成长型思维（Dweck）**：错误是"尚未（not yet）"，神经可塑性在建连接；避免只夸努力，要配策略与反馈。

## 九、可落地清单（速查）

**学生错题本必备动作**：三栏记录 → K/T/C/P 或 三级标签归因 → 当天/3天/周测前 → 盖答案重做 → 毕业移出 → 主动改编。
**教师课堂错例利用**：容错接纳 → 暴露前概念（POE/概念图）→ 认知冲突 → 例题变式/姊妹题 → 论证式建构 → 二段式后测。
**改编出题靶标优先级**：先打 7.1~7.5 高频迷思与高考八大失分点；用八法 + 一题多变 + 逆向/综合变式。
**诊断首选工具**：二段式诊断测验（班级共性）、概念图（个体结构）、错题标签（趋势）。
