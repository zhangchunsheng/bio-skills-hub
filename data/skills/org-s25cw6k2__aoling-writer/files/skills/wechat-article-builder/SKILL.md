# 公众号文章全流程生成器

完整的公众号文章生产管线：参考文章 → 选题大纲 → 正文撰写 → 封面生成 → 排版 → 推送草稿箱。

## 前置依赖

本 skill 串联以下 skill，确保它们已安装：

- `wechat-topic-outline-planner` — 选题与大纲
- `khazix-writer` — 卡兹克文风撰写
- `inkjun-writer` — 文本精炼优化
- `xiaohu-wechat-format` — 微信排版 + 封面生成 + 草稿推送

## 工作流

### 第一步：获取参考文章

用户提供参考文章 URL 或文件路径。用 fetch/读取提取全文内容，确认标题和核心信息。

### 第二步：选题与大纲

调用 `wechat-topic-outline-planner` 产出 2-3 个选题角度 + 推荐角度 + 主大纲。展示给用户确认。

约束：
- 如果用户有「公司信息」需要在结尾植入，此时确认植入方式（一句话带过/一段话介绍）
- 如果用户指定了目标读者和文章目的，纳入大纲规划

### 第三步：确认文风

询问用户文风偏好，默认使用卡兹克（数字生命卡兹克）风格。如有指定风格 DNA 文件路径，加载之。

### 第四步：标题生成

调用 `wechat-title-generator` 产出 8 个标题候选并推荐最佳，展示给用户确认。

硬约束：
- 开头无引号、冒号、破折号
- 必须让目标受众一眼识别文章场景（如「HR」「招聘」）
- 含情绪或反差

### 第五步：正文撰写

1. 用已确认的标题、大纲、文风 DNA，撰写初稿
2. 调用 `inkjun-writer` 起稿模式做逻辑重构 + 信息精炼 + 语法检查
3. 展示终稿给用户确认

写作约束（卡兹克风格）：
- 段落 = 1-2 句，平均 1 句/段
- 每 5-6 句一个设问
- 开头必须 hook（时间/事件 + 第一反应）
- 全文 ≥3 个情绪高点
- 禁用「你」字（不教导读者）
- 禁用分号、破折号
- 禁用「毋庸置疑」「显而易见」「众所周知」
- 禁用「第一第二」「首先其次」等结构套话
- 结尾三件套：个人感悟 + 引用 + 升华一句
- 结尾自然植入公司信息（如有），不超过一段

### 第六步：生成封面

用 `xiaohu-wechat-format` 的封面子技能生成 4 张不同风格的封面：

1. **暖橙插画** — 温暖场景插画
2. **科技感** — 深色/霓虹科技风
3. **极简文字** — 大字标题 + 极简构图
4. **反差对比** — 前后对比 split 构图

4 张封面全部展示给用户，用户选一张。

### 第七步：排版（需确认）

默认用 `aoling-purple`（遨灵紫）主题排版。同时渲染 gallery.html（全部 24 个主题）供用户浏览对比，确认或切换主题后生成最终 HTML。

### 第八步：推送草稿箱

用 `xiaohu-wechat-format` 的推送功能，将排版好的文章 + 选中的封面推送至公众号草稿箱。

命令格式：
```bash
python <skill-dir>/scripts/publish.py --dir <排版输出目录> --cover <封面路径> --author <作者名>
```

推送成功后告知用户去公众号后台「草稿箱」查看和发布。

## 配置

推送需要微信公众号 AppID 和 AppSecret，配置在 `xiaohu-wechat-format/config.json` 的 `wechat` 字段中。

封面生成需要 API key，配置在 `xiaohu-wechat-format/cover/config.json` 中。

## 输出约定

每一步产出后必须等待用户确认再进入下一步。确认环节包括：
- 选题角度与大纲（第二步）
- 标题选择（第四步）
- 正文终稿（第五步）
- 封面选择（第六步）
- 排版主题（第七步）
