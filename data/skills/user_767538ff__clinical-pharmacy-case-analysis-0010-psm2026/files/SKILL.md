# 临床药历分析部分生成器

## 概述

本技能是一个"药历分析部分生成器"：当用户提供一份缺少分析部分的教学药历（仅有病历首页、初始治疗方案表、用药日志原始数据等），即模仿8份优秀药历的写作风格，自动补全生成六大分析板块，输出一份完整的教学药历。方法论提炼自8份高分药历，涵盖糖尿病酮症、糖尿病合并 G6PD 缺乏性溶血性贫血、糖尿病肾病合并冠心病、痛风性关节炎、糖尿病合并肝损伤/慢性胰腺炎、糖尿病酮症酸中毒合并蜂窝织炎、脓毒血症合并免疫性溶血性贫血、SLE 合并深静脉血栓等多种情形。

## 适用场景

- **补全药历分析部分（主场景）**：用户说"帮我补全这份药历的分析部分"并附上一份残缺药历（缺六大分析板块），即模仿8份优秀药历风格，补全生成完整药历。
- **生成单个板块**：用户只需生成某一板块（如仅初始治疗方案分析）。
- **点评优化**：用户已有分析部分，要求按本方法论点评并优化。

## 输入要求（用户需提供的信息）

用户提供残缺药历时，至少包含以下信息方可生成（信息越全，分析越精准）：

1. **患者基本信息**：年龄、性别、体重、身高、BMI、血压。
2. **主诉与现病史**：发病经过、诱发因素、症状演变。
3. **既往史/用药史/过敏史/家族史**：合并疾病、既往用药、不良反应史。
4. **入院/出院诊断**。
5. **初始治疗方案表**：药名、剂量、用法、频次、起止时间、用药目的。
6. **用药日志原始数据**：各日期的一般情况、辅助检查结果、治疗方案调整（加药/停药）、血糖监测表（如有）。
7. **其它主要治疗药物表**（如有）。

若用户仅提供病历首页与初始方案，可生成"初始治疗方案分析+初始监护计划"；若同时提供日志数据，可生成完整六大板块。

## 六大板块生成规范

### 板块一 · 初始治疗方案分析

**结构**：一句话总起患者核心特征（年龄/性别/病程性质/入院主因）→ 按治疗目标或诊断分模块（一、二、三…）→ 每模块独立分析。

**每模块必含要素**：
- **指南依据**：引用指南/共识名称+版本，给出诊断标准/选药原则/剂量原则。
- **数据对照**：用患者实际检验值/体重/肾功能/合并症逐条对照指南标准。
- **剂量计算**：按体重（如胰岛素 0.5~0.8 U/kg/d、低分子肝素 100 U/kg）、eGFR、年龄计算合理区间，对照实际医嘱判断。
- **获益—风险权衡**：对关键选药列出候选药物"为什么不选+为什么选"，结合患者合并症。
- **明确结论**：每模块结尾给出"选择合理/剂量合理/用法用量合理/治疗不适宜/存在不足/不建议使用"判断词。
- **评分工具驱动**：营养支持用 NRS2002 评分、DVT 用 WELLS 评分、疼痛用 VAS、肝损分型用 R 值、应激性溃疡风险用评估工具——用评分支撑结论。

**进阶识别**（8份药历亮点，按患者情况主动运用）：
- 药物相互作用：如艾司奥美拉唑—氯吡格雷（CYP2C19）、他汀—大环内酯/唑类。
- 机制级重复用药：如舒洛地特（类肝素）+低分子肝素属重复用药。
- 辅料/成分致不良反应：如多种维生素（12）含维生素 C 125mg 及吐温80可致 G6PD 缺乏者溶血。
- 药物经济学：作用重叠药物"二者择一即可"。
- 遴选药物适宜性：如皮肤感染常见 G+ 菌却选抗 G- 的三代头孢→遴选不适宜。
- 无指征用药：如无应激性溃疡高危因素却用 PPI、NRS2002 不达标却用营养支持、可普食却用维生素——指出"不适宜"。

### 板块二 · 初始药物治疗方案监护计划

**结构**：按初始方案中的药物逐一或分类列出，每药/每类包含：
1. **监测指标**：症状+生命体征+需追踪的检验检查清单。
2. **不良反应关注**：该药常见 ADR 及观察要点（如秋水仙碱→腹泻；头孢哌酮他唑巴坦→凝血酶原时间延长/出血）。
3. **特殊用药注意**：滴速（复方氨基酸高渗≤15滴/分、硫辛酸滴注≥15分钟、木糖醇≤0.3g/kg/h）、配伍、给药顺序、储藏。
4. **教育提示**：一句关键教育点（如达格列净多喝水保持外阴卫生）。

### 板块三 · 用药日志中的治疗方案分析

**每个记录节点结构**：日期（Dx）→ 一般情况 → 辅助检查 → 诊疗经过 → 治疗方案调整（加药/停药/剂量变更）→ 治疗方案分析 → 药学监护 → 健康宣教/用药教育。

**治疗方案分析要点**：
- 紧扣当日数据变化做分析，不重复首页内容。
- **检验指标纵向对比**：用"较前下降/升高"判断疗效（PCT 较前下降80%、肝酶较前明显下降）。
- **血糖数据动态分析**：用血糖观察表+趋势判断指导胰岛素调整（晨前较睡前下降4.1mmol/L→减基础率防夜间低血糖）。
- **三段式论证**：当日新增/调整药物同样按"指南—数据—结论"论证。
- **敢于指出不适宜+记录闭环**：如"予非甾体抗炎药治疗不适宜，但临时医嘱药师无法及时干预""建议暂不予中药（何首乌/半夏/柴胡肝损风险），医师采纳"。
- **不良反应识别与处置**：如异甘草酸镁致假性醛固酮增多→水肿→停药换还原型谷胱甘肽；秋水仙碱致水样便腹泻。
- **降阶梯/升阶梯决策链**：药敏结果→病原菌→肾毒性排除→按排泄通路优选抗菌药。

### 板块四 · 药学监护

**结构**：按日期分条，每条绑定具体指标阈值与观察重点。可固定"五维监测"框架：
1. 生命体征（体温/血压/心率/呼吸）。
2. 疗效指标（血糖/炎症指标/肝酶/病原学）。
3. 安全指标（肝肾功能/电解质/凝血/血小板）。
4. 不良反应症状（出血/腹泻/皮疹/水肿/肌痛）。
5. 出血-血栓双向观察（抗凝/抗板患者）。

不良反应按"症状清单+鉴别提示"成对列出（如皮疹+鉴别药物过敏 vs 原发病皮疹）。

### 板块五 · 用药教育/健康宣教

**结构**：分点编号，每点可执行。包含：
1. **疾病相关教育**：如 G6PD 缺乏症完整禁忌清单（禁忌药物：伯氨喹/磺胺类/呋喃类/黄连素/维K3K4 等；禁忌食物：蚕豆；禁忌物品：萘丸/樟脑/苯类试剂；嘱每次就诊主动告知）。
2. **用药方法**：服药时间（阿卡波糖与第一口饭同嚼服、他汀睡前）、注射部位轮换、整片吞服不可掰开。
3. **不良反应识别**：低血糖症状（心慌/手抖/冒冷汗）及处置、抗凝出血防护（软毛牙刷/剃须保护）、利尿剂防体位性低血压（起身缓慢）。
4. **饮食指导**：低盐低脂糖尿病饮食、痛风饮食（每日饮水2~3L、禁酒/海鲜/动物内脏、肉类<100g/d）、避免热带水果。
5. **监测与随访**：血糖监测频率与记录、复诊时间、需复查指标。
6. **出院带药教育表**：药名/每次用量/给药次数/给药途径/用途/注意事项，逐药列出。

### 板块六 · 药物治疗总结

含三个子板块：

**6.1 治疗经过小结**：按 D1→D2→D5… 时间线串联关键节点（入院诊断→关键检验/影像→方案调整→药师干预→出院），形成"病情演变—决策—干预"轨迹。

**6.2 完整治疗过程的总结性分析意见**：分系统/分主题回顾（抗感染治疗/降糖药物调整/贫血查因/抗凝治疗/其他药物治疗），每主题：
- 回顾选药依据与疗效。
- **主动反思不足与干预时机**：如"抗感染疗程未及时停用，最终药师介入停药""PPI 品种选择未给出具体建议，导致使用与氯吡格雷相互作用的艾司奥美拉唑，存在不足""艾司奥美拉唑严重肝损应≤20mg/日但用了 bid，药师未及时发现"。
- **回顾性人群级建议**（进阶）：如"长期糖皮质激素患者应常规行 PAI-1 基因检测及长期抗凝"。

**6.3 药师在本次治疗中参与药物治疗工作的总结**：
- 列出依据的指南/共识清单（含版本）。
- 分点列出药师干预：开展药学监护（监测内容）、建议方案调整（采纳/未采纳闭环）、发现并上报不良反应、用药教育。
- 体现药师价值，量化药学服务贡献。

## 生成流程

1. **信息提炼**：从用户输入提取患者画像、关键检验值、诊断、初始方案、日志数据、血糖/检验动态变化。若关键信息缺失，向用户询问。
2. **判断生成范围**：根据用户提供的日志数据完整度，判断生成全部六大板块还是仅初始板块。
3. **逐板块生成**：按上方六大板块规范依次生成，每板块运用核心方法论。
4. **风格对齐**：语言风格对齐8份模板——客观、循证、敢于表态，医学专业术语准确。
5. **自检**：用下方清单逐条核对，未达标即补充。

## 核心方法论速查（贯穿所有板块）

- **三段式论证**：指南依据 → 患者数据对照 → 明确结论（合理/不适宜）。
- **诊断推理链**：定义+标准 → 数据对照 → 鉴别诊断逐一排除 → 明确诊断。
- **剂量计算**：体重/eGFR/年龄/评分工具驱动。
- **获益—风险权衡**：写"为什么不选"比"选了什么"更重要。
- **患者特异性**：肾功能/消瘦/感染/G6PD/妊娠/老年多重用药→个体化选药。
- **敢于表态**：明确判断词，不回避"不适宜""存在不足"。
- **纵向对比**：检验/血糖用动态趋势，不罗列单次值。
- **闭环记录**：建议+医师采纳与否+后续结果。

## 质量自检清单

生成完成后逐条核对，任一未达标即补充：

- [ ] 初始方案分析是否有一句话总起+按治疗目标分模块？
- [ ] 每个用药决策是否标注指南/共识依据（含版本）并对照患者数据？
- [ ] 药物剂量是否经体重/eGFR/年龄/评分工具计算并判断合理性？
- [ ] 关键选药是否做了获益—风险权衡（含"为什么不选"）？
- [ ] 是否结合患者特异疾病做个体化选药？
- [ ] 是否主动识别药物相互作用/重复用药/辅料风险/无指征用药？
- [ ] 是否有"选择合理/不适宜/存在不足"等明确判断？
- [ ] 监护计划是否分层（监测指标+不良反应+特殊用药注意）？
- [ ] 日志分析是否紧扣当日数据变化、检验纵向对比？
- [ ] 用药教育是否个体化、可执行（如禁忌清单、具体食物/行为）？
- [ ] 总结是否分系统回顾并主动反思不足与干预时机？
- [ ] 药师参与总结是否列出依据指南清单与具体干预闭环？
- [ ] 血糖/检验数据是否做了动态对比而非罗列单次值？

## 安全与合规提示

- 药历涉及患者数据，生成内容如需引用须脱敏（隐藏姓名、住院号等），院内处理，人工复核后方可归档。
- 指南依据须标注版本年份；剂量计算、相互作用判断、不良反应归因须由执业药师/医师人工复核。
- 本生成器辅助写作，不替代临床判断；最终医嘱与教育内容由临床团队确认。
- 若输入信息不足以下结论，应标注"信息不足，建议补充XX检查/数据"而非臆断。
