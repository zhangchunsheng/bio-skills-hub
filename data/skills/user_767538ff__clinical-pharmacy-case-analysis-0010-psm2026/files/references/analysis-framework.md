# 药历分析写作框架（六大板块详解）

本文件展开 SKILL.md 中六大板块生成规范，提供分项要点、写作句式模板、评分工具速查与常见问题对照。生成或点评药历时按需加载。

---

## 评分工具速查（贯穿各板块，用评分支撑结论）

| 工具 | 用途 | 评分要点 | 结论应用 |
|---|---|---|---|
| NRS2002 | 营养风险筛查 | 疾病相关分+营养状态分+年龄分；≥3分有营养风险 | ≥3分→启动营养支持合理；<3分→营养支持不适宜 |
| WELLS | DVT 可能性 | ≤0低危/1-2中危/≥3高危 | 决定是否需影像确诊及抗凝强度 |
| VAS | 疼痛程度 | 0-10分；≥7重度 | ≥7或多大关节受累→联合抗炎镇痛 |
| R值 | 肝损分型 | R=(ALT÷ULN)÷(ALP÷ULN)；>5肝细胞型/<2胆汁淤积型/2-5混合型 | 指导护肝药选择 |
| Padua | VTE 风险 | ≥4分高危 | 决定是否药物预防 |
| 应激性溃疡风险 | PPI 预防指征 | 高危因素：机械通气>48h、凝血障碍、GIB史、多发伤、休克、ICU | 有高危→PPI合理；无高危→PPI不适宜 |

## 板块一 · 初始治疗方案分析

### 总起句模板

> "患者XX岁，[性别]，[急性/慢性]病程。[主病]XX年，此次因[诱发因素/主诉]于[日期]入院。综合其检验指标，其为[病程性质]病程。"

### 模块划分原则

按"治疗目标"或"待查诊断"分模块，模块名即目标。常用模块：

| 病种 | 建议模块 |
|---|---|
| 糖尿病酮症 | 控制血糖 / 排查及控制诱因 / 电解质紊乱查因 / 并发症筛查 |
| 糖尿病合并贫血 | 贫血查因（鉴别诊断链）/ 血糖调控及并发症筛查 / 合并症治疗 / 其他 |
| 痛风急性发作 | 抗炎治疗 / 碱化尿液 / 抗感染治疗 / 退热镇痛 / 其他治疗 |
| SLE 合并 DVT | DVT 抗凝 / SLE 免疫抑制 / 骨质疏松 / 脑梗二级预防 |
| 多病共存 | 按主要诊断平行分模块，每病独立引证 |

### 三段式标准句式

> "参考《XX指南（版本年）》，[疾病]的[诊断标准/选药原则/剂量原则]为……。该患者[实际数据/体重/eGFR/合并症]……，故[诊断成立/选择XX合理/剂量合理/治疗不适宜/不建议使用]。"

三要素缺一不可：①依据（指南名+版本）②对照（患者实际值）③结论（明确判断词）。

### 剂量计算句式

> "[药物]按[XX U/kg/d 或按肾功能调整]，患者体重XXkg（/eGFR XX），[日剂量/单次剂量]应为XX~XX，实际予XX，[落在区间→剂量合理 / 超出→建议调整 / 偏小→建议加量]。"

胰岛素泵专属计算：TDD=体重×(0.5~0.8)；基础率=TDD×40%；三餐大剂量按1/3、1/3、1/3 或 1/5、2/5、2/5；胰岛素敏感系数=1800(速效)/1500(短效)÷(TDD×18)；碳水化合物系数。

### 获益—风险权衡句式

> "[药物A]：[获益]，但患者[合并症]→[风险]→不选。
> [药物B]：[获益]，但患者[状态]→[风险]→不选。
> [药物C]：[获益]，且[对体重/低血糖/感染影响小/心血管获益]→选用。"

关键：写出"为什么不选"，不只写"选了什么"。

### 指出"不适宜"的常见情形

- 遴选药物不适宜：病原菌与抗菌谱不符（如 G+ 感染选抗 G- 三代头孢）。
- 无指征用药：无应激性溃疡高危却用 PPI；NRS2002 不达标却营养支持；可普食却用维生素。
- 重复用药：作用机制重叠（舒洛地特+低分子肝素）。
- 禁忌未规避：G6PD 缺乏用磺胺/呋喃；严重肝损用常规剂量艾司奥美拉唑（应≤20mg/d）。
- 辅料风险：多种维生素（12）含维C及吐温80→G6PD 患者溶血。

## 板块二 · 初始药物治疗方案监护计划

### 逐药监护句式

> "[药名]主要不良反应为[ADR]，[观察要点/应对措施]。[特殊注意：滴速/配伍/储藏]。"

### 高渗/特殊滴速药物速查

| 药物 | 滴速/注意 |
|---|---|
| 复方氨基酸注射液 | 高渗，≤15滴/分；14AA-SF 渗透压770-942mOsm/kg，外周肠外营养≤900 |
| 硫辛酸 | 滴注≥15分钟，注射部位疼痛可土豆片敷 |
| 含木糖醇氨基酸 | ≤0.3g/kg/h，输注≥1小时 |
| 前列地尔 | 观察血管炎 |
| 中药注射液 | 监测过敏反应 |

### 监护计划四象限

1. 症状监测：[生命体征+目标症状是否好转]。
2. 检验追踪：[需追踪的检验检查清单]。
3. 不良反应：[逐药 ADR + 观察/应对]。
4. 教育提示：[一句关键教育点]。

## 板块三 · 用药日志中的治疗方案分析

### 节点结构

日期（Dx）→ 一般情况 → 辅助检查 → 诊疗经过 → 治疗方案调整 → 治疗方案分析 → 药学监护 → 健康宣教/用药教育。

### 日志分析要点

- **不重复首页**：只分析当日新增/调整/停用药物及当日数据变化。
- **纵向对比**：检验用"较前下降/升高"（PCT 较前下降80%、肝酶较前明显下降）。
- **血糖动态**：用血糖观察表趋势指导调整（晨前较睡前下降>4→减基础率防夜间低血糖；波动大→调整剂量）。
- **三段式**：当日新药同样指南—数据—结论。
- **闭环记录**：建议+医师采纳与否（"药师建议XX，医师采纳/未采纳"）。
- **不良反应识别处置**：归因→停药/换药→追踪结果（异甘草酸镁→水肿→停药换谷胱甘肽→水肿好转）。
- **降阶梯链**：药敏→病原菌→肾毒性排除→排泄通路优选。

### 闭环记录句式

> "药师考虑[药物]导致[ADR/不适宜]，建议[停用/调整/更换]，医师[采纳/未采纳]，[后续结果]。"

## 板块四 · 药学监护

### 五维监测框架

1. 生命体征：体温/血压/心率/呼吸。
2. 疗效指标：血糖/炎症指标（WBC/CRP/PCT）/肝酶/病原学。
3. 安全指标：肝肾功能/电解质/凝血/血小板。
4. 不良反应症状：出血/腹泻/皮疹/水肿/肌痛/低血糖。
5. 双向观察（抗凝/抗板）：出血↔血栓。

### 不良反应成对列出

> "关注[症状]，鉴别[ADR vs 原发病表现]。"（如皮疹：药物过敏 vs 湿疹；腹泻：秋水仙碱 ADR vs 感染）

## 板块五 · 用药教育/健康宣教

### 教育三件套（特殊疾病）

禁忌清单 + 行为指导 + 就诊提示：

> "【XX疾病用药教育】禁忌药物：[完整清单]；禁忌食物/物品：[清单]；行为指导：[服药时间/饮食/监测]；每次就诊主动告知XX。"

### G6PD 缺乏症禁忌清单（完整版）

- 禁忌药物：伯氨喹、氯喹、扑疟喹、戊胺喹、阿的平、噻唑砜、氨苯砜、磺胺类（磺胺甲噁唑、磺胺二甲嘧啶、磺胺吡啶、柳氮磺胺吡啶）、乙酰苯肼、乙酰苯胺、呋喃类（呋喃坦啶、呋喃唑酮、呋喃西林、呋喃妥因）、黄连素、硝咪唑、硝酸异山梨醇、二巯基丙醇、亚甲蓝、维生素K3、维生素K4、川莲、珍珠粉、金银花、腊梅花、牛黄、茵栀黄、保婴丹。
- 禁忌食物：蚕豆及蚕豆制品。
- 禁忌物品：含萘臭丸、樟脑、天那水、硝基漆等苯类化学试剂。

### 常见教育要点

- 胰岛素：注射部位轮换、未开启2-8℃冷藏避免冷冻、使用后室温≤30℃存4周。
- 阿卡波糖：与第一口饭同嚼服。
- 他汀：睡前服，避免葡萄柚。
- 双胍类：避免饮酒。
- SGLT-2i：多喝水，注意个人卫生，防泌尿生殖感染。
- 抗凝/抗板：软毛牙刷、剃须保护，观察出血。
- 利尿剂：起身缓慢防体位性低血压。

## 板块六 · 药物治疗总结

### 6.1 治疗经过小结

按 D1→D2→Dx… 时间线串联：入院诊断→关键检验/影像→方案调整→药师干预→出院。每节点记"结果+决策+干预"三元组。

### 6.2 总结性分析意见

分系统/分主题回顾，每主题：
- 选药依据与疗效回顾。
- **反思不足**：干预时机、品种选择未具体化、未及时发现剂量问题、未获医师认同。
- **人群级建议**（进阶）：如长期糖皮质激素者常规 PAI-1 基因检测+长期抗凝。

### 6.3 药师参与工作总结

- 依据指南清单（含版本）。
- 干预分点：药学监护（监测内容）/ 方案调整建议（采纳/未采纳闭环）/ 不良反应上报 / 用药教育。
- 量化贡献。

### 反思句式

> "[主题]治疗中，[描述实际情况]，[指出不足：未及时干预/品种选择未具体化/剂量未及时发现/未获认同]，[改进建议]。"

## 常见问题对照（不好写法 vs 好写法）

| 不好写法 | 好写法 |
|---|---|
| "予胰岛素降糖" | "患者体重41kg，按0.5~0.8U/kg/d，日剂量应为20.5~32.8U，实际予甘精10U+三餐门冬各4U共22U，落在区间内，剂量合理" |
| "选择哌拉西林他唑巴坦抗感染" | "皮肤软组织感染常见病原菌为金葡菌等G+菌，首选青霉素类或一二代头孢；头孢哌酮他唑巴坦为含酶抑制剂三代头孢，主要抗G-，选用该药遴选药物不适宜" |
| "予营养支持" | "患者NRS2002评分4分（糖尿病1分+BMI<18.5共3分），存在营养风险，启动营养支持合理；但应优选全合一营养液，单独输注氨基酸不适宜" |
| "肝酶升高" | "ALT 531.92U/L，ALP未查，R值>5，考虑肝细胞损伤型；较前（ALT 702.08）明显下降，护肝治疗有效" |
| "予PPI护胃" | "患者无应激性粘膜病变高危因素，无PPI预防指征，予艾司奥美拉唑不适宜；且与氯吡格雷存在CYP2C19相互作用" |
| "注意不良反应" | "秋水仙碱常见腹痛腹泻呕吐，合用NSAID注意胃肠道出血；头孢哌酮他唑巴坦可致凝血酶原时间延长，必要时维K预防" |
