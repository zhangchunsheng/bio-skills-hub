# Skill Info

## Skill Name
医药财务总监·战略顾问

## Description
医药行业财务总监+战略顾问+管线估值专家+BD交易分析师完整技能包。包含五大医药化职责（管线预算健康管理者、药政与市场准入风险控制者、药品商业化战略保障者、GMP合规与研发保密权限设计者、医药行业持续学习者）、14个制药财务模型、2个辅助决策模型、FP&A医药分析师能力以及自主学习效果量化评估机制。基于CDE/NMPA/医保局/PubMed/药智等公开数据源，为药企提供从管线估值到市场准入的完整财务战略支撑。

## Introduction

本技能在医药/市场与策略管理领域提供从管线估值到市场准入的完整财务战略支撑。

医药财务总监·战略顾问旨在帮助药企CEO/CFO/BD负责人/市场准入总监/投资分析师快速完成管线估值、BD交易分析、现金流预警、集采与医保政策评估等核心决策场景的计算与分析。

核心能力：

- rNPV管线估值（含各临床阶段成功率概率树）
- BD交易对价分析（License-in/out，含分级分成计算）
- 峰值销售预测（患者流模型）
- 药品定价敏感性分析（集采/国谈/DRG多维龙卷风图）
- 药物生命周期财务预测（含专利悬崖与集采叠加效应）
- 临床阶段现金流分析（Burn Rate / Cash Runway / 融资预警）
- 制药资金管理（GMP冷链效期管理、两票制回款、Phase-Gate预算）
- 医药市场准入SWOT分析
- GMP合规与研发保密权限分层设计
- 医药行业自主学习效果量化评估

应用场景：

- rNPV管线估值与管线组合优先级排序
- BD交易对价合理性分析（License-in/License-out）
- 临床阶段现金流预警与融资时机判断
- 集采降价对产品生命周期的财务冲击评估
- NRDL医保准入定价弹性分析与准入路径规划
- 药品专利悬崖财务预警
- 药企财务比率分析与ROE分解（创新药/仿制药双线）
- 医院/经销商信用评级（两票制约束模型）
- GMP冷链库存效期风险评估
- 董事会级综合财务报告生成
