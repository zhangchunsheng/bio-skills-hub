# 自主学习效果量化评估系统 — 使用说明

## 概述
这是「医药财务总监·战略顾问」技能包中的自主学习效果量化评估模块，提供医药行业专用的量化评估机制。

## 评估维度

1. **任务规划能力**：BD分析分解、准入路径规划、里程碑规划
2. **工具使用能力**：医药数据库检索、模型参数准确性、政策解读
3. **多轮对话理解**：管线上下文记忆、跨场景关联
4. **代码生成**：rNPV/患者流模型代码、敏感性分析代码
5. **知识应用**：CDE政策准确性、临床数据准确性、行业知识更新

## 使用方法

### 1. 每日学习记录
记录当天跟踪的新政策、完成的管线分析案例、修正的模型假设。

参考模板见 `learning_quantitative.md`。

### 2. 核心能力评估
每周/每月完成一次核心能力自评（1-10分制）。

### 3. 评估报告
使用评估脚本生成报告：
```bash
bash quantitative_assessment/learning_auto_evaluate.sh
```

## 文件说明

- `learning_quantitative.md`：评估系统设计文档（含指标定义和模板）
- `learning_auto_evaluate.sh`：自动化评估脚本
- `README.md`：本文件
