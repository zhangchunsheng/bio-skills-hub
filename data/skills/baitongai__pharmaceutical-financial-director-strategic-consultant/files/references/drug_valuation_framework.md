# 药品估值框架

## 为什么医药估值不能用传统DCF？

### 传统DCF的三大缺陷（应用于药物）

1. **确定性假设错误**：DCF假设现金流"会发生"，但药物的商业化取决于临床成功
2. **折现率单一**：DCF用统一折现率，但临床前风险和上市后风险完全不同
3. **不考虑竞争动态**：DCF假设持续的现金流，但药物面临专利到期后的断崖式下跌

### rNPV的核心改进

```
rNPV = Σ(各阶段成功概率 × 该阶段产生的现金流 / (1+该阶段折现率)^t)

即：把"会不会成功"和"值多少钱"分开处理
```

## rNPV估值五步法

### Step 1：确定临床阶段成功率

数据来源：Nature Reviews Drug Discovery（年度统计）、Clinical Development Success Rates

| 治疗领域 | Phase I→II | Phase II→III | Phase III→NDA | NDA→获批 | 累积成功率 |
|----------|-----------|-------------|---------------|----------|-----------|
| 肿瘤 | 62% | 35% | 52% | 87% | 9.8% |
| 心血管 | 65% | 42% | 58% | 89% | 14.1% |
| CNS | 58% | 30% | 48% | 85% | 7.1% |
| 免疫 | 68% | 45% | 62% | 90% | 17.1% |
| 感染 | 70% | 48% | 65% | 92% | 20.1% |
| 代谢 | 66% | 44% | 60% | 89% | 15.5% |
| 罕见病 | 72% | 50% | 68% | 93% | 22.8% |

> 注意：从Phase I开始累积成功率仅7-23%。这解释了为什么biotech投资是"九死一生"。

### Step 2：预测峰值销售

**患者流模型**（详见主文档SKILL.md的峰值销售估计模型）

关键参数获取来源：
- 发病率/患病率：中国肿瘤登记年报、全球疾病负担研究（GBD）、流行病学文献
- 诊断率：基层vs三甲差异显著（如肺癌一线城市诊断率>80%，基层<30%）
- 治疗率：取决于医保覆盖状态
- 年治疗费用：参照NRDL谈判价格或同类药物

### Step 3：构建商业化现金流

```
年销售额曲线：
- 上市第1-4年：爬坡期（线性增长到峰值）
- 第5-9年：峰值期（维持峰值销售）
- 第10年+：衰退期（专利到期+仿制药侵蚀）

净现金流 = 销售额 - COGS - SG&A - 维护型研发 - 税费
典型净利率：创新药25-35%（因高毛利+高费用）
```

### Step 4：选择折现率

| 阶段 | 折现率 | 原因 |
|------|--------|------|
| 临床前 | 18% | 最高风险：科学假设未验证 |
| Phase I | 16% | 安全性尚未确认 |
| Phase II | 14% | 初步疗效数据已有 |
| Phase III | 12% | 确证性试验进行中 |
| NDA | 10% | 审评中，风险大幅降低 |
| 已上市 | 8% | 商业化阶段 |

### Step 5：计算并解读rNPV

```
rNPV > 开发成本 → 继续推进
rNPV < 开发成本 → 评估是否调整策略或寻找合作伙伴
rNPV < 0 → 从纯财务角度不值得继续
```

## 其他估值方法

### BD交易倍数法

用于License-in/out交易的快速估值参考

| 交易类型 | 首付款/峰值销售 | 总交易金额/峰值销售 |
|----------|----------------|-------------------|
| 临床前 | 0.03-0.08x | 0.15-0.30x |
| Phase I | 0.05-0.12x | 0.20-0.40x |
| Phase II | 0.10-0.20x | 0.30-0.55x |
| Phase III | 0.15-0.30x | 0.40-0.70x |
| 已上市 | 0.20-0.40x | 0.50-1.00x |

> 数据来源：2024-2025年中国医药BD交易统计（药智/医药魔方）

### 可比药物分析法

找同靶点/同适应症药物的关键指标对标：
- 峰值销售（已上市同类药物）
- 定价区间（NRDL谈判后年治疗费用）
- 放量速度（上市前3年的收入增长曲线）
- 市场份额天花板（同类药物中第一名通常占40-50%）

### 成熟产品估值

适用于已过/将过专利期的品种

```
产品价值 = Σ(预期年度销售额 / (1+r)^t)

预期销售额 = 当前销售额 × (1 - 仿制药侵蚀率)× (1 - 集采降价影响)
```

## 常见估值误区

### 误区1：峰值销售估算过高

**正确做法**：参考同类已上市药物的实际峰值销售，不要直接乘"目标患者×年治疗费用"。因为总有：诊断率<100%、治疗率<治疗指南推荐率、实际上处方率<治疗率。

### 误区2：忽略竞争动态

**正确做法**：不是"假设我们拿到20%市场份额"，而是列出所有竞品（已上市+Phase III+Phase II），评估每个产品的优劣势，再推算合理份额。

### 误区3：专利到期后仍假设持续销售

**正确做法**：化合物专利到期后，考虑3年内的仿制药侵蚀（累计侵蚀80-85%），以及集采加速侵蚀效应。
