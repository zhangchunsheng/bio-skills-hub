# 医药CFO思维模式

## 核心思想
**从管线出发、以估值/准入为语言、聚焦研发效率和商业化确定性**

## 医药财务总监分析的六步框架

### 第一步：看管线 — 管线价值排序

**改自通用CFO「看战略」**

每个管线必须回答：
1. rNPV是多少？在管线组合中排第几？
2. rNPV/成本比是否>2？
3. 治疗领域覆盖度如何？（避免过度集中于单一适应症）

**示例**：某Biotech有4个管线，PD-L1单抗rNPV=8亿（Phase III）、HER2 ADC rNPV=5亿（Phase II）、GLP-1口服rNPV=12亿（Phase I）、CD19 CAR-T rNPV=1.5亿（Phase I）。重点推PD-L1和HER2 ADC，GLP-1寻找合作伙伴分担风险。

### 第二步：看成长 — 管线成长性

**改自通用CFO「看成长」**

1. 临床进度是否按计划？对比行业平均周期
2. 下一个催化剂（Catalyst）是什么时间？（数据读出/IND获批/NDA受理）
3. 催化剂后估值变化空间有多大？

### 第三步：看效益 — 已上市产品效益

**改自通用CFO「看效益」**

1. 单品毛利率（>80%代表定价权强）
2. 学术推广费用率（<30%为优）
3. 人均销售额（>100万元/人为优）
4. 医保准入后的放量速度（通常2-4年达到峰值）

### 第四步：看效率 — 研发效率

**改自通用CFO「看效率」**

1. 临床入组效率（实际 vs 计划入组速度）
2. CRO费用/入组患者（benchmark: 肿瘤项目约5-8万元/患者）
3. IND到NDA的周期（创新药通常8-12年）
4. 研发杠杆系数 = 管线组合估值/累计研发投入

### 第五步：看资产质量 — 无形资产与产能

**改自通用CFO「看资产质量」**

1. 专利剩余年限（化合物专利通常20年，从申请日算起）
2. 在研管线减值风险（临床失败=无形资产减值）
3. 产能利用率（GMP产线是否闲置）
4. 仿制药威胁窗口

### 第六步：看风险 — 多维风险矩阵

**改自通用CFO「看风险」**

1. 集采风险 × 降价幅度
2. 医保谈判不确定性
3. 临床III期失败概率（参考CRL/NEJM/NRD年度统计）
4. 专利悬崖
5. 替代疗法威胁（同类靶点竞品临床进度）

## 医药CFO五大思维特质

### 1. 概率思维（替代双向奔赴思维）

**核心**：不追求确定性，而是量化不确定性

- rNPV = 成功率 × 商业化估值
- 不是"这个药能不能成功"，而是"这个药成功概率40%，调整后期望价值5亿"
- 管线组合思维：10个管线各10%成功率 → 至少1个成功的概率=65%

### 2. 管线即资产（替代业财融合）

**核心**：管线不是成本中心，而是无形资产

- 每一分钱投入研发 = 购买一个"看涨期权"
- 管线减值比库存减值更难察觉（库存可以盘点，管线无法盘点）
- 管线终止决策：不要因为"已投了3亿"而继续投（沉没成本谬误）

### 3. 临床数据驱动（替代问题刨根问底）

**核心**：财务分析必须基于临床数据，而非财务数据

- 为什么BLA延迟了？→ 因为入组慢了 → 因为方案设计了严格的入排标准 → 因为安全性信号
- 财务总监需要能读懂临床数据：OS HR、PFS、ORR、3级以上AE率
- 每次期中分析/数据读出后，重新预测rNPV

### 4. 政策敏感（替代数据驱动决策）

**核心**：医药行业的"数据"包含政策变量

- 集采一轮可能让单品销售额下降70%
- 医保谈判可能让年治疗费用从20万降到8万
- DRG/DIP改革可能改变医院的用药行为
- 财务模型必须能跑"policy scenario analysis"

### 5. Phase-Gate思维（替代预测导向）

**核心**：药物开发是门控（gated）的，不是连续的

- 每个Phase结束 = Go/No-Go决策点
- 财务计划应是"如果Go，需要多少钱"而非"全年预算"
- 滚动预算不是12个月滚12个月，而是滚到下一个Gate

## 医药CFO vs 通用CFO核心差异

| 维度 | 通用CFO | 医药CFO |
|------|---------|---------|
| 估值逻辑 | DCF（确定性折现） | rNPV（概率性折现） |
| 核心竞争力 | 成本控制、资金效率 | 管线决策、BD谈判 |
| 风险来源 | 市场风险、信用风险 | 科学风险、监管风险 |
| 决策周期 | 月度/季度 | Phase-Gate（半年到数年） |
| 关键指标 | ROE、净利率、CCC | rNPV、Burn Rate、Cash Runway |
| 最大噩梦 | 现金流断裂 | 临床III期失败（管线减值+股价暴跌） |
| 最佳结局 | 持续盈利、分红增长 | 重磅炸弹上市（Blockbuster drug）+ 管线持续输出 |

## 不被理解的医药CFO

**场景1：烧钱焦虑**

- CEO："我们每个月烧2000万，什么时候能有收入？"
- 医药CFO："目前3个管线在临床期，预计最快2029年首款上市。我们账上有5亿，跑道25个月。2028年底前需要下一轮融资或BD收入。"
- **关键**：不回避烧钱，而是量化烧钱的终点和意义。

**场景2：管线终止**

- 研发VP："A管线Phase II数据不好，但我觉得再做一个亚组分析可能有戏..."
- 医药CFO："A管线目前rNPV=-2000万（假设成功率已降至15%）。如果用同样预算投B管线，rNPV增量是+1.5亿。建议终止A，加强B。"
- **关键**：用数字说话，不为沉没成本辩护。

**场景3：BD决策**

- BD VP："这家公司有个Phase II的ADC，首付要2亿。"  
- 医药CFO："同靶点3个竞品在Phase III，我们即使拿下也要3年后上市。峰值销售估计15亿，rNPV约4亿，但首付2亿+里程碑5亿→买方净价值为负。建议压价到首付1亿以内。"
- **关键**：BD不是"看好就买"，而是"算出买家的净价值"。
