# 医保谈判（NRDL）定价参考

## NRDL谈判规则概要

### 纳入流程
```
企业申报 → 形式审查 → 专家评审 → 谈判/竞价 → 公布结果 → 落地执行
（通常每年6月开始，9-10月谈判，次年1月1日执行）
```

### 定价核心逻辑

1. **国际参考价**：参考韩国、台湾、葡萄牙等中等发达国家/地区的药品价格
2. **药物经济学评价**：ICER（增量成本效果比）通常要求不超过1-3倍人均GDP
3. **预算影响分析**：评估新药纳入对医保基金年度支出的影响

### 2025年NRDL价格参考区间（经验值，非官方）

| 药品类型 | 典型年治疗费用（谈判后） |
|----------|----------------------|
| PD-1/PD-L1单抗 | 5-8万元/年 |
| 小分子靶向药（TKI） | 3-6万元/年 |
| ADC药物 | 10-20万元/年 |
| CAR-T细胞治疗 | 120万元/次（按疗效付费方案协商中） |
| 罕见病药物 | 30-100万元/年（视疾病严重性和替代方案） |
| GLP-1类减重药 | 待定（首轮谈判中） |

> 注意：以上为经验区间，实际定价取决于药物经济学数据和谈判策略。每年谈判结果差异可能较大。

## 财务模型中的NRDL/集采参数设定建议

### 乐观情景
- NRDL谈判降价：-30%
- 集采概率：0%（创新药/独家品种）
- 放量倍速：2-3x

### 基准情景
- NRDL谈判降价：-50%
- 集采概率：视过评企业数而定
- 放量倍速：1.5-2x

### 悲观情景
- NRDL谈判降价：-70%
- 集采概率：100%
- 放量倍速：0.8-1.0x（有价无市）

### 龙卷风图建议步长

| 变量 | 范围 | 步长 |
|------|------|------|
| NRDL降价幅度 | -30% ~ -70% | 10% |
| 集采降价幅度 | -40% ~ -80% | 10% |
| 集采中标概率 | 0% ~ 100% | 25% |
| 患者渗透率 | 5% ~ 30% | 5% |
| 竞品上市时间 | -2年 ~ +2年 | 1年 |

---

> **持续更新提醒**：NRDL和集采政策每年都有变化，建议每年第2季度关注国家医保局发布的最新谈判规则，及时更新模型参数。
