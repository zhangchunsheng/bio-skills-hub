## 加速审评通道

| 通道 | 条件 | 优势 |
|------|------|------|
| **突破性治疗药物** | 用于防治严重危及生命的疾病，且已有初步临床证据显示明显优于现有治疗 | CDE优先配置审评资源、滚动提交数据 |
| **附条件批准** | 用于严重危及生命且无有效治疗手段的疾病，可基于替代终点或中间临床终点批准 | 缩短上市时间1-3年 |
| **优先审评** | 具有明显临床价值的新药、儿童用药、罕见病用药 | 审评时限缩短至130工作日 |
| **特别审批** | 突发公共卫生事件应急所需 | 最快可在数周内批准 |

## 典型创新药研发时间轴

```
药物发现 → 临床前 → IND → Phase I → Phase II → Phase III → NDA → 获批上市
  (2-4年)  (1-2年)  (6月)  (1-2年)  (1.5-3年)  (2-4年)   (1-1.5年)

总计：从发现到获批通常8-15年
财务影响：越早阶段，投入越少但风险越高；越晚阶段，投入越多但确定性越强
```

## 关键监管里程碑及其财务影响

| 里程碑 | 财务影响 | 估值影响 |
|--------|----------|----------|
| IND获批 | 可启动临床试验，研发支出开始加速 | rNPV小幅上升（消除了"不能进入临床"的风险） |
| Phase I完成（安全性确认） | 决定是否进入Phase II | 成功率从62%变为100%→rNPV跳升 |
| Phase II期中分析（初步疗效） | 决定是否进入Phase III | rNPV大幅跳升（如果数据正面）或归零（如果数据负面） |
| Phase III完成（确证性试验） | NDA申报 | rNPV接近最大（仅剩审批风险） |
| NDA获批 | 可商业化 | rNPV变为确定NPV |
| 首次纳入NRDL | 放量开始 | NPV+15-25%（放量加速） |
| 纳入集采 | 降价换量 | NPV可能下降30-60%（降价效应通常大于放量效应） |

## 专利保护时间线

```
化合物专利申请（T=0）
    → 约2-4年：专利公开/授权
    → 约10-12年：药物获批上市（此时剩余专利期约8-10年）
    → 最多+5年：专利延长期（PTE，中国目前无，但可争取）
    → T+20年：化合物专利到期
    → 制剂专利/用途专利可能延续保护（但保护力度弱于化合物专利）
```

### 延长有效专利期的策略

1. **制剂专利**：特殊剂型（缓释、靶向等）
2. **用途专利**：新适应症获批
3. **晶型专利**：特定晶型结构
4. **组合物专利**：固定剂量复方制剂
5. **儿科用药延长期**（中国已建立）：完成儿科临床试验可延长6个月
