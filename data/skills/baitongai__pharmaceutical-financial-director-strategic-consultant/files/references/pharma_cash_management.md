# 制药资金管理五大模型详解

> 基于通用财务总监资金管理五大模型改造，全部替换为医药行业专用场景

## 一、药品现金周转周期模型（原：现金周转周期）

### 制药CCC公式
```
制药CCC = API库存天数 + 生产周期天数 + 成品库存天数 + 医院回款天数 - 供应商账期天数
```

### 为什么制药CCC天然比制造业长？

| 阶段 | 制造业 | 制药业 | 差异原因 |
|------|--------|--------|----------|
| 原材料采购 | 7-30天 | 30-180天（进口API需备货3-6个月） | API供应不稳定、进口注册周期长 |
| 生产 | 1-7天 | 15-60天（含检验放行） | GMP要求：每批全检+留样+QA放行 |
| 成品库存 | 7-14天 | 15-90天（冷链生物药效期压力） | 效期管理+区域配送中心备货 |
| 回款 | 30-60天 | 90-450天（两票制下医院回款6-15个月） | 医保拨款周期决定 |
| 应付 | -45天 | -30天（CRO/CDMO需预付） | 无法像制造业占用供应商资金 |

**关键洞察**：制药业CCC通常在180-450天（6-15个月），远超制造业。这**不是管理问题，是行业结构性特征**。财务总监的重点不是"缩短CCC"，而是"确保有足够现金覆盖这个周期"。

### 生物药特有风险

- 冷链生物药效期通常12-24个月
- API库存+成品库存如超过效期50%→面临过期报废风险
- 报废=直接损失，无法回收

## 二、研发现金储备模型（原：最佳现金持有量）

### 重新定义"最佳"：从确定性区间变为生存区间

```
资金下限 = 月Burn Rate × 6个月 + 紧急不可缩减费用
资金最优 = 月Burn Rate × 12个月 + 下一里程碑付款 + 融资周期缓冲（6个月）
资金上限 = 月Burn Rate × 18个月
最低生存线 = 固定管理费 × 12个月（停止所有管线，仅维持公司存活）
```

### 管线暂停决策

当现金触达"资金下限"时：
1. 盘点所有在研管线，按rNPV/成本比排序
2. 暂停rNPV/成本比最低的管线
3. 评估BD机会：能否License-out部分权益换取首付款？
4. 启动新一轮融资

**案例**：某Biotech月度Burn Rate为2000万，账上现金2.4亿...
- 资金下限：2000万×6 = 1.2亿（当前2.4亿，OK）
- 最优储备：2000万×12+5000万里程碑+1.2亿融资缓冲 = 4.1亿（不足！）
- **结论**：虽然Cash Runway有12个月，但下一里程碑支付和融资准备都需要更多现金。建议6个月内启动融资。

## 三、API/制剂GMP库存模型（原：存货占用）

### ABC分类逻辑转变：从"货值"到"效期敏感性"

| 分类 | 原版依据 | 医药版依据 | 管理策略 |
|------|----------|-----------|----------|
| A类 | 货值高、品种少 | 效期敏感（冷链生物药效期<18个月） | 少批量多频次采购，目标库存<效期40% |
| B类 | 中等货值 | 常规化学药制剂（效期24-36个月） | 按销售预测备货，安全库存=2-4周销量 |
| C类 | 小零碎 | 辅料/包材/试剂 | 批量采购降低单价，定期审核供应商 |

### GMP库存特有问题

1. **效期报废风险**：生物药过期=直接报废，无法回收
2. **留样管理**：每批至少保留2倍检验量的留样，留样至有效期后1年
3. **温控监测**：冷链品种需24小时温度记录，偏差>2°C启动偏差调查
4. **供应商变更成本**：辅料/包材供应商变更→重新验证→监管备案

### 决策案例

某PD-1单抗（冷链、效期18个月），当前库存价值5000万，月消耗量300万。
- 库存覆盖：5000万/300万 = 16.7个月
- 超过效期18个月的50% = 9个月的警戒线
- **风险**：约有5个月库存可能面临效期过期
- **建议**：降低安全库存至3-4个月消耗量，将现有库存加速出货

## 四、医院/经销商信用评级模型（原：信用决策）

### 两票制下的信用逻辑转变

**原版**："这笔生意毛利多少？资金被占多久？能覆盖坏账风险吗？"
**医药版**："这家医院的回款周期取决于当地医保局的拨款节奏，不是医院本身能决定的。"

### 五维评级体系

| 维度 | 原版 | 医药版 |
|------|------|--------|
| 客户类型 | 新客户/老客户 | 三甲/三乙/二甲/基层 |
| 还款历史 | 付款记录 | 回款准时率（考虑医保拨款周期因素） |
| 交易规模 | 单笔金额 | 年采购额 |
| — | — | **新增**：当地医保结算周期（3个月/6个月/12个月+） |
| — | — | **新增**：区域经济水平（按省GDP排名分档） |

### 分省医保结算周期参考

| 省份/直辖市 | 典型医保结算周期 |
|------------|-----------------|
| 北京/上海/广东/浙江/江苏 | 2-4个月 |
| 山东/福建/湖北/四川/重庆 | 3-6个月 |
| 河北/湖南/安徽/陕西 | 5-9个月 |
| 东北三省/西部省份 | 8-15个月 |

> **说明**：以上为典型经验值，具体以当地医保局实际拨款节奏为准。两票制后，公立医院回款高度依赖医保预付款和结算款。

## 五、药物开发Phase-Gate预算模型（原：现金流滚动预算）

### 从"13周滚动"变为"Phase-Gate驱动"

**原版**：每周滚未来13周
**医药版**：每个Phase结束→Go/No-Go→滚到下一个Gate（3-36个月不等）

### Phase-Gate决策框架

```
Phase I完成 → Gate Review
    ├── Go → 释放Phase II预算
    │   ├── 准备Phase II方案
    │   ├── 选择CRO
    │   └── 预计入组18个月
    ├── No-Go → 终止项目
    │   ├── 冻结剩余预算
    │   ├── 计提无形资产减值
    │   └── 团队重新分配
    └── Hold → 暂停
        ├── 仅维持基本费用（团队保留核心成员）
        ├── 等待新数据/新方案
        └── 重新评估科学假设
```

### 预算编制粒度

| 阶段 | 预算粒度 | 编制周期 |
|------|----------|----------|
| 临床前 | 按季 | 滚到IND |
| Phase I | 按月 | 滚到Phase I数据读出 |
| Phase II | 按月 | 滚到期中分析 |
| Phase III | 按月 | 滚到最终分析 |
| NDA | 按月 | 滚到获批 |

### 预警机制

| 预警级别 | Cash Runway | 触发行动 |
|----------|------------|----------|
| 🟢 绿色 | >24个月 | 正常运营 |
| 🟡 黄色 | 18-24个月 | 启动融资/BD准备 |
| 🟠 橙色 | 12-18个月 | 加速融资/BD流程 |
| 🔴 红色 | <6个月 | 紧急融资、缩减管线、启动出售谈判 |
