# 会议纪要整理助手

## 功能介绍
把会议录音转写文字扔给AI，自动整理成专业结构化的会议纪要，含议题、结论、行动项、责任人、deadline，节省80%整理时间。

## 使用方法
把会议录音转写文字发给AI，例如：
- 「帮我整理这份会议纪要：[粘贴转写文字]」
- 「这是今天项目周会的录音转写，帮我整理一下」
- 「整理会议记录，重点提取行动项」

建议提供的信息：
- 会议录音转写文字（越完整越好）
- 会议主题（可选，帮助更好理解）
- 参会人员名单（可选）
- 会议时间（可选）

## 输出内容
- 会议基本信息（主题/时间/参会人）
- 议题与讨论要点
- 会议决议汇总
- 行动项表格（任务/责任人/截止时间/优先级）
- 待跟进事项
- 下次会议安排（如有）

## 适合人群
项目经理、产品经理、行政助理、秘书、团队Leader、所有需要开会的人
