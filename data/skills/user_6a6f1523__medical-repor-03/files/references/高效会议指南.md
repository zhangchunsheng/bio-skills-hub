# 高效会议指南

## 好会议的标准
1. 有明确的议题和目标
2. 有合适的参会人员
3. 有时间限制
4. 有明确的结论和行动项
5. 有跟进机制

## 常见问题
- 会议太多，没时间干活
- 会议冗长，效率低下
- 议而不决，决而不行
- 参会人太多，讨论发散

## 改进建议
1. 能不开的会就不开（用文档沟通）
2. 能短开的会就不长开（设闹钟）
3. 能少人的会就不多人（只邀必要的人）
4. 每次会议必须有结论和行动项
5. 会后24小时内发出纪要并跟进

## 会议类型及时长建议
- 站会：15分钟
- 周会：30-60分钟
- 项目评审：60-90分钟
- 头脑风暴：45-60分钟
- 一对一：30分钟
