# GEO内容合规禁用语清单与审核规则库

> 本文件是 geo-compliance-check 的参考文件，提供详细的禁用语分类、AI拼接风险场景、以及各平台医药内容特殊限制。

---

## 一、绝对禁用语（出现即否决）

### 1.1 疗效绝对化用语

| 禁用语 | 风险说明 | 替代建议 |
|--------|---------|---------|
| 治愈 | 暗示100%治愈率，违反药品广告法 | "改善""缓解""控制" |
| 根治 | 同上 | "治疗""管理" |
| 痊愈 | 同上 | "好转""有效" |
| 100%有效 | 绝对化数字声称 | "在临床研究中显示XX%的有效率" |
| 无副作用 | 否定安全性风险 | "在规定剂量下安全性良好" |
| 绝对安全 | 绝对化安全声称 | "安全性经过临床验证" |
| 零风险 | 绝对化安全声称 | "风险可控" |
| 药到病除 | 夸大疗效 | 删除 |
| 神药/仙药 | 夸大疗效 | 删除 |
| 包治 | 绝对化疗效声称 | "适用于" |

### 1.2 比较性违规用语

| 禁用语 | 风险说明 | 条件（何时可用） |
|--------|---------|----------------|
| 优于XX药 | 无头对头A级证据时的比较性优劣评价 | 仅在有头对头RCT A级证据时可用 |
| 比XX药更好 | 同上 | 同上 |
| 最有效的 | "最"字级最高级声称 | 永远不可用 |
| 最安全的 | 同上 | 永远不可用 |
| 第一选择 | 无指南支撑的首选声称 | 仅在有官方指南一级推荐时可用 |
| 唯一的选择 | 排他性声称 | 永远不可用 |
| 替代XX药 | 无替代研究证据 | 仅在有正式替代研究时可用 |

### 1.3 诱导性用语

| 禁用语 | 风险说明 |
|--------|---------|
| 买X送X | 药品促销违规 |
| 限时优惠 | 药品促销违规 |
| 免费试用 | 处方药违规 |
| 咨询有礼 | 变相促销 |
| 健康热线（无资质） | 无资质医疗咨询 |

## 二、相对禁用语（需上下文判断）

### 2.1 需限定语的用语

| 用语 | 使用条件 | 限定语示例 |
|------|---------|-----------|
| 安全 | 必须加剂量/人群限定 | "在规定剂量下安全性良好" |
| 有效 | 必须标注证据等级和条件 | "在XX周治疗中，临床研究显示有效率XX%" |
| 推荐 | 必须标注推荐来源 | "XX指南推荐作为一线治疗" |
| 首选 | 必须有指南支撑 | "XX指南将其列为一线首选" |
| 长期 | 必须标注时间范围 | "在XX月的长期随访中" |
| 广泛 | 必须有数据支撑 | "在XX个国家广泛使用" |

### 2.2 AI特定风险用语

| 用语 | AI风险 | 建议 |
|------|--------|------|
| "也可以用于" | AI可能提取为超适应症推荐 | 改为"目前批准用于" |
| "一些医生认为" | AI可能提取为专家共识 | 改为"在XX研究中，XX%的医生选择" |
| "通常建议" | AI可能提取为指南推荐 | 改为"XX指南建议" |
| "与XX药联合使用效果更好" | AI可能提取为联合用药推荐 | 需有联合用药的A级证据 |
| "老年人/儿童也可以使用" | AI可能提取为全人群适用 | 需标注说明书中的特殊人群限制 |

## 三、AI拼接风险场景库

### 场景1：超适应症拼接

**触发条件**：信源A提到"XX药在研究中对YY病有效" + 信源B提到"XX药的安全性良好"

**AI可能生成**："XX药可以有效治疗YY病，且安全性良好"

**风险**：如果YY病不在说明书批准范围内，这就是超适应症传播

**预防策略**：
- 所有提及研究性适应症的内容必须紧跟"尚处于研究阶段，未获批准"
- 安全性描述不与未批准适应症在同一信源出现

### 场景2：剂量拼接

**触发条件**：信源A提到"XX药推荐剂量为15mg" + 信源B提到"有些患者使用25mg效果更好"

**AI可能生成**："XX药的推荐剂量为15-25mg"

**风险**：如果说明书只批准15mg，这就是超剂量传播

**预防策略**：
- 剂量信息只引用说明书标准，不引用个体化调整数据
- 如需提及剂量范围，必须标注"请遵医嘱"

### 场景3：比较性结论拼接

**触发条件**：信源A提到"XX药有效率为85%" + 信源B提到"YY药有效率为75%"

**AI可能生成**："XX药比YY药更有效"

**风险**：如果两个数据来自不同研究（不同人群/终点/方法），不能直接比较

**预防策略**：
- 不在不同信源发布不同药品的数据对比
- 如需比较，必须在同一内容中使用头对头研究数据

## 四、各信源平台医药内容特殊限制

| 平台类型 | 特殊限制 | 注意事项 |
|---------|---------|---------|
| 百科类（百度百科/维基百科） | 需引用权威来源、不允许商业推广语 | 内容必须中立客观，不可包含品牌宣传 |
| 学术类（知网/万方） | 需符合期刊发表规范 | 内容必须以学术论文形式呈现 |
| 社媒类（微信公众号/知乎） | 处方药不可直接面向公众推广 | 需标注"仅供医疗卫生专业人士参考" |
| 医疗平台（好大夫/春雨） | 需具备医疗资质 | 健康科普内容不得包含具体药品推荐 |
| 电商类（京东健康/阿里健康） | 需有药品经营许可证 | OTC可展示，处方药仅可展示信息不可直接销售 |
| 视频类（抖音/快手） | 医疗内容需通过平台审核认证 | 不得在短视频中做药品功效宣传 |
