# 药房调剂工作量计算 - 业务规则与表格结构约定

本文件记录医院药房月度工作量统计表的结构约定、岗位标记规则、绩效计算公式。
当表格结构与本约定一致时，可直接运行 `scripts/calc_pharmacy_workload.py`；结构有差异时按本文件规则调整脚本参数。

## 一、工作簿 Sheet 组成

典型月度工作量统计簿包含以下 sheet（名称可能微调，脚本按特征自动识别）：

| Sheet | 作用 | 列布局 |
|-------|------|--------|
| 日班 | 门诊药房日班排班+实际工作量 | 每天占 **3 列**：窗口 / 发 / 配 |
| 均数 | 日班副本，住院药房/机动/补休岗位按门诊均数折算 | 同日班 3 列 |
| 夜班 | 夜班排班+工作量 | 每天占 **4 列**：窗口 / 发 / 配 / 借药 |
| 个人汇总 | 月度绩效汇总 | 工号/姓名/发/配/借药/工作总量/分值/基准/差额 |
| 每日统计汇总 | 日级汇总（脚本生成） | 日期/星期/窗口人数/住院人数/发药总数/配药总数/人均发/人均配/机动人员 |

- 第 1 天数据起始列：日班=2(C)、夜班=2(C)；姓名列=1(A)。
- 第 i 天(i 从0计)：日班窗口列=2+3i、发列=3+3i、配列=4+3i；夜班窗口列=2+4i、发列=3+4i、配列=4+4i、借药列=5+4i。
- 人员行：从第 4 行开始（第3行为表头"窗口/发/配"）。
- 月末第 31 天后接合计列：均数=月发合计(CQ)/月配合计(CR)；夜班=月发(DV)/月配(DW)/月借药(DX)。

## 二、窗口列标记规则（核心业务约定）

日班/均数 sheet 的"窗口"列填写值含义：

| 标记 | 含义 | 是否计入窗口人数 | 发/配列如何取值 |
|------|------|------------------|-----------------|
| 纯数字(如 8) | 上对应窗口号 | **是** | 填实际工作量 |
| "住" | 轮转住院药房 | 否 | 均数sheet填当天门诊窗口人均发/人均配；日班sheet不填(住院另计) |
| "X+补休"(如 4+补休) | 上X号窗口+补休 | **是**(算上窗口) | 均数sheet填当天门诊人均发/人均配 |
| "X机动"(如 12机动) | 机动岗 | 否 | 均数sheet填当天门诊人均发/人均配 |
| 空(None) | 休息/夜班/产假 | 否 | 不填 |

- **窗口人数** = 纯数字 + "X+补休" 的人数；不含"住"、"机动"、空。
- **发药总数/配药总数** 只统计上窗口人员（纯数字+"补休"），住院药房/机动/空不计入。
- **人均发** = 当天发药总数 / 当天窗口人数；**人均配** = 当天配药总数 / 当天窗口人数。

## 三、日班表统计行（原表预留，脚本填入）

日班 sheet 行尾预留统计行（0-based 行号，openpyxl 1-based = +1）：

| 统计行(0-based) | 内容 | 填入位置 |
|-----------------|------|----------|
| R37 | 当日所有人员发药总数 | 每天的窗口列 |
| R38 | 每天门诊长班人数(窗口人数) | 每天的窗口列 |
| R39 | 当日白天平均数 | 人均发→窗口列；人均配→配列 |
| R42 | 全天配药数 | 每天的窗口列（覆盖旧值） |

## 四、绩效计算公式（个人汇总 sheet）

```
工作总量 = 发 × 2 + 配 + 借药
均值     = 绩效池子 / 总工作总量        # 池子默认 11200(=28人×400)
分值     = 工作总量 × 均值
基准     = 400
差额     = 分值 − 基准
```

- **绩效池子**：默认 11200（28人×400），写在个人汇总 sheet 行1 的 H 列。如人数变动需调整。
- **产假规则**：产假人员（默认"敖雪敏""张璐"）差额特殊设 0，不扣 400；其余人员差额=分值−400。
- **分值守恒**：全员分值之和 = 绩效池子（=总工作总量×均值）。
- **差额合计** = 分值合计 − 基准合计；产假人员基准保留但差额补0。

## 五、合并口径

个人汇总 sheet 的发/配/借药来自日班+夜班合并：

| 列 | 取值 |
|----|------|
| 发(日+夜) | 均数sheet月发合计(CQ) + 夜班sheet月发合计(DV) |
| 配(日+夜) | 均数sheet月配合计(CR) + 夜班sheet月配合计(DW) |
| 借药(夜) | 夜班sheet月借药合计(DX)（日班无借药列） |

- 均数 sheet 月合计 = 日班纯窗口实际工作量 + 住院药房/机动/补休按当天门诊均数折算量。
- 因此个人汇总总工作总量 > 日班纯窗口实际总数，属正常（住院等岗位按门诊平均贡献折算绩效）。
