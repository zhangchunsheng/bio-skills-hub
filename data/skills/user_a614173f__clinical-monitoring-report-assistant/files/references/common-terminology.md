# 临床试验监查报告常用术语规范

## 一、访视类型术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 启动访视 | SIV (Site Initiation Visit) | 中心启动前进行的访视，确认中心具备开展试验的条件 |
| 常规监查访视 | IMV (Interim Monitoring Visit) | 试验进行期间的定期监查访视 |
| 关闭访视 | CSV (Close-Out Visit) | 中心完成所有试验活动后的最终访视 |
| 远程监查 | Remote Monitoring | 通过远程方式进行的监查活动 |
| 跟进访视 | Follow-up Visit | 针对特定问题的额外访视 |

## 二、数据核查术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 源数据验证 | SDV (Source Data Verification) | 将 CRF 中的数据与源文件进行逐项比对 |
| 源数据审核 | SDR (Source Data Review) | 对源文件本身的完整性和逻辑性进行审核 |
| 关键数据 | Key Data | 主要疗效指标、主要安全性指标等核心数据 |
| 数据质疑 | Query / DCF | 对 CRF 中数据的疑问，需研究者确认或更正 |
| 数据锁定 | Database Lock | 所有数据清理完成后锁定数据库 |

## 三、方案偏离术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 方案偏离 | Protocol Deviation (PD) | 未遵循方案要求的情况 |
| 重大方案偏离 | Major Protocol Deviation | 影响试验参与者安全或数据完整性的偏离 |
| 轻微方案偏离 | Minor Protocol Deviation | 不影响试验参与者安全和数据完整性的偏离 |
| 方案违背 | Protocol Violation | 严重违反方案或 GCP 要求的行为 |
| 超窗 | Window Deviation | 访视完成时间超出方案规定的时间窗 |
| 纠正与预防措施 | CAPA | 针对偏离采取的纠正和预防措施 |

## 四、安全性术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 不良事件 | AE (Adverse Event) | 试验参与者出现的任何不利的医学事件 |
| 严重不良事件 | SAE (Serious Adverse Event) | 导致死亡、危及生命、住院或延长住院、永久性残疾、先天畸形等 |
| 非预期严重不良反应 | SUSAR | 性质或严重程度与已有安全性信息不一致的 SAE |
| 因果关系 | Causality Assessment | 判断 AE 与试验药物的关系 |
| 严重程度分级 | Severity Grading | 通常采用 CTCAE 分级（1-5 级） |

## 五、药品管理术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 试验用药品 | IMP (Investigational Medicinal Product) | 试验中使用的研究药物 |
| 药品问责 | Drug Accountability | 药品从接收到销毁的全流程追踪 |
| 交互式网络应答系统 | IWRS / IRT | 用于药品分配和随机化的系统 |
| 药品接收 | Drug Receipt | 中心接收药品的记录 |
| 药品发放 | Drug Dispensing | 向试验参与者发放药品的记录 |
| 药品回收 | Drug Return | 回收试验参与者未使用药品的记录 |
| 温度偏移 | Temperature Excursion | 储存温度超出规定范围 |

## 六、文件管理术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 研究者文件夹 | ISF (Investigator Site File) | 研究中心保存的试验文件 |
| 试验主文件 | TMF (Trial Master File) | 申办方保存的试验文件 |
| 病例报告表 | CRF (Case Report Form) | 用于记录试验参与者数据的表格 |
| 电子病例报告表 | eCRF | 电子化的 CRF |
| 电子数据采集 | EDC (Electronic Data Capture) | 电子化数据采集系统 |
| 知情同意书 | ICF (Informed Consent Form) | 试验参与者签署的知情同意文件 |
| 授权分工表 | Delegation Log | 记录研究团队各成员职责授权的文件 |

## 七、表述规范

### 7.1 时态
- 描述已完成的监查活动：使用过去时（"本次核查了…""审阅了…"）
- 描述持续状态：使用现在时（"目前库存为…""当前温度为…"）
- 描述待办事项：使用将来时或祈使句（"需在 XX 日前完成…""建议…"）

### 7.2 人称
- 统一使用第三人称或无主语句式
- 正确："本次核查了试验参与者 1001-015 的 CRF 数据"
- 错误："我核查了试验参与者 1001-015 的 CRF 数据"

### 7.3 编号规范
- 试验参与者编号：统一使用"试验参与者 XXX"或"Subject XXX"
- 方案偏离编号：统一使用"PD-XXX"
- Query 编号：引用 EDC 系统中的 Query 编号
- SAE 编号：引用安全性数据库中的 SAE 编号
