# 法规检索指南

> 重要：本文件所列具体条款号、章节号与日期均为**常见映射示例与检索锚点**，并不保证绝对准确。
> 引用前必须按"标准检索流程"联网检索官方最新原文确认，禁止直接将本文件中的条款号当作既定事实写入报告。

## 一、检索原则
监查报告中涉及任何法规、指南、共识的引用，必须通过联网搜索检索官方来源的最新原文，确认条款号和表述准确后方可引用。禁止凭记忆引用法规条款。

## 三、检索流程

### 3.1 标准检索流程
```
识别法规引用需求
  ↓
确定法规类型（中国法规/广东省地方要求/ICH/其他）
  ↓
使用 web_search 工具检索官方来源
  ↓
核对条款号、条款内容、发布日期
  ↓
确认准确 → 在报告中以红色加粗字体标注
确认不准确/未找到 → 标注"待确认"，提示 CRA 核实
```

### 3.2 检索示例
示例1：引用 GCP 中关于 SAE 上报时限的条款
- 检索词："NMPA 药物临床试验质量管理规范 2026 SAE 报告时限"
- 预期结果：《药物临床试验质量管理规范（2026年修订）》（2026年第50号公告）相关条款
- 标注格式：【法规依据：《药物临床试验质量管理规范（2026年修订）》（2026年第50号公告）第X条】

示例2：引用广东省地方性共识
- 检索词："广东省药品监督管理局 临床试验 GCP 共识"
- 预期结果：找到广东省相关共识文件名称和发布机构
- 标注格式：【法规依据：广东省药品监督管理局《XX共识》（20XX年X月）第X条】

示例3：引用 ICH 指南
- 检索词："ICH E6(R3) 良好临床实践 监查 指导原则 章节"
- 预期结果：ICH E6(R3) Annex 1, Section 3.1
- 标注格式：【法规依据：ICH E6(R3) Annex 1, Section 3.1】

## 五、检索失败处理
若联网检索未能找到对应法规条款，按以下优先级处理：
1. 更换检索词重新检索（如用法规全称替代简称）
2. 检索发布机构官网的法规数据库
3. 若仍无法确认，在报告中标注：【法规依据：待确认——未能从官方来源检索到对应条款，请CRA核实后补充】
4. 禁止在未确认的情况下引用法规条款号和具体内容

## 六、法规更新追踪
法规可能随时间更新，使用时需注意：
- 引用时标注法规的发布/修订日期
- 若检索到同一法规的多个版本，以最新版本为准
- 对于已废止的法规，标注"已废止"并引用替代法规
- 建议 CRA 定期核查报告中引用的法规是否仍为现行有效版本
