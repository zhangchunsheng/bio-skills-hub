# 英文监查报告风格与术语指南（English Clinical Monitoring Report Style & Terminology Guide）

> 用途：当用户在「第零步」勾选「英文」功能时，依据本指南生成符合行业标准的英文监查报告（Clinical Monitoring Report / Site Monitoring Visit Report）。
> 目标三项：① 术语专业（对齐 ICH E6(R3) 与行业通用 SOP 用语）；② 语法标准（学术/监管文书体）；③ 描述清晰无争议（客观、可核、避免歧义）。

## 一、标准报告章节命名（Standard Section Structure）

按行业通用监查访视报告结构组织（可按用户模板增减，命名以模板为准）：

1. **Visit Identification / Cover Information** — Study title, Protocol No., Site No., Monitor name, Visit date, Visit type, Visit number
2. **Purpose of Visit**
3. **Site Personnel Present**
4. **Documents Reviewed**
5. **Enrollment & Subject Status** — Screening, Randomized/Enrolled, Completed, Withdrawn, Dropout
6. **Informed Consent Compliance**
7. **Source Data Verification (SDV)**
8. **Protocol Compliance & Deviations**
9. **Investigational Product (IP) Accountability**
10. **Adverse Events (AE) & Serious Adverse Events (SAE)**
11. **Data Management & Query Resolution**
12. **Essential Documents / Regulatory File (ISF)**
13. **Findings, Corrective and Preventive Actions (CAPA)**
14. **Action Items / Follow-up**
15. **Conclusion & Site Status**
16. **Monitor Sign-off**

术语使用规则：
- 缩写首次出现须拼写全称并附缩写，如 `Serious Adverse Event (SAE)`；后文可只用 `SAE`。
- 优先使用 ICH E6(R3)  Glossary 术语；本指南用语仅作锚点，正式报告以 ICH / 申办方 SOP 为准。

## 三、语法与文体标准（Grammar & Style）

1. **时态**：描述已发生的监查活动用**过去时**（The monitor reviewed… / SDV was performed…）；描述持续状态或结论用现在时。
2. **语态**：以**被动语态**表达客观发现（was identified / were documented / was confirmed），减少主观色彩。
3. **人称**：避免第一/第二人称主观判断；以事实与编号指代（Subject 001, Visit 3）。
4. **无争议表述**：
   - 不用模糊量词（"some / several / many" 无具体依据时）；用可核验表述（"3 of 12 consent forms"）。
   - 不臆造结论；缺失信息标注 `[To be supplemented: …]`；矛盾信息标注 `[To be confirmed: …]`。
   - 专业判定（偏离严重程度、因果关系、CAPA）标注 `[Subject to CRA review and confirmation]`。
5. **数字与日期**：日期用 ISO 格式 `YYYY-MM-DD`；数字与单位间留空格（e.g., `25 mg`）；编号统一。
6. **法规引用**：保留官方英文出处（如 `ICH E6(R3), Section 4.5.1`）并加注中文法规名以便核查；若需检索以确认条款，按 SKILL.md 第三节强制联网检索后标注。
7. **一致性**：同一术语、缩写、编号在全文中保持一致；章节命名与用户模板一致。

## 四、质量自检要点（与中文报告同等要求）

- 每个发现对应具体 Subject No. / Visit / 文件 / 数据条目（可追溯）。
- 所有 `[To be supplemented]` / `[To be confirmed]` / `[Subject to CRA review and confirmation]` 标注完整。
- 法规引用已检索官方原文并标注来源。
- 无歧义表述、无拼写/语法错误、术语统一。

> 注：本指南所列章节与术语为行业标准锚点；最终以用户模板、申办方 SOP 及实时检索到的官方法规原文为准，不得直接套用未核实内容。
