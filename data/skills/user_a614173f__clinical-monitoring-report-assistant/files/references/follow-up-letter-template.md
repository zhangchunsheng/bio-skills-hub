# 随访信（Follow-up Letter）生成模板

> 用途：当监查发现需研究者 / 申办方跟进（如方案偏离确认、数据质疑、文件补正）时，生成随访信初稿。
> 原则：仅基于用户提供的监查发现生成；专业判断与时限标注 `[待CRA审核确认]`；最终由 CRA 审核后发出。本文件为结构模板，非法规引用，无需联网检索。

## 一、标准结构
1. 标题：随访信 / Follow-up Letter（含中心编号、访视日期）
2. 致：主要研究者（PI）姓名 / 机构
3. 发：CRA 姓名、日期
4. 事由：本次监查发现概述（引用监查报告编号）
5. 跟进事项清单（逐条）：
   - 事项描述（对应具体试验参与者编号 / 访视 / 文件）
   - 要求（补正 / 确认 / 提供说明）
   - 时限要求（标注 `[待CRA审核确认]` 或引用项目 SOP）
   - 责任人
6. 联系人及回复方式
7. 署名

## 二、字段模板
> 致：[PI 姓名]，[机构名称]
> 关于：[中心编号] [访视类型 / 日期] 监查报告（报告编号：[XX]）的跟进事项
>
> 尊敬的 [PI 姓名]：
> 根据 [日期] 监查发现，以下事项需贵中心跟进：
> 1. [试验参与者编号]：[具体发现 / 偏离描述]，请于 [时限，待CRA审核确认] 前提供 [补正 / 说明]，并反馈至 CRA。
> ……
> 如有疑问，请联系 [CRA 姓名]，[邮箱 / 电话]。
> 此致
> [CRA 姓名]
> [日期]

## 三、质量自检（生成后）
- [ ] 每条跟进事项对应到具体试验参与者编号 / 访视 / 文件
- [ ] 时限均已标注（引用 SOP 或 `[待CRA审核确认]`）
- [ ] 未包含任何未脱敏患者隐私信息
- [ ] 语气客观、专业
- [ ] 已注明"本信为初稿，须经 CRA 审核后发出"
