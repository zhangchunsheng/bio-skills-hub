# 监查报告质量检查清单

> 使用说明：本清单用于 CRA 在提交监查报告前自查，也可作为 AI 生成报告后的质量校验依据。逐项检查，确保报告质量达标。

## 一、结构与格式
- [ ] 报告板块结构与项目模板完全一致，未自行增减板块
- [ ] 板块顺序与模板一致
- [ ] 所有必填字段均已填写或标注 [待补充]
- [ ] 报告包含基础信息（中心编号、日期、访视类型、CRA 姓名）

## 二、内容完整性
- [ ] 上次访视遗留问题逐一跟进，标注解决状态
- [ ] 本次监查的所有发现均已归入对应板块
- [ ] 方案偏离已完整记录（编号、描述、分类、原因、CAPA）
- [ ] 安全性事件已完整记录（试验参与者编号、AE 描述、分级、因果关系、处理措施）
- [ ] 待解决问题清单已列出，包含责任人和预计解决时间

## 三、准确性与可追溯性
- [ ] 所有数据引用可追溯到具体源文件（如"源文件第 X 页""CRF 页面 XX"）
- [ ] 试验参与者编号准确无误
- [ ] 日期信息准确（访视日期、偏离日期、SAE 发生日期等）
- [ ] 方案条款引用准确（如"方案第 X.X 节"）
- [ ] 数值数据与源文件一致（如实验室检查结果、生命体征等）

## 四、法规引用合规性
- [ ] 所有涉及法规引用的内容均已通过联网搜索检索官方来源
- [ ] 法规条款号和条款内容经核对准确无误
- [ ] 所有法规引用处均使用红色加粗标注了法规来源（Markdown 用 HTML span 或加粗退化方案）
- [ ] 标注格式统一为：【法规依据：法规名称（版本/日期）第 X 条】
- [ ] 检索优先级正确：NMPA/CDE > 广东省地方要求 > ICH > 其他
- [ ] 无法确认的法规引用已标注"待确认"，未擅自引用
- [ ] 引用的法规均为现行有效版本，已标注发布/修订日期
- [ ] 术语已对齐《药物临床试验质量管理规范（2026年修订）》表述（如"重要方案偏离"而非"重大方案偏离"）
- [ ] 报告末尾已汇总所有法规引用清单

## 五、专业规范性
- [ ] 使用标准术语（参见 common-terminology.md）
- [ ] 方案偏离分类合理（参见 pd-classification-guide.md）
- [ ] AE 因果关系判断有依据
- [ ] 专业判断处已标注 [待CRA审核确认]
- [ ] 无主观推测性表述

## 六、语言规范
- [ ] 使用过去时描述已完成的监查活动
- [ ] 使用第三人称或无主语表述
- [ ] 表述客观、专业、简洁
- [ ] 无口语化表述
- [ ] 无错别字和语法错误

## 七、待补充内容检查
- [ ] 所有 [待补充] 标注已汇总列出，方便 CRA 集中补充
- [ ] 所有 [待确认] 标注已汇总列出，方便 CRA 集中核实
- [ ] 所有 [待CRA审核确认] 标注已汇总列出，方便 CRA 重点审核
- [ ] 所有法规"待确认"标注已汇总列出，方便 CRA 核查法规来源
