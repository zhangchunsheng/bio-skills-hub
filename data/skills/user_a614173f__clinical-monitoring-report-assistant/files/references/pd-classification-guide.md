# 方案偏离分类指南

> 本文件为方案偏离（PD）严重程度分类的参考。**具体分类需 CRA 结合场景判断，专业判断处标注 `[待CRA审核确认]`。**

> <span style="color:red;font-weight:bold">【术语对齐：《药物临床试验质量管理规范（2026年修订）》（2026年第50号公告，2026年9月1日起施行）第二十三条采用"重要方案偏离"表述。本文件据此将偏离分为"重要方案偏离"与"一般方案偏离"；既往"重大/轻微方案偏离"为旧版（2020 GCP）及实务惯用表述，"重大"与"重要"同义。】</span>

## 一、分类原则
方案偏离的严重程度分类应综合考虑以下因素：
1. 对试验参与者安全的影响程度
2. 对数据完整性和可靠性的影响程度
3. 对试验参与者权益的影响程度
4. 偏离的持续时间和可逆性

## 二、分类标准

### 2.1 重要方案偏离（Significant PD）
> <span style="color:red;font-weight:bold">【术语依据：《药物临床试验质量管理规范（2026年修订）》第二十三条，采用"重要方案偏离"表述；既往"重大方案偏离"与之同义，属需重点向申办者报告并视情况报告伦理委员会的情形】</span>

定义：显著影响试验参与者安全、权益或数据完整性的方案偏离（即 2026 GCP 所称"重要方案偏离"）。

常见情形：
- 试验参与者不满足入选标准或满足排除标准仍被入组
- 知情同意缺失或签署不规范（如签署日期晚于研究操作）
- 使用禁止的合并用药且可能影响安全性或疗效评估
- 剂量错误导致试验参与者暴露于过量或不足的药物
- SAE 未在规定时限内上报
- 关键疗效评估缺失（如主要终点检查未做）
- 试验参与者随机化错误

报告要求：
- 发现后及时通知申办方（具体时限请检索 2026 GCP 及项目 SOP 确认）
- 需详细记录偏离原因、影响评估、CAPA 措施
- 可能需要报告伦理委员会

### 2.2 一般方案偏离（通用表述）
> 注：2026 GCP 以"重要方案偏离"为正式报告术语，未使用"轻微方案偏离"一词。对影响较小的偏离，本文件称"一般方案偏离"，按项目 SOP 在常规监查报告中记录即可，通常不强制报告伦理委员会（具体以项目 SOP 与 2026 GCP 实时检索为准，标注 `[待CRA审核确认]`）。

定义：对试验参与者安全和数据完整性影响较小的方案偏离（既往常称"轻微方案偏离"）。

常见情形：
- 访视超窗（通常 ≤7 天，且不影响关键评估）
- 非关键检查项目遗漏或延迟
- 非关键实验室检查超窗
- 文件签署延迟（如授权分工表更新不及时）
- 非关键 CRF 页面填写延迟

报告要求：
- 在常规监查报告中记录
- 记录偏离描述、原因、纠正措施

### 2.3 边界情况处理
以下情况需 CRA 根据具体场景判断分类：
- 访视超窗 7-14 天：需评估超窗是否影响关键评估
- 非禁止合并用药但未提前报备：需评估是否影响安全性
- 实验室检查超窗但结果正常：需评估对数据完整性的影响

## 三、分类判断流程

```
发现方案偏离
  ↓
是否影响试验参与者安全？
  ├── 是 → 重要偏离
  └── 否 → 是否影响数据完整性？
              ├── 是 → 是否涉及主要终点/关键数据？
              │         ├── 是 → 重要偏离
              │         └── 否 → 一般偏离
              └── 否 → 是否影响试验参与者权益？
                        ├── 是 → 重要偏离
                        └── 否 → 一般偏离
```

## 四、监查报告中的偏离记录规范

### 4.1 必要字段
每条方案偏离记录应包含：
- 偏离编号（PD-XXX）
- 试验参与者编号
- 偏离发生日期
- 偏离发现日期
- 偏离描述（引用方案具体条款）
- 偏离分类（重要/一般，按 2026 GCP 术语）
- 原因分析
- 影响评估
- 纠正措施
- 预防措施（CAPA）
- 研究者确认签名/日期

### 4.2 描述模板
> "试验参与者[编号]的[具体事件]，方案第[X.X]节规定[方案要求]，实际情况为[实际发生情况]，偏离持续时间为[时长]，已记录为[重要/一般]方案偏离 PD-[编号]。"

### 4.3 示例
重要偏离示例：
> "试验参与者 1001-008 入组时未进行方案第 4.2 节要求的基线 MRI 检查，该检查为主要疗效评估的关键依据。已记录为重要方案偏离 PD-1001-008，研究者已安排补做 MRI，伦理委员会已获知。"

一般偏离示例：
> "试验参与者 1001-005 的访视3计划日期为随机化后第 84 天±7 天（方案第 6.3 节），实际完成日期为随机化后第 94 天，超出时间窗 3 天，未影响关键评估项目。已记录为一般方案偏离 PD-1001-005。"
