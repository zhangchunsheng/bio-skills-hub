# 中国公开范本与蒸馏结果

检索核验日期：2026-07-28。以下选取的是三种互补的中国官方“规范/提纲型范本”，不把它们误称为可直接套用的企业内部成文报告。

## 1. 企业全面风险管理范本

**来源**：国务院国资委《中央企业全面风险管理指引》（国资发改革〔2006〕108号）

官方链接：

- https://www.sasac.gov.cn/gzjg/qygg/200606200105.htm
- https://wap.sasac.gov.cn/n2588035/n2588320/c4426962/content.html

适用：企业年度全面风险、重大决策、重大事件和重要业务流程风险评估。

关键结构：

1. 收集战略、财务、市场、运营、法律等风险初始信息；
2. 风险辨识、风险分析、风险评价；
3. 制定风险管理策略；
4. 提出并实施风险管理解决方案；
5. 监督与改进；
6. 董事会/风险管理委员会审议重大风险与报告。

可蒸馏要点：

- 风险评估必须服务于企业目标和治理决策；
- 定性与定量结合，分析风险之间的相关性和组合效应；
- 风险排序之后仍需策略、方案、责任和监督闭环；
- 风险偏好和承受度属于管理层/治理层口径，不能由报告撰写者臆定。

局限：它是企业风险管理框架，不是逐章填空式报告；具体分级、表格和证据要求需组织自定。

## 2. 项目风险评估报告大纲

**来源**：国家发展改革委《重大固定资产投资项目社会稳定风险评估报告编制大纲及说明（试行）》（发改办投资〔2013〕428号附件2）

官方链接：

- https://www.ndrc.gov.cn/fggz/gdzctz/tzfg/201907/W020191104862123790201.pdf
- https://zfxxgk.ndrc.gov.cn/upload/images/20229/202292711274972.pdf

适用：重大固定资产投资项目社会稳定风险评估，也可借鉴其报告骨架。

关键结构：

1. 基本情况：项目、依据、评估主体、过程与方法；
2. 风险调查和各方意见采纳；
3. 风险识别与估计；
4. 防范化解措施评价；
5. 落实措施后的风险等级；
6. 评估结论与应急建议。

可蒸馏要点：

- 评估要说明主体、程序、证据来源与利益相关者意见；
- 必须评价原分析是否完整、客观、方法适用；
- 措施应落实到责任主体、协助单位、控制节点和实施时间；
- 结论应是“措施后风险”，而不是只列固有风险；
- 合法性、合理性、可行性、可控性提供通用的项目审查视角。

局限：风险领域聚焦社会稳定，不能直接替代财务、安全、网络或企业全面风险评价标准。

## 3. 信息安全风险评估范本

**来源**：GB/T 20984-2022《信息安全技术 信息安全风险评估方法》

官方链接：

- https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=FDA38AB7D08A715C6B6D69DFDEABB2C0
- https://std.samr.gov.cn/gb/search/gbDetailed?id=DD3D95E5C09371EBE05397BE0A0AF33F
- https://datasec.sic.gov.cn/sic/83/260/0429/11483_pc.html

状态：现行；2022-04-15发布，2022-11-01实施。

适用：各类组织的信息安全风险评估。

关键结构：

1. 评估准备；
2. 业务、系统资产及其边界识别；
3. 威胁、已有安全措施和脆弱性识别；
4. 风险分析与评价；
5. 业务层与系统资产层的风险呈现；
6. 生命周期不同阶段的评估。

可蒸馏要点：

- 以业务目标为最高管控对象，而非只罗列技术漏洞；
- 风险要联系资产、威胁、脆弱性、控制和业务影响；
- 控制有效性必须单独分析；
- 管理层总览和技术明细应分层输出。

局限：专注信息安全；其风险模型不能机械复制到财务、市场或人身安全领域。

## 三份范本的合并映射

| 通用环节 | 国资委 | 发改委 | GB/T 20984-2022 | Skill 统一要求 |
|---|---|---|---|---|
| 目标与边界 | 企业目标、业务流程 | 项目概况与评估主体 | 业务与系统边界 | 对象、目标、范围、时间跨度 |
| 证据 | 初始信息 | 资料审阅、调查、意见 | 资产、威胁、控制证据 | 可定位证据台账 |
| 识别 | 风险辨识 | 风险因素补充完善 | 资产—威胁—脆弱性 | 原因—事件—后果 |
| 分析 | 可能性、影响、关联性 | 概率、影响、持续时间 | 风险要素与模型 | 固有风险、速度、关联、置信度 |
| 控制 | 解决方案 | 防范化解措施 | 已有安全措施有效性 | 设计与运行有效性分开 |
| 控制后评价 | 监督改进 | 措施后风险等级 | 风险评价 | 剩余风险与偏好对照 |
| 行动 | 策略与方案 | 责任、节点、时间 | 处理与生命周期 | 责任人、日期、KRI、触发器、验证 |

## 使用原则

- 三者用于提炼结构和方法，不意味着所有项目均受三份文件直接约束。
- 行业法规、地方要求、合同和组织制度优先；引用前核验适用性与最新状态。
- 若用户要求“企业范本”，可在上述框架基础上查找其指定行业或公司公开报告，但不得把营销材料当权威标准。
