# 领域模块

先使用通用流程，再按评估对象加载相关模块。模块是补漏清单，不是固定目录。

## 企业全面与战略

- 战略假设、政策与宏观环境、竞争格局、商业模式；
- 重大决策与资本配置、组织能力、治理与授权；
- 目标分解、风险偏好、重大风险所有人和董事会监督；
- 风险相关性、集中度、跨业务传导和机会风险。

重点证据：战略规划、预算、董事会材料、经营数据、风险偏好声明、重大决策记录。

## 投资与建设项目

- 需求、市场、选址、土地与许可、技术方案；
- 进度、造价、融资、现金流、承包商和供应链；
- 质量、安全、环境、社会影响、网络与数据；
- 全生命周期运营、退出和应急。

重点方法：合法性、合理性、可行性、可控性；情景分析；关键路径和成本敏感性。

融资证据至少检查贷款承诺/审批进展、提款条件、利率与期限、担保与契约、建设期付息、成本超支资金来源、投产后偿债现金流和合理不利情景。

安全、环保、消防等法定前置事项应明确“许可—施工—试运行—投产”的适用顺序和阶段门。未满足法定前置条件时，不能用综合分数批准跨越。

## 财务与流动性

- 盈利质量、现金流、营运资金、融资与偿债；
- 利率、汇率、商品价格、信用、税务；
- 资产减值、担保、或有负债、表外安排；
- 集中度、契约条款和流动性压力。

财务风险必须基于有日期和口径的数据。不要把会计利润等同于现金能力，不要在缺少可靠模型时编造违约概率。

## 法律、合规与廉洁

- 适用法规与许可、合同义务、监管报告；
- 反商业贿赂、制裁与出口管制、竞争、隐私；
- 利益冲突、关联交易、举报与调查；
- 违法后果、整改期限、个人与组织责任。

法律结论需注明是否经专业法律意见核验；矩阵不能覆盖法律禁止或合规红线。

## 运营、质量与供应链

- 流程能力、设备、维护、产能、库存和计划；
- 客户与供应商集中度、单一来源、物流；
- 质量体系、变更控制、召回和追溯；
- 人员、外包、业务连续性和恢复。

第三方认证仅是证据之一。若核心决策为供应商入库，应转用供应商准入专门 Skill。

## 生产安全与环境

- 危险源、暴露对象、事故场景、屏障与失效模式；
- 人员伤害、职业健康、消防、设备完整性；
- 污染、排放、资源、极端天气、生态影响；
- 应急资源、演练、报告和事故调查。

人员死亡、重大环境违法等不得因概率低而被平均稀释。技术判断应由相应资质人员和现场证据支持。

## 网络、信息与数据

以业务连续性和数据价值为起点：

- 业务、信息系统、数据、网络和组件边界；
- 威胁来源、能力、动机、路径和频率；
- 身份、访问、配置、漏洞、供应链和人员脆弱性；
- 预防、检测、响应、备份与恢复控制的有效性；
- 机密性、完整性、可用性、合规和业务影响。

输出至少分为管理层业务风险总览和技术明细。漏洞严重度不等于业务风险，必须结合可利用性、控制和业务影响。

## 第三方与外包

- 主体、所有权、财务韧性、合规记录；
- 服务范围、数据访问、分包、人员与地域；
- SLA、审计权、事件通知、退出与数据返还；
- 替代性、集中度、连续性和合同救济。

风险评估结论不是中标、采购或准入承诺。
