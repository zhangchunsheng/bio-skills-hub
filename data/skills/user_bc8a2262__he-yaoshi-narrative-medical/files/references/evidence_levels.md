# 循证医学证据分级表

## 一、循证医学证据等级体系

### 1.1 牛津证据分级 (OCEBM)

| 等级 | 证据类型 | 说明 |
|------|---------|------|
| 1a | RCTs的系统评价 | 同质性随机对照试验的系统评价 |
| 1b | 单个RCT | 置信区间窄的单个随机对照试验 |
| 1c | 全或无研究 | 所有患者均死亡但某些存活的疗法；或部分死亡但治疗使更多患者存活 |
| 2a | 队列研究的系统评价 | 同质性队列研究的系统评价 |
| 2b | 单个队列研究 | 包括低质量RCT的单个队列研究 |
| 2c | 结局研究 | 生态学研究 |
| 3a | 病例对照研究的系统评价 | 同质性病例对照研究的系统评价 |
| 3b | 单个病例对照研究 | - |
| 4 | 病例系列 | 低质量的队列和病例对照研究 |
| 5 | 专家意见 | 无批判性评价的专家意见 |

### 1.2 GRADE系统

| 证据等级 | 含义 | 说明 |
|---------|------|------|
| 高 (A) | 非常有信心 | 真实效应接近效应估计 |
| 中 (B) | 对效应估计有中等信心 | 真实效应可能接近效应估计，但也可能存在显著差异 |
| 低 (C) | 对效应估计信心有限 | 真实效应可能与效应估计显著不同 |
| 极低 (D) | 对效应估计几乎无信心 | 真实效应很可能与效应估计显著不同 |

### 1.3 中国循证医学分级

| 等级 | 证据类型 |
|------|---------|
| Ⅰa | 同一项目的随机对照试验系统评价 |
| Ⅰb | 单个随机对照试验(可信区间窄) |
| Ⅱa | 队列研究系统评价 |
| Ⅱb | 单个队列研究 |
| Ⅲa | 病例对照研究系统评价 |
| Ⅲb | 单个病例对照研究 |
| Ⅳ | 病例系列 |
| Ⅴ | 专家意见、病例报告 |

## 二、推荐强度分级

### 2.1 GRADE推荐强度

| 推荐等级 | 说明 | 适用情况 |
|---------|------|---------|
| 强推荐 (1) | 非常确信干预利大于弊 | 适用于几乎所有患者 |
| 弱推荐 (2) | 干预可能利大于弊 | 适用于部分患者，需考虑个体情况 |

### 2.2 中国推荐等级

| 推荐等级 | 说明 |
|---------|------|
| A | 强力推荐：证据明确支持或反对 |
| B | 推荐：证据支持但不太确定 |
| C | 可选：证据不足，需个体化决策 |
| D | 不推荐：证据不支持或有害 |

## 四、常见疾病证据汇总

### 4.1 心血管疾病

#### 高血压
- **一线药物**：ACEI/ARB、CCB、利尿剂 (A级推荐)
- **证据**：多项大型RCT证实降压可减少心血管事件
- **目标血压**：一般<140/90 mmHg，老年人可适当放宽

#### 冠心病
- **抗血小板**：阿司匹林终身、氯吡格雷/替格瑞洛一年 (A级)
- **降脂治疗**：高强度他汀 (A级)
- **二级预防**：多因素综合干预

#### 心房颤动
- **卒中预防**：CHA₂DS₂-VASc评分评估，OAC抗凝 (A级)
- **节律控制**：抗心律失常药、导管消融
- **心室率控制**：β阻滞剂、CCB、地高辛

### 4.2 内分泌疾病

#### 2型糖尿病
- **二甲双胍**：一线药物 (A级)
- **GLP-1受体激动剂/SGLT2抑制剂**：有心血管获益 (A级)
- **血糖控制目标**：HbA1c一般<7%，个体化调整

#### 甲状腺疾病
- **甲亢**：ATD、放射性碘、手术各有所长
- **甲减**：左甲状腺素替代 (A级)

### 4.3 肿瘤

#### 常见实体瘤
- **化疗**：依据分期和病理类型
- **靶向治疗**：基于基因检测
- **免疫治疗**：PD-1/PD-L1抑制剂

#### 支持治疗
- **疼痛**：WHO三阶梯镇痛
- **恶心呕吐**：5-HT3拮抗剂、NK1受体拮抗剂
- **营养支持**：NRS2002评估

### 4.4 精神心理

#### 抑郁症
- **一线治疗**：SSRIs、SNRIs (A级)
- **心理治疗**：CBT、人际治疗
- **联合治疗**：药物+心理

#### 焦虑障碍
- **一线治疗**：SSRIs、SNRIs (A级)
- **短期**：苯二氮卓类

### 4.5 感染性疾病

#### 细菌感染
- **原则**：尽可能做病原学检查
- **经验治疗**：根据感染部位和常见病原体
- **抗生素管理**：避免过度使用

#### 病毒感染
- **流感**：奥司他韦早期使用
- **乙肝**：核苷酸类似物长期治疗
- **HIV**：ART抗逆转录病毒治疗

## 五、证据检索策略

### 5.1 检索词构建
1. **PICO原则**：
   - P (Patient/Population)：患者特征
   - I (Intervention)：干预措施
   - C (Comparison)：对照措施
   - O (Outcome)：结局指标

2. **布尔运算符**：AND、OR、NOT

3. **截词符**：* (无限截词)、? (有限截词)

### 5.2 检索式示例

#### 糖尿病合并高血压
```
("diabetes mellitus"[MeSH Terms] OR "type 2 diabetes"[Title/Abstract])
AND
("hypertension"[MeSH Terms] OR "antihypertensive"[Title/Abstract])
AND
("treatment outcome"[MeSH Terms] OR "guideline"[Title])
```

#### 某药物疗效评价
```
[药物名称] AND ("randomized controlled trial"[Publication Type] OR "meta-analysis"[Publication Type])
```

### 5.3 筛选流程
1. 初筛：标题和摘要
2. 复筛：全文阅读
3. 质量评价：Jadad量表、ROB量表
4. 数据提取：标准化表格
5. 合成分析：定性/定量

## 六、注意事项

1. **证据不是一成不变**：需关注最新研究和指南更新
2. **证据≠推荐**：需结合临床情境和患者意愿
3. **关注中国特色**：某些疾病可能有中国人群特点
4. **伦理考量**：循证不能代替伦理判断
5. **经济因素**：考虑卫生经济学证据
