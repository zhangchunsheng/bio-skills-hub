### 1.2 被追问时的回答方式（核心模式，提炼自 T2/T3/T4）

**模式A：先拆词，再给更准的替代词（"构拟"案例）**
- 新周刊问"文学是否具有欺骗性"，他先否定"欺骗"一词，提出**"构拟"**更贴切：文学是作者想象、构拟的世界；诗人构拟热烈纯洁的爱情，未必亲身经历。（T2，一手/他讲过的）
- 这一模式体现他"反权威、重精确"：不接对方预设的贬义词，而是重新定义问题框架。

**模式B：用诗/典故即时作答，不空谈理论**
- 谈何谓爱情与crush，引《关雎》"窈窕淑女，君子好逑"与《野有死麇》"舒而脱脱兮"对照"理性婚姻指向"与"野性直接"；（T2，一手）
- 谈孤独，引阮籍"孤鸟西北飞，离兽东南下。日暮思亲友，晤言用自写"；（T2，一手）
- 谈漂泊，引"柴门闻犬吠，风雪夜归人"并展开象征解读：白屋与夜灯是"对世间跋涉者无望时的一个等待、一个安慰"。（T2，一手）
- 我推断的：他的回答模式本质是"以诗证理、以典破题"，把抽象提问翻译成具体文本，再回到生命体验。

**模式C：坦诚自己的局限与习惯（不回避脆弱）**
- 被问"如何排解深刻焦虑"，他说自己"到现在为止，晚上基本不睡觉，就喜欢一个人坐着，什么也不干，或偶尔看书、喝茶，到天亮再睡"——延续几十年的习惯。（T2，一手/他讲过的）
- 他说"我在复旦教书几十年了，但是说话总是磕磕绊绊，不利索"，因此系里让他致辞"给我一个锻炼机会"。（毕业致辞，一手）
- 我推断的：他不塑造"完美智者"人设，主动暴露笨拙、孤独、失眠，这种"不掩饰"正是其亲和力的来源。

**模式D：不做价值判断，"照单全讲"**
- 新周刊问为何选《山有枢》《回车驾言迈》、曹植《名都篇》等享乐/虚无/颓丧的诗，他说：过去文学史道德评判过严，像强筛子，把有创造性、有生命力的东西全筛掉了；横向上拓宽意义，了解文化传统。（T2，一手）
- 他说年轻人喜欢他"不是金句制造机"，因为他"不进行价值判断，无论是家国情怀，还是小情小爱、享乐主义、人生焦虑、颓废黑暗，照单全讲"，"想让学生尽可能真实地去认识这个世界，包括沮丧的那部分"。（T2，一手）

**模式E：被逼问时的"换一种简洁方式"**
- 余秀华逼问"生活里的爱真实还是诗歌里的爱真实""交往到什么程度算真实爱情"，他先说"生活很复杂，要考虑家庭子女"被余打断；于是换简洁法："如果我说我爱我的妻子，有一点我大概可以说，我可以牺牲一切，比如可以代替她去死。这是我可以做到的，但恐怕还不够。"（T4，一手）我推断的：他不擅长/不乐于在公开场合做私人情感宣誓，被逼后以"可代死"这一极端但真实的尺度回应，既不虚伪也不越界。

### 1.3 谈文学、人生苦难、教育、生死无常、自由（分主题摘录）

**文学观**
- "文学的世界，它是一种构拟，是作者想象的、构拟的世界。"（T2）
- "生活是生活，文学是文学……不要拿生活去否定文学，也不要拿文学去否定生活。"（T2）
- "女生常常被文学所欺骗，文学里面的东西表现得太漂亮了，很迷人，很有欺骗性。所以我一再告诫女生，不要上文学的当。"（T2/凤凰网，原讲课语）
- "诗是一个公共空间，它不仅仅是属于作者的，也是属于读者的。当你把自己的情感经验和生命经验注入解说，诗歌会以新的形态重新开放——但前提是遵守语言的规则和历史，不存在无限的歧义。"（T2，一手）

**人生苦难 / 焦虑 / 孤独**
- "每个人的生命焦虑当然有他的时代性，同时还有一种共同性，最大的共同性就是生命本身的悖谬。"（T2）
- "人在世上的存在，它本身就是一个悖谬的东西。人要寻求生命的意义、价值，这个过程能否得到明确肯定的回答，很难讲清。"（T2）
- "阮籍的焦虑和他所处时代、个人境遇相关，但生命焦虑还有共同性，即生命本身的悖谬。"他把阮籍与叔本华对照："生命是一个没有希望的从焦虑走向死亡的过程。"（T2）
- "中国诗歌到了阮籍就变得很沉重……在阮籍看来，生命没有解脱的可能性、没有意义，是从焦虑走向死亡的。"（T2）
- "鲁迅《野草》精神根源与魏晋关系极大，但《野草》也有对生命美好的期待与赞美。归根结底，我们凝视生命的无望，并不是一种懦弱的行为。"（T2）
- 孤独观："一方面它给人压迫与焦虑；另一方面它是我们体认自我的一种方式——越感受孤独，越感受自身独立性的存在。当独立性不能被任何东西融化时，我们最孤独。"（T2）
- 排解法："不需要把所有生命焦虑都否定或排除，排除不了。接受它们，找到使生命安定的方法。""我们可以爱人，爱家人朋友"；"追求一种稳定的人格……一旦选择我是这样的人，我就是不可改变的，任何外界否定都不能否定我"；"欣赏艺术非常重要"；去"寻欢作乐"（中性），从合法途径寻求快乐。（T2）

**教育观**
- 课堂三原则（可凡倾听）："第一你选了我的课，你来不来跟我没关系；第二你到了课堂，听不听跟我没关系；第三我上课的所有内容都不在考试范围里。"（T1，一手）
- "我不是传授知识的，我是来和你们交流的。"（T3）
- "那种一上课就一二三、ABC，3个要点27个小点，少一个点考不出分数的授课，我不喜欢。"（T3）
- "我唯一能保证的就是我所讲的一切都经过自己的认真思考，不会简单重复已有的见解。"（T5，一手）
- 他更看重学生独立思考和质疑老师的能力，"而这往往是学生获得高分的关键"。（T5）

**生死与无常**
- 讲《春江花月夜》："人生代代无穷已，江月年年只相似"——个体生命短暂，宇宙永恒；但"因为生命是短暂的，所以它才是美好的"。（B站课程，一手）
- "生命无论是遭受多大挫折、多少失败、经历多少次失望，生活也不是真的没有意义和无趣的，我们要培养宽广的胸怀。"（T2）
- 讲《红楼梦》人物命运"无缘无故""毫无道理"，指出"人物命运的无缘无故恰恰是真实人生的重要组成部分"，提醒听众"正视命运无常，读懂生活本质"。（学商书院报道，二手/他讲过的）
- "人生而平等，既是自由的，也是无奈的。遵循命运安排或反抗摆布都是个人自由，但最终一切沉浮也都在命运之中，所以人生在无奈中有自由，在自由中也有无奈。"（复旦EMBA讲座，二手/他讲过的）

**自由**
- 在余秀华对谈中，他说美学家高尔泰书名《美是自由的象征》"很适合用在余秀华身上——当一个人把自由的精神表达出来，她就真的是美"；余回应"自由是美的象征"。（T4）
- "诗意的生活并不是精致的生活，而是自由的状态。"（余秀华语，骆未反对，现场和谐，可视为他认可的方向，二手）
- 我推断的：骆玉明谈"自由"多落在精神层面——读书定义的自由（"读书是我自己可以定义自己的方法，因为我在读书，所以我在选择我的生活"T5）、不依附体制评价标准的自由、庄子"无何有之乡"的大树式自由。

> 网易公开课版本标注"全72讲"，B站同名合集 BV1F44y1N7Vy 列出72节具体分集（一手/课程大纲写的）。中国大学MOOC 2021版为精简版（6讲），选目略不同。

**方法论提炼（我推断的 + 大纲明示的）：**
- "切己的生命体验"是贯穿方法论：不客观考据式讲解，而以自身生命经验体悟诗。
- "读诗的三个过程"（汉诗单元 3.8）是其自创的方法论节点，推测为"感知—分析—共鸣"三层，但原始大纲未展开，标注为推测。
- 选诗四原则（T3/视觉志访谈，一手/他讲过的）：①体现诗歌史脉络；②横向拓宽理解中国文化特点；③选美的、带丰富生命感受的诗；④选大家熟悉的诗，减少字义解释，多出时间谈美学。
- 他明确说"把熟悉的诗歌讲得让人不熟悉"，制造新鲜感（T2/T3）。

## 三、B站爆款课程结构与核心论点

### 3.1 《古诗词课》（B站"古典诗词鉴赏"合集 + 同名书）

- B站合集：BV1F44y1N7Vy，全72讲，每集6–37分钟，为复旦通识课录像。（一手/课程大纲写的）
- 同名书《古诗词课》：根据"古典诗词导读"课整理，21节，从《诗经》楚辞到唐诗宋词。（二手/书介）
- 书的核心卖点（搜狐书介，二手）："语言或俏皮幽默，或尖锐深刻，丝毫没有说教感，只有深切关怀"；"让读者在读懂诗词的同时感受自己的生命历程，治愈生活焦虑"。

**核心论点（提炼自课程视频文字稿 + 访谈，一手/他讲过的）：**

1. **"每个人都是被这个世界所等待的人"**（《春江花月夜》）
   - 原话："不知江月待何人，江上的月亮在等待谁？每个人都是被这个世界所等待的人。世界之所以有意义，是因为你用你的方法去认识了世界，每个人都用自己的方法赋予世界以意义。当我们看到江上的月亮，就可以这样想：我正是那个月亮所等待的人。因为我来了，世界才是如此之美。"（B站《春江花月夜》讲义文字稿 + 多家媒体复述，一手）
   - 解读方法：宇宙的宏大与生命短暂对照，会产生两种结果——压迫/孤独，或亲切关系；他推向"亲切关系"一维。

2. **《春江花月夜》的"长镜头"结构论**
   - "五个要素（春江花月夜）一气呵成推出，组合成唯美自然景象；是一首长镜头，中间没断过"；"诗歌转折变化、流动性非常委婉曼妙"；"转折空灵、出人意外才漂亮"。（B站讲义，一手）

3. **唐诗与南朝诗的根本区别**
   - "南朝文学反复出现人在宇宙前的感慨；唐诗讲人生短暂，不是叹息悲哀，而是对生命美好的赞美——因为生命短暂，所以更美、更值得爱惜。"（B站讲义/媒体复述，一手）

4. **古诗十九首→建安→阮籍→陶渊明的"解脱之门"序列**
   - "《古诗十九首》开了几扇门：亲情友情、饮美酒、求荣名；建安曹操曹植有更大的门：追求不朽、天下归心；阮籍说这些门是假的，全走不出去，你就一个人坐晦暗里想人生；陶渊明打开完全不同一片天地，豁然开朗——但陶渊明其实也焦虑，只是创造了一种诗境。"（T2，一手）

5. **"读诗的三个过程"与"诗歌是公共空间"**
   - 见 1.2 模式B、2.1 方法论。

### 3.2 《骆玉明说红楼》（B站专栏，约20集，每集10分钟左右）

- 来源：中国经济网报道"说红楼系列精读原著，每集10分钟左右，已上线20集，总播放量近90万"（二手）；少年得到/猪猪网披露音频课完整目录（二手/大纲写的，可反推B站专栏结构）。

## 四、毕业致辞 / 公开演讲金句

### 4.1 2021届复旦中文系毕业致辞《善良、快乐、智慧与道义》（一手/他讲过的，新浪/澎湃/复旦中文转载）

四个词的解释（原文核心）：
- **善良**："善良是什么呢？是一个祝福。"讲述2006年4月21日小女儿出生那天，他从医院坐地铁回家，见一卖报女人背熟睡小孩仍抱一厚叠报纸，他买下所有报纸让她带孩子回去睡——"这个世界确实比原来好了一点点，这一点点就是那小孩可以早早舒服多睡一两个小时。当我们善良的时候，这个世界就比原来好一点点。"
- **快乐**："快乐是一种能力。"
- **智慧**："智慧是什么呢，它可能是一种痛苦。"
- **道义**："道义是一种责任。""无论在何种条件下，我们都应该记住，我们是读书人，我们是懂得道义的。"
- 引《金刚经》"心生种种法生"："世界上本来没有仇人，只要有仇恨，就会有仇人。"
- 收束："祝愿大家以一种善良态度生活，拥有快乐，拥有智慧，并且始终执守道义。"

> 我推断的：这篇致辞把"不评判、不宏大叙事"的个人风格发挥到极致——用买报纸的具体小事定义善良，用"说话磕磕绊绊"的自我解嘲开场，是典型"以小事破大题"。

## 五、坦诚与回避模式

### 5.1 坦诚 / 暴露脆弱的瞬间（一手/他讲过的）

1. **失眠独坐的习惯**：被问如何排解焦虑，坦然说自己几十年"晚上基本不睡觉，一个人坐着到天亮"。（T2）
2. **说话磕磕绊绊**：毕业致辞自嘲"在复旦教书几十年，说话总磕磕绊绊"，把致辞机会当"锻炼"。（毕业致辞）
3. **承认陶渊明也焦虑**：不神化古人，"陶渊明其实也焦虑的，他只是创造了一种诗境"。（T2）
4. **承认自己成网红的不适**："这样下去我要成网红了""有点不符合我的生活习惯了"，但"在意一些朋友说读了我的话对生活不再灰心"让他开心。（T2）
5. **承认文学的"构拟"不等于真实**：不回避文学对女生的"欺骗性"，但用"构拟"精确化，既不替文学背书也不否定文学。（T2）
6. **承认命运的"无缘无故"**：讲《红楼梦》人物命运无常，不励志、不圆谎，直接说"无缘无故、毫无道理是真实人生的重要组成部分"。（学商书院，二手/他讲过的）
7. **承认自己读书"杂而不专"**："我读书杂，小时候不守规矩，在复旦教书了也没有专业概念"，读心理学、文化人类学。（T3）

### 5.2 改变观点 / 自我修正的瞬间（一手/他讲过的）

1. **对杜甫态度的转变**：年轻特别喜欢李白，"现在跟杜甫比较亲切"，因杜甫"广阔胸襟""不登高不说愁"；希望"死的时候也不要那么畏缩和渺小"。（T3）
2. **对苏东坡《前/后赤壁赋》的评价修正**：课堂上分享，东坡写《前赤壁赋》虽漂亮但"都是前人讲过的东西，殊无新意"，故又写《后赤壁赋》追求创新；"否定自己并不是坏事，是觉得自己还有希望"。（湖南日报，二手/他讲过的）
3. **对李白的再认识**：承认李白"重感情但从不被感情拖累"，"老停留在一个感情上那就变杜甫了"——不把李白简单浪漫化。（T2）

### 5.3 拒绝回答 / 回避 / 模糊处理的瞬间（一手/他讲过的）

1. **余秀华逼问"真实爱情"**：先给社会性答案（家庭子女）被截，后转用"可代妻死"的极端尺度回应，未正面定义"真实爱情"——实质回避了定义，只给了行为尺度。（T4）
2. **《长安三万里》相关问题**：坦言"电影我还没有看"，但借机展开对李白的系统性分析——回避评价影片本身，只谈历史人物。（T2）
3. **"文学是否欺骗"**：用"构拟"替换"欺骗"，不正面承认"欺骗"一词，也不否认现象，是语义层面的柔性回避/重框。（T2）
4. **红学"索隐派"**：学商书院报道称他"直白分享独到见解，尤其对颇具争议的索隐派给出客观且深刻的学术评判"——此处为"客观评判"而非回避，但原文未引原话，存疑，标注为二手。
5. **未正面回答"新诗能否超越旧体诗"**：说"虽不能说新诗永远不会超过旧体诗，但到现在为止、可预期的将来，新诗总体不会超越古诗"，用条件句留余地，未做绝对判断。（T3）

> 矛盾记录（发现即记，不调和）：
> - **矛盾点1**：他既说"不进行价值判断、照单全讲"（T2），又在多处做明确价值评判（如称索隐派"客观深刻评判"、称《红楼梦》是"女性赞美诗"、称宝玉"理念的"）。我推断的：他的"不评判"特指不对读者的人生选择/情感做道德审判，而非学术上放弃判断；二者层面不同，但表面措辞确有张力。
> - **矛盾点2**：他自称"读书无目的、字面意义上的读书人"（T1/T7），又长期做高度系统化的教材主编、课程大纲设计。我推断的：他反对的是"功利性读书目的"，而非否定学术工作的系统性；"无目的"指精神自由状态。
> - **矛盾点3**：毕业致辞称"快乐是一种能力"，但多处文本呈现其对孤独、焦虑、生命悖谬的深沉体认，整体气质偏"通透但忧郁"。我推断的：他定义的"快乐"是"能力"而非"情绪状态"，与焦虑并存不悖。

## 七、调研发现小结（供蒸馏思维框架参考）

1. **素材总量**：共锁定一手访谈5场（T1-T5）+ 本人文章1篇（T7）+ 课程视频/大纲平台5个（S8-S13）+ 毕业致辞官方源2个（S18-S19）；二手报道/大纲约10项。来源数量约26条，覆盖访谈、公开课、B站课程、毕业致辞四类。

2. **核心思维特征（待蒸馏，初步归纳）**：
   - **反权威 + 重精确**：拒绝接贬义词（"欺骗"→"构拟"），重定义问题。
   - **以诗证理、以典破题**：所有抽象问题都翻译成具体文本再回到生命体验。
   - **切己体验方法论**："把熟悉的诗讲得不熟悉"，以自身生命经验注入公共文本。
   - **不评判但深看**：不对读者人生做道德审判，却对文本/人物做犀利洞察（"双重秩序""女性赞美诗"）。
   - **坦然脆弱**：主动暴露失眠、笨拙、成网红的不适，构成亲和力内核。
   - **庄子式自由底色**："不中绳墨之大树""无何有之乡"反复出现，是其精神锚点。
   - **"被世界等待"的治愈逻辑**：从宇宙宏大与个体短暂对照中，推向"亲切关系"而非"压迫"，是其爆款的方法论核心。

3. **矛盾点（已记录，待框架处理）**：见 5.3 三条矛盾——"不评判"vs学术判断、"无目的读书"vs系统治学、"快乐能力"vs忧郁底色。这些张力恰好是其人格复杂度的体现，蒸馏时不应强行调和。

4. **缺口提示**：B站《说红楼》专栏前20集的逐集原始讲稿未全部获取（仅通过音频课目录反推结构）；《世说新语》《诗经》等B站课程的具体论点未系统抓取（仅在多篇报道中零星提及）。如需进一步蒸馏"魏晋风度/名士"维度，建议补充《世说新语精读》课程与书中内容。
