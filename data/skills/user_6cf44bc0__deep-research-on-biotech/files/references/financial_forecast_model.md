# 公司财务前瞻建模框架（★ v3.1 新增 ★）

> **来源**：本轮（2026-08）为康方生物（9926.HK）搭建整体收入/净利润预测的实战沉淀。
> **适用**：任何 license-out 型创新药公司（康方 / 映恩 / 再鼎 / 亚盛）的公司级收入与利润前瞻。
> **本质**：把 `peak_sales_model.md` 的"产品峰值"作为**输入**，叠加授权/分成/其他管线，外推成多年收入与净利润。
> **与 financial_analysis.md 的分工**：本文件做**前瞻建模**（未来收入/利润分拆与拐点）；`financial_analysis.md` 做**已实现财报的比率解读**（毛利率/ROE/PS、报告模板）。两者互补，不重叠。

## 一、收入桥（Revenue Bridge）—— 5 类分项必须逐条枚举

公司总收入 = Σ 以下分项，建模时**不得合并隐藏**，每项单独给 base / bear / bull：

1. **自有产品收入（中国，本币）**：按产品逐一建模（AK112 中国、AK104 中国、AK105…）。来源 = `peak_sales_model.md` 的"风险调整峰值 × 该年渗透率（S 曲线）"。
2. **授权 / 里程碑收入（License & Milestone）**：一次性或阶段性确认（Summit 首付款、济川依努西、新授权）。与"分成"区分——里程碑是**事件驱动**（获批/递交），分成是**销售驱动**。
3. **海外销售分成（Royalty / Profit Share）**：license-out 资产海外商业化后，按合同比例确认**分成收入（非产品收入）**。关键：Akeso 对美国 AK112 记"Summit 分成收入"而非"产品收入"，且需考虑对海外合作方的**股权损失分摊**（见第四节）。
4. **其他管线产品收入**：非核心两药的所有获批/在售产品（PCSK9、IL-17、IL-12/23、IL-4Rα、JV 产品等），逐条给峰值与渗透率。
5. **（期权类，默认不含入 base）**：见第六节。

> ⚠️ **穿透性检查清单（本轮暴露的盲区，必须逐项核对）**：
> - [ ] 是否漏算**核心药的海外收入**？（如 AK104 海外——胃癌 COMPASSION-37 全球 Ph3（FDA 2025-12 获批开展）、肝癌 IO 耐药全球 COMPASSION-36——成功且合作伙伴化后的销售，默认作期权并**乘 PoS**）
> - [ ] 是否漏算**组合疗法中"搭档药"的独立收入**？（关键区分：AK117(CD47) 与 AK112 联用在**头颈鳞癌（AK117-302，全球 vs 帕博利珠，较高 PoS）**和**胰腺癌（AK112-310 ±AK117，仅国内，较低 PoS）**；AK109(VEGFR-2) 与 AK104 联用**国内胃癌 PD-L1 经治二线（AK109-301，II 期 ORR 48%）**——搭档药独立商业化更晚，默认作期权，**按适应症分别给 PoS**）
> - [ ] 上述两项若用户追问，必须**显式回答"已计入 / 未计入"并说明原因**，不能含糊带过。

## 二、净利润 / P&L 预测框架

自下而上构建利润表：

```
毛利     = 总收入 × 毛利率（创新药 Biotech 稳态 ~78–85%，医保后下行）
研发费用  = 历史趋势外推 + 新管线增量（规模不随收入线性增长，增速放缓）
销售及营销 = 历史趋势外推，但销售费用率随规模经营杠杆**下降**（如 32% → 26%）
行政开支  = 平稳增长
财务收益  = 现金储备利息（大额现金为正时）
```

**IFRS 与 Non-IFRS 还原（康方特有，必须固化）**：

```
Non-IFRS 归母 = IFRS 归母
              + 对海外合作方（Summit）股权损失分摊   （海外商业化越慢，分摊越高）
              + 股份支付（SBC）
              + 汇兑损益
```

- **验证案例**：2025A 复算 −114.1（IFRS） + 3.25（Summit 摊） + 1.57（SBC） + 0.74（汇兑） ≈ −58.5 ≈ 公告 Non-IFRS ✓
- **外推假设**：Summit 股权损失随海外上市后费用化下降（如 3.5 → 0.5 亿）；若海外延迟则更高，压低 IFRS。

## 三、出海 / 授权交易结构（通用模板，可复用于映恩 / 再鼎）

Summit 式 license-out 结构：

- **首付款（Upfront）**：签约即收（如 5 亿美元，2023 已收，记历史授权收入）。
- **里程碑（Milestone）**：最高可达数十亿，按监管/销售节点触发。
- **销售分成（Royalty）**：低双位数（low-teens %），净销售口径。
- **补充协议**：可能新增区域权益，收增量首付/里程碑。

建模要点：

- 首付款 / 历史里程碑 → 已计入历史年度，未来仅计**新增里程碑 + 分成**。
- 分成自海外上市后起（如 AK112 美国 PDUFA 2026-11-14 → 2027 起计）。
- 注意**权益比例**与**合作方亏损分摊**对 IFRS 的拖累。

### 3.1 ★ 收入质量分层：三类 BD 收入，三种估值待遇（v4.5 新增）

同一笔"BD 收入"里三类现金流的经济性质完全不同，**不可按同一倍数估值**：

| 类型 | 时点特征 | 可持续性 | 估值处理 |
|---|---|---|---|
| **首付款** | 签约时一次性（或按进度分摊 1–2 年） | 🔴 **不可持续** | **不计入经常性盈利**，单列一次性项目 |
| **里程碑款** | 触发条件（药证/注册/销售门槛）达成时确认 | 🟠 阶段性，**时点不可预测** | 按**概率加权的期权**处理，**不做年化外推** |
| **销售分成** | 随终端销售持续确认 | 🟢 **可持续且质量最高** | **唯一可给予经常性估值倍数**的 BD 收入 |

**铁律**：看到"BD 收入同比 +146%、占营收 18%"这类表述时，**必须先拆解再估值**。实战中某期 6.5 亿 BD 收入里可按经常性口径估值的**不足 2 亿**——若简单年化并给予与产品销售相同的倍数，会系统性高估公司价值。

**连带效应——高基数陷阱**：首付款到账年会形成营收高基数，次年若无新交易，增速可能显著低于表观（甚至负增长）。预测次年营收时应**按经常性收入的 CAGR 建模，而非按含首付款的表观增速线性外推**，并显式提示基数效应。

**补充：销售分成也有口径差异**——"终端销售额"与"公司实际确认的供货价/分成收入"是两回事，前者必然高于后者。跨节引用时必须标明用的是哪个口径（见 `delivery_selfaudit.md` §三）。

## 四、组合疗法收入归属原则

- **主导药归因**：联用方案中，收入多"打包进主导药"。典型组合（康方案例）：
  - AK112（依沃西）+ AK117（莱法利，CD47）—— 头颈鳞癌（AK117-302，全球 vs 帕博利珠）、胰腺癌（AK112-310 ±AK117，国内）
  - AK104（卡度尼利）+ AK109（普洛西，VEGFR-2）—— 国内胃癌 PD-L1 经治二线（AK109-301，III 期）
- **搭档药独立增量触发条件**：仅当搭档药**单独获批 + 单独定价 + 单独销售**时，才产生独立收入线（多数落在 2028+，属期权）。
- **PoS 按适应症区分**：同一搭档药不同适应症成功率差异大——AK117 头颈（II 期优效、全球首个 CD47 实体瘤 Ph3）PoS 较高；AK117 胰腺（冷肿瘤、仅国内）PoS 较低；AK109 胃癌二线（II 期 ORR 48%）PoS 中等。期权表须**按适应症分别给 PoS 与增量**。
- 建模默认：组合疗法价值计入主导药 base；搭档药独立收入单列期权表（含 PoS 折减），不污染主拐点。

## 五、模型校准护栏（★ 本轮血泪教训 ★）

> 自下而上峰值绝不能"自说自话"，必须与市场体量反校：

1. **市场体量反校**：中国单药峰值 ≫ 该适应症中国 IO 总市场时，份额假设必错。
   - **教训**：初版 AK112+AK104 中国份额按理想值设定，合计 1160 亿，超出整个中国 IO 市场体量 → 已校准为"拥挤医保市场单药份额 5–10%"。
2. **份额校准规则**：医保后拥挤市场，单药赢线份额 8–14%、冷肿瘤 4–9%；勿用理想值。
3. **净价下行**：随医保续约，净价乘数应可下修至 0.7–0.85×（2026 续约风险）。
4. **敏感性区间**：每项给 base / bear / bull，bull 含 BTD 兑现 / 份额超预期，bear 含医保再降价 / 数据归零。

## 六、期权 vs 基础分离原则

- **base case**：仅含已获批 + 高确定性在研（PoS 高）+ 已结构化的授权/分成。
- **期权 / optionality**：早研、海外（未合作伙伴化）、联用搭档药独立收入、新适应症——**单独建表**，作 bull 上行，不污染 base 拐点。
- **目的**：保持盈利拐点（如 2026 Non-IFRS 转正）由确定性驱动，不被远期期权虚高。

## 九、集采 / 强制性降价的影响判断（v4.5 新增）

### 9.1 份额方向性：守成者 vs 挑战者

🔴 **关键认知：集采对同一家公司不同品种的净影响方向可能相反**，判断前必须先问份额。

| 角色 | 特征 | 集采的净影响 |
|---|---|---|
| **守成者** | 该品种份额高（如 >30%），已是市场主导者 | 🔴 **净负面**——降价损失大于以量换价收益，份额已无处可抢 |
| **挑战者** | 份额低（如 <10%），原研或他厂仍主导 | 🟢 **净正面**——以价换份额，集采等于"借政策完成准入" |

**双向清单**：分析一家公司时须把品种**逐个判定角色**，**不得**给出"集采对公司是利好/利空"的笼统结论。同一家公司内出现守成者与挑战者并存是常态。

### 9.2 毛利率冲击恒等式：降价不是"少赚一点"

降价幅度 ≠ 利润降幅。在 COGS 绝对额不变的假设下：

```
新毛利率 = 1 − 原COGS绝对额 / (原收入 × (1 − 降幅))
```

**实战量级**：原毛利率 77.1%、降价 50% → 新毛利率 **54.2%**；此时若销售费用率 33.2%，剩余毛利已**无法覆盖** 40% 的研发投入率。

**结论**：大幅降价不是"少赚一点"，而是**换一套商业模式**。唯一数学上成立的解通常是**结构切换**——用海外收入 + 创新药收入替换被侵蚀的存量收入。因此降价分析的真正问题是**结构切换速度能否跑赢侵蚀速度**，而不是"降了多少"。

> 注：本式为**静态测算**，未考虑以量换价、产品结构切换与费用端同步压缩，实际冲击可能小于或大于该值——须在报告中声明（联动 `delivery_selfaudit.md`）。

### 9.3 出清/准入事件的信息核查纪律

集采、医保谈判类事件是**谣言高发区**（自媒体常把"省级联盟集采"写成"国家集采"、把"预期降幅"写成"实际降幅"）。

**核查三问**：
1. **发文主体**——是国家联采办（国采）还是省级/联盟集采？覆盖范围与强制力完全不同。
2. **文件状态**——是正式文件，还是预期/征求意见/媒体报道？**未发布的文件不得作为测算输入**。
3. **品种范围**——是否真的包含所分析的品类（例如某批集采只含化药、不含单抗）。

**处理**：核查发现不实时，在报告中**单列澄清框**写明"该组数据不实、本报告不采用"，并说明改用哪个口径——**不得静默忽略**（读者可能已看过该传闻）。
