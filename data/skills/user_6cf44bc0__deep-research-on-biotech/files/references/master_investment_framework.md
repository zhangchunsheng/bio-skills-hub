# 19位投资大师分析框架汇总

> 从专家团报告中学习提炼，用于升级创新药投研分析框架。
> 适用于：亚盛医药、康方生物、再鼎医药、范式智能、药师帮、超威动力、新氧等标的。

---

## 一、框架总览

| 维度 | 涵盖大师 | 核心问题 |
|------|---------|---------|
| 价值面 | 巴菲特、芒格、格雷厄姆、阿克曼、大空头 | 安全边际是否足够？FCF是否稳定？ |
| 成长面 | 林奇（麦哲伦舵手）、木头姐、费雪、金君瓦拉 | 增速是否可持续？TAM是否足够大？ |
| 风险面 | 塔勒布（黑天鹅之父）、大空头、风险管理师 | 尾部风险概率？反脆弱还是脆弱？ |
| 技术面 | 技术面分析师、宏观之王（德鲁肯米勒） | 动量方向？卖空比例警戒？ |
| 情绪面 | 情绪分析师、新闻情绪分析师、基本面分析师 | 机构覆盖度？内部人增持/减持？ |

**信号聚合公式（简化版）：**

```
综合信号 = Σ(维度权重 × 该维度信号得分)
最终建议 = 综合信号 + 安全边际量化 + 风险调整
```

## 二、价值面大师框架

### 2.1 奥马哈先知（巴菲特）

| 评估要素 | 具体指标 | 本报告中应用示例 |
|---------|---------|---------------|
| 护城河宽度 | 品牌/网络效应/成本优势/转换成本 | 药师帮94%付费率→强网络效应 |
| 自由现金流FCF | FCF yield > 15%为优 | 药师帮FCF yield 23%，巴菲特评分70 |
| 管理层质量 | 资本配置能力、股东回报 | 药师帮CEO连续4次增持→强正面信号 |
| 合理价格 | PE < 15x 或 FCF yield > 10% | 药师帮PE 15.68x，处合理区间 |

**触发条件：** FCF yield > 15% + 护城河明确 + 管理层增持 → Bullish

---

### 2.2 芒格

| 评估要素 | 具体指标 |
|---------|---------|
| 高质量企业 | ROE > 15%、净利率 > 10% |
| 合理价格 | 不追求极端低估，接受合理溢价 |
| 避免平庸 | 拒绝"还行"的企业 |

**与巴菲特差异：** 芒格接受更高估值买入最高质量企业；巴菲特更强调安全边际。

---

### 2.3 格雷厄姆（估值教父）

| 评估要素 | 计算公式 | 判断标准 |
|---------|---------|---------|
| 安全边际 | (内在价值 - 市价) / 内在价值 | > 30% 为显著低估 |
| NCAV折扣 | (流动资产 - 总负债) / 市值 | > 0 为NCAV折价机会 |
| PB | 市值 / 净资产 | < 1.0x 为低估；< 0.5x 为深度低估 |
| PE | 市值 / 净利润 | < 15x 为合理；亏损企业不适用 |

**本报告中应用：**
- 药师帮：PB 0.98x、FCF yield 23%、安全边际61% → Bullish 75
- 超威动力：PB 0.21x、PE 3.84x、安全边际40% → Bullish 60（但标注"价值陷阱"）
- 创新药三标的：ROE为负、持续亏损 → Bearish

**核心价值判断逻辑：**
```
if PB < 0.5 and 盈利稳定 → 深度低估（格雷厄姆买入）
if 安全边际 > 30% → 显著低估
if 安全边际 < 0% → 显著高估（回避）
```

---

### 2.4 达克曼（Dhandho掌门）

| 评估要素 | 具体指标 |
|---------|---------|
| 集中持仓 | 高确信度下重仓 |
| 高质量护城河 | 消费者垄断型企业 |
| 安全边际 | 与格雷厄姆类似但更宽松 |

**本报告中应用：** 药师帮 Bullish 75（高确信度集中持仓候选）

---

### 2.5 大空头（巴斯）

| 评估要素 | 具体指标 |
|---------|---------|
| 市场忽视的极端低估 | 基本面大幅改善但股价下跌 |
| 隐性风险识别 | 价值陷阱、流动性风险 |
| 催化剂 | 内部人增持、机构覆盖度提升 |

**本报告中应用：**
- 药师帮：净利+410%但股价-28% → 市场完全忽视 → Bullish 65
- 超威动力：PB 0.21x但"价值陷阱"标注 → Bullish 55（谨慎）

### 3.2 木头姐（凯茜·伍德）

| 评估要素 | 具体指标 |
|---------|---------|
| 颠覆性创新 | 是否重塑行业格局 |
| TAM指数增长 | 可触达市场是否指数级扩张 |

**本报告中应用：**

**木头姐评分逻辑（本报告中提取）：**
```

if 渐进式改进 → 信心分50-70

```

### 3.3 费雪

| 评级体系 | 含义 |
|---------|------|
| A/A- | 强烈买入 |
| B+/B/B- | 谨慎买入 |

**评估15要点（简化）：**

## 四、风险面大师框架

### 4.1 黑天鹅之父（塔勒布/纳西姆·塔勒布）

**核心概念：**

| 概念 | 含义 | 投资含义 |
|------|------|---------|
| 脆弱 | 波动→损失 | 避免持有 |
| 鲁棒 | 波动→无影响 | 可持有 |
| 反脆弱 | 波动→受益 | 重点持有 |

**本报告中应用：**
- 范式智能：平台型+API生态，算力需求波动中受益 → **反脆弱(55)** ← 全组合唯一
- 创新药三标的：临床失败(30-50%) + FDA审批趋严 + 集采扩大 → **脆弱(60-65)**
- 药师帮：FCF+低PB提供下行保护，但流动性极差 → **中性偏反脆弱(55)**

**塔勒布评估清单：**
```
□ 该企业是否从波动/混乱中受益？（反脆弱）
□ 该企业是否对尾部风险极度敏感？（脆弱）
□ 是否有期权式不对称收益？（正向黑天鹅）
□ 是否过度杠杆？（脆弱放大器）
```

## 七、达摩达兰（安全边际量化）

> 报告中"估值教父"即阿斯沃斯·达摩达兰（Aswath Damodaran），NYU Stern估值教授。

**安全边际计算公式（从报告中反向推导）：**

```
安全边际 = (DCF内在价值 - 当前市价) / 当前市价 × 100%
```

| 标的 | 达摩达兰安全边际 | 判断 |
|------|----------------|------|
| 药师帮 | +61% | 显著低估 |
| 范式智能 | +42% | 低估 |
| 超威动力 | +40%（但标注"价值陷阱"） | 低估但谨慎 |
| 再鼎医药 | +34% | 轻度低估 |
| 新氧 | +28% | 轻度低估 |
| 亚盛医药 | +8% | 安全边际薄 |
| 康方生物 | -31% | 显著高估 |

**DCF关键假设（推断）：**
- 创新药：管线NPV（净现值）+ 已上市产品销售预测
- AI平台：Token/API收入CAGR + 终值（Terminal Value）
- 医药电商：GMV增速 + 变现率提升 + 终值

## 八、信号聚合与仓位管理

### 8.1 信号统计表（从报告中提取）

| 信号类型 | 计算方式 | 本报告中应用 |
|---------|---------|---------------|
| 看多人数 | 19位中给出Bullish/买入的人数 | 药师帮9/14看多 |
| 看空人数 | 19位中给出Bearish/卖出的人数 | 新氧10/14看空 |
| 偏多偏空比 | 看多人数 / 看空人数 | 药师帮9.0（最强共识） |

**决策阈值：**
```
if 偏多偏空比 > 3.0 → 强共识看多，重点配置
if 偏多偏空比 1.0-3.0 → 偏多，条件买入
if 偏多偏空比 0.5-1.0 → 分裂，持有观察
if 偏多偏空比 < 0.5 → 强共识看空，回避
```

---

### 8.2 仓位管理框架（从报告中提取）

| 信号强度 | 建议仓位 | 入场方式 | 示例中应用 |
|---------|---------|---------|---------------|
| 强共识看多 + 高安全边际 | 5-7% | 分批建仓（50%→30%→20%） | 药师帮7% |
| 强共识看多 + 中安全边际 | 4-6% | 等回调建仓 | 范式智能6% |
| 条件看多（催化剂驱动） | 2-3% | 催化剂前建小仓，数据正面后追加 | 亚盛医药3% |
| 信号分裂/中性 | 1-3% | 最小观察仓 | 康方2%、超威3% |
| 强共识看空 | 0% | 清仓/回避 | 再鼎0%、新氧0% |

**现金比例原则：**
```
if 催化剂临近（如ASCO前） → 70-80%现金防御
if 数据正面确认 → 逐步加仓至上限
if 数据负面 → 进一步收缩至90%现金
```
