# 技术面信号监控框架

> 从专家团报告中提取的技术面分析维度，整合技术面分析师 + 宏观之王（德鲁肯米勒）框架。
> 适用于：港股/美股标的技术信号监控、卖空预警、动量判断。

---

## 一、核心技术指标

### 1.1 卖空比例（Short Interest Ratio）

**数据来源：** 港交所披露易（港股）、Finra（美股）

| 卖空比例 | 信号含义 | 操作建议 |
|---------|---------|---------|
| < 5% | 正常，市场情绪中性 | 无特别操作 |
| 5-10% | 轻度看空 | 关注，结合基本面 |
| 10-20% | 中度看空 | 谨慎，设好止损 |
| > 20% | 危险区间 | 减仓/对冲 |
| > 27% | 极端警戒 | 清仓/强力对冲 |

**本报告中案例：**
- 康方生物：卖空27.5% → 极度危险信号
- 范式智能：卖空从20%降至6% → 空头撤退，正面信号

**监控方法（港股）：**
```
1. 访问港交所披露易：https://www.hkexnews.hk
2. 搜索标的代码 → "卖空成交数据"
3. 计算：卖空股数 / 流通股数 × 100%
4. 跟踪趋势：上升→空头加仓；下降→空头撤退
```

---

### 1.2 量比（Volume Ratio）

```
量比 = 当日成交量 / 过去5日平均成交量
```

| 量比 | 信号含义 | 操作建议 |
|------|---------|---------|
| < 0.5 | 极度缩量 | 关注转折点 |
| 0.5-1.5 | 正常 | 无特别操作 |
| 1.5-3.0 | 异常放量 | 关注转折 |
| > 3.0 | 极度异常 | 确认趋势变化 |
| > 5.0 | 恐慌/狂热 | 极短期信号 |

**本报告中案例：**
- 新氧：量比6.57 → 恐慌性抛售确认

---

### 1.3 振幅（Amplitude）

```
振幅 = (当日最高价 - 当日最低价) / 昨日收盘价 × 100%
```

| 振幅 | 信号含义 |
|------|---------|
| < 3% | 正常波动 |
| 3-10% | 异常波动，关注转折 |
| > 10% | 极端波动，可能趋势变化 |
| > 30% | 极度极端，确认反转或突破 |

**本报告中案例：**
- 新氧：振幅634% → 极度异常，恐慌性抛售

---

### 1.4 涨跌幅信号

| 指标 | 警戒线 | 信号含义 |
|------|---------|---------|
| 年初至今涨跌幅 | < -20% | 超卖，关注反转 |
| 20日涨跌幅 | < -15% | 短期超卖 |
| 单日涨跌幅 | > ±10% | 异常，确认趋势 |

**本报告中案例：**
- 药师帮：年初至今-28%、20日-32% → 严重超卖
- 范式智能：5/22涨11.23% → 动量偏多

## 二、动量信号

### 2.1 多头动量（Bullish Momentum）

**确认条件（需同时满足）：**
```
□ 股价在20日均线以上
□ MACD金叉（DIF上穿DEA）
□ 成交量温和放大
□ 无极端卖空信号（< 10%）
```

### 2.2 空头动量（Bearish Momentum）

**确认条件（需同时满足）：**
```
□ 股价在20日均线以下
□ MACD死叉（DIF下穿DEA）
□ 卖空比例 > 20%
□ 量比 > 3（放量下跌）
```

## 三、宏观之王（德鲁肯米勒）框架

### 3.1 宏观动量三要素

| 要素 | 评估方法 | 本报告中应用 |
|------|---------|---------------|
| 政策方向 | 央行政策+财政刺激 | 中国AI信创政策 → 范式智能动量强 |
| 流动性环境 | M2增速+利率趋势 | 港股流动性危机风险10-15% |
| 行业Beta | 行业指数相对大盘 | AI算力国产化Beta > 1.5 |

### 3.2 宏观动量评分（0-100）

| 分数 | 判断 | 操作建议 |
|------|------|---------|
| 70-100 | 宏观动量极强 | 积极建仓 |
| 50-69 | 宏观动量偏多 | 持有/小仓建仓 |
| 30-49 | 宏观动量偏空 | 减仓/对冲 |
| 0-29 | 宏观动量极弱 | 清仓/强力对冲 |

**本报告中应用：**
- 范式智能：宏观之王评分70（AI算力国产化宏观动量极强）
- 创新药：宏观之王评分55-60（中性偏多，ASCO前）

```
**操作建议：**
- [基于技术信号的具体建议]
```

## 五、技术面与基本面结合规则

### 5.1 冲突处理

| 基本面信号 | 技术面信号 | 处理规则 |
|------------|------------|---------|
| 强看多（Bullish） | 卖空>20% | 等卖空下降后再建仓 |
| 强看多（Bullish） | 严重超卖（年初至今-20%） | 分批建仓，技术面提供更好入场点 |
| 强看空（Bearish） | 严重超买 | 借技术面强势逢高减仓 |
| 强看空（Bearish） | 严重超卖 | 等待反弹再减仓 |

### 5.2 确认规则

```
技术面确认基本面：
  基本面Bullish + 技术面多头动量确认 → 积极建仓
  基本面Bullish + 技术面空头动量     → 等回调建仓

技术面预警基本面：
  基本面中性 + 技术面卖空>20% → 谨慎，可能基本面有未发现的利空
  基本面中性 + 技术面严重超买     → 谨慎，可能泡沫
```

## 六、港股特有技术信号

### 6.1 港股通标的监控

| 状态 | 影响 | 本报告中案例 |
|------|------|---------------|
| 纳入港股通 | 南下资金流入，流动性改善 | 药师帮2023/9纳入，但2026/3调出 |
| 调出港股通 | 南下资金流出，流动性恶化 | 药师帮2026/3调出，当日跌15%+ |

**监控方法：**
```
1. 关注恒生指数公司季度调整公告
2. 关注深交所/上交所港股通标的调整公告
3. 调出前通常有预告，可提前减仓
```

### 6.2 港股流动性风险

| 日均成交额 | 评估 | 建仓建议 |
|------------|------|---------|
| > 10亿港元 | 极好 | 任意建仓 |
| 1-10亿港元 | 良好 | 正常建仓 |
| 1000万-1亿港元 | 一般 | 分批建仓 |
| 500-1000万港元 | 较差 | 小仓位，拉长建仓期 |
| < 500万港元 | 极差 | 仅观察，避免建仓 |

**本报告中流动性风险案例：**
- 药师帮：日均成交476万港元 → 极差
- 超威动力：日均200-300万港元 → 极差
