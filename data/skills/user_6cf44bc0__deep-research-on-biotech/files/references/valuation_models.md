# 估值模型与安全边际量化

> 整合达摩达兰（Aswath Damodaran）DCF框架与格雷厄姆安全边际，用于创新药/AI平台/医药电商等多行业估值。

---

## 一、达摩达兰 DCF 估值框架

### 1.1 核心公式

```
企业价值（EV）= Σ [FCFt / (1+WACC)^t] + Terminal Value / (1+WACC)^n
权益价值 = EV - 净债务
每股内在价值 = 权益价值 / 流通股数
安全边际 = (每股内在价值 - 当前股价) / 当前股价 × 100%
```

### 1.2 创新药企业 DCF 关键假设

| 参数 | 取值参考 | 说明 |
|------|---------|------|
| 预测期 | 5-10年 | 管线NDA后5-10年达峰 |
| 收入增速 | 峰值销售 × 上市概率PoS | PoS需按临床阶段加权 |
| 毛利率 | 80-95%（生物药） | 考虑医保谈判降价 |
| WACC | 9-12% | 创新药企风险溢价高 |
| Terminal g | 2-3% | 永续增长率 |
| PoS加权 | Phase 3: 60-70%；Phase 2: 30-40%；Phase 1: 10-20% | 按管线加总NPV |

**管线NPV计算示例（APG-2575）：**
```
峰值销售假设：10亿美元（全球CLL适应症）
上市概率PoS：60%（假设已进Phase 3）
权益比例：50%（武田合作后）
贴现率：10%
NPV ≈ 10亿 × 60% × 50% / (1.10)^5 ≈ 1.8亿美元
```

### 1.3 AI平台企业 DCF 关键假设

| 参数 | 取值参考 | 说明 |
|------|---------|------|
| 预测期 | 10年 | AI赛道变化快，长期不确定性高 |
| 收入增速 | Token/API量 × 单价趋势 | 需区分项目制vs按量付费 |
| 毛利率 | 60-80%（SaaS平台） | 算力成本为主要可变成本 |
| WACC | 11-14% | AI泡沫溢价 |
| Terminal g | 3-4% | 平台强者恒强 |
| 多情景分析 | 乐观/基准/悲观三情景 | 必须做情景分析 |

## 二、格雷厄姆安全边际框架

### 2.1 安全边际计算公式（格雷厄姆版）

```
安全边际（格雷厄姆）= (内在价值 - 市价) / 市价 × 100%

内在价值（简化版）= 每股收益EPS × (8.5 + 2 × 预期增速g)
```

### 2.2 NCAV 折扣法（Net Current Asset Value）

```
NCAV = 流动资产 - 总负债
NCAV折扣 = (市值 - NCAV) / NCAV × 100%
```

**判断标准：**
- NCAV折扣 < 0：市值低于净流动资产，极度低估（格雷厄姆买入信号）
- PB < 0.5x：考虑买入
- PB > 3.0x：需极高成长验证

### 2.3 各标的格雷厄姆指标（截至2026-05-25）

| 标的 | PB | PE | NCAV折扣 | 格雷厄姆判断 |
|------|----|----|-----------|---------------|
| 药师帮 | 0.98x | 15.68x | 待计算 | 轻度低估（安全边际61%） |
| 超威动力 | 0.21x | 3.84x | 待计算 | 深度低估但价值陷阱 |
| 范式智能 | 亏损中 | -664x | 不适用 | DCF远期定价 |
| 亚盛医药 | 亏损中 | 负 | 不适用 | 安全边际仅8% |
| 康方生物 | 亏损中 | 负 | 不适用 | 安全边际-31%高估 |
| 再鼎医药 | 亏损中 | 负 | 不适用 | 安全边际34%但"低估≠买入" |
| 新氧 | ~1.0x | 亏损中 | 待计算 | 轻度低估但盈利不可测 |

### 3.2 安全边际判断标准

| 安全边际 | 判断 | 操作建议 |
|---------|------|---------|
| > 50% | 深度低估 | 积极买入 |
| 30-50% | 显著低估 | 买入 |
| 15-30% | 轻度低估 | 谨慎买入 |
| -15%~+15% | 合理估值 | 持有观察 |
| -15%~-30% | 轻度高估 | 减仓 |
| < -30% | 显著高估 | 卖出/回避 |

## 四、价值陷阱识别清单

> 超威动力（PB 0.21x）和再鼎医药（安全边际34%）均被标注"价值陷阱"风险，必须做以下检查：

```
价值陷阱识别清单：
□ 行业是否处于长期衰退？（铅酸电池→锂/钠电）
□ 盈利能力是否持续恶化？（营收增长但净利率极低）
□ 是否面临技术替代？（胶卷→数码，铅酸→锂电）
□ 是否出现"低估→更低估"的持续下跌？
□ 自由现金流是否持续为负？
```

**若≥3项命中 → 标注"价值陷阱"，不直接买入。**

---

## 五、使用注意事项

1. **亏损企业**：PE为负，DCF是唯一有效估值方法，但假设高度敏感
2. **创新药企业**：管线NPV高度依赖PoS假设，需做情景分析
3. **AI平台企业**：Token/API增长假设需参考行业报告，不可拍脑袋
4. **安全边际是必要条件而非充分条件**：价值陷阱普遍存在
