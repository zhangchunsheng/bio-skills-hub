# 财务分析框架

> **与 `financial_forecast_model.md` 的分工（★ v3.1 明确 ★）**：
> - **本文件**：解读**已实现财报**的通用比率（毛利率/ROE/PS、现金流、估值指标）与报告模板——用于"复盘过去"。
> - **`financial_forecast_model.md`**：做**未来前瞻建模**（收入桥分拆、P&L/净利润、IFRS/Non-IFRS 还原、出海授权结构、组合疗法归因、校准护栏、期权分离）——用于"预测未来"。
> - 两者互补不重叠：先用本文件看懂历史财报质量，再用 forecast 模块外推未来。涉及"公司收入/净利润预测"任务时，优先加载 forecast 模块。

## 一、核心财务指标

### 1. 盈利能力
| 指标 | 计算方式 | 解读 |
|------|----------|------|
| 毛利率 | (营收-成本)/营收 | 产品竞争力 |
| 净利率 | 净利润/营收 | 整体盈利能力 |
| ROE | 净利润/股东权益 | 股东回报率 |
| ROA | 净利润/总资产 | 资产使用效率 |

### 2. 研发投入
| 指标 | 计算方式 | 解读 |
|------|----------|------|
| 研发费用率 | 研发费用/营收 | 创新投入力度 |
| 研发费用同比增长 | YoY | 研发投入增速 |
| 研发管线数量 | 直接统计 | 管线丰富度 |

### 3. 现金流
| 指标 | 解读 |
|------|------|
| 经营现金流 | 主业造血能力 |
| 现金及等价物 | 资金储备 |
| 现金流消耗速度 | 烧钱速度（月均消耗） |

### 4. 估值指标
| 指标 | 适用场景 |
|------|----------|
| 市值 | 同行业比较 |
| P/S (市销率) | 收入阶段公司 |
| EV/Revenue | 企业价值比较 |
| P/E (市盈率) | 盈利阶段公司 |

## 一·B 经营质量横向对比框架：MNC 基准法（★ v4.6 新增 ★）

> **来源**：2026-08 国内创新药企 2026H1 经营质量深度分析（14 家国内 vs 19 家 MNC 横向对比）。
> **适用**：任何「某公司/某组公司 vs 全球成熟药企」的横向对比任务；也与 `financial_forecast_model.md` §九（集采降价判断）、`valuation_rnpv.md` §6（市值对账）互补。

### B.1 净利率恒等式与三层分解（分析固定起点）

```
净利率 ≡ 毛利率 − S&M% − R&D% − 其他经营费率% ± 非经常项
```

**三层价值分解**——任何"盈利质量"结论都必须能落到某一层：

| 层 | 变量 | 回答的问题 |
|---|---|---|
| **L1 单位经济性** | 毛利率 | 每卖 1 元产品留下多少？（产品竞争力与商业模式：创新药 / 生物类似药 / 授权分成三种模式毛利结构完全不同） |
| **L2 经营效率** | S&M% / R&D% / 管理费率 | 钱花得是否有效率？（注意 R&D% 有倒 U 结构，见 B.4） |
| **L3 收入结构** | 创新药占比 / 海外占比 / BD 经常性占比 | 收入的质量与可持续性（见 `financial_forecast_model.md` §3.1 收入质量分层） |

🔴 **纪律：不要从净利率直接下结论。** 先按恒等式拆到三层，逐层与基准带比较，再归因——净利率相同可能是完全不同的故事（高毛利高研发 vs 低毛利低研发）。

### B.2 基准带法：先建带，再定锚

1. **建可比组基准带**：选取成熟药企可比组（如 19 家 MNC），计算三项核心中位数带：C&G&A%（销售+管理费率）、R&D%、Net Margin%。
2. **异常值剔除规则**（不可照单全收）：
   - **超级周期驱动**——某产品线的阶段性爆发推高全部指标（如 GLP-1 周期的 Lilly），不可作为目标值；
   - **并购整合失真**——大额并购年份费用与摊销非稳态（如 Takeda / Merck KGaA 类）；
   - **业务结构本质不同**——CXO/器械/消费医疗混业者不与纯药企同带。
3. **单点对标锚**：为标的另找"业务结构最相似"的一两家 MNC 作单点参照。**对标锚必须写明相似点与不相似点**，禁止只写"对标 X"。

### B.3 倍数法三大失真机制与降权规则

| 失真 | 机制 | 处理 |
|---|---|---|
| **PE 被一次性授权首付款污染** | 分母（净利润）含不可持续项目，PE 假性偏低 | 剔除非经常项后再看；或直接降权 PE |
| **PB 被累计亏损侵蚀** | 未盈利 biotech 净资产极薄 → PB 虚高且无信息量 | 未盈利/微净资产公司**禁用 PB** |
| **研发资本化 vs 费用化口径不可比** | 会计政策不同 → R&D% 与利润率跨公司不可比 | 对比前统一口径，或在表内标注口径差异 |

**结论**：对中国创新药企横向对比，PE/PB 只作低权重参考；主力工具为「**质量分 ÷ 调整后 PS**」性价比框架或两分法 rNPV（见 `valuation_rnpv.md`）。

### B.4 四个反直觉判据（高频误读纠正）

1. **R&D% 倒 U 型**：良性高投入 = 有收入支撑的全球 III 期布局；恶性高投入 = 收入基数过小导致比率失真。**同是 35% 的 R&D%，含义完全不同——先看分母质量，再看比率本身。**
   - 🔴 **危险信号**：授权首付款到账当年 R&D 绝对额同比下降（首付款撑大分母 + 同期砍研发）——"首付款依赖症"，收入质量与研发投入双降。
2. **创新药占比非越高越好**：真正判据是「**创新药增量能否对冲存量（仿制药/集采品种）下滑**」。占比高但增量不足，仍是下滑型结构。
3. **海外收入占比是与 MNC 决定性差距的第一来源**，三重机制：**定价**（美国净价可达中国的 3–10 倍）+ **毛利率**（海外直售毛利显著更高）+ **S&M 效率**（美国无医生返点体系，销售费率天然低 10–15pct）。费用率追赶无法替代这一差距。
4. **毛利率异常低是商业模式信号**：显著低于同业的毛利率可能直接证伪"创新药企"标签（典型：License-in 净额分成模式确认的收入）——**先问商业模式，再谈经营质量**。

### B.5 四维经营质量评分卡（通用模板）

四个维度各 25 分、合计 100（权重默认等权，可按分析目的调整并内置模拟器）：

| 维度 | 考察点 | 打分锚点（示例逻辑） |
|---|---|---|
| **商业化质量** | 核心品种增速、放量结构（新品接力 vs 单品依赖） | 存量靠新品接力加分；单品依赖、核心品种负增长减分 |
| **销售管理质量** | S&M% 水平 + 同比改善幅度 | "高毛利 + 低 S&M"黄金组合最高分；S&M 高且恶化减分 |
| **研发管理质量** | R&D% 在倒 U 上的位置、管线转化效率 | 有收入支撑的全球 III 期加分；靠首付款撑分母减分 |
| **收入结构质量** | 创新药占比、海外占比、BD 经常性占比（§3.1 口径） | 海外占比达标者显著加分；授权收入以首付款为主减分 |

**纪律**：① 每项分数必须附理由，且理由可回溯到 B.1–B.4 的判据（禁止"凭感觉打分"）；② 评分是**排序与沟通工具**，不是估值输入——估值仍走 rNPV；③ 跨期复评时用同一套锚点，保证可比。

### B.6 横向对比报告结构模板

```
① 矩阵全景（公司 × 指标，同源同期同口径）
② 与基准带的差距分解（按 L1/L2/L3 三层归因，标注决定性差距）
③ 四维评分卡（等权基准 + 权重可调模拟器）
④ PS 交叉验证（质量分 ÷ 调整后 PS，防"好公司 = 好股票"混淆）
⑤ 结论与诚实边界（异常值原因、口径差异、数据缺口）
```

**纪律**：同行数字必须**同源同期同口径**（同一份半年报/年报）；异常值必须标注原因（B.2 三类）；数据冲突先校正再使用（见 `edge_case_protocols.md`）。

### B.7 基准快照（2026H1 · ⚠️ 会过期，使用前必须核对报告期）

> 本节是**数据快照**而非方法——仅作分析时的对照锚点。报告期更新后应刷新；若快照与最新报告期差超过一个报告期，**宁可现场重算，不要引用本节数字**。

- **MNC 基准带（19 家中位数）**：C&G&A% ~27.5%（区间 20–34%）｜R&D% ~25%（18–40%）｜Net Margin% ~14%（−10%~36%）
- **国内毛利率排序（2026H1）**：翰森 91.9% 全场最高（唯一"高毛利+低 S&M 22.4%"黄金组合）＞ 百济 89.2% ＞ 恒瑞 ~86.0% ＞ 信达 85.0% ＞ … ＞ 康方 74.24% ＞ **再鼎 58.0% 全场最低（License-in 分成特征，证伪"创新药企"假设）**
- **海外收入占比**：百济 69.8%（国内唯一与 MNC 差距达标者）≫ 恒瑞 12.25% ＞ 信达 3.45% ＞ 复宏 <3%
- **四维评分卡排序**：百济 92 ＞ 翰森 79 ＞ 恒瑞 77 ＞ 信达 75 ＞ 中生 74 ＞ 复宏 69 ＞ 康方 65 ＞ 先声 64 ＞ 荣昌 61 ≈ 君实 61 ＞ 康诺亚 58 ＞ 和黄 50 ＞ 亚盛 42 ＞ 再鼎 29
- **PE/PB 失真实证**：荣昌 PE 7.06 为首付款假象；亚盛 PB 20.45 系每股净资产仅 1.715 元所致

## 二、创新药公司特殊分析

### 1. 管线价值评估
```
管线价值 = Σ(适应症市场 × 成功概率 × 峰值市占率 × 权益比例)
```

### 2. 里程碑事件追踪
| 阶段 | 里程碑 | 价值影响 |
|------|--------|----------|
| 临床前 | IND批准 | 初步验证 |
| I期 | 完成安全剂量爬坡 | 概念验证 |
| II期 | 初步疗效数据 | 重大拐点 |
| III期 | 达到主要终点 | 商业化临近 |
| 上市 | NDA/BLA批准 | 商业化开始 |

### 3. 竞争格局分析维度
- 靶点分布（热门/差异化）
- 临床进度（领先/跟随）
- 疗效数据（安全性/有效性）
- 商业化能力（销售网络）
