# 估值框架：两分法 rNPV（已商业化 DCF + 在研逐试验 rNPV）

> 适用：创新药企 EV / 股权价值测算。核心思想——**资产状态不同，估值方法不同**：
> - **Part A（已商业化 / 临床已成功资产）**：用收入 DCF 折现，残差风险低。
> - **Part B（仍在开发的临床）**：用 rNPV，**成功率按单个试验填写**，逐试验折现。
> 验证样例：亚盛医药 (6855.HK) `ascentage_rnpv.py` / `ascentage_rnpv.html`（与本文同源）。

---

## 一、为什么分两部分（用户要求的方法论）

| 资产状态 | 风险特征 | 估值法 | 折现率 | 成功率处理 |
|---|---|---|---|---|
| 已上市 / 临床已读出成功 | 残差退市+竞争风险 | 收入 DCF（收入×经营利润率） | WACC 偏低（10~11%） | PoS≈0.90~0.95 |
| 注册 III 期在研 | 主要剩批准后风险 | rNPV | 12~15% | PoS 按阶段+资产填 |
| 早研 I/II 期 | 高失败+长周期 | rNPV（小权重） | 12~15% | PoS 低（8~25%） |

**致命陷阱**：把所有资产都按"峰值×单一系数"折算，会忽略"已商业化"与"在研"的风险结构差异，且无法暴露"价值由哪些试验、哪些 PoS 驱动"。逐试验 rNPV 是更诚实的拆法。

---

## 二、Part A — 已商业化资产（收入 DCF）

```
资产价值 = Σ_t [ 收入_t × 经营利润率 ] / (1 + r_comm)^t
```
- **收入路径**：以最近实际年报为锚，按医保放量/新适应症爬坡外推至峰值，再缓慢衰减（专利悬崖）。
- **经营利润率**：单产品约 30~40%（毛利 80%+ 扣 SG&A/管理费）；组合公司取合并口径。
- **PoS**：取 0.90~0.95（仅残差退市/集采超预期降价风险）。
- **折现率 r_comm**：10~11%（已获批，近无临床风险）。

## 三、Part B — 在研逐试验 rNPV（核心）

### 3.0 节点构建前置双硬卡（★ v4.2 P0 新增，构建任何 Part B 节点前必须先过 ★）

> 来源：2026-08-25/26 实战 4 次用户纠正的根因分析——全部为同方向「低估资产广度/价值」，共同失效模式 = **锚定过早、枚举不足**（拿到第一个自洽解释即停止枚举备选假设）。聚合层的高估有市值对账兜底，**单节点构成层的漏配只能靠以下两卡兜底**。

**硬卡 A：机制全景枚举 checklist（防"单机制窄化"）**

在把任何资产在某适应症中的价值锚定为某条机制轴之前，**强制枚举该分子全部已知靶点/机制轴**，并逐条判定"是否适用于当前适应症"：

- [ ] 该分子的完整靶点清单是什么？（药物说明书/公司管线页/年报机制图，例：奥雷巴替尼 = BCR-ABL1(本职) + FLT3 + cKIT + PDGFR + Src 家族(Lck/Fyn/YES1) + PI3K + FGFR）
- [ ] 每条轴在该适应症的适用性：逐条标注「适用/不适用/待验证」+ 一句理由（例：AML 中 BCR-ABL1 轴不适用，FLT3 轴适用(FLT3mut 子集)，MCL-1 多通路下调轴适用且 **FLT3 非依赖**——OCI-AML-3 FLT3-WT 证据）
- [ ] 是否存在「FLT3 非依赖」式的旁路贡献？（多激酶/多通路药物必须专门问）
- [ ] 联用伙伴药各自贡献哪条轴？（联用归因，见 `financial_forecast_model.md`）
- [ ] 交付物"机制"节以**全景表**呈现（轴 × 适应症适用性 × 证据 × 置信度），不得只写单轴

> 反面教材：把 1351 在 AML 的价值锚定"仅 FLT3 交叉抑制（~28% 子集）"→ 漏掉多激酶→MCL-1 广谱下调轴（VEN 耐药 all-comers 主战场），被用户两次纠正后才闭环。

**硬卡 B：权益/分成事实核查硬卡（防"权益误设"，出海/全球节点必过）**

建模任何海外/全球节点**之前**，先用一手来源核验该资产在目标区域的**权益归属事实**（这是可核查的事实，不是判断题）：

- [ ] 核验来源（按优先级）：公司年报管线表（权益列）→ 港交所/交易所公告 → 交易公告（首付/里程碑/royalty 结构）→ 公司官网管线页
- [ ] 产出三列清单：**区域 × 权益持有方 × 分成结构**（自建 / royalty ~x% / 里程碑 / 混合）
- [ ] 明确每个 Part B 节点落在清单的哪一行；无对应权益依据的节点**不得创建**
- [ ] 区分「全球权益自持（如 AK104 ex-China）」vs「已对外授权（如 AK112→Summit）」——两者 peak 口径完全不同（§4.1）

> 反面教材：AK104 海外初版写成"伙伴主导 cap=0.5"，实际康方自持全球权益（年报管线表白纸黑字），用户点名后重构为两节点，rNPV 由 16.4 修正至 24.1 亿。此核查 10 分钟可完全预防一次结构性低估。

```
rNPV_trial = PoS_trial × Σ_t [ 峰值年化现金流_t × 爬坡/衰减因子 ] / (1 + r_pipe)^(t − 今年)
```
- **峰值年化现金流**：= 标签人群 × 份额 × 净价（见 `peak_sales_model.md`），或海外用 royalty/净捕获口径。
- **爬坡/衰减因子**：上市年起 3 年爬坡至峰值，持平 ~10 年，之后 5~6 年衰减至 15%~20%（专利到期+仿制）。
- **上市年**：按试验当前阶段+入组/随访时长推算读出时间+监管审评（NDA ~1y，BLA/FDA ~1.5y）。
- **r_pipe**：基准 12%，早研/高不确定可上探 15%。
- **PoS_trial：必须逐项填写**（见下表），不得用全局单一系数替代。

### 标准 PoS 基准（按阶段，来自 BIO/Informa 行业统计，可作起点）
| 阶段 | → 获批基准 PoS |
|---|---|
| Ph1 | 7~10% |
| Ph2 | 16~20% |
| Ph3 | 55~65% |
| BLA/NDA 审评中 | 90% |
| 已获批/商业化 | 95% |

### 资产/靶点/机制调整（加在基准上，需在交付物注明理由）
- **机制已被验证**（如 Bcl-2/Venetoclax 先例、BCR-ABL）：+5~15%
- **First-in-class 且有监管激励**（孤儿药/儿童罕见病/单臂可批）：+5~15%
- **难治异质人群**（AML、实体瘤冷肿瘤）：−5~10%
- **联用/早期（Ph1）**：取低值 8~15%

> 每个试验的 PoS 必须写在交付物里并给依据——这是 rNPV 比"峰值×系数"更严谨的地方。

## 四、出海 / 全球权益的两种处理（决定 Part B 量级）

### 4.1 铁律：peak 一律 =「归公司净捕获」，capture 恒 = 1.0（防双重打折）

> **高频错误（本轮康方 AK112 已踩坑）**：初版把海外节点写成 `peak = ex-China 毛峰值`、`capture = 低双位数 royalty（0.15）`，随后又乘 PoS/地域——等于把 royalty **打了两遍折**，系统性低估出海资产。
> **正确写法**：`peak_rev` 直接定义为**公司实际到手**（royalty 运行率 + 里程碑运行率 + 自建净捕获），`capture` 字段**恒 = 1.0**；地域/风险差异**只通过 PoS 与 launch year 体现**，绝不再用 capture 二次打折。

| 情形 | 公司实际到手 | peak_rev 写法（capture=1.0） |
|---|---|---|
| 对外授权（如 Summit 拿 AK112 海外） | 低双位数 royalty（~20~22%）+ 累计里程碑（~$5B 运行率） | peak = ex-China 毛峰值 × **royalty 运行率**（已含里程碑摊销），即"分成后净收入" |
| 保留全球权、自建/未来合作（如 AK104 全球权益） | 净捕获 ~40~60% 毛利后净额 | peak = ex-China 毛峰值 × **净捕获率**（默认 55%，暴露为敏感性变量）；若纯自建海外 capture→1.0 全拿 |

- 净捕获率 55% 隐含"自建美国商业化"；若改为 20~25%（纯 royalty 路线），全球价值缩水 2~3 倍——**必须在交付物标注此假设**。
- **helper**：`royalty 运行率 = 全球毛峰值 × royalty%`；对外授权 vs 自建的差异已并入 peak，不要再用 capture 区分。

### 4.2 节点必含「地理」字段（防"中国 III 期误判为全球捕获"）

每个 Part B 节点**必须带地理标记**，贯穿模型与报告：
- `中国`：仅中国权益/中国单区域试验（如 HARMONi-GI1 BTC 中国单区域）
- `海外`：对外授权或 ex-China，归公司净捕获按 4.1
- `全球`：公司自持全球权益（如 AK104 全球权益），peak 已是混合净捕获
- **规则**：中国单区域试验阳性 ≠ 自动获得海外峰值；海外需伙伴另行启动全球 III 期（如 Summit 的 HARMONi/3/7），否则不得计入海外节点或仅以小概率期权计入。

## 五、汇总与 EV 桥

```
EV    = Part A + Part B
权益值 = EV − 净现金（现金−有息债）
隐含空间 = 权益值 / 当前市值 − 1
```

## 六、校准护栏（避免 rNPV 失控，来自实战教训）

### 6.1 市值对账自动化护栏（硬触发规则）

算出 EV/权益值后，**必须**与市场价对比，并触发以下硬卡（不得跳过）：
- **EV / 市值 > 1.5×** → 强制自查：① 全球净捕获率是否过高（>55%）？② ex-China 峰值是否过胖（对照已上市竞品 global 销售）？③ PoS 是否整体偏松？④ 是否把"中国 III 期阳性"误算成全球捕获？
- **EV / 市值 < 0.7×** → 检查是否漏计已商业化资产（Part A 缺失）、或海外/组合疗法收入未计入。
- **0.7× ~ 1.5×** → 视为合理区间，交付物说明 gap 的**分析含义**（市场隐含了多低的 PoS/捕获率），而非简单喊低估。
- 交付物**内置「市值对账卡」**：EV、股权值、当前市值（HK$ × 股数 × 汇率）、隐含上行，四数同屏。

### 6.2 事件 → 市值 delta 分解（交易决策附加层）

当用户问"某获批/数据对估值影响"时，用**事件冲击分解**直接回答：
```
单日市值增量 = |新市值 − 旧市值| （按事件日前后收盘价/盘中价）
该节点 rNPV 贡献 = 对应 Part B 节点 rNPV
price-in 比例 = 单日市值增量 / 节点 rNPV
```
- 比例 < 0.6 → 市场尚未充分 price-in（剩余空间 + 杠杆效应待兑现）
- 比例 0.6~1.0 → 基本消化
- 比例 > 1.0 → 情绪/β 超涨，需警惕回吐
- **杠杆效应**：单节点阳性常提升同机制/同瘤种其他节点的事前 PoS（如 BTC 阳性→TNBC/mCRC/PDAC 冷肿瘤 PoS 上修），其合计 rNPV 远超单节点本身。

### 6.3 两分法防双计 checklist（强制）

每个适应症只能落在 **A 或 B 一处**，杜绝经典双计：
- [ ] 已获批/商业化中适应症 → **仅 Part A**（含已批 3 NSCLC 等）
- [ ] 在研/未批适应症 → **仅 Part B**
- [ ] 组合疗法（如 AK112+AK117 头颈 combo）：**只在主导药节点计一次**（中国+海外可各一列），搭档药节点**不再重复计**该适应症
- [ ] 节点表加一列"所属分部 A/B" + "地理"，交付前逐行核对无重叠
- [ ] 对外授权收入与自建收入不重复；royalty 已并入 peak 则 capture 不再打折（见 §4.1）

### 6.4 其他单位/时点铁律

1. **单位铁律**：金额统一为"亿 RMB"；USD 百万($M) → 亿 RMB = $M/100 × 汇率（常见错误：直接 ×7.1 漏掉 /100，导致放大约 100 倍）。
2. **时点核验**：财务数字以港交所/公司公告董事会审议日为准，搜索索引常误标年份（同 `source_whitelist.md` 第八节）。
3. **rNPV ≠ 市值**：中国 biotech 普遍含"执行/融资稀释/地缘"折价，模型值结构性高于交易价。

## 七、交付物标准（交互式）
- 深灰+翠绿终端美学，纯单文件 HTML 无依赖。
- 必含：
  - **市值对账卡**（§6.1 硬触发）：EV、股权值、当前市值（HK$ × 股数 × 汇率）、隐含上行，四数同屏，并标注触发状态（>1.5×自查 / <0.7×查漏 / 合理区间）。
  - Part A 表、Part B 逐试验表（**含 PoS 列+依据+地理字段+所属分部 A/B**），按资产 rNPV 柱状图(SVG)。
  - **事件→市值 delta 分解**（当用户问"获批/数据影响"时，§6.2）：单日市值增量 vs 节点 rNPV + price-in 比例 + 杠杆效应。
  - **三滑块敏感性模拟器**（折现率 / 全球 PoS 乘数 / 净捕获率或经营利润率），下游数值实时重算。
  - 🟢🟡🔴 局限与待核实。
- 交付前跑一遍 **§6.3 防双计 checklist**，确认无适应症跨 A/B 双计、组合疗法不重复计。
