# SCI Medical Journal Shortlist (Reference Seed List)

> **CRITICAL — READ FIRST**
> This file is a **seed shortlist of real, established SCI medical journals** to initialize
> the recommendation search. It is NOT an authoritative source of Impact Factor (IF), JCR
> quartile, or operational metrics. All numbers (IF, quartile, TFD/TTA/AR) change yearly and
> vary by year/manuscript type.
>
> **Every `≈` value below is a SEED ESTIMATE — always web-verify before finalizing.**
> - TFD = Time to first decision (初审决定时长)
> - TTA = Time to acceptance (录用时长, from submission to accept)
> - AR  = Acceptance rate (录用率)
>
> **Before finalizing any journal in the SKILL output:**
> 1. Verify the latest IF and JCR quartile via WebSearch for each candidate.
> 2. Verify **TFD / TTA / AR** (journal "About"/"Author Info" pages, or SJR/ScimagoJR).
> 3. Verify the journal's current **Aims & Scope**.
> 4. Confirm recent published themes (last 12–24 months) fit the manuscript.
> 5. Screen for predatory status (Think. Check. Submit.; Cabell's denylist; DOAJ inclusion).
>
> The tier labels (T1/T2/T3 orientation) are **relative guidance only** assuming a typical
> strong-but-not-breakthrough manuscript. Always re-rank against the actual manuscript's
> Novelty Score and the user's target quartile.

---

## How to use this list
- Match the manuscript's **primary field** to a section below.
- Pick candidates spanning the three tiers (aim ≥3 per tier), then **web-verify** and
  re-sort by the manuscript's measured quality.
- Expand with additional verified journals the web search surfaces (esp. society-owned
  specialty journals and strong regional journals).

## Predatory / low-trust screening (check before recommending)
- Cross-check every candidate against **Think. Check. Submit.** (thinkchecksubmit.org).
- Cross-check Cabell's denylist and confirm **DOAJ / PubMed / Scopus** indexing.
- Be especially wary of: unsolicited invitation emails, unusually low APC with high IF
  claims, broad "universal" scopes, and missing editorial boards.
- If uncertain, **do not recommend** — prefer a verified society or major-publisher journal.

## Verification query templates (WebSearch)
- `"<Journal Name>" Impact Factor <year> JCR quartile`
- `"<Journal Name>" time to first decision acceptance rate`
- `"<Journal Name>" average time to acceptance weeks`
- `"<Journal Name>" aims and scope recent articles <year>`
- `"<Journal Name>" predatory OR think check submit`
- Cross-check metrics on **Scimago JR** (scimagojr.com) and **SJR / SNIP** pages.
