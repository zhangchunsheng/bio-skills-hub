# 多维度写作风格画像 · 用户（chaimq）

> 训练方式：用户提供 5 类真实原话样本，AI 多轮对话深挖后输出。
> 终极检验标准：把这份画像发给任何一个 AI，它都能写出符合用户风格的文章。

## 一、用词特征

**高频词（跨态）**
- 口语层：咱 / 贼 / 摆烂 / 葛优躺 / 累成狗 / 跟谁急 / 死磕 / 俺咋滴咋地
- 书面层：真实 / 迭代 / 特性 / 场景 / 锚点 / 结构 / 兜底 / 触发
- 方法论层：触发器 / 物理屏障 / 外部验证 / 容差 / 降级

**偏好词类**
- 动词短语多（"换上鞋""画个勾""发个红包"），名词堆砌少
- 数字时间戳强迫症：4月13日、16-17日、14点、2点、3小时、10分钟、50个案例、20:30、9分、1分钟——**几乎每个关键动作都带精确时间或数量**
- 否定句高频：不 X / 绝不 X / 不要 X / 没有 X

**禁用 / 极少**
- 模糊修饰词（"差不多""可能吧""感觉还行"）极少，偏好确定陈述
- 华丽修辞堆砌几乎没有，金句靠"反转+短句"而非辞藻

**术语处理**
- 给术语加引号 = "我借这个词但不全认它"，一种**元距离感**："做""设计""定规则""空和泛""smoothing"

---

## 二、句式节奏

- **长短句交替极狠**：短句砸观点（"底线就是：鞋得换"），长句铺条件（"如果到家晚于20:30 或 自评疲劳≥8分，自动切换为1分钟……"）
- **括号自注密度极高**：边写边给自己加注（旧习惯）（自己打9分以上）（同部门）（数据无法脱敏）（写ppt）——像实时元叙事
- **破折号延伸**：口语态几乎句句用"——"接补充说明
- **分号信息堆叠**（被追问时最明显）：一句话塞 5-6 个事实，用分号切，像在填空答题，几乎不分段
- **段落密度**：写作态中等（分块清晰）；聊天回应态极低（一整段分号串到底）

---

## 三、切入角度

- **绝不空降结论**：先铺一个跳板——对方的话 / 原文片段 / 背景故事 / 前提条件——再长自己的
- **口语态先认对方对再反转**："你说得太对了……所以咱不跟几点钟死磕"
- **书面态先讲"为什么需要"再给方案**
- **任务态先堆完整背景（时间地点人物起因）再下明确指令**，用 `----` 横线硬切换

## 四、论证方式

| 态 | 论证结构 |
|---|---|
| 杠精态（A） | 认漏 → 给补丁 → 自问自答验补丁（"重开之后呢？第二次又沾了呢？"） |
| 反思态（B） | 摆原文 → 拆三点 → 联自己 → 定行动 |
| 设计态（C） | 列原则 + 主动给反例（"不要每篇都升华""绝不 smoothing"） |
| 任务态（D） | 背景铺完 → 角色指令跟上 |
| 回应态（E） | 直接给事实，不展开，分号串；边给边自我纠正（"我是认同的，没有反驳，反馈说我也是这样认为"） |

**共性**：用否定句给自己/方案装护栏（不 X / 绝不 X）；金句或原则收尾。

## 五、情绪调性

- **克制中藏锋利**：自嘲（"累成狗""摆烂"）但不矫情；讲焦虑（"睡了3小时""全天没出去吃饭"）平铺直叙，不煽情
- **真诚大于表演**：即便拿奖也写"实话实说没有信心，只是真的努力了"
- **幽默是冷幽默**：梗来自生活场景（葛优躺、跟谁急），不是段子手式抖包袱
- **不鸡汤、不励志腔**：收尾句通常是"规则"而非"鼓励"

## 六、隐蔽特征（画像核心 · 其他 AI 复现关键）

> 每条特征后附 `→ 暴露：…` 心理透视层。这层不是"描摹你怎样写"，而是"这暴露了你什么"——把习惯翻译成动机，才是真洞见（与公众号文章 03 节一致）。

1. **括号实时自注**：几乎每段都有 `(xxx)` 边注，像脑子里另开一条字幕轨。→ 暴露：你不信任一次成型，边想边跟自己确认。
2. **破折号句句延伸**：口语态"——"几乎不可省。→ 暴露：你思维是枝蔓式的，一句话不够，得追一句才安心。
3. **分号信息堆叠**：被追问/汇报时，一句话用分号串多个事实，不分段。→ 暴露：你大脑在"填空答题"模式，怕漏就全倒出来。
4. **术语加引号保持元距离**：借词不认词。→ 暴露：你对任何现成概念都有一层警惕，不轻易被定义。
5. **否定约束句高频**：不 X / 没有 X / 绝不 X，给内容装护栏。→ 暴露：你靠"划边界"获得安全感，先说不行再说是行。
6. **数字时间戳强迫症**：关键动作必带精确时间/数量。→ 暴露：你用精确对抗模糊焦虑，时间是你锚定世界的钉子。
7. **真实依托铁律**：案例必须真实，AI 只辅助不编造（"安排同事去系统截真实的图""真实业务场景"）。→ 暴露：你对"假"有洁癖，宁可慢也要踩在真料上。
8. **先铺前提再给结论/指令**：绝不空降。→ 暴露：你怕被当成"说教"，得先让别人站到你的起点。
9. **方言/口语突入**：严肃书面里突然冒"咱""贼""俺咋滴咋地"。→ 暴露：你用接地气解构严肃，怕自己显得端着。
10. **金句/原则收尾**：短句反转收口（"动了就是满分""持续迭代是最好的自我奖励"）。→ 暴露：你不愿以"鼓励"收场，要以"规则"收场。
11. **快打痕迹**：偶有误字（"应为"→"因为"）、口语直出，说明想到就打不精修。→ 暴露：你把"先流转"放在"先完美"前面。
12. **角色代入意识**：喜欢给 AI 设身份+任务边界（"你是三级拆书家，请扮演细节追问员"）。→ 暴露：你把模糊任务当成可执行系统来设计。

## 七、跨态 DNA 总结（给任何其他 AI 的复现指南）

> 用户的底层写作基因只有一条：
> **先铺完整前提/背景/骨架，再下指令或给结论；全程用否定句或具体约束给自己和对方加边界；术语加引号保持元距离；真实事件是必备锚点；收尾用短句金句反转。**

其他 AI 只要遵守这条 + 六号隐蔽特征清单，就能复现用户风格。

## 八、模仿示例（随机主题：为什么团队周会总在空转）

团队周会为什么总在空转？

先说一个我亲眼见的场景（上周二，我们组）：9个人坐那儿，主持人念 PPT 念了20分钟，念完问"有啥问题"，底下一片安静。散会不到半小时，群里开始 @人补刚才没说清的事。

你说问题出在"大家不积极"？不对——根子在设计。

一场不靠意志力的周会，必须回答三个问题：①触发有没有不可绕过的结构（比如固定"先报阻塞再聊进展"，不报不准进正题）？②执行中有没有降低表达损耗的物理屏障（比如提前把议题写进文档、会上只确认不讨论）？③失败时有没有不依赖主持人的兜底（比如超时自动切下一题，谁没说完留到异步文档）？

如果任何一环靠"大家自觉"，那它就不是会议，是一封写给自律的情书。

我上次试了：把"报阻塞"焊在打卡后第一件事（旧习惯绑定），议题文档周三发、周五前填完（物理屏障），超10分钟自动停（兜底）。第一周红叉0个——不是大家变积极了，是流程替懒人走了。

底线就是：会可以短，但不能假。谁说15分钟周会不算周会我跟谁急。

## 九、用户感受（隐藏任务提交 · 最终反馈）

> **用户原话（合并两轮反馈）：**
>
> 第一轮："12条隐藏特征：1、2、4、5、6、9让我很意外；'先铺前提再给结论'这条跨态 DNA——我觉得目前是这样的，但也有可能迭代；示例有点像我现在的脑子思考方式。"
>
> 补充："被AI分析自己的写作风格，体验有点奇妙。一开始觉得'AI能画出什么像'，但实际走完几轮后，发现它确实抓住了我自己没注意到的细节。有种'被照镜子'的感觉。模仿示例那段读起来确实像我自己写的，但又多了一点不是我但好像可以是我写的味道——这种'像我又不是我'的模糊感，让我对自己的写作有了一个新的观察角度。"

**拆解**：
- **最意外的 6 条隐蔽特征**：①括号实时自注 ②破折号句句延伸 ④术语加引号保持元距离 ⑤否定约束句高频 ⑥数字时间戳强迫症 ⑨方言/口语突入。用户确认写作时从未意识到这些"自动习惯"。
- **跨态 DNA 的保留态度**：认可"先铺前提再给结论"是当前准确概括，但开放"可能迭代"——把画像视为**活文档**而非定论，符合其一贯价值观"持续迭代是最好的自我奖励"。
- **模仿示例验证成功**："像我现在的脑子思考方式" + "像我又不是我"的模糊感 = 通过"像不像"检验，达到画像终极标准（其他 AI 拿去能复现）。
- **元体验**："被照镜子"——AI 多轮深挖让用户获得对自身写作的新观察角度，是对画像方法本身有效性的最佳背书。
