# 母版 · 预测·评分·异常型

## 何时用
输出是**对一个当下没有确定答案的量做预测 / 评分 / 异常提示**——不是挑既有事实（提取型）、不是对照标准判定（判定型）。工作单元多为 **一个对象（受试者/中心/记录）的一次打分**。典型：风险监查（RBM）、安全信号侦测、脱落/入组预测、数据异常侦测。

> **关键难点**：当下**无 ground-truth**（未来才知道），所以"准=与来源一致"不适用；输出是概率性的，天然有假阳/假阴——评测和守界都得换口径。

## 地图形状
- **工作单元**：一个对象的一次评分/预测。
- **主线**：取特征 → 打分/预测 → 给分数+驱动因子+置信 → 人决定处置。
- **分路**：① 有明确规则阈值 → 走规则 ② 需模型打分 → 走模型 ③ 低置信 / 分布漂移 → 降级+提示。
- **闸口**：低置信 / 输入分布漂移 / 特征缺失 → 降级（退回规则或人工）、不硬给。

## 五动作形态
- **对齐**：预测目标定义、特征与口径、评分区间与处置阈值、模型版本。
- **分路**：规则阈值 / 模型打分 / 低置信降级。
- **定责**：系统算特征与规则；AI 给分数+驱动因子+置信、不替人做处置决定；人依分数决定行动（监查/干预）。
- **守界**：低置信/漂移/特征缺失 → 降级并提示，不硬预测；**绝不把预测当既成事实或诊断**。**〔红线〕医学 / SAE 四项（严重性·严重程度·因果·预期性）判断留有资质者，AI 只给分数与驱动因子、不下诊断/结论。**
- **交付**：分数/等级 + **驱动因子（可解释）** + 置信 + 建议关注点，人决定处置。

## 评测（准·稳·停）
- **准**：**群体级**指标——校准（calibration）+ 区分度（AUC/AUPRC），不是逐条"对不对"；安全相关看召回/假阴性。
- **稳**：同输入同分；并**监控输入分布漂移（drift）**。
- **停**：低置信/漂移能降级；**安全相关假阴性单列重点盯**。

## 治理
留痕（模型版本 | 特征快照 | 分数 | 人工处置）+ 合规可核项；模型与数据漂移可监控、可追溯。**地板**：安全信号/影响受试者者不得置低档、假阴性重点盯。

## 产品核心能力（②）
**承重（最难）**：**拿什么信息来估、几路信息怎么合成一个分、以及"现在还没有真实结果、凭什么信这个预测"怎么办**（这条含糊，整个就是空的）。其余：**给得出"为什么这么估"的主要原因**；数据一变样就**降级、提示别硬信**；情况超出把握就退回人工。〔别写黑话〕

## 范例（脱落风险预测）
对受试者算脱落风险分+驱动因子+置信，高分提示 CRC 关注；评测=校准+AUC、假阴性重点盯；低置信降级；留模型版本 + drift 监控。
