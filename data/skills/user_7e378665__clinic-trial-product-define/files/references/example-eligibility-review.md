# 完整范例 · 入排审核（判定·分类型为主的跨型 · 风险高）

第二个**填满四层**的端到端示范。挑这个场景，是要补上智能录入范例看不到的三件事：**判定型的承重能力（标准拆解 + 改版重判）、一个需求跨几型合成到一张图、以及"本任务不裁决单个 AE、不机械套 SAE 红线、改写本任务真正失效面"**。任务：某试验候选受试者的入选/排除（I/E）标准审核。

## 第 0 步 · 大白话对话（实录，示范"大白话在前、画像是副产品"）
> **产品**：你想让它帮你做的到底是哪件事？
> **用户**：每个候选受试者入组前，我们要拿他的病历，对着方案里几十条入选/排除标准一条条看符不符合，慢，还怕漏。
> **产品**：看完你手上多出来的，是每条标准"符合/不符合"的结论吧？
> **用户**：对，最后汇成"这个人能不能入组"，每条得有依据。
> **产品**：判错了会怎样、谁最后签字？
> **用户**：把不合格的人判进组是严重违背，影响受试者安全和数据；最后研究者签字负责。
> **产品**：怎么算判对了——能对着方案标准一条条核吗？
> **用户**：大部分能，像年龄、某个化验值有没有超范围；但有些像"无临床显著的合并疾病"要医生拿捏。

（背后推出：**判定·分类型为主** · **风险高**〔入排资格，硬分类、强制高档、不可下调〕· 工作单元=每条 I/E 标准 · 有方案标准可对照 · 含医学判断的条归研究者 · **跨型**：纯规则条〔年龄〕＋ 需先提取事实再判的条〔化验值〕＋ 需医学判断的条〔临床显著性〕——全程没跟用户提过一个术语。）

## 问题定义卡
- **业务问题**：每名候选者入组前，需把其病历事实逐条对照方案数十条 I/E 标准判"符合/不符合"，慢、吃经验，漏判一条就可能让不合格者入组（严重违背、危及受试者）。
- **AI 设计题**：非 AI 基线（把标准做成勾选清单/硬规则表）能覆盖"年龄≥18、某化验值在区间"这类纯规则条，但覆盖不了"要先从病历定位事实再判"和"标准含'临床显著'等需医学解读"的条；AI 增量只落在——**从病历定位判定所需事实 + 给带依据链的符合性建议 + 把需医学判断的条挑出来转人**，研究者兜底签字。
- **本轮范围**：取一个已入组批次的 I/E 条目做回溯验证，走通"事实定位 → 逐条符合性建议 + 依据链 → 边界/医学条转人 → 研究者复核签字"。
- **明确不做**：不追求 AI 判满所有条；不替研究者裁决医学显著性/因果；边界即转人，不对排除条命中与否硬下不可弃权的结论。
- **验收标准**（可测·非口号）：金标准=一批研究者已终判的 I/E 条目作参照（样本量 N 上线前定、由研究者裁定）；**逐条"判定一致率"、依据链"引对率"分别设数字阈值（不用"不低于人工"）；不符合/命中排除条的"漏判（判成符合）"按穷尽复核测、目标=0（安全非对称，漏判远比误判危险）；净省时（AI 初筛 + 研究者复核 vs 纯人工）作为"是否解决了慢"的反证指标。**
- **数据关 & 风险档**（三问）：病历即便去掉姓名病案号，仍是**对具名候选者做入组决定**、且残留生日/化验值等准标识 → **去标识文档喂模型、研究者回连签字**；知情同意与伦理允许入组审核用途 → 过；涉入排资格 → **风险档=高（硬分类，不可下调）**。

## 设计地图（判定·分类型为主 · 跨型 · 风险高）

### ① 故事主线
明确本试验 I/E 标准清单 → 逐条对齐"这条要看哪些事实、按什么规矩算符不符合" → 从病历定位所需事实及出处 → **分路判定**（纯规则条走系统 / 需推导条 AI 给建议＋依据链 / 边界与医学条不判、标待人） → 汇总"能否入组"＋全部依据 → 研究者复核改判并签字 → 归档
　　**支线**：事实缺失 / 标准需实质解释 / 落在边界 → 该条弃权标"待研究者判"，不阻断其他条

### ② 产品核心能力
**承重（判定型成败在此）**：能把**方案里用大白话写的每条 I/E 标准，拆成"判这条要看病历里哪些数据、按什么规矩算符不符合"、让系统逐条照着判**；而且**方案一改版（标准修订很常见），能自动认出哪几条受影响、要对已筛人群重判**，旧筛查结论还能回看是按哪版标准做的。其余：把"凭病历哪条事实、依方案哪条标准得出"**串成一条研究者能复核的依据链**；需先取值的条（如某化验值是否在区间）要能**指到病历里那个值的位置、并核对单位/区间**（这段是提取型的活，并进来）；拿不准或含医学显著性的条**单独挑出来交研究者**。〔说清能干啥、难在哪，别写数据结构/代码黑话〕

### ③ 五动作决策（跨型：各段并列在同一张图）
- **对齐**：本试验 I/E 标准全集与**版本**、每条的判定维度与所需事实、病历来源与口径。
- **分路**（按"这条能不能硬判"切）：① **纯规则条**（年龄≥18、某化验值在区间）→ 系统硬规则，属**非 AI 规则泳道**，不劳模型；② **需先提取事实再推导的条** → AI 定位事实（提取型子段）＋ 给符合性建议 ＋ 依据链；③ **边界模糊 / 需医学判断的条**（如"无临床显著的合并疾病"）→ 不判，标"待研究者"。
- **定责**：系统跑纯规则条；AI 给②类符合性建议 ＋ 依据链、无据或边界弃权；研究者复核全部、改判、对医学条终裁并签字。
- **守界**：事实缺失 / 标准需实质解释 / 落在边界 / 需医学判断 → 该条不判、说明缺什么，不阻断其他条。**子任务接缝闸：某条依赖的事实未经确认，不喂给"是否符合"的判定。〔红线〕医学/科学性判断（某合并疾病是否"临床显著"、某异常值的临床意义）留研究者，AI 只整理支持事实与标准出处、不下判；涉化验数值须带出处＋单位/区间核对。本任务是"逐条判入排符合性、不裁决单个 AE"，故不套 SAE 四项——本任务真正的失效面是：把"需医学显著性判断的条"当硬规则判了、或把"不符合/命中排除"漏判成"符合"，这两条才是这里要在守界显性挡住的红线。**
- **交付**：每条 符合/不符合/待判 ＋ 依据链（病历事实 → 方案标准出处）＋ 边界标注 ＋ 汇总"可否入组"，研究者可同时复核、改判、署名。

### ④ 评测·治理轨
- **评测**：准=逐条判定与"方案标准＋病历事实"一致（是"判得对"，不是"值对"），盯误判/误分类与依据是否成立；稳=同一事实、同一标准版本，判定不漂移；停=边界/证据不足能弃权，并查过度停（该判不判）与系统性误分类；**安全非对称：不符合/命中排除条的"漏判（判成符合）"单列为重点指标，默认走更严一侧、宁可多转人。**
- **治理**：留痕（**标准版本** | 病历事实来源位置 | AI 判定 | 依据链 | 研究者终判 | 操作人·时间 | 输入快照〔去标识〕）→ 可审计、可追溯"按哪版标准判"；涉签名 → 研究者终判署名留痕；合规=去标识与最小化 · 数据流向与留存 · AI 参与可追溯披露（按 GCP/SOP）· 点明适用法规。
