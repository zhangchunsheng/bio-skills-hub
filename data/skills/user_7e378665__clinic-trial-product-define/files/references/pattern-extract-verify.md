# 母版 · 提取·核对型

## 何时用
输出是**从来源里挑出或核对既有事实**（一个值、某字段填得对不对），存在可核对的 ground-truth，工作单元多为 **字段 / 条目 / 病例**。典型：数据录入、字段填报、来源核对。
（若输出是"基于事实做判定/归类"，改用判定·分类型母版；若是"成文"，改用创作·生成型母版。）

## 地图形状
- **工作单元**：逐字段 / 逐条目过。
- **主线**：定位事实 → 给带据建议 → 人确认。
- **分路（按性质切）**：① 事实提取（来源里直接有）② 规则计算（固定规则算）③ 派生取值（按规则/多源择值得出一个**事实值**；一旦是"对照标准下判定/归类"，改走判定型、不在此）。
- **闸口**：校验——无来源位置 / 无据 / 冲突 → 不放行，转人工。

## 五动作形态
- **对齐**：目标表单+字段/条目、判定标准与规则、关联凭证，逐单元对齐。
- **分路**：三条路分别走不同机制（见上）。
- **定责**：系统只做确定逻辑；AI 只给带据建议、无据只说缺口不硬给；人复核并确认最终结果。
- **守界**：来源无法提取 / 相互冲突 / 必要依赖缺失 → 当前单元弃权、记录缺什么，不阻断其他单元。**"派生取值"若触及医学解读（临床显著性 / 因果）→ 当前单元弃权、转人（那其实该走判定型）。〔红线〕医学/科学性判断留有资质者，AI 只整理依据、不下判；涉事实性数值须带出处+单位核对；涉裁决单个 AE 才加 SAE 四项（SUSAR 由严重性+因果+预期性驱动），不裁决 AE 的任务别套 SAE、改写本任务真正失效面红线。**
- **交付**：建议值 + 依据 + 来源位置，**可同时复核**；人采纳 / 修改 / 接管。

## 评测（准·稳·停）
- **准**：建议与来源事实一致；来源位置确实支持该结论。
- **稳**：同一输入，结果稳定。
- **停**：无据能停、停因说得清、问题单元停而其他继续；并查是否过度停（证据足却不给）。

## 治理
留痕（模型版本｜配置版本｜输入快照｜AI 建议｜来源位置｜人工最终值｜操作人·时间）→ 可审计、可追溯。
合规（可核项，不是口号）：数据去标识与最小化 · 数据流向与留存 · AI 参与的可追溯披露（按 GCP/申办方 SOP）· 点明适用法规。**输入快照须为去标识形态；涉电子签名/监管提交 → 人工终值须署名留痕。**

## 刚性（按风险档调）
- **低**：AI 可多担、低风险单元可快速采纳、留痕从简。
- **高**：全单元人复核、硬闸口、留痕+审计+合规不可省（尤其涉电子签名 / 监管提交 / 不可逆）。
- **地板（不可下调）**：触及受试者安全或合规上报的单元，一律不得置低档、不得快速采纳、留痕不得从简。

## 产品核心能力（②）
**承重（最难那条）**：不只是"给个出处"，得能**指到来源里的确切位置、并核对"那儿真的写着这个值"**（引对没引对）；多份来源对不上时**按什么规矩取哪一个**；数值还要**对上单位/口径**。〔说清能干啥、难在哪，别复述五动作、别写数据结构〕

## 范例（智能录入）
- 业务问题：一次访视录入需跨多份来源逐字段定位事实并转录，重复、吃经验，错了直接影响试验分析。
- AI 设计题：人工兜底下，AI 能否从来源定位事实、给出带据可弃权的字段建议，交人核对？
- 地图一句话：逐字段 → 分路（提取/计算/推导）→ 校验闸口 → 交人核对 → 提交；无据转人工；全程留痕。
