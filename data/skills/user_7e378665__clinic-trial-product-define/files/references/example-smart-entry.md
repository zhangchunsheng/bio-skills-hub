# 完整范例 · 智能录入（提取·核对型）

一个**填满四层**的端到端示范，给学习者/其他 LLM 照着复现。任务：一次访视 eCRF 录入。

## 第 0 步 · 大白话对话（实录，示范"大白话在前、画像是副产品"）
> **产品**：你想让它帮你做的到底是哪件事？
> **用户**：我们录入员每次访视都要照着一堆化验单、病历，往 eCRF 里一个字段一个字段填，太慢。
> **产品**：填完你手上多出来的，是一条条填好的数据吧？
> **用户**：对，就是把该填的值填进表。
> **产品**：填错了会怎样、谁最后签字？
> **用户**：错了影响数据分析；最后录入员核对，医学上的事研究者负责。
> **产品**：怎么算填对了——能跟原始单子一条条对上吗？
> **用户**：能，值就在化验单/病历上。

（背后推出：**提取·核对型** · **风险高**〔进 eCRF 正式数据〕· 工作单元=字段 · 有 ground-truth 可核 · 医学判断归研究者——全程没跟用户提过一个术语。）

## 问题定义卡
- **业务问题**：一次访视录入需跨多份来源逐字段定位事实并转录，重复、吃经验，错了直接影响试验分析。
- **AI 设计题**：人工兜底下，AI 能否从来源定位事实、给带据可弃权的字段建议，交人核对？
- **本轮范围**：选一次访视数据工作包，验证"事实定位 → 字段建议 → 人工核对"。
- **明确不做**：不追求 AI 填满字段；无据/冲突不强给；不替人做医学判断。
- **验收标准**（可测·非口号）：金标准=一批人工已核字段作参照（样本量 N 上线前定）；**建议值一致率、来源位置"指对率"分别设阈值**（不用"不低于人工"）；**安全相关字段漏读/误填按穷尽复核测、目标=0**；**净省时**（AI+复核 vs 纯人工）作为"是否解决了慢"的反证指标。
- **数据关 & 风险档**（三问）：图片虽脱敏，录入仍是**对具名受试者**的决定 → **去标识文档喂模型、录入员/研究者回连签字**；伦理与知情同意允许、输入快照去标识 → 过；涉 eCRF 正式数据 → **风险档=高（硬分类，不可下调）**。

## 设计地图（提取·核对型 · 风险高）

### ① 故事主线
明确录入任务 → 对齐字段与要求 → 定位事实及出处 → 分路生成字段结果 → 人工核对并确认 → 提交
　　**支线**：依据不足 / 冲突 → 合理停止 → 转录入人员手工

### ② 产品核心能力
**承重**：不只是"附张图"，得能**指到图上那个值的确切位置、并核对"那儿真写着这个数"**；多份来源对不上时**按什么规矩取哪个**；数值还要**对上单位**。其余：把该带的表单/凭证凑齐；BMI 这类算出来的值要能追到从哪两个数算的。〔别写数据结构〕

### ③ 五动作决策
- **对齐**：目标表单+字段、录入要求、关联凭证，逐字段对齐。
- **分路**：直接提取 / 规则计算（如 BMI=身高+体重） / 依据推导；**推导若触及医学解读 → 弃权转人**。
- **定责**：系统算确定逻辑；AI 给带据建议、无据不给；录入人员复核确认，**医学判断转研究者**。
- **守界**：来源无法提取 / 冲突 / 依赖缺失 → 该字段弃权、记缺口，不阻断其他字段。**〔红线〕医学判断（如某异常值是否临床显著）留研究者，AI 只整理依据、不下判；涉数值（如 BMI）须带出处 + 单位核对。本任务不裁决单个 AE，不套 SAE 红线。**
- **交付**：建议值 + 依据 + 来源位置，可同时复核；人采纳 / 修改 / 接管。

### ④ 评测·治理轨
- **评测**：准=值与来源一致且位置支持；稳=同输入同结果；停=无据能停、**安全相关假阴性单列**。
- **治理**：留痕（模型版本｜配置｜输入快照〔去标识〕｜AI 建议｜来源位置｜人工最终值｜操作人·时间）→ 可审计；涉签名 → 署名。
