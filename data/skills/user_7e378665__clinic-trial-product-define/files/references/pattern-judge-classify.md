# 母版 · 判定·分类型

## 何时用
输出是**基于事实、对照标准做一个判定或归类**——合规/不合规、符合/不符合、Major/Minor、达标/不达标——而**不是**挑出事实本身（那是提取型），也不是成文（那是创作型）。工作单元多为 **条目 / 病例 / 报告 / 偏离**。典型：入排审核、方案/监查审查、PD 分类与评估、质量核查判定。

## 地图形状
- **工作单元**：逐条目 / 逐病例 / 逐项判。
- **主线**：定位事实 → 对照标准 → 给判定/分类 **+ 依据链** → 人复核。
- **分路（按"这条能不能硬判"切）**：① 规则明确可判（硬规则/阈值）② 需综合多因素推导判（依据推导）③ 边界模糊 / 需实质判断（不判，标"待人"）。
- **闸口**：事实不足 / 标准需实质解释 / 落在边界 → **不判定**，标"待人判"。

## 五动作形态
- **对齐**：判定标准与分类定义、规则版本、被判事实来源、判定维度。
- **分路**：硬规则判 / 依据推导判 / 边界待人（见上三条）。
- **定责**：系统跑硬规则；AI 给判定/分类建议 **+ 依据链**、无据或边界弃权；人复核改判；实质/严重性判断留有资质者。
- **守界**：事实缺失 / 规则未覆盖 / 边界模糊 / 需医学或科学判断 → 不判，说明缺什么。**〔红线〕医学/科学性判断留有资质者，AI 只整理依据、不下判；涉事实性数值须带出处+单位核对。涉裁决单个 AE 才加：其严重性·严重程度·因果·预期性不下判（SUSAR 由严重性+因果+预期性驱动），即便有 Naranjo/阈值表也不走硬规则路、不得快速采纳、一律待人判；不裁决 AE 的任务改写本任务真正失效面红线、别套 SAE。**
- **交付**：判定/分类建议 + **依据链（事实 → 所依据的标准/规则）** + 边界标注，人**可同时复核、改判**。

## 评测（准·稳·停）
- **准**：**判得对**（判定/分类与标准+事实一致）——不是"值对"，是"判对"；盯**误判/误分类**与依据是否成立。
- **稳**：同一事实、同一判定/分类，不漂移。
- **停**：边界/证据不足能弃权；并查**过度停**（该判不判）与**系统性误分类**。
- **安全非对称**：影响受试者安全或合规上报的分类（如 PD 定级、AE 严重性相关），**漏判/降级（假阴性）单列为重点指标**，默认走更严一侧、人先判，别被"过度停"掩盖。

## 治理
留痕（标准/规则版本 | AI 判定 | 依据链 | 人工终判），分类与改判可追溯、可复核。
合规（可核项）：数据去标识与最小化 · 数据流向与留存 · AI 参与的可追溯披露（按 GCP/SOP）· 点明适用法规。**涉签名/上报 → 人工终判须署名留痕。**

## 刚性（按风险档调）
- **低**：AI 可多担、规则明确项快速采纳。
- **高**：全条人复核、边界一律待人、实质/严重性判断留专家、全量留痕（尤其影响合规上报的分类，如 PD 定级）。
- **地板（不可下调）**：影响受试者安全或合规上报的判定，一律不得置低档、不得快速采纳。

## 产品核心能力（②）
**承重（最难那条，判定型成败在此）**：能把**方案里用大白话写的每条标准，拆成"判这条要看哪些数据、按什么规矩算符不符合"、让系统逐条照着判**；而且**方案一改版，能自动认出哪几条受影响、要重判**（旧核查还能回看）。其余：把"凭哪些事实、依哪条标准得出"**串成一条能复核的依据**；拿不准的条目**挑出来单独交给人**。〔说清能干啥、难在哪，别写代码/数据结构〕

## 范例
- **入排标准审核**：逐条对照标准判"符合/不符合/待判"，依据=参与者事实+标准出处；含医学判断的条目转研究者裁决。
- **PD 分类与评估**：依据 PD 定义与规则判 Major/Minor + 依据链；边界与严重性影响判断留人。
