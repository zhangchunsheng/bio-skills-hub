# 母版 · 创作·生成型

## 何时用
输出是**生成一段连贯文本**（报告、叙述、申请、撰写稿、方案/计划文档），**没有单一正确答案**，工作单元为 **段 / 文档**。典型：报告撰写、叙述生成、申请填写、RMP/计划生成。

## 地图形状
- **工作单元**：段 / 文档（不是字段）。
- **主线**：AI 起草 → 人审校 → 人定稿并署名。
- **分路（按段的性质切）**：① 纯事实复述段 ② 需组织推理段 ③ 含医学判断/结论段。
- **闸口**：逐条事实溯源 + 查杜撰——有断言无据 / 引入来源外事实 → 挡下。

## 五动作形态（关键：换形，不是调松紧）
- **对齐**：模板/规范结构、术语标准、可用来源与数据范围。
- **分路**：三类段分别管——复述段严溯源；推理段留推导链；判断段只草拟、标注需人定夺。
- **定责**：系统组装模板 / 查合规；AI 只**起草**；人（有资质写作者 / 研究者 / QC）**审校定稿并署名**——人更重。
- **守界**：不整体弃权，而是**逐条事实锚定 · 禁止来源外新事实/杜撰 · 缺口留空标注"待补"不硬写 · 不偏离规定模板与术语**。**数值（剂量/化验值/p值/样本量/终点）必须带精确出处 + 单位核对，无源或不匹配一律挡下、不得由模型生成或换算。〔红线〕医学 / SAE 四项（严重性·严重程度·因果·预期性）判断留有资质者，AI 只草拟、不下判。**
- **交付**：草稿 + 逐条事实来源 + 待定夺处标注；人在此之上审校、补全、署名。

## 评测（准·稳·停 —— 重新解读）
- **准**：拆两层——**事实忠实度**（逐条可溯源、无杜撰、无来源外事实，可核）+ **质量/合规**（结构·术语·语气，靠 rubric / 人评，部分主观）。
- **稳**：不要求逐字一致——要求**关键事实与结论稳定，措辞可变**。
- **停**：数据不足 → 留空/标注待补，不编一段圆过去；结论/医学判断段只草拟、标注需人定夺。

## 治理
留痕 + **AI 草稿 ↔ 人终稿 diff + 署名**（创作改动大、主观，审计与归责全靠这个）。
合规（可核项）：数据去标识与最小化 · 数据流向与留存 · AI 参与的可追溯披露（按 GCP/SOP）· 点明适用法规。

## 刚性（按风险档调）
- **低**（内部纪要草稿）：草稿 + 轻溯源 + 单人快过 + 轻留痕。
- **高**（CSR 结论 / 监管提交 / 知情同意）：草稿 + 强制逐条溯源 + 事实稳定 + 有资质写作者与研究者双审 + 署名 + 全量留痕/合规。
- **地板（不可下调）**：涉监管提交 / 知情同意 / 安全性叙述者，一律走高档，不得轻溯源、不得单人快过。

## 产品核心能力（②）
**承重（最难）**：①每句话都能**指回它依据的原文、核对没引错**；②**该写进去的事实一条都不能漏**（创作最怕漏、不只是"不编"——得有一份"这类文书必须覆盖哪些点"的清单兜底）。其余：术语/格式合不合规范的自查；人改了哪、和 AI 稿差在哪要留得下。〔别写数据结构〕

## 范例（安全性叙述撰写）
- 业务问题：为每例 SAE 撰写安全性叙述，需从多来源汇集事实、按规范成文，量大、吃经验、涉安全性上报不能错。
- AI 设计题：AI 能否按规范起草叙述、每条事实可溯源、不确定处留空标注，交有资质者审校定稿署名？
- 地图一句话：起草（按段分路）→ 逐条溯源+查杜撰闸口 → 人审校补全 → 定稿署名；数据不足留空；草稿↔终稿 diff 留痕。
