# 生物医药实验方案设计标准工作流程

## 触发场景
科研人员或生物医药科研服务公司需要为客户设计科研实验方案，
涉及机制研究、国自然申请书、SCI文章实验设计等。

## 核心原则：四锚点文献检索 → 方案设计

**在写任何实验方案之前，必须先完成四件事：**
**四锚点结构 = 1篇高分综述 + 2篇实验文章 + 1篇博士论文检索建议**

| 锚点 | 文献类型 | 目的 |
|------|---------|------|
| 锚点1 | 高分综述（Review） | 确认研究方向框架和热点 |
| 锚点2 | 实验文章（Original Article） | 获取同疾病/场景实验范式参考 |
| 锚点3 | 实验文章（Original Article） | 核查同类分子机制创新性+方法参考 |
| 锚点4 | 知网博士论文检索建议 | 了解国内完整实验框架 |

---

## 第一步：四锚点文献检索

### 锚点1：最新高分综述（Review）⚠️ 必须锚定当前年份
- 检索目标：**优先检索当前年份和上一年** 发表的高分综述
- 期刊偏好：IF > 10，如 Nature Reviews系列（IF≈70）、Cell Reviews、Trends系列
- 检索方式：PubMed搜索 `[主题词] review [当前年份]:[当前年份][dp]`，若结果不足再往前扩展一年
- 目的：**确认研究方向的最新框架和当前热点**，确保方案引用的是领域最新认知
- **禁止行为**：不能拿两年以前的综述作为锚点1，除非近两年确实无相关综述

### 锚点2：最新同类疾病/场景实验文章（Original Research Article）
- 检索目标：**优先检索近两年**在同一疾病/场景发表的**原创实验文章**（非综述）
- 期刊偏好：IF 6-10，如 Cell Death Dis、Redox Biol、Free Radic Biol Med
- 检索方式：PubMed搜索 `[疾病名] [机制关键词] [当前年份]:[当前年份][dp]`，筛选"Journal Article"且排除"Review"
- 目的：**了解同领域最新实验设计模式**，获取可参考的实验方法学范式，确保方案不落后于最新发表

### 锚点3：最新同类分子机制实验文章（Original Research Article）
- 检索目标：**优先检索近两年**研究同一分子机制（同一蛋白/修饰/通路）的**原创实验文章**（非综述）
- 检索方式：PubMed搜索 `[蛋白名] [修饰类型/通路] [当前年份]:[当前年份][dp]`，筛选"Journal Article"且排除"Review"
- 目的：**确认机制轴的创新性**，检查是否有最新实验文章已报道相同机制，获取具体实验方法参考

### 锚点4：知网博士论文
- 检索目标：近5年发表的相关博士论文
- 检索方式：知网（CNKI）主题词检索，筛选"博士论文"
- 目的：**了解国内同类研究的完整实验设计框架**，包含详细方法学描述，
  对照客户的实验能力和资源

---

## 第二步：创新性核查（关键，防止撞车）

在开始写方案之前，必须核查以下三个问题：

1. **核心分子（A）在目标疾病中是否已有报道？**
   - 检索：`[分子名] [疾病名]`
   - 若已有报道 → 记录文献，调整创新点表述为"首次系统研究/深入机制"
   - 若零报道 → 这是最强创新点，必须明确标注

2. **核心机制（C=修饰）对效应分子（B）的功能后果是否已知？**
   - 检索：`[修饰类型] [效应分子] activity function`
   - 若已有报道功能后果 → **不能声称这是未知的**，改为验证已知机制在新场景
   - 若未报道功能后果 → 这是机制深度创新点

3. **整体故事轴（A→C→B→疾病）是否有完整报道？**
   - 如果每一步都有单独报道，整体仍可发，但需要清晰表述为"首次整合验证"

---

## 第三步：方案结构（固定模板）

每份方案文档包含以下内容，**不含参考文献全文、经费、时间计划**（客户只看方案内容）：

```
1. 标题（中文）
2. 摘要（200-300字，一段）
3. 研究背景与立项依据
   - 疾病背景（2-3段）
   - 科学假说（1段，清晰表述A→C→B→疾病轴）
   - 创新点（3条，每条标注文献依据）
4. 研究内容（3个方向，每个一段）
5. 实验方案（主体）
   - 按图编号，每个大图下列小图（1A、1B...）
   - 每个小图：仅写实验内容 + 检测方法，**不写"预期结果"**（避免编造数据）
6. 预期成果写作规范（见下方专门章节）
7. 参考文献
```

---

## 第三步（补充）：预期成果写作规范 ⚠️ 关键

**核心原则：只写方向和目标，不编具体数据和结果。**

### ✅ 可以写的内容（基于实验体量的合理推断）

| 可写内容 | 判断依据 | 示例 |
|---|---|---|
| 预计产出SCI论文X篇 | 实验体量：纯细胞=1篇3区；细胞+动物=1-2篇2区 | "预计发表SCI论文1-2篇" |
| 目标期刊档次 | 实验体量+创新性：有动物实验→2区；有临床样本→可冲1区 | "目标期刊：Journal of Investigative Dermatology（2区，IF≈6）" |
| 拟申请专利X项 | 机制新颖且有转化潜力 | "拟申请发明专利1项" |
| 为后续基金申请提供预实验数据 | 任何探索性研究都适用 | "为后续国自然申请提供关键预实验证据" |

**判断依据的逻辑链：**
1. 纯细胞实验 → 数据量有限 → 3区（IF 3-5）
2. 细胞+动物实验 → 数据量充足+体内验证 → 2区（IF 5-8）
3. 细胞+动物+临床样本 → 完整转化链条 → 1区（IF >10）
4. 机制完全新颖（零文献报道）→ 可上浮一个档次

### ❌ 绝对不能写的内容（编造数据/给自己挖坑）

| 不能写的内容 | 原因 |
|---|---|
| "预期某某因子表达上调2倍" | 编造具体数值，无法兑现 |
| "预期GSEA富集到TGF-β通路" | 编造生信分析结果 |
| "预期动物模型生存率提高50%" | 编造动物实验数据 |
| "预计Figure 3结果将证明..." | 为每个小图预测具体结果 |
| "预期结果：Piezo1敲除后胶原沉积显著减少" | 用肯定语气描述未做实验的结果 |

### 客户版 vs 内部版 差异

| 内容模块 | 内部版（给你自己看） | 客户版（给客户看） |
|---|---|---|
| 试剂/抗体清单 | ✅ 包含（便于报价） | ❌ 删除（商业敏感） |
| 预算估算 | ✅ 包含 | ❌ 删除 |
| 预期结果（每个小图） | ❌ 本来就不写 | ❌ 删除 |
| 预期成果（论文/期刊） | ✅ 可写 | ✅ 可写，但措辞谨慎 |
| 时间计划 | ✅ 包含 | 可选（视客户要求） |

**客户版措辞示例（谨慎版）：**
> "根据上述实验设计，预计可积累足够数据支撑1-2篇SCI论文发表，目标期刊为伤口修复领域2区期刊（如 *Journal of Investigative Dermatology*, IF≈6）。最终发表档次取决于实验数据的完整性和创新性发现。"

**而不是：**
> ~~"预期结果：Piezo1敲除后创面愈合速度提高40%，胶原沉积减少50%。"~~

## 第四步：交付标准

- **格式**：Word文档（.docx），用 `docx` npm包（Node.js）或 python-docx 生成
- **文件命名**：`[分子名]_[疾病]_实验方案_拟[目标期刊]_[年份].docx`
- **图面板设计**：按A-C-B-热点-疾病框架排布，共8-11个大图，30-45个小图
- **关键试剂**：仅内部版包含（供应商+货号）；客户版删除
- **方案文档末尾**：附"四锚点文献清单"（4条文献的完整标题+期刊+年份+PMID）
- **预期结果**：每个小图下方不写"预期结果"；仅保留"实验方法/检测指标"
- **预期成果章节**：写论文篇数+目标期刊档次，不写具体数据预测

---

## 注意事项

- **知网博士论文**目前只能给用户提供检索建议，让用户自行下载；
  可提供检索关键词和预期论文题目
- 每次检索结果要**截图或记录文献标题**，供用户核实
- 如果文献检索发现创新点"撞车"，**立即告知用户**，不要继续沿用原来的创新点表述
- 目标期刊方向：用户服务的客户通常目标是2区（IF 5-8）；冲1区需要更强的创新设计
- **预期成果的判断必须有依据**：写"目标2区"之前，必须先确认实验设计是否包含动物实验；
  写"冲1区"之前，必须确认是否有临床样本或前瞻性数据
- **客户版文档三层过滤**：生成后必须检查①无试剂/预算 ②无"预期结果"具体描述 ③预期成果措辞谨慎（用"目标/预计"而非肯定语气）
- **四锚点文献类型强制检查**：锚点2和锚点3必须是实验文章（Original Research Article），不能全是综述。生成方案后必须验证"1综述+2实验+1博士论文"的结构。
