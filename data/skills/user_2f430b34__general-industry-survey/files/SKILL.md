# 通用行业调查 Skill（通用行业调查）

> 一句话定位：用户说"查一下XX行业"，30秒给出报告级行业全景图。
> 这是一个通用行业调研框架，输入任意行业名（如房地产、咖啡、新能源汽车）即可套用，不绑定任何特定项目或客户。

---

## 一、核心定位

**解决什么问题**：用户想进一个新行业、找新赛道、调研竞品、找选题/选品方向时，不用自己手动查 N 个网站，AI 一次性给出可直接落地的行业认知。

**输出形态**：报告级 Markdown 文档，八大模块全展开，每个模块有数据 + 表格 + 真实品牌/案例。

**数据来源策略**（按优先级）：
1. **联网搜索公开数据**（WebSearch / WebFetch）：
   - 综合咨询：欧睿国际（Euromonitor）、艾媒咨询、中研普华、灼识咨询
   - 垂直数据：巨量算数（抖音/头条）、新榜、艺恩
   - 电商：京东、天猫、小红书官方榜单
   - 行业媒体：36氪、虎嗅、晚点 LatePost、雷峰网（科技类）、医谷（医疗类）等
   - **平台热搜词**：搜索「小红书热搜 XX行业 2026」「抖音热搜 XX行业 2026」获取最新热搜词
   - **平台账号数据**：搜索「抖音 XX行业 粉丝排行 2026」「小红书 XX行业 博主排行 2026」获取头部账号清单
2. **通用知识库兜底**——对成熟行业直接用行业知识补足

> 可选增强：若用户已接入自己的知识库（如 ima 等连接器），可先查再联网，但本 skill 不强制依赖任何外部连接器。

数据时效性要求：
- **优先使用 2026 年数据**（当前年份）
- 2025 年数据作为对比基准
- 2024 年及更早数据需标注年份
- 老数据需标注年份

## 二、调用方式

### 默认触发词
- 「XX行业数据库」「XX行业分析」
- 「查一下XX行业」「了解一下XX行业」
- 「调研XX行业」「XX赛道调研」
- 「我要做XX，给我出份行业报告」

### 语法支持
| 用户输入 | 行为 |
|---------|------|
| `房地产行业数据库` | 默认全量出，八大模块全展开 |
| `服装行业数据库，只看趋势和品牌` | 全量出，但在「品牌产品」「行业趋势」模块后加 ⭐ 标记，其他模块可折叠 |
| `查一下餐饮，给我概览级就行` | 每个模块给 2-3 个核心结论，不展开（详见粒度切换） |
| `调研一下咖啡行业，对标精品咖啡` | 在文档开头加「对标基准：精品咖啡」一节 |

### 粒度切换
- **报告级（默认）**：每模块详细展开，含表格、品牌清单、具体数据
- **概览级**：每模块 2-3 条核心结论 + 关键数字，快速决策用

## 三、八大模块结构（必填，可裁剪可加深）

> 行业之间差异大，部分行业会缺一些模块，缺位时标「不适用/数据有限」并简短说明原因。

### 模块 1：行业概览
**核心问题**：这行业多大、多快、谁在驱动、格局如何？
- **市场总规模 + 时间**：2024/2025/2026 年数据 + 同比增速
- **渗透率 / 占比**：（如「宠物食品占宠物消费 67%」）
- **驱动因素**：3-5 条核心驱动力
- **竞争梯队**：头部 / 腰部 / 尾部代表品牌
- **生命周期阶段**：导入期 / 成长期 / 成熟期 / 衰退期

**示例（房地产）**：
- 2024 年商品房销售额 9.7 万亿，2025 年预计 8.5 万亿
- TOP10 房企市占率从 2020 年 28% 提升至 2024 年 41%
- 驱动：城镇化放缓 + 改善型需求 + 二手房占比上升
- 梯队：央国企（保利/中海/华润）/ 优质民企（龙湖/滨江）/ 区域深耕型

### 模块 2：品牌产品矩阵
**核心问题**：这行业有谁在做？分别卖什么？差异化在哪？
- **品牌梯队表**：梯队 / 特征 / 代表品牌 / 价位段
- **核心产品线**：按定位分（高端/中端/入门）+ 每个产品线的卖点
- **差异化锚点**：每家品牌的「核心记忆点」（如沃尔沃=安全、宝马=驾驶、海底捞=服务）

### 模块 3：用户痛点
**核心问题**：用户买这个时，在纠结什么？被什么坑过？
- **选购决策痛点**（决策前）：3-5 条决策障碍
- **使用过程痛点**（买完后）：3-5 条使用麻烦
- **售后 / 安全焦虑**（长期）：3-5 条长期担心

**特别要求**：痛点要具体到场景，不要说"品质不好"，要说"用了半年味道就散了"。

### 模块 4：关键词矩阵
**核心问题**：用户怎么搜这个品类？搜索心智词是哪些？

**数据获取方式**：
1. 搜索「小红书热搜 XX行业 2026」「抖音热搜 XX行业 2026」获取最新热搜词
2. 搜索「XX行业 搜索量 2026」获取搜索趋势数据
3. 如可能，访问巨量算数、小红书营销中心获取官方数据

- **品类大词**：行业核心词（附2026年搜索量）
- **长尾精准词**：3-5 个长尾（带场景/带痛点/带人群）
- **品牌词**：头部品牌词（附搜索量）
- **成分 / 工艺词**：（如"零添加""低敏""零糖"）
- **电商转化词**：（"测评""排行""推荐""避坑"）
- **平台热搜词**：小红书 / 抖音 / 淘宝热搜词（按平台分，附2026年最新数据）

**输出格式**：
| 类型 | 关键词 | 2026搜索量/热度 | 适用平台 | 趋势 |
|------|--------|----------------|----------|------|
| 品类大词 | ... | ... | ... | ↑/↓ |
| 长尾词 | ... | ... | ... | ↑/↓ |

### 模块 5：内容渠道玩法
**核心问题**：这行业的人在哪看内容？做内容的人在哪些平台怎么打？

**数据获取方式**：
1. 搜索「抖音 XX行业 粉丝排行 2026」获取头部账号清单
2. 搜索「小红书 XX行业 博主排行 2026」获取头部账号清单
3. 搜索「XX行业 抖音 爆款视频 2026」「XX行业 小红书 爆款笔记 2026」获取近期爆款内容
4. 分析最近3个月（2026年4-6月）的内容趋势

- **小红书玩法**：
  - 笔记类型（测评/合集/避坑/打卡）
  - **Top 30 账号分析**（见模块8）
  - 爆款公式
  - 最近3个月数据最好的内容类型
- **抖音 / 视频号玩法**：
  - 视频类型
  - **Top 30 账号分析**（见模块8）
  - 最近3个月数据最好的内容类型
- **B 站 / YouTube 玩法**（如适用）
- **公众号 / 私域玩法**（如适用）
- **知乎 / 什么值得买**（适合 3C / 母婴 / 家电等）
- **线下渠道**（如适用：经销商、KA 卖场、体验店）

每渠道给 1-2 个头部账号/品牌做代表案例。

### 模块 6：行业趋势
**核心问题**：未来 2-3 年，这行业往哪走？新机会在哪？
- **3-5 条核心趋势**：每条要可落地（不只是"消费升级"这种废话）
- **新机会点 / 细分赛道**：3-5 个高潜新方向
- **政策/监管变化**（如适用）
- **技术/渠道变革**：AI / 直播 / 私域 / 出海 等

**铁律**：趋势必须落到「这意味着我可以做什么」，不能只讲宏观。

### 模块 7：黑榜 / 召回 / 翻车
**核心问题**：这行业有哪些坑、翻车事件、监管处罚？
- **近期翻车事件**：3-5 个具体案例（品牌+时间+事件+影响）
- **常见消费陷阱**：（如"虚假宣传""成分造假""售后跑路"）
- **行业负面舆情热点**
- **监管动作 / 处罚案例**

> 此模块对部分行业不适用（基础设施、底层技术等），可标「不适用」并跳过。

## 五、输出规范

### 输出位置
- **默认**：对话区直接展示完整 Markdown 文档，同时生成 Word（.docx）和 Markdown（.md）两个版本
- **文件保存位置**：默认保存到用户桌面，文件名格式：`{行业名}行业调查报告_{YYYYMMDD}.docx` 和 `{行业名}行业调查报告_{YYYYMMDD}.md`
- **不默认存知识库**：不主动存到任何外部知识库（用户没要求就只给本地文件）
- **用户明确要求存档时**：可存到 `~/.workbuddy/industries/{行业名}_{YYYYMMDD}.md`（本地）

### 长度控制
- **报告级（默认）**：3000-5000 字，含表格、品牌清单、具体数据
- **概览级**：1500-2500 字，每模块 2-3 条核心结论
- **超出处理**：如果该行业资料特别丰富（电商、SaaS、餐饮等），可分上下两篇输出

### 数据真实性原则
- **尽量给具体数字**：不要写"市场很大"，要写"2024 年规模 9.7 万亿"
- **不编造品牌**：没把握的品牌用「某头部品牌」「某新锐品牌」占位
- **数据有年份**：每条数据必须标年份（2024/2025/2026）
- **数据冲突时**：优先采用欧睿/艾媒/中研普华等付费数据源，公开数据次之
- **无法核实标 [待核实]**：宁可标注待核实，也不要编一个

## 七、协作流程

### 标准流程（增强版）

**阶段一：准备与数据获取（并行执行）**

1. **识别行业**：用户说「房地产行业数据库」→ 锁定「房地产」+ 全行业（不限住宅/商业/办公）
2. **明确细分**（如不明确就一次）：问用户「要全行业还是聚焦某细分？」如「住宅地产」「快时尚女装」
3. **并行联网搜索**：
   - 搜索1：行业规模/趋势数据（优先2026年）
   - 搜索2：平台热搜词（「小红书热搜 XX行业 2026」「抖音热搜 XX行业 2026」）
   - 搜索3：平台头部账号（「抖音 XX行业 粉丝排行 2026」「小红书 XX行业 博主排行 2026」）
   - 搜索4：近期爆款内容（「XX行业 抖音 爆款视频 2026年4月」「XX行业 小红书 爆款笔记 2026年4月」）

**阶段二：数据分析与组织**

4. **整理平台热搜词**：提取小红书/抖音2026年最新热搜词，填入模块4
5. **整理 Top 30 账号**：提取抖音/小红书头部账号，分析其内容类型和数据表现，填入模块8
6. **分析近期内容趋势**：分析最近3个月（2026年4-6月）的爆款内容特征，填入模块8.3
7. **组织其他模块**：按模板填充模块1-3、5-7

**阶段三：输出与交付**

8. **输出到对话区**：完整 Markdown 展示（含八大模块）
9. **生成 Word 版本**（需先 `pip install python-docx`）：
    - 先用 `Write` 工具把 Markdown 内容写到本地文件（如 `/tmp/report.md`）
    - 再用本 skill 自带的脚本 `references/md_to_docx.py` 把 Markdown 转成 Word
    - 命令（在 skill 目录下执行，或给定脚本绝对路径）：
      `python3 references/md_to_docx.py /tmp/report.md /tmp/report.docx`
    - 然后把 Word 文件移到用户桌面：`cp /tmp/report.docx ~/Desktop/`
10. **展示文件**：用 `present_files` 工具展示 Word 和 Markdown 两个文件
11. **用户反馈**：根据用户反馈决定是否深入某模块或存档

## 九、注意事项

1. **行业差异大**：金融、医疗、教育、电商、餐饮、地产、SaaS 玩法完全不同，模块要按行业适配，不可硬套
2. **别硬塞「黑榜」**：技术类、基础设施类行业可能没黑榜，跳过即可
3. **不点名批评**：分析问题可以，不点名爆黑料；不故意抹黑竞争对手
4. **地域可选项**：用户如果说"杭州房地产"或"杭州服装"，地域默认带上
5. **跨境可选项**：用户如果说"美国房地产"或"日本餐饮"，按用户要求切换地域
6. **数据时效性**：优先2026年数据，2025年作为对比，2024年及更早需标注年份
7. **平台数据获取**：如无法获取精确粉丝数/播放量，用「约XX万」「XX万+」估算，并标注「估算」
8. **Top 30 账号**：如无法获取完整30个，至少提供10-15个头部账号，并说明「完整30个待补充」
9. **通用模板，不绑定特定客户/项目**：行业调查报告是通用模板，报告应保持中立客观，聚焦于行业本身，不要在报告中刻意带入任何个人、客户或项目的名称，除非用户明确要求。
