# DNAnexus 基因组云

- 唯一标识：`hub-dnanexus-integration`
- 显示名称：DNAnexus 基因组云
- 能力摘要：使用 DNAnexus 的 app/applet、dxpy SDK、数据对象、工作流和作业监控管理 FASTQ、BAM、VCF 等基因组分析流程。

## 案例素材

1. 生信团队要把变异检测脚本交付给研究者自助运行。该 skill 会建立 app 输入输出、容器依赖和测试数据，使用平台构建与版本化发布。
2. 数百个 FASTQ 样本需要并行质控。该 skill 会上传与组织数据对象，发起可追踪的并行子作业，持续检查状态、日志和失败原因。
3. 合作项目需要在两个受控项目空间共享参考数据。该 skill 会使用平台链接、克隆和权限机制而非无控制下载，保留数据与分析来源关系。
