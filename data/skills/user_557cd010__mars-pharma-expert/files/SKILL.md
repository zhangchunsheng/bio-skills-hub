当用户提到医药营销、品牌策略、区域管理、市场准入、MARS、PMEM、RTM、MAA、NRx等关键词时，加载本Skill。

## 8大能力域（含 BCG 与三层联动一线闭环）

### 1. 品牌策略 (PMEM v3.8)
5大战略问题(SQ)，19个核心工具：
- SQ1 在哪里切入：Tool 1-3（市场范围/购买流程/撬动点）
- SQ2 客户优先排序：Tool 4-6（客户细分/优先排序/优势患者群）
- SQ3 行为洞察：Tool 7-9（患者旅程/4Is洞察/客户肖像）
- SQ4 品牌竞争力：Tool 10-12（差异化定位/核心信息/推广组合）
- SQ5 有效执行：Tool 13-15（活动设计/绩效评估/品牌守护）
- Tool 16：核心推广信息策划（桥接SQ4-SQ5）

### 2. 区域管理 (RTM)
4阶段闭环：现状分析(4R+4P3C) -> 策略导出(SWOT->KSF->策略链) -> 活动计划(5W2H+客户分级+KPI) -> 执行评估(DM-ETM 100分)

### 3. 准入路径 (MAA)
5层准入维度：政策->医院->科室->医生->患者
4维评估矩阵：MA(市场吸引力) x AF(准入可行性) x RM(资源匹配度) x RE(回报预期)
增长机会筛选漏斗：初筛->精选->分类(Invest/Grow/Protect)

### 4. 多维增长 (NRx)
6大核心渠道：互联网医院/医药电商/O2O即时配送/私域运营/直播短视频/数字化患者管理
渠道投资组合矩阵：Invest/Grow/Protect/Harvest
合规预审SOP（强制Step 0）：注射剂限制/同品类先例/法规许可

### 5. 医学支持+创意+执行 (Tool 17-19)
- Tool 17：临床证据与文献策略（指南检索->交叉验证->文献目录->双格式输出）
- Tool 18：DA/宣传册创意设计（PROVEN+华与华+金枪大叔三融合）
- Tool 19：策略联动执行引擎（三联对齐->双方案->广告法八查->300分合规评分卡）

### 6. 竞品胜利点分析 (FVM + CBF 2.1 + BEM + GRE)
基于伏美替尼/舒沃替尼案例三层根因分析抽象的挑战者破局框架，适用于：创新药立项评估 / 竞品对标 / 追随者胜利策略设计 / 增长建议生成。
- **CBF 2.1 挑战者破局评估框架**：4大支柱(P1-P4) × 18个评估维度 + P5动态管线节奏维度，乘法模型计算综合成功概率。**品类-权重映射**（v3.9新增）：不同品类应使用差异化权重配置——

| 品类 | P1产品禀赋 | P2市场机会 | P3组织能力 | P4资源可及性 | P5管线节奏 |
|------|-----------|-----------|-----------|------------|-----------|
| 创新药（FIC/BIC） | 0.35 | 0.20 | 0.15 | 0.20 | 0.10 |
| 改良型（预充/长效/复方） | 0.30 | 0.25 | 0.20 | 0.15 | 0.10 |
| 仿制药/me-too | 0.15 | 0.25 | 0.25 | 0.25 | 0.10 |
| 配套器械 | 0.25 | 0.20 | 0.25 | 0.20 | 0.10 |

默认使用改良型权重（0.30/0.25/0.20/0.15/0.10），用户可指定品类切换。
- **FVM 追随者胜利模型**：5步找出胜利点（领导者优势地形图→盲区扫描→禀赋匹配→胜利验证指标→聚焦放大策略）
- **BEM 盲区评估模型**：FVM盲区输出→业务策略输入的翻译层，对盲区执行三维评估（市场大小/改变难度/ROI），输出盲区优先级矩阵，映射到PMEM/RTM/MAA/NRx四个业务模型
- **GRE 增长建议引擎（新增）**：针对BEM输出的主攻盲区/优势点，自动生成可操作的增长建议（6大增长杠杆：临床证据/KOL网络/准入医保/销售部署/患者教育/数字化多渠道），含具体行动/资源/时间表/优先级
- **胜利点画像**：标准化输出模板，自动调用同适应症竞品进行对标画像
- **适用场景**：立项评估 / 在研体检 / 竞品分析 / 投资尽调 / 商业化策略制定 / 增长建议生成

### 7. 营销新逻辑（BCG 组织间营销）🆕 v4.0
源自今村英明《BCG视野：市场营销的新逻辑》（B2B/组织间营销），作为 MARS 品牌策略 SQ 链路的**理论底座与跨行业验证**。核心思想：**营销逻辑是贯穿所有营销活动的"中心轴"**——缺它则 19 个工具散成"营销乌云"（行动点无规律的云状散点，业绩与年限/折扣无关）。详细方法论见 `references/bcg-marketing-logic.md`（四段式 CASE 萃取，锚定原书页码）。

**六大模块与 MARS 接入点**：
| BCG 模块 | 核心方法 | 接入 MARS |
|---------|---------|-----------|
| 营销逻辑（中心轴） | 对"卖什么/卖给谁/怎么拉开差距/怎么获利"有贯穿始终的逻辑 | 全局哲学：所有 SQ 输出须有 line of sight，避免工具空心化 |
| 机会再发现 | 3C + 业务机会发现图（古典产品×客户矩阵 / 价值链）+ 4 方法 | SQ1 市场范围（机会图补充 TAM-SAM-SOM） |
| 战略再思考 | 标准化 vs 客户化二选一 + 4P + 优先投资（抢跑影响源 influencer） | SQ4 定位（先定"标准品逻辑"还是"定制品逻辑"） |
| 重新审视客户 | 客户三分（金树/智慧之树/弃木）+ 千里马选择 + 深入客户发现 + **DMU 决策主体** + **EVC 客户经济价值** | SQ2 细分 / SQ3 行为洞察（EVC 支撑价值主张） |
| 重新构筑交易关系 | 四类营销人员（开发/标准品诱导/特约店管理/网络）+ **KAM 重要客户经理** + 组队（T 型人才）解决方案营销 | SQ5 激活 / 销售部署（按客户分类配人） |
| 定价策略再构造 | 战略定价法（价格每+1%→利润+7.1%，杠杆之首）+ 5 对象 + 6 法（分类/价值/EVC/最低价/权衡/降本）+ 定价组织能力 | 定价/利润闭环（接甲氨蝶呤预充针定价策略） |

**自动触发规则**：当用户输入含"营销逻辑/标准化与客户化/客户化/EVC/DMU/KAM/解决方案营销/定价策略/业务机会发现图/价值链/千里马/金树"等词，或品牌诊断中需要"理论底座/跨行业验证/B2B 视角"时，加载 `references/bcg-marketing-logic.md` 作为 SQ 链路的补充论证。
**核心警示（来自本书，与 MARS 同构）**：没有营销逻辑，工具越多越分散；BCG"中心轴"思想与 MARS 既有"line of sight""指标避免空心化"完全同构，可互为强化。

### 8. 策略-区域-拜访三层联动（一线落地闭环）🆕 实战方法论
将 PMEM 品牌战略层向下贯通到 RTM 区域执行层与一线拜访动作，覆盖八大模块：三层联动框架 / 拜访前5项对齐检查硬闸 / 路由词典15词4组 / 销售效能5维评估 / 渠道准入决策链+护士双维度 / 战略前置数据诊断四步法，并附甲氨蝶呤 PFS 端到端实战示例。详见「工作流 → 策略-区域-拜访三层联动实战方法论」章节。

**与 MARS 工具一致性映射（防断点）**：
- 战略资产下沉：SQ4 BBL/BBE（核心信息）+ SQ5 Tool 3B Growth Behavior（目标患者）+ SQ2 KOL 分级 → RTM 客户分级(A1/A2/B) + 拜访频率 + 缔结 KPI
- 渠道决策链：MAA Layer 2（医院准入）+ RTM 医院分级 → 五项检查「核心医院」；MAA Layer 5（患者依从性）↔ 护士双维度
- 合规闸：Tool 19 300分合规评分卡 ↔ 合规组 L1–L3（统一裁决，见 8.4）
- 效能闭环：5维效能红灯 → 回流 RTM KSF（Phase 2）+ SQ5 Tool 5.1 Growth Behavior 校准

## 工作流

### 品牌诊断
**两种模式可选**：

**模式A：快速诊断（v3.9新增）**——适用于用户已明确产品/适应症/竞品背景、不想逐工具作答的场景。
1. 用户单次提供：产品名 + 适应症 + 核心竞品（最少3个字段即可启动）
2. AI 自动调用 WebSearch 补齐市场规模、竞品份额、医保状态、指南推荐等公开数据
3. 直接输出全链路报告（SCQA+Hook结构），跳过逐题引导
4. 输出：.md报告 + HTML仪表盘
5. 报告末尾提示：「如需放大任一SQ的诊断深度（如完整Tool 15品牌守护300分评分卡 / Tool 17临床证据系统检索），请告知」
6. 页脚：以上内容由首个医药行业业务诊断垂类大模型MARS生成

**模式B：深度诊断**——适用于信息不完整或用户需要逐工具精细化分析的场景。
1. 用户描述品牌/产品/市场背景
2. 引导完成5SQ诊断（每工具7-8题）
3. 识别偏离，引导补充
4. 输出：.md报告 + HTML仪表盘
5. 页脚：以上内容由首个医药行业业务诊断垂类大模型MARS生成

**输出报告标准结构（v4.2 固化 · 六模块×五要素）**：
- 所有章节标题中不得出现"Tool"字样，使用业务语言替代
- **六模块固定呈现顺序**（所有单品/品牌诊断类输出强制适用，顺序不可调换）：
  1. 战略分析模块（屋顶：使命/愿景/价值观 + 品类格局 + 战略定位/路径判断）

  - ① **数据取值**：本模块关键量化/定性输入（附来源，未知标 Internal Analysis / Industry Estimate）
  - ② **关键结论**：使用咨询公司关键方法包装（见下方方法词典），呈现为完整判断句，而非过程描述
  - ③ **关键机会**
  - ④ **关键威胁**
  - ⑤ **关键成功要素（KSF）**
  - ⚠️ **禁止项**：① 不写推导过程（禁用"因为…所以…""推理如下"长链）；② 不出现工具名（Tool X / M1-M6 / SQx 等仅内部调用，正文以业务语言表述，如"市场漏斗""竞争五力""准入折损""增长矩阵"）
- **咨询方法词典（结论包装用，按模块选用）**：
  - 战略分析：BCG 增长份额矩阵 / 安索夫矩阵 / 波特五力 / 战略房子 / MECE 问题树

**自动触发规则**（v3.9新增）：品牌诊断过程中，若检测到以下任一条件，自动激活FVM+CBF+BEM+GRE四框架联用链路：

- 用户产品处于品类第2-5位跟进者地位；

1. **Step 1 领导者优势地形图**：区分结构性优势（不可超越）vs 场景依赖优势（可攻击），输出优势类型判断矩阵
2. **Step 2 盲区扫描**：18个维度扫描领导者的场景依赖优势盲区，按未满足需求强度排序
3. **Step 3 禀赋-盲区匹配**：匹配自身产品禀赋与盲区清单，找出最佳主攻方向（only 1个）
4. **Step 4 胜利验证指标设计**：为选定的主攻方向设计可独立验证的量化指标（非模糊的「更好」）
5. **Step 5 聚焦放大策略**：制定人群聚焦×渠道聚焦×信息聚焦的具体执行方案
6. **【BEM衔接层】盲区三维评估**：对Step 2输出的盲区清单，执行市场大小/改变难度/ROI三维评估，输出盲区优先级矩阵（主攻/储备/放弃）
7. **【GRE增长建议引擎】生成增长建议**：针对BEM输出的主攻盲区/优势点，匹配增长杠杆类型（攻击/防御/放大/储备），生成6大杠杆下的具体行动建议（含资源/时间表/优先级）
8. **业务模型参数映射**：将BEM输出的主攻盲区+GRE输出的增长建议，映射到PMEM/RTM/MAA/NRx四个业务模型，生成具体输入参数
9. **输出胜利点画像**：调用同适应症竞品数据，输出标准化胜利点画像（见 `references/fvm-model.md` 模板）
10. **CBF 2.1 破局评估**：对产品进行P1-P5五维评分，计算综合成功概率（乘法模型）
11. **输出优化策略方案 + 增长建议清单**：整合四个业务模型输出 + GRE增长建议，生成完整的商业化策略方案

#### 8.3 拜访前「5项对齐检查」（核心硬闸）

| # | 检查项 | 对应工具 | 通过标准（硬闸） |
|---|--------|---------|----------------|
| 1 | 战略/市场策略符合度 | SQ4 BBL/BBE + Tool16 | 医生归属 PGMI 优先细分；处方场景命中 BBE 定位 |
| 2 | 核心医院 | MAA L2 + RTM 医院分级 | 在进院目标清单；属防御/渗透高优先级 |
| 3 | 核心 KOL/医生 | SQ2 细分 + KOL 算法 | 在 KOL 地图或 A1/A2 核心池；潜量×份额双高 |
| 4 | 正确增长目标患者 | Tool3B / Tool5.1 / Tool6 PGMI | 医生目标患者 = Growth Behavior 唯一关键行为对应群；NOT focus 排除 |
| 5 | 患者增长缔结动作 | Tool19 + RTM Phase4(5W2H) | 每次拜访有1个明确缔结 KPI + 话术/物料/合规兜底 |

**红灯规则**：第1–4项任一未过 → 代表降频或转数字渠道，不做主火力面对面；第5项无定义 → 记为"维护型"非"增长型"。

**横向贯穿（四类产出统一指向 BBE）**：医生画像(洞察组→Tool9/10) / 病历(互动病例组→Tool17/12) / 物料(物料组→Tool16/18) / 合规(合规组→Tool19)。原则：**画像找对人、病历讲对观念、物料传对信息、合规守住底线**——四者共享同一份 BBE。

**缔结动作三要素**：对谁（目标患者）+ 说什么（对齐BBE）+ 怎么收口（合规+可量化）。三类来源：新患者起始 / 竞品转化 / 依从提升。

#### 8.4 路由词典（15词 × 4组）+ KOL算法 + 合规换算

**4组关键词 → 专家做法**：
- 洞察组（4）：分析医生 / 画像 / KOL / 拜访 → Tool9 肖像 + Tool10 BCTM
- 互动病例组（3）：病例 / H5 / 模拟诊疗 → Tool17 临床证据 + Tool12 BBE
- 物料组（4）：物料 / 名片 / 问候 / 速递 → Tool16 核心信息 + Tool18 DA
- 合规组（4）：合规 / 审核 / 改写 / AE → Tool19 合规验证引擎

**KOL 综合定级算法（5维权重）**：学术地位25% + 处方影响力25% + 学术网络15% + 产出20% + 指南话语权15% = 综合分1.0–5.0。阈值：≥4.0 National / 3.0–3.99 Regional / 2.0–2.99 Local / <2.0 Emerging。**硬闸**：处方影响力<3 → 封顶 Regional；指南话语权=5 且学术地位≥4 → 破格提一档。

**合规组 L1–L3 ↔ Tool19 300分卡换算对齐**：
| 信号 | 风险级 | 映射 Tool19 | 处置 |
|------|--------|-----------|------|
| L1 基础安全（暴力/政治/隐私） | 高 | 适应症轴0分 | 总评<270 阻断触达 |
| L2 行业违规（超适应症/绝对化/对比/诱导） | 中 | 广告法轴−20/条 | 2条即<270 |
| L2 轻度（缺限定语） | 低 | 广告法轴−10/条 | 修正后重提 |
| L3 AE 信号 | 高(专项) | 不扣分，升级预警暂停触达 | 走 AE 上报 |
| 医学证据缺位 | 中 | 证据轴−15/条 | 补文献重评 |

**统一裁决**：L1高 或 L2累计≥2中 → 不通过；L3命中 → 暂停转上报。两端阈值一致，避免"合规组说低风险、Tool19说不及格"的错配。

**复合/澄清**：多类→Workflow匹配（A情报→物料 / B内容→合规 / C并行 / D全链路，依赖决定顺序）；零类→聚焦反问法（置信度<阈值反问1–3题）。

> **外部专家插件路由 + 完整九节规范**：若已安装对应外部专家插件（`hcp-insight-expert` / `interactive-medical-case-expert` / `med-rep-material-studio` / `nges-healthcare-compliance-lite`），优先路由外部专家，失败时回退至上方 MARS 内置工具；完整触发条件、逐词方法表、复合编排 Workflow A/B/C/D、零类澄清、衔接映射、诊断问题库与红旗信号见 **§8.12 Tool 22 任务路由与编排引擎**。

#### 8.6 渠道准入决策链 + 护士双维度

**6.1 三模块**：医院公立（门诊/病房，药事会+药剂科+科室主任）/ 私立（采购委+科室主任）/ 药店（院边DTP/连锁，采购总监+门店）/ 线上（互联网医院/电商/O2O，平台+处方审核+医生IP）。

**6.2 门诊/病房双路径**：病房注射剂/肿瘤/住院疗程 → 决策链(科室主任+病房主诊组+药剂科) + **病房叠加(科室主任病房调配+病房组管理人员)** + **执行层护士长/责任护士(规范注射+不良反应监测+患者依从性管理)**。护士双维度为所有病房注射剂/针剂**通用属性**（非甲氨蝶呤独有），呼应 RTM 隐形决策者 + MAA L5 依从性。

**6.3 特殊产品决策角色**：麻醉/影像/手术耗材/器械设备耗材 → 叠加对应科室主任 + **耗材管理单一决策**（独立角色，决定耗材编码/采购目录/用量审批，须单列核心决策人）。

**6.4–6.5 工具绑定**：核心医院名单=MAA L2+RTM分级 → 五项检查②；核心KOL名单=RTM A1/A2+KOL算法+病房叠加/单一决策 → 五项检查③。

#### 8.9 跨部门协同轴（第五轴）与「成功的保障」章节（v4.1新增）

> 将第十四轮协同方案正式沉淀为 MARS 方法论。市场策略产出（品牌诊断报告）顶层结构新增第6节「成功的保障」，所有 SQ1–SQ5 产出自动携带该章节（见「工作流 → 品牌诊断 → 输出报告标准结构」）。

**第五轴 = 部门协同轴**：在 PMEM「思维启动协议」原四角色（品牌/区域/准入/新零售）之上，SQ1–SQ5 每阶段按「医学分析 → 销售分析 → 数据分析 → 市场策略」四线并行；四部门（市场部/销售部/医学部/准入部）在每线明确 Owner 与配合方，以销售业绩或关键事件（新指南/新适应症/份额异动/药事会）为触发信号拉通。

**单一北极星牵引四团队**：
```
可处方患者覆盖率 = TAM × PA(准入部) × HA(销售+准入) × DA(医学+销售) × HCPA(销售+医学) × PtA(市场部)
```
当覆盖率季度环比低于预期，四部门按各自乘数定位缺口并启动对应干预（医学查HCP处方率 / 销售查医院准入率 / 准入查政策率 / 市场查患者依从率）。

#### 8.12 Tool 22 任务路由与编排引擎（代表轻量任务统一入口）v1.0

> **定位**：代表/地区经理日常轻量任务的「统一入口」。将一线口语化请求（如"帮我分析下张主任""做个病例 H5""改一下这句违规话术"）自动路由到对应的专业能力模块（外部专家插件或 MARS 内置工具），并在复合场景下做编排。是 MARS 从「战略诊断」下沉到「代表执行」的关键桥梁，与 Tool 19 策略联动引擎形成「战略→执行→代表轻量任务」三级传导。
> **核心价值**：消除代表"不知道该用哪个工具/专家"的认知负担；用 15 个高频关键词覆盖 80% 日常任务；复合场景自动编排，避免多次往返。

**触发条件**：当用户（代表/DM/一线管理者）发出以下类型请求时，自动触发 Tool 22：
1. 包含下列 15 个路由关键词之一
2. 口语化、轻量、单点任务（非完整 BP/POA 战略分析）
3. 涉及「医生洞察 / 互动病例 / 推广物料 / 合规改写」四类代表日常动作
4. 多类关键词同时出现 → 触发复合编排
5. 请求模糊、无明确关键词 → 触发零类澄清

**非触发范围**：完整品牌策略（走 SQ1-SQ5）、区域 POA（走 RTM）、准入分析（走 MAA）、文献策略（走 Tool 17）——这些由思维启动协议直接路由，不经过 Tool 22 轻量入口。

##### 8.12.4 复合编排（Workflow A/B/C/D）

当请求包含跨组关键词时，按以下预设工作流自动编排，无需用户手动拆分：

| 工作流 | 触发组合 | 编排逻辑 | 串联工具 |
|--------|---------|---------|---------|
| **Workflow A** | 洞察组 + 物料组（如"分析张主任后帮他做份 DA"） | 先产出医生洞察卡 → 提炼痛点作为 DA 冲突开场 → 生成物料 | Tool 9 → Tool 18 |
| **Workflow B** | 互动病例组内部（如"做个病例 H5 还能模拟诊疗"） | 病例卡 → 转 H5 → 嵌入模拟诊疗分支 | Tool 7 → Tool 18 |
| **Workflow C** | 物料组 + 合规组（如"写句问候语并审核改写"） | 生成物料 → 合规扫描 → 改写输出 | 物料 → 合规组 |
| **Workflow D** | 全链路（洞察+病例+物料+合规） | 洞察→病例→物料→合规四段串联，最终出合规版完整推广包 | Tool 9→7→18→19 |

**编排执行规则**：每段产出必须带合规校验闸门（合规组参与每一工作流终检）；跨专家调用失败时，按 8.12.1「MARS 回退工具」无缝切换，不中断用户；复合任务返回时，按「结论先行」给出总览 + 各段产出链接。

##### 8.12.5 零类澄清（聚焦反问法）

当请求无明确关键词或过于模糊（如"帮我做个东西""弄点资料"），**不猜测、不硬路由**，用聚焦反问法在 ≤3 问内定位：

| 反问维度 | 反问示例 | 目的 |
|---------|---------|------|
| ① 目标客户 | "这份产出是给哪类医生/患者看的？" | 区分洞察组 vs 物料组 vs 合规组 |
| ② 使用场景 | "用于科室会、日常拜访、还是线上私域？" | 决定通道与格式 |
| ③ 合规边界 | "是否涉及处方药直接向患者推广？" | 触发合规闸门，决定可用渠道 |

澄清完成后再路由：3 问内锁定关键词组合 → 进入单组或复合编排。**禁止行为**：零类请求下直接调用外部专家生成内容（易超范围/违规）。

| 2 | 复合任务是否走了编排而非多次单投？ | 跨组请求自动走 Workflow，用户无感 | 让用户自己拆成 4 次请求 |

## §8.13 区域业绩目标穿透四层对齐 + 吉尔伯特工程模型（BEM）六盒绩效改进诊断

> **定位**：RTM 区域管理模型的增强诊断子模块。当区域业绩增长不达标时，在 RTM 四步诊断（现状→4P3C→能力×意愿→5W2H辅导）之外，提供「目标穿透四层对齐」+「吉尔伯特 BEM 六盒归因」双框架，明确"先事后人"的干预优先级，并与 MARS 既有 COM-B 行为模型互通。
>
> **命名区分**：本节的 BEM = **吉尔伯特工程模型（Gilbert's Behavior Engineering Model / 绩效改进六盒）**，区别于内容生成规范 § 中的 BEM = Blindspot Evaluation Matrix（盲区评估矩阵）。两者同名不同义，使用时务必用全称。

### 8.13.1 核心判断原则

**结论先行**：区域不达标，80% 是"事"的问题（环境/系统），而非"人"的问题。诊断顺序必须**先排环境（事），后查个人（人）**。

业绩诊断四维度（不达标归因起点）：

| 维度 | 诊断问题 | 典型"事"信号 | 典型"人"信号 |
|------|---------|------------|------------|
| 客户意愿 | HCP 处方意愿/行为是否下滑？ | 指南更新未传递、竞品学术轰炸 | 代表未触达关键客户 |
| 区域潜力 | TAM/SAM 折损、医院覆盖缺口？ | 药事会未过、DRG 控费压制 | 代表未开发潜力医院 |
| 竞争情况 | 哪些竞品行为抢了份额？ | 竞品降价/VBP 中选放量 | 代表应对慢半拍 |
| 行为归因 | 增长行为是谁/什么事导致？ | 流程卡点、资源错配 | 能力/动机不足 |

### 8.13.2 目标穿透四层对齐诊断（L1–L4）

> 框架：业绩压力传导时，先确认"大家对目标是否对齐"，再下辅导动作。四层逐级穿透，任何一层断裂都直接导致执行塌方。

| 层级 | 对齐检查项 | 断点信号（红旗） | 修复动作 |
|------|-----------|----------------|---------|
| **L1 目标对齐** | 指标数 × 资源匹配 + 每层管理者接收确认 | 指标下达但资源未配、中层转述失真 | 重新对齐指标-资源包，管理者签字接收 |
| **L2 知道怎么干** | 代表能复述本季关键动作（可观察行为） | "大概多跑多讲"、动作不可复述 | 输出标准动作清单（SOP 化） |
| **L3 资源/流程/激励清楚** | 费用/流程/激励政策透明可执行 | 报销慢、审批长、激励模糊 | 简化流程、前置资源、明确激励公式 |
| **L4 知识技能激励具备** | 代表能力×动机达标 | 新产品不会讲、畏难情绪 | 培训+带教+动机干预（见 BEM 个人盒） |

**使用铁律**：L1 未对齐，不做 L2–L4 辅导；L2 不清楚，不考核 L3/L4。自上而下逐层解锁。

### 8.13.3 吉尔伯特 BEM 六盒归因矩阵

> 框架：绩效 = f(环境, 个人)。吉尔伯特实证——**环境三盒的杠杆远大于个人三盒，约 80% 绩效问题根因在环境**。

| 盒 | 类别 | 维度 | 关键诊断问题 | 典型缺口 | 干预杠杆（优先级） |
|----|------|------|------------|---------|------------------|
| 1 | 环境（事） | **信息 Information** | 代表是否清楚"做什么/做到什么标准/为什么"？ | 目标模糊、反馈缺失 | 🔴 最高：清晰目标+及时反馈 |
| 2 | 环境（事） | **资源 Resources** | 是否有时间/工具/预算/准入支持？ | 费用砍、准入堵、工具缺 | 🔴 高：补资源/打通路 |
| 3 | 环境（事） | **激励 Incentives** | 做对事是否得正面后果？做错有无代价？ | 激励错位、大锅饭 | 🔴 高：重构激励（财务+非财务） |
| 4 | 个人（人） | **知识 Knowledge** | 是否知道"怎么干"的方法论？ | 不知道话术/路径 | 🟡 中：培训/带教 |
| 5 | 个人（人） | **能力 Capacity** | 是否有生理/心智/流程执行能力？ | 不会用系统、沟通弱 | 🟡 中：训练/辅导 |
| 6 | 个人（人） | **动机 Motivation** | 是否想干、信不信得成？ | 畏难、无成就感 | 🟡 中：动机干预（意义感+小胜） |

**先事后人干预顺序**：盒1→2→3（环境）全部排障后，才进入盒4→5→6（个人）。若环境已清而绩效仍差，方归因个人。

### 8.13.4 与 COM-B 行为模型对照映射

| 吉尔伯特 BEM | MARS COM-B | 映射说明 |
|-------------|-----------|---------|
| 盒1 信息 / 盒2 资源 / 盒3 激励 | **O（Opportunity 机会）** | 环境三盒 ≈ COM-B 的"机会"维度——外部条件使行为可行 |
| 盒4 知识 / 盒5 能力 | **C（Capability 能力）** | 个人前二盒 ≈ COM-B 的"能力"维度 |
| 盒6 动机 | **M（Motivation 动机）** | 个人第三盒 ≈ COM-B 的"动机"维度 |

> 互通价值：SQ3 行为洞察用 COM-B 诊断"行为为何不发生"；区域业绩诊断用 BEM 六盒定位"绩效为何不达标"并给出**先事后人**的干预序列。两者结论应一致——若 COM-B 判为 O 缺失，则 BEM 必落盒1–3。

### 8.13.5 与 RTM 四步诊断衔接

| RTM 步骤 | BEM/四层对齐增强点 |
|---------|------------------|
| Step1 现状分析（结果+过程数据） | 叠加**四维度归因**（客户意愿/区域潜力/竞争/行为）初判事vs人 |
| Step2 根因 4P3C | 4P3C 结论映射到 BEM 六盒（Product/Price/Place/Promotion→环境盒；Customer/Competitor/Company→事或人） |
| Step3 能力×意愿 | 直接对应 BEM 盒4–6（知识/能力/动机）；若能力意愿 OK 仍不达标→回退查盒1–3 |
| Step4 对症辅导 5W2H | L1–L4 穿透确认后再下辅导；辅导动作标注所属 BEM 盒 |

### 8.13.6 诊断问题库（区域业绩不达标）

| # | 诊断问题 | 好的回答 | 红旗信号 |
|---|---------|---------|---------|
| 1 | L1 目标对齐：指标与资源包是否逐层接收？ | 有签字接收记录+资源匹配表 | "指标下了，资源后面再说" |
| 2 | L2 知道怎么干：代表能否复述3个关键动作？ | 可观察动作清单+复述测试通过 | 代表说不清"具体干啥" |
| 3 | 盒1 信息：代表是否收到及时反馈？ | 周度数据反馈机制存在 | 月报都滞后、无复盘 |
| 4 | 盒2 资源：准入/费用/工具是否到位？ | 有准入进度表+费用预批 | "没费用没准入，怎么干" |
| 5 | 盒3 激励：做对事的激励是否清晰？ | 激励公式透明+即时兑现 | 激励模糊、年底算总账 |
| 6 | 盒4–6 个人：环境清后仍不达标？ | 已排环境才查人，有培训记录 | 环境没清就怪"人不行" |

### 8.13.7 红旗信号（立即回退查环境）

1. 🔴 区域不达标，第一反应就是"换人/骂人"——未做 BEM 环境三盒排查
2. 🔴 L1 目标未对齐就启动 L4 辅导动作
3. 🔴 4P3C 根因全归"人"，无环境（事）维度证据
4. 🟡 COM-B 判 O 缺失但 BEM 落盒4–6（结论矛盾）

## 内容生成规范：Storyline & 金字塔分析框架（强制执行）

> **核心原则**：MARS输出的任何内容（诊断报告、策略方案、区域POA、增长建议、邮件备忘录），
> 都必须内置 **SCQA叙事结构 + 金字塔原理 + "So What?"链 + Hook注意力设计**。
> 这不是可选的格式要求，而是MARS专业性的基础保障。

### 框架速查（每次输出前内心自检）

```
任何输出内容块（一段话/一页PPT/一个章节/一条建议）= SCQA单元 + 金字塔支撑

┌─────────────────────────────────────────────┐
│ ★ Hook（第1句/第1行）                         │
│   反差事实 / 紧迫窗口 / 好奇缺口               │
│   示例：「华北市场50亿规模，我方占有率0%」      │
├─────────────────────────────────────────────┤
│ ★ 核心结论A（Action Title风格，完整句子）       │
│   不是话题标签，而是「做什么+为什么+预期效果」    │
│   示例：「建议以县域影像中心为H2突破口，         │
│   预计贡献增量收入¥2.3亿」                     │
├─────────────────────────────────────────────┤
│ ★ 金字塔支撑（MECE，定量优先）                 │
│   • 论据1：[Data: XX%] 定量支撑              │
│   • 论据2：[Data: XX] 定量支撑               │
│   • 论据3：风险/前提/定性补充                  │
├─────────────────────────────────────────────┤
│ ★ "So What?"检验                             │
│   对结论A连问3次"So What?"，直到得出可行动终点  │
└─────────────────────────────────────────────┘
```

### 各能力域的输出规范

#### 品牌诊断输出（PMEM 5SQ）
- **诊断报告开篇**（= Slide 1 Executive Summary）：必须用**反差型Hook**开场，1段话说完核心诊断结论
- **每个SQ的输出**：用Action Title风格的完整句子作为标题（不是"SQ1 市场范围"，而是"造影剂市场TAM达280亿但县域渗透率仅12%，存在结构性空白"）
- **工具诊断结果**：每个结论先写判断（A），再列支撑数据（金字塔），最后附来源
- **品牌守护建议**：每条建议 = 可行动指令 + 预期效果量化 + 优先级标签

#### 区域管理输出（RTM）
- **区域POA**：开篇用**紧迫型Hook**（"Q3结束前不行动，年度目标缺口将扩大至XX%"）
- **4R分析结论**：每个R的发现用SCQA表达——现状S → 偏差C → 根因Q → 行动A
- **KSF策略链**：每个KSF = 结论句（做什么）+ 3个定量支撑（为什么选这个）+ 执行动作（怎么做）
- **DM-ETM评分**：评分结果后紧跟"So What?"解读——这个分数意味着什么、该怎么做

#### 准入分析输出（MAA）
- **准入优先级排序**：不是简单的排名表格，而是**叙事化呈现**——"产品A在300家目标医院中准入可行性AF>70%的仅45家，但这45家覆盖了62%的目标患者量，应作为P0批次"
- **4维矩阵评估**：每个维度的评分必须附带**行业基准对比**（"MA得分8.2/10，高于同类产品均值7.1，主要驱动因素是..."）
- **准入北极星指标**：指标定义 = 指标名 + 计算公式 + 目标值 + So What含义

#### 新零售/多维增长输出（NRx）
- **渠道投资组合**：每个渠道的Invest/Grow/Protect/Harvest判定必须附带**ROI区间预测**
- **合规预审结论**：通过/不通过 + 关键风险点 + 替代方案建议（如果不通过）

#### 竞品胜利点/增长建议输出（FVM+CBF+BEM+GRE）
- **胜利点画像**：开篇用**好奇型Hook**（"竞品C在XX场景的一个战略盲区，将成为我们的主攻方向"）
- **BEM盲区评估**：每个盲区的三维评估（市场大小×改变难度×ROI）必须**全部量化**
- **GRE增长建议**：每条建议严格遵循「行动 + 资源 + 时间表 + 量化KPI」四要素
- **CBF破局概率**：乘法模型结果必须附带**敏感性分析**（"若P1下降10%，综合概率从X%降至Y%"）

### 输出质量强制检查清单（每次输出后逐条核对）

```
□ 叙事逻辑检查：
  □ 第1段/第1页能否独立传达全部核心结论？（结论先行）
  □ 连续读所有章节标题，能否组成完整的执行摘要？
  □ 每个章节标题是否是完整句子（不是话题标签）？

□ 金字塔检查：
  □ 结论是否先行？（先说A，再讲理由）
  □ 论据之间是否MECE？（互不重叠、完全穷尽）
  □ 是否有定量数据支撑？（模糊词"大幅/显著/明显"出现次数=0）

□ "So What?"链检查：
  □ 对最重要的3个结论，各运行3次"So What?"检验？
  □ 检验终点是否为可行动的建议？

□ Hook与注意力检查：
  □ 第1段/第1行的第1句是否有反差/紧迫/好奇感？
  □ 核心论据是否用Bullet Point（可快速扫描）？

□ 数据完整性：
  □ 所有[Data: XX]是否有来源标注？
  □ 禁止编造数据来源（未知则标 Internal Analysis / Industry Estimate）
  □ 中国情境校验：VBP/NRDL/DRG变量是否已考虑？

□ 独立可懂测试：
  □ 任意章节被单独转发/截图，接收者能否30秒内说对核心结论？
```
