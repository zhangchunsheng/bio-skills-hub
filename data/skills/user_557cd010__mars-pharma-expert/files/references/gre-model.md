# 增长建议引擎（Growth Recommendation Engine · GRE）

> BEM盲区评估输出 → 具体增长行动 的生成层
> 版本：v1.0 · 2026-06-29
> 适用：基于优势/盲区自动生成可操作的增长建议

---

## 一、设计逻辑

### 问题：BEM评估后仍然断层

```
当前状态：
  BEM输出：「脑转移盲区，综合分4.3，主攻」
  ↓
  断层：然后呢？具体要做什么？
  ↓
  增长建议：？？？

正确状态：
  BEM输出：「脑转移盲区，综合分4.3，主攻」
  ↓
  GRE翻译：针对这个盲区，生成6个增长杠杆的具体行动建议
  ↓
  具体行动：① 启动脑转移真实世界研究 ② 签约脑转移KOL ③ ...
```

### 核心思路：盲区类型 → 增长杠杆匹配 → 具体行动建议

```
每个盲区/优势点
    ↓
判断类型（攻击型/防御型/放大型）
    ↓
匹配增长杠杆（6大类）
    ↓
生成具体行动建议（含优先级/资源/时间表）
```

## 二、增长杠杆分类（6大类）

### 杠杆1：临床证据生成（Clinical Evidence Generation）

> 适用：优势点需要证据支撑，或盲区需要数据验证

| 行动类型 | 具体内容 | 适用场景 |
|---------|---------|---------|
| 真实世界研究（RWE） | 在目标人群收集真实世界数据 | 优势点需要补充真实世界证据 |
| 亚组分析（Subgroup Analysis） | 对已有临床数据进行亚组分析 | 优势点在特定人群更明显 |
| 头对头研究（Head-to-Head） | 与领导者/竞品直接比较 | 优势点需要独立验证 |
| 生物标志物研究 | 探索预测疗效的生物标志物 | 优势点需要精准人群定义 |
| 长期安全性数据 | 收集长期随访数据 | 优势点需要安全性证据 |

**资源需求：** 中-高（需要医学部资源）
**时间窗口：** 6-24个月
**预期影响：** 高（指南级证据可直接改变处方行为）

---

### 杠杆2：KOL网络建设（KOL Engagement）

> 适用：需要改变医生处方行为的盲区/优势点

| 行动类型 | 具体内容 | 适用场景 |
|---------|---------|---------|
| 核心KOL签约 | 签约领域顶级专家作为顾问 | 优势点需要权威背书 |
| 专家顾问会 | 定期举办专家顾问会议 | 优势点需要专家共识 |
| 青年医生培养 | 培养下一代处方医生 | 长期市场教育 |
| KOL内容共创 | 与KOL共同产出学术内容 | 优势点需要学术传播 |
| 国际学术会议 | 支持KOL参加国际会议发言 | 全球化优势点 |

**资源需求：** 中（需要医学部+市场部资源）
**时间窗口：** 3-12个月
**预期影响：** 中-高（KOL影响力直接带动处方）

---

### 杠杆3：准入和医保（Access & Reimbursement）

> 适用：支付壁垒是主要障碍的盲区

| 行动类型 | 具体内容 | 适用场景 |
|---------|---------|---------|
| 医保谈判准备 | 准备医保谈判材料和测算 | 已上市产品准备医保谈判 |
| 医院准入打包 | 准备医院准入材料和价值主张 | 新产品进院 |
| 省级医保补充 | 在已进国家医保后，拓展省级补充目录 | 国家医保后进一步降低患者自付 |
| 商保合作 | 与商业健康险合作，覆盖患者自付部分 | 未进医保或医保后仍有自付压力 |
| 患者援助项目（PAP） | 设立患者援助项目，降低低收入患者自付 | 支付能力有限的患者群体 |

**资源需求：** 低-中（主要是人力和材料准备）
**时间窗口：** 3-12个月（医保谈判周期）
**预期影响：** 极高（医保准入是销售放量的决定性因素）

---

### 杠杆4：销售团队部署（Sales Force Deployment）

> 适用：需要地面执行的优势点/盲区

| 行动类型 | 具体内容 | 适用场景 |
|---------|---------|---------|
| 重点医院清单 | 基于盲区患者分布，制定重点医院清单 | 资源有限，需要聚焦 |
| 销售团队培训 | 针对优势点/盲区，培训销售团队的核心信息传递 | 销售团队需要统一话术 |
| 关键客户管理 | 对重点客户（高处方潜力医生）制定专属管理计划 | 重点客户需要精细化运营 |
| 销售激励调整 | 调整销售激励政策，奖励优势点相关处方 | 需要激励销售团队聚焦优势点 |
| 销售工具包 | 制作针对优势点/盲区的销售工具包（DA/幻灯片/话术） | 销售团队需要武器 |

**资源需求：** 中（主要是销售团队时间）
**时间窗口：** 1-3个月（培训+部署）
**预期影响：** 中（销售执行力直接影响处方转化）

---

### 杠杆5：患者教育和支持（Patient Education & Support）

> 适用：患者认知/依从性是关键障碍的优势点

| 行动类型 | 具体内容 | 适用场景 |
|---------|---------|---------|
| 患者教育内容 | 制作患者教育材料（视频/手册/小程序） | 患者对疾病/治疗认知不足 |
| 患者社区运营 | 建立患者社区，促进患者交流和经验分享 | 慢性病需要长期管理 |
| 患者支持热线 | 设立患者支持热线，解答用药疑问 | 复杂用药需要支持 |
| 依从性管理项目 | 设计依从性管理项目（提醒/奖励） | 口服药依从性是关键 |
| 患者KOL培育 | 培养和赋能患者KOL，传播真实体验 | 患者影响力越来越重要 |

**资源需求：** 中（需要患者运营团队）
**时间窗口：** 3-6个月
**预期影响：** 中-高（患者需求驱动处方）

---

### 杠杆6：数字化和多渠道（Digital & Omnichannel）

> 适用：需要创新渠道覆盖的优势点/盲区

| 行动类型 | 具体内容 | 适用场景 |
|---------|---------|---------|
| DTP药房合作 | 与DTP药房合作，提供专业药事服务 | 口服药/特殊管理药物 |
| 互联网医院 | 在互联网医院平台开设专科门诊 | 需要复诊开药便利的患者 |
| O2O即时配送 | 与O2O平台合作，提供药品即时配送 | 突发需求/行动不便患者 |
| 私域运营 | 建立医生/患者私域，持续运营 | 需要长期关系的场景 |
| 数字化患者管理 | 开发数字化患者管理工具（APP/小程序） | 需要长期依从性管理 |

**资源需求：** 中-高（需要数字化团队+技术投入）
**时间窗口：** 3-12个月
**预期影响：** 中（数字化是趋势，但需要时间积累）

## 三、盲区类型 → 增长杠杆匹配规则

### 类型判断

```
每个盲区/优势点，先判断类型：

攻击型（Attack）：
  → 领导者的盲区，我们的优势
  → 策略：放大优势，快速占领

防御型（Defend）：
  → 领导者的优势，我们的劣势
  → 策略：避免正面竞争，找差异化角度

放大型（Amplify）：
  → 我们的优势，领导者也在做但还没做好
  → 策略：加大投入，拉开差距

储备型（Reserve）：
  → 有潜力但时机未到
  → 策略：持续投入，等待时机
```

### 匹配规则

| 盲区类型 | 优先杠杆 | 次优先杠杆 | 不推荐杠杆 |
|---------|---------|-----------|-----------|
| 攻击型（我们的优势，领导者盲区） | 杠杆1（证据）+ 杠杆2（KOL） | 杠杆4（销售）+ 杠杆6（数字化） | 杠杆3（准入）如果已进医保 |
| 防御型（领导者优势，我们劣势） | 杠杆1（找到我们的优势场景证据） | 杠杆5（患者教育，找差异化角度） | 杠杆4（避免在领导者优势场景硬拼） |
| 放大型（我们的优势，领导者也在做） | 杠杆2（KOL抢占）+ 杠杆3（准入抢占） | 杠杆6（数字化抢占） | 杠杆1（证据已经够了吗？） |
| 储备型（有潜力，时机未到） | 杠杆1（持续积累证据） | 杠杆2（培养未来KOL） | 杠杆4（销售资源不要太早投入） |

## 四、增长建议生成流程

### 输入

```
BEM输出：
  - 主攻盲区清单（综合分≥4.0）
  - 储备盲区清单（3.0≤综合分<4.0）
  - 每个盲区的三维评分（市场大小/改变难度/ROI）
```

### 处理

```
对每个主攻盲区：
  Step 1：判断盲区类型（攻击/防御/放大/储备）
  Step 2：基于类型，匹配优先增长杠杆
  Step 3：为每个优先杠杆，生成具体行动建议
  Step 4：评估每个行动建议的资源需求、时间窗口、预期影响
  Step 5：按预期影响/资源需求比值排序，输出优先级
```

### 输出

```
增长建议清单：

| 盲区 | 类型 | 增长杠杆 | 具体行动 | 优先级 | 资源需求 | 时间窗口 | 预期影响 |
```

  - 负责部门：医学部 / 市场部 / 销售部 / 准入部 / 患者运营部

## 七、增长建议优先级排序规则

### 排序矩阵

```
优先级 = 预期影响 × 0.5 + (1/资源需求) × 0.2 + (1/时间窗口) × 0.3

其中：
  预期影响：高=5，中=3，低=1
  资源需求：低=1，中=3，高=5（注意：这里数值越大=资源需求越大=扣分）
  时间窗口：短=1，中=3，长=5（注意：这里数值越大=时间越长=扣分）

→ 分数越高，优先级越高
```

### 快速判断规则（简化版）

| 场景 | 优先级 |
|------|--------|
| 预期影响高 + 资源需求低 + 时间窗口短 | 高（立即执行） |
| 预期影响高 + 资源需求高 | 中（需要审批预算） |
| 预期影响低 + 资源需求高 | 低（不推荐） |
| 储备型盲区 | 中（持续投入，不急于产出） |

## 十、使用流程

### 何时生成增长建议？

```
触发条件（任一）：
  1. BEM评估完成，识别出主攻盲区
  2. 业务模型诊断完成，识别出策略缺口
  3. 用户明确要求「给出增长建议」或「怎么做」

不触发：
  1. 只做FVM诊断，不需要策略输出
  2. 综合成功概率<30%，建议放弃（不需要增长建议）
```

### 生成流程

```
Step 1：读取BEM输出（主攻盲区清单）
Step 2：对每个主攻盲区，判断类型（攻击/防御/放大/储备）
Step 3：基于类型，匹配优先增长杠杆（见第三节匹配规则）
Step 4：为每个优先杠杆，生成具体行动建议（使用第五节模板）
Step 5：评估每条建议的资源需求、时间窗口、预期影响
Step 6：按优先级排序，输出增长建议清单
Step 7：将高优先级建议映射到业务模型参数，更新策略方案
```

## 十一、附录：增长建议速查表

### 不同盲区类型的最有效杠杆组合

| 盲区类型 | 最有效杠杆组合 | 理由 |
|---------|--------------|------|
| 给药便利性（如舒沃替尼口服 vs 输液） | 杠杆4（销售）+ 杠杆5（患者教育） | 口服的优势需要医生和患者都认知到 |
| 脑转移疗效（如伏美替尼CNS渗透） | 杠杆1（证据）+ 杠杆2（KOL） | 需要指南级证据 + 专家推荐 |
| 特定突变亚型（如exon20ins） | 杠杆1（证据）+ 杠杆3（准入） | 需要临床证据获批 + 医保覆盖 |
| 价格/支付（如未进医保） | 杠杆3（准入） | 支付是核心障碍 |
| 医生认知（如新产品） | 杠杆2（KOL）+ 杠杆4（销售） | KOL影响 + 销售覆盖 |
| 患者依从性（如口服药） | 杠杆5（患者教育）+ 杠杆6（数字化） | 需要长期管理 |

## 十二、完整工作流（最终版）

```
输入：产品名称 + 适应症
    ↓
【FVM】五步法 → 识别胜利点和盲区
    ↓
【BEM】三维评估 → 盲区优先级矩阵（主攻/储备/放弃）
    ↓
【GRE】增长建议引擎 → 针对主攻盲区生成增长建议
    ↓
【业务模型映射】→ 将增长建议映射到PMEM/RTM/MAA/NRx
    ↓
【优化策略方案输出】→ 整合所有输出，生成完整商业化策略
```

**这就是完整的 FVM → BEM → GRE → 业务模型 → 策略输出 链路。**
