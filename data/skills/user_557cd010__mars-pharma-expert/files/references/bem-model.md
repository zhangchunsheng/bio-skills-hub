# BEM 盲区评估模型 · 业务策略衔接层

> FVM盲区输出 → 业务策略输入 的翻译层
> 版本：v1.0 · 2026-06-29
> 适用：将胜利点/盲区分析接入PMEM/RTM/MAA/NRx业务模型

---

## 一、设计逻辑

### 问题：FVM输出和业务模型之间的断层

```
当前状态：
  FVM输出：「脑转移是奥希替尼的盲区」
  ↓
  断层：这句话怎么变成具体的市场策略？
  ↓
  业务模型输入：？？？

正确状态：
  FVM输出：「脑转移是奥希替尼的盲区」
  ↓
  BEM翻译：脑转移场景市场大小=X万患者，改变难度=中，ROI=高
  ↓
  业务模型输入：PMEM-Tool13活动设计聚焦脑转移专家，RTM资源分配脑转移高发医院
```

### 核心思路：盲区三维评估 → 策略优先级排序 → 业务模型参数输入

```
FVM盲区清单
    ↓
BEM三维评估（市场大小 / 改变难度 / ROI）
    ↓
策略优先级矩阵（主攻 / 储备 / 放弃）
    ↓
业务模型参数映射（PMEM / RTM / MAA / NRx）
    ↓
优化策略产出
```

## 二、BEM 盲区评估模型（三维评估）

### 维度1：市场大小（Market Size）

> 这个盲区对应的患者池有多大？值得投入多少资源？

#### 评估指标

| 指标 | 数据来源 | 评分标准 |
|------|---------|---------|
| 目标患者数/年 | 流行病学数据（新发+存量） | 见评分表 |
| 患者识别率 | 检测率（如基因检测覆盖率） | 识别率越高，实际可及市场越大 |
| 支付能力 | 医保状态 + 患者自付能力 | 已进医保=5分，未进=1-3分 |
| 市场增长趋势 | 过去3年患者数变化 | 增长=加分，萎缩=扣分 |

#### 市场大小评分表

```
评分标准（5分制）：

5分：目标患者 > 5万/年，且已进医保，支付无壁垒
4分：目标患者 2-5万/年，或 >5万/年但未进医保
3分：目标患者 1-2万/年，已进医保
2分：目标患者 < 1万/年，或支付壁垒高
1分：目标患者 < 5000/年，且支付壁垒高

定量锚点（肺癌领域参考）：
  > 5万/年：EGFR经典突变（19Del/21L858R）—— 大市场
  2-5万/年：EGFR exon20ins / PACC突变 —— 中市场
  1-2万/年：罕见突变（如EGFR ex18ins）—— 小市场
  < 1万/年：极罕见突变 —— 需评估ROI后决定
```

---

### 维度2：改变难易程度（Change Difficulty）

> 在这个盲区上，领导者反击有多难？我们执行有多难？

#### 评估指标

| 指标 | 说明 | 评分逻辑 |
|------|------|---------|
| 领导者反击难度 | 领导者要多长时间才能弥补这个盲区？ | 时间越长得分越高 |
| 我们执行难度 | 我们需要多少资源才能在这个盲区建立优势？ | 资源越少得分越高 |
| 医生改变难度 | 目标医生改变处方行为的难度有多大？ | 改变越容易得分越高 |
| 证据生成难度 | 产生指南级证据的难度有多大？ | 难度越低得分越高 |

#### 改变难度评分表（合并为综合难度，分数越高=越容易改变/我们越有优势）

```
评分标准（5分制，分数越高=改变越有利）：

5分：领导者>3年才能追上 + 我们执行难度低 + 医生改变意愿强 + 有现成证据
4分：领导者2-3年追上 + 我们执行难度中 + 医生愿意改变
3分：领导者1-2年追上 + 我们执行难度中 + 医生需要更多证据
2分：领导者<1年追上 + 我们执行难度高 + 医生改变意愿弱
1分：领导者已在这个盲区有布局 + 我们执行难度极高

示例（伏美替尼-脑转移盲区）：
  领导者反击难度：奥希替尼要改进CNS渗透需开发新一代化合物 → >3年 → 5分
  我们执行难度：已有CNS ORR数据，不需新临床 → 低 → 5分
  医生改变难度：脑转移专家渴望更好药物 → 强 → 5分
  证据生成难度：已有脑脊液浓度数据 → 低 → 5分
  → 综合：5分（极易改变）
```

---

### 维度3：投入产出比（ROI）

> 投入这个盲区的预期回报 vs 所需投入

#### 评估指标

| 指标 | 说明 | 计算方法 |
|------|------|---------|
| 预期收入 | 在这个盲区能达到的销售峰值 | 患者数 × 渗透率 × 定价 |
| 所需投入 | 商业化所需的总投入 | 销售团队 + 医学部 + 市场费用 |
| 时间窗口 | 从投入到达峰的时间 | 越短越好 |
| 竞争强度 | 这个盲区有多少竞品在布局 | 越少越好 |

#### ROI评分表

```
评分标准（5分制）：

5分：ROI > 3倍，时间窗口 > 3年，竞争强度低
4分：ROI 2-3倍，时间窗口 2-3年，竞争强度中
3分：ROI 1.5-2倍，时间窗口 1-2年，竞争强度中高
2分：ROI 1-1.5倍，时间窗口 < 1年，竞争强度高
1分：ROI < 1倍，或时间窗口已过

ROI简易计算：
  ROI = (预期收入峰值 × 毛利率) / 所需投入
  所需投入包括：销售团队成本 + 医学活动成本 + 市场推广成本
  时间窗口：领导者进入这个盲区的时间 - 我们现在的时间
```

## 三、BEM评估输出：盲区优先级矩阵

### 评估表格模板

| 盲区描述 | 市场大小(1-5) | 改变难度(1-5) | ROI(1-5) | 综合分 | 优先级 |
|---------|--------------|--------------|---------|-------|--------|
| | | | | 见公式 | 见规则 |

```
综合分计算：
  综合分 = 市场大小 × 0.3 + 改变难度 × 0.4 + ROI × 0.3
  （改变难度权重最高，因为策略可执行性最关键）

优先级规则：
  综合分 ≥ 4.0 → 主攻（投入70%资源）
  3.0 ≤ 综合分 < 4.0 → 储备（投入20%资源，持续观察）
  综合分 < 3.0 → 放弃（不投入资源）
```

### 可视化矩阵

```
        高市场大小
            ↑
            │  主攻区    │  储备区(高)
            │  (≥4.0)   │  (3-4.0)
            │            │
 低ROI ←────┼────────────┼────→ 高ROI
            │            │
            │  储备区(低) │  放弃区
            │  (3-4.0)   │  (<3.0)
            ↓
        低市场大小
```

## 四、业务模型参数映射

### 核心衔接逻辑

BEM输出（盲区优先级 + 主攻盲区）→ 映射到4个业务模型的输入参数

---

### 映射1：PMEM（品牌策略模型）

| BEM输出 | PMEM对应输入 | 具体参数 |
|---------|-------------|---------|
| 主攻盲区 | Tool 1 市场范围界定 | 市场范围 = 主攻盲区对应的人群（如：脑转移患者） |
| 盲区对应的患者画像 | Tool 4 客户细分 | 细分维度 = 盲区对应的医生类型（如：脑转移专家） |
| 胜利验证指标 | Tool 10 差异化定位 | 定位陈述 = 「在XX场景下，我们比领导者好XX」 |
| 改变难度评估 | Tool 13 活动设计 | 活动强度 = 改变难度越低，活动强度越高（快速占领） |
| ROI评估 | Tool 14 绩效评估 | KPI设定 = 基于ROI预期设定销售目标 |

#### PMEM参数映射示例（伏美替尼）

```
BEM输出：脑转移盲区，市场大小4分，改变难度5分，ROI 4分 → 主攻

↓ 映射到PMEM

Tool 1 市场范围：限定为「EGFR突变伴脑转移NSCLC患者」（而非全人群）
Tool 4 客户细分：重点客户 = 脑转移高发医院（肿瘤医院）的胸外科/呼吸科专家
Tool 10 差异化定位：「伏美替尼 = 脑转强效的三代EGFR-TKI」
Tool 13 活动设计：80%医学活动预算投向脑转移学术会议 + 脑转移专家顾问会
Tool 14 绩效评估：KPI = 脑转移患者处方占比 > 50%
```

---

### 映射2：RTM（区域管理模型）

| BEM输出 | RTM对应输入 | 具体参数 |
|---------|-------------|---------|
| 主攻盲区的患者地理分布 | RTM Phase 1 现状分析 | 高潜力医院清单 = 盲区患者集中的医院 |
| 改变难度（医生改变意愿） | RTM Phase 2 策略导出 | 区域策略 = 改变意愿强的区域先行 |
| ROI评估 | RTM Phase 3 活动计划 | 资源分配 = ROI高的区域多投 |
| 竞争强度 | RTM Phase 2 KSF | 关键成功因素 = 在竞争强的区域找差异化切入点 |

#### RTM参数映射示例（伏美替尼）

```
BEM输出：脑转移盲区，患者集中在三甲医院肿瘤科

↓ 映射到RTM

Phase 1 现状分析：
  高潜力医院 = 脑转移患者量TOP 200的三甲肿瘤医院
  当前进院率 = 评估这些医院的伏美替尼进院率

Phase 2 策略导出：
  区域策略 = 先攻肿瘤医院（脑转移患者集中），再下沉到综合医院
  KSF = 在肿瘤医院建立「脑转强效」的专家共识

Phase 3 活动计划：
  资源分配 = 70%销售资源投向TOP 200肿瘤医院
  KPI = TOP 200医院进院率 > 80%
```

---

### 映射3：MAA（准入模型）

| BEM输出 | MAA对应输入 | 具体参数 |
|---------|-------------|---------|
| 市场大小（患者数） | MAA 政策层 | 医保申报测算 = 基于患者数的用量测算 |
| 支付能力评估 | MAA 医院层 | 医院准入优先级 = 支付能力强的医院先行 |
| 改变难度（医生改变意愿） | MAA 医生层 | 医生教育策略 = 改变意愿强的医生先教育 |
| ROI评估 | MAA 回报预期 | 准入ROI = 基于ROI决定准入投入强度 |

#### MAA参数映射示例（伏美替尼）

```
BEM输出：脑转移盲区，市场大小4分（患者数足够），已进医保

↓ 映射到MAA

政策层：
  医保后放量策略 = 基于医保价格重新测算各省市放量预期

医院层：
  准入优先级 = 脑转移患者量TOP医院 > 综合排名TOP医院
  （因为脑转移是主攻盲区，对应医院就是高潜力医院）

医生层：
  教育重点 = 脑转移诊疗规范 + 伏美替尼CNS渗透数据
  目标医生 = 脑转移专家（而非全肺癌医生）

患者层：
  患者教育重点 = 「脑转移患者也能服药控制」
```

| ROI评估 | NRx GMV预测 | 渠道ROI = 基于ROI决定渠道投入 |

#### NRx参数映射示例（伏美替尼）

```
BEM输出：脑转移盲区，患者需长期服药，依从性要求高

↓ 映射到NRx

渠道评估：
  DTP药房 = 高优先级（脑转移患者需持续服药，DTP可提供配送）

渠道投资组合：
  Invest：DTP药房 + O2O
  Grow：互联网医院
  Protect：传统零售药房（份额维护）
```

## 五、完整工作流：FVM → BEM → 业务模型

### 工作流总览

```
输入：产品名称 + 适应症
    ↓
【FVM】五步法
  Step 1：领导者优势地形图
  Step 2：盲区扫描（18维度）
  Step 3：禀赋-盲区匹配
  Step 4：胜利验证指标设计
  Step 5：聚焦放大策略
    ↓
【BEM】三维评估（新增）
  对Step 2输出的每个盲区，执行：
    D1：市场大小评估（患者数/支付/增长）
    D2：改变难度评估（领导者反击/我们执行/医生改变/证据生成）
    D3：ROI评估（预期收入/所需投入/时间窗口/竞争）
    ↓
  输出：盲区优先级矩阵（主攻/储备/放弃）
    ↓
【业务模型映射】
  主攻盲区 → PMEM参数（市场范围/客户细分/差异化定位/活动设计）
  主攻盲区 → RTM参数（高潜力医院/区域策略/资源分配）
  主攻盲区 → MAA参数（准入优先级/医生教育/患者教育）
  主攻盲区 → NRx参数（渠道选择/渠道投资组合/患者运营）
    ↓
【优化策略产出】
  综合四个模型的输出，生成：
    ① 品牌策略（PMEM输出）
    ② 区域执行计划（RTM输出）
    ③ 准入路径（MAA输出）
    ④ 多渠道增长方案（NRx输出）
  四个输出整合为完整的商业化策略方案
```

## 七、案例演示：伏美替尼完整流程

### FVM Step 2 输出（盲区清单）

| 盲区 | 未满足需求 | 领导者反击难度 | 产品匹配度 | FVM得分 |
|------|----------|--------------|-----------|---------|
| 脑转移CNS渗透 | 5 | 5 | 5 | 5.0 → 主攻候选 |
| exon20ins | 4 | 4 | 4 | 4.0 → 主攻候选 |
| 辅助治疗 | 3 | 3 | 3 | 3.0 → 储备 |
| 一线治疗 | 5 | 2 | 2 | 3.0 → 储备 |

### BEM三维评估（对两个主攻候选）

| 盲区 | 市场大小 | 改变难度 | ROI | 综合分 | 优先级 |
|------|---------|---------|-----|-------|--------|
| 脑转移CNS渗透 | 4 | 5 | 4 | **4.3** | **主攻** |
| exon20ins | 3 | 4 | 4 | **3.7** | 储备（第二主攻） |

### 业务模型映射（脑转移盲区 → 主攻）

**PMEM输入：**
- Tool1：市场范围 = EGFR突变伴脑转移NSCLC
- Tool4：客户细分 = 脑转移专家（肿瘤医院胸外科/神经科）
- Tool10：定位 = 「伏美替尼 = 脑转强效」
- Tool13：活动 = 脑转移学术会议赞助 + 专家顾问会

**RTM输入：**
- 高潜力医院 = 脑转移患者量TOP 200三甲医院
- 区域策略 = 先攻肿瘤医院，再下沉
- 资源分配 = 70%资源投向TOP 200

**MAA输入：**
- 准入优先级 = 脑转移患者量TOP医院
- 医生教育 = 脑转移诊疗规范 + CNS数据
- 患者教育 = 「脑转移可控制」

**NRx输入：**
- 渠道 = DTP + O2O（脑转移患者依从性需求高）
- 患者运营 = 长期服药管理 + 复查提醒

### 优化策略产出

```
【伏美替尼商业化策略方案（基于BEM优化）】

一、品牌策略（PMEM）
  核心定位：「脑转强效的三代EGFR-TKI」
  目标人群：EGFR突变伴脑转移NSCLC患者（占整体~30%）
  核心信息：「强入脑，伏美替尼」
  推广组合：医学驱动（指南推荐）+ 专家网络（脑转移KOL）

二、区域执行（RTM）
  高潜力医院：脑转移患者量TOP 200三甲医院
  区域节奏：T1（TOP200）→ T2（地级市肿瘤科）→ T3（综合医院）
  销售KPI：TOP200医院进院率 > 80%，脑转移患者处方占比 > 50%

三、准入路径（MAA）
  准入优先级：脑转移患者量TOP医院 > 综合排名TOP医院
  医保后策略：基于医保价格重新测算各省市放量预期
  医生教育：脑转移诊疗规范 + 伏美替尼CNS数据

四、多渠道增长（NRx）
  重点渠道：DTP药房（服药依从性管理）+ O2O（突发需求响应）
  患者运营：长期服药管理 + 脑转移复查提醒 + 患者社区
  GMV预测：DTP渠道贡献 > 30%销售额

五、策略优先级（基于BEM综合分）
  T0-T1：脑转移盲区主攻（综合分4.3）→ 投入70%资源
  T1-T2：exon20ins盲区储备（综合分3.7）→ 投入20%资源，持续积累数据
  T2以后：辅助治疗盲区（综合分3.0）→ 等待数据成熟后启动
```

## 八、使用说明

### 何时使用BEM？

| 场景 | 是否使用BEM |
|------|-----------|
| FVM分析完成后，需要知道「主攻盲区怎么变成具体策略」| ✅ 必须使用 |
| 有多个盲区候选，需要决定资源分配优先级 | ✅ 必须使用 |
| 已确定主攻盲区，需要制定详细的商业化方案 | ✅ 必须使用 |
| 只想做FVM诊断，不需要策略输出 | ❌ 不需要 |

### 谁来完成BEM评估？

```
市场大小评估：市场部/商业拓展团队
改变难度评估：医学部 + 销售部（共同评估）
ROI评估：财务部 + 战略规划部（共同评估）

→ 建议三方共同完成，避免单一视角偏差
```

### 评估频率

```
新产品：立项时完成第一次BEM评估
在研产品：每6个月重新评估一次（竞品变化、临床数据更新）
已上市产品：每12个月重新评估一次（市场变化、指南更新）
```
