# Tool 18: DA/宣传册创意设计工具

融合三大方法论体系，打造高认知效率的医药推广物料。

## 方法论融合详解

### PROVEN 行为科学框架（规范DA信息结构）

| 字母 | 含义 | DA应用 |
|----|----|----|
| **P**rioritisation | 优先级 | 每页DA一个核心信息，不堆砌 |
| **R**esonance | 共鸣 | HCP临床痛点精准击中，数据->洞察->行动 |
| **O**bjective | 目标 | 每页DA有明确行为目标（了解/考虑/处方） |
| **V**isualisation | 可视化 | 数据->图表->视觉锚点，3秒读懂 |
| **E**ase | 易理解 | Flesch阅读便利分>=60，避免专业术语堆砌 |
| **N**arrative | 叙事 | 证据->故事->行动号召，有起承转合 |

### 华与华超级符号方法论（建立品牌识别）

**文化母体**：寄生到HCP已有认知
- 例：降糖药 -> "血糖管家"（管家是已有认知）
- 例：心血管药 -> "血管清道夫"（清道夫是已有认知）

**超级符号**：3秒识别，7天记忆
- 视觉：颜色/形状/图像（如：XX的蓝色圆形LOGO）
- 听觉：口号/声音（如："XX，守护每一次心跳"）
- 设计原则：简单、重复、一致

**超级口号**：口语化、指令性、可传递（7-12字）
- ❌ "XX产品具有卓越的疗效和安全性"（书面语，不口语化）
- ✅ "降糖，选XX"（口语化，指令性，7字）

**货架思维**：在HCP注意力货架上竞争
- HCP每天接收大量DA，如何让她/他记住你的？
- 答案：超级符号 + 超级口号 + 重复曝光

### 金枪大叔冲突营销（捕获注意力）

**冲突定位**：用反常识/痛苦场景/挑衅提问作为DA开场
- 例："你的T2DM患者，餐后血糖达标率有多少？"
- 答案可能："可能远低于你想象"（冲突：期望vs现实）
- 接着："XX可有效改善餐后血糖，达标率提高XX%"

**口语化**：拒绝书面语，用HCP日常语言
- ❌ "本品具有显著的疗效优势"
- ✅ "用了XX，患者餐后血糖降了"

**反常识切入**：用"不对吧？"开场
- 例："你说XX不适合老年患者？数据显示..."（挑战固有观念）

**去精英化**：不装，直接说人话，有态度有观点
- 不用"尊敬的教授"，用"Dr. Zhang，您有没有遇到过..."
- 不说"本研究显示"，说"我们看一组数据"

## 四阶工作流

### Phase 1：冲突定位（金枪大叔方法）
**目标**：挖掘HCP临床痛点，用冲突开场

**步骤**：
1. 列出HCP最常见的临床痛点（未被满足的需求）
   - 例：T2DM患者餐后血糖达标率低
   - 例：老年患者多重用药，依从性差
2. 用反常识数据/痛苦场景作为DA第1页
3. 输出：冲突开场文案（3个备选）

**冲突开场模板**：
```
[反常识数据/问题]
-> [现状：很多HCP没意识到这个问题]
-> [代价：不解决的后果]
-> [解决方案：产品可以解决这个问题]
```

### Phase 2：符号寄生（华与华方法）
**目标**：将产品寄生到HCP已有认知，创作超级符号+超级口号

**步骤**：
1. 找到HCP已有认知（文化母体）
   - 例：血糖仪、降压药、支架...
2. 设计超级符号（视觉锚点）
   - 颜色：与竞品区分，容易被记住
   - 形状：简单，可延展到各种物料
3. 创作超级口号（7-12字，口语化）
   - 测试：让一线MR读一遍，能否记住？
4. 输出：超级符号描述 + 超级口号（3个备选）

### Phase 3：证据叙事（PROVEN方法）
**目标**：用12页标准DA模板，将证据转化为故事

**12页DA标准模板**：
```
P1: 冲突开场（反常识数据/痛苦场景）-> 捕获注意力
P2: 临床问题定义（指南推荐/未满足需求）-> 建立相关性
P3-4: 产品机制（MOA，可视化）-> 理解"为什么有效"
P5-7: 核心证据（RCT/头对头，数据可视化）-> 建立信心
P8: 患者获益（不是药效，是患者结果）-> 情感连接
P9: 安全档案（诚实展示，建立信任）-> 降低顾虑
P10: 使用便捷性（依从性优势）-> 促进尝试
P11: 行动号召（下一步是什么？）-> 驱动行为
P12: 合规声明+参考文献 -> 满足合规
```

**每页设计检查清单（PROVEN）**：
- [ ] Prioritisation：一页一个重点？
- [ ] Resonance：与HCP临床痛点共鸣？
- [ ] Objective：有明确行为目标？
- [ ] Visualisation：数据可视化了？
- [ ] Ease：Flesch评分>=60？
- [ ] Narrative：有故事性？

### Phase 4：双格式输出

**HTML 交互式创意仪表盘**：
- 创意评分卡（PROVEN 6维 + 华与华 4项 + 金枪大叔 3项）
- 超级符号库（颜色/形状/图像建议）
- DA预览（12页可交互预览）
- 竞品对比（与竞品DA的差异化分析）

|----|----|----|

| 超级口号传播度 | 20分 | 口语化，可传递 |
