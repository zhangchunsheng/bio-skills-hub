# RTM Phase 4: 执行与评估（DM-ETM 100分评估体系）

阶段目标：跟踪执行质量，持续改进区域营销策略。

## DM-ETM 100分评估体系详解

### 数据质量（20分）
- **完整性（7分）**：关键字段填写率>=95%
  - 处方数据、拜访记录、活动执行、KOL互动
- **准确性（7分）**：与传统报表核对差异<5%
  - 销量数据、份额数据、活动费用
- **及时性（6分）**：活动后48小时内完成录入
  - CRM系统录入及时性

### 分析深度（30分）
- **根本原因诊断质量（15分）**
  - 能力根因：产品知识/拜访技巧/时间管理
  - 机会根因：市场机会/竞品动态/政策机会
  - 意愿根因：激励/认可/团队文化
  - 评分：每准确识别1个根因得5分
- **洞察深度（15分）**
  - 可行动的洞察 vs 表面描述
  - 有数据支撑 vs 主观判断
  - 评分：每个可行动洞察得3分

### 策略质量（30分）
- **策略针对性（10分）**：与SWOT/KSF的对齐度
  - 每个策略都能追溯到KSF：10分
  - 部分能追溯：5分
  - 不能追溯：0分
- **策略创新性（10分）**
  - 差异化做法 vs 常规操作
  - 有创新：10分；常规：5分；无差异：0分
- **策略可衡量性（10分）**
  - KPI具体且可追踪：10分
  - KPI模糊：5分
  - 无KPI：0分

### 执行落地（20分）
- **活动执行率（10分）**
  - 计划vs实际完成率>=90%：10分
  - 80-90%：7分
  - <80%：0分（需说明原因）
- **KPI达成率（5分）**
  - 核心KPI达成>=80%：5分
  - 60-80%：3分
  - <60%：0分
- **团队采纳度（5分）**
  - 一线团队反馈评分>=4/5：5分
  - 3-4/5：3分
  - <3/5：0分

**总分：100分**
- >=80分：优秀（绿色）
- 60-79分：通过（黄色）
- <60分：需改进（红色，强制辅导计划）

## 持续改进循环

```
[执行] -> [数据回顾] -> [偏差分析] -> [策略调整] -> [再执行]
              |              |
              v              v
          [DM-ETM评分]  [改进计划]
```

### 月度回顾会议议程
1. 数据回顾（15分钟）：销量/份额/KPI达成情况
2. DM-ETM评分（15分钟）：各区域自评+互评
3. 偏差分析（20分钟）：未达成KPI的根本原因
4. 策略调整（20分钟）：下月策略优化
5. 改进计划（10分钟）：能力培养/资源补充

## 评估输出格式

- .md 评估报告（含DM-ETM评分表+改进建议+辅导计划）
- HTML 可视化仪表盘（含评分雷达图+趋势对比+改进优先级矩阵）
- 页脚：以上内容由首个医药行业业务诊断垂类大模型MARS生成
