## 0. 总纲：营销逻辑（贯穿全书的中心轴）

**① 背景场景**：企业营销一线陷入"无规则、无秩序的纷乱状态"——营销人员行动点散落成不规则的"营销乌云"（图1-1），业绩与从业年限、折扣率毫无关系。此时缺的不是技巧，而是**营销逻辑**。

**② 工作流程（定义）**：营销逻辑 = 对"以何种方式将何种产品/服务出售给哪些客户、如何持续拉开与竞争者的差距、如何获取利润"四问，形成**一套贯穿始终的观点、思路和行为方式**。它是给所有营销活动（技巧、人才选拔、资源配置）提供"焦点和方向"的中心轴（绪论 p17）。

**③ 核心路径·差异点·数据抓取**：
- 差异点（vs 普通方法论）：优等生与中等生的分水岭**不是技巧技能，而是是否具有营销逻辑**（p17）。符合逻辑的技巧才有价值，否则"别人成功对你未必适用，绝不做无用模仿"（p18）。
- 数据抓取：诊断企业是否患"营销逻辑缺乏症"——用散点图画出"营销人员从业年限×销售业绩""客户交易额×收益率""客户销售额×实价折扣"，若点呈无规律云状，即"乌云"，缺逻辑（图1-1、图4-1、图6-1）。

**④ 核心产出**：企业从"中等生"（勤奋但业绩平平）升级为"市场观察家"——能站在经营者角度科学观察市场、找到最大限度发展本企业的机会（绪论 p5-6）。

## 1. 机会再发现——科学分析市场（对应 MARS · SQ1 市场范围）

**① 背景场景**：治愈营销逻辑缺乏症、消除乌云、选对战略的**第一步**。不需要微积分，而是"用科学的眼光观察市场"。

**② 工作流程（市场生态学三含义）**：
1. 准确如实把握 **3C**（Customer / Competitor / Company）；
2. 将 3C 要素分解为更小要素并重新组合，确认整体是否符合逻辑；
3. 用数字计算重组后的形态在经济上是否成立（p27-28）。
- 比喻：像生态学家观察森林——先分类动植物（3C），再观察物种间竞争/共生关系及强弱，再推测森林形成与变化，最后用数字（能量平衡）验证（p28-30）。**关键差异**：市场观察家最终要"变成森林中的某种生物"，从自身企业立场出发制定生存策略，而非仅客观旁观（p30）。

**③ 核心路径·差异点·数据抓取**：
- 顾问常用 **4 种方法**（p31）：①业务机会发现图（找市场机会）②区别对待客户（找重要客户）③销售额方程式（提销售额）④竞争标杆管理（定胜负处）。
- **业务机会发现图**分两类：
  - 古典式（产品×客户矩阵）：纵轴新/现有客户，横轴新/现有产品 → 深入挖掘客户 / 横向展开 / 交叉销售 / 新业务（图2-1、2-2、2-3，p31-37）。制作分"整体图"（按产品×客户分类，标注规模/增长/份额/自身位置）与"个别图"（细分行业、用途、设备购入时间等，p37）。
  - 价值链式（Value Chain，波特）：将企业活动视为为客户创造价值的连续活动，扩展到产业层面找机会与威胁（图2-5、2-6 个人电脑产业变迁，p39-41）。
- 数据抓取：市场统计数据、行业团体/杂志数据、各竞争者主业与投资者信息、自身销售数据、权威调查报告（多已公开）；个别图所需的客户经营信息需通过拜访、简单问卷补充（p38、p43-44）。

**④ 核心产出**：一张"业务机会发现图"（整体+个别），明确哪里有魅力、本企业位置、进攻哪块市场（如 D 企业用交叉销售打 Z 产品运输市场，p35-37）。

## 2. 战略再思考——标准化与客户化（对应 MARS · SQ4 定位/战略）

**① 背景场景**：科学观察市场后，决定"如何作战"。两种截然相反的战略若选错，会"多花成本还得不到利润"（p69）。

**② 工作流程（二选一）**：
- **标准化（产品化）战略**：开发客户广泛使用的标准品，以市价或低价大量销售获利。核心是抢在对手前开发标准品、在被赶超前卖给更多客户（p70、图3-1）。
- **客户化（定制）战略**：按少数客户个别需求量身定做，通过附加价以超均价售出获利（p71）。

**③ 核心路径·差异点·数据抓取**：
- **适用产品差异**（p73-75）：标准化→持续重复大量交易、生命周期中后期成熟品、差别要素少（通用品 commodity，如原材料/螺丝/文具）；客户化→交易量小不定期、生命周期前期、差别要素多含附加价（特制品 specialty，如大型设备/航天零件/解决方案销售）。
- **适用客户差异**（p76-79）：标准化→在意价格、订货量小的中小/微型企业；客户化→有"任性需求"、有财力支付高价的特殊客户（大客户、研发型、安全质量敏感企业），宜"交叉销售"多产品锁客。
- **4P 营销组合差异**（p78-82）：标准化→标准品/标准价/广覆盖代理渠道（特约店、网络）/非特定客户广告；客户化→定制品/特价/直销访问/业内口碑与龙头客户背书。
- **优势构筑=优先投资**（p80-85，核心差异点）：标准化三投资——产品化（定制品转通用品并降本）、行业标准品 defacto（抢占"影响源" influencer 客户带动）、业务标准化；客户化三投资——产品服务品质、与特定实力客户长期关系（牺牲单笔亏本换长期）、业务组织客户化（设客户专门窗口 account manager、驻厂设计）。
- 数据抓取：产品生命周期阶段、客户价格敏感度与预算、交易量稳定性、是否存在"影响源"客户（采购量大/技术尖端/大学等影响力大）。

**④ 核心产出**：明确的战略选择与对应的 4P 组合，以及"优先投资"路线图（在对手前抢跑的三类投资）。

## 3. 重新审视客户——需求与决策结构（对应 MARS · SQ2/SQ3 客户细分/行为洞察）

**① 背景场景**：客户管理不该以"交易额"或"收益率"单一基准（图4-1 显示二者几乎无关）。需重新分类、深挖需求、理解决策结构。

**② 工作流程（三方法 + 三分类）**：
- **找准目标客户三基本点**（p92-93）：①把握各客户现在及将来的收益；②分三类——赢利发展源泉客户 / 非赢利但具广告效应或新产品开发伙伴客户 / 准备舍弃客户；③按分类改变资源配置、态度、渠道、方法。
- 案例 G 企业三分法（p95-97）：**金树**（赢利主力，保数量）/ **智慧之树**（不赢利但提技术、广告效应，选少数高附加值）/ **弃木**（无交易价值，排除）。同行业 B 企业因分类定位错误而失败。
- **千里马选择**（p97-101）：在快速发展行业（液晶面板、汽车、计算机、连锁、金融），及早绑定"千里马"客户共成长，规避"劣马"。难点在马驹期判断，取决于经营者"把握时代、选择企业、衡量经营者"能力；需考虑对千里马的期待定位、候选者取舍、被挟制风险（图4-5）。
- **深入客户发现**（p101-105，图4-6/4-7）：暂时排除供应商自身，从客户观点重新审视产品；理解客户整体想法行动、客户的客户直至最终用户；案例 X 耐火材料商跳出"同行竞争"转向"建筑物成本/工期/工程管理"视角而逆袭。
- **失败原因分析**（p104-105，图4-8）：投标失利时刨根问底追问客户真因，而非接受"价格高/业绩差"托词——常暴露"方案抓不到点子/提案太晚/不能从大处高处着眼"。

**③ 核心路径·差异点·数据抓取**：
- **DMU（决策主体 Decision Making Unit）**：理解客户决策结构的方法（p91、图5-3 KAM 运用）。
- **EVC（客户经济价值 Economic Value to Customer）**：从客户角度评价产品服务的方法（p91、图6-6 交货期缩短降低储存成本即 Z 企业 EVC）。
- 数据抓取：各客户交易额×收益率散点（图4-1）、客户分类定位表（图4-3）、决策链访谈（DMU 图）、客户总成本节省测算（EVC）、失标后客户深访（图4-8）。

**④ 核心产出**：客户三分定位（金树/智慧之树/弃木）+ 千里马清单 + 深入客户发现的需求地图 + DMU 图 + EVC 测算，作为 SQ2/SQ3 的量化输入。

## 4. 重新构筑交易关系——接近客户的方法（对应 MARS · SQ5 激活/执行）

**① 背景场景**：客户已分类、需求已明，需匹配"使命不同的营销人员"与组织方式，建立互动关系。

**② 工作流程（方法1-3 + 团队）**：
- **方法1 四类营销人员**（图5-1，p125-128）：①开发营销人员（深入大客户共开定制品，具营销思维的技术人）②标准品诱导营销人员（向中坚客户推大客户衍生的便宜标准品）③特约店管理人员（管中小客户渠道）④网络销售策划人员（低成本的网络流通化）。
- **KAM 重要客户经理**（图5-2/5-3，p128-130）：对顶级大客户设专人/兼人做"关系营销"，综合运深客户发现、DMU 图、EVC，做企业内部的客户代言人。
- **方法2 组队（teaming）解决方案营销**（p130-138）：因"无人能总揽"（行业知识壁垒/业务通壁垒/多阶段营销技能壁垒，图5-4/5/6），故由多领域专家临时组队。IBM 例：客户关系专家+业界专家+问题解决专家+IT专家+项目管理专家（T 型人才：横杆通用技能、纵杆专业技能，图5-7/5-8）。组队三重点：人才分类储备、按阶段组队协作、任务完即散。配套机制：专业性组织形态、方法积累与专家网络、专家型人事/考核制度。
- **方法3 建立与客户互动的关系**（p139 起，未完全 OCR）。

**③ 核心路径·差异点·数据抓取**：
- 差异点：营销人员类型必须**与客户分类一一映射**（大客户→开发/KAM，中坚→标准品诱导，中小→特约店管理，长尾→网络），而非一刀切。
- 数据抓取：客户分类×渠道×人员类型对照表（图5-1）、KAM 业务内容清单（图5-3）、团队专家技能缺口诊断（图5-6 个人能力 vs 解决方案所需能力长方体差距）。

**④ 核心产出**：按客户分类配置的营销人员矩阵 + KAM 关系营销机制 + 专家组队（T 型）解决方案交付能力。

## 5. 定价策略再构造——通过定价实现高收益（对应 MARS · 定价/利润闭环）

**① 背景场景**：与前述"乌云"同源——客户销售额与实价折扣无关系（图6-1 定价乌云）。重新定价对利润杠杆最大：价格每升 1%，销售利润升 **7.1%**（vs 销量+1%→+3.6%，固定费-1%→+3~3.5%，p156）。

**② 工作流程（5 对象 + 6 方法 + 组织能力）**：
- **重审 5 对象**（图6-3，p157）：产品价格（实际实现价，管价格清单/折扣/OEM/投标）、产品组合（回扣激励诱导高价品、捆绑）、服务价格（超距运输/加急/技术支持收费）、售后服务（保修/升级/保险，降产品价提服务价赢利）、定价能力（组织）。
- **6 种定价法**（图6-4，p160-167）：①分类定价（按客户类别高价，图6-5）②价值定价（按客户 EVC 出高价，紧急/定制/泡沫型客户，图6-6）③最低价定价（price floor，线下设限，宁失客户保收益，图6-7）④权衡定价（重新审视量多打折，图6-8）⑤降低成本定价（引导客户买低成本高收益品，图6-9）⑥（书中称基本方法，含以上）。
- **定价组织能力**（p169-170）：明确作用责任、集中价格信息经验、决策执行过程管理、对不愿涨价的队伍激励、IT 管理体系。

**③ 核心路径·差异点·数据抓取**：
- 差异点：**定价是利润杠杆之首**（7.1% 弹性），且必须组织化而非个人化，否则效果暂时。
- 数据抓取：客户销售额×实价散点（图6-1）、按客户类别最低价格线（图6-2/6-7）、各客户 EVC 测算（图6-6）、量多打折曲线（图6-8）、产品成本收益对比（图6-9）。

**④ 核心产出**：战略定价法落地（分类/价值/最低价/权衡/降本五法）+ 定价组织能力与 IT 工具，实现高定价高收益。

## 6. 与 MARS 品牌策略 SQ 的映射（接入点）

| BCG 新逻辑 | MARS 能力域 / SQ | 接入动作 |
|------------|------------------|----------|
| 营销逻辑（中心轴） | 全局哲学 | 所有 SQ 输出须有"贯穿始终的逻辑"，避免营销乌云 |
| Ch2 科学分析市场（3C/机会发现图/价值链） | SQ1 市场范围 | 用业务机会发现图替代/补充 TAM-SAM-SOM |
| Ch3 标准化 vs 客户化 | SQ4 定位 | 定位时明确"标准品逻辑"还是"定制品逻辑"，决定 4P |
| Ch4 客户三分/千里马/DMU/EVC | SQ2 细分 / SQ3 行为洞察 | 客户细分用金树/智慧之树/弃木；EVC 支撑价值主张 |
| Ch5 四类人员/KAM/组队 | SQ5 激活 / 销售部署 | 推广组合按客户分类配人；KAM 对应关键客户管理 |
| Ch6 战略定价 | 定价/利润 | 定价作为利润杠杆之首，接甲氨蝶呤预充针定价策略 |

**核心警示（来自本书）**：没有营销逻辑，MARS 的 19 工具会变成"乌云"——工具越多越分散。BCG 的"中心轴"思想与 MARS 已有的"line of sight（SQ→说什么做什么）""指标避免空心化"完全同构，可互为强化。
