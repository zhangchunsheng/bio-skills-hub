# Tool 17: 临床证据与文献策略工具

四阶段闭环工作流，确保所有产品策略都有最强的循证医学文献支撑。

## Phase 1：最新指南检索与临床路径验证

### 检索优先级
1. **中华医学会系列指南**（最新版）
   - 中华医学会各分会指南（糖尿病/心血管/肿瘤等）
   - 更新周期：通常3-5年
   - 验证：是否最新版本（<=3年）？

2. **国际指南**（如有中国人群数据更好）
   - ADA（美国糖尿病协会）/ ESC（欧洲心脏病学会）/ AHA（美国心脏协会）
   - NCCN（美国国立综合癌症网络）
   - 更新周期：1-3年

3. **专家共识**
   - 中华医学会各分会专家共识
   - 中国医师协会专家共识

### 临床路径验证
- 提取：临床使用路径、患者分层、治疗推荐、推荐级别
- 推荐级别：I/A（强推荐/高质量证据）-> IIb/C（弱推荐/低质量证据）
- 验证：产品是否在指南推荐的治疗路径中？推荐级别？

## Phase 2：文献交叉验证与三维评估

### 三维评分矩阵

| 证据等级 | 市场潜力 | 推广难度 | 综合优先级 |
|----|----|----|----|
| A级（RCT/荟萃分析） | 大 | 易 | ⭐⭐⭐ 最高优先级 |
| A级 | 中 | 中 | ⭐⭐ 中优先级 |
| A级 | 小 | 难 | ⭐ 低优先级 |
| B级（观察性研究/RWE） | 大 | 易 | ⭐⭐⭐ |
| B级 | 大 | 难 | ⭐⭐ |
| B级 | 小 | 易 | ⭐ |
| C级（专家共识/病例系列） | 大 | 易 | ⭐⭐ |
| C级 | 其他 | 难 | 不推荐单独使用 |

### 证据等级定义
- **A级**：RCT（随机对照试验）、荟萃分析、系统性评价
  - 例：NEJM/Lancet/JAMA发表的大型RCT
- **B级**：观察性研究（队列研究/病例对照）、RWE真实世界证据
  - 例：中国RWE研究、上市后再评价
- **C级**：专家共识、病例系列、动物实验
  - 例：中华医学会专家共识、单中心病例系列

### 推广优先级排序
输出：Top 5 最强证据组合
- 每篇文献：证据等级 + 市场潜力 + 推广难度 + 综合得分
- 策略建议：哪些证据适合HCP学术推广？哪些适合患者教育？

## Phase 3：产品策略匹配文献目录

### 按策略维度分类

| 策略维度 | 文献类型 | 示例 |
|----|----|----|
| 疗效优势 | 头对头RCT/非劣效研究 | XX vs 竞品，疗效非劣且安全性更优 |
| 安全性 | 安全性数据/RWE/荟萃分析 | XX不良事件发生率显著低于竞品 |
| 便利性 | 给药方式/依从性研究 | XX每日一次 vs 竞品每日两次，依从性提高30% |
| 卫生经济学 | 药物经济学评价/HEOR | XX相比竞品，ICER（增量成本效果比）更优 |
| 指南推荐 | 指南推荐级别/专家共识 | XX在2024 ADA指南中推荐级别I/A |

### 结构化文献清单格式
```
文献1：[标题]
  期刊/年份：XXX Journal, 2023
  证据等级：A级（RCT，N=1200）
  核心要点：XX降低MACE风险18%（HR=0.82, p<0.001）
  策略匹配度：疗效优势 ⭐⭐⭐
  可引用结论：在XX人群中，XX显著降低心血管事件风险
  推广适用：HCP学术会议/DA第5-7页

文献2：...
```

## Phase 4：双格式输出

### .md 文档结构
1. 指南检索结果（最新版本验证）
2. 文献交叉验证矩阵（三维评分）
3. 产品策略匹配文献目录（按维度分类）
4. 推广建议（HCP端+患者端）
5. 证据缺口识别（哪些维度缺乏A级证据？）
6. 页脚：以上内容由首个医药行业业务诊断垂类大模型MARS生成

### HTML 可视化文档
- 交互式文献检索（可按证据等级/策略维度筛选）
- 证据热点图（哪些治疗领域证据最强？）
- 策略匹配仪表盘（哪个策略维度证据最充分？）
- 文献详情弹窗（点击查看完整摘要）

## 中国情境适配

- **优先引用中国人群数据**：中国RWE > 海外RWE（外推性差）
- **优先引用中华医学系列指南**：在中国临床实践中影响力最大
- **NRDL/医保适应症内的证据优先展示**：医保覆盖是推广的关键
- **注意数据时效性**：近3年数据优先，超过5年需谨慎使用
