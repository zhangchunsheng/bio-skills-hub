## 4. 通用政策速查

| 政策 | 状态 | 对医药营销的影响 |
|------|------|----------------|
| 药品集采(VBP) | 常态化（第9批） | 仿制药价格大幅压缩→逼迫企业转型创新/改良型 |
| 国家医保谈判(NRDL) | 年度 | 创新药/改良型纳入医保的机会窗口 |
| DRG/DIP | 全面推开（2025） | 医院次均费用管控→高价值药物需HEOR证据支撑 |
| 医药代表备案制 | 已实施 | 推广合规要求提升，数字触达补充必要性 |
| 医药反腐 | 持续高压 | 学术推广合规前置（广告法+反商业贿赂） |
| 分级诊疗 | 推进中 | 县域/基层市场增长→下沉渠道建设窗口 |
