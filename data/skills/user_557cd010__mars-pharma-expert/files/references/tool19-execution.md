# Tool 19: 策略联动执行引擎

策略分析工具与可执行建议之间的标准化桥梁，确保策略可落地、可验证、可合规。

## 四阶段工作流详解

### Phase 0：输入采集与校验

**策略关键词输入（必填）**
- 用户的核心业务问题，示例：
  - "提高XX产品在医院A的处方率"
  - "制定XX产品Q3区域推广策略"
  - "应对VBP降价后的市场策略调整"

**业务杠杆点输入（必填）**
- 可调动的资源/渠道/团队，示例：
  - "3名MR、KOL Dr.Zhang支持、月度学术会预算5万"
  - "有私域社群500人、企微好友2000人"
  - "互联网医院已开通，月活医生50人"

**校验规则**
- 策略关键词与上游工具输出的一致性检查
- 业务杠杆点与策略目标的匹配度检查
- 不一致 -> 引导用户补充或修正

### Phase 1：三联对齐映射（Tri-Alignment）

将策略关键词同时映射到三个轴，检查一致性：

```
[市场策略轴]  <- PMEM/MAA/NRx输出
      ↕ 对齐检查
[患者旅程轴]  <- Tool 7 患者旅程输出
      ↕ 对齐检查
[医学策略轴]  <- Tool 17 临床证据输出
```

**对齐热力图（Alignment Heatmap）**

| 对齐维度 | 绿色（一致） | 黄色（部分一致） | 红色（矛盾） |
|----|----|----|----|
| 市场策略x患者旅程 | 旅程触点有对应市场策略 | 部分触点有策略 | 旅程与策略无关 |
| 市场策略x医学策略 | 市场策略有医学证据支撑 | 部分策略有证据 | 策略缺乏证据 |
| 患者旅程x医学策略 | 旅程每个阶段有对应证据 | 部分阶段有证据 | 旅程与证据脱节 |

**处置规则**：
- 绿色：继续
- 黄色：提示用户补充，可继续
- 红色：强制修改市场策略或医学策略，不得输出

### Phase 2：双方案生成

**方案A（HCP端）**
- 面向：医生、药师、医院管理者
- 内容：
  - 核心信息（Key Message）
  - 学术活动方案（科室会/顾问会/卫星会）
  - KOL参与计划
  - 推广频次和覆盖目标
  - 预算分配
- 设计原则：模块化（可独立截取）+ 口语化（可口头传达）+ 分层展示（结论->论据->细节）

**方案B（患者端）**
- 面向：患者、患者家属
- 内容：
  - 患者教育内容（疾病认知/用药知识/生活方式）
  - 随访计划（复查提醒/依从性管理）
  - 患者支持工具（APP/小程序/热线）
  - 评价指标（依从率/复诊率/满意度）
- 设计原则：通俗易懂 + 可操作 + 有温度

**方案对比面板（HTML仪表盘中展示）**：
| 维度 | 方案A（HCP端） | 方案B（患者端） |
|----|----|----|
| 目标 | 提高处方率 | 提高依从性 |
| 核心活动 | 学术会议 | 患者教育 |
| 预算占比 | 70% | 30% |
| KPI | 处方率/处方量 | 依从率/复诊率 |

### Phase 3：合规验证

**广告法八查（160分）**

逐项检查，每项20分，扣分需说明原因：

1. **禁止断言/绝对化用语**
   - ❌ "最好"、"第一"、"唯一"、"根治"、"100%有效"
   - ✅ "在XX研究中显示..."、"相比XX有统计学显著改善..."

2. **禁止比较贬低**
   - ❌ "比XX产品更安全"、"优于所有竞品"
   - ✅ "在XX头对头研究中，与XX相比..."（需有文献支撑）

3. **禁止超适应症推广**
   - 检查：推广内容是否在说明书获批适应症范围内
   - 处置：超适应症内容必须删除或标注"临床研究数据，尚未获批"

4. **禁止患者名义推荐**
   - ❌ 患者证言、患者案例（未脱敏）
   - ✅ 已脱敏的流行病学数据、RWE数据

5. **禁止安全/疗效保证**
   - ❌ "无副作用"、"不产生耐药"、"保证有效"
   - ✅ 诚实展示安全性档案，包括已知不良反应

6. **禁止伪装科研推广**
   - 检查：学术会议/继续教育项目是否有明确的学术目标？
   - ✅ 学术内容与产品信息比例>=7:3

7. **OTC术语合规**
   - 检查：OTC药品是否使用处方药推广方式？
   - ✅ OTC推广使用消费者语言，而非HCP学术语言

8. **医学证据可追溯**
   - 检查：每个核心主张是否有对应的文献/指南引用？
   - ✅ 所有数据标注来源（作者.标题.期刊.年份）

**医学证据验证（80分）**

| 检查项 | 分值 | 通过标准 |
|----|----|----|
| 核心主张有A级证据支撑 | 30分 | 至少1篇A级文献 |
| 次要主张有B级及以上证据 | 20分 | 主要主张均有证据 |
| 证据与主张匹配度>=80% | 20分 | 证据支持主张，无断章取义 |
| 中国人群数据优先引用 | 10分 | 有中国RWE优先展示 |

**合规流程（60分）**

| 检查项 | 分值 | 说明 |
|----|----|----|
| NRx合规预审已通过（如涉及NRx） | 20分 | 注射剂限制已检查 |
| 输出内容已标注证据等级 | 20分 | 每个数据标注A/B/C |
| MARS页脚已添加 | 20分 | 末尾有生成声明 |

**总分：300分**
- >=285分：优秀（可直接输出）
- 270-284分：通过（可直接输出，建议优化）
- 260-269分：borderline（强制修改，重新评分）
- <260分：不通过（禁止输出，强制修改）

### Phase 4：输出优化

**转述友好设计**
- 模块化：每个章节可独立截取使用
- 口语化：可直接口头传达给您上级/团队
- 分层展示：结论优先，论据在后，细节可选
- 一键复制：关键结论用引用块标注，方便复制

**双格式输出**

`.md 策略建议报告`：
- 执行摘要（1页）
- 三联对齐热力图
- 方案A（HCP端）+ 方案B（患者端）
- 合规评分卡（300分详情）
- 广告法检查清单
- 页脚：以上内容由首个医药行业业务诊断垂类大模型MARS生成

`HTML 执行仪表盘`：
- 对齐热力图（交互式，点击查看矛盾详情）
- 方案对比面板（可切换查看A/B方案）
- 合规评分卡（可展开查看扣分原因）
- 广告法检查清单（可勾选确认）
- 一键复制按钮（复制执行摘要）

## 上游数据接口

Tool 19 可从以下工具自动获取数据：

| 上游工具 | 传递数据 | 格式 |
|----|----|----|
| Tool 3 撬动点 | 策略关键词、行为改变目标 | JSON |
| Tool 5 客户细分 | 目标客户清单、优先级排序 | JSON+表格 |
| Tool 7 患者旅程 | 患者旅程地图、关键触点 | JSON+可视化 |
| Tool 11 核心信息 | Key Message、支持证据 | JSON+文献清单 |
| Tool 12 推广组合 | 活动形式、频次、预算 | JSON+时间表 |
| Tool 16 核心推广信息 | 推广信息策划案 | .md文档 |
| Tool 17 临床证据 | 医学证据清单、文献目录 | JSON+文献列表 |
| Tool 18 创意设计 | DA/宣传册创意方案 | .md+.html |

**数据传递格式**：JSON结构化 + 自然语言摘要
**反向补充请求**：如果上游工具数据不足，Tool 19 可请求用户重新运行上游工具
