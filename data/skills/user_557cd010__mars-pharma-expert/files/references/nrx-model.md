# NRx 线上新零售模型

NRx（New Retail Excellence）是PMEM在线上新零售维度的战略延伸，深度融合中国医药线上生态。

## 6大核心渠道详解

### 1. 互联网医院
- **模式**：线上诊疗->电子处方->线上购药->配送到家
- **核心策略**：医生端学术推广（提高线上处方意愿）+ 患者端便利性（复诊配药）
- **关键指标**：处方转化率、月活医生数、客单价
- **注射剂适用性**：⚠️ 仅限医生端学术传播，禁止患者端推广

### 2. 医药电商（B2C）
- **模式**：旗舰店运营+搜索优化+详情页转化
- **核心策略**：SEO优化（症状词/疾病词）+ 详情页DA设计 + 用户评价管理
- **关键指标**：GMV、转化率、客单价、复购率
- **注射剂适用性**：✅ 可用（但需OTC或DTP资质）

### 3. O2O即时配送
- **模式**：LBS定位->附近药店->30分钟送药
- **核心策略**：药店覆盖密度 + 搜索排名优化 + 促销活动
- **关键指标**：订单密度、履约率、客单价
- **注射剂适用性**：✅ 可用（DTP药房）

### 4. 私域运营
- **模式**：企微加好友->社群运营->小程序复购
- **核心策略**：患者教育内容 + 用药提醒 + 专属优惠 + 医生IP
- **关键指标**：私域用户数、复购率、LTV（客户终身价值）
- **注射剂适用性**：✅ 可用（患者教育+依从性管理）

### 5. 直播/短视频
- **模式**：医生IP直播->科普内容->留资->转化
- **核心策略**：合规科普（不违规）+ 医生IP打造 + 留资转化
- **关键指标**：观看量、留资率、转化率
- **注射剂适用性**：⚠️ 仅限医生端学术直播，禁止患者端推广

### 6. 数字化患者管理
- **模式**：用药提醒->复诊预约->依从性管理->真实世界数据
- **核心策略**：患者APP/小程序 + 医生端数据查看 + 回访计划
- **关键指标**：注册患者数、依从率、复诊率
- **注射剂适用性**：✅ 可用（依从性管理）

## 合规预审SOP（强制 Step 0）

**NRx启动前必须完成，不通过不得输出任何线上推广方案**

| 检查项 | 验证内容 | 验证方法 | 不通过处置 |
|----|----|----|----|
| 剂型核查 | 是否注射剂？ | 查看说明书 | 注射剂->仅限HCP-only学术传播 |
| 同品类先例 | 同类产品有线上推广合规先例？ | 搜索NMPA/行业案例 | 无先例->法规许可验证 |
| 法规许可 | 在广告法/药品管理法许可范围内？ | 法律意见/合规审核 | 超出范围->中止NRx，切换HCP-only |

**注射剂特殊处理**：
- ❌ 禁止在患者端渠道推广（医药电商患者端/O2O/私域/短视频患者端）
- ✅ 仅限医生端学术传播（互联网医院医生端、医学会议直播）
- ✅ 不良反应监测数据收集（RWE）可在数字化患者管理平台

## GMV/ROI 量化评估框架

### GMV预测公式
```
GMV = 流量 × 转化率 × 客单价 × 复购率

流量：渠道月活用户数（MAU）
转化率：浏览->购买转化率
客单价：平均订单金额
复购率：3个月内复购比例
```

### ROI计算
```
ROI = （增量销量 × 毛利率 - 渠道投入） / 渠道投入 × 100%

增量销量：线上渠道带来的额外销量（非自然增长）
毛利率：产品毛利率（考虑VBP后可能对毛利率的影响）
渠道投入：平台扣点+营销费用+团队成本+技术投入
```

## 全渠道协同SOP

### 线上->线下引流
- 线上处方 -> 线下DTP药房取药/注射
- 线上患者教育 -> 线下医院复诊
- 线上医生IP -> 线下学术会参会

### 线下->线上引流
- 线下医院复诊 -> 线上互联网医院续方
- 线下患者教育 -> 线上私域社群
- 线下医生关系 -> 线上医生IP直播

### 数据打通
- CRM系统：整合线上+线下客户数据
- 统一ID：HCP统一ID（线下拜访+线上互动）
- 患者统一ID：线下就诊+线上购药+线上随访
