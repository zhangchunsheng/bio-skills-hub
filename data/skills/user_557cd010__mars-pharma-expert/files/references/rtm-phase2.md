# RTM Phase 2: 策略导出（SWOT->KSF->策略链）

阶段目标：从现状分析导出可执行的区域策略。

## 策略导出工作流

### Step 1: SWOT归纳
从4R+4P3C分析结果中归纳：

| SWOT | 内容 | 数据来源 |
|----|----|----|
| Strengths（优势） | 内部正向因素 | 销量增长/份额领先/KOL支持 |
| Weaknesses（劣势） | 内部负向因素 | 覆盖不足/执行率低/团队能力 |
| Opportunities（机会） | 外部正向因素 | 新指南发布/VBP落地/竞品退出 |
| Threats（威胁） | 外部负向因素 | 竞品新品/VBP降价/政策变化 |

### Step 2: KSF提取（关键成功因素）
从SWOT中提炼3-5个对达成目标最关键的因素：
- KSF必须是可影响的（非完全外部决定）
- KSF必须是可衡量的
- KSF数量3-5个（过多则失去焦点）

### Step 3: 策略链构建
```
目标：[具体可衡量的业务目标，如：Q2销量增长15%]

KSF1：[关键成功因素1，如：提高目标医院处方率]
  -> 策略方向A：加强KOL学术影响
    -> 具体举措：①邀请KOL参与顾问会 ②KOL主导区域研讨会 ③KOL推荐在科室会分享
  -> 策略方向B：优化代表拜访质量
    -> 具体举措：①拜访脚本培训 ②关键处方者高频拜访 ③拜访后24h内跟进

KSF2：[关键成功因素2]
  -> ...
```

### Step 4: SMART检验
- Specific（具体）：策略是否具体明确？
- Measurable（可衡量）：是否有量化KPI？
- Achievable（可实现）：资源和能力是否匹配？
- Relevant（相关）：是否与SQ1-3诊断结果一致？
- Time-bound（有时限）：是否有明确时间表？

## 策略质量评分

| 评分项 | 分值 | 标准 |
|----|----|----|
| 与SWOT对齐 | 25分 | 策略直接从SWOT导出 |
| KSF准确性 | 25分 | KSF确实是关键成功因素 |
| 举措可执行 | 25分 | 举措具体、有负责人、有预算 |
| SMART达标 | 25分 | 所有策略符合SMART |

**总分：100分 | 通过线：70分**
