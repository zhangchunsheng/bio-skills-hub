**2026-06-27**: Research baseline — platform docs, the two API surfaces, pricing, and channel/rate-limit model captured from live sources on this date. Re-verify before relying. Key facts: **two APIs** — (1) current **GraphQL** developer API (`developers.buffer.com`, **Bearer API key** from `https://publish.buffer.com/settings/api`, create posts/drafts + manage channels/orgs + read post metrics/reports + ideas + media; **plan-based rate limits** across 15-min/24-hr/30-day windows, 1–5 API keys/OAuth clients, Free ~100/24h+3k/30d, Team ~500/24h+15k/30d; **beta, free**; **2026-05-25 Assets-Input migration** broke the legacy media format) and (2) **legacy REST v1** (`api.bufferapp.com/1/`, OAuth 2.0 via `bufferapp.com/oauth2/authorize`, auth code valid only 30s, `/profiles.json`/`/updates/create.json`, `access_token` query param, **60 req/user/min**) — being deprecated, migrate to GraphQL. **No webhooks on either API — poll only.** No MCP server. 11 networks: Bluesky, Facebook, GBP, Instagram, LinkedIn, Mastodon, Pinterest, Threads, TikTok, X, YouTube. Modules: Publish, Create (Ideas), Community (engagement, UI-only), Analyze, Collaborate (approvals, Team plan), AI Assistant, Start Page (link-in-bio). **No social listening.** Pricing is **per channel**: Free $0 (3 channels, 10 queued/channel, **lifetime 8-unique-channel-connection cap**), Essentials $5/channel/mo annual ($6 monthly), Team $10/channel/mo annual ($12). Approval workflows + first-comment scheduling + hashtag manager are paid-tier gated. GitHub org `bufferapp` (196 repos). Top complaints: per-channel pricing compounds for agencies, no listening, collaboration gated to Team. No affiliate program confirmed.
