# 新型电池架构与叠层技术指南

## 1. TBC 电池（TOPCon Back Contact）

### 结构设计
TBC 电池将 TOPCon 的全背面钝化接触技术与背接触（BC）电池的叉指电极结构相结合。正面无金属栅线遮挡，全部电极位于背面，通过叉指排列的 n+ 和 p+ Poly-Si 接触区域实现载流子收集。

### 关键工艺挑战
- **背面叉指图形化**：需在背面交替形成 n+ 和 p+ Poly-Si 区域，图形精度要求 <50 μm
- **隔离沟道**：n+ 与 p+ 区域之间需形成隔离沟道，防止短路，沟道宽度 20-50 μm
- **金属化方案**：背面细栅线宽度需控制在 20-30 μm，降低接触面积同时保证导电性
- **正面钝化**：正面需 Al2O3/SiNx 叠层钝化，反射率优化目标 <3%

### 效率潜力
- 相比常规 TOPCon（正面有栅线遮挡 ~3-4% 面积），TBC 可提升 Jsc 3-5%
- 理论效率极限：26.5-27.0%
- 量产效率目标：25.5-26.0%

## 2. TOPBC 电池

### 技术路线
TOPBC 是 TOPCon 与背接触技术的融合路线，在 TOPCon 工艺平台上实现背接触结构。核心思路是利用 TOPCon 已有的 Poly-Si 钝化技术，通过工艺改造实现背面叉指电极。

### 工艺兼容性分析
- 可复用 TOPCon 的 LPCVD/PECVD Poly 沉积设备
- 新增：背面光刻或激光图形化设备、背面金属化精密印刷设备
- 制程步骤增加 3-5 步，量产成本预估增加 15-25%

### 效率潜力评估
- 短期（1-2年）：25.0-25.5%
- 中期（3-5年）：26.0-26.5%
- 长期：与 HJT-BC 路线竞争，取决于工艺成本降低速度

## 3. HTBC 杂化电池

### 结构设计
HTBC 结合 HJT（异质结）的优异钝化性能与 TBC 的背接触结构。正面采用 HJT 的 a-Si:H(i)/a-Si:H(p) 钝化层 + TCO，背面采用叉指排列的 n+ 和 p+ 异质结接触。

### 关键技术要点
- **透明导电层（TCO）选型**：ITO（In2O3:Sn）或 IWO（In2O3:W），需兼顾透光率（>90%@550nm）与方阻（<100 ohm/sq）
- **界面工程**：a-Si:H 本征层厚度 4-8 nm，需精确控制以平衡钝化质量与隧穿效应
- **低温工艺约束**：全流程温度 <200°C，限制了金属化方案（需低温银浆或电镀铜）
- **背面叉指制备**：可采用掩膜刻蚀或激光开孔方案

### 效率潜力
- 理论效率极限：27.0-27.5%
- 量产效率目标：26.0-26.5%
- 主要挑战：工艺复杂度高、设备投资大、良率爬坡周期长

## 4. 叠层电池技术

### 4.1 TOPCon/钙钛矿叠层

#### 结构设计
- 顶电池：钙钛矿吸收层，带隙 1.65-1.73 eV，吸收短波（300-750 nm）
- 底电池：TOPCon 硅电池，带隙 1.12 eV，吸收长波（750-1100 nm）
- 隧道复合结（TCJ）：连接顶电池与底电池，通常采用 ITO/SnO2 或 MoO3/ITO 方案

#### 关键技术参数
- **钙钛矿带隙调控**：Cs0.05(FA0.85MA0.15)0.95Pb(I0.85Br0.15)3，带隙 ~1.68 eV
- **顶电池厚度**：钙钛矿吸收层 400-600 nm，需与底电池电流匹配
- **透明电极**：顶电池需高透 TCO（ITO 或 AZO），方阻 <150 ohm/sq
- **隧道结**：复合结厚度 20-40 nm，需保证载流子高效复合同时光学损失小

#### 电流匹配设计
- 顶电池 Jsc 目标：14-16 mA/cm2
- 底电池 Jsc 目标：14-16 mA/cm2
- 叠层 Jsc 取较小值，典型 13-15 mA/cm2
- 叠层 Voc = 顶电池 Voc + 底电池 Voc - 复合结损失，典型 1.85-1.95 V

#### 效率潜力
- 实验室目标：30-33%
- 量产化挑战：大面积均匀性、长期稳定性、铅泄漏防护

### 4.2 HJT/钙钛矿叠层

#### 技术特点
- HJT 底电池具有更低的表面复合速率（<5 cm/s），提供更高的底电池 Voc
- HJT 的低温工艺（<200°C）与钙钛矿的低温工艺兼容性更好
- 顶电池与底电池的界面复合层设计更灵活

#### 关键差异（vs TOPCon叠层）
| 参数 | TOPCon/钙钛矿叠层 | HJT/钙钛矿叠层 |
|------|-------------------|----------------|
| 底电池 Voc | 690-710 mV | 730-750 mV |
| 底电池工艺温度 | 800-900°C（高温） | <200°C（低温） |
| 界面复合层 | 需高温兼容 | 低温兼容 |
| 叠层 Voc | 1.85-1.95 V | 1.90-2.00 V |
| 量产成本 | 较低（TOPCon产线成熟） | 较高（HJT设备投资大） |

### 4.3 p-HJT 叠层

#### 技术路线
p-HJT 作为底电池，与 n-HJT 路线相比有以下差异：
- **钝化机制**：p-HJT 的 p/n 异质结界面隧穿效率不同，需优化 a-Si:H(p) 层厚度与掺杂浓度
- **效率潜力**：p-HJT 底电池 Voc 略低于 n-HJT（720-740 mV vs 730-750 mV），但工艺更简化
- **工艺复杂度**：p-HJT 可省去部分背面 TCO 沉积步骤，降低制造成本
- **叠层适配性**：p-HJT 与钙钛矿顶电池的能带匹配需额外优化界面层

### 4.4 叠层关键共性技术

#### 宽带隙钙钛矿组分调控
- 目标带隙：1.65-1.73 eV
- 组分方案：Cs-FA-MA 三元体系，Br/I 比例 0.15-0.25
- 相稳定性：需控制 Cs 含量（5-10%）抑制相分离
- 缺陷钝化：添加 MACl 或 Pb(SCN)2 等添加剂减少深能级缺陷

#### 界面钝化
- 钙钛矿/ETL 界面：使用 C60/SnO2 或 TiO2，需优化界面缺陷态密度
- 钙钛矿/HTL 界面：使用 Spiro-OMeTAD 或 PTAA，关注空穴提取效率
- 界面偶极子工程：2D/3D 钙钛矿界面钝化层提升开路电压

#### 光管理
- 绒面匹配：底电池绒面金字塔（5-10 μm）与顶电池平面工艺的兼容性
- 减反膜设计：顶电池 MgF2 或 LiF 减反层，反射率目标 <5%
- 光学耦合层：TCJ 区域的光学损失优化，目标透射率 >90%

#### 机械稳定性
- 热膨胀匹配：钙钛矿与硅的热膨胀系数差异导致界面应力
- 封装方案：柔性封装材料缓解热应力，避免叠层结构剥离

## 5. 太空光伏技术

### 空间辐射衰减机制
- **位移损伤**：高能质子/电子在晶格中产生缺陷，形成深能级复合中心
- **电离损伤**：高能粒子在钝化层/介质层中产生电荷俘获，导致钝化退化
- **衰减规律**：典型 LEO 轨道（400-800 km）1 年衰减 5-15%，GEO 轨道 1 年衰减 3-8%

### 抗辐射电池结构设计
- **薄型化设计**：电池厚度 80-120 μm（vs 地面 130-150 μm），减少粒子穿透路径
- **倒置结构**：将活性结区远离入射面，降低正面辐射损伤
- **特殊钝化层**：Al2O3/SiO2 叠层钝化，具有自愈特性（退火恢复 50-70%）
- **盖片保护**：Cerium-doped 玻璃盖片（100-300 μm）阻挡大部分粒子

### III-V 族与硅基空间电池对比
| 参数 | GaAs/Ge 多结 | 硅基空间电池 |
|------|-------------|-------------|
| 效率（BOL） | 28-32% | 18-22% |
| 效率（EOL） | 24-28% | 14-18% |
| 比功率 | 150-250 W/kg | 100-150 W/kg |
| 成本 | 极高 | 中等 |
| 适用轨道 | LEO/GEO/深空 | LEO（近地轨道） |

### 轨道参数评估方法
- **LEO（低地球轨道）**：以质子辐射为主（南大西洋异常区），需重点评估 1-10 MeV 质子衰减
- **GEO（地球同步轨道）**：以电子辐射为主（外辐射带），需评估 1-10 MeV 电子衰减
- **深空探测**：需考虑太阳耀斑事件（SPE）的极端辐射剂量，电池需冗余设计

### 寿命预测方法
1. 根据轨道参数计算辐射等效 1 MeV 电子注量（fluence）
2. 使用 JSC/NIEL 模型将实际粒子能谱转换为等效 1 MeV 电子损伤
3. 查找 Remaining Factor 曲线（Pmax/Pmax0 vs fluence），估算 EOL 功率
4. 结合温度循环（-80°C 到 +100°C）评估热疲劳寿命
