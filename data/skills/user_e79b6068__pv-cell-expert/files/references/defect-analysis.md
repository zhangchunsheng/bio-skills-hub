# 产线不良分析与表征指南

## 1. EL（电致发光）分析

### EL 成像原理
EL 成像通过给电池片施加正向偏压，使 P-N 结注入载流子复合发光（波长 ~1150 nm），用红外相机捕捉发光图像。发光强度与局部少子寿命和结质量正相关，缺陷区域表现为暗区。

### 常见不良模式与根因分析

#### 1.1 黑斑（局部暗区）
- **特征**：EL 图像中局部圆形或不规则暗斑，直径 1-20 mm
- **根因排查**：
  - 硅片体缺陷：氧沉淀/COP/夹杂物 → 检查硅片来源与氧含量
  - 局部复合中心：金属污染（Fe/Cu/Ni）→ SIMS/ICP-MS 分析
  - 接触不良：局部银浆烧结不足或 LECO 欠加工 → 检查烧结曲线与 LECO 参数
  - 颗粒污染：制绒/扩散工序颗粒附着 → 检查洁净度与过滤系统
  - 钝化局部退化：SiNx 针孔或 Al2O3 涂覆不均 → 检查 PECVD/ALD 均匀性

#### 1.2 黑边（边缘暗区）
- **特征**：电池片边缘 1-5 mm 范围内 EL 强度减弱
- **根因排查**：
  - 边缘复合：切割损伤引入边缘缺陷 → 检查切割工艺（激光切割 vs 机械切割）
  - 边缘钝化不足：PECVD 边缘绕镀不均或掩膜偏移 → 检查石墨舟遮挡设计
  - 扩散边缘效应：磷扩散边缘浓度梯度 → 优化扩散气流量与温度均匀性
  - 金属接触边缘效应：边缘栅线接触不良 → 检查丝网印刷对准精度

#### 1.3 黑片（大面积暗区）
- **特征**：整片或大面积区域 EL 强度极低
- **根因排查**：
  - 严重钝化退化：退火/烧结温度异常导致氢逸出 → 检查温度曲线 SPC
  - 扩散异常：磷浓度偏低或结深不足 → 检查扩散方阻 SPC
  - 大面积污染：制绒槽液污染或清洗不良 → 检查槽液浓度与更换周期
  - 电池短路：并联电阻 Rsh 极低 → 检查隔离沟道/边缘刻蚀质量

#### 1.4 网纹/隐裂
- **特征**：EL 图像中出现细线状暗纹，呈直线或网状分布
- **根因排查**：
  - 硅片原生隐裂：来料检测（红外透射/超声扫描）
  - 加工应力：搬运/传输/丝网印刷/烧结工序引入 → 检查传输带与印刷压力
  - 热应力：烧结温区温差过大 → 优化烧结曲线升降速率
  - LECO 热应力：激光局部加热导致微裂纹扩展 → 优化激光功率与扫描路径

#### 1.5 断栅
- **特征**：沿栅线方向的线状暗区
- **根因排查**：
  - 丝网印刷缺陷：网版堵塞/浆料不足 → 检查网版使用寿命与浆料粘度
  - 栅线宽度不均：印刷压力不均 → 检查刮刀压力与网版张力
  - 烧结不足：局部银浆未形成良好欧姆接触 → 优化烧结曲线
  - LECO 未覆盖：激光扫描漏区 → 检查扫描对准与覆盖率

#### 1.6 烧结异常
- **特征**：EL 图像中出现区域性亮度异常（过亮或过暗）
- **根因排查**：
  - 过烧：局部温度过高导致结退化/银浆烧穿 → 检查烧结炉温区均匀性
  - 欠烧：银浆玻璃料未充分熔融，接触电阻高 → 优化峰值温度与带速
  - 温区偏移：烧结炉链速变化或温度漂移 → 加强 SPC 管控

### EL 不良分析流程
```
EL 不良图像
  ├─ 识别不良模式（黑斑/黑边/黑片/隐裂/断栅/烧结异常）
  ├─ 定位不良位置（片内分布/边缘/中心）
  ├─ 批次统计（偶发 vs 批量）
  ├─ 关联工序（制绒/扩散/PECVD/印刷/烧结/LECO）
  ├→ 缩小排查范围
  ├→ 交叉验证（PL/Suns-Voc/方阻/外观）
  └→ 根因定位与改善方案
```

## 2. PL（光致发光）分析

### PL 成像原理
PL 成像通过激发光（通常 808 nm 激光或 LED 阵列）照射电池片表面，激发载流子复合发光（~1150 nm），用红外相机捕捉。与 EL 不同，PL 不需要外加偏压，可以在电池完成金属化前进行检测。

### PL 应用场景

#### 2.1 钝化质量评估
- PL 强度与表面钝化质量正相关，可用于：
  - 评估 SiNx/Al2O3 钝化层质量
  - 比较不同钝化方案（退火前/后对比）
  - 检测钝化层均匀性（CV <5% 为优）

#### 2.2 少子寿命面分布
- 通过 PL 强度校准获得有效少子寿命分布图
- 识别低寿命区域（<100 μs）作为重点排查对象
- 典型 TOPCon 电池少子寿命目标：>1 ms（正面钝化后）

#### 2.3 界面钝化均匀性
- PL 图像的均匀性反映界面钝化质量
- 不均匀性来源：PECVD 沉积不均、扩散方阻不均、退火温度不均
- 目标 PL 强度 CV（变异系数）<5%

#### 2.4 工艺前后对比
- 制绒后 PL：评估硅片本体质量
- 扩散后 PL：评估扩散结质量
- 钝化后 PL：评估钝化层质量
- 烧结后 PL：评估烧结对钝化的影响

## 3. 外观不良分析

### 3.1 色差
- **成因**：PECVD SiNx 膜厚不均（目标 75-80 nm）、折射率偏差（目标 2.05-2.10）
- **排查**：椭偏仪测量膜厚/折射率面分布，检查 PECVD 均匀性
- **改善**：优化气流量分布、石墨舟间距、沉积温度均匀性

### 3.2 水纹
- **成因**：制绒绒面不均匀、PECVD 沉积过程中气体流动方向性
- **排查**：SEM 观察绒面形貌、检查制绒槽液浓度与反应时间
- **改善**：优化制绒工艺（KOH/IPA/添加剂比例）、调整 PECVD 气流设计

### 3.3 翘曲
- **成因**：双面应力不平衡（正面 SiNx vs 背面 Poly/SiNx 应力差异）
- **排查**：测量翘曲量（目标 <0.5 mm）、分析各层薄膜应力
- **改善**：调整 SiNx 拉应力与 Poly 压应力的平衡、优化膜厚组合

### 3.4 碎片
- **成因**：硅片强度不足、加工应力（切割/搬运/印刷/烧结）
- **排查**：统计碎片位置与工序分布、检查硅片来料强度
- **改善**：优化传输带设计、降低印刷压力、控制烧结温区温差

### 3.5 脱膜/气泡
- **成因**：PECVD 膜层附着力不足、界面污染
- **排查**：检查界面清洗质量、PECVD 预热除水效果
- **改善**：增加 RCA 清洗/臭氧清洗、优化 PECVD 预热温度

## 4. 综合表征手段

### 4.1 Suns-Voc（准稳态光导）
- **用途**：测量少子寿命、暗饱和电流 J0、隐含 Voc
- **优势**：无需完成金属化即可评估电池钝化质量
- **典型参数**：TOPCon 电池隐含 Voc >710 mV，J0 <15 fA/cm2

### 4.2 量子效率（IQE/EQE）
- **用途**：分析不同波长范围的载流子收集效率
- **解读**：
  - 短波（300-500 nm）→ 正面发射极质量
  - 中波（500-800 nm）→ 体内少子寿命
  - 长波（800-1100 nm）→ 背面钝化质量
- **典型 IQE 目标**：@400nm >75%，@600nm >95%，@900nm >85%

### 4.3 少子寿命测量
- **μ-PCD（微波光电导衰减）**：面分布扫描，分辨率 ~1mm，适合产线监控
- **WCT-120（准稳态光电导）**：绝对寿命测量，适合实验室精确分析
- **典型目标**：TOPCon 硅片（制绒后）>500 μs，钝化后 >1 ms

### 4.4 SIMS（二次离子质谱）
- **用途**：元素深度分布分析（磷/硼/氢/氧/碳/金属杂质）
- **应用场景**：
  - 扩散结深与浓度分布验证
  - Poly-Si 中磷浓度梯度分析
  - 界面杂质（Fe/Cu/Ni）检测
  - 钝化层氢含量分析

### 4.5 SEM/EDS（扫描电镜/能谱）
- **用途**：表面/断面形貌观察 + 元素成分分析
- **应用场景**：
  - 绒面形貌评估（金字塔尺寸/覆盖率/均匀性）
  - Poly-Si 膜层厚度与界面质量
  - 银浆烧结形貌（银-硅接触、玻璃料分布）
  - 异常区域断面分析（隐裂路径/分层界面）

### 4.6 其他表征手段
- **AFM（原子力显微镜）**：表面粗糙度测量（Ra 目标 <10 nm for SiNx）
- **台阶仪**：薄膜厚度测量（精度 ~1 nm）
- **四探针方阻仪**：扩散层/Poly 层方阻测量（精度 <2%）
- **椭偏仪**：薄膜厚度与折射率测量（SiNx: n=2.05-2.10, d=75-80nm）

## 5. 不良分析综合策略

### 分层排查法
```
Layer 1: 硅片来料
  → 氧含量/电阻率/少子寿命/COP密度/隐裂检测
  ↓
Layer 2: 制绒
  → 绒面形貌/反射率/重量损失/PL 强度分布
  ↓
Layer 3: 扩散
  → 方阻均匀性/结深/表面浓度/PL 强度变化
  ↓
Layer 4: 钝化（PECVD/ALD）
  → 膜厚/折射率/钝化质量(PL/Suns-Voc)/均匀性
  ↓
Layer 5: 金属化（印刷/烧结/LECO）
  → 栅线形貌/接触电阻/EL 图像/串联电阻
  ↓
Layer 6: 成品测试
  → IV 参数/EL 全检/外观检测/分级统计
```

### 数据驱动决策
- 每日 EL 不良统计需按模式分类追踪趋势（SPC 控制图）
- 批量不良（>3% 突增）需启动 8D 报告流程
- 偶发不良（<0.5%）需建立不良图谱库，定期分析共性根因
- 交叉验证：EL + PL + Suns-Voc + IV 数据综合分析，避免单一手段误判
