# TOPCon 电池工艺开发详细指南

## 1. LP 双插（Low Pressure 双面 PECVD Poly 沉积）

### 工艺原理
LP 双插是指在低压 PECVD 设备中，通过双面沉积方式在硅片正面和背面同时生长 Poly-Si 钝化层。核心目标是在背面形成高质量的 n+ Poly-Si 钝化接触，同时在正面控制 Poly 沉积以避免遮光损失。

### 关键工艺参数
- **沉积温度**：580-620°C，温度过高导致多晶硅晶化度增大、钝化退化；温度过低则非晶硅含量高，后续退火后膜层质量下降
- **沉积压力**：0.5-2.0 Torr，低压有助于提高膜层均匀性但降低沉积速率
- **气体比例**：SiH4 / PH3 / H2，典型 SiH4 流量 100-300 sccm，PH3/SiH4 比例 0.5%-2%
- **膜厚控制**：背面 Poly 80-150nm，正面需控制在 20nm 以下以避免遮光
- **退火温度**：800-900°C，实现 Poly-Si 晶化与磷激活

### 常见量产问题
- **膜厚一致性差**：检查石墨舟位偏移、气流量分布、温度均匀性（目标片内均匀性 <3%，片间 <5%）
- **绕镀问题**：优化石墨舟遮挡设计，控制正面 Poly 厚度在可接受范围
- **气泡/脱膜**：检查界面清洗质量（RCA/臭氧清洗）、沉积前预热除水
- **钝化退化**：排查退火温度曲线、磷浓度梯度设计

## 2. SE 激光掺杂（Selective Emitter）

### 工艺原理
通过激光选择性加热硅片表面，促进磷源在金属栅线下方区域快速扩散形成重掺杂区（低方阻 ~40-60 ohm/sq），而栅线间保持轻掺杂（高方阻 ~80-120 ohm/sq），实现选择性发射极结构。

### 关键工艺参数
- **激光波长**：532nm（绿光）或 1064nm（红外），绿光吸收更浅适合浅结掺杂
- **激光功率**：8-15W，需根据磷源浓度和扩散深度精确调节
- **扫描速度**：5000-15000 mm/s，速度越快热影响区越小但掺杂深度越浅
- **光斑直径**：30-50 μm，需与栅线宽度匹配
- **掺杂源**：POCl3 预沉积或旋涂磷酸（H3PO4），浓度 2-5%
- **方阻目标**：重掺杂区 40-60 ohm/sq，轻掺杂区 80-120 ohm/sq

### 优化方向
- 结深控制：目标 0.5-1.0 μm，过深影响蓝光响应，过浅导致接触电阻增大
- 掺杂浓度梯度：优化激光参数实现平滑过渡，避免死层效应
- 与金属化工艺匹配：确保激光掺杂图形与丝网印刷栅线对准精度 <10 μm
- 效率增益：典型提升 0.1-0.3% 绝对效率

## 3. 背 Poly Finger

### 工艺原理
在 TOPCon 电池背面钝化层中，通过图形化方式开设指状接触区域，使 Poly-Si 仅在金属接触位置形成局部重掺杂，而非全背面覆盖。这样可以在保持钝化质量的同时降低金属接触复合。

### 关键设计参数
- **Finger 宽度**：20-40 μm，过宽增加复合，过窄增加接触电阻
- **Finger 间距**：1.0-2.0 mm，与背面金属栅线间距匹配
- **开孔比例**：3%-8%，在接触电阻与复合速率之间取得平衡
- **Poly 厚度**：80-120 nm（接触区域），需保证足够的磷掺杂浓度

### 工艺方案
- 方案一：激光开孔 + 局部 Poly 沉积（精度高但成本增加）
- 方案二：掩膜刻蚀 + 选择性沉积（工艺复杂度高但适合量产）
- 方案三：全背 Poly 沉积 + 局部激光退火（简化工艺但钝化均匀性需验证）

### 效果评估
- 背面复合速率降低 20-40%
- 开路电压（Voc）提升 2-5 mV
- 填充因子（FF）提升 0.3-0.8%

## 4. 正面局部 PN 结

### 工艺原理
在电池正面通过局部重掺杂与轻掺杂区域协同设计，优化正面量子效率与钝化效果。重掺杂区域位于金属栅线下方降低接触电阻，轻掺杂区域在栅线间减少表面复合。

### 关键工艺参数
- **重掺杂区方阻**：50-70 ohm/sq，结深 0.3-0.5 μm
- **轻掺杂区方阻**：100-150 ohm/sq，结深 0.1-0.2 μm
- **掺杂源**：POCl3 液态源扩散或磷浆料丝网印刷
- **掩膜方案**：SiNx 或 SiO2 作为扩散掩膜，激光开孔或光刻定义图形

### 优化要点
- 结深梯度控制：避免重掺杂区死层效应，确保短波响应
- 表面浓度调控：重掺杂区表面浓度 >1E20 cm-3，轻掺杂区 <5E19 cm-3
- 过渡区设计：优化重掺杂到轻掺杂的过渡宽度（<10 μm），减少界面复合
- 与 SE 激光掺杂的协同：可与 SE 工艺结合，进一步提升正面效率

## 5. LECO 技术（Laser Enhanced Contact Optimization）

### 工艺原理
LECO 是一种激光增强接触优化技术，通过特定波长的激光照射已烧结的电池表面，在金属电极与硅基底之间形成局部高温区域，促进银浆中的玻璃料熔融与银-硅合金反应，从而降低接触电阻、提升填充因子（FF）。与传统烧结相比，LECO 允许使用更低温度的烧结曲线，减少对钝化层的热损伤。

### 关键工艺参数
- **激光波长**：808nm 或 980nm（近红外），穿透银浆到达硅表面
- **激光功率**：5-12W，需精确控制以避免钝化层损伤
- **光斑直径**：200-500 μm，覆盖整个栅线宽度
- **扫描方式**：沿栅线方向连续扫描，速度 100-500 mm/s
- **扫描次数**：1-3 次，多次扫描可进一步降低接触电阻但增加热应力风险
- **浆料匹配**：需使用 LECO 专用银浆，玻璃料组分与激光波长吸收匹配

### 与传统烧结的对比
| 参数 | 传统烧结 | LECO 工艺 |
|------|---------|-----------|
| 烧结峰值温度 | 780-820°C | 700-740°C（降低 60-80°C） |
| 接触电阻 | 3-8 mohm·cm2 | 1-3 mohm·cm2 |
| FF（填充因子） | 82.5-83.5% | 84-85.5% |
| 钝化退化风险 | 较高（高温导致氢逸出） | 较低（低温烧结保护钝化） |
| 效率增益 | 基准 | +0.15-0.3% 绝对效率 |

### 量产化关键挑战
- **激光均匀性**：大面积扫描需保证功率均匀性 <3%，避免局部过烧或欠烧
- **浆料-激光匹配验证**：不同银浆厂商的玻璃料组分差异大，需逐一验证激光参数窗口
- **EL 良率监控**：LECO 后需全检 EL，排查局部过烧导致的暗斑或烧穿
- **设备节拍**：LECO 增加一道工序，需评估对产线产能的影响（典型增加 0.3-0.5 s/片）
- **工艺窗口窄**：功率偏差 5% 即可能导致效果不达标或损伤电池，需严格 SPC 管控

### 典型不良与排查
- **LECO 后 EL 黑斑**：排查激光功率局部异常、浆料印刷偏移、烧结曲线偏差
- **FF 未提升**：检查激光波长与浆料匹配性、扫描速度过快导致能量不足
- **Voc 下降**：激光功率过高导致钝化层退化，降低功率或减少扫描次数
- **碎片率上升**：激光热应力导致隐裂扩展，优化光斑均匀性与扫描路径
