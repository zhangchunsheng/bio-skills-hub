# 医学影像技术专业科目 · 出题规范与解析格式

> 用途：定义"如何出题、如何判分、如何解析"的规范，供技能按大纲生成练习题时参照。

## 一、出题规范

1. **题目格式**：题干 + 选项 A/B/C/D（或 A-E），单选四选一、多选五选多、判断正确选A错误选B。
2. **答案格式**：`【答案】X。解析：……`，解析须说明"考查知识点 + 解题依据 + 易错点"。
3. **否定词提示**：题干含"不正确 / 不属于 / 不包括"等否定词时，解析中须强调"注意选非项"。
4. **判分规则**：
   - 判断题：正确选 A、错误选 B，答对得满分。
   - 单选题：答对得满分，答错得 0 分。
   - 多选题：错选或多选不得分；少选且所选均正确的，每个正确项得 0.3 分。
5. **专业性要求**：题目须基于专业科目官方大纲与常见考点；**不确定的内容必须标注"建议核对官方教材"，不得编造权威数据**。

## 二、出题质量红线

1. **不编造权威数据**：若无法确认标准答案，宁可不出该题，并提示"建议核对官方教材"，不得凭感觉编造。
2. **计算题可验算**：数学、统计等计算题必须能通过明确公式/步骤验算出唯一答案。
3. **选项无歧义**：四个（或五个）选项互斥，正确答案唯一（多选除外）。
4. **解析完整**：每道题须附"考点 + 依据 + 易错点"三段式解析。
5. **定位为练习**：题目为 AI 按大纲生成的练习，正式考试以官方真题为准。
