# 我的基金经理 Skill

> 🎯 全市场基金经理投资风格蒸馏与复刻工具
>
> 覆盖公募4273+人（东方财富）+ 私募24万+产品（AMAC），配置最多100名经理，
> 自动蒸馏投资风格DNA -> 第一人称答疑 -> 策略复刻 -> 表格导出 -> 定期刷新。
> 内置2025-2026知名经理种子库（80位）一键导入，支持智能增量更新。

## ✨ 核心功能

- 🔍 **全市场搜索**：支持公募（东方财富4273+人）+ 私募（AMAC 24万+产品）+ QDII，按姓名/产品/公司/管理人名搜索，自动标注类型（🏆公募/📈私募）
- 🌱 **知名经理种子库**：内置2025-2026年80位知名基金经理（公募明星30/私募百亿20/QDII海外15/当红15四分类），一键导入到名单
- 🧬 **投资风格蒸馏**：季报官腔->人话 + 思维DNA提炼，两级引擎自动fallback（对话LLM->规则）
- 📊 **十大重仓聚合**：跨所有管理产品获取最新重仓股/债券/基金，去重排序
- 📈 **业绩数据**：近1月/3月/6月/1年/3年/今年以来收益率 + 管理费率
- 🗂️ **名单管理**：最多100名经理，支持新增/删除/查看/种子库导入
- 📤 **表格导出**：Excel（4个sheet）或CSV，一键导出名单/风格/重仓/业绩
- 🔄 **三种更新模式**：智能增量（smart_update，变化检测）/ 全量（update_all）/ 过期（stale），自动bump版本
- 💬 **经理口吻答疑**：以基金经理第一人称回答问题
- 🎯 **策略复制**：基于风格DNA定制/复制基金产品

### 🆕 v2.0.0 三大能力层

**🗣️ 言论能力（Sub-Skill E）**
- 言论风格指纹：句长偏好 / 第一人称密度 / 数据驱动倾向 / 确定性程度
- 观点时序追踪：每期 JSONL 记录 + 立场漂移检测（看多→看空报警）
- 多轮对话记忆：Jaccard 检索相似历史问答，避免重复回答

**🎯 投资能力（Sub-Skill F）**
- 4 维能力评分：选股 35% + 择时 25% + 风控 20% + 稳定 20% → composite 0-100
- 业绩归因：简化 Brinson 模型，拆解为行业暴露 + 选股超额 + 择时 三项贡献
- 风险调整收益：最大回撤估算 + 夏普 + Calmar + Sortino

**📐 投资风格（Sub-Skill G）**
- 6 维风格雷达：价值/成长 · 大盘/中小盘 · 动量 · 质量 · 集中度 · 换手率
- 风格漂移检测：跨期 Euclidean 距离 > 15 自动报警
- 同风格聚类：纯 Python KMeans + 余弦相似度，找出风格最相似的 5 位经理
- 季度调仓追踪：自动快照 + 换手率 + 新增/退出个股

## 🚀 4步上手

### 第1步：一键导入知名经理（可选）
直接说：
```
导入2025-2026知名基金经理种子库
```
或者执行命令一键导入全部80位知名经理：
```bash
python scripts/famous_manager_importer.py import_all
```
也可按分类导入（如只导入公募明星）：
```bash
python scripts/famous_manager_importer.py import_category 公募明星
```

### 第2步：抓取全量数据并蒸馏
```
智能更新数据
```
或执行命令（首次会全部视为变化，等价于全量抓取+蒸馏）：
```bash
python scripts/monthly_updater.py smart_update
```

### 第3步：查看或导出
```
张坤的十大重仓是什么
导出我的基金经理名单
```

### 第4步（可选）：添加自定义经理
```
跟踪张坤
```
或者：
```
添加易方达蓝筹精选的基金经理
```
如果有多位同名/相似经理，我会反问确认。

## 🔧 蒸馏引擎

两级 fallback，适配任意环境：

| 引擎 | 说明 | 依赖 |
|------|------|------|
| 对话LLM（优先） | 用当前对话的大模型蒸馏，质量最高 | 零安装 |
| 规则引擎（fallback） | 关键词/持仓打标签，最轻量 | 零依赖 |

## 🔄 三种更新模式

| 模式 | 命令 | 适用场景 | 耗时 |
|------|------|---------|------|
| 🎯 智能增量（推荐） | `smart_update` | 日常定期维护，变化检测4维度（规模±10%/重仓变动/新季报/业绩±5%） | 最短 |
| 📦 全量更新 | `update_all` | 季度末大刷新/首次初始化 | 最长 |
| ⏰ 过期更新 | `stale [天数]` | 按时间阈值兜底（默认30天） | 中等 |

**新增维护 vs 增量维护：**
- 新增维护：`import_and_fetch <姓名>` 或 `add` + `update_one`，把新经理加入名单并初始化档案
- 增量维护：`smart_update`，对名单中已有经理定期刷新

## ⚠️ 数据时效说明

| 数据类型 | 实际滞后 | 说明 |
|---------|---------|------|
| 基金净值 | T+1~T+2 | 估算值，非精确 |
| 十大重仓 | 季度末后4-8周 | 每季度更新 |
| 经理档案 | 实时 | 任职/离职状态 |
| 业绩数据 | T+1~T+2 | 近1月/6月/1年/3年 |

**所有数据仅供辅助参考，不构成投资建议。**

## 🔄 自我迭代

- smart_update 变化日志记录在 `data/change_log/` 便于追溯
