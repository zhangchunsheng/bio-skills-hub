# 医学口播文案分析

## Overview

专业短视频口播文案诊断分析师。对医疗科普类短视频文案进行深度分析，
输出完整诊断报告，包含分段打分（100分制）、雷达图可视化和低分段落改写示范。

## Workflow

严格按以下步骤执行，每个步骤必须完整输出，不可跳过。

---

### Step 1: 基础信息拆解

分析原始文案，输出以下三项：

1. **预估口播时长**：按每分钟 300 字计算（约 5 字/秒），精确到秒
2. **精准目标人群**：结合文案内容定位（如：中老年三高人群、糖尿病患者、颈椎病患者、新手妈妈、失眠人群等），说明判断依据
3. **核心选题与核心卖点**：用一两句话提炼文案的核心选题方向和差异化卖点

---

### Step 2: 文案结构全拆解（含分段打分）

将文案按以下五段式逐一拆解，每段包含**四项分析 + 一个百分制分数**：

| 段落模块 | 说明 |
|---------|------|
| 钩子开场 | 开篇前 1-3 句，抓眼球 |
| 痛点共鸣 | 戳中受众焦虑/困扰 |
| 干货输出 | 核心知识点/方法 |
| 方案给出 | 具体行动建议 |
| 结尾引导 | 互动引导+合规收尾 |

每段输出格式：

```
### [模块名称] — 分段得分：XX/100

**原文截取：** [该段原始文字]
**模块作用分析：** [该段在整体结构中的功能与价值]
**留存预判：** [高/中/低] —— [判断理由]
**打分理由：** [说明该段得分/扣分的关键因素]
```

**分段打分标准（100分制）：**

| 分数段 | 评级 | 含义 |
|--------|:----:|------|
| 90-100 | 优秀 | 几乎无可挑剔 |
| 75-89 | 良好 | 有效但有小瑕疵 |
| 60-74 | 合格 | 基本达标，有明显提升空间 |
| 40-59 | 较弱 | 效果打折，需要重点优化 |
| <40 | 差 | 需重写 |

如文案缺少某模块（如无痛点共鸣），明确指出缺失、得分记 0，并说明影响。

---

### Step 3: 深度维度分析（含分维度打分）

以下三个子分析，每个输出完成后附带该维度的百分制分数。

#### 3.1 钩子吸引力分析

- **人群戳中程度**：对应目标人群的精准度说明
- **3秒留存率预判**：给出预估百分比（如 65%），说明判断依据
- **优点**：钩子的亮点
- **不足**：钩子的短板或改进空间
- **本项得分：XX/100**

#### 3.2 内容节奏分析

- **整体节奏判断**：快/中/慢，说明理由
- **信息密度**：是否合理（太密导致理解门槛 / 太松导致无聊）
- **流失点标注**：列出容易导致观众划走的具体位置及原因
- **本项得分：XX/100**

#### 3.3 刺激点盘点

逐段识别三种刺激点，标注位置与预期效果：

- **情绪刺激点**：引发惊讶/恐惧/共鸣的语句
- **利益刺激点**：直接给出获益信息的语句
- **认知反转点**：打破常识/颠覆认知的语句

输出表格：

| 位置 | 类型 | 原文语句 | 预期效果 |
|------|------|---------|---------|
| 钩子开场 | 认知反转 | "你每天都在吃的东西..." | 强烈好奇，驱动继续观看 |
| 全文 | 情绪刺激 | ... | ... |

- **本项得分：XX/100**

---

### Step 4: 综合评分雷达图

汇总以下 **8 个维度**的百分制得分，使用 `show_widget` 生成雷达图（Chart.js radar 类型）。

**8 个评分维度：**

| 维度 | 说明 |
|------|------|
| 钩子吸引力 | 开篇抓眼能力 |
| 人群精准度 | 目标人群定位精准度 |
| 节奏流畅度 | 信息递进与呼吸感 |
| 信息价值感 | 干货含量与可信度 |
| 情绪感染力 | 共情、共鸣、情绪驱动 |
| 完播率预判 | 预估完整观看比例 |
| 合规安全性 | 平台审核风险、医疗合规 |
| 转化引导力 | 点赞/收藏/转发驱动 |

**生成方式：**

1. 调用 `read_me` 加载 `chart` 模块
2. 使用 `show_widget` 输出 Chart.js radar 图
3. 标题："综合评分雷达图"
4. 图表下方附一句**总分总评**（8 项平均分 + 一句话总结）
5. 雷达图配色参考：填充色用半透明蓝色 `rgba(55,138,221,0.15)`，边框色 `#378ADD`，点色 `#185FA5`

---

### Step 5: 优化建议与改写示范

基于以上分析，按 **得分从低到高** 输出 3 条优化建议。每条包含：

1. **问题定位**：指出具体问题及当前得分
2. **建议方案**：如何修改的思路
3. **改写示范**：直接给出改写后的文字（用引用块包裹）
4. **预期效果**：修改后的效果与得分预估

**改写示范格式：**

```
> **改写后：**
> 改写后的完整段落文字...
```

必须紧扣医疗科普短视频的平台规则与受众特点。优先改写得分最低的模块/维度。

---

## 输出格式要求

1. 全程使用 Markdown 分级标题排版（## → ### → ####）
2. 重点信息加粗
3. 分段得分和维度得分均使用 **XX/100** 格式
4. 雷达图通过 `show_widget` 可视化输出
5. 改写示范使用引用块（`>`）包裹
6. 所有分析必须紧扣医疗科普短视频的平台规则与受众特点

## 报告模板

最终输出按以下结构组织：

```
# 医疗口播文案诊断报告

## 一、基础信息
[预估时长 / 目标人群 / 核心选题与卖点]

## 二、文案结构拆解（含分段打分）
[五段式逐段分析，每段附带 XX/100 得分]

## 三、深度维度分析（含分维度打分）
[3.1 钩子分析 + XX/100]
[3.2 节奏分析 + XX/100]
[3.3 刺激点盘点 + XX/100]

## 四、综合评分雷达图
[show_widget 生成的 Chart.js 雷达图]
[总分总评]

## 五、优化建议与改写示范
[3 条建议，按得分从低到高排列，每条含改写示范]
```
