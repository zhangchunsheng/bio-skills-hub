## 关键里程碑

### 1. CS231n 课程创建（2015）
斯坦福首门深度学习课程，Karpathy 设计并主讲。课程成为计算机视觉领域最具影响力的入门课程，培养了整一代 AI 从业者。选课人数从150人（2015）爆炸增长至750人（2017）。

### 2. OpenAI 创始成员（2015-2017）
作为11位创始成员之一加入 OpenAI，帮助塑造机构早期研究方向。这一时期 OpenAI 的工作直接影响了后续 GPT 系列模型的发展。

### 3. Tesla 视觉栈架构（2017-2022）
领导 Tesla Autopilot 视觉团队，推动"纯视觉"（vision-only）路线——移除雷达与超声波传感器，完全依赖摄像头+神经网络。构建了全球最大的真实世界 AI 训练运营体系之一。

### 4. Software 2.0 范式提出（2017）
发表《Software 2.0》博客，提出"软件1.0=手写代码，软件2.0=神经网络权重定义的程序"的核心框架，成为 AI 时代最具影响力的思想之一。

### 5. State of GPT 演讲（2023）
在 Microsoft Build 2023 的系统讲解 GPT 训练全流水线（预训练→SFT→RLHF），是业界最清晰的 LLM 训练科普内容，数百万次观看。

### 6. Eureka Labs 创立（2024）
离开 OpenAI 后创立 AI 原生教育平台，首款产品 LLM101n 旨在指导学生从头训练自己的 AI 模型。标志其将教育作为核心使命的决心。

### 7. Vibe Coding 概念提出（2025）
定义了一种新的编程范式：以自然语言描述意图，由 AI 编码工具完成实现。引发全球编程社区广泛讨论，重新定义了人机协作模式。

### 8. Software 3.0 框架（2025）
在 YC AI Startup School 提出 Software 3.0：软件1.0=手写代码，2.0=神经网络权重，3.0=LLM 作为新型计算机、对话即编程。是 Software 2.0 思想的重大升级。

### 9. 加入 Anthropic（2026）
重返前沿 R&D，聚焦预训练研究。标志着其在"教育探索期"后重新回到 AGI 竞争的前沿阵地。

## 思想转折点

### 转折点一：从研究者到教育者（2015）

- **转变**：从专注个人研究 → 将教育作为核心使命
- **触发因素**：在斯坦福设计 CS231n 课程，发现教学成果的影响力远超单篇论文
- **来源**：[karpathy.ai](https://karpathy.ai/)

### 转折点二：Software 2.0 认知（2017）

- **转变**：从"软件是手写代码" → "软件可以是神经网络权重"
- **触发因素**：在 Tesla 大规模部署神经网络，意识到传统编程无法应对视觉任务的复杂性
- **来源**：[Software 2.0 博客](https://karpathy.medium.com/software-2-0-a64152b37c35)（2017-11）

### 转折点三：离开 Tesla，回归研究（2022）

- **转变**：从大规模工程部署 → 回归前沿研究
- **触发因素**：Tesla Autopilot 已建立完整体系，感觉使命完成；希望回到更前沿的 AGI 研究
- **来源**：[TechCrunch Tesla 离职报道](https://techcrunch.com/2022/07/13/tesla-loses-top-ai-executive-who-led-autopilot-vision-team/)（2022-07）

### 转折点四：Vibe Coding 与"权力归于人民"（2025）

- **转变**：从"专业编程" → "任何人都可以通过英语构建软件"
- **触发因素**：2025年 LLM 能力跨越关键阈值，亲眼验证"仅凭英语就能构建复杂程序"
- **来源**：[X @karpathy](https://x.com/karpathy)（2025-02）

### 转折点五：Software 3.0——LLM 作为新型计算机（2025）

- **转变**：从"LLM 是工具/API" → "LLM 是新型操作系统/计算机"
- **触发因素**：Claude Code 等本地 AI Agent 的成熟，意识到 LLM 交互范式将从文本对话进化到图形界面
- **来源**：[YC AI Startup School 演讲](https://blog.iaieye.com/posts/agentic-coding-classics/karpathy-software-3.0-fulltext/)（2025-06）

### 转折点六：从"进化动物"到"召唤幽灵"（2025）

- **转变**：从"AGI 是生物智能的延续" → "LLM 是一种全新的智能形态"
- **触发因素**：2025年 RLVR 带来的能力跃迁，以及 LLM "锯齿状"性能特征的深入观察
- **来源**：[年度复盘](https://new.qq.com/rain/a/20251220A03DZH00)（2025-12）

### 转折点七：重返前沿 R&D（2026）

- **转变**：从"独立教育者/创业者" → "回到 frontier 预训练研究"
- **触发因素**：认为"LLM 未来几年的 frontier 将尤其关键"，希望在最重要的技术前沿亲自参与
- **来源**：[VentureBeat](https://venturebeat.com/technology/andrej-karpathy-announces-hes-joining-anthropic/)（2026-05）

## 最近12个月动态（2025年中-2026年中）

### 2025年

**2月——Vibe Coding 概念爆发**
- 提出"Vibe Coding"术语，描述通过自然语言提示词驱动 AI 工具完成编程的范式
- 引发全球开发者社区讨论，成为2025年最具影响力的编程思潮之一

**6月——Software 3.0 框架系统阐述**
- 在 YC AI Startup School 发表演讲，提出 Software 3.0 完整框架
- 核心观点：LLM 是继1970-80年代传统计算机之后的新型计算范式；"对话即编程"
- 配套31张演讲 slides，内容被全文翻译传播

**下半年——开源项目持续产出**
- nanoGPT 持续优化，成为最受欢迎的 GPT 教学实现
- 活跃于 GitHub、X/Twitter，持续发布技术见解
- YouTube 频道发布《Deep Dive into LLMs like ChatGPT》《How I Use LLMs》等面向大众的教育视频

**12月——年度 AI 复盘**
- 发布 X 长文年度复盘，总结2025年 LLM 领域的6个关键拐点：
  1. **RLVR（基于可验证奖励的强化学习）** 成为 LLM 生产流程的新阶段
  2. **"幽灵智能"的锯齿状特征**——LLM 既是博学天才又像认知障碍小学生
  3. **Cursor 引领 LLM 应用层崛起**——垂直领域"Cursor 版本"成为新创业方向
  4. **Claude Code 开创本地 AI Agent 新范式**——AI "住"在电脑里，而非云端访问
  5. **Vibe Coding 普及化**——编程能力从专业人士专利变为人人可用
  6. **Nano Banana（Gemini）开启 LLM 图形界面时代**——从文本对话到富媒体交互
- 核心判断："整个行业实现出的 LLM 潜力还不到10%"

### 2026年

**2月——microGPT 发布**
- 发布 microGPT：约200行纯 Python、零依赖的极简 GPT 实现
- 强调算法可读性，是"从零到英雄"教育理念的延续

**3月——AutoResearch 开源**
- 发布 AutoResearch：AI Agent 自主科研循环系统
- 核心设计：给 AI Agent 一个小型 LLM 训练设置，让其在无人监督的情况下自主实验
- 成果：单 GPU、2天、700+次实验，自动发现并应用20+改进
- 哲学意义：预示"AI 自主科研"时代的到来

**3月——nanochat 发布**
- 发布 nanochat：极轻量全栈 ChatGPT 克隆，完整训练+推理流水线

**5月19日——加入 Anthropic**
- 在 X 宣布加入 Anthropic，任职预训练（Pretraining）团队
- 本人原话："我认为未来几年 LLM 的前沿将尤其关键。我非常兴奋能加入这里的团队，回到 R&D。"
- Anthropic 预训练负责人 Nicholas Joseph："欢迎 Andrej 加入预训练团队！他将组建一个专注于用 Claude 加速预训练研究本身的团队。"
- 本人同时表示："我仍然对教育充满热情，计划适时恢复相关工作。"

**5月下旬——Anthropic 后首讲**
- 阐述 Vibe Coding 已进入"分叉"阶段：进入生产环境需要更严肃的工程框架
- Software 3.0 从概念走向落地实践

## 当前关注焦点（2026年中）

### 1. 前沿预训练研究（Anthropic）
- 加入 Anthropic 预训练团队，专注于大规模 LLM 训练
- 探索用 Claude 自身加速预训练研究（递归自我改进方向）

### 2. AI Agent 与自主科研
- AutoResearch 的方向：AI Agent 自主进行科研实验
- 关注"loopy era"（循环时代）：AI 系统能够自我改进

### 3. Software 3.0 工程化
- Vibe Coding 的生产化、工程化框架
- "Agentic coding"：多 Agent 编排与系统设计

### 4. LLM 图形界面（GUI for LLMs）
- 认为当前文本对话类似于1980年代命令行，未来 LLM 交互将是图形化、多模态的
- 关注 Gemini 等模型在多模态融合上的进展

### 5. 教育（暂停但持续关注）
- 明确表示"仍然对教育充满热情，计划适时恢复"
- Eureka Labs 方向未放弃，但因 Anthropic 入职而暂停
