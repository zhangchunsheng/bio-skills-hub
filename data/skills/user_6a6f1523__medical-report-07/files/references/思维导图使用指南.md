# 思维导图使用指南

## 什么时候用思维导图
1. 做笔记/读书总结
2. 项目规划/任务拆解
3. 知识梳理/体系构建
4. 头脑风暴/创意发散
5. 会议记录/汇报准备
6. 复习备考/记忆辅助

## 如何让思维导图更有效
1. 用关键词，不用长句
2. 多用图标和颜色
3. 动手画比看更有效
4. 定期回顾和更新
5. 先发散再收敛

## 常用工具推荐
- **XMind**：最流行，功能强大
- **MindMaster**：国产，模板多
- **幕布**：大纲+思维导图一键切换
- **ProcessOn**：在线协作
- **Obsidian**：笔记软件，支持思维导图插件
- **纸笔**：最原始也最有效

## 常见误区
1. 太复杂：信息过载，失去导图意义
2. 太花哨：颜色图标太多，干扰阅读
3. 只看不做：动手画才能加深理解
4. 追求完美：先完成再完善
