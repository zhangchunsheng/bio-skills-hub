# 思维导图生成器

## 功能介绍
输入主题或零散要点，生成结构化思维导图的Markdown文本，可直接导入XMind/MindMaster/幕布等工具，知识梳理好帮手。

## 使用方法
把你要做思维导图的主题发给AI，例如：
- 「帮我做一个Python学习路线的思维导图」
- 「生成项目管理知识体系思维导图」
- 「梳理一下考研复习计划的大纲」
- 「帮我把这些要点整理成思维导图：[要点列表]」

可以指定：
- 主题名称
- 结构类型（总分/流程/要素等）
- 层级深度
- 侧重方向

## 输出内容
- Markdown格式思维导图文本
- 清晰的层级结构（中心→一级→二级→三级）
- 使用说明（如何导入各种工具）
- 扩展建议

## 适合人群
学生、职场人、知识管理爱好者、需要做汇报的人、想梳理思路的人
