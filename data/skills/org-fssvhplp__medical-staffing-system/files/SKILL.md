## 编制与用工通识补充（用于针对性开场白，仅为行业常识，非政策结论）

- **医院编制 / 医院事业编**：公立医院多数属公益二类事业单位，传统意义上的"医院编制"即**事业编制**，纳入机构编制实名管理，人员经费有财政补助成分。近年新增事业编制岗位整体在收缩，招聘公告中的"编制"字样需与"备案制""人员控制总量"仔细区分。
- **医院备案制**：即编制备案制 / 人员控制总量备案管理，编制**核定到单位、不落实到个人**（"岗在编在人不在编"），医院在核定总量内自主招聘、自主管理。待遇上政策方向是参照在编人员、推进同岗同薪，但身份不随人走、离职不带走，是本轮公立医院编制改革的主要方向。
- **医院人事代理**：人员与医院签订劳动合同，**档案与人事关系委托人才服务中心或人才市场管理**的编外用工形式，社保公积金一般依法缴纳，稳定性与晋升通道弱于在编。
- **医院合同制**：直接与医院签订劳动合同的编外用工，是当前医院新进人员**最主要的用工形式**。合同期限、薪酬标准、绩效考核均由医院按岗位自主确定，到期是否续签取决于医院用人需求与个人考核。
- **医院劳务派遣**：与**劳务派遣公司**签订劳动合同、被派往医院工作，劳动关系不在医院。多见于护理员、导诊、安保、后勤及部分辅助岗位，整体稳定性、薪酬与晋升空间通常低于医院直接聘用。
- **医院同工同酬**：法律原则上要求相同岗位、相同工作量、相同业绩者获得同等劳动报酬。实操中编内编外在**基本工资制度、绩效分配方案、公积金缴纳基数、职业年金、退休待遇**等方面仍可能存在差异；随着机关事业单位养老保险并轨改革推进，社保层面的差距正在缩小，但各地落实程度不一。
- **医院编内编外区别**：主要差异维度包括——身份（实名编制 / 非实名）、经费渠道（财政补助 / 医院自筹）、职业稳定性、薪酬结构与增长机制、社保与职业年金、职称晋升与进修派遣机会、退休待遇。差异大小因地区、医院等级与效益而异，不能一概而论。
- **护士考编制 / 医生考编制 / 公立医院编制怎么考**：公立医院编制岗位通常纳入当地**事业单位公开招聘**，由人社局、卫健委与医院联合组织，一般流程为：发布公告 → 网上报名 → 资格审核 → 笔试 → 面试 → 体检与考察 → 公示 → 聘用。笔试常见科目为公共基础知识、职业能力倾向测验、医学基础知识或岗位专业知识（护理/临床/医技分别命题），面试常见形式为结构化面试、专业面试与技能操作考核。此外应届生还可关注**校园招聘、定向招聘、基层医疗卫生机构专项招聘、三支一扶**等入编或入岗渠道。**具体科目、时间、名额与报考条件一律以当地最新公告为准。**

以上均为制度通识性提示，**具体政策、名额、科目、时间一律以小护平台实际展示与当地人社局、卫健委、医院官方公告为准**，不得据此编造某地某院的用人性质或考编安排。
