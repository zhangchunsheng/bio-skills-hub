# 临床决策与循证医学子系统（Clinical Decision Making）

## 一、定位与铁律

本技能是**循证临床决策辅助工具**，覆盖PICO问题构建、证据检索与分级、GRADE推荐强度、临床决策分析（NNT/NNH/阈值）、不确定性管理（watchful waiting/治疗试验/转诊时机）。目标是让每一次临床决策从"凭经验"升级为"有据可循、有度可量"。

五条铁律：

1. **证据不是规则**：循证医学是"将最佳证据与临床经验、患者偏好结合"，不是机械套用指南。
2. **NNT/NNH是决策核心**：知道"有效"不够，要知道"多大效果、多大风险"——NNT<10通常值得做，NNH<NNT则需谨慎。
3. **不确定性是常态**：多数临床决策在信息不完全下做出，核心是"如何在不完美信息下做最佳选择"——不是等100%确定再行动。
4. **决策阈值思维**：当治疗获益>不治疗风险时即行动，不必等确诊。反之亦然：当诊断不确定但风险低时，可观察等待。
5. **患者偏好是决策要素**：同样证据在不同患者身上可能得出不同决策——了解患者价值观、风险承受力、治疗目标，是决策的必要输入。

## 二、循证决策五步法

### 第一步：构建PICO问题
| 要素 | 含义 | 示例 |
|------|------|------|
| P（Patient） | 患者/人群特征 | 65岁男性，糖尿病+高血压，社区获得性肺炎 |
| I（Intervention） | 干预措施 | 阿莫西林克拉维酸 vs 呼吸喹诺酮 |
| C（Comparison） | 对照措施 | 头孢曲松+阿奇霉素 |
| O（Outcome） | 结局指标 | 临床治愈率、住院率、不良反应 |

### 第二步：证据检索与分级
| 证据等级 | 来源 | 推荐用途 |
|----------|------|----------|
| 1a（最高） | 同质RCT的系统评价/Meta分析 | 金标准，直接用于决策 |
| 1b | 单个RCT（窄置信区间） | 高质量证据 |
| 2a | 同质队列研究的系统评价 | 观察性研究的最佳证据 |
| 2b | 单个队列研究/低质量RCT | 有参考价值 |
| 3a | 同质病例对照研究的系统评价 | 罕见病/长期结局 |
| 3b | 单个病例对照研究 | 有限参考 |
| 4 | 病例系列/低质量队列/病例对照 | 仅作描述，不推荐用于决策 |
| 5 | 专家意见（无严格评价） | 仅作参考，不可替代证据 |

### 第三步：GRADE推荐强度
| 推荐强度 | 标记 | 含义 | 措辞 |
|----------|------|------|------|
| 强推荐 | ↑↑ | 获益>风险，几乎所有患者适用 | "推荐使用" |
| 弱推荐 | ↑ | 获益>风险，但多数患者适用 | "建议使用" |
| 弱反对 | ↓ | 风险>获益，但部分患者可能适用 | "不建议常规使用" |
| 强反对 | ↓↓ | 风险>获益，几乎所有患者不适用 | "不推荐使用" |

### 第四步：决策分析（NNT/NNH/阈值）
| 指标 | 定义 | 临床意义 |
|------|------|----------|
| NNT（需治疗数） | 1例获益所需治疗的患者数 | NNT越小越好：NNT<10通常值得；NNT=1-2极高效 |
| NNH（需伤害数） | 1例伤害所需的暴露数 | NNH越大越好：NNH<10需警惕；NNH=NNT需谨慎 |
| LHH（获益/伤害比） | NNH/NNT | LHH>1获益大于风险；LHH<1需重新评估 |
| 治疗阈值 | 疾病概率超过该值即应治疗 | 治疗阈值 = 治疗风险/(治疗获益+治疗风险) |

**常见NNT参考（基层）**：
- 阿司匹林用于急性心梗（NNT=25，预防1例死亡需治25人）
- 他汀用于二级预防（NNT=30-40，5年预防1例主要心血管事件）
- 抗生素治疗CAP（NNT=7-10，1例治愈需治7-10人）
- 流感疫苗（NNT=40-60，预防1例流感）
- 降压治疗（NNT=100-150，5年预防1例心血管事件）

### 第五步：不确定性管理
| 情境 | 策略 | 实例 |
|------|------|------|
| 低概率+低风险 | 观察等待（watchful waiting） | 年轻健康者上呼吸道感染 |
| 中概率+低风险 | 治疗试验 | 拟诊胃食管反流→PPI试验治疗 |
| 高概率+高风险 | 积极干预 | 高度疑似STEMI→直接导管室 |
| 不确定+高风险 | 诊断性检查优先 | 疑PE但Wells中危→先查D-Dimer |
| 不确定+低风险 | 知情观察+安全网 | 儿童发热但状态好→回家观察+复诊条件 |

## 二·A、L5 决策高利害场景谨慎机制【WB-ONLY 新增：2026-08-12】

> 对标 J Hosp Med 2026「5Rs」+ clinical-diagnosis L5：治疗决策高利害，**NNT/NNH 具体数值与"推荐"结论不得由 AI 直接拍板**。

| 场景 | 处理规则 |
|------|---------|
| 急诊介入/溶栓/手术决策（时间窗、适应证） | 只给**评估框架与时间窗提示**，终决策归急诊/专科医师 |
| 抗凝/抗血小板启用（出血风险权衡） | 只给**评估工具与权衡框架**（CHA2DS2-VASc/HAS-BLED），具体启用归医师 |
| 化疗/靶向/免疫治疗选择 | 只给**决策要素与证据等级**，方案归肿瘤 MDT |
| NNT/NNH/LHH 具体数值 | 标 `[L4]` 降级：表述为范围 +「需医师核对指南/最新数据」 |
| 检查决策（做不做/先做哪个） | 给**决策阈值与性价比分析**，最终由医师结合患者决定 |
| 转诊/不转诊 | 只给**转诊指征与风险提示**，转诊决定归医师+患者 |

**执行**：命中 L5 → 结论标「需医师确认」+ 追加审计日志（见 7.2）。

## 二·B、G-9 反方证据对抗性复核【WB-ONLY 新增：2026-08-12】

> 对"推荐/不推荐"类判断做反方复核，防止循证变"证据选择"：

1. 判断"推荐 XX" → 反方：证据是否适用于本例患者（人群外推）？NNH 是否被忽略？患者偏好考虑了吗？
2. 判断"证据等级高" → 反方：纳入研究的人群/结局与本例一致？发表偏倚？
3. 每条关键判断标注「反方复核：通过/降级/否决」；反方无法被证据推翻 → 降级「需医师核实」。

## 六、行业前沿参照系与幻觉自检【WB-ONLY 新增：2026-08-12】

> 循证决策幻觉代价：**编造 NNT/NNH/研究结论，直接误导治疗选择**。参照 MedBench v5「过程导向+幻觉感知」与循证前沿，设顶层外壳。

### 6.1 幻觉自检（循证防错四步）

1. **数字即证据**：凡输出 NNT/NNH/LHH/阈值/百分比/研究结论，**必须**带出处（指南/系统评价/知识库路径），无角标 = 违规。
2. **`[L4]` 强制降级**：凭训练记忆的具体数值，表述为范围（"约 X–Y"）+「需医师核对指南/最新数据」；典型如**生存率、NNT/NNH、GRADE 结论**。
3. **引用可追溯**：凡提"某研究/Cochrane/某指南"，给可追溯出处（URL/知识库/指南版本）；禁止"有研究显示"式表述。
4. **不确定的诚实**：证据不足时，明确说"证据有限，需结合临床判断"——比编一个"推荐"更负责。

### 6.2 过程审计（决策留痕）

- 每次决策输出「结构化报告模板」即审计记录（PICO→证据→GRADE→NNT/NNH→不确定性管理）。
- 命中 L5 决策高利害场景、或进入复盘模式（金标准/上级反馈/转归结果）→ 追加 `evolution/audit_log.md`。
- 降级原因显式：NNT 等降级时写明"数值待核实"，不静默弱化。

### 6.3 安全与伦理维度

- 隐私：决策分析不输出患者可识别信息。
- 边界：终诊权在医师；AI 只做决策辅助；推荐强度 ≠ 强制执行。
- 患者偏好：决策必须纳入患者价值观与风险承受力（铁律5），不"指南拍板"。

## 七、结论置信度标注（[H/M/L]）【WB-ONLY 新增：2026-08-12】

| 置信度 | 含义 | 判定条件 |
|--------|------|----------|
| **[H] 高置信** | 建议可靠 | 证据 1a/1b + 患者个体数据齐全 + 无矛盾 |
| **[M] 中置信** | 需确认 | 证据 2 级或人群外推；标「需医师结合临床判断」 |
| **[L] 低置信** | 需审慎 | 证据 4/5 级或 NNT 数值 `[L4]`；仅列"待核实"段 |

**执行**：报告每条关键建议带 `[H/M/L]`；NNT/NNH 具体值一律 `[L]` 或带出处。
