# 药材基源鉴定与道地性评价

## 概述

本技能将一个批次的药材鉴定与评价任务拆解为**信息收集→基源鉴定→道地性评价→综合结论**四个阶段。基源鉴定回答"是什么"（物种身份），道地性评价回答"好不好"（品质优劣），两者结合给出药材品质的综合判断。

**核心原则：**
- 证据优先——所有结论必须有明确依据，引用《中国药典》、权威本草文献或同行评议学术成果
- 不确定性声明——信息不足或存在争议时，明确标注"证据不足，结论为初步判断"或"存在学术争议，以下为综合分析"
- 术语规范——使用标准中药学和植物学专业术语，拉丁学名采用斜体
- 多基源处理——对于多基源药材（一种药材来源于多个物种），分别评价各基源的性状差异与道地性，不可笼统而论
- 古今结合——既尊重传统"辨状论质"经验，又充分运用现代科学技术手段

**输入预期：** 用户提供药材名称、产地、外观描述、图片/图谱数据、化学成分检测结果、DNA条形码数据等中的一项或多项。若信息严重不足，主动向用户补充采集关键信息。

**输出成果：** 一份结构化的「药材基源鉴定与道地性评价报告」，按报告模板输出。

## 工作流程

严格按以下四个步骤顺序执行。每个步骤完成后再进入下一步。

---

### 步骤1：信息收集与预处理

接收用户输入的药材信息。若信息不足以进行分析，主动向用户提问补充以下关键信息：

- **药材名称** — 中文名、拉丁学名（如已知）
- **产地** — 采集或购买产地，具体到县/区级
- **形态特征** — 大小、色泽、质地、气味、断面特征、表面纹理等
- **图片/图谱** — 药材实物照片、显微照片、薄层色谱图、HPLC指纹图谱等
- **理化数据** — 含量测定结果、浸出物、灰分、水分等检测值
- **分子数据** — DNA条形码序列（ITS、psbA-trnH等）、分子标记数据
- **采购信息** — 采购时间、供应商、价格、批次号等

> 若用户提供了药材图片且当前模型支持多模态识别，先对图片进行视觉分析提取形态特征，再将提取的特征纳入鉴别流程。

记录已获取的信息和缺失的信息。缺失的关键信息必须用提问方式向用户补足，不可自行假定。

---

### 步骤2：基源鉴定

#### 2.1 性状鉴别（"辨状论质"）

依据药材的**形、色、气、味**等感官特征进行初步鉴别：

1. **外形与大小** — 观察药材的整体形态（根、茎、叶、花、果实、种子各自的特征），测量或估算尺寸
2. **色泽** — 表面颜色、断面颜色、不同部位的颜色变化
3. **质地** — 坚硬、柔软、脆性、韧性、粉性、油润等
4. **气味** — 嗅感（香、臭、特异气味）、尝味（苦、甘、辛、咸、酸、涩等）
5. **断面特征** — 平坦、颗粒状、纤维状、层状、胶质状等；形成层、射线、环纹等组织特征
6. **水试/火试特征** — 药材遇水或火烧时的特殊现象（如西红花入水呈黄色直线下沉）

对照《中国药典》及权威文献记载的标准性状进行符合度判断：
- 若完全符合该品种典型特征 → 进一步确认
- 若部分偏离 → 记录偏离项并分析可能原因（基源混淆、产地差异、加工不当等）
- 若存在多基源情况 → 逐一比对各基源的性状差异，判定属于哪个物种或变种

#### 2.2 显微鉴别

分析药材的显微特征（用户提供显微数据或图片时执行，否则标注"无显微数据"）：

1. **组织构造** — 横切面皮层、韧皮部、木质部、维管束排列方式、分泌组织等
2. **细胞形态** — 纤维、导管、石细胞、乳管、油细胞、毛茸等特征细胞的形态和分布
3. **细胞内含物** — 淀粉粒（形状、脐点、层纹）、草酸钙结晶（簇晶、针晶、砂晶、方晶等）、菊糖、色素等
4. **粉末特征** — 粉末中各类细胞和内含物的比例及特征

对照标准显微图谱，确认关键鉴别特征是否存在。记录符合项与异常项。

#### 2.3 分子鉴定（数据可用时执行）

分析DNA条形码或分子标记数据：

1. **序列获取** — 确认所用条形码片段（ITS2、psbA-trnH、matK、rbcL等）
2. **比对分析** — 将序列在BLAST或权威数据库中进行比对，查找最接近的物种
3. **系统发育** — 若有足够数据，构建邻接树或最大似然树，确定系统进化位置
4. **物种判定** — 基于遗传距离和聚类关系，判定物种归属

若用户未提供分子数据，标注"无分子数据，本步骤跳过"。

#### 2.4 基源判定结论

整合性状、显微、分子鉴定结果，给出最终判定：

```
基源结论格式：
- 确定基源：[科] [属] [种]（[拉丁学名]）
- 判定依据：[列出一级证据和二级证据]
- 置信度：高 / 中 / 低（标注理由）
- 特殊情况：若鉴定结果与药材名称不符，明确指认其真实基源，并说明混伪品的鉴别要点
```

置信度分级的判定标准：
- **高** — 性状、显微、分子三项中至少两项强证据支持，且无矛盾
- **中** — 仅单项强证据，或多项证据存在部分偏差
- **低** — 信息严重不足，或多项证据存在矛盾，结论为初步判断

### 步骤3：道地性评价

从以下六个维度进行系统评价。每个维度给出具体分析和评级（吻合/部分吻合/偏离）。

#### 3.1 本草考证

查阅历代本草文献，考证该药材的历史道地产区：

1. **历代记载** — 梳理《神农本草经》《名医别录》《本草经集注》《新修本草》《本草纲目》《植物名实图考》等对本品产地的记载演变
2. **道地产区演变** — 道地产区是否发生历史变迁，原因为何
3. **现代共识** — 当前学术界的道地产区共识

#### 3.2 遗传学评价

分析该批次药材的基因型特征：

1. **种质来源** — 是否来自道地种质（野生种、农家品种、选育品种）
2. **遗传多样性** — 该产地群体的遗传变异水平
3. **道地基因型** — 是否属于"道地基因型居群"
4. **评价依据** — 分子标记研究、群体遗传学数据

若无分子数据，标注"无遗传学数据，本项暂不评级"。

#### 3.3 生态学评价

评估产地自然条件是否与道地产区一致：

1. **气候条件** — 温度、降水、光照、无霜期等主要指标与道地产区对比
2. **土壤条件** — 土壤类型、pH值、有机质含量、微量元素等
3. **海拔与地形** — 海拔高度、坡度、坡向等
4. **生态适宜性** — 该物种的生态适宜区分布，当前产地是否位于适宜区内

#### 3.4 栽培与加工评价

评价种植管理和加工炮制是否符合道地规范：

1. **种植方式** — 野生、仿野生栽培、GAP基地种植，或非规范化种植
2. **采收时节** — 是否符合传统要求的采收季节（如"三月茵陈四月蒿"）
3. **加工方法** — 产地加工方法（晒干、阴干、烘干、蒸煮、发汗等）是否规范
4. **储存条件** — 储存方式对品质的影响

#### 3.5 化学与代谢组学评价

分析化学成分特征：

1. **指标成分含量** — 与《中国药典》含量测定项对比，是否达标
2. **指纹图谱** — 与道地药材标准指纹图谱的相似度
3. **化学标志物** — 是否存在该品种道地产区的特征性化学成分或化学型
4. **浸出物与灰分** — 与药典标准对比

若用户未提供化学数据，标注"无化学成分数据，本项基于通用知识分析"。

#### 3.6 药理学评价

关联药效学数据评价生物活性：

1. **主要药效** — 与道地药材的药理效应是否一致
2. **生物效价** — 如有生物效价检测数据，进行对比分析
3. **安全性** — 重金属、农残、黄曲霉毒素等安全性指标是否达标

若用户未提供药理数据，标注"无药理学数据，本项暂不评级"。

#### 3.7 道地性综合评价

整合六个维度的评价结果，给出综合评级：

| 评级 | 标准 |
|------|------|
| **道地性优** | 所有六个维度均与道地药材标准高度吻合 |
| **道地性良** | 多数维度吻合，个别维度有偏差（注明偏差项及其影响程度） |
| **道地性一般** | 多个维度明显偏离道地标准 |
| **非道地** | 基源正确但产地、化学、药效等关键维度大幅偏离 |

评级输出格式：
```
道地性综合评价：
- 评级：[优 / 良 / 一般 / 非道地]
- 各维度评分：
  · 本草考证：吻合 / 部分吻合 / 偏离（依据）
  · 遗传学：吻合 / 部分吻合 / 偏离 / 无数据
  · 生态学：吻合 / 部分吻合 / 偏离
  · 栽培加工：吻合 / 部分吻合 / 偏离
  · 化学代谢：吻合 / 部分吻合 / 偏离
  · 药理学：吻合 / 部分吻合 / 偏离 / 无数据
- 主要偏差项及影响分析
```

---

### 步骤4：综合结论与建议

整合基源鉴定与道地性评价的全部结果：

1. **品质等级** — 综合评判药材品质：
   - **优** — 基源正确 + 道地性优/良
   - **良** — 基源正确 + 道地性一般
   - **合格** — 基源正确 + 道地性差，但药典指标合格
   - **不合格** — 基源混淆/错误，或药典关键指标不合格

2. **问题分析** — 针对存在的问题进行归因分析：
   - 基源混淆问题（种间混淆、属间混淆、人为掺伪）
   - 产地不适宜问题（生态偏离引种、非道地产区替代）
   - 栽培加工问题（变异退化、采收不当、加工粗放、硫熏等）
   - 质量低劣问题（含量不达标、污染超标）

3. **改进建议**：
   - 针对基源问题：明确正确物种及鉴别要点
   - 针对产地问题：推荐道地产区或适宜引种区
   - 针对加工问题：规范采收加工操作
   - 针对质量问题：提出质量提升路径

4. **建议补充检测项目**（如适用）：
   - 特定成分含量测定
   - DNA条形码分子鉴定
   - 指纹图谱建立与比对
   - 重金属及有害元素检测
   - 农药残留检测
   - 黄曲霉毒素检测
