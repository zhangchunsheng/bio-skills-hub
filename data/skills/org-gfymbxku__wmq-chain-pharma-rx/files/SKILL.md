# 处方审核与用药指导（药学服务 · 医药连锁 skill）

## 用途
本技能使 WorkBuddy 充当医药连锁（连锁药店）「处方审核与用药指导」场景的专属助手，覆盖《医药连锁AI应用场景白皮书》对应场景集。处方审核与用药指导：调配前审核、中药相互作用、慢病、特殊人群、患者教育
## 触发示例
- "帮我审下这张处方 / 这方子有没有配伍禁忌"
- "这些中西药能一起吃吗 / 中西药联用有冲突吗"
- "给这个慢病患者出个用药指导"
- "孕妇能用这个药吗 / 老人儿童用药禁忌"
- "这个药怎么跟患者讲 / 出个用药指导卡片"

## 适用场景明细
### 处方前置审核
- **触发**：帮我审下这张处方 / 这方子有没有配伍禁忌
- **输入**：处方图片(JPG/PDF,需OCR)或结构化处方文本(药品/剂量/用法)；患者基本信息(年龄/性别/诊断,脱敏)
- **输出**：风险审核报告(HTML)：配伍禁忌/超剂量/重复用药/相互作用/风险等级+处置建议
- **知识依赖**：药品相互作用库(更新至当月)；配伍禁忌库；处方管理办法；超剂量判定规则
- **合规边界**：AI仅提示风险,最终由执业药师审核签字；不得直接拒配或改方；处方变更需医师确认；患者信息脱敏
- **责任岗位**：执业药师使用,店长监督

### 中西药联用分析
- **触发**：这些中西药能一起吃吗 / 中西药联用有冲突吗
- **输入**：患者同时服用的中西药清单(药品名/剂量/频次)；可选患者特征(脱敏)
- **输出**：联用分析(HTML)：相互作用/禁忌组合/用药间隔建议+风险等级
- **知识依赖**：中西药相互作用库；中药配伍禁忌(十八反十九畏)
- **合规边界**：AI辅助提示,执业药师解读；不得替代医师判断；信息脱敏
- **责任岗位**：执业药师

### 慢病患者用药方案
- **触发**：给这个慢病患者出个用药指导
- **输入**：患者慢病类型/用药史/化验指标(脱敏)；当前用药清单
- **输出**：用药指导建议(HTML)：用药时间/剂量提醒/监测指标/生活方式建议+复诊提示
- **知识依赖**：慢病用药指南(糖尿病/高血压等)；药物相互作用库
- **合规边界**：药店无处方权,仅出「用药指导建议」非「用药方案」；需医师/执业药师确认；不得调方；信息脱敏
- **责任岗位**：执业药师指导,医师确认处方变更

### 特殊人群用药
- **触发**：孕妇能用这个药吗 / 老人儿童用药禁忌
- **输入**：患者特征(孕妇/哺乳期/儿童年龄体重/老人/肝肾异常)；候选药品清单
- **输出**：禁忌筛选(HTML)：禁忌药品标注+替代方案建议+剂量调整提示
- **知识依赖**：特殊人群用药禁忌库；药品说明书；儿童剂量换算规则
- **合规边界**：AI辅助,执业药师审核；儿童/孕妇用药须谨慎,必要时建议就医；信息脱敏
- **责任岗位**：执业药师

### 患者用药教育
- **触发**：这个药怎么跟患者讲 / 出个用药指导卡片
- **输入**：药品名称；可选患者特征
- **输出**：用药指导卡(HTML/PDF)：通俗化用法用量/注意事项/不良反应/贮藏+短视频脚本(可选)
- **知识依赖**：药品说明书；患者教育素材库
- **合规边界**：内容须与说明书一致,不得夸大/隐瞒；处方药教育须一对一；AI生成,药师复核
- **责任岗位**：执业药师

## 工作流
1. **明确场景与输入**：根据用户诉求定位目标场景，收集所需输入（文本/CSV/Excel/图片等）。
2. **组织内容**：基于场景要点与领域知识，撰写/归纳结构化内容。
3. **产出 spec**：将内容组织为 render.py 所需的 spec JSON（结构见 references/templates.md）。
4. **渲染交付物**：执行 `python scripts/render.py <spec.json> --format <md|html|docx|json> --output <路径>`。
5. **交付与复核**：返回交付物，提示合规与人工复核要求（见下）。

- `scripts/render.py`：通用文档渲染器（支持 md / html / docx / json）。
