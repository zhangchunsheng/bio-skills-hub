## 三、与已有 Skill 的差异

本 Skill 是 **主题/概念蒸馏** 而非 **人物蒸馏**。
- 人物蒸馏：提炼某人的思维方式（如 Elon Musk、Naval）
- 主题蒸馏：提炼某个领域的知识体系（如本 Skill）

属于 nuwa-skill 的合理外延。
