# Biome 高性能 JavaScript TypeScript 格式化工具和 Linter

Biome 是一个基于 Rust 的高性能工具链，适用于 JavaScript、TypeScript、JSX、JSON、CSS 和 GraphQL，它将格式化和 linting 统一到一个工具中。具有 97% 的 Prettier 兼容性以及超过 450 条 lint 规则，Biome 以显著更快的执行速度取代了 ESLint 和 Prettier。
