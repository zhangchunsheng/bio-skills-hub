# 医药流通ERP 证照管控 — 详细模型

本文件是 `pharma-license-control` skill 的支撑细节：证照字典全量、9 格三级规则矩阵、数据模型 DDL、校验流程伪代码。

---

## 1. 证照分类字典（全量）

> 说明：有效期、适用主体以中国大陆现行《药品管理法》《药品经营质量管理规范》及配套法规为基准；具体以企业所在地药监要求为准。

### 1.1 主体资质类（证明"能不能经营"）

| 证照 | 适用主体 | 法定要求 | 有效期 |
|------|----------|----------|--------|
| 营业执照 | 全部 | 必持 | 长期（需年报） |
| 药品生产许可证 | 厂家（生产端） | 附 GMP 合规 | 5 年 |
| 药品经营许可证·批发 | 供应商（商业/批发）、企业自身 | 附 GSP 合规 | 5 年 |
| 药品经营许可证·零售 | 零售药店（客户的特殊分支） | 附 GSP 合规 | 5 年 |
| 医疗机构执业许可证 | 医院/诊所/卫生室类客户 | 必持 | 校验周期（通常 5 年） |
| 执业药师注册证 | 零售药店（必配）、批发（质管需配） | 必持且在岗 | 5 年 |

### 1.2 特殊品种许可类（证明"能不能经营某类/某品种"）

| 证照/资质 | 授权范围 | 适用主体 | 备注 |
|-----------|----------|----------|------|
| 麻醉药品、精神药品定点经营许可 | 麻精一/二类 | 批发供应商、企业自身 | 医疗机构使用需"印鉴卡" |
| 印鉴卡 | 麻精药品使用 | 医疗机构类客户 | 与定点许可区分（使用端） |
| 医疗用毒性药品经营/使用资质 | 医疗用毒性药品 | 供应商/客户 | 经营范围含该项 |
| 放射性药品使用/经营许可 | 放射性药品 | 供应商/医疗机构客户 | — |
| 药品类易制毒化学品经营许可 | 易制毒化学品 | 供应商/企业自身 | 公安+药监双线 |
| 蛋白同化制剂、肽类激素备案 | 兴奋剂目录品种 | 供应商/客户 | 备案制 |
| 疫苗经营许可 | 疫苗 | 指定批发 | 高度受限 |
| 中药材/中药饮片经营范围 | 中药材、中药饮片 | 供应商/客户 | 毒性饮片需专项 |
| 医疗器械经营许可证（三类）/ 备案（二类） | III 类 / II 类器械 | 供应商/客户 | I 类不须许可 |
| 食品经营许可证 / 备案 | 食品、保健食品 | 供应商/客户 | — |

### 1.3 仓储/设施类（证明"能不能存"）

| 证照/条件 | 授权范围 | 适用 | 备注 |
|-----------|----------|------|------|
| 药品第三方物流资质 | 委外仓储经营 | 仓库（委外） | 自有仓不须 |
| 冷链储存运输条件 | 冷链品种存放 | 仓库 | 冷库+验证+温湿度监控 |
| 特殊药品专库/专柜 | 麻精等专储 | 仓库 | 双人双锁、视频监控 |
| 仓库地址药监核准 | 地址合法 | 仓库 | 许可载明地址+房产/租赁 |
| 中药材仓库条件 | 中药材存放 | 仓库 | 防虫防鼠、阴凉等 |
| 危化品/易制毒仓库备案 | 危化/易制毒存放 | 仓库 | 公安/安监备案 |

## 2. 三级规则矩阵（9 格，逐证照）

符号：`基础`=任意品种必持；`+类`=该类品种追加；`+品种`=该具体品种再追加。

### 2.1 采购管理（供应商）

**1.1.1 供应商基础证照（任意采购）**
- 营业执照
- 药品生产许可证 **或** 药品经营许可证（按供应商是厂家/商业）
- GMP/GSP 合规证明（随许可）
- 执业药师注册证（视主体类型，批发质管需配）

**1.1.2 供应商采购某一类品种（在基础之上追加）**
| 品类 | 追加证照/条件 |
|------|---------------|
| 化学药/中成药/抗生素/生化药 | 无额外（基础已覆盖） |
| 麻精药品 | 麻精定点经营许可 |
| 医疗用毒性、放射性 | 对应专项许可 |
| 药品类易制毒 | 易制毒经营许可 |
| 蛋白同化制剂/肽类激素 | 备案 |
| 医疗器械 I/II/III 类 | 一类不须；二类备案；三类经营许可 |
| 冷链品种 | 冷链储存运输条件 |
| 中药材/中药饮片 | 对应经营范围（毒性饮片专项） |
| 食品/保健食品 | 食品经营许可/备案 |
| 疫苗 | 疫苗经营许可 |

**1.1.3 供应商采购具体品种（在"基础+类"之上再追加）**
- 首营品种审核记录（首营必做）
- 批准文号/注册证与企业一致性
- 进口药品：进口药品注册证 + 进口通关单
- 某麻精具体品种：定点许可 +（医疗机构端）印鉴卡
- 某冷链具体品种：该品种指定温区（如 2~8℃ / -20℃）的验证

### 2.2 销售管理（客户）

**1.2.1 客户基础证照（任意销售）**
- 营业执照
- 药品经营许可证 **或** 医疗机构执业许可证（按客户是商业/医疗）
- GSP/合规证明

**1.2.2 客户销售某一类品种（基础之上追加）**
| 品类 | 追加证照/条件 |
|------|---------------|
| 处方药（零售） | 执业药师审方在岗 |
| 麻精药品（医疗） | 印鉴卡 / 定点 |
| 医疗器械 I/II/III | 一类不须；二类备案；三类经营许可 |
| 冷链品种 | 客户具备冷链接收能力 |
| 蛋白同化制剂/肽类激素 | 备案 |
| 食品/保健食品 | 食品经营许可/备案 |

**1.2.3 客户销售具体品种（基础+类之上再追加）**
- 含麻黄碱复方制剂：实名登记 + 限量销售
- 某冷链具体品种：客户有对应温区接收条件
- 特殊管理药品：按品种逐一管控（如印鉴卡品种名录）

### 2.3 仓库管理（仓库）

**1.3.1 仓库基础证照（任意存放）**
- 仓库地址在许可核准范围内（房产证/租赁协议 + 许可载明）
- 主体营业执照
- 药品第三方物流资质（若委外仓储）

**1.3.2 仓库存放某一类品种（基础之上追加）**
| 品类 | 追加条件 |
|------|----------|
| 冷链类 | 冷库 + 温湿度监控 + 验证 |
| 麻精类 | 专库/专柜 + 双人双锁 + 监控 |
| 中药材类 | 防虫防鼠、阴凉/常温条件 |
| 危化/易制毒类 | 公安/安监备案库 |
| 医疗器械类 | 对应存储条件（无菌/防震等） |

**1.3.3 仓库存放具体品种（基础+类之上再追加）**
- 某生物制品：-20℃ 专用冷库验证
- 某毒性饮片：独立专柜 + 双锁
- 某疫苗：专用冷库 + 温度实时监测
- 某放射性品种：放射源专用储存设施

## 3. 数据模型（DDL 建议，逻辑模型）

```sql
-- 证照档案（一张证一个实例）
license (
  id, license_type,            -- 见第1节三大类
  holder_type,                 -- SUPPLIER / CUSTOMER / WAREHOUSE
  holder_id,                   -- 主体ID
  license_no, issuer,          -- 证号、发证机关
  valid_from, valid_to,        -- 有效期区间
  status,                      -- NORMAL / REVOKED / CANCELLED
  attached_file
);

-- 关联方式 2.1：证照 → 经营范围项
license_scope_rel (license_id, scope_item_id);

-- 关联方式 2.2：证照 → 品种集合
license_productset_rel (license_id, productset_id);
productset (id, name);                       -- 如"冷链品种集合"
productset_item (productset_id, product_id);

-- 关联方式 2.3：证照 → 具体品种
license_product_rel (license_id, product_id);

-- 主体证照挂载视图（快速查某主体持有哪些证照）
-- supplier_license / customer_license / warehouse_license 可视图化以上 holder 维度

-- 商品主数据（含经营范围归属，复用经营范围管控 skill 的字典）
product (id, name, scope_item_id, /* 厂家/商业/零售三类 */ ...);
```

> 关联三张表可并存：同一证照可同时挂经营范围、品种集合、具体品种，按最细粒度生效。

## 4. 校验流程与过期阻断（伪代码）

### 4.1 有效判定
```
isLicenseValid(lic):
  return (today >= lic.valid_from)
     and (today <= lic.valid_to)
     and (lic.status == NORMAL)
```

### 4.2 取某主体对"某品种 P"的所有授权证照
```
authorizedLicenses(holder, product P):
  result = []
  for lic in holder.licenses where isLicenseValid(lic):
    if lic relates to P.scope_item        : result.add(lic)   # 2.1
    if lic relates to any set containing P: result.add(lic)   # 2.2
    if lic relates directly to P          : result.add(lic)   # 2.3
  return result
```

### 4.3 业务行校验（采购/销售/入库通用）
```
validateLine(holder, product P, bizType):
  required = requiredLicenseTypes(holder, P, bizType)  # 由第2节矩阵得出
  held     = authorizedLicenses(holder, P)
  missing  = [r for r in required if no held license of type r is valid]
  if missing:
     BLOCK(line, reason="主体缺少有效证照: " + missing)
  else:
     PASS(line)
```

### 4.4 过期阻断（核心诉求落地）
```
onLicenseExpired(lic):
  # 证照到期当天自动触发
  deactivate(lic)                                 # 置无效
  for each scope_item in lic.scopes:   markScopeUnavailable(lic.holder, scope_item)
  for each set in lic.productsets:     markSetUnavailable(lic.holder, set)
  for each product in lic.products:    markProductUnavailable(lic.holder, product)
  # 后续 validateLine 因 isLicenseValid=false 自然拦截对应范围/品种

beforeExpiry(lic, days=N):   # 预警，不阻断
  sendWarning("证照 X 将于 N 天后到期，关联范围/品种将停用")
```

### 4.5 续期恢复
```
onLicenseRenewed(lic_new):
  reactivate linked scopes/sets/products
  # 2.1 方式下品种无需重挂，仅激活经营范围项即可恢复
```

## 5. 设计注意事项（避坑）

1. **级别叠加**：品类证照是在"基础证照"之上的追加，不是替代；具体品种证照是在"基础+品类"之上的再追加。校验必须逐层 AND。
2. **多证冗余**：同一范围可能被多张有效证照授权，任一张有效即不阻断；过期的是冗余证据时结论仍成立。
3. **仓库与经营范围**：仓库按"商业经营范围"口径参与收货校验（仓库是流通存储节点，不涉及生产剂型/零售 OTC 分级）。
4. **本地化叠加**：不同省份对特殊药品、冷链、蛋白同化制剂等可能有额外限制，作为本地化规则叠加到矩阵之上。
5. **预警不阻断、到期才阻断**：避免误伤在途业务，但到期必须硬阻断。
6. **状态维度独立**：吊销/注销应即时失效，不等到期——`status` 维度与 `valid_to` 维度都要判。
