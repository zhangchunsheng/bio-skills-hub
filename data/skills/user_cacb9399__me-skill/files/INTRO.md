# me.skill - 你在小龙虾眼中的样子 🦞

## 💫 一句话介绍

**一直在用小龙虾,小龙虾眼中的我长什么样?**

me.skill 会用数据告诉你答案:你是效率狂魔还是完美主义者?你的超能力是自动化还是系统思维?海狸、猫头鹰还是章鱼更像你?除了严肃的自我分析,还有"吐槽我"、"夸夸我"、"预测下一步"等 15+ 种趣味模式,让 AI 用好玩的方式帮你认识自己、优化工作流,甚至自动生成每周使用报告。数字镜子+AI教练,了解一下? 😊

---

## 🎯 核心亮点

### 📊 数据驱动的自我认知
- 分析你的 Memory、Skills、对话历史
- 生成完整人格画像 + 技术档案
- 只关注你真正使用的工具(智能过滤56→15)

### 🎮 15+ 趣味模式
**经典模式**:
- "我是谁?" - 快速档案
- "深度分析我" - 完整报告
- "我该学什么?" - 定制建议

**趣味模式** (NEW!):
- "小龙虾眼中的我" - AI视角画像
- "吐槽我一下" - 善意吐槽
- "夸夸我" - 彩虹屁时间
- "如果我是动物" - 精神动物匹配
- "我的超能力" - 核心能力高光
- "我的弱点" - 成长空间(趣味版)

**游戏化模式**:
- "给我生成技能卡片" - RPG角色卡
- "我的生产力评分" - 0-100分段位
- "预测我的下一步" - AI预言
- "对比我和XX" - 技能对比矩阵
- "本周复盘" - 自动周报
- "年度总结" - 史诗回顾

### 📈 AI 使用优化 (NEW v2.0!)
- "分析我的 AI 使用情况" - 深度分析报告
- "优化我的 AI 工作流" - 可操作建议
- "设置 AI 使用周报" - 自动化定期review

## 🌟 为什么有趣?

### 1. 不是冷冰冰的数据
```
传统: "你有56个skills,分布在8个类别"
me.skill: "你是技能囤积症患者,56个skills用了15个,
         剩下41个在吃灰📦。你的精神动物是海狸🦫,
         超能力是自动化光环⚡"
```

### 2. AI 有人格
```
传统: "分析结果如下..."
me.skill: "从我(小龙虾)的视角,你是一个把自动化
         刻进DNA的系统优化狂魔🔥"
```

### 3. 可以互动玩梗
```
你: "吐槽我一下"
AI: "代码改3行,文档写300字,这效率有点...😅"

你: "夸夸我"
AI: "认真的,你的系统思维一流🧠,学习速度惊人🚀"

你: "我的超能力"
AI: "自动化光环 Lv.MAX ⚡,手动做2次第3次就写脚本"
```

### 4. 有用又好玩
- ✅ 真实数据分析(基于Memory + Skills + 对话)
- ✅ 可操作建议(优化工作流 + 学习路径)
- ✅ 自动化周报(定期review + 持续改进)
- ✅ 游戏化呈现(RPG卡片 + 成就系统 + 精神动物)
