## 🎪 8种趣味模式

### 1. 小龙虾眼中的我 🦞
**触发**: "小龙虾眼中的我" / "how does OpenClaw see me"

AI 从第一视角描述你:
```
从我(小龙虾)的视角,你是:
- 第一印象: 效率驱动的工程师
- 相处感受: 问题具体,喜欢数据,追求质量
- 一句话形容: "把自动化刻进DNA的系统优化狂魔"🔥
```

### 2. 吐槽我一下 🔥
**触发**: "吐槽我一下" / "roast me"

善意吐槽(有爱的批评):
```
1. 完美主义过头了吧 😅
   代码改3行,文档写300字...
   
2. 自动化上瘾症
   喝水都想写脚本?
   drink-water.py --temp 45 --vol 250ml
   
3. 技能囤积症
   56个skills,用了15个,剩下41个吃灰📦
```

### 3. 夸夸我 🌟
**触发**: "夸夸我" / "compliment me"

```

3. 质量意识超强 ✨

```

而是: "从我(小龙虾)的视角,你是把自动化刻进DNA的狂魔🔥"
```

```
你: "吐槽我"
AI: "代码改3行,文档300字,这效率...😅"

你: "夸我"
AI: "认真的,你系统思维一流🧠"
