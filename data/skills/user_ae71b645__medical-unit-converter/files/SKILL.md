# 医学单位换算器

在临床检验单位之间换算数值，换算过程公式透明，并附带参考范围。支持血糖、胆固醇、肌酐、血红蛋白、甘油三酯、尿素、钙、钠、钾。

## 适用场景

- 在不同单位制之间换算血糖、胆固醇、肌酐、血红蛋白、甘油三酯、尿素、钙、钠、钾等检验值
- 核对临床文档或研究中使用的单位换算是否正确
- 批量转换检验结果表格中的 mg/dL 与 mmol/L 等惯用单位
- 在给出换算结果的同时提供对应的参考范围

## 工作流程

1. 先确认用户目标、必需的输入信息和不可妥协的约束条件，再展开具体工作。
2. 校验请求是否落在本技能的文档化范围内；如果任务需要依赖未文档化的假设，及早停止。
3. 使用打包好的脚本路径，或文档中给出的推理路径，仅使用实际可获得的输入信息。
4. 返回结构化结果，将假设、交付物、风险和未解决事项分开呈现。
5. 如果执行失败或输入不完整，切换到兜底路径，并明确说明是什么阻碍了任务的完整完成。

## 支持的换算

| 检验项目 | 源单位 | 目标单位 | 换算系数 | 参考范围（目标单位） |
|---------|------|----|--------|-------------------------------|
| 血糖 | mg/dL | mmol/L | ÷18.02 | 3.9–5.6 mmol/L（空腹） |
| 血糖 | mmol/L | mg/dL | ×18.02 | 70–100 mg/dL（空腹） |
| 胆固醇 | mg/dL | mmol/L | ÷38.67 | < 5.18 mmol/L（理想值） |
| 胆固醇 | mmol/L | mg/dL | ×38.67 | < 200 mg/dL（理想值） |
| 肌酐 | mg/dL | μmol/L | ×88.42 | 44–97 μmol/L（女性）、62–115 μmol/L（男性） |
| 肌酐 | μmol/L | mg/dL | ÷88.42 | 0.5–1.1 mg/dL（女性）、0.7–1.3 mg/dL（男性） |
| 血红蛋白 | g/dL | mmol/L | ÷1.611 | 7.4–9.9 mmol/L（女性）、8.7–11.2 mmol/L（男性） |
| 血红蛋白 | mmol/L | g/dL | ×1.611 | 12.0–16.0 g/dL（女性）、14.0–18.0 g/dL（男性） |
| 甘油三酯 | mg/dL | mmol/L | ÷88.57 | < 1.70 mmol/L（理想值） |
| 甘油三酯 | mmol/L | mg/dL | ×88.57 | < 150 mg/dL（理想值） |
| 尿素 | mg/dL | mmol/L | ÷2.801 | 2.5–7.1 mmol/L |
| 尿素 | mmol/L | mg/dL | ×2.801 | 7–20 mg/dL |
| 钙 | mg/dL | mmol/L | ÷4.008 | 2.15–2.55 mmol/L |
| 钙 | mmol/L | mg/dL | ×4.008 | 8.6–10.2 mg/dL |
| 钠 | mEq/L | mmol/L | ×1.0 | 136–145 mmol/L |
| 钠 | mmol/L | mEq/L | ×1.0 | 136–145 mEq/L |
| 钾 | mEq/L | mmol/L | ×1.0 | 3.5–5.0 mmol/L |
| 钾 | mmol/L | mEq/L | ×1.0 | 3.5–5.0 mEq/L |

> 说明：钠、钾均为一价离子，mEq/L 与 mmol/L 之间为 1:1 等价换算。

## 输入参数

| 参数 | 类型 | 是否必填 | 说明 |
|-----------|------|----------|-------------|
| `--value` | float | 是 | 需要换算的数值 |
| `--from-unit` | str | 是 | 源单位（例如 `mg/dL`、`mmol/L`、`umol/L`、`g/dL`、`meq/L`，也可用下划线写法如 `mg_dl`） |
| `--to-unit` | str | 是 | 目标单位 |
| `--analyte` | str | 是 | 检验项目名称，用于选择换算系数和参考范围（如 `glucose`、`cholesterol`、`creatinine`、`hemoglobin`、`triglycerides`、`urea`、`calcium`、`sodium`、`potassium`） |

## 输出格式

```json
{
  "analyte": "glucose",
  "input_value": 100.0,
  "input_unit": "mg/dL",
  "output_value": 5.5494,
  "output_unit": "mmol/L",
  "reference_range": "3.9–5.6 mmol/L (fasting)"
}
```

## 快速检查

```bash
python -m py_compile scripts/main.py
python scripts/main.py --value 100 --from-unit mg/dL --to-unit mmol/L --analyte glucose
```

## 实现说明（供脚本开发者参考）

脚本必须：

1. **解析命令行参数** —— 使用 argparse，接收 `--value`、`--from-unit`、`--to-unit`、`--analyte`，且 `--analyte` 为必填项。将解析后的参数传给 `convert()`。不要在 `main()` 中硬编码演示用的数值。
2. **CONVERSIONS 字典** —— 覆盖上表全部 18 组换算，每组包含 `factor` 和 `reference_range` 字段。键为 `(analyte, from_unit, to_unit)` 元组或等价的嵌套结构。
3. **convert() 方法** —— 返回包含 `analyte`、`input_value`、`input_unit`、`output_value`、`output_unit`、`reference_range` 的字典。
4. **不支持的单位组合** —— 如果该单位对不在 CONVERSIONS 中，打印支持的检验项目列表并以退出码 1 结束。
5. **兜底模板中的部分结果** —— 当请求了不支持的单位组合时，兜底模板中的“部分结果”字段应始终填写：`"该单位组合暂无可用的手动换算公式"`。

## 输入校验

本技能接受：带有源单位和目标单位的数值型检验数据，用于在可识别的临床检验单位体系之间换算。

如果请求不涉及在单位之间换算某个具体的数值型检验值——例如要求解读检验结果、诊断病情，或换算非检验类的量——不要继续处理，应回复：

> "医学单位换算器专用于在不同单位体系之间换算医学检验数值。你的请求似乎超出了这个范围。请提供带有源单位和目标单位的数值，或改用更适合你任务的工具。"

## 错误处理

- 如果缺少 `--value`、`--from-unit` 或 `--to-unit`，需明确指出缺失的字段，只索要这些字段。
- 如果该单位组合不受支持，列出支持的换算列表并停止。
- 如果 `--value` 不是有效数字，按以下格式拒绝：`Error: --value must be a numeric value.`
- 如果任务超出文档化的范围，应停止，不要臆测或悄悄扩大处理范围。
- 如果 `scripts/main.py` 执行失败，报告失败点，并提供手动换算公式作为兜底方案。
- 不要编造换算系数或参考范围。
