# 病历质量检查清单

本清单是记录完整性和可追溯性参考，不是诊疗规范。检查的是“材料是否记录、是否互相一致、是否有后续记录”，不是判断动物是否患病或应该接受什么治疗。

## A. 字段完整性参考

先按记录类型取适用字段；不适用写“不适用”，没有看到证据写“未提供”。

| 区块 | 可核对字段 | 记录口径 |
|---|---|---|
| 就诊背景 | 记录类型、就诊/入院/出院日期时间、时间范围、记录来源 | 区分实际发生时间、录入时间、签署时间；不混为一个时间 |
| 宠物基本信息 | 宠物代号、物种、品种（如有）、性别/绝育状态、年龄或出生日期、体重与单位 | 只核对一致性；缺字段不推断 |
| 病史信息 | 主诉、持续时间、既往记录、当前用药、过敏史、饮食/暴露史（如适用） | “未记录过敏史”不等于“无过敏” |
| 客观记录 | 生命体征、体格检查、观察结果、左右侧/部位、测量单位 | 只核对原文是否存在和前后是否一致，不判定正常或异常 |
| 检查记录 | 检查项目、开立/采样/完成时间、结果、单位、报告来源或附件索引 | “详见附件”但未提供附件时，列为来源缺口 |
| 医疗表述 | 原文评估、原文计划、风险告知或转诊记录 | 仅作为原文记录，不改写成 AI 建议 |
| 处置记录 | 处置项目、执行时间、执行状态、记录人、相关观察 | 只检查状态和时间是否可追踪，不判断处置是否正确 |
| 后续事项 | 复查、回访、预约、转诊反馈、结果告知、责任人、截止时间 | 找后续完成/取消/改期/结果记录；找不到写“未见闭环记录” |

## B. 前后矛盾检查

优先逐项比较以下对象：

1. 同一宠物代号与就诊上下文是否一致；
2. 物种、性别、绝育状态、年龄、体重和单位是否一致；
3. 记录日期、时间、时区说明和事件顺序是否一致；
4. 检查状态是否同时出现“未完成”和“已完成”；
5. 处置/用药记录的名称、规格、单位、频次、途径、开始/结束状态是否前后一致；
6. 症状、体征、检查结果或原文评估是否出现未解释的互斥表述；
7. 预约、转诊、回访和结果反馈的状态是否互相冲突。

发现冲突时，用以下格式保留证据：

```text
Q-xxx｜前后矛盾｜优先级
记录 A：位置 + 原文值
记录 B：位置 + 原文值
当前判断：矛盾待核对，不选择任何一方
核对动作：回看原始系统/附件/责任人确认
```

“单位不同”先标为单位待核对；除非用户明确授权且原始单位可靠，不自行换算、四舍五入或改写。

## C. 时间异常检查

以下情况只作为待核对信号：

- 日期晚于声明的审计截止时间或明显位于未来；
- 采样、检查、报告、反馈、签署和就诊的顺序互相冲突；
- 计划日期已过，但材料范围内没有完成、取消或改期记录；
- 同一事件存在两个不同时间，且未说明是实际时间、录入时间还是签署时间；
- 时间格式、时区或日期缺失，导致无法比较先后。

不要因为系统补录、批量签署或时区差异直接判定记录造假；输出“时间异常待核对”，并指出需要回看的时间字段。

## D. 未闭环检查

仅从原文已经出现的事项出发，建立：`事项 → 责任人 → 截止时间 → 结果/状态`。下列情况可列为未闭环：

- 明确写了“待复查/待回访/待补报告”，但未见后续记录；
- 已开立检查，但材料中没有结果或报告来源；
- 已写转诊，但没有接收、反馈或取消记录；
- 已记录预约或提醒，但没有到诊、取消、改期或结果状态；
- 已写需要告知/签署/确认，但未见完成状态、责任人或时间；
- 发现冲突并提出核对，但没有确认记录。

不要把“未见后续记录”写成“未执行”。如果材料截止时间早于事项截止时间，标为“当前范围无法判断”。

## E. 记录质量优先级

优先级衡量“先核对什么”，不是临床危险等级：

- **立即人工核对**：身份/关键上下文、药品或过敏信息、关键检查结果、重量/单位或时间冲突可能影响记录可靠性；只要求回看原始记录并交由相应责任人确认。
- **优先核对**：附件、检查结果、转诊、复查、预约、回访或结果反馈缺口影响事项追踪。
- **一般核对**：一般字段、格式、索引或不影响当前阅读的辅助信息缺口。

涉及具体动物的诊疗信息时，责任人栏补充“需执业兽医复核”，但不写诊断或治疗方案。
