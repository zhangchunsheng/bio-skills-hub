# 药剂科政策文件分析 · 任务下发 · 检查闭环（skill）

> 适用角色：三甲医院药剂科负责人。工作性质——不直接做数据，而是**解析文件 → 拆分任务（指定人员/具体工作/交付时间）→ 规定要求范围 → 日常检查 → 闭环**。本 skill 把这套闭环固化，支持用户"套入文件直接产出所需内容"。

## 一、闭环工作流（6 步）

收到政策文件（多为 PDF 手册）与数据采集表（多为 Excel）后，按序执行：

1. **解析政策手册（PDF）**：逐页提取每个指标的结构化字段：
   - 指标序号 + 名称、指标属性、计量单位
   - 指标定义、计算方法（分子/分母公式）、指标说明（口径）
   - 指标导向（提高/降低）、指标来源（填报平台）、指标解释部门
   - 关键阈值/红线（如抽样率下限、DDDs≤40、基药占比≥60%）
2. **解析数据采集表（Excel）**：提取子指标树（父指标→分子/分母→延伸指标）、行次、项目定义、主管科室，重点读取**备注/责任列**（用户常在 Excel 内标注"西药房/药库"分工）。
3. **建立责任矩阵并补全未标注项**：按备注拆分药房/药库；对 Excel 未标注责任岗位的父指标，**按数据口径归并并明确说明理由**，请用户确认可调整。记录每个指标的：导向、目标基线/阈值、主责、配合。
4. **产出《数据提交要求要点》（按岗位分册）**：每个子指标给出 数据项(分子/分母)、单位、计算口径、数据来源系统、上报周期；并附**计算示例模板**（参考上报周期列，如 2023全年/2024/2025/2026上半年），给出占位与示例算法。若 Excel 数据列为空，说明其为待填模板。
5. **产出《工作规范》**：对照手册列出各岗位**日常应常态备存的资料清单** + 工作流程与时限 + 质量基线/达标要求。
6. **产出《季度考核工作制度》（药房版 + 药库版）**：含考核维度权重、本岗位指标考核明细、处罚扣款标准（建议基准，注明由科室依绩效方案核定）、闭环流程。

此外，闭环还应生成一份**日常检查清单**（月度/季度自查表），便于负责人随手核对，见第四节。

## 二、责任拆分逻辑（默认规则，可覆盖）

- **西药房（含门诊药房、住院药房）**：处方点评类、门诊/住院基本药物使用类（数据源于处方/医嘱/发药）。例：指标16、18、19。
- **药库（采购/验收/保管/发放）**：抗菌药物消耗(DDD)、基本药物采购品种/金额、集采采购与使用。例：指标17、20、21。
- 跨岗位指标（如集采使用比例=采购+使用）：主责一方（药库），另一方配合提供使用量数据。
- Excel 备注列是**最高优先级**依据；无备注时按上述口径归并并标注"原表未标注，已按口径归并"。

## 三、输出物与排版标准（用户偏好）

默认产出 4 个 Word（.docx）：
- `A_数据提交要求要点_药房药库分册.docx`
- `B_药剂科国考指标工作规范.docx`
- `C_季度考核制度_药房版.docx`
- `C_季度考核制度_药库版.docx`

排版规范（用户明确要求）：
- 标题色 **深蓝 #1F4E79**，中文 **宋体**（正文中文字体 eastAsia=宋体），1.5 倍行距。
- 一级标题黑体14号加粗深蓝，二级标题黑体12号加粗深蓝，正文宋体10.5号。
- 表格：表头深蓝底白字，网格线，居中。
- 生成用 python-docx，在**隔离 venv** 中安装（见 assets/doc_style.py 复用样式函数）。

**环境注意**：本机为 Windows，python 在隔离 venv：`C:/Users/Administrator/.workbuddy/binaries/python/envs/default/Scripts/python.exe`（先用 `.../versions/3.13.12/python.exe -m venv` 建好）。解析 PDF 用 pdfplumber，Excel 用 openpyxl，Word 用 python-docx。网络共享路径(UNC `\\10.169.42.93\...`)在 Git Bash 下不可直接访问，可用 PowerShell `Copy-Item` 先拷到本地工作区再处理。

## 四、日常检查清单（闭环核对用，附在交付物或单独给出）

- [ ] 本季各指标数据是否按时（月度次月5日 / 季度末月25日）提交
- [ ] 分子/分母口径是否与手册一致、底表是否齐全可追溯
- [ ] 指标是否达导向/阈值（17 是否 ≤40 DDDs；基药品种占比是否 ≥60%）
- [ ] 平台账号与医院识别信息是否一致（绩效监测管理平台可提取）
- [ ] 未达标项是否下达整改通知并在限期跟踪验证

## 五、本次示例（exemplar，供模仿结构）

输入：三级国考手册PDF（药剂科6项指标：16处方点评比例、17抗菌药物使用强度DDDs、18门诊基药处方占比、19住院基药使用率、20基药采购品种占比、21集采中标药品使用比例）+ 数据采集Excel（药剂科，40行，备注标 16/18=西药房、17/20=药库，19/21未标注→按口径归并）。
输出：4 份 Word，结构见 `C:\Users\Administrator\WorkBuddy\2026-08-20-09-50-35\` 下同名文件。阈值要点：16（门急诊抽样≥1‰且月≥100张、病房≥1%且月≥30份）、17（≤40DDDs）、20（三级公立医院基药品种占比≥60%）。

## 六、执行原则

- 所有判断标注依据（引用手册原文/Excel行），不臆造数据；Excel 空数据列明确标注"待填模板"。
- 扣款金额为"建议基准"，必须提示用户依本院绩效方案核定。
- 未标注责任的指标必须显式标注并给出归并理由，交用户确认。
- 交付前用 python-docx 回读校验表格/段落数量，确保文件可打开。
