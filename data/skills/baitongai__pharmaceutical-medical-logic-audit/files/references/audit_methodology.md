# 逻辑审计方法论详述

## 1. 断言提取操作指南

### 1.1 断言识别词库

以下词汇出现时，须提取所在句子为断言：

| 类别 | 触发词 |
|------|--------|
| **证实类** | 证实、显示、表明、证明、验证、确认、确定 |
| **比较类** | 优于、更安全、更有效、更经济、更高、更低、显著优于、优于竞品 |
| **机制类** | 通过、基于、由于、因其含有、作用于、靶向、调控 |
| **效果类** | 降低、改善、减少、增加、提升、保护、预防、治疗 |
| **绝对类** | 最、唯一、100%、完全、根治、首选、唯一选择 |
| **数字类** | XX%、XX倍、XX例患者（须追溯来源） |
| **推断类** | 因此、所以、意味着、说明、提示（须检查推断逻辑） |

### 1.2 隐含断言显式化

有些断言不直接说出来，但逻辑上隐含了。须显式化后提取：

| 原文 | 隐含断言 | 提取方式 |
|------|----------|----------|
| "为不耐受X的患者处方Y" | Y比X更耐受 | 显式化后提取为独立断言 |
| "含X成分，因此具有Y效果" | X成分→Y效果的因果关系 | 提取因果断言 |
| "经多年临床使用验证" | 有临床研究数据支撑 | 追溯"验证"的具体数据 |
| "受到专家好评" | 有专家背书且无利益冲突 | 追溯专家身份与证据 |

### 1.3 断言编号规则

- 按文档中出现顺序编号：C1、C2、C3……
- 跨版本重复出现的断言只编号一次，在"所在位置"列标注所有出现位置
- SWOT 中的断言用 W1/W2（弱点）、S1/S2（优势）前缀，便于交叉检查

## 2. 证据分级操作标准

### 2.1 GRADE 证据等级映射

| GRADE 等级 | 定义 | 对应标注 | 推广使用建议 |
|------------|------|----------|-------------|
| **高** | RCT / Meta 分析，结果稳健 | 🟢 证据充分 | 可直接用于推广 |
| **中** | RCT 但有方法学局限，或大样本观察性研究 | 🟢 证据充分 | 可用于推广，标注研究类型 |
| **低** | 观察性研究 / 小样本 RCT / 动物实验 | 🟡 证据有限 | 须标注"基于XX研究，需进一步验证" |
| **极低** | 专家意见 / 理论推测 / 无直接证据 | 🔴 证据不足 | 不得作为推广断言，须修改措辞 |

### 2.2 证据类型层级

```
        ┌─────────────┐
        │  Meta 分析   │  ← 可直接推广
        │  / 系统综述   │
        └──────┬──────┘
               │
        ┌──────┴──────┐
        │  大样本 RCT  │  ← 可直接推广
        └──────┬──────┘
               │
        ┌──────┴──────┐
        │  小样本 RCT  │  ← 须标注样本量
        └──────┬──────┘
               │
        ┌──────┴──────┐
        │  队列研究    │  ← 须标注研究类型
        │  / 病例对照  │
        └──────┬──────┘
               │
        ┌──────┴──────┐
        │  动物实验    │  ← 须标注"基于动物实验"
        │  / 细胞实验  │
        └──────┬──────┘
               │
        ┌──────┴──────┐
        │  网络药理学  │  ← 须标注"机制假说"
        │  / 计算机模拟│
        └──────┬──────┘
               │
        ┌──────┴──────┐
        │  专家意见    │  ← 不可作为推广断言
        │  / 理论推测  │
        └─────────────┘
```

### 2.3 证据追溯检查清单

每个断言须回答以下问题：

- [ ] 数据来源是哪篇文献？（作者/期刊/年份/DOI）
- [ ] 研究设计是什么？（RCT/队列/动物/细胞/模拟）
- [ ] 样本量多少？
- [ ] 主要终点是什么？
- [ ] P值和置信区间是多少？
- [ ] 研究人群与推广人群是否匹配？
- [ ] 是否有头对头比较？（涉及竞品比较时）
- [ ] 是否有 AE 监测数据？（涉及安全性断言时）
- [ ] 是否有药物经济学评价？（涉及经济性断言时）

**任一问题无法回答 → 证据等级降级**

## 3. 逻辑谬误检测操作指南

### 3.1 循环论证检测

**检测方法**：画出断言 A 的因果链，如果因果链形成闭环（A→B→A），即为循环论证。

**示例**：
- 断言："复方X药性平和"
- 支撑："因为组方温和"
- 支撑组方温和："因为药性平和"
- → 循环论证 ⚫

**修复**：寻找独立于"药性"的外部证据（如 AE 发生率数据）

### 3.2 过度外推检测

**检测方法**：比较证据来源的样本/条件与断言的适用范围，如果范围扩大，即为过度外推。

**常见外推路径**：
- 动物实验 → 人体疗效（最常见）
- 单一人群 → 所有人群（如糖尿病患者 → 所有心血管患者）
- 短期研究 → 长期效果（如 4 周研究 → "适合长期服用"）
- 替代终点 → 硬终点（如炎症因子下降 → "降低心血管事件"）
- 体外实验 → 体内效果（如细胞实验 → 临床疗效）

**修复**：在断言后标注证据来源的范围限制

### 3.3 自相矛盾检测

**检测方法**：将文档中所有断言列出，交叉检查是否存在直接冲突。

**高频矛盾模式**：
| 断言 A（定位/优势） | 断言 B（SWOT/弱点） | 矛盾类型 |
|---------------------|---------------------|----------|
| "经过证实" | "缺少大样本 RCT" | 证据矛盾 |
| "更安全" | "未做安全性随访" | 安全性矛盾 |
| "更经济" | "未做药物经济学评价" | 经济性矛盾 |
| "唯一选择" | "竞品也有类似机制" | 差异化矛盾 |

**修复**：统一措辞，消除矛盾——以证据等级低的一方为准

### 3.4 因果倒置检测

**检测方法**：检查"因为A所以B"的断言中，是否可能是"B导致A"或"A和B有共同原因C"。

**示例**：
- 断言："用药组患者好转率高，证明药物有效"
- 倒置可能："好转率高的患者更倾向于坚持用药"（依从性偏倚）
- 混杂可能："用药组病情更轻"（选择偏倚）

**修复**：须有 RCT 控制混杂因素，或使用倾向性评分匹配

### 3.5 采樱桃偏差检测

**检测方法**：检查证据列表是否只包含支持性证据，遗漏了反面证据。

**检查要点**：
- 同一机制是否有阴性结果的研究？
- 同一终点是否有不同结论的文献？
- 竞品是否有反驳该断言的数据？
- 是否只引用了有利亚组分析结果？

**修复**：补充反面证据，或标注"目前仅检索到支持性证据"

## 4. 合规风险扫描检查清单

### 4.1 超适应症检测

| 检测项 | 检测方法 | 风险等级 |
|--------|----------|----------|
| 适应症超出获批范围 | 比对 NMPA 批准的适应症 vs 推广材料声称的适应症 | 🔴 极高 |
| 人群超出获批范围 | 比对获批人群 vs 推广目标人群 | 🔴 极高 |
| 用法用量超出说明书 | 比对说明书用法 vs 推广建议用法 | 🔴 极高 |

### 4.2 绝对化用语检测

| 禁用词 | 检测规则 | 风险等级 |
|--------|----------|----------|
| 最 / 唯一 / 第一 | 全文搜索 | 🔴 极高 |
| 100% / 完全 / 根治 | 全文搜索 | 🔴 极高 |
| 首选 / 必选 / 唯一选择 | 全文搜索 | 🔴 极高 |
| 无副作用 / 绝对安全 / 无毒 | 全文搜索 | 🔴 极高 |
| 彻底 / 永不复发 / 断根 | 全文搜索 | 🔴 极高 |

### 4.3 比较性 claims 检测

| 检测项 | 检测方法 | 风险等级 |
|--------|----------|----------|
| 与竞品比较无头对头数据 | 检查比较断言是否有 RCT 支撑 | 🔴 高 |
| 暗示竞品不安全/无效 | 检查是否有"竞品有X问题"的表述 | 🟡 中-高 |
| 选择性比较（只比有利维度） | 检查比较维度是否全面 | 🟡 中 |

### 4.4 数据引用规范检测

| 检测项 | 检测方法 | 风险等级 |
|--------|----------|----------|
| 数据无文献来源 | 检查每个数字/百分比是否有引用 | 🔴 高 |
| 来源为"品牌定位报告引用" | 追溯到原始文献 | 🔴 高 |
| 引用过时数据（>10年） | 检查文献发表年份 | 🟡 中 |
| 引用非同行评审来源 | 检查期刊是否为同行评审 | 🟡 中 |

## 5. 修复策略矩阵

### 5.1 措辞修复策略

| 原文 | 修复后 | 适用场景 |
|------|--------|----------|
| "经过证实" | "经前临床研究提示" | 证据仅为动物/细胞实验 |
| "更安全" | "组方不含X，理论上刺激性较低，安全性需进一步验证" | 无头对头数据 |
| "更经济" | "日治疗费用低于部分竞品，药物经济学评价待开展" | 无 CEA 研究 |
| "显著降低" | "在XX研究中观察到降低趋势（P=XX）" | 有数据但样本量小 |
| "唯一选择" | "目前少数具有X特征的选择之一" | 绝对化用语 |
| "100%有效" | "在XX研究中有效率为XX%" | 绝对化用语 |
| "无副作用" | "常见不良反应包括XX（发生率XX%），多数为轻度" | 安全性绝对化 |

### 5.2 证据补全策略

| 证据缺口 | 补全研究类型 | 预期周期 | 优先级 |
|----------|-------------|----------|--------|
| 缺头对头安全性比较 | 多中心 RCT，6个月 | 18-24月 | P1 |
| 缺大样本疗效 RCT | 多中心 RCT | 24-36月 | P1 |
| 缺药物经济学评价 | CEA / CMA | 12月 | P2 |
| 缺长期安全性随访 | 前瞻性队列 | 12-24月 | P1 |
| 缺真实世界证据 | 回顾性 RWE | 6-12月 | P2 |
| 缺硬终点研究 | RCT，硬终点 | 36-48月 | P3 |
| 机制需临床验证 | 生物标志物研究 | 12-18月 | P3 |

### 5.3 修复优先级判定流程

```
发现断言问题
    │
    ├─ 触及合规红线？─是→ P0（发布前必须修复）
    │                    │
    │                    └─ 修复方式：删除/改措辞（24-48h）
    │
    ├─ 核心卖点证据不足？─是→ P0/P1
    │                       │
    │                       ├─ 可追溯文献→ P0（48h内追溯）
    │                       └─ 需新研究→ P1（启动研究）
    │
    ├─ 安全性断言无数据？─是→ P1
    │                       │
    │                       └─ 修复方式：改措辞+启动安全性研究
    │
    ├─ 经济性断言无CEA？─是→ P2
    │                       │
    │                       └─ 修复方式：改措辞+启动CEA
    │
    └─ 机制断言需验证？─是→ P3
                            │
                            └─ 修复方式：标注"机制假说"+启动验证研究
```

## 6. 质疑话术模板

### 6.1 疗效性断言质疑模板

> "你说{断言内容}——你的证据是什么？你做过{研究类型}吗？样本量多少？主要终点是什么？P值和置信区间是多少？你用的是替代终点还是硬终点？如果是动物实验，你凭什么外推到人体？"

### 6.2 安全性断言质疑模板

> "你说{安全性断言}——你的 AE 监测数据在哪？随访多长时间？对照组是谁？你做过与{竞品}的头对头安全性比较吗？没有头对头比较，你怎么得出'更安全'的结论？"

### 6.3 经济性断言质疑模板

> "你说{经济性断言}——你做过药物经济学评价吗？是 CMA 还是 CEA？你的成本-效果比是多少？如果疗效不如竞品，总治疗费用可能反而更高。你只比日治疗费用，不比成本-效果比，这在药物经济学上站得住吗？"

### 6.4 差异化断言质疑模板

> "你说{差异化断言}——你的差异化和{竞品}有什么本质区别？{竞品}也有类似机制研究。你的差异化是临床验证过的，还是理论推测？你做过头对头比较吗？"

### 6.5 逻辑矛盾质疑模板

> "你在{位置A}说{断言1}，但在{位置B}又说{断言2}——这两个断言直接矛盾。你不能在同一份报告里既说{A}又说{B}。这是证据问题还是逻辑问题？"

## 7. 边缘案例处理

### 7.1 中药特殊性问题

| 问题 | 处理方式 |
|------|----------|
| "基于中医理论推断" | 标注"中医理论推断，非现代循证医学证据"，等级不高于 🟡 |
| "君臣佐使配伍逻辑" | 可作为机制解释，不可作为疗效/安全性证据 |
| "多年临床使用经验" | 标注"传统使用经验，非临床研究证据"，等级不高于 🟡 |
| "网络药理学预测靶点" | 标注"计算机模拟结果，机制假说"，等级不高于 🟡 |

### 7.2 真实世界证据（RWE）问题

| 问题 | 处理方式 |
|------|----------|
| RWE 作为疗效证据 | 须评估偏倚风险（选择偏倚/混杂因素/信息偏倚），等级通常为 🟡 |
| RWE 作为安全性证据 | 可接受，但须标注"基于真实世界观察，非 RCT" |
| 回顾性 RWE | 须评估数据完整性和随访偏倚 |

### 7.3 间接比较证据

| 问题 | 处理方式 |
|------|----------|
| 间接治疗比较（ITC） | 可接受但标注"间接比较，非头对头 RCT"，等级不高于 🟡 |
| 网状 Meta 分析 | 可接受但标注"基于间接比较的网络分析"，须检查假设一致性 |

### 7.4 正在进行的临床研究

| 问题 | 处理方式 |
|------|----------|
| III期临床进行中 | 不可引用未发表数据做推广断言，可标注"III期临床进行中，结果待出" |
| 预印本数据 | 不可作为推广证据（未经同行评审），审计中标注"预印本，未经同行评审" |

## 8. 审计报告质量自检清单

审计报告交付前，须自检以下项目：

- [ ] 所有断言已提取并编号（无遗漏）
- [ ] 每个断言已标注四级证据等级（🟢🟡🔴⚫）
- [ ] 每个断言有"我的质疑"段落（引用块格式）
- [ ] 每个断言有具体修复建议（非空话）
- [ ] 总览表先于逐条审计
- [ ] 修复行动分为即刻/中长期两类
- [ ] P0 级问题已标注"发布前必须修复"
- [ ] 合规红线问题已全部标红
- [ ] SWOT 与定位断言已交叉检查
- [ ] 审计声明已附在报告末尾
- [ ] 证据等级标注从严不从宽
- [ ] 无"建议进一步研究"式空话（须指明具体研究类型）
