# 权威数据源与核对方法（药品不良反应）

本文件定义本 skill 在撰写任何不良反应内容时**必须**参考的权威数据来源，以及核对流程。
临床药师的核心诉求是「数据准确、不能随意联想」，因此：凡是涉及「某药品有哪些不良反应 / 发生频率 / 严重程度 / 禁忌」的陈述，都必须能追到一个可核验的权威来源；追不到的一律标注「待人工核实」，绝不允许凭模型记忆编造。

---

## 一、数据源分级（按权威度）

### 第一级：法定/监管一级来源（最高权威，优先使用）
| 来源 | 网址 | 适用 | 权威度 |
|------|------|------|--------|
| 国家药品监督管理局（NMPA） | https://www.nmpa.gov.cn/ | 药品说明书、批准文号、法规、公告 | ★★★★★ |
| 国家药品不良反应监测中心（CDR） | https://www.cdr-adr.org.cn/ | 《药品不良反应信息通报》、公众查询、监测数据 | ★★★★★ |
| 国家药品监督管理局药品审评中心（CDE） | https://www.cde.org.cn/ | 审评报告、个药安全性信息、临床试验数据 | ★★★★★ |
| 药品法定说明书（最近一次核准版本） | 经 NMPA 数据库核发的说明书 | 「已知不良反应」的法定清单 | ★★★★★ |

### 第二级：国际监管/标准来源
| 来源 | 网址 | 适用 |
|------|------|------|
| 世界卫生组织 UMC（VigiBase / WHODrug / MedDRA 维护方） | https://who-umc.org/ | 国际信号、MedDRA 术语、个药安全性综述 |
| FDA 说明书（Labeling） | https://labels.fda.gov/ | 同通用名药品的美方安全性信息（仅供参考，需说明中外差异） |
| EMA / EudraVigilance | https://www.ema.europa.eu/ | 欧盟安全性信息 |

### 第三级：学术/文献来源（作背景与信号支撑，不作法定结论）
- 中国知网（CNKI）、万方、维普：国内个药 ADR 文献、医院监测分析
- PubMed：国际 RCT / 队列 / 病例系列
- 文献结论须注明「研究类型 + 样本量 + 发表年份 + 期刊」，且仅作参考信号，不能直接等同于药品法定安全性结论。

### 明确不采纳为权威来源
- 商业用药 App（如用药助手等）的非官方整理内容——除非其直接引用并标注了说明书出处。
- 患者社区、论坛、自媒体、百科类内容。
- 模型自身记忆中的「某药常见副作用」——**一律视为待核实，不得直接写入报告。**

---

## 二、核对流程（每次必走）

当报告中出现任一药品的安全性陈述时，按以下顺序核对：

1. **锁定药品身份**：同时记录「通用名 + 商品名 + 生产厂家 + 批准文号」，避免同名不同厂导致的说明书差异。
2. **调取法定说明书**：用 WebSearch/WebFetch 从 NMPA 数据库或 CDR 获取该药品**最新核准版**说明书，提取【不良反应】章节原文。
3. **区分已知 / 新的**：
   - 出现在说明书【不良反应】中的 → 标注为「已知不良反应（说明书收录）」。
   - 未出现在说明书但出现在 CDR《信息通报》或文献 → 标注为「新的 / 新的一般 / 新的严重」，提示需按《办法》上报。
4. **交叉信号**：对严重、死亡、聚集性事件，额外检索 CDR 信息通报与 WHO UMC，确认是否存在已知安全信号。
5. **标注来源**：每条关键安全性陈述后附「来源：名称 + 获取日期 + URL/版本」。无法获取时写「⚠️ 待人工核实：未能从权威来源核验，请药师确认」。

---

## 三、常见检索式（WebSearch 用）

- 药品说明书：`"<通用名>" 药品说明书 site:nmpa.gov.cn`
- 不良反应信息通报：`"<通用名>" 药品不良反应信息通报 site:cdr-adr.org.cn`
- 个药监测分析：`"<通用名>" 不良反应 监测 分析`
- 严重事件信号：`"<通用名>" 严重不良反应 死亡`

检索结果以一级来源为优先；若只找到三级来源，须在报告中降级标注并提示药师终审。

---

## 四、准确性红线（不可违背）

- 不得凭记忆断言某药「常见/罕见」某不良反应及其频率，除非有说明书或权威文献的频率数据。
- 不得把不同厂家、不同剂型的说明书混为一谈。
- 不得把国外说明书结论直接套用于国内药品而不说明差异。
- 任何「待核实」项都必须保留在报告中交药师终审，不得悄悄删除或替换为看似合理的猜测。
