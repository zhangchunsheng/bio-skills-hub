# 报告模板与结构指引

本 skill 支持四类报告。每种报告在 `assets/templates/` 下有可直接复制填充的 Markdown 模板文件。下表说明每类报告的**目的、核心章节、必须核验项**。撰写时先复制对应模板，再逐项填充，未核到的项保留「待核实」占位。

## 1. 个例药品不良反应报告（ICSR）— `assets/templates/icsr_template.md`
- 目的：单例病例的结构化记录与上报草稿。
- 核心章节：患者信息（脱敏）｜可疑药品（通用名/商品名/批号/用法用量/起止时间）｜不良反应过程（发生时间、表现、MedDRA PT/SOC、严重程度）｜处置与转归｜合并用药｜因果关系评价（WHO 五分法 + Naranjo 计分）｜关联性结论｜报告人/审核人。
- 必核验：不良反应是否属于说明书【不良反应】已知项；严重程度判定；关联性评价；是否为新的/严重。

## 2. 季度 / 年度汇总分析报告 — `assets/templates/quarterly_template.md`
- 目的：一段时间内本机构 ADR 监测的汇总与趋势分析。
- 核心章节：统计期与数据来源｜总体指标（总例数、新的例数、严重例数及占比）｜按药品分布（Top N）｜按 ADR 类型/SOC 分布｜按科室/人群分布｜按关联性评价分布｜按转归分布｜重点信号分析（新出现、聚集、死亡）｜问题与改进建议。
- 必核验：统计口径与「严重/新的」定义一致；Top 药品的安全性结论须引用权威来源；趋势判断基于数据而非臆测。

## 3. 定期安全性更新报告（PSUR）— `assets/templates/psur_template.md`
- 目的：面向监管/持有人的定期获益-风险评估。
- 核心章节：报告期与药品基本信息｜安全性数据源（说明书、SRS、文献、研究）｜累计暴露量｜非预期严重 ADR 列表｜信号检测与评估｜获益-风险结论｜风险管理行动。
- 必核验：所有安全性结论须对应数据源并标注；「非预期」须对照最新核准说明书；不得下超越数据的获益-风险结论。

## 4. 聚集性 / 严重事件上报 — `assets/templates/cluster_template.md`
- 目的：短期内同品种/同批号集中出现的严重 ADR 的紧急上报与处置。
- 核心章节：事件概述（时间、地点、涉及例数）｜涉及药品（通用名/批号/来源）｜病例列表摘要｜共同特征分析｜初步因果关系｜已采取/拟采取处置（停用、封存、上报）｜后续监测计划。
- 必核验：批号与来源链可溯；是否触发「聚集性事件」上报阈值；处置措施符合 GVP 与《办法》。

## 通用撰写纪律
- 每一安全性陈述要么有来源标注，要么标「待核实」。
- 区分「AI 起草」与「药师终审」：模板末尾保留审核签字栏。
- 数字统计以 `scripts/structure_cases.py` 输出为准，避免手工加总数错。
