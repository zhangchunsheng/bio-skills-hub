# 因果关系评价方法

因果关系评价是判断「该不良反应是否由该药品引起」的核心环节，直接决定报告性质（是否上报、是否归为新的严重）。本文件提供两种常用量表的操作方法。

> 评价结论属专业判断，AI 可辅助计分与整理，但**最终关联性判定应由药师/医师终审签字**。

## 一、Naranjo 量表（计分法，适合个例）

对以下 10 个问题回答「是/否/不知道」，按规则计分：

| # | 问题 | 是 | 否 | 不知道 |
|---|------|----|----|--------|
| 1 | 该反应之前有无关于该药的明确报告？ | +1 | 0 | 0 |
| 2 | 该反应在用药后是否出现？ | +2 | -1 | 0 |
| 3 | 停药或减量后反应是否减轻？ | +1 | 0 | 0 |
| 4 | 再次用药反应是否再现？ | +2 | -1 | 0 |
| 5 | 是否存在其他非药物原因可解释？ | -1 | +2 | 0 |
| 6 | 给安慰剂后反应是否再现？ | -1 | +1 | 0 |
| 7 | 该药血药浓度是否达中毒水平？ | +1 | 0 | 0 |
| 8 | 剂量与反应是否呈正相关？ | +1 | 0 | 0 |
| 9 | 该反应是否与已知药理一致？ | +1 | 0 | 0 |
| 10 | 是否有客观证据支持？ | +1 | 0 | 0 |

**计分判定：**
- ≥ 9 分 → 肯定（Definite）
- 5–8 分 → 很可能（Probable）
- 1–4 分 → 可能（Possible）
- ≤ 0 分 → 可疑（Doubtful）

## 二、WHO 因果关联度（分类法，国内监测常用）

按国内《药品不良反应报告和监测管理办法》采用五分法：

| 等级 | 含义 |
|------|------|
| 肯定 | 用药时间顺序合理；停药后反应停止或迅速减轻；再次用药反应再现；与原患疾病无关 |
| 很可能 | 时间顺序合理；反应符合该药已知 ADR；停药后反应减轻/消失；无法用原患疾病解释 |
| 可能 | 时间顺序合理；反应与已知 ADR 相似；原患疾病或其他治疗也可造成 |
| 可能无关 | 时间顺序不密切；反应与已知 ADR 无关；可用原患疾病解释 |
| 待评价 / 无法评价 | 资料不全或无法判定 |

## 三、使用建议

- 个例报告（ICSR）建议同时给出 WHO 五分法结论，并在备注中附 Naranjo 计分过程，便于复核。
- 怀疑药品与合并用药并存时，须分别评价每一味药的关联性。
- 关联性评价结论必须写入报告「关联性评价」字段，不得空缺。
