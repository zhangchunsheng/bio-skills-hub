# 医药推广合规审查参考

## 核心法规依据

- 《中华人民共和国药品管理法》—— 对药品广告、处方药推广的要求
- 《中华人民共和国广告法》—— 对广告内容的禁止性规定
- 《药品广告审查发布标准》—— 药品广告发布的具体规范
- 《医药行业合规营销规范》—— 行业自律性推广准则
- 《关于印发医疗机构药事管理规定的通知》—— 处方药管理的相关规定

## 禁止性表述清单（红线）

### 绝对化用语（绝对禁止）
| 违规词 | 正确替代 |
|--------|---------|
| 首选 | "可供选择的方案之一" / "临床常见选择" |
| 最佳 | "有效" / "可靠的" |
| 金标准 | 不适用，换用具体描述 |
| 特效 | "有效" / "显著改善" |
| 独一无二 | "具有特点" |
| 万能 | 不适用 |
| 第一 / 领先 / 王牌 | "具有丰富临床应用经验" |
| 安全无毒 | "安全性良好" / "耐受性良好" |
| 根治 / 治愈 | 不适用（药品不宣称治愈） |

### 不当比较（绝对禁止）
- ❌ "优于XX产品" → ✅ "在XX维度显示了临床价值"
- ❌ "副作用比XX少" → ✅ "安全性数据良好"
- ❌ "XX不推荐，XXX才是正确选择" → ✅ 仅正面陈述产品特点
- ❌ 直接引用竞品名称做负面对比

### 功效声称（严格控制）
- ❌ 超出说明书的适应症范围
- ❌ 未获批的联合用药推荐
- ❌ 由机制推理但无临床证据的功效
- ❌ 扩大患者人群（如从"辅助治疗"暗示为"主要治疗"）

## 合规表述指南

### 功效表述
```
✅ "[产品]用于[说明书原文所载适应症]"
✅ "临床研究显示，[产品]可改善[适应症相关症状]"
✅ "适用于中医辨证为[证型]的患者"
✅ "在[XX研究]中观察到[XX指标]的改善"
```

### 证据引用
```
✅ "一项纳入XX例患者的RCT研究（GRADE等级：高）显示..."
✅ "根据《XX指南》推荐..."
✅ "系统评价/Meta分析（纳入X项RCT，GRADE等级：高）结论显示..."
❌ 不标注来源地引用数据
❌ 夸大研究结论的说服力
```

### 安全性陈述
```
✅ "药品说明书示：不良反应包括..."
✅ "临床研究中常见的不良反应为..."
✅ "在XX例患者中观察到的安全性数据表明..."
❌ 宣称"无任何副作用"
❌ 暗示绝对安全
```

### 患者描述
```
✅ "适用于中医辨证属[证型]的患者，临床表现为..."
✅ "对于存在[症状]的患者，可考虑..."
❌ "所有患者都适合"（绝对化）
❌ 暗示不使用的医生"不负责任"（道德绑架）
```

## 合规审核流程

### 逐页审核清单

每一页都要问以下问题：

| 检查项 | 是/否/不适用 |
|--------|-------------|
| 该页是否包含产品功效声明？ | ☐ 是 ☐ 否 |
| — 如果是，是否在说明书范围内？ | ☐ 是 ☐ 否 |
| 该页是否包含与其他产品的比较？ | ☐ 是 ☐ 否 |
| — 如果是，是否未使用贬低性语言？ | ☐ 是 ☐ 否 |
| 该页是否使用了证据引用？ | ☐ 是 ☐ 否 |
| — 如果是，是否标注了来源和GRADE级别？ | ☐ 是 ☐ 否 |
| 该页是否存在绝对化用语？ | ☐ 是 ☐ 否 |
| 该页是否包含用药推荐？ | ☐ 是 ☐ 否 |
| — 如果是，是否与说明书一致？ | ☐ 是 ☐ 否 |

### 终审检查清单

在做完逐页检查后，再做一次全局检查：

- [ ] 全篇核心论点是否有超出说明书范围的内容？
- [ ] 是否存在与竞品的直接比较？
- [ ] 所有数据是否可溯源的公开来源？
- [ ] 患者人群描述是否结合了辨证/临床诊断标准？
- [ ] 是否存在"HCP不处方则患者受损"的暗示？
- [ ] 整体语气是"平等学术交流"还是"推销"？

## 合规改写示例

### 示例1：违规表述改写

**违规版**：
> "当归补血胶囊是放化疗后贫血患者的最佳选择，相比其他补血产品疗效更优，且无任何毒副作用。"

**合规保守版**：
> "当归补血胶囊【功能主治】用于气血两虚证。临床研究数据显示，在肿瘤放化疗后辨证为气血两虚的患者中，该药可改善贫血相关指标。药品说明书提示，该药不良反应少。"

**合规营销版**：
> "对于肿瘤放化疗后出现贫血、疲乏，中医辨证属气血两虚的患者，当归补血胶囊提供了一种基于传统名方的对症干预选择。一项纳入XX例患者的RCT（GRADE等级：中）显示，该药可改善血红蛋白水平和疲乏评分。药品说明书提示不良反应较少。"

### 示例2：证型与人群表述规范

**不规范的表述**：
> "适用于所有放化疗患者"

**规范的表述**：
> "适用于放化疗后出现神疲乏力、面色少华、头晕心悸、舌淡脉细等气血两虚证候的患者"
