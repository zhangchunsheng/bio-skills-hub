# STEPS框架完整参考

## 概述

STEPS框架是科室会PPT内容创作的核心组织方法，确保从信息收集到最终交付的全流程结构化、可追溯。

## 框架速览

```
S - Situation（明确目标）: 收集产品、受众、会议背景信息
T - Task（任务拆解）: 5步递进式内容构建
E - Embedding（内嵌理论）: AIDA + GRADE + 合规
P - Providing Context（提供语境）: 受众/疾病/产品三维画像
S - Setting Format（设定格式）: 15页标准结构
```

---

## S - 信息收集清单

以下是在开始内容创作前必须收集的信息维度：

### 必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 产品名称 | 商品名/通用名 | 当归补血胶囊 |
| 功能主治 | 基于药品说明书的原文 | "补养气血。用于气血两虚证" |
| 目标科室 | 具体的临床科室 | 三级医院肿瘤科 |
| 目标医生 | 医生的层级和职称 | 高年资主治医师及以上 |
| 核心患者群体 | 适应人群的疾病描述 | 肿瘤放化疗后康复期患者 |
| 中医辨证/西医诊断 | 辨证分型或诊断标准 | "气血两虚证"（神疲乏力、面色少华、头晕心悸、舌淡脉细） |
| 说服目标 | 希望医生采取的具体行动 | 为辨证适宜的康复期患者处方该药 |

### 可选字段

| 字段 | 说明 |
|------|------|
| 会议时长 | 如30分钟/45分钟/1小时 |
| 会议形式 | 线上/线下/线上+线下 |
| 是否有其他讲者 | 是/否，及各自分工 |
| 竞品信息 | 主要竞品及差异化定位 |
| 关键文献 | 可引用的临床研究文献列表 |
| 引用指南 | 相关疾病诊疗指南/共识 |

## T - 五步内容构建法

### 第一步：定义核心主张

**模板句式：**
> "针对[目标患者群体]，[产品名称]通过[核心机制/价值主张]，为[目标科室医生]提供[具体临床价值]，最终帮助[患者获益]。"

**示例**（基于当归补血胶囊）：
> "针对肿瘤放化疗后康复期气血两虚证患者，当归补血胶囊通过补养气血改善癌因性疲乏与贫血，为肿瘤科医生提供一个有循证证据支持的症状管理方案。"
>
> ① 使用AIDA模型贯穿整个PPT，确保逻辑层层递进
> ② 所有文献证据使用GRADE分级标注
> ③ 所有产品陈述严格遵循药品说明书

**质量检查标准：**
- 是否清晰定义了"为谁、在什么场景、解决什么问题"
- 是否包含"行动号召"的暗示（为什么医生应该关注）
- 是否可以在15页演讲中贯穿始终

### 第二步：设计说服路径（AIDA）

#### Attention（引起注意）—— 3-4页
**目标**：让目标科室医生意识到"这是一个值得我关注的问题"

**策略**：
- 展示临床现状数据（发病率、治疗缺口等）
- 指出未被满足的临床需求
- 制造"认知差距"——当前做得不够好，这里有优化空间

**关键问题自检**：
- [ ] 这个问题是否足够"疼"？（医生真的在意吗？）
- [ ] 数据是否准确且可溯源？

#### Interest（激发兴趣）—— 2-3页
**目标**：从"这个问题很重要"过渡到"这个解决方案值得了解"

**策略**：
- 引入产品机制（为什么它可能有效）
- 提供初步证据线索
- 点明差异化定位

**关键问题自检**：
- [ ] 机制解释是否通俗易懂？
- [ ] 是否与Attention阶段提到的问题直接呼应？

#### Desire（建立欲望）—— 4页
**目标**：用高级别证据让医生确信"这个方案是可靠的"

**策略**：
- 依次呈现：RCT证据 → Meta分析 → 真实世界数据
- 每个证据标注GRADE级别
- 从"有效"延伸到"安全"、"便捷"等维度

**关键问题自检**：
- [ ] 证据级别是否由高到低排列？
- [ ] 每个证据是否标注了GRADE分级？
- [ ] GRADE分级理由是否简要说明？

#### Action（促进行动）—— 2-3页
**目标**：清晰告诉医生"下一步做什么"

**策略**：
- 患者识别路径（什么样的患者适合）
- 用药建议（剂量、时机、疗程）
- 总结核心信息

**关键问题自检**：
- [ ] 行动路径是否足够清晰具体？
- [ ] 是否结合了医生的日常工作流程？
- [ ] 总结是否回归了核心论点？

## E - 三大理论框架详述

### AIDA模型检查矩阵

|---------|----------|------------|---------|
| 1 (封面) | A | 吸引注意，建立专业印象 | ☐ |
| 2 (议程) | A | 预告内容，管理期望 | ☐ |
| 3 | A | 指出临床问题/痛点 | ☐ |
| 4 | A | 数据佐证问题严重性 | ☐ |
| 5 | A→I | 过渡：从问题到解决方向 | ☐ |
| 6 | I | 介绍解决方案 | ☐ |
| 7 | I | 机制/原理阐释 | ☐ |
| 8 | I→D | 初步证据/案例 | ☐ |
| 9 | D | 核心RCT证据 | ☐ |
| 10 | D | Meta分析/系统评价 | ☐ |
| 11 | D | 真实世界/安全性数据 | ☐ |

| 14 | A | 处方指导/用法用量 | ☐ |
| 15 | A | 核心信息回顾与号召 | ☐ |

### GRADE分级详细标准

#### 定义
GRADE（Grading of Recommendations Assessment, Development and Evaluation）是国际公认的证据质量分级与推荐强度评价体系。

#### 四等级分级

| 等级 | 英文 | 信心度 | 典型研究设计 | 评分基准 |
|------|------|--------|-------------|---------|
| **高 (High)** | @@@@ | 非常确信真实效应接近估计效应 | 高质量RCT、无严重局限性的Meta分析 | 起始为高质量 |
| **中 (Moderate)** | @@@◯ | 对估计效应有中等信心 | 有缺陷的RCT、高质量观察性研究 | 降一级 |
| **低 (Low)** | @@◯◯ | 对估计效应信心有限 | 观察性研究、病例对照研究 | 降两级 |
| **极低 (Very Low)** | @◯◯◯ | 对估计效应几乎没有信心 | 病例报告、专家意见、机制研究 | 降三级以上 |

#### 降级因素
- **局限性 (Risk of bias)**：分配隐藏不充分、未盲法、失访多
- **不一致性 (Inconsistency)**：不同研究结果差异大
- **间接性 (Indirectness)**：研究对象/干预措施/结局指标差异
- **不精确性 (Imprecision)**：样本量小、置信区间宽
- **发表偏倚 (Publication bias)**：阴性结果未发表

#### 升级因素（观察性研究）
- 效应量大（RR>2或<0.5）
- 剂量-效应关系存在
- 混杂因素可能低估效应

### 合规检查详细清单

#### 红线和禁止性内容
- ❌ "首选"、"最佳"、"金标准"、"特效"、"独一无二"
- ❌ 与竞品的直接贬低性比较
- ❌ 超出说明书范围的适应症或功效
- ❌ 暗示"绝对安全"、"无副作用"
- ❌ 利用患者或医生的恐惧心理施压
- ❌ 未经批准的适应症推广

#### 要求性内容
- ✅ 功效声明须与诊断/辨证标准紧密结合
- ✅ "适合患者"须结合具体临床标准描述
- ✅ 证据须标注来源
- ✅ 用药建议须与说明书一致

### 内容脚本交付标准
- [ ] 共15页，封面+14页正文
- [ ] 每页含三个区块：标题、要点、备注
- [ ] 备注中包含GRADE分级引用（有证据的页面）
- [ ] 备注中包含页面过渡衔接语
- [ ] 全篇无违规表述
- [ ] 核心论点贯穿始终
