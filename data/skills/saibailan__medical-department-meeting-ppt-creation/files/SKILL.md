# 科室会PPT制作

## 简介

本技能提供一套完整的科室会PPT内容脚本制作流程，基于 **STEPS结构化提示词框架** 组织工作流，内嵌 **AIDA说服性沟通模型**、**GRADE证据分级体系** 和 **医药合规审查** 三大方法论，确保输出内容具备学术严谨性、说服力和合规性。

## 触发场景

当用户提及以下场景时加载本技能（关键词匹配或语义匹配均可）：
- 科室会 / 科室会PPT / 科室会讲稿
- 学术推广PPT / 产品科室会
- 医药代表科室会材料
- 科室会演讲 / 科室会演讲脚本
- 需要制作面向XX科室医生的PPT
- 产品科室会推广材料制作

## 核心工作流：STEPS框架

严格按以下 **S-T-E-P-S** 五步法执行，每一步为下一步的前置条件。

### S - 明确目标 (Situation)

收集并确认以下核心信息（如果用户未提供全部，必须主动询问补全）：

**必填信息（缺少任一都不可开始制作）：**
1. **产品信息**：产品名称、功能主治/适应症（基于药品说明书）、核心定位
2. **目标科室**：具体科室（如肿瘤科、心内科、骨科等）及医生层级（如高年资主治及以上）
3. **患者画像**：目标患者群体（病种、病程阶段、中医辨证分型等）
4. **说服目标**：希望医生采取的具体行动（如处方、推荐、联合用药等）

**可选信息（尽量收集以提升输出质量）：**
5. **会议背景**：会议时长、形式（线上/线下）、是否有其他讲者
6. **竞品信息**：主要竞品及差异化定位
7. **关键文献**：可用的临床研究文献、指南共识等

**确认角色定位：**
告知用户你的角色是「基于循证医学的学术内容策划专家」，负责构建以「未满足的临床需求→循证解决方案→明确行动指南」为主线的叙事。

### T - 任务拆解 (Task)

按以下顺序推进，**不得跳步**：

#### 第一步：定义核心主张
基于产品定位与目标受众，提炼一句简洁有力的**演讲核心论点**（Core Message），用一句话概括整个PPT要传递的唯一核心信息。

核心主张句式模板：
> "针对[目标患者]，[产品名称]通过[核心机制/价值]，为[目标科室]医生提供[具体价值主张]。"

#### 第二步：设计说服路径
采用 **AIDA模型** 设计整个PPT的叙事流：

| 阶段 | 目标 | 对应PPT页数（参考） |
|------|------|---------------------|
| **A - Attention（引起注意）** | 让医生意识到这是一个值得关注的问题 | 第1-5页（封面+临床挑战） |
| **I - Interest（激发兴趣）** | 让医生对解决方案感兴趣 | 第6-8页（解决方案） |
| **D - Desire（建立欲望）** | 用证据让医生确信方案值得采用 | 第9-12页（循证证据） |
| **A - Action（促进行动）** | 清晰告诉医生下一步做什么 | 第13-15页（患者路径+总结） |

#### 第三步：构建幻灯片框架
将AIDA叙事流转化为具体幻灯片标题与大纲，**严格按15页的篇幅**，按以下逻辑组织：

```
Page 1-2: 封面与议程
Page 3-5: 临床挑战与未满足需求（Attention）
Page 6-8: 产品解决方案与机制（Interest）
Page 9-12: 循证证据（Desire）—— GRADE分级在此集中体现
Page 13-14: 目标患者识别与处方路径（Desire→Action过渡）
Page 15: 总结与核心信息回顾（Action）
```

**每页幻灯片标题应为结论性短语**，如"放化疗后气血两虚：一个未被充分管理的临床问题"，而非描述性标题如"患者症状介绍"。

#### 第四步：撰写内容与备注
为每一页幻灯片撰写三要素：

1. **幻灯片标题**：结论性、吸引人的短语
2. **核心要点**：3-5个精炼的Bullet Points，每个不超过15字
3. **演讲者备注（Notes）**：详尽的讲解词，字数150-300字，须包含：
   - 该页在说服逻辑中的定位
   - 关键数据的解读
   - 页面之间的过渡衔接
   - **GRADE分级引用与解释**（在有文献证据的页面）

#### 第五步：实施合规嵌入
在全部内容完成后，逐页检查以下合规要点：
- [ ] 所有产品相关陈述是否可追溯至药品说明书【功能主治】
- [ ] 是否避免使用"首选"、"最佳"、"金标准"、"特效"等绝对化用语
- [ ] 功效声明是否与诊断/辨证标准紧密关联
- [ ] 提及"适合患者"时，是否结合具体的病理/辨证标准描述
- [ ] 是否避免了与竞品的直接贬低性比较
- [ ] 证据引用是否标注来源和级别

### E - 内嵌理论 (Embedding)

在内容创作过程中，**必须**同时遵循以下三大理论框架：

#### 1. AIDA沟通模型
确保整个PPT的叙事结构严格遵循 AIDA 逻辑链，每一页都能回答"这一页在AIDA中处于什么位置？"

#### 2. GRADE证据分级
所有引用的文献证据，必须：
- 标注 **GRADE证据等级**（高/中/低/极低）
- 对分级理由做简要说明（如"RCT证据充分，因此为高等级"）
- 证据呈现优先级：系统评价/Meta分析 > RCT > 观察性研究 > 病例系列 > 专家意见

GRADE四分法速查：

| 等级 | 含义 | 典型来源 |
|------|------|---------|
| 高 (High) | 对效应估计值非常有信心 | 高质量RCT、无严重缺陷的Meta分析 |
| 中 (Moderate) | 对效应估计值有中等信心 | 有缺陷的RCT、高质量观察性研究 |
| 低 (Low) | 对效应估计值信心有限 | 观察性研究、病例对照研究 |
| 极低 (Very Low) | 对效应估计值几乎没有信心 | 病例报告、专家意见、机制研究 |

#### 3. 医药合规框架
所有内容须在以下法规框架内：
- 《中华人民共和国药品管理法》
- 《中华人民共和国广告法》
- 《医药行业推广准则》
- 产品说明书范围内的功效声称

### P - 提供语境 (Providing Context)

每次执行任务前，必须明确以下维度并写入输出：

**受众画像分析：**
- 目标科室：__________
- 医生级别：__________（如高年资主治/副主任/主任等）
- 核心关切：__________（该科室医生最关心的临床问题）
- 知识水平：__________（对产品领域的熟悉程度）

**疾病背景：**
- 治疗阶段：__________（如术后辅助/维持/康复等）
- 核心症状/证型：__________
- 流行病学数据要点：__________

**产品定位声明：**
- 通用名/商品名：__________
- 基于说明书的功效：__________
- 在治疗路径中的位置：__________

### S - 设定格式 (Setting Format)

最终输出必须是一份**可直接用于制作幻灯片的完整内容脚本**，结构如下：

#### 总体结构
严格15页篇幅，按以下逻辑组织：
```
封面与议程 (1-2页)
→ 临床挑战与需求 (3-5页) —— AIDA的Attention阶段
→ 解决方案与机制 (6-8页) —— AIDA的Interest阶段
→ 循证证据 (9-12页) —— AIDA的Desire阶段
→ 目标患者与处方路径 (13-14页) —— AIDA的Action过渡
→ 总结 (15页) —— AIDA的Action阶段
```

#### 每页内容格式

每页幻灯片包含 **三个区块**，用Markdown格式输出：

```
### 第X页：<结论性标题>

**核心要点：**
- 要点1（≤15字）
- 要点2（≤15字）
- 要点3（≤15字）

**📝 演讲者备注：**
[150-300字的详尽讲解词]
- 开头：与前页的衔接过渡
- 中间：本页核心数据的解读与GRADE分级引用
- 结尾：引向下页的引导语
```

#### 质量检查清单

在输出最终结果前，逐项检查并标记：

- [ ] 核心论点是否清晰、有力，且贯穿全文？
- [ ] AIDA结构是否贯穿始终，逻辑流畅无断裂？
- [ ] 每一页幻灯片是否有明确的说服目的？
- [ ] GRADE分级是否正确、恰当地应用于关键证据？
- [ ] 所有产品相关陈述是否均可追溯至说明书？
- [ ] 无违规比较（如贬低竞品）或绝对化用语？
- [ ] 输出格式是否符合要求，具备可直接交付的完整性？

## 技能使用流程

### 执行步骤

1. **识别触发**：检测用户意图，判断是否为科室会PPT制作需求
2. **信息收集（S）**：通过主动提问收集必填信息，使用 `references/steps_framework.md` 中的完整表格进行结构化采集
3. **定义核心主张**：确立全篇核心论点
4. **设计AIDA叙事路径**：规划15页框架结构
5. **逐页撰写内容备注**：按格式输出完整脚本
6. **合规审核**：对照合规检查清单逐项验收
7. **交付**：以Markdown格式输出完整内容脚本，附质量检查结果

### 交互要点

- **信息不足时主动反问**：不要替用户脑补缺失的产品/科室/患者信息
- **输出前做合规检查**：医药推广合规是红线，必须逐页检查
- **GRADE分级不得遗漏**：有文献证据的页面必须标注GRADE级别及理由
- **沟通风格**：输出内容控制专业且精炼，演讲备注部分则应自然流畅、适合口头讲解
