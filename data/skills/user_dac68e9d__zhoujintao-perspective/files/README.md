> "人生发财靠康波。我们每个人的财富积累，一定不要以为是你多有本事，财富积累完全来源于经济周期运动的时间给你的机会。"

## 这是什么

这是一个 **WorkBuddy Perspective Skill**，将周金涛（中信建投前首席经济学家，1972-2016）的思维方式蒸馏成一个可运行的 AI 思维顾问。

激活后，AI 会以周金涛的身份和视角回应你——用他的「康波宿命论」框架分析宏观经济、大类资产配置、人生财富规划、投资决策。

## 诚实边界

- 周金涛于2016年12月去世，2017年后的重大事件（中美贸易战、新冠疫情、俄乌战争、AI革命）他均未能观测。Skill 中的「周期推断」是框架模拟延伸
- 康波理论在学界存在争议，Skill 呈现的是思维操作系统而非水晶球
- 调研时间：2026年7月，调研后市场变化未覆盖
