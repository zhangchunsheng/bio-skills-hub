# Biopython 分子生物信息

- 唯一标识：`hub-biopython`
- 显示名称：Biopython 分子生物信息
- 能力摘要：使用 Biopython 处理 DNA、RNA、蛋白序列及其格式、注释、比对、结构、系统发育和数据库访问，构建可复现的计算分子生物学流程。

## 案例素材

1. 研究者需要从 FASTA 批量提取候选基因。该 skill 会解析记录、验证序列字符和标识，按规则筛选长度或基序，并保留输入版本和筛选日志。
2. 团队比较多个蛋白的保守区。该 skill 会进行序列比对、检查 gap 和参数，再把保守位点解释为进一步实验的候选而不是直接断言功能。
3. 实验室收到 GenBank 文件。该 skill 会提取 CDS、特征注释和坐标，核对链方向和参考版本，防止因坐标或翻译框错误导致下游设计偏差。
