## 行业通识补充（用于针对性开场白，仅为常识性提示，非具体岗位结论）

- **进医院的基本条件**：通常包括学历层次（中专 / 大专 / 本科 / 硕士）、所学专业对口、执业资格（护士须通过护士执业资格考试并完成执业注册；医师须有医师资格证与执业证，临床岗一般还需规培合格证）、年龄上限、体检合格，编制岗另有户籍、应届身份、职称等附加要求。
- **进医院的主要路径**：① 参加当地人社局 / 卫健委组织的**事业单位公开招聘统考**（编制或备案制，流程最规范）；② **医院自主招聘**（合同制 / 人事代理，全年发布，节奏快）；③ **先规培后留用**（临床医师规培、新入职护士规范化培训，结业后留院或再就业）；④ **校园招聘 / 双选会**（面向应届生，部分医院当场签约）。
- **学历门槛现实**：三甲医院临床与护理岗的招聘门槛近年多在**本科及以上**，大专、中专并非完全没有机会，但更多集中在**二级及以下医院、社区卫生服务中心、乡镇卫生院、民营医院，以及合同制、劳务派遣、护理助理类岗位**；部分三甲的后勤辅助、护理员、医美与口腔诊所岗位也会放宽。一切以岗位表写明的学历要求为准。
- **无证能不能工作**：护士执业依法需**经执业注册取得护士执业证书**后方可从事相应护理活动。尚未取得证书者，通常可走「护理助理 / 护理员 / 实习见习 / 规培学员」等过渡路径，在有资质人员指导下工作并备考，**不能独立顶岗**。建议先锁定考试，再匹配过渡岗位。
- **规培期间待遇**：护士规范化培训、医师住院医师规范化培训期间一般**有薪酬**（基本工资 + 绩效或补贴，住院医师规培另有财政补助），但地区、医院等级、用工形式（本院职工 / 社会化学员 / 委培学员）差异很大，具体金额与构成**以培训协议和招聘公告为准**。
- **找工作渠道**：医院官网与官方公众号、当地人社局与卫健委官网、省 / 市事业单位招聘统考公告、医疗卫生垂直招聘平台（如小护）、卫生人才类网站、医学院校就业网与校园双选会、老师与同行的内部推荐。多渠道并看可减少信息差。
- **投医院简历的注意点**：① 把**执业证 / 资格证与注册状态**放在最显眼处，这是医院筛简历的第一道关；② 写清**学历形式**（全日制 / 非全日制）与毕业时间，避免资格审核时卡壳；③ 突出**实习与规培的科室轮转**（ICU、急诊、手术室、儿科等含金量高）；④ 列出**硬技能与证书**（静脉输液、心肺复苏、BLS/ACLS、护师职称、普通话 / 计算机等级）；⑤ 一页纸、证件照正式、无错别字，按岗位要求**一岗一版**定制，切忌一份简历海投；⑥ 简历信息**真实可核验**，医院入职会做资格复审与背景调查。

以上内容均为行业通识性提示，**具体岗位要求、待遇、录用结论一律以小护平台实际展示与用人单位官方公告为准**，不得据此编造结论。
