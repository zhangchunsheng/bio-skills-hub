# Skill Info

## Skill Name
学术会议晨报

## Description
面向医药企业学术会议板块负责人的定制晨报 Skill。通过 WebSearch 实时检索今日医药行业新闻，按六个版块（学术会议动态、KOL动态追踪、竞品会议情报、重磅数据发布、政策与会议合规、数字化会议趋势）分类整理，生成橙红渐变风的响应式 HTML 晨报单页。触发词包括：学术会议晨报、医药晨报学术版、学术会议日报、医药行业晨报学术会议版、pharma conference daily、学术会议资讯汇总、生成学术会议晨报。

## Introduction

本技能在医药学术会议资讯领域提供面向学术会议板块负责人的定制化晨报生成服务。

学术会议晨报旨在简化和自动化每日医药行业学术会议相关新闻的检索、分类与整理工作，为医药企业学术会议板块负责人、医学事务团队及市场准入部门提供结构化的每日资讯支持。

核心能力：

- 时间检测与回退策略：智能判断检索时间窗口，8:00 前自动回退检索昨日资讯
- 多渠道并行搜索：六个版块 12 组搜索词并行发起 WebSearch，覆盖学术会议动态、KOL追踪、竞品情报、重磅数据、政策合规、数字化趋势
- 数据清洗与分类：去重、按六版块归类、60字摘要生成、时间格式化
- 数据数组构建：按标准格式填充 REPORT_DATA，含 title/url/source/summary/category/tags
- HTML 晨报生成与输出：基于 template.html 生成橙红渐变风响应式单页，含 Hero 数据看板、导航系统、卡片区、悬浮面板
- 定时推送引导：主动询问用户设定每日 10:00 自动化定时推送

应用场景：

- 医药企业学术会议板块负责人每日晨报生成
- 学术会议注册/投稿截止日期预警
- KOL学会任职变更与专家动态追踪
- 竞品企业卫星会/研讨会/展台情报监测
- 会议首发重磅临床数据与 LBA 追踪
- 医药政策更新与会议合规动态监测
- 数字化会议技术创新趋势扫描
