# ClinicalTrials 试验检索

- 唯一标识：`hub-clinicaltrials-database`
- 显示名称：ClinicalTrials 试验检索
- 能力摘要：通过 ClinicalTrials.gov API v2 按疾病、药物、地点、状态、分期和 NCT 编号检索、导出并持续跟踪临床研究信息。

## 案例素材

1. 研究协调员需要了解本地正在招募的二型糖尿病研究。该 skill 会按疾病、招募状态、城市和入排条件检索，再将候选试验交由具资质人员进行人工匹配。
2. 医药情报团队跟踪某 PD-1 药物的 III 期竞争格局。该 skill 会批量查询干预名称、分期和申办方，导出 NCT 编号、终点、状态与更新时间供趋势分析。
3. 项目经理每周监控已关注研究是否更新。该 skill 会按 NCT ID 拉取详情、比对状态和结果模块变化，并遵守公开 API 限速与数据使用约束。
