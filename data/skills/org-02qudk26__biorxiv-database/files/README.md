# bioRxiv 预印本检索

- 唯一标识：`hub-biorxiv-database`
- 显示名称：bioRxiv 预印本检索
- 能力摘要：按关键词、作者、日期和学科检索 bioRxiv 预印本，获取结构化元数据、DOI、引用信息和全文链接，支持追踪前沿研究与可复现文献筛选。

## 案例素材

1. 研究组追踪新出现的单细胞方法。该 skill 会按领域和日期定期检索，去重版本记录，标记是否已有同行评审版本，避免把预印本当作最终定论。
2. 作者想整理自己的预印本产出。该 skill 会按作者及时间范围提取标题、摘要、DOI 和版本，核对同名作者与重复发布后生成清单。
3. 文献综述需要补充最新研究。该 skill 会把预印本与 PubMed 正式文献分别标注证据状态，在引用和结论中清楚说明其尚未经过同行评审。
