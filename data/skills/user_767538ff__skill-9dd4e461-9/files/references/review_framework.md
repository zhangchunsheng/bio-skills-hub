# 医嘱点评 · 七维度分析框架

每条病例按以下七个维度逐项评价，区分「合理」与「需关注 / 需纠正」，并给出可执行的改进建议。所有结论须引用真实指南/共识/说明书，拿不准先用 WebSearch 核实，严禁编造。

---

## 维度一：抗肿瘤方案评价
- **方案适配**：方案选择是否贴合诊断与危险度分层（如 AML 适合强化者用 IA 方案、NPM1 突变巩固用 MD-AraC；高级别 B 细胞淋巴瘤双打击用 DA-EPOCH±HD-MTX；ALL 用 HD-MTX+门冬；MM 用 PI+IMiD+CD38 单抗等）。参照 NCCN / CSCO / ESMO / ASH。
- **剂量/疗程/顺序**：药物剂量、疗程天数、给药顺序是否符合规范（如 HD-MTX 后亚叶酸钙解救；蒽环类累积剂量与心脏毒性）。
- **CNS 预防**：高危中枢累及风险者是否行鞘注预防（Ara-C/MTX+地塞米松）。
- **靶向/免疫**：IDH1/2、FLT3、BCL-2 等突变是否纳入维持或联合考虑（巩固化疗阶段多为可选，非必需）。

## 维度二：抗感染评价（IDSA / 桑福德）
- **病原学依据**：是否先留取培养/NGS/PCR/涂片再用药；经验性覆盖是否在获得结果后及时降阶梯。
- **覆盖谱合理**：免疫低下宿主肺炎是否覆盖 PJP（复方磺胺甲噁唑为首选）、耐药革兰阴性菌、非典型病原体、真菌。
- **剂量个体化**：按肝肾功能（eGFR/Child-Pugh）调整剂量（如 SMZ 依 eGFR 下调）。
- **特殊病原体**：PJP 治疗剂量（TMP 15–20 mg/kg/d）、真菌（伏立康唑对克柔念珠菌天然耐药、对光滑念珠菌活性中等，必要时换棘白菌素）、CMV（缬更昔洛韦/来特莫韦，伐昔洛韦无效）。

## 维度三：预防用药评价
- **粒缺期氟喹诺酮预防**：2023 IDSA / ASCO 已不常规推荐 afebrile neutropenia 的氟喹诺酮预防（耐药、肌腱/糖代谢不良反应）；如采用应限定高危方案且短期，并告知不良反应。
- **VTE 预防**（ASCO/COSO，Khorana 评分）：肿瘤住院患者高危且出血低危者应予药物预防（低分子肝素/普通肝素）；仅基础预防不足。
- **乙肝再激活预防**：HBsAg(-)/HBcAb(+) 接受 CD38 单抗、激素、化疗等免疫抑制时，应予恩替卡韦/替诺福韦预防。
- **抗病毒**：HSV/VZV 用伐昔洛韦；CMV 抑制须用缬更昔洛韦或来特莫韦（伐昔洛韦几无 CMV 活性）。
- **肿瘤溶解综合征预防**：IMiD / 蛋白酶体抑制剂 / 高肿瘤负荷方案予水化、碱化、利尿。
- **应激性溃疡**：PPI 护胃（尤其激素/NSAIDs/化疗）。

## 维度四：对症支持
- **止吐**：化疗致吐风险分层，5-HT3 拮抗剂 / NK-1 拮抗剂 / 地塞米松合理联用；突破性呕吐及时加药（如冬非合剂）。
- **营养/补钾**：白蛋白、丙球支持；补钾须有低钾依据与监测，避免无指征长期补钾。
- **输血/造血支持**：粒缺期 G-CSF、贫血/血小板输注指征。

## 维度五：监测
- **血药浓度**：HD-MTX 后监测 MTX 浓度并按需解救至清除（<0.30 μmol/L）。
- **脏器毒性**：卡非佐米/蛋白酶体抑制剂心脏毒性（心衰、高血压）；蒽环类心脏；老年大剂量阿糖胞苷小脑毒性（共济失调、构音障碍）加强神经监测。
- **实验室**：肝肾功能、电解质、CRP/PCT 动态。

## 维度六：书写质量
- 剂量/周期前后不一致（如 MTX "4.5mg" 与 "4.5g" 混用，易致漏救）；方案周期（C1/C3）转录错误。统一规范书写，避免误读。

## 维度七：相互作用与重复用药
- **CYP 相互作用**：伏立康唑经 CYP 代谢，与化疗药相互作用需关注。
- **QT 延长叠加**：两种喹诺酮（如西他沙星+莫西沙星）联用增加 QT 延长与重复用药风险，须有协同指征。
- **双药重复**：同类药物叠加需说明理由。

---

## 结论分档
- **合理**：方案与处理整体符合规范，无明显可优化点。
- **基本合理（含需关注点）**：主体合理，存在质量改进建议。
- **不合理（含需纠正点）**：存在较明确的可优化/应纠正项（如伐昔洛韦替代 CMV 预防、高危 VTE 仅基础预防等）。
