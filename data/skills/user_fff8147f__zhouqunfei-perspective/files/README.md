# 周群飞 · 思维操作系统（Skill）

> 用周群飞的视角，分析企业经营、危机应对、技术攻坚、逆周期布局与转型决策。

## 这是什么

一个由 [女娲 · Skill 造人术](https://github.com/alchaincyf/nuwa-skill) 方法论蒸馏出的「人物思维视角」Skill。

它把蓝思科技创始人周群飞（"手机玻璃女王"）的**思维方式、表达风格、决策逻辑**提炼成可运行的 `SKILL.md`，让 AI 在对话中「扮演」她的视角来回答问题或做顾问式分析。

核心提炼（均经女娲三重验证）：
- **6 个核心心智模型**：逆周期布局 / 制造业实业逻辑优先 / 技术死磕 / 去单一依赖（米缸理论）/ 跨界迁移 / 刚柔共生
- **9 条决策启发式**：危机即时机、实业逻辑决策、技术储备前置、跨界迁移、去单一依赖、家族禁入管理层、躬身一线、忍辱负重、逆风而行
- **完整表达 DNA**：湘妹子朴素务实、爱用亲身故事拎道理、微信签名"舍，即得也"
- **核心张力与诚实边界**：明确标注「公开二手资料、含媒体叙事、非本人原话」

## 怎么用

在支持 Skill 的 AI 客户端（WorkBuddy / Cursor / Claude Code / OpenClaw 等）中，把本文件夹放进对应 skills 目录后，对话里输入：

- 「用周群飞的视角分析一下：现在该不该收购一家亏损的电池厂？」
- 「切换到周群飞，帮我看看蓝思的去苹果化走得对不对」
- 「如果是周群飞会怎么做？」

Skill 激活后会直接以周群飞的口吻回应（用「我」而非「周群飞认为」）。

## 安装

将本文件夹整体放入客户端的 skills 扫描目录即可，无需依赖、无需额外安装。

- **WorkBuddy**：放入 `C:\Users\<你的用户名>\AppData\Roaming\WorkBuddy\skills\`（或用户级 `~/.workbuddy/skills\`）
- 其他客户端参见各自 Skill 加载文档

## 来源与诚实边界（必读）

此 Skill **基于公开信息提炼，并非周群飞本人观点，也不代表蓝思科技**。

- 素材来自 15+ 篇财经媒体、人物专访、招股书与公开演讲（财富中文网、21 世纪经济报道、澎湃、凤凰等），含媒体叙事甚至"爽文"美化色彩，需自行甄别。
- 周群飞本人极度低调、深度自述极少，本 Skill 的不少内容是外部观察推断，非本人原话。
- 未覆盖蓝思内部董事会决策、客户谈判细节等非公开信息。
- 调研时间快照：2026-07-25，之后的战略动向未覆盖。
