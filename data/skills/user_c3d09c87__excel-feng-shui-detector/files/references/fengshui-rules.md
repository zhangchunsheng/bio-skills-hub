# Excel 风水规则

## 等级

- 85–100：办公室祥瑞
- 70–84：小煞可化
- 50–69：暗流涌动
- 0–49：百鬼夜行

分数只用于排序，不代表数据一定正确或错误。

## 发现类型

| 代码 | 默认性质 | 说明 |
| --- | --- | --- |
| `formula_error` | 确定错误 | 缓存结果为 `#REF!`、`#DIV/0!` 等 |
| `used_range_bloat` | 高风险 | 声明使用范围远大于实际非空区域 |
| `full_column_formula` | 维护风险 | 公式使用 `A:A` 等整列引用 |
| `numeric_text_candidate` | 人工复核 | 数字外观文本可能影响求和，也可能是标识符 |
| `merged_cells` | 人工复核 | 明细区合并会阻碍筛选，标题区可能合理 |
| `hidden_structure` | 人工复核 | 隐藏工作表、行或列可能影响理解和公式 |
| `blank_header` | 维护风险 | 数据区域内缺少字段名 |
| `duplicate_header` | 维护风险 | 相同表头导致引用和导入歧义 |
| `style_fragmentation` | 维护风险 | 工作簿样式过多，可能由反复粘贴产生 |
| `missing_freeze_pane` | 易用性 | 大表没有冻结表头 |

## 修复顺序

1. 公式错误、损坏引用和关键数据类型；
2. 隐藏依赖、重复表头和范围膨胀；
3. 整列公式、合并明细和筛选问题；
4. 样式碎片、冻结窗格、列宽和可读性。

任何修复都应在副本中完成，并在修改后重新计算、检查关键范围和视觉渲染。
