## P1 场景-方法匹配速查表

| 业务场景 | 首选方法 | 替代方法 | 前提条件 |
|----------|----------|----------|----------|
| 宏观环境分析 | PESTEL | STEEP | 有政策/经济/社会/技术/环境/法律数据 |
| 内外部综合 | SWOT | TOWS | 内外因素可区分 |
| 行业竞争结构 | Porter五力 | PESTEL+Competitor Map | 行业边界清晰 |
| 市场细分 | MECE | 自然分类 | 流行病学数据完整 |
| 目标选择 | GE-McKinsey | BCG/Ansoff | 评分维度数据可得 |
| 定位 | STP(定位阶段) | Value Proposition Canvas | S和T已完成 |
| 视觉隐喻 | ZMET | 半结构化深访+卡片分类 | 有条件做一对一深度访谈 |
| 客户分级 | 九宫格(潜力x观念) | RFM/CLV | 潜力+观念可量化 |
| 销售预测 | Time Series | Delphi/Judgment | 历史数据>3年 |
| 估值 | DCF | 实物期权(创新药)/可比交易(仿制药) | 现金流可合理预测 |
| 责任分配 | RACI | RASCI/RAPID | 任务边界清晰 |

## P4 12类逻辑谬误速查

| 谬误 | 检测关键词 | 典型表现 |
|------|-----------|----------|
| 循环论证 | "因为A所以B，因为B所以A" | 用结论证明前提 |
| 过度外推 | "适用于所有患者" | 小样本推广到全人群 |
| 因果倒置 | "疗效好所以处方多" | 可能是处方多→数据多→看起来疗效好 |
| 自相矛盾 | 跨模块数值/方向不一致 | M2说"进口替代"M7却按"进口对标"定价 |
| 采樱桃 | 只引有利文献 | 选择性引用 |
| 虚假二分 | "不进医保就是死" | 忽略多层次市场策略 |
| 相关!=因果 | "X指标降低说明产品有效" | 混淆相关性与因果性 |
| 以偏概全 | "根据某三甲医院数据" | 单中心推广全国 |
| 数字幻觉 | "精确到小数点后两位" | 无计算过程支撑 |
| 稻草人 | "竞品A副作用严重" | 歪曲竞品数据 |
| 视觉漂移 | KV"火焰"vs定位"温和" | 视觉隐喻与定位锚点矛盾 |
| 财务假设矛盾 | M3-02增长率12% vs M3-05折现率8% | 同变量不同模块取值矛盾 |
