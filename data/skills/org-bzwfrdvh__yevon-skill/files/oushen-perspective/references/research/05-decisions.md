# 欧成效（欧神）重大决策、转折点与争议行为调研

> 调研维度：05-决策（重大决策 / 人生转折点 / 争议事件 / 决策背景与逻辑 / 事后反思 / 言行一致性与不一致 / 推荐标的与结果 / 本人投资实践）
> 调研日期：2026-08-17
> 说明：欧成效本人核心阵地（水库论坛公众号、微博）已于2020年9月被永久封禁，大量一手言论仅以截图、粉丝转载、媒体引用形式存世。本文件中"一手"指欧成效本人公开发言/朋友圈/直播的直接引用（经媒体转引），"二手"指第三方转述、评论或当事人陈述。

## 关键发现

- **欧成效的"决策神化"高度依赖2002-2018年中国房价普涨大周期，2018年离婚是其个人财务与声誉的双重转折点，此后所有重大商业决策（海外土地、贵阳团购、沈阳重庆团购）均以粉丝资金为杠杆、以佣金为收益，本人风险敞口极小。**
- **言行不一致的核心证据链：一边宣称"身家10亿""房价永远涨"，一边自曝两年亏损3300万；推荐粉丝"卖掉上海买重庆"的同时自己赚取团购佣金。**

## 一、人生与决策时间轴（按主题整理）

### 1.1 早期人生决策

**决策1：放弃学术道路（1998年）**
- 复旦大学物理系毕业（跳级保送），导师希望他深造理论物理，他反问"你给我30万月薪，我就跟你做物理"。
- 来源：新浪财经《一个时代结束了》(https://k.sina.com.cn/article_2266218903_8713c19701903v8m8.html)；东方楼书转载 (http://dfjb.net/dongfang/103836.html)
- 可信度：高（多家媒体一致转述，含纪录片《月亮与400万英镑》内容）｜一手（本人原话）

**决策2：辞去500强管培生（2001年）**
- 1998年入职某500强快销企业（高露洁）管培生，原目标亚太区主管；三年后认为职场"付出无限大、收益无限小"，辞职回上海，留下名言"真正勤奋的人不上班"。
- 来源：搜狐/无冕财经《起底"欧神"》(https://www.sohu.com/a/441071887_226049)；网易 (https://www.163.com/money/article/GR78LLRV00259DLP.html)
- 可信度：高｜一手（本人多次自述）

**决策3：入场楼市（2002年）**
- 契机：替女友办理500元定房意向金退款，两赴上海莘庄顺便看盘，发现套利机会。随后花两个多月看盘，以5700元/㎡在南外滩买入首套（总价60余万），2005年以175万卖出。
- 来源：无冕财经 (https://www.sohu.com/a/441071887_226049)；腾讯新闻 (https://news.qq.com/rain/a/20240717A0902C00)
- 可信度：高（本人公开访谈多次复述）｜一手

### 1.2 财富积累期决策（2002-2017）

**决策4：金融危机加杠杆扫货上海（2008年）**
- 借"四万亿"刺激东风，以"三成首付+七成贷款"在上海大量购入，据称2008-2009年购入30-40套。2009年（31岁）手中已有20套上海房产，账面资产回报号称达1亿。

- 可信度：中高（本人自述"20套""1亿"，无独立核实；欧本人有夸大宣传动机）｜一手（自述）

**决策5：创办水库论坛（2012年10月）**
- 讲解选房与融资（含媒体披露的争议手法，细节从略），被称"中高层炒家聚集地"。核心方法论《楼市秘籍》速成篇将全职炒房分解为"67个步骤"。

**决策6：All-in知识付费（2017年）**
- 知识星球开通当晚会员费税后收入号称百万；2018年"知识星球"单年粉丝年费税后号称千万；5000元/年的高级圈子一夜售出200个。每天至少5小时回答问题。曾与张五常、茅于轼等经济学家同台论道。
- 来源：易简财经 (https://www.thepaper.cn/newsDetail_forward_15824223)；头条 (https://www.toutiao.com/article/7512669392396648960/)

### 1.3 重大转折点

**转折点1：离婚（2018年1月）——人生分水岭**

## 二、重大投资/商业决策及推荐标的的事后结果

### 2.1 重庆（2016-2024，持续最久、最核心的推荐城市）

**决策内容与口号**
- 2017年2月《下一站，重庆》："未来是哪里，未来是重庆"；"卖掉上海/北京一套房，置换重庆十套房"；"卖掉北上10套房，可以去重庆买一栋楼"；2020年直播称"重庆房价到10万/㎡不需要等太久"，号称"5年内带粉丝来重庆买10万套"；2024年直播称"中国城市排名将是渝上北深广，重庆将成中国第一城"。
- 具体团购：重庆天地翡翠湖山大户型35套（宣称"大户型比小户型便宜2000元/㎡"的BUG、"九折笋盘"、"全网最低价"）；海尔路唐家沱"美好天赋"精装洋房（建面13000元/㎡，宣称一二手倒挂3000-5000元，"一小时订爆"）——重庆本地俗语"亏到唐家沱"；2024年再入重庆买下解放碑顶峰·尚城华府4套顶复+小户型（总价超3000万）。
- 来源：搜狐 (https://www.sohu.com/a/440163614_100294901)；房天下 (https://news.fang.com/open/49185766.html)；网易/重庆楼市自媒体 (https://www.163.com/dy/article/GBRKFNOI0535L5KD.html)；新浪财经 (https://k.sina.com.cn/article_2266218903_8713c19701903v8m8.html)
- 可信度：高（直播与文章均有存档）｜一手（口号）+二手（结果）

**事后结果**
- 重庆本地大V联系水库管家公司获知：其联系的2000多名外地炒房客中约80%亏损（最高亏30-40%），仅20%保本或赚钱；房子"既难涨又难卖"。
- 2021-2022年重庆商品房成交均价仅约1.32万元/㎡，在同量级城市中为价格洼地；"10万/㎡""三四年涨50%"的预期落空。
- 有北京粉丝因信水库"稀里糊涂在重庆买房"，买在高点、高利率，被套，不知割肉还是死等。
- 交叉证言：资深粉丝张先生（2024年采访）称自己在重庆有11套、2024年又买10套，自称"跟着欧老师确实赚到过钱的这批人"——说明早期（2016-2017低位）跟随者确实有盈利，分化极大。
- 来源：网易 (https://www.163.com/dy/article/H5VHCKUV0535P5TS.html)；头条 (https://www.toutiao.com/article/7512669392396648960/)；每经/新浪 (https://finance.sina.cn/2024-08-23/detail-inckpzkw3293220.d.html)
- 可信度：中高（80%亏损为管家公司口径，无审计；方向与重庆行情一致）

**决策逻辑（其自述）**
- 重庆不限购、总价低、两江四岸单价相对上海"是享福"；"思维不能太局限"；"不要老想着抄底，想发不了财"（即鼓励追涨）。
- 批评者归因：重庆不限购+总价低+佣金比例高，"只要带外地粉丝来买就能赚佣金"——这是外地大V偏爱重庆的真实原因。
- 来源：网易 (https://www.163.com/dy/article/FHEAD5VF05358H0I.html)；网易 (https://www.163.com/dy/article/H5VHCKUV0535P5TS.html)
- 可信度：高（逻辑链条为媒体与业内共识）｜二手

### 2.2 沈阳（2018）

**决策内容**
- 重庆"能买的都买了"后，经青岛投资者"乐墨"牵线转向沈阳：信贷宽松、开发商好谈。欧成效亲自北上考察后大张旗鼓造势，渲染房价"马上暴涨50%-100%"；宣称"沈阳才是环京之洼地"（北京一套老房子可换12套沈阳恒大新房）。
- 来源：头条《放弃西安，买到沈阳的那波朋友怎么样了》(https://www.toutiao.com/article/7161320324804542976/)；网易 (https://www.163.com/money/article/GR78LLRV00259DLP.html)；中金在线（欧成效本人文章）(http://mp.cnfol.com/article/1784369)
- 可信度：高｜一手（欧文原文）+二手（结果）

**事后结果**
- 半职业投资者复盘（2018年买入浑南两套二手房，200万总价/不到20万自有资金）：5年后市值260-270万但流动性极差，急售仅能成交约220万；扣除约45万利息后"基本不赔不赚，白白忙活一场"。若买欧成效推荐的新盘（某大楼盘）"现在房产证还没拿到手"。仅其知晓的西安赴沈阳购房粉丝不下50人。
- 欧成效本人2021年11月抖音表态（一手）："我们主力已经从沈阳撤退了，沈阳站结束了。5000多块进场涨到1万块，对东北城市来说是ok的。"——注意：外界普遍质疑跟随者在5000-8000元的更晚波段高位接盘，"5000进1万出"的收益主要属于欧成效的早期团队。
- 来源：头条 (https://www.toutiao.com/article/7161320324804542976/)；澎湃/易简财经 (https://www.thepaper.cn/newsDetail_forward_15824223)
- 可信度：高（撤退言论有视频存档）

## 四、言行一致 vs 不一致案例（重点）

### 4.1 言行不一致（主要证据）

2. **"加杠杆致富" vs 自己现金流被击穿**：教粉丝"负债率越高越有机会跑赢大盘""没有负债是对家庭最大的犯罪"，自己却在2022-2023两年自曝亏损约3300万，教义与本人财务现实完全背离。
3. **"卖掉上海一套换重庆十套" vs 本人重心在上海/知识付费收佣**：鼓励粉丝置换到重庆沈阳，自己变现渠道是团购佣金、知识星球年费（2018年税后千万）。粉丝承担房价风险，本人赚取通道费。
5. **"永久产权"话术 vs 旅游特许用地**：宣传海外土地"不限购不限贷永久产权"，实为88年剩余租期的特许用地且流转受限、可被**撤销——核心卖点与法律事实不符。
6. **市场判断的双标**：对粉丝喊"不要想着抄底，追涨才能发财"，自己却称团队"主力已从沈阳撤退"、深圳"战略撤退"——本人做波段，粉丝被教育长持。

### 4.2 言行一致（避免只呈现单面的平衡记录）

1. **自己确实下场买房**：2002首套至2009年20套、离婚时35套京沪房；2024年仍被证实亲自在重庆买顶复/整层、并称"2024年在重庆买了10套"。其"永远满仓做多"的操作纪律与其言论一致，并非纯嘴盘（但仓位集中度与杠杆承受力远超普通粉丝）。
2. **看多立场20年未动摇**：从2004年到2024年"渝上北深广"论，无论牛熊始终唱多，人设稳定，从未公开承认方法论失效。
