# T-1思维 · 底层规律挖掘工具

> "T-1：比表层规律低一层的底层规律。一条定律可以解释现存的100条定律。" —— 欧神文集

本Skill提炼欧成效最核心的思维工具——T-1挖掘法——为通用的本质分析工具。
不限领域：可用于商业、职业、产品、人际、社会现象的底层归因。

## 什么是T-1

```
表层（T）：你看到的现象和大众讨论的层面
T-1：驱动表层的下一层规律
T-2：更深的结构性力量（欧神通常挖到这里就停：** R≠0）
```

**判断标准**：如果一条规律能解释这个领域里"现存的100条规律"，它就是T-1。

## 分析工作流

### Step 1: 表述表层问题（T）
把用户的问题写成一句表层规律陈述。
例："为什么现在年轻人都不买房了？"

### Step 2: 追问三连（挖到T-1）
对表层陈述依次问：
1. **"这一层由什么驱动？"**（找到直接原因）
2. **"那个原因又由什么驱动？"**（再挖一层）
3. **"挖到哪一层就不需要再解释了？"**（找到公理层）

欧神的公理层通常是：货币（财富计量）、**（秩序底座 R≠0）、交易（dT>0）、重复博弈（信任的来源）。

### Step 3: 用T-1生成新推断（生成力检验）
真正的T-1必须能解释该领域内其他现象。
测试：拿T-1去解释同领域至少3个其他现象——都能解释，才算挖到了。

例：若"年轻人不买房"的T-1是"房价上涨预期消失+持有成本显性化"，
则可推断：奢侈品消费也会分化、储蓄率会上升、婚育决策推迟——如果这些推断与事实相符，T-1成立。

### Step 4: 反向检验（排他性）
问：**"所有聪明人都会想到这一层吗？"**
- 是 → 这不是独到的T-1，只是常识
- 否 → 保留
（例："房子是用来住的"人人会说；"房产的本质是货币现象"在2004年是排他性洞察，在2026年已是共识——T-1会随时间贬值）

### Step 5: 输出格式

```
【表层 T】...
【T-1】...（一句话，公理式）
【推导链】T-1 → 中间机制 → 表层现象
【生成力验证】用这个T-1还能解释：①②③
【失效条件】什么情况下这个T-1不再成立
```

## T-1挖矿的四个公理层（欧神体系的底座）

当挖不下去时，检查是否触达这四层之一：

1. **货币层**：这是财富计量问题吗？→ 谁在稀释，谁在被稀释
2. **交易层**：这是交易结构问题吗？→ dT>0还是dT<0，谁在阻止交易
3. **博弈层**：这是重复博弈还是一次性博弈？→ 一次性博弈催生欺骗，重复博弈催生诚信
4. ****层**：最终谁说了算？→ R≠0，**是市场的例外（文集#72、#74）

## 使用警示

- **T-1陷阱：万物归因货币**。欧神体系的最大盲区是把太多问题强行归到货币层。技术变革、组织能力、人口结构都是与货币平行的T-1——遇到不属于经济范畴的问题，换工具。
- **T-1会过期**。2004年的"货币贬值→买房"是T-1洞察；2026年在人口拐点后需要叠加"城市分化"层。挖到底层≠挖到永恒。
- **挖层不是抬杠**。T-1挖掘的目的是解释和预测，不是为了显得深刻。如果一个"底层规律"不能生成任何新推断，它只是修辞。
