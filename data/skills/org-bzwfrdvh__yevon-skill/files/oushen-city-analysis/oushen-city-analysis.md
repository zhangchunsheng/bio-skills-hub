# 欧神城市研判法 · 城市价值分析工具

> "只有大城市，才有房地产。" —— 欧神经典语录
> "中国以后的城市排名一定是渝上北深广。" —— 2024年直播（原话）

本Skill把欧成效的城市分析框架提炼为可执行工具。
适用场景：评估某城市房产投资价值、城市间对比、判断进出时机。

## ⚠️ 前置警示（比选筹skill更严重）

城市研判是欧神失手最重的领域：
- 沈阳"暴涨50%-100%"→ 流动性枯竭，跟随者被套（2021年自认"沈阳站结束"）
- 重庆"10万/㎡不需等太久"→ 2021-2022均价仅约1.32万，跟随者约80%亏损
- 贵阳"跳涨30%" → 贵安时代花园烂尾
- 海外土地"2030年每亩1000万" → 2023年15万/亩无人问津
**用此框架时必须同时运行"反面检验"（见Step 5）。**

## 五维分析框架

### 维度1: 人口底盘（欧神的"第一城只看人口"论）

- 常住人口总量与增减趋势（连续3年）
- 人口机械增长（迁入）vs 自然增长（生育）
- 欧神逻辑（2024直播原话）："高铁飞机充分发达后，人口自由迁徙，全国的GDP都差不多，谁是第一城只看人口"
- **反面检验**：人口多≠购买力强。欧神"重庆3300万人口红利"论忽视了人均收入与购买力迁移方向——人从重庆流向沿海，不是反向。

### 维度2: 二手流动性（"决战在二手"的城市版）

- 二手房月成交量 / 挂牌量比值
- 成交周期（房子挂多久能卖出）
- **一票否决项**：月成交枯竭的城市，再便宜也不是资产，是家具
- 这是欧神框架中最经得起检验的一条：沈阳、贵阳的失败本质都是二手流动性陷阱

### 维度3: 庄家行为（**筹码结构分析）

欧神博弈论的核心应用：
- 供地节奏：**在收缩供地（拉盘）还是放量供地（出货）？
- **依赖度：土地**占比多高？依赖越高，做盘动机越强
- 新区筹码分布："只要筹码到了散户手里，**就不发展了"（2018深圳签售会原话）
  → 查目标片区的存量房归属：散户接盘率高的新区，后续投入必然递减

### 维度4: 价差结构（洼地论的用法与误用）

欧神的"上海8万/重庆8千，10倍价差"逻辑：
- **正确用法**：同能级城市间的异常价差 + 基本面收敛催化剂（政策、基建）
- **误用警示**：价差存在的原因往往是真实的能级差。欧神推荐的"洼地"（沈阳、贵阳、海外土地）全部是假洼地——便宜是因为不值钱
- 检验问题："这个价差在收敛还是在扩大？"连续5年扩大的价差不是机会，是趋势
- 价差论的T-1源头（知乎发布文章#1《毁三观竖新生》原话）：2001年股市2100点 vs 莘闵虹梅房子2100元/㎡（1:1）→ 2009年股市2200点 vs 房子22000元/㎡（1:10）——城市资产与金融资产的长期背离是欧神城市判断的经验底座

### 维度5: 进站/出站周期（欧神的择城时钟）

欧神城市投资隐喻（2021抖音原话："沈阳站已经结束了"）：
- **进站期**：政策松绑初起、价格启动前、庄家开始做盘 → 跟进
- **站台期**：涨幅兑现中、成交放量 → 持有
- **出站期**：散户大规模接盘、媒体铺天盖地、**放量供地 → 撤离
- **检验方法**：百度指数搜索该城市"买房"关键词的热度曲线；售楼处外地车牌占比

## 分析工作流

### Step 1: 数据采集（必须联网搜索，不可凭记忆）
- 目标城市：常住人口3年趋势、二手月成交量、挂牌去化周期
- 土地**依赖度、近期供地计划
- 限购限贷政策最新状态
- 目标板块一二手倒挂情况

### Step 2: 五维打分
每维度给 强/中/弱 + 一句话依据。

### Step 3: 庄家-散户筹码推演
回答：现在这个城市/板块，筹码在谁手里？庄家下一步的动作动机是什么？

### Step 4: 进出站判断
当前处于进站/站台/出站哪一阶段？依据是什么？

### Step 5: 反面检验（强制执行）
针对欧神框架的已知盲区逐一自检：
1. **幸存者偏差**：这个"机会"是不是又一个沈阳？（流动性检验）
2. **利益冲突**：推荐这个城市的人赚不赚佣金？（欧神团购模式的教训："免费的才是最贵的"）
3. **时代beta**：判断依赖的是结构性趋势还是普涨周期记忆？
4. **预言记录**：该城市过去5年的实际走势 vs 当年的看多理由，兑现了几成？

### Step 6: 输出格式

```
【五维打分表】
【筹码推演】
【周期位置】进站/站台/出站 + 依据
【欧神式结论】（用其框架会怎么说）
【反面检验结果】（本分析的失效条件）
```

## 欧神城市论断存档（用于校准，含成败记录）

| 论断 | 时间 | 结果 |
|------|------|------|
| "京沪永远涨""30年后上海80万/㎡" | 2017 | 阶段性证伪（2021-2025一线下跌） |
| "卖掉上海一套，置换重庆十套" | 2017-2018 | 跟随者约80%亏损 |
| 沈阳"马上暴涨50%-100%" | 2018 | 高位横盘，流动性枯竭 |
| "战略撤退，深圳房价将跌3-4年、最大跌幅20%" | 2020.7 | 基本应验（少数兑现的预测） |
| "房地产下半场已到来，不能再乱买" | 2020初 | 方向正确 |
| "渝上北深广，重庆中国第一城" | 2024 | 待验证（倾向未兑现） |
| 海外土地"2030年每亩1000万" | 2019 | 严重证伪（腰斩无人接盘） |

**规律总结**：其预测在"看空/撤退"方向偶有命中，在"看多洼地"方向系统性失败——因为看多有商业利益（团购佣金），看空没有。用此框架时对"看多结论"自动降权一档。
