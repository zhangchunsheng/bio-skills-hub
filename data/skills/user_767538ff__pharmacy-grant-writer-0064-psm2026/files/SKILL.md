# 药学标书写作助手

## 用途

封装药学国自然标书正文写作的三个环节,提供可复用的工作流与提示词,确保产出符合评审标准、无空话、逻辑闭环。

## 触发条件

当用户提出以下需求时触发:
- 撰写国自然/省部级科研基金标书的立项依据
- 生成研究目标与内容(三件套)
- 撰写研究方案
- 药学标书正文写作全流程

## 工作流

**输入**:课题方向 + 科室前期基础(数据条件、已有工作、样本量、测量工具、统计方法等)

按以下顺序依次产出三环节,每环节产出后附自查报告:

### 环节一:立项依据五段式(4000-6000 字)
- 五段:研究意义 / 国内外研究现状 / 发展动态分析 / 科学意义与应用前景 / 主要参考文献
- 读取 `references/prompts.md` 的"环节一"提示词,填入 5 个输入空位(课题方向、关键科学问题、研究空白、数据条件、预期结局)后执行

### 环节二:研究目标与内容三件套(700-800 字)
- 三件套:研究目标 3 条 / 研究内容 3 块 / 关键科学问题 1 句
- 基于环节一产出 + 补充信息(样本量、方法、工具、统计),读取"环节二"提示词执行

### 环节三:研究方案(1500-1600 字)
- 五部分:研究设计 / 研究对象 / 研究工具 / 资料收集与质控 / 可行性
- 基于环节一+二产出 + 补充信息(场所、数据源、时间跨度),读取"环节三"提示词执行

## 核心约束(三环节通用)

### 禁用词总表
探讨 / 研究 / 了解 / 掌握 / 分析 / 考察 / 综上 / 因此 / 值得注意 / 有望 / 具有重要意义 / 根据经验 / 分阶段实施 / 按计划推进 / 采取措施 / 信效度良好 / 视情况而定 / 前景广阔 / 有待深入 / 研究尚少

产出后逐词扫描,确保零出现。

### 自查报告(每环节必附)
每环节产出后,附五维自查表:
- **方向性**:假设/目标是否单向明确
- **可检验性**:结局是否可量化、数据是否可得
- **机制性**:是否有明确中介/因果链
- **具体性**:方法/样本/产出是否写死
- **禁用词**:全文是否含禁用词

弱项直接给改法。

## 提示词模板

三环节的完整提示词(角色/任务/输入/输出结构/写法规范/硬性约束)存于 `references/prompts.md`。执行某环节时,读取该文件对应环节的提示词,填入用户输入后生成。禁用词总表与自查报告框架亦在该文件末尾。

## 输出规范

- 每环节产出后导出为 Word 文档(使用本地文档编辑能力:create_doc → doc_insert_markdown → save_file)。
- 文件命名:立项依据-初稿.docx / 研究目标与内容-三件套.docx / 研究方案-完整版.docx
- 引用文献必须真实,不得编造;未提供的信息用"[待补充]"占位。
- 量表、药理指标首次出现写英文全称。

## 使用示例

**输入**:
- 课题方向:卫星药房联合智能药柜对手术科室麻醉药品闭环追溯管理效果的评价
- 科室基础:HIS 处方数据、门诊随访记录、部分患者 MoCA 评分;样本量 PSM 后每组 300 例共 600 例

**输出**:依次生成立项依据五段式 → 三件套 → 研究方案,各附自查报告与 Word 文件。

## 质量底线

- 样本量估算必须给 G*Power 或公式 + 效应量 + α + 1-β + 失访率,禁止"根据经验"。
- 每个量表必须写四件事(原作者+年份 / 汉化者+年份 / 条目数+Cronbach's α / 得分方式与高低含义),Cronbach's α 不允许缺失。
- 质控措施必须写清"谁做、什么频率"。
- 三条研究目标必须一一映射三块研究内容,编号对齐。
