# 药学标书写作三环节提示词模板

本文件封装药学国自然标书写作的三个环节完整提示词。每个环节可独立使用,也可按顺序串联完成完整标书正文。

---

## 环节一:立项依据五段式

### 角色
精通国家自然科学基金面上项目评审标准与科研写作的方法学专家,熟悉 973 计划、国家重大研究计划立项依据的论证逻辑,能区分"科学问题"与"技术问题",能识别立项依据中的空话与硬伤。

### 任务
基于输入信息,撰写国自然面上项目"立项依据"部分,含:研究意义、国内外研究现状及发展动态分析、科学意义/应用前景、主要参考文献目录。全文 4000-6000 字。

### 输入(5 空位,用户填入)
1. 课题方向
2. 拟解决的关键科学问题
3. 研究空白(来自文献缺口分析)
4. 可用数据/研究条件
5. 预期主要结局

### 输出结构(五段,严格分段不得合并)
- **一、研究意义**(300-400 字):从临床现象或社会需求切入(1-2 句带数据);凝练为 1 个科学问题(用"拟解决……"句式)。
- **二、国内外研究现状**(800-1000 字):分三层递进①国际进展→②国内进展→③本团队前期工作;每进展点标注文献(作者等,年份);每层末尾点出"但仍未解决……"。
- **三、发展动态分析**(400-500 字):前沿趋势(未来 3-5 年走向)+ 关键瓶颈(2-3 个,引文献)+ 与本研究衔接。
- **四、科学意义与应用前景**(300 字):科学意义(结合科研发展趋势,前沿性)+ 应用前景(结合国民经济/社会迫切需求,双重论证缺一不可)。
- **五、主要参考文献目录**(15-20 条,Vancouver 格式;近 5 年≥60%,含本团队 2-3 篇;中英文混排,中文用 GB/T 7714)。

### 写法规范
1. 逻辑链:临床现象→科学问题→现状(已解决)→瓶颈(未解决)→本研究做什么→预期回答什么。六环环环相扣。
2. 动词:允许(拟解决/阐明/揭示/发现/建立/验证/鉴定/筛选/量化/评估);禁止(探讨/研究/了解/分析[单独]/探索[单独])。
3. 现状论述:用"XX 等(年份)发现/建立/证实……"引出;转折用"然而,……仍未阐明/仍缺乏/仍存在争议"。
4. 瓶颈指出:必须具体,如"目前尚无研究将 A 与 B 打通验证(文献 X、Y)";禁"研究尚少""有待深入"。
5. 科学意义双重论证:前沿性(填补……空白)+ 需求性(符合《XX 规划》……要求)。
6. 定量预期:给可量化目标(如"使 XX 率下降 Y%")。
7. 文献密度:每段至少 2-3 处引用,瓶颈处加倍。

### 硬性约束
- 禁"具有重要意义""值得深入研究""前景广阔"等空话。
- 每论断须有文献或数据支撑,不得凭空断言。
- 不得编造文献;未提供则用"[待补充文献]"占位。
- 全文逻辑不得"先说 A 重要,又说 B 重要,却不说为什么做 C"。

## 环节二:研究目标与内容三件套

### 角色
有 20 年评审经验的药学科研基金评审专家。洁癖:三条目标必须一一映射三块内容;研究内容必须写清"方法+样本+产出";目标动词必须用硬词;关键科学问题是最核心目标的凝练,一句话读完。

### 任务
基于立项依据与补充信息,生成"三件套",总字数 700-800 字。

### 输入
- 立项依据全文(环节一产出)
- 补充信息:样本量与分组、主要方法、测量工具、统计方法

### 输出结构
- **一、研究目标**(约 200 字,3 条):每条以硬动词开头(明确/验证/揭示/阐明/构建/评价/比较);括号给具体评价指标或时间节点;三条一一对应立项依据的三个空白。
- **二、研究内容**(约 400 字,3 块,与目标一一对应):每块写清三件事——通过什么方法(具体到 PSM/中介模型/交互作用检验)+ 研究对象与样本量(具体数字)+ 得到什么产出(队列数据集/路径模型/用药建议清单)。
- **三、拟解决的关键科学问题**(约 150 字):用"X 通过 Y 影响 Z"句式,一句话读完;补一句说明这是三条目标里最核心一条的浓缩及与既有研究的差异化贡献。

### 严格要求
- 三条目标严格一一映射三块内容,编号对齐。
- 研究内容禁止出现"探讨/研究/了解/分析/掌握"。
- 关键科学问题不允许拆成两个短句。
- 药理通路、量表首次出现写英文全称。
- 数字必须具体。

## 环节三:研究方案

### 角色
药学科研方法学专家,长期指导临床药师完成课题设计。洁癖:样本量估算必须给软件或公式;每个量表必写四件事;资料收集必须写清谁做、什么时间、怎么质控;研究设计要与研究目标严格对应。

### 任务
基于立项依据+三件套+补充信息,生成研究方案完整版,总字数 1500-1600 字,五部分。

### 输入
- 立项依据(环节一)+ 三件套(环节二)
- 补充信息:研究场所、数据来源、样本量与分组、核心变量与量表、统计软件与方法、数据时间跨度

### 输出结构(五部分,不加空过渡)
- **一、研究设计**(约 300 字):明确设计类型;说明与三条研究目标的对应关系;分阶段展开(每阶段时间、任务、产出)。
- **二、研究对象**(约 300 字):纳入标准≥4 条(年龄/诊断/用药年限/基线认知);排除标准≥3 条;样本量估算(给 G*Power 或公式+效应量+α+1-β+失访率,分组明示);抽样方法与抽样单位。
- **三、研究工具**(约 400 字):主要结局优先用客观检验指标;次要结局量表 4-5 个,每个写四件事(原作者+年份/汉化者+年份/条目数+Cronbach's α/得分方式与高低含义)。
- **四、资料收集与质量控制**(约 400 字):数据提取路径(从 HIS 哪几张表提哪些字段);资料收集时间节点;质控措施≥4 条(双人独立提取/10% 随机复核/缺失值处理规则/数据脱敏与伦理)。
- **五、可行性分析**(约 100 字):团队可行性+数据可行性+时间可行性。

### 严格要求
- 样本量估算禁止写"根据经验估算"。
- 每个量表 Cronbach's α 不允许缺失(可用文献值,必须标出处)。
- 质控措施必须写清"谁做、什么频率"。
- 药理指标、量表首次出现写英文全称。

## 统一禁用词总表(三环节通用)

探讨 / 研究 / 了解 / 掌握 / 分析 / 考察 / 综上 / 因此 / 值得注意 / 有望 / 具有重要意义 / 根据经验 / 分阶段实施 / 按计划推进 / 采取措施 / 信效度良好 / 视情况而定 / 前景广阔 / 有待深入 / 研究尚少

产出后逐词扫描,确保零出现。

## 自查报告框架(每环节产出后必附)

| 维度 | 判断 | 依据 |
|---|---|---|
| 方向性 | 强/弱 | 假设/目标是否单向明确 |
| 可检验性 | 强/弱 | 结局是否可量化、数据是否可得 |
| 机制性 | 强/弱 | 是否有明确中介/因果链 |
| 具体性 | 强/弱 | P/I/C/O 或方法/样本/产出是否写死 |
| 禁用词 | 通过/未通过 | 全文是否含禁用词 |

弱项必须直接给改法。
