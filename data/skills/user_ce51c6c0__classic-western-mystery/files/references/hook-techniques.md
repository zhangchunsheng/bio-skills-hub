# 章末钩子

### 1. 悬念
**做法：** 章节末尾抛出核心谜题的新变量（身份、动机、道具去向），不给答案。

**示例：** 手电筒只剩两支，可活着的人却有三个。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要在结尾直接揭示凶手身份。
**验收：** 末段留未解问题；关键道具计数与人数错位。

### 2. 反转
**做法：** 用物证或旁证推翻前章既定认知（自杀→他杀、失踪→藏匿），以客观事实落地。

**示例：** 验尸报告显示颈部有挣扎痕迹，原本判定的自杀变成了他杀。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要仅凭角色主观猜测就推翻既定结论。
**验收：** 看似自杀实为他杀；失踪者并未死亡。

### 3. 危机
**做法：** 在封闭空间内叠加‘尸体+1’与‘资源-1’双重打击，迫使人物被动应对。

**示例：** 第二具尸体躺在走廊尽头，唯一的对讲机也不见了。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要让主角主动寻找新武器化解危机。
**验收：** 封闭空间再添一具尸体；唯一武器/通讯手段失窃。

### 4. 期待
**做法：** 建立显性倒计时规则（童谣、道具计数），让读者预判下一节奏点。

**示例：** 童谣唱到『第三声钟响，红伞落地』，下一句暗示毒气释放，幸存者正准备揭穿真凶。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要只靠模糊的预感制造悬念。
**验收：** 童谣下一句预示下一死法；幸存者即将揭穿真凶。

### 5. 冲突
**做法：** 利用指控会、搜身、分组搜索等强制互动场景，让嫌疑在对话中外化。

**示例：** 「是你把钥匙藏起来的！」
「凭什么怀疑我，队长自己也没交代行踪。」
「大家分头搜查，谁藏东西谁就是凶手。」
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要让人物独自内心独白化解嫌疑。
**验收：** 两派人马互扣凶手帽子；权威人物被迫自证清白。

### 6. 情感
**做法：** 在高压下剥离社会面具，用过往罪行细节引发羞耻/愧疚/愤怒的真实反应。

**示例：** 「我曾把同事推下楼，今天终于被揭开了。」
「我不认，那是意外！」
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要用平铺直叙的背景介绍代替当场情绪爆发。
**验收：** 过往罪行被公开审判；临死前的忏悔或拒认。

### 7. 幽默
**做法：** 紧张处插入一句黑色讽刺或冷面调侃，释放微量张力再拉升。

**示例：** 「看来死神也挑食，连这顿泡面都不放过。」
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要在高潮处插入轻松笑话破坏氛围。
**验收：** 紧张中插入黑色讽刺对白；荒诞情境下的冷面调侃。

### 8. 新奇
**做法：** 引入超预期的呈现形式（全知音频、童谣道具、密室物理诡计）作为核心钩子。

**示例：** 广播里突然响起全知旁白：『第七条规则，死者将在午夜前被锁在冰柜。』
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要沿用普通日记或线索卡片作为唯一钩子。
**验收：** 童谣与杀人手法严丝合缝；全知音频指控打破第四面墙。
