# 对话声口

- 禁止说明腔: True

## 声口技法
### 1. vp_01
**做法：** 面对指控时，先用简短否定或反问化解，再抛出反制性细节转移焦点，保持语速平稳不急不缓。

**示例：** 「我没做。」他补充道：「那天晚上我正在码头卸货，有三个工友作证。」
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 「我绝对没做！」他大喊大叫，语气激动。
**验收：** 首句十二字；含一个反问或否定词；随后补一句具体细节；全程无感叹号。

### 2. vp_02
**做法：** 多人对峙时，插入极短的附和或纠正，制造“旁观者视角”假象，实则控制信息流向。

**示例：** 「没错。」
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 「你说得对，那个细节改变一切。」
**验收：** 单句不足八字；仅用评价性形容词或动词；不提供新事实；语气平淡如评论天气。

### 3. vp_03
**做法：** 关键线索出现前，先用无关闲笔（天气、饮食、琐事）铺垫三到五句，再以平叙口吻抛出核心信息。

**示例：** 雨点敲着窗棂，咖啡冷了一半，桌上的日历翻到周三。突然灯光熄灭，尸体出现在储藏室中央。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要在闲笔后用‘接着’、‘随后’等连接词引出核心线索。
**验收：** 闲笔与核心信息间无显性连接词；核心句去掉修饰语后仍为完整陈述句。

### 4. vp_04
**做法：** 被追问隐私时，用“记不清/不确定/听说”模糊限定词，配合反向提问将举证责任推回对方。

**示例：** 「记不清那天具体几点，你怎么知道的？」
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要用‘我清楚记得’或肯定语气直接回答。
**验收：** 模糊词位于句首或句中；反向提问以“什么/怎么/”开头；全句不含第一人称确信表达。

### 5. vp_05
**做法：** 临死/极限压力前，保留一句未完成的半截话（被打断/自行中止），留白作为悬念钩子。

**示例：** 「门外传来脚步声，钥匙还在——」
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要在后文补全那句被打断的话。
**验收：** 句子在关键名词/动词前戛然而止；后文不补全；后续叙述不解释内容。

### 6. 问答拒绝
**做法：** 对白落实「问答拒绝」：用短句交锋推进信息差或情绪转折，禁止旁白替角色解释立场。

**示例：** 「你为什么不报警？」
「报警又能换来什么？」
「凶手还在里面。」
「那你打算自己查？」
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要让旁白替角色解释动机。
**验收：** 本场至少一处对白可勾选「问答拒绝」的功能，且无说明腔堆砌。
