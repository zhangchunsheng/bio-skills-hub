# 常见问题 FAQ

本页服务 `classic-western-mystery-all`（主类型：封闭环境连环杀人悬疑）。按需使用，勿把主类型名当成万能标签。

## 1. 题材不完全匹配还能用吗？
若落在「不适合」（摘要：依赖天才侦探现场破案的本格推理；开放城市背景下的连环案件侦破流程；以/科幻设定解释作案手法的异能悬疑），**不要硬套强题材层**（tropes-dna / 题材专属槽位）。emotion-curve、开篇冲突、章末钩子、对话做法等**通用技法仍可按需用**；Agent 应声明已跳过题材专属切片。完整清单见 `tropes-dna.md`。

## 2. Agent 没有提醒我题材不对怎么办？
本包要求写前过「拒写闸门」（见 `SKILL.md`）。若 Agent 跳过闸门直接开写，可明确说：「按 `classic-western-mystery-all` 闸门先核对题材；不匹配就跳过 tropes，只留通用技法。」

## 3. 怎么让 Agent 真正用上这个 Skill？
安装到 skills 路径后，用短口令点名包 id，例如：「启用 `classic-western-mystery-all`」或「@`classic-western-mystery-all`」。详见 `SKILL.md`「调用示例」。只说「帮我写小说」而不点名包，Agent 可能不会加载本包。

## 4. 示例可以照着仿写吗？
**不可以。** 示例是无样章条件下的独立虚构示意，只帮助理解「做法 / 验收」。写你自己的书时，用自己的情节与专名落地技法；禁止模仿任何样书声口或节奏指纹。对外 Skill 不附带专名清单，也不渲染样书精确句长/对话占比。

## 5. `-all` 聚合包和分 facet 微包怎么选？
新手直接装 `-all` 即可。只有需要「只注入声口 / 只注入钩子」时，再装对应微包；或用触发口令声明「只用 hook + opening」。

## 6. 禁用词好多，会不会写不下去？
硬禁用（可检索）约 1 条，写完抽查命中即可；另有 5 条「规避类别」偏润色建议，不必句句死磕。优先保证 playbook「验收」勾选，而不是堆禁用词。

## 7. 写崩了或腔调不对怎么自检？
按顺序：① 是否误用强题材层（闸门 / tropes-dna）；② opening 是否前段就有冲突；③ 章末是否落到 hook 验收；④ 是否误用了样书专名或把主类型专属词写进不匹配正文。

## 8. 只想学声口、不想学题材套路？
可以只注入 `style-voice.md` / `dialogue.md`，并跳过 tropes-dna；仍建议先过闸门，避免题材冲突结构悄悄带进正文。

## 9. 和别的 Skill 一起用？
可以。若另一 Skill 主类型与本包冲突，以「边界更严」的 unfit 为准，或拆章分别注入；冲突时优先保留各包的通用技法层。

## ⚠ 错用告警（指针）

边界全文只维护在 `references/tropes-dna.md`。任务落在「不适合」时跳过 `classic-western-mystery-all` 的强题材层，通用技法可按需保留或换对应题材包。
