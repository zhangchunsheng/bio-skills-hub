# 情绪曲线

- 模板: 平静好奇 → 震惊质疑 → 紧张搜索 → 恐惧蔓延 → 绝望对峙 → 释然揭秘
- 章长目标: 2800–3800
- 题材情绪标签: 幽闭恐惧、猜疑博弈、绝望求生、道德审判

## 用法
1. 写章前确认本章对应模板中的哪一拍（或最接近的情绪标签）。
2. 章内至少完成一次与该拍方向一致的**可观察**情绪行为（动作/对话/代价），勿只写形容词。
3. 章末钩子类型应服务下一拍，避免与当前拍冲突。
4. 「拍点说明」是**可迁移写法**（怎么落地情绪），不是样书剧情摘要；专名须换成你的人物/场景。

## 拍点说明
- 平静好奇：用环境细节与陌生人互动建立封闭感，避免大段说明。
- 震惊质疑：用权威声音抛出指控清单，让全员被动接收，禁止主角长独白。
- 紧张搜索：以分组行动切分视角，用物理空间限制制造节奏呼吸。
- 恐惧蔓延：用童谣道具与死亡对应，每亡一人移走一物，视觉化倒计时。
- 绝望对峙：幸存者互指为凶，用短对话加速节奏，拒绝心理独白堆砌。
- 释然揭秘：留书/录音回溯全局，用冷静口吻收束，勿在高潮后再铺排新谜。

## 情感自检
- [ ] 本章情绪拍可一句话说清
- [ ] 有物件或动作承载情绪，而非空心心理词
- [ ] 章末钩子与下一拍情绪衔接
