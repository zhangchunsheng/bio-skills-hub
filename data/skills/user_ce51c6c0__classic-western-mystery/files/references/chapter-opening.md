# 开篇技法

- 前 15% 必须出现冲突或压力

## 开篇 playbook
### 1. 以多视角交替呈现受邀者踏上前往封闭岛屿的旅途，各自手持格式相似的神秘邀请函
**做法：** 以多视角交替呈现受邀者踏上前往封闭岛屿的旅途，各自手持格式相秘邀请函，内心独白暗藏过往秘辛。

**示例：** 他站在码头，手里攥着一张压着烫金边框的信笺，心底默念着多年前那桩未了的债务；她在舱室里反复抚摸信封的压痕，脑海闪过被迫签下的保密协议；另一人在甲板眺望灰雾笼罩的岛影，指尖摩挲着同款信纸，暗自盘算如何利用这场邀约洗清罪名。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要用单一视角直述全员登船过程，也不要省略信笺的细节与内心算计。
**验收：** 开篇在前15%内完成：多位主角登场、邀请函细节露面、各自隐秘动机初现、封闭环境地理框架铺陈。

### 2. 抵达岛上后，东道主缺席
**做法：** 抵达岛上后，缺席，仅有仆役伺候；首次聚餐以/录音形式公开逐人指控过往罪行，瞬间撕破社交假面。

**示例：** 管家领着众人步入餐厅，长桌上空无一人，只有留声机在无人操控下缓缓转动，机械嗓音逐一宣读每位客人的过往罪行，现场瞬间陷入死一般的寂静。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要让东道主亲自现身解释，也不要跳过指控环节直接进入自由活动。
**验收：** 首场群戏必须在开篇25%前落地：全员到齐、缺席成谜、机械化指控逐名点破、现场陷入死寂与恐慌。



## 场景语法
### 1. 首死案以看似意外的中毒/窒息发生，死者正是童谣首句对应角色；现场无外来痕迹
**做法：** 首死案以看似意外的中毒/窒息发生，死者正是童谣首句对应角色；现场无外来痕迹，确立“凶手在内部”铁律。

**示例：** 翌日清晨，靠窗的客人被发现面色紫黑、嘴角残留苦杏仁气味，恰如童谣首句「一颗糖，甜入喉」所暗示，房门窗户完好无损，无任何打斗痕迹。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要让死因明显是外力撞击，也不要在现场留下陌生人足迹。
**验收：** 首死场景须验收：死亡方式符合童谣首句、现场排除外力介入、幸存者随即展开全岛搜索且。

### 2. 后续每死必伴随童谣推进、瓷偶减少、关键道具
**做法：** 后续每死必伴随童谣推进、瓷偶减少、关键道具（枪、针筒、解药）离奇失窃或现身，形成“物证倒计时”视觉线索。

**示例：** 第二具尸体出现时，桌上原本排列的七只瓷偶只剩六只，童谣第二句「两只鸟，飞不远」应验，原本锁在抽屉的针筒凭空出现在床头柜，枪支也在无人察觉间换了位置。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要让死亡顺序与童谣脱节，也不要让道具数量保持不变。
**验收：** 每轮杀人场景须验收：死亡序次与童谣严丝合缝、瓷偶数量同步递减、核心凶器/线索在封闭空间内诡异流转。

### 3. 搜索场景采用“分组并行+交叉监视”结构：幸存者结伴搜索可疑空间
**做法：** 搜索场景采用“分组并行+交叉监视”结构：幸存者结伴搜索可疑空间，实则互相监防；搜索结果必为空，强化“无外人”绝望感。

**示例：** 三人一组分别深入地下室、灯塔与储藏室，彼此约定每十分钟汇报一次位置，实际上每组都在暗中记录同伴的异常举动，搜索结束时一无所获，恐惧感却在相互监视中加倍。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要让全员一起行动且毫无防备，也不要让搜索发现关键线索。
**验收：** 搜索场景须验收：分组由当下联盟决定、搜索路线覆盖全岛死角、结果零发现但心理防线进一步崩塌。

### 4. 疑心场景通过“单人独白+二人对质+全员会议”三层递进
**做法：** 疑心场景通过“单人独白+二人对质+全员会议”三层递进，将过往罪行细节碎片化植入对话，让动机与手段在推演中浮现。

**示例：** 夜深时，他独自在床边低声复盘那年火灾的细节；随后两人在走廊对峙，试探对方是否知晓毒药来源；最后全员围坐会议桌，形成暂时共识：凶手必在熟悉岛屿布局的人之中。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要跳过内心独白直接进入群体讨论，也不要让对质毫无试探性。
**验收：** 疑心场景须验收：至少包含一段内心独白揭示隐秘、一段对质试探破绽、一段会议形成暂时性嫌疑共识。

### 5. 环境封锁场景利用风暴/涨潮/通讯中断等物理隔绝，压缩幸存者活动半径
**做法：** 环境封锁场景利用风暴/涨潮/通讯中断等物理隔绝，压缩幸存者活动半径，迫使高频正面交锋；自然景观描写映照内心恐惧。

**示例：** 暴风雨夜电报线被巨浪扯断，唯一的对讲机只剩静电噪音，潮水淹没了通往灯塔的栈道，众人被迫挤在餐厅角落，有人因寒冷与绝望崩溃大哭，另一人趁机露出破绽。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要让通讯畅通无阻，也不要让环境变化对行动范围无影响。
**验收：** 封锁场景须验收：物理隔绝条件具象化（如电报线断、航班停飞）、活动区域肉眼可见缩小、至少一人因环境压力崩溃或暴露破绽。

### 6. 终局场景以最后幸存者视角揭露真相
**做法：** 终局场景以最后幸存者视角揭露真相：凶手利用伪装死亡/时间差/心理操纵完成全员清洗，留下书面自白解释手法动机。

**示例：** 仅存的她翻开凶手留下的手写自白，字迹工整地还原了伪装死亡的时间差、利用录音制造不在场证明、以及逐步毁灭瓷偶的手法，动机直指开篇指控名单上的每一项罪名。
**替换提醒：** 示例为独立虚构示意，只对照做法与验收；人名/地名/物件换成你的设定。禁止模仿任何样书声口或照抄样书专名。
**避雷：** 不要让真相靠外部侦探突然出现揭示，也不要留下与前文矛盾的漏洞。
**验收：** 终局场景须验收：手法与前文所有反常细节零矛盾、动机回扣开篇指控名单、自白形式符合凶手人设、留予读者复盘空间。



## 验收
- 开篇15%内完成多视角汇聚、邀请函细节、隐秘动机、地理封闭四要素铺陈
- 首场群戏在25%前落地：全员到齐、缺席、机械指控逐名点破、现场陷入死寂
- 无具体人名地名情节细节泄露，仅保留结构性动作与心理动作描述
- 前 15% 出现冲突或压力
- 禁止纯氛围铺陈超过开篇配额
- 禁止天气描写、睡醒刷牙式开场占满开篇配额
