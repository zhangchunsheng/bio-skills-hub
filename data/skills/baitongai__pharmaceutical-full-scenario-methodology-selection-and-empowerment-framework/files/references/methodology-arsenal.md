## 弹药库一：经典弹药库（市场/战略）

| 方法论 | 核心用途 | 适用场景 | 注意事项 |
|--------|----------|----------|----------|
| SWOT分析 | 优势/劣势/机会/威胁评估 | 产品定位、竞品对比 | 易流于表面，需配合量化数据 |
| 波特五力 | 行业竞争结构分析 | 新市场进入决策、品类吸引力评估 | 静态框架，需结合时间维度 |
| STP理论 | 市场细分-目标-定位 | 产品定位、受众划分 | 医药领域需结合患者亚型树 |
| 4P/7Ps | 营销组合策略 | 年度计划、推广策略 | 医药领域需加入第5P：Policy |
| BCG矩阵 | 产品组合管理 | 多产品线资源分配 | 现金牛≠战略核心 |
| GE矩阵 | 业务单元评估 | 市场吸引力×竞争力 | 比BCG更精细 |
| Ansoff矩阵 | 增长策略选择 | 市场渗透/开发/产品开发/多元化 | 医药领域需考虑政策变量 |
| 3C分析 | 公司-竞争者-顾客三角 | 战略环境分析 | 需加入第4C：Compliance |
| 蓝海战略 | 价值创新打破竞争 | 新品类创建、差异化定位 | 医药领域需验证临床需求真实性 |
| 价值主张画布 | 产品价值与客户需求匹配 | 产品定位验证 | 区分功能价值与情感价值 |

## 弹药库二：医学证据弹药库

| 方法论 | 核心用途 | 适用场景 | 注意事项 |

| 循证医学五步法 | 提出-检索-评价-应用-后效 | 临床问题解答 | 强调患者价值观 |

| ISPOR良好实践 | 药物经济学研究规范 | HEOR研究设计 | 需对齐中国HEOR专家共识 |
| NNT/NNH | 绝对效益/风险量化 | 临床获益沟通 | 优于相对风险降低(RRR) |

## 弹药库五：系统/元思维弹药库

| 方法论 | 核心用途 | 适用场景 | 注意事项 |
|--------|----------|----------|----------|
| WSR（物理-事理-人理） | 系统分析三维度 | 复杂业务问题诊断 | 物理=事实，事理=逻辑，人理=人心 |
| 系统动力学 | 反馈回路建模 | 市场趋势预测 | 增强回路vs调节回路 |
| 12杠杆点(Donella Meadows) | 系统干预点识别 | 战略杠杆分析 | 越靠底层杠杆力越强（12最弱→1最强） |
| 第一性原理 | 回归本质推理 | 新品类定位、创新突破 | 需剥离所有假设 |
| MECE原则 | 互斥穷尽分类 | 问题拆解、数据分析 | 不重叠不遗漏 |
| 假设树 | 假设驱动分析 | 战略推演、市场预测 | 自上而下逐层分解 |
| 决策树 | 决策路径分析 | 方案选择、风险评估 | 需标注概率与期望值 |
| 贝叶斯推理 | 概率更新 | 不确定性决策 | 先验→似然→后验 |
| 80/20法则 | 帕累托优先级 | 资源分配、客户分级 | 找到关键少数 |
| 反向推理 | 从目标倒推路径 | 战略规划、目标分解 | 从终点出发，逐层回溯 |
| 第二层思维 | 超越显而易见 | 战略决策、竞争推演 | "然后呢？"追问法 |

根据职能快速定位优先弹药库：

| 职能 | 首选弹药库 | 辅助弹药库 | 禁用（一般情况） |
|------|------------|------------|------------------|
| 市场部 | 经典 + 系统 | 跨界（品牌相关） | — |
| 医学部 | 医学证据 | 经典（战略层面） | 推广/销售（除非MSL） |

| 商务部 | 经典（供应链） | 系统（渠道优化） | 跨界（非直接相关） |

## 方法论组合模式

常见的高效方法论组合：

### 模式一：证据驱动型（医学/准入）
```
GRADE证据分级（骨架） + HEOR框架（量化） + WSR（校验）
```
适用：DA制作、医保谈判、KOL教育

### 模式二：战略分析型（市场）
```
SWOT（现状） + 波特五力（结构） + GE矩阵（优先级） + 12杠杆点（干预）
```
适用：年度市场计划、新品上市策略

### 模式三：客户转化型（推广/销售）
```
采纳阶梯（分层） + SPIN（探询） + FABE（传递） + LSCPA（异议）
```
适用：拜访话术设计、客户转化策略

### 模式四：创新突破型（品牌/前沿）
```
第一性原理（破局） + ZMET（洞察） + 设计思维（共创） + WSR（校验）
```
适用：新品类定位、KV设计、患者教育创新

### 模式五：合规防线型（合规/全员）
```
RDPAC准则（底线） + 广告法（红线） + WSR-物理（事实核验）
```
适用：物料审核、话术合规检查、培训设计
