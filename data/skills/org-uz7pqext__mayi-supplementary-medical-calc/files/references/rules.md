# 补充医疗保险缴费计算器 - 政策法规参考

## 技能简介

计算补充医疗保险缴费金额和报销规则

## 与工资条的关联

补充医疗保险在工资条上体现为补充扣缴项

## 社保公积金核心规则

### 五险缴费比例（全国通用参考）
| 险种 | 单位比例 | 个人比例 |
|------|---------|---------|
| 养老保险 | 16% | 8% |
| 医疗保险 | 8% | 2% |
| 失业保险 | 0.5% | 0.5% |
| 工伤保险 | 0.2%-1.9% | 0 |
| 生育保险 | 1%（已并入医保） | 0 |

### 公积金缴存
- 缴存比例：5%-12%（单位和个人各选一档）
- 缴存基数：上年度月平均工资
- 基数上限：一般为当地上年度社平工资3倍
- 基数下限：一般为当地最低工资标准

### 注意事项
- 各地具体比例和基数上下限有差异
- 社保基数每年7月调整一次
- 公积金基数每年7月调整一次
