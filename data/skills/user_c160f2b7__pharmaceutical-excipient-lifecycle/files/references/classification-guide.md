# 药用辅料分类与登记资料指南

## 一、辅料分类判断流程

### 1. 分类判断决策树

```
开始
  │
  ├─ 该辅料是否在境内外已上市药品中使用过？
  │   │
  │   ├─ 从未使用过 ──→ 第1类（1.1-1.4）
  │   │   ├─ 天然提取物/发酵产物（未经化学修饰）→ 1.1
  │   │   ├─ 化学合成/修饰的单一实体 → 1.2
  │   │   ├─ 化学合成/修饰的混合物 → 1.3
  │   │   └─ 其他 → 1.4
  │   │
  │   └─ 已有使用历史 ──→ 第2类（2.1-2.4）
  │       ├─ 国产上市药品中使用 → 2.1
  │       ├─ 进口上市药品中使用 → 2.2
  │       ├─ 其他国家/地区上市药品中使用 → 2.3
  │       └─ 已有食用历史 → 2.4
  │
  ├─ 未在药品中使用过，但在食品/化妆品中使用过？
  │   ├─ 食品中使用 → 3.1
  │   └─ 化妆品中使用 → 3.2
  │
  └─ 其他情况 → 第4类（按风险确定资料要求）
```

### 2. 关键判断要素

| 要素 | 说明 |
|------|------|
| 使用历史 | 境内外药品中是否有使用先例（查FDA IID、CDE登记平台、药典收载情况） |
| 药典收载 | 是否收录于ChP、USP、EP、JP等主流药典 |
| 给药途径 | 口服、外用、注射、眼用、吸入——决定风险等级 |
| 化学修饰 | 是否经过化学修饰或合成（区别于天然提取物） |
| 来源属性 | 天然提取/化学合成/发酵产物/动物来源/植物来源/矿物来源 |
| 结构属性 | 单一实体/混合物/复杂混合物 |

### 3. 高风险辅料清单

**高风险辅料**需提交更全面的资料（尤其药理毒理模块）：

- **给药途径相关**：
  - 注射剂用辅料
  - 眼用制剂用辅料
  - 吸入制剂用辅料
  - 植入剂用辅料
  - 鞘内注射用辅料

- **来源相关**：
  - 动物来源或人源的药用辅料（BSE/TSE风险）
  - 转基因来源的药用辅料
  - 微生物发酵来源的药用辅料

- **功能相关**：
  - 新型功能性辅料（缓控释、靶向等）
  - 具有药理活性的辅料
  - 已知或潜在致敏性/毒性辅料

## 二、登记资料8大模块

### 模块1：登记人基本信息

**内容清单**：
- □ 登记人名称、注册地址、生产地址
- □ 营业执照（经营范围须含药用辅料生产）
- □ 药品生产许可证（如已取得）
- □ 授权委托书（如委托代理）
- □ 境外登记人委托中国代理机构的授权文书及公证认证文件
- □ 联系人信息（姓名、电话、邮箱）

### 模块2：辅料基本信息

**内容清单**：
- □ 辅料名称（中文名、英文名、化学名、CAS号）
- □ 结构信息（化学结构式/分子式/分子量）
- □ 理化性质（性状、溶解度、pH/pKa、熔点/沸点等）
- □ 用途信息（功能类别、建议用量范围、给药途径）
- □ 药典收载情况（ChP/USP/EP/JP等）
- □ 已有使用历史证据

### 模块3：生产信息

**内容清单**：
- □ 工艺流程图（含关键步骤标识）
- □ 工艺详述（步骤参数、温度/时间/pH等）
- □ 物料控制清单（原料/溶剂/催化剂来源与质量标准）
- □ 关键步骤控制（IPC参数及范围）
- □ 工艺验证方案与报告
- □ 工艺开发历史（如适用）
- □ 生产设备清单

### 模块4：特性鉴定

**内容清单**：
- □ 结构确证（IR/UV/NMR/MS/XRD等谱图及解析）
- □ 理化性质
- □ 杂质研究（有机杂质/无机杂质/残留溶剂/元素杂质）
- □ 功能特性（流动性/可压性/粒径分布/黏度/渗透压等，视功能类别而定）
- □ 微生物限度/无菌（视给药途径而定）

### 模块5：质量控制

**内容清单**：
- □ 质量标准草案（含检验项目、限度、方法）
- □ 方法学验证资料（专属性/线性/范围/精密度/准确度/耐用性等）
- □ 标准制定依据（论述各项目限度设定的合理性）
- □ 对照品来源与标定信息

### 模块6：批检验报告

**内容清单**：
- □ 不少于连续三批的商业规模或中试规模批次
- □ 每批检验报告（全项检验）
- □ 批间一致性评估
- □ 与质量标准的对比分析

### 模块7：稳定性研究

**内容清单**：
- □ 稳定性研究方案
- □ 长期稳定性数据
- □ 加速稳定性数据
- □ 影响因素试验数据（光/热/湿）
- □ 内包材相容性信息
- □ 稳定性研究承诺（如仍在进行中）
- □ 包装完整性验证

### 模块8：药理毒理研究

**内容清单**（按分类决定深度）：
- □ 急性毒性试验
- □ 重复给药毒性试验
- □ 遗传毒性试验
- □ 生殖毒性试验（视情况）
- □ 致癌性试验（视情况）
- □ 局部耐受性试验
- □ 过敏/刺激/溶血试验
- □ 药代动力学（视情况）
- □ 已有安全性文献综述

### 资料要求的分类差异

| 资料模块 | 第1类 | 第2类 | 第3类 | 第4类 |
|----------|-------|-------|-------|-------|
| 1-6模块 | 全套 | 全套 | 全套 | 按风险确定 |
| 稳定性 | 全套 | 全套 | 全套 | 按风险确定 |
| 药理毒理 | 全面开展 | 提供已有安全性文献/可选择简化 | 食品级可参考食品毒理数据；化妆品级提供现有数据 | 按风险确定 |

## 三、关联审评流程

### 登记-关联-审评三阶段

```
阶段一：辅料登记
  辅料登记人通过CDE原辅包登记平台提交资料
  → 获取登记号（初始状态无标识）
  → 平台自动生成登记信息

阶段二：制剂关联
  MAH在提交制剂注册申请时，提供辅料登记号
  → CDE在审评制剂时，通过登记号关联辅料资料
  → 辅料与制剂同步审评

阶段三：审评结论
  制剂获批 + 辅料通过审评 → 辅料状态更新为 "A"
  制剂获批 + 辅料未通过审评 → 辅料状态更新为 "I"
  → 目前状态为"A"的辅料仍需接受定期监督检查
```

### A/I状态含义

| 状态 | 含义 | 后续行动 |
|------|------|---------|
| **A** | 已激活，通过技术审评 | 5年一次的定期监督检查；变更须更新平台并告知MAH |
| **I** | 未激活/未通过审评 | 补充资料后重新提交审评；可与新的制剂申请重新关联 |

### 状态转换

```
I → A 的条件：
1. 补充缺失或不符合要求的资料
2. 与新的制剂申请重新关联
3. 通过技术审评

A → I 的条件：
1. 监督检查发现严重缺陷且未完成整改
2. 变更后未及时更新平台信息
3. 不再符合药用要求
```

## 四、常见问题

### Q1：某辅料已有食用历史，但药品中未使用过，应归哪类？
→ 归入**第3类（3.1）**。可提交食品毒理学资料作为安全性评估依据，
   但仍需完成全部6个基础模块和稳定性研究。

### Q2：辅料已在USP收载，但中国药典未收载，如何分类？
→ 归入**第2类（2.2或2.3）**。USP收载可作为已有使用历史的证据，
   但需注意USP方法与ChP方法的差异，可能需要方法转移或等效性验证。

### Q3：天然植物提取物作为辅料，有哪些特殊要求？
→ 归入**1.1类**（如药品中未使用过）。需要：
   - 明确药材基原（拉丁学名、药用部位）
   - 提取工艺标准化（含指纹图谱）
   - 批间一致性控制
   - 农残、重金属、黄曲霉毒素等安全性指标
   - 如用于注射剂，还需内毒素等控制

### Q4：辅料登记后多久可以关联获批？
→ 无固定时限，取决于：
   - 关联的制剂品种审评进度
   - 辅料资料的完整性
   - 如资料完整且与制剂配合良好，一般与制剂同步完成审评
