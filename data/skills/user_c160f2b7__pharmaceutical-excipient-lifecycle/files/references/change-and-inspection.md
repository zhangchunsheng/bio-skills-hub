# 药用辅料变更管理与监督检查指南

## 一、变更管理体系

### 1.1 变更分类体系

根据GMP附录§10（第六十八条），变更按风险分为三大类：

| 变更类别 | 定义 | 影响程度 |
|----------|------|---------|
| **重大变更** | 可能对辅料安全性、有效性、质量可控性产生显著影响 | 需全面研究、CDE平台更新、出具报告 |
| **中等变更** | 可能对辅料质量产生一定影响 | 需专项研究、告知MAH、平台更新 |
| **微小变更** | 对辅料质量基本不产生影响 | 企业内部管控，年度报告 |

### 1.2 常见变更类型及处理

#### A. 生产场地变更
- **重大变更**：生产场地整体搬迁或新建车间
- **处理**：工艺验证（至少三批）+ 稳定性研究 + 质量对比 + 清洁验证
- **告知**：更新CDE登记平台 + 书面通知所有MAH
- **时间**：变更实施前完成验证，获批后方可上市销售

#### B. 原材料及配方变更
- **重大变更**：主要原材料来源变更；配方比例变更
- **中等变更**：辅助原材料供应商变更（同一质量标准）
- **微小变更**：非功能性工艺助剂供应商变更
- **处理**：原材料变更需对比研究；配方变更需重新验证

#### C. 生产工艺和过程控制
- **重大变更**：工艺路线变更；关键工艺参数改变
- **中等变更**：非关键工艺参数调整（在已验证范围内）
- **微小变更**：设备型号更新（等同替代）
- **处理**：工艺验证 + 质量对比 + 稳定性考察

#### D. 质量标准变更
- **重大变更**：放宽关键质量属性限度
- **中等变更**：增加新的检测项目
- **微小变更**：文字勘误、标准格式调整

#### E. 产品包装变更
- **重大变更**：变更内包材材质（如PE→PP）
- **中等变更**：变更内包材供应商
- **微小变更**：外包材样式变更

### 1.3 变更管理流程

```
变更发起
  │
  ├─→ 变更申请（申请人填写变更申请单）
  │      │
  │      └─→ 变更评估（跨部门团队评估风险等级）
  │             │
  │             ├─→ 微小变更 → 质量管理负责人批准 → 实施 → 关闭
  │             │
  │             ├─→ 中等变更 → 研究方案设计 → 实施研究
  │             │                 │
  │             │                 ├─→ 变更涉及产品质量？
  │             │                 │     ├─→ 否 → 告知MAH → 更新CDE平台 → 实施
  │             │                 │     └─→ 是 → 评估对MAH影响 → 提前与MAH沟通
  │             │                 │            → 告知MAH → 更新CDE平台 → 实施
  │             │
  │             └─→ 重大变更 → 研究方案设计 → 全面实施
  │                              │
  │                              └─→ 工艺验证（至少三批）
  │                                   → 稳定性研究（长期+加速）
  │                                   → 质量对比分析
  │                                   → 清洁验证（如需）
  │                                   → 结论报告
  │                                   → 提前与MAH充分沟通
  │                                   → 告知MAH → 更新CDE平台
  │                                   → 实施
  │
  └─→ 变更关闭（相关文件归档）
```

### 1.4 告知MAH的要求

**法定要求**（GMP附录§10第六十八条）：
> "辅料生产企业应当将变更情况及时告知药品上市许可持有人"

**告知方式与内容**：
- 书面形式（纸质函件或电子邮件+确认回执）
- 内容应包括：变更类型、变更内容、实施时间、对辅料质量的影响评价、必要的支持性数据
- 重大变更：应在变更实施前**提前通知**MAH
- 中等变更：应在变更实施后**及时通知**MAH
- 微小变更：可在**年度报告**中汇总通知

**证据保存**：告知函件、MAH确认回执应存档备查

### 1.5 CDE登记平台更新

**需要更新的情形**：
- 生产场地变更
- 生产工艺或主要设备重大变更
- 原材料来源（尤其是动物/植物来源）变更
- 质量标准变更
- 其他可能影响辅料安全性和有效性的变更

**更新流程**：
1. 登录CDE原辅包登记平台
2. 选择"变更申请"
3. 上传变更说明及相关支持性资料
4. 提交后等待审核
5. 审核通过后平台信息更新

## 二、偏差处理与CAPA

### 2.1 偏差管理流程

```
偏差发生
  │
  ├─→ 发现与报告
  │     → 任何人发现偏差应立即报告
  │     → 填写偏差报告
  │     → 初始分级（重大/主要/微小）
  │
  ├─→ 紧急处理
  │     → 评估对产品质量的影响
  │     → 必要时隔离相关物料/产品
  │     → 采取紧急纠正措施
  │
  ├─→ 调查
  │     → 组建调查团队
  │     → 根本原因分析（鱼骨图/5Why法等）
  │     → 受影响批次评估
  │
  ├─→ 纠正与预防措施（CAPA）
  │     → 纠正措施：消除已发生的偏差
  │     → 预防措施：防止再次发生
  │     → 措施责任人 + 完成时限
  │
  └─→ 关闭
        → 纠正措施完成并确认有效
        → 偏差报告审核批准
        → 归档
```

### 2.2 常见偏差类型

| 类型 | 举例 |
|------|------|
| 工艺偏差 | 温度超限、搅拌时间不足、pH偏离范围 |
| 检验偏差 | OOS、OOT、检验方法偏离 |
| 设备偏差 | 设备故障、校准过期 |
| 物料偏差 | 来料不合格、物料混淆 |
| 文件偏差 | 记录填写错误、SOP未及时更新 |
| 人员偏差 | 未按SOP操作、培训不足导致操作失误 |

### 2.3 CAPA有效性评估

- 是否有明确的整改措施？
- 是否设定了可量化的完成标准？
- 是否按期完成？
- 同一问题是否重复发生？
- CAPA是否能预防问题再发？

## 三、供应商管理

### 3.1 供应商管理流程

```
供应商筛选 → 资质审核 → 现场审计 → 样品检验 → 小批试验
→ 批准 → 签订质量协议 → 列入合格供应商名单
  → 定期复评
```

### 3.2 供应商审计重点

- 质量管理体系运行情况
- 生产工艺的稳定性和可控性
- 检验能力和数据完整性
- 变更管理流程（是否能及时通知变更？）
- 发运和追溯能力
- 是否有接受GMP检查的历史及结果

### 3.3 质量协议模板

质量协议必须包含：
1. 双方基本信息与职责划分
2. 辅料的技术规格和质量标准
3. 检验方法及验收标准
4. 放行责任方（通常为生产企业）
5. 变更通知条款（变更前通知的时限要求）
6. 偏差和OOS的通报机制
7. 退货和召回的责任界定
8. 审计权限
9. 保密条款
10. 协议的生效、变更和终止
11. 争议解决机制

## 四、接受GMP检查的准备

### 4.1 检查前准备清单

**文件准备**：
- [ ] 质量管理体系文件（质量手册、SOP目录）
- [ ] 厂区平面图
- [ ] 工艺流程图
- [ ] 关键人员名单与资质证明
- [ ] 验证文件（工艺验证、清洁验证、计算机化系统验证）
- [ ] 自检报告和整改记录
- [ ] 批生产记录（最近1-2批）
- [ ] 检验记录（最近批次）
- [ ] 稳定性考察方案与数据
- [ ] 供应商审计档案
- [ ] 变更控制记录
- [ ] 偏差和CAPA档案
- [ ] 培训记录
- [ ] 设备维护校准记录
- [ ] 质量协议

**现场准备**：
- [ ] 生产现场清洁有序
- [ ] 设备标识完整（设备编号、状态标识、校准标签）
- [ ] 物料标识清晰（物料名称、批号、数量、状态）
- [ ] 管道走向标识、介质标识
- [ ] 压差、温湿度记录完整
- [ ] 废弃物管理规范
- [ ] 个人防护用品配备
- [ ] 参观路线规划

**人员准备**：
- [ ] 关键岗位人员（企业负责人、生产/质量负责人）就位
- [ ] 遴选陪同检查人员（熟悉公司整体情况）
- [ ] 各部门负责人随时待命
- [ ] 文件检索人员（能快速找到检查员索要的文件）

### 4.2 检查中常见问题

- 现场无法提供关键文件或记录
- 回答与文件不一致（说一套做一套）
- 重要数据缺失（验证数据、稳定性数据）
- 质量管理体系形同虚设（有文件不执行）
- 变更不受控（无记录、无评估、未告知MAH）
- 培训走过场（无效果评估）
- 数据完整性缺陷（审计追踪未开启、权限设置混乱）

### 4.3 检查后缺陷整改

**整改要求**：
- 严重缺陷：立即停产整改 → 约谈企业负责人 → 完成整改后申请复查
- 主要缺陷：限期整改（通常30天） → 提交整改报告 → 复查
- 一般缺陷：限期整改 → 提交整改报告

**整改报告应包括**：
1. 缺陷描述
2. 根本原因分析
3. 受影响批次/范围的评估
4. 已采取的紧急措施
5. 永久性纠正措施
6. 预防措施
7. 措施完成时间及责任人
8. 整改效果验证证据
