# 药用辅料GMP附录（2025年第1号）检查指南

## 检查要点速览（13章79条）

### 第1章 总则（§1-4）

**核心要求**：
- §1：适用于药用辅料生产的质量管理全过程
- §3：诚实守信原则——禁止任何虚假、欺骗行为
- §4：基于风险管理原则，结合辅料特性确定 GMP 管控程度

**检查关注点**：
- 企业是否将附录条款与本单位实际相结合转化为内部文件
- 是否建立质量风险管理流程

### 第2章 质量管理（§5-9）

**核心要求**：
- §5：企业应建立符合辅料质量管理要求的**质量管理体系**
- §6：质量方针和质量目标——全员理解并执行
- §7：**质量风险管理**——风险评估方法的选用应符合法规要求
- §8：**自检**——定期组织自检，每年至少一次系统全面自检
- §9：**管理评审**——企业负责人定期评审质量管理体系

**检查要点**：
- [ ] 是否有书面的质量方针和质量目标？
- [ ] 是否建立了质量风险管理规程？是否使用合适的风险管理工具？
- [ ] 自检计划、自检报告是否完整？自检缺陷是否整改到位？
- [ ] 管理评审的频次和内容是否符合要求？

### 第3章 机构与人员（§10-16）

**核心要求**：
- §10：企业应建立组织机构图，明确职责
- §11-12：**企业负责人**——最终责任；确保质量管理体系有效运行
- §13：**生产管理负责人**——须具有药学或相关专业本科以上学历（或中级技术职称/执业药师资格），具有至少三年药品/辅料生产管理实践经验
- §13：**质量管理负责人**——资质要求同生产负责人；质量管理负责人与生产管理负责人不得互相兼任
- §14：人员培训——与岗位要求相适应的培训，定期评估培训效果
- §15-16：人员卫生——健康档案、洁净区着装规范

**常见缺陷**：
- 质量管理负责人与生产管理负责人为同一人兼任
- 人员培训记录不完整或培训效果未评估
- 关键人员变更未及时办理变更手续

### 第4章 厂房与设施（§17-25）

**核心要求**：
- §17：厂区环境整洁，布局合理
- §18：生产区、仓储区、质量控制区合理分区
- §19：洁净区级别要求——生产区的**洁净度级别应当与预期用途相适应**
- §19：**压差梯度**——不同洁净级别之间维持≥10Pa的压差
- §20：物料进入洁净区的净化处理
- §21：**防虫防动物**设施
- §22：**仓储条件**——温湿度控制、通风照明
- §23：特殊物料贮存——毒性/易制毒/麻醉/精神/易燃易爆/腐蚀性物料
- §24：不合格品与退货区分区存放

**检查要点**：
- [ ] 洁净区的设计是否满足辅料生产的要求？
- [ ] 是否有压差监测装置和记录？
- [ ] 特殊物料（毒性、易燃等）是否有专区存放？
- [ ] 防虫防动物设施是否有效？

### 第5章 设备（§26-35）

**核心要求**：
- §26：设备设计、选型、安装应符合生产要求，易于清洁和维修
- §27：**设备维护**——制定预防性维护计划并执行
- §28：**设备校准**——关键设备按期校准，可追溯至国家基准
- §29：**计算机化系统**——权限管理、数据备份、审计追踪；相关确认已实施
- §30：关键设备的**操作和清洁规程**
- §31：非专用设备换品种时的清洁验证
- §32-33：**工艺用水**——根据产品要求确定水质标准；循环系统定期监测
- §34：与物料直接接触的**气体**（氮气、压缩空气等）应经过净化处理
- §35：设备的标识管理

**检查要点**：
- [ ] 设备是否有唯一编号和状态标识（运行/待修/停用）？
- [ ] 校准台账是否完整？校准标识是否在有效期内？
- [ ] 计算机化系统的权限设置是否合理？是否有审计追踪功能？

### 第6章 物料与产品（§36-44）

**核心要求**：
- §36：物料接收规程——验收、核对、入库
- §37：物料**贮存条件**——按标签要求执行
- §38：物料**发放**——先进先出/近效期先出
- §39：物料**放行**——经质量管理负责人批准
- §40：**不合格物料**——隔离存放、清晰标识、按规定处理
- §41：**召回产品**——隔离存放、显著标识
- §42-43：**标签管理**——标签的接收、发放、使用、销毁
- §44：动物/植物来源辅料的特殊管理

**特殊要求**：
- **动物来源辅料**：BSE/TSE风险评估、动物检疫证明、可追溯性
- **植物来源辅料**：药材基原鉴定、农残/重金属/黄曲霉毒素控制

### 第7章 确认与验证（§45-50）

**核心要求**：
- §45：确认与验证的范围和程度应通过风险评估确定
- §46：**厂房、设施、关键设备**的确认（DQ/IQ/OQ/PQ）
- §47：**工艺验证**——首次验证/变更后验证/定期再验证
- §48：**清洁验证**——目视检查 + 化学残留 + 微生物限度
- §49：计算机化系统和检验仪器的确认
- §50：再验证周期——基于风险评估确定；持续工艺确认

**检查要点**：
- [ ] 验证总计划（VMP）是否包含所有验证活动？
- [ ] 工艺验证批次是否至少三批？
- [ ] 清洁验证的残留限度标准是否科学合理？
- [ ] 再验证周期是否有明确规定？

### 第8章 文件管理（§51-57）

**核心要求**：
- §51：文件体系——建立涵盖质量标准、工艺规程、SOP、记录的文件系统
- §52：文件的起草、审核、批准、发放、修订、废止的流程化管理
- §53：**批生产记录**——及时填写，内容真实完整，可追溯
- §54：批记录审核——质量管理负责人审核并签字
- §55：文件保存期限——产品有效期后一年（不少于三年）
- §56-57：记录的修改——更改处签名并注明日期，原信息可见

**常见缺陷**：
- 批记录填写不及时（事后补写）
- 记录修改未签名或覆盖原数据
- 批记录审核流于形式

### 第9章 生产管理（§58-63）

**核心要求**：
- §58：按批准的工艺规程生产
- §59：**清场管理**——每一阶段生产后的清场、清洁、确认、记录
- §60：**批次划分与批号编制**——具有唯一性和可追溯性
- §61：**物料称量与复核**——独立复核或自动称量系统验证
- §62：**中间体控制**——按规程进行中间体/过程控制检验
- §63：**污染与交叉污染防控**——物理隔离/时间隔离/专用设施

### 第10章 质量控制与质量保证（§64-73）

**核心要求**：
- §64：质量控制实验室管理——人员、设施、仪器
- §65：**取样规程**——取样数量、取样方法、取样记录
- §66：检验记录与**数据完整性**——ALCOA+原则
- §67：**放行管理**——检验合格 + 批记录审核通过
- §68：**OOS调查**——实验室调查→全面调查→CAPA
- §69：**留样管理**——每批留样至少全检量的两倍
- §70：**稳定性考察**——持续稳定性考察方案
- §71：**供应商评估与批准**——质量审计、质量协议
- §72：**变更控制**——变更评估 → 批准 → 实施 → 结论
- §73：**偏差处理**——偏差发现 → 记录 → 分类 → 调查 → CAPA → 关闭

### 第11章 发运与召回（§74-76）

**核心要求**：
- §74：发运记录——可追溯至购货方
- §75：**退货处理**——评估后决定放行/销毁/返工
- §76：**召回操作规程**——每年至少一次模拟召回

### 第12章 合同管理（§77-78）

**核心要求**：
- §77：与MAH签订**质量协议**——明确双方质量责任
- §78：合同评审——满足委托方需求和法规要求

**质量协议应包含内容**：
- 质量标准和检验方法
- 放行责任
- 变更通知义务
- 偏差/OOS的沟通流程
- 退货/召回的责任划分
- 审计权限
- 保密条款

### 第13章 附则（§79）

- 微生物限度与无菌检查按药典要求执行
- 如无特别说明，参照《药品生产质量管理规范》正文执行

## 检查缺陷分级

| 缺陷等级 | 定义 | 举例 |
|----------|------|------|
| **严重缺陷** | 对产品质量、患者安全有直接严重影响，或涉及诚信问题 | 数据造假、工艺验证缺失、交叉污染 |
| **主要缺陷** | 对产品质量有重要影响，系统性不合规 | 质量管理体系不健全、培训缺失、校准过期 |
| **一般缺陷** | 对产品质量影响有限，偶发/非系统性 | 个别记录不完整、标识不规范 |

## 检查结论类型

| 结论 | 含义 | 后续行动 |
|------|------|---------|
| **符合要求** | 未发现严重缺陷，主要缺陷≤3项且已整改 | 通过检查 |
| **待整改后评定** | 主要缺陷>3项或严重缺陷有整改可能的 | 限期整改—复查 |
| **不符合要求** | 严重缺陷或主要缺陷无法整改 | 不通过，可能影响A状态 |

## 监督检查频次

- **已标识"A"的生产企业**：至少每五年一次监督检查
- **高风险辅料生产企业**：可能缩短检查周期
- **有因检查**：投诉举报、不良反应事件、质量抽检不合格等触发
