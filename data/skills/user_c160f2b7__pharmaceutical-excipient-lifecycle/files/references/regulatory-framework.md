# 药用辅料监管法规框架

## 法律层级体系

### 上位法
1. **《中华人民共和国药品管理法》**（2019年修订）
   - 确立药品（含辅料）全生命周期管理原则
   - 药品上市许可持有人（MAH）制度
   - 关联审评审批制度框架

2. **《中华人民共和国药品管理法实施条例》**
   - 细化药品管理法中的实施细则

3. **《药品注册管理办法》**（2020年第27号）
   - 原辅包关联审评审批的程序性规定

4. **《药品生产监督管理办法》**（2020年第28号）
   - 药品生产许可、GMP符合性检查

### 核心规章

#### I. 药用辅料GMP附录（2025年第1号）
- **发布机关**：国家药监局
- **施行日期**：2026年1月1日
- **结构与适用范围**：共13章79条
- **章节速览**：
  - 第1章 总则（§1-4）——适用范围、诚信原则、风险管理
  - 第2章 质量管理（§5-9）——质量方针、质量目标、质量风险管理、自检
  - 第3章 机构与人员（§10-16）——关键人员资质、培训、人员卫生
  - 第4章 厂房与设施（§17-25）——洁净级别、压差控制、仓储条件
  - 第5章 设备（§26-35）——设备选型、计算机化系统、工艺用水
  - 第6章 物料与产品（§36-44）——物料接收/贮存/放行、标签管理
  - 第7章 确认与验证（§45-50）——厂房确认、工艺验证、清洁验证
  - 第8章 文件管理（§51-57）——文件体系、批记录、工艺规程
  - 第9章 生产管理（§58-63）——工艺执行、清场、批号管理
  - 第10章 质量控制与质量保证（§64-73）——实验室、OOS、变更控制
  - 第11章 发运与召回（§74-76）——发运记录、退货、召回
  - 第12章 合同管理（§77-78）——质量协议、配合MAH审核
  - 第13章 附则（§79）

#### II. 药用辅料附录检查指导原则（药监综药管〔2025〕67号）
- **发布机关**：国家药监局综合司
- **内容**：GMP检查中针对药用辅料附录的具体检查方法和判定标准
- **关键要点**：缺陷分级（严重/主要/一般）、检查结论评定标准

#### III. 药用辅料登记资料要求（试行）
- **发布机关**：国家药监局药审中心（CDE）
- **核心内容**：
  - 辅料分类体系（四大类）
  - 8大模块登记资料要求
  - 高风险辅料界定标准
- **分类体系**：
  - 第1类：境内外上市药品中未有使用历史的药用辅料
    - 1.1 未经化学修饰的天然来源提取物或发醇产物
    - 1.2 通过化学修饰或合成得到的单一实体
    - 1.3 通过化学修饰或合成得到的混合物
    - 1.4 其他
  - 第2类：境内外上市药品中已有使用历史的药用辅料
    - 2.1 在国产上市药品中已使用
    - 2.2 在进口上市药品中已使用
    - 2.3 在国产和进口上市药品中均未使用，但在其他国家或地区已上市药品中使用
    - 2.4 已有食用历史的辅料
  - 第3类：在食品或化妆品中已有使用历史的药用辅料
    - 3.1 在食品中已有使用历史
    - 3.2 在化妆品中已有使用历史
  - 第4类：其他（按风险确定资料要求）

#### IV. 关联审评审批公告（2019年第56号）
- **发布机关**：国家药监局
- **核心制度**：原辅包与药品制剂关联审评审批
- **登记号获取**：平台登记 → 自动生成登记号
- **状态标识**：
  - **A**（激活/通过审评）——与制剂关联并通过技术审评
  - **I**（未通过审评/未激活）——尚未关联审评或未通过
- **主体责任**：MAH承担药品质量主体责任，须对原辅包供应商进行审计

### 配套文件
1. **《药品检查管理办法（试行）》**——药品检查类型与程序
2. **《药品生产质量管理规范符合性检查工作程序（试行）》**——GMP符合性检查流程
3. **《中华人民共和国药典》现行版（2025年版）**——辅料质量标准
4. **ICH Q3D**——元素杂质指南（适用于注射用辅料）
5. **ICH Q7**——原料药GMP（与辅料GMP互参）
