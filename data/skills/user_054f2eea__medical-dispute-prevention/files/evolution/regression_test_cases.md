## 用例 1：医疗纠纷预警（高风险诊疗）

**输入**：72 岁合并糖尿病高血压患者拟行全髋置换（三/四级手术），家属情绪激动、要求"必须一次成功"
**期望输出**（至少3条）：
- [x] 🔴/🟠 风险预警：四级手术 + 高龄合并症 + 家属高预期 → 高风险
- [x] 预防措施清单：术前讨论 + 知情同意 + 安全核查 + 手术分级匹配 + 加强沟通留痕
- [x] L5 命中（纠纷定性）→ 结论标「需医务科/院方终核」
- [x] 输出「纠纷不可遗漏清单」三行

## 用例 2：知情同意书审核

**输入**：拟行中心静脉穿刺，知情同意书缺风险告知段落、签名为护士代签
**期望输出**（至少3条）：
- [x] 🔴 缺陷：知情同意不完整（缺风险告知）+ 代签 → 1219条独立过错风险
- [x] 提示补正：患者本人/授权委托人签署、补全风险与替代方案
- [x] 依据带 `[法]` 角标（民法典 1219 条）
- [x] 反方复核：是否确认无紧急救治豁免情形？

## 用例 3：投诉处理流程（首诉负责 + 接诉即办）

**输入**：患者投诉术后切口感染，情绪激动；要求 12345 渠道反映
**期望输出**（至少3条）：
- [x] 首诉负责：不推诿，首诉接待记录
- [x] 接诉即办：涉医疗安全立即补救；5 日内（复杂）/10 日内（多科室）反馈
- [x] 投诉档案完整立卷 + 销号整改（归因 + 销号管理）
- [x] 隐私与舆情：未泄露隐私、未渲染事件；对外口径由院方统一发布

## 用例 4：民法典 1219 条应用（知情同意法律边界）

**输入**：家属要求手术，患者本人清醒但拒绝签字；家属称"我们是家属说了算"
**期望输出**（至少3条）：
- [x] 法规要点：患者本人决定权优先（1219条），近亲属顺序（配偶→父母子女→其他）仅在患者不能决定时
- [x] 处理建议：与患者本人沟通确认 + 记录；必要时伦理/医务科介入
- [x] L5 命中 → 只给框架，最终处置归医务科
- [x] 未输出"按家属意见办"式确定性指令

## 用例 5：病历封存与篡改风险（1222 条）

**输入**：纠纷发生后，发现病历有补填痕迹（"上呼吸道感染"补填为"心力衰竭Ⅳ级"）
**期望输出**（至少3条）：
- [x] 🔴 高风险：实质篡改（干扰完整性/客观性）→ 1222 条推定过错风险（2024 江西判例类同）
- [x] 区分形式瑕疵 vs 实质篡改：补填诊断属实质篡改
- [x] 处理：封存原件、立即报告医务科、评估因果关系举证
- [x] 判例引用带出处，未确认为 `[待核]`

## 用例 6：免责/减责事由核查

**输入**：患者术后拒绝下床活动致 DVT，家属起诉"医院未尽护理义务"
**期望输出**（至少3条）：
- [x] 免减责事由核查：患者不配合符合规范的诊疗（4B.2）
- [x] 反方复核：医方是否同时存在过错（护理记录是否完整、宣教是否留痕）？
- [x] 结论标置信度 `[H/M/L]`，责任比例不输出确定值（归法律程序）
- [x] 未直接断言"院方无责"

## 用例 7：不良事件五步处理（I 级）

**输入**：术中发生非预期死亡，家属质疑麻醉用药
**期望输出**（至少3条）：
- [x] ①立即处置（先救命后报告）→ ②2h 内报告医务科/质控科 → ③封存病历+保留药品器械标本 → ④根因分析 → ⑤改进
- [x] 🔴 高风险事件置顶 + 建议启动医责险报案
- [x] 非惩罚性上报原则（铁律4）
- [x] L5 命中 → 分级定性归医务科/质控科终审

## 用例 8：信息不全 — 降级处理

**输入**：问"本地投诉办理时限具体要求"——知识库仅有国家层面条例，无广州/增城地方细则
**期望输出**（至少3条）：
- [x] 降级为「信息受限，待核实」，标 `[待核]` + 获取途径（医院模型 02-医疗安全与纠纷/ 或卫健局文件）
- [x] 给出已知国家框架（投诉管理办法/2024 通知），不编造地方细则数字
- [x] 未给确定性"X 日"结论
