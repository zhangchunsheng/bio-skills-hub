## 二、初中内容框架（以人教版为例）

- **七年级上册**：生物与生物圈 / 细胞是生命活动的基本单位 / 细胞怎样构成生物体 / 生物圈中的绿色植物（藻类→被子植物一生）
- **七年级下册**：人的由来 / 人体的营养 / 人体的呼吸 / 人体内物质的运输 / 人体内废物的排出 / 人体生命活动的调节 / 人类活动对生物圈的影响
- **八年级上册**：动物的主要类群 / 动物的运动和行为 / 动物在生物圈中的作用 / 细菌和真菌 / 病毒 / 生物多样性及其保护
- **八年级下册**：生物的生殖和发育 / 生物的遗传与变异 / 生物的进化 / 传染病和免疫 / 用药与急救 / 健康地生活

## 三、2022年版2025年修订课标 → 2024新版教材变化要点

- 新增「跨学科实践」主题（如模型制作、校园生物调查、发酵食品制作）
- 强化探究活动与必做实验（显微镜、临时装片、种子萌发、光合作用等）
- 情境化栏目增多（「科学·技术·社会」「与生物有关的职业」）
- 云南中考命题已按新课标衔接（2023年起题型改革）

## 四、初中必做实验清单（实验考查/命题依据）

1. 练习使用显微镜、制作并观察植物细胞/人体口腔上皮细胞临时装片
2. 观察人的基本组织、观察草履虫
3. 探究种子萌发的环境条件、观察种子结构
4. 绿叶在光下制造有机物（淀粉检验）、探究光合作用需要二氧化碳
5. 观察小鱼尾鳍内血液的流动、模拟膈肌运动
6. 测定食物中的能量、探究馒头在口腔中的变化
7. 观察鸡卵的结构、发酵现象（制作酸奶/米酒）
8. 校园生物调查、制作生态瓶

## 五、应用要点

- **初中备课**：以新版教材「章节导语+探究活动」为主线设计课时
- **初高中衔接**：对照高中教材，标注初中已学概念（如"细胞结构""遗传变异"），避免重复讲授或断层
- **中考备考**：结合模块10（云南中考）掌握命题侧重
