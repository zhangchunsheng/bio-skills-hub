## 二、历年文献主题演化（以实验教学主题为样本）

### 高频研究主题
1. **实验教学设计**：5E模式实验教学、探究式实验（"探究教学八式"）、"展示·研究"模式、概念建构型实验（如"植物细胞"实验建构重要概念）
2. **实验教学改革**：虚拟仿真实验、智慧实验室、微型实验、生活化实验策略、录像与演示实验比较
3. **实验评价**：表现性评价模型、实验教学品质评价、高考实验试题对教学的启示
4. **教学模式研究**：STEM理念融合、论证探究式（ADI）、深度学习项目式、高阶思维培养
5. **教学诊断**：实验教学"盲点"研究、农村实验教学现状个案、台湾初中实验教学比较

## 三、论文写作选题方向（期刊近年关注）

- 实验教学的"真实化"（真实情境、真实问题）
- 实验教学与核心素养的对接（表现性评价、高阶思维）
- 数字化/AI赋能实验教学（虚拟仿真、智慧实验室）
- 高考实验试题反向指导教学
- 跨学科实践（STEM/STEAM）

## 四、论文写作结构模板（教学研究类）

1. **引言**：问题提出（教学痛点/课标要求）+ 研究意义
2. **理论依据**：课标素养要求 + 相关模式理论
3. **实践策略**：分点论述（每点=策略名称+做法+课例佐证）
4. **案例呈现**：1~2个完整课例（含设计意图、课堂实录片段、效果）
5. **反思与建议**：成效、不足、推广建议
6. **参考文献**：5~10条，含期刊名、年份、作者、页码

## 五、引用规范自查

- 期刊文献引用格式：作者.题名[J].期刊名,年份,卷(期):页码
- 数据引用：注明来源与统计口径
- 概念表述：与教材/课标口径一致（如"细胞呼吸"不用"呼吸作用"混用场景）
