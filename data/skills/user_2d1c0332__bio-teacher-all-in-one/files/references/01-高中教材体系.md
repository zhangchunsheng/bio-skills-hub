## 二、五模块内容骨架（各版本通用逻辑）

1. **必修1《分子与细胞》**：组成细胞的分子 → 细胞结构 → 物质运输 → 能量供应（酶/ATP/光合/呼吸）→ 细胞生命历程
2. **必修2《遗传与进化》**：遗传规律 → 减数分裂与受精 → 基因与染色体 → DNA结构与复制 → 基因表达 → 变异与育种 → 进化
3. **选择性必修1《稳态与调节》**：内环境与稳态 → 神经调节 → 体液调节 → 免疫调节 → 植物生命活动调节
4. **选择性必修2《生物与环境》**：种群 → 群落 → 生态系统 → 生态环境与保护
5. **选择性必修3《生物技术与工程》**：发酵工程 → 细胞工程 → 基因工程 → 生物技术安全与伦理

## 三、2026新版（人教）主要变化信号

- 依据2025年修订版课标重新组织栏目
- 强化真实情境导入、「问题探讨」升级
- 增加跨学科实践与数字化实验栏目
- 教材新增内容：合成生物学简介、表观遗传补充、生态修复案例等（以实际教材为准）

## 四、教学应用要点

- **教学设计**：以教材「本节聚焦」+「问题探讨」为锚点设计导入与核心问题链
- **命题溯源**：高考题情境多可在教材「科学·技术·社会」「与生物学有关的职业」等栏目找到原型
- **跨版本比较**：同一概念（如"基因突变"定义）在不同版本表述有差异，命题与答疑时注意口径统一（建议以人教版为准）

## 五、教材高频命题素材库（教学/命题直接可用）

- **必修1**：酶本质探究史、光合作用探究史（普利斯特利→英格豪斯→萨克斯→鲁宾卡门→卡尔文）、细胞膜成分探究（欧文顿/丹尼利-戴维森）
- **必修2**：孟德尔豌豆杂交实验、摩尔根果蝇实验、DNA双螺旋发现史、肺炎链球菌转化实验、噬菌体侵染实验、中心法则
- **选必1**：促胰液素发现、胰岛素发现、生长素发现史（达尔文→詹森→拜尔→温特）
- **选必2**：种群密度的调查方法（样方法/标志重捕法）与适用条件
- **选必3**：发酵工程实例（果酒果醋/腐乳/泡菜）、基因工程操作四步曲
