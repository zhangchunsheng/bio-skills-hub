## 三、命题规律要点

1. **素养立意**：以真实科研情境（实验数据、文献结论）为素材，考查科学思维与探究能力
2. **图表信息**：坐标图、遗传系谱图、实验装置图、流程图为高频载体
3. **长句表达**：非选择题设问梯度递进（填名词 → 析原因 → 述机制 → 提建议），"原因依据类"为失分重灾区
4. **教材溯源**：多数情境可在教材"科学史/拓展应用/问题探讨"找到原型
5. **创新趋势**：2026卷新增跨学科情境（AI、合成生物学等前沿）

## 四、非选择题"原因依据类"答题模板（长句表达核心）

**通用句式**：由于……（生理机制/条件变化）→ 导致……（直接结果）→ 从而使……（最终表现）。

- **原因类**：先写直接原因，再写根本原因；由近及远
- **依据类**：先摆事实（数据/现象），再作结论（符合……原理）
- **判断+理由**：先给判断（是/否/能/不能），再分点给理由
- **对策类**：从"原理→措施→预期效果"三层展开

**高频失分点**：①只写现象不写机制；②因果链条断裂；③缺乏"因→果"关键词衔接；④未答出限定条件

## 五、备考应用指引

- **二轮复习**：按21个专题做"原卷→解析"对照训练
- **答题规范**：用"原因依据类微专题"训练长句表达的因果链书写
- **命题参考**：真题"完全解读"是命制校内模拟题的素材库与难度标尺
- **难度对标**：选择题考查水平1~2（基础/理解），非选择题考查水平3~4（应用/综合）
