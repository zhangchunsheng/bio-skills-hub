# 报告质量标准

本文件定义输出 HTML 报告的结构、计算精度与可视化规范。基于 assets/report-template.html 填充。本标准为「骑行健康评估」通用化版本：去掉踏频/码表/功率专属表述，保留并泛化体成分、强度倒挂、恢复、损伤、周期、饮食等维度。

## HTML 必须包含的章节

1. **核心指标速览卡** — 每指标带判定色标（绿=正常 / 蓝=优秀 / 橙=警示 / 红=风险）
2. **体成分深度评估** — BMI 定位可视化条 + 判定表（BMI/体脂/腰围/腰臀比）
3. **运动数据深度解读** — 心率区间分布横向堆叠条、运动模式/动作质量评估、MHR 校准前后对比表、配速/距离
4. **综合诊断** — "为什么练得多却体脂高"的四因素循环（强度倒挂/运动模式不当/缺力量/饮食敏感）
5. **修正后周训练计划** — 含运动模式优化目标、Z2 比例、力量训练日（用 7 格日历来呈现）
6. **损伤防护升级** — 结合运动发现的应力点（如跑步跨步过大→膝、久坐→腰）
7. **HRV 说明** — 仅当设备支持时给出具体查看路径；否则明确"设备不支持"并给出替代恢复监测方案（晨脉趋势 / 运动后 HRR / 睡眠 / 主观疲劳）
8. **睡眠监测实测**（如有数据）— 睡眠心率（最低/范围）、夜间 SpO₂、入睡时间偏差提示；解读恢复余量与是否可承受加量（如最低睡眠心率 &lt;50 = 有氧底子好；SpO₂ ≥95% 排除睡眠呼吸风险）
9. **总结与行动项** — 按优先级排序的 3 个（如：优化运动模式/加 Z2 运动/加力量）
10. **参考文献** — WHO、极化训练 80/20（Seiler）、ACSM、中国 WS/T 428、睡眠心率恢复参考
11. **饮食结构与训练补给分析**（有饮食数据时）— 三大营养素速览表（蛋白/碳水/脂肪 vs 目标 + 判定色标）、碳水缺口核心提醒、一日餐次点评（早/午/晚 优点+待优化）、训练日补给方案（练前/练中/练后 目标量+食物+依据）、三条日常调整；标准见 references/analysis-framework.md 第十一节
12. **维生素矿物质补充评估**（有补充剂评估需求时）— 按 IOC/GSSI/中国 DRIs 2023 给优先级判断表（VD 最该补、铁先验血、钙食补优先、镁/B族/复合维/蛋白粉不盲补）+ 验血精准路线（25(OH)D/血清铁蛋白/Hb/必要时骨密度）；标准见 references/analysis-framework.md 第十二节
13. **🩸 月经周期与训练周期化（女性专属·可选）** — 仅性别=女且提供月经数据时显示。含：①周期基本信息（规律否/周期天数/最近月经第一天/经期天数/PMS 与痛经）；②以"最近月经第一天=Day 1"推算的**周期阶段时间线表**（标注今日 Day N 与所处阶段）；③四阶段训练适配表（月经期/Z1–2、早卵泡期/逐步加量、⭐晚卵泡期黄金窗口 VO₂max+力量加重、排卵期/Tempo、黄体期/Z2 长距离）；④**25 天短周期等特殊长度的窗口压缩提醒**；⑤铁补充联动（接第 12 节）；⑥周期化排课建议（黄金窗口排高强度、PMS 降量）。标准见 references/analysis-framework.md 第十三节

## 计算精度

- BMI 保留 1 位小数
- 腰臀比保留 2 位
- 心率区间取整 bpm
- 脂肪量/瘦体重保留 1 位 kg
- 所有标准切点用中国成人标准

## 可视化要求

- 心率区间用横向堆叠条：Z1-Z5 按占比宽度，颜色梯度（蓝→绿→黄→橙→红）
- BMI 用定位条：标出用户位置 vs 标准切点（18.5/23.9/27.9/≥28）
- 校准前后用对比卡（旧值 → 新值，箭头）
- 7 格日历呈现周计划（日/一/二/三/四/五/六）
- 月经周期阶段时间线用色块日历：5 阶段（经期/早卵泡/晚卵泡黄金/排卵/黄体）分别配色，标注今日位置；25 天短周期须标注"黄金窗口仅约 3 天"

## 语气与边界

- 建设性、不评判；用"你不是懒，是…需要调整"框架
- 明确标注"非医疗诊断，如有不适请就医"
- 基于单次运动数据须注明"基于单次样本推断"
- 用在用户档案要求：报告文件内避免 emoji
