# 通用健康评估分析框架

本文件提供计算标准与诊断逻辑，供 Skill 在分析用户数据时参考。所有标准优先采用中国成人标准；体脂率分级采用 ACSM 区间。本框架为「骑行健康评估」的通用化版本，去掉了踏频、码表、FTP 等骑行专项，保留并泛化体成分、强度倒挂、恢复、损伤、周期、饮食等通用逻辑。

## 一、体成分评估标准

### BMI（中国成人标准 WS/T 428）
- <18.5 偏瘦
- 18.5–23.9 正常
- 24.0–27.9 超重
- ≥28.0 肥胖

### 体脂率（女性 / 男性）
- 女性：20–30% 健康区间；>35% 肥胖
- 男性：10–20% 健康区间；>25% 偏高
- 换算：脂肪量 = 体重×体脂率；瘦体重 = 体重−脂肪量
- 目标推演：若瘦体重不变，体脂率从 X% 降到 Y% 的目标体重 = 瘦体重 / (1−Y%)

### 腰围与腰臀比
- 腰围：女性 ≥80cm、男性 ≥85cm 为中心性（腹型）肥胖
- 腰臀比：女性 ≥0.85、男性 ≥0.90 为中心性肥胖
- 腰臀比正常但腰围超标 = 脂肪偏下半身（梨形），代谢风险低于苹果形，但仍需优先降腰围

## 二、心率区间计算（按运动类型选择基准）

> **前提声明（强制）**：心率区间与强度倒挂诊断**仅 B 路（有心率设备、提供心率区间分布）执行**。无心率设备（A 路）不进行本节计算，不估算静息心率，改以 RPE 谈话测试 / 功率区间 / 运动模式与体成分输出建议，并在报告中注明「无心率数据，未评估强度倒挂」。

**先判定运动类型，再选百分比基准**（五区强度含义一致：Z1 恢复 / Z2 有氧基础 / Z3 Tempo / Z4 阈值 / Z5 无氧；仅 B 路计算）：

- **骑行 / 跑步 → 储备心率法 %HRR（Karvonen）**：需静息心率 RHR（B 路已收集）。靶心率 = (MHR − RHR) × 区间% + RHR。
  - 依据：Garmin 等手表默认 %HRR；%MHR 对有氧区常偏差 5–10 bpm，fit 运动员低静息心率时偏差更大。
  - Z1 50–60% / Z2 60–70% / Z3 70–80% / Z4 80–90% / Z5 90–100%（均为 HRR）
- **游泳 → 最大心率法 %MHR，但用「泳池特定最大心率」**：泳池最大心率 = 陆上最大心率 − 10~13 bpm（水温 / 横卧体位 / 静脉回流使水中最大心率更低，不能直接套陆上最大），再按 Z1 50–60% … Z5 90–100% MHR 划分。心率在游泳中为**辅助**，配速 / 划频 / 划水质量为主。
- **其他（快走 / 健身 / 球类 / 瑜伽 / 未指定运动类型）→ 最大心率法 %MHR**：Z1 50–60% / Z2 60–70% / Z3 70–80% / Z4 80–90% / Z5 90–100% MHR。

MHR = 设备实测最大值（优先）或 220−年龄。若设备实测最大心率显著低于公式值（差 >10bpm），以实测值 +4-5bpm 安全余量重算区间，并注明"按实测校准"。RHR 优先用设备静息值，否则用晨脉。

## 三、心率区间分布诊断（核心洞察）

健康耐力训练强度分布（极化模型 80/20，Seiler 等）：
- Z2 应占 ~80%
- Z4 应 ≤5%（仅间歇日）
- Z1/Z3/Z5 补充

**"强度倒挂"判定（关键反直觉发现）：**
- Z4 占比 >30% 且 Z2 <20% → 几乎无恢复性低强度运动
- 推论：慢性应激 → 皮质醇升高 → 腹部脂肪囤积 → "练得多却体脂高"
- 高温（>30℃）会额外抬高心率 5-10bpm（心血管漂移），回看区间时需考虑；但不改变整体结论

## 四、运动模式与动作质量分析（通用维度·替代骑行踏频）

骑行踏频在通用人群中没有统一对应指标，此处改为"运动模式与动作质量"维度，按运动类型给出判定与建议：

- **跑步者**：步频 150–190 spm（多数业余 150–165 偏低，目标 170–180）；跨步过大（脚落点在身体前方过远）→ 膝/髋制动冲击大；跑姿代偿（左右摆臂不对称、躯干侧倾）→ 提示核心/髋稳定不足。
- **力量训练者**：动作模式（深蹲/硬拉/推举）是否存在代偿（圆背、膝内扣、腰椎超伸）；负荷渐进是否过快；与旧伤部位是否冲突。
- **球类/高强度间歇者**：急停急转对膝/踝韧带负荷大，旧伤史者须重点防护。
- **久坐/低活动人群**：日常 NEAT 不足（职业久坐），基础消耗低，减脂需靠结构化运动 + 打断久坐。
- **通用风险线**：任何运动若长期单一模式 + 存在疼痛代偿 → 关节慢性劳损风险高，须提示"动作优化 + 交叉训练"而非只加量。

与旧伤关联：运动模式不当使旧伤部位应力集中，须提示"动作纠正 + 负荷管理 + 针对性力量"。

## 五、静息心率解读

- 正常人 60–80 bpm
- <60（尤其 <55）提示有氧基础好（运动员级）
- 晨脉 > 基线 5-10bpm 且持续 2-3 天 → 疲劳累积信号，需减量

## 六、损伤防护（通用运动）

通用原则（均非医疗诊断）：
- 上肢/肩腕（如球类摔倒、支撑）：核心收紧分担、护具意识、力量平衡训练
- 膝/踝（跑步、急停）：纠正跨步/落地点、强化臀中肌/小腿、合适鞋具
- 腰（负重、久坐）：核心稳定、避免腰椎超伸动作、打断久坐
- 旧伤部位力量训练从低重量渐进，避免直接受压/剪切动作
- 长途/大强度后旧伤部位酸痛 → 缩短单次时长、增加休息日

## 七、恢复监测

- 晨脉趋势比单次值更有意义
- HRV：并非所有手表都支持直读（如华为 GT3 Pro 经客服确认不提供独立 HRV 数值，仅以"压力"指数间接反映）。若设备支持，HRV 越高恢复越好，连续下降 3 天以上需减量；若不支持，改用静息/晨脉趋势、运动后心率恢复(HRR)、睡眠与主观疲劳监测。
- 睡眠 7h+ 有助减脂（睡眠不足升皮质醇、促腹部脂肪）

## 八、极化训练与减脂

- 80% Z2 + 20% 高强度（含每周 1 次 4×4min Z4 间歇）
- 减脂期蛋白 1.6–2.2 g/kg 瘦体重
- 增肌（力量训练）提高基础代谢，是"不控制饮食也不易反弹"的结构性解法
- "慢就是快"：刻意安排 Z2 疗愈性低强度运动（能聊天不喘）才是真正燃脂窗口

## 八(续)、体脂秤"蛋白质 %"指标的重要辨析（易误导！）

- 体脂秤显示的"蛋白质 %"是**生物电阻抗(BIA)估算的身体蛋白质占比**（瘦体组织中约 20% 为蛋白质），反映的是**身体成分**，不是用户"当天吃了多少蛋白"。
- 该值受体重、水分、测量时间、饱食状态影响极大（家用秤误差可达 ±5%），**单日波动无意义，应按周趋势看**。
- **常见误判**：看到"蛋白质偏低"就警告用户"吃不够蛋白"——这是错的。正确做法是：
  1. 先问用户饮食记录（如一日蛋白摄入估算），确认是否真的摄入不足；
  2. 若用户实际摄入已达标（如 ~1.6g/kg 瘦体重），则"蛋白质 %"偏低只说明**身体肌肉量仍不足**，根因是缺力量训练而非吃得少；
  3. 关注**骨骼肌量 / 去脂体重**的周趋势，而非秤上"蛋白质 %"单日值。
- 参考：ProteinJug 科普文、百度健康 BIA 原理说明。

## 九、有氧能力评估（可选·有功率/FTP 数据时启用）

当用户提供功率计、跑步功率或骑行台（MyWhoosh/Zwift）数据时启用；否则跳过本节，改由心率区间与替代测试估算。

### FTP 与功率六区间（Coggan 经典模型，基于 FTP%）
- Z1 恢复：<55% FTP
- Z2 有氧基础：55–75% FTP（燃脂/耐力底盘，目标占 80% 时间）
- Z3 Tempo：75–90% FTP
- Z4 阈值：90–105% FTP（乳酸阈值，每周 ≤1 次间歇）
- Z5 无氧/VO₂max：105–120% FTP
- Z6 无氧容量：>120% FTP

### 相对功率 W/kg 分级（仅提供功率时）
- W/kg = FTP ÷ 体重(kg)
- 休闲 <1.5 / 爱好者 2.0–2.5 / 竞技 ≥3.0
- 首测 FTP 即定位当前水平，作为训练进步追踪基线

### TSS（训练压力分）解读
- TSS = 单次训练相对阈值强度的压力积分
- 参考：Z2 匀速运动 22 分钟 ≈ TSS 8-12；若 TSS 29（同 22 分钟）→ 实际强度在 Z4，密度极高
- 连续多日高 TSS → 需安排恢复日

### 功率 vs 心率
- 功率是"绝对输出"，不受温度/情绪/咖啡因/睡眠不足影响；心率是"生理响应"，会受上述因素干扰
- 有功率设备时以功率为主、心率为辅；无功率时以心率为主

### 无功率设备时的有氧能力替代估算
- **3 分钟台阶试验**：运动后心率越低、恢复越快 → 有氧能力越好；可粗略分级（优/良/中/差）。
- **心率恢复 HRR**：运动停止 1 分钟内心率下降 <12 bpm 提示心肺适应不足。
- **运动手表有氧负荷**：如 Garmin VO2max 估计、华为"有氧训练压力"——可作趋势参考，置信度中等，报告中标注"非功率实测"。

## 十、多源数据冲突识别（关键纠偏逻辑）

同一运动可能被多个设备记录，呈现方式不同，**必须先识别"记录范围"再下结论**：

### 数据源特性
- **运动手表/码表（Garmin/华为/Apple Watch）**：按"开始/结束"记录全程，含自然热身冷身
- **运动 App（华为运动健康/Keep 等）**：室内模式记录从开始到结束的**全 session**，包括刻意的热身和冷身放松段
- **跑步机/智能设备/骑行台平台**：只统计"实际运动段"，不计入前后热身冷身

### 典型冲突与处理（实测验证）
- **冲突现象**：华为显示 40 分钟 / 平均 HR 125；跑步机/骑行台显示 22.5 分钟 / 平均 HR 146
- **真相**：差值 ~18 分钟 = 华为多记的热身+冷身；运动段的 146 才是"真正在动"的强度
- **处理步骤**：
  1. 比对时长差 → 识别热身冷身段
  2. 比对平均心率 → 运动段 HR 应≈设备 HR（若用户也有户外/设备数据）
  3. 报告中明确标注每个数据源的"记录范围"，避免把"全session低温平均值"误读为"这次很轻松"
- **勿犯的错误**：仅凭 App 125 就下"室内比户外健康"的结论——那只是数据切片差异，实际运动强度一致

## 十一、饮食结构与训练补给分析

当用户提供饮食记录（App 截图或文字）时启用，输出「饮食结构与训练补给分析」章节。

### 三大营养素目标（基于体重 kg 与运动量）
- **蛋白质**：1.6–2.0 g/kg/日（减脂/增肌期；ACSM 力量训练人群 1.6–2.2）。判定：达 1.6 g/kg 即"达标"，>2.0 为"略高"无需再补蛋白粉（除非图训练后方便）。
- **碳水化合物**：
  - 训练日（中高强度 1–3h）：6–10 g/kg（ACSM/AND/DC 联合立场 Thomas 2016）；减脂期温和目标可降至 4–5 g/kg。
  - 非训练日 / 控热量减脂：130–200 g（绝对下限 RDA 130g 供大脑与中枢神经）。
  - 判定：<130g = 严重不足的"糖原亏空"信号（红色风险）；远低于训练日下限 = 红色风险。
- **脂肪**：占总热量 20–35%；关注"质量"（油炸 vs 蒸烤）而非仅克数。

### 常见结构性缺口（运动人群高频）
- "蛋白吃够了，但碳水严重不足 + 脂肪偏油炸"——因控脂/控热量低估碳水，且高强度运动下糖原需求被忽略。
- 危害：糖原亏空训练 → 间歇掉速、恢复慢、被迫分解肌肉供能（抵消增肌提 BMR 努力）。

### 训练日补给窗口（用于生成补给方案表）
- **练前 1–4h**：1–4 g/kg 碳水 + 低脂蛋白低脂（如燕麦+香蕉+面包）。
- **练中（>60min）**：30–60 g/h 碳水（香蕉 / 能量胶 / 运动饮料）。
- **练后 30–60min**：1.0–1.2 g/kg 碳水 + 0.25–0.3 g/kg 蛋白（4:1 碳蛋比），如厚酸奶+香蕉+燕麦 / 巧克力奶；错过后糖原储存可降 ~50%。

### 一日餐次点评逻辑
- 评估每餐"优质蛋白来源 + 优质碳水来源 + 微量营养素"覆盖；油炸/精制碳水标为待优化；"优质蛋白+优质碳水+蔬菜"组合标为模范餐（建议每周保持 3–4 次）。

### 三条日常调整（通用建议）
1. 碳水"移"到训练窗口：非训练日 130–200g，训练日 330–450g（按 4–5 g/kg），重点放练前+练后餐而非晚餐猛吃。
2. 油炸换蒸烤：同蛋白同碳水，脂肪少一半、热量差 200–300 kcal/餐，直接服务减脂。
3. 保留模范晚餐：优质蛋白+优质碳水+蔬菜组合，作为体成分改善基石。

### 第十二节 维生素矿物质补充评估（按"风险画像"给优先级判断）
- **基本原则（IOC 共识）**：先做营养评估（饮食记录 + 血液标志物）再决定是否补；禁止盲目补充；补剂仅用于纠正缺乏，非增效。运动员/运动人群最常需补：铁、钙、维生素 D。
- **维生素 D（高危人群最该补）**：肥胖者 VD 溶入脂肪被"稀释"、室内训练日照不足、骨折史（关系钙吸收与骨密度）三重高危；女运动人群 VD 不足率 33–42%；建议 VD3 2000–4000 IU/日（不足时）或 IOC 维持 800–2000 IU/日；先测 25(OH)D 定剂量。
- **铁（先验血）**：月经失血 + 耐力运动足部撞击溶血/汗铁流失 + 红肉摄入不稳定；女运动人群缺铁 15–35%（约男性 3 倍）；女性 RDI 18mg/日；须查血清铁蛋白（<30 μg/L 提示储备耗竭）+ 血红蛋白；高剂量铁有毒，须医生督导；钙铁不同服。
- **钙（食补优先）**：女性 <50 岁 RNI 1000mg/日，IOC 建议运动人群 1500mg/日；骨折史为骨密度关注最强理由；优先奶制品/豆腐/深绿菜，不足再补 1000–1500mg/日（分次 <500mg）。
- **镁/电解质/B族（食补）**：减脂期食物体积小 + 运动出汗易缺；优先坚果/深绿菜/全谷/盐，不常规补剂。
- **复合维生素（非必须）**：营养良好成人无获益且或超 UL（IOC/Cochrane）；减脂期可作"保险"非增效。
- **蛋白粉（不需要）**：蛋白已达标者不补。
- **精准路线**：抽血查 25(OH)D、血清铁蛋白、血红蛋白，骨折史背景下必要时加骨密度（DXA），再定精确剂量。

## 十三、女性月经周期与运动训练周期化（通用分析框架）

**启用条件**：仅当性别=女时启用；男性用户跳过本节。需先收集（见 SKILL Step 1）：月经是否规律、周期天数（正常 21–35 天、平均 28）、最近一次月经第一天日期、经期天数、是否有经前综合征(PMS)/痛经、是否用 App 记录（如华为健康 / FitrWoman / Wild.AI）。

### 四阶段生理特征与训练适配（基于 28 天标准周期；短/长周期按比例调整）

| 阶段 | 大致天数 | 主导激素 | 主观感受 | 训练建议 |
|------|---------|----------|----------|----------|
| 月经期 | Day 1–5 | 雌激素↓、孕酮↓ | 可能疲倦、腹部不适 | Z1–2 恢复、轻量力量；**补铁**；避有氧能力/VO₂max 测试 |
| 早卵泡期 | Day 6–10 | 雌激素缓升仍低 | 主观疲劳感强（71% 精英运动员自述最差阶段之一） | 逐步加量，不急于上高强度；Z2–Z3 稳态 |
| **⭐晚卵泡期** | **Day 11–14** | **雌激素高峰、孕酮低** | 精力充沛、力量好、恢复快 | **黄金窗口：VO₂max 间歇、力量加重 5–10%、有氧能力测试最佳时机** |
| 排卵期 | Day 14–16 | 雌激素急降、孕酮↑ | 韧带松弛（ACL 损伤风险 ↑4–8 倍） | Tempo 稳定输出（75–85% 阈值）；避突发加速 |
| 黄体期 | Day 17–28 | 孕酮高峰、体温 ↑0.3–0.5°C | 易疲劳、保水、碳水代谢效率降 | 长距离 Z2 耐力；避有氧能力测试；多补水 200–300ml/h + 多补碳水 10–15g/h |

**黄金窗口的生理依据**：雌激素促进蛋白质合成、提升疼痛阈值、加速恢复；此时做高强度/力量训练收益最大。

### 周期长度差异处理（关键，文献多基于 28 天）
- 黄体期（排卵→下次月经）固定约 14 天，因此 **排卵日 ≈ 下次月经预计日 − 14 天**。
- 推算"今日所处阶段"：以最近一次月经第一天为 Day 1，按周期天数算今日 = Day N，再对照各阶段天数判断。
- **短周期（如 25 天）**：卵泡期压缩至约 9 天，黄金窗口仅 Day 10–12（约 3 天），必须精准抓住；每月"好日子"比 28 天周期少约 3 天。
- **长周期（如 35 天）**：卵泡期延长至约 21 天，黄金窗口 Day 17–20，高强度训练机会更分散。

**精确推算：用比例而非固定天数（避免短/长周期错位）**
阶段边界必须按用户实际周期天数缩放，不可照搬 28 天表的 Day 编号：
- 黄体期固定 ≈14 天（占比 = 14 ÷ 周期天数）；
- 月经期 = 用户实际经期天数；
- 卵泡期（经期结束 → 排卵）= 周期天数 − 14 − 经期天数，起止按实际日历推算；
- 黄金窗口（晚卵泡期）落在"排卵前约 3–4 天"，即约 Day(周期天数−14−3) 至 Day(周期天数−14)。
- 例：21 天短周期、经期 5 天 → 黄体期 14 天、卵泡期仅 2 天（Day 6–7），黄金窗口压缩至约 Day 8–9；若仍按固定 Day 11–14 套用将完全错位，阶段判断失效。
- 实操：先用上述公式算出该用户的阶段边界，再标注"今日所处阶段"，而非直接引用 28 天表的 Day 编号。

### 经后"能力一般/累"的科学解释（用户常自述模式）
- 早卵泡期雌激素低 → 血清素低 → 主观疲劳感强（多项研究一致：Solli 2020 / Armour 2020 / Findlay 2020）。
- 经期铁流失 30–80ml → 氧运输能力暂时下降，对耐力影响明显。
- **重要澄清**：PMC 综述（2021，纳入 35 项客观研究）多数未发现周期对客观功率/VO₂max 的显著差异，但**运动员主观感受高度一致**——"感觉累"是真实生理体验，分析时不应否定用户体感。

### 铁补充联动（接第十二节）
女性因月经失血 + 耐力运动足部撞击溶血/汗铁流失，缺铁率 15–35%（约男性 3 倍）。月经周期分析须联动铁评估——经期后/早卵泡期尤其关注铁储备，建议验血清铁蛋白（<30 μg/L 提示耗竭）+ 血红蛋白。

### 周期化排课实操
- 黄金窗口（晚卵泡期）排 VO₂max 间歇 / 有氧能力测试 / 力量加重；黄体晚期（PMS）主动降量，安排瑜伽/普拉提/恢复性活动；月经期避高强度，以恢复为主。
- 建议用户连续记录 3 个周期确认个人模式后再做年度周期表。
