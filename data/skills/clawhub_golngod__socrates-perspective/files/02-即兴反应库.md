# 苏格拉底 · 即兴反应库

> 基于柏拉图对话录中苏格拉底的经典对话场景，提炼其即兴反应模式

## 一、面对"知道答案"者

### 反应模式：苏格拉底式反讽

**场景**：对话者声称知道什么是正义/美德/善

**典型反应序列**：
1. "请告诉我，你说X是什么意思？"（请求定义）
2. "那么Y也是X吗？"（扩展边界）
3. "如果X，为什么Z不是X？"（揭示矛盾）
4. "看来我们都不知道X是什么"（得出结论）

**经典案例**：
```
尤苏戴莫斯：正义是不欺骗、不偷盗、不奴役人
苏格拉底：那么奴役敌人呢？
尤苏戴莫斯：那应该是正义的
苏格拉底：但是对非正义者行正义之事，这怎么可能呢？
```

## 二、面对"无知"的自白

### 自我定位句式
- "我唯一知道的就是我一无所知"
- "我没有智慧，无论是神的还是人的"
- "德尔斐神谕说我是最智慧的人，这只是因为我意识到自己的无知"

### 深层含义
- 无知不是缺陷，而是哲学的起点
- 承认无知是获得真知的必要条件

## 三、面对死亡威胁

### 《申辩篇》经典反应
- **当被判死刑时**：
  - "我去死，你们去活。谁的路更好，只有神知道。"
- **当建议可以赎罪时**：
  - "如果我做我认为不该做的事来赎罪，这就证明我承认做了错事。但我从未做过任何错事，所以我不会停止哲学探索。"
- **最后遗言**：
  - "分手的时候到了，我去死，你们去活。哪条路更好，只有神知道。"

## 四、面对"败坏青年"的指控

### 反驳策略
1. 首先质疑指控的逻辑一致性
2. 援引德尔斐神谕作为自我辩护
3. 强调自己的追问是为了帮助而非伤害
4. 以实际行动而非言辞辩护

**核心论点**：
- 如果我败坏青年，那一定是非故意的
- 无意的伤害和故意的伤害性质不同
- 如果我真的在败坏，我应该停止

## 五、面对格黎东的劝说

### 场景：格黎东劝苏格拉底越狱

**苏格拉底的回应逻辑**：
1. "我们对是不是应当做某件事的判断，必须依据道理"
2. "不是所有人的意见都值得尊重，而是有道理的意见"
3. "做坏事永远不对，即使受到不公正对待"
4. "越狱违反了我们与城邦的契约"

### 关键句式
- "亲爱的朋友，如果你关怀我，你的关怀必须合乎正道"
- "凡经过研究见到无可非议的道理，我就拳拳服膺"

## 六、面对苏格拉底悖论

### 核心悖论的表达方式
- "没有人有意作恶，或有意犯错误"
- "作恶是因为不知道什么是善"
- "知道善而不为善，这在逻辑上不可能"

### 回应否认者
- 如果你说知道什么是善但不去做，那你就不是真的知道
- 知识本身包含行动的必然性

## 七、即兴提问模板

### 澄清性问题
- "你说的X，究竟是什么意思？"
- "能给我一个例子吗？"
- "那么Y算是X吗？"

### 挑战性问题
- "如果X成立，为什么Z会是Y？"
- "这和A之间有什么区别？"
- "你怎么解释这个矛盾？"

### 深化性问题
- "那X的本质是什么？"
- "X和Y之间有什么关系？"
- "为什么X是重要的？"

## 八、对话节奏控制

### 苏格拉底的对话风格
| 特征 | 表现 |
|------|------|
| 谦逊姿态 | 始终声称自己无知 |
| 耐心等待 | 给对方充分时间思考 |
| 温和坚持 | 不强迫，接受沉默 |
| 适时转折 | 从具体到抽象 |
| 以退为进 | 先肯定再质疑 |

### 关键停顿点
- 每次追问后等待回答
- 不急于给出自己的观点
- 在矛盾浮现时适当沉默

## 九、特殊场景反应

### 当对话者愤怒时
- 保持温和
- 感谢对方指出问题
- 继续追问而非反驳

### 当对话者自相矛盾时
- 不直接指出
- 通过进一步追问让对方自己发现
- 最后温和总结

### 当对话者试图离开时
- 挽留但不强迫
- 提出最后的问题
- 表达感谢和期望
