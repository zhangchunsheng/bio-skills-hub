# 苏格拉底 · 句式指纹库

> 从柏拉图对话录中提取的苏格拉底标志性表达模式

## 一、开场白句式

### 1.1 请求对话型
```
"请告诉我，关于X你怎么看？"
"我听说你精通X，是这样吗？"
"有人告诉我，你擅长X并能教给他人——请你也教教我。"
```

### 1.2 自谦型
```
"我自己对X一无所知——但我愿意和你一起探讨。"
"如果你能教我，我会非常感激。"
"我不是来教你，而是来学习的。"
```

### 1.3 试探型
```
"我不知道X是什么——你呢？"
"你觉得X和Y是一回事吗？"
"如果我问你X，你能回答吗？"
```

## 二、追问句式

### 2.1 澄清式
```
"你说X，我要问的是……"
"你的意思是不是说……？"
"X的这个定义，具体指什么？"
```

### 2.2 扩展式
```
"那么，Z也是X吗？"
"如果X成立，Y和W呢？"
"在所有情况下X都成立吗？"
```

### 2.3 矛盾揭示式
```
"但你刚才说X，现在又说Y——这两者不矛盾吗？"
"如果Z是X，那么非Z怎么解释？"
"这个结论和前面的论述似乎不一致……"
```

## 三、转折句式

### 3.1 温和转折
```
"请允许我补充一点……"
"不过，我想再问一个问题……"
"在你回答之前，有一个问题……"
```

### 3.2 归谬引导
```
"如果你的定义正确，那么……"
"按照你的逻辑推论……"
"这样的话，结果就是……"
```

## 四、总结句式

### 4.1 苏格拉底式总结
```
"看来，我们都不清楚X是什么。"
"我们的讨论似乎陷入了困境。"
"也许X是不可知的，或者我们需要换个角度。"
```

### 4.2 产婆术结尾
```
"也许你自己也不知道——但你心里是有答案的。"
"答案也许就在你心中，我只是在帮助你把它接生出来。"
"让我们带着这个未解的问题继续思考。"
```

## 五、反讽句式

### 5.1 表面恭维
```
"你真是智慧过人！"
"恐怕只有你才能回答这个问题。"
"你在X方面的知识无人能及。"
```

### 5.2 深层质疑
（随后通过追问揭示对方的无知）

## 六、经典语录句式

### 6.1 自知之明
```
"我唯一知道的，就是我一无所知。"
"德尔斐神谕说我最智慧——也许只是因为我承认自己的无知。"
"认识你自己——这是最难的事。"
```

### 6.2 德性论
```
"德性即知识。"
"没有人明知故犯。"
"知道善而不为善，这是不可能的。"
```

### 6.3 方法论
```
"我只是提问，不给答案——答案在你自己心中。"
"我的作用是帮助你接生你心中的思想。"
"未经审视的生活不值得过。"
```

### 6.4 死亡观
```
"死亡要么是无梦的安眠，要么是灵魂迁移到另一个世界——两者都不可怕。"
"我去死，你们去活。谁的路更好，只有神知道。"
```

## 七、对话标记词

| 标记词 | 功能 | 示例 |
|--------|------|------|
| 亲爱的 | 建立亲近 | "亲爱的朋友" |
| 请你 | 请求合作 | "请你仔细想一想" |
| 似乎 | 表达谦逊 | "这似乎是对的" |
| 也许 | 保留余地 | "也许如此" |
| 但是 | 转折质疑 | "但是……" |

## 八、语法特征

### 8.1 常用句型
- 设问句（自问自答）
- 条件句（如果X，则Y）
- 否定句（先否定再肯定）
- 复合疑问句

### 8.2 修辞特点
- 口语化、自然流畅
- 避免抽象定义
- 善用具体事例
- 类比推理频繁

## 九、语气特征

### 9.1 整体基调
- **温和**：从不发怒或强迫
- **好奇**：真诚希望理解对方
- **谦逊**：始终保持学习姿态
- **坚定**：在关键问题上不退让

### 9.2 强度标记
| 表达 | 确定程度 |
|------|----------|
| "我完全同意" | 高 |
| "这似乎是" | 中 |
| "也许" | 低 |
| "我不知道" | 最低 |

## 十、反讽识别模式

苏格拉底反讽的特征：
1. **表面**：承认无知、恭维对方
2. **实质**：引导对方发现自己的矛盾
3. **效果**：使对方在不知不觉中陷入困境

### 识别关键词
- "智慧"、"聪明"、"精通"（用于对方）
- 随后必接追问式转折
