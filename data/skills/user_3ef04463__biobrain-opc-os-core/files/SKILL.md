# OPC OS Core — 一人公司的AI操作系统

## 一句话看懂

**把一家公司变成7个AI部门的自动运转系统——数据部采集情报、品牌部写内容、财务部算账、监察部盯质量……你只看日报，做决策。**

不是帮你干活的AI工具。是让公司替代你干活。

---

## 为什么要用这个？

市面上所有"一人公司"工具都是在帮你一个人干所有人的活——你写内容、你做推广、你回客服。效率提高了，但你还在干。

OPC OS Core彻底不同。它把工作分给7个自带"大脑"的AI部门，每个部门自主运转。品牌部每天自己采集热点、自己写文章、自己发布。数据部自己学最新的东西。监察部自己查有没有出问题。

你做什么？定方向、做决策。就像CEO而不是打杂的。

这不是理论。这是一个跑了12+定时任务、7个部门、从零到运营只用了不到2周的生产系统。打过仗的，不是PPT里的。

---

## 这套系统能做什么？

### 7个部门各自负责的事

| 部门 | 干什么 | 怎么干 |
|------|--------|--------|
| **数据中心** | 公司大脑——采集情报、管理其他AI、发现新资源 | 全天自动 |
| **品牌部** | 写内容、发到小红书/微信/头条/即刻 | 定时发布 |
| **销售部** | 管客户、推销售 | 自动跟进 |
| **财务部** | 计数用了多少AI费用、赚了多少、省了多少 | 每天报告 |
| **法务部** | 检查合规风险、审合同，有一票否决权 | 定时+按需 |
| **监察部** | 抽查所有部门的质量，发现问题报警 | 每周巡检 |
| **行政部** | 早间同步、文件管理、云备份、提醒下班 | 定时执行 |

### 一天的自动运转

**早上 7:30-8:30**：7个部门开始"学习"——各自搜索自己领域的最新信息，写300字笔记。全部用免费AI模型，不花钱。

**晚上 22:00-22:15**：7个部门提交一天的工作日报。错开2分钟避免拥堵。

**每周五 22:00**：监察部全面巡检，检查有没有定时任务连续失败、有没有部门悄悄罢工。

## 3分钟快速上手

### 第1步：理解架构（不是操作，是认知）

这套系统的核心就三层：

**通讯层**：AI之间怎么说话。4条路并行（直接喊话+写文件+在线文档+状态标记），断一条不影响。就像你家上网有宽带+手机热点，宽带了还能用。

**治理层**：规则怎么写。三层：祖训（永远不改的基本原则）→ 宪法（可以改但不能违背祖训）→ 铁律（每个部门的具体规矩）。就像宪法→法律→规章。

**信息分级**：什么数据用什么AI处理。🔴绝密（API密钥、密码）只用本地、不上云；🟠机密（财务、策略）用最好的AI；🟡内部（日报、笔记）用免费AI；🟢公开（发布内容）随便用。省钱的秘密在这里。

### 第2步：建立7个部门（Day 1-2）

创建7个AI助手配置（一个部门一个），建好文件夹结构。

### 第3步：部署自动化（Day 3-5）

设好定时任务：早上学习、晚上汇报、每周巡检。全部用免费AI模型。

### 第4步：变现（Day 6+）

打通变现漏斗：免费平台（小红书/头条/即刻）→ 社群互动（QQ频道）→ 付费服务。永远不在免费平台放付费链接。

## 变现漏斗（怎么赚钱）

```
免费平台（获客）→ QQ频道（养客）→ 知识星球（赚钱）
小红书/即刻/头条 → 社区互动        → 付费订阅 ¥9.9-299/月
```

铁律：靠内容免费获取信任，把愿意付费的人引流到付费平台。免费和付费的内容严格分开。

## 成本控制（怎么省钱）

| 用途 | 用什么AI | 为什么 |
|------|---------|--------|
| 对外发布内容 | 付费模型（DeepSeek Pro等） | 质量不能省 |
| 内部日报/学习 | 免费模型（智谱GLM-4-Flash等） | 这些任务免费模型完全够用 |
| 巡检/审计 | 免费模型 | 轻量任务 |

别给写日报的任务用付费模型。这就是为什么有人一个月烧几千块AI费用——给什么事都用最好的模型。聪明人对内走免费，对外走付费。

## 灾难恢复：万一某平台突然不能用了怎么办？

免费平台随时可能改规则。不是"会不会"的问题，是"什么时候"的问题。

### 1小时切换原则

每个关键依赖都有备份方案：

| 依赖 | 切到哪 | 最多几分钟 |
|------|--------|-----------|
| 主力AI模型 | 备用模型链（DeepSeek→GLM→ERNIE） | ≤10分钟 |
| 文档（腾讯文档） | 金山文档或本地文件 | ≤15分钟 |
| 通讯（飞书） | 企业微信或内部通道 | ≤30分钟 |
| 代码仓库（GitHub） | Gitee（码云） | ≤15分钟 |
| QQ频道 | 备用内容渠道 | ≤10分钟 |
| 知识星球（收钱！） | 备用付费渠道 | ≤30分钟 |

收钱管道永远优先恢复。每月做一次演练，真切的过去。

## 常见问题 FAQ

**Q：我需要会编程吗？**
A：不需要。整个过程在AI里用自然语言操作。你告诉AI"创建一个品牌部"它会帮你。

**Q：最少需要几个部门？**
A：3个可以起步：数据部+品牌部+监察部。7个是完整配置，不是最低要求。

**Q：需要什么平台？**
A：核心依赖OpenClaw的Agent运行时（支持定时任务和多AI之间的直接通讯）。文档和通讯的外部平台（飞书、腾讯文档）可以用免费版。

**Q：这套系统要花钱吗？**
A：AI费用方面：内部任务全部用免费模型（不花钱），只有对外发布内容用付费模型（几毛到几块钱一次）。一个月的AI开销可以控制在几十块钱以内。

**Q：适合什么样的人？**
A：想做"一人公司"但不想一个人干所有事的人。自媒体创作者、独立开发者、咨询师、小团队负责人。

**Q：和agent-org-manager有什么不同？**
A：agent-org-manager是搭建方法（怎么建部门）。OPC OS Core是完整的操作系统（建好了之后怎么运转、怎么变现、怎么灾备）。前者是手册，后者是引擎。

**Q：出毛病了怎么修？**
A：配合cron-health-monitor（定时任务健康监控skill），自动发现故障、自动修复。你很少需要亲手调试。

**Q：最大风险是什么？**
A：不是AI出错——是过于依赖单一平台。小红书可能改规则、飞书可能政策变。所以这套系统内置了多通道通讯和灾难恢复方案。

## 公司什么不该做（做了会垮掉）

1. **CEO自己干部门的事**：如果你在调试定时任务，你已经输了。交给数据部。
2. **只靠一条通讯路**：它坏的时候（一定会坏），公司就瞎了。至少三条并行。
3. **没有检查环节**：不检查的定时任务会慢慢腐坏。每周巡检，不能商量。
4. **免费和付费内容混在一起**：两边都污染。严格分开。
5. **部门职责模糊**：重叠产生混乱。每个部门只在自己的文件夹里做事。
6. **跳过写规则**：不给AI写清楚规则，它就会乱跑。规则必须写出来，不能只靠"你心里知道"。

## 运行时稳定性保障（QP 韧性体系）

本技能为 Prompt 型技能，稳定性通过以下机制保障：

### 输出一致性校验
- 同一输入多次运行时，核心结论应一致（允许表达方式差异）
- 若输出出现显著矛盾，优先回溯最后一次修改的源头
- 引用型数据以原始来源为准，不因模型采样差异改变结论

### 异常输入降级链
```
正常输入 → 完整流程
    ↓ 关键信息缺失
    追问补充（1轮）→ 仍不足？→ 标注「信息不足」+ 给出最小可行输出
    ↓ 超出能力边界
    硬边界拦截 → 明确告知「不在能力范围」+ 建议替代方案
    ↓ 模型采样不稳定
    核心结论不变 → 仅标注「表达可能存在微调」
```

### 重试与恢复指引
| 场景 | 处理 |
|------|------|
| 输出明显偏离工作流程 | 用户可追加「请严格按工作流程重新执行」触发重试 |
| 数据引用不一致 | 以首次引用来源为准，后续引用追加「已核实与首次一致」 |
| 中间步骤遗漏 | 用户可指定步骤号要求补执行 |
| 外部依赖不可用 | 标注「外部依赖暂不可用」+ 使用缓存/已知数据替代，不静默跳过 |

### 用户干预入口
- 任何步骤输出不满足预期时，直接指出问题即可触发修正
- 不需要重新描述全部需求，模型保留上下文并增量修正
- 连续 2 轮修正失败 → 建议缩小范围或拆分子任务
