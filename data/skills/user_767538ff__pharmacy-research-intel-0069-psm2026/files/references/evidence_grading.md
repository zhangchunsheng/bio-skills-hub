# 循证评级与偏倚评估框架

本文件提供"有理有据"所需的证据分级、PICO 框架与偏倚评估工具。在做"循证文献总结"与"综述/立项素材"时必须应用。

## 1. PICO 框架（检索与总结的骨架）

对每一个临床/干预性问题，先拆解为：
- **P** (Population)：人群/疾病/样本
- **I** (Intervention)：干预/暴露/药物
- **C** (Comparison)：对照
- **O** (Outcome)：结局指标
- （可选 **T** Study design / **S** Setting）

检索式与证据表均按 PICO 组织，避免遗漏关键维度。

## 2. 证据等级（Oxford CEBM 五级，常用）

| 等级 | 证据类型 |
|------|----------|
| 1a | 同质性 RCT 的系统评价/Meta 分析 |
| 1b | 单个 RCT（窄可信区间） |
| 2a | 同质性队列研究的系统评价 |
| 2b | 单个队列研究 / 低质量 RCT |
| 3a | 病例对照研究的系统评价 |
| 3b | 单个病例对照研究 |
| 4 | 病例系列 / 低质量队列/病例对照 |
| 5 | 专家意见（无明确评价标准） |

- 系统评价/Meta 分析（尤其 Cochrane）列为最高级证据；专家意见最低。
- 对每一篇纳入文献，在证据表中标注其 CEBM 等级。

## 3. GRADE 方法（用于证据体整体质量）

对某一结局的证据体，从 HIGH → MODERATE → LOW → VERY LOW 评级，考虑：
- 偏倚风险（risk of bias）
- 不一致性（inconsistency）
- 间接性（indirectness）
- 不精确性（imprecision）
- 发表偏倚（publication bias）

升级因素：效应量大、剂量-效应梯度、混杂反证。
在做"循证文献总结"的结论时，用 GRADE 表述证据体可信度。

## 4. 偏倚风险评估工具（按研究设计选用）

- **RCT** → Cochrane ROB 2（随机序列生成、分配隐藏、盲法、结局数据完整性、选择性报告）。
- **非随机干预研究** → ROBINS-I。
- **诊断准确性** → QUADAS-2。
- **观察性（队列/病例对照）** → NOS（Newcastle-Ottawa Scale）。
- **系统评价** → AMSTAR 2（条目 16 条，评方法学质量）。

在证据表中设"偏倚风险"列，给出简评（如"低风险/中风险/高风险"或具体工具得分）。

## 5. PRISMA 流程（系统评价/综述必备）

- 四阶段：Identification → Screening → Eligibility → Included。
- 记录各阶段文献数、剔除原因（去重、不符题、不符标准）。
- 在产出"综述/立项素材"时，如做系统性检索，给出 PRISMA 式漏斗（可用文字或图表描述），保证可复现。

## 6. 输出时的严谨表述规范

- 区分"已确立结论"与"初步/争议性结论"。
- 对预印本与低质量证据，明确加注"证据等级低 / 待验证"。
- 不夸大相关性为因果；队列/病例对照只能说"关联"。
- 数值（OR/RR/HR、CI）原样引用并注明来源，不四舍五入失真。
