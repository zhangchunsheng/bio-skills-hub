# 四类产出模板

本 skill 支持四种产出形态。每种均须"有理有据"：每条结论可回溯文献，预印本单独标注。

## 模式 A：前沿动态速递（Frontier Digest）

用途：定期/按需推送最新高相关文献 + 一句话价值点。
结构：
```
# 药学科研前沿速递 · {日期区间}
> 检索源：PubMed / CNKI / bioRxiv | 主题：{主题}

## 1. {标题}（{期刊}, {年}）[证据类型]
- 一句话价值：{对您研究的启示}
- 关键发现：{1-2 句，含核心数值与 CI}
- 来源：PMID {x} / DOI {x} ｜ {预印本·未评议 标注}
## 2. ...

## 速递小结
- 本周期{X}篇，热点集中在：{2-3 个方向}
- 值得跟进的开放问题：{...}
```
注意：预印本明确标 `[预印本·未评议]`；控制条数（10-20 篇），突出"对您科研的增量价值"。

## 模式 B：循证文献总结（Evidence Table）

用途：对一组文献做结构化证据表（PICO + 证据等级 + 偏倚风险）。
结构：
```
# 循证文献总结 · {主题}
> 检索策略：{检索式} ｜ 源：{源} ｜ 日期：{区间}

## 证据总表
| # | 研究(作者,年,期刊) | 设计(CEBM) | P | I | C | O(主要结果,含CI) | 偏倚风险 | 来源 |
|---|---|---|---|---|---|---|---|---|
| 1 | ... | 1b RCT | ... | ... | ... | ... | 低 | PMID |

## GRADE 证据体评价
- 结局1：{MODERATE/LOW...}，理由：{偏倚/不一致/不精确...}

## 结论
- 已确立：...
- 争议/待验证：...
- 对您课题的衔接点：...
```

## 模式 C：综述/立项素材（Review / Grant Draft）

用途：辅助起草综述框架或基金本子文献基础。
结构：
```
# {主题} 文献框架（草稿）
> 检索式与方法（PRISMA 四阶段计数）：初检{X} → 去重{Y} → 筛{Z} → 纳入{N}

## 一、背景与未满足需求
## 二、研究脉络（按时间/主题分小节，每节列关键文献+您的解读）
## 三、争议与空白（明确标注，作为立项切入点）
## 四、本团队可衔接的基础（提示您已有方向，不要编造数据）
## 五、参考文献（规范著录：作者. 题名. 刊. 年;卷(期):页. DOI）
```
注意：此为"素材/框架"，不代写整篇；明确提示用户补充其团队真实数据与成果。

## 模式 D：研究热点与趋势图（Trend / Hotspot）

用途：按主题生成文献计量/趋势/研究热点可视化。
做法：
- 用 `scripts/pubmed_search.py` 取时间序列与 MeSH/关键词分布。
- 用 Visualizer（`show_widget` / `read_me`）渲染：
  - 年度发文量折线/柱状图（趋势）。
  - 高频 MeSH/关键词词云或条形图（热点）。
  - 国家/机构合作网络（如数据可得）。
- 文字配合：指出上升期方向、饱和方向、新兴交叉点。

## 通用规范

- 所有产出顶部写明：检索源、检索式、日期区间、证据/质量工具。
- 数值原样引用，不臆造影响因子/被引数（注明"以官方最新为准"）。
- 中文结论为主，关键术语中英对照。
