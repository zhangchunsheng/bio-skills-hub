# 选材规律与选文库（蒸馏版）

选材规律、历年选文清单、候选经典篇目库与文本组合策略，供命制模拟题时直接选用。

## 一、选材规律（五年实证）

### 1. 选文来源演变
- **2020及以前**：以"二十四史"纪传体为主（《明史·左光斗传》《明史·海瑞传》等）
- **2021**：突破史传，首用纪事本末体《通鉴纪事本末》（贞观君臣论治、祖逖北伐）
- **2022**：《战国策》（国别体）、《东观汉记》（纪传体）
- **2023**：诸子散文（《韩非子》）＋问对体（《孔丛子》《唐太宗李卫公问对》）＋兵书（《百战奇略》）
- **2024**：编年体（《资治通鉴》）＋史论（《读通鉴论》《论衡》）＋纪传体（《史记》）
- **2025**：经传（《左传》）＋杂史传记（《列女传》《韩诗外传》）＋考据（《考信录》）＋正史（《晋书》）＋笔记（《东坡志林》）

### 2. 选材五原则
1. **经典性**：优秀传统文化典范文本，思想价值与语言风格同教材相当，但**必须出自课外典籍**（教材篇目只作勾连参照，不可直接入选）。
2. **价值性**：承载家国情怀、崇德重礼、忠孝节义、尊贤敬长、勤政爱民等正向价值。
3. **思辨性**：存在可比较、可质疑、可论证的思想空间（史实与史论、事实与寓言、观点与反证）。
4. **语言典范性**：文辞雅正规范，生僻字可控（可加注），匹配高中毕业生阅读水平。
5. **篇幅可控**：600-800字，可删节不改意。

### 3. 高频考点对应选材
- 断句：对话密集、分句多、有人物变换的段落
- 实词：含古今异义、词类活用、通假字的文段
- 句式：含判断句、被动句、宾语前置、状语后置的句子
- 简答思辨："史实＋评论"组合文本，评论部分有明确观点可被史实支持/质疑

## 二、候选经典篇目库（命制模拟题可选）

> **使用提示**：带书名号者为教材同名篇目（如《烛之武退秦师》《廉颇蔺相如列传》《屈原列传》《鸿门宴》），仅借其"周边文段"作思路参考，**须避开课文原文及所选语段**；实际入选一律取课外文本，或取他书异文（如秦末史事可改选《资治通鉴·秦纪》而非《史记·陈涉世家》）。

### A. 史传 / 编年 / 纪事本末
- 《左传》：《烛之武退秦师》《崤之战》《晋公子重耳之亡》《郑伯克段于鄢》周边文段
- 《国语》《战国策》：《邹忌讽齐王纳谏》《唐雎不辱使命》《赵威后问齐使》
- 《史记》：《廉颇蔺相如列传》《屈原列传》《魏公子列传》（信陵君）《田单列传》《管晏列传》《滑稽列传》
- 《汉书》《后汉书》《晋书》等正史传记：循吏、直臣、孝廉题材
- 《资治通鉴》：《汉纪》《唐纪》中的帝王将相片段
- 《通鉴纪事本末》：贞观君臣论治、祖逖北伐、淝水之战、安史之乱等

### B. 诸子散文 / 论说
- 《论语》《孟子》《荀子》《庄子》《韩非子》《吕氏春秋》中名段
- 《孔丛子》《说苑》《新序》（刘向）：对话问对体，含说理
- 《淮南子》《论衡》（王充）：批判性议论

### C. 史论 / 考据 / 笔记（2024-2025新增长点）
- 王夫之《读通鉴论》《宋论》：史论评鉴，观点鲜明
- 顾炎武《日知录》：考据札记，实证辨伪
- 崔述《考信录》：史料辨伪，考据批判
- 赵翼《廿二史札记》：史事考证
- 苏轼《东坡志林》《仇池笔记》：文人笔记，史事议论

### D. 传统美德题材（价值导向用）
- 孝：《孝经》、曾子言行、二十四孝类记载
- 廉：《清官》类传、杨震"四知"等
- 忠节：《苏武传》、文天祥、岳飞相关史料
- 教子/家风：《颜氏家训》、司马光《家范》

## 三、文本组合策略（2023年起多文本命题）

### 组合模型

| 模型 | 组合方式 | 代表年份 | 考查落点 |
|---|---|---|---|
| 史实＋史论 | 史书事件＋后世史评家议论 | 2024Ⅰ卷《资治通鉴》＋《读通鉴论》 | 证据筛选、多元评判 |
| 事例＋评论 | 两个同类事例＋思想家总评 | 2024Ⅱ卷《史记》×2＋《论衡》 | 比较归纳、共同原则 |
| 观点＋反证 | 一家观点＋另一家驳论 | 2023Ⅰ卷《韩非子》＋《孔丛子》 | 批驳逻辑、事实核查 |
| 用典＋考辨 | 典故本原＋考据辨伪 | 2025Ⅰ卷《左传》＋《列女传》《韩诗外传》＋《考信录》 | 史料辨伪、批判阅读 |
| 史传＋评论 | 正史人物＋后世文人评论 | 2025Ⅱ卷《晋书》＋《东坡志林》 | 观点评价、伦理思辨 |

### 组合设计要点
1. 文本间关系必须明确：印证、对立、补充、递进之一。
2. 第14题的设问空间来自文本关系，而非单文本内容。
3. 选文主题统一于一个价值命题（如"赏罚""忠孝""修德""忧国"）。
4. 跨时代组合（先秦典籍＋后世评论）最能体现"文化传承与思辨"。
5. **由易到难排序**：先史实叙事（语言浅显、信息直观、无抽象观点），再浅近议论，后深邃史论（观点抽象、哲理思辨）；命制后复核，若后则材料难度不高于前则应调整选段或顺序。

## 四、选材避坑清单

- **严禁直接选用统编教材（初高中）篇目原文作阅读材料**，如《过秦论》《陈涉世家》《烛之武退秦师》《鸿门宴》《师说》《屈原列传》《六国论》《阿房宫赋》等；同一史事与教材重叠时，改选《资治通鉴》《通鉴纪事本末》《汉书》等他书异文，或另择史事。教材篇目仅用于第11题课内勾连与翻译比较。
- 避开敏感历史人物与政治议题（人物评价只限学术与道德层面）。
- 避开过于冷僻的文本（需保证命题者与考生可查证）。
- 避开生僻字过多、需大量注释的段落（注释一般控制在1-3条）。
- 避免选文价值导向模糊或存在明显争议的题材。
- 文本长度不足时以"节选＋删节"处理，须保持文意完整。
