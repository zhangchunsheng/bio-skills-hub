# 命题思想与课标依据（蒸馏版）

本文件为高考文言文命题顶层设计精要：课程标准、核心素养、高考评价体系、官方评析与权威专家论述。

## 一、课程标准依据（《普通高中语文课程标准（2017年版2020年修订）》）

- **学习任务群**：对应任务群8"中华传统文化经典研习"。核心要求：精读代表作品体会传统美德与家国情怀；梳理常见实词、虚词、特殊句式和文化常识；培养对优秀传统文化的"客观、科学、礼敬"态度；结合具体作品分析评价思想内容与艺术特色。
- **学业质量水平4为高考命题直接依据**：水平3-3"能凭借语感把握文言语料，结合语境区分词语多义性"；水平3-4"能比较分析不同文本中的文化现象"；水平4-4"能借助多种材料进行专题探究，理性评论传统经典思想观念"。
- **情境化命题**：文本组合形成比较、互证、对话情境（复合文本）；设问依托思辨任务；语言材料源于真实典籍，语境即情境。

## 二、语文学科核心素养（命题观测维度）

| 素养 | 在文言文命题中的体现 |
|---|---|
| 语言建构与运用 | 断句、实词虚词、翻译——语言理解与运用（基础层） |
| 思维发展与提升 | 第14题简答：证据筛选、比较归纳、批判性思维（进阶层） |
| 审美鉴赏与创造 | 欣赏史传/论说文辞之美（隐性渗透） |
| 文化传承与理解 | 选文价值导向：家国情怀、崇德重礼、尊贤敬长（贯穿层） |

**关键结论**：以"文化传承与理解"为价值底色，以"语言建构与运用"为测评底座，以"思维发展与提升"为区分度所在。

## 三、高考评价体系："一核四层四翼"

（教育部考试中心张开《基于高考评价体系的语文科考试内容改革实施路径》，《中国考试》2019年第12期）

- **一核**：立德树人（服务选才、引导教学）
- **四层**：核心价值、学科素养、关键能力、必备知识
- **四翼**：基础性、综合性、应用性、创新性

古代诗文阅读关键能力：掌握实词、虚词、活用、特殊句式，能断句、翻译；在接受性、理解性阅读基础上实现"创造性、批判性阅读"。

## 四、教育部教育考试院历年评析要点

- **2023年**：首次系统呈现"复合文本"命题（Ⅰ卷《韩非子·难一》+《孔丛子·答问》聚焦"赏罚"；Ⅱ卷《百战奇略》+《唐太宗李卫公问对》构成"史实—评论"对话）；断句题改客观选择为"8选3"主观填涂（0-3分四级），"反技巧、考真读"。
- **2024年**（《中国考试》2024年第7期）：Ⅰ卷《资治通鉴·汉纪》+王夫之《读通鉴论》（李陵事件），第14题"用史实支持王夫之观点"，考查多元评判与批判性思维；Ⅱ卷《史记·魏世家》《史记·留侯世家》《论衡·非韩》三则组合，引导"崇德重礼、尊贤敬长"；强调"看待问题角度不同形成不同判断"，不简单论定历史人物功过。
- **2025年**（光明日报等）：从中华优秀传统文化中寻找"文化密码"，突出"以文化人"与家国情怀；基础考查与思维赋能并重；Ⅰ卷四则文本（《左传》《列女传》《韩诗外传》《考信录》）构成"典籍互证"，考史料辨伪与批判性阅读。

## 五、权威专家论述

- **温儒敏**：古诗文"无用之大用"；高考是选拔性考试，材料多不选自教材，需拉开区分度。
- **顾之川**：近年高考命题主动贴近教材，体现"教、学、考"有机衔接。
- **方正、王钰瑶**（《语文建设》2024年第11期）：新高考文言文命题三大取向——关联教材促"重语用"、营造情境促文化融通、综合考查促思维多元。
- **教研共识**：多文本比较阅读、教考衔接、真实情境与典型任务、辩证思维考查为四大命题关键词。

## 六、价值导向总纲

立德树人为根本，中华优秀传统文化传承、文化自信、家国情怀为底色。2024年选文崇德重礼，2025年以"家国同构""史料辨伪"统整。命题设计链：选文正能量 → 设问导向思辨 → 答案指向价值认同。
