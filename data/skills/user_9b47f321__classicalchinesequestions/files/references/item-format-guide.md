# 题型规范与命题操作指南（蒸馏版）

五道题型的命题规范、设错规律、评分标准与答题要领。**建议命题操作顺序：先定选文，再拟第13/14题（最重），后拟第10/11/12题。**

## 选文与注释格式规范（通用）

- **出处标注**：每则材料末尾括注出处，如"（节选自《史记·秦始皇本纪》）"；多则材料逐则标注，标注"节选自"后不再重复"（三则材料均删节）"字样。
- **注释规范**：只标注影响理解文意且超出学生必备积累的实词虚词（生僻字、易误解的古今异义），控制在1-3条，**跨材料统一编号**（①②③连续排列于所有材料末尾）。**严禁标注**：①第10-13题考点词（第11题加点词、第13题采分点词，加注即泄题）；②必背篇目与课内常见词。可由上下文或材料间互文推知的词不必注。
- **原文标注规范**（试卷完整性要求）：①第11题4个加点词在原文用黑点（•）或加粗标出；②第10题断句选段用波浪线标出并标注起止位置；③第13题2个翻译句用直线下划线标出。不加标注则学生无法定位。
- **材料篇幅**：全文总字数600-800字，**每则材料不少于100字**（过短则单薄，难以支撑第12题四选项覆盖不同段落）。
- **删节处理**：同一则材料内部删节用省略号"……"标示；不同材料间的删节无需标注。
- **断句选段来源**：取自单则材料的连续文段，不跨材料拼接。
- **翻译句分布**：第13题两句翻译分别取自不同材料。
- **加点词与断句选段不重叠**：第11题加点词原则上不出现在第10题断句选段中（防泄题）。
- **第14题分值分配**：5分按"2+3"或"2+2+1"分配（前问印证/筛选2分，后问比较/深化/认识3分），先定分值再拟要点。

## 第10题：断句（3分）

**命题规范**
- 形式（2023年起）：选取3-5个分句、约25-40字句段，分拆为8个待选位置（标A-H），"有三处需要断句"，涂黑3个标号。
- 评分：每涂对一处1分，涂黑超过三处不给分（整题归零）。
- 选段要求：语法结构存在真实断点歧义；断点一般分布于句末语气词后、主谓宾结构分界处、独立分句边界。
- **末标号（H）后必须保留文字，严禁紧贴选段句末**；正确断点恰好三处，逐一检验其余标号处"断开不通"或"断开即改变语义"。

**命制技巧**
1. 选段含至少一个"迷惑点"（句中连词、介词结构、同位语），使非三处位置具备干扰性。
2. 断点设计依据：①句末语气词（也、矣、乎、焉、哉）；②对话标志（曰、云）；③主语变换处；④固定结构（如"若……何"）；⑤排比对仗。
3. 答案唯一性检验：确保且仅有三处断点语法上必断。

**答题要领**：先找语气词、对话词定位句末；再按"主语+谓语"完整句切分，警惕宾语前置、状语后置；人名、地名、官职名是天然边界。

## 第11题：词语及相关内容解说（3分）

**命题规范**
- 形式：文中4个加点词语（实词、虚词，可含句式、词类活用），各配一句课内例句比较，"不正确的一项"。
- 考点（2022年起）：跳出纯文学常识，转向文言词语的课内外勾连比较——实词多义辨析、通假、活用、句式结构、音义关系。
- 设错规律：错误项常设于"多义实词的语境误判"（如"若"理解为"如果"实为"好像"）、"音义关系误判"、"结构类比错误"。

**命制技巧**
1. 每项格式统一：文言词语解释＋课内例句（必修/选择性必修）＋比较结论。
2. 干扰项设计：取该词常见义但在选文语境中不成立；或取罕见义而课内例句语义不同。
3. 课内例句来源：统编教材名篇——《烛之武退秦师》《师说》《六国论》《屈原列传》《苏武传》《项脊轩志》《孔雀东南飞》《离骚》《短歌行》等。
4. **选项等长**：四选项字数相当、句式统一（统一"（句中文）中『词』意为……＋课内例句……＋二者相同/不同"四段式），选项长短不得成为作答线索。

**答题要领**：代入语境检验词义，"一词多义、词随境转"；注意通假、活用对词义的影响；比较课内例句看结构而非字面。

## 第12题：内容概述（3分）

**命题规范**
- 形式：对文本内容作4个概括，"不正确的一项"。
- 设错规律：①曲解文意（偷换概念、添枝加叶）；②强加因果（把类比当因果，2025年Ⅰ卷错误项即此型）；③错位概括（张冠李戴、时序错乱）；④以偏概全。
- 正确项必须是"概述"而非"摘抄"，体现理解性转化。

**命制技巧**
1. 四选项覆盖文本不同段落/人物/事件。
2. 错误项在"因果、范围、程度、时序"四维度选一处做手脚。
3. 错误点不能靠常识判断，必须依托文本细节。

**答题要领**：逐项回文定位比对，警惕"看似合理实则错位"；关注关联词暗示的因果、转折、条件关系是否与原文一致。

## 第13题：翻译（8分）

**命题规范**
- 形式：两句（一句史实叙述、一句议论/人物语言），各4分。
- 采分点（每句3-4个）：重点实词1-2个（含古今异义、词类活用）、虚词1个、特殊句式1个（判断句、被动句、宾语前置、状语后置、省略句、固定句式）。
- 评分：大意对（1-2分）＋采分点（每点1分），错一处扣一点，扣完为止；允许同义表达。

**命制技巧**
1. 选择含"障碍词"的句子——现代汉语已不常用或易误解的词（如"悖""偶""倩""被"）。
2. 确保句中含有明确句式特征（如"者……也""……乎""何以……"）。
3. 两句难度梯次：第一句偏实词，第二句偏句式与虚词。
4. 先答关键词语（1分/个），再给句意分。

**答题要领（翻译六字诀：留删补换调贯）**
- **留**：人名、地名、官职、年号、朝代名保留不译。
- **删**：发语词、音节助词、偏义复词中的衬字删除。
- **补**：省略的主语、谓语、宾语、介词补出。
- **换**：古词换成今词（单音→双音）。
- **调**：宾语前置、状语后置、定语后置按现代汉语语序调整。
- **贯**：固定句式（若……何、奈……何、无乃……乎、不亦……乎）意译贯通。

## 第14题：简答（5分，2024年起）

**命题规范**
- 形式：依托复合文本设思辨任务，常见四型：
  1. **证据筛选型**："材料一有哪些事实可以支持材料二的观点？"（2024Ⅰ卷）
  2. **比较归纳型**："两件事有何相似之处？归纳共同原则。"（2024Ⅱ卷）
  3. **观点评价型**："作者如何评价某人物/事件？谈谈你的认识。"（2025Ⅱ卷）
  4. **批判思辨型**："概括观点并谈认识／说明作者如何论证。"（2025Ⅰ卷）
- 评分：按要点给分，通常2-3个要点；观点与"认识"分层次计分；语言组织与条理占1分左右。

**命制技巧**
1. 设问必须依赖**文本间关系**（互证/对立/补充），杜绝单一文本可答的简单概括。
2. 答案要点"可穷尽、可验证"——要点数量与文本信息一一对应。
3. 评价型第二问"谈谈你的认识"需开放性与价值导向并存（思辨但不越界）。
4. 先写参考答案要点，再反向检验设问无歧义。

**答题要领**：先审清"问什么"（观点/证据/相似/评价），再分层作答（观点＋证据＋认识）；答案"据文作答"，引原文关键词作支撑；认识类开放题立足文本价值导向（传统文化、家国情怀、理性思辨），避免偏激。

## 命题质量控制清单

- [ ] 选文总字数600-800字，生僻字有注释，与高中毕业生水平匹配
- [ ] 价值导向正能量，无敏感话题
- [ ] 第11题课内例句全部来自统编教材
- [ ] 第13题采分点明确（3-4个/句），无歧义翻译
- [ ] 第14题答案要点可穷尽、依据充分
- [ ] 断句答案唯一，干扰点有效
- [ ] 难度梯度：第10-12题基础，第13-14题进阶
- [ ] 第10题末断点标号不贴句末，其后留有文字
- [ ] 第11题四选项字数相当、句式统一
- [ ] 多则材料按由易到难排序（史实叙事→浅近议论→深邃史论）
- [ ] 每则材料末尾括注出处"（节选自《XXX》）"
- [ ] 注释仅限影响理解的非必背实词虚词，1-3条；考点词、课内必背词不加注
- [ ] 原文中标注加点词（•/加粗）、断句波浪线、翻译横线
- [ ] 每则材料不少于100字，篇幅均衡
- [ ] 断句选段取自单则材料连续文段
- [ ] 翻译两句分别取自不同材料
- [ ] 加点词不出现在断句选段中
- [ ] 注释跨材料统一编号（①②③）
- [ ] 第14题分值分配明确（2+3或2+2+1）
