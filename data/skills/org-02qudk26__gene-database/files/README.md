# NCBI 基因数据查询

- 唯一标识：`hub-gene-database`
- 显示名称：NCBI 基因数据查询
- 能力摘要：借助 NCBI Gene 的 E-utilities 与 Datasets API 按符号、ID、物种、GO、表型和位置查询基因、RefSeq、功能、通路与批量注释信息。

## 案例素材

1. 研究人员要校验一个基因面板的标准标识。该 skill 会按物种批量查询符号和 Gene ID，标出别名歧义与缺失项，再生成可追溯注释表。
2. 功能组学项目需要提取候选基因的 RefSeq 与 GO 信息。该 skill 会选择适当 API、限制请求速率并记录查询版本，供下游富集分析使用。
3. 课题组研究某表型相关基因。该 skill 会用受控词与物种条件检索，区分数据库关联和实验因果证据，避免过度解读自动返回结果。
