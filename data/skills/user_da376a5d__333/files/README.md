# 医学文献智能分析 Skill

基于大语言模型的医学文献深度分析工具，支持单篇文献的全流程分析，从核心内容提取到交互式知识图谱生成，一次完成。

---

## 简介

医学论文专业性强、信息密度高，完整阅读一篇文献通常需要 1-2 小时。本 Skill 将阅读、提取、检索、推演、可视化五个环节整合为一个自动化流程，帮助医学研究者、临床医生和医药研发人员快速掌握文献核心价值。

**核心设计理念**：模型负责理解和分析，脚本负责结构化输出。文本理解、实体识别、关系提取、报告撰写全部由模型完成；知识图谱的数据构建和 HTML 可视化由专用脚本完成，确保图谱格式稳定可复现。

---

## 功能特性

### 1. 核心文献深度分析
自动提取论文的完整结构化信息：
- 基本信息：标题、作者、期刊、DOI、PMID
- 研究设计类型 + 牛津 EBM 证据等级（1a-5）
- 研究目的（1-2 句精炼概括）
- 主要发现（3-5 个，必须含具体数据）
- 关键统计数据：P 值、95% CI、HR / OR / RR、效应量、样本量
- 创新点、研究局限性、临床意义

### 2. 补充文献智能检索
围绕核心论文的关键药物 / 疾病 / 机制，自动检索 PubMed 5-10 篇相关文献：
- 每篇文献附带可点击跳转链接（PMID 优先，其次 DOI）
- 自动标注与核心论文的关系：一致 / 补充 / 冲突 / 拓展
- 补充文献独立呈现，不与核心论文内容混淆

### 3. 主要发现转化路径推演
基于论文发现，系统性推演研究成果的落地路径：
- 短期（0-2 年）：验证性实验方向、待回答的核心科学问题
- 中期（2-5 年）：临床前研究 / 早期临床试验设计
- 长期（5+ 年）：大规模应用、监管审批、商业化
- 关键挑战与对策（技术 / 临床 / 监管 / 伦理 / 商业化多维度）

### 4. 实验方法总结 + 可落地实验方案
- **方法总结**：提炼论文中每项关键技术的目的、路线、材料、步骤、质控要点
- **落地方案**：设计 1-3 套可直接复现 / 拓展的实验方案，含完整材料清单（品牌/货号建议）、逐步 SOP、预期结果、预算估算、伦理要求

### 5. 交互式医学知识图谱
**关系驱动**的图谱构建策略：只提取论文中有实质关系的实体对，不堆砌孤立节点。
- 支持 14 类医学实体，全部以中文标注：疾病、药物、基因、症状、医疗程序、生物标志物、解剖结构、研究人群、实验动物、细胞系、信号通路、代谢物、器械仪器、结局指标
- 关系类型使用中文，仅提取有文本依据的关系
- 输出 D3.js 交互式 HTML 图谱，支持搜索、筛选、拖拽、缩放、节点详情、SVG 导出

### 6. 综合分析报告
整合以上所有模块，输出结构化 Markdown 报告，包含六大章节：核心文献分析、补充文献综述、转化路径、实验方法总结、可落地方案、知识图谱链接。

## 使用指南

### 环境准备

```bash
pip install networkx jinja2
```

### 安装方式

将项目目录复制到 AI 工具的 Skills 目录下，例如：

```bash
cp -r medical-literature-skill-v3 ~/.kiro/skills/
```

### 触发方式

直接在对话中提供文献内容，Skill 会自动启动完整分析流程：

```
# 方式一：上传附件
请帮我分析这篇论文
[上传 PDF 或 DOCX 文件]

# 方式二：粘贴文本
请帮我分析以下论文内容：
[粘贴论文摘要或全文]

# 方式三：提供链接
请帮我分析这篇论文：https://pubmed.ncbi.nlm.nih.gov/XXXXXXXX/
```

## 使用场景

**医学研究人员**
快速掌握一篇新发表论文的核心发现，了解与已有研究的关系，规划下一步验证实验。

**临床医生**
在繁忙的临床工作中，15 分钟内获取一篇指南或 RCT 的关键结论和临床意义，辅助循证决策。

**医药研发人员**
分析竞品或靶点相关文献，提取实验方法和材料清单，评估研究成果的转化可行性。

**医学生 / 研究生**
快速理解导师推荐的文献，提取统计数据和研究设计要点，辅助文献综述写作。

**科研项目立项**
围绕研究方向检索补充文献，识别研究空白，为项目申请提供文献支撑。

## 注意事项与边界

### 准确性
- AI 提取的信息仅供参考，关键统计数据和结论请以原文为准
- 实体识别和关系提取可能存在遗漏，建议结合人工审核
- 补充文献检索结果取决于 PubMed 数据库的收录情况，可能不完整

### 文献输入
- 支持 PDF / DOCX 附件直接上传，或粘贴文本内容
- 扫描版 PDF（图片格式）无法直接读取，建议先用 OCR 工具处理
- 单次分析建议 1-3 篇文献，不适合大批量文献的自动化处理

### 知识图谱
- 图谱仅呈现论文中有明确文本依据的关系，不进行推断或臆造
- 节点数量取决于论文中实质性关系的数量，关系稀少的论文图谱节点会较少，这是正常现象
- 图谱可视化依赖网络加载 D3.js，离线环境下无法正常显示

### 转化路径与实验方案
- 转化路径推演具有不确定性，需结合领域专家判断
- 实验方案实施前必须通过所在机构的伦理审查
- 材料清单中的品牌和货号建议仅供参考，请以实际采购为准

### 隐私与合规
- 论文内容会通过 AI 模型处理，请勿上传含有未公开数据或保密信息的文献
- 补充文献检索通过 PubMed 公开 API 进行，无需注册，不涉及付费
