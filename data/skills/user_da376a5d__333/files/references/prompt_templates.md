## 8.1 主要发现转化路径推演

```
请基于以下核心论文的主要发现，推演该研究成果的未来转化路径：

【核心论文主要发现】
{main_findings}

【研究设计】{design_type}
【关键药物/疾病/机制】{key_topics}

请按以下结构输出：

**整体转化路径概述**（150-250字）：从基础发现到临床/产业落地的整体路径。

**短期（0-2年）**：
- 需开展的验证性实验
- 需回答的核心科学问题
- 技术指标的进一步细化方向
（至少3条，必须基于论文实际发现，避免空泛表述）

**中期（2-5年）**：
- 临床前研究 / 早期临床试验设计建议
- 可拓展的候选适应症（基于机制相似性）
- 关键合作方/资源需求
（至少3条）

**长期（5+年）**：
- 大规模临床应用 / 产品化前景
- 监管审批路径（FDA / NMPA / EMA）
- 商业化模式与社会影响
（至少3条）

**关键挑战与对策**（覆盖至少3个维度：技术/临床/监管/伦理/商业化）：
| 挑战类型 | 具体挑战 | 应对策略 |
|----------|----------|----------|
```

## 8.2 实验方法总结

```
请从以下论文中提炼实验方法，逐项总结：

{content}

对每项关键实验方法，输出以下内容：

**方法名称**（如：Western Blot 检测 XX 蛋白表达）
- **目的**：该方法在本研究中的目的
- **技术路线**：2-3句话概述
- **材料/试剂/设备**：清单
- **关键步骤**：逐步列出
- **质量控制**：本研究采用的质控措施
- **局限性**：该方法的固有局限或本研究中的局限

要求：
1. 覆盖论文涉及的所有关键实验技术
2. 步骤需足够详细，让读者理解技术路线
3. 突出论文特有的优化或改进点
```

## 8.3 可落地实验方案设计

```
请基于以下核心论文，设计 1-3 套读者可直接复现/拓展的实验方案：

【核心论文摘要】
{paper_summary}

【主要发现】
{main_findings}

每套方案包含：

**方案标题**（明确目标，如：体外验证 XX 药物对 XX 细胞系的抑制作用）

- **方案目标**：要回答的具体科学问题
- **实验类型**：体外 / 动物 / 临床
- **样本/受试者**：来源、数量、入组排除标准

**材料清单**：
| 类别 | 名称 | 规格/品牌建议 | 用量 |
|------|------|---------------|------|

**详细步骤**：
Step 1：[标题]
- 操作描述（含浓度、温度、时长等参数）
- 预计耗时：
- 注意事项/易错点：

（以此类推）

- **预期结果**：定量指标与判读标准
- **数据分析**：统计方法（含检验类型）
- **关键控制点**：至少3个，含排错建议
- **预算估算**：粗略估算（人民币）
- **时间周期**：总时间（周/月）
- **伦理/合规要求**：所需审批

要求：
1. 必须可直接执行，不要写"使用合适的方法"这类模糊表述
2. 材料清单具体到品牌/货号建议
3. 步骤包含具体参数（浓度、温度、时长）
4. 涉及动物/人体研究必须列明伦理审批要求
```

## 8.4 补充文献检索与总结

```
请使用 fetch_webpage 工具检索 PubMed 中与下列主题相关的文献：

【检索主题】{topic}
【关键词】{keywords}
【时间范围】近5年

步骤：
1. 访问检索 URL：
   https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pubmed&term={keywords}&retmode=json&retmax=10&sort=date
2. 从结果中提取 PMID 列表
3. 访问摘要 URL：
   https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi?db=pubmed&id={pmid_list}&retmode=json
4. 选取 5-10 篇高相关性文献，提取详细信息

每篇文献输出：
- **标题**（超链接，优先用 PMID 链接：https://pubmed.ncbi.nlm.nih.gov/{PMID}/，其次 DOI：https://doi.org/{DOI}）
- **作者/年份**：第一作者 等 (年份)
- **期刊**
- **核心发现**：1-3句话精炼总结
- **与核心论文的关系**：一致 / 补充 / 冲突 / 拓展

⚠️ 严格规则：
1. 补充文献结果必须独立呈现，绝不混入核心论文的分析内容
2. 每篇文献必须附带可点击的跳转链接
3. 检索失败时如实标注，不要伪造文献
```
