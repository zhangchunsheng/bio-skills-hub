# Skill Info

## Skill Name
医药代表职业转型导航

## Description
本技能用于医药代表从销售型到学术型的系统性职业转型规划。基于医药代表管理办法的合规要求，评估代表个人能力现状与法规要求的差距，生成个性化学习路径（疾病知识、循证医学、学术沟通），并提供转型时间线和里程碑管理。适用于面临结构性优化的存量医药代表、MAH培训部门、以及医药行业HR的职业发展支持场景。当用户需要进行医药代表转型规划、合规能力自评、学习路径设计、或制定备案准备时间表时，应使用本技能。

## Introduction

本技能在合规与职业发展领域提供医药代表从"销售导向"到"学术导向"的系统性职业转型规划。基于《医药代表管理办法》（2026年8月1日施行）的合规要求，通过六维能力对标评估、GAP差距量化和三段式学习路径设计，为医药代表生成个性化的转型导航方案。

医药代表职业转型导航旨在简化和自动化医药代表的合规能力自评、学习路径规划及备案准备时间表制定，为面临结构性优化的存量医药代表、MAH培训部门及医药行业HR提供全面的工具支持。

核心能力：

- 用户画像采集
- 能力现状评估（六维对标）
- GAP 差距分析报告
- 三段式学习路径生成
- 转型时间线与里程碑
- 生成转型导航报告

应用场景：

- 医药代表合规能力自评与转型规划
- 个性化三段式学习路径设计（疾病知识 → 循证医学 → 学术沟通）
- 备案准备时间表制定与里程碑管理
- MAH培训部门批量评估代表能力现状
- 医药代表管理办法合规差距诊断
