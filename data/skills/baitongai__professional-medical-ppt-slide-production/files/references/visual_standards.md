# 医学PPT视觉设计规范

## 核心设计原则

### 1. 单一核心信息原则（One Message Per Slide）
每页幻灯片只传递一个核心信息。标题应为结论性陈述，而非泛化主题标签。
- ✅ "PD-L1高表达患者ORR提升2.3倍"
- ❌ "疗效数据"

### 2. 认知负荷最小化
每页信息量控制在听众可在30秒内理解的范围：
- 标题 ≤ 15字
- 正文段落 ≤ 6行
- 要点列表 ≤ 6项
- 每项要点 ≤ 12字

### 3. 视觉动线引导
通过字号、颜色、位置的自然对比，引导观众视线从最重要元素流向补充信息。

## 色彩规范

### 学术场景配色原则
- 主色调：沉稳、专业（深蓝、藏青、墨绿、酒红）
- 辅助色：用于区分数据系列或强调
- 禁止：高饱和度荧光色、多色渐变、娱乐化配色

### 推荐配色方案

**方案一：经典学术蓝**
| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | #1B3A5C | 标题栏背景、强调色 |
| 辅色 | #2E86C1 | 图表主系列、超链接 |
| 中性色 | #5D6D7E | 正文文字 |
| 底色 | #FFFFFF / #F8F9FA | 页面背景 |

**方案二：医学专业绿**
| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | #1A5632 | 标题栏背景、强调色 |
| 辅色 | #27AE60 | 图表主系列、正面数据 |
| 中性色 | #566573 | 正文文字 |
| 底色 | #FFFFFF / #F4F6F6 | 页面背景 |

**方案三：科研深紫**
| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | #4A235A | 标题栏背景、强调色 |
| 辅色 | #8E44AD | 图表主系列 |
| 中性色 | #5B6C7D | 正文文字 |
| 底色 | #FFFFFF / #F5EEF8 | 页面背景 |

### 数据可视化配色
- 正面/向好指标：暖色系（学术场景建议用蓝/绿替代红色，或使用中国红 #C0392B）
- 负面/风险指标：冷色系（深灰 #7F8C8D）
- 中性/对照：灰色系（#BDC3C7）
- 对比度：确保文字与背景对比度 ≥ 4.5:1（WCAG AA标准）

## 页面布局规范

### 标准学术页面模板

```
┌──────────────────────────────────────┐
│  [Logo]  结论性标题（≤15字）    [保密标识] │
├──────────────────────────────────────┤
│                                      │
│   核心视觉区（图表/流程图/关键数据）      │
│   占页面面积 50-60%                   │
│                                      │
├──────────────────────────────────────┤
│   辅助说明区（要点列表/解读文字）         │
│   占页面面积 20-30%                   │
│                                      │
├──────────────────────────────────────┤
│  页码 X/Y    数据来源脚注    日期       │
└──────────────────────────────────────┘
```

### 统一元素检查清单
- [ ] Logo位置：左上角，所有页面统一
- [ ] 保密级别：右上角（如"内部资料""仅供学术交流"）
- [ ] 页码：右下角，格式统一
- [ ] 数据来源：左下角脚注区，格式"[研究名称/PMID], [年份]"
- [ ] 合规声明：如"数据截至YYYY-MM-DD""仅供内部培训使用"
- [ ] 标题样式：全篇字体、字号、颜色统一
- [ ] 正文样式：全篇字体、字号、行距统一
- [ ] 项目符号：全篇格式统一

## 图表规范

### 图表类型选择矩阵

| 数据类型 | 推荐图表 | 禁止使用 |
|----------|----------|----------|
| 生存数据 | Kaplan-Meier曲线 | 柱状图 |
| 分类比较 | 柱状图/条形图 | 饼图（>4类时） |
| 趋势分析 | 折线图 | 柱状图堆叠 |
| 分布特征 | 箱线图/小提琴图 | 饼图 |
| 组成比例 | 堆叠柱状图/瀑布图 | 饼图（>6类时） |
| 多变量关系 | 森林图/热力图 | 3D图表 |

### 图表强制标注项
- [ ] X轴/Y轴标签及单位
- [ ] 图例（含分组说明）
- [ ] 误差线（适用于需要展示变异性的数据）
- [ ] 显著性标记（*p<0.05, **p<0.01, ***p<0.001）
- [ ] 样本量（n=XXX）
- [ ] HR/OR/RR值及95%CI（适用于生存/风险分析）

### 图表风格要求
- 纯色填充，清晰线条
- 禁止渐变填充、3D效果、阴影
- 网格线使用浅灰色细线（#E5E7E9）
- 数据点标记大小适中，不宜过大
