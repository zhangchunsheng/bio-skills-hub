# 学术软植入策略指南

## 核心理念

软植入（Soft Value Integration）是指在尊重KOL学术独立性的前提下，通过精准、得体、有据可依的方式，在学术报告中自然引出产品相关的科学价值锚点，实现"无痕关联、科学支撑、共识共建"。

**本质**：让人记住科学价值，而非强行推广产品。

---

## 叙事路径框架

### 标准叙事弧线（疾病负担→产品定位）

```
疾病负担 → 未满足需求 → 当前疗法局限 → 机制突破 → 产品自然浮现
   ↓              ↓              ↓            ↓            ↓
 唤起共识      构建痛点      预留空间     展现创新     价值锚定
```

### 各阶段软植入策略

| 叙事阶段 | 核心任务 | 软植入策略 | 安全等级 |
|----------|----------|------------|----------|
| 疾病负担 | 唤起共识 | 引入流行病学数据，关联本品针对的人群特征 | 🔹 安全 |
| 未满足需求 | 铺垫痛点 | 使用"治疗空白区"图示，暗示解决方案存在 | 🔹 安全 |
| 当前疗法局限 | 构建认知 | 讨论应答率不足、耐药问题，预留空间 | 🔹 安全 |
| 机制突破 | 展现创新 | 用"通路演化图"引出靶点合理性，产品作为其中一环 | 🔸 中度 |
| 数据展示 | 体现实力 | 图表注释中轻描淡写提及产品代号 | 🔸 中度 |
| 讨论与展望 | 引导方向 | 提出"下一代治疗范式"设想，本品成为实现路径之一 | 🔺 谨慎 |

## 软植入十大红线（绝对禁止）

| # | 红线行为 | 说明 |
|---|----------|------|
| 1 | 在摘要/结论中植入产品名 | 高敏感区域，任何引导均不可接受 |
| 2 | 图表标题提及产品名称 | 图表标题应为纯学术描述 |
| 3 | 直接要求KOL推荐产品 | 侵犯KOL学术独立性 |
| 4 | 虚构或夸大临床数据 | 严重违反合规底线 |
| 5 | 暗示"唯一选择""最佳方案" | 属误导性宣称 |
| 6 | 在未获批适应症领域提及产品 | 超适应证违规 |
| 7 | 提供KOL未要求的产品资料 | 隐性推广 |
| 8 | 修改KOL原稿中的科学结论 | 学术造假 |
| 9 | 使用"我们""公司"等商业主体语言 | 破坏客观中立形象 |
| 10 | 在产品尚未获得临床数据的领域暗示优势 | 无证据推测 |

## 软植入十大加分项

| # | 加分行为 | 效果 |
|---|----------|------|
| 1 | 提供高质量的最新文献支持 | 体现科学合作诚意 |
| 2 | 建议引用KOL本人发表的研究 | 尊重学术贡献 |
| 3 | 引用领域内公认权威的研究方法 | 提升学术严谨性 |
| 4 | 使用"某新型XX抑制剂（代号XXX）"等客观称呼 | 保持学术距离 |
| 5 | 在"未满足需求"环节建立共识 | 为后续关联铺垫 |
| 6 | 探讨机制/通路而非具体产品 | 最安全的关联方式 |
| 7 | 提议补充中立性数据（如流行病学、真实世界研究） | 拓展讨论空间 |
| 8 | 用"领域正走向XX方向"而非"我们正在做XX" | 去商业化 |
| 9 | 在讨论部分将产品作为"未来可探索的方向之一" | 开放性表述 |
| 10 | 尊重KOL的修改意见，不坚持植入 | 维护信任 |

## 植入强度决策树

```
是否涉及产品适应症领域？
  ├── 否 → 不植入
  └── 是 → 是否有明确未满足需求描述？
        ├── 否 → 🔹 轻量提示：仅提及机制/通路
        └── 是 → 是否有已发表文献支持？
              ├── 否 → 🔹 轻量提示：建议补充文献
              └── 是 → KOL是否有相关研究背景？
                    ├── 否 → 🔸 中度关联：引用联合用药趋势
                    └── 是 → 场景是否为纯学术会议？
                          ├── 是 → 🔸 中度关联：引用KOL研究
                          └── 否 → 🔺 增强引导：需合规审批
```

## 经典场景分析

### 场景一：肿瘤领域学术卫星会

**背景**：KOL为肿瘤内科主任，报告主题为"晚期NSCLC治疗新进展"

**软植入策略**：
1. 疾病负担环节：引用最新发病率数据，关联"驱动基因阴性"患者群体（本品目标人群）
2. 当前疗法局限：强调"免疫治疗耐药后的治疗空白"，为后续引出新品铺垫
3. 机制突破：以通路图展示，将本品靶点作为"该通路研究的最新进展"自然引入
4. 数据展示：在本品临床数据页，标题使用"XX抑制剂在XX人群中的初步结果"，脚注标注研究阶段

**禁忌**：
- 不在摘要中提及"新药问世"
- 不与已上市药物进行疗效比较
- 不在总结中使用"推荐使用"

### 场景二：心血管领域小型圆桌会

**背景**：KOL为心血管内科PI，3-5位专家闭门讨论

**软植入策略**：
1. 开场以临床困惑引发讨论："SGLT2i之后还有什么？"
2. 用"治疗范式演进时间线图"展示，本品作为时间线末端节点出现
3. 引用KOL本人发表的机制研究，建立学术共鸣
4. 互动环节："如果XX通路可以被精准调控，各位认为临床上最大的受益人群是谁？"

**禁忌**：
- 不直接发放产品资料
- 不使用准备好的产品话术
- 不引导专家出镜代言

### 场景三：指南解读学术推广

**背景**：最新指南更新解读，需植入产品在指南中的位置

**软植入策略**：
1. 完整呈现指南推荐层级，产品所在层级与其他选项并列
2. 引用指南原文描述，不自行添加评价
3. 讨论部分："该推荐基于XX研究（PMID: XXXXX），未来更多数据可能会影响推荐强度"
4. 结语："期待更多临床证据丰富治疗选择"

**禁忌**：
- 不使用高亮/放大等视觉手法突出产品
- 不对指南推荐进行主观解读
- 不暗示"指南推荐=临床最佳"

## 措辞示例库

### 引入产品相关概念的安全表述

| 目的 | 安全表述 | 风险表述 |
|------|----------|----------|
| 提及产品靶点 | "目前研究正在探索XX通路的调控" | "我们的药靶向这个通路" |
| 提及产品机制 | "该机制代表了一类新的治疗策略" | "这是目前最先进的机制" |
| 提及产品研究 | "一项正在进行的临床研究初步显示了积极信号" | "即将上市的XX药物效果惊人" |
| 提及产品优势 | "在该特定人群中的数值趋势值得关注" | "明显优于现有疗法" |
| 提及未满足需求 | "约XX%患者对现有治疗应答不足" | "目前没有有效的治疗方法" |

### 面向不同性格KOL的措辞调整

| KOL类型 | 措辞风格 | 示例 |
|---------|----------|------|
| 客观中立型 | 数据驱动，保留所有限定语 | "数据显示XX趋势，但需更大样本验证" |
| 创新拥抱型 | 强调机制新颖性，适度展望 | "这一思路为领域提供了新的探索方向" |
| 保守稳健型 | 强化证据基础，弱化不确定性 | "基于已有证据，XX假设值得进一步研究" |
| 批判质疑型 | 主动承认局限性，预留讨论空间 | "该研究的局限性包括XX，期待各位专家的批评指正" |
