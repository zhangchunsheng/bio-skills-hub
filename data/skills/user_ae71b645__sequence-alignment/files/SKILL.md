# 序列比对分析

一个基于 NCBI BLAST API 进行序列比对的技能，支持核酸和蛋白序列与主流生物数据库之间的相似性比较。

## 适用场景

- 需要基于 NCBI BLAST API 进行核酸或蛋白序列相似性比对时使用本技能。
- 需要在数据分析任务中明确假设前提、限定范围、并输出可复现格式结果时使用本技能。
- 需要将响应严格限定在已文档化的任务边界内、而不扩展到相邻工作范围时使用本技能。

详见上方「## 功能特性」。

## 功能特性

- **BLAST API 集成**：调用 NCBI BLAST 服务进行序列相似性检索
- **多种 BLAST 程序**：blastn、blastp、blastx、tblastn、tblastx
- **比对结果可视化**：以人类可读的格式展示比对结果
- **数据库支持**：nr、nt、swissprot、refseq、pdb 等

## 用法

```text
python scripts/main.py --sequence "ATGCGTACGTAGCTAGCTAG" --program blastn --database nt --output results.txt
```

### 参数说明

| 参数 | 说明 | 是否必填 |
|-----------|-------------|----------|
| `--sequence` | 查询序列（DNA/蛋白） | 是 |
| `--program` | BLAST 程序：blastn、blastp、blastx、tblastn、tblastx | 是 |
| `--database` | 目标数据库：nr、nt、swissprot、pdb、refseq_protein | 是 |
| `--output` | 输出文件路径 | 否 |
| `--format` | 输出格式：text、json、csv | 否（默认：text） |
| `--max_hits` | 返回的最大命中数 | 否（默认：10） |
| `--evalue` | E-value 阈值 | 否（默认：10） |

## 技术难度

**中等** —— 需要理解 BLAST 算法、带重试机制的 API 调用，以及生物序列格式。

## BLAST 程序参考

| 程序 | 查询类型 | 数据库类型 | 使用场景 |
|---------|-----------|---------------|----------|
| blastn | 核酸 | 核酸 | DNA 对 DNA |
| blastp | 蛋白 | 蛋白 | 蛋白 对 蛋白 |
| blastx | 核酸（翻译后） | 蛋白 | DNA 对 蛋白 |
| tblastn | 蛋白 | 核酸（翻译后） | 蛋白 对 DNA |
| tblastx | 核酸（翻译后） | 核酸（翻译后） | 翻译后的 DNA 对 DNA |

## 示例工作流程

### DNA 序列相似性检索
```text
python scripts/main.py --sequence "ATGGCCCTGTGGATGCGCTTCTTAGTCG" --program blastn --database nt --max_hits 5
```

### 蛋白序列比对
```text
python scripts/main.py --sequence "MKTAYIAKQRQISFVKSHFSRQLEERLGLIEVQAPILSRVGDGT" --program blastp --database swissprot --evalue 0.001
```

## 输出格式

结果包含：
- 查询序列信息
- 命中序列的定义与登录号（accession number）
- 比对得分（bit score、e-value）
- 一致性（identity）与相似性百分比
- 带匹配/不匹配标注的比对可视化
