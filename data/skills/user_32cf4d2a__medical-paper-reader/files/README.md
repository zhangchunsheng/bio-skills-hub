# 医学论文速读助手 - Skill包说明

## 文件结构
```
医学论文速读助手/
├── SKILL.md                    # 技能描述文件（必须）
├── scripts/
│   └── paper_abstractor.py     # 论文结构化提取与分析脚本
└── README.md                   # 本文件
```

## 安装方法

### 方法一：通过WorkBuddy导入（推荐）
1. 打开WorkBuddy桌面版
2. 左侧菜单 → 技能 → 本地技能 → 导入技能
3. 选择本文件夹中的 SKILL.md
4. 导入成功后即可使用

### 方法二：打包上传到SkillHub
1. 将整个文件夹压缩为 ZIP 格式
2. 访问 https://skillhub.cn
3. 登录 → 开发者中心 → 发布Skill
4. 上传ZIP包，填写信息，提交审核

## 测试用例

### 测试用例1：RCT论文摘要速读
**输入：**
```
标题：一项多中心随机双盲安慰剂对照试验评估XX单抗治疗中重度溃疡性结肠炎的疗效与安全性

摘要：
背景：中重度溃疡性结肠炎治疗选择有限。本研究评估XX单抗的疗效与安全性。
方法：纳入420例中重度UC患者，1:1随机分至XX单抗组（n=210）和安慰剂组（n=210），
治疗8周。主要终点为第8周临床缓解率。次要终点包括内镜改善、组织学缓解等。
结果：第8周，XX单抗组临床缓解率为38.6%，安慰剂组为12.4%（P<0.001）。
内镜改善率XX单抗组56.2% vs 安慰剂组23.8%（P<0.001）。
不良事件发生率两组相当（42.4% vs 39.5%）。
结论：XX单抗治疗中重度UC疗效显著，安全性良好。
```
**预期输出：** 识别为RCT研究，结构化提取目的/方法/结果/结论，计算NNT等指标

### 测试用例2：Meta分析速读
**输入：**
```
请速读这篇Meta分析：
纳入23项队列研究，共125,000名受试者，
评估阿司匹林与结直肠癌发病风险的关系。
合并RR=0.78（95%CI: 0.69-0.88），I²=56%。
结论：长期服用阿司匹林可降低结直肠癌发病风险。
```
**预期输出：** 识别为Meta分析，评价异质性，解读合并效应量

### 测试用例3：诊断试验研究速读
**输入：**
```
论文题目：新型肿瘤标志物CA50在胰腺癌诊断中的价值
研究纳入200例胰腺癌患者和200例健康对照，
CA50诊断胰腺癌的灵敏度为78%，特异度为85%，
AUC为0.88（95%CI: 0.84-0.92）。
```
**预期输出：** 识别为诊断试验，计算约登指数、阳性似然比等指标

### 测试用例4：队列研究速读
**输入：**
```
一篇10年随访的队列研究，纳入5000名健康成年人，
发现每天喝3杯咖啡的人比不喝咖啡的人，
心血管疾病发病风险降低25%（HR=0.75, 95%CI: 0.62-0.91, P=0.004）。
```
**预期输出：** 识别为队列研究，计算ARR、NNT等临床指标
