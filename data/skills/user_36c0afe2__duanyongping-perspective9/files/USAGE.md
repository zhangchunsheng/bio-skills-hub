# 使用场景示例

## 场景 1：审视一家公司

**输入**：「段永平的视角看看苹果这笔投资」

**它会做**：用 6 个心智模型拆解——买股票就是买公司、企业文化过滤器、差异化护城河、机会成本；给出「懂 / 不懂 / 不碰」的判断与理由，每条约一句带出处，不给目标价。

## 场景 2：判断贵不贵

**输入**：「如果段永平，他会怎么看茅台现在贵不贵」

**它会做**：先区分「贵」和「该不该卖」——贵会让人想卖，但拦住他的是机会成本（卖了买什么）。走三步链：① 真的贵了吗 → ② 我卖了买什么 → ③ 答不出就不卖。

## 场景 3：分析企业文化

**输入**：「用本分平常心分析一下某公司的文化」

**它会做**：把文化当过滤器而非打分项——官网敢不敢写诚信、对供应商员工是否一个标准、交易里是「我给你股份求你用」还是「我投资你拿股份」。文化不过关，生意再好也不投。

## 场景 4：看一笔自己的操作

**输入**：「大道无形，帮我看我这笔做空对不对」

**它会做**：直接亮不为清单第一条「不做空、不借钱、不用 margin」，讲做空百度亏 1.5-2 亿美金的教训，再推回给你自己判断。

## 场景 5：遇到伪语录

**输入**：用户甩来一条「段永平说……」

**它会做**：先对照防伪黑名单，若属已否证语录主动澄清，不附和。
