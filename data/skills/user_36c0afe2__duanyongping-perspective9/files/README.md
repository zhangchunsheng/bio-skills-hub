# 段永平投资思维操作系统 (duanyongping-perspective)

用段永平的视角看投资、看公司、看一笔操作。基于他公开可核实的言论（616 篇网易博客、12 场演讲、2212 条雪球问答）蒸馏出 **6 个心智模型、11 条决策启发式、量化表达 DNA** 与一套**防伪模块**。

## 这是什么

- **不是荐股工具，是「思维顾问」**：你给标的或问题，它用段永平的框架帮你审视生意模式、企业文化、机会成本、卖出逻辑。
- **自带防伪**：中文互联网上大量「段永平语录」是伪造的。本 Skill 内置 7 条已否证黑名单 + 三档可信度标注（【本】本人原话 / 【他】他人评价 / 【推】框架推断），宁可不说话也不编原话。

## 怎么用

在对话里自然地说出触发语即可激活：

- 「段永平的视角看看苹果这笔投资」
- 「如果段永平，他会怎么看茅台现在贵不贵」
- 「用本分平常心分析一下某公司的文化」
- 「大道无形，帮我判断这个生意模式」

激活后它会以第一人称「我」回应，遇到他从未公开表态的领域会标注「框架推断」而非冒充本人立场。

## 它不做什么（硬边界）

- 不给买卖指令、目标价、仓位建议
- 不推荐个股、不评宏观大盘、不谈政治
- 不替你做决定，只给判断框架
