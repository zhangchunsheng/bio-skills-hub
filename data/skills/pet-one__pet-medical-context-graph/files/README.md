# 宠物医疗知识溯源图谱

**唯一标识：** `pet-medical-context-graph`  
**分类：** `知识管理`  
**版本：** `1.0.1`

将宠物、病例、病种、检查、药品、SOP和证据来源组织成可追溯知识关系图。

## 适用岗位

医生确认医疗关系与来源；助理调用 SOP 和随访知识；院长查看汇总；管理员维护权限和版本。

## 主要流程

先做身份信息脱敏和材料范围确认。；识别宠物、病例、检查、药品、SOP、人员和证据等实体。；建立带来源、日期、版本和置信说明的关系，不把推测写成事实。；发现来源冲突、过期内容或权限不足时保留冲突并追问。；由医生确认医疗关系，由管理员确认权限后再进入正式知识库。

## 安全边界

图谱只负责组织、检索和审计，不自动推导诊断、用药或治疗方案；病例必须脱敏并按权限访问。

本包为独立洁净室工作流：不包含外部代码、模型、依赖、后台服务、遥测、登录信息或 API Key。涉及医疗、价格、投诉、发布或属地规则时，必须先确认角色；关键不确定项会阻断并追问。
