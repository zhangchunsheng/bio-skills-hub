# 宠物医疗知识溯源图谱

**Slug:** `pet-medical-context-graph`  
**Category:** `知识管理`  
**Version:** `1.0.1`

将宠物、病例、病种、检查、药品、SOP和证据来源组织成可追溯知识关系图。

This is an independent clean-room workflow package for pet hospitals. It contains no external code, models, credentials, telemetry, or automatic external actions. Medical, privacy, publication, pricing, complaint, and regulatory decisions require human review.
