# 安装与上传

## Skill Hub 上传

选择本目录下的 `pet-medical-context-graph-v1.0.1-WorkBuddy-SkillHub.zip` 上传。上传前请确认平台显示名为 `[知识管理] 宠物医疗知识溯源图谱`，并自行完成平台审核。

## 本地安装

解压后保持根目录 `pet-medical-context-graph/` 不变，将整个目录放入宿主技能目录。安装后重启宿主或新建任务，并用 `$pet-medical-context-graph` 做一次显式触发测试。

## 状态边界

本地验证、安装、Skill Hub 上传、平台审核和公开发布是四个独立状态。本包只证明本地包结构和内容已验证，不代表已上传或已发布。
