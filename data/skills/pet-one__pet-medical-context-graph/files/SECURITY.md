# 安全、隐私与医疗边界

本 Skill 是无后台、无遥测、无密钥的工作流包，不主动上传材料、发送消息、修改外部系统或自动联网。需要外部数据时，先说明来源、范围、平台条款和数据出境风险，再等待逐次授权。

使用者必须确认自己有权处理材料。正式处理前遮蔽宠主姓名、电话、地址、证件、支付信息、社交账号、完整病历号和其他直接标识；宠物姓名默认使用代号。

不在公开 Issue、PR、截图、示例或 Skill Hub 包中放入真实病例、病历图片、检查单、联系方式、登录凭据或 API Key。公开示例全部为虚构。

具体动物的诊断、处方、剂量、手术、预后和急症处置不由本 Skill 决定。疑似急症只提示立即联系就近动物诊疗机构或执业兽医。
