# 成本估算框架（医疗净化工程 · 按专业）

> 用途：把项目预算分解到六专业，形成报价基线，支撑投标核算与成本控制。
> 关联 SOP 节点：节点 1（投标前置）、节点 2（询比核算）、节点 6（付款履约）。
> 脱敏：金额区间仅作结构示范，真实数值以项目询价与合同数据为准，本框架不承载成交价。

## 估算结构
总成本 = 直接设备费 + 材料费 + 安装配合费 + 税费 + 不可预见费 + 管理费

## 填写要点
- **成本建模维度**：货期（长交期设备占用资金）、物流、安装配合、税票（专票/普票影响成本）须纳入，不止设备裸价。
- **专业成本占比经验区间（洁净手术部类项目通用匡算，非某项目实绩；定标后以实际询价回填）**：
  - 暖通 25%–35%（净化空调机组 + 风机过滤 + 风管，通常最高）
  - 医疗设备 20%–30%（吊塔、无影灯、手术床、显示系统）
  - 装饰 15%–20%（洁净板、地面、门窗、圆弧）
  - 电气 10%–15%（配电、照明、自控/弱电）
  - 给排水 5%–8% / 医气 5%–8%
  - 注：ICU / 实验室 / 生殖中心等结构不同，此表仅为投标匡算锚点；完整维度见 `references/sop_detail.md` 节点 2。
- **变更与签证控制**：施工中变更须即时重算该专业小计，避免超预算（节点 6、节点 10 余料联动）。
- **中标后二次核价**：投标到中标进场常隔数月乃至数年，原料价格波动且可能二次图变，故须按成本部门最新材料清单与工程量清单**再次询价核价**，不可直接沿用投标报价（详见 `references/sop_detail.md` 节点 2）。
- **付款节奏**：按节点（预付款→发货款→验收款→质保金）与供货风险挂钩，关键设备早付早锁。
