# 医疗净化采购全生命周期

把"医疗净化工程采购"从投标前置介入到移交后维保的全链路，转化为可复用的**结构化交付物与节点 SOP**。覆盖六个专业（暖通、装饰、给排水、电气、医气、医疗设备），产出可直接用于采购执行的文档。

## 何时使用

- 用户要生成：**采购申请单 / BOM 拆解表 / 供应商比价矩阵 / 成本估算框架**。
- 用户描述采购场景，需要按节点给出流程与产出：投标选型报备、询比核算、二次品牌报备、排单计划、谈签合同、付款履约（质保金）、加急、仓库/盘点/余料、竣工资料、维保。
- 触发词参考：`采购申请单`、`BOM 拆解`、`供应商比价`、`成本估算`、`采购全生命周期`、`投标前置`、`品牌报备`、`排单计划`、`质保金`、`洁净工程采购`。

## 采购全生命周期节点 SOP（投标 → 维保）

医疗净化采购并非"中标后才启动"，而是从投标阶段前置介入，贯穿施工到移交后维保。各节点为通用流程（不含具体商务数据）：

1. **投标阶段 · 采购前置介入**：分设计供材输入、投标成本询价、投标资料授权三阶段，使报价有真实成本与可落地产品支撑。
2. **询比核算成本**：基于清单做询价比对，核算综合成本（货期、物流、安装配合、税票），形成报价基线；中标后须按最新图纸/清单二次核价。
3. **中标后开工前 · 二次品牌报备确认**：分"投标已锁品牌"与"未锁/允许变更"两种情形报送样品与资料，做进场前品牌与参数确认。
4. **开工后 · 排单申请计划**：依项目经理敲定的施工进度，按材料/设备货期倒推项目部申请日，形成排单计划。
5. **过程商务 · 谈单 / 开发 / 签合同**：把控六点（买对 / 货期起点 / 付款方式 / 售后质保 / 违约处罚 / 文本准确）。
6. **付款与履约**：预付款→发货→验收→尾款，部分设备预留质保金；按供应商类型（长期账期 / 贵重预付授信 / 新供应商全款应急）区分付款方式。
7. **突发加急材料处理**：按材料类别（常规库存 / 兄弟项目调拨 / 非常规插队或换牌 / 零散就地采买）选择加急路径，优先保关键路径。
8. **现场管理 · 仓库布置 / 签发物料**：两类仓库位置（集装箱分仓 / 施工区房间），重物分散靠结构柱梁；签发须授权专人、双签+项目经理加签。
9. **物料盘点**：按月/季度核对账实；ERP 与现场出入须防范惰性强忘签单与监守自盗模仿代签。
10. **完工前 · 剩余材料归类**：按"外观/功能/配件"三标准判定可再利用；废料合规处置、残值回收入账。
11. **竣工验收前 · 资料准备**：按材料/设备两类交付标准备齐资料；甲方须原件，注意易缺项（说明书、保障卡、合格证原件）。
12. **施工完成 · 清场与维保移交（含厂家联动）**：清场保洁→设备调试→空气洁净度检测；预留易损备料，厂家售后方式书面汇总双签移交。（原节点 13「厂家联动」已并入本节点。）

> 各节点的深入检查清单、审核要点与决策逻辑见 `references/sop_detail.md`。

## 程序化生成

`scripts/generate.py` 从一份 JSON 项目简述生成上述 4 类文档，并做合计/加权校验：

```bash
# 生成示例
python3 scripts/generate.py --demo --out output_demo

# 从 spec 生成
python3 scripts/generate.py --spec my_project.json --out output

# 仅校验 spec 合法性
python3 scripts/generate.py --validate my_project.json
```

## 使用步骤

1. 先问清项目画像（医院等级、科室、洁净度、预算区间、工期），不凭空填数。
2. 按用户需要选择交付物：要申请单→填 `application`；要 BOM→填 `bom`；要比价→填 `compare`；要估算→填 `cost`。
3. 用 `generate.py` 产出，或指导用户直接复写 `templates/` 空白表。
4. 金额、合同、供应商具体信息以实际询价与项目数据为准；输出中**仅用档次、不用真名、不写成交价**。

## 实战方法论速查（节选自 sop_detail）

> 全节点一句话结论速查；完整检查清单、审核要点与决策逻辑见 `references/sop_detail.md`。

| 节点 | 一句话方法论 |
|------|--------------|
| 1 投标前置 | 设计供材输入 + 投标询价（含税/税点/含运）+ 资料授权（唯一授权/参数响应/节能认证）三阶段 |
| 2 询比核价 | 综合成本含货期占款/物流/安装配合/税票；中标后按最新图纸二次核价 |
| 3 二次报备 | 锁品牌→照投送审；未锁/可变更→三家报备周转留一家 |
| 4 排单计划 | 依施工进度 + 货期表倒推申请日，长交期设预警阈值 |
| 5 谈签合同 | 六点：买对 / 货期起点 / 付款方式 / 质保 / 违约 / 文本准确 |
| 6 付款履约 | 长期账期 / 贵重预付授信 / 新供应商全款应急；质保金 1–2 年释放 |
| 7 加急处理 | 常规库存加急 > 兄弟项目调拨 > 非常规插队/换牌 > 零散就地采买 |
| 8 仓库签发 | 集装箱分仓 / 施工区房间两型；重物靠柱梁；授权专人双签+经理加签 |
| 9 物料盘点 | 账实应吻合；出入排查惰性强忘签单与监守自盗 |
| 10 剩余归类 | 外观/功能/配件三标准判可再用；废料合规、残值入账 |
| 11 资料准备 | 材料/设备两类交付标准；甲方须原件；易缺说明书/保障卡/合格证 |
| 12 清场维保 | 保洁→调试→洁净度检测；预留易损备料；厂家售后方式书面双签移交 |

- **成本占比（洁净手术部通用匡算）**：暖通 25%–35% / 医疗设备 20%–30% / 装饰 15%–20% / 电气 10%–15% / 给排水 5%–8% / 医气 5%–8%。综合成本须含货期占款、物流、安装配合、税票（专票可抵 13% 进项，比价须同口径）。
- **报备筛法**：三家分国产一线 / 二线 / 进口三档梯度，每档预埋备份；审检测报告（CMA/CNAS 有效）、合格证、原厂授权；被否→同档顶替或微调参数换型号，重大偏差走变更。
- **付款节奏**：预付款 20%–30% → 发货 30%–40% → 验收 25%–30% → 质保金 3%–5% 释放；关键设备前置付款锁产能，现货标准品争取后付；质保金 1–2 年期满无争议释放，可约定阶段释放。
- **加急场景**：货期突变 / 变更增补 / 复试不合格 / 甲方赶工；三级通道「现货调配 > 就近调货 > 升级物流」；加急成本 < 停工损失则保关键路径，决策须留痕。

## 能力边界

本技能专注于采购流程方法论与文档生成，以下事项**不在本技能覆盖范围内**：

| # | 不做什么 | 说明 |
|---|---------|------|
| 1 | 不替代实地考察 | 供应商工厂考察、样品检测须线下完成，本技能仅提供检查清单框架 |
| 2 | 不替代法务审核 | 合同条款合法性、违约责任效力等需公司法务或法律顾问审定 |
| 3 | 不提供真实报价 | 所有金额为 0 或占位符，实际价格以询价结果为准 |
| 4 | 不做财务决策 | 付款节奏、授信额度等建议供参考，最终由成本部/财务部决定 |
| 5 | 不处理招投标合规投诉 | 围标/串标线索举报、异议申诉等走公司合规流程 |
| 6 | 不替代项目管理系统 | 本技能产出 markdown 文档，不直接对接 ERP/MES 等系统 |

## 常见误区与 FAQ

**Q1：生成的申请单/估算表里金额都是 0，有用吗？**
A：模板定位是「结构化框架」。金额填 0 是刻意脱敏——实际使用时把你询到的真实单价填入 spec 的 `price` 字段即可重新生成。模板的价值在字段完整性、审批流程节点和专业分解维度。

**Q2：比价矩阵的权重可以自己调吗？**
A：可以。spec 里 `compare.weights` 各维度之和须等于 1.0（100%），你可以根据项目偏好调整。比如赶工期项目可以把「交期」权重从 0.20 调高到 0.30，相应压低其他维度。

**Q3：generate.py 报错了怎么办？**
A：先用 `--validate your_spec.json` 校验 spec 格式。常见错误：① 权重之和不等于 1；② 供应商缺某个维度的打分；③ 数量/价格填了非数字。校验输出会逐条告诉你哪里有问题。

**Q4：二次品牌报备到底要报几家？**
A：行业通用做法是每类材料/设备报 **3 家**，覆盖国产一线 / 二线 / 进口三个档次。但实际情况分两种：投标时已锁定品牌的只需按锁定的那家送审；未锁品牌的才需要三家比选。

**Q5：货期表里的天数准不准？**
A：`templates/常用材料设备货期表.md` 中的 98 条数据是历史项目脱敏后的基线参考，不同厂家/地区/季节会有浮动。**每次采购前必须向当前供应商确认最新货期**，表格仅用于倒排计划的初步估算。

**Q6：付款方式里"账期"和"授信"有什么区别？**
A：账期 = 先收货后付款（如货到 30 天内付清），依赖长期合作信任；授信 = 供应商给你一个信用额度（如 100 万），额度内可以先发货后结算，超额度须先付款。两者都是"先货后款"的变体，但授信有明确上限、更适合大型设备集中采购。

**Q7：质保金一般扣多少？什么时候退？**
A：通常合同总额的 **3%–5%** 作为质保金，质保期 **1–2 年**。期满无重大质量争议 + 完成竣工验收备案后释放。可谈"阶段释放"（满 1 年放一半）以降低双方资金压力——这点可在节点 5 签合同时写入。

## 合规边界（必守）

- **脱敏**：项目名用"某 X 级医院净化项目"等；供应商仅标"国产一线/二线/进口高端"等档次，不写真实商号、联系人、合同价、内部额度。
- **不提供违规方案**：串标、围标、回扣、规避招投标等一律不生成。
- **国标依据**：引用 GB50333（医院洁净手术部）、GB51039（综合医院建筑）、GB50751（医用气体）等时注明版本年号。
- **资质与验收**：医疗净化强依赖净化工程专业承包/机电安装资质与验收规范，决策前建议核对当地卫健/住建要求。
- 本技能内容均为脱敏后的行业通用方法论，不承载任何原任职单位的专有商业数据。
