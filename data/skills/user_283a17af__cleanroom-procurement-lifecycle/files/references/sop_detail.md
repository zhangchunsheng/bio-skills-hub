# 采购全生命周期 SOP · 节点详情与采集指引

> 配套 `SKILL.md` 的深入参考。各节点为通用方法论框架，已结合一线实战细节填充（脱敏整理）。
> 全程脱敏：不出现真实项目名、供应商商号、合同价、内部额度。

## 节点 1 · 投标阶段 · 采购前置介入

- **动作**：从投标阶段前置介入，分三阶段配合，使报价有真实成本与可落地产品支撑。
- **三阶段配合**：
  1. **设计时期—供材规格与性能输入**：为设计部门提供供应商材料的**产品规格**（哪些为标准型号、哪些可在一定范围定制；尤其暖通设备、风机盘管、管道、阀门、水泵、分体式空调多为标准产品；多联机、模块机有标准产品也可按模数拼组）与**性能说明**（实际产品性能须 ≥ 设计要求，一旦小于即不满足）。目的：避免设计师凭空设想出不存在的产品/规格，导致后期买不到或需额外定制，抬高成本、侵蚀项目预计利润。
  2. **投标成本询价**：成本预算部门依设计部图纸出具详细工程材料清单，采购据此找各厂家报价。要点：厂家产品参数须满足清单要求、不得低于设计；报价须明确**是否含税、税点多少、是否含运费**。
  3. **投标资料授权**：招投标部门依成本预算部门的总成本 + 招标方预算测算差价/利润，满足公司盈利点才参与投标；此时要求采购配合，将项目中主要设备/材料（如 PVC 地板、净化循环空调机组、UPS 不间断电源、橡塑保温棉、无影灯/LED 子母灯、医用自动趟门等）报备对应品牌厂家/代理商，由其提供**唯一授权书**（该厂家该设备在本项目仅授权我方一家、不得授权其他同项目投标方；模板通常用厂家自有样式）、**参数响应表**、**售后服务承诺书**；多联机、分体式空调、节水型洁具、UPS 等还需**有效期内节能认证证书**。
- **检查清单**：
  - [ ] 设计输入的产品规格/性能是否真实可得（非凭空设想）
  - [ ] 投标询价是否含完整报价口径（含税 / 税点 / 含运）
  - [ ] 主要设备/材料的唯一授权、参数响应、售后承诺、节能认证是否齐备

## 节点 2 · 询比核算成本

- **动作**：基于清单做询价比对，核算综合成本（货期、物流、安装配合、税票），形成报价基线。
- **为什么中标后还要再次核价**：本环节针对**已中标项目**。投标时虽已成本核算，但投标到中标进场施工时间跨度长（最短数月、最长数年），原材料价格波动、且可能经历二次图纸变更，故须按成本部门提供的最新材料与工程量清单**再次询价核价**。
- **检查清单**：
  - [ ] 比价是否含到岸价（含税、含运、含安装配合）
  - [ ] 各专业成本占比是否匡算（暖通与医疗设备通常最高）
  - [ ] 长交期设备的资金占用是否计入
  - [ ] 是否基于最新版图纸/清单二次核价（非沿用投标价）
- **交付物**：`成本估算框架.md`、`供应商比价矩阵.md`
- **成本建模维度（综合成本，不止裸价）**：
  - 综合成本 = 裸价 + 货期资金占用（长交期设备早付占用资金）+ 物流（直达/中转/上楼费）+ 安装配合（是否需厂家指导、是否含辅材）+ 税票（专票 13% 可抵扣，净成本更低；普票全额计入）。
  - 同型号设备，专票比普票净成本低约 13% 进项，比价须同口径（都按含税净成本或都按含税总价，不可混比）。
  - 长交期/大金额设备：资金占用成本（按工期折算资金成本）须单列，避免"裸价低但占款贵"。
- **各专业成本占比经验区间（洁净手术部类项目通用匡算，非某项目实绩）**：
  - 暖通：约 25%–35%（净化空调机组 + 风机过滤 + 风管，通常占比最高）
  - 医疗设备：约 20%–30%（吊塔、无影灯、手术床、显示/转播系统）
  - 装饰：约 15%–20%（洁净板、地面、门窗、圆弧）
  - 电气：约 10%–15%（配电、照明、自控/弱电）
  - 给排水：约 5%–8%（给水、排水、纯水）
  - 医气：约 5%–8%（中心供氧、负压、压缩空气）
  - 注：ICU / 实验室 / 生殖中心等结构不同；此为投标匡算锚点，定标后以实际询价回填 `成本估算框架.md`。

## 节点 3 · 中标后开工前 · 二次品牌报备确认

- **动作**：单项材料/设备报送样品与资料，做进场前品牌与参数确认。分两种情形：
  - **情形一（投标已锁品牌）**：投标即以具体品牌描述（非"国标优质"），且甲方不允许变更 → 按投标品牌找对应厂家/渠道商准备**一式三份**资料与样品送项目部，由其报送监理、甲方审批存档即可。
  - **情形二（未锁或允许变更）**：投标未指定品牌，或指定但甲方允许变更、或监理要求多家 → 联系同设备/材料的多家厂家，通常每类材料/设备需提供**三家**品牌与样品报送监理、甲方；经几轮周转，最终每类材料/设备只留存一家品牌作为后续供应商。
- **检查清单**：
  - [ ] 情形判定（锁品牌 / 多家报备）是否明确
  - [ ] 每家是否报送样品 + 完整资料（检测报告/合格证/授权）
  - [ ] 三家是否覆盖不同档次（国产一线/二线/进口）以留选择空间
  - [ ] 报备被否的备选方案是否就绪
- **交付物**：`供应商比价矩阵.md`
- **三家筛选标准（三档梯度）**：
  - 国产一线 / 国产二线 / 进口高端 各选至少 1 家，形成"价格—档次"梯度，留选择空间。
  - 同档内比：原厂授权完整性、本地服务能力、近 2 年同类业绩、账期配合度。
  - 每档预埋 1 家备份（报备被否可即时顶上，不空档）。
- **样品 / 资料审核要点**：
  - 检测报告：须 CMA/CNAS 资质机构出具、在有效期内、参数覆盖招标要求。
  - 合格证 + 出厂检验报告：批次对应，防串货。
  - 原厂授权书：保障正品与售后；进口设备查代理链完整性。
  - 关键参数第三方认证（如过滤器效率、防火等级、抗菌等级）与主材一致性核对。
- **报备被否的应对**：
  - 同档备选顶替；或参数微调（不降低招标标的）换可报备型号。
  - 提前与甲方/监理沟通报备口径，避免进场前卡壳。
  - 重大偏差须走变更流程，不擅自替换影响验收的关键材料。

> **行业现实注记（潜规则 · 懂者自懂）**：在中小净化工程商内部，因各品类供应商已在前期货期与账期绑定中高度收敛（每品类通常固定合作 1–2 家，以换取更优价格与账期），许多「招标 / 比价」流程在实质上更接近**合规留痕而非真竞争**——真实合作方多数已在关系与账期层面内定，额外参与的几家多为捧场、卖人情。
> 因此本节点（连同节点 2 询比）的实操要义是：**评标重点放在实质维度，而非表面低价**。即①技术参数是否如实响应招标标的、能否真正落地；②履约风险（货期确定性、产能保障、售后可达性）；③账期与资金占用的可控性。表面比价仅作合规口径与价格锚，不宜作为唯一或主导定标依据。本条为一线方法论注记，不点名任何主体，亦非对合规流程的否定。

## 节点 4 · 开工后 · 排单申请计划

- **动作**：核对施工总计划，结合材料/设备货期倒排采购与进场节点。
- **排单逻辑**：施工进度由项目部项目经理敲定，并同步制定各施工节点所需材料；采购按各材料/设备**货期**（需一份**常用材料设备货期表**作基准，见 `templates/常用材料设备货期表.md`），**倒推**项目部具体申请日，形成排单计划。
- **检查清单**：
  - [ ] 关键路径设备货期是否早于进场节点 1.5–2 倍缓冲
  - [ ] 是否存在多专业同时到货的仓库容量冲突
  - [ ] 长周期设备是否设预警阈值（如货期 > 8 周）
- **交付物**：`BOM拆解表.md`（锁单时机列）、`常用材料设备货期表.md`

## 节点 5 · 过程商务 · 谈单 / 开发 / 签合同

- **动作**：完成谈单、供应商开发与合同签订。合同洽谈须重点把控**六点**：
  1. **买对**：仔细核对材料/设备参数、型号、数量。
  2. **货期起点**：明确货期多长、从何时起算（合同签订 / 合同签章完毕 / 预付款到账 / 全款后发货，各情形起算点不同）。
  3. **付款方式**：账期（货到多少工作日内付款）/ 分批（预付多少、发货前付多少、到货验收后付多少、是否预留质保金）/ 全款（款到发货）。
  4. **售后质保**：约定是否合理。
  5. **违约处罚**：明确违约如何处罚。
  6. **文本准确**：合同无错别字，公司名称、产品、金额大小写、开户行/账号等无误。
- **检查清单**：
  - [ ] 六点是否逐条核对（买对 / 货期起点 / 付款 / 质保 / 违约 / 文本）
  - [ ] 甲指/甲供与自采边界是否厘清
  - [ ] 关键设备是否先锁交期再谈价

## 节点 6 · 付款与履约

- **动作**：预付款→发货→验收→尾款；部分设备预留质保金。
- **付款方式全貌（按供应商类型区分）**：
  - **老/长期供应商**：多有账期，货到多少工作日内付款，或按自然月/季度/年付款；需每月固定时间对账后付款。
  - **贵重/大型设备供应商**：常要求先预付后生产、发货前付清（除预留质保金）；或给予**授信额度**（如 100 万授信，超额度须付超额货款才发货，未超可先发货、货到验收合格后一月内付款）。
  - **新开发供应商 / 临时应急**：缺乏信任，通常要求全款发货，此类通常有一定风险。
- **检查清单**：
  - [ ] 预付款比例是否足以启动排产
  - [ ] 到货收货验收流程是否闭环（出厂检/到货检）
  - [ ] 质保金释放条件是否写入合同
- **付款节奏与供货风险挂钩**：
  - 标准节奏：预付款 20%–30%（启动排产）→ 发货款/提货款 30%–40%（凭出厂检/提单）→ 到货验收款 25%–30% → 质保金 3%–5%（质保期满释放）。
  - 关键设备（长交期/大金额/影响验收）：提高预付款锁定产能与交期，必要时"先款后货"争取优先排产。
  - 标准化/现货物资：争取货到付款或月结账期，降低资金占用。
  - 原则：风险越高（交期越不确定、定制越强）越前置付款以锁资源；现货越标准越后付以压占用。
- **质保金释放条件（写入合同）**：
  - 质保期通常 1–2 年；期满 + 无重大质量争议 + 完成最终验收/竣工备案后释放。
  - 可约定"阶段性释放"（如满 1 年释放一半）以降供应商资金压力、促配合。

## 节点 7 · 突发加急材料处理

- **动作**：建立加急响应通道，按材料类别选择路径，优先保关键路径不停工。
- **按材料类别的加急路径**：
  - **常规材料（厂家有库存）**：可走加急、调拨/借调，协调后走专车及时到货。
  - **兄弟项目有同料**：内部协商走调拨。
  - **非常规材料**：优先考虑厂家能否插队赶工（通常增加一笔费用）；或更换有货的其他品牌，向甲方说明缘由走品牌变更。
  - **零散少量常规材料**：授权项目部自行使用备用金就地采买，注意价格在合理范围内。
- **检查清单**：
  - [ ] 现货调配/就近调货/升级物流三条通道是否可用
  - [ ] 加急决策是否与施工/商务协同（成本 vs 停工损失）
- **典型加急场景**：
  - 关键路径设备货期突变（厂家排产冲突、物流/海关延误）。
  - 设计变更导致增补物料（线缆、阀门、矿棉、密封胶等）。
  - 验收前某批次复试不合格需替换。
  - 甲方临时赶工/提前验收节点。
- **三级响应通道（按成本与时效排序）**：
  1. 现货调配（同城/就近库存，最快）
  2. 就近调货（兄弟项目/区域仓调拨）
  3. 升级物流（专车/空运，成本最高）
- **协同决策（成本 vs 停工损失）**：
  - 加急成本 < 停工待料窝工损失 + 违约风险时，优先保关键路径节点。
  - 与施工负责人确认关键路径与最晚进场时点；与商务确认预算余量与授权额度。
  - 加急单须留痕（原因、决策人、溢价幅度），便于结算追溯与复盘。

## 节点 8 · 现场管理 · 仓库布置 / 签发物料

- **动作**：规划现场仓库，建立物料签发流程，领用可追溯。
- **仓库布置（两类位置）**：
  - ① 活动板房生活办公区：用集装箱搭建成仓库，按材料贵重程度、是否易损分仓管理，配多处摄像头 24h 监控。
  - ② 施工区域内选定房间：注意各施工区域路程合适、减少二次搬运时效；装好门窗、配摄像头做成仓库。**重物须分散靠近结构柱梁摆放**，尤其铅板（密度大、极重），集中堆放易造成建筑局部结构性破坏。
  - 量大又重、价值低的物料（硅酸钙板、石膏板、瓷砖等）一般在施工区域内分类堆放（设存放点即可），不单独设上锁仓库。
- **签发流程控制点**：须劳务班组公司/老板授权指定 **1–2 人**签领材料（严禁其他人代领）；核对数量、型号无误后，项目部材料员与领料人**双签**，项目经理加签，底单存档。
- **检查清单**：
  - [ ] 仓库分区（待验/合格/不合格）、防潮防损、监控是否到位
  - [ ] 重物是否分散靠结构柱梁（尤其铅板）
  - [ ] 签发是否授权专人、双签+项目经理加签、底单存档

## 节点 9 · 物料盘点

- **动作**：按月/季度盘点，核对账实。
- **目标与风险**：日常规范管理下，入库出库应完全吻合；若 ERP 系统记录与现场实际明显出入，需防范两点：
  1. **惰性与遗忘**：时间久了项目部和班组出现惰性/忘性，领料不签单、忘记签单。
  2. **监守自盗**：警惕模仿代签。
- **检查清单**：
  - [ ] 盘点差异（超领/丢失/积压）是否及时发现
  - [ ] ERP 与现场记录出入是否排查上述两类成因

## 节点 10 · 完工前 · 剩余材料归类

- **动作**：统计剩余材料，可利用的归其他部位/项目；不可利用的合规处理。
- **可再利用判定标准**：
  1. 外观好（不脏乱差、无锈迹）；
  2. 功能完整、无故障；
  3. 如有配件，配件齐全。
- **废料合规处置与残值回收**：低价值物料找废品回收站处理，记录过磅信息、付款截图，费用交公司指定账号；可利用的，调拨其他项目，或沟通厂家是否回收，或考虑同项目其他单位是否可用、打折卖给对方（费用由公司收走）。
- **检查清单**：
  - [ ] 可再利用三标准是否逐条核对
  - [ ] 废料处置是否合规、残值是否回收入账

## 节点 11 · 竣工验收前 · 资料准备

- **动作**：备齐资料，便于移交甲方、监理/总包及城建档案馆。
- **交付标准**：常规普通材料—合格证、检测报告（注意在有效期内）；设备类—合格证、检测报告、使用说明书、售后保障书/卡。
- **交付份数**：甲方必须原件；其余单位视情况可复印/彩印；若城市建设档案馆也需要，一般也要原件（原件也可为复印件加盖鲜章）。
- **常见缺项**：合格证、使用说明书、售后保障书/卡易缺失（施工保管不当或无收集意识）；交付时难寻原件，尤其定制设备合格证独一份、难补办。
- **检查清单**：
  - [ ] 各类资料份数是否满足移交（甲方/监理/总包/城建档案馆）
  - [ ] 易缺项（说明书、保障卡、合格证原件）是否预检留底

## 节点 12 · 施工完成 · 清场与维保移交（含厂家联动）

- **动作**：剩余材料清场；移交后进入维保，留部分材料给现场售后备用，并完成厂家售后方式汇总。
- **清场与调试**：项目联合验收竣工前通常全面保洁、清理交付区域；过后进行设备调试（采购联系相关厂家到场或远程指导）、空气洁净度检测（大公司多自有检测设备与人员，无则请第三方）。
- **维保备料与厂家联动**：现场售后维保人员（第三方外包与甲方主管维护人员）仓库通常较小；若有多余材料，可预留几卷不同色电线、几根线材、若干开关插座。最后将相关设备厂家的**售后方式整理汇总，书面交现场售后维保人员，一式两份签字确认、回执存档**。（原节点 13「厂家联动」已并入本节点：售后方式汇总即厂家服务链路的落点。）
- **检查清单**：
  - [ ] 备料品类/数量是否按易损件逻辑预留（线缆/线材/开关插座）
  - [ ] 厂家售后方式是否汇总书面移交、双签存档
  - [ ] 维保响应机制与责任边界是否明确

## 节点 13 · （已合并）

- 原「设备维修·厂家联动」经确认并入节点 12「清场与维保移交」，不再单列。其服务链路与保外成本预判落点为：设备调试联系厂家、售后方式汇总书面移交。
