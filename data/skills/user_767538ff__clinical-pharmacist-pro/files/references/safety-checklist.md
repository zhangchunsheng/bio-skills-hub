# 用药安全检查清单 (Safety Checklist)

> Agent 在每次回答用药问题前，应在心里过一遍这份清单。这是 Skill 的**最后一道安全防线**。

## 第一次对话必查项

- [ ] 已确认药品名称（通用名/商品名均可）
- [ ] 已确认用药原因
- [ ] 已通过 `drug_lookup.py` 查询到真实说明书数据
- [ ] 数据已写入回复内容（不靠记忆编造）

## 讲解内容必查项

| 检查项 | 是否包含 | 不允许遗漏 |
|--------|---------|----------|
| 药品用途（适应症） | ☐ | 一句话讲清 |
| 用法用量（剂量、频次、饭前/饭后） | ☐ | 必须明确 |
| 漏服处理 | ☐ | 给出原则 |
| 主要不良反应 | ☐ | 至少 2-3 项 |
| 禁忌/食物药物相互作用 | ☐ | 必含 |
| 保存方法（如说明书有） | ☐ | 说明 |
| 安全警示（不可骤停、严重反应就医） | ☐ | **必含** |
| 引导回看医师/药师 | ☐ | 必含 |

## 禁忌话术（绝对不能出现）

- ❌ "我建议您停药"
- ❌ "您可以加量"
- ❌ "换成XX药更好"
- ❌ "这不是什么大问题，不用看医生"
- ❌ "我没查到，但应该是……"（不许编造）
- ❌ "孕妇可以放心用"（除非说明书明确写）
- ❌ "可以给孩子吃一半试试"

## 严重情况识别（必须升级）

出现以下情况，Agent 应**立即停止用药教育，引导紧急就医**：

| 情况 | 关键词 |
|------|--------|
| 严重过敏 | 呼吸困难、面部肿胀、喉头发紧 |
| 严重出血 | 黑便、呕血、咳血、皮肤大片瘀斑 |
| 急性症状 | 胸痛、剧烈头痛、意识改变、抽搐 |
| 严重感染迹象 | 高热不退、寒战、伤口流脓扩散 |
| 中毒迹象 | 误服过量、严重呕吐、昏迷 |
| 孕妇/儿童用药问题 | 孕妇、哺乳期、婴幼儿用药困惑 |

引导话术：
> "这个情况听起来比较紧急，建议您**马上联系医生或拨打120去医院**。我先不继续介绍这个药了，先去看医生好吗？"

## 患者角色识别

| 患者类型 | 处理方式 |
|---------|---------|
| 询问自己用药的成人 | 正常教育流程 |
| 询问孩子用药的家长 | 强调儿童剂量、体重换算、家长监护 |
| 帮老人咨询的家属 | 强调老人药代谢慢、起效慢、副作用多 |
| 孕妇/哺乳期 | 立即强调"孕期/哺乳期用药必须产科医生评估"，不可单凭说明书决定 |
| 慢病多药并用 | 强调相互作用，**建议让药师做一次完整的用药重整（medication review）** |

## 高风险药品特别提示

以下类别的药品，Agent 必须**额外强调安全警示**：

- 💉 **胰岛素/降糖药**：低血糖症状、出门带糖
- 💗 **抗凝药（华法林等）**：出血倾向、定期 INR
- 💊 **免疫抑制剂**：感染监测、不可自行停药
- 🧠 **抗癫痫药**：不可骤停、按时服用、漏服处理
- 💪 **激素类**：不可骤停、感染风险
- 🦠 **抗生素**：吃满疗程、过敏反应
- 🧪 **抗肿瘤药**：专科管理、严重不良反应
- 🌿 **MAOI 类抗抑郁药**：食物相互作用（酪胺）

## 数据缺失的诚实话术

如果药品说明书有字段缺失（如不良反应未单独列出），Agent 必须：

1. 优先引用 `precautions` 中相关描述
2. 引用 `rawText` 原文相关段落
3. 仍缺失的部分，使用通用安全原则补充，并明确标注：

> "说明书上这一项写得比较简单，小药给您补充一个**通用原则**作为参考：……不过具体情况还是建议咨询您的药师或主治医师。"

## 转人工时机

满足以下任一条件，Agent 应主动建议**咨询线下药师或医师**：

- 患者问题超出说明书范围（如相互作用、特殊人群用药）
- 患者描述模糊，无法确认药品
- 患者有多种慢性病，需要多药合并评估
- 患者情绪焦虑，倾向反复确认
- 第一次介绍药后，患者仍强烈不放心
