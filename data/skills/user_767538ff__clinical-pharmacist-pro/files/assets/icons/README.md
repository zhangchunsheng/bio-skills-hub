# 表情符号与图标速查

> Agent 在讲解时使用这些表情符号增加亲和力，但要**适度**——一段话 1-2 个即可，不要堆叠。

## 推荐使用（讲解类）

| 图标 | 用途 | 示例 |
|------|------|------|
| 📌 | 用途说明 | 📌 这个药是干什么的 |
| 💊 | 用法用量 | 💊 怎么吃 |
| ⏰ | 漏服处理 | ⏰ 漏服了怎么办 |
| 😟 | 不良反应 | 😟 可能的不良反应 |
| 🚫 | 禁忌/避免 | 🚫 要避免什么 |
| 🏠 | 保存方法 | 🏠 怎么保存 |
| ⚠️ | 安全警示 | ⚠️ 小药叮嘱 |
| 😊 | 温暖/友好 | 收尾问候 |
| 💡 | 提醒/小贴士 | 💡 小药解释 |

## 推荐使用（比喻类）

| 图标 | 用途 | 适用比喻 |
|------|------|---------|
| 🛡️ | 保护 | "肝脏保镖"、"血管放松师" |
| 👮 | 警察 | "细菌警察"、"血管保安" |
| 🌱 | 生长 | 适合生长激素、维生素类 |
| 🔥 | 火/炎症 | 适合抗炎药 |
| 🧹 | 清理 | 适合祛痰药、通血管药 |
| 🚰 | 排水 | 适合利尿药 |
| 🧊 | 冷/降温 | 适合退烧药 |
| 🤝 | 配合 | "医生和药师一起帮您" |

## 推荐使用（响应类）

| 图标 | 用途 |
|------|------|
| ✅ | 已确认/已查好 |
| 🙏 | 致谢/抱歉 |
| 📞 | 联系医生 |
| 🏥 | 去医院 |
| 📋 | 列清单 |
| 📷 | 拍照 |
| 💪 | 鼓励 |

## 谨慎使用

| 图标 | 注意 |
|------|------|
| 😱 | 容易引起焦虑，尽量不用 |
| 💀 | 严禁使用 |
| 💊 反复 | 不要连续多句都带 |

## 演示模板（讲解一段完整教育）

```
好嘞，我来给您说说～ 😊

📌 这个药是干什么的
（1-2 句话讲清用途）

💊 怎么吃
（剂量、频次、饭前/饭后）

⏰ 漏服了怎么办
（说明书有按说明书；通用原则补充）

😟 可能的不良反应
（2-3 项 + 应对办法）

🚫 要避免什么
（食物/药物相互作用、禁忌）

🏠 怎么保存
（如说明书有）

⚠️ 小药叮嘱：
- 不可自行停药/调量
- 出现 X、Y、Z 立即联系医生
- 定期复查

您还有什么不清楚的吗？😊 还有别的药想了解吗？
```
