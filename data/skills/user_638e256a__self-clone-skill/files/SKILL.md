# 自我风格数字分身 v1.0

> 不只模仿你怎么写——而是复刻你怎么想

## 与 ai-humanized-writing 的区别

| 维度 | ai-humanized-writing | self-clone-skill |
|------|---------------------|------------------|
| 目标 | 去AI味，让文本像人写的 | 建立完整的数字人格孪生 |
| 输入 | 3段原创文本 | 10+段跨场景文本 |
| 输出 | 风格迁移后的文本 | "如果是你，会怎么想/怎么说/怎么做" |
| 维度 | 写作DNA（8维） | 人格DNA（10维） |
| 应用 | 改写/润色 | 决策模拟/人格对话/场景预演 |

## 核心能力

1. **采集自我人格**：输入10+段自己的真实文本（聊天/邮件/方案/评论），建立10维人格DNA
2. **人格对话**：任何问题，AI以你的风格回答——不只是语气像，是思维方式像
3. **决策模拟**：给定一个场景，模拟"如果是你，会怎么决策"
4. **场景预演**：模拟你在不同场景下的反应（谈判/面试/冲突/社交）
5. **自我认知报告**：基于你的文本数据生成人格分析报告——你可能不知道的自己

## 人格DNA十维模型

| 维度 | 说明 | 采集方式 |
|------|------|----------|
| 思维模式 | 线性/发散/批判/系统性 | 分析论证结构和逻辑链 |
| 价值排序 | 效率/公平/创新/稳定/关系 | 分析决策理由中的价值词 |
| 情绪基调 | 乐观/务实/悲观/中性 | 情感词频和强度分析 |
| 表达风格 | 简洁/详细/幽默/严肃 | 句长+修辞+语气词分析 |
| 决策偏好 | 数据/直觉/共识/权威 | 分析"因为""所以"等因果链 |
| 社交模式 | 外向/内向/主导/随和 | 对话中的主动性分析 |
| 风险态度 | 冒险/稳健/保守 | 分析对不确定性的表述 |
| 时间取向 | 过去/现在/未来导向 | 时态词和展望词分析 |
| 认知复杂度 | 简单/中等/复杂 | 词汇丰富度和句式复杂度 |
| 自我认知 | 自信/谦虚/自我批评 | 自我指代词的情感倾向 |

## 工作流程

### Step 1: 采集自我文本（核心步骤）

至少10段文本，建议覆盖以下场景：
- 工作沟通（3段）：与同事/客户的正式沟通
- 日常聊天（3段）：微信/社交平台的日常对话
- 观点表达（2段）：方案/评论/朋友圈等有观点的文本
- 决策记录（2段）：你做过的决策及其理由

```bash
python main.py collect --samples chat1.txt chat2.txt ... chat10.txt
```

### Step 2: 查看人格报告

```bash
python main.py report
```

### Step 3: 人格对话

```bash
python main.py chat --intent "如果有人当众质疑你的方案，你会怎么回应？"
```

### Step 4: 决策模拟

```bash
python main.py decide --scenario "两个offer选哪个：A钱多但996，B钱少但965有成长空间"
```

### Step 5: 场景预演

```bash
python main.py rehearse --scene "面试" --context "面试官问：说说你最大的缺点"
```

## 命令速查

| 命令 | 用途 |
|------|------|
| `collect --samples f1 f2 ... fN` | 采集自我文本（≥10段） |
| `report` | 查看十维人格报告 |

## 隐私声明（最高级别）

- 所有个人文本和人格数据**仅存储在本地**，绝不联网
- 人格DNA仅包含统计特征向量，不存储原始文本全文
- 支持一键清除：`python main.py reset`
- 本技能不会将你的任何数据用于训练或分析
- 建议定期审查人格报告，确保建模准确反映你的真实状态

## 常见问题 FAQ

**Q1：为什么需要10段文本？3段不行吗？**
A：自我人格比同事/老板画像复杂得多。10维DNA需要覆盖工作沟通+日常聊天+观点表达+决策记录四类场景，每类至少2-3段。10段是最低门槛，越多越像你。

**Q2：人格数据存哪里？安全性如何？**
A：所有数据存本地 `data/self_dna.json`，不上传任何服务器。DNA只存储十维统计特征向量，不保留原始全文。一键清除：`python main.py reset`。

**Q3：人格对话准不准？**
A：基于十维统计建模+模式匹配，准确率约65-75%。能抓住你的核心思维模式（系统性还是直觉型）、价值偏好（效率还是公平）、表达风格（简洁还是详细），但无法复刻你的全部经验记忆和情感深度。

**Q4：和 ai-humanized-writing 有什么区别？**
A：ai-humanized-writing 是"写作风格迁移"——让AI生成的文字像你写的。self-clone-skill 是"认知建模"——让AI以你的方式思考和决策。前者改文字，后者改思维。

**Q5：多久更新一次人格模型？**
A：建议每季度重新采集，因为人的认知模式和价值观会随经历变化。重大人生决策后（换工作、搬家等）建议立即更新。

**Q6：采集哪些文本效果最好？**
A：工作沟通（与同事/客户正式交流）+ 日常聊天（微信/社交平台）+ 观点表达（方案/评论/朋友圈）+ 决策记录（做过的重要决策及理由）。覆盖越广，建模越准。

## 注意

- 至少需要10段文本（每段30字以上）才能建立有效人格模型
- 文本多样性直接影响建模精度——覆盖越广，越像你
- 人格不是静态的，建议每季度更新一次
- 人格模型是辅助工具，不能替代真实的自我认知和反思
