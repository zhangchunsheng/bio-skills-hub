# 世界观管理

## 三层规则体系

```text
硬规则（不可违反）
  ├─ 能力体系
  ├─ 时代背景
  ├─ 组织制度
  ├─ 物理/魔法边界
  └─ 因果逻辑
      ↓
软规则（可扩展）
  ├─ 风俗
  ├─ 地名
  ├─ 支线组织
  ├─ 配角背景
  └─ 局部生态
      ↓
待定规则（未确认）
  ├─ 用户尚未敲定的设定
  ├─ 不能当成事实写死
  └─ 必须显式标注
```

## 记忆文件中的标准写法

```markdown
## 世界观

### 硬规则（不可违反）

1. 主角能力觉醒需要「血脉 + 痛苦刺激」双重触发，单一条件无效。
2. 星际航行最长 30 天，超过则触发时空畸变。
3. 顾闻在前 10 章不能向林澈明确透露父亲相关信息。

### 软规则（可扩展）

1. 星港由七个环形城区组成，越靠内层权限越高。
2. 内务局是星港的情报机构，行事低调。
3. 黑匣子记录可被剪裁但不可伪造。

### 待定规则（未确认）

1. 第三卷的「新星域」是否引入新势力？
2. 黑匣子剪裁的判定是否需要技术门槛？
```

## 硬规则优先级

> 生成章节时，硬规则优先级高于临场灵感。

如果临场灵感与硬规则冲突，必须：

1. 放弃临场灵感
2. 在章节自检卡中说明「本段未涉及硬规则」
3. 或修改硬规则（需用户确认）

## 自动校验工具

```bash
# 检测硬规则是否被章节违反
python3 scripts/world-rules-lint.py \
  --memory memory/novels/{slug}.md \
  --chapter chapter-008.md
```

输出：

- 已违反的硬规则及对应段落
- 建议的修改方向
- 是否阻塞写入（默认是）

## 流派特定的世界观模板

| 流派 | 必填硬规则 | 详见 |
|---|---|---|
| 玄幻 | 修炼体系、境界分层、突破条件 | `references/genres/xianxia.md` |
| 都市 | 现实时代、行业背景、社会制度 | `references/genres/urban.md` |
| 言情 | 关系伦理、社会背景、情感边界 | `references/genres/romance.md` |
| 悬疑 | 案件规则、推理逻辑、动机合理性 | `references/genres/mystery.md` |
| 历史 | 历史事件、时代制度、人物原型 | `references/genres/historical.md` |
| 科幻 | 物理规则、技术边界、伦理边界 | `references/genres/scifi.md` |

## 协作中的世界观变更

多人协作时，世界观变更流程：

1. **提议**：「提议修改硬规则 #N：{原规则} → {新规则}，原因是 {理由}」
2. **影响评估**：列出受影响的章节、人物、伏笔
3. **决策**：主线作者 + 世界观维护者共同决定
4. **记录**：在记忆文件的「待确认问题」中追加决策记录
5. **回溯**：评估是否需要回溯修改已写章节

详见 `references/collab-workflow.md`。
