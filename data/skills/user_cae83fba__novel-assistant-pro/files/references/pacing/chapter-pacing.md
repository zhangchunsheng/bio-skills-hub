# 章节节拍规划（chapter-pacing）

> v2.0.0 新增。每章必须有"目标-阻力-变化-反馈-钩子"五要素。

## 五要素定义

| 要素 | 含义 |
|---|---|
| 目标（Goal） | 主角本章想达成什么？ |
| 阻力（Obstacle） | 是什么阻止他达成目标？ |
| 变化（Change） | 本章结束时，主角的状态发生了什么变化？ |
| 反馈（Feedback） | 主角对变化的反应是什么？ |
| 钩子（Hook） | 章末给读者的悬念是什么？ |

## 五要素检查表

每章写完后自检：

```markdown
### 章节节拍卡（第 N 章）

- 目标：{主角本章目标}
- 阻力：{阻力来源}
- 变化：{本章结束状态}
- 反馈：{主角反应}
- 钩子：{章末悬念}
```

## 自动评分脚本

```bash
python3 scripts/chapter-pacing-report.py \
  --memory memory/novels/{slug}.md \
  --chapter chapter-008.md \
  --output reports/pacing-008.md
```

输出：

```markdown
=== 章节节拍诊断（第 8 章）===

五要素检查：
  ✓ 目标：明确（林澈想追查黑匣子）
  ✓ 阻力：清晰（顾闻拒绝透露更多）
  ✓ 变化：明显（林澈首次直接质疑顾闻）
  - 反馈：略弱（缺少主角内心戏）
  ✓ 钩子：清晰（顾闻的反问）

节拍分：7/10（合格）

修改建议：
  - 加入林澈的内心戏（反馈维度）
  - 强化顾闻反问的"不寒而栗感"
```

## 五要素打分标准

| 要素 | 0-3 分 | 4-6 分 | 7-10 分 |
|---|---|---|---|
| 目标 | 无明确目标 | 目标基本明确 | 目标清晰、具体、强烈 |
| 阻力 | 无阻力或太弱 | 阻力存在但不够强 | 阻力强大、不可解决 |
| 变化 | 无变化 | 状态变化但小 | 状态变化显著、不可逆 |
| 反馈 | 无反馈 | 反馈过简 | 反馈深刻、情感真挚 |
| 钩子 | 无钩子 | 钩子较弱 | 钩子强烈、必读下一章 |

## 五要素与开篇三章的关系

开篇三章的五要素应该：

- 第 1 章：目标清晰、阻力出现、变化显著、反馈强烈、钩子爆炸
- 第 2 章：目标升级、阻力增强、变化累积、反馈深化、钩子延伸
- 第 3 章：目标转向、阻力反转、变化转折、反馈爆发、钩子收束

## 节奏与节拍的关系

节奏是章节间的密度分布，节拍是单章内的五要素结构。

| 节奏类型 | 表现 | 适合流派 |
|---|---|---|
| 慢热 | 每章节拍松散、变化小 | 历史、文学 |
| 强情节 | 每章节拍紧凑、变化大 | 起点中文网爽文 |
| 高爽点 | 每 3 章一次大变化 | 番茄小说爽文 |
| 悬疑递进 | 每章钩子强烈 | 悬疑、推理 |
| 史诗 | 长卷累积变化 | 玄幻、科幻 |

## 跨章节节拍链

```markdown
### 章节节拍链（第 1-5 章）

第 1 章：林澈接手爆炸案 → 调查开始
  ↓
第 2 章：发现残片异常 → 调查深入
  ↓
第 3 章：黑匣子出现顾闻识别码 → 矛盾激化
  ↓
第 4 章：内务局警告 → 阻力升级
  ↓
第 5 章：林澈首次直面顾闻 → 高潮前夜
```

## 协作中的节拍卡

- 主线作者提供每章节拍卡草案
- 编辑 / 风格审计者审核
- 节拍卡与大纲保持一致
- 偏离节拍卡需在写作群说明

详见 `references/collab-workflow.md`。
