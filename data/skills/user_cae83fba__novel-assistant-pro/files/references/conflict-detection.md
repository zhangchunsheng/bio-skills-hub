# 剧情冲突检测

## 七项检查维度

当生成、续写或审查章节时，按以下 7 维度检查：

| 维度 | 含义 | 严重度 |
|---|---|---|
| 1. 人物能力突变 | 能力突然增强或遗忘 | 严重 |
| 2. 人物立场反转 | 立场无理由反转 | 严重 |
| 3. 事件因果断裂 | 因果链断裂 | 严重 |
| 4. 时间线冲突 | 时间无法成立 | 严重 |
| 5. 世界观硬规则违反 | 硬规则被违反 | 严重 |
| 6. 已回收伏笔重复 | 已回收伏笔被当新伏笔 | 中度 |
| 7. P1 伏笔长期未推进 | 关键伏笔被遗忘 | 中度 |

## 输出格式

```markdown
### 剧情冲突预警（chapter-NNN.md）

- 严重冲突：无 / 列出
- 中度疑点：无 / 列出
- 轻微可优化：无 / 列出
- 建议处理：
```

## 自动检测脚本

```bash
python3 scripts/conflict-detect.py \
  --memory memory/novels/{slug}.md \
  --chapter chapter-008.md
```

输出：

```text
=== 剧情冲突检测 ===

严重冲突（2 项）：
  [C001] chapter-008.md L23-L25
        主角在未获得"血脉 + 痛苦"双重触发的情况下使用能力 X
        违反硬规则 #1（能力觉醒需要双重触发）
        建议：加入触发场景，或修改硬规则（需用户确认）

  [C002] chapter-008.md L45-L48
        顾闻主动告诉林澈父亲相关信息
        违反硬规则 #3（顾闻在前 10 章不能明确透露）
        建议：将"明确透露"改为"暗示"

中度疑点（1 项）：
  [M001] F003（P2）已 4 章未推进
        建议在第 9-10 章推进或回收

轻微可优化（0 项）：

阻塞状态：必须修复 [C001] [C002] 才能继续
```

## 严重度判定

| 类型 | 处理 |
|---|---|
| 严重冲突 | 必须修复才能继续 |
| 中度疑点 | 提示用户，由用户决定 |
| 轻微可优化 | 输出建议但不阻塞 |

## 跨章一致性扫描

```bash
python3 scripts/conflict-detect.py \
  --memory memory/novels/{slug}.md \
  --chapter-range 5-10
```

扫描连续 5-10 章，输出一致性报告：

```text
=== 跨章一致性扫描（第 5-10 章）===

人物能力：
  ✓ 无突变

人物立场：
  ✓ 无反转

时间线：
  ✗ 冲突 1：第 7 章与第 8 章时间跳跃不一致

因果链：
  ✓ 完整

世界观硬规则：
  ✗ 冲突 1：第 9 章违反硬规则 #2（星际航行最长 30 天）
```

## 协作中的冲突解决

多人协作时：

1. 主线作者运行 conflict-detect.py 排查
2. 冲突列表发到写作群
3. 涉及硬规则变更的，主线作者 + 世界观维护者共同决策
4. 涉及人物立场变化的，主线作者 + 人物作者共同决策
5. 决策结果写入记忆文件

详见 `references/collab-workflow.md`。
