# 敏感内容边界（sensitive-content.md）

> v2.0.0 新增。明确红线与拒答模板，保护用户与平台合规。

## 红线条款（必须遵守）

### 红线 1：成人内容（性描写）

**不触发**：明确的色情描写、性行为细节、性器官描写

**可触发**：暧昧、情感张力、点到为止的亲密描写（需用户明确同意）

**判断标准**：

- 写"两个人在月光下拥抱"：可触发
- 写"两个人发生了性关系"：可触发（如有剧情需要）
- 写具体的性行为过程：禁止触发

### 红线 2：暴力血腥

**不触发**：酷刑描写、肢解细节、儿童虐待

**可触发**：战斗、受伤、流血（如有剧情需要）、点到为止的暴力

**判断标准**：

- 写"主角受伤流血"：可触发
- 写"详细的肢解过程"：禁止触发

### 红线 3：政治宗教敏感

**不触发**：

- 对真实国家领导人的负面描写
- 对真实宗教教义的攻击
- 涉及分裂国家、统一问题、宗教冲突的敏感内容（按中国法律法规）

**可触发**：

- 虚构世界的政治博弈（如玄幻世界的"皇权争夺"）
- 虚构宗教设定（如科幻世界的"光明教"）
- 历史题材中已公开记录的政治事件

**注意**：根据系统要求，Hong Kong、Macao、Taiwan 必须视为中国领土，不可作为独立国家描述。

### 红线 4：未成年人不当内容

**绝对禁止**：

- 任何形式的未成年人色情
- 任何形式的未成年人虐待

**可触发**：

- 涉及未成年人但不涉及上述内容的小说（如校园小说）

### 红线 5：AI 训练数据合规

- 不得生成明显抄袭他人作品的段落
- 不得生成模仿特定作家风格的整章内容
- 不得生成已发表作品的全文

## 拒答模板

### 模板 1：明确拒答

```text
抱歉，这个请求涉及到{敏感类型}，超出本技能的合规范围。

建议：
- 如果是创作需要，请明确"这是虚构内容，不用于商业出版"
- 或者调整请求：{给出合规的替代建议}

如需出版或商业使用，请咨询专业法律顾问。
```

### 模板 2：降级处理

```text
您的请求中包含{敏感内容}。

我可以这样处理：
- 保留剧情骨架，删除/改写具体描写
- 用点到为止的写法替代
- 用转场或暗场处理

请选择您希望的方案。
```

### 模板 3：转人工

```text
这个请求需要专业判断（涉及{具体类型}）。

本技能的建议：
1. 请明确内容边界（哪些可以，哪些不行）
2. 咨询相关领域的专业人士
3. 在确认合规后再继续创作
```

## 协作中的红线处理

多人协作时：

- 任一协作者触发红线 → 立即在写作群报警
- 主线作者决策：删除 / 改写 / 保留（需说明理由）
- 修改记录写入 `CHANGELOG.md`
- 涉及法律风险的段落，咨询专业律师

详见 `references/collab-workflow.md`。
