# 开篇留存诊断（first3-retention）

> v2.0.0 新增。开篇三章（黄金三章）决定 80% 的留存。本模块提供 4 维评分卡。

## 4 维评分卡

| 维度 | 分值 | 说明 |
|---|---|---|
| 钩子强度 | 0-10 | 章首 200 字能否抓住读者 |
| 主角处境 | 0-10 | 主角的处境是否清晰、是否有张力 |
| 欲望与异常 | 0-10 | 主角的欲望是什么？异常机制是什么？ |
| 信息密度 | 0-10 | 设定信息是否在情节中自然展开 |

## 维度 1：钩子强度（0-10）

### 评估标准

| 分值 | 钩子表现 |
|---|---|
| 0-2 | 章首平淡，无冲突无异常 |
| 3-5 | 章首有轻微冲突或悬念 |
| 6-8 | 章首有强烈冲突或意外 |
| 9-10 | 章首即爆点，读者无法停止 |

### 检查清单

- [ ] 章首 200 字内是否有具体场景？
- [ ] 是否有冲突 / 异常 / 悬念？
- [ ] 是否有具体的人物动作？
- [ ] 是否避免大段背景说明？
- [ ] 章末是否有钩子？

### 示例

低分示例：

```text
第 1 章

我叫林澈，今年 28 岁，是星港事故调查员。今天早上我接到一个任务……
```

（平淡，无冲突，无具体动作）

高分示例：

```text
第 1 章

黑匣子的指示灯在第 47 秒停止了闪烁。林澈的手指停在记录仪上。
这意味着它已经死了 47 秒。
但她五分钟前才把黑匣子从残骸里取出来。
```

（具体场景、异常机制、悬念）

## 维度 2：主角处境（0-10）

### 评估标准

| 分值 | 处境表现 |
|---|---|
| 0-2 | 主角处境模糊，缺乏代入基础 |
| 3-5 | 主角处境基本清晰，但缺乏张力 |
| 6-8 | 主角处境清晰且有张力（困境 / 对手 / 危机） |
| 9-10 | 主角处境清晰、紧迫、有多重张力 |

### 检查清单

- [ ] 主角是谁？（身份、年龄、阶段）
- [ ] 主角的当前处境是什么？
- [ ] 主角面临什么压力？（外部 + 内部）
- [ ] 主角的欲望是什么？
- [ ] 主角的核心矛盾是什么？

### 主角处境三要素

```text
欲望：主角想要什么？
障碍：是什么阻止他？
代价：失败会失去什么？
```

## 维度 3：欲望与异常（0-10）

### 评估标准

| 分值 | 异常机制 |
|---|---|
| 0-2 | 无明显异常或欲望 |
| 3-5 | 欲望或异常较弱 |
| 6-8 | 欲望 + 异常机制清晰 |
| 9-10 | 欲望强烈 + 异常机制独特 |

### 异常机制的类型

| 类型 | 示例 |
|---|---|
| 金手指 | 主角获得超能力 / 系统 / 重生 |
| 谜题 | 主角面临一个必须解开的谜 |
| 限时任务 | 主角面临时间压力 |
| 身份反转 | 主角发现自己不是普通人 |
| 关系冲突 | 主角面临复杂的人际冲突 |
| 道德困境 | 主角面临两难选择 |
| 失忆 / 替身 | 主角不知道自己是谁 |

### 检查清单

- [ ] 主角的异常机制是什么？
- [ ] 异常机制是否在第 1 章就揭示？
- [ ] 异常机制是否有"代价"？
- [ ] 异常机制是否独特（区别于同类作品）？

## 维度 4：信息密度（0-10）

### 评估标准

| 分值 | 信息密度 |
|---|---|
| 0-2 | 大段背景说明，缺乏情节 |
| 3-5 | 信息基本展开，但过于密集 |
| 6-8 | 信息在情节中自然展开 |
| 9-10 | 信息完全融入情节，几乎察觉不到"设定说明" |

### 检查清单

- [ ] 设定是否在情节中展开，而非大段说明？
- [ ] 信息是否分层（核心设定 → 细节设定 → 世界观背景）？
- [ ] 是否避免"信息倾倒"（一次性给读者太多设定）？
- [ ] 是否在第一章末留有"未揭示的设定"以吸引读者？

## 总分与判定

| 总分 | 判定 | 处理 |
|---|---|---|
| 32-40 | 优秀 | 建议保留，可微调 |
| 24-31 | 合格 | 建议优化，重点改进低分维度 |
| 16-23 | 需改进 | 必须重写关键章节 |
| < 16 | 不合格 | 重写第 1 章 |

## 自动评分脚本

```bash
python3 scripts/first3-retention.py \
  --memory memory/novels/{slug}.md \
  --chapter chapter-001.md \
  --output reports/first3-retention-001.md
```

输出示例：

```markdown
=== 开篇留存诊断（第 1 章）===

钩子强度：8/10
  ✓ 章首 200 字有具体场景
  ✓ 有异常机制（黑匣子停止闪烁）
  - 建议：可加入更明显的冲突

主角处境：7/10
  ✓ 主角身份清晰（林澈，星港事故调查员）
  ✓ 有外部压力（爆炸案调查）
  - 建议：加强内部矛盾（如对父亲的执念）

欲望与异常：6/10
  ✓ 异常机制存在（黑匣子异常）
  - 主角欲望不够强烈
  - 建议：明确林澈的"调查动机"（如父亲的失踪）

信息密度：7/10
  ✓ 设定在情节中展开
  - 少量背景说明略显密集
  - 建议：分散到第 2-3 章

总分：28/40（合格）

修改建议：重点加强"欲望与异常"维度
```

## 多人协作下的开篇诊断

- 主线作者提供开篇草案
- 编辑 / 风格审计者运行诊断
- 主线作者根据诊断结果修订
- 修订后重新诊断
- 达成 32+ 分后定稿

详见 `references/collab-workflow.md`。
