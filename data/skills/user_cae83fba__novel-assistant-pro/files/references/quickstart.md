# 5 分钟上手（quickstart）

> v2.0.0 新增。把 SKILL.md 中的"5 分钟上手"卡片扩展为完整流程。

## Step 1：告诉我你想写什么（30 秒）

格式：

```text
我想写一部{类型}长篇，主角是{身份}，核心看点是{爽点/反转/悬念}。
```

示例：

```text
我想写一部玄幻长篇，主角是退婚少年，核心看点是废材逆袭。
```

技能收到后会进入[构思期]。

## Step 2：我会问你 5 个问题（1 分钟）

```text
1. 目标读者：男频/女频/全年龄？
2. 平台风格：番茄小说 / 起点中文网 / 晋江文学城 / 七猫小说 / 微信公众号 / 小红书连载 / 其他？
3. 叙事人称：第一人称 / 第三人称 / 多视角？
4. 预期篇幅：30 章 / 100 章 / 长篇 200 万字 / 短篇 5 万字？
5. 保存目录：用户指定（默认：~/Documents/novels/）

可选问题（按需）：
- 是否有参考作品？
- 是否有核心意象/主题词？
- 是否有必须包含的元素？
```

## Step 3：我生成基础设定（2 分钟）

输出：

```markdown
## 主题与核心冲突

[一句话概括故事核心]

## 主要人物卡

### 主角：{姓名}
[身份、目标、矛盾、对话风格样本]

### 导师/反派：{姓名}
[身份、目标、矛盾、对话风格样本]

### 配角 1：{姓名}
[身份、目标、对话风格]

## 世界观硬规则

1. [硬规则 1]
2. [硬规则 2]
3. [硬规则 3]

## 前三章大纲

### 第 1 章：{标题}
- 钩子：{章首钩子}
- 目标：{主角本章目标}
- 阻力：{阻力来源}
- 变化：{本章结束时的状态变化}
- 钩子：{章末钩子}

### 第 2 章：{标题}
[同上结构]

### 第 3 章：{标题}
[同上结构]

## 风格 DNA 默认值

- 句长：{中短句}
- 对话比例：{中}
- 修辞密度：{中等}
- 平台调性：{已选平台}
```

## Step 4：你确认后我落盘（30 秒）

技能执行：

```bash
python3 scripts/init-novel-project.py \
  --slug {your-slug} \
  --title "《{小说名}》" \
  --type {类型} \
  --platform {平台} \
  --pov {人称} \
  --output-dir {保存目录}
```

创建：

```text
{保存目录}/
├── memory/novels/{slug}.md          # 记忆文件
├── novels/{slug}/
│   ├── chapters/                    # 章节目录
│   ├── backups/                     # 备份目录
│   └── meta.json                    # 项目元数据
└── README.md                        # 项目说明
```

## Step 5：进入续写循环（持续）

每次续写只需说：

```text
续写第 N 章
```

技能自动：

1. 读 meta.json 确认当前作品
2. 读记忆文件
3. 读上一章末段
4. 列未解决 P1 伏笔
5. 列本章涉及人物与硬规则
6. 询问 ≤ 3 项缺失（一般是"本章目标"或"特殊要求"）
7. 生成正文 + 自检卡 + AI 痕迹分
8. 询问覆盖策略（覆盖/另存/取消）
9. 写入 + 时间戳备份
10. 更新记忆文件

## 常见场景速查

| 想做什么 | 该怎么说 |
|---|---|
| 检查冲突 | 「帮我检查第 N 章有没有冲突」 |
| 节拍诊断 | 「帮我诊断第 N 章的节拍」 |
| 开篇留存 | 「帮我评估第 1 章的留存」 |
| 压缩记忆 | 「这部小说的记忆太长了，帮我压缩」 |
| 提取风格 | 「分析开篇，提取风格 DNA」 |
| 去 AI 腔 | 「把第 N 章改成更人味的版本」 |
| 导出 docx | 「导出第 N 章到 {路径}」 |
| 切换作品 | 「我现在开始写新作品《YYY》」 |
| 加入灵感 | 「把这条灵感记到《XXX》的素材库：{灵感内容}」 |

## 退出快速开始

快速开始仅适用首次创建项目。后续：

- 修订章节 → 进入[修订期]
- 检查冲突 → 运行 conflict-detect.py
- 导出 → 运行 export-to-docx.py
- 切换作品 → 进入[清理态]

## 失败模式

如果快速开始任何一步卡住：

- 不要重复输入同一指令
- 直接说「卡住了，我想{目标}」
- 技能会自动诊断卡点
