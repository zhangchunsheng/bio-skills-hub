# 时间线管理

## 记忆文件中的标准写法

```markdown
## 时间线

| 顺序 | 章节 | 故事时间 | 事件 | 涉及人物 | 影响 |
|---:|---|---|---|---|---|
| 1 | 001 | 第一天夜 | 港口爆炸事故发生 | 林澈 | 引出调查 |
| 2 | 001 | 第一天夜（+2 小时） | 林澈接到调查任务 | 林澈、上级 | 进入主线 |
| 3 | 002 | 第一天晨 | 残片鉴定结果出来 | 林澈 | 推进主线 |
```

## 时间粒度选择

| 类型 | 推荐粒度 |
|---|---|
| 悬疑 / 推理 | 精确到小时（便于案件推演） |
| 都市 / 言情 | 精确到天 |
| 玄幻 / 仙侠 | 精确到天或季节（避免过于精确失真） |
| 科幻 / 太空 | 精确到小时或精确到任务编号 |
| 历史 | 精确到历史事件纪年 |

## 续写前必检项

```text
用户："续写第 8 章"

技能自动：
  1. 读记忆文件的时间线表
  2. 读上一章的"故事时间"列
  3. 询问用户：本章的故事时间起点中文网？
     - [1] 紧接着上一章（默认）
     - [2] 跳转到 {时间点}
     - [3] 倒叙/插叙
  4. 写入新时间线条目
```

## 时间冲突检测

发现以下情况立即报警：

1. **物理不可能**：A 在第 3 章从北京到上海用了 1 小时
2. **因果倒置**：A 在第 5 章才知道的事，第 4 章已使用
3. **年龄倒退**：30 年前的人物现在变年轻
4. **季节错乱**：明明是夏天却描写下雪
5. **节日错乱**：春节当天描写不放假

## 自动校验工具

```bash
python3 scripts/validate-novel-memory.py memory/novels/{slug}.md \
  --check-timeline

python3 scripts/world-rules-lint.py \
  --memory memory/novels/{slug}.md \
  --chapter chapter-008.md \
  --check-timeline
```

输出：

```text
=== 时间线检查 ===

✓ 无冲突

或

✗ 时间线冲突（严重）：
  - chapter-005.md: 主角从 A 城到 B 城仅用 1 小时，但世界观规则要求最少 6 小时
  - 建议修改：将"1 小时"改为"6 小时"，或在途中加入停留事件
```

## 跨作品时间线（P3-02 预留）

多作品共用人物或势力时，建议在每部作品的记忆文件中标注：

```markdown
## 跨作品引用

- 势力 X：来自《YYY》第 12 章后
- 人物 Z：与《YYY》第 8 章同一人
```

详见 P3-02 跨作品知识迁移。

## 协作中的时间线协调

多人协作时，时间线由主线作者统一维护：

- 每章写完必须更新记忆文件的时间线表
- 跨章时间跳跃必须主线作者确认
- 倒叙/插叙必须显式标注章节号
- 时间冲突必须在写作群内报警

详见 `references/collab-workflow.md`。
