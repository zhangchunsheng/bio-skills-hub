## 章节结构

```markdown
# 第 N 章 标题

[章首：进入场景 + 男女主互动（300-500 字）]
[发展：情感推进（800-1500 字）]
[冲突：误会 / 第三者 / 身份揭露（500-1000 字）]
[收尾：变化 + 钩子（300-500 字）]
```

## 钩子模板

| 位置 | 钩子类型 | 示例 |
|---|---|---|
| 章末 | 心动 | 「他突然低头，在她耳边说了一句话。」 |
| 章末 | 误会 | 「她转身离开，却不知道身后有人在看着她。」 |
| 章末 | 第三者 | 「一个女人出现在他办公室门口。」 |
| 章末 | 揭秘 | 「她发现，原来他一直在骗她。」 |
| 章末 | 强悬念 | 「她推开家门，发现……」 |

## 爽点密度

| 类型 | 频率 | 表现 |
|---|---|---|
| 心动 | 每章 | 男女主互动、心动瞬间 |
| 小甜 | 每 3 章 | 暧昧升级、撒糖 |
| 中甜 | 每 10 章 | 关系确认、初吻 |
| 大甜 | 每 30 章 | 告白、订婚 |
| 虐点 | 每 50 章 | 误会、分离、第三者 |

## 禁忌

- 男主霸道无脑（不尊重女主）
- 女主傻白甜（缺乏主动）
- 强行误会（缺乏逻辑）
- 男二工具人化（只为衬托男主）
- 男主出轨 / 女主出轨（破坏信任）

## 标题命名风格

- 简洁典雅：5-15 字
- 强人物：含人名或代号
- 强情感：含「心动」「暗恋」「等待」等
- 强设定：含时代或场景特征

示例：

```text
第1章 重生
第2章 初遇
第3章 心动
```

## 推荐 AI 痕迹分

≥ 8 分（晋江文学城读者对文笔有高要求）

## 推荐节拍分

≥ 6 分（情感推进为主，节奏可放缓）

## 写作节奏建议

- 日更 1 章，特殊剧情可加更
- 每月一次"关系推进"
- 每季度一次"重大转折"
- 完结前保持情感连贯
