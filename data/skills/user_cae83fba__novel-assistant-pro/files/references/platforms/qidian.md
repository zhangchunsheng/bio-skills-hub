## 章节结构

```markdown
# 第 N 章 标题

[章首：进入场景，可有设定铺垫（300-500 字）]
[发展：情节推进，可有设定展开（1000-2000 字）]
[高潮：本章核心冲突（500-1500 字）]
[收尾：变化 + 强钩子（300-500 字）]
```

## 钩子模板

| 位置 | 钩子类型 | 示例 |
|---|---|---|
| 章首 | 设定悬念 | 「星际航行的最长记录是 30 天。这是所有人都知道的常识。」 |
| 章首 | 强冲突 | 「他的未婚妻当众撕毁了婚约。」 |
| 章末 | 强悬念 | 「门被推开了。他看见了一个不可能出现的人。」 |
| 章末 | 反转 | 「原来，他才是幕后黑手。」 |
| 章末 | 新伏笔 | 「他不知道的是，这份档案已经被修改过三次。」 |

## 爽点密度

| 类型 | 频率 | 表现 |
|---|---|---|
| 小爽点 | 每 2-3 章 | 主角打脸、装逼 |
| 中爽点 | 每 5 章 | 越级挑战、阴谋揭露 |
| 大爽点 | 每 15 章 | 实力突破、身份反转 |
| 史诗高潮 | 每 50-100 章 | 阵营大战、世界转折 |

## 禁忌

- 章末不钩子（影响订阅）
- 主角过度谨慎（破坏爽感）
- 反派强行降智（起点中文网读者智商在线）
- 章节字数过短（< 2000 字）
- 大段背景说明（影响节奏）
- 主角突然无敌（破坏升级曲线）

## 标题命名风格

- 简洁典雅：5-15 字
- 强设定：含「规则」「真相」「秘密」等
- 强冲突：含「对决」「反杀」「回归」等
- 史诗感：含「纪元」「时代」「命运」等

示例：

```text
第1章 凡人林澈
第2章 黑匣子的秘密
第3章 静默航线
```

## 推荐 AI 痕迹分

≥ 8 分（起点中文网读者对文笔有要求）

## 推荐节拍分

≥ 7 分（每章五要素必须齐全）

## 写作节奏建议

- 日更 1-2 章，每章间隔 4-6 小时
- 每月一次"卷中高潮"
- 每季度一次"大爽点"
- 完结前保持稳定更新
