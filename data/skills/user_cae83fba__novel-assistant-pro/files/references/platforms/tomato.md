# 番茄小说平台调性卡

## 平台特征

| 维度 | 番茄小说特征 |
|---|---|
| 用户群 | 大众、男性为主、低龄偏多 |
| 章节长度 | 1500-2500 字 |
| 更新频率 | 日更 2-4 章（强求） |
| 核心爽点 | 每 3 章一次大爽 |
| 钩子位置 | 章末（必） + 章首（可选） |
| 开篇要求 | 黄金三章必爆 |
| 流量分布 | 推荐流量为主，签约后流量陡增 |
| 签约难度 | 中等 |
| 收益模式 | 广告分成 + 礼物 |

## 推荐流派

| 流派 | 适合度 | 备注 |
|---|---|---|
| 玄幻 | ★★★★★ | 番茄小说最强 |
| 都市 | ★★★★★ | 番茄小说主力 |
| 战神 / 神豪 | ★★★★★ | 番茄小说爆款 |
| 赘婿 / 神医 | ★★★★ | 中等 |
| 悬疑 | ★★★ | 偏小众 |
| 历史 | ★★★ | 偏小众 |
| 科幻 | ★★ | 较冷门 |
| 言情 | ★★ | 男频少 |

## 章节结构

```markdown
# 第 N 章 标题

[章首：直接进入场景，最好有钩子（300 字以内）]
[发展：情节推进（800-1500 字）]
[冲突：核心冲突出现（500-1000 字）]
[收尾：变化 + 钩子（300-500 字）]
```

## 钩子模板

| 位置 | 钩子类型 | 示例 |
|---|---|---|
| 章首 | 异常机制 | 「黑匣子的指示灯在第 47 秒停止了闪烁。」 |
| 章首 | 强冲突 | 「她被退婚的那天，正好是她的成人礼。」 |
| 章末 | 强悬念 | 「门被推开了。她看见了一个不可能出现的人。」 |
| 章末 | 反转 | 「原来，他才是幕后黑手。」 |
| 章末 | 新伏笔 | 「她不知道的是，这份档案已经被修改过三次。」 |

## 爽点密度

| 类型 | 频率 | 表现 |
|---|---|---|
| 小爽点 | 每章 | 主角打脸、装逼、获得好处 |
| 中爽点 | 每 3 章 | 越级挑战、阴谋揭露 |
| 大爽点 | 每 10 章 | 实力突破、身份反转、阵营大战 |

## 禁忌

- 章末不钩子（直接断流）
- 主角过度谨慎（破坏爽感）
- 反派强行降智
- 章节字数过短（< 1500 字）或过长（> 3000 字）
- 大段背景说明（破坏阅读节奏）

## 自动校验

```bash
python3 scripts/platform-validate.py \
  --platform tomato \
  --chapter chapter-008.md \
  --memory memory/novels/{slug}.md
```

输出：

- 字数是否符合 1500-2500 区间
- 章末钩子是否强烈
- 爽点密度是否达标
- 流派特征是否符合

## 标题命名风格

- 简洁有力：5-15 字
- 强悬念：含「竟然」「震惊」「不可思议」等
- 强冲突：含「打脸」「逆袭」「复仇」等
- 主角光环：含「最强」「无敌」「神」等

示例：

```text
第1章 退婚之日
第2章 觉醒金手指
第3章 打脸前未婚妻
```

## 推荐 AI 痕迹分

≥ 7 分（番茄小说读者对文笔要求不高，但对节奏要求高）

## 推荐节拍分

≥ 7 分（每章五要素必须齐全）

## 写作节奏建议

- 日更 2 章，建议每章间隔 4 小时
- 每月一次"大爽点"章节
- 每季度一次"卷末高潮"
- 完结前 30 天保持节奏
