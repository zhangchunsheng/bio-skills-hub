# 微信公众号平台调性卡

## 平台特征

| 维度 | 微信公众号特征 |
|---|---|
| 用户群 | 多元化、女性偏多、深度读者 |
| 章节长度 | 1500-3000 字 |
| 更新频率 | 周更 1-3 章 |
| 核心爽点 | 故事性 + 思考性 |
| 钩子位置 | 章末（必） |
| 开篇要求 | 强人物 + 强故事 |
| 流量分布 | 朋友圈 + 推荐流量 + 关注推送 |
| 签约难度 | 自助（无需签约） |
| 收益模式 | 流量主 + 付费阅读 + 打赏 |

## 章节结构

```markdown
# 第 N 章 标题

[章首：进入场景（300-500 字）]
[发展：情节推进（800-1500 字）]
[冲突：本章核心（500-1000 字）]
[收尾：变化 + 钩子 + 思考（300-500 字）]
```

## 钩子模板

| 位置 | 钩子类型 | 示例 |
|---|---|---|
| 章末 | 思考性 | 「她看着手中的证据，突然明白了什么。」 |
| 章末 | 强悬念 | 「第二天，她发现……」 |
| 章末 | 反转 | 「她没想到的是……」 |
| 章末 | 留白 | 「窗外的雨还在下。」 |

## 风格特征

| 维度 | 微信公众号风格 |
|---|---|
| 语言风格 | 克制、细腻、文学性强 |
| 节奏偏好 | 慢热、强情节、思考性 |
| 对话比例 | 中（30-50%） |
| 描写尺度 | 细腻 |
| 情绪基调 | 多元（悬疑/治愈/现实） |

## 爽点密度

| 类型 | 频率 | 表现 |
|---|---|---|
| 故事性推进 | 每章 | 情节推进 |
| 小思考 | 每章 | 章末思考 |
| 中冲击 | 每 5 章 | 反转、揭秘 |
| 大冲击 | 每 15-20 章 | 重大反转 |

## 禁忌

- 章末不钩子
- 大段背景说明
- 强行煽情
- 网络用语滥用（破坏文学性）

## 标题命名风格

- 文学性强：5-15 字
- 强故事：含悬念
- 强思考：含哲理

示例：

```text
第1章 港口的雾
第2章 黑匣子
第3章 真相的代价
```

## 推荐 AI 痕迹分

≥ 8 分（微信公众号读者对文学性有高要求）

## 推荐节拍分

≥ 6 分（可放缓节奏，重思考性）

## 写作节奏建议

- 周更 1-3 章
- 每月一次"重大推进"
- 每季度一次"卷末总结"
- 完结后可做"全集回顾"
