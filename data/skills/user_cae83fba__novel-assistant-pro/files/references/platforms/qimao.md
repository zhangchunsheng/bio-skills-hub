# 七猫小说平台调性卡

## 平台特征

| 维度 | 七猫小说特征 |
|---|---|
| 用户群 | 大众、男性为主、低龄偏多 |
| 章节长度 | 1500-2500 字 |
| 更新频率 | 日更 2-4 章 |
| 核心爽点 | 每 3 章一次大爽 |
| 钩子位置 | 章末（必） + 章首（可选） |
| 开篇要求 | 黄金三章必爆 |
| 流量分布 | 推荐流量为主 + 平台补贴 |
| 签约难度 | 中等偏低（量大） |
| 收益模式 | 广告分成 + 平台补贴 + 礼物 |

## 推荐流派

| 流派 | 适合度 | 备注 |
|---|---|---|
| 玄幻 | ★★★★★ | 七猫小说最强 |
| 都市 | ★★★★★ | 七猫小说主力 |
| 战神 / 神豪 | ★★★★★ | 七猫小说爆款 |
| 赘婿 / 神医 | ★★★★ | 七猫小说主流 |
| 悬疑 | ★★★ | 七猫小说中等 |
| 历史 | ★★★ | 七猫小说中等 |
| 科幻 | ★★ | 七猫小说较冷 |

## 章节结构

```markdown
# 第 N 章 标题

[章首：直接进入场景（200-300 字）]
[发展：情节推进（800-1500 字）]
[冲突：核心冲突（500-800 字）]
[收尾：变化 + 钩子（300-500 字）]
```

## 钩子模板

| 位置 | 钩子类型 | 示例 |
|---|---|---|
| 章首 | 强冲突 | 「他被未婚妻当众退婚。」 |
| 章末 | 强悬念 | 「他突然看见了一个不可能出现的人。」 |
| 章末 | 反转 | 「原来，她才是幕后黑手。」 |
| 章末 | 新伏笔 | 「他不知道的是，这份档案已经被修改过三次。」 |

## 爽点密度

| 类型 | 频率 | 表现 |
|---|---|---|
| 小爽点 | 每章 | 主角打脸、装逼 |
| 中爽点 | 每 3 章 | 越级挑战 |
| 大爽点 | 每 10 章 | 实力突破、阵营大战 |

## 禁忌

- 章末不钩子
- 主角过度谨慎
- 章节字数过短（< 1500 字）
- 大段背景说明

## 标题命名风格

- 简洁有力：5-15 字
- 强冲突：含「打脸」「逆袭」「复仇」等
- 强爽感：含「最强」「无敌」「震惊」等

示例：

```text
第1章 觉醒血脉
第2章 打脸富二代
第3章 神豪归来
```

## 推荐 AI 痕迹分

≥ 7 分（七猫小说读者对节奏要求高，对文笔要求中等）

≥ 7 分
