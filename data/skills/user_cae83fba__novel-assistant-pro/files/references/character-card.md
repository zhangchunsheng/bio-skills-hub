## 对话风格校验（v2.0.0 新增）

使用 `scripts/dialogue-style-check.py` 校验章节对白是否漂移：

```bash
python3 scripts/dialogue-style-check.py \
  --character {人物名} \
  --chapter chapter-008.md \
  --memory memory/novels/{slug}.md
```

输出：

- 漂移度（0-100，< 20 为合格）
- 不符合风格的对白行号
- 改写建议

## 多人协作下的合并规则

协作场景下，人物卡更新规则：

1. 每次更新必须说明：新增/修改/删除/冲突
2. 不静默覆盖他人设定
3. 冲突时提出合并建议，由主线作者决策
4. 决策结果写入记忆文件的「待确认问题」并标记为「已解决」

详见 `references/collab-workflow.md`。
