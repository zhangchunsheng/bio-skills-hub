# 写入安全契约（write-safety.md）

小说正文是高价值原稿，任何文件写入必须遵守以下 7 条契约。

## 七条铁律

### 1. 首次创建项目必须确认目标目录

```text
用户：我想创建小说
技能：我会写入到 /Users/.../memory/novels/{slug}.md，请确认目录正确吗？
用户：确认
技能：开始创建
```

如未确认，禁止创建任何文件。

### 2. 目标文件已存在时不得直接覆盖

```text
场景：chapter-008.md 已存在
技能：检测到 chapter-008.md 已存在（最后修改 2026-09-08 14:23）。
      请选择：
        [1] 覆盖（将生成 .backup-YYYYMMDD-HHMMSS.md 备份）
        [2] 另存为 chapter-008.new.md
        [3] 取消本次写入
用户：选择 1
技能：已生成备份，开始覆盖
```

### 3. 自动备份开启后，每次覆盖前先生成备份

备份命名：`chapter-008.backup-20260909-180000.md`

备份保留数量可通过 `compress_novel_memory.py --keep-backups N` 控制（默认 5）。

### 4. 写入失败时必须保留完整正文

```text
场景：磁盘已满 / 权限不足 / 文件被占用
技能：写入失败，错误信息：{error}。
      完整正文已保留在对话中，请手动复制保存：
      ─────────
      {完整章节正文}
      ─────────
      建议保存到：/Users/.../chapter-008.md
```

### 5. 不把用户作品写入技能包自身目录

技能包路径：`.app-state/skills/novel-assistant-pro/` 或工作区 `源技能/`

如检测到目标路径在技能包内，立即报错并要求用户重新指定。

### 6. 不把章节、记忆文件或备份写入系统隐藏目录

禁止目录：

- `~/.app-state/`（除技能包自身与配置文件外）
- `~/Library/`（macOS）
- `~/AppData/`（Windows）
- `~/Documents/.config/`
- `/System/`、`/private/`

如用户明确指定，警告一次后仍按用户指令执行。

### 7. 多作品并行时，每部作品必须有独立记忆文件和章节目录

禁止不同作品共用：

- 记忆文件
- 章节目录
- 备份目录
- 人物档案

切换作品前，必须：

1. 读取当前 meta.json 确认当前作品
2. 清空会话记忆摘要中上一作品的关键设定
3. 提示用户确认切换

详见 `references/multi-work-management.md`。

## 自动化校验

```bash
# 写入前校验
python3 scripts/validate-novel-memory.py memory/novels/{slug}.md

# 写入后校验
python3 scripts/validate-novel-memory.py memory/novels/{slug}.md --after-write
```

## 异常处理对照表

| 异常 | 处理 |
|---|---|
| 路径权限不足 | 报错 + 保留正文 + 建议手动保存 |
| 磁盘空间不足 | 报错 + 保留正文 + 清理建议 |
| 文件被占用 | 重试 1 次 + 报错 + 保留正文 |
| 目标在技能包内 | 报错 + 要求重新指定 |
| 目标在隐藏目录 | 警告一次 + 询问用户 |
| 多作品切换未确认 | 强制询问当前作品名 |
