# 风格控制模板

## 记忆文件中的标准写法

```markdown
## 风格规则

- 语言风格：克制 / 紧张 / 轻松 / 诗意 / 粗粝 / 学术
- 节奏偏好：慢热 / 强情节 / 高爽点 / 悬疑递进 / 史诗
- 对话比例：低 / 中 / 高
- 描写尺度：克制 / 细腻 / 强感官 / 极简
- 情绪基调：轻松 / 压抑 / 热血 / 荒诞 / 现实 / 治愈 / 致郁
- 平台调性：番茄小说 / 起点中文网 / 晋江文学城 / 七猫小说 / 微信公众号 / 小红书连载 / 其他
- 禁用表达：（列出）
- 标志性写法：（列出）
```

## 维度详解

### 语言风格

| 风格 | 特征 | 适合流派 |
|---|---|---|
| 克制 | 留白多、点到为止 | 悬疑、历史 |
| 紧张 | 短句多、信息密度高 | 都市、悬疑 |
| 轻松 | 长句多、对话活泼 | 都市、言情 |
| 诗意 | 修辞多、意象密 | 言情、奇幻 |
| 粗粝 | 方言、江湖气 | 武侠、现实 |
| 学术 | 专业术语多 | 科幻、推理 |

### 节奏偏好

| 偏好 | 表现 | 适合 |
|---|---|---|
| 慢热 | 前 30 章铺垫 | 历史、文学 |
| 强情节 | 每章有冲突 | 起点中文网爽文 |
| 高爽点 | 每 3 章一次爽 | 番茄小说爽文 |
| 悬疑递进 | 每章末尾留钩 | 悬疑、推理 |
| 史诗 | 长卷慢推 | 玄幻、科幻 |

### 对话比例

| 比例 | 表现 |
|---|---|
| 低（< 20%） | 重描写、轻对白 |
| 中（20-50%） | 描写与对白平衡 |
| 高（> 50%） | 重对白、轻描写 |

### 平台调性

详见 `references/platforms/`，不同平台的章节长度、钩子位置、爽点密度各异。

## 风格 DNA 提取（v2.0.0 新增）

使用 `scripts/style-dna-extract.py` 从开篇 1000 字提取：

```bash
python3 scripts/style-dna-extract.py \
  --memory memory/novels/{slug}.md \
  --chapter chapter-001.md \
  --output references/{slug}-style-dna.json
```

输出字段：

- 平均句长（字）
- 句长分布（短句/中句/长句占比）
- 词频 Top50
- 修辞密度（比喻/反讽/排比/对仗占比）
- 对话比例
- 信息密度（每段信息量）
- 禁用表达扫描结果

## 跨章风格一致性校验

```bash
python3 scripts/style-drift-detect.py \
  --style-dna references/{slug}-style-dna.json \
  --chapter chapter-008.md
```

输出漂移度（0-100）：

- < 10：完全一致
- 10-20：轻微漂移（合格）
- 20-40：中度漂移（建议调整）
- > 40：严重漂移（必须改写）

## 平台调性的风格差异

| 平台 | 章节长度 | 钩子位置 | 爽点密度 |
|---|---|---|---|
| 番茄小说 | 1500-2500 字 | 章末 | 每 3 章一次 |
| 起点中文网 | 2000-4000 字 | 章末 + 段中 | 每 5 章一次 |
| 晋江文学城 | 1500-3000 字 | 章末 | 不强求 |
| 七猫小说 | 1500-2500 字 | 章末 + 章首 | 每 3 章一次 |
| 微信公众号 | 1500-3000 字 | 章末 | 全文统一 |
| 小红书连载 | 800-1500 字 | 章末 | 短频快 |

详见 `references/platforms/`。
