# AI 痕迹改写示范（anti-ai/rewrites.md）

> v2.0.0 新增。每条 AI 痕迹提供 3 个改写示范（正反对比）。

## 痕迹 1：破折号「——」滥用

### 反例（高 AI 痕迹）

```text
她的父亲——那个失踪了十年的舰长——从未离开过她的心。
```

### 正例 1：用冒号

```text
她的父亲，那个失踪了十年的舰长，从未离开过她的心。
```

### 正例 2：用句号

```text
她的父亲是那个失踪了十年的舰长。他从未离开过她的心。
```

### 正例 3：用直接融合

```text
失踪十年的舰长父亲从未离开过她的心。
```

---

## 痕迹 2：「不是 X，是 Y」对比结构

### 反例

```text
这不是普通的港口，而是一座死去的港口。
```

### 正例 1：直接陈述

```text
这座港口已经死了三十年。
```

### 正例 2：用具体动作

```text
港口的指示灯已经熄灭。潮汐退去后只剩生锈的钢架。
```

### 正例 3：保留对比但改写

```text
港口曾经喧嚣。现在只剩风声。
```

---

## 痕迹 3：拟人化用词

### 反例

```text
沉默在房间里蔓延。
```

### 正例 1：用具体描写

```text
房间里没有人说话。空调的嗡鸣声从天花板传来。
```

### 正例 2：用动作暗示

```text
她没说话。他也没说话。
```

### 正例 3：用物理环境

```text
房间里安静得能听见墙上的钟摆。
```

---

## 痕迹 4：过度雕琢的比喻

### 反例

```text
她的眼泪如同破碎的星辰，在寂静的夜空中缓缓坠落。
```

### 正例 1：克制白描

```text
她的眼泪流下来。
```

### 正例 2：用动作暗示

```text
她抬手擦了一下眼角。
```

### 正例 3：用克制比喻

```text
她的眼泪落在地上，没有声音。
```

---

## 痕迹 5：解释性补注

### 反例

```text
星港是这座城市最古老的建筑，建于三百年前（注：星港是城市的标志性建筑）。
```

### 正例 1：融入情节

```text
三百年前，这片地方还是码头。现在是星港。
```

### 正例 2：用人物视角

```text
「星港比这座城市还老。」她说。
```

### 正例 3：删除补注

```text
星港建于三百年前。
```

---

## 痕迹 6：列表化排比

### 反例

```text
她想知道真相。
她想知道动机。
她想知道背后的人。
```

### 正例 1：合并

```text
她想知道真相、动机和背后的人。
```

### 正例 2：变化句式

```text
真相是什么。动机是什么。背后的人是谁。
```

### 正例 3：用具体动作

```text
她翻完了最后一页档案，站起身，合上灯。
```

---

## 痕迹 7：被动句堆叠

### 反例

```text
证据被发现了。
文件被销毁了。
嫌疑人被审讯了。
```

### 正例 1：主动句

```text
调查员发现了证据。
档案员销毁了文件。
警察审讯了嫌疑人。
```

### 正例 2：用人物视角

```text
调查员找到了证据。她翻开档案，却发现文件已经被销毁了。警察把嫌疑人带走审讯。
```

---

## 痕迹 8：情绪标签直白化

### 反例

```text
她感到非常难过。
```

### 正例 1：用动作

```text
她转过头去。
```

### 正例 2：用外貌

```text
她的眼眶红了。
```

### 正例 3：用克制描写

```text
她没说话。过了很久，她才点了点头。
```

---

## 痕迹 9：章节编号泄露

### 反例

```text
（这是第三章的结尾）
本章结束。
```

### 正例 1：删除元叙述

```text
（直接以场景收尾，无元叙述）
```

### 正例 2：用钩子替代

```text
她挂断电话。手机屏幕上显示了一个未接来电：父亲的号码。
```

---

## 痕迹 10：通用化总结

### 反例

```text
从此，她的人生彻底改变了。
```

### 正例 1：具体场景

```text
她合上档案，站起身。窗外的星港亮起来了。
```

### 正例 2：用动作收尾

```text
她按下了录音键。
```

### 正例 3：用悬念收尾

```text
门被推开了。
```

## 改写 SOP

```text
1. 扫描 AI 痕迹（anti-ai-scan.py）
2. 标注每个段落的具体痕迹
3. 按本文件的正例改写
4. 重新扫描，确认 AI 痕迹分 ≥ 8
5. 写入记忆文件的"修订记录"
```

详见 `references/anti-ai/checklist.md`。
