```markdown

| 痕迹 | 出现次数 | 单次扣分 | 合计扣分 |
|---|---|---|---|
| 1. 破折号滥用 |  | 0.5 |  |

| 3. 拟人化用词 |  | 1 |  |

| 8. 情绪标签直白化 |  | 1 |  |
| 9. 章节编号泄露 |  | 2 |  |
| 10. 通用化总结 |  | 1.5 |  |

合计扣分：
最终得分：10 - 合计扣分

判定：
- 8-10 分：人味充足，建议保留

- < 4 分：必须改写整章
```

## 自动评分脚本

```bash
python3 scripts/anti-ai-scan.py \
  --chapter chapter-008.md \
  --output reports/anti-ai-008.md
```

输出示例：


## 痕迹定位

```bash
python3 scripts/anti-ai-scan.py \
  --chapter chapter-008.md \
  --locate \
  --output reports/anti-ai-locate-008.md
```

输出每个痕迹的具体段落和行号：

```markdown
=== 痕迹定位 ===

痕迹 1（破折号）：
  - 第 3 段 L12：「她的父亲——那个失踪了十年的舰长——」
  - 第 5 段 L23：「星港——这座城市的心脏——」
  - 共 12 处

痕迹 2（对比结构）：
  - 第 2 段 L5：「这不是普通的港口，而是一座死去的港口」
  - 共 4 处
```

## 改写 SOP

```text
1. 运行 anti-ai-scan.py --locate 获取段落定位
2. 按 references/anti-ai/rewrites.md 的正例改写
3. 重新运行 anti-ai-scan.py 确认 ≥ 8 分
4. 在章节文件末尾追加修订记录：
   - "修订日期：2026-09-09"
   - "AI 痕迹分：从 3 分 → 8 分"
   - "主要修改：去除破折号滥用、对比结构"
```

## 与其他评分的关系

| 评分项 | 合格标准 | 关系 |
|---|---|---|
| AI 痕迹分 | ≥ 6 | 与其他评分独立 |
| 风格漂移度 | < 20 | 独立 |
| 节拍分 | ≥ 6 | 独立 |
| 开篇留存分 | ≥ 24 | 仅第 1-3 章 |

总合格率：

- 4 项全部合格：可定稿
- 任意 1 项不合格：必须修订
- 任意 2 项不合格：必须重写
