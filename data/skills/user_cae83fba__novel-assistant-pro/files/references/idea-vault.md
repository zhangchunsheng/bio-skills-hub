# 灵感素材库（idea-vault.md）

> v2.0.0 新增。把零散的灵感、片段、参考素材统一管理。

## 为什么需要灵感素材库

创作过程中会产生大量零散灵感：

- 一句话意象
- 一个场景片段
- 一个对白片段
- 一个参考设定
- 一张参考图片
- 一段引用

如果不及时落盘，灵感容易丢失；落到不统一的地方，又难以检索。

## 落盘位置

### 项目级灵感库

```text
novels/{slug}/idea-vault.md
```

### 用户级灵感库（跨项目）

```text
~/.app-state/novels/idea-vault.md
```

或自定义路径。

## 标准写法

```markdown
# 《星港尽头》灵感素材库

> 最后更新：2026-09-09

## 临时灵感（待分类）

- [ ] 林澈第一次进入黑匣子室的场景：她闻到了陈旧的金属味，但还有一丝不属于那个年代的香水味 → 暗示有人近期进入
- [ ] 内务局总部在第七环的最深处，需要穿过七道门 → 数字"七"的意象反复出现
- [ ] 顾闻年轻时是个诗人 → 与现在的克制形象形成反差
- [ ] 林澈的导师代号是"Sleeper"（沉睡者）→ 暗示她长期潜伏
- [ ] 黑匣子不是金属做的，是某种有机物 → 与星港技术背景形成反差

## 已分类（待使用）

### 场景

- [ ] 港口爆炸后，林澈在现场发现一块不属于现场的怀表 → 推进调查（可在第 3 章使用）
- [ ] 林澈第一次怀疑顾闻的场景：她发现顾闻办公桌上有一张她父亲的照片 → 推进主线（第 4 章）

### 对白片段

- [ ] 林澈对顾闻说：「证据不会消失，只会被人放错地方。」
- [ ] 顾闻对林澈说：「有些真相，知道了比不知道更痛苦。」

### 设定点

- [ ] 星港的"环形"意象：每个章节对应一个环，从外到内
- [ ] 时间设定：十年前 → 一年前 → 现在，三段时间线交织

### 主题意象

- [ ] "放错地方"——真相被挪动、被隐藏、被遗忘
- [ ] "沉睡者"——长期潜伏、等待唤醒
```

## 触发方式

```text
用户："把这条灵感记到《XXX》的素材库：{灵感内容}"

技能：
  1. 确认当前作品（如有）
  2. 询问分类（场景/对白/设定/主题/未分类）
  3. 写入 idea-vault.md
  4. 显示写入位置
```

## 灵感分类

| 分类 | 说明 |
|---|---|
| 临时灵感 | 未分类的原始想法 |
| 场景 | 可直接使用的场景 |
| 对白片段 | 可直接使用的对白 |
| 设定点 | 世界观/人物/情节设定 |
| 主题意象 | 反复出现的核心意象 |
| 参考资料 | 引用、图片、外部链接 |

## 灵感 → 章节的转化

```text
场景：idea-vault.md 中的"林澈第一次怀疑顾闻"灵感，需要在第 4 章使用

技能：
  1. 在灵感条目后追加：[已使用：第 4 章，2026-09-09]
  2. 在第 4 章大纲中加入该场景
  3. 在章节概要中标记：[来源灵感 ID：#002]
```

## 灵感回收

```text
场景：灵感长期未使用（> 30 章）

技能每月一次提醒：
  - 未分类灵感：X 条
  - 已分类未使用：X 条
  - 建议：保留 / 删除 / 整合到章节
```

## 多人协作下的灵感库

- 每位协作者可贡献灵感
- 主线作者整合到主线大纲
- 灵感被使用时需标注作者
- 灵感冲突时由主线作者决策

## 灵感库 vs 记忆文件

| 维度 | 灵感库 | 记忆文件 |
|---|---|---|
| 内容 | 零散想法 | 已确定的设定 |
| 状态 | 待分类 / 待使用 | 当前生效 |
| 写入时机 | 随时 | 修订时 |
| 删除 | 可删除 | 谨慎删除 |

灵感进入设定后，应从灵感库移到记忆文件。
