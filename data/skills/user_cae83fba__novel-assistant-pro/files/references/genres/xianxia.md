# 玄幻流派模板

## 流派特征

| 维度 | 特征 |
|---|---|
| 核心爽点 | 废物逆袭、打脸、装逼、升级、复仇 |
| 核心雷区 | 主角能力突变、逻辑断裂、过度巧合 |
| 节奏 | 强情节 + 高爽点，每 3-5 章一次大爽 |
| 对话比例 | 中（30-50%） |
| 描写尺度 | 中等 |
| 情绪基调 | 热血、爽、燃 |
| 章节长度 | 2000-4000 字 |

## 必填世界观硬规则

```markdown
### 硬规则

1. 修炼体系（如：练气 → 筑基 → 金丹 → 元婴 → 化神 → 仙人）
2. 每个境界的突破条件（资源 + 领悟 + 生死历练）
3. 主角的初始定位（废物 / 天才 / 落魄 / 重生）
4. 主角的金手指（系统 / 老爷爷 / 重生记忆 / 血脉觉醒）
5. 反派势力的核心矛盾（与主角不可调和）
6. 主要地图分布（宗门、城市、秘境、险地）

### 软规则

1. 宗门文化（弟子等级、长老权力、资源分配）
2. 丹药 / 法器 / 阵法 / 符箓的等级
3. 主要 NPC 的姓名风格
4. 异族设定（如妖族、魔族）

### 待定规则

1. 是否引入多女主 / 单女主？
2. 是否引入"穿越"元素？
3. 是否引入"系统面板"？
```

## 典型主角原型

| 原型 | 描述 | 爽点 |
|---|---|---|
| 废物逆袭 | 主角被退婚 / 废掉修为 → 重生 / 觉醒 | 打脸、复仇 |
| 穿越重生 | 现代人穿越 / 重生到玄幻世界 | 金手指、复仇 |
| 系统流 | 主角获得"签到系统""加点系统" | 系统奖励、爽感累积 |
| 老爷爷流 | 主角获得"前世强者"的残魂指导 | 升级加速、传承 |
| 血脉觉醒 | 主角发现自己有远古血脉 | 血脉压制、身份反转 |
| 扮猪吃虎 | 主角隐藏实力，被轻视后反杀 | 反差爽感 |

## 典型势力原型

| 势力 | 描述 | 与主角关系 |
|---|---|---|
| 主角宗门 | 主角所在的修炼组织 | 起点中文网 |
| 敌对宗门 | 与主角宗门有世仇 | 主要反派 |
| 帝国 / 王朝 | 世俗权力 | 中立或敌对 |
| 异族势力 | 妖族 / 魔族 | 大后期反派 |
| 隐秘势力 | 隐藏在暗处的强大组织 | 中后期揭露 |

## 节拍模板

```markdown
### 玄幻四段式

开篇：废物身份 + 金手指觉醒
  ↓
发展：进入宗门 / 拜师 / 试炼
  ↓
高潮：第一次大爽点（如宗门大比、越级挑战）
  ↓
转折：卷入更大势力（如帝国、异族）
```

## 风格 DNA 默认值

- 句长：中短（10-20 字为主）
- 修辞密度：中等
- 对话比例：中（30-50%）
- 标志性写法：装逼打脸、热血沸腾、系统提示音

## 禁忌

- 主角突然无敌（违反升级曲线）
- 主角突然失忆（破坏设定）
- 反派强行降智（降低爽感）
- 主角过度谨慎（破坏爽感）
