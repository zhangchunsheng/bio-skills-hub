# 科幻流派模板

## 流派特征

| 维度 | 特征 |
|---|---|
| 核心爽点 | 科技震撼、悬念、宏大叙事、伦理冲突 |
| 核心雷区 | 物理逻辑断裂、技术设定矛盾、伦理简化 |
| 节奏 | 中等或快节奏 |
| 对话比例 | 中（30-50%） |
| 描写尺度 | 克制到中等 |
| 情绪基调 | 震撼、悬疑、思辨、史诗 |
| 章节长度 | 2000-4000 字 |

## 必填世界观硬规则

```markdown
### 硬规则

1. 时代背景（近未来 / 远未来 / 太空时代）
2. 科技水平（AI / 太空航行 / 时间旅行 / 虚拟现实）
3. 物理规则（光速限制 / 时空结构 / 量子规则）
4. 社会结构（国家 / 公司 / 联盟 / 后国家形态）
5. 主角的身份（科学家 / 军人 / 平民 / AI / 改造人）
6. 主要冲突（科技 vs 伦理 / 物种 vs 物种 / 国家 vs 国家）

### 软规则

1. 太空设定（地球 / 太阳系 / 银河系 / 跨银河）
2. 主要科技（能源 / 推进 / 通讯 / 武器 / AI）
3. 外星 / 异族设定

### 待定规则

1. 是否引入"硬科幻"设定（基于真实物理）？
2. 是否引入"软科幻"设定（基于想象）？
3. 是否多视角叙事？
```

## 典型主角原型

| 原型 | 描述 | 关键点 |
|---|---|---|
| 科学家 | 主角是物理学家 / 生物学家 | 发现、伦理 |
| 军人 | 主角是太空军 / 海军陆战队员 | 战斗、团队 |
| 平民 | 主角是普通人卷入大事件 | 视角、悬念 |
| AI | 主角是 AI / 改造人 | 自我意识、伦理 |
| 记者 | 主角是调查记者 | 揭露、悬疑 |
| 外交官 | 主角是星际外交官 | 政治、文化冲突 |

## 典型科幻设定

| 设定 | 描述 |
|---|---|
| 太空歌剧 | 大尺度太空叙事（《银河帝国》） |
| 赛博朋克 | 高科技 + 低生活（《神经漫游者》） |
| 反乌托邦 | 集权社会反乌托邦（《1984》） |
| 硬科幻 | 基于真实物理（《火星救援》） |
| 第一接触 | 人类首次接触外星文明 |
| 时间旅行 | 时间悖论、蝴蝶效应 |
| 后人类 | AI、改造人、意识上传 |

## 节拍模板

```markdown
### 科幻四段式

建立：科技设定 + 主角身份
  ↓
冲突：核心事件（灾难 / 发现 / 战争）
  ↓
揭秘：科技真相 / 外星真相
  ↓
抉择：伦理困境与最终选择
```

## 风格 DNA 默认值

- 句长：中等（15-25 字）
- 修辞密度：中等
- 对话比例：中（30-50%）
- 标志性写法：科技用语、悬疑铺垫、宏大叙事

## 禁忌

- 物理逻辑断裂（如光速被轻松突破）
- 技术设定矛盾（前后不一致）
- 伦理简化（如"好人 vs 坏人"二元论）
- 强行煽情（破坏科幻冷静感）
