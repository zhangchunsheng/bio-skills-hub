# 都市流派模板

## 流派特征

| 维度 | 特征 |
|---|---|
| 核心爽点 | 装逼、打脸、商战、逆袭、暧昧 |
| 核心雷区 | 主角突然无敌、金手指过于夸张、女主工具人 |
| 节奏 | 中等节奏，事件驱动 |
| 对话比例 | 中高（40-60%） |
| 描写尺度 | 克制 |
| 情绪基调 | 现实、爽、暧昧 |
| 章节长度 | 1500-3000 字 |

## 必填世界观硬规则

```markdown
### 硬规则

1. 现实时代背景（2020s / 2030s）
2. 主角的身份（学生 / 白领 / 老板 / 医生 / 律师 / 退伍军人）
3. 主角的初始困境（穷 / 被欺 / 失业 / 离婚 / 病重）
4. 主角的逆袭路径（创业 / 升职 / 复仇 / 暧昧）
5. 主要行业（互联网 / 金融 / 医疗 / 法律 / 房地产）
6. 反派类型（富二代 / 职场对手 / 前任 / 黑社会）

### 软规则

1. 城市设定（北上广深 / 海外）
2. 社交圈（学校 / 公司 / 家族 / 江湖）
3. 主要 NPC 的姓名风格
4. 主角的感情线（单女主 / 多女主 / 无女主）

### 待定规则

1. 是否引入"重生"元素？
2. 是否引入"异能"元素？
3. 是否引入"系统"元素？
```

## 典型主角原型

| 原型 | 描述 | 爽点 |
|---|---|---|
| 退婚流 | 主角被退婚 / 抛弃 → 逆袭 | 打脸前未婚妻 |
| 神豪流 | 主角突然继承巨额财富 | 装逼、消费 |
| 神医流 | 主角获得神医能力 | 治病救人、暧昧 |
| 兵王流 | 主角是退伍特种兵 | 身手、忠诚、暧昧 |
| 重生流 | 主角重生回到过去 | 复仇、商业先知 |
| 系统流 | 主角获得"日常签到系统" | 系统奖励、爽感累积 |
| 职场流 | 主角从小职员逆袭成 CEO | 升职、打脸 |

## 典型势力原型

| 势力 | 描述 |
|---|---|
| 主角公司 | 主角的工作单位 |
| 敌对公司 | 商业对手 |
| 主角家族 | 血缘家族 |
| 姻亲家族 | 婚姻关联家族 |
| 江湖势力 | 地下社会 |

## 节拍模板

```markdown
### 都市三段式

开篇：主角困境 + 金手指 / 觉醒
  ↓
发展：进入职场 / 商战 / 暧昧
  ↓
高潮：第一次大爽点（如打脸富二代、商战胜出）
  ↓
收尾：感情线 + 事业线双收
```

## 风格 DNA 默认值

- 句长：中等（15-25 字）
- 修辞密度：低（克制白描）
- 对话比例：中高（40-60%）
- 标志性写法：装逼金句、现实共鸣

## 禁忌

- 主角突然获得不合理的巨额财富
- 主角在商战中毫无逻辑地胜利
- 女主工具人化（只为推进暧昧情节）
- 强行巧合（破坏现实感）
