# 悬疑流派模板

## 流派特征

| 维度 | 特征 |
|---|---|
| 核心爽点 | 推理、揭秘、反转、真相大白 |
| 核心雷区 | 推理逻辑断裂、巧合过多、反派降智 |
| 节奏 | 悬疑递进，每章末尾留钩 |
| 对话比例 | 中（30-50%） |
| 描写尺度 | 克制（信息密度高） |
| 情绪基调 | 紧张、悬疑、压抑、揭秘 |
| 章节长度 | 1500-3000 字 |

## 必填世界观硬规则

```markdown
### 硬规则

1. 案件规则（如：密室杀人、不可能犯罪）
2. 推理逻辑（演绎法 / 归纳法 / 反向推理）
3. 主角的推理能力（侦探 / 警察 / 法医 / 律师 / 普通人）
4. 案件时间跨度（连环 / 单案 / 多年悬案）
5. 反派动机（复仇 / 利益 / 掩盖 / 心理扭曲）
6. 信息披露规则（主角知道但读者不知道 / 平等披露）

### 软规则

1. 案件类型（密室 / 不在场 / 身份反转 / 连续杀人）
2. 配角设定（助手 / 警察 / 嫌疑人 / 受害者家属）
3. 场景（都市 / 乡村 / 学校 / 公司 / 列车）

### 待定规则

1. 是否引入超自然元素？
2. 是否采用"叙述性诡计"？
3. 是否多视角叙事？
```

## 典型主角原型

| 原型 | 描述 |
|---|---|
| 侦探 | 主角是专业侦探 / 神探 |
| 警察 | 主角是刑警 / 调查员 |
| 法医 | 主角是法医 / 鉴证人员 |
| 律师 | 主角是律师 / 检察官 |
| 普通人 | 主角因缘卷入案件 |
| 受害者 | 主角的家人 / 自己受害 |
| 嫌疑人 | 主角被误认为嫌疑人 |

## 典型叙事结构

### 结构 1：侦探视角（古典推理）

```text
案件发生 → 侦探介入 → 收集线索 → 推理 → 真凶揭露
```

### 结构 2：嫌疑人视角（反转推理）

```text
案件发生 → 多视角展开 → 嫌疑人各自有嫌疑 → 反转揭示
```

### 结构 3：受害者视角（社会派）

```text
案件发生 → 受害者家属调查 → 揭示社会问题 → 真凶揭露
```

## 节拍模板

```markdown
### 悬疑五段式

开篇：案件发生（强钩子）
  ↓
调查：侦探介入（铺设线索）
  ↓
迷雾：增加嫌疑人（每章末尾留钩）
  ↓
揭秘：核心推理（真相大白）
  ↓
收尾：反派动机揭示 + 案件余波
```

## 风格 DNA 默认值

- 句长：短（5-15 字为主）
- 修辞密度：低（克制白描）
- 对话比例：中（30-50%）
- 标志性写法：悬念句、线索铺垫、反转揭示

## 禁忌

- 推理逻辑断裂（关键推理无证据）
- 巧合过多（缺乏合理动机）
- 反派降智（缺乏智商对决）
- 信息披露不公（破坏读者信任）
