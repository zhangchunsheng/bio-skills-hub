# 历史流派模板

## 流派特征

| 维度 | 特征 |
|---|---|
| 核心爽点 | 权谋、英雄、热血、家国天下 |
| 核心雷区 | 历史事实错误、穿越过度金手指、人物 OOC |
| 节奏 | 中等或慢热 |
| 对话比例 | 中（30-50%） |
| 描写尺度 | 中等（细节描写多） |
| 情绪基调 | 史诗、悲壮、家国、热血 |
| 章节长度 | 2000-4000 字 |

## 必填世界观硬规则

```markdown
### 硬规则

1. 朝代设定（秦汉唐宋明清 / 架空）
2. 主要历史事件（基于史实或明确架空）
3. 权力结构（皇帝 / 丞相 / 大将军 / 文官集团）
4. 主角的身份（帝王 / 将军 / 文臣 / 谋士 / 平民 / 商人）
5. 地理设定（都城 / 边疆 / 海外）
6. 经济基础（农业 / 商业 / 盐铁 / 漕运）

### 软规则

1. 文化设定（服饰 / 礼仪 / 饮食 / 节庆）
2. 官职体系
3. 军事制度
4. 人物姓名风格

### 待定规则

1. 是否引入"穿越"元素？
2. 是否引入"架空"设定（与真实历史的距离）？
3. 是否引入女性视角？
```

## 典型主角原型

| 原型 | 描述 | 关键点 |
|---|---|---|
| 帝王流 | 主角成为 / 重生为皇帝 | 权谋、宫斗 |
| 将军流 | 主角成为将军 / 名将 | 战争、热血 |
| 文臣流 | 主角是文臣 / 谋士 | 权谋、智斗 |
| 商人流 | 主角是商人 / 红顶商人 | 商业、家族 |
| 谋士流 | 主角是军师 / 幕僚 | 智斗、辅佐 |
| 穿越流 | 现代人穿越到古代 | 历史先知、改革 |
| 架空流 | 完全架空世界观 | 自由度大 |

## 典型势力原型

| 势力 | 描述 |
|---|---|
| 皇权 | 皇帝、太子、诸王 |
| 文官集团 | 丞相、六部尚书、地方官 |
| 武官集团 | 大将军、都督、节度使 |
| 世家大族 | 五姓七望、江南士族 |
| 江湖势力 | 帮派、教门、绿林 |
| 外族 | 匈奴、突厥、女真、蒙古 |

## 节拍模板

```markdown
### 历史四段式

入局：主角进入权力场（科举 / 军功 / 家族）
  ↓
扎根：建立势力 / 获得信任
  ↓
风云：卷入大事件（政变 / 战争 / 改革）
  ↓
收官：完成使命 / 全身而退
```

## 风格 DNA 默认值

- 句长：中等偏长（15-25 字）
- 修辞密度：中等（典雅）
- 对话比例：中（30-50%）
- 标志性写法：典雅用语、典故引用、史笔白描

## 禁忌

- 历史事实错误（如穿越者改变已知结局但缺乏合理动机）
- 人物 OOC（如让诸葛亮突然变成恋爱脑）
- 现代价值观强行植入古代（如人人平等、穿越者强行推行）
- 强行金手指（破坏历史感）
