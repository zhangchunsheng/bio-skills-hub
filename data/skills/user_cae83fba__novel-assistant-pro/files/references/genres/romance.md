# 言情流派模板

## 流派特征

| 维度 | 特征 |
|---|---|
| 核心爽点 | 心动、暧昧、误会解开、撒糖 |
| 核心雷区 | 男主工具人化、女主傻白甜、强行误会 |
| 节奏 | 慢热、细腻 |
| 对话比例 | 中高（40-60%） |
| 描写尺度 | 细腻（心理描写多） |
| 情绪基调 | 甜蜜、虐、治愈、致郁 |
| 章节长度 | 1500-3000 字 |

## 必填世界观硬规则

```markdown
### 硬规则

1. 现实时代背景或架空时代
2. 男女主角的身份设定
3. 主角的初始关系（陌生人 / 同学 / 同事 / 仇人 / 婚约）
4. 感情线推进的阻力（身份差距 / 家族仇恨 / 已有婚约 / 误会）
5. 主要场景（校园 / 职场 / 豪门 / 江湖 / 宫廷）

### 软规则

1. 配角设定（闺蜜 / 兄弟 / 父母 / 情敌）
2. 主要 NPC 的姓名风格
3. 感情线节奏（慢热 / 中等 / 快节奏）

### 待定规则

1. 是否引入"重生"元素？
2. 是否引入"穿越"元素？
3. 是否走"先婚后爱""追妻火葬场"等套路？
```

## 典型主角原型

| 原型 | 描述 | 关键点 |
|---|---|---|
| 甜宠流 | 男女主从一开始就互相喜欢 | 高甜、低虐 |
| 虐恋情深 | 男女主经历多次误会、分离 | 高虐、高甜 |
| 先婚后爱 | 男女主先婚后培养感情 | 婚后日常 |
| 追妻火葬场 | 男主曾伤害女主 → 追回 | 男主后悔 |
| 重生复仇 | 女主重生 → 改变命运 | 复仇、重新选择 |
| 灰姑娘 | 女主平民 vs 男主豪门 | 身份差距 |
| 竹马 | 男女主从小认识 | 长大后相恋 |

## 典型配角原型

| 配角 | 作用 |
|---|---|
| 闺蜜 | 女主倾诉对象、推动感情 |
| 情敌 | 制造误会、推动剧情 |
| 男二 | 深情备胎、衬托男主 |
| 父母 | 家族阻力或支持 |
| 兄弟 | 男主社交圈、对比衬托 |

## 节拍模板

```markdown
### 言情四段式

相识：男女主相遇（偶然 / 必然）
  ↓
暧昧：互动、试探、心动
  ↓
误会：制造冲突（身份 / 第三者 / 家族）
  ↓
圆满：误会解开、关系确认

或

相识 → 相恋 → 误会 → 分离 → 重逢 → 圆满（虐恋情深版）
```

## 风格 DNA 默认值

- 句长：中等偏短（10-20 字）
- 修辞密度：中等（细腻描写）
- 对话比例：中高（40-60%）
- 标志性写法：心理描写、细节暗示、甜蜜对话

## 禁忌

- 男主霸道无脑（不尊重女主）
- 女主傻白甜（缺乏主动）
- 强行误会（缺乏逻辑）
- 男二工具人化（只为衬托男主）
