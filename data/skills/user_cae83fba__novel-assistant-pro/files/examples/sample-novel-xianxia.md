# 示例：玄幻流派《凡人之上》

> 用于展示玄幻流派的记忆文件结构与项目流程。

## 基本信息

- 小说名：凡人之上
- 类型/题材：玄幻 / 凡人修仙
- 目标平台：起点中文网
- 叙事人称：第三人称
- 当前章节：未开始
- 当前状态：构思中

## 风格规则

- 语言风格：克制、史诗感
- 节奏偏好：强情节 + 高爽点，每 5 章一次大爽
- 对话比例：中（30-50%）
- 禁用表达：「不是 X，是 Y」对比结构
- 标志性写法：装逼金句、打脸反杀
- 平台调性：起点中文网

## 世界观规则

### 硬规则（不可违反）

1. 修炼体系：练气 → 筑基 → 金丹 → 元婴 → 化神 → 仙人
2. 每个境界的突破需要"资源 + 领悟 + 生死历练"三重条件
3. 主角的初始定位是"凡人"（无灵根）
4. 主角的金手指是"残破古玉"（内含远古剑修的残魂）
5. 反派势力是"玄天宗"（与主角有不共戴天之仇）
6. 主要地图：凡人界 → 修真界 → 仙界

### 软规则（可扩展）

1. 丹药等级：下品 → 中品 → 上品 → 极品 → 仙品
2. 法器等级：灵器 → 宝器 → 灵宝 → 仙器
3. 宗门结构：外门弟子 → 内门弟子 → 真传弟子 → 长老 → 宗主

### 待定规则（未确认）

1. 是否引入多女主？
2. 是否引入"穿越"元素？
3. 是否引入"系统面板"？

## 主要人物

### 主角：林逸

- 身份：凡人界的贫寒少年
- 年龄/阶段：16 岁，修炼前
- 外显目标：成为强者，替父报仇
- 隐性需求：被认可、不再被人轻视
- 核心矛盾：天赋不足 vs 决心坚定
- 能力/限制：无灵根（凡人），但有"残破古玉"
- 与主线关系：核心主角
- 对话风格：倔强、隐忍、偶尔爆发
- 典型台词：「我林逸，就算没有灵根，也要走出一条路。」
- 不会说的话：「我认输」「我放弃」

#### 对话风格样本

- 语气关键词：倔强、隐忍
- 常用表达：「就算……也要……」「我……」
- 典型台词：「凡人又如何？凡人也有凡人的路。」
- 不会说的话：「我认输」「这不可能」（除非在极度震惊下）

#### 声音指纹

- 平均句长：12-18 字
- 句式偏好：短促反问、长复合句
- 修辞偏好：克制白描、偶尔反讽
- 口头禅：「我林逸」
- 词汇偏好：古语、武林话

### 导师/反派：玄天宗宗主

- 身份：玄天宗宗主，主角杀父仇人
- 年龄/阶段：元婴期修士
- 外显目标：飞升仙界
- 隐性需求：掩盖 30 年前的秘密
- 核心矛盾：野心 vs 良心（曾与主角父亲是好友）
- 能力/限制：元婴期修士，但有旧伤
- 与主线关系：终极反派
- 对话风格：威严、偶尔叹息
- 典型台词：「修仙界，弱肉强食。这是天道。」
- 不会说的话：「我错了」「对不起」（直到大结局）

#### 对话风格样本

- 语气关键词：威严、深沉
- 常用表达：「修仙界……」「天道……」
- 典型台词：「你父辈的事，与你何干？」
- 不会说的话：「我向你道歉」「我认错」

### 配角：苏婉

- 身份：玄天宗内门弟子，主角的青梅竹马
- 年龄/阶段：18 岁，金丹期
- 外显目标：成为玄天宗真传弟子
- 隐性需求：保护林逸
- 核心矛盾：宗门规矩 vs 个人情感
- 能力/限制：金丹期修士，但有宗门任务在身
- 与主角关系：暗恋对象
- 对话风格：温柔、克制
- 典型台词：「逸哥哥，你快走吧。」
- 不会说的话：「我不爱你」「你是凡人」（即使心中矛盾）

## 人物关系

- 林逸 与 玄天宗宗主：杀父之仇
- 林逸 与 苏婉：青梅竹马 + 暗恋
- 林逸 与 残破古玉：金手指传承
- 苏婉 与 玄天宗宗主：师徒
