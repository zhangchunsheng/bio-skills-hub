# 《星港尽头》记忆文件

## 基本信息
- 作品名：星港尽头
- 类型：科幻悬疑
- 目标读者：喜欢太空歌剧、身份谜团和人物反转的读者
- 叙事人称：第三人称有限视角
- 语言风格：克制、紧张、画面感强，避免解释过满

## 世界观
- 星港由七个环形城区组成，越靠内层权限越高。
- 失踪舰队曾参与十年前的“静默航线”任务。
- 黑匣子记录不可伪造，但可以被剪裁。

## 主要人物
### 林澈
- 身份：星港事故调查员
- 目标：查明父亲所在舰队失踪真相
- 矛盾：理性克制，但对父亲相关线索失去判断
- 对话风格：短句、追问多、很少直接表达情绪
- 典型台词："证据不会消失，只会被人放错地方。"

### 顾闻
- 身份：林澈导师，前舰队顾问
- 目标：阻止林澈接近静默航线真相
- 矛盾：保护林澈与掩盖真相之间摇摆
- 对话风格：温和、绕开核心问题、常用反问

## 人物关系
- 林澈信任顾闻，但从第 4 章开始怀疑他。
- 顾闻认识林澈父亲，且隐瞒了最后一次通讯记录。
