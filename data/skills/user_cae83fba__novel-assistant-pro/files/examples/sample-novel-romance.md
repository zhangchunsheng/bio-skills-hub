# 示例：言情流派《春暖花开》

> 用于展示言情流派的记忆文件结构与项目流程。

## 基本信息

- 小说名：春暖花开
- 类型/题材：言情 / 都市
- 目标平台：晋江文学城
- 叙事人称：第一人称（女主视角）
- 当前章节：未开始
- 当前状态：构思中

## 风格规则

- 语言风格：细腻、情感强
- 节奏偏好：慢热、强情节
- 对话比例：中高（40-60%）
- 禁用表达：网络用语、霸总套路
- 标志性写法：心理描写、细节暗示
- 平台调性：晋江文学城

## 世界观规则

### 硬规则（不可违反）

1. 时代背景：2025 年上海
2. 男女主身份：女主是新人律师，男主是合伙人
3. 关系起点中文网：律所上下级
4. 感情线阻力：律所规矩、行业性别偏见、男方母亲反对
5. 主要场景：律所、咖啡馆、女主公寓、男主家
6. 现实规则：律师行业规则、伦理规范

### 软规则（可扩展）

1. 配角：闺蜜、同事、男方母亲、女主父母
2. 行业术语：合伙人、案源、调解、诉讼
3. 季节：春（开篇）、夏（相识）、秋（暧昧）、冬（分离）、春（重逢）

### 待定规则（未确认）

1. 是否引入"先婚后爱"？
2. 是否引入"追妻火葬场"？
3. 是否引入"重生"？

## 主要人物

### 女主：林若晴

- 身份：律所新人律师
- 年龄/阶段：26 岁，入职第一年
- 外显目标：通过律师资格考试，成为合伙人
- 隐性需求：被尊重、被看见
- 核心矛盾：理想主义 vs 现实压力
- 能力/限制：有热情但经验不足
- 与主线关系：核心女主
- 对话风格：温柔、倔强、有时犹豫
- 典型台词：「我会努力的，请你相信我。」
- 不会说的话：「我不在乎」「我随便」

#### 对话风格样本

- 语气关键词：温柔、倔强
- 常用表达：「我会……」「我想……」
- 典型台词：「我选择这条路，不是为了别人，是为了我自己。」
- 不会说的话：「我不在乎输赢」

#### 声音指纹

- 平均句长：10-18 字
- 句式偏好：陈述句、偶尔反问
- 修辞偏好：细腻描写、心理活动
- 口头禅：「若晴」
- 词汇偏好：法律术语 + 日常用语

### 男主：陆辰

- 身份：律所合伙人
- 年龄/阶段：32 岁，合伙人第三年
- 外显目标：扩大律所规模
- 隐性需求：摆脱家族控制，证明自己
- 核心矛盾：理性 vs 情感
- 能力/限制：业务能力强但不懂表达
- 与女主关系：从上司到恋人
- 对话风格：克制、专业、偶尔温柔
- 典型台词：「这个案子，你跟。」
- 不会说的话：「我错了」「对不起」（直到中后期）

#### 对话风格样本

- 语气关键词：克制、专业
- 常用表达：「这个案子……」「我认为……」
- 典型台词：「我不喜欢把工作和生活混在一起。但有时候，我没得选。」
- 不会说的话：「对不起」（除非重大剧情转折）

## 人物关系

- 林若晴 与 陆辰：从上司到恋人
- 林若晴 与 闺蜜：倾诉对象
- 陆辰 与 母亲：家族压力
- 林若晴 与 母亲：理解支持
