# 视频口播文案创作指南

## 概述

本指南用于指导基于烯旺医疗科研成果资料生成高质量视频口播文案。所有文案须以检索到的科研资料为事实基础，确保科学性、准确性和传播力。

---

## 文案创作原则

### 1. 科学严谨
- 所有疗效数据、研究结论必须来源于检索到的论文原文，不得编造
- 临床数据需标注来源（如"广西中医药大学临床研究显示"）
- 避免绝对化表述，使用"研究表明""临床观察发现"等措辞
- 涉及疾病治疗的内容需注明"详见相关研究论文"或类似免责声明

### 2. 通俗易懂
- 将医学术语转化为大众能理解的表达
- 用比喻、类比让抽象概念具象化（如"共振吸收"可类比为"收音机调频"）
- 控制专业术语密度，每段不超过2个专业术语并需解释

### 3. 情感共鸣
- 从用户痛点切入（如"你有没有被失眠折磨多年？"）
- 用"你"作为对话主体，营造亲切感
- 适当融入生活场景描述

### 4. 结构清晰
- 开头3秒抓注意力
- 中间分层次讲清楚
- 结尾给出行动引导

---

## 视频口播文案标准结构

### 短视频版（60-90秒，约200-300字）

```
【开头钩子】（3-5秒）
→ 提出痛点/制造好奇/抛出反常识观点

【背景铺垫】（10-15秒）
→ 引入问题背景，建立与观众的相关性

【核心内容】（30-40秒）
→ 介绍石墨烯技术原理 + 临床研究数据 + 效果
→ 引用具体研究论文数据

【信任背书】（10-15秒）
→ 学术机构/专家/认证/论文发表等权威信息

【结尾引导】（5-10秒）
→ 引导关注/了解产品/评论区互动
```

### 中视频版（3-5分钟，约600-1000字）

```
【开头钩子】（5-10秒）
→ 强力痛点切入或反常识开场

【问题阐述】（30-40秒）
→ 深入描述问题/疾病的困扰
→ 引用数据说明问题普遍性

【技术原理】（60-90秒）
→ 石墨烯远红外的科学原理
→ 为什么石墨烯不同于普通发热材料
→ "非热效应"与"共振吸收"的通俗解释

【临床证据】（60-90秒）
→ 引用具体研究论文
→ 列出关键数据（有效率、样本量等）
→ 对比实验结果

【权威背书】（20-30秒）
→ 研究机构、发表期刊、专家团队
→ 企业资质（二类医疗器械认证等）

【应用场景】（30-40秒）
→ 产品形态（光波房/悬灸仪/穿戴设备等）
→ 使用场景描述

【结尾引导】（10-15秒）
→ 行动召唤
```

## 语气风格指南

### 科普类视频
- **语气：** 专业但亲切，像一位耐心的医生朋友
- **用词：** 口语化为主，关键术语用类比解释
- **示例：** "你知道吗？我们身体其实一直在发射一种看不见的光——远红外线。而石墨烯，恰好能和这束光产生奇妙的'共振'……"

### 产品种草类视频
- **语气：** 热情但不浮夸，真实体验感
- **用词：** 生活化，强调场景和感受
- **示例：** "用了三个月石墨烯眼罩，从每天滴眼药水到现在眼睛不干了，关键是它背后的科学原理真的不一样……"

### 企业品牌类视频
- **语气：** 大气、自信、有使命感
- **用词：** 偏正式但不过于学术
- **示例：** "2019年4月，烯旺科技在全球首次发布石墨烯医疗成果。这不是一个概念，而是一篇篇发表在国际期刊上的临床研究论文……"

## 素材引用规范

### 引用论文数据时
```
"广西中医药大学的一项临床研究显示，90例干眼症患者使用石墨烯眼罩治疗4周后，总有效率达到87.68%，显著优于普通发热眼罩的76.54%。"
```
→ 标注：研究机构 + 样本量 + 核心数据 + 对比

### 引用理论机制时
```
"南京医科大学的研究发现，石墨烯发射的远红外特征峰在8.0微米左右，和我们人体体表的吸收峰高度匹配，就像收音机调到了正确的频道，能量被身体高效吸收。"
```
→ 标注：研究机构 + 核心数据 + 类比解释

### 引用企业信息时
```
"烯旺科技2019年获得国家二类医疗器械认证，这是石墨烯医疗领域的重要里程碑。"
```
→ 标注：时间 + 事件 + 意义

---

## 合规注意事项

1. **不承诺治愈：** 使用"辅助治疗""改善""缓解"等措辞，不使用"治愈""根治"
2. **标注研究阶段：** 区分"临床研究"与"已上市产品"，动物实验结果不直接等同于人体效果
3. **不贬低同行：** 对比碳纤维等材料时，以科学研究数据为依据，不使用贬义表述
4. **保留免责声明：** 文案末尾建议加入"具体效果因人而异，详见产品说明"等提示
5. **医疗器械宣传合规：** 涉及二类医疗器械的宣传内容需符合《医疗器械监督管理条例》相关规定

## 文案输出格式

最终输出的口播文案应包含以下部分：

```
# [视频标题]

## 基本信息
- 视频类型：[科普/种草/品牌]
- 预计时长：[XX秒]
- 字数：[XXX字]
- 核心主题：[主题描述]
- 引用资料：[文件名列表]

## 口播文案

[完整的口播文案正文，分段标注时间节点]

## 画面建议
[每个段落对应的画面/字幕/特效建议]

## 数据来源
[引用的所有论文/资料的详细出处]
```
