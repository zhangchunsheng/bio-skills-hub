## 📋 功能详解

### 1. 全平台智能适配

| 平台 | 风格 | 字数 | 核心策略 |
|------|------|------|----------|
| 小红书 | 种草风 | 300-800字 | emoji密集 + 真实体验 + 干货信息图 |
| 微博 | 短快狠 | 140-280字 | 话题词 + 互动引导 + 争议点 |
| 抖音 | 口语化 | 50-200字 | 黄金3秒 + 行动指令 + 热门标签 |
| 公众号 | 深度干货 | 800-2000字 | 故事开头 + 结构化 + 金句收尾 |

### 2. 爆款DNA提取器

分析爆款文案的：
- 开头类型（数字/疑问/对话/故事）
- 情绪曲线（共鸣→高潮→转化）
- 结构模板（场景式/问题式/清单式/叙事式）
- 关键词密度TOP10
- 风格指纹（口语化/专业度/互动性/感召力/亲和力）
- 传播潜力评分（0-10分）

### 3. AI痕迹消除引擎

消除六大AI写作特征：
1. 夸大象征意义 → 用具体场景替代
2. 宣传性语言 → 用客观描述
3. 三段式机械结构 → 用自然过渡
4. AI万能词汇 → 直接删除
5. 破折号过度使用 → 换标点
6. 否定式排比 → 正面陈述

### 4. 智能SEO优化

- 7种标题公式（数字型/疑问型/对比型/命令型/揭秘型/清单型/故事型）
- 平台热搜词匹配
- 标签策略自动生成
