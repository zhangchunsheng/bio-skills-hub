# 电商详情页文案生成器

## 功能介绍
输入产品信息，一键生成专业电商详情页文案，包含标题、卖点、产品描述、场景化文案，提升转化率。

## 使用方法
把你的产品信息发给AI，例如：
- 「帮我写一款无线蓝牙耳机的详情页，卖点：降噪、续航24小时、防水」
- 「生成护肤品详情页，产品是烟酰胺精华，主打美白淡斑」
- 「我卖保温杯，316不锈钢，24小时保温，帮我写详情页」

需要提供的信息（越详细越好）：
- 产品名称和品类
- 核心功能/特点
- 目标人群
- 价格区间
- 竞品差异点

## 输出内容
- 主标题+副标题（抓眼球+讲清楚）
- 3-5个核心卖点（FAB法则）
- 产品详情描述
- 场景化文案
- 详情页结构排版建议

## 适合人群
淘宝/天猫/京东/拼多多卖家、电商运营、产品文案策划、独立站卖家
