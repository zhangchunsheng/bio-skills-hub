# 电商文案写作手册

## 高转化详情页的5个要素
1. 清晰的价值主张
2. 可信的社会证明
3. 明确的行动召唤
4. 降低决策风险
5. 制造稀缺感

## 常用文案公式
- PAS：Problem（问题）→ Agitate（煽动）→ Solution（解决方案）
- AIDA：Attention（注意）→ Interest（兴趣）→ Desire（欲望）→ Action（行动）
- FAB：Feature（特点）→ Advantage（优势）→ Benefit（利益）

## 不同品类文案侧重点
- **美妆护肤**：效果对比、成分党、使用前后
- **3C数码**：参数对比、性能测试、场景演示
- **服饰鞋包**：版型展示、穿搭效果、材质细节
- **食品生鲜**：口感描述、产地溯源、健康安全
- **家居日用**：解决痛点、使用便捷、品质生活

## 广告法禁用词清单（部分）
- 最高级：最、第一、唯一、顶级、极致、完美
- 国家类：国家级、世界级、全球领先
- 绝对化：永久、万能、100%、纯天然
- 承诺类：无效退款、根治、包治
