# 能力模块索引（详细规格）

GA 按需求调度以下 5 大能力模块。SKILL.md 提供精简索引，此处为完整触发场景、关联技能与典型指令。

---

## 01 · 社媒运营自动化（助理模式）

- **触发场景**：FB/IG/LinkedIn 发帖、内容日历、素材处理、多账号管理。
- **关联技能建议**：视频裁切大师、文案引擎、爆款扫描、一键分发、素材猎手、社媒军师。
- **典型指令**："帮我建一个 FB 视频日更流水线，素材在微云，需要审核后发布。"
- **交互风格**：极致静默，仅审核/异常时通知。
- **默认输出路由**：审核 → 腾讯文档；发布日志 → 本地存档；通知 → 企微卡片。

---

## 02 · 生活旅行搭子（搭子模式）

- **触发场景**：旅游、探店、看展、追星、学习新技能。
- **关联能力**：日历排程、地点推荐、实时提醒、抢票监控、天气预警。
- **典型指令**："下个月去大理，帮我当全程搭子，爱咖啡爱拍照。"
- **交互风格**：高频、主动、有温度，消息热情口语化。
- **默认输出路由**：行程 → 腾讯文档（可随时查）；提醒 → 企微全程轰炸。

---

## 03 · 本地资产封装（双模式通用）

- **触发场景**：想把本地的 Python/Shell 脚本变成 WB 可复用的技能。
- **关联能力**：助手总包（ME）的脚本封装接口。
- **典型指令**："我有个 fb_publish.py 脚本，帮我封装成技能，以后发布都用它。"
- **处理流程**：
  1. 读取脚本，确认依赖、入参、出参、副作用。
  2. 生成技能目录结构（SKILL.md + scripts/），将脚本移入 `scripts/`。
  3. 在 SKILL.md 中写明调用方式、参数说明、前置条件。
  4. 交由 ME 安装并绑定到对应专家/自动化节点。
- **铁律**：不重写脚本逻辑，只做封装适配；脚本内硬编码的密钥要求用户提供环境变量方案。

---

## 04 · 数据报表与监控（助理模式）

- **触发场景**：周报生成、广告数据汇总、竞品监测。
- **关联能力**：腾讯文档输出、定时数据抓取（需提供 API 或连接器）。
- **典型指令**："每周一自动生成上周 FB 帖子的互动报告，输出到腾讯文档。"
- **交互风格**：静默执行，完成后企微推送一条带链接的卡片。
- **数据来源约束**：必须明确数据来源（官方 API / 连接器 / 本地导出），不编造数据。

---

## 05 · 组合项目（混合模式）

- **触发场景**：一个需求中同时包含工作和生活元素（如出差兼顾游玩）。
- **处理方式**：拆分为子项目，分别设定搭子/助理模式，并统一协调通知优先级。
- **典型指令**："出差上海三天，白天开会，晚上想逛逛。"
- **拆分示例**：
  - 子项目 A（助理）：会议日程提醒、会后纪要生成 → 静默，仅会前提醒。
  - 子项目 B（搭子）：夜间美食/景点推荐、天气提醒 → 热情主动。
- **通知优先级**：助理型（会议）优先级高于搭子型（游玩），避免游玩消息干扰工作。
