# 触发与能力边界总表

本文件是判断是否调用本技能的统一入口。先看安全，再看范围，最后看用户是否需要关系分析或行动决策。

## 直接触发关键词

| 类别 | 关键词与常见说法 |
|---|---|
| 职场关系 | 抢功、甩锅、排挤、越级、背锅、资源争夺、绩效冲突、领导打压、同事使绊子 |
| 合作与金钱 | 合伙、分钱、拖款、欠款、借钱、账目不清、贡献不对等、口头约定、合作方试探 |
| 边界与谈判 | 拒绝、设边界、试探底线、谈条件、讨价还价、被占便宜、如何开口、怎么谈 |
| 关系判断 | 识人、隐藏动机、忽冷忽热、双标、控制、内耗、被利用、被操控、权力不对等 |
| 行动障碍 | 不敢拒绝、害怕冲突、总是心软、知道该做但做不到、反复被说服 |

关键词本身不证明恶意。只有用户需要判断互动、选择策略、设置边界、谈判或采取行动时才使用本技能。

## 应该触发

- 用户描述了具体互动，希望判断事实、动机可能性或利益结构；
- 用户需要在合作、保护、降依赖、升级和退出之间作选择；
- 用户想要可直接使用的话术、谈判步骤、留痕方式或边界方案；
- 用户知道合理边界，却因愧疚、恐惧或依赖难以行动；
- 问题同时包含关系与法律、医疗等内容，但仍有明确的人际决策部分。

## 不应触发

- 国际政治、战争、政党或历史权谋分析；
- 只要求法律效力、罪名、赔偿金额或诉讼结论；
- 临床诊断、药物建议或心理疾病判定；
- 企业投资、证券、财务估值或市场研究；
- 与具体关系无关的习惯养成、一般知识问答；
- 用户只要情绪陪伴，明确不需要分析或行动建议。

## 混合请求

先拆分，再处理：

| 请求组成 | 本技能保留 | 需要转向 |
|---|---|---|
| 关系 + 法律 | 目标、沟通、证据保存、谈判与风险 | 当前法律、司法辖区、罪名或效力 |
| 关系 + 临床 | 可观察行为、影响、边界与安全 | 疾病、人格障碍或治疗诊断 |
| 关系 + 当前事实 | 利益、依赖、选择与沟通 | 最新规则、新闻、机构政策 |
| 关系 + 财务 | 合作结构、权限、账目透明和退出条件 | 投资收益、税务或专业会计结论 |

保留能安全分析的部分，不因一个范围外词汇丢弃整项请求。

## 安全优先

出现暴力、跟踪、堵门、威胁、自伤、诈骗、勒索、隐私侵犯或急性危险时，暂停普通博弈建议。优先读取 `evidence-and-safety.md`，给即时安全、可信支持、证据保存和专业转向；不得建议刺激、试探或当面对抗。

## 一分钟判断

1. 有急性危险或有害请求吗？有则安全优先或拒绝并替代。
2. 用户要的是纯专业结论吗？是则转向，只保留关系部分。
3. 用户有具体关系决策或行动目标吗？有则触发。
4. 只有标签或泛泛科普吗？先请其给一个具体互动；若无具体关系任务，不触发。
