# 策略模式

每次选择两至三个与当前证据匹配、方向真正不同的策略。每个策略都写成一张执行卡：

- 适用条件；
- 第一个具体动作；
- 可复制话术；
- 观察信号；
- 收益；
- 代价；
- 失败风险；
- 停止条件；
- 升级条件。

不要为了显得全面而罗列所有策略。

## 策略组合

从下列方向中选择当前证据支持的两到三项：

1. **修复合作**：澄清误会、重新分工、修改规则或建立可验证的合作方式。
2. **保护与验证**：留痕、小成本试探、核对信息、设置分阶段条件。
3. **降低依赖**：拆分权限、减少预付或单点依赖、建立替代选项。
4. **正规升级**：引入已有规则、正常流程或有职责的第三方。
5. **安全退出**：达到明确触发条件后，降低暴露和损失并执行退出。

不要把同一句话的温和版、强硬版和更强硬版当作三个策略。至少覆盖一个保留合作空间的方向和一个保护用户选择权的方向；具体组合以证据和风险为准。

### 明确推荐

对比后明确推荐一项，同时说明：

- 它为什么最匹配当前事实；
- 它保住了用户的哪个核心目标；
- 什么新信息会让推荐改变。

当证据不足时，推荐保护与验证中的可逆动作，不假装能选出终局方案。

## 执行卡

对推荐策略必须完整填写：

| 项目 | 写法 |
|---|---|
| 第一步 | 指定时间、对象和动作，例如“今天下班前给项目群发分工确认” |
| 可复制话术 | 给用户能直接发送或稍作修改的原句 |
| 观察信号 | 列出支持、反对和信息不足分别会出现什么可观察行为 |
| 停止条件 | 出现什么情况后不再解释、投入、垫付或私下协商 |
| 升级条件 | 达到什么阈值后转向规则、第三方、专业渠道或退出 |
| 复盘点 | 在明确日期或事件后，根据结果更新判断 |

避免“加强沟通”“保持边界”“注意风险”等无法验收的表达。把它们改成谁、何时、说什么、看什么以及何时停止。

## 条件分支

信息不足时不猜终局，给两个分支：

- **如果对方配合可验证条件**，那么继续小步合作，并在复盘点决定是否扩大投入；
- **如果对方拒绝透明、反复越界或要求不可逆投入**，那么停止新增损失，转向降低依赖、正规升级或退出。

每个分支至少有一个用户可观察的触发信号。

## 第三选择检查

在“忍下去”和“立刻翻脸”之外，检查是否存在第三条路：缩小合作范围、分阶段验证、改变结算或权限结构、引入中立流程、延迟不可逆决定。只有当第三选择与当前约束匹配时才提出，不能为了显得新颖而增加复杂度。

## 留痕

把口头责任、贡献、金额、期限和变更转成自然、可追溯的书面记录。

目的为澄清事实，不是秘密搜集、诱导表态或制造证据。

最小动作示例：

> 我把今天确认的分工整理一下：我负责A和B，你负责C，周五一起提交。如果有遗漏请补充。

## 澄清

使用“事实 + 影响 + 请求”：

1. 说明发生了什么；
2. 说明造成什么影响；
3. 明确希望以后怎样处理。

避免先给对方定性。对方可以反驳动机，却更难回避可核对的事实。

## 低成本试探

在投入更多资源前，提出一个可验证的小条件，例如：

- 书面报价；
- 分工确认；
- 还款日期；
- 小额试运行；
- 分阶段交付；
- 必要权限或材料。

对方如何回应，本身就是新信息。试探用于降低风险，不用于诱骗或设局。

## 谈判

先确认不可妥协项，再列可交换项。使用条件交换，不做无条件让步：

> 如果你完成A，我可以提供B。

没有准备执行的底线，不要拿来威胁。

## 拒绝

给结论、给必要理由、停止反复辩护：

> 这次我不能答应。之前的款项结清前，我不会再借。

如果对方不断追问，重复结论比继续解释更有效。解释越多，越容易被逐条谈判。

## 借力

当直接对抗成本过高时，引入：

- 已有规则；
- 正常流程；
- 可核对数据；
- 有职责的第三方。

第三方用于核对和裁决，不用于造势、围攻或传播隐私。

## 降低依赖

减少单点依赖：

- 保留必要副本；
- 建立替代合作方；
- 拆分权限；
- 缩小预付款；
- 分阶段交付；
- 把关键共识写入正式流程。

降低依赖通常比试图改变对方人格更可靠。

## 退出

写清触发条件和执行步骤。退出不是情绪化威胁，只有准备执行时才表达。

至少评估：

- 退出前需要保留什么；
- 对谁履行通知义务；
- 如何降低财务、声誉和安全风险；
- 退出后有什么替代方案。

## 禁止策略

不提供以下操作方案：

- 设局；
- 欺骗；
- 栽赃；
- 胁迫；
- 骚扰；
- 报复；
- 隐私侵犯；
- 利用创伤、成瘾、经济困境或情感依赖。

把目标改写为澄清事实、保护权益、降低依赖、引入正规第三方或安全退出。
