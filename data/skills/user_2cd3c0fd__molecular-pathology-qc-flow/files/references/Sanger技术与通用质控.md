# Sanger 技术与通用质控

作者：WangYunL  
核对日期：2026-08-27

## 一、技术定位

Sanger 测序采用链终止测序反应和毛细管电泳读取目标区域序列，常用于特定位点检测、较短区域分析或其他方法结果确认。Thermo Fisher 的技术概览将其工作流概括为 PCR 扩增、测序反应、毛细管电泳和数据分析。

来源：Thermo Fisher, What is Sanger Sequencing?  
https://www.thermofisher.com/us/en/home/life-science/sequencing/sequencing-learning-center/capillary-electrophoresis-information/what-is-sanger-sequencing.html

## 二、通用质控阶段

| 阶段 | 通用质控点 | 常见问题 |
| --- | --- | --- |
| PCR 产物 | 目标区域、特异性、产物量和污染控制 | 无产物、非特异扩增、混样 |
| 测序反应 | 模板和引物、反应体系、方向和板位 | 引物错误、加样错误、反应失败 |
| 毛细管电泳 | 仪器、聚合物、毛细管和运行对照 | 信号弱、迁移异常、运行失败 |
| 峰图质控 | 背景、峰形、可读区间和碱基质量 | 噪声高、峰重叠、前端或末端不可读 |
| 结果复核 | 正反向一致性、参考序列和命名 | 单向证据不足、比对或命名错误 |

## 三、阈值边界

峰高、信噪比、可读长度、碱基质量和最低可检出变异比例均可能受仪器、试剂、软件和样本影响。没有实验室验证资料时，只能列为待确认指标，不能生成数值接受标准。

## 四、流程图建议

1. PCR 产物不合格与测序反应失败应分开处置。
2. 峰图质量不合格可进入重复测序、反向测序或重新扩增，但回环必须标记处置含义。
3. 只有满足当前 SOP 的峰图和复核条件后，才能进入结果完成终点。
4. `assets/Sanger通用质控.json` 是通用结构模板，不替代实验室 SOP。
