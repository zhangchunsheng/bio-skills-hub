# FISH 技术与通用质控

作者：WangYunL  
核对日期：2026-08-27

## 一、技术定位

FISH（荧光原位杂交）使用荧光标记探针，在细胞或组织原位识别特定核酸区域。根据探针设计，可用于评估重排、融合、扩增、缺失或其他信号模式。ALK 重排 FISH 是项目层概念，具体探针、样本和判读规则必须绑定产品说明书和实验室 SOP。

权威实例来源：

- FDA Vysis ALK Break Apart FISH Probe Kit PMA：https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfpma/pma.cfm?id=p110012
- FDA Labeling：https://www.accessdata.fda.gov/cdrh_docs/pdf11/P110012C.pdf
- FDA Summary of Safety and Effectiveness Data：https://www.accessdata.fda.gov/cdrh_docs/pdf11/P110012b.pdf

## 二、通用实验阶段

FDA ALK FISH 产品资料展示了 FFPE 组织切片预处理、探针杂交、洗涤、DAPI 复染、荧光信号观察以及阳性/阴性对照等关键环节。这些环节可用于建立通用质控框架，但具体条件只适用于相应产品标签范围。

| 阶段 | 通用质控点 | 失败或待处理方向 |
| --- | --- | --- |
| 样本与切片 | 样本标识、组织区域、切片质量和可评估细胞 | 重新选区、重切或退样 |
| 预处理 | 脱蜡、消化和组织形态保存 | 调整或重复预处理 |
| 杂交 | 探针、温度、时间和封片完整性 | 重复杂交或调查试剂/设备 |
| 洗涤与复染 | 背景、DAPI 和信号保留 | 重洗、复染或重做 |
| 信号质控 | 对照、信号强度、背景和可计数细胞核 | 整批或单样本无效 |
| 计数与判读 | 信号模式、计数范围、截止值和灰区复核 | 增加计数、第二阅片人或重做 |

## 三、ALK 项目边界

ALK 分离探针项目需要依据匹配版本 IFU 确认：适用样本、目标细胞选择、正常与异常信号模式、计数细胞数、截止值、灰区和双人复核规则。Skill 不内置这些数值，避免把一个产品或实验室的规则推广为全部 ALK FISH。

## 四、流程图建议

1. 将“切片可评估”“对照和信号质量合格”“计数及判读条件满足”拆成不同判断节点。
2. 把重切、重复杂交、增加计数和人工复核写成明确处置，不使用笼统“异常”。
3. 通用模板使用 `CUSTOM` 条件，收到 IFU/SOP 后再替换成结构化数值或枚举规则。
4. `assets/FISH-ALK通用质控.json` 只演示结构和泳道，不是临床执行规则。
