## 三、流程

1. 输入 PCR 下机数据。
2. 判断 FAM Ct 是否小于等于 24。
3. 如果是，直接判定 BRAF V600E 阳性；VIC 不参与该分支判定。
4. 如果否，判断 FAM 是否有 Ct，且 24 小于 Ct、小于 35。
5. 如果 FAM 无 Ct 或 Ct 大于等于 35，判定未检出突变。
6. 如果进入灰区，判断 VIC Ct 是否小于等于 20。
7. 如果 VIC 不满足条件，判定结果无效，处置为增加上样量或重新提取。
8. 如果 VIC 满足条件，计算 ΔCt = FAM Ct − VIC Ct。
9. 判断 ΔCt 是否小于等于 13。
10. 如果是，判定 BRAF V600E 阳性；如果否，判定未检出突变。
