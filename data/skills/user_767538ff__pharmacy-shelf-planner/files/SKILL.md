# 药房货位智能规划

## 概述

本技能将医院药房历史发药数据转化为可落地的货位调整方案。按照GSP货位管理规范，
结合ABC-XYZ库存分析法与智能货位规划算法，输出包含红色预警（紧急调整）和黄色建议
（常规优化）的结构化报告，附带可执行的货位规划表。

## 适用场景

- 药房季度/年度货位复盘与调整
- 新建药房或搬迁时的初始货位规划
- 临购药品转正/退库决策
- 高警示药品合规检查
- 拣选动线优化（S型路径设计）

## 前置条件

- 输入文件：药房发药/出库数据（xls/xlsx/csv），至少包含：科室、药品名称、规格、数量、单位字段
- 推荐数据周期：≥6个月（用于波动分析）
- Python环境：pandas + xlrd + openpyxl

## 标准化分析流程（10步）

### 步骤1：数据清洗

执行 `scripts/pharmacy_analysis.py`，自动完成以下清洗：
- 移除合计行、空行
- 数量列转数值型，缺失值填充0并标记异常
- 药品名称/规格/科室字段去空白
- 标记零发药记录和停用药品（名称含"(停用)"）

关键参数：`PERIOD_MONTHS`（数据周期月数，默认12）

### 步骤2：周转计算

- 月均消耗 = 总量 / PERIOD_MONTHS
- 周转等级划分：极高(>200/月)、高(50-200)、中(10-50)、低(1-10)、极低(<1)
- 注：无库存数据时，周转率以月均消耗+科室覆盖度近似

### 步骤3：专科标签化

按药品适应症和科室分布自动匹配标签：
- 【女性】：妇科/产科用药（缩宫素、益母草、地屈孕酮等）
- 【儿童】：儿科专属药品或儿科使用占比≥40%
- 【康复】：康复科用药（肠内营养、精神类、肉毒毒素等）或康复科使用占比≥40%
- 【通用】：无明显专科倾向
- 【临购】：药品名含"【临购】"标记，记录来源科别

标签规则详见 `references/drug_tagging_rules.md`

### 步骤4：ABC-XYZ矩阵分类

**ABC分类**（按用量累计占比，排除停用药品）：
- A类：累计前70%
- B类：70%-90%
- C类：后10%

**XYZ分类**（按科室间变异系数CV）：
- X类：CV≤0.5（需求稳定）
- Y类：0.5<CV≤1.5（季节/周期波动）
- Z类：CV>1.5 或 临购药品（极高波动）

### 步骤5：五级货位编码

编码结构：**区-架-层-位-库**

| 级别 | 含义 | 取值规则 |
|------|------|----------|
| 区 | 药理大类 | A=门诊住院常用药, F=康复精神药, G=高警示, H=临购, I=外用, K=输液, L=输液备选, M=阴凉柜 |
| 架 | 药理子类 | 药理大类代码后两位 |
| 层 | 周转等级 | 3=黄金层, 2=中下层, 1=下层/上层 |
| 位 | ABC分类 | 01=A类, 02=B类, 03=C类 |
| 库 | 特殊管理 | G=高警示, H=临购, M=阴凉柜, 空=常规 |

药理大类匹配规则详见 `references/pharma_categories.md`

### 步骤6：关联度聚类

- 构建科室-药品矩阵
- 按科室大类聚合（妇产科/儿科/康复科/手术室/其他）
- 取各科室大类TOP20药品，计算两两共现强度（共同科室最小用量）
- 输出TOP15高频处方组合，指导相邻放置

### 步骤7：黄金层分配

| 矩阵分类 | 物理层位 | 高度 |
|----------|----------|------|
| AX, AY | 黄金层 | 1.2-1.5m |
| AZ | 中下层 | 0.6-1.2m |
| BX, BY | 中下层 | 0.6-1.2m |
| BZ | 下层 | 0-0.6m |
| CX, CY, CZ | 上层 | 1.5-1.8m |
| 停用 | 退库区 | — |

### 步骤8：临购专项处置

30天观察期机制：
- 发药频次≥3次/月 或 总量≥20 → **建议转常规**，分配正式货位
- 发药≤1次/季 且 总量≤5 → **建议释放归档**，退出临购专区
- 其他 → **继续观察**，维持临时编码H区

### 步骤9：合规兜底检查

强制检查项：
1. 高警示药品（▲★标记或特定药品）不得位于底层（0-0.6m）→ 违规则强制调整至中下层
2. 高警示药品必须加贴红底黑字标识
3. 精神/毒性药品（【精一】【精二】【毒性】）必须分配至M区阴凉柜
4. 易混淆药品（▲△★●☆标记）必须分层摆放

### 步骤10：输出生成

执行 `scripts/pharmacy_analysis.py` 生成以下文件：
- `药品货位规划表.xlsx` — 完整货位编码+物理层位+调整标记
- `高频处方关联组合.xlsx` — TOP15处方组合及关联强度
- `临购药品处置建议.xlsx` — 转常规/观察/释放分类
- `analysis_summary.json` — 汇总统计数据

可选执行 `scripts/generate_report.py` 生成可视化HTML报告。

## 使用方法

```bash
# 1. 修改脚本中的 INPUT_FILE 和 PERIOD_MONTHS
# 2. 运行分析
python scripts/pharmacy_analysis.py

# 3. （可选）生成HTML报告
python scripts/generate_report.py
```

## 专科定制要点

### 妇幼康复专科医院
- 女性用药（激素类、妇科外用制剂）按药理分类集中
- 儿童用药安全：儿童药品独立分区
- 康复科临购药品专项追踪：临时观察-转正/退库动态管理
- 外观/读音相似药品严格分层摆放

### 其他专科类型
- 修改 `references/drug_tagging_rules.md` 中的标签关键词
- 修改 `references/pharma_categories.md` 中的药理大类映射
- 调整 `scripts/pharmacy_analysis.py` 中的 `DEPT_GROUP` 字典

## 注意事项

- 原始数据无日期维度时，月均消耗按总量/周期月数估算
- 原始数据无价格时，ABC分类以用量替代金额
- 原始数据无库存时，周转率以用量+科室覆盖度近似
- 冷藏药品和特殊管理药品（麻醉/精神一类）的货位分析需另行处理
