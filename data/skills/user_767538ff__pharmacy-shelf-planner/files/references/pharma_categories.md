# 药理大类分类规则

## 分类体系

药理大类按关键词优先级匹配，匹配到第一个即停止。每类对应一个货位区码。

| 货位区码 | 药理大类代码 | 药理大类名称 | 关键词示例 |
|----------|-------------|-------------|-----------|
| K | L01 | 大输液类 | 氯化钠注射液、葡萄糖注射液、乳酸钠林格、灭菌注射用水、甘露醇 |
| A | A01 | 抗感染药 | 头孢、青霉素、阿莫西林、美罗培南、万古霉素、克林霉素、甲硝唑、左氧氟沙星 |
| A | A02 | 妇科/产科专科药 | 缩宫素、阿托西班、利托君、硫酸镁、益母草、地屈孕酮、黄体酮、雌二醇 |
| A | A03 | 抗凝/止血药 | 肝素、依诺肝素、华法林、利伐沙班、氨甲环酸、维生素K |
| A | A04 | 营养/血液系统药 | 蛋白琥珀酸铁、多糖铁、叶酸、维生素B12、肠内营养、氨基酸、脂肪乳 |
| A | A05 | 心血管系统药 | 阿托伐他汀、非诺贝特、硝苯地平、氨氯地平、美托洛尔、缬沙坦、呋塞米 |
| A | A06 | 消化系统药 | 奥美拉唑、兰索拉唑、伏诺拉生、硫糖铝、多潘立酮、开塞露、乳果糖、蒙脱石 |
| F | A07 | 神经/精神系统药 | 右佐匹克隆、氯硝西泮、阿米替林、曲唑酮、丙戊酸、卡马西平、尼莫地平 |
| A | A08 | 呼吸系统药 | 氨溴索、羧甲司坦、氨茶碱、布地奈德、沙丁胺醇、孟鲁司特、奥司他韦 |

| A | A10 | 生物制品/免疫调节 | 人血白蛋白、免疫球蛋白、胸腺肽、干扰素、肉毒毒素、地舒单抗 |
| A | A11 | 内分泌/降糖药 | 胰岛素、格列美脲、二甲双胍、阿卡波糖、西格列汀、达格列净 |
| A | A12 | 激素/内分泌药 | 甲巯咪唑、左甲状腺素、泼尼松、甲泼尼龙、地塞米松、氟轻松 |
| K | A13 | 电解质/酸碱平衡 | 氯化钾、葡萄糖酸钙、碳酸氢钠、硫酸镁 |
| I | I01 | 外用消毒/皮肤制剂 | 碘伏、碘酊、酒精、过氧化氢、氯己定、硫软膏 |
| I | I02 | 外用制剂 | 乳膏、软膏、凝胶、酊、喷雾剂、贴剂、栓剂、滴眼液、泡沫剂 |
| A | C01 | 中成药 | 益母草、开喉剑、银胡感冒、板蓝根、蒲地蓝、丹参、六味地黄 |

## 剂型推断规则

按药品名+规格文本匹配：

| 关键词 | 剂型 |
|--------|------|
| 注射液、注射用 | 注射剂 |
| 输液、氯化钠注射液、葡萄糖注射液 | 大输液 |
| 片、分散片、缓释片、控释片、肠溶片 | 口服固体制剂 |
| 胶囊、软胶囊 | 口服固体制剂 |
| 颗粒、干混悬、散剂 | 口服颗粒/散剂 |
| 口服液、口服溶液、混悬液、糖浆、合剂 | 口服液体制剂 |
| 乳膏、软膏、凝胶、霜、搽剂、洗剂 | 外用半固体制剂 |
| 滴眼液、眼膏、滴耳液、鼻喷、喷雾剂、气雾剂、泡沫剂、贴剂、酊 | 外用液/气雾剂 |
| 栓剂、栓 | 栓剂 |

## 易混淆药品标记体系

| 标记 | 含义 | 管理要求 |
|------|------|----------|
| ▲ | 高警示药品 | 红底黑字标识，禁止底层 |
| △ | 同类名似药品 | 分层摆放，隔位放置 |
| ★ | 产科急救药品 | 集中放置，急救动线优先 |
| ● | 重点监测药品 | 定期盘点，双人核对 |
| ☆ | 普通警示药品 | 黄底标识 |

## 五级编码示例

```
A-02-3-01-G
│  │  │ │  └─ 库码：G=高警示专区
│  │  │ └──── 位码：01=A类
│  │  └─────── 层码：3=黄金层(1.2-1.5m)
│  └────────── 架码：02=妇科/产科专科药
└─────────── 区码：A=门诊住院常用药
```

解读：A区（门诊住院常用药）、02架（妇科产科专科药）、黄金层、A类、高警示专区
