# 药品专科标签规则

## 标签体系

| 标签 | 适用人群 | 匹配规则 |
|------|----------|----------|
| 【女性】 | 妇产科患者 | 药品名含女性专科关键词 或 妇产科使用占比≥30% |
| 【儿童】 | 儿科患者 | 药品名含儿童关键词 或 儿科使用占比≥40% |
| 【康复】 | 康复科患者 | 药品名含康复关键词 或 康复科使用占比≥40% |
| 【通用】 | 全院通用 | 无明显专科倾向 |
| 【临购】 | 临时采购 | 药品名含"【临购】"标记 |

## 临购药品标记规则

- 药品名含"【临购】" → 标记为临购
- 药品名同时含"(停用)" → 标记为停用临购（不参与活跃临购统计）
- 记录来源科别：从发药数据中提取该药品的所有使用科室

## 高警示药品判定规则

满足以下任一条件即为高警示药品：
1. 药品名含▲或★标记
2. 药品名含以下关键词：人血白蛋白、免疫球蛋白、肉毒毒素、50%葡萄糖、氯化钾、
   浓氯化钠、胰岛素、肝素、依诺肝素、硫酸镁、缩宫素、阿托西班、利托君、
   肾上腺素、去甲肾上腺素、去氧肾上腺素、多巴胺、多巴酚丁胺、硝普钠、
   氨茶碱、甲氨蝶呤、长春新碱、顺铂、高渗

## 精神/毒性药品判定

药品名含以下标记：【精一】【精二】【毒性】【麻醉】【易制毒】
