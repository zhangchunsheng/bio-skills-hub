## 故障排除

**问题：验证失败，缺少必需字段**
- 症状：错误提示缺少 SDTM 字段
- 原因：
  - 数据导出缺少列
  - 字段名与 SDTM 不同
  - 部分数据提取
- 解决方案：
  - 检查数据导出设置
  - 将字段名映射到 SDTM 标准
  - 导出完整数据集

**问题：检测到过多异常值**
- 症状：超过 20% 的数据被标记为异常值
- 原因：
  - 检测方法与数据分布不匹配
  - 数据质量问题
  - 单位不正确
- 解决方案：
  - 对临床数据使用领域特定阈值
  - 检查原始数据是否存在系统性错误
  - 核实单位一致性

**问题：日期解析错误**
- 症状：大量日期被转换为 NaT（Not a Time）
- 原因：
  - 源数据中日期格式混杂
  - 非标准日期字符串
  - 国际日期混淆（DD/MM 与 MM/DD）
- 解决方案：
  - 在源系统中统一日期格式
  - 明确指定日期格式
  - 手动检查无法解析的日期

**问题：填补产生不合理的值**
- 症状：填补值超出合理范围
- 原因：
  - 填补策略选择错误
  - 数据高度偏态
  - 不同子组数据混合
- 解决方案：
  - 对偏态数据使用中位数而非均值
  - 在相关子组内分别填补
  - 考虑使用多重填补

**问题：清洗后数据比原始数据更大**
- 症状：输出文件比输入文件更大
- 原因：
  - 添加了异常值标记列
  - 日期格式扩展（增加了时间）
  - 字符串列变宽
- 解决方案：
  - 这是正常现象——审计列会增加体积
  - 如需存储可进行压缩
  - 分别归档原始数据和清洗后数据

**问题：处理大型数据集时出现内存错误**
- 症状："MemoryError" 或系统冻结
- 原因：
  - 数据集超出可用内存容量
  - 数据类型效率低下
  - 处理过程中存在内存泄漏
- 解决方案：
  - 分块处理数据
  - 优化数据类型（分类型、更小的浮点数）
  - 对超大数据集使用云端处理
  - 考虑基于数据库的清洗方式
