# AI 图像生成与编辑

- 唯一标识：`hub-generate-image`
- 显示名称：AI 图像生成与编辑
- 能力摘要：通过图像生成与编辑模型创建照片、插画和产品视觉素材，围绕清晰提示、构图、风格、迭代、来源透明和使用边界产出可交付图像。

## 案例素材

1. 产品团队需要新功能的概念插画。该 skill 会将受众、信息层级、场景、色调和留白写成视觉 brief，生成多个方向并由设计师选择与调整。
2. 电商需要统一的背景素材。该 skill 会定义尺寸、主体位置、品牌配色和可复制的提示模板，避免直接生成包含真实商标、误导性价格或不当人物肖像的图像。
3. 研究报告需要示意图。该 skill 会将图像标为概念性插图而非数据证据，核对标签与科学关系，并在需要精确结构时转向可编辑图表或专业绘图。
