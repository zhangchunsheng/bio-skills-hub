## 用例 1：18 项核心制度前置核查（S1-S6 全流程）

**输入**：65 岁男性，拟行腹腔镜胆囊切除；术前已行术前讨论（副高主持）、三方核查（麻醉前/切皮前/离室前）、术者具二级授权；术后 20h 才补记手术记录
**期望输出**（至少3条）：
- [x] 风控栏逐步骤输出制度核查结果（S1-S6 全覆盖）
- [x] 🔴 红线：手术记录 >24h 内补记？——本例 20h 达标（≤24h），标 🟢；若 >24h 则 🔴
- [x] 术前讨论/三方核查/手术分级均标 🟢 合规，附 `[法]` 依据（《医疗机构手术分级管理办法》2022）
- [x] L5 场景命中（手术）→ 放行结论标「需术者/医务科确认」

## 用例 2：病历质控红线（丙级判定）

**输入**：抽查 1 份归档病历：主诊断编码错误 + 抢救记录 7h 补记 + 无患者入院记录
**期望输出**（至少3条）：
- [x] 🔴 否决：主诊断编码错误/无入院记录/抢救记录超 6h → 丙级（单项否决）
- [x] 逐项列出触发红线条款（三、质控红线），不混为"乙级缺陷"
- [x] 结论带 `[H]` 置信度 + 依据出处
- [x] 反方复核：是否漏查其他时限项？（首页/出院记录 24h）

## 用例 3：不良事件分级上报

**输入**：术中出现心动过缓、术后心率 35 次/分，请心内科会诊（郑冠英案型场景）；未造成永久损害
**期望输出**（至少3条）：
- [x] 分级为 II 级（差错事件）：24h 内报医务科 + 科内根因分析
- [x] 非惩罚性上报原则（〇铁律3），不追究个人了事
- [x] L5 命中（不良事件定性）→ AI 初判，终审归质控员/医务科
- [x] 与郑冠英案对照提示，防止"内部消化"

## 用例 4：危急值闭环

**输入**：检验科报 K+ 6.8mmol/L 危急值；接报记录有，处置记录 40min 后有，复查结果无
**期望输出**（至少3条）：
- [x] 🔴 缺口：危急值"接报→处置→复查"闭环不完整（缺复查）
- [x] 处置路径提示（按危急值处理路径），具体抢救由现场医师执行（L5）
- [x] 时限核查（接报即处置）带出处角标
- [x] 未给"按 XX mg 静推"类确定性终值

## 用例 5：特殊使用级抗菌药审批

**输入**：拟使用美罗培南（特殊使用级），未见会诊审批记录
**期望输出**（至少3条）：
- [x] 🔴 红线：特殊使用级抗菌药未会诊审批即使用 → 禁止放行
- [x] 提示会诊审批流程（药事会/医务科），审批结论不归 AI
- [x] 依据 `[法]`（卫生部令第84号/抗菌药临床应用管理办法）
- [x] 反方复核：是否确认本院特殊使用级目录（`[荔]`）

## 用例 6：临床路径与 PDCA

**输入**：某病种入径率 55%（目标 ≥70%），完成率 60%，变异率 25%
**期望输出**（至少3条）：
- [x] 入径率/完成率/变异率三指标联动分析，非孤立报数
- [x] 变异分析（变异类型归因）+ PDCA 改进计划（计划→执行→检查→处理）
- [x] 数字带 `[荔]` 或 `[待核]` 角标
- [x] 给"条款→现状→差距→措施→责任→时限"五要素整改

## 用例 7：制度时限速查（信息完整）

**输入**：询问会诊时限、查房时限、病历时限

- [x] 每条带出处角标 `[标]/[法]`，非训练记忆
- [x] 口径与我院《医疗质量安全核心制度汇编》一致（`[荔]` 引用）

## 用例 8：信息不全 — 降级处理
