# 药剂科科普宣传全流程技能

## 概述

本技能封装医院药剂科科普宣传的完整工作流：从栏目规划→内容日历排期→单篇科普文章撰写→宣传统计优化→宣传栏制作。基于「中山市沙溪隆都医院药剂科」《药师之言》栏目实战沉淀，可适配任何基层医院药剂科。

核心方法论：
- **八大栏目体系 S1-S8**：让科普系列化、可持续产出
- **节气+月份+事实热点三轴排期**：让选题不枯竭、自带流量
- **《药师之言》文章模板**：开篇引经→分节展开→药膳/清单→落款
- **写作8大技巧+发布前自查清单**：保证专业性与可读性

## 工作流决策树

按用户需求选择路径：

```
用户需求
├─ 规划系列科普栏目 → 加载 references/eight-columns.md → 输出八大栏目+选题池
├─ 生成内容日历 → 加载 references/content-calendar-method.md → 输出Excel/MD日历
├─ 写一篇科普文章 → 加载 references/article-template.md + references/writing-techniques.md → 输出Word
├─ 优化宣传统计表 → 见下方「宣传统计优化」流程
├─ 制作宣传栏 → 加载 references/article-template.md → 多板块Word输出
└─ 培训/写作指导 → 加载 references/writing-techniques.md → 输出技巧手册
```

## 核心资产

### 八大栏目体系（S1-S8）

详见 `references/eight-columns.md`。速查：

| 代码 | 栏目 | 定位 |
|------|------|------|
| S1 | 时令药事 | 跟着节气学中药养生 |
| S2 | 用药避坑 | 误区辟谣，强传播 |
| S3 | 中西对话 | 同病不同药怎么选 |
| S4 | 慢病长管 | 长期用药不踩雷 |
| S5 | 特殊人群 | 精准用药（孕哺/儿童/老人） |
| S6 | 抗菌药合理使用 | 契合科室研究方向 |
| S7 | 中药那些事 | 专业科普（炮制/配伍） |
| S8 | 家庭药箱 | 实用管理（清单/储存） |

### 内容日历生成方法

详见 `references/content-calendar-method.md`。三轴排期：
- **节气轴**：24节气，每个节气对应一个时令主题
- **节日轴**：60+节日（世界药师日9/25、中国医师节8/19、联合国糖尿病日11/14等）
- **流行病轴**：按季节（流感11-3月/过敏3-5月/手足口5-7月/中暑6-9月）

双热点合并技巧：立春+世界癌症日、春分+世界睡眠日，单篇双借势。

### 《药师之言》文章模板

详见 `references/article-template.md`。标准结构：
1. 标题《药师之言》XXX（带栏目品牌）
2. 开篇引经（《本草纲目》《黄帝内经》等）
3. 分节（一、二、三），每节小标题+正文
4. 实操内容（药膳方/剂量表/清单/对比表）
5. 配图建议
6. 落款（科室+作者+编辑+审核）

### 写作8大技巧+自查清单

详见 `references/writing-techniques.md`。8大技巧：
1. 标题（5种公式）
2. 开头（4种开局法）
3. 结构（引子→分节→落款）
4. 内容（准确/实用/翻译）
5. 语言（把药学话翻译成人话）
6. 安全边界（4条红线）
7. 结尾（药师寄语+行动引导）
8. 传播（节气借势+栏目化）

## 单篇科普文章撰写流程

1. **确定栏目与选题**：从八大栏目选一个，结合节气/节日/热点
2. **套用标题5公式**：设问式/数字式/警示式/场景式/对比式
3. **写开头**：引经/场景/痛点/悬念，50字内点明主题
4. **分3-4节展开**：每节小标题（痛点型/清单型/行动型）+ 200-400字
5. **给实操**：药膳方（材料+做法+功效）/剂量表/清单/对比表
6. **加配图建议**：每300字一张
7. **安全声明**：「请遵医嘱」「请及时就医」+特殊人群提醒
8. **落款**：科室+作者+编辑+审核
9. **自查**：对照发布前16项自查清单

## 内容日历生成流程

1. 确定排期周期（建议滚动12个月）
2. 加载节气表+节日表+流行病表（见 references/content-calendar-method.md）
3. 每月排3-5篇：2节气/节日主题（公众号）+ 1-2常青（投稿）
4. 双热点合并（节气+节日同日）
5. 分配栏目（S1-S8）+拟作者+渠道+状态
6. 输出Excel（多Sheet：日历/热点索引/栏目索引/标题库/进度统计）
7. 每月续期：复制模板追加下月，删除过期月

## 宣传统计表优化流程

原表常见问题：缺栏目分类、发布渠道混列、无节气维度、无汇总。

优化步骤：
1. 读取原表，识别字段（序号/日期/标题/作品类型/发布情况/作者/备注）
2. **扫描删除线行**：用 sheet_get_cell_style 的 strike_through 字段识别已采纳发布的行，剔除
3. 补全字段：栏目分类(S1-S8)/节气时令/状态/发布渠道细化
4. 重编序号
5. 生成3个Sheet：优化版统计 / 宣传计划表 / 汇总分析（按栏目/作者/渠道/月份统计+优化建议）
6. 用 openpyxl 生成，分类底色+状态底色

## 宣传栏制作流程

宣传栏 = 多板块综合内容包，可打印贴出。结构：
1. 刊头（栏目名+期数+月份）
2. 卷首语
3. 当季主题（节气对应）
4. 中药科普专栏（药材+药膳）
5. 用药避坑专栏
6. 慢病管理专栏
7. 特殊人群专栏
8. 家庭药箱专栏
9. 用药咨询窗口介绍
10. 下期预告
11. 落款

## 输出格式约定

- **文章/宣传栏/写作手册** → Word（.docx），用 python-docx 生成，样式：标题微软雅黑18pt深蓝、正文宋体12pt、小节黑体、配图建议楷体灰色
- **内容日历/统计表** → Excel（.xlsx），用 openpyxl 生成，多Sheet，分类底色+状态底色
- **内部参考** → Markdown

## 关键约束

- **准确性红线**：剂量、禁忌、不良反应必须基于药品说明书、《中国药典》、临床指南或国家药监通报；涉及具体数字必须核实
- **安全声明**：每篇必须有「请遵医嘱」「请及时就医」+特殊人群（孕妇/哺乳期/儿童/老人/肝肾功能不全）提醒
- **不贬低他药**：评价药物客观，强调适应症/禁忌症/用法，不情绪化推荐
- **栏目品牌**：《药师之言》作为固定前缀，长期沉淀品牌识别
- **节气为准**：标题可随气候微调，但节气主题不轻易挪到非当季月份
