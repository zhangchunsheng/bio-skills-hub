## 开头4种开局法

### 1. 引经据典法
引用中医药典籍或名人名言，建立权威，适合中药/养生类。
- 示例：《月令七十二候集解》载：「秋，揪也，物于此而揪敛也。」立秋一到……
- 示例：苏轼诗云：「无姜食不美」，一块姜，藏着千年食养智慧……

### 2. 场景代入法
用具体生活场景把读者拉进来，让其觉得"说的就是我"。
- 示例：暑假余额清零，熊孩子陆续返校，教室里交叉感染……

### 3. 痛点共鸣法
直接点出读者正在经历的困扰。
- 示例：晨起口干、咽痒咳嗽、皮肤紧绷——这都是身体在提醒你：该润一润了。

### 4. 悬念反转法
用反常识结论勾起好奇，适合"用药避坑"类。
- 示例：「中药纯天然，没副作用」——这句话骗了多少人？

## 小标题3公式

- **痛点型**：秋燥最喜欢找上谁 / 哪些人不宜膏方
- **清单型**：立秋润肺的8味药食 / 家庭药箱五大常备类
- **行动型**：如何安全使用中药 / 药师给您5条建议

## 安全声明模板

每篇必须包含：
1. 「请遵医嘱」「请及时就医」
2. 特殊人群声明（孕妇/哺乳期/儿童/老人/肝肾功能不全）
3. 急重症提醒就医（胸痛/呼吸困难/持续高热/抽搐等）

示例：
- "食疗平和、症状轻时合适；如咳嗽痰多、久咳不愈，请及时就医。"
- "儿童不是缩小版的大人，用药剂量要按体重计算。"
- "出现以下情况请及时就医：高热3天以上不退、精神差、抽搐……"

## 术语翻译对照表（药学话→人话）

| 药学话 | 人话（建议改写） |
|--------|------------------|
| 本品为非甾体抗炎药 | 这是一种常见的退烧止痛药（如布洛芬） |
| 抑制血小板聚集 | 让血液不容易凝固，防止血栓 |
| 生物利用度 | 药吃进去后，身体实际能吸收多少 |
| 缓释制剂 | 药片慢慢释放，一天只需吃一两次，不能掰开 |
| 药物相互作用 | 两种药一起吃，互相影响效果或增加副作用 |
| 肝首过效应 | 药吃进去先经肝脏，部分会被过滤掉 |

## Word生成样式约定（python-docx）

- 标题：微软雅黑 18pt 加粗 深蓝(#1F4E79)
- 副标题：微软雅黑 12pt 灰色
- 一级小节：黑体 13pt 加粗 深蓝
- 二级小节：黑体 12pt 加粗 蓝(#2E75B6)
- 正文：宋体 12pt 行距1.5 首行缩进0.74cm
- 引经：楷体 11pt 灰色 缩进
- 配图建议：楷体 10pt 灰色 居中
- 落款：宋体 10pt 灰色 居中
- 表格：表头微软雅黑10pt白字蓝底，正文宋体9pt
