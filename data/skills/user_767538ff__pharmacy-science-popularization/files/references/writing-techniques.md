# 药学科普写作8大技巧 + 发布前自查清单

## 技巧一｜标题：3秒抓住读者

标题决定80%打开率。5种公式：

| 公式 | 句式 | 示例 |
|------|------|------|
| 设问式 | XX该XX吗？ | 感冒了该吃抗生素吗？ |
| 数字式 | 这N类人/种药… | 这5类人慎用布洛芬 |
| 警示式 | XX，可能XX | 头孢配酒，说走就走 |
| 场景式 | 家里/开学/节气… | 家里囤的药过期了还能吃吗？ |
| 对比式 | A vs B | 咳嗽：川贝枇杷膏 vs 右美沙芬 |

栏目品牌：《药师之言》固定前缀，长期沉淀品牌识别。

## 技巧二｜开头：50字内让读者看下去

4种开局法：
1. **引经据典法**：引用典籍建立权威（适合中药类）
2. **场景代入法**：用生活场景把读者拉进来
3. **痛点共鸣法**：点出读者正在经历的困扰
4. **悬念反转法**：用反常识结论勾起好奇（适合避坑类）

心法：开头不超过80字，一句话讲清"这篇解决什么问题"。

## 技巧三｜结构：给读者一个"读得完"的骨架

通用骨架：引子 → 分节 → 落款
- 引子（1段）：场景/痛点/引经，80字内
- 主体（3-4节，用"一、二、三"）：每节小标题+200-400字
- 结尾（1段）：药师寄语+引导咨询窗口+落款

小标题3公式：
- 痛点型：秋燥最喜欢找上谁
- 清单型：立秋润肺的8味药食
- 行动型：如何安全使用中药

心法：每节金字塔结构，先给结论/清单，再展开解释。

## 技巧四｜内容：专业性与可读性的平衡

三个抓手：
1. **准确**：剂量、禁忌基于药品说明书、《中国药典》、临床指南、国家药监通报。数字必须核实。
2. **实用**：给剂量、给清单、给食谱、给流程。不只讲"为什么"，要给"怎么办"。
3. **翻译**：能用比喻就不用术语，必须用术语时紧跟一句解释。

## 技巧五｜语言：把"药学话"翻译成"人话"

5个小习惯：
1. 多用"你/您"，少用"患者""本品"
2. 多用短句，一句不超过30字
3. 多用"•""·"分点，少用大段文字
4. 多用具体数字和场景，少用"适量""酌情"
5. 多用动词，少用名词化表达

## 技巧六｜安全边界：科普的红线

4条红线绝不能碰：
1. **不替代诊疗**：科普是健康教育，不是开处方。"请遵医嘱"放显眼位置。
2. **急重症必须提醒就医**：胸痛、呼吸困难、持续高热、抽搐、严重脱水、便血、过敏休克——明确写"请立即就医"。
3. **特殊人群特别声明**：孕妇、哺乳期、儿童、老人、肝肾功能不全者——单独提醒。中药注明"在中医师/中药师指导下使用"。
4. **不贬低他药、不夸大功效**：不写"XX药副作用大千万别吃""XX中药包治百病"。评价客观，强调适应症/禁忌症/用法。

## 技巧七｜结尾：留下行动指引

三个要素：
1. 药师寄语：一句温暖的话，强化"药师在你身边"人设
2. 行动引导：引导到用药咨询窗口、流感疫苗接种、家庭药箱整理
3. 落款规范：科室名+作者+编辑+审核

## 技巧八｜传播：让科普"被看见"

4个传播杠杆：
1. **节气借势**：24节气是天然发文日历，自带搜索流量
2. **系列栏目化**：《药师之言》+八大子栏目，培养"追更"习惯
3. **热点借势**：流感季、开学季、世界药师日、药品安全宣传周
4. **公众号排版**：段落短、字号15-16px、行距1.6-1.8、重点加粗、每300字一图
