# 合规审核体系（五节点全流程）

> 本文件是 `pharma-content-orchestrator` 技能的合规参考，定义贯穿七管线全流程的五节点审核体系、红线清单与Audit Trail规范。

---

## 合规审核总览

合规审核不是事后检查，而是**贯穿全流程的五节点防线**。每个节点有明确的审核对象、审核方式和处置方式，形成"拦截→标红→报告→双签→监测"的完整链条。

### 五节点审核流程

```
生成前 → 生成中 → 生成后 → 发布前 → 发布后
  │        │        │        │        │
  ▼        ▼        ▼        ▼        ▼
拦截     标红     全审     双签     监测
违规     暂停     报告     复审     预警
输入     生成     +建议    签发     撤回
```

---

## 节点一：生成前审核（策略输入预检）

### 审核对象
产品经理提交的策略输入（产品定位、核心卖点、目标适应症、创意简报）

### 审核方式
规则引擎预检，自动拦截违规输入

### 检查清单

| 检查项 | 规则 | 违反处置 |
|--------|------|----------|
| 超适应症检测 | 策略主张是否超出NMPA获批适应症 | 拦截，提示"超出获批范围，请修正" |
| 绝对化用语检测 | 是否含"最""唯一""第一""100%"等 | 拦截，提示广告法第9条违规 |
| 疗效承诺检测 | 是否含"治愈""根治"" guaranteed"等 | 拦截，提示禁止疗效承诺 |
| 竞品贬低检测 | 是否含直接贬低竞品的表述 | 拦截，提示禁止竞品贬低 |
| 适应症外延检测 | 是否暗示未获批的适应症/人群 | 拦截，提示超说明书风险 |

### 处置方式
- 命中任何一条 → 拦截输入，返回违规原因 + 合规修改建议
- 全部通过 → 进入管线执行

---

## 节点二：生成中审核（实时扫描）

### 审核对象
内容生成过程中的每个文本片段

### 审核方式
实时扫描，风险标红 + 暂停生成

### 检查清单

| 检查项 | 触发条件 | 处置 |
|--------|----------|------|
| 超说明书内容 | 生成内容超出获批适应症 | 标红 + 暂停 + 提示修正方向 |
| 无引用数据 | 关键数据未标注GRADE等级和文献来源 | 标红 + 暂停 + 要求补充引用 |
| 绝对化表述 | 生成文本含广告法禁用词 | 标红 + 自动替换建议 |
| 误导性比较 | 与竞品对比未基于公开数据 | 标红 + 要求标注数据来源 |
| 不良事件遗漏 | 疗效描述未伴随安全性信息 | 标黄 + 提醒补充安全性数据 |
| 米尔顿越界 | 说服技巧超出RDPAC合规边界 | 标黄 + 降维建议 |

### 处置方式
- 红色风险：暂停生成，必须修正后方可继续
- 黄色提醒：继续生成但标记需复核项
- 全部绿色：继续生成

## 节点三：生成后审核（完整物料全量审核）

### 审核对象
管线产出的完整物料（DA/PPT/话术/KV/图表）

### 审核方式
全量审核，输出合规报告 + 修改建议

### 审核维度

#### 文本合规（DA/话术/PPT备注）

| 审核项 | 标准 | 工具 |
|--------|------|------|
| 适应症范围 | 100%在NMPA获批范围内 | 说明书比对 |
| 数据引用完整性 | 每条关键数据有GRADE+来源 | 引用追溯 |
| 绝对化用语 | 0处违反广告法第9条 | 关键词扫描 |
| 竞品对比规范 | 对比基于公开数据+标注来源 | 对比审查 |
| 不良事件披露 | 完整列出常见AE+严重AE+禁忌 | 说明书比对 |
| 疗效承诺 | 0处确定性疗效承诺 | 语义分析 |
| 引用时效 | 优先近5年，>10年标注"历史研究" | 时间戳检查 |

#### 视觉合规（KV/配图/图表）

| 审核项 | 标准 | 工具 |
|--------|------|------|
| 人脸肖像权 | 使用授权确认 | 图像检测 |
| 分子结构准确性 | 与PubChem/DrugBank一致 | 结构校验 |
| 坐标轴规范 | 不得截断误导 | 图形分析 |
| 图中文字合规 | OCR扫描无违规表述 | OCR+NLP |
| 色彩无障碍 | 符合WCAG 2.1 AA标准 | 色彩分析 |
| 品牌VI一致性 | 色值/字体/Logo符合规范 | VI比对 |

### 合规报告格式

```json
{
  "material_id": "物料ID",
  "material_type": "DA/PPT/KV/...",
  "audit_date": "审核日期",
  "overall_status": "PASS/CONDITIONAL_PASS/FAIL",
  "findings": [
    {
      "severity": "CRITICAL/MAJOR/MINOR",
      "category": "超适应症/绝对化用语/无引用/...",
      "location": "页码/段落/坐标",
      "description": "问题描述",
      "recommendation": "修改建议",
      "regulation": "违反法规条款"
    }
  ],
  "sign_off": {
    "ai_audit": "AI初审结果",
    "medical_review": "待医学经理审",
    "compliance_review": "待合规经理审"
  }
}
```

### 处置方式
- CRITICAL：必须修改，不可发布
- MAJOR：修改后方可发布
- MINOR：建议修改，可附条件发布
- 全部通过：进入发布前双签

## 节点四：发布前审核（人机协同双签）

### 审核对象
最终定稿物料

### 审核方式
AI初审 + 专家复审双签制

### 双签流程

```
AI初审（自动）
    │
    ├─ PASS → 医学经理审核（科学性）
    │              │
    │              ├─ PASS → 合规经理审核（合规性）
    │              │              │
    │              │              ├─ PASS → 双签通过 → 可发布
    │              │              └─ FAIL → 退回修改
    │              └─ FAIL → 退回修改
    └─ FAIL → 退回修改
```

### 签字权限矩阵

| 物料类型 | AI初审 | 医学经理 | 合规经理 | 额外签字 |
|----------|--------|----------|----------|----------|
| DA正文 | Y | Y | Y | — |
| 学术PPT | Y | Y | Y | — |
| 拜访话术 | Y | Y | Y | — |
| KV主视觉 | Y | Y | Y | 设计总监（视觉规范） |
| 患者教育材料 | Y | Y | Y | 法务（广告法专项） |
| 数字营销内容 | Y | Y | Y | 法务+数据隐私官 |

### 处置方式
- 三方签字齐全 → 物料入库，可发布使用
- 任一方未通过 → 退回对应管线修改，重新审核

## 节点五：发布后监测（预警与追溯）

### 审核对象
已发布物料的使用数据与反馈

### 审核方式
监测预警，发现违规立即撤回 + 追溯

### 监测项

| 监测项 | 预警条件 | 处置 |
|--------|----------|------|
| 超适应症投诉 | 收到任何超适应症使用反馈 | 立即撤回 + 全量复查 |
| 医生质疑数据 | 医生对数据准确性提出质疑 | 48小时内核查 + 回复 |
| 竞品投诉 | 竞品发起对比数据争议 | 法务介入 + 数据复核 |
| 监管问询 | 监管部门问询 | 紧急合规审查 + 整改报告 |
| 不良事件关联 | 物料关联AE报告 | PV团队介入 + 物料评估 |
| 使用范围偏移 | 物料在非目标场景使用 | 追踪溯源 + 使用规范重申 |

## 合规红线清单（L0否决项）

以下为**不可逾越的合规红线**，任何一条违反即触发物料否决：

| 编号 | 红线 | 法规依据 |
|------|------|----------|
| L0-01 | 超适应症推广 | NMPA药品管理法 |
| L0-02 | 绝对化用语（最/唯一/第一） | 广告法第9条 |
| L0-03 | 疗效确定性承诺 | 广告法第16条 |
| L0-04 | 直接贬低竞品 | 广告法第13条 |
| L0-05 | 无引用数据（关键数据无来源） | RDPAC行为准则 |
| L0-06 | 不良事件未披露 | RDPAC行为准则 |
| L0-07 | MSL薪酬与销量挂钩 | 两高司法解释 |
| L0-08 | 未备案医药代表从事推广 | 医药代表备案管理办法 |
| L0-09 | 虚构研究数据 | 刑法第229条（提供虚假证明文件罪） |
| L0-10 | 患者个人信息未脱敏 | 个人信息保护法 |

## 数据安全要求

| 要求 | 标准 |
|------|------|
| 对话记录 | 可追溯、可审计 |
| 患者数据 | 严格脱敏，不可逆 |
| 医生画像 | CRM数据使用须授权 |
| 竞品数据 | 仅使用公开来源 |
| 存储加密 | AES-256加密存储 |
| 访问日志 | 保留≥3年 |
