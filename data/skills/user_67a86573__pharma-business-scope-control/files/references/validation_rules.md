# 经营范围校验规则矩阵

本文件定义医药流通ERP各业务环节的经营范围校验口径、交集逻辑与拦截条件。所有校验在事务内执行，交集为空即拦截并给出明确的资质缺口提示。

## 1. 符号约定

- `S_self`：企业自身商业经营范围集合
- `S_supplier`：供应商经营范围集合（商业口径；厂家供货时取商业类）
- `S_mfr`：厂家经营范围集合（剂型口径，仅直采用）
- `S_customer`：客户经营范围集合（商业或零售口径，按客户类型）
- `S_product`：商品经营范围（按场景取 mfr / comm / retail 三类之一）
- `S_warehouse`：仓库经营范围集合（商业口径）
- `∩`：取交集；交集为空 → 拦截

## 2. 上游校验（采购 / 收货准入）

### 2.1 厂家直采（生产端）

```
放行条件 = S_self(comm) ∩ S_product(comm)  ≠ ∅
        AND S_mfr(剂型) ⊇ S_product(mfr剂型)
```
- 第一路：企业商业大类能覆盖该商品（大类交集非空）。
- 第二路：厂家生产剂型包含该商品剂型（剂型包含关系，非交集）。
- 两路同时满足才放行。

### 2.2 厂家作为供应商供货

```
放行条件 = S_self(comm) ∩ S_supplier(comm) ∩ S_product(comm) ≠ ∅
```
- 此时厂家视作商业供应商，用**商业大类口径**，不再校验剂型。
- 三方（企业/供应商/商品）商业经营范围取交集，非空放行。

### 2.3 普通商业供应商供货

```
放行条件 = S_self(comm) ∩ S_supplier(comm) ∩ S_product(comm) ≠ ∅
```
- 同 2.2 逻辑，供应商本就是商业口径。

## 3. 下游校验（销售 / 出货准入）

### 3.1 客户为商业/医疗机构

```
放行条件 = S_self(comm) ∩ S_customer(comm) ∩ S_product(comm) ≠ ∅
```

### 3.2 客户为零售药店（特殊分支）

```
放行条件 = S_self(comm) ∩ S_customer(retail) ∩ S_product(retail) ≠ ∅
```
- 客户经营范围切换到**零售口径**（甲类/乙类/处方药）。
- 商品取零售属性（OTC分级）参与交集。
- 例：商品为「甲类OTC」而客户仅有「乙类OTC」资质 → 交集为空 → 拦截。

## 4. 仓库校验（存储条件准入）

```
入库放行条件 = S_warehouse(comm) ∩ S_product(comm) ≠ ∅
            AND 仓库温区/存储条件 ⊇ 商品存储要求
```
- 在**收货（入库）环节**执行，独立于上下游交易校验。
- 不仅校验经营范围，还需校验物理存储条件（冷藏/冷冻/阴凉/常温、避光等）满足商品要求。
- 不满足则拒绝入该仓库，提示改派合规仓库。

## 5. 本地药监叠加规则

所有上述交集校验之上，叠加企业所在地药监的特殊管控：
- 特殊管理药品（麻、精、毒、放）、蛋白同化制剂、冷链品种等，按当地要求追加许可标记位校验。
- 本地规则以配置表形式维护，与通用交集逻辑「与」关系组合，不写死在代码里。

## 6. 拦截提示规范

拦截时必须返回：
1. 缺失的资质维度（企业/供应商/客户/商品/仓库 哪一方缺）。
2. 缺口的具体经营范围项（如「企业无 III 类医疗器械资质」）。
3. 可用的合规替代路径（如「改派具备 III 类资质的仓库」）。

## 7. 证照过期与关联口径

厂家、供应商、客户持有的证照（生产/经营/GSP/GMP/零售许可）有有效期，过期即资质失效。证照与品种之间以「经营范围」为解耦中间层，降低维护成本。

### 7.1 方式A：证照 → 经营范围（推荐）

```
有效主体经营范围内 = 主体经营范围项 且 其挂载证照未过期
放行条件(沿用第2/3节) = S_self ∩ S_supplier/customer(有效) ∩ S_product ≠ ∅
```
- 证照过期 → 其关联经营范围项置为失效 → 交集计算时该方缺此范围 → 拦截。
- 维护只需：「证照有效期」+「证照↔经营范围项」映射；新增/停用品种不影响证照映射。

### 7.2 方式B：证照 → 直接品种（特殊）

```
有效主体品种集 = 证照直接绑定品种 且 证照未过期
校验时额外要求：商品 ∈ 有效主体品种集
```
- 用于必须按证照限定特定品种的场景（如注册批文对应特定商品）。
- 维护成本高：逐品种挂接，证照变更需重挂全部品种。仅特殊启用。

### 7.3 过期控制行为

- 证照到期前 N 天：**预警**（通知质管/采购/销售）。
- 证照到期后：自动**停用**其关联范围/品种，相关交易**拦截**。
- 续期/换新证：恢复关联，方式A 下无需重挂品种。
- 同一主体多张证照各自独立关联、独立过期控制，互不牵连。
