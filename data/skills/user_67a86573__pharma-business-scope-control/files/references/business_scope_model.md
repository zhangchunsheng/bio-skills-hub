# 经营范围数据模型与层级结构

本文件定义医药流通ERP经营范围管控的底层数据模型，供设计表结构、维护字典、编写校验逻辑时参照。

## 1. 三大类经营范围字典（独立维护）

每一类维护一张独立的经营范围字典表，禁止跨类混用。

### 1.1 厂家经营范围（剂型口径）

源于《药品生产许可证》生产范围 / 《医疗器械注册证》。

```
厂家经营范围（树形）
└─ 剂型
   ├─ 针剂（注射剂）
   ├─ 粉剂（粉针剂 / 散剂）
   ├─ 片剂
   ├─ 胶囊剂
   ├─ 溶液剂
   ├─ 软膏剂
   ├─ 颗粒剂
   └─ 气雾剂
```

### 1.2 商业经营范围（药品/器械大类口径）

源于《药品经营许可证》经营范围 / 《医疗器械经营许可证》。

```
商业经营范围（树形，含层级）
├─ 药品
│  ├─ 中成药
│  ├─ 化学药
│  │  ├─ 化学药制剂
│  │  └─ 化学原料药
│  ├─ 抗生素
│  ├─ 生化药品
│  ├─ 生物制品
│  ├─ 蛋白同化制剂
│  ├─ 肽类激素
│  └─ 中药饮片
└─ 医疗器械（见第2节层级）
```

### 1.3 零售经营范围（OTC分级口径）

源于《药品经营许可证》（零售）与药店分级。

```
零售经营范围（树形）
├─ 处方药（Rx）
│  ├─ 注射类处方药
│  └─ 口服/外用处方药
├─ 甲类非处方药（甲类OTC）
├─ 乙类非处方药（乙类OTC）
└─ 中药饮片（零售）
```

## 2. 医疗器械层级（强制层级，I/II/III 类）

医疗器械必须建立三级及以上层级关系，否则无法精确匹配与监管统计。示例：

```
医疗器械
├─ I类医疗器械
│  ├─ 基础外科用刀
│  ├─ 医用冷敷贴
│  └─ 手术衣（非无菌）
├─ II类医疗器械
│  ├─ 医用超声仪器
│  ├─ 血压计
│  ├─ 血糖仪
│  └─ 物理治疗设备
└─ III类医疗器械
   ├─ 植入器械
   │  ├─ 心脏起搏器
   │  └─ 骨科植入物
   ├─ 血管介入器械
   ├─ 一次性无菌输注器具
   └─ 体外循环设备
```

要点：
- 每类器械向上归属到 I/II/III 类，再向上归属到「医疗器械」商业大类。
- 校验时支持「大类匹配」与「细项匹配」两种粒度：企业有 III 类资质即可经营其下所有细项；仅维护细项则只放行该项。

## 3. 主体分类标签与映射

每个主体记录带一个 `scope_category` 标签，用于校验时路由到对应经营范围集合。

| 主体类型 | scope_category | 维护的经营范围 | 备注 |
|----------|----------------|----------------|------|
| 企业自身 | COMMERCIAL | 商业 | 交集基准 |
| 厂家 | MANUFACTURER | 厂家（生产剂型） | 作为供应商时同时参与商业校验 |
| 供应商（批发/商业） | COMMERCIAL | 商业 | 中成药、化学药等 |
| 客户（商业/医疗） | COMMERCIAL | 商业 | 中成药、化学药等 |
| 零售药店 | RETAIL | 零售 | 甲类/乙类/处方药分级 |

## 4. 商品经营范围三属性模型

商品主数据需同时挂三个经营范围字段，缺一不可：

| 字段 | 口径 | 取值来源 |
|------|------|----------|
| product_scope_mfr | 厂家（剂型） | 1.1 字典 |
| product_scope_comm | 商业（大类） | 1.2 字典 |
| product_scope_retail | 零售（OTC分级） | 1.3 字典 |

每个字段至少明确到「一类」；精密管控可到叶节点。本地药监特殊限制（冷链、麻精、蛋白同化等）以独立标记位叠加。

## 5. 证照与经营范围/品种关联模型

厂家、供应商、客户持有证照，证照是经营范围的**资质来源与有效期载体**。引入「经营范围」作为证照与品种之间的解耦中间层，降低维护成本。

### 5.1 实体关系

```
主体(厂家/供应商/客户)
  ├─ 持有 1..N 证照(lic)
  │     ├─ 有效期(有效起/止)
  │     └─ 关联方式
  │           ├─ A: 指向 经营范围项(scope_item)   ← 推荐
  │           └─ B: 直接指向 商品(product)        ← 特殊
  └─ 经营范围(scope) 由 经营范围项 组成
商品(product) ── 挂 经营范围(厂家/商业/零售三属性)
```

### 5.2 两种关联字段

| 关联方式 | 字段示例 | 维护成本 | 适用 |
|----------|----------|----------|------|
| A 证照→经营范围项 | lic_id ↔ scope_item_id | 低（仅挂范围项） | 默认 |
| B 证照→商品 | lic_id ↔ product_id | 高（逐品种挂接） | 特殊限定品种 |

### 5.3 校验取数规则

- 计算主体有效经营范围时，仅纳入「挂载证照未过期」的范围项（方式A）。
- 方式B 额外要求交易商品 ∈ 该证照绑定品种集。
- 无论哪种方式，最终都收敛到「主体 ∩ 商品 经营范围交集」这一统一入口，避免多套逻辑并行。
