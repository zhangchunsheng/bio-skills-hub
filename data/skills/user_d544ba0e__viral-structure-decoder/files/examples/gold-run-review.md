## 表面 vs 深层

- 不要只学：产品名 A/Y/Z、「60%」数字照搬、「千万别买」恐吓语气  
- 要迁移：认知失调钩子；证据从「我」→「身边人」→「更大样本叙述」；让步后给可验证动作与替代出口  

🔎 五维扫描：钩子✓ | 情绪✓ | 说服✓ | 密度✓ | 框架✓  

## 🎣 钩子解剖

- 技术：挑战共识 + 结果前置  
- 原文证据：「别人都说 A 产品好用…」「先说结论：如果你属于 X 类人，千万别买。」  

## 🎯 说服技巧清单

1. 个人经历锚定 —「我用了 3 个月」  
2. 社会认同 —「5 个人里有 3 个」  
3. 数据冲击 —「200 多条」「60%」（**引用内容真伪未核实**）  
4. 让步句 —「所以如果你确实想买」  

## 📦 可复用内容蓝图

### 结构模板（空槽）

1. 别人都说 `___` 好，我 `___` 之后发现不是这么回事  
2. 先说结论：如果你是为了 `___`，建议先看完再决定  
3. 时间线：先 `___`，后来出现 `___`  
4. 社交证据：问了约 `___` 人，其中约 `___` 也遇到  
5. 更大范围证据：我查看了 `___`，发现 `___`  
6. 若仍想行动：先做可验证小实验 `___`  
7. 替代出口：`___` / `___`  
8. CTA：你们遇到过 `___` 吗？  

### 迁移度

- **高** — 骨骼不绑定具体产品  

### 发布前自检

- [ ] 经历真实可讲  
- [ ] 证据可自核验  

## 🔧 弱点诊断

1. 「X 类人」过糊 → 改成具体用途/场景  

## 边界

学结构不搬原文；不代笔、不保证爆款；文中数据叙述真伪未核实。

## 答辩必指

1. **⚡速览**：DNA一句 + PAS + Top1 弱点  
2. **表面 vs 深层**  
3. **三层证据堆叠** + 数据未核实  
4. **空槽蓝图** + 不代笔  

## 答辩演示（75 秒）
