🔍 分类：小红书风格图文（推断） | 产品测评/避坑 | 转化 + 互动（推断）  
🧬 DNA一句：挑战共识开场 → 个人/社交/数据三层搅动 → 试用门槛 + 替代品出口 + CTA  

## 表面 vs 深层

- 不要只学：具体产品名 A/Y/Z、「60%」这个数字本身、口头禅句式照搬  
- 要迁移：认知失调钩子；证据从个例升级到群体；「若仍想买」让步后给可验证动作；替代出口降低绝望感  

🔎 五维扫描：钩子✓ | 情绪✓ | 说服✓ | 密度✓ | 框架✓  

## 🎣 钩子解剖

- 技术：挑战共识 + 结果前置  
- 机制：挑战流行判断制造好奇缺口；「3 个月」给发言资格；身份筛选（X 偏糊）  
- 原文证据：  
  - 「别人都说 A 产品好用，我用了 3 个月发现根本不是这么回事。」  
  - 「先说结论：如果你属于 X 类人，千万别买。」  

## 📈 情绪曲线（启发式，主观）

- 开场 +3 好奇 → 警示 -2 → 经历 +1 → 朋友比 -3 → 评价数据 -4 → 方案 +2 → 替代 +3 → CTA +2  
- 类型：先抑后扬  
- 转折：「所以如果你确实想买」  

## 🎯 说服技巧清单

1. 个人经历锚定 —「我用了 3 个月」  
2. 社会认同 —「5 个人里有 3 个」  
3. 数据冲击 —「200 多条」「60%」（**引用内容真伪未核实**）  
4. 对比锚定 —「便宜 40%」（未核实）  
5. 让步句 —「如果你确实想买」  
6. 互动 CTA —「你们买过 A 吗」  

最有力组合：个人经历 → 社交 → 数据 三层堆叠。

## ⏱ 信息密度与节奏

- 开场中密；中段高密（连续证据）；方案段具体动作；CTA 留白邀互动  

## 📐 结构框架

PAS + 替代对比：P 流行说法；A 三层搅动；S 试用建议 + Y/Z + CTA  

## 📦 可复用内容蓝图

### 结构模板（空槽）

1. 别人都说 `___` 好，我 `___` 后发现不是  
2. 先说结论：如果你是为了 `___`，先别冲动  
3. 时间线：先 `___`，后出现 `___`  
4. 社交证据：`___` 人里约 `___` 也遇到  
5. 更大范围证据：我查看 `___`，发现 `___`（请用自己可核验材料）  
6. 若仍想做：先做可验证小实验 `___`  
7. 替代出口：`___` / `___`，差异 `___`  
8. CTA：你们遇到过 `___` 吗？  

**迁移度：高** — 骨架不依赖具体产品名，可换到服务/生活方式测评。

### 5 个备选主题

1. 冥想场景边界 2. 餐厅复测 3. 远程办公边界 4. 某课程适合人群 5. 某 App 隐藏成本  

### 跨平台 / 篇幅适配

- 约 60 秒口播：P + A一层（朋友或数据二选一）+ S + CTA  
- 图文短：保留三层证据但每层一句  
- 长文：A 可加一节机制，仍自写经历

## 🔧 弱点诊断

1. 「X 类人」过糊（命中失败模式：筛选过糊）→ 改成具体用途筛选  
2. 满意期细节少 → 补一个可感细节  
3. CTA 可先给自己的选择理由再提问  
4. 「60%/200 条」若无法核验，仿写时改成自己可核验材料（命中：假精确风险）
