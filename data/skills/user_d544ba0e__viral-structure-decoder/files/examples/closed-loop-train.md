# 闭环 · 培训打钩模式（节选）

触发：培训模式  

## ✅ 新人五维打钩（对照任意一篇对标文）

- [ ] 能说出钩子技术名  
- [ ] 能标出情绪转折句  
- [ ] 能说出主框架（如 PAS）  
- [ ] 能区分表面元素与深层机制  
- [ ] 能写出不含原文的三步空槽  

## 辨识题（示例）

1. 开场「别人都说…我发现…」主要是？ A 清单体 B 挑战共识 C 英雄之旅  
2. 「所以如果你确实想买」在情绪上最像？ A 继续抑 B 转折出口 C 开场钩  
3. 「5 人里 3 人」主要承担？ A 纯抒情 B 社会认同证据 C 稀缺限时  

要点答案：1B 2B 3B  

## 边界

用于内训辨识结构；不代笔、不保证爆款。
