# 常见结构失败模式（弱点诊断对照）

拆解与给弱点时优先检查是否踩坑。用于教学，不是嘲讽作者。

## 1. 只搅动不给出口
全文控诉问题，没有「若仍想…」的可执行下一步或替代 → 情绪高但转化/信任易崩。

## 2. 过早剧透又注水
开头丢完结论后，中段重复同一信息无升级 → 密度假高、节奏塌。

## 3. 受众筛选过糊
「所有人/打工人/想变好的人」→ 身份钩子失效。

## 4. 假精确 / 不可核验数字
「99%」「翻了几万条」却无来源语境 → 可标技巧，但弱点应提示「仿写请换可核验材料」。

## 5. 证据不升级
反复讲「我觉得」无社交/案例/对比层 → 可信度停在第一层。

## 6. CTA 悬空
末尾「评论区聊聊」前无讨论抓手（二选一/自己先表态）→ 互动弱。

## 7. 表面堆料
emoji、网络热词密集，机制句缺失 → 指出表面/深层对照。

## 8. 框架错配平台
长文 PAS 五层硬塞进 15 秒口播 → 跨平台适配应删层。

诊断句式：`现状（引原文）→ 若改成…（结构层，不代写成稿）`
