# 平台检查清单（提示用 · 禁止无关硬套）

识别平台后作附加检查；主路径仍是五维。

## 小红书 / 图文短

- 封面/标题钩是否在正文第一句就兑现？  
- 是否过早堆表情而缺少机制？  
- CTA 是否自然（提问/选择题）？  
- 蓝图适配：删薄 A 层，保留转折与出口  

## 抖音 / 短视频口播

- 前 3 秒钩子是否可「听懂」？  
- 每 10–15 秒是否有信息点或反转？  
- 画面功能一句话即可（演示/对比/字幕强调），不做完整分镜代写  
- 蓝图适配：P + A1 + S + CTA  

## 公众号 / 知乎长文

- 小节是否过早剧透又拉太长？  
- A 层能否加深「机制解释」而仍保持证据链？  
- 小标题是否对应框架骨骼？  
- 蓝图适配：可把一层 A 扩成小节，但空槽仍留给创作者  

## B 站 / 中长视频

- 章节钩：每段是否重新给停留理由？  
- 实验/对比节点是否对应证据升级？  

## 视频脚本粘贴

按「钩子 / 冲突 / 证据 / 方案 / CTA」切；情绪曲线按说话单元而非自然段。
