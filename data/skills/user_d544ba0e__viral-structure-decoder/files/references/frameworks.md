# 内容框架与技巧库（教学用 · 非唯一真理）

映射时允许「近似 / 混合」。勿宣称某框架是唯一正确答案。

## 常见结构框架

| 框架 | 骨骼 | 常见于 |
|------|------|--------|
| **PAS** | Problem → Agitate → Solve | 测评避坑、痛点种草 |
| **AIDA** | Attention → Interest → Desire → Action | 广告感强的转化帖 |
| **BAB** | Before → After → Bridge | 蜕变对比、方法分享 |
| **SPAC** | Situation → Problem → Answer → Call | 职场/经验帖 |
| **4U/结果前置** | 先给结论或利益，再展开 | 知乎/公号开头 |
| **英雄之旅（简）** | 日常→召唤→试炼→归来赠礼 | 长故事、Vlog 脚本 |
| **清单体** | 承诺数字 → 分点交付 → 收束 | 干货号 |
| **挑战共识** | 打破流行说法 → 证据 → 新立场 | 对立流量 |

## 常见钩子技术（开场 0–3 秒语义）

- 挑战共识：「别人都说…我发现…」  
- 结果前置：「先说结论：…」  
- 身份点名：「如果你是…一定要看」  
- 反差/反转：「用了才知道亏大了」  
- 数字冲击：「我翻了 200 条…」  
- 悬念缺口：「后面发生的事让我傻了」（勿剧透过早或过晚失衡）  
- 提问钩：「你们有没有发现…」  

机制关键词：好奇缺口、认知失调、身份认同、权威/经验资格、损失厌恶。

## 常见说服技巧（须配原文证据）

- 个人经历锚定、社会认同、权威暗示、数据冲击  
- 对比锚定（贵/便宜 %）、稀缺/限时（若出现且合法）  
- 具体细节（可验证的小场景）、让步句（当然如果你还想…）  
- 互动 CTA、二选一、故事因果链  

## 情绪曲线类型（启发式标签）

- 先抑后扬、持续抬升、中间深坑、波浪反复、开头高开维持  

强度建议标度：约 **-5～+5**（负=焦虑/愤怒/不适，正=共鸣/释然/惊喜）；声明主观。
