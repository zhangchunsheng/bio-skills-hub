# 拆解规则

## 总原则

1. **结构优先于文采**；少空夸。  
2. **证据可核验**；数据技巧标「真伪未核实」。  
3. **教结构不抄袭**；蓝图空槽；禁止全文代笔。  
4. **启发式透明**：情绪条、信息点计数须声明。  
5. **不保证爆款**。  
6. **表面 vs 深层**：必须指出勿只抄表面。  
7. **五维全覆盖**或显式跳过原因。  

## 分段方法

1. 空行 / 序号 / 转折词优先。  
2. 无格式：切 4–10 语义段并声明。  
3. 口播：钩子/冲突/证据/方案/CTA。  

## 信息密度启发式

- **高密**：连续新事实、数字、案例  
- **中密**：解释或单一故事推进  
- **低密/留白**：提问、情绪感叹、重复强调  
节奏点评：哪里该密（证据堆叠）、哪里该疏（转折前呼吸）。

## 五维检查清单

### 钩子
技术名 + 机制 + 开场原句  

### 情绪
分段强度 + 类型 + 转折 + 主观声明  

### 说服
≥3 条（过短可少）+ 摘录 + 组合拳 + 数据未核实  

### 密度
密/疏分布 + 快慢  

### 框架
主框架 + 混合 + 对应层次  

## 蓝图质量条

空槽清晰；5 换题可写且合法；跨平台可执行。

## DNA 一句写法

格式：`机制A → 机制B → 出口C`（不出现具体产品名更佳，便于迁移）

## 培训打钩（新人）

- [ ] 能指出钩子技术名  
- [ ] 能标出情绪转折句  
- [ ] 能说出框架骨骼  
- [ ] 能区分表面元素与深层机制  
- [ ] 能写出不含原文的空槽三步  

## 违规优化红线

可拆操纵；禁止教虚假宣传/违禁转化/造谣更有效。
