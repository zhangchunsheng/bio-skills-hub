# 糖皮质激素处方点评不合理判定规则参考

> 依据：《糖皮质激素类药物临床应用指导原则》（2011年版、2023年版）、《医院处方点评管理规范（试行）》、各专科激素使用规范。
> 本参考用于点评脚本提取的不合理记录后，由药师依据诊断与激素品种进行不合理类型判定与原因补充。

## 一、糖皮质激素主要适应症（严格把握）

判定"适应症不适宜 / 无适应症用药"时，须对照以下适应症清单：

1. **内分泌系统疾病**：肾上腺皮质功能减退症（原发/继发）、先天性肾上腺皮质增生症。
2. **风湿免疫性疾病**：系统性红斑狼疮、类风湿关节炎（重症）、皮肌炎/多发性肌炎、系统性血管炎、干燥综合征、强直性脊柱炎（重症）等。
3. **呼吸系统疾病**：支气管哮喘急性发作及慢性持续期、慢性阻塞性肺疾病急性加重（AECOPD）、间质性肺病、过敏性肺泡炎、结核性胸膜炎（联合抗结核）。
4. **过敏性疾病**：严重过敏反应/过敏性休克、血清病、严重药物过敏、严重荨麻疹/血管性水肿。
5. **感染性疾病（限严重炎症反应/辅助）**：感染性休克（经充分液体复苏及血管活性药后仍血流动力学不稳定者）、严重结核病（脑膜炎等，联合抗结核）。
6. **血液系统疾病**：免疫性血小板减少症（ITP）、自身免疫性溶血性贫血、淋巴瘤/白血病化疗方案组成。
7. **肾脏疾病**：肾病综合征、原发性肾病综合征（微小病变等）、新月体性肾炎。
8. **消化系统疾病**：炎症性肠病（重症克罗恩病/溃疡性结肠炎）、自身免疫性肝病。
9. **神经系统疾病**：多发性硬化急性发作、视神经脊髓炎、重症肌无力危象、格林-巴利综合征。
10. **眼科疾病**：眼眶炎性假瘤、视神经炎、严重葡萄膜炎（局部或全身）。
11. **皮肤疾病**：重症药疹（大疱性表皮坏死松解症等）、天疱疮/类天疱疮、重症银屑病。
12. **器官移植排斥**：抗排斥治疗。
13. **肿瘤辅助治疗**：化疗方案中的止吐预处理、肿瘤相关高钙血症、副肿瘤天疱疮等（须有明确方案依据）。
14. **其他**：早产儿促胎肺成熟、甲状腺眼病等。

> **核心原则**：糖皮质激素的"抗炎、退热、消肿、抗过敏"是药理作用，**不等于适应症**。适应症须严格限定于上述特定疾病情形，且评估风险-获益。

## 二、不合理问题分类标准

| 不合理类型 | 判定要点 |
|---|---|
| **无适应症用药** | 患者诊断完全不含糖皮质激素适应症，无任何使用指征 |
| **适应症不适宜** | 诊断与糖皮质激素适应症不符，或虽有炎症/发热/疼痛但属一般情况，未达激素使用门槛 |
| **用法用量不适宜** | 剂量超范围、给药频次不当、疗程过长/过短、未规范减停 |
| **联合用药不适宜** | 与非甾体抗炎药、利尿剂、降糖药等联用未评估相互作用风险 |
| **禁忌症用药** | 存在活动性感染未控制、严重精神病、活动性消化性溃疡、严重骨质疏松等禁忌仍使用 |
| **特殊人群用药不适宜** | 孕妇、儿童、老年人、肝肾功能不全者未调整方案 |

## 三、常见超适应症场景判定规则（高频痛点）

以下场景在点评中反复出现，均判定为**适应症不适宜**或**无适应症用药**：

### 1. 以"退热"为目的使用激素
- **场景**：感染性发热（如泌尿道感染、脓毒血症、肺部感染）使用地塞米松退热。
- **判定**：适应症不适宜。感染性发热非激素适应症，激素可抑制免疫、掩盖感染征象、加重感染。仅在感染性休克经充分液体复苏及血管活性药后仍不稳定时方可考虑。
- **依据**：2023版指导原则——糖皮质激素不作为常规退热药。

### 2. 以"消肿"为目的使用激素（骨科术后等）
- **场景**：骨折/软组织术后使用甲泼尼龙"消肿"。
- **判定**：适应症不适宜。术后肿胀应首选物理措施（抬高、冰敷、加压）或必要时NSAIDs；全身用激素增加切口愈合延迟、感染风险，无循证依据。

### 3. 以"止痛"为目的口服激素（门诊慢性疼痛）
- **场景**：关节炎/肌筋膜炎/颈椎病/腰椎病门诊口服泼尼松止痛。
- **判定**：适应症不适宜。慢性疼痛应规范使用NSAIDs、物理治疗、神经阻滞等；口服中效激素无循证依据，存在HPA轴抑制及系统不良反应风险。

### 4. 肿瘤患者无指征使用激素
- **场景**：恶性肿瘤支持治疗中，无咳嗽/气促/免疫指征使用甲泼尼龙。
- **判定**：无适应症用药。须有明确化疗方案预处理或副肿瘤综合征等指征。

### 5. 消化系统疾病方向相悖用药
- **场景**：腹泻、胃肠功能紊乱使用泼尼松。
- **判定**：适应症不适宜。非炎症性肠病适应症，且激素本身可致消化道黏膜损伤、诱发溃疡，用药方向与诊断相悖。

### 6. 神经外科非适应症口服
- **场景**：慢性硬膜下血肿、脑梗死后遗症等口服地塞米松。
- **判定**：适应症不适宜。非激素适应症，高龄患者尤需警惕代谢与感染风险。

## 四、激素制剂特性与风险提示

| 制剂 | 效价分类 | HPA轴抑制 | 主要风险 |
|---|---|---|---|
| 氢化可的松 | 短效 | 较弱 | 水钠潴留 |
| 泼尼松/甲泼尼龙 | 中效 | 中等 | 长期用致骨质疏松、血糖血压升高 |
| 地塞米松/倍他米松 | 长效 | 强 | HP A轴抑制明显、感染风险、代谢紊乱 |
| 吸入剂（布地奈德等） | 局部 | 全身影响小 | 口咽部局部不良反应 |
| 鼻喷/外用/滴眼 | 局部 | 全身影响小 | 局部萎缩、眼压升高（滴眼） |

> **点评提示**：全身用激素（注射/口服）的不合理风险显著高于局部制剂，点评应重点关注静脉地塞米松、注射用甲泼尼龙、口服泼尼松的超适应症使用。

## 五、特殊人群重点关注

- **≥65岁老年人**：系统性使用激素须评估骨质疏松、血糖、感染、精神症状风险。
- **糖尿病患者**：监测血糖，调整降糖方案。
- **感染患者**：激素前须评估感染控制，避免掩盖病情。
- **儿童**：关注生长抑制，严格掌握适应症与剂量。
- **孕妇**：评估胎儿风险，优先选用泼尼松（胎盘代谢率高）。

## 六、判定工作流

1. 读取脚本输出的不合理明细（科室、年龄、诊断、激素药品、存在问题原文）。
2. 若原表已填写"存在问题"原文，直接引用并归类为对应不合理类型。
3. 若原表未填写（如门急诊表无"存在问题"列），依据患者诊断 + 激素品种，对照本规则第一、三部分判定不合理类型与原因。
4. 在报告第二步表格中注明"经药师依据《指导原则》判定"。
