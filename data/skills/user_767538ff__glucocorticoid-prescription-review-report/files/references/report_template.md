## 第四步 高频问题深度分析与现实痛点

按以下四个维度展开（每维度一段，结合本季度数据具体分析）：

1. **医师认知层面**：对糖皮质激素适应症边界认知模糊，将"抗炎/退热/消肿"药理作用误作适应症，忽视指导原则对适应症的严格限定；对长效制剂HPA轴抑制、代谢风险认知不足。
2. **科室习惯层面**：高频科室的经验性用药惯性（如骨科术后消肿、泌尿外科退热），低年资医师模仿上级医嘱延续不合理用法。
3. **应急滥用层面**：门急诊以症状控制替代病因治疗，口服激素当"便捷消炎止痛药"，疗程与减停不规范。
4. **专科宣教缺失层面**：专项培训覆盖不足，处方权限分级管理未落地，病历未记录使用理由，HIS规则引擎缺位。

## 第五步 分层整改对策与常态化筛查方案

按四层展开：

### 一、药师干预（即时执行层）
- 在架医嘱实时审核、门急诊处方前置审核、专项反馈单下发。

### 二、专项培训（能力建设层）
- 重点科室定向培训、典型病例讨论、考核闭环。

### 三、科室质控约谈（管理约束层）
- 药事委牵头约谈、纳入科室质量考核、处方权限动态调整。

### 四、后续常态化筛查方案（长效机制层）
- 月度专项点评、HIS规则引擎建设、季度分析报告、专项指标监测（DDDs/不合理率/干预成功率）、重点人群关注。
