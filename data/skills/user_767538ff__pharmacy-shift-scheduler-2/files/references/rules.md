# 住院药房班表生成器 —— 规则、算法与排错指南（v3.4）

本文档是 `schedule_generator.py` 的权威说明。每次生成或排错前，先通读本文件，避免在修复一处时 reintroduce 已被修掉的历史 bug。

> **v3.4 重大变更（无补班日 + 假期=周末模式 + 盘点日避开假期）**
> 1. **隐私优先（设计即合规）**：本 skill **不内置任何真实姓名**。`DEFAULT_STAFF` 为空，两份 `assets/班表输入模板*.xlsx` 均为**空名单**。名单、类型、禁止/偏好/尽量避免岗位、备注，**全部**由使用方在输入模板填写；模板名单为空时生成器直接 `ValueError` 退出，绝不回退到内置姓名。代码与本文档均不出现任何个人姓名（下文示例用占位符「药师一…药师九 / 后勤一、后勤二」）。
> 2. **无补班日（医院不调休、不补班）**：本工具**不存在「补班日」类别**——任何周末都不会被改成工作日，生成器也无 `--makeup` 参数。往年"补班日按工作日排"的设定已整体移除。
> 3. **公共假期 = 周末模式**：法定节假日按「休息日人数」排班（休 4 / 上 5），**仅排周末岗位**（②片剂机配方 / ③审方校对 / ⑤机动调配麻精一 / ⑥13:30 / ⑦窗口）；④片剂校对、⑧机动调配、后勤等「仅工作日」岗位**不排**；列头浅蓝标记，且**排除在平衡统计之外**。
> 4. **机动调配（⑧）限制**：⑧机动调配**仅在每周一与月度盘点日**排人，且**法定假期日不排**（假期按周末模式）；其余日该格留空属正确状态。
> 5. **盘点日自动 + 避开假期**：月度盘点日默认 = 当月**最后一个周五**；若最后一个周五恰为月末、或恰为法定假期，则顺延至**上周五**（避开假期）。可用模板「月底盘点日」或 `--stock` 覆盖。
> 6. **总表自描述**：`write_summary_sheet` 在末尾写入「假期日：…；盘点日：…」备注，verify / selfcheck **无需输入模板**即可识别假期与盘点日。

## 一、人员与岗位定义

### 1.1 人员（完全由输入模板决定，**代码零硬编码**）

- 角色分两类：`核心`（参与每日命名岗轮转）、`后勤`（仅工作日，固定在 ⑨ 后勤岗）。
- 人数、姓名、类型、约束**全部来自输入模板「人员名单」页**。
- 模板名单为空 → 生成器报错退出（保证「未提供名单时模板不可用」）。

**约束列说明（输入模板「人员名单」页，共 6 列）**：

| 列 | 含义 | 生成器是否解析 |
|---|---|---|
| 姓名 | 人员姓名 | 是 |
| 类型 | `核心` / `后勤` | 是 |
| 禁止岗位 | 硬约束：绝不排这些岗（逗号分隔） | 是（`can_fill_position`） |
| 偏好岗位 | 软偏好（当前版本仅记录，轮转已由公平匹配保证） | 是（记录） |
| **尽量避免岗位** | 软约束：尽量少排这些岗（非禁止），匹配时加高额费用惩罚 | 是（`_match_posts_fair` 加罚） |
| 备注 | 自由文本，人看 | 否（不解析） |

> ⚠️ 约束只认「禁止岗位 / 尽量避免岗位」两列。「备注」是给人看的，写备注里的禁令**不生效**；改岗位职责请直接编辑对应列，岗位名须与岗位表完全一致（如 `片剂机配方`），多个用英文逗号隔开。

## 二、核心约束（铁律）

1. **人头数神圣**：周末严格休 4（在岗恰好 5）、工作日休 2（在岗 7）、盘点日全员（休 0）、**法定假期按「休息日人数」= 周末模式（休 4 / 上 5，仅周末岗位）**。**永不浮动、永不为填岗而拉休息的人顶岗。**
2. **岗位必须有人 ＞ 员工休息**：固定人头优先。每日命名岗用二分匹配（人头数严格 = 当日上岗数），只在约束使「当日上岗人员」无解时才牺牲休息——正常情况下上岗者足以填满命名岗，backfill 不应触发。
3. **公共假期 = 周末模式**：休 4 / 上 5，仅排周末岗位（②③⑤⑥⑦）；④⑧⑨⑩等工作日专属岗不排；列头浅蓝标记且**排除在平衡统计之外**。假期日的总表单元格仍按真实休息状态写「休 / 班」（不写「假」单元格），以便与周表 100% 一致；识别假期靠列头浅蓝 + 末尾自描述备注。
4. **无补班日**：医院不调休、不补班，本工具**不存在「补班日」类别**——任何周末都不会被改成工作日，生成器也无 `--makeup` 参数。
5. **机动调配 ⑧ 限制**：⑧机动调配**只在每周一与月度盘点日**排人，**法定假期日不排**（假期按周末模式，无⑧）；其余日格留空是正确的（verify 不会因此报错）。
6. **13:30**：每人每个 ISO 周（周一~周日）至多 1 次（含周末）。每周 7 天用回溯保证由不同人员担任。两名均被禁窗口/片剂机配方/机动调配麻精一的人员同时周末在岗时，强制其一占 13:30（二人只能填 ③，否则命名岗卡死）。盘点日全员盘点，当日不单列 13:30。
7. **平衡 best-effort**：在固定人头下，平衡差值 ≤ 2 属正常（与真实班表 −1~−3 一致）。不要追求精确为 0 —— 那在数学上不可能（如周末多月，要求人均周中休 = 周末上班数，但工作日固定休 2 时必差 ±1~2）。
8. **跨月不完整周（半自动）**：周表按完整 ISO 周展开；不足 7 天的边界日自动从邻月生成结果借来填充满（带 `*` 标记）。跨月周的 13:30 周频与边界日建议人工复核（校验工具已自动跳过跨月日，避免与邻月重复计）。

## 三、算法流程（schedule_generator.py）

1. `read_input(path)`：从模板读人员名单 + 生成参数（年份/月份/工作日休息人数/周末休息人数/月底盘点日/公共假期日/随机种子）。名单为空 → `ValueError`。**已移除「补班日」解析。**
2. `compute_inventory_day(year, month)`：盘点日 = 当月最后一个周五；若该周五为月末则顺延上周五。`generate_schedule` 在取定后还会**顺延避开法定假期**（若落到的周五恰为假期，继续减 7 天直到非假期）。
3. `generate_rest_schedule(staff, params)`：固定人头休息安排。周末休 4、工作日休 2、**法定假期休 4（等同周末模式）**、盘点休 0；假期排除平衡统计；用交换法 + 连续休息平滑（≤2）逼近平衡。**此函数不得 discard 任何人的休息标记。**
4. `assign_daily_positions(staff, rest_schedule, params)`：
   - 定义 `is_off(d) = 周末 或 法定假期`，用于决定「工作日专属岗是否排 / 后勤是否上岗」；
   - 13:30 周统筹（回溯，保证每周不同人；跳过盘点日）；
   - 命名岗 `_match_posts_fair`（最小费用二分匹配，费用=该人已做此岗次数 + **尽量避免岗高额罚分**，实现轮转与软避让）；处理每一天后累加 `pos_counts`；
   - ⑧机动调配只在周一/盘点日且**非假期**时进候选；
   - 药架整理由在岗者兼任（假期后勤不排，由核心兼任 m-p/q-w 架）。
5. `write_weekly_sheets(...)`：写「名单」+ 各 ISO 周表（圆圈编号、C 列时间段、收单行、药架子表）。假期单元格按周末模式显示（9:00 后缀、工作日专属岗留空）。
6. `write_summary_sheet(...)`：写「总班表」人 × 日矩阵（休/班/盘），并在末尾写入自描述备注「假期日：…；盘点日：…；假期/盘点不计入平衡；跨月*日属邻月」。

## 四、输入模板格式

`班表输入模板.xlsx` / `班表输入模板_10月盘点.xlsx` 含三个 sheet（**均为空名单，仅留提示行**）：

- **人员名单**：6 列 = 姓名 / 类型 / 禁止岗位（英文逗号分隔）/ 偏好岗位（英文逗号分隔）/ **尽量避免岗位（英文逗号分隔）** / 备注。空行忽略；提示行（`（`开头）忽略。
- **生成参数**：键值对 —— 年份 / 月份 / 工作日休息人数 / 周末休息人数（保留未用，固定 4）/ 月底盘点日（留空=自动取最后周五并避开假期；或填 `31` 等覆盖）/ 公共假期日（如 `25` 或 `1,2`）/ 随机种子（默认 42，设 0 则随机）。**无「补班日」行。**
- **岗位说明**：岗位清单与周末标记（参考用）。

命令行 `--holiday` 会**覆盖**模板里的对应值；盘点日优先取 `--stock`，其次模板「月底盘点日」，最后自动计算（并避开假期）。

## 五、历史 Bug 根因与修复（交付前务必确认未复发）

### Bug ① 总表「同一个人既休息又上班」+ Bug ②「有人永远不休息」
- **根因**：旧总表设计成「工作日列显示休息名单、周末列显示值班名单」两栏并排 —— 同一个人在两栏都出现，看着像既休又上；而主要在周末休息的人只出现在值班列，看着像从不休。
- **修复**：总表改为**人 × 日矩阵**，每格单一状态（休/班/盘），末列附当月休息天数。数据直接来自 `rest_schedule`，与周表 100% 一致。
- **验证**：`selfcheck.py` 的 [A] 段逐日比对总表「休」与周表推断的真实休息，必须 100% 一致；[B] 段每人最少休息 ≥ 2 天。

### Bug ③ 能排多岗却「一直被钉死在一个岗」
- **根因**：第二阶段命名岗原用「只求有解」的二分匹配，且 `pos_counts` 对命名岗从不累加 → 可干岗少的人每次都被固定分到同一岗（实测 76–84%）。
- **修复**：改用 `_match_posts_fair`（最小费用二分匹配，费用=该人已做此岗次数），处理每天后累加 `pos_counts`，自然轮转。新增「尽量避免岗位」软避让（高额罚分）。
- **验证**：`selfcheck.py` 的 [C] 段，任何人主岗占比 ≥ 70% 且总次数 ≥ 5 即告警。**仅能担任②③者固定在②③属正常**，不告警。

### Bug ④（关联）拉休息的人顶岗破坏「周末严格休 4」
- **根因**：旧 backfill 在岗位卡死时 `rest_schedule[d].discard(chosen)`，把休息标记删掉 → 周末实际只休 3。
- **修复**：删除 backfill；二分匹配保证人头数 = 当日该上几个人，永不多拉人。

### Bug ⑤（关联）假期日总表强制全班与周表矛盾
- **根因**：早期总表把所有假期日写成「班」，但 `rest_schedule` 假期仍按正常休息排。
- **修复**：假期日按真实休息状态标注（总表仍是休/班，列头浅蓝 + 末尾备注标记假期），与周表一致。

### Bug ⑥ selfcheck 误报「总表/周表矛盾」18 天
- **根因**：`selfcheck.py` 用 `ws.cell(r,2).value=='日期'` 定位药架区段，但周表**第 2 行 B 列也是「日期」**（表头），于是错把 row 2 当成药架起点，只扫了 3–9 行，**真正的药架行（约 17–23）被漏扫**。结果只出现在药架行的在岗者被误判为「休息」→ 与总表矛盾。
- **修复**：`_find_shelf_start` 改用稳定的 `SHELF_NOTE`（「住院药房每天整理药架安排表」）锚点定位真实药架区段。
- **验证**：`selfcheck.py` [A] 必须 100% 一致。

### Bug ⑦ verify 误报「岗位空缺 / 13:30 违规」与跨月重复计
- **根因（三处）**：
  1. ⑧机动调配仅周一/盘点日排人，verify 却默认每天都必须有人 → 误报「岗位空缺」（约 20 处）。
  2. verify 把跨月拼接的 `*` 日也纳入 13:30 周频与人数统计，而跨月日归属邻月、与本月 ISO 周重叠 → 误报 13:30 跨周重复（3 处）。
  3. `read_forbidden` 用 `re.split(r"[,，、]")` 把复合岗位名「机动调配、麻精一调配」拆成「机动调配」+「麻精一调配」，误把 ⑧机动调配（显示名「机动调配」）当成被禁岗 → 误报禁止岗位（5 处）。
- **修复**：
  1. ⑧机动调配仅当 `周一 或 盘点日 且非假期` 才要求有人；其余日空缺正确。
  2. 从「总班表」末尾自描述备注解析归属假期日 / 盘点日，并跳过非本月（跨月 `*`）日。
  3. `read_forbidden` 复用生成器的 `parse_position_list`（先整串匹配岗位名，再退化按、拆分），与生成器口径一致。
- **验证**：verify 三项违规总数均应为 0。

## 六、排错速查

| 现象 | 检查点 |
|---|---|
| verify 报周末/假期人数 ≠ 5 | `generate_rest_schedule` 是否被改成 discard 休息；`assign_daily_positions` 有无残留 backfill；假期是否被当作工作日（应休 4） |
| 假期日出现 ④/⑧/后勤 在岗 | 错误：`is_off` 未把假期当周末模式；检查 `_day_named_posts` 是否对假期跳过工作日专属岗 |
| selfcheck [A] 矛盾集中在每月首/末周 | 多为误报：跨月拼接日（带 `*`）只存于周表，summary 不含 → 确认矛盾日期是否在本月日内；若仍矛盾检查 `_find_shelf_start` 是否锚定 SHELF_NOTE |
| selfcheck [C] 某人主岗 ≥ 70% | `_match_posts_fair` 是否生效、`pos_counts` 是否每日累加 |
| 生成器报「岗位空缺」或「命名岗匹配失败」 | 13:30 周统筹可行性校验失效；检查两名受限人员同时周末在岗时是否强制其一占 13:30 |
| 盘点日 13:30 显空 | 正常（盘点日全员盘点无窗口）；verify 已对全员在岗日跳过 13:30/岗位断言 |
| 盘点日落在法定假期（如中秋周五） | 异常：应已顺延上周五。检查 `generate_schedule` 中 `while inv.day in hol_days` 顺延逻辑 |
| verify 报 ⑧机动调配空缺 | 该日非周一/非盘点日/或假期 → 属正确，不应报；若周一/盘点日且非假期仍空，检查 `p8b_days` 与 `compute_inventory_day` |
| verify 误报禁止岗位（如把⑧当⑤禁） | 检查 `read_forbidden` 是否复用 `parse_position_list`，不要自行按、拆分 |

## 七、自检命令（交付前强制两层全绿）

```
python scripts/verify_output.py <结果.xlsx> [--input 模板.xlsx]
python scripts/selfcheck.py     <结果.xlsx>   # 或不传参，自动扫当前目录班表文件
```

任一门槛未过，回到 `schedule_generator.py` 修复后重新生成，**不得交付半成品**。
