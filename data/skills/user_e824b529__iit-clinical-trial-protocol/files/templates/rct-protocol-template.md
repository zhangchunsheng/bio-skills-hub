# 临床研究方案通用模板（RCT / pRCT）

> 本文件描述 RCT/pRCT 方案的完整章节结构，供 AI 读取后通过 `scripts/generate_protocol_template.js` 生成 Word 文档。
> 对应脚本：`scripts/generate_protocol_template.js`（占位符版，需替换 `{{PLACEHOLDER}}` 后运行）。

## 文档结构总览

```
封面页 → 保密声明 → 签字页 → 缩略语表 → 方案摘要 →
第1-17章正文 → 附录1 → 附录2
```

## 各章节详细结构

### 封面页
- 研究题目全称（居中、大号加粗）
- 设计类型描述（居中、大号加粗）
- "临床研究方案"标题（居中、特大号加粗）
- 研究方案编号：`{{编号}}`
- 研究阶段：`{{阶段}}`
- 版本号：V1.0
- 版本日期：`{{日期}}`
- 分页符

### 保密声明
- 标题"保密声明"（居中、加粗）
- 正文：本方案属于保密性文件，所有权归申办者，仅提供给研究者、伦理委员会和监督管理部门审阅
- 分页符

### 签字页
- 标题"临床试验方案确认签字页"（居中、加粗）
- 研究题目全称
- 主要研究者关于方案的同意书段落
- 研究组长单位、主要研究者签字与日期
- 分页符

### 缩略语表
- Heading 1 标题"缩略语表"
- 三列表格：英文缩写 | 英文全称 | 中文全称
- 基础缩略语：AE, SAE, GCP, CRF, FAS, PPS, SS
- 按研究领域补充特定术语
- 分页符

### 方案摘要
- Heading 1 标题"方案摘要"
- 两列表格（左列加粗底色）：
  - 研究名称、研究方案编号、版本号/版本日期
  - 研究设计、研究对象、样本量
  - 研究目的（主要+次要）、研究分组
  - 干预措施、对照措施
  - 入选标准、排除标准
  - 研究终点（主要+次要）、分析方法
- 分页符

## 格式规范
- 字体：中文 Microsoft YaHei，英文 Arial
- A4 页面：width 11906, height 16838
- 页边距：上下左右各 1440 twips
- 页眉：研究方案简称（灰色小字，居中）
- 页脚：页码（居中，"第 X 页"）
- 表格：双重宽度（columnWidths + cell width），行不跨页（cantSplit）
- 标题样式：Heading1（32pt加粗）、Heading2（28pt加粗）、Heading3（26pt加粗）
- 单一 section（避免多 section 产生空白页）
- keepNext: false（避免标题与后续内容强制同页）
