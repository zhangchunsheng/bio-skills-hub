# 真实世界研究方案通用模板（RWS）

> 本文件描述 RWS 方案的完整章节结构，供 AI 读取后通过 `scripts/generate_rws_protocol_template.js` 生成 Word 文档。
> 对应脚本：`scripts/generate_rws_protocol_template.js`（支持 CLI 标志切换子类型）。
> 与 RCT 模板的主要差异：第4章（分组与暴露定义）、第7章（无干预）、第13章（混杂控制与加权分析）。

## 文档结构总览

```
封面页 → 保密声明 → 签字页 → 缩略语表 → 方案摘要 →
第1-17章正文 → 附录1 → 附录2
```

## 各章节详细结构

### 封面页
- 研究题目全称（居中、大号加粗）
- 设计类型描述（居中、大号加粗，需体现"真实世界研究"及子类型）
- "临床研究方案"标题（居中、特大号加粗）
- 研究方案编号：`{{编号}}`
- 研究阶段：`{{阶段}}`
- 版本号：V1.0
- 版本日期：`{{日期}}`
- 分页符

### 保密声明
- 标题"保密声明"（居中、加粗）
- 正文：本方案属于保密性文件，所有权归申办者
- 分页符

### 签字页
- 标题"临床研究方案确认签字页"（居中、加粗）
- 研究题目全称
- 主要研究者关于方案的同意书段落
- 研究组长单位、主要研究者签字与日期
- 分页符

### 缩略语表
- Heading 1 标题"缩略语表"
- 三列表格：英文缩写 | 英文全称 | 中文全称
- RWS 专属缩略语：PSM, IPTW, HR, KM, CI, TTE, CER
- 按研究领域补充特定术语
- 分页符

### 方案摘要
- Heading 1 标题"方案摘要"
- 两列表格（左列加粗底色）：
  - 研究名称、研究方案编号、版本号/版本日期
  - 研究设计类型、数据来源、研究对象、样本量
  - 研究目的（主要+次要）
  - 暴露组与对照组定义
  - 入选标准、排除标准
  - 研究终点（主要+次要）、分析方法
- 分页符

### 4 研究设计（RWS 专用）
- Heading 1 标题
- 4.1 整体设计和计划（Heading 2）
  - 说明研究类型：前瞻性队列 / 回顾性队列 / PSM 模拟 RCT / CER / 登记研究
  - 数据来源描述
- 4.2 分组与暴露定义（Heading 2）**【RWS 核心差异】**
  - 暴露组定义（用药、剂量、疗程）
  - 对照组定义（对照药或未暴露）
  - 暴露确定方法（处方记录、药品追溯、暴露窗定义）
- 4.3 混杂控制策略（Heading 2）**【RWS 核心差异】**
  - PSM（倾向性评分匹配）：匹配变量列表、匹配方法（1:1/1:N）、卡钳值
  - IPTW（逆概率加权）：权重计算模型、稳定性处理
  - 负二项/Logistic 回归校正
  - 敏感性分析方案
- 4.4 模拟靶试验框架（Heading 2）**【TTE 子类型专用】**
  - 七要素： eligibility, treatment strategies, assignment, causal contrast, outcome, follow-up, analysis plan

### 13 统计分析（RWS 专用）
- Heading 1 标题
- 13.1 样本量确定（完整公式、参数来源、计算过程）
  - **RWS 特定**：基于暴露组/对照组比例、基线事件率、目标差值
  - 考虑匹配后样本损耗（PSM 场景）
- 13.2 分析人群的定义和选择
  - **RWS 特定**：匹配后人群（PSM 场景）、加权后人群（IPTW 场景）
  - ITT-like / Per-protocol-like 分析
- 13.3 统计方法（与设计类型匹配）**【RWS 核心差异】**
  - 基线特征比较（SMD < 0.1 判定平衡）
  - 主要分析：KM 曲线 + Log-rank 检验 + Cox 比例风险模型（HR + 95%CI）
  - 加权分析：IPTW-Cox / PSM-Cox
  - 负二项回归（计数型终点）
  - 敏感性分析：未匹配/未加权结果、不同匹配比、不同暴露窗
  - **CER 子类型**：比较效果研究专用分析框架
- 13.4 统计软件与一般要求
  - R 软件优先（PSM/IPTW 包丰富）
  - SAS 作为备选
- 分页符

## RWS 子类型差异速查

| 子类型 | CLI 标志 | 第4章差异 | 第13章差异 |
|--------|---------|-----------|-----------|
| 前瞻性队列 | （默认） | 标准分组+暴露定义 | KM+Cox+IPTW |
| 回顾性队列 | `--retrospective` | 增加回顾性数据来源说明 | 增加匹配后分析 |
| PSM 模拟 RCT | `--psm` | 增加 PSM 匹配策略节 | 增加匹配后人群+SMD |
| CER | `--cer` | 增加比较效果框架 | 增加竞争风险模型 |

## 格式规范
- 字体：中文 Microsoft YaHei，英文 Arial
- A4 页面：width 11906, height 16838
- 页边距：上下左右各 1440 twips
- 页眉：研究方案简称（灰色小字，居中）
- 页脚：页码（居中，"第 X 页"）
- 表格：双重宽度（columnWidths + cell width），行不跨页（cantSplit）
- 标题样式：Heading1（32pt加粗）、Heading2（28pt加粗）、Heading3（26pt加粗）
- 单一 section（避免多 section 产生空白页）
- keepNext: false（避免标题与后续内容强制同页）
