## 示例1的输出（对应"药物A用于老年患者无痛胃肠镜"输入）

### 交付物1：方案设计概要（对话中输出）

```
## 方案设计概要

| 要素 | 内容 |
|------|------|
| 研究题目 | 药物A用于老年患者无痛胃肠镜诊疗的有效性与安全性研究 |
| 设计类型 | 前瞻性、随机、单盲、阳性对照、非劣效性设计 |
| 样本量 | 240例（试验组120例，对照组120例） |
| 试验组 | 药物A 10mg/kg + 辅助镇痛药 0.1μg/kg |
| 对照组 | 药物B 1.5mg/kg + 辅助镇痛药 0.1μg/kg |
| 主要终点 | 镇静成功率（MOAA/S评分≤2的比例） |
| 非劣效界值 | -10% |

## 研究背景核心逻辑
无痛胃肠镜在老年患者中应用广泛，但药物B在老年人群中低血压、低氧血症等
不良反应发生率较高。药物A作为水溶性药物B前体药物，理论上面呼吸
抑制和低血压风险更低。然而目前缺乏在老年患者中直接对比两者的RCT证据，
本研究旨在填补这一空白。

## 参考文献概况
共引用文献18篇，其中：
- Meta分析/系统综述：2篇
- RCT：8篇（大样本3篇）
- 观察性研究：4篇
- 指南/共识：3篇
- 药品说明书：1篇
核心文献包括：[1] 中华医学会消化内镜学分会指南(2024), [3] Smith et al. RCT (2023, n=320)等

## 关键设计决策说明
1. 终点选择：选择镇静成功率作为主要终点（非劣效设计），因研究药物的核心
   优势在安全性而非有效性
2. 非劣效界值：-10%，基于既往药物Bvs安慰剂Meta分析的效应保留率75%确定
3. 剂量选择：10mg/kg基于药品说明书推荐及已有剂量探索研究[12]
4. 样本量参数：预期率95%基于3项同类RCT的加权平均值
```

## 示例5的输出（对应"药物A对比药物B术后 IV-PCA 真实世界队列"输入）

### 交付物1：方案设计概要（对话中输出）

```
## 方案设计概要

| 要素 | 内容 |
|------|------|
| 研究题目 | 药物A对比药物B用于成人术后静脉自控镇痛的有效性与安全性：一项前瞻性、多中心、观察性真实世界队列研究 |
| 设计类型 | 前瞻性、多中心、观察性真实世界队列（非随机、非盲），TTE 框架 + IPTW/重叠权重 |
| 样本量 | 计划 720~810 例（药物A组与药物B组约 1:1） |
| 暴露组 | 药物A IV-PCA（按真实处方） |
| 对照组 | 药物B IV-PCA（按真实处方） |
| 主要终点 | 术后 24h 静息痛 NRS 峰值 / NRS≤3 比例 |
| 混杂控制 | IPTW/重叠权重，加权后 SMD<0.1；E-value 敏感性分析 |

## 关键设计决策说明
1. 设计家族：因用药按真实临床决策、不拟随机，选 RWS 而非 RCT/pRCT
2. 混杂控制：数据前瞻采集、样本宝贵，采用 IPTW/重叠权重保留全样本，不配对丢弃
3. 框架：遵循 TTE 七要素（Hernán 等，PMID:26994063/36508210），因果问题陈述清晰
4. 报告：STROBE + RECORD + NMPA 真实世界研究指导原则
```

## 示例6的输出（对应"药物A vs 药物B 老年胸科 回顾性 CER + PSM 模拟 RCT"输入）

### 交付物1：方案设计概要（对话中输出）

```
## 方案设计概要

| 要素 | 内容 |
|------|------|
| 研究题目 | 药物A对比药物B用于老年胸科手术患者术后谵妄的比较效果研究：一项回顾性真实世界队列与倾向评分匹配模拟随机对照 |
| 设计类型 | 回顾性、观察性真实世界队列（CER）；非随机、以真实处方为暴露；PSM 1:1 匹配模拟 RCT |
| 数据来源 | 既有 HIS/EHR，ETL 提取；伦理豁免；遵循 RECORD |
| 样本量 | 提取目标人群后 1:1 最近邻匹配（caliper 0.2×SD），匹配前后 SMD<0.1 |
| 暴露组 | 药物A维持 |
| 对照组 | 药物B维持 |
| 主要终点 | 术后谵妄发生率（CAM-ICU） |
| 混杂控制 | 倾向评分 1:1 匹配 + caliper + 匹配前后 SMD 平衡表；条件 Logistic 报 aOR + 95%CI；E-value 敏感性 |

## 关键设计决策说明
1. 子类型：HIS 已有真实数据且三类变量较完整 → 选回顾性（`--retrospective`），省去前瞻录入成本
2. 混杂控制：需直观展示"模拟 RCT"组间可比 → PSM 匹配优先（`--psm`），附匹配前后 SMD 平衡表
3. 目的：双活性干预实效对比、服务医保论证 → CER（`--cer`），加效应修饰/亚组分析（§13.5）
4. 与示例5 区别：示例5 前瞻+IPTW 保留全样本；本例回顾性+PSM 丢弃未匹配样本但呈现更直观
```
