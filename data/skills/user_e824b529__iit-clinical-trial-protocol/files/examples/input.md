# 示例输入

## 示例1：完整方案设计（标准流程）

```
药物A用于老年患者无痛胃肠镜，对照组选择药物B。设计一个IIT研究方案。
```

**解析**：
- 研究药物/干预措施：药物A
- 适应症/目标人群：老年患者（≥65岁）无痛胃肠镜
- 对照选择：药物B（阳性对照）
- 研究类型：IIT（默认）
- 特殊要求：老年人群（安全性需重点关注）

## 示例2：带有研究类型偏好

```
药物A用于结肠镜息肉切除术中度镇静，对照用药物B。想做非劣效设计的IIT，
主要关注安全性优势，样本量不要超过500。
```

**解析**：
- 研究药物/干预措施：药物A
- 适应症/目标人群：结肠镜息肉切除术患者
- 对照选择：药物B
- 研究类型偏好：IIT，非劣效设计
- 特殊要求：关注安全性优势，样本量上限500例

## 示例3：仅执行部分阶段（样本量计算）

```
我有一个非劣效设计的RCT，主要终点是镇静成功率（率比较），
试验组预期率95%，对照组预期率95%，非劣效界值-10%，单侧α=0.025，
把握度90%，脱落率15%。帮我算样本量。
```

**解析**：
- 用户仅需样本量计算（阶段四），可跳过文献检索、背景撰写和文档生成
- 所有计算参数已由用户提供

## 示例5：真实世界研究（RWS）方案设计

```
药物A对比药物B用于成人术后静脉自控镇痛，做一个前瞻性、多中心、观察性的
真实世界队列研究，按真实处方分组，用 IPTW 控制混杂，不做 RCT。
```

**解析**：
- 暴露药物：药物A IV-PCA
- 对照药物：药物B IV-PCA
- 设计家族：RWS（非随机、非盲、真实世界）
- 混杂控制：IPTW / 重叠权重
- 路由：使用 `templates/rws-protocol-template.md` + `scripts/generate_rws_protocol_template.js`
- 关键差异：阶段三按 2.5 / rws-design-guide.md 选择；文档"随机化与设盲"替换为"分组与暴露定义、混杂控制"

---

## 示例6：RWS 子类型——回顾性 + PSM 模拟 RCT + CER

```
我们医院 HIS 里已经有药物A和药物B在老年胸科手术的真实用药数据，想做个
回顾性的比较效果研究，用倾向评分匹配模拟 RCT 来比两组的术后谵妄。
```

**解析**：
- 暴露药物：药物A；对照药物：药物B
- 设计家族：RWS，子类型 = 回顾性（`--retrospective`）+ PSM 模拟 RCT（`--psm`）+ CER（`--cer`）
- 数据来源：既有 HIS/EHR（非前瞻录入）→ 方案自动切换 ETL 提取、伦理豁免、RECORD 报告
- 混杂控制：1:1 最近邻匹配 + caliper + 匹配前后 SMD<0.1 平衡表（§13.3 自动改写）
- 目的标签：比较效果研究 CER（双活性干预实效对比 + 效应修饰/亚组，§13.5 自动加）
- 脚本调用：`node generate_rws_protocol_template.js --retrospective --psm --cer`
- 与示例5（前瞻+加权）对比：示例5 保留全部样本用 IPTW；示例6 丢弃未匹配样本用 PSM 但更直观展示"模拟 RCT"
