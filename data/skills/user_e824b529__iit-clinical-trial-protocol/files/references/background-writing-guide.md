## 1. 总体原则

研究背景是方案的核心章节，必须实现以下目标：
- **逻辑递进**：从宏观到微观，从已知到未知，最终落到研究空白
- **证据支撑**：每个关键论断必须有文献引用
- **聚焦科学问题**：所有内容服务于最终提出的科学问题

## 2. 五段式结构

### 2.1 第一段：临床需求与现状

**目标**：阐述目标疾病/诊疗操作的流行病学和临床现状，建立"为什么这个领域重要"的认知。

**内容要素**：
- 目标疾病/操作的发病率或施行量
- 当前标准诊疗方法的地位
- 权威指南的相关推荐（引用最新版指南）
- 目标人群的特殊需求（如老年、儿童、合并症等）

**示例句式**：
> "根据《XXX指南（20XX版）》，...约占...的XX%，...有助于提升...[1]。"

### 2.2 第二段：对照药物现状与局限

**目标**：阐述对照药物的应用现状和已知问题，为研究药物的优势建立参照。

**内容要素**：
- 对照药物的临床地位与广泛应用
- 对照药物的有效性数据（简要）
- 对照药物的已知安全性问题（详细，特别是目标人群中的问题）
- 具体数据支撑（发生率、风险比等）

**关键**：这一段要为后续"研究药物优势"建立明确的靶点。如果研究药物的优势是安全性，这里要详细论述对照药物的安全性问题。

### 2.3 第三段：研究药物特性

**目标**：介绍研究药物的药理学特性和理论优势。

**内容要素**：
- 药物类别与作用机制
- 与对照药物的药理学差异
- 理论优势（如水溶性、起效特点、代谢途径等）
- 研发与上市历程（如适用）

### 2.4 第四段：研究药物临床证据

**目标**：综述研究药物已有的临床研究证据，按证据等级从高到低排列。

**内容结构**（建议按以下子标题组织）：

**2.4.1 最高等级证据**（Meta分析、大样本RCT）
- 研究设计、样本量、主要发现
- 与对照药物的比较结果

**2.4.2 目标适应症证据**
- 在目标适应症中的已有研究
- 剂量探索研究（如有）

**2.4.3 目标人群证据**
- 在目标人群（如老年患者）中的研究
- 剂量调整建议
- 安全性数据

### 2.5 第五段：研究空白与立题依据

**目标**：明确当前证据缺口，提出本研究的必要性和科学问题。

**内容要素**：
- 总结已有证据的局限性（"综上所述..."）
- 逐条列出研究空白（第一、第二、第三...）
- 提出本研究的科学问题
- 说明研究设计的总体思路

**示例句式**：
> "基于以上研究空白，本研究拟开展一项...，以...为对照，评价...用于...的有效性与安全性。本研究的主要科学问题为：..."

## 3. 引用规范

### 3.1 正文引用格式
- 正文中使用方括号编号引用：`[1]`, `[2]`, `[1,3]`, `[1,3,5-7]`
- 引用编号按正文首次出现顺序排列

### 3.2 参考文献格式（GB/T 7714）
- 中文期刊：`作者. 题名[J]. 期刊名, 年份, 卷(期): 页码.`
- 英文期刊：`Author A B, Author C D, et al. Title[J]. Journal, Year, Vol(Issue): Pages.`
- 指南：`机构名. 指南名称[J]. 期刊名, 年份, 卷(期): 页码.`
- 说明书：`药品名 (通用名) [package insert]. 厂家名; 年份.`

### 3.3 数据引用
- 具体数值（发生率、效应量、置信区间等）必须标注来源
- 示例：`低血压发生率高达72.7%[8]`
- Meta分析结果报告效应量和置信区间：`RR=0.23, 95%CI 0.18-0.29, P<0.00001[3]`

## 4. 常见问题与规避

| 问题 | 规避方法 |
|------|---------|
| 文献堆砌无逻辑 | 严格按照五段式递进结构，每段服务于最终科学问题 |
| 编造文献 | 只引用实际检索到的文献，无法获取全文的标注说明 |
| 忽略阴性结果 | 如有矛盾证据，均报告并分析原因 |
| 研究空白不明确 | 第五段必须明确列出2-3条具体的研究空白 |
| 科学问题模糊 | 用疑问句明确提出，如"药物A的镇静成功率是否非劣效于药物B" |
| 剂量依据缺失 | 给药方案的剂量选择必须有文献支撑 |
