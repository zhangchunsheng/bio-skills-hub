## 1. 科学问题提炼

### 1.1 从研究空白到科学问题

研究背景的最后一段已列出2-3条研究空白。科学问题应直接回应最核心的研究空白。

**转换示例**：
- 研究空白："药物A在老年患者无痛胃肠镜中的有效性证据缺乏"
- 科学问题："在老年患者无痛胃肠镜诊疗中，药物A的镇静成功率是否非劣效于药物B？"

### 1.2 科学问题的PICO框架

每个科学问题应可拆解为PICO要素：

| 要素 | 含义 | 示例 |
|------|------|------|
| P (Population) | 目标人群 | 老年患者（≥65岁）行无痛胃肠镜 |
| I (Intervention) | 干预措施 | 药物A10 mg/kg + 辅助镇痛药0.1 μg/kg |
| C (Comparator) | 对照措施 | 药物B1.5 mg/kg + 辅助镇痛药0.1 μg/kg |
| O (Outcome) | 结局指标 | 镇静成功率 / 低血压发生率 |

## 2. 研究设计类型选择

### 2.1 设计类型决策树

```
核心科学问题是什么？
├── "是否不劣于对照？" → 非劣效性设计
├── "是否优于对照？" → 优效性设计
├── "是否与对照等效？" → 等效性设计
└── "安全性/真实世界实效特征如何？" → 观察性研究 / RCT安全性终点

需要随机化吗？（设计家族选择，见 2.4 / 2.5）
├── 需要确证效力、可接受严格入选 → 解释性 RCT
├── 关注实效、需宽入选与灵活干预 → 实用性 RCT（pRCT）
└── 用药按真实临床决策、不干预分配 → 真实世界研究（RWS，TTE 框架）

需要设盲吗？
├── 药物外观不同 → 双模拟技术 + 双盲
├── 药物外观相同 → 直接双盲
└── 无法设盲 / RWS 真实场景 → 开放标签 / 单盲（评估者盲）

单中心还是多中心？
├── IIT研究，样本量<300 → 单中心可接受
├── 样本量300-1000 → 建议多中心
└── 注册临床试验 / 大样本 RWS → 通常多中心
```

### 2.2 非劣效性设计要点

- **非劣效界值（δ）的确定**：
  - 基于既往阳性对照试验的Meta分析（最严谨）
  - 参考同类研究的常用界值
  - 临床最小可接受差异
  - 常见界值：成功率类-8%~-15%；连续变量0.3~0.5倍SD

- **检验方向**：单侧检验，α通常为0.025

### 2.3 序贯检验（Gatekeeping）设计

当研究药物有明确的安全性优势且这也是临床关注重点时，可采用序贯设计：

| 层级 | 终点 | 检验类型 | 前置条件 |
|------|------|---------|---------|
| 第一层 | 有效性终点 | 非劣效性 | 无 |
| 第二层 | 安全性终点 | 优效性 | 第一层成立后检验 |

**优势**：层级检验自动控制I类错误，无需额外多重比较校正。

### 2.4 RCT 与实用性 RCT（pRCT）的区分

解释性 RCT 与实用性 RCT 同属随机对照，但设计哲学不同（可用 PRECIS-2 工具评估实效性维度）。选择时须明确边界：

| 维度 | 解释性 RCT（explanatory） | 实用性 RCT（pragmatic, pRCT） |
|------|--------------------------|------------------------------|
| 核心目标 | 验证效力（efficacy，理想条件下是否有效） | 评估实效（effectiveness，真实条件下是否有效） |
| 研究对象 | 严格入选排除，同质性高 | 较宽入选，代表真实人群（含合并症/老年） |
| 干预实施 | 方案固定、剂量/流程强约束 | 允许按临床判断灵活调整 |
| 对照设置 | 常安慰剂/活性对照、双模拟 | 常标准治疗对照，贴近常规 |
| 设盲 | 常双盲 | 常开放或仅评估者盲 |
| 结局 | 替代终点/主要疗效终点 | 以患者为中心、卫生系统相关终点 |
| 偏倚控制 | 随机化内建 + 严格依从 | 随机化 + 宽纳入 + 真实世界依从 |
| 典型用途 | 注册确证、机制验证 | 卫生技术评估、医保/指南决策 |

> 判断要点：若用户目标是"证明药物在理想条件下有效"→解释性 RCT；若目标是"在真实诊疗中是否值得用"→pRCT。两者模板结构一致（含随机化与设盲章节），差异主要在人群宽度、干预灵活度与结局选择。

### 2.5 真实世界研究（RWS）设计分支

当科学问题依赖真实临床决策、无法或不拟随机时，采用 RWS（详见 `rws-design-guide.md`）。关键决策：

- **时序**：前瞻性（自建 eCRF 采集，完整度自控）vs 回顾性（依托 HIS/EHR/登记库，需注意变量完整性）
- **框架**：遵循目标试验模拟（TTE）七要素，将观察性比较显式化为一个假设的 RCT
- **混杂控制**：非随机导致组间失衡，用 IPTW / 重叠权重 / PSM 控制；前沿方案保留全部样本（加权），不强行配对丢弃
- **报告规范**：STROBE（观察性）、RECORD（常规收集数据）、NMPA《真实世界证据支持药物研发与审评的指导原则》
- **与 RCT/pRCT 文档差异**：RWS 模板将"随机化与设盲"替换为"分组与暴露定义、混杂控制策略"，统计章节以加权估计 + 敏感性分析（E-value）为主

### 2.6 RWS 子类型选择（前瞻 / 回顾 / PSM 模拟 RCT / CER）

在选定 RWS 后，技能包进一步按以下维度细分生成路径（对应 `generate_rws_protocol_template.js` 的标志）：

| 维度 | 选项 | 触发标志 | 适用情形 |
|------|------|---------|---------|
| 时序 | 前瞻性 | （默认） | 用户团队自建 eCRF、完整度自控、不依赖现成 HIS（最常见） |
| 时序 | 回顾性 | `--retrospective` | 已有高质量 HIS/EHR/登记库；方案自动切换 ETL 提取、伦理豁免、RECORD |
| 混杂控制 | 加权（IPTW/重叠权重） | （默认） | 大样本/前瞻，保留全部样本，前沿推荐 |
| 混杂控制 | PSM 模拟 RCT（匹配优先） | `--psm` | 需直观展示"模拟 RCT"组间可比；1:1 匹配 + caliper + SMD<0.1 平衡表 |
| 目的标签 | 比较效果研究 CER | `--cer` | 双活性干预实效对比、医保论证；自动加效应修饰/亚组分析章节 |

> 四个维度**正交可组合**：如"回顾性 + PSM + CER" = `node generate_rws_protocol_template.js --retrospective --psm --cer`。
> 选择判据：时序看"暴露/结局/混杂三类变量完整度"（系统性缺失→前瞻 IIT）；混杂控制看"样本量与是否需直观匹配展示"；CER 看"是否双活性干预实效对比"。

## 3. 主要终点选择

### 3.1 选择原则

1. **直接回答科学问题**：主要终点必须能直接回答PICO中的"O"
2. **临床相关性**：选择对临床决策有直接影响的指标
3. **可测量性**：终点定义清晰、可标准化测量
4. **文献支持**：同类研究常用的终点，便于结果比较
5. **敏感性**：能区分两组差异的指标

### 3.2 常见终点类型

| 领域 | 常用主要终点 | 适用设计 |
|------|-------------|---------|
| 镇静/麻醉 | 镇静成功率（MOAA/S≤2） | 非劣效 |
| 镇痛 | NRS评分≤3的比例 | 非劣效/优效 |
| 心血管 | 低血压发生率 | 优效 |
| 呼吸 | 低氧血症发生率 | 优效 |
| 肿瘤 | 无进展生存期（PFS） | 优效/非劣效 |
| 感染 | 临床治愈率 | 非劣效 |

### 3.3 主要终点 vs 次要终点

- **主要终点**：仅1个（最多2个，需多重比较校正），用于样本量计算
- **次要终点**：5-15个，包括时效性、安全性、满意度等
- **安全性终点**：不良事件发生率，通常作为次要终点或探索性终点

## 4. 入排标准设计

### 4.1 入选标准（通常3-6条）
- 年龄与性别范围
- 疾病/手术/状态特征
- ASA分级/功能状态
- 知情同意条款

### 4.2 排除标准设计逻辑
- **安全性考量**：过敏、严重合并症、妊娠
- **干扰因素排除**：合并使用禁用药物、其他临床试验
- **依从性考量**：认知障碍、语言障碍
- **特殊人群保护**：困难气道、严重器官功能不全

### 4.3 老年患者特殊考量
- 年龄界值通常≥65岁
- 需评估认知功能（MMSE）
- 需评估衰弱状态
- 排除严重器官功能不全
- ASA分级通常限制I-III级

## 5. 给药方案设计

### 5.1 剂量确定依据
1. 药品说明书推荐剂量
2. 目标人群的剂量调整（老年减量、肝肾功能调整）
3. 已有临床研究的剂量探索数据（ED50/ED95）
4. 联合用药的剂量调整

### 5.2 给药方案要素
- 初始剂量与给药速度
- 补救/追加剂量与时机
- 最大允许剂量
- 给药途径与配制方法

### 5.3 监测方案
- 生命体征监测频率
- 镇静深度评估工具（MOAA/S、BIS等）
- 不良事件处理预案（低血压、心动过缓、低氧血症）
