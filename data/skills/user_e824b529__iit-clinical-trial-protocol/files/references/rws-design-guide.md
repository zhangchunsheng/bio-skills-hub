## 1. RWS 的适用场景与边界

真实世界研究指在真实医疗环境下，以常规诊疗数据或前瞻性真实采集数据，评价干预措施的疗效与安全性。适用：

- 药物对标、日常决策、医保论证（用户常见诉求）
- 罕见暴露/对照、伦理学上不可随机的对比
- 长期安全性、以患者为中心结局（QoR、满意度）的评估

**边界**：RWS 不等于"低质量研究"。其因果推断强度依赖混杂控制质量；当无法合理控制混杂（关键变量系统性缺失、不可测量的强混杂）时，应转向 RCT/pRCT 或明确指出证据等级限制。

## 2. 设计家族选择（前瞻/回顾/登记）

| 类型 | 数据来源 | 完整度控制 | 偏倚 | 适用 |
|------|----------|-----------|------|------|
| 前瞻性观察性队列 | 自建 eCRF 前瞻录入 | 高（字段必填自控） | 选择偏倚较小 | 用户常选：不依赖现成 HIS、完整度可控 |
| 回顾性观察性队列 | HIS/EHR/登记库提取 | 取决于库质量 | 缺失/测量偏倚 | 已有高质量数据库时 |
| 真实世界登记研究（registry） | 长期结构化登记 | 高、可复用 | 中 | 需长期累积大样本 |

> 若医院 HIS 中"暴露/结局/混杂"三类关键变量常不完整，优先选**前瞻性 eCRF**；先做一次"数据可行性预查"统计关键变量缺失率再定。

### 2.1 回顾性 RWS 专属要点

当数据来自既有 HIS/EHR/登记库（非前瞻录入）时，方案须额外明确：

- **数据提取（ETL）**：预设字段集与提取窗口；记录数据溯源与字段映射（如 ICD/ATC 编码映射至暴露/结局/协变量）。
- **伦理与知情同意**：回顾性研究多依伦理委员会**豁免**或**宽泛同意**，不触及受试者前瞻性操作；须在方案中写明豁免依据与去标识化措施。
- **报告规范**：除 STROBE 外，须遵循 **RECORD**（常规收集数据研究报告）扩展，专门报告数据来源、采集、缺失与链路。
- **缺失与测量偏倚**：回顾性偏倚风险更高，平衡诊断（SMD）与敏感性分析（E-value）须更充分；系统性缺失应触发方案修订而非强行插补。
- **生成脚本**：`generate_rws_protocol_template.js --retrospective` 会自动将 5.1/7.1/12.1/12.4/15.2 切换为回顾性专属措辞（ETL、伦理豁免、RECORD）。

> 选择前瞻 vs 回顾的核心判据仍是"三类关键变量（暴露/结局/混杂）的完整度"——完整则回顾性可行（配 MICE），系统性缺失则改前瞻性 IIT（用户团队优势所在）。

## 3. 目标试验模拟（TTE）七要素

将观察性比较显式化为一个假设的 RCT（Hernán 等，PMID:26994063 / JAMA 2022，PMID:36508210）。方案"4.1 整体设计"须逐条填写：

| # | 要素 | 方案落点 |
|---|------|----------|
| ① | 目标人群 Eligibility | 5.1–5.3 入选/排除（仅安全性排除，宽入选） |
| ② | 治疗策略 Treatment strategy | 6.1–6.2 真实暴露/对照定义 |
| ③ | 分配 Assignment | 4.2 非随机、以真实处方为暴露；借 PS 加权模拟随机 |
| ④ | 随访 Follow-up | 7.3 随访时点（如术后 24/48/72h、30天） |
| ⑤ | 结局 Outcome | 8.1–8.3 主要/次要/安全性终点 |
| ⑥ | 因果对比 Causal contrast | 13.3 加权后 ATE/ATT，aOR/aHR + 95%CI |
| ⑦ | 分析 Analysis | 13.3 IPTW/重叠权重 + 平衡诊断 + 敏感性分析 |

## 4. 混杂控制：IPTW / 重叠权重 / PSM

非随机导致暴露组与对照组基线失衡，须控制混杂：

- **IPTW（逆概率治疗加权）**：由倾向评分构造权重，使加权后协变量分布均衡；保留全部样本。
- **重叠权重（Overlap Weighting, OW）**：仅对"共同支持"区域加权，更稳定、避免极端权重；前沿推荐。
- **PSM（倾向评分匹配）**：1:1 最近邻匹配，直观但丢弃样本（尤其大样本时不经济）。
- **平衡诊断**：报告加权前后各协变量标准化均数差（SMD），以 **SMD<0.1** 为达标。
- **选择**：前瞻/大样本优先 IPTW 或 OW（不丢样本）；小样本或需直观展示可 PSM。

### 4.1 PSM 模拟 RCT（匹配优先模式）

当研究目的就是要"把观察性比较包装为一个假设的目标 RCT"并直观展示组间可比时，采用 **PSM 模拟 RCT** 作为首要方法（区别于默认的加权法）：

- **匹配算法**：多变量 logistic 回归估倾向评分 → **1:1 最近邻匹配**、**caliper = 0.2×SD（或 0.05 对数评分）**、无放回。
- **平衡诊断**：报告匹配**前后**各协变量标准化均数差（SMD），以 **SMD<0.1** 为达标（附平衡表/ Love plot）。
- **结局分析**：在匹配队列上用条件 Logistic（二分类）/ 条件 Cox（时间事件）报 aOR/aHR + 95%CI；连续变量用配对 t 检验或配对秩和。
- **残余混杂**：即便匹配后 SMD<0.1，仍须 E-value 评估未测量混杂；可做敏感性（不同 caliper、不同协变量集、IPTW 交叉验证）。
- **与加权法的关系**：PSM 丢弃未匹配样本，大样本时不经济；故默认推荐 IPTW/OW，PSM 作为"匹配优先"显式选项。
- **生成脚本**：`generate_rws_protocol_template.js --psm` 会将 §13.3 自动切换为"1:1 匹配 + caliper + SMD 平衡表"范式。

## 5. 样本量与统计分析方法

- **样本量**：RWS 以"效应估计精度 + 加权后有效样本量"为原则。连续终点 n = 2(Z_{1-α/2}+Z_{1-β})²σ²/Δ²；率终点用两样本率公式；最终以预试验效应量与变异精算并在统计计划锁定。预留 15% 脱落与加权损耗。
- **分析人群**：观测队列全分析集（OBS）+ 加权伪人群（因果对比）+ 敏感性子集。
- **估计方法**：加权线性回归（连续）、加权 Logistic / 边际结构 Cox（二分类/时间事件），报均差/OR/HR + 95%CI。
- **敏感性分析**：① E-value 评估未测量混杂稳健性；② 不同权重（IPTW/OW/匹配）与协变量集稳健性；③ 按年龄/肾功能/术式分层的效果修饰。
- **软件**：R（MatchIt、WeightIt、survey、mice）或 SAS；脚本与锁定数据集存档。

## 6. 缺失数据处理（真实世界关键控制）

真实世界缺失普遍，须透明处理并遵循 STROBE 缺失报告：

- **完整性预查**：开工前统计暴露、结局、各 PS 协变量缺失率。
- **MCAR/MAR 且缺失<10%**：完整病例分析（listwise deletion），并在敏感性中验证。
- **缺失 5%~20%**：多重插补（MICE）后在插补数据集内完成加权分析并合并（Mitra & Reiter 法）。
- **系统性缺失**（关键变量大面积空白）：不强行插补，触发方案修订或改敏感性分析，明确证据等级限制。

## 7. 报告规范与法规依据

| 规范 | 用途 |
|------|------|
| STROBE | 观察性研究通用报告（缺失、偏倚、混杂须透明） |
| RECORD | 使用常规收集数据（HIS/EHR）的报告扩展 |
| NMPA《真实世界证据支持药物研发与审评的指导原则（试行）》（2020） | 国内监管依据 |
| ISPOR RWE 良好实践 | 监管/医保提交的真实世界证据质量 |
| 研究注册 | ChiCTR 或国际观察性登记预注册，锁定分析计划 |

> 文献真实性要求同 RCT 技能：所有引用必须实际检索；TTE 与 STROBE/RECORD/NMPA 指导原则建议作为 RWS 背景与方法学的必引项。

## 8. 比较效果研究（CER）目的标签与效应修饰

当科学问题是"在真实临床决策下，比较两种（及以上）干预的**实效**差异"时，本 RWS 即属于**比较效果研究（Comparative Effectiveness Research, CER）**。方案须：

- **目的标签**：在方案摘要、研究目的中显式标注"比较效果研究 CER"，明确比较的是两活性干预的实效而非效力。
- **效应修饰（effect modification）**：CER 的核心价值在于识别"哪些亚组获益更大"。须在统计计划中预设效应修饰分析：按年龄、肾功能、术式、基线严重程度、合并用药等分层，用交互项检验 + 亚组森林图呈现。
- **因果对比一致性**：报告加权/匹配后的 ATE/ATT，并说明在关键亚组中方向是否一致；不一致时讨论机制与证据等级限制。
- **生成脚本**：`generate_rws_protocol_template.js --cer` 会在摘要、研究目的、§13.5 自动加入 CER 标签与效应修饰/亚组分析章节。

> CER 与"前瞻性/回顾性/PSM"正交：CER 是**目的标签**，可叠加在任意时序与设计上（如"回顾性 CER + PSM 模拟 RCT"）。脚本支持组合标志 `--retrospective --psm --cer`。
