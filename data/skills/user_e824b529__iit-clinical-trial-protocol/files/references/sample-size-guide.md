## 1. 基本参数

| 参数 | 说明 | 常用值 |
|------|------|--------|
| α (检验水准) | I类错误概率 | 优效/等效：双侧0.05；非劣效：单侧0.025 |
| 1-β (把握度) | 检验效能 | ≥80%，推荐90% |
| p_T | 试验组预期率 | 基于文献 |
| p_C | 对照组预期率 | 基于文献 |
| δ | 非劣效/等效界值 | 基于Meta分析或临床共识 |
| 脱落率 | 预计脱落比例 | 15%-20% |

## 2. 计算公式

### 2.1 两样本率比较 — 优效性检验

**公式**：
```
n = (Z_{1-α/2} + Z_{1-β})² × [p_T(1-p_T) + p_C(1-p_C)] / (p_T - p_C)²
```

**Z值参考**：
| α（双侧） | Z_{1-α/2} | α（单侧） | Z_{1-α} |
|-----------|-----------|-----------|---------|
| 0.05 | 1.960 | 0.025 | 1.960 |
| 0.01 | 2.576 | 0.005 | 2.576 |
| 0.10 | 1.645 | 0.05 | 1.645 |

| 1-β | Z_{1-β} |
|-----|---------|
| 0.80 | 0.842 |
| 0.85 | 1.036 |
| 0.90 | 1.282 |
| 0.95 | 1.645 |

> **注**：非劣效性检验使用单侧 Z_{1-α}。当单侧 α=0.025 时，Z_{0.975}=1.960；
> 当单侧 α=0.05 时，Z_{0.95}=1.645。

**示例**：
p_T=0.75, p_C=0.55, α=0.05(双侧), power=90%
n = (1.96+1.282)² × [0.75×0.25 + 0.55×0.45] / (0.20)²
  = 10.51 × 0.435 / 0.04
  = 114.3 ≈ 115例/组

### 2.2 两样本率比较 — 非劣效性检验

**公式**：
```
n = (Z_{1-α} + Z_{1-β})² × [p_T(1-p_T) + p_C(1-p_C)] / (p_T - p_C - δ)²
```

注意：δ为负值（非劣效界值），如δ=-0.10

**示例**：
p_T = p_C = 0.95, δ = -0.10, α=0.025(单侧), power=90%
n = (1.96+1.282)² × [0.0475+0.0475] / (0+0.10)²
  = 10.51 × 0.095 / 0.01
  = 99.8 ≈ 100例/组

### 2.3 两样本均数比较 — 优效性检验

**公式**：
```
n = 2 × (Z_{1-α/2} + Z_{1-β})² × σ² / Δ²
```
σ为共同标准差，Δ为预期均数差

### 2.4 两样本均数比较 — 非劣效性检验

**公式**：
```
n = 2 × (Z_{1-α} + Z_{1-β})² × σ² / (Δ - δ)²
```
δ为非劣效界值（负值）

### 2.5 序贯设计样本量

取各层检验所需样本量的最大值：
```
N_total = max(n_layer1, n_layer2) × (1 + 脱落率)
```

## 3. 非劣效界值确定方法

### 3.1 基于Meta分析的方法（最严谨）

1. 汇总既往阳性对照试验（研究药物 vs 安慰剂/阳性对照）的Meta分析
2. 计算合并效应量（如率差RD或相对风险RR）
3. 非劣效界值 = 保留对照药物效应的50%-75%

### 3.2 参考同类研究

查阅同类设计的已发表研究使用的界值。

### 3.3 常见界值参考

| 终点类型 | 常用非劣效界值 | 来源 |
|---------|---------------|------|
| 成功率（镇静/麻醉） | -8% ~ -15% | 多数RCT |
| 成功率（治愈率） | -10% ~ -15% | FDA非劣效指南 |
| 连续变量 | 0.3~0.5 × SD | ICH E9 |
| 生存数据 | HR=1.3~1.5 | 肿瘤试验 |

## 4. 验证与敏感性分析

### 4.1 正态近似条件检查
- np ≥ 5 且 n(1-p) ≥ 5
- 若不满足，改用Farrington-Manning得分检验法

### 4.2 Farrington-Manning法
对极端比例（p>0.95或p<0.05）更稳健，计算结果通常略小于正态近似法。

### 4.3 参数敏感性分析
- 在预期率的合理波动范围内（±5%）重新计算样本量
- 报告不同参数组合下的样本量范围
