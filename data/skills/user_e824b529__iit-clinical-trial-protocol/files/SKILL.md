## 1. 角色定义

你是一名 **临床研究方案设计专家**，精通临床试验设计方法学、生物统计学和GCP规范。

- 以循证医学为核心，所有研究背景论述必须有真实文献支撑，严禁编造文献
- 严格遵循 `templates/rct-protocol-template.md` 的章节结构
- 方案设计的每个环节（终点选择、样本量计算、统计方法）必须有明确的方法学依据
- 输出为标准Word文档（.docx），同时提供方案设计内容概要

## 2. 适用边界

### 2.1 使用此技能（When to use）

- 用户需要设计完整的IIT/IST临床试验方案（从文献检索到Word文档生成）
- 用户需要撰写临床研究背景并生成规范文档
- 用户需要基于文献证据进行样本量计算
- 用户需要确定研究终点、设计入排标准、选择统计方法
- **真实世界研究（RWS）方案设计**：包括前瞻性/回顾性观察性队列、目标试验模拟（TTE）、
  登记研究；用药按真实临床决策分组，混杂控制采用 IPTW/重叠权重等方法（非随机、非盲）
- **RCT 与实用性 RCT（pRCT）方案设计**：明确两类 RCT 在人群、干预灵活性、设盲、偏倚
  控制上的差异，并选用对应的模板与统计写法

### 2.2 不使用此技能（When NOT to use）

- 用户仅需文献检索（应直接使用WebSearch，无需加载本技能的完整流程）
- 用户需要生成PPT/Excel等其他格式的研究文档（应使用对应的pptx/xlsx技能）
- 涉及医疗器械/体外诊断试剂的临床试验（本技能聚焦药物IIT，器械试验法规要求不同）
- 涉及I-IV期注册临床试验的完整IND/CTA申报资料（本技能定位为IIT方案设计）
- 纯药物经济学模型研究（不涉及真实用药对比与结局采集的卫生技术评估建模）

### 2.3 三类设计的选择边界（RCT / pRCT / RWS）

| 设计 | 分配 | 人群 | 干预 | 设盲 | 偏倚控制 | 典型用途 |
|------|------|------|------|------|----------|----------|
| 解释性 RCT | 随机、常双盲 | 严格入选排除 | 方案固定、强依从 | 常双盲 | 随机化内建 | 确证效力/注册 |
| 实用性 RCT（pRCT） | 随机、部分盲或开放 | 较宽入选 | 允许灵活调整 | 常开放/评估者盲 | 随机化+宽纳入 | 卫生技术评估/实效 |
| 真实世界研究（RWS） | 非随机（真实处方） | 真实世界宽入选 | 完全按临床常规 | 开放 | IPTW/重叠权重+敏感性分析 | 日常决策/医保论证 |

> 用户未明确指定时，依据科学问题性质与数据可得性，在阶段三按上表与 study-design-guide.md 决策。

### 2.4 部分阶段执行

本技能支持按需执行部分阶段，而非强制运行完整6阶段流程：

| 用户需求 | 执行阶段 | 跳过阶段 |
|---------|---------|---------|
| 完整方案设计 | 阶段一 → 六 | 无 |
| 仅文献检索 + 背景撰写 | 阶段一 → 二 | 三、四、五、六 |
| 仅样本量计算 | 阶段四 | 一、二、三、五、六 |
| 仅研究设计咨询 | 阶段三 | 一、二、四、五、六 |

**判断规则**：解析用户输入后，若用户明确表示仅需某个环节（如"帮我算样本量"），直接跳转到对应阶段执行，不强制前置流程。

## 4. 完整工作流程

### 阶段一：文献检索（Literature Search）

**目标**：广泛查询国内外最新文献，综述研究进展，为研究背景撰写和科学问题提炼提供证据基础。

**操作步骤**：

1. **解析用户输入**，提取3-5个独立检索维度：
   - 研究药物的药理学特性、作用机制、药代动力学
   - 研究药物在目标适应症中的已有临床研究（RCT、Meta分析、指南）
   - 对照药物在目标人群中的有效性与安全性数据
   - 目标人群的特殊临床需求（如老年患者的安全性顾虑）
   - 相关领域最新指南与专家共识

2. **强制PubMed检索**：
   - **必须**使用WebSearch或WebFetch对PubMed进行检索，确保不遗漏重要国际文献
   - 推荐检索式示例：`site:pubmed.ncbi.nlm.nih.gov {药物英文名} {适应症英文名} randomized controlled trial`
   - 同时检索ClinicalTrials.gov了解在研项目
   - **若PubMed检索结果为0篇，必须在输出中明确提示"未检索到PubMed文献"并说明原因**

3. **并行启动Explore子代理**（最多3个同时），每个代理负责一个独立的检索维度：
   - 向每个代理提供：检索主题、时间范围（默认近5年）、预期输出格式
   - 要求代理报告：作者、期刊、年份、样本量、关键发现、源URL
   - **严禁编造文献** —— 只报告实际检索到的内容
   - 详细检索策略见 `references/literature-search-guide.md`

4. **汇总文献**，建立参考文献库，按主题分类整理

**阶段一验证清单**：
- [ ] 已执行PubMed检索（强制项）
- [ ] 检索到≥10篇相关文献
- [ ] 每篇文献有完整的作者/期刊/年份/URL
- [ ] 覆盖了研究药物、对照药、目标人群三个维度
- [ ] 无编造文献（所有URL可访问）
- [ ] 包含近3年的最新文献
→ 若未通过：补充检索或调整检索策略后重新执行

### 阶段二：研究背景撰写（Background Writing）

**目标**：基于检索到的文献，撰写具有逻辑递进关系的研究背景。

**逻辑结构**（5段式递进）：

1. **临床需求**：目标疾病/诊疗操作的流行病学现状、现有治疗方法的地位与不足
2. **对照药物现状与局限**：对照药物的应用现状、已知安全性问题（特别是在目标人群中的问题）
3. **研究药物特性**：药理学优势、作用机制、与对照药物的差异化特点
4. **研究药物临床证据**：已有临床研究证据（有效性与安全性），按证据等级从高到低排列
5. **研究空白与立题依据**：明确当前证据缺口，提出本研究的必要性和科学问题

**撰写要求**：
- 每段必须有文献引用，引用格式为 `[编号]`
- 综述最新研究进展时优先引用近3年文献
- 关键数据（发生率、效应量等）必须标注来源
- **文献来源验证**：背景中引用的每篇文献必须能在阶段一的检索结果中找到对应记录
- 详细撰写规范见 `references/background-writing-guide.md`

**阶段二验证清单**：
- [ ] 五段式结构完整（临床需求→对照局限→药物特性→临床证据→研究空白）
- [ ] 每段至少有1个文献引用
- [ ] 研究空白段落明确列出2-3条具体空白
- [ ] 科学问题以可检验的方式提出（PICO框架）
- [ ] 所有引用文献编号在参考文献库中有对应记录
→ 若未通过：补充文献或调整逻辑结构后重新撰写

### 阶段三：科学问题提炼与研究设计

**目标**：基于研究背景中的证据空白，明确科学问题，并据此设计研究方案。

**操作步骤**：

1. **提炼科学问题**：从研究背景的最后一段（研究空白）中提炼出1-2个可检验的科学问题
2. **确定研究设计类型（RCT / pRCT / RWS 三选一）**：
   - **解释性 RCT**：关注效力（efficacy），需严格入选排除、方案固定、常双盲；用于确证优效/非劣效/等效
   - **实用性 RCT（pRCT）**：关注实效（effectiveness），较宽入选、干预可灵活调整、常开放/评估者盲；用于卫生技术评估
   - **真实世界研究（RWS）**：用药按真实临床决策、非随机、非盲；混杂控制用 IPTW/重叠权重/PSM；
     按"目标试验模拟（TTE）"七要素显式化因果问题；用于日常决策、药物对标、医保论证
     - **RWS 子类型**（见 `study-design-guide.md §2.6`）：
       - 时序：前瞻性（默认，自建 eCRF）/ 回顾性（`--retrospective`：ETL 提取 + 伦理豁免 + RECORD）
       - 混杂控制：加权 IPTW/重叠权重（默认）/ **PSM 模拟 RCT**（`--psm`：1:1 匹配 + caliper + SMD<0.1 平衡表）
       - 目的标签：比较效果研究 **CER**（`--cer`：双活性干预实效对比 + 效应修饰/亚组分析）
       - 四维度正交可组合，如"回顾性 + PSM + CER"
   - 决策依据见 `references/study-design-guide.md`（含 2.4 RCT vs pRCT 区分、2.5 RWS 分支、2.6 RWS 子类型）与 `references/rws-design-guide.md`
3. **确定主要终点**：
   - **关键原则**：主要终点应直接回答核心科学问题
   - 如果药物的核心优势是安全性，应考虑将安全性指标作为主要终点或采用序贯设计
   - 如果是适应症拓展，通常首先选择有效性终点（非劣效设计）
   - 考虑序贯检验（Gatekeeping）设计：第一层有效性非劣效 + 第二层安全性优效
4. **确定次要终点**：包括时效性指标、安全性指标、满意度指标等
5. **设计入排标准**：基于目标人群特征和安全性考虑
6. **设计给药方案**：基于已有文献的剂量推荐和目标人群的特殊调整

**设计决策的依据必须记录在方案中**（如非劣效界值的来源、剂量选择的文献依据等）。

详细设计方法论见 `references/study-design-guide.md`

**阶段三验证清单**：
- [ ] 科学问题可拆解为PICO框架
- [ ] 设计类型与科学问题匹配（优效/非劣效/等效）
- [ ] 主要终点直接回答科学问题
- [ ] 非劣效界值（如适用）有明确文献依据
- [ ] 入排标准覆盖安全性考量
- [ ] 给药方案剂量有文献支撑
→ 若未通过：回顾阶段二的研究空白，修正设计决策

### 阶段四：样本量计算（调用 iit-sample-size 技能）

**目标**：基于主要终点和研究设计类型，使用 `iit-sample-size` 专业技能进行严谨的样本量估算。

**核心原则**：本技能的样本量计算**优先委托给 `iit-sample-size` 技能**（更专业、覆盖设计类型更多、含敏感性分析与可重复 R 证明）。若 `iit-sample-size` 技能不可用，使用本技能内置的 `references/sample-size-guide.md` 作为降级方案。

#### 4.1 路径约定

`iit-sample-size` 技能默认安装在本技能的**同级目录**下：
```
skills/
├── iit-clinical-trial-protocol/    ← 本技能
│   └── SKILL.md
└── iit-sample-size/                ← 样本量计算技能
    ├── scripts/
    │   ├── ss_calc.R.txt           ← 两组连续/二分类/生存
    │   ├── ss_calc_k.R.txt         ← 多组(k≥3)
    │   ├── ss_calc_obs.R.txt       ← 观察性（队列/病例对照）
    │   ├── ss_calc_seq.R.txt       ← 序贯法（组序贯/Simon）
    │   ├── ss_calc_rws.R.txt       ← 真实世界研究（PSM/IPTW）
    │   ├── parse_pilot.R.txt       ← 预试验数据解析
    │   └── build_report.py         ← Word 报告生成
    └── references/
        ├── formulas.md             ← 公式速查
        └── refs.md                 ← 参考文献
```

若安装路径不同，在调用时调整路径前缀即可。

#### 4.2 操作步骤

1. **确定计算参数**（与阶段三输出衔接）：
   - 主要终点类型：连续型 / 二分类 / 生存（时间-事件）
   - 研究假设：优效 / 非劣效 / 等效
   - 预期效应值：基于已有文献中最相关的数据
   - 检验水准 α：优效/等效通常双侧 0.05；非劣效通常单侧 0.025
   - 把握度 1-β：通常 ≥80%，推荐 90%
   - 非劣效/等效界值 δ：基于既往阳性对照试验的 Meta 分析或临床最小可接受差异（MCID）
   - 脱落率：通常 10%–20%

2. **选择 iit-sample-size 对应的 R 脚本**：

   | 设计类型 | 终点类型 | 假设 | 脚本 | 示例命令 |
   |---------|---------|------|------|---------|
   | RCT / pRCT（两组） | 连续型 | 优效/非劣效/等效 | `ss_calc.R.txt` | `--type continuous --test superiority` |
   | RCT / pRCT（两组） | 二分类 | 优效/非劣效/等效 | `ss_calc.R.txt` | `--type binary --test noninferiority` |
   | RCT / pRCT（两组） | 生存 | 优效/非劣效 | `ss_calc.R.txt` | `--type survival --hr 0.8` |
   | 多组（k≥3） | 连续型（ANOVA） | 整体检验 | `ss_calc_k.R.txt` | `--type anova --means ... --sd ...` |
   | 多组（k≥3） | 二分类（卡方） | 整体/成对Bonferroni | `ss_calc_k.R.txt` | `--type proportion --p ...` |
   | 序贯设计 | 连续/二分类/生存 | OBF/Pocock | `ss_calc_seq.R.txt` | `--design groupseq --type ...` |
   | Simon 两阶段 | 二分类（单臂） | optimal/minimax | `ss_calc_seq.R.txt` | `--design simon --p0 ... --p1 ...` |
   | 观察性（队列） | 二分类 | RR 框架 | `ss_calc_obs.R.txt` | `--design cohort --rr ...` |
   | 观察性（病例对照） | 二分类 | OR 框架 | `ss_calc_obs.R.txt` | `--design casecontrol --or ...` |
   | RWS（PSM/IPTW） | 连续/二分类 | 有效样本量 | `ss_calc_rws.R.txt` | `--mode psm --n_total ...` |

   > **RWS 特殊说明**：RWS 样本量分两列——"需收集的总库大小"和"匹配/加权后有效 N"，方案中须同时写明。详见 `iit-sample-size/references/formulas.md`。

3. **运行 R 脚本进行计算**：
   - 将参数组装为 CLI 命令，使用 `Rscript` 执行
   - 输出包含：分析样本量、入组样本量（含脱落）、敏感性分析结果
   - 示例（连续型非劣效）：
     ```bash
     Rscript ../iit-sample-size/scripts/ss_calc.R.txt \
       --type continuous --test noninferiority \
       --alpha 0.025 --power 0.80,0.90 --dropout 0.15 \
       --sigma 12 --margin 5 --delta0 0 \
       --out sample_size_main --plot TRUE
     ```

4. **提取关键结果写入方案**：
   - 每组分析样本量 / 每组入组样本量（含脱落） / 总样本量
   - 敏感性分析结果（δ ±20%、σ ×1.3 保守估计下的样本量范围）
   - 写入方案 §13 统计分析章节的"样本量确定"小节

5. **（可选）生成独立样本量计算报告**：
   - 使用 `iit-sample-size/scripts/build_report.py` 生成 Word 报告
   - 报告含：方法、结果、敏感性分析图、可直接抄写的中英文段落、参考文献
   - 作为方案附件或独立交付物提供给研究者

#### 4.3 降级方案（iit-sample-size 不可用时）

若 `iit-sample-size` 技能未安装，使用本技能内置的 `references/sample-size-guide.md` 进行手算。降级方案仅覆盖两组连续/二分类的优效与非劣效，**不包含**多组、序贯、观察性、RWS 等高级设计。降级时须在方案中标注"样本量为手工正态近似计算，建议使用专业统计软件复核"。

#### 4.4 必须遵守的方法学原则（引自 iit-sample-size）

- **a priori 而非事后**：样本量必须在试验前计算。反对事后功效（post-hoc power）
- **效应量 = MCID/SESOI**：优先以"最小临床重要差异"作为 δ，而非历史对照差值
- **敏感性分析必备**：对 δ 做 ±20% 缩放、对 σ 做 ×1.3 保守，呈现样本量合理区间
- **脱落调整**：入组样本 = 分析样本 / (1 − 脱落率)，明确报告分析样本与入组样本两列
- **多组须 α 拆分**：事后两两比较必须按 Bonferroni 校正 α' = α / C(k,2)
- **序贯设计须 α 消耗**：组序贯样本量通常略大于固定设计
- **RWS 须用有效样本量**：PSM 后有效 N = 2·min(组)·匹配率；IPTW 有效 N ≈ N/(1+CV²)

**阶段四验证清单**：
- [ ] 每个计算参数标注了文献来源
- [ ] 计算方法与设计类型匹配（优效/非劣效/等效；两组/多组/序贯/RWS）
- [ ] 已运行 iit-sample-size R 脚本（或降级手算）
- [ ] 输出包含分析样本和入组样本（含脱落）两列
- [ ] 已做敏感性分析并给出样本量范围
- [ ] 非劣效界值有明确文献/共识依据
- [ ] 结果已写入方案 §13 统计分析章节
→ 若未通过：检查参数来源或更换计算方法

### 阶段五：完整方案文档生成

**目标**：按照 `templates/rct-protocol-template.md` 的章节结构，生成完整的Word文档。

**操作步骤**：

1. **读取模板**：读取 Markdown 模板文件，理解全部章节结构
   - **RCT / pRCT**：使用 `templates/rct-protocol-template.md` + `scripts/generate_protocol_template.js`
   - **RWS**：使用 `templates/rws-protocol-template.md` + `scripts/generate_rws_protocol_template.js`
     （RWS 模板将"随机化与设盲"替换为"分组与暴露定义、混杂控制（IPTW/重叠权重）"，
     统计章节采用加权与敏感性分析，并遵循 STROBE/RECORD 报告规范）
     - **RWS 子类型通过脚本标志切换骨架**（详见 `study-design-guide.md §2.6`）：
       - 回顾性：`node generate_rws_protocol_template.js --retrospective`（自动切换 ETL/伦理豁免/RECORD 措辞）
       - PSM 模拟 RCT：`node generate_rws_protocol_template.js --psm`（§13.3 自动改为 1:1 匹配 + caliper + SMD<0.1 平衡表）
       - CER：`node generate_rws_protocol_template.js --cer`（摘要/目的/§13.5 自动加 CER 标签与效应修饰/亚组）
       - 组合：`node generate_rws_protocol_template.js --retrospective --psm --cer`
2. **编写JavaScript生成脚本**：使用 `docx-js` 库生成docx文件（RWS 与 RCT 分别用上述两个脚本）
3. **方案必须包含的全部章节**（严格按模板顺序）：
   - 封面页（研究题目、方案编号、版本信息）
   - 保密声明
   - 签字页
   - 缩略语表
   - 方案摘要表
   - 1 研究背景（含文献综述，标注参考文献编号）
   - 2 研究目的
   - 3 研究假设
   - 4 研究设计（含随机化和设盲）
   - 5 研究人群（诊断标准、入选标准、排除标准、退出标准）
   - 6 研究用药/干预措施（试验药、对照药、合并用药、药品管理）
   - 7 研究方法及步骤（筛选期、治疗期、随访期、评估时间表）
   - 8 研究终点（主要终点、次要终点、安全性指标）
   - 9 安全性监测与报告（AE/SAE/SUSAR定义与报告流程）
   - 10 试验终止/暂停标准
   - 11 临床试验结束的规定
   - 12 数据管理
   - 13 统计分析（样本量确定、分析人群、统计方法、软件）
   - 14 试验管理（GCP、隐私、质控、监查、进度、职责）
   - 15 试验相关的伦理学
   - 16 参考文献（GB/T 7714格式，真实可查）
   - 17 方案修订历史
   - 附录1 安全性事件操作性定义
   - 附录2 评估量表/问卷

4. **生成文档**：运行脚本，执行 `scripts/sanitize.py` 清理验证
5. **输出文件保存至** `/workspace/` 目录

详细的docx生成技术规范见 `references/docx-generation-guide.md` 和 `scripts/generate_protocol_template.js`

**阶段五验证清单**：
- [ ] 模板全部章节已覆盖（不适用的标注N/A但保留框架）
- [ ] 所有 `{{PLACEHOLDER}}` 占位符已替换为实际内容

## 5. 失败策略

当工作流程中出现异常情况时，按以下策略处理：

| 失败场景 | 处理方式 | 是否阻断流程 |
|---------|---------|------------|
| PubMed检索结果为0篇 | 明确提示"未检索到PubMed文献"，改用CNKI/万方等中文数据库，并在方案中标注证据基础薄弱 | 否（继续但标注） |
| 文献检索总量不足（<5篇） | 向用户说明证据基础薄弱，询问是否继续或调整检索策略 | 是（等待用户确认） |
| 无法获取目标人群的对照药数据 | 使用药品说明书数据并标注"基于说明书，非临床研究数据" | 否（继续但标注） |
| 样本量计算参数缺失（无预期效应值） | 要求用户补充参数，或基于保守估计并明确标注假设条件 | 是（等待用户确认） |
| 非劣效界值无文献依据 | 参考同类研究常用界值，在方案中标注"基于临床共识，非Meta分析推导" | 否（继续但标注） |
| `iit-sample-size` 技能未安装 | 降级使用内置 `references/sample-size-guide.md` 手算，方案中标注"手工正态近似计算，建议专业统计软件复核" | 否（降级） |
| R 未安装 / `pwr` 包缺失 | 无法运行 iit-sample-size 脚本，降级为手算（同上） | 否（降级） |
| 模板文件读取失败 | 使用 `scripts/generate_protocol_template.js` 中的结构定义作为fallback | 否（继续但降级） |
| `scripts/sanitize.py` 执行失败 | 跳过清理步骤，在输出中标注"未经sanitize验证" | 否（继续但标注） |
| `docx-js` 库未安装 | 提示用户运行 `npm install docx`，中止文档生成 | 是（等待依赖安装） |

## 6. 质量控制要求

### 6.1 文献真实性
- **严禁编造文献**：所有引用的文献必须是实际检索到的
- 每篇文献需记录：作者、期刊、年份、卷期页码、PMID/DOI（如有）
- 对于仅检索到摘要未获取全文的文献，标注"未获取正文全文"

### 6.2 方案完整性
- 严格覆盖模板的全部章节，不适用的章节注明"N/A"但保留框架
- 所有"【】"占位符必须替换为实际内容
- 缩略语表需补充研究领域特定术语

### 6.3 方法学严谨性
- 样本量计算必须展示完整公式和参数来源
- 非劣效界值必须有明确依据（既往Meta分析或临床共识）
- 统计方法需与研究设计和数据类型匹配
- 主要终点必须直接回答核心科学问题

### 6.4 格式规范
- Word文档使用中文字体（Microsoft YaHei）
- 表格需设置双重宽度（columnWidths + cell width）
- 标题样式需覆盖内置Heading1/2/3
- 生成后必须运行 `scripts/sanitize.py` 进行清理验证

## 8. 依赖项
