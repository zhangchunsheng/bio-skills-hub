# 产品知识培训内容（维T2）

> 本 reference 解决"产品培训讲什么、课件怎么搭"。**边界：医学证据（机制/靶点/临床数据）由 drug-medical-postlaunch 提供，本维负责转译与产品化呈现。**

## T2.1 产品知识体系搭建

按 foundation.md §1 临床档案框架提取，产品化重组为可讲结构：
1. **一句话定位**：临床价值主张 ∩ 商业定位
2. **机制与靶点**：通路/靶点/药理分类（引用 references/drug-classes.md）
3. **临床数据**：关键 RCT/Meta/RWE（研究名·设计·样本量·终点·年份·证据等级，循证三件套）
4. **用法用量与特殊人群**：剂量/途径/儿童孕妇肝肾注意
5. **安全性**：不良反应/禁忌/相互作用/黑框警示
6. **竞品差异**：与主要竞品的特征-优势-利益对比

## T2.2 标准课件结构（PPT/手册）

```
1. 封面与定位（一句话价值主张）
2. 疾病背景与未满足需求（为什么需要这个药）
3. 作用机制（靶点/通路，图示化）
4. 关键临床证据（循证三件套，数据卡）
5. 用法与剂量（含特殊人群）
6. 安全性档案（不良反应/禁忌/管理）
7. 竞品对比（FAB 表，客观）
8. FAQ（医生最常问的 10 个问题 + 标准应答）
```
> 配套交付物：产品手册(PDF)、讲师 PPT、操作/机制动画视频、FAQ 话术卡。

## T2.3 FAB 转化（特征→优势→利益）

| 维度 | 说明 | 示例（创新药） |
|---|---|---|
| Feature 特征 | 产品客观属性 | 每月一次给药 |
| Advantage 优势 | 相对竞品的优势 | 相比每日给药，依从性更佳 |
| Benefit 利益 | 对患者/医生的价值 | 减少漏药、提升长期疗效、门诊负担降低 |

> 培训中须演练：把每个产品特征都翻译成"医生/患者能得到什么"。

## T2.4 竞品差异卡（应对异议）

| 维度 | 本产品 | 主要竞品 A | 主要竞品 B | 应对话术要点 |
|---|---|---|---|---|
| 机制 | | | | 机制差异化价值 |
| 关键数据 | | | | 客观呈现，禁贬低 |
| 安全性 | | | | 安全性档案对比 |
| 便利性 | | | | 依从性/给药方式 |

> 红线：竞品对比须客观、有依据，**禁止贬低性表述**（接口合规法务 skill MLR）。

## T2.5 更新机制

触发内容更新的事件：
- 产品新适应症获批 → 增补适应症模块
- 关键临床数据读出 → 更新证据卡
- 竞品上市/新数据 → 更新竞品差异卡
- 医保/集采准入 → 增补可及性模块

> 版本管理：课件标版本号+更新日期，确保 accuracy。

## T2.6 多对象适配（三套讲法）

| 对象 | 讲法重点 |
|---|---|
| 销售团队 | 卖点/FAB/竞品应对/如何讲给医生 |
| 医生（学术会） | 机制/证据/指南地位/真实世界数据 |
| 药师（药房/双通道） | 用法/相互作用/储存/患者用药指导 |

## T2.7 与 drug-medical-postlaunch 接口
- 医学证据（机制/靶点/循证三件套/指南地位）由医学 skill 提供，本维不重复生产。
- 本维负责：把医学证据转译为销售能讲、医生愿听的课件与话术。
