# 新人训练营内容体系（维T1）

> 本 reference 解决"新人从入职到转正，培训讲什么内容"。**边界：内容（课件/题库/路径）归培训 Skill；考核门槛、节奏、达标判定归 drug-hr H6。**

## T1.1 三阶段内容模型

| 阶段 | 周期 | 核心目标 | 内容重点 |
|---|---|---|---|
| **筑基期** | 入职 1–2 周 | 建立合规认知、熟悉规则与基础 | 行业政策概览、企业合规手册、产品知识入门、医学基础通识、销售流程（拜访准备→售后跟进）、职业素养、文化认同 |
| **实战期** | 入职 3–6 月 | 知识转技能、提升客户覆盖与学术推广 | 复杂客户沟通策略、学术活动策划执行、竞品应对技巧、压力与情绪管理、区域管理入门 |
| **进阶期** | 入职 1 年+ | 向学术专家型/管理者转型 | 行业趋势研判（创新药出海、AI 营销）、团队管理基础、高端客户维护、跨部门协作 |

## T1.2 各阶段课件清单

### 筑基期课件（必开）
1. 《医药行业与政策概览》——医保谈判/DRG-DIP/集采/代表备案
2. 《企业合规手册精讲》——礼品款待/学术推广规范/报销（合规承诺必签；合规课件由合规法务 skill 待建提供，本 Skill 只做排课嵌入）
3. 《产品知识入门》——定位/机制/核心数据/用法（锚 T2）
4. 《医学基础通识》——疾病机制/常用指标（锚 T3）
5. 《销售流程五步》——准备-拜访-跟进-学术活动-复盘
6. 《职业素养与职业形象》——沟通/时间管理/商务礼仪

### 实战期课件（在岗）
1. 《复杂客户类型沟通》——学术型专家/事务型主任的不同打法
2. 《学术活动策划与执行》——科室会/城市会组织（锚 T4.4）
3. 《竞品应对工作坊》——常见质疑应答（锚 T4.5）
4. 《区域管理与时间管理》——客户分层/20-80 法则（锚 T4.2）

### 进阶期课件（项目制）
1. 《行业趋势与自我定位》
2. 《从代表到管理者：角色转换》（内容接口通用管理，体系归 H6.3）

## T1.3 知识地图（知识点依赖）

```
行业政策 → 合规手册 → 产品入门 → 医学通识 → 销售流程
                                    ↓
                              实战:客户沟通→学术活动→竞品应对→区域管理
                                    ↓
                              进阶:趋势→管理→高端客户
```
> 知识地图用于排课顺序与先修关系；缺失前序知识不得跳级授课。

## T1.4 转正考核题库结构（评分表见 T7）

| 维度 | 内容 | 形式 | 权重（示例） |
|---|---|---|---|
| 理论（产品+合规） | 产品机制/数据/竞品、合规红线、代表备案 | 笔试/在线题库 | 40% |
| 模拟拜访 | 需求挖掘-价值传递-异议处理完整沟通 | 角色扮演评分 | 30% |
| 实操 | 产品讲解、科室会演讲片段 | 现场演示 | 20% |
| 合规承诺 | 合规手册签署 + 合规情景判断 | 必过项 | 10%（一票否决） |

## T1.5 融入路径设计（内容衔接）

```
集中培训(内容由本 Skill 提供)
   ↓
在岗带教(导师制，机制归 H6.5，带教内容归本 Skill)
   ↓
转正考核(理论+模拟+实操+合规，题库/评分表归本 Skill，门槛/节奏归 H6.2)
```

## T1.6 与 drug-hr H6 接口
- 本维产出：筑基/实战/进阶三套课件、知识地图、转正考核题库与评分表。
- H6 产出：培训排期、考核门槛（须全部通过）、节奏（2–4 周集中+1–3 月带教）、达标判定、与晋升联动。
- **不重叠**：本维不写"培训体系架构/考核闭环运行机制"，只交付内容资产。
