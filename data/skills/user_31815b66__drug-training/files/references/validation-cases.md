## 案例一 · 产品知识培训内容（T2）：GLP-1 减重药「诺和盈」产品培训课件体系

### 元数据头
- 分析对象：司美格鲁肽注射液（减重版·诺和盈 Wegovy）产品培训内容
- 真实锚点：NMPA 于 **2024-06-25** 批准诺和盈用于长期体重管理 🔍
- 分析视角：T2 产品知识培训内容（证据转译归 drug-medical-postlaunch）
- 数据截止：2026-07｜证据等级总览：L1（NMPA/官媒）· L2（STEP 系列 RCT）

### 执行摘要
1. 诺和盈（减重版司美格鲁肽）2024-06-25 获 NMPA 批准，用于成人长期体重管理，BMI≥30 或 27–30 伴合并症，一周一次 🔍。
2. 减重版（诺和盈）与降糖版（诺和泰）**不可相互替代**，培训须明确区分，避免超适应症误导 🔍。
3. 机制为 GLP-1 受体激动剂（周制剂）；STEP 系列全球约 2.5 万例，厂商称平均减重 17%（16.8kg）🔍（具体数据以医学 skill 文献复核）。
4. 常见不良反应：胃肠道反应（恶心/呕吐/腹泻），罕见胰腺炎风险，须如实告知、不得隐匿 🔍。
5. 课件须嵌入合规红线：禁超适应症推广、禁疗效断言、禁与竞品贬低对比（接 drug-compliance C1/C3）。

### 主体（按 T2 工作流）
- **产品知识体系**：机制（GLP-1RA）/靶点/规格/用法（周制剂、起始剂量递增）/适应症（与说明书一致）🔍。
- **标准课件结构**：定位→机制→循证（STEP 系列，标研究名/样本量/终点/🔍）→安全性→正确使用→竞品差异卡（客观，禁贬低）。
- **竞品差异卡**：与利拉鲁肽/替尔泊肽客观对比，仅列公开获批信息与文献数据，标 🔍/💭。
- **更新机制**：接 drug-medical-postlaunch，新循证/新适应症滚动更新；合规审视必过。

### 关键结论与行动建议
- 所有临床数据以 drug-medical-postlaunch 或权威文献为唯一来源，本 Skill 只做转译，不生产医学结论。
- 设"合规必过项"：任何超适应症/疗效保证/竞品贬低表述一律删除。

### 不确定性·待核实清单
- ⚠️ STEP 系列具体各研究样本量、终点、年份须以原始文献/医学 skill 复核，本案例仅引厂商公开宣称值。
- ⚠️ 诺和盈国内定价与医保状态未公开，培训中涉及报销须标 💭 并指引最新医保目录。

### 信息来源与证据等级
- NMPA 批准诺和盈（央视/澎湃 2024-06-25）🔍 L1
- 中新网/光明网 获批报道（适应症/BMI 标准/副作用）🔍 L1
- STEP 系列研究（诺和诺德公开数据，须文献复核）💭→🔍 L2

## 案例二 · 销售与拜访技能培训内容（T4）：专业拜访六步法 + LSCPA 异议处理

### 元数据头
- 分析对象：创新药（肿瘤/代谢）一线代表「专业拜访 + 异议处理」技能课件
- 方法论锚点：专业拜访六步法（准备-开场-探询-介绍-异议-成交）；LSCPA 异议处理；柯氏四级评估（Kirkpatrick）🔍
- 分析视角：T4 销售与拜访技能培训内容（业务执行归 drug-sales）
- 数据截止：2026-07｜证据等级总览：L2（经典方法论）

### 执行摘要
1. 六步法每步配提问库/脚本/正误示范/评分锚点，确保可练可评 💭（本 Skill 模板已含）。
2. 真实异议场景须源自学员痛点（如"这药那么贵值吗""远期安全性数据够吗"），脚本用 LSCPA（倾听-同理-澄清-求证-建议）💭。
3. 科室会演讲（策划-结构-PPT-控场-Q&A）单列模块，禁疗效保证、禁对比贬低 🔍（合规边界）。
4. 评估闭环：L2 实操量规 + 柯氏 L3 行为跟进表（接 drug-hr H6）🔍。
5. 业务执行动作（终端/纯销/POA）不归本 Skill，仅出训练内容 🔍（边界）。

### 主体（按 T4 工作流）
- **六步法脚本**：准备（客户画像/目标）→开场（专业问候）→探询（开放式提问库）→介绍（FAB，锚定循证）→异议（LSCPA 逐字脚本）→成交（推进下一步）。
- **区域管理工具**：客户分层（20-80）、SWOT、拜访频次模型 💭。
- **科室会演讲结构**：钩子-疾病负担-机制-循证-指南地位-小结-Q&A 预案（合规护栏内）。
- **竞品应对**：客观差异陈述，禁贬低；话术卡标 🔍/💭。

### 关键结论与行动建议
- 用 t4 模板的评分锚点做角色扮演考核，L2 不达标不得转正（接 T1/H6）。
- 异议脚本须经 drug-compliance 红线审视，避免"更安全/更有效"等违规断言。

### 不确定性·待核实清单
- ⚠️ 具体客户痛点与高频异议须由企业内数（用户）提供，本案例示例为通用归纳（💭）。
- ⚠️ 各治疗领域专属循证须由 drug-medical-postlaunch 提供，本 Skill 不编撰数据。

### 信息来源与证据等级
- 专业销售拜访/SPIN/LSCPA 经典方法论（行业通用）💭 L2
- 柯氏四级评估模型（Kirkpatrick 1994 体系）🔍 L2
- 本 Skill `references/t4-sales-skill-training.md`、`t7-evaluation-tools.md` 🔍

## 案例三 · 新人训练营内容体系（T1）：入职到转正闭环 + 合规承诺必过项

### 元数据头
- 分析对象：医药新人代表训练营（入职→转正）内容体系
- 合规锚点：《医药代表管理办法》（2026-05-07 发布、2026-08-01 施行）🔍；GSK 案（2014 罚金 30 亿）警示 🔍
- 分析视角：T1 新人训练营内容体系（考核闭环归 drug-hr H6）
- 数据截止：2026-07｜证据等级总览：L1（官方法规）

### 执行摘要
1. 三阶段内容地图：筑基（产品/疾病/合规）→ 实战（六步法/协访）→ 进阶（区域/大客户）💭（模板结构）。
2. 合规承诺为**必过项**：九大禁止、备案要求、反商业贿赂红线，内容由 drug-compliance 提供、本 Skill 排课嵌入 🔍。
3. 转正考核四维（理论/模拟/实操/合规），评分表见 T7；合规不达标一票否决 🔍。
4. GSK 案作警示案例纳入合规模块，转译归 drug-training 内容工厂 🔍。
5. 体系运营与达标判定归 drug-hr H6，本 Skill 只产内容与工具 🔍（边界）。

### 主体（按 T1 工作流）
- **三阶段内容地图**：筑基期（产品知识 T2 + 疾病医学 T3 + 合规红线）→ 实战期（拜访六步 T4 + 协访 T8）→ 进阶期（区域管理 + 科室会）。
- **知识地图与课件清单**：按岗位（MR/RM）分层；合规课件引用 drug-compliance 输出。
- **转正考核题库结构**：理论（产品/医学/合规单选）+ 模拟拜访（L2 量规）+ 实操（协访评分）+ 360 评。

### 关键结论与行动建议
- 合规模块须在入职首周完成并签署承诺，未过不得进入实战期。
- 考核内容与工具交付 drug-hr H6，由其纳入考核闭环与 IDP。
