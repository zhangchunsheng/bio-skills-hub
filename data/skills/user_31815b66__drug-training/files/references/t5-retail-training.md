# 终端与零售培训内容（维T5）

> 本 reference 解决"OTC/零售终端培训讲什么"。**边界：院外场景运营（连锁/DTP/院边店/线上）归 drug-retail skill，本维只出培训内容。OTC 推广须符合《广告法》第16条与《药品广告审查发布标准》。**

## T5.1 OTC/零售店员培训

### 5.1.1 产品认知四件套（必讲）
| 模块 | 内容要点 | 培训落点 |
|---|---|---|
| 成分与机制 | 活性成分、作用通路（如布洛芬抑制COX）、与同类差异 | 店员能说清"为什么有效" |
| 适应症与用法 | 主治、剂量、疗程、服用时间（餐前/后）、特殊人群（孕/哺/老/童） | 不超说明书推荐 |
| 禁忌与相互作用 | 禁忌人群、中西药相互作用（如头孢+酒）、慢病用药冲突 | 风险前置提醒 |
| 储存与效期 | 温湿度、开封后有效期、外观变质识别 | 避免售出变质药 |

### 5.1.2 卖点提炼（FAB→店员语言）
- **F（特征）**：成分/剂型 → **A（优势）**：吸收快/口感好/一天一次 → **B（利益）**："您不用老想着吃药，一天一次更省心"。
- 竞品差异须**客观**（标数据/机制），禁贬低性表述（"那个不如我们这个"属违规）。

### 5.1.3 推荐话术库（分品类示例）
- **感冒发热**：「您是怕冷酸痛还是嗓子疼？布洛芬对酸痛退烧快；若是嗓子红肿，配个局部含片更对症。」
- **肠胃不适**：「是吃坏肚子还是老胃病？急性腹泻先补液盐防脱水，慢性反酸用质子泵抑制剂更稳。」
- **皮肤外用**：「破皮处别用激素膏；湿疹渗液先湿敷，干燥了再上乳膏。」
- **维矿/保健**：「这个适合饮食不规律的上班族，但不能代替正餐，配合作息才有效。」
- **慢病复购**：「您一直在用的这款，记得定期测指标；这次顺便帮您看看要不要调整剂量（提示复诊）。」

### 5.1.4 关联销售（合规前提下）
- 逻辑：症状关联（感冒+维C）、人群关联（老人+钙+D）、疗程关联（抗生素+益生菌护肠道）。
- 红线：不强行搭售、不暗示"不吃就无效"、不替代医师处方建议。

## T5.2 导购与基层医师

### 5.2.1 导购转化（简化六步）
需求挖掘（开放式提问："您主要想改善什么？"）→ 痛点确认 → 方案呈现（FAB）→ 顾虑处理 → 利益促成 → 用药交代（用法+注意事项）。

### 5.2.2 基层医师/诊所用药指导
- 剂量调整：肝肾功能、体重、年龄的剂量换算。
- 不良反应处理：轻症观察/停药指征、何时转诊上级医院。
- 转诊指征：持续高热、胸痛、出血、意识改变等"红旗症状"立即转医。

## T5.3 动销话术与陈列

| 要点 | 说明 |
|---|---|
| 推荐转化 | 类比拜访六步简化版：需求→利益→促成 |
| 关联销售 | 合规搭配（见 5.1.4） |
| 陈列要点 | 黄金位置（视平线）、价格带分层、POP 文案合规（禁"包治""无效退款""疗效最佳"等断言） |
| 疗程提示 | 慢性病"按疗程备药"须基于说明书，不夸大疗程必要性 |

## T5.4 场景化培训脚本（role-play 用）

**场景A：顾客比价**——「这款比隔壁贵。」→ 标准应答：「价格差在{成分纯度/剂型/厂家}，您看重的若是{起效速度/肠胃刺激小}，这款更合适；预算有限我也可以帮您看同成分的平价替代。」（禁贬低竞品）

**场景B：安全性质疑**——「有副作用吗？」→ 「任何药都可能有反应，这款常见的是{轻度XX}，多数人可耐受；若出现{红旗症状}请停药就医。说明书第X条写得很清楚，我帮您圈出来。」

**场景C：医保/报销**——「能刷医保吗？」→ 「OTC 多数走个人医保账户或自费，具体看当地目录；处方药须凭医院外配处方在定点药店结算，我帮您确认是否双通道品种。」（口径归 drug-retail）

**场景D：慢病复购+依从性**——「老吃这个没事吧？」→ 「长期用建议您每{周期}复查{指标}；这药本身可长期用，但指标变化要医生判断，我帮您记个复诊提醒。」

## T5.5 合规边界（零售推广红线）

- 遵守《广告法》第16条：药品广告**不得**含"表示功效、安全性的断言或保证"，**不得**说明治愈率/有效率，处方药**不得**在大众媒介发布广告。
- OTC 广告须有广告批准文号；店员口头话术禁"包治""无效退款""最/第一"等绝对化用语。
- **禁向消费者推荐/代开处方药**；处方药须凭合规外配处方，由药师审核发药。
- 患者数据收集（会员/随访）须知情同意，归 drug-retail 数据合规口径。

## T5.6 与 drug-retail 接口

- 本维出培训内容（店员话术/用药指导/动销脚本/合规护栏）；院外渠道运营（连锁网络/DTP/院边店/双通道/线上O2O/患者引流）归 **drug-retail skill**。
- 终端动销活动配合市场部（锚 drug-market），培训 Skill 提供学术支持与培训保障。
- 合规推广审查(MLR)与广告合规归 **合规法务 skill（drug-compliance）**。
