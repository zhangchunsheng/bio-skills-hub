# 疾病与医学培训内容（维T3）

> 本 reference 解决"疾病领域与医学证据怎么培训"。**边界：医学证据由 drug-medical-postlaunch 提供，本维负责转译为可讲授、可练习的内容。**

## T3.1 治疗领域全景（内容框架）

1. **疾病负担**：患病率/发病率/未满足需求（标口径：确诊/估测）
2. **诊疗路径**：诊断→分型→一线/二线治疗→随访
3. **患者旅程**：症状→就诊→确诊→治疗→管理，痛点地图
4. **领域趋势**：新药/新靶点/指南更新方向

> 数据来源：drug-medical-postlaunch L1 治疗领域洞察；引用须标 🔍。

## T3.2 循证解读卡（可讲数据点）

每张卡结构（按 foundation.md §1 循证三件套）：
```
【研究名】XXX 研究（年份）
【设计】RCT/Meta/RWE，样本量 N=____
【关键终点】主要终点 ____；次要终点 ____
【结果】HR/OR/RR = __（95%CI），P=__
【证据等级】IA/IB/IIA…（按 references/evidence-levels.md）
【可讲要点】一句话转译给医生/销售
```
> 禁止：只给"研究显示有效"无来源；必须标研究名+样本量+终点。

## T3.3 医学沟通要点（分受众）

| 受众 | 沟通重点 | 边界 |
|---|---|---|
| 医药代表（内部） | 如何把证据讲给医生、应对数据质疑 | 不替医生做处方决策 |
| 医生（学术会） | 机制/证据/指南地位/真实世界数据 | 客观，不夸大，不对比贬低 |
| 药师 | 用法/相互作用/安全管理 | 用药安全优先 |

## T3.4 证据转译工作流

```
医学 skill 证据(原始文献/指南)
   ↓ 提炼
循证解读卡(研究名/数据/等级)
   ↓ 转译
销售能讲的"数据点 + 一句话价值"
   ↓ 演练
模拟拜访中的证据呈现(锚 T4.1)
```

## T3.5 合规边界（医学内容红线）

- 医学内容须客观、基于已发表证据，**禁止夸大疗效、禁止对比性贬低竞品**。
- 推广材料合规审查(MLR)归合规法务 skill；本维只出医学培训内容，须经医学审阅。
- 不提供"超说明书用药"指引，禁越界处方建议。
