# 合规培训内容交付（内容扩展模块 t10）

## ⚠️ 边界声明（首要，必须遵守）

**本文件只产出"可讲授的合规培训内容 + 测评题库 + 红线话术卡"，不做合规判断 / 法律意见。** 那属于 **drug-compliance（合规法务 skill）** 的职责。

- 本模块是培训 Skill 的**内容扩展**：把合规要求转译成学员能学、能练、能用的培训物料。
- 遇到任何合规**结论**（某行为是否违规、红线如何认定、处罚尺度），**必须引用 drug-compliance 的输出**，不自行下判断、不复制其结论为己有。
- 法规条文须标名称+文号+发布机构+时效（🔍，截至 YYYY-MM），超期标 ⚠️。
- 本模块不产出"推广内容合规审查(MLR)"——MLR 归 drug-compliance。
- 红线话术卡的"标准应答"仅作培训示范，正式合规口径以 drug-compliance 为准。

### 场景二：推广合规

### 场景三：数据安全与隐私
- 模块1 法规：《个人信息保护法》《数据安全法》（标 🔍 文号）

### 场景四：反舞弊/内部诚信
- 模块1 诚信准则、举报机制

> 每个模块只写"讲什么、练什么"，不写"是否违规"的定性结论。

## t10.2 测评题库模板

### 单选题（知识层）
```
题号：Q1
题干：关于学术会议讲课费，以下说法正确的是？
A. 可私下现金支付
B. 须事前审批、公对公、凭真实劳务
C. 无金额限制
D. 可转给代表家属
答案：B（依据：drug-compliance 口径 / 🔍 反商业贿赂规范）
解析：（仅陈述规则，不下法律定性）
```

### 情景判断题（应用层）
```
题号：S1
情景：医生提出"帮我科室申请一笔科研经费，我多用你们产品"。代表应如何？
选项：A 拒绝并上报 / B 先答应再谈 / C 转交同事处理
答案：A
要点：属高风险利益输送，须拒绝对接并上报合规（判定引用 drug-compliance）
```

### 红线识别题（红线层）
```
题号：R1
描述：以下哪项是绝对红线？（多选）
□ 承诺产品疗效 □ 给医生个人返利 □ 超适应症宣讲 □ 正常学术拜访
答案：前三项（红线清单以 drug-compliance 发布为准）
```
