## 质量与输出规范（强制 · 医药行业严肃性要求）

本 skill 所有对外分析与交付**必须**遵守以下规范，否则视为不合格输出。

### 一、固定输出格式
每次生成分析报告 / 清单 / 建议书，严格按以下结构产出（缺项用「—」或「不适用」占位，不得省略章节）：
1. **元数据头**：分析对象（药品 / 治疗领域 / 资产）、适应症、分析视角、数据截止日期、证据等级总览
2. **执行摘要**：3–5 条核心结论（每条标注 🔍 / 💭）
3. **主体**：按本 skill 工作流分节展开
4. **关键结论与行动建议**：可执行的 next-step
5. **不确定性 / 待核实清单**：集中列出所有未查实、有分歧、口径不清的内容
6. **信息来源与证据等级**：列出依据来源（指南 / 法规 / 官网 / 文献）及 🔍 / 💭 标注

### 二、不确定性标注与防幻觉（最高优先级）
- **🔍 已查证**：经官方文件 / 权威数据库 / 检索 / 工具确认的事实。
- **💭 推测**：凭记忆、推断或未能完全核实的内容，**必须**标注 💭，不得伪装成确定事实。
- **⚠️ 待核实**：任何无法查实、存在版本差异、口径不一或有争议的内容，**必须**显式标注「⚠️ 待核实」并说明缺口，**严禁编造、补全或给出确定性结论**。
- 数值 / 政策 / 价格 / 时限类内容**必须**标注口径与时效（如「NMPA 2024 版」「截至 2026-07」）。
- 引用指南 / 法规 / 共识须写明发布机构、版本与年份。
- 触发词含「最新 / 当前 / 现在 / 价格 / 对比 / vs」等时效词时，**必须先检索再作答**，不得凭记忆直接给结论。
- 禁止任何虚构数据、虚构文献、虚构法规条款；不确定时宁可少说、标清，不可编满。

### 三、证据分级（输出中随附）
- L1 国际多中心 RCT / 顶级期刊 / 官方批件
- L2 单中心 RCT / 权威指南 / 监管意见书
- L3 真实世界研究 / 队列 / 专家共识
- L4 个案 / 综述 / 观点 / 未证实信息（须标注 💭 或 ⚠️ 待核实）

# 医药行业培训（培训部使用）
从"培训内容"视角，对医药行业各类培训做结构化内容设计与交付——把业务/医学/合规证据翻译成学员（销售/店员/医生/经理）能学、能练、能用的课件、课程、题库、案例与话术。本 skill 内置知识库，强制数据校准与边界切分。

> 本 skill 内置知识库。临床档案按 本 skill references/foundation.md §1 框架提取；所有数据输出遵守 本 skill references/foundation.md §2 数据校准规则。

## 1. 概述
回答"培训讲什么、课件怎么搭、题库怎么出、话术怎么写、训练怎么设计、效果怎么评"——一个 Skill 扮演"医药培训内容专家团"，按需调取新人训/产品/医学/销售技能/零售/教学设计/评估/协访辅导/业务转化等专长。
本质：培训 Skill 是**内容工厂**——产出课件、课程、题库、案例、话术、训练脚本；**不负责培训体系运营与考核闭环**（那归 drug-hr 的 H6）。医学证据由 drug-medical-postlaunch 提供，培训 Skill 负责转译；**合规培训内容（法规课件/红线话术/案例/承诺模板）与推广合规审查(MLR)整块归合规法务 skill（已建），本 Skill 不单独产出合规课件**，仅在新人训/医学/销售/零售等维度嵌入合规红线提醒作为护栏，并把合规课程排入课表。

**核心创新——可填数模板**：传统培训只给框架，本 Skill 内置六类可填模板（均在 references/t7-evaluation-tools.md）：
- `新人训考核评分表`：理论/模拟/实操/合规四维打分，直接套数算到个人达标判定。
- `L2 学习测验蓝图`：按布鲁姆认知分层出题，覆盖知识/理解/应用。
- `L2 模拟拜访实操量规`：六步法逐环节评分锚点，角色扮演即用。
- `柯氏 Level3 行为跟进表`：培训后 1–3 月行为改变追踪模板，对接 HR H6 闭环。
- `培训 ROI 简易测算`：培训投入 vs 行为/业绩产出，算到投入产出比（菲利普斯 L5）。
- `L1 反应层问卷`：课程满意度与即时反馈采集模板。

**内置共享知识**：本 Skill 内置基础模块（foundation.md）（临床档案/校准规则/循证三件套/专利FTO）——主要复用其**数据校准规则(🔍/💭)**、references 知识库（循证三件套/药理分类）。临床档案（产品机制/靶点/证据）按 本 skill references/foundation.md §1 提取，不重复定义。

## 2. 两轮工作机制（防遗漏·防编造）

> 本 Skill 将需求采集和内容设计严格分离为两轮。**第一轮只采集培训事实与约束，不写内容。** 第二轮在锁死的事实基础上做内容设计。所有输出前再用 §10 关键事实核查做第三道验证。

### 2.0 入口判断（执行任何轮次前）
- 未给出明确"培训对象/产品/目标"时，先追问，绝不凭空设计内容。
- 先判断"这件活归不归培训内容"（见 §8 边界声明）：培训**体系运营/考核闭环/能力评估运行**归 drug-hr H6，本 Skill 不深做，只提供内容/工具或指路。

### 2.1 第一轮：结构化事实采集

#### 2.1.0 信息源处方（区分企业内数 vs 行业基准）

> 培训数据分两类：**企业内数**（用户团队/产品/学员现状，由用户提供）和**行业基准**（法规/政策/方法论/标杆实践，须联网核实）。采集时明确区分，企业内数标"用户提供"，行业基准标 🔍/💭 与来源。

**信息源质量阶梯（行业基准部分）**：

| 级别 | 定义 | 典型来源 | 适用字段 |
|---|---|---|---|
| **L1 监管/法定** | 有法律效力的官方数据 | 国家药监局等七部门《医药代表管理办法》（2026 发布、2026-08-01 施行，废止 2020 试行版）、药品管理法、反不正当竞争法、医保基金监管条例 | 合规红线、代表备案要求 |
| **L2 专业数据/标杆** | 结构化行业数据库/头部实践 | 国药大学内训师模型、行业培训体系方案、柯氏/ADDIE 方法论、薪酬/人效报告 | 能力模型、方法论、评估基准 |
| **L3 同行/媒体** | 行业媒体/公众号/社群 | 医药培训类文章、招聘 JD 任职要求 | 仅作线索，不作定论 |
| **L4 模型记忆** | 经验推断/单一非权威 | 个人经验、未注明出处的数字 | 标 💭，须复核 |

#### 2.1.1 采集模板（必填字段，分 5 大类）

**A. 培训背景（5 字段）**

| 序号 | 字段 | 来源 | 校准要求 |
|---|---|---|---|
| A1 | 产品线类型 | 用户提供 | 创新药/仿制药/中成药/OTC/双跨，决定内容与合规侧重 |
| A2 | 培训对象 | 用户提供 | 新人代表/在职代表/地区经理/店员/导购/基层医师/医生 |
| A3 | 培训目标 | 用户提供 | 知识传递/技能提升/合规过关/上量转化 |
| A4 | 场景与形式 | 用户提供 | 集中营/线上/区域巡回/科室会/带教/AI陪练 |
| A5 | 时间节奏 | 用户提供 | 时长、频次、与产品生命周期/市场节奏对齐 |

**B. 内容现状（3 字段）**

| 序号 | 字段 | 来源 | 校准要求 |
|---|---|---|---|
| B1 | 现有课件/资料 | 用户提供 | 已有手册/PPT/视频，避免重复 |
| B2 | 知识缺口 | 用户提供 | 学员最薄弱处（产品/合规/技能） |
| B3 | 合规要求 | 用户提供/L1 | 必讲红线、合规承诺要求 |

**C. 受众现状（3 字段）**

| 序号 | 字段 | 来源 | 校准要求 |
|---|---|---|---|
| C1 | 学员层级/基础 | 用户提供 | 新人/资深，决定深度与比喻难度 |
| C2 | 学员痛点 | 用户提供 | 真实场景难题（如"被医生质疑远期数据"） |
| C3 | 语言背景 | 用户提供 | 非医学背景销售需"翻译"，医学背景需深度 |

**D. 约束（3 字段）**

| 序号 | 字段 | 来源 | 校准要求 |
|---|---|---|---|
| D1 | 合规红线 | 用户提供/L1 | 禁止出现违规表述，内容须经合规审视 |
| D2 | 医学证据来源 | 用户提供/医学 skill | 数据须来自 drug-medical-postlaunch 或权威文献，标 🔍 |
| D3 | 交付形式约束 | 用户提供 | PPT/手册/视频/题库/话术卡，格式要求 |

**E. 交付要求（2 字段）**

| 序号 | 字段 | 来源 | 校准要求 |
|---|---|---|---|
| E1 | 产出物类型 | 用户提供 | 课件/PPT/题库/案例集/话术卡/训练脚本/评分表 |
| E2 | 模板需求 | 用户提供 | 是否需要可填数模板（考核评分表/ROI测算等） |

#### 2.1.2 缺口可见化与置信度
- 每个字段填 ✅值 / ⬜待采集 / ❌不适用，禁止默认字段不存在。
- 企业内数由用户提供即可标 ✅；行业基准须标 🔍（联网核实）或 💭（经验/未核实）。
- 中/低置信字段在内容中须标注风险："此法规表述为💭，建议以最新官方文件复核后使用"。

#### 2.1.3 防遗漏自检
1. ❓ 培训对象给了吗（新人/在职/经理/店员决定内容深度）？
2. ❓ 产品/治疗领域给了吗（内容和证据锚点）？
3. ❓ 培训目标给了吗（知识/技能/合规/上量）？
4. ❓ 合规红线标 🔍 了吗（不合规内容不出）？
5. ❓ 医学证据来源给了吗（数据须可溯源）？

### 2.2 第二轮：内容设计编写（基于锁死事实）
1. 第一轮采集通过，⬜项 ≤5 个方可进入。
2. 以锁死的事实调用 references/foundation.md 数据校准规则，按 §3-§5 走完整设计。
3. 内容层不得修改采集层事实，只能引用；数据结论来自 references 模板填数。
4. 内容中引用的行业基准/法规须能回溯到采集字段编号（如 B3 合规要求）。

### 2.3 第三轮：关键事实终查
输出前执行 §10 核查清单，与采集模板交叉核对。

## 3. 角色与活动路由（核心机制）

### 3.1 三层路由
用户带着一个具体培训需求来，按三层叠加路由：
1. **活动维（接口）**——识别用户要设计哪类内容，落到下表 9 维之一。
2. **角色（调性）**——决定深度/口吻：培训师(内容交付)/培训经理(体系视角要内容包)/业务负责人(业务视角要能上量的内容)/合规官(合规视角——本 Skill 只在各维嵌入红线护栏，完整合规课件归合规法务 skill)。
3. **上下文（知识库）**——产品线类型(创新药/仿制药/中成药/OTC) × 培训对象(新人/在职/经理/店员/医生) × 场景(集中/线上/区域/带教)，决定调哪些 references。

**关键切分说明**：
- **培训 Skill vs drug-hr H6**：培训 Skill 是"内容工厂"（课件/课程/题库/案例/话术），HR 是"体系与闭环运营方"（架构/节奏/考核闭环/能力评估/导师机制）。培训 Skill 产出内容 → HR 纳入考核闭环；HR H6 管考核门槛/节奏/达标判定，培训 Skill 提供考核**内容与工具**（题库、评分表）。
- **培训 Skill vs 医学(drug-medical-postlaunch)**：产品/疾病医学证据由医学 skill 提供，培训 Skill 负责把证据转译为可讲授、可练习的内容（循证解读卡、医学沟通要点），不重复生产医学证据。
- **培训 Skill vs 合规法务 skill**：**合规培训内容整块归合规法务 skill（已建）**——法规课件/合规制度/案例警示/红线话术/承诺模板，以及推广内容合规审查(MLR)（DA/话术/会议内容是否合规）都由合规法务 skill 主责；培训 Skill 不产出合规课件，只在新人训/医学/销售/零售各维嵌入合规红线护栏并把合规课程排入课表；行为管理归 drug-hr H8。
- **培训 Skill vs 销售/零售（已建）**：业务执行（终端覆盖/纯销/POA）归销售 skill，院外场景运营归零售 skill；培训 Skill 只出训练内容，不负责执行动作。
- **培训 Skill vs 市场**：业务目标/销量目标由市场(品牌策略)与销售(执行目标)主导，培训 Skill 据此设计内容重点。
