# 细胞/基因治疗产品分类规则

本文档用于指导将新产品正确分类到对应的工作表中。

---

## 工作表对应关系

| 工作表 | 适用产品类型 | 关键词/判断依据 |
|--------|--------------|----------------|
| 免疫细胞上市产品 | CAR-T, TCR-T, CAR-NK, TIL, 其他工程化免疫细胞 | 产品名称含 CAR、TCR、NK、TIL；或细胞类型明确为免疫细胞工程化改造 |
| 免疫细胞上市产品-已合并 | 同上（合并去重版） | 与"免疫细胞上市产品"内容对应，但已去重合并 |
| 干细胞上市产品 | 间充质干细胞(MSC)、iPS/iPSC、造血干细胞(HSC)、脂肪来源干细胞等 | 细胞类型含 MSC、iPS、iPSC、干细胞、间充质、脂肪来源 |
| 基因疗法（兜底） | 基因治疗、基因编辑、病毒载体治疗、不符合上述三类的产品 | AAV载体、慢病毒、基因编辑(CRISPR/ZFN)、OTOF等基因替代疗法 |

---

## 分类决策树

```
新产品
  ├── 是否是免疫细胞工程化改造产品？
  │     ├── 是 → 「免疫细胞上市产品」+「免疫细胞上市产品-已合并」
  │     └── 否 ↓
  ├── 是否是干细胞产品（MSC/iPS/HSC等）？
  │     ├── 是 → 「干细胞上市产品」
  │     └── 否 ↓
  └── 其他 → 「基因疗法」（兜底表）
```

## 各工作表列结构

### 免疫细胞上市产品 / 免疫细胞上市产品-已合并

| 列 | 字段 | 说明 |
|----|------|------|
| A | 序号 | 自增数字 |
| B | 商品名 | 产品商品名（英文） |
| C | 靶点 | 如 CD19, BCMA, GPC3 等 |
| D | 上市时间 | 格式：YYYY.MM.DD |
| E | 首次上市国家/地区 | 如 美国、日本、中国 等 |

## 注意事项

1. **两个免疫细胞表都要更新**：新产品若属于免疫细胞，需同时追加到「免疫细胞上市产品」和「免疫细胞上市产品-已合并」两个表
2. **黄色标注**：所有新增行必须设置黄色填充（fill RGB="#FFFF00"）
3. **日期格式**：统一使用 `YYYY.MM.DD` 格式
4. **不确定时**：归入「基因疗法」表，并在报告中标注 `⚠️ 分类不确定`
