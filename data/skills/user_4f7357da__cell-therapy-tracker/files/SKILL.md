# 细胞治疗产品追踪器 (Cell Therapy Tracker)

> 一句话定位：**自动搜索 FDA / EMA / NMPA / PMDA 等监管机构最新获批的细胞与基因治疗产品，分类追加到你的 Excel 追踪总表，并用黄色高亮标出本次新增。**

---

## 一、你可以这样问我（触发方式）

用户无需懂技术，说下面任意一句即可启动（也可直接说「跑一次 cell-therapy-tracker」）：

| 用户原话示例 | 触发动作 |
|-------------|---------|
| 「更新细胞治疗追踪表」 | 自动定位工作区最新 xlsx → 搜索 → 更新 → 交付 |
| 「最近有没有新的细胞/基因疗法获批？」 | 以文件最新日期为起点搜索，汇报新增 |
| 「把本周新上市的细胞治疗产品加进 Excel」 | 搜索本周窗口，追加新行 |
| 「帮我追踪一下 FDA / EMA / NMPA 最新 CAR-T 获批」 | 按关键词重点搜索并入库 |
| 「跑一次 cell-therapy-tracker」 | 完整执行一次更新流程 |
| 「检查一下这个文件有没有漏录的产品」 | 边界补录扫描（见 §5 使用示例） |

> 如果用户**没有给文件路径**，技能会在工作区自动寻找名称最匹配的 `.xlsx`（含「细胞/治疗/上市/CGT」等关键词），绝不要求用户手动输路径。

## 二、文件结构速查

实际 xlsx 文件共 **6 个工作表**（2 个为隐藏状态）：

| 工作表名称 | 状态 | 内容类型 |
|------------|------|---------|
| 免疫细胞上市产品 | 可见 | CAR-T, TCR-T, CAR-NK, TIL 等免疫细胞产品 |
| 干细胞治疗产品 | **隐藏** | 与「干细胞上市产品」同步更新（共享数据源） |
| 免疫细胞上市产品-已合并 | 可见 | 合并去重后的免疫细胞产品 |
| 干细胞上市产品 | 可见 | 间充质干细胞(MSC)、iPS、HSC 等 |
| 基因疗法 | 可见 | 基因治疗、基因编辑、病毒载体 |
| 其他上市细胞治疗产品 | **隐藏** | 无法归类的细胞治疗产品（兜底） |

**重要**：`干细胞治疗产品`（隐藏）和 `干细胞上市产品`（可见）是两个不同工作表，更新干细胞产品时**必须同时更新两者**。

## 三、完整运行流程（Agent 自主 runbook）

> 设计目标：用户说一句话，Agent 一条龙完成。以下步骤 Agent 自动执行，无需用户逐步操作。

### 第 1 步：定位追踪文件
- 若用户已给路径 → 直接用。
- 否则用 `scripts/update_excel.py --info <file>` 或 `scripts/gen_search_queries.py` 的自动定位（搜索工作区含关键词的最新 `.xlsx`）。
- 若都找不到 → 友好询问用户给出文件路径，**不要凭空创建文件**。

### 第 2 步：生成搜索清单（告别“手动照清单搜”）
运行查询生成器，拿到本轮应搜的全部关键词：
```bash
python scripts/gen_search_queries.py <input.xlsx> --output queries.txt
```
它会自动解析文件内**最新上市日期**作为搜索起点，并输出：
- 第一梯队 FDA / EMA 英文监管源关键词
- 第二梯队 NMPA / PMDA / 中文行业源关键词
- 第三梯队 行业新闻/媒体扫描关键词
- watchlist 在审产品的精确查询（来自 `references/watchlist.md`）

### 第 3 步：执行搜索（WebSearch）
用 `WebSearch` 按清单**逐条或分批**搜索（必要时 `WebFetch` 抓具体页面）。优先顺序：监管官网 > 企业公告 > 行业媒体。

### 第 4 步：交叉验证与筛选
每条候选产品须满足 **≥2 个独立来源**（监管官网 / 企业公告 / 行业媒体）才入库。仅出现于非权威聚合站且无印证的 → 排除。

**入库红线**：只收录「上市 / 营销授权（marketing approval）」级别。IND、临床试验批准、征求意见稿 **不入库**。

### 第 5 步：分类（见 `references/classification.md`）
- CAR-T / TCR-T / CAR-NK / TIL → `免疫细胞上市产品` + `免疫细胞上市产品-已合并`
- 干细胞(MSC/iPS/HSC) → `干细胞上市产品` + `干细胞治疗产品`(隐藏)
- 基因治疗/编辑 → `基因疗法`
- 不确定/未归类 → `其他上市细胞治疗产品`(隐藏)

### 第 6 步：生成 products.json
按工作表分组，列字母→值（日期格式 `YYYY.MM.DD`）：
```json
{
  "免疫细胞上市产品": [
    {"A": 41, "B": "Amtagvi", "C": "—", "D": "2026.06.03",
     "E": "澳大利亚", "F": "TIL", "G": "黑色素瘤", "H": "Iovance", "I": "澳洲 TGA 附条件批准"}
  ],
  "免疫细胞上市产品-已合并": [ { "同上" } ]
}
```

### 第 7 步：写入并更新（健壮版，不崩溃）
```bash
python scripts/update_excel.py <input.xlsx> --products-json products.json
```
脚本会自动：补建缺失的 styles/sharedStrings 节点、复用已有黄色样式、校验输入、生成 `<原名>_updated_YYYYMMDD.xlsx`（**永不覆盖原文件**）、写后做 zip 完整性校验。任何异常都会给出人话报错而非堆栈。

### 第 8 步：交付与报告
- 用 `present_files` 交付更新后的 xlsx + 一份执行报告（列出本次新增、补录项、无更新项）。
- 若无新产品：不生成文件，仅向用户发送「无更新」通知。
- 更新 `references/watchlist.md`（获批产品移入「已获批」表）。
- 将执行情况写入 workspace memory。

## 四、健壮性说明（对应「不够傻瓜化」的反馈）

| 场景 | 行为 |
|------|------|
| 未给文件路径 | 自动定位工作区最新且最匹配的 xlsx；找不到才询问 |
| 文件不存在 / 非 zip / 缺核心部件 | 人话报错 + 排查建议，安全退出，不抛堆栈 |
| 缺 styles.xml / sharedStrings.xml / fills / cellXfs | 自动补建最小化节点后继续 |
| 文件中已有黄色样式 | 自动复用，避免重复追加 |
| 缺少 `--products-json` 或 JSON 格式错 | 明确提示结构要求，不静默失败 |
| 输出时原文件 | 永远生成 `_updated_YYYYMMDD.xlsx`，原文件保留 |
| products.json 表名写错 | 跳过该表并告警，其余正常写入 |
| 额外辅助 | `--check` 预览不写入；`--info` 打印结构与各表最新日期 |

## 五、使用示例

### 示例 A：常规更新（有新增）
**你说**：「更新细胞治疗追踪表」
**Agent 做**：
1. 定位 `细胞产品上市情况汇总-2025.12_updated_20260703.xlsx`，解析最新日期 `2026.07.02`
2. 生成搜索清单 → 搜索 → 发现澳洲 TGA 于 `2026.06.03` 附条件批准 **Amtagvi（lifileucel，TIL）**，2+ 来源印证
3. 分类追加至免疫细胞两张表，黄色高亮
4. 交付 `..._updated_20260718.xlsx` + 报告

### 示例 B：无新增
**你说**：「最近有新的细胞疗法获批吗？」
**Agent 做**：搜索后窗口内无上市级产品 → 回复「2026.07.03–07.18 无新上市产品（NMPA 多为 IND，不入库）」，**不生成文件**。

### 示例 C：补录遗漏（边界扫描）
**你说**：「检查一下有没有漏录的产品」
**Agent 做**：以更早日期为起点扫描，发现既往遗漏项（如某产品在某地区早前已上市）→ 作为「补录项」黄色标注并明确说明日期早于检索窗口。

## 六、常见问题 FAQ

**Q1：我的追踪 xlsx 不在工作区根目录，技能找得到吗？**
A：找得到。自动定位会递归搜索工作区子目录（深度 3），并按文件名关键词（细胞/治疗/上市/CGT…）打分选最匹配者；你也可直接给路径。

**Q2：搜到的是 IND / 临床试验批准，要入库吗？**
A：不入库。本表只收录「上市 / 营销授权」级别。IND、临床默示许可、征求意见均不计入。

**Q3：为什么新增行是黄色？能去掉吗？**
A：黄色高亮用于让你一眼识别「本次新增/补录」，方便核对。建议保留；如确需去除，可在交付后手动清除填充，或告知 Agent 本次不加高亮。

**Q4：运行后会覆盖我的原文件吗？**
A：不会。永远输出 `<原名>_updated_YYYYMMDD.xlsx`，原文件原样保留。

**Q5：遇到打不开 / 报错的 xlsx 怎么办？**
A：脚本已做容错：缺失节点自动补建、输入非法给出明确指引，且写后做完整性校验。若仍失败，会把原因清楚告诉你，原文件不受影响。

**Q6：中文源和英文源以哪个为准？**
A：监管官网（FDA/NMPA/PMDA/EMA）优先；任何产品须 ≥2 个独立来源印证才入库，单一非权威来源直接排除。

**Q7：能定时自动跑吗？**
A：可以。在 WorkBuddy 配置「每周定时」自动化，prompt 写「更新细胞治疗追踪表」即可周期性自动执行。

**Q8：搜索清单里的关键词每年要手动改吗？**
A：不用。`gen_search_queries.py` 会自动用文件内最新日期的年份填充所有 `{Y}` 占位符并输出当年清单。

## 九、注意事项

- 原有表格内容和格式**完全不动**，仅在末尾追加。
- 2 个隐藏表（sheet2 干细胞治疗产品、sheet6 其他上市细胞治疗产品）需与对应可见表**同步更新**。
- 搜索结果不明确时，用最可能正确的信息继续更新，并在报告中标注 `⚠️ 不确定性`。
- **XML 命名空间**：不同 xlsx 可能用 `ns0:` 前缀或无前缀，所有正则与生成代码必须兼容两种格式（脚本已内置兼容）。
