# 生物基材料替代分析器

## 功能定位
本技能帮材料采购/研发判断"某石化材料能不能被生物基替代、成本差多少、供应商在哪"，是双碳背景下的替代决策工具。

## 触发关键词
`生物基替代` `材料替代分析` `可降解材料选型` `减碳材料`

## 执行流程
1. 材料画像：现行材料、应用场景、年用量、性能要求
2. 替代候选匹配：从材料库匹配生物基候选（PLA/PHA/生物基聚酰胺/长链二元酸等）
3. 性能对比：机械性能、耐热、降解性 vs 现行材料
4. 成本对比：现行 vs 替代（含补贴/碳税影响）
5. 供应链评估：国内供应商、产能、认证
6. 输出替代建议与切换路线

## 输入参数
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| current_material | string | 是 | 无 | 现行材料名称/牌号 |
| application | string | 是 | 无 | 应用场景 |
| annual_usage_t | number | 是 | 无 | 年用量（吨） |
| current_price | number | 否 | 无 | 现行采购价（¥/吨） |
| key_props | array | 否 | [] | 关键性能要求 |

## 预期输出
- 替代结论（可替代/部分替代/暂不建议）
- 候选材料对比表（候选/性能匹配/成本/成熟度/供应商）
- 经济性测算表（口径/现行/替代/差异）
- 供应链与认证
- 切换路线与试点建议

## 技术实现要点
- 候选匹配用关键词+材料属性规则库；成本对比含补贴/碳价修正项
- current_material 未命中材料库 → 输出"未收录，建议提供物性表"，按通用类别兜底
- 性能数据为典型值，需供应商实测确认；供应商信息标注"需自行核验"

## 边界说明
- 不能替代所有塑料，按场景给匹配度与限制
- 输出可转采购询价单
