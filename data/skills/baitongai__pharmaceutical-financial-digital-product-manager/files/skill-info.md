# 医药财务数字化产品经理 Skill Info

## Skill Name
医药财务数字化产品经理

## Version
1.0.0

## Description
面向医药企业财务数字化场景的机会识别、方案设计、BRD/PRD 编写与 Word 交付技能。内置 8 个医药行业专属场景及 8 个通用财务场景。支持 .docx 动态生成、项目投入产出估算、ROI 量化计算、场景智能推荐。

## Core Capabilities

- **场景智能推荐**：基于企业类型/痛点/规模等参数，5 维度自动打分推荐最相关财务数字化场景
- **医药行业深度定制**：内置两票制、CSO推广费合规、集采财务、研发费用全生命周期、GSP冷链、医保对账、药品追溯码、GMP审计 8 个医药专属场景
- **方案文档自动生成**：python-docx 动态生成含封面、表格、页眉页脚的方案/BRD/PRD Word 文档
- **投入产出精准测算**：支持 16 个场景的基线估算，自动复杂度评估，AI 能力增量计算
- **ROI 三维量化**：人效（工时节约/FTE）、资金（DSO/现金流）、合规（风险规避价值）独立计算
- **方案质量自动校验**：章节完整性、估算合理性、指标可观测性三重检查
- **专业框架内嵌**：FSSC 成熟度模型、COSO 内控框架、TCO 成本模型贯穿方案设计
- **参数化灵活适配**：13 个医药行业参数可配置，信息不足时按行业默认推进不阻塞

## Application Scenarios

- 医药企业 CFO/财务总监的数字化转型规划与机会识别
- 财务数字化项目的售前方案编写与客户提案
- 两票制合规/CSO推广费管控等医药专项系统的需求分析与 BRD 编写
- 集采药品财务处理/研发费用归集等业财一体化场景的 PRD 编写
- 财务共享中心建设的分阶段路线图规划
- 医药企业年度 IT 规划中的财务数字化场景优先级排序
- 财务数字化项目的投入产出可行性分析与 ROI 论证

## Labels
财务数字化、BRD、PRD、医药合规、CSO管理、两票制、Word方案、场景推荐
