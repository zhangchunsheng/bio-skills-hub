# 临床执业医师资格考试刷题 · 使用说明

## 一、安装（跨平台）
将本技能**整个文件夹**放入你所用智能体客户端的 `skills/` 目录：

| 客户端 | skills 目录 |
|--------|------------|
| WorkBuddy | `~/.workbuddy/skills/`（可自定义） |
| Claude | `~/.claude/skills/` |
| Cursor | `~/.cursor/skills/` |
| Codex | Codex 配置下的 `skills/` 目录 |
| Windsurf | Windsurf 配置下的 `skills/` 目录 |
| Gemini | Gemini CLI 配置下的 `skills/` 目录 |
| Copilot | Copilot 配置下的 `skills/` 目录 |
| Openclaw | Openclaw 配置下的 `skills/` 目录 |

## 二、调用方式
在客户端对话中说：
- "刷几道基础医学综合的题"
- "来一套临床执业医师资格考试刷题模拟卷"
- "复习我的错题"

## 三、错题库说明
- 位置：本技能目录内的 `mistakes/mistakes.json`（相对路径，跨平台通用）
- 首次使用自动创建；答错自动记录，可随时"复习错题"重练。

## 四、版本
当前版本：1.0.0
