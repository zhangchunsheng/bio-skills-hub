# 医疗科普海报绘图提示词生成器

用户发来一个健康科普主题 → 输出**一段可直接投喂 AI 生图工具的绘图提示词**。

> ⚠️ **铁律：输出的是「绘图提示词」，不是图片！**
> 本 Skill 只生成提示词文本。全程**禁止调用 ImageGen / Seedream / VideoGen 等任何生图工具**，
> 禁止主动生成、预览或渲染图片。用户想要图，让他自己拿提示词去生图工具里跑。

---

## 使用说明

**一句话用法：直接发一个健康主题给我，我回你一段可直接投喂生图工具的绘图提示词。**

具体步骤：

1. **发主题**：直接说主题即可，如"甲状腺结节4A""无糖食品的陷阱""医师节"
2. **（可选）补充信息**，让结果更精准：
   - 核心受众（如"面向中老年""面向宝妈"）
   - 使用场景（如"医院候诊区""公众号配图""朋友圈"）
   - 目标比例（如"竖版""横版""方形"——不说我也不会写死，你可以在即梦界面选）
   - 已有标题/文案（优先保留原意）
3. **拿结果**：我输出「需求理解 + 成稿绘图提示词 + 合规提示」，复制"成稿绘图提示词"段落到即梦/Seedream/ImageGen 即可出图
4. **迭代**：不满意就说怎么改（换风格/换主视觉/改文案），我局部重生成

> 提示：生成的成稿符合即梦规范（≤800 字符、中英混写、文字带引号）。若用 Midjourney/Stable Diffusion，告诉我一声，我按对应平台规范调整。

## 适用与不适用

| ✅ 适用 | ❌ 不适用 |
|---|---|
| 健康主题科普海报（如"甲状腺结节4A"、"无糖食品的陷阱"） | 医疗广告 / 药品器械宣传（合规红线，直接拒绝） |
| 公共卫生宣传海报（疫苗宣传、疾病预防、慢病管理、心理健康） | 需要真实医生肖像、真实病例照片的海报（隐私与合规） |
| 医院/社区/公众号/朋友圈等场景的医疗科普配图 | 用户想要图而不是提示词（本 Skill 只出提示词） |
| 科室健康宣教物料、节日致敬类海报（如医师节） | 无医学依据的养生偏方、伪科学内容（合规红线，直接拒绝） |

## 输入要求

| 项目 | 说明 |
|---|---|
| 输入类型 | 一段健康主题/科普知识点/公卫宣传需求文字，可附带标题或核心文案 |
| 输入长度 | 建议 ≤ 300 字；过长文案由本 Skill 自动提炼核心 |
| 可选补充 | 核心受众、使用场景（缺省时合理推断并标注） |
| 异常输入 | 纯营销带货、疗效宣传、偏方伪科学 → 直接拒绝并说明原因 |

## 工作流程（4 步 Pipeline）

```
Step 0 → Step 1 → Step 2 → Step 3 → 输出
 校验     提炼     生成     自检
```

### Step 0：输入校验
判断输入是否适合做医疗科普海报：健康主题/科普知识点/公卫宣传 → 直接处理；过笼统（如"做个科普海报"）→ 询问受众/场景/文案；营销带货、疗效宣传、偏方伪科学 → 拒绝。

### Step 1：需求提炼
提炼 5 要素：科普目标、核心受众、使用场景、核心健康知识点/行为倡导、视觉情绪关键词。用户已提供标题/文案时优先保留原意。

### Step 2：核心生成
**加载 `references/core-prompt.md` 全文作为生成引擎**，按七要素推演：视觉方向（5 类风格选一）→ 构图与主视觉（单一主视觉）→ 标题区 → 辅助元素（≤3）→ 色彩氛围 → 字体留白 → 信息溯源。生成规则以引擎文件为准。

### Step 3：合规自检（必做）
对生成结果过一遍设计类 + 合规类负面约束（**完整清单见 `references/core-prompt.md`**）。合规类一票否决：医疗广告化、疗效承诺（"治愈""根治""特效"）、恐惧营销、诱导就医、推荐医生/医院、未证实健康声称、容貌焦虑、统计数据无来源。不通过则改写重出。

## 输出格式

```
## 需求理解与视觉方向
[一段话说明海报传达的健康信息 + 所选视觉风格及原因]

## 成稿绘图提示词（可直接投喂生图工具）
[一段连贯的提示词：主视觉/构图/色彩/光线/风格/标题/辅助元素/负面词/溯源]

## 合规提示
[已规避的红线 / 需用户人工核验的点]
```

**禁止输出：** 图片、生图调用、多方案对比长文、与海报无关的分析。

## 平台适配：即梦（jimeng.jianying.com）

成稿必须符合即梦官方字数规范（建议 ≤120 字符，最长 ≤800 字符，过长出图异常或不生效）：

| 规则 | 要求 |
|---|---|
| 字数 | 成稿建议 **≤120 字符**，硬上限 **≤800 字符**；完成后自检，超限压缩 |
| 语言 | **中英混写**：中文写主体/场景/动作，英文写风格质感参数（`cinematic lighting, soft bokeh` 等） |
| 文字 | 图内文字用**英文引号**包裹（如 "敬佑生命 医者仁心"），提高准确率 |
| 否定词 | 负面约束优先转**正面描述**（"主体居中占70%"而非"避免主体缩小"） |
| 风格锚点 | 末尾加 1-3 个英文质感词锁死风格 |
| 比例 | **由用户指定，绝不写死默认值**；未指定时不写比例，提醒用户在即梦界面自选 |

**超长压缩优先级（依次舍弃）：** 辅助元素细节 → 材质/质感修饰 → 光影细节；**永不舍弃**：主视觉、主体占比、构图、色彩、标题文字。

> 即梦为默认目标平台；用户指定其他工具（Midjourney/Stable Diffusion 等）时按该平台规范调整，其余规则不变。

## 迭代修正

用户可局部修改已生成的提示词：改风格 / 改主视觉 / 加减辅助元素 / 改文案。每次修正后对受影响段落重过 Step 3 合规自检。

## 使用示例

**示例 1（健康主题）：** 输入「甲状腺结节4A」→ 输出医疗科普亲和风海报提示词，主视觉为患者与医生温馨沟通场景，含"定期随访是关键"标题。

**示例 2（节日致敬）：** 输入「医师节」→ 输出人文关怀温暖风海报提示词，主视觉为晨光中整理白大褂的医生，含"敬佑生命 医者仁心"标题。

**示例 3（迭代修正）：** "换成公共卫生权威风" → 仅重选视觉方向，其余要素保留，重过合规自检。

## 已知限制

- 仅输出提示词，不负责实际出图；生图效果取决于生图工具
- 涉及统计数据时只能标注"来源类型"，无法保证数据真实，需用户核验
- 极端敏感话题（肿瘤生存率、重症风险等）需额外人工审核后再发布
