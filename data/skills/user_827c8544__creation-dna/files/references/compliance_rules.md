## 学术诚信边界

本技能**不得**用于以下场景。若检测到用户请求涉及以下场景，应拒绝记录相关偏好，简要说明原因，并正常完成用户的其他合法创作需求。

### 禁止场景

1. **论文代写辅助**：不为学术论文、学位论文、期刊投稿提供风格模仿或内容生成的偏好记忆，避免助长学术不端
2. **数据造假偏好**：不记录"把数据改得更好看""P 掉异常值"等涉及数据篡改的创作偏好
3. **引用伪造**：不学习或记忆"编造参考文献""虚构引用来源"等违规操作模式
4. **身份冒用**：不记录用于模仿特定在世学者、作家写作风格以冒充其作品的参数

### 拒绝话术

当检测到上述场景时，使用以下话术拒绝：

> 该请求涉及学术诚信风险，创作 DNA 技能不做记录。正常创作需求可继续完成。

### 边界判断

- 记录"用户偏好学术论文的严谨表述风格"是允许的（记录的是抽象调性偏好）
- 记录"模仿某学者的具体论证结构和用词习惯以代写论文"是禁止的（涉及身份冒用和代写）
- 记录"图表配色偏好"是允许的（记录的是视觉审美参数）
- 记录"调整数据使其更美观"是禁止的（涉及数据造假）

## 版权与原创边界

### 风格学习与内容复制的界限

| 允许记录 | 禁止记录 |
|----------|---------|
| 从参考图提取的色调倾向（如"偏冷色调""低饱和度"） | 参考图本身的完整像素数据 |
| 从他人作品中抽象出的风格关键词（如"极简主义""赛博朋克"） | 他人作品的具体文案、画面构图、核心表达 |
| 用户对某作品维度的评价（如"喜欢该排版的留白感"） | 该作品的具体排版参数、字体名称组合 |
| 通用审美趋势的偏好（如"当前偏好大字号标题"） | 特定品牌的设计规范全文 |

### 参考图脱敏规则

若用户提供参考图作为风格参考：

1. 仅从图中提取风格参数关键词（色调、构图风格、情绪倾向）
2. 不存储图片本身
3. 不存储图片的文件路径或 URL
4. 不记录图中包含的任何文字内容、Logo、水印
5. 提取记录格式：`色调：偏冷蓝 | 构图：中心对称 | 情绪：科技感`（仅记录抽象维度）

### 第三方作品参考规则

若用户提供第三方作品作为风格参考：

1. 仅记录"用户喜欢该作品的 [抽象维度]"
2. 不记录作品名称、作者、出处
3. 不记录作品的具体内容、文案、画面细节
4. 记录格式：`用户偏好：极简留白风格（来源：用户提供的参考）`

## 隐私与数据权利

### 数据主权

- 所有沉淀的创作 DNA 均为用户个人偏好的结构化存档
- 数据所有权归用户本人
- 用户享有完全的知情权、修改权、删除权

### 遗忘权执行规范

当用户要求删除特定偏好时：

1. 在1次工具调用内完成移除
2. 将被删除的条目移入 `archive/deprecated.md` 的废弃区，标注"用户要求删除"
3. 向用户确认删除结果："已删除 [N] 条偏好记录，涉及 [创作类型]"
4. 若条目存在于多个 profile.md 中，逐一处理并汇总确认

### 数据本地化

- 所有数据存储在当前工作目录的 `.creation-dna/` 文件夹下
- 数据不离开本地文件系统
- 不上传到任何远程服务器
- 不用于模型训练或微调
- 不与第三方共享

### 数据保留策略

| 数据类型 | 保留期限 | 到期处理 |
|----------|---------|---------|
| 已确认偏好 | 90天未引用后降级 | 降级为休眠偏好 |
| 待验证偏好 | 无强制期限 | 维持至晋升或废弃 |
| 观察候选 | 30天未再次提及 | 清理删除 |
| 休眠偏好 | 无强制期限 | 保留，不主动使用 |
| 已废弃偏好 | 无限保留 | 作为历史记录，不删除 |
| 模糊反馈记录 | 无限保留 | 作为参考，不主动使用 |
| 损坏事件记录 | 无限保留 | 作为审计日志 |

## 敏感内容处理规则

### 敏感内容定义

以下内容被视为敏感内容，捕获时需特殊处理：

| 类别 | 示例 | 处理方式 |
|------|------|---------|
| 个人隐私 | 真实姓名、电话、地址、身份证号 | 仅记录格式偏好，不记录具体内容 |
| 医疗健康 | 疾病、症状、用药信息 | 仅记录文档结构偏好，不记录医疗细节 |
| 法律事务 | 案件细节、法律建议 | 仅记录表述风格偏好，不记录案件内容 |
| 金融信息 | 收入、资产、投资详情 | 仅记录数据呈现偏好，不记录具体金额 |
| 未成年人内容 | 涉及未成年人的创作 | 完全不捕获，跳过记录 |

### 敏感内容处理流程

1. 识别反馈中是否包含敏感信息
2. 若包含：仅提取格式/结构层面的偏好（如"偏好条目式排版""偏好短段落"）
3. 丢弃所有敏感内容本身
4. 记录格式偏好时标注"来源：敏感内容反馈，仅记录格式偏好"

## 免责声明

### 责任归属

- 本技能仅记录用户本人在创作交付过程中表达的审美偏好与返工经验
- 所有沉淀的"创作 DNA"均为用户个人偏好的结构化存档
- 不构成对任何第三方作品的复制、模仿或衍生
- 用户基于本技能生成的创作内容，其版权与合规责任由用户自行承担

### 偏差免责

- 本技能不对因偏好记录偏差导致的创作结果不满意承担责任
- 偏好记录基于用户主观表达，可能存在解读偏差
- 用户应定期审阅创作 DNA 画像，确保记录准确

### 使用限制

- 本技能不保证创作质量的提升
- 本技能不替代用户的审美判断
- 本技能的预检功能为辅助参考，不构成创作决策的唯一依据
- 用户保留对所有创作决策的最终决定权
