# 质量维度矩阵 - 各创作类型详细定义

本文件定义各创作类型的质量评估维度，供捕获反馈时标注使用。

1. [文案写作](#文案写作)
2. [图像生成](#图像生成)
3. [视频制作](#视频制作)

---

## 文案写作

| 维度 | 定义 | 捕获示例 |
|------|------|---------|
| 标题吸引力 | 标题是否能在信息流中抓住注意力 | "标题不够抓眼""开头太平淡" |
| 开头钩子 | 前3行/前3秒是否能留住读者 | "开头太长""切入太慢" |
| 信息密度 | 单位篇幅内的有效信息量 | "太空洞了""信息量不够" |
| 调性匹配 | 语气、口吻与目标受众的匹配度 | "太正式了""不够接地气" |
| 结尾行动指令 | 结尾是否有效引导读者行动 | "结尾没有call to action" |
| 用词精准度 | 词汇选择是否准确传达意图 | "用词太模糊""不够精准" |
| 逻辑连贯性 | 段落间逻辑是否通顺 | "上下文衔接不好" |

## 图像生成

| 维度 | 定义 | 捕获示例 |
|------|------|---------|
| 色调 | 整体色彩倾向与氛围 | "色调太暖了""颜色太艳" |
| 构图 | 画面元素的布局与视觉重心 | "构图偏了""主体不够突出" |
| 主体突出度 | 核心元素是否清晰可辨 | "主体被背景淹没了" |
| 风格一致性 | 画面内各元素风格是否统一 | "风格混搭了""不协调" |
| 细节精度 | 渲染质量与细节完成度 | "手指画错了""细节太粗糙" |
| 光影 | 光线方向、阴影合理性 | "光影不自然" |
| 负空间 | 留白是否舒适、不拥挤 | "画面太满了" |

## 视频制作

| 维度 | 定义 | 捕获示例 |
|------|------|---------|
| 节奏 | 剪辑节奏与内容节奏的匹配 | "节奏太慢""拖沓" |
| 转场 | 场景切换的流畅度与合理性 | "转场太硬""跳切突兀" |
| 字幕可读性 | 字幕大小、位置、时长的合理性 | "字幕太小了""字幕挡住画面" |
| 音画同步 | 画面与音频的对齐精度 | "声音对不上画面" |
| 开头3秒留存 | 开头是否能在3秒内抓住观众 | "开头没吸引力" |
| 色彩分级 | 整体调色风格与情绪传达 | "调色太灰了" |
| 信息节奏 | 关键信息出现的密度与间隔 | "信息太密集了""中间太空" |

## 视觉设计

| 维度 | 定义 | 捕获示例 |
|------|------|---------|
| 排版层级 | 信息层级是否清晰可读 | "层级不分明""重点不突出" |
| 留白 | 空间分配的舒适度 | "太挤了""留白不够" |
| 配色和谐 | 色彩搭配的协调性 | "颜色撞了""配色不舒服" |
| 品牌一致性 | 与品牌规范的符合度 | "不符合品牌调性" |
| 信息传达效率 | 核心信息是否快速传达 | "核心信息不够突出" |
| 字体选择 | 字体与内容的匹配度 | "字体太花了""不够正式" |
| 视觉动线 | 阅读路径的引导性 | "不知道先看哪里" |

## 结构化内容

| 维度 | 定义 | 捕获示例 |
|------|------|---------|
| 逻辑递进 | 内容层层递进的合理性 | "逻辑跳跃了""没有递进" |
| 视觉重点 | 关键信息是否突出 | "重点不够突出" |
| 页数控制 | 总页数/总量的合理性 | "太多了""太长了" |
| 图表可读性 | 图表是否清晰易懂 | "图表看不懂""太小了" |
| 信息分层 | 主次信息的分层清晰度 | "主次不分" |
| 导航友好 | 页面间跳转的便利性 | "找不到下一页在哪" |
