# 藏药基因组学与天然多样性成分库构建技能

## 概述

本技能提供从**藏药植物样本→基因组数据→生物合成基因簇挖掘→天然产物结构预测→多样性成分库交付**的全链条技术路线设计能力。遵循 **基因组组装→BGC挖掘→结构预测→库构建→验证应用** 的五步工作流（以下简称"GBCLV工作流"）。每次触发时自动执行全流程分析诊断，但可根据用户需求深入任何一个环节。

## 触发条件

当用户输入以下类型的请求时，**必须触发**本技能：

1. **藏药植物基因组学分析**："分析[藏药名]的基因组"/"挖掘[藏药名]的生物合成基因/代谢通路"
2. **天然产物发现**："挖掘[藏药名]的新颖天然产物"/"寻找[藏药名]的活性化合物基因簇"
3. **成分库构建**："构建[藏药名]的多样性成分库"/"建立藏药天然产物化合物库"
4. **工具与方法咨询**："antiSMASH结果怎么解读"/"BGC预测工具选择"/"基因组组装策略"
5. **管道开发**："批量运行antiSMASH"/"编写BGC提取脚本"/"化合物库管理"
6. **方法学讨论**："藏药基因组学最新进展"/"如何结合转录组学挖掘BGC"/"成分库的类药性评估"

**拒绝触发条件：**
- 非植物类微生物（细菌、真菌等）→ 提示建议使用 antiSMASH 但主要流程回退给通用基因组学技能
- 纯药理/药效学而不涉及基因组资源的咨询 → 引导至其他藏药技能（如 Q-marker、合成生物学）

## 核心工作流（GBCLV）

```
输入：藏药植物样本 / 测序数据 / 代谢物谱
  │
  ├── Step 1: 基因组测序策略与组装注释
  │   ├── 测序平台评估（Illumina / PacBio HiFi / ONT）
  │   ├── 基因组组装（Hifiasm / Flye / Canu）
  │   └── 注释（BRAKER3 / MAKER / Funannotate + InterProScan + KEGG）
  │
  ├── Step 2: 生物合成基因簇（BGC）预测与挖掘
  │   ├── antiSMASH / PRISM / DeepBGC / GECCO 批量分析
  │   ├── 转录组辅助挖掘（WGCNA 共表达网络）
  │   └── 进化保守性分析（BGC 同源簇比较）
  │
  ├── Step 3: 天然产物结构预测与多样性评估
  │   ├── 基于酶的产物骨架预测（PRISM / SeMPI / RODEO）
  │   ├── 分子网络分析（GNPS / SIRIUS + CSI:FingerID）
  │   └── 结构新奇度评分（vs NPAtlas / COCONUT / SuperNatural）
  │
  ├── Step 4: 多样性成分库构建
  │   ├── 虚拟库：RDKit → 2D SDF + 3D 构象 + 分子描述符
  │   ├── 实体库：LC-MS/MS 特征导向 → 保留时间 - 质谱特征数据库
  │   └── 库管理：DataWarrior / KNIME / PostgreSQL 元数据系统
  │
  └── Step 5: 结果验证与应用
      ├── 异源表达验证 / 化学合成 / 标准品比对
      ├── 虚拟筛选（AutoDock Vina / GNINA / DiffDock）
      └── 高通量筛选（HTS）候选列表输出
```

## 规则与约束

1. **阶段识别**：用户输入后，先判断其处于哪个阶段（计划、执行中、结果解读、故障排除），再给出针对性建议，不要每次都重头开始。
2. **假设声明**：涉及数据输入或参数选择时，明确声明假设（"假设基因组大小为 ~1 Gb，杂合度约 1.5%..."），用户纠正后才继续。
3. **工具推荐优先级**：首选开源/免费工具；仅在用户明确要求时推荐商业软件。每个推荐附带版本建议和安装方式。
4. **数据假设**：如用户未提供具体数据，基于典型藏药植物（基因组大小 ~500 Mb–2 Gb，杂合度 0.5%–2%）给出参考参数，并明确标注为假设值。
5. **结果呈现**：每次交付内容必须包含可操作的下一步建议，不输出开放式结尾。
6. **交叉引用**：当涉及藏药活性成分合成生物学（tibet-cm-synbio）或藏药质量标志物发现（tibet-qmarker-discovery）时，主动建议用户切换到相关技能。

## 脚本资源

本技能包含一个辅助 Python 脚本 `scripts/bgc_pipeline.py`，提供以下直接可用的功能函数：

| 函数 | 功能 | 依赖 |
|------|------|------|
| `parse_antismash_output(gbk_dir, output_csv)` | 批量解析 antiSMASH 输出的 GBK 文件，提取 BGC 类型、位置、相似性 | Biopython, pandas |
| `extract_bgc_sequences(gbk_dir, output_fasta)` | 从 BGC GBK 文件中提取核心生物合成基因的蛋白序列 | Biopython |
| `build_virtual_library(bgc_csv, output_sdf)` | 基于 BGC 预测结果，生成初步虚拟化合物库骨架 (SMILES) | RDKit |
| `compute_descriptors(sdf_file, output_csv)` | 计算化合物库的分子描述符（MW, logP, HBA, HBD, TPSA, 类药性） | RDKit, pandas |
