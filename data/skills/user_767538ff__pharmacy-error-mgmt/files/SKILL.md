# 药房差错管理 · Pharmacy Error Management

三甲医院药房（门急诊/住院/静配中心）用药错误与调剂差错的闭环管理助手。

不是通用"医疗问答"——而是把药房质控的实际流程（登记 → 分级 → 根因分析 → 统计改进）沉淀成可复用工作流。

---

## 触发场景

- "帮我登记一条药房差错 / 这条差错该怎么分级"
- "我们药房这个月差错变多了，做个统计 / 画个趋势图"
- "做一次差错根因分析 / 用鱼骨图看为什么总发错药"
- "给个差错登记表模板 / 帕累托分析重点差错类型"
- 用户提供一份差错记录 CSV/Excel 要求分析

---

## 工作流总览

```
模块1 差错登记与分级  ──►  模块2 根因分析 RCA  ──►  模块3 统计与趋势图表
   (单条/批量登记)        (针对严重/重复差错)        (周期复盘 & 改进效果评价)
```

用户可只调用其中一个模块。若用户只有零散描述、没有结构化数据，先走模块1产出登记表，再按需进入模块2/3。

---

## 模块1 · 差错登记与分级

**目标**：把用户口述/纸质的差错，规范成一条结构化记录，并给出分级建议。

1. 读取 `references/grading_standard.md`，按其中「差错类型」「分级标准」「登记字段」与用户核对。
2. 向用户逐项补齐登记要素（编号可自动生成 `YYMMDD-序号`）：
   - 发生/发现日期时间、部门（门诊药房/住院药房/静配中心/药库）、药房小组、班次、当事人
   - 差错类型（处方审核/调剂/发药/储存养护…细分类见标准）
   - 差错分级（A-I 级 或 一般/严重/事故，见标准）
   - 涉及药品（名称/规格/批号）、差错环节、错误内容 vs 正确内容
   - 是否已发出、是否造成伤害、伤害程度、发现人与上报人
3. 输出一张**结构化登记表**（Markdown 表格或 CSV），并标注分级依据（例如「已发至患者但未使用 → B级」）。
4. 若同批有多条，汇总成 CSV，可直接喂给模块3统计。

> 分级与类型以各院《药品调剂差错管理制度》为准；本 skill 提供的是可编辑的通用基准，请提醒用户对齐本院制度。

---

## 模块2 · 根因分析 RCA

**目标**：对严重差错（C级及以上）或重复发生的差错，定位系统性根因并产出可执行的改进措施。

1. 读取 `references/rca_guide.md`，按其中 8 步法推进。
2. 与用户一起完成：
   - **事件时间线**（5W1H）：什么药、谁、何时、哪环节、怎么错的。
   - **鱼骨图分析**：从 人/机/料/法/环/测 六个维度枚举可能原因（药房语境下的具体诱因见指引）。
   - **5Why 追问**：对关键近端原因连续追问至根因。
   - **根因判定**：区分 root cause（系统性、可改进）与偶发因素。
3. 产出：
   - 一张**鱼骨图**（用 Visualizer 画 SVG，或直接给 Markdown 维度表）
   - 一份 **5Why 根因链**
   - 一张 **改进行动表**（措施 / 责任人 / 完成时限 / 可测量指标 / 追踪方式）
4. 改进措施应可量化，便于模块3做前后对比评价。

---

## 模块3 · 统计与趋势图表

**目标**：把多期差错记录转化为可汇报的统计图表与趋势分析。

1. 若有 CSV/Excel 数据：
   - 列名尽量对齐 `references/grading_standard.md` 的登记字段（至少含：日期、差错类型、分级、部门/小组、是否造成伤害）。
   - 运行 `scripts/error_stats.py`（依赖 pandas + matplotlib，中文需 CJK 字体）：
     ```
     python scripts/error_stats.py --input 差错记录.csv --outdir ./差错分析输出
     ```
   - 脚本产出：①月度频次趋势折线图 ②类型分布条形图 ③分级分布 ④部门/小组对比 ⑤**帕累托图**（定位累计占比≥80%的重点差错类型）⑥Markdown 汇总报告。
2. 若用户暂无数据：先产出**空白登记表模板（CSV）**让其采集，再回来跑统计。
3. 报告要点：总差错数、环比/同比变化、Top 差错类型（帕累托）、高危环节与分级、改进建议。

> 中文字体：脚本会自动探测 macOS 的 PingFang / 系统字体；若图表中文乱码，提示用户在脚本顶部 FONT_PATH 指定本机中文字体路径。

---

## 输出规范

- 登记表/分析表用 Markdown 表格，便于直接粘进 OA/质控股。
- 统计图表保存为 PNG，报告为 Markdown，二者一并 `present_files` 交付。
- 涉及真实患者信息时，提醒用户脱敏（隐去姓名/床号/病历号）后再分析。
- 任何分级、制度口径均标注「以本院制度为准」，不替代医院正式判定。
