# 药房差错根因分析（RCA）八步法

> 适用于严重差错（三级制"严重差错"及以上，或 NCC MERP C 级及以上）及**重复发生**的差错。一般差错做科室内部小结即可，不必全套 RCA。

---

## 步骤

1. **组建 RCA 小组**：当事药师 + 组长 + 护理/医师代表 + 质控员；明确 facilitator。
2. **准确描述事件**：用 5W1H 与**时间线**还原（见模板）。
3. **识别直接原因与近端原因**：差错是怎么一步步发生的（流程哪一步断了）。
4. **根因分析**（核心，见下方工具）。
5. **判定根因**：区分 *root cause*（系统性、可改进）与*偶发因素*（个人一时疏忽但系统已防护）。
6. **制定改进措施**：每条根因对应 ≥1 条可量化措施。
7. **实施与追踪**：写入行动改进表，明确责任人/时限/指标。
8. **效果评价**：下一周期用模块3统计做前后差错率对比。

## 工具一：鱼骨图（6M 维度，药房语境）

| 维度 | 药房常见诱因子类 |
|---|---|
| **人 (Man)** | 疲劳/忙乱、培训不足、新入职、LASA 识别力弱、核对流于形式 |
| **机 (Machine)** | 系统未拦截、HIS 无警示、打印机/标签机故障、灯光不足 |
| **料 (Material)** | 外观相似药品、同名不同规格、近效期混放、包装变更未通知 |
| **法 (Method)** | 双人核对未执行、流程缺环节、医嘱转录易错、无标准操作SOP |
| **环 (Environment)** | 高峰拥堵、布局不合理、噪声干扰、温湿度异常 |
| **测 (Measurement)** | 差错定义不一、登记不全、无趋势监测、考核导向偏差 |

## 工具二：5Why 模板

```
问题：______ 发错药（应为A，实际发B）
Why1：为什么发错？ → 调配时拿了外观相似药
Why2：为什么会拿错？ → 货位相邻且未二次核对
Why3：为什么没二次核对？ → 高峰时段为赶速度跳过了核对
Why4：为什么流程被跳过无阻断？ → 系统不强制核对环节
Why5：为什么系统不强制？ → 旧流程未配置强制节点
根因：法/机 — 系统未设强制核对节点 + 高峰排班不足
```

## 改进行动表（输出用）

| 根因 | 改进措施 | 责任人 | 完成时限 | 可测量指标 | 追踪方式 |
|---|---|---|---|---|---|
| 法-系统未强制核对 | HIS 增加调配后强制核对节点 | 信息科+药师长 | 2026-09-30 | 核对执行率100% | 月度抽检 |
| 人-高峰排班不足 | 高峰增援1人 | 组长 | 即时 | 高峰差错数下降 | 周统计 |
| 料-LASA混放 | 相似药品分柜+警示标 | 库房 | 2026-09-15 | LASA差错=0 | 巡检 |

> 措施须可量化，才能被模块3统计验证改进效果。
