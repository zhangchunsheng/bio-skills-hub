# 药房差错分级与登记基准（通用版，以本院制度为准）

> 本文件为**可编辑通用基准**。各三甲医院应以本院《药品调剂差错管理制度》《用药错误管理制度》为最终口径；本表用于快速登记与初判。

---

## 一、差错类型（按环节/性质细分）

### 1. 处方审核环节
- 用法用量不当（超量/不足/频次错）
- 配伍禁忌 / 相互作用未识别
- 重复用药（同成分不同商品名）
- 诊断与用药不符 / 无指征用药
- 超说明书用药未审批

### 2. 调剂（调配）环节
- 药品**品种**差错（同名/易混淆）
- **规格/剂型**差错
- **数量**差错（多发/少发）
- 药品成品/半成品混淆、相似包装错拿
- 近效期/过期药品发出
- LASA 错误（外观相似 Look-alike / 读音相似 Sound-alike）
- 标签/标识错误（姓名、用法、剂量）

### 3. 发药环节
- **发药对象**错误（错人/错床）
- 用药交代不清 / 指导错误

### 4. 储存与养护
- 温湿度失控、破损、污染、混放

## 二、差错分级标准

提供两套常用口径，登记时二选一并注明。

### 口径 A：三级制（多数医院 QA 常用）
| 级别 | 定义 | 示例 |
|---|---|---|
| **一般差错** | 未造成患者伤害，调配/发药环节内及时发现纠正 | 调配时发现规格拿错，未发至患者 |
| **严重差错** | 已发生或可能造成患者伤害，需处理或延长住院 | 错发药品但已追回未服用；或服用后需医学观察 |
| **差错事故** | 造成患者死亡或严重残疾 | 错误用药致器官损伤/死亡 |

### 口径 B：NCC MERP 九级（A–I，研究/上报常用）
| 级别 | 含义 |
|---|---|
| A | 差错已形成，但未抵达患者（事前拦截） |
| B | 差错抵达患者，但未使用 |
| C | 使用，需监测，未造成伤害 |
| D | 使用，需治疗/住院延长，未永久伤害 |
| E | 造成暂时伤害，需干预 |
| F | 造成住院/延长住院 |
| G | 造成永久伤害 |
| H | 危及生命，需挽救 |
| I | 死亡 |

## 三、登记字段（每条差错一条记录）

| 字段 | 说明 | 示例 |
|---|---|---|
| 编号 | `YYMMDD-序号` 自动生成 | 260821-03 |
| 发生日期时间 | 差错实际发生时刻 | 2026-08-21 09:12 |
| 发现日期时间 | 被发现时刻（用于算拦截时效） | 2026-08-21 09:15 |
| 部门 | 门诊药房/住院药房/静配中心/药库 | 住院药房 |
| 药房小组 | 小组/窗口 | 一组 |
| 班次 | 白班/夜班 | 白班 |
| 当事人 | 当事药师（脱敏可用工号） | P1023 |
| 差错类型 | 见第一节细分 | 调剂-品种差错 |
| 差错分级 | 三级制 or A–I | 一般差错 / B |
| 涉及药品 | 名称/规格/批号 | 阿司匹林0.1g / 批号X |
| 差错环节 | 审核/调配/核对/发药/养护 | 调配 |
| 错误内容 | 实际发生的错误 | 发了对乙酰氨基酚 |
| 正确内容 | 应为 | 应为阿司匹林 |
| 是否已发出 | 是/否 | 否 |
| 是否造成伤害 | 是/否 | 否 |
| 伤害程度 | 无/轻度/中度/严重/死亡 | 无 |
| 发现人 | 谁发现 | 核对药师 |
| 上报人 | 谁上报 | 组长 |
| 根本原因分类 | 人/机/料/法/环/测（见 RCA 指引） | 法-流程缺陷 |
| 整改措施 | 文字 | 双人核对+LASA警示标 |
| 状态 | 待处理/已整改/关闭 | 已整改 |

> CSV 表头建议（供模块3统计脚本直接读取）：
> `编号,发生日期,发现日期,部门,药房小组,班次,当事人,差错类型,差错分级,涉及药品,差错环节,是否已发出,是否造成伤害,伤害程度,根本原因分类,状态`
