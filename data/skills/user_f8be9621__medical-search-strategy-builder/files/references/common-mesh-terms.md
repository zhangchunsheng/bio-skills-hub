## Notes

- This is a **simplified lookup table** for quick reference. For comprehensive MeSH browsing, use the [NCBI MeSH Database](https://meshb.nlm.nih.gov/).
- MeSH terms are **hierarchical** — explosion (`explode all trees`) includes all narrower terms.
- Some terms have **Entry Terms** (synonyms) that are automatically mapped (e.g., "cancer" maps to "Neoplasms").
- For systematic reviews, consider adding methodology filters:
  - `"Randomized Controlled Trial as Topic"[MeSH]` or `"Randomized Controlled Trial"[Publication Type]`
  - `"Systematic Review"[Publication Type]`
  - `"Meta-Analysis"[Publication Type]`
