# IP 自我定位剖析师 · SkillHub 介绍文档

> **Skill 名称**：`ip-zizhu-dingwei`  
> **定位**：自媒体人的「IP 定位教练」——基于 22 题自我剖析表，引导用户梳理基础信息、内核价值、人生经历、自媒体认知、行业信息，最终输出一份可直接落地的 IP 定位报告。

---

## 一、一句话卖点

**不知道自己该做什么 IP，就先用 22 道题把自己扒清楚。**

本 Skill 不会凭空给你造一个人设，而是带你一层一层回答你是谁、你能给谁价值、你凭什么被关注，最后输出人设名、定位、受众、内容支柱、差异化、变现路径和 30 天启动清单。

---

## 二、适合谁用

1. **想开始做自媒体但不知道怎么定位的人**：有想法、有经历，但说不清楚自己该立什么人设。
2. **准备转型/升级个人 IP 的博主**：内容做久了流量瓶颈，需要重新梳理差异化。
3. **知识付费/创业老板**：要把个人经历和行业优势打包成一个可传播、可变现的 IP。
4. **短视频编导/MCN 运营**：给客户做 IP 定位时，用这个 Skill 快速跑通前期访谈和方案框架。
5. **想做付费咨询/陪跑的人**：把 22 题作为客户信息采集流程，直接出定位报告。

---

## 三、解决什么问题

| 常见痛点 | 这个 Skill 怎么治 |
|---|---|
| 不知道自己该做什么赛道 | 从人生经历 + 内核价值 + 行业信息三个维度交叉定位 |
| 人设太虚，像编出来的 | 强制所有结论基于用户真实回答，禁止编造 |
| 有经历但讲不出差异化 | 用「冲突即亮点」原则，把反差经历变成记忆点 |
| 内容方向混乱 | 输出 4 个内容支柱，直接对应选题库 |
| 只会做流量不会变现 | 变现路径必须衔接现有产品/服务 |
| 定位方案落不了地 | 结尾附 30 天启动清单 |

---

## 四、核心能力

- **5 个模块逐步引导**：个人基础信息、内核价值、人生经历、自媒体认知、行业信息，避免一次性 22 题砸晕用户。
- **灵活输入方式**：用户可以一次性粘贴全部答案，也可以分模块慢慢答。
- **智能追问**：答得太简略时，自动追问 1-2 个问题，把定位挖深。
- **结构化报告**：包含基础画像、核心定位、目标受众、内容四支柱、差异化、人设 DNA、变现路径、30 天启动清单、待补信息。
- **可结合档案**：按约定放置 `docs/用户/档案.md` 和 `docs/用户/人设卡.md`，会自动读取已知信息作为追问和校验基准。

## 六、对话流程

1. **开场**：说明会分 5 个模块、22 题，最后给定位报告。
2. **模块一：个人基础信息**（5 题）
3. **模块二：内核价值**（3 题）
4. **模块三：人生经历**（4 题）
5. **模块四：自媒体认知**（4 题）
6. **模块五：行业信息**（6 题）
7. **输出 IP 定位报告**

用户也可以直接一次性粘贴已经填好的 22 题答案，AI 直接出报告。
