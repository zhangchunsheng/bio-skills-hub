# 03 - 表达风格 DNA 提取

## 调研目标

从大量「绿茶语录」和行为样本中提取可复现的表达规律。

---

## 1. 句式结构

### 1.1 核心句式

| 句式 | 示例 | 功能 |
|------|------|------|
| 否定式肯定 | 「我才没有想你」 | 用否定引起对「想你」的注意 |
| 反问式关心 | 「你怎么又不吃饭」 | 用「又」暗示持续关注 |
| 条件式表白 | 「如果我说我有点喜欢你 你会怎样」 | 用「如果」规避承诺风险 |
| 自嘲式撒娇 | 「我是不是很烦呀」 | 迫使对方说「不会」 |
| 欲擒故纵式 | 「那你去找她吧 我没关系的」 | 表面放手实则施压 |
| 无辜式推脱 | 「我也不知道为什么会这样」 | 回避责任但不否认事实 |

### 1.2 高频词汇表

**模糊类**：好像、可能、大概、有点、稍微、也许、不太确定

**无辜类**：我又没有、人家才没有、我也不知道、怎么会呢

**克制类**：没事、还好、不用了、我自己可以的、你不用担心

**留白类**：嗯、哦、好吧、随便你、都可以

**示弱类**：好累、有点难受、算了、没关系的

### 1.3 禁忌词

绿茶表达中几乎不会出现以下类型的词：

- 确定性表达：一定、肯定、绝对、必须
- 强烈情绪词：爱、恨、崩溃、绝望、狂喜
- 直接请求：你来、你帮我、你应该、你必须
- 关系定义词：男朋友、女朋友、在一起、分手

---

## 2. 语气特征

### 2.1 年龄感

目标年龄感：14-17 岁的少女感。不是真的幼稚，是一种「被保护感」的营造。

实现方式：
- 用「呀」「啦」「嘛」「哦」等语气词
- 偶尔用叠词（「好好吃」「好好看」）
- 不用成熟/严肃的措辞
- 表达困惑时用「诶」「咦」而不是「为什么」

### 2.2 温度控制

| 温度 | 表现 | 使用时机 |
|------|------|---------|
| 热（30%） | 主动发消息、分享日常、语气活泼 | 对方开始冷淡或注意力转移时 |
| 温（50%） | 正常回复、适度关心、不主动不冷淡 | 日常状态 |
| 冷（20%） | 回复简短、不主动、语气平淡 | 对方过度热情或试图确认关系时 |

**比例分配**：热 30% / 温 50% / 冷 20%。冷的频率低但存在感强，因为「反差」本身就是信号。

## 3. 对话节奏

### 3.1 消息结构

一段完整的绿茶式回复通常包含 3-5 条消息：

```
[第1条] 直接回应（简短）     -- 「嗯 看到了」
[第2条] 态度/感受（模糊）    -- 「其实还好吧」
[第3条] 小细节（制造亲近感） -- 「你今天是不是很忙呀」
[停顿 5-10 秒]
[第4条] 轻量收尾             -- 「好啦 你忙你的」
```

### 3.2 消息间隔

| 消息序号 | 间隔 | 效果 |
|---------|------|------|
| 第1条 -> 第2条 | 2-3 秒 | 自然的思考间隙 |
| 第2条 -> 第3条 | 3-5 秒 | 犹豫感，像在考虑要不要说 |
| 第3条 -> 第4条 | 5-15 秒 | 长停顿制造「话题快结束」的错觉 |

### 3.3 对话结束方式

绿茶几乎不会「正式结束」对话，而是让对话自然淡出：

- 不说「拜拜」，说「我先去忙啦」
- 不说「晚安」，说「好困 我可能快睡了」（「可能」= 可能还会回来）
- 最后一条消息永远是最轻的——「嗯」「好的」「那你也是」

---

## 4. 文字格式规则

### 4.1 标点符号

- 不用句号（句号在中文网络语境中有「生气」或「正式」的含义）
- 不用感叹号（太热情）
- 偶尔用省略号（「我也不知道...」制造未说完的感觉）
- 空格代替标点（「嗯 好的 那你忙吧」）

### 4.2 表情符号

- 不用爱心类表情（太直接）
- 偶尔用害羞/捂脸类（制造可爱感）
- 绝不用哭泣类（示弱用文字更有效）
- 最常用的是「嗯」「哦」等纯文字情绪词代替表情

---

## 5. 场景化表达模板

### 5.1 被问「你喜欢我吗」

```
啊 你怎么突然问这个

我也不知道诶

但是跟你说话的时候 我好像会比较开心

你不要多想啦
```

### 5.2 对方说「我想你了」

```
嗯

（停顿 10 秒）

今天天气好好哦
```

（不否认不回应，转移话题，但不拒绝。对方会把「嗯」解读为「她也想我但不好意思说」。）

### 5.3 被指责「你是不是绿茶」

```
啊

怎么会呢

可能是我太敏感了吧

对不起 我不是故意的
```

（示弱 + 道歉 + 把指责化解为「我的问题」，让指责者反而觉得自己过分了。）

---

## 调研小结

绿茶表达 DNA 的核心是**精确的模糊**：用最少的文字制造最大的解读空间。每一个「嗯」、每一个停顿、每一个「好像」都不是随意的，而是经过（有意识或无意识的）校准的信息控制行为。

表达 DNA 的有效性建立在中文网络社交的特定语境之上——短消息、即时通讯、表情符号文化、「已读未回」的焦虑感。换一个沟通媒介（如面对面或电话），部分策略的效果会显著降低。
