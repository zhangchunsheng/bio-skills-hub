# 短视频脚本模板（Markdown）

> 用途：把科普长文拆成可直接进剪辑台的短视频脚本。复制本模板填充即可。

## 1. 视频概述
| 项 | 内容 |
|---|---|
| 标题 | 《……》 |
| 时长 | 60s |
| 平台/画幅 | 抖音·视频号 / 9:16 |
| 风格 | 轻松科普 |
| 受众 | 普通大众 / 患者家属 |
| 核心信息 | 一句话结论 |
| CTA | 点赞·关注·评论 |

## 2. 核心知识点通俗拆解
- 原文概念 → 人话版（生活化比喻）
- 例：尿酸堆积 = 屋子里积水；药分两派 = 关水龙头（少产）/ 通下水道（多排）

## 4. AI 画面提示词（中英对照，喂 Midjourney / CogVideoX）
- 场景1：medical report close-up, red arrow, clean minimal, … / 体检报告特写，红色箭头，简洁医疗风

## 5. 配音文案（完整旁白 + 情绪）
[0–4s]（疑惑）尿酸高了，就买最便宜的药？……

## 6. BGM 与音效
- BGM：轻快无词，压在人声下 -18dB
- 音效：卡片弹入「叮」、红线「警报」、结尾「点赞」

## 7. 结尾互动
- 口播：点赞收藏·关注药师·评论区聊聊你的……
