# 人类遗传资源申报材料审核清单与工作指南

> 参考来源：科技部政务服务平台（https://fuwu.most.gov.cn/）
> 更新日期：2023年7月（实施细则生效后）

---

## 一、国际合作科学研究审批材料清单

### 1.1 必备材料

| 序号 | 材料名称 | 要求 |
|------|----------|------|
| 1 | 人类遗传资源采集/国际合作科学研究申请书 | 科技部标准模板，须在线填写并打印 |
| 2 | 合作各方协议书 | 须明确各方权利义务、知识产权归属、样本处置方式 |
| 3 | 伦理委员会批件 | 须为组长单位/各参加单位的EC批件（复印件加盖公章） |
| 4 | 知情同意书样本 | 须含遗传资源相关知情内容 |
| 5 | 申办方资质文件 | 营业执照/法人证书（外方需公证+翻译+认证） |
| 6 | 研究者资质证明 | 主要研究者的执业资质、GCP培训证书 |
| 7 | 试验方案（Protocol） | 须为EC批准的最终版本，含版本号和日期 |

### 1.2 补充材料（视情形）

| 情形 | 需补充材料 |
|------|------------|
| 涉及多中心 | 各中心EC批件汇总表 |
| 涉及保藏 | 保藏设施合格证明文件 |
| 涉及重要遗传资源 | 安全审查评估报告 |
| 涉及生物样本出境 | 出境样本清单、接收方承诺函、海关审批（如需） |

### 1.3 材料形式要求

- 所有材料须为中文（外文原件须附中文翻译）
- 外方提供的文件须经所在国公证+中国驻该国使领馆认证
- 所有复印件须加盖申请单位公章
- 电子版与纸质版内容须一致

## 三、常见补正问题汇总

根据科技部政务服务平台公布的常见补正问题：

### 3.1 申请书问题

1. **项目摘要过于简略**（应包含研究背景、目的、方法、预期结果）
2. **方案版本号和日期未填写**（须与实际使用的方案一致）
3. **合作各方信息填写不完整**（须完整填写所有合作单位）
4. **缺少法定代表人签字**（或签字人与备案不一致）

### 3.2 附件问题

1. **EC批件过期**（EC批件有效期限内，过期需更新）
2. **知情同意书缺少"遗传资源"相关知情选项**
3. **协议书缺少知识产权条款**（按实施细则第22条要求）
4. **授权委托书不规范**（须明确授权范围和期限）

### 3.3 时效问题

1. **EC批件出具日期在申请书提交日期之后**（正确顺序相反）
2. **审批通过后超过1年仍未启动试验**（需重新申请或说明）

## 四、科技部政务服务平台操作要点

### 4.1 账号注册

- 申请单位须先完成法人注册
- 注册需上传营业执照原件扫描件
- 审核周期约1-3个工作日

### 4.2 在线填报

- 登录 → 选择"人类遗传资源管理" → 选择申报类型
- 按系统引导填写表单
- 上传所有附件（PDF格式，单个文件≤20MB）
- 正式提交后无法修改（如需修改须撤回）

### 4.3 审批进度查询

- 提交后状态：已提交 → 已受理 → 审查中 → 审批通过/补正/退回
- 补正时限：收到补正通知后15个工作日内完成补正
- 逾期未补正视为撤回申请

## 五、变更申报指南

### 5.1 需审批的重大变更

- 增加样本采集量≥20%
- 新增或更换合作单位
- 试验方案关键要素修改（主要终点、入选标准等）
- 数据出境范围扩大
- 研究期限延长≥6个月

### 5.2 仅需备案的变更

- 非实质性文字修正
- 研究团队成员调整（非主要研究者）
- 样本保存地点变更（同一机构内）
- 不涉及人权资源变化的行政性变更

### 5.3 变更流程

```
发现变更需要 → 同步启动：
  ① EC提交伦理复审申请
  ② 科技部系统提交变更审批/备案
  ↓
伦理批件 → 补充至变更材料中
  ↓
科技部审查（变更审批20个工作日/变更备案即时）
  ↓
变更批准 → 方可实施新方案
```
