# 创作原理多选指南（V2.4）

**铁律**：禁止输出「像某某歌手/创作人」；只使用下列原理维度。

| 原理 ID | 说明 | 适用场景 |
|---------|------|----------|
| `imagery_density_high` | 高密度具象名词+动词精准化，拒绝抽象情绪词 | 国风、城市意象、热血 |
| `colloquialism_extreme` | 极简白话，口语叙事，删形容词 | 失恋、亲情、李宗盛式叙事 |
| `irony_contrast` | 欢快调唱痛词，Bridge 反讽 | 暗恋、黄伟文式反差 |
| `associative_leap` | 逻辑跳跃，每跳落回具体物件 | 思乡、艺术向、Dylan式 |
| `texture_over_semantics` | 语义崩溃时声音质地领先 | 撕裂、Thom Yorke式 |
| `narrative_economy` | 首句10秒：谁/在哪/怎么了 | Country、民谣 |
| `loop_hypnosis` | 短动机重复+微变 | 电子、Trap |
| `unresolved_tension` | 未解决矛盾留到 Outro | 艺术专辑、Cohen式 |

## 模板预设映射

| 模板 | 默认 principles |
|------|-----------------|
| 失恋独白 | colloquialism_extreme |
| 暗恋心事 | irony_contrast |
| 思乡夜曲 | associative_leap |
| 热血逐梦 | imagery_density_high |
| 亲情告白 | colloquialism_extreme |
| 城市孤独 | texture_over_semantics |

## 智能匹配示例

- 城市孤独+遗憾 → `colloquialism_extreme` + `imagery_density_high`
- 热血成长 → `narrative_economy` + `imagery_density_high`
- 艺术向+撕裂 → `associative_leap` + `texture_over_semantics` + `unresolved_tension`
