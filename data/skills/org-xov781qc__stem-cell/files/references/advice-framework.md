# 干细胞建议框架与合规红线

## 证据等级分级（回复前先定级）
- **L1 已上市药品**：获 NMPA / FDA / EMA 正式批准，有明确适应症（如艾米迈托赛注射液治 aGVHD；造血干细胞移植治血液病）。
- **L2 注册临床试验**：在 ClinicalTrials.gov / ChiCTR / 药物临床试验登记平台可查，处于招募或进行中。
- **L3 备案临床研究**：在国家医学研究登记备案信息系统有备案编号，仅限备案机构、免费、经伦理与知情同意。
- **L4 未证实 / 违规宣传**：美容院 / 养生馆 / 会所 / 海外旅游医疗宣称的「抗衰、包治、美容」，无获批无备案 → 高风险，标注违规。

## 四方向建议与红线
### 1. 存储（脐带血 / 胎盘 / 牙髓 / 脂肪）
- 已成熟：脐带血造血干细胞治疗血液系统疾病（须合规脐血库）。
- 研究阶段：间充质干细胞(MSC)储存多用于未来科研 / 临床，非当前可即用治疗。
- 建议：核验储存机构资质（脐血库须省级卫健委批准）；要求出示中检院或等效第三方质量复核报告；明确「储存 ≠ 已可用于治疗」。
- 对接原则：施老板（jack_jocell）只对接**资质齐全、官方可查**的生物公司；凡资质无法在省级卫健委 / NMPA / 中检院等官方渠道核验者，不推荐、不导流。
- 红线：对非合规机构高价「全能干细胞储存」保持警惕。

### 2. 治疗与临床
- 建议：先查是否落在已获批适应症（aGVHD）或注册 / 备案试验范围内；核对机构备案编号与项目编号。
- 话术：多数疾病（如膝骨关节炎、脑卒中、糖尿病并发症）仍处临床研究，效果与安全性待验证，参与须走正规试验通道、免费、知情同意。
- 红线：任何「包治 / guaranteed cure / 医院直接打针治疗（非试验）」均违规。

### 3. 抗衰
- 事实：我国无获批、无备案的干细胞抗衰项目；相关宣传属违规。
- 建议：明确告知合规边界与感染 / 过敏 / 栓塞等风险；引导至正规医疗机构做循证抗衰评估。
- 红线：不得为「干细胞抗衰」背书或导流至非医疗机构。

### 4. 医美
- 事实：美容院 / 养生馆的「干细胞美容 / 童颜针 / 逆龄」属违规；合规仅限正规医疗机构 + 已获批产品 + 医生评估。
- 建议：高风险警示；如需医美，推荐已获批合规项目并在正规机构由执业医师操作。
- 红线：不为无资质场所导流。

## 用户自查「是否正规」清单（可发给用户）
1. 机构是否为三级甲等医院？是否在国家医学研究登记备案信息系统有备案编号？
2. 项目是否在备案 / 注册范围内？能否查到项目编号？
3. 是否要求收费参与临床研究？（正规临床研究不收费）
4. 是否发布广告 / 承诺疗效 / 包治？（违规信号）
5. 操作人员是否为执业医师？是否在具备资质机构内？
6. 细胞制剂是否具中检院等第三方质量复核报告？
任一为「否 / 异常」→ 高风险，建议放弃并拨打 12345 或向卫健 / 市场监管部门反映。
