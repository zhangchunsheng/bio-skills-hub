# 腾讯健康-报告解读助手

专业、深度、精准的医疗报告与体检报告解读技能。适用于 WorkBuddy / CodeBuddy 等支持 Agent Skill 的客户端。

---

## 这个技能解决什么问题

市面上多数报告解读工具停留在「找箭头 → 讲人话 → 建议就医」，存在五个结构性缺陷：

1. **不做单位归一** —— 直接读报告上的箭头，跨实验室、跨单位制的报告必然误读
2. **只罗列指标不归纳问题** —— 用户看完 8 条指标记不住自己到底有什么问题
3. **不做关联分析** —— 指标逐项独立解释，丢失组合信号这一最高价值信息
4. **危急值建议放在末段** —— 模型逐项解读时容易被细节淹没，漏掉致命信号
5. **判定阈值没有出处** —— 用户无从核对，也无法拿去跟医生对质

本技能针对这五点做了重构，定位不是「报告翻译器」，而是**健康轨迹分析器**。

---

## 核心能力

| 能力 | 说明 |
|---|---|
| **单位归一后再判读** | LDL-C 的 mmol/L 与 mg/dL 差 38.6 倍，甘油三酯是 88.5 倍，肌酐是 88.4 倍。不换算等于瞎读 |
| **双基准判读** | 除报告参考区间外，同时比对「个体目标值」。LDL-C 3.2 报告上不带箭头，但高风险人群目标 <2.6 —— 这是漏诊重灾区 |
| **危急值前置硬中断** | 命中危急值即中断常规流程，首句直给就医指令，科普内容全部后置 |
| **问题层归纳** | 异常总结写「血脂异常（坏胆固醇未达标）」而非罗列「LDL-C 3.2 偏高」，指标降为证据。用户记不住指标名，记得住问题名 |
| **关联性分析与因果链** | 贫血四型鉴别、肝损三型（R 值分型）、甲功四象限、代谢综合征、肾功三联；并输出因果链指明共同上游 |
| **标注所属检查项目** | 每个指标说清属于「血脂四项」「肝功能」还是「甲功三项」，复查时说得出项目名；本次未查的建议加项单列 |
| **误读陷阱强制排查** | 对每个异常项反问「有没有非疾病解释」：采样溶血、生理时相、药物与保健品、个体差异 |
| **影像分级体系** | BI-RADS / TI-RADS / Lung-RADS / LI-RADS / 骨密度 T 值，给恶性概率区间而非模糊判断 |
| **定量风险计算** | eGFR、10 年 ASCVD 风险（China-PAR 为主 + ACC/AHA PCE 对照）、FIB-4、BMI 与腰高比、AIP、HOMA-IR |
| **纵向趋势分析** | 识别「全程在正常范围内但持续单向漂移」的隐性风险 |
| **术语双写** | 专业名词保留 + 人话解释并存，既看得懂又能拿去跟医生沟通 |
| **判定可追溯** | 报告附「参考指南」段，每个阈值都能追到具体指南条目，可拿去与医生核对 |
| **双轨输出** | 默认通俗版，显式指令可切专业版 |
| **交付分两步** | 默认在对话内出 Markdown，再询问是否导出 HTML/Word，不越权直接生成文件 |

## 输出结构

固定十一段，一二三级标题全部带序号，便于精确引用：

```
01 报告总结
02 处理优先级
03 异常指标详细解读
04 关联性分析
05 干扰因素排查
06 风险预测
07 趋势变化          ← 提供多份报告时才有
08 下一步
09 生活指导
10 参考指南
11 重要提醒
```

二级标题为 `3.1`、`3.2`，三级为 `3.1.1`。**全文不用 emoji** —— 导出 Word/PDF 或黑白打印时表现不稳定，跨平台渲染也不一致。

就诊建议分四档，每档给明确时间、科室与复查项目：

| 档位 | 时间窗 |
|---|---|
| 需立即就医 | 数小时内 |
| 两周内专科就诊 | 14 天 |
| 一至三个月复查 | 30~90 天 |
| 年度随访 | 12 个月 |

### 交付形态

| 形态 | 时机 |
|---|---|
| **Markdown**（默认） | 解读完成后直接在对话内输出，不询问 |
| **HTML** | 用户确认后生成。单个文件、零外部依赖，不联网也能打开，可打印带去门诊或转发家人 |
| **Word** | 用户确认后生成，便于归档与二次编辑 |

HTML 只有一个版本，不区分「自用」与「转发」—— 离线可开、锁定浅色、打印优化这些特性对自用场景也全是净收益。

## 安装方法

### 方式一：解压到用户级技能目录（推荐）

**macOS / Linux**
```bash
unzip medical-report-deep-reader.zip -d ~/.workbuddy/skills/
```

**Windows（PowerShell）**
```powershell
Expand-Archive medical-report-deep-reader.zip -DestinationPath "$env:USERPROFILE\.workbuddy\skills\"
```

解压后目录结构应为：
```
~/.workbuddy/skills/medical-report-deep-reader/
├── SKILL.md
├── references/
├── scripts/
└── templates/
```

### 方式二：项目级安装

若只想在某个项目中使用，解压到该项目的 `.workbuddy/skills/` 下即可。

### 安装后

重启客户端或新建会话即生效。上传报告后技能会自动触发，也可直接说「用腾讯健康报告解读助手」。

## 使用方法

### 基本用法

直接上传报告（图片 / PDF / 文本 / 截图均可）并说明诉求：

```
帮我看看这份体检报告
这个指标偏高要紧吗
需要复查吗，挂什么科
```

### 切换专业版

默认输出通俗版。需要含医学术语、鉴别诊断谱、指南推荐等级的版本时：

```
专业版
```

### 多份报告做趋势对比

同时提供多份报告并说明：

```
这是我近三年的体检报告，帮我看看变化趋势
```

这是本技能的核心能力之一 —— 能识别「每次都正常但持续恶化」的隐性风险。

### 单独使用计算工具

计算脚本可独立运行，不依赖客户端：

```bash
# 查看全部命令
python3 scripts/calc.py --help

# 肾功能
python3 scripts/calc.py egfr --cr 88 --age 45 --sex male

# 10 年心血管风险（China-PAR + PCE 双模型）
python3 scripts/calc.py ascvd --age 55 --sex male --sbp 135 --tc 5.6 \
    --hdl 1.1 --wc 92 --smoker 1 --diabetes 0 --north 1 --urban 1 --family 0

# 肝纤维化评分
python3 scripts/calc.py fib4 --age 45 --ast 40 --alt 62 --plt 180

# 体重与腰高比
python3 scripts/calc.py bmi --height 172 --weight 82 --wc 92 --sex male

# 血脂危险指数
python3 scripts/calc.py aip --tg 2.1 --hdl 1.1

# 胰岛素抵抗
python3 scripts/calc.py homa --glucose 5.8 --insulin 12.5

# 单位换算
python3 scripts/calc.py unit --item ldl --value 3.2 --to mgdl
```

### 查看完整样例

`examples/` 下有两份完整样例，直接打开即可了解输出形态：

| 文件 | 说明 |
|---|---|
| `examples/sample_report.md` | Markdown 交付形态（默认形态） |
| `examples/sample_report.html` | HTML 导出形态，11 段全实现，已通过全部 20 项校验 |

样例覆盖：危急边缘项（血钾偏高需排除溶血）、双基准漏诊项（LDL-C 区间内但未达个体目标）、
代谢综合征组合识别、三年趋势中的隐性风险（TSH 三次均正常但持续上升 90%）。

### 校验生成的报告

生成 HTML 后跑一遍合规校验：

```bash
python3 scripts/check_report.py 体检报告解读_2026-08-20.html
```

20 项自动检查：零外部依赖、零脚本、锁定浅色、表格全部可横滑、无开发痕迹、无身份信息、
章节序号连续性、目录锚点有效性、**表格列数一致性**、emoji 残留、档位代号泄漏、色块预算。

> 表格列数不齐这类问题肉眼看不出来但渲染会错位，尤其在加列后漏改某一行时 —— 必须靠脚本查。

### 生成趋势图

```bash
python3 scripts/make_trend_svg.py \
    --labels 2024-08,2025-08,2026-08 \
    --series "空腹血糖 mmol/L:6.0,6.7,7.4:#a32d2d" \
    --series "TSH mIU/L:2.1,3.0,4.0:#854f0b"
```

输出内联 SVG（约 4 KB），替代 Chart.js（外部 JS 约 200 KB）。
各指标单位不同无法共用 Y 轴，故绘制**相对首次检测的增幅百分比**，三条线可直接比较恶化速度。

## 数据来源

判读标准以中国指南为准，国际指南仅在无对应中国指南时采用并标注人群局限。

| 领域 | 主要依据 |
|---|---|
| 血脂 | 《中国血脂管理指南（2023年）》 |
| 心血管风险 | 《中国心血管病风险评估和管理指南（2019）》、China-PAR 原始研究（Circulation 2016） |
| 糖尿病 | 《中国 2 型糖尿病防治指南（2020年版）》 |
| 肥胖 | 《肥胖症诊疗指南（2024年版）》 |
| 检验参考区间 | 《全国临床检验操作规程》（第4版） |
| 危急值 | 国家卫健委相关规范、中国医院协会《临床危急值报告制度》 |
| 乳腺影像 | 中国抗癌协会《中国居民肿瘤防筛核心科普知识（2026）》、ACR BI-RADS 第5版 |
| 甲状腺影像 | C-TIRADS（中华医学会超声医学分会，2020） |
| 肾脏 | KDIGO CKD 指南、CKD-EPI 2021 方程 |

**关于 ASCVD 双模型**：以 China-PAR 为主要结论，ACC/AHA PCE 仅作参考对照。China-PAR 原始研究已证实 PCE 不适用于中国人群 —— 实测同一中国男性案例，PCE 给出 14.18%（高危）而 China-PAR 为 8.72%（中危），高估约 63%。PCE 系数已用官方标准算例校验（55 岁男性算例：本实现 5.38% vs 官方 5.3%）。

## 重要边界

- **本技能输出为健康信息解读，不是医疗诊断**，不替代医生面诊
- 不做：确诊疾病、开具处方、判定肿瘤良恶性、解读影像原始图像
- 病理诊断为金标准，不对病理结论做二次推测
- 不推荐具体药品、保健品、商业体检套餐或特定医院
- 健康数据**仅本地分析**，不调用任何外部报告解读接口
- 参考区间主要适用于 18~65 岁成人；儿童与孕产妇需按专用区间判读，技能会主动提示
- 危急值阈值各医院存在浮动，以报告出具医院标注为最终准据

## 常见问题

**Q：为什么报告上没标箭头的项目也被列为需要干预？**
A：报告参考区间是「大多数健康人的统计范围」，而个体目标值是「按你的风险水平定的目标」。例如已确诊冠心病者的 LDL-C 目标是 <1.8，远严于参考区间的 <3.4。这类项目最容易被漏掉，技能会单独标出。

**Q：为什么有些异常先让我排除干扰因素，而不是直接建议就医？**
A：很多「异常」是假象。抽血时血样破损会让血钾假性升高，前一天力量训练会让肌酸激酶升高数倍，非空腹采血会让甘油三酯虚高 30~50%。先排除这些能避免无谓恐慌与过度检查。但危急值命中时优先给就医建议，不会因此延迟。

**Q：能解读影像片子本身吗？**
A：不能。技能解读的是影像报告的文字结论（含分级），阅片需影像科医师。

**Q：计算脚本的结果可信吗？**
A：所有公式系数均来自官方指南或原始文献，PCE 已用官方标准算例校验通过。但计算结果仅供风险分层参考，不构成诊断。
