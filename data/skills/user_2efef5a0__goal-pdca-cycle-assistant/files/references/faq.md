# PDCA Skill 常见问题解答（FAQ）

> 按需查阅：高频 10 问，每条 ≤60 字。

## 1. 怎么开始 / 怎么结束？
开始：直接说目标（或用 `/goal-pdca-cycle-assistant`）。结束：在 A 阶段回复「已完成」，自动输出结案报告。

## 2. 中途可以暂停吗？怎么续？
可以。说「暂停存档」保存当前轮次。下次说「继续 PDCA」或「开启 PDCA 第 N 轮」即可接着跑。

## 3. 能同时跑多个目标吗？
**推荐一次一个**。多目标并行会让轮次计数器混乱，记忆负担大。建议一个攻坚完再开下一个。

## 4. 多少轮算正常？什么时候该换方法？
通常 2-5 轮达成。**3 轮仍无实质改善**就应换方法/拆目标/转交专业顾问，避免无限循环。

## 5. 强触发方式有哪些？
- `/goal-pdca-cycle-assistant`（最稳，任何上下文都生效）
- 对话开头加「请使用 PDCA Skill」

## 6. 和普通对话 / 其他 Skill 区别？
普通对话一次性回答；其他 Skill 单次任务。PDCA 是**多轮循环教练**，帮你把一个目标啃到底。

## 7. 数据怎么记？
建议用表格（xlsx）记录每轮 P/D/C/A。模板可让 Skill 帮你生成，含「状态/达成率」自动统计。

## 8. 失败怎么办？会一直循环吗？
不会。3 轮无改善会自动触发「换方法 / 拆目标 / 转交」提醒，不会死循环。

## 9. 怎么结案？结案报告包含什么？
A 阶段回「已完成」→ 教练立即按固定模板输出 4 部分：总览表 / 演进时间线 / 标准化清单（可勾选）/ 最终复盘一句。具体格式和样例见 `SKILL.md` 的「输出格式要求」与「结案报告示例」章节。

## 10. 触发词没响应怎么排查？
① 改用 `/goal-pdca-cycle-assistant` 强触发；② 开头加「请使用 PDCA Skill」；③ 检查是否落在「不适合」场景。
