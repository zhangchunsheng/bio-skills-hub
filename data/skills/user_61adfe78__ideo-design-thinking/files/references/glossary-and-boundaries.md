# 术语与全局边界

## 关键术语

| 术语 | 本专家采用的含义 | 必须区分 |
|---|---|---|
| 设计思维 | 以真实情境为证据，在需求性、可行性与延续性之间持续整合，用外化、试验、参与和实施降低创新不确定性的系统 | 不等于固定五步法、头脑风暴工具箱、艺术直觉或保证成功的算法 |
| 设计 | 专业设计师对物件、形式、界面或体验的具体创造实践 | 不等于设计思维的全部；末端形式美化不能替代上游问题重构 |
| 以人为本 | 从人的真实生活、行为、意义和参与出发 | 不等于“用户说什么就做什么”，更不等于伦理正当或公共利益 |
| 需要 | 可能潜伏在适应、变通、遗漏和情境中的未满足状态 | 不等于用户明确提出的产品要求 |
| 需求 | 需要被转成愿意采用且系统能提供的形式 | 不等于营销制造的短期渴求 |
| 需求性 | 方案对人是否具有功能、认知、情感和情境意义 | 不等于市场热度、销量、伦理正当性 |
| 可行性 | 在真实条件下实现、制造、交付、维护并可靠运行的可能性 | 不等于技术新颖或能做出样品 |
| 延续性 | 商业或运营体系能否长期获得资源、支付、维护与责任承接 | 不等于短期盈利，也不专指环境可持续 |
| 灵感/构思/实施 | 可往返的三个重叠创新空间：发现方向、生成与测试想法、进入组织和现场 | 不是一次走完、不再返回的线性阶段 |
| 项目 | 有目标、期限、约束和学习节点，把想法转为现实的行动容器 | 不等于无终点的问题讨论或不可修改计划 |
| 简报 | 可指导探索、衡量进展并容许证据修订的初始假设与约束容器 | 不等于预写答案的规格书，也不等于空泛愿景 |
| 观察 | 在自然情境记录做/不做、说/不说、绕过/补救及关系互动 | 不等于只做问卷、焦点小组或无目的观看 |
| 洞察 | 从证据中综合出的、能改变问题理解并生成机会的模式 | 不等于单个事实、用户原话或统计结果 |
| 极端用户 | 沿关键维度处于两端、能放大隐藏机制的人群 | 不等于目标市场代表样本或总体结论 |
| 发散/汇聚 | 扩大与减少解释或方案选项 | 区别于分析/综合；截止日触发汇聚但不证明正确 |
| 分析/综合 | 分解事实与结构；再从碎片构成可行动意义 | 不等于汇聚/发散；综合不是资料摘要或故事美化 |
| 模型/原型 | 足以探索、评估和推进想法的外部表征，可为物件、场景、角色扮演、服务或组织试验 | 不等于高仿真终版、最小可售产品或方案证明 |
| 恰好足够 | 只投入获得下一条有用反馈所需的最低时间、精度与成本 | 不等于粗制滥造，也不表示始终保持低保真 |
| 体验旅程 | 以人的时间线记录行为、等待、触点和情绪 | 不等于内部部门流程图 |
| 蓝图 | 把关键时刻连接到前台、后台、能力、成本和责任的实施模型 | 不等于僵硬服务脚本或工程架构替代品 |
| 参与/共创 | 相关人对定义、生成、评估、测试或实施拥有实质影响 | 不等于调查、众包、投票或人人决定一切 |
| 行为嫁接 | 把最小新动作嵌入既有触发和流程，并闭合即时反馈 | 不等于信息宣传、强迫或操控性助推 |
| 组织承载 | 让真实项目、所有权、领导、资源、激励、教练、回岗和扩散形成制度链 | 不等于工作坊、创意空间或创新飞地 |
| 创新 | 被真实采用、可靠交付并产生可验证结果的好想法 | 不等于创意、发明、概念获批或获奖 |

## 全局证据边界

1. **书中证据的性质**：案例以 IDEO 或合作方自述为主，成功故事多，常见过程指标和结果指标，严格对照、长期追踪与负面结果少。它们适合说明动作链和生成可迁移假设，不足以证明设计思维普遍优于其他方法。
2. **禁止不可证伪归因**：不能用“成功证明方法有效、失败证明方法没做完整”的循环。每个新项目需预先定义关键假设、基线、结果指标、替代解释和停止条件。
3. **四级证据不得跳级**：局部可用 → 组织可复制 → 跨地区可扩展 → 系统结果改善。每一级都需新证据，不能从单点试点直接推导规模化。
4. **发现与估计分离**：定性观察、极端用户和类比适合发现机制；市场比例、发生率、风险率、因果效应和长期持续性须用代表性样本、定量方法或领域实验另行验证。
5. **证据账本**：始终区分 B 书中证据、P 当前项目事实、I 专家推断、U 未知。建议须附证伪点，不把类比写成事实。

## 伦理边界：人本不等于正当

- 需求性只说明某些人觉得有意义，不证明对所有受影响者公平、无害或可接受。
- 额外检查：未直接使用但受影响的人、知情参与、退出权、隐私、操控、歧视、可访问性、分配效果、长期伤害、代际与生态影响。
- 共创不能把医疗、工程、法律、安全或伦理责任转嫁给参与者；参与人数与投票结果不是质量门。
- 行为设计不得强化成瘾、歧视、有害消费、不可持续习惯，或通过暗黑模式削弱自主性。
- 原型测试须有权限和适当告知；低成本不等于可以把风险转移给参与者。

## 权力与组织边界

书中对领导、预算、奖励和部门壁垒有认识，但对正式权力和损失分配处理不足。组织与共创任务必须补充：

- 谁有权定义“人的需要”、批准、否决、解释证据和分配资源；
- 谁承担试验失败、工作增加、职业风险、隐私风险与长期维护；
- 谁拥有成果、数据和收益，地方参与者是否有真实决策权；
- 冲突不可调和时的升级、否决、补偿和退出机制；
- 一线裁量的不可变质量原则、可变动作、撤回与扩大条件。

“目标一致”“共同创造”“创新文化”不能掩盖利益冲突、权力不对称和资源承诺缺失。

## 商业与运营边界

三约束中的延续性在书中操作化弱于观察和原型，必须补强：

- 付款者、受益者、使用者、渠道、维护者和责任主体可能不是同一方；
- 早期验证支付意愿、收入结构、单位经济、总拥有成本、渠道成本、维护、现金流和敏感性；
- 社会或公益项目也须说明持续资源、交付和维护路径，但救急任务可明确采用非商业目标；
- 销量、融资、管理层同意或试点补贴不是长期延续性的充分证据；
- 若多轮试点后成本、支付、渠道或责任仍不闭环，停止扩张并重做模式。

## 专项验证边界

需求性—可行性—延续性是整合框架，不替代：

- 工程可靠性、结构安全、信息安全、隐私与容量验证；
- 财务模型、审计、税务、采购和单位经济分析；
- 法律、监管、劳动、知识产权与合规审查；
- 临床有效性、医疗安全、诊断与伦理委员会审查；
- 无障碍标准、科学因果研究、统计市场测量；
- 环境生命周期评价、碳核算、供应链可追溯和气候风险分析。

高风险领域的设计原型只能帮助形成假设、流程和体验证据，不能降低专业验证门槛。

## 规模化与系统边界

- 规模会改变参与者构成、协调成本、容量、文化、基础设施、网络效应和外部性；原有机制可能失效。
- 试点依赖特殊团队、低流量、顾问驻场或补贴时，先验证可复制条件。
- 区分不可变质量原则与地方可适配动作；不要把蓝图写成统一脚本。
- 扩张应分批，监测效果衰减、副作用和责任断裂；出现显著衰减即暂停、纠偏或限定适用范围。
- 商业成功不等于系统成功。淘汰审计中“全生命周期审查”未作为独立能力通过包内筛选，但生态、材料、处置和反弹效应仍是强制边界检查，必要时调用专项方法。

## 文化与地方知识

- 短期沉浸和极端样本可能产生洞察，也可能由外来团队压缩、浪漫化或误读文化。
- 当地用户、实施者与运营者应参与问题定义、解释、取舍、收益和长期运营，而非只在末期验收。
- “符合地方情境”不能成为降低医疗、安全、人权或可靠性底线的理由。
- 明确可迁移机制与不可迁移差异；任何跨地区复制都重新验证语言、支付、基础设施、维护、规范与权力关系。

## 2009 年语境修正

本书原作发表于 2009 年，具体平台、远程协作与开放参与判断不可原样搬到当前环境：

1. **平台与数据权力**：补查平台集中化、数据所有权、隐私、算法中介、推荐偏差、自动化决策和生成式 AI 的影响。
2. **远程协作**：书中对邮件和视频会议局限的判断受当时工具能力限制；当下按任务与证据选择同步、异步、远程或同地协作，不把同室协作当普遍必要条件。
3. **开放参与**：众包、开源和社交平台并不天然民主或高质量；检查治理、劳动、激励、审核、代表性和平台规则。
4. **环境验证**：把碳核算、供应链可追溯、电子废弃物、循环设计和气候适应纳入专项审查。
5. **数字/AI 原型**：低代码和生成式工具降低制作成本，但高仿真输出可能放大“已经完成”的错觉；仍按唯一学习问题和最低必要保真度控制投入。

## 未独立通过的方法如何处理

以下主题在书中重要，但未满足独立能力的全部验证门，不得作为额外“筛选通过能力”宣传：三空间回跳、功能—认知—情感透镜、T 形全流程小团队、故事化资源动员、创新组合与适应性预算、系统目标对齐、全生命周期审查、社会创新运营生态。

其有效部分可作为辅助规则：

- 三空间回跳由简报修订、双循环和原型证伪触发；
- 功能/认知/情感作为行为观察和旅程记录维度；
- T 形协作作为执行条件，不宣称独立方法已通过筛选；
- 证据化故事归入综合或原型，不以感染力代替证据；
- 生命周期、权力和系统治理作为强制边界，必要时转专项专家；
- 社会运营中的支付、维护与地方参与分别归入三约束和共创。
