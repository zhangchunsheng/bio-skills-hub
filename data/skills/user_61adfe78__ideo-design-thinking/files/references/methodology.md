# 十种筛选通过的方法能力：紧凑执行卡

## 使用约定

- 先识别用户已有信息，最多补问 3 个会改变路线、实验或风险判断的高信息增益问题；能先做就先做。
- 按症状选择 1–4 项能力，不机械全跑。每项建议必须写明假设、证据、证伪点、下一步。
- 证据分为：B 书中证据、P 当前项目事实、I 专家推断、U 未知。案例支持机制可执行与可迁移，不证明普遍因果效果。

## 01 把任务改写成可检验简报

**触发**：抽象愿景、功能清单、采购规格、预设产品；新证据动摇初始问题定义。

**输入**：目标受益者与情境、期望改变、现有方案、硬约束、软约束、期限、成功信号、关键未知。

**步骤**：
1. 写成“帮助谁在什么情境中发生什么可观察改变”。
2. 分开不可违反的硬约束、可调整的软约束、待验证假设；不得预设唯一解法。
3. 加入期限、成功标尺和第一轮可执行范围。
4. 做宽窄测试：任何方案都算相关则过宽；只剩一个答案则过窄。
5. 设证据评审点；新证据可修改假设和软约束，但不得让目标无限漂移。
6. 关键前提被推翻时重写，并保留修改记录。

**输出**：一页简报；约束/假设表；成功标尺；修改日志；首轮学习问题。

**停止/转向**：宽窄测试通过且首轮可执行则转原型或研究；关键前提被证伪则重写；法规执行、精确复制、成熟工艺、紧急处置等答案已确定时停止使用本能力。

**与相邻能力区分**：本项定义“探索什么”；02 判断候选方案能否整体成立；06 用最低成本模型检验简报中的假设。

## 02 动态整合需求性、可行性与延续性

**触发**：仅凭“用户喜欢”“技术能做”或“财务可行”推进；出现新方案、模型反馈或扩张决策。

**输入**：候选方案；人的采用与意义证据；实现、交付、维护证据；付款、成本、渠道、运营与资源证据。

**步骤**：
1. 分别写出需求性、可行性、延续性假设和证据缺口。
2. 标出冲突和当前主导约束，不做固定权重平均，也不允许三个部门分别签字后机械拼接。
3. 为最高风险假设设计独立实验。
4. 每轮新证据后重画三者关系；一维变化必须触发另外两维复核。
5. 任一关键维失败，调整方案、模式或简报。
6. 三者构成可运行整体后才扩大。

**输出**：三约束假设图；冲突表；证据门槛；实验与规模化决定。

**停止/转向**：任一关键维无证据不得规模化；关键维证伪则修改或停止；科研、艺术、救急项目可不立即商业自持，但须说明资源与运营持续路径。

**与相邻能力区分**：本项评审单个方案的整体成立性；01 定义探索边界；06 产生验证证据；不能替代工程、财务、伦理、法律或市场专项分析。

## 03 从行为证据推导潜在需求

**触发**：访谈答案熟悉；声明偏好与实际采用矛盾；现场出现绕过、补救、遗漏、焦虑、放弃或私人替代流程。

**输入**：自然情境记录；做/不做、说/不说、绕过/补救；现有流程；参与者解释；必要的范围数据。

**步骤**：
1. 在目标行为真实发生的环境观察。
2. 并列记录行为、遗漏、变通、等待、情绪与关系，不先把偏离流程判为用户错误。
3. 解释行为在局部处境中的合理性：它解决了什么阻碍？
4. 形成“行为→阻碍→需要→机会”的假设链。
5. 用访谈补充原因，用复访或模型验证；声明偏好只能补充，不能单独关闭判断。
6. 用定量数据估计范围，但不让其替代情境解释；单个轶事不得升级为总体结论。

**输出**：行为证据表；潜在需求假设；替代解释；验证计划。

**停止/转向**：行为机制在复访/模型中不复现则撤回或改写；需估算市场规模、发生率或因果效应时转代表性研究；观察可能受文化与权力偏差影响时转 08 共创复核。

**与相邻能力区分**：本项规定如何从行为推理；04 决定观察谁与哪些异域场景；07 沿完整时间结构定位行为；09 设计重复行为改变。

## 04 用极端用户与类比场景放大机制

**触发**：主流用户把困难正常化；结果同质；行业惯例遮蔽机制；需要跳出原参照系。

**输入**：待放大的矛盾；关键维度；两端极端人群候选；结构相似的类比场景；主流验证对象。

**步骤**：
1. 定义要放大的矛盾及关键维度。
2. 沿该维度两端选择极端样本，并写明选择理由。
3. 选择至少一个表面不同、结构相似的类比场景。
4. 明确“可迁移机制/不可迁移差异”，只提取机制，不复制表面形式。
5. 把机制转成多个候选模型。
6. 回到主流目标人群、真实环境和代表性更强样本验证。

**输出**：极端取样理由；类比结构图；可迁移/不可迁移清单；主流验证计划。

**停止/转向**：机制回到主流场景后增加摩擦或无改善则撤回；需估算平均偏好、市场比例或风险率时停止外推；医疗、安全等高风险领域转正式代表性验证。

**与相邻能力区分**：本项是启发性取样策略；03 是行为证据解释规则；06 检验迁移机制。

## 05 运行发散—汇聚与分析—综合双循环

**触发**：选项过少或过多；资料堆积无洞察；团队混淆拆解、意义构成、增加选项和做选择。

**输入**：简报；研究事实；反常证据；候选解释或方案；约束；截止日；选择标准。

**步骤**：
1. 明确本轮要发散的是事实、解释还是方案。
2. 分析变量、流程、事实和约束。
3. 综合模式、矛盾和“意味着什么”，保留反常证据；综合叙事必须可追溯。
4. 把洞察转成机会或待验证假设，再围绕它发散方案。
5. 到预设截止日依据简报、三约束和证据汇聚；截止日只是选择触发器，不是正确性证据。
6. 记录淘汰、组合、继续测试理由；可围绕更聚焦的问题再次发散。

**输出**：证据—模式—机会链；候选集；选择标准；淘汰/组合日志；下一轮问题。

**停止/转向**：新增选项不再改变关键假设或排序时汇聚；连续两轮无新有效证据时选择、试验或终止；核心模式不复现则撤回综合；唯一合规答案或事故响应不人为发散。

**与相邻能力区分**：本项管理选项数量与意义结构；06 通过模型产生新证据；01 校准问题边界。

## 06 制作“恰好足够”的情境原型

**触发**：停留在文字争论；关键假设未验证却准备昂贵开发；价值依赖真实行为、社会互动或环境限制。

**输入**：本轮唯一关键假设；可推翻它的观察；目标参与者与情境；风险/权限；媒介选项；预算和时限。

**步骤**：
1. 写明唯一学习问题、当前信念和证伪观察。
2. 选择足以表达该问题的最低成本媒介；模型是提问装置，不是准成品或方案证明。
3. 尽早并行制作多个可丢弃版本。
4. 先完成必要安全、伦理、权限与隐私检查，再让真实参与者在目标情境使用；内部演示不是情境依赖假设的充分证据。
5. 记录行为、适应、副作用和意外用途。
6. 一旦获得下一条有用反馈，立即停止打磨当前版本；风险和阶段上升时才提高保真度。

**输出**：原型假设卡；媒介与最低保真理由；测试脚本；行为记录；放弃/组合/修改/升级决定。

**停止/转向**：无法说明模型会推翻什么则停止制作；信息足够即停止美化；关键假设失败则放弃或重构；人工低成本模型已稳定解决问题时，复杂系统的必要性也可能被证伪。

**与相邻能力区分**：本项选择验证媒介、现场和精度；05 管理候选与意义；07 定义要沿哪些时间点和前后台关系建模。低保真不能替代医疗、结构、安全、隐私和合规验证。

## 07 沿完整旅程定位关键时刻并连接蓝图

**触发**：局部功能正常但整体体验差；价值跨时段、触点、角色或后台能力形成；组织按部门边界配置体验投资。

**输入**：目标人物；真实起止点；行为/等待/交接/情绪证据；接触点；前后台角色；成本、容量和责任。

**步骤**：
1. 以用户时间边界而非部门边界定义真实起点和结束点。
2. 按时间记录行为、等待、交接、接触点、功能/认知/情绪变化。
3. 用现场跟随验证，不用总部流程图替代。
4. 区分全部触点与少数经观察证实、决定信任/焦虑/完成/放弃的关键时刻。
5. 在蓝图中连接前台行为、后台能力、成本、容量、商业机会和责任主体。
6. 用场景或现场试点验证，再重排资源。

**输出**：证据化旅程图；关键时刻清单；前后台蓝图；责任与投资优先级；验证计划。

**停止/转向**：端到端证据证明原单点确为主因时可返回单点；整体指标无改善则停止美化局部并重界系统；纯后台且不改变用户结果的局部任务可单独优化。

**与相邻能力区分**：本项识别完整体验结构；06 决定用什么模型验证；09 只在重复行为改变时设计触发与反馈。旅程图不替代技术架构、容量、成本或因果分析。

## 08 让用户与实施者共创，同时保留质量门

**触发**：专业团队无法掌握全部地方知识；一线最终交付；文化和多方互动决定采用；用户仅在访谈或验收出现。

**输入**：受影响者、实施者、领域专家、决策者与责任人；权力与失败成本；开放决策；不可下放边界；质量标准。

**步骤**：
1. 绘制受影响者、实施者、专家、责任人，以及谁有权定义问题、承担失败、拥有成果。
2. 明确参与发生在定义、生成、评估、建模或改进的哪些环节。
3. 区分开放决策与不可下放的专业、安全、法律和伦理边界。
4. 用低门槛媒介让非专业者能表达、制作和测试，给予实质影响而非只征求意见。
5. 专业人员综合，并记录采纳、修改、拒绝及理由。
6. 以安全、可靠性、可用性、效果和运行结果验证，不以投票或参与人数验证。

**输出**：参与者/权力图；决策权矩阵；共创计划；采纳日志；质量门和责任归属。

**停止/转向**：共同设计版本未过独立质量门则返工；参与增加而核心指标下降则暂停扩张；医疗诊断、工程安全、法律判断等最终责任不得转嫁；目标不可调和时升级治理，不用“共创”掩盖冲突。

**与相邻能力区分**：03 把人作为行为证据来源；本项赋予生成、评估或实施中的实质权力；10 改造组织长期承载机制。

## 09 把新行为嫁接到旧习惯并闭合反馈

**触发**：用户口头认同却不行动；回报遥远；新流程摩擦高；已有稳定触发点或补偿行为。

**输入**：目标行为；行为前后稳定习惯；触发点；开始/重复/恢复摩擦；个人目标；结构约束；真实行为基线。

**步骤**：
1. 观察目标行为前后的稳定习惯与触发点。
2. 识别最小新动作，以及开始、重复和中断后恢复的摩擦。
3. 把新动作嵌入原流程，不另建平行流程。
4. 提供与个人目标相关、即时且可理解的反馈。
5. 在真实现场测试并跟踪发生、持续、恢复和副作用，不以态度问卷代替行为。
6. 未发生时定位触发、能力、激励或制度阻碍，并重构。

**输出**：行为闭环图；摩擦表；嵌入方案；反馈机制；真实行为指标；结构性障碍清单。

**停止/转向**：行为不发生或不持续时，不以认同度自我安慰；提示无效且根因是权限、无可行选项或制度冲突时转结构干预；不强化有害、歧视、成瘾或不可持续习惯。

**与相邻能力区分**：07 描述全程体验；本项专门改变重复行为；03 发现行为机制；严重成瘾、精神健康和制度约束问题需临床、政策或结构性专业介入。

## 10 把创新能力嵌入组织承载系统

**触发**：创新实验室与业务隔离；培训回岗无应用空间；项目无长期预算、评价、实施所有权或内部扩散机制。

**输入**：真实项目；业务所有者；参与和实施角色；领导与资源；采购/合规/绩效流程；回岗采用率；扩散证据。

**步骤**：
1. 选择有业务所有者、结果指标和实施责任的真实示范项目。
2. 让跨领域与一线成员共同完成研究、模型和实施。
3. 把成功实践者转为内部教练和可复用能力。
4. 补齐领导、预算、空间、时间、失败学习许可和回岗任务。
5. 调整评价、奖励、采购、合规和跨部门机制，显式处理职业风险与失败成本。
6. 同时测量体验与业务结果，设计回归、扩散、再验证和退出路径。

**输出**：组织承载诊断；责任/资源/激励图；90 天回岗计划；内部教练机制；结果和扩散门。

**停止/转向**：无业务所有者、实施预算或回归路径时不扩大培训；承载机制补齐后项目仍因机会无价值而失败，则停止文化项目并淘汰项目；单次工作坊、空间装饰或飞地不得宣称组织变革完成。

**与相邻能力区分**：08 设计单个项目的参与结构；本项建立长期制度承载。工作坊可启蒙，但不是充分条件；承载机制可嵌入业务，不强制设独立实验室。
