# 岭南药学科普初审规则详解（2023.11 更新）

本文件对 10 条初审规则逐条展开，供审核时加载参考。每条包含：规则原文、判断标准、岭南特别处理、边界情况、处理方式。

---

## 规则 ① 思想价值观应符合党的要求

**性质**：一票否决

**判断标准**：
- 内容立场符合党和国家的方针政策
- 弘扬社会主义核心价值观，传播正能量
- 不违背党的基本路线、方针政策
- 涉及中医药内容时，体现"守正创新"导向

**边界情况**：
- 介绍中药与传统医学须客观，不贬损、不神化
- 涉及中外医药对比须实事求是，不盲目崇外或贬外
- 涉及健康公平、合理用药等议题须符合国家医药卫生政策导向

**处理方式**：发现违背党的要求的表述 → 判 ❌ → 不录用

## 规则 ② 文章应无错别字

**性质**：可修正（退修项）

**判断标准**：
- 无错别字、多字、漏字
- 药品名称书写规范（通用名优先，注意易混淆药名）
- 医学术语使用准确
- 标点符号规范

**常见问题**：
- 药名错字：如"阿莫西林"误写"阿莫西琳"、"甲氨蝶呤"误写"甲氨喋呤"
- 同音错字：如"辨证"误写"辩证"、"综合征"误写"综合症"
- 量词错误：如"粒"与"片"混用
- 岭南药材名错字：如"广藿香"误写"广霍香"、"化橘红"误写"化桔红"

**处理方式**：
- 偶发错别字（1-3 处）→ 判 ⚠️ → 退修，列出所有错别字及位置
- 错别字较多（影响阅读理解）→ 判 ⚠️ → 退修，建议作者通篇校对
- 错别字导致医学含义错误（如药名、剂量、用法写错）→ 判 ❌ → 退修并重点标注风险

---

## 规则 ③ 图片应符合平台要求（主要不侵犯人物肖像权）

**性质**：可修正（退修项）

**判断标准**：
- 图片不侵犯他人肖像权（未获授权的人物正面照不可用）
- 图片不侵犯版权（注明来源或使用授权图片）
- 图片内容与文章主题相关，不夸大、不误导
- 医学图片（如患处照片）注意隐私保护，避免可识别个人信息

**视频审核**：审脚本中的画面描述，核查是否涉及人物肖像

**边界情况**：
- 使用公开人物的新闻照片须注明来源
- 患处照片须脱敏处理（遮挡面部、去除可识别特征）
- 网络配图须确认版权许可

**处理方式**：
- 图片涉嫌侵权 → 判 ⚠️ → 退修，要求替换或补充授权证明
- 无法确认图片来源 → 判 ⚠️ → 退修，要求作者提供图片来源与授权说明

## 规则 ④ 无亮点如写得如说明书一样的科普不录用

**性质**：判断项（不录用项）

**判断标准**：
- 科普应有独到视角、生动表达或实用价值，非单纯罗列药品说明书信息
- "说明书式"特征：通篇照搬适应症、用法用量、不良反应、禁忌等说明书内容，缺乏解读与转化
- 有亮点的表现：结合临床案例、生活场景、通俗类比、互动问答、常见误区辨析等

### 岭南特别处理

**强制判断文章是否承载以下岭南特色亮点之一，否则等同说明书式退稿：**

- **道地药材**：岭南道地药材（如广陈皮、广藿香、砂仁、巴戟天、化橘红、高良姜等）的产地、品质、鉴别、道地性知识
- **凉茶文化**：岭南凉茶文化（二十四味、夏桑菊、五花茶等）的组方思路、适用人群、饮用禁忌
- **炮制技艺**：岭南中药炮制传统技艺（如广陈皮陈化、熟地九蒸九晒、巴戟天盐制等）
- **民间故事/民俗**：与岭南用药相关的民间故事、民俗习惯、地名由来等文化内容
- **岭南名医/流派**：岭南医学流派、名医用药经验与学术思想

**判断要点**：
- 文章为纯药品说明书式内容且不承载上述任何岭南特色亮点 → 判 ❌ → 不录用
- 文章承载岭南亮点但部分段落偏说明书式 → 判 ⚠️ → 退修，建议扩充岭南特色解读

**边界情况**：
- 介绍药品基本信息本身不违规，关键看是否有"翻译"与"增值"——把专业信息转化为公众易懂、可用的内容
- 单纯罗列知识点但表达生动、结构清晰，可视情况通过

**处理方式**：
- 通篇为说明书式内容、无岭南亮点、无解读增值 → 判 ❌ → 不录用
- 部分段落偏说明书式但整体有价值 → 判 ⚠️ → 退修，建议增加案例或通俗解读

## 规则 ⑤ 大篇幅介绍疾病诊断的不录用

**性质**：判断项（不录用项）

**判断标准**：
- 科普重点应在药学知识（用药、合理用药、药品安全等），而非疾病诊断
- "大篇幅诊断"特征：诊断标准、鉴别诊断、检查指标解读等占主导，药学内容被弱化
- 岭南药学平台的定位是药学科普，疾病诊断内容应服务于用药知识，而非本末倒置

**边界情况**：
- 为讲清用药背景而简要介绍疾病是合理的，但篇幅须适度
- 介绍症状以引出"何时就医 / 何时不建议自行用药"是合理的
- 诊断内容与用药紧密相关（如某检测指标指导用药调整）可酌情保留

**处理方式**：
- 疾病诊断内容占比过大、药学科普被弱化 → 判 ❌ → 不录用
- 诊断内容偏多但有药学关联 → 判 ⚠️ → 退修，建议压缩诊断部分、扩充药学内容

## 规则 ⑥ 内容应有明确观点且具备原创性

**性质**：一票否决

**判断标准**：
- 文章须有明确观点或核心信息，非无主题的信息堆砌
- 须为原创，非已发表文章、非抄袭文章

### 岭南特别处理：内置查重步骤

**查重须按以下步骤执行，先网络检索再判定：**

1. **提取关键词**：从标题和正文中提取核心关键词（如药名、方名、主题词）
2. **搜索标题**：将文章完整标题放入 WebSearch 搜索，查看是否有同名 / 高度相似文章
3. **搜索代表性段落**：抽取 2-3 段代表性文字（开头段、核心论述段、结尾段），分别搜索
4. **记录搜索关键词**：在报告中记录每次搜索使用的关键词
5. **雷同对比**：若发现相似文章，逐句对比，标注雷同段落与雷同程度
6. **判定标准**：
   - 连续大段文字（50 字以上）一致 → 抄袭
   - 结构、表述高度雷同但文字微调 → 疑似抄袭，标注"建议人工复核"
   - 仅引用公开知识、指南原文（已标注来源）→ 合理引用

**边界情况**：
- 引用指南 / 共识 / 论文内容并标注来源属合理引用，非抄袭
- 对公开知识的合理表述重组属原创
- 自媒体平台已发布的自己的文章，若提交至本平台仍属"已发表"，不录用

**处理方式**：
- 发现抄袭或已发表 → 判 ❌ → 不录用，附搜索关键词、雷同对比与相似来源链接
- 原创但观点不明确 → 判 ⚠️ → 退修，建议提炼核心观点
- 经搜索确认原创且观点明确 → 判 ✅

## 规则 ⑦ 涉及的结论、数据应该标注来源

**性质**：可修正（退修项）

**判断标准**：
- 文中涉及的具体数据、结论、推荐均须标注来源
- 文章结尾处须标注参考文献，格式规范
- 非权威来源（个人博客、未经验证的自媒体、商业软文）不作为合格依据

### 岭南特别处理：依据层级与参考文献格式

**岭南药学依据层级（从高到低）：**

1. 《中国药典》（最新版）
2. 地方中药材标准：如《广东省中药材标准》《广西壮族自治区中药材标准》等
3. 国家 / 行业共识、指南（如中华医学会、中国药学会发布的共识 / 指南）
4. 学术论文（优先核心期刊、SCI）

> 岭南道地药材相关结论，优先引用《中国药典》及《广东省中药材标准》等地方标准。

**参考文献格式（文末）：**

- 期刊论文：作者. 题名[J]. 刊名, 年, 卷(期): 起止页.
- 标准 / 药典：国家药典委员会. 中华人民共和国药典[S]. 版次. 北京: 中国医药科技出版社, 年.
- 地方标准：XX 省 / 自治区药品监督管理局. XX 中药材标准[S]. 版次. 出版地: 出版社, 年.
- 指南 / 共识：作者 / 学会名. 标题[J]. 刊名, 年, 卷(期): 起止页.
- 药品说明书：XX 药品说明书. 生产企业, 修订日期.

**边界情况**：
- 常识性医学知识可不标注来源，但具体数据（如有效率、发生率）必须标注
- 引用药品说明书内容须注明"据 XX 药品说明书"
- 引用网络科普须溯源至原始指南 / 论文

**处理方式**：
- 数据 / 结论缺来源标注 → 判 ⚠️ → 退修，逐条列出需补来源的结论
- 文末无参考文献 → 判 ⚠️ → 退修，要求补充
- 来源不权威（仅引用自媒体 / 商业软文）→ 判 ⚠️ → 退修，建议替换为药典 / 地方标准 / 指南 / 论文
- 参考文献格式不规范 → 判 ⚠️ → 退修，按上述格式修正

## 规则 ⑧ 涉及国家重点保护动植物的不录用

**性质**：一票否决

**判断标准**：
- 文章不得涉及国家重点保护野生动植物（含入药部位）
- 依据《国家重点保护野生动物名录》《国家重点保护野生植物名录》
- 介绍含有保护动植物成分的传统方剂 / 偏方同样不录用

### 岭南特别处理：高频雷区清单与联网核验

**岭南高频雷区清单（须对照核查）：**

以下物种在岭南药学科普中常见出现，多为国家重点保护物种，涉及即不录用：

| 物种 | 保护情况 | 常见出现场景 |
|------|----------|--------------|
| 土沉香（沉香） | 国家二级保护野生植物 | 理气止痛、安神方剂 |
| 金毛狗脊 | 国家二级保护野生植物 | 补肝肾、强筋骨 |
| 石斛属（金钗石斛、铁皮石斛等） | 国家一级 / 二级保护野生植物 | 滋阴清热 |
| 穿山甲 | 国家一级保护野生动物 | 通经下乳（鳞甲入药） |
| 蛤蚧（大壁虎） | 国家二级保护野生动物 | 补肺益肾、纳气平喘 |
| 犀角 | 国际全面禁止贸易 | 清热凉血（已禁用） |
| 虎骨 | 国家一级保护野生动物 | 祛风通络（已禁用） |
| 熊胆 | 国家二级保护野生动物 | 清热平肝 |
| 羚羊角 | 国家一级保护野生动物 | 平肝息风 |
| 野生人参 | 国家一级保护野生植物 | 大补元气 |
| 野生天麻 | 国家二级保护野生植物 | 息风止痉 |

**联网核验要求：**
- 上述清单为常见雷区，但保护名录会更新，须联网搜索《国家重点保护野生动物名录》《国家重点保护野生植物名录》最新版本核验
- 对文中出现的每一个动植物，若不确定其保护等级，须联网核验后再下结论
- 不鼓励采挖野生保护物种，即便文章主题为"识别野生药材"，若导向为采挖利用而非保护，同样不录用

**人工栽培 / 养殖物种处理：**
- 人工栽培 / 养殖且合法来源的物种（如栽培铁皮石斛、人工养殖蛤蚧）须在文中明确说明"人工"字样
- 未说明来源或暗示野生的 → 判 ❌

**边界情况**：
- 人工养殖 / 栽培且合法来源的物种须明确说明"人工"字样，否则不予通过
- 文章以"保护野生动物、拒绝非法药用"为主题的科普，内容正面、倡导保护，可酌情通过，但须导向明确

**处理方式**：
- 涉及国家重点保护动植物（入药 / 使用 / 介绍）→ 判 ❌ → 不录用
- 涉及但未说明人工来源 → 判 ❌ → 不录用或退修要求明确来源证明
- 以保护为主题的正面科普 → 视导向判 ✅ 或 ⚠️

**提示**：动植物保护名录专业性强，存疑时标注"建议人工复核物种保护等级"。

## 规则 ⑨ 涉嫌药品、保健品宣传的科普不录用

**性质**：一票否决

**判断标准**：
- 不得对单一药品进行介绍式宣传（通篇介绍某一种药品的功效、优势，形同软文）
- 不得涉及保健品宣传
- 合理用药科普可提及具体药品，但须满足以下条件：
  - 以药品类别 / 机制 / 用药原则为主线，而非以某一品牌药品为中心
  - 提及具体药品是为说明用药知识（如不良反应、相互作用、合理选用），而非推荐购买
  - 不出现"疗效好""首选""推荐使用"等带有商业导向的表述
  - 同类药品应公平提及，不偏向某一品牌

### 岭南特别处理：药膳 / 凉茶文化边界

岭南药学科普常涉及药膳、凉茶等具有地方特色的用药文化，须划清以下边界：

| 允许（药膳 / 凉茶文化科普） | 不录用（宣传 / 导流） |
|------------------------------|----------------------|
| 介绍药膳组方思路、适用人群、食用禁忌 | "某方治某病"，将药膳等同于治疗手段 |
| 介绍凉茶文化历史、组方原理、饮用注意事项 | 围绕某一款凉茶产品做单品推介 |
| 介绍岭南道地药材的食疗应用 | 出现购买渠道、价格、品牌对比等商业信息 |
| 介绍药膳 / 凉茶的合理选用原则 | 导流话术（"点击购买""私信获取""扫码下单"等） |
| 客观介绍药膳的局限性、不适宜人群 | 夸大疗效（"包治""根治""一定有效"） |

**判断要点**：
- 药膳 / 凉茶文化科普的核心是"知识传播"，而非"产品推销"
- 提及具体药膳方可以，但须以"组方思路、适用原则、注意事项"为主线
- 不得将药膳 / 凉茶包装成可替代正规治疗的手段

**边界情况**：
- 介绍某类药品（如"他汀类""质子泵抑制剂"）的合理用药知识 → 合理
- 以案例形式提及某药品的不良反应 → 合理（须客观，非贬低竞品）
- 通篇围绕某一药品展开，即便内容科学，仍涉嫌单一药品宣传 → 不录用
- 文中出现购买渠道、价格优惠、品牌对比等商业信息 → 不录用

**处理方式**：
- 通篇介绍单一药品、形同软文 → 判 ❌ → 不录用
- 涉及保健品宣传 → 判 ❌ → 不录用
- 药膳 / 凉茶科普演变为单品推介或导流 → 判 ❌ → 不录用
- 提及具体药品 / 药膳但以用药知识为主线、无商业导向 → 判 ✅
- 边界模糊 → 判 ⚠️ → 退修或标注"建议人工复核商业导向"

## 规则 ⑩ 针对社会热点的时效性科普优先审核

**性质**：优先项

**判断标准**：
- 针对近期社会热点的科普优先审核，同等条件下倾向录用
- 社会热点包括：季节性疾病（流感季、登革热季等）、突发公共卫生事件、热议健康话题、国家政策相关的用药话题
- 时效性评估：内容与当前时间节点的相关性

**判断方式**：
- 结合当前日期判断是否处于某类疾病高发季
- 搜索近期是否有相关健康热点新闻
- 评估文章发布时机是否契合热点周期

**处理方式**：
- 属于时效性科普 → 在报告中标注"时效性科普，优先"→ 在其他规则均通过的前提下，倾向录用并建议优先排期
- 不属于时效性科普 → 正常审核，不影响结论

## 附：结论判定速查

| 命中规则 | 结论 |
|----------|------|
