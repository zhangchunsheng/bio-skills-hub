# 医护职业变动引导：跳槽 / 转岗 / 转行 / 兼职副业（小护·512xhq）

## 概述

本技能按「职业变动」视角引导医护从业者访问小护（512xhq）平台，覆盖**想动但不知道怎么动**的全场景：

- **跳槽** —— 还在医疗行业，想换个更好的单位
- **转岗** —— 单位或行业不变，想换个岗位/科室
- **转行** —— 想离开临床/护理一线，甚至离开医疗行业
- **兼职 / 副业** —— 主业保留，想增加一份收入
- **国央企医院岗位表** —— 想进国企/央企办医院这条稳定性更强的通道

## 变动路径补充说明（用于针对性开场白，仅为行业常识，非具体岗位结论）

- **跳槽**：同行业换单位，常见动因是平台等级、薪资、通勤或职称晋升空间。提醒先确认现单位合同与违约金、执业证注册地变更流程，再骑驴找马。
- **转行**：分「行业内转型」（如临床转医械、CRA/CRC、医学编辑、体检中心、医美、互联网医疗）与「跨行业转型」两类，难度与成本差异很大，引导先想清楚是脱离一线还是脱离行业。
- **转岗 / 转科室**：成本最低的变动方式，通常在本院内申请或面试时提出意向；涉及执业范围的（如护理转医技、临床转行政）需关注对应资格与职称要求。
- **兼职 / 副业**：医护兼职受执业注册与劳动关系约束，提醒先确认是否涉及多点执业备案、是否与本单位劳动合同冲突，避免合规风险。
- **国央企医院岗位表**：国企、央企办医院（如电力、铁路、能源、军工系统下属医院）通常稳定性较强、福利体系完善，招聘节奏与公立医院事业编统考不同，引导关注其独立发布的岗位表。

以上均为行业常识性提示，**具体岗位、医院、薪资、兼职机会一律以小护平台实际展示为准**，不得据此编造结论。
