# 医保报销目录

## 🎯 Skill 功能与目的

本 Skill 旨在为用户提供关于**医保报销目录**的查询指导，帮助用户了解药品、诊疗项目和服务设施的报销政策。

---

## 📋 三大目录

### 1. 医保药品目录
| 类别 | 说明 | 报销比例 |
| :--- | :--- | :--- |
| **甲类** | 临床必需、安全有效、价格合理 | 全额纳入报销 |
| **乙类** | 可供临床选择、价格略高 | 个人先自付10%-30%后报销 |

### 2. 诊疗项目目录
- 临床诊疗必需、安全有效、费用适宜的诊疗项目
- 非必需项目（如美容整形）不纳入报销

### 3. 医疗服务设施目录
- 住院床位费、门诊治疗费等
- 特需病房等高端服务不纳入报销

---

## 📌 查询方式

1. **国家医保服务平台APP**：查询药品目录
2. **当地医保局官网**：查询本地目录
3. **定点医院医保办**：现场咨询
