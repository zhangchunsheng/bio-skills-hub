# 自查报告结构与闭环机制

被 SKILL.md「三、执行流程」第 1 步与第 6 步指向。搭章节骨架、生成缺陷清单表与整改闭环机制时读取。不读会缺章节或整改措施无时限，报告无法作为质控整改依据留档。

## 一、报告正文六章

| 章 | 标题 | 必含内容 |
|---|---|---|
| 1 | 报告期与抽查概况 | 报告期起止、出院患者病历总数、抽查例数与抽样方式（科室全覆盖或按比例）、抽查比例、质控依据文件清单 |
| 2 | 质控指标测算 | 指标测算表（七列）；每指标附分子分母绝对数；与上期同比变化；未达标指标标注 |
| 3 | 缺陷分类与典型问题 | 三类高频缺陷的例数与占比、逐类典型问题描述（脱敏）、缺陷病案清单表 |
| 4 | 成因分析 | 按五类归因，每类附本期实例：认知偏差（重治疗轻首页）、填报习惯性错误（凭经验选主诊、简化手术名称）、质控流于形式（仅质控员抽查、科主任未把关重点病例）、绩效联动不足（整改主动性差、同类问题反复）、数据滞后复盘（月度亏损后才追溯） |
| 5 | 整改措施与责任分工 | 分事前预防、事中核查、事后复盘三段；每条含责任岗位、完成时限、复核方式 |
| 6 | 闭环机制与下期目标 | 三级自查机制、月度数据复盘机制、绩效挂钩奖惩、跨部门协同整改、病案质量台账、下期目标值 |

文末附「数据完整性说明」：逐条列出缺失数据项与需补充的部门。

## 二、指标测算表七列

| 列 | 填写要求 |
|---|---|
| 指标编码 | 用 `MER-TQ-03` 这类标准编码 |
| 指标名称 | 用《病案管理质量控制指标（2021年版）》原名 |
| 分子 | 绝对数，不写百分比 |
| 分母 | 绝对数，注明分母口径 |
| 本期值 | 百分比保留一位小数 |
| 上期值 | 无上期数据时写「—」 |
| 同比变化 | 上升/下降 + 百分点 |

## 三、缺陷病案清单表八列

| 列 | 填写要求 |
|---|---|
| 序号 | 连续编号 |
| 科室 | 临床科室名 |
| 住院号 | 脱敏，保留前 4 位并以 `××` 补足 |
| 缺陷类型 | 归入三类高频缺陷之一 |
| 缺陷描述 | 写清首页填写内容与病历实际内容的差异 |
| 涉及指标 | 如 `MER-TQ-03` |
| 责任岗位 | 管床医师 / 质控员 / 编码员 / 科主任 |
| 整改状态 | 已整改 / 待整改 / 已复核 |

## 四、三级自查机制（整改措施事中段）

| 级 | 责任人 | 动作 | 时限 |
|---|---|---|---|
| 一级自查 | 管床医师 | 出院 24 小时内完整填写首页，核对诊断、手术、并发症 | 出院后 24 小时内 |
| 二级复核 | 科室质控员 | 每日抽查 30% 出院病案，标记缺陷反馈医师整改 | 每日 |
| 三级终审 | 科主任 | 每日抽查全部四级手术、危重、高费用病例；每周全覆盖抽查普通病例；签字确认后送病案室 | 每日 / 每周 |

缺陷病案当日退回修改，不允许带病归档。

## 五、闭环机制四件事

1. **月度数据复盘**：每月 5 日前收取病案质控缺陷报表、DRG 分组异常清单、CMI 统计表、四级手术台账，牵头开专题分析会，明确整改责任人与时限，会议记录留存备查。
2. **绩效挂钩奖惩**：正向——月度首页缺陷率为 0 的医师绩效加分、科室整体质控合格率达标发放质量奖励；反向——主诊选错、手术漏填、并发症大面积漏填扣单项绩效；同一医师同类问题月度出现 3 次及以上加倍扣罚并约谈；科室缺陷率超标扣科室月度医疗质量绩效。
3. **跨部门协同**：与病案编码室建立日常沟通渠道，编码歧义与 DRG 分组争议病例及时沟通修正；医保办每月同步 DRG 盈亏数据，定位首页填报导致的医保损失。
4. **病案质量台账**：指定质控员建立电子台账，记录缺陷病例类型、责任人、整改结果、重复问题频次；每季度梳理高频易错点，更新科室填报细则。

## 六、常用整改动作库（按责任岗位）

| 责任岗位 | 可落地动作 | 完成时限写法 |
|---|---|---|
| 科主任 | 每月固定设置病案首页专项培训议程，以案说法复盘三类高频问题 | 次月起每月 1 次，连续 3 个月 |
| 科室质控员 | 建立缺陷病例电子台账，按周统计缺陷率并公示 | 本月内建立，每周五更新 |
| 病案编码室 | 联合开展 MCC/CC 专项培训，明确哪些并发症可提升病例权重 | 每季度 1 次 |
| 管床医师 | 出院前对照科室特色四级手术与微创手术清单逐项填报 | 即时执行 |
| 新入职与轮转医师 | 岗前完成首页规范考核，合格后方可独立书写出院记录 | 入科 3 个工作日内 |

## 七、报告留档要求

1. 报告须注明质控依据文件，供上级质控中心或医保检查复核。
2. 指标测算的原始数据（抽查名单、缺陷明细）随报告留存。
3. 整改措施与下期目标须可量化，便于下期报告做同比。
