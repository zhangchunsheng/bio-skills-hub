# 缺陷分类与校验规则

被 SKILL.md「三、执行流程」第 3 步与「四、判定规则」指向。把缺陷明细逐条归类时读取。不读会把主诊选错与编码错误混为一类，整改措施失去针对性。

## 一、三类高频首页缺陷（自查报告主线）

| 类型 | 核心判定标准 | 高频错误表现 | 连锁损失 |
|---|---|---|---|
| 主要诊断选择错误 | 本次住院对患者健康危害最大、消耗医疗资源最多、住院时间最长的疾病；手术患者优先选择对应手术治疗的疾病；急症入院且全程围绕急症诊疗的，急症为主诊断 | 主次颠倒（以高血压、糖尿病、冠心病等基础慢病为主诊断）；手术病例错选（主诊断填基础病）；症状代替确诊疾病；并发症替代主病；转科病例逻辑混乱 | DRG 错分低权重组、医保拨付降低、科室结余减少、CMI 均值拉低、国考病种覆盖指标失真 |
| 手术/操作漏填与排序错误 | 首页手术操作第一栏填主要手术：与主要诊断对应、技术难度最高、风险最大、资源消耗最多；多台手术按难度从高到低排序；住院实施的全部操作均须填报 | 漏填（内镜下治疗、穿刺、置管、活检、介入消融仅写在病程）；排序颠倒；名称简化失真（笼统写「微创手术」）；只填手术不填配套关键操作（术中冰冻、血管阻断、淋巴结清扫）；转科手术重复或漏录 | 四级手术与微创手术占比统计偏低、DRG 权重下降、学科评审缺数据支撑、手术分级考核缺依据 |
| 并发症/合并症填写不全 | 其他诊断含并发症（本次住院疾病衍生、住院新发）与合并症（入院既有、影响本次诊疗的基础病）；存在 MCC/CC 均须完整填报；排序先重后轻、先并发症后合并症 | 选择性漏填心衰、肾衰、严重感染、电解质紊乱、术后出血、血栓；轻症基础病全部空白；院内感染、药物不良反应、术后并发症不体现；只写病名未标分型与严重程度；单病例仅 1-2 个诊断 | MCC/CC 是权重提升核心条件，漏填直接拉低病例权重、科室 CMI 下降、绩效总量缩水、危重病例占比不达标 |

## 二、首页填报校验规则（按五组归类）

### 组1 基本信息与住院过程

| 校验项 | 规则 |
|---|---|
| 首页完成时限 | 患者出院后 24 小时内完成 |
| 入院时间 / 出院时间 | 与本次住院实际时间一致；死亡患者出院时间取死亡时间 |
| 实际住院天数 | 与实际住院情况一致 |
| 入院科别 / 出院科别 / 转科科别 | 分别与首次正式收治科室、出院前所在科室、转科记录及病区流转一致 |
| 离院方式 | 与出院记录、死亡记录、转院记录及实际离院情况一致 |
| 31 日内再住院计划 | 有则填完整并与出院计划相符 |
| 药物过敏 | 与入院记录、护理评估一致；≥2 种过敏依次写通用名、逗号分隔，禁止只写「多种」；无过敏统一填 0，不空白、不写「无」 |

### 组2 诊断与编码

| 校验项 | 规则 |
|---|---|
| 主要诊断 | 在本次住院病历中有相应诊断依据 |
| 其他诊断 | 在病程、会诊、检查检验记录中有相应依据 |
| 诊断漏填 | 出院记录已有明确诊断、符合填报条件但首页未填时提示 |
| 诊断无依据 | 首页存在诊断但病历无支持性记录时提示 |
| 入院病情 | 与实际入院时诊断状态一致；填「无」时入院记录中不应已明确存在该诊断 |
| 性别 / 年龄与诊断 | 诊断名称或编码与性别、年龄范围明显不符时提示 |
| 损伤、中毒外因 | 按规定填写外部原因，名称、编码与实际原因相符 |
| 主要诊断编码 | 不宜作为主要诊断的编码作主诊使用时提示 |
| 诊断编码组合 | 存在应合并、互斥、联合编码或需附加编码的诊断组合时提示复核 |

### 组3 手术及操作

| 校验项 | 规则 |
|---|---|
| 手术操作漏填 | 已实际完成且符合填报范围但首页无对应项目时提示 |
| 手术操作无记录 | 首页已填但无相应实施记录时提示 |
| 取消手术 | 仅有申请、预约或术前医嘱、实际未实施的不应进入首页 |
| 手术操作日期 | 与实际实施日期一致 |
| 手术名称与编码 | 与实际完成术式相对应 |
| 主要手术 | 与本次住院主要治疗目的及主要诊断相符 |
| 术者、麻醉方式、麻醉医师 | 与手术记录、麻醉记录一致 |
| 手术级别 | 与医院现行手术分级管理目录及实际术式相符 |
| 切口等级 / 愈合等级 | 与手术记录、术后病程及出院时切口情况相符 |

### 组4 病理及检验

| 校验项 | 规则 |
|---|---|
| 病理信息完整性 | 符合条件病例的病理诊断、病理编码、病理号按要求填写 |
| 病理号 | 与本次住院对应病理报告一致 |
| 病理诊断 | 与最终病理报告相对应 |
| 肿瘤形态学编码 | 与最终病理诊断及现行编码字典相符 |
| ABO、Rh 血型 | 与本次住院有效检验结果或输血系统记录一致 |

### 组5 特殊病例与费用

| 校验项 | 规则 |
|---|---|
| 新生儿出生体重 / 入院体重 | 与出生记录、入院记录一致 |
| 死亡时间 / 死亡病例离院方式 / 尸检信息 | 与死亡记录及死亡事实一致 |
| 抢救次数 / 抢救成功次数 | 与病程、抢救记录一致；成功次数不大于抢救次数 |
| 颅脑损伤昏迷时间 | 与病程记录相符 |
| 住院费用 | 与最终结算数据一致，各费用分项与总费用符合逻辑关系 |
| 编码后病历变更 | 编码完成后出院诊断、手术操作或关键病理结果发生变化时重新编码复核 |

## 三、内涵质控两组术语

| 术语 | 内涵 |
|---|---|
| 四合理 | 合理诊断（依据充分、主次选择合规、无漏诊过诊错诊）、合理检查（指征充分、无重复过度检查、异常结果有分析）、合理治疗（方案贴合诊断、有评估与疗效追踪）、合理用药（有适应症、剂量疗程合规、调整有病程记录） |
| 七吻合 | 医嘱、病程记录、处方、检验检查报告、治疗操作记录、病案首页、收费结算清单七项相互对应，无矛盾、无虚记、无漏记 |

## 四、质控标准四项

| 项 | 要求 |
|---|---|
| 真实性 | 记录与实际诊疗一致，严禁虚构、涂改、后补无痕迹 |
| 及时性 | 入院、首次病程、查房、抢救、术前、术后、死亡记录按时限完成 |
| 完整性 | 眉栏、过敏史、知情同意、核心制度记录、检查治疗评价无缺项 |
| 逻辑性 | 落实四合理，全程满足七吻合，十八项核心制度有书面记录佐证 |
