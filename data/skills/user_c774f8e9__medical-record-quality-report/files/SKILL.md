# 病案首页质控自查报告

## 一、适用与硬性约定

1. 本 skill 只做自查报告的**文本组织、指标测算与缺陷归类**，不做病历真实性判定、不代科室定性医疗责任。
2. 指标公式与分母口径以 `references/quality-indicators.md` 为准。分母用错（如把手术患者分母写成全部出院患者）视为不合格。
3. 用户未提供的数值一律留占位符 `【待填：指标名】`，禁止编造抽查量、正确率或整改完成时间。
4. 引用文件必须带完整文号，写法示例：`《病案管理质量控制指标（2021年版）》指标二十一（MER-TQ-03）`。
5. 报告不得出现「为提升 CMI 而补充诊断」这类导向。缺陷整改一律指向记录完整性，不指向指标美化。
6. 涉及患者信息的字段脱敏：住院号保留前 4 位，姓名用「张××」形式。

## 二、输入

必需：报告期、出院患者病历总数、抽查例数、缺陷病案明细（含缺陷类型）。
可选：DRG 分组异常清单、CMI 月度趋势、四级手术与微创手术台账、上一期整改落实情况、按科室或按医师汇总数据。

缺必需项时，先建报告结构，缺项处留占位符并在首部「数据完整性说明」逐条列出。

## 三、执行流程

1. 读 `references/report-structure.md`，搭出自查报告章节骨架。
2. 读 `references/quality-indicators.md`，按指标定义与公式测算本期各指标值，标注分子分母。
3. 读 `references/defect-checklist.md`，把缺陷明细逐条归类到对应缺陷类型，统计各类型占比。
4. 分析成因：按「认知偏差 / 填报习惯 / 质控流于形式 / 绩效联动不足 / 复盘滞后」五类归因，每类附本期实例。
5. 生成整改措施与闭环机制，明确责任岗位、整改时限、复核方式。
6. 输出自查报告正文与缺陷病案清单表，附数据完整性说明。

第 2、3 步可并行。第 4 步依赖第 3 步的归类结果；第 5 步依赖第 4 步；第 6 步在第 2 至 5 步全部完成后执行。

人工介入点：缺陷定性（属主诊选择错误还是编码错误）、整改责任岗位、是否上报医务部由用户确认。

## 四、判定规则

| 规则 | 判据 | 反例 |
|---|---|---|
| 指标分母口径 | 主要诊断填写正确率分母为同期出院患者病历总数；主要手术填写正确率分母为同期出院手术患者病历总数 | 两个指标共用同一分母 |
| 缺陷归类 | 一条缺陷只归一类主类型，可标注次类型 | 一条缺陷同时计入三类 |
| 主要诊断判定 | 对照「对健康危害最大、消耗医疗资源最多、住院时间最长」三条，三条中至少两条成立 | 按入院第一诊断直接认定 |
| 手术操作判定 | 手术操作第一栏为与主要诊断对应、技术难度最高、风险最大、资源消耗最多的手术 | 按实施时间先后排序 |
| 并发症合并症判定 | 入院前及住院期间与主要疾病相关的并发症、住院期间新发生或新发现的疾病均须填报 | 只填主要疾病 |
| 整改措施 | 每条含责任岗位、完成时限（具体天数）、复核方式 | 写「加强培训」这类无动作表述 |

## 五、内容质量标准

1. 报告必须含指标测算表，列固定为：指标编码、指标名称、分子、分母、本期值、上期值、同比变化。缺任一列视为不合格。
2. 指标测算结果必须同时给出分子与分母的绝对数，只给百分比视为不合格。
3. 缺陷分类统计必须给出各类型例数与占比，占比合计 100%。
4. 成因分析必须每类附本期至少 1 个实例，实例用脱敏表述，不得泛泛而谈。
5. 整改措施按「事前预防 / 事中核查 / 事后复盘」三段组织，覆盖「三级自查」节点。
6. 全篇禁用「加强」「重视」「严格」单独成句。

## 六、输出格式

交付两份文本，均为 Markdown。

自查报告正文一级标题固定为六章：报告期与抽查概况、质控指标测算、缺陷分类与典型问题、成因分析、整改措施与责任分工、闭环机制与下期目标。末尾附数据完整性说明。

缺陷病案清单表列固定为八列：序号、科室、住院号（脱敏）、缺陷类型、缺陷描述、涉及指标、责任岗位、整改状态。

完整字段见 `references/report-structure.md`。

## 七、自检

1. 六章标题是否齐备且顺序未变。
2. 指标测算表七列是否齐备。
3. 每个指标是否给出分子与分母绝对数。
4. 主要手术指标分母是否为出院手术患者病历总数。
5. 缺陷占比合计是否为 100%。
6. 成因分析是否每类附实例。
7. 整改措施是否含责任岗位与具体时限。
8. 是否有「为提升 CMI 补充诊断」类表述。
9. 患者信息是否脱敏。
10. 是否残留未标注填写人的占位符。

## 八、红线

1. 不编造抽查例数、正确率与 DRG 亏损金额。
2. 不指导为提升指标而虚构诊断或操作，此类请求一律拒绝并说明属医保违规行为。
3. 不代替医务部或医保办做违规定性。
4. 不引用 `references/quality-indicators.md` 与 `references/defect-checklist.md` 之外的文件编号。
5. 不含 scripts：指标公式为四则运算，模型直接完成，无确定性批处理需求。
