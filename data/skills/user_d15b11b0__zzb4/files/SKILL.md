# 太仓小锦蒸溜 - 博主内容策略DNA蒸馏方法论

> 本 Skill 是一套**可复用的博主蒸馏工作流**：给定一个房产视频号博主的若干作品（链接或口播文稿），
> 按统一方法论蒸馏出其完整内容策略 DNA，产出可套用的 HTML 报告，并可选沉淀为对标 Skill。
> 首个范例为「太仓楼市小锦」（其蒸馏结果已存于 `太仓楼市小锦-对标` Skill）。

---

| Skill | 性质 | 内容 | 何时用 |
|-------|------|------|--------|

| 太仓楼市小锦-对标 | 蒸馏**结果** | 太仓小锦的 DNA 成品库 | 要参考太仓小锦策略/做融合生成时 |
| 视频号口播文案 | 内容**生成** | 南京IP人格 + 口播秒级公式 | 蒸馏后要套用生成自己的内容时 |

三者关系：本 Skill 产出"新博主的DNA报告" → 可仿照「太仓楼市小锦-对标」沉淀为新对标 Skill → 与「视频号口播文案」融合生成内容。

## 触发场景

当出现以下意图时加载本 Skill：
- 用户给出一个或多个博主作品链接/口播文稿，要求"蒸馏""分析内容策略""拆解这个博主"
- 用户说"帮我做个对标账号分析""蒸馏这个博主""套用蒸馏方法"
- 用户要求把某博主的风格提炼成可套用的模板

**输入形式**：①视频号/公众号作品链接（用 WebFetch 抓取）；②用户直接粘贴的口播文稿/标题/标签；③两者的组合。链接优先抓取，文稿作为补充（链接常抓不到口播正文，需文稿补全）。

---

## 蒸馏工作流（6 步）

### Step 1 · 抓取作品内容

对每个作品链接用 WebFetch 抓取，prompt 统一为：
> "请完整提取这篇内容的所有要素：标题/文案全文、作者或账号名、定位地点、话题标签、点赞/转发/评论等可见数据。逐字保留原文，不要总结。"

**关键提醒**：
- 视频号链接（`weixin.qq.com/sph/xxx`）常重定向到 `channels.weixin.qq.com/finder-preview/pages/sph?id=xxx`，需跟踪重定向
- 视频号动态通常**抓不到口播正文**，只能拿到：标题金句 + 定位签到 + 话题标签 + 互动数据
- 口播正文必须从用户直接提供的文稿获取——**链接抓不全时主动向用户索要文稿**，不要凭空补
- 公众号图文链接可抓到完整正文
- 并行抓取多个链接以提高效率

### Step 2 · 提取内容要素

对每条作品提取以下要素（缺失项标注"未获取"）：

| 要素 | 说明 | 来源 |
|------|------|------|
| 标题/金句 | 视频封面文字或口播开场金句 | 链接/文稿 |
| 口播正文 | 完整逐字稿 | **文稿为主**，链接常缺失 |
| 定位签到 | "苏州市·XXX"格式地点 | 链接 |
| 话题标签 | #开头的所有标签 | 链接 |
| 互动数据 | 点赞/转发/评论/收藏 | 链接（常缺失） |
| 产品类型 | 别墅/洋房/大平层/高层等 | 正文推断 |
| 地标类型 | 学区/商业/交通/环境 | 定位+正文推断 |

### Step 3 · DNA 7 维度分析

按 `references/dna_dimensions.md` 的 7 大维度逐一分析。每个维度有明确的"提取什么/怎么归纳/产出什么"。7 维度概览：

1. **博主画像** — 定位锚词/地域聚焦/受众画像/核心卖点路线/内容类型/人格标签
2. **标题公式库** — 归纳标题的重复结构，提炼可填空模板（含"为什么有效"）
3. **口播内容结构** — 秒级段落拆解（开场→卖点堆叠→场景代入→加持→收尾）
4. **标签架构** — 层级划分/数量比例/重复加权策略
5. **心理钩子** — 机制清单（数字冲击/认知反转/新旧对比等）+ 口播配合
6. **定位签到 + 地理叙事** — 地标类型分类 + 双线叙事（外溢客线 vs 本地客线）
7. **表达风格规则** — 语气/叙事法/价值话术/反模式清单

详细分析指南见 `references/dna_dimensions.md`，**分析时务必加载该文件**。

### Step 4 · 生成 HTML 蒸馏报告

基于 `assets/report_template.html` 模板生成报告。模板含完整章节结构 + 内联样式 + 占位符。

**报告必备章节**（顺序固定）：
1. 博主画像卡片
2. 标题公式库（每个公式：模板 + 示例 + 为什么有效 + 适配要点）
3. 口播秒级结构（段落表 + 关键话术）
4. 标签架构（层级 + 比例表）
5. 心理钩子清单
6. 定位签到 + 地理叙事双线
7. 表达风格规则（含反模式）
8. 可直接套用的内容模板（填空式）
9. 套用示例（演示如何往模板填信息）
10. 融合工作流（与口播Skill如何协同）

**关键要求**：
- 每个公式/话术必须配"为什么有效"的心理学解释——这是蒸馏的价值所在
- 套用模板必须是**可填空**的（用 `[占位符]` 标注），不能只给固定文案
- 套用示例要演示跨城市/跨产品适配，证明公式可移植
- HTML 用内联样式，不依赖外部资源，确保离线可看

章节结构详见 `references/report_template.md`。

### Step 5 · 与「视频号口播文案」Skill 融合（可选但推荐）

蒸馏出的 DNA 若要与用户的内容生成能力结合，按 `references/fusion_workflow.md` 建立融合：

- **形式策略层**（本报告产出）= 钩子/标签/定位/结构/话术
- **内容生成层**（视频号口播文案 Skill）= IP人格/人设/秒级结构/活人感自检/违禁词

融合后用户给房源信息即可一次性产出：标题 + 定位 + 标签 + N条逐字稿。

融合要点详见 `references/fusion_workflow.md`，**做融合时务必加载该文件**。

### Step 6 · 沉淀为对标 Skill（可选）

若用户希望长期复用该博主的 DNA，仿照「太仓楼市小锦-对标」的结构，将蒸馏结果沉淀为一个新的用户级 Skill：
- 路径：`~/.workbuddy/skills/<博主名>-对标/SKILL.md`
- frontmatter 必须含 `agent_created: true`
- 内容直接取自 Step 4 报告的各章节
- 在「视频号口播文案」Skill 中追加交叉引用（仿照已有的第4.5步"注入对标账号策略"）

## DNA 7 维度概览

> 这是 Step 3 分析的速查表，**详细指南见 `references/dna_dimensions.md`**。

| 维度 | 核心问题 | 产出物 |
|------|---------|--------|
| ① 博主画像 | 这个博主是谁、卖给谁 | 画像表（6字段） |
| ② 标题公式 | 标题有什么重复结构 | 3-6个可填空公式模板 |
| ③ 口播结构 | 正文怎么展开 | 秒级段落拆解表 |
| ④ 标签架构 | 标签怎么选配 | 层级划分 + 比例表 |
| ⑤ 心理钩子 | 靠什么抓住注意力 | 钩子机制清单 |
| ⑥ 定位地理 | 在哪拍、讲什么线 | 地标4型 + 叙事双线 |
| ⑦ 表达风格 | 怎么说话 | 语气/话术/反模式 |

## 范例：太仓楼市小锦

首个用本方法蒸馏的博主。其完整 DNA 已沉淀在 `~/.workbuddy/skills/太仓楼市小锦-对标/SKILL.md`（v2.2），蒸馏报告见工作区 `太仓楼市小锦-博主蒸馏报告.html`。

**范例验证了方法的有效性**：6条作品 → 7维度 → 6个标题公式 + 5层标签 + 5段口播结构 + 8种心理钩子 + 4型地标 + 双线叙事。蒸馏后与「视频号口播文案」Skill 融合，用户给房源信息即可生成成片内容。

蒸馏新博主时可参照该范例的深度和粒度。

## 诚实边界

> ⚠️ 蒸馏时必须注意以下局限：

1. **样本量**：蒸馏质量与作品数量正相关，建议至少 5-8 条作品覆盖主要选题类型
2. **口播正文依赖文稿**：视频号链接常抓不到口播正文，**务必向用户索要文稿**，不要凭标题臆测正文结构
3. **互动数据常缺失**：无法判断哪种公式效果最好，需如实标注"数据未获取"
4. **地域特异性**：每个城市的数字锚点/痛点词/差异化王牌产品不同，跨城市套用必须替换，不能照搬数字
5. **话术合规风险**：部分话术（如"不要钱送给你的"）在某些城市可能涉广告法，蒸馏报告需标注合规提醒
6. **蒸馏 ≠ 复制**：目标是理解"为什么有效"然后做适配，不是让用户变成那个博主
