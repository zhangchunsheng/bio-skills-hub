# 07 三地对比与出海策略

> 用途：回答「三地怎么选」「并行申报怎么排」「先做哪个市场」。
> 核对基准日：2026-08-27

## 1. 三地总对比表

| 维度 | 美国 FDA | 欧盟 MDR+AI Act | 中国 NMPA |
|---|---|---|---|
| AI 诊断软件类别 | 多为 Class II（510(k)） | 多为 Class IIb/III（Rule 11） | 多为 Class III |
| 审评时间（中风险） | 9-15 个月 | 15-30 个月 | 18-24 个月（III 类 18-36） |
| 审评时间（高风险） | 12-24 个月 | 24-36 个月 | 24-36 个月 |
| 官方费用（中风险） | $24,655-26,067（小企业减 75%） | 0（NB 费用另计） | 0（检测/临床另计） |
| 测试+咨询+临床 | $8-65 万 | €8-70 万 | ¥75-680 万 |
| 变更机制 | PCCP（最灵活） | PACMP（日本）类似 | 变更注册（保守） |
| 数据本地化 | 无强制 | GDPR 合规 | **1000+ 例中国数据、境内存储** |
| 网络安全 | SBOM 强制（否则 RTA） | MDR 17.2 + CRA | 建议（标准趋严） |
| 临床证据 | 文献/等同/研究 | CER + PMCF | 多中心临床（III 类常需） |

## 2. 出海策略：三地并行申报

### 2.1 并行申报五步

1. **产品画像**：确定预期用途、适应症、目标市场 → 三地分类初判（工具 `classify`）；
2. **市场优先级排序**（见 §3）；
3. **数据与临床统筹设计**：一次临床试验设计满足多地要求（如前瞻性多中心设计同时覆盖 FDA/NMPA 证据需求；国内研究同时满足数据本地化）；
4. **文档矩阵管理**：共享内核文档（算法文档、数据文档、性能验证）+ 各地差异文档（CER、510(k) 摘要、NMPA 申报）；
5. **排期与资源**：锁定欧盟公告机构（最紧俏）→ Q-Sub 预约 FDA → NMPA 分类界定同步启动。

### 2.2 常见并行组合

| 组合 | 适用 | 要点 |
|---|---|---|
| 中国首发 → 出海 | 国产创新 | 先满足 1000 例本地化，再复用部分证据出海 |
| 美国首发 → 欧中 | 国际化产品 | FDA 证据体系成熟，欧盟需补 CER/PMCF，中国需补本地临床 |
| 三地同时 | 大投入 | 临床设计一体化，成本高但时间最优 |

## 3. 优先级决策框架

| 考虑因素 | 建议 |
|---|---|
| 变更迭代速度是核心卖点 | 美国优先（PCCP） |
| 中国市场竞争激烈、需快速验证 | 中国优先（本地化先行） |
| 产品生命周期长、重临床证据 | 欧盟优先（但排期最紧，早锁公告机构） |
| 预算有限 | 美国 510(k) 路径性价比最高（小企业费率） |
| 目标客户在特定市场 | 按客户市场优先 |

## 4. 时间线统筹示例（三地并行）

```
第 0-2 月   产品画像 + 三地分类 + 预算
第 1-3 月   Q-Sub（FDA）+ 公告机构锁定（EU）+ 分类界定（NMPA）
第 3-9 月   数据准备 + 算法文档 + 验证测试（三地共用）
第 6-18 月  临床研究（中国前瞻性多中心 + 兼顾海外证据）
第 12-24 月 各地申报：510(k) / CE（MDR）+ AI Act / NMPA 注册
第 24-36 月 获批后：PMCF / 漂移监控 / 变更管理
```

## 5. 出海避坑清单

- [ ] 公告机构排期提前 18-24 个月锁定（欧盟最大瓶颈）
- [ ] 中国 Class III 数据本地化预算与周期预留（¥300-800 万、18-30 个月）
- [ ] 网络安全文档（SBOM 等）按最严市场标准准备，一次满足多地
- [ ] 变更策略提前规划：PCCP 方案在 FDA 申报时写入
- [ ] 商标/UDI/EUDAMED 注册等配套事项并行启动
- [ ] 授权代表：欧盟（EU REP）、中国（境内代理人）配置
