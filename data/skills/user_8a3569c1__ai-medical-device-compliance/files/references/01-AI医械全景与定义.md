# 01 AI 医械全景与定义

> 用途：回答「什么算 AI 医疗器械」「SaMD 是什么」「GMLP 是什么」「AI 分哪几类」。
> 核对基准日：2026-08-27

## 1. SaMD 定义（IMDRF 国际共识）

**软件即医疗器械（SaMD, Software as a Medical Device）**：用于一项或多项医疗目的的软件，且该软件**不是**硬件医疗器械的组成部分（可独立运行于通用计算平台）。

| 要素 | 说明 |
|---|---|
| 独立运行 | 不依赖特定硬件，可在通用计算平台运行 |
| 医疗目的 | 用于诊断、预防、监测、治疗或缓解疾病 |
| 算法核心 | 核心功能由算法实现，尤其是 AI/ML 类 |

**AI/ML 医疗器械**：使用人工智能/机器学习算法实现医疗功能的软件或器械。

**判断关键**：软件是否"医疗目的"——用于诊断/治疗决策/疾病监测的算 SaMD；仅健康管理、生活方式建议（如普通计步、通用健身建议）一般不算。

## 2. AI 医疗器械的四种类型

| 类型 | 特征 | 监管关注点 |
|---|---|---|
| 锁定型 AI（Locked） | 算法固定，部署后不自动更新 | 与传统器械类似，上市后漂移监测 |
| 自适应 AI（Adaptive） | 算法可从新数据学习并更新 | 变更控制（PCCP/PACMP/变更注册） |
| 生成式 AI（Generative） | 生成新内容（报告、问诊文本） | 幻觉风险、人机协同、内容责任 |
| 混合型 | 多技术组合 | 多模态验证、接口责任 |

## 3. GMLP（良好机器学习实践）——全球合规底座

由 IMDRF 倡导，三大监管机构（FDA/欧盟/NMPA）不同程度吸收，2026 年已成为全球 AI 器械监管的共识基线：

- **训练集与测试集物理隔离**：绝对禁止数据泄露（Data Leakage）；
- **代表性数据集**：涵盖不同人种、性别、年龄、设备型号、临床场景，消除算法偏见；
- **临床参考标准（金标准）**：建立过程透明可溯源；
- **人机协同底线**：AI 作为辅助工具，最终医疗决策由持证医师做出——**自主诊断（Autonomous Diagnostic）AI 面临最高等级临床证据要求**。

## 4. 全生命周期监管（TPLC）——2026 年主基调

监管从"上市前静态审批"转向**全生命周期管理（Total Product Life Cycle）**：

```
设计 → 数据 → 开发 → 验证 → 提交 → 上市 → 变更 → 退役
 │      │      │      │      │      │      │      │
透明性  代表性  IEC62304 泛化/对抗 文档   漂移监测 变更控制 数据清理
偏倚    质量    文档     临床验证  提交    不良事件  重评     责任交接
```

**核心矛盾**：AI 的核心价值是"学习与迭代"，但每次权重更新都重新申报会扼杀创新——因此各监管机构都在发展"预定变更控制"机制（FDA PCCP / 日本 PACMP / NMPA 试点灵活变更），详见 06 模块。

## 5. WHO 六支柱（全球治理参考）

WHO《AI 健康伦理与治理指南》六支柱：透明度与文档、风险管理与安全、数据治理与隐私、协作与利益相关方参与、监管监督与合规、评估与监测——非约束但有规范权重，常作各国立法基线。

## 6. 快速自查：我的产品算不算 SaMD

1. 是软件/算法吗？（不是硬件主体）→ 是
2. 有医疗目的吗？（诊断/预防/监测/治疗/缓解）→ 是
3. 独立于硬件运行吗？→ 是
4. 结论：可能构成 SaMD → 进入三地分类评估（02/03/04 模块）
