# 04 中国 NMPA 注册路径

> 用途：回答「NMPA 怎么注册 AI 医疗器械」「分类界定怎么做」「变更注册何时触发」「数据本地化要求」。
> 核对基准日：2026-08-27

## 1. 分类体系与路径

| 类别 | 审批路径 | 说明 |
|---|---|---|
| Class I | 备案制（地市级） | 低风险 |
| Class II | 省级药监局注册 | 中风险 |
| Class III | 国家药监局（NMPA）注册 | 高风险——**AI 诊断软件通常归 Class III** |

> 2026 年初 NMPA 发布更新版《AI 辅助诊断软件分类界定指南》，确立三档风险框架；指南按年度修订，2023 规则下获批的产品可能需按 2026 新要求重新验证。

## 2. 审评指导原则（2022 + 2026 更新）

NMPA 医械技术审评中心（CMDE）《人工智能医疗器械注册审查指导原则》核心要求：

| 维度 | 要求 |
|---|---|
| 需求规范 | 数据采集标准、标注规则（标注人员资质、背靠背双盲标注） |
| 数据收集 | **地域代表性**：须包含全国不同地域、不同级别医院（三甲/基层）数据 |
| 算法设计 | 算法架构说明、超参数设置原理、防过拟合策略 |
| 验证与确认 | 独立第三方数据库交叉验证、金标准比对 |
| 性能验证 | 多中心验证、泛化能力（人群/设备差异） |
| 可解释性 | AI 决策可解释性说明 |
| 持续学习 | 如有自适应学习，建立更新验证程序 |
| 网络安全 | 数据安全、算法安全 |

## 3. 核心算法变更与版本控制（与 FDA PCCP 的关键差异）

NMPA 对软件版本命名有严格要求（如 V1.0.0.0），分两类变更：

| 类型 | 触发 | 动作 |
|---|---|---|
| **重大变更** | 算法架构改变、预期用途扩大、核心指标（敏感度/特异性）显著改变、运行环境重大升级、**核心算法权重重新训练** | **重新注册 / 变更注册** |
| 轻微变更 | 不影响核心临床功能的 Bug 修复、UI 优化 | 企业体系控制，无需立即申报 |

> ⚠️ 相比 FDA PCCP，NMPA 变更控制**相对保守**：任何涉及核心算法权重的重新训练通常触发变更注册。2026 年起部分创新通道产品开始**试点更灵活的变更方案**——计划持续学习的产品建议提前与审评中心沟通。

## 4. 临床评价路径

| 路径 | 条件 | 说明 |
|---|---|---|
| 同品种临床评价 | 有已上市同类产品且差异不影响安全有效 | 豁免临床试验，但 AI"黑盒"特性导致对比困难，需补充验证 |
| 前瞻性临床试验 | Class III 辅助诊断通常要求 | 多中心、对照组设定（与人类专家对比）、盲法、样本量计算规范 |

**数据本地化（国际厂商最大门槛）**：Class III 诊断 AI（CT 肺结节、病理等）须以 **1,000+ 例中国患者病例**在 NMPA 认可的国内医院验证、数据存境内服务器——海外已获批产品需另做独立中国临床研究（约 ¥300-800 万、18-30 个月）。

## 5. 创新通道（绿色通道）

符合"国内首创、国际领先、明显临床优势"可申请**创新医疗器械特别审查**：专人辅导、优先审评（约 12 个月）。

## 6. 费用与周期

| 项目 | Class II | Class III |
|---|---|---|
| 注册检测费 | ¥50,000-150,000 | ¥100,000-300,000 |
| 临床试验费 | ¥500,000-2,000,000 | ¥1,000,000-5,000,000 |
| 注册咨询费 | ¥200,000-500,000 | ¥500,000-1,500,000 |
| 行政规费 | 免费 | 免费 |
| 总计 | ¥750,000-2,650,000 | ¥1,600,000-6,800,000 |

**时间线**：分类界定 1-2 个月 → 检测 3-6 个月 → 临床评价 6-12 个月 → 注册申报/技术审评 6-12 个月 → 体系核查 1-2 个月 → 批准 1-2 个月，**总计约 18-36 个月**（创新通道约 12 个月）。

**行业数据（截至 2025 底）**：NMPA 累计批准创新医疗器械 367 件，其中 AI 医疗器械约 80 件（22%）；主要领域：影像诊断、病理分析、心电分析。

## 7. 获批 ≠ 落地

医院采用还需：省级卫健委批准 + 预算分配；Class III AI 工具**不得自主诊断**，须标注"决策支持"并由持证医师复核。

## 8. 实操检查清单

- [ ] 分类界定（NMPA 分类界定申请，1-2 个月）
- [ ] 数据集：全国多地域多级医院代表性 + 标注规范
- [ ] 算法文档：架构、超参数、防过拟合
- [ ] 检测（第三方检测所）
- [ ] 临床评价：同品种比对 or 多中心临床试验（Class III 常需中国患者数据）
- [ ] 注册申报（含软件文档、网络安全）
- [ ] 生产体系核查
- [ ] 规划变更策略：持续学习产品提前与审评中心沟通
- [ ] 创新通道评估：国内首创/国际领先/明显临床优势
