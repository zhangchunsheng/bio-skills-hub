# 03 欧盟 MDR 与 AI Act

> 用途：回答「欧盟医疗器械 AI 怎么分类」「MDR Rule 11 怎么用」「AI Act 对医械有什么要求」「CE 认证流程」。
> 核对基准日：2026-08-27

## 1. MDR Rule 11——软件器械分类

欧盟 MDR 附录 VIII 的 **Rule 11** 专门针对软件：

| 类别 | 条件 | 示例 |
|---|---|---|
| Class III | 提供用于做出高公共卫生风险/患者风险决定的信息 | 恶性肿瘤诊断 AI、ICU 决策支持 |
| Class IIb | 提供用于做出高患者风险决定的信息 | 大多数诊断辅助 AI |
| Class IIa | 其他提供临床决策信息的软件 | 临床信息整理软件 |
| Class I | 其他软件 | 健康数据存储、显示软件 |

**Rule 11 判定流程**：
```
是否预期用于临床决策？
├── 否 → Class I（自我声明）
└── 是 → 决策错误是否导致：
    ├── 死亡或不可逆伤害 → Class III
    ├── 严重手术干预或直接患者危害 → Class IIb
    └── 其他情况 → Class IIa
```

## 2. AI Act 对医疗器械的叠加要求

**医疗器械中的 AI 系统属于 AI Act 高风险类（Annex I 受监管产品内嵌）**——高风险义务 **2028-08-02 起适用**（Digital Omnibus 修订后时间线，此前为 2026-08-02）。

**高风险 AI 系统额外要求**（叠加在 MDR 之上）：

| 要求 | 说明 |
|---|---|
| 风险管理体系 | ISO 14971 + AI 特定风险 |
| 数据治理 | 训练数据质量、代表性、来源合法（GDPR） |
| 技术文档 | AI Act 特定文档要求 |
| 记录保存 | 自动日志记录、可追溯 |
| 透明度 | 向用户提供 AI 使用信息（局限性、准确率） |
| 人为监督 | 关键决策需人为确认，可随时干预/停止 |
| 准确性/稳健性 | 性能标准 |
| 网络安全 | 安全要求 |

**一个 CE 标志 = 同时符合 MDR + AI Act**：同一公告机构在 MDR 审核时一并审查 AI Act 合规。

⚠️ **现实瓶颈**：同时具备 MDR + AI Act 双重审核能力的公告机构严重不足 → 排队时间极长，**建议提前 18-24 个月锁定公告机构排期**。

## 3. 临床评价（CER）与上市后

- **等效性（Equivalence）论证极难**：MDR 要求证明与竞品在技术/生物学/临床属性完全等同且能合法获取其技术文件——对封闭算法驱动的 AI 几乎不可能；
- **强制 PMCF（上市后临床跟踪）**：主动收集真实世界数据（RWD），证明长期多场景泛化能力，定期更新 PSUR（定期安全性更新报告）。

## 4. 网络安全（MDR Annex I 17.2）

网络攻击防护、传输与存储数据保护、安全补丁支持、最小权限原则；参考法规：NIS 2 Directive（2024-10）、Cyber Resilience Act（预期 2027）、AI Act（2025-08 部分生效）。

## 5. 费用与周期

| 项目 | Class IIa | Class IIb | Class III |
|---|---|---|---|
| 初始认证费用 | €30,000-60,000 | €50,000-100,000 | €80,000-150,000 |
| 年度监督费用 | €10,000-20,000 | €15,000-30,000 | €20,000-40,000 |
| 技术文件审查 | €5,000-15,000 | €10,000-25,000 | €20,000-40,000 |

**时间线**：分类确认 1-2 个月 → 公告机构申请 1-3 个月 → QMS 审核（ISO 13485 + MDR）6-12 个月 → 技术文件审查 6-12 个月（含 CER）→ AI Act 合规（如适用）2-4 个月 → EUDAMED 注册 1-2 个月，**总计约 15-30 个月**。

## 6. 实操检查清单

- [ ] Rule 11 分类判定（临床决策影响）
- [ ] 确定公告机构并锁定排期（早于计划 18-24 个月）
- [ ] ISO 13485 QMS（含 AI 生命周期管理要素）
- [ ] 技术文件（含 CER、算法文档）
- [ ] AI Act 高风险义务准备（2028-08-02 前）：风险管理、数据治理、日志、人工监督
- [ ] 网络安全：MDR Annex I 17.2 + SBOM（建议）
- [ ] PMCF 计划与真实世界数据收集
- [ ] EUDAMED 注册 + UDI
- [ ] 第三国制造商：确认是否需欧盟授权代表
