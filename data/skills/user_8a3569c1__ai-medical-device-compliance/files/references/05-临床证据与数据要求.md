# 05 临床证据与数据要求

> 用途：回答「三地临床评价要求有什么不同」「RWD 能不能用」「多中心验证怎么做」。
> 核对基准日：2026-08-27

## 1. 三地临床证据要求对比

| 维度 | FDA | 欧盟 MDR | NMPA |
|---|---|---|---|
| 临床数据来源 | 文献、等同器械、临床研究 | CER（文献、等同、临床、PMCF） | 临床试验或同品种比对 |
| AI 验证要求 | 独立数据集验证、多中心验证 | 临床性能验证、数据集代表性 | 多中心验证、金标准比对 |
| 文献使用 | 可接受（证明等同性） | 系统性文献检索 | 有限接受 |
| 真实世界证据 | 逐步接受 | 接受（PMCF） | 逐步接受 |
| 临床试验要求 | 视风险而定 | Class IIb/III 可能需要 | Class III 通常需要 |

## 2. GMLP 数据要求（三地共识基线）

1. **训练集/验证集/测试集物理隔离**：绝对禁止数据泄露——测试集不得以任何形式参与训练；
2. **代表性**：人种、性别、年龄、设备型号、临床场景全覆盖（NMPA 特别要求地域与医院层级代表性）；
3. **金标准（参考标准）**：建立过程透明可溯源，避免主观偏差；
4. **独立第三方数据库交叉验证**（NMPA 要求）。

## 3. 三类常见临床路径

| 路径 | 适用 | 特点 |
|---|---|---|
| 文献/等同性论证 | 低风险、有充分文献 | 成本低，FDA 可接受，MDR 等效论证难 |
| 同品种比对 | 有已上市同类产品（中国） | 豁免临床试验，但黑盒算法对比难 |
| 前瞻性多中心临床试验 | 高风险/自主诊断 | 金标准，证据最强，成本最高 |

**对照设计要点（NMPA 规范）**：与人类专家医生对比、盲法设计、样本量计算、多中心分布。

## 4. 真实世界数据（RWD）的使用

- **FDA**：逐步接受 RWD 作为上市后性能监测与补充证据；
- **欧盟**：PMCF 强制要求收集 RWD，用于泛化能力验证与 PSUR 更新；
- **中国**：逐步接受，但 Class III 首次注册通常仍需前瞻性临床。

## 5. 数据本地化差异（关键约束）

| 市场 | 数据要求 |
|---|---|
| 中国 | Class III 诊断 AI：1,000+ 例中国患者病例、境内医院、境内服务器 |
| 欧盟 | 训练数据合规（GDPR）、数据来源合法性证明 |
| 美国 | 无强制数据本地化，但需文档可审计 |

## 6. 临床证据文档清单

- [ ] 数据集说明：来源、规模、标注规范（标注人员资质、双盲背靠背）
- [ ] 训练/验证/测试集划分与隔离证明
- [ ] 代表性分析（人群/设备/地域/医院层级）
- [ ] 金标准定义与建立过程
- [ ] 性能验证报告（敏感度/特异性/AUC 等）
- [ ] 泛化能力测试（跨中心/跨设备/对抗样本）
- [ ] 偏倚评估（不同亚组性能差异）
- [ ] 临床评价报告（CER/临床研究报告）
- [ ] 上市后监测计划（RWD/PMCF/漂移检测）
