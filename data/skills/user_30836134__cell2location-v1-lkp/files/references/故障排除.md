# cell2location 故障排除指南

## 常见问题

### 问题：数据格式错误

**错误**: 输入数据格式不正确

**解决**:
1. 检查 scRNA-seq 数据格式
2. 检查 spatial 数据格式
3. 确保基因名一致

### 问题：内存不足

**错误**: MemoryError / cannot allocate vector

**解决**:
1. 减少数据量
2. 使用分块处理
3. 增加系统内存

### 问题：计算速度慢

**解决**:
1. 使用 GPU 加速（如支持）
2. 减少迭代次数
3. 使用并行计算

### 问题：结果不准确

**解决**:
1. 检查参考数据质量
2. 调整参数
3. 使用更多细胞类型

## 性能优化

### 大数据集处理

- 分块处理
- 减少高变基因数量
- 使用降采样

### 参数调优

- 调整学习率
- 调整迭代次数
- 调整正则化参数
