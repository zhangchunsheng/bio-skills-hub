# cell2location 安装指南

## 环境要求

- **Python**: 3.8+
- **操作系统**: Linux (推荐), Windows, macOS

## 安装步骤

### 1. 创建虚拟环境

```bash
python -m venv cell2location_env
source cell2location_env/bin/activate  # Linux/Mac
# 或
cell2location_env\Scripts\activate  # Windows
```

### 2. 安装 cell2location

```bash
pip install cell2location
```

### 3. 安装依赖

```bash
pip install scanpy pandas numpy matplotlib seaborn
```

## 验证安装

```python
import cell2location
print("cell2location 安装成功！")
```

## 常见问题

### 问题：CUDA 版本不匹配

**解决**: 安装与 CUDA 版本匹配的 PyTorch

### 问题：内存不足

**解决**: 减少 batch size 或使用 CPU
