# 美学设计师 · 意象与色场库

本库存「意象 → 视觉系统方案」的已验证种子（中文意象说明＋可直接落地的色场／字体／印章方案）。美学设计师服务盘古整体与九技任一，本库按「领域」分卷：节气物候为已验证首卷（含二十四节气意象扩展表），其余技能（医道本草、命术命理、卜术卦象、相术气色等）可续写各自卷目，统一守视觉 DNA 与守界。新增意象时，按同法回填对应卷。

> 本技**不画具象插画、不调平台图像生成**。凡意象一律以「节气底色色场＋色彩留白＋纹样母题（符号化）＋字体印章＋文脉点题」承载，具象落地交人工。

## 二、色场方案模板（每次出视觉照填）

```
[节气意象] ＋ [底色：查 24节气配色基盘 取 base/support/accent/deep]
＋ [形态：封面色场(分层) / 图说色场(细框) / 纹样母题 / 品牌印章]
＋ [字体：标题楷体栈 / 正文系统默认 / 字号层级]
＋ [禁忌：不画具象 / 不渐变 / 不卡通 / 不标AI]
```

出稿后四问自检：配色合否（≤3＋节气底色）？字体层级清否？留白给标题否？有违禁字样或具象描摹否？

## 四、守界速查

- 不露真实人脸，以物象／色彩／母题代人物。
- 不标病名、证型、方剂、剂量，不许诺疗效。
- 成品与说明不写「自动生成」「机器绘制」「AI」字样。
- 不调平台图像生成接口；具象意象不手绘、不 AI，交人工或留白色场。
- 「节气伙伴」四字无括号，封面置顶小字。
