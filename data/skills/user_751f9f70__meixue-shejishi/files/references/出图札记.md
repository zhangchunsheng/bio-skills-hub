# 美学设计师 · 设计札记（观形四观 · 刻骨成习）

本件承接 SKILL.md 第八节「养·观形四观」。每次出视觉（或每见一视觉）后即写一条，过四观，注明意象与心骨形风，日积月累汇入道录与悬置池，经魂印回照反哺本技。追加不覆盖，每条注明日期与意象。

## 写法（一条一象）

- **意象**：本视觉写的是什么象（节气物候／本草／命理／卦象／气色…）。
- **观形（术层·表·设计之形）**：色场分层、字体层级、网格、留白、母题、印章——这一处的形怎么处理的。
- **观骨（法层·里·设计之法）**：构成章法（九宫／疏密虚实）、取势原则、气眼落在哪、合设计原理六则否（对比／层级／平衡／节奏／统一／强调）。
- **观心（道层·根）**：为何用此象此色——承载什么理、什么时节信号、什么心境。
- **观风（人层·显）**：拿掉物象剩下什么气；清浊如何。
- **化成判**：哪处本能发动（自然用上清气与取势），哪处仍是刻意堆的；下次如何化。
