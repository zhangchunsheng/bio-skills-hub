# 报表模板规范（pharmacy-word-report）

本文件定义由 `scripts/build_docx.py` 生成的 Word 报表的章节结构、表格规格与可疑性判定口径，
供调整结构或措辞时参照，无需重读脚本。

## 一、总体结构（结论先行 + 分层级）

1. 标题：`全院药品使用分析报表` + 副标题（期间 · 药库出库数据 · 全院各科室）+ 来源/粒度/生成行
2. 一、数据概况与质量
3. 二、总体药品使用金额分析（排名前50）
4. 三、ATC 分类药品使用金额分析
5. 四、科室药品使用分析
6. 附录：ATC 2–4 级金额汇总（前30）
7. 方法学与约束说明

## 二、表格规格（三线表）

- 仅保留：顶线（表上方）、栏目线（表头下沿）、底线（表末）。无竖线、无表内横线。
- 表头：黑体、居中、加粗；表体：宋体、居中、9–9.5 号。
- 金额单元格单位用 **万元**（2位小数，千分位），总体量级用 **亿元**。
- 占比 = 该分组金额 / 全院总金额 ×100%。

## 四、可疑性判定口径（不臆造、不下最终结论）

### 4.1 专科-主导药品匹配存疑（susp_mismatch）
规则：科室名含明确非肿瘤/非系统治疗关键词
（康复/理疗/中医/针灸/皮肤/眼科/口腔/耳鼻喉/整形/美容/妇产/生殖/计划生育/保健/营养/心理/精神…）
但其金额第一的药品 ATC1 = 抗肿瘤药及免疫调节剂。

呈现：列为“需药师核实”，并加注临床合理性：
- **属合理（不列为不合理）**：风湿科用阿达木单抗（RA）、眼科用阿达木单抗（葡萄膜炎）、
  生殖中心用环孢素（复发性流产/辅助生殖免疫调节）、耳鼻喉/口腔颌面外科用头颈鳞癌靶向/免疫药（部分合理，建议核实）。
- **明显存疑（重点核查）**：康复理疗科、中医内科病房/门诊、中医针灸门诊等主导高值抗肿瘤药，
  高度提示药品归属/代发录入或转科流通问题。

### 4.2 单药高度集中（susp_concentration）
规则：单一药品占本科室金额 > 30%。属结构性集中标志，报告数量与前20例；
不据此单独判定不合理（肿瘤科靶向治疗可属合理），应结合科室性质评估。

## 五、约束（始终遵守）
- 不填补/臆造缺失数据；缺失与金额为0/单价为0如实报告。
- “匹配存疑”“高度集中”为提示信号，非不合理认定；最终判定须结合病历与药师复核。
- 金额单位万元为主、亿元表量级；占比均相对全院总额。
