# 于祥宇 金句库 (Golden Lines Bank)

供研习其语感、做 pastiche 时参考。按主题分组。

## 努力观 / 自由观
- "什么亚里士多德，多劳才能多得。"
- "什么积极自由，什么消极自由，财务自由才是真正的自由。"
- "你的人生不是轨道，是旷野，那才是你牛马该去的地方。"

## 应届生自嘲 / 人设
- "有人出生是罗马，而我是应届生。"
- "我表面是个干净的应届生，心里其实住了个GAI。"
- "我从这里来，要到哪里去"——虽然在哪都被当做笑话，但至少可以 stand up。

## 原生家庭 / 家庭
- "家庭幸福的人不叫原生家庭，人家叫：家。"

## 租房 / 消费主义
- "我租房还带个管家，就好像我骑共享单车还配个司机。"
- "这破房子它只是看着好，住着一点都不自如。"
- "品牌大使……你是要跟外星人建交吗？三体人一看吊牌，不要回答，不要回答。"
- "你让我保护地球，不就相当于让蚂蚁保护森林。"
- "很多奢侈品甚至有全球大使，你都能代表地球了。"

## 表面功夫 / 漂亮话
- "这个世界不需要语言来精装修，只需要少点宣传墙。"
- "利群：我这好烟大家都尝尝。"（把损人利己演成大公无私）
- "电子烟就像个加湿器。"
- "发型总监""品牌大使，你这个名头叫得也太大了吧。"

## 职场 / 整顿
- "领导，方案明天交？不——我不要你觉得紧急，我要我觉得合理！"
- "你签了肯定会更好" → "你好给我画个饼呢？""让你三年做李诞，五年当李现。"
- "台上的人有时候真没那么 real，挺虚伪的。"

## 存在主义 / 收尾
- "我是谁？我从哪里来？到哪里去？"（哲学三问收尾，展露年轻人野心）
- "虽然笑着，但笑着笑着就陷入沉思。"

> 用法提示：pastiche 时**不要直接照抄**，而是模仿其"用典+降维+精准比喻"的
> 生成机制，套到新话题上。
