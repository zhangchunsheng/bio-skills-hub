# 于祥宇 风格深度指南 (Deep Style Guide)

本文件供生成或评估"于祥宇风格"脱口秀文本时加载。核心公式：
**笑点为表、思考为里、讽刺为核。**

---

## 一、六大特征详解

### 1. 哲学底色 + 化繁为简
- 把抽象哲学概念翻译成生活观察：积极/消极自由、亚里士多德、叔本华、存在主义三问。
- 关键技巧 **"用典/曲解"**：引用大家熟识的哲学家/概念，做滑稽的误读或降维。
- 例："亚里士多德，多劳才能多得"——把形而上的哲学家拉来给加班文化背书。
- 天然戏剧冲突：哲学脑子（形而上）找形而下工作，本身就是笑点。

### 2. 强人设叙事（"品牌人设"）
- 固定人设：**刚毕业的哲学研究生 / 应届生 / 祥子**。
- 所有段子贴着人设展开，每个笑料都"往品牌人设里存钱"——反复强化同一身份标签。
- 自嘲式用典：把"祥子"与"于祥宇"并置，形容尴尬处境。
- 检验：去掉人设，段子是否还能成立？不能 → 人设贴靠成功。

### 3. 高密度文本 + 精准观察
- **两句一梗**：文本打磨精细，不允许大段无笑点的铺垫。
- 擅长精准比喻、巧妙反差、通透视角。
- 从生活小细节精准吐槽（脚趾撞桌脚、租房带管家、电子烟像加湿器）。
- 好观察的标准：观众"狠狠切中痛点""直击痛点，令人印象深刻"。

### 4. 讽刺 / 冒犯精神（"坏"）
- "脱口秀要坏"——不是刻薄，是天生的狡黠、对人性的洞见与坏坏的嘲讽心。
- 敢于冒犯漂亮话、表面功夫、消费主义、职场规训、身份标签。
- 冒犯对象要"安全且共识"：品牌话术、画饼领导、伪善标语——而非具体弱势个体。
- 例：嘲讽"品牌大使"（"你是要跟外星人建交吗？三体人一看吊牌，不要回答，不要回答"）。

### 5. 情绪价值 + 年轻人共鸣
- 站在年轻人角度直球输出："年轻人的困境，不就是你们造成的吗""谁惹我不爽，我就对付他"。
- **整顿职场**代表梗：模仿黄晓明"我不要你觉得，我要我觉得"，引爆打工人共鸣。
- 底色是**佛系/丧/内心悲凉**，能触摸人性幽暗与人生荒谬，笑着笑着陷入沉思。
- 避免强行升华、生硬说教。

### 6. 表演提示：使相（歪嘴）+ 稳定节奏
- "歪嘴战神"：用相声术语"使相"表达情绪态度（岳云鹏式表情包），但配强文本。
- 谐音哏 + 使相结合制造笑料。
- 写稿时标注 **[使相] [停顿] [坏笑]** 等表演节拍，让文本可直接上台。
- 整体气质：极致稳定，无笑点断层、无临场翻车感。

## 二、DO / DON'T

| ✅ DO | ❌ DON'T |
|---|---|
| 贴着"应届生/哲学"人设叙事 | 脱离人设讲泛泛段子 |
| 用具体生活细节（租房/面试/加班） | 只喊口号、只输出情绪无细节 |
| 用典/曲解制造反差梗 | 堆砌网络热梗、抄段子 |
| 精准比喻一键引爆 | 铺垫过长、笑点稀 |
| 冒犯"漂亮话/画饼/消费主义" | 冒犯具体弱势个体（变刻薄） |
| 结尾回到丧/悲凉/存在主义三问 | 强行正能量升华、鸡汤收尾 |
| 标注使相/停顿等表演节拍 | 只给纯文本无表演提示 |

## 三、评估 checklist（每项 0–10）

- [ ] **哲学化繁为简**：是否用哲学概念/用典制造反差？
- [ ] **人设贴靠**：是否贯穿"应届生/祥子/哲学"身份？
- [ ] **梗密度**：是否接近两句一梗、无长段空白？
- [ ] **精准观察**：是否有具体生活细节而非空泛情绪？
- [ ] **讽刺冒犯**：是否有"坏坏的"冒犯漂亮话/规训？
- [ ] **年轻人共鸣**：是否站在年轻人对立面（老板/品牌/社会）？
- [ ] **丧式结尾**：收尾是否悲凉/存在主义而非鸡汤？
- [ ] **表演性**：是否标注使相/停顿，读起来可上台？

**总分判定**：
- 48+ → "像于祥宇"
- 32–47 → "有点像，建议加强__"
- <32 → "不像，主要问题：__"

## 四、常见失败模式（生成时规避）

1. **情绪足但文学性欠**：全是"年轻人太难了"式口号，没有具体观察支撑。
2. **缺人设**：忘了"哲学应届生"身份，变成通用段子。
3. **太温**：只吐槽不冒犯，少了"坏"的锋芒。
4. **梗太稀**：铺垫过长，失去两句一梗的密集感。
5. **升华过度**：结尾强行正能量，破坏丧/悲凉底色。
6. **冒犯越界**：嘲讽对象变成具体个人而非"话术/制度"，显得刻薄。
