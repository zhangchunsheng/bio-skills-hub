# 健康检测与轻问诊（药学服务 · 医药连锁 skill）

## 用途
本技能使 WorkBuddy 充当医药连锁（连锁药店）「健康检测与轻问诊」场景的专属助手，覆盖《医药连锁AI应用场景白皮书》对应场景集。健康检测与轻问诊：报告解读、症状分诊、健康方案
## 触发示例
- "帮看下这个体检报告 / 化验单异常指标解读"
- "这个症状该看什么科 / 要不要去医院"
- "给个健康管理方案 / 血压血糖偏高怎么管理"

## 适用场景明细
### 检测报告解读
- **触发**：帮看下这个体检报告 / 化验单异常指标解读
- **输入**：患者体检报告/化验单(图片PDF,需OCR或文本)
- **输出**：通俗化解读(HTML)：异常指标标注+可能意义+建议(复查/就医/生活方式)
- **知识依赖**：检验指标参考范围库；常见异常临床意义
- **合规边界**：药店不得诊断,仅做指标科普解读；异常须建议就医；信息脱敏；AI辅助,药师解读
- **责任岗位**：执业药师

### 症状轻问诊分流
- **触发**：这个症状该看什么科 / 要不要去医院
- **输入**：患者症状描述(自然语言)；可选年龄/性别/持续时间
- **输出**：分流建议(HTML)：严重程度初步判断+就诊科室建议+是否需紧急就医+非处方药提示
- **知识依赖**：症状分诊规则库；急症识别标准
- **合规边界**：药店不得诊断,仅做分流建议；急症须立即就医；不得替代医师诊断；信息脱敏
- **责任岗位**：执业药师

### 健康方案生成
- **触发**：给个健康管理方案 / 血压血糖偏高怎么管理
- **输入**：用户健康数据(体重/血压/血糖/BMI等,脱敏)；可选生活方式
- **输出**：健康管理方案(HTML)：饮食/运动/监测建议+目标值+复查提醒
- **知识依赖**：健康管理指南；慢病生活方式干预
- **合规边界**：不得诊断/开方,仅生活方式建议；异常须就医；信息脱敏
- **责任岗位**：执业药师/健康管理师

## 工作流
1. **明确场景与输入**：根据用户诉求定位目标场景，收集所需输入（文本/CSV/Excel/图片等）。
2. **组织内容**：基于场景要点与领域知识，撰写/归纳结构化内容。
3. **产出 spec**：将内容组织为 render.py 所需的 spec JSON（结构见 references/templates.md）。
4. **渲染交付物**：执行 `python scripts/render.py <spec.json> --format <md|html|docx|json> --output <路径>`。
5. **交付与复核**：返回交付物，提示合规与人工复核要求（见下）。

## 脚本
- `scripts/render.py`：通用文档渲染器（支持 md / html / docx / json）。


## 合规提示
药学服务类场景涉及处方审核、用药指导、患者健康信息。AI仅辅助提示，最终由执业药师审核签字；不得直接诊断、开方或改方；处方变更需医师确认；患者信息须脱敏。处方药不得在大众媒介宣传。
