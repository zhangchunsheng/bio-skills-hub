# General-skill-reviewer — 通用 Skill 评审专家

基于 **LLM 认知科学**的 8 维度评分体系，对任意 Skill 进行架构审计、规则工程质量评估和可操作修复指令输出。

## 触发词

- 评审skill、审查skill、skill review
- 评估skill质量

## 文件结构

| 文件 | 说明 |
|---|---|
| `SKILL.md` | Skill 主体（v2.0），包含完整评审工作流和 8 维度评分标准 |

## 八大评审维度

| 维度 | 满分 | 核心关注 |
|---|:---:|---|
| A. 架构与Token经济性 | 15 | 行数、token 预算、渐进式披露 |
| B. LLM注意力适配 | 15 | P0 首尾呼应、中段刷新 |
| C. 规则工程质量 | 20 | 硬规则数、条件-动作格式、正向/负向比例 |
| D. 知识效率 | 10 | 领域独有知识占比（裸跑测试） |
| E. 示例设计质量 | 10 | 多样性、锚定破除、正反例成对 |
| F. 工作流与门控设计 | 15 | 阶段划分、门控质量、前置淘汰 |
| G. 输出规范与格式约束 | 10 | 结构化模板、格式锚点 |
| H. 鲁棒性与边界处理 | 5 | 边界回退、冲突解决、降级策略 |

## 工作模式

| 模式 | 触发条件 | 行为 |
|---|---|---|
| **单次评审** | 用户直接提交 Skill | 输出完整诊断报告 |
| **迭代驱动** | 被 General-skill-creator 的 PHASE 4/6/7 调用 | 额外输出可操作修改指令列表 |

## 配套 Skill

- **General-skill-creator**：Skill 工程师在 PHASE 7 工程质量审计阶段会调用本 Skill 执行评审。
