# 医疗图片智能识别与脱敏报告（Medical OCR）

## 技能介绍

医疗图片智能识别与脱敏报告生成技能（Medical OCR），专为临床医生和医学研究人员设计，解决医疗文书图片的OCR识别与隐私脱敏两大核心需求。

在实际工作中，门诊病历、化验单、影像学报告等资料常以拍照或扫描件形式存在，难以直接用于科研、教学或跨机构分享——患者姓名、就诊卡号、身份证号、医院名称等隐私信息散落其中，手动脱敏既耗时又容易遗漏。本技能通过AI视觉识别能力对医疗图片进行高精度文字提取，自动判断单病例或多病例，按标准化模板生成结构化Markdown脱敏报告。报告涵盖主诉、现病史（含时间轴）、既往史、过敏史、体格检查、辅助检查（化验数值含异常标记、影像报告全文）、诊断、治疗方案及病情评估共11个模块，完整保留所有临床信息的同时，彻底移除患者姓名、就诊卡号、病历号、身份证号、医疗机构名称、医生签名、具体就诊时刻、地址联系方式等全部隐私标识。支持门诊病历照片、化验单、彩超/CT/MRI报告、PDF扫描件（自动转页处理）等多种输入格式，适用于病例讨论准备、科研病历整理、教学素材脱敏、多中心研究数据预处理等场景。每份报告末尾附带核实提醒，确保脱敏质量可追溯。

## 使用方法

### 第一步：上传图片

将需要处理的医疗图片上传到对话中。支持以下格式：

- 门诊病历照片（手机拍摄即可）
- 化验单照片
- 影像学报告照片（彩超、CT、MRI等报告单）
- PDF扫描件（技能会自动将PDF拆分为单页图片后逐页识别）

可以一次上传一张，也可以一次上传多张。如果分多次上传，上传完毕后告知"全部上传完了"即可。

### 第二步：自动识别与分组

技能会逐张识别所有图片中的文字内容，然后自动判断这些图片属于几位患者。判断依据包括患者姓名、年龄性别、就诊日期等。如果所有图片属于同一位患者，合并为一份报告；如果涉及多位患者，则按患者分组，每人独立输出一份报告。

### 第三步：获取脱敏报告

技能会为每位患者生成一份结构化的Markdown格式脱敏报告，报告按11个标准模块组织：患者基本信息、主诉、现病史（含时间轴）、既往史、过敏史、个人史与家族史、体格检查、辅助检查（分化验单和影像学检查）、诊断、治疗方案、病情评估与建议。所有个人隐私信息在报告中已被彻底移除，同时完整保留全部临床医学内容。

### 第四步：核实确认

每份报告末尾附有核实提醒，请重点检查三个方面：是否有遗漏的隐私信息、医学术语和数值是否准确、诊断中的"待查""疑诊"等关键表述是否完整保留。如发现问题，可直接指出，技能会针对性修正。

### 使用提示

- 图片清晰度越高，识别准确率越高，建议尽量上传高清原图
- 如果一张图片中有模糊字迹，技能会主动标注并询问确认
- PDF扫描件会自动拆页处理，无需手动转换
- 现病史中治疗经历复杂时，报告会自动生成时间轴表格，便于快速回顾病程演变
