# twu-financial-analysis — 上市公司财务分析系统框架 v1.0.0

## 定位

不做表面比率堆砌。做的是：**锚定这家公司在业绩链条和行业空间中的位置，用三路输入（报表事实/经营机制/市场观点）交叉验证，对每个关键判断做正反合检验，最终给出带置信度、带残余不确定性的财务判断**。

适用市场：A 股 + 港股 + 美股。方法体系覆盖 GAAP/IFRS/CAS。

## 职责边界（P0）

- 本 skill 做上市公司财报分析：会计质量、财务表现、同业定位、舞弊识别、估值判断
- 不做市场事件归因（为什么涨跌，转 twu-causal-chain）
- 不做事件影响推演（会怎样传导，转 twu-event-impact）
- 不做未来事件链预测（接下来会发生什么，转 twu-event-predict）
- 不输出具体买卖指令，结论限于公司基本面判断

## 触发条件

**触发**：用户要求分析某家上市公司的财报/业绩/基本面/财务质量/估值水平/舞弊风险，或提供财报文件（PDF/截图）要求解读时启用本 skill。

触发词：财报分析、业绩解读、年报解读、半年报、季报、财务质量、盈余质量、舞弊排查、估值分析、公司质地、护城河、DCF、财务报表、财务数据。

**不触发（转对应 skill）**：
- 只问股价走势/K 线形态 → twu-trend-narrator
- 问行业全景/产业链结构 → twu-industry-analyzer
- 问宏观数据/政策 → macro-data-monitor / macro-monitor
- 问新闻事件对市场的影响 → twu-event-impact

## 三大核心原则（比任何具体方法都重要）

**⏰ 时间高度敏感：所有输出遵守 `references/data_time_audit_rules.md`（P0）。每条财务数据必须附带报告期时间戳，禁止"当前""最新""最近"等无锚定表述。**

1. **时间是分析的骨架**。财报数据是时间序列，不是快照。同一数字在 Q1 和 Q4 含义不同，在行业上行期和下行期含义不同。
2. **分析一家公司就是分析一个行业**。没有同行业参照的财务分析等于没有基准的体检报告。ROE 15% 是好是坏，取决于行业均值是 8% 还是 25%。
3. **财务数据只是拼图的一半**。产能利用率、用户留存率、市场份额、员工周转率，这些非财务数据往往更早反映基本面变化。

## 底层逻辑（P0 · 吸收四个分析 skill 的思考 DNA）

财务分析不是比率计算，是论证。以下八条贯穿整个分析流程：

1. **财务锚定先行（两维）**。一家公司的财报，在时序上是业绩链上的一个环节（相对历史趋势和相对市场预期的位置），在截面上是行业空间里的一个点（公司定位 + 生命周期）。**预期差是财报解读的第一输入**：相对一致预期超/符合/低于，决定第一解读方向。同一份财报，超预期 vs 低于预期发布，结论可能完全相反。

2. **三路输入，不闭门造车**。任何财务判断必须同时吸收三路：
   - **事实路**：报表数据本身，标注 [已验证]/[推断]
   - **理论路**：经营机制论证（这个增长为什么可持续/不可持续）
   - **观点路**：卖方一致预期、分析师分歧、市场反应（行为证据比言论诚实）
   三路同向 → 支持充分；事实+理论同向但观点分歧 → 拷问重点；观点强但事实/理论弱 → 怀疑为情绪驱动。

3. **每个关键判断必须过正反合**。对每个核心判断（"增长可持续""利润质量高""估值合理"），主动构建最强反面论证（替代解释：会计操纵/一次性/低基数/行业贝塔），收敛到"合"。合不是折中，是更完整的认识：条件化（什么条件下成立）、时间分层（短期成立长期存疑）、或重构（问题换一种问法）。

4. **论据铁律**。每条财务断言必须有可验证数据点支撑：区分事实与推断（[已验证]=双源 / [推断]=有旁证 / [推断/无直接数据]=无旁证）；关键数据至少双源交叉；数据与新闻打架以数据为准；被质疑时回应数据而不是态度。**数据来源标注与可信性分级详见"数据来源可信性保障"（P0）。**

5. **时间红线**。原因必须早于结果（禁止把本季数据说成上季业绩变化的原因）；财报窗口标注（盘前/盘中/盘后对应不同反应窗口）；基期效应必须显式检查；跨年对比必须统一口径（TTM/LTM）。

6. **三属性刻画**。对任何财务变化（利润率下降/现金流恶化/应收激增），必须从三个维度刻画：程度（多深）、时长（多久）、范围（影响哪些业务/市场）。只说方向不说三属性，是没有刻度的空话。

7. **置信度与共识度判定**。结论必须分级：高置信（论证链完整、三路同向、无未化解矛盾）/ 中共识（方向可信、幅度不确定）/ 大分歧（正反未化解）。**分歧是有价值的输出**：输出分歧图景、双方论据、裁决信号，不假装全知。

8. **监控变量与残余不确定性**。分析结束时必须给出：(a) 监控变量清单（领先/同步/滞后指标 + 证伪信号）；(b) 残余不确定性清单（数据冲突/信息真空/推断项）。没有验证窗口的判断与占卜无异。

## 数据来源可信性保障（P0 · 用户钦定硬规则）

**上市公司的财务报告是强制披露的公开数据，境内外交易所网站均有完整原始文件，且格式相对固定。这是本 skill 的数据基石：真实性、准确性、完整性必须保障到可追溯的程度。**

### 数据来源五级信任层级

| 层级 | 来源 | 信任度 | 使用规则 |
|------|------|--------|---------|
| L1 | 交易所官方披露文件（巨潮/披露易/SEC EDGAR 原始 PDF） | 最高 | 最终裁决依据，所有关键数据必须能追溯至此 |
| L2 | 交易所结构化接口 + 官方数据商（Tushare/AKShare 抓取的官方披露） | 高 | 效率来源，需与 L1 抽查验证 |
| L3 | 权威数据商/行情终端（Wind/Bloomberg/Yahoo/Alpha Vantage） | 中高 | 标注来源品牌，重要数据需 L1 复核 |
| L4 | 财经媒体/新闻稿（财联社/华尔街见闻/公司新闻稿） | 中 | 只做线索和旁证 |
| L5 | 搜索碎片/二手转述（博客/社交/未署名转载） | 低 | 仅触发深入查证，禁止直接引用 |

**铁律**：
- 涉及收入/净利润/总资产/现金流等核心财务数据的最终结论，必须能追溯到 L1
- 二手数据（L3-L5）与一手数据（L1-L2）冲突时，以一手为准
- 无法追溯到 L1 的数据，标注"[数据来源待核验]"，相关结论降置信度

### 强制标注三要素

**报告中每一条财务数据必须标注三要素，缺一不可：**

```
数据是什么 + 来源（哪个披露文件/接口）+ 报告期（YYYY年Q/半年/年报）
示例："营业收入 715.53 亿元 [2026 半年报，H 股中期业绩公告，报告期 2026-06-30]"
```

- 来源必须具体到文件或接口，禁止"据公开信息""据机构统计"
- 报告期是数据的时间锚，禁止"当前""最新""最近"
- 同一数据多来源时标注差异

### 勾稽关系校验闸门（P0，全局强制）

**数据完整性是硬闸门。** 输出前必须通过五项勾稽校验（BS 平衡 / CF 衔接 / 利润衔接 / 留存收益滚动 / 上年同期数核对），具体公式见 `references/report-fetching.md` 4.3 节。

勾稽不过 → 数据必有问题，禁止进入后续分析。

### 三市场财报科目映射（格式固定性的利用）

**境内外财报格式相对固定，科目可映射。** 从原始 PDF 取数时先做科目映射，防止口径错配。CAS / HKFRS / US GAAP 九项标准科目对照表（收入/毛利/经营利润/归母净利/扣非/合同负债/经营现金流/CapEx）见 `references/report-fetching.md` 4.2 节。

详细数据源 URL、API 参数见 `references/data-sources.md`。

## Part 0: 财务锚定 — 时间维度 + 预期差 + 公司定位

### 0.1 为什么时间维度必须先行

同一条财务数据在不同时间点含义完全不同：
- 茅台 Q4 收入通常是 Q1 的 1.5 倍（春节备货季），不调整季节性直接对比是错的
- 周期股在行业顶部利润最高 PE 最低，但那是卖点不是买点
- 某公司毛利率从 40% 降到 35%，如果它过去 5 年一直在降，和 5 年来第一次降，含义完全不同

### 0.2 报告期识别（分析前必须明确）

每次分析的第一件事，不是算比率，而是回答：

| 必须明确 | 为什么重要 |
|---------|-----------|
| 当前最新报告期是什么？ | 年报？半年报？季报？数据完整度不同 |
| 数据覆盖的时间范围？ | 3 年？5 年？10 年？范围决定结论可信度 |
| 同比还是环比？ | 同比消除季节性，环比反映边际变化 |
| 该公司是否有明显的季节性？ | Q1 强 vs Q4 强，决定对比口径 |
| 最近一期数据是否有"特殊因素"？ | 减值洗澡、并购并表、会计准则变更 |
| 基期是否异常？（详见 0.4） | 基期过高或过低都会扭曲同比口径 |

**强制性要求**：每项指标至少追溯 3 年年度 + 8 个季度（如果数据可得），不做单期分析。

### 0.3 时序趋势分析框架

#### 三层时间粒度

| 层级 | 时间范围 | 分析方法 | 回答的问题 |
|------|---------|---------|-----------|
| **长期趋势** | 5-10 年年报 | 方向判断：改善、恶化还是横盘？ | 基本趋势是什么？ |
| **中期变化** | 3 年年报 + 近 8 季度 | 拐点检测：趋势何时开始变？ | 基本面变好还是变坏？ |
| **短期边际** | 最近 2-4 个季度 | 边际变化：最新一期改善还是恶化？ | 拐点确认？最新信号？ |

#### 趋势分析四问（每个指标必答）

1. **方向**：过去 3-5 年往哪个方向走？
2. **速度**：变化在加速还是减速？
3. **波动**：稳定趋势还是大幅波动？波动来源？
4. **一致性**：这个指标的趋势和其他相关指标是否一致？（如收入增长但应收账款增长更快 = 红旗）

#### 异常检测

| 异常模式 | 示例 | 排查方向 |
|---------|------|---------|
| 结构性断点 | 毛利率从 35% 突然跳到 50% | 并购？会计变更？业务模式变化？ |
| 趋势反转 | ROE 连续 5 年上升后突然下降 | 竞争加剧？周期拐点？管理层变动？ |
| 季节性异常 | 今年 Q4 明显弱于往年 Q4 | 需求走弱？渠道压货后遗症？ |
| 背离信号 | 收入增长 20% 但经营现金流下降 30% | 虚增收入？回款恶化？ |
| 波动率突变 | 历史上稳定的利润率开始大幅波动 | 商业模式变化？管理层盈余管理？ |

### 0.4 基期效应警示

**基期扭曲是最常见的分析错误之一。**
- 去年同期基数极低，今年的"高增长"可能毫无意义
- 去年同期有一次性大额收益，今年的"负增长"可能是正常化而非恶化
- 解决：永远同时报告同比增长率、环比增长率、以及相对正常基期的 CAGR

### 0.5 时间维度的市场差异

| 维度 | A 股 | 港股 | 美股 |
|------|------|------|------|
| 年报截止日 | 12/31 为主，4 月底前披露 | 灵活，3 月底前披露 | 灵活，3 月前披露（大加速） |
| 季报要求 | 强制 Q1/Q3 + 半年报 | 仅半年报+年报 | 10-Q + 10-K |
| 业绩预告 | 强制（大幅变动时） | 自愿 | 自愿（8-K） |
| 数据频率 | Q1 数据可得 | Q1/Q3 无独立报告 | 全部季度有 10-Q |

**分析适配**：港股不期待 Q1/Q3 详细报表；美股注意财年可能与自然年不同（如 Apple 财年截止 9 月）。

### 0.6 预期差判定（财报解读的第一输入，P0）

**同一份财报，相对市场预期的位置决定第一解读方向。**

| 预期差 | 第一解读方向 | 关注重点 |
|--------|------------|---------|
| 明显超预期 | 基本面走强信号，需验证质量驱动还是噪音 | 超在哪，质量如何 |
| 小幅超预期 | 方向确认，幅度有限 | 增速可持续性 |
| 基本符合预期 | 无增量信息，反应取决于细节和指引 | 分部数据、毛利率、现金流、指引 |
| 小幅低于预期 | 暂时性还是趋势性？ | 低于的项目，是否有一次性解释 |
| 明显低于预期 | 基本面恶化信号，需排除一次性因素 | 洗大澡？汇兑？减值？还是真实恶化 |

**规则**：
- 预期必须取自发布前信息（卖方一致预期/业绩预告/公司指引），**不能用发布后市场反应倒推预期**
- 无一致预期数据时，标注"[无一致预期数据]"，降置信度
- 区分"数字预期差"（收入/利润 vs 一致预期）和"质量预期差"（毛利率/现金流/应收质量 vs 市场隐含假设），后者往往更关键

### 0.7 公司定位锚定（是什么与不是什么，P0）

**分析财报前，先锚定这家公司本质上是什么生意。**

| 锚定项 | 问什么 | 产出 |
|--------|--------|------|
| 是什么 | 一句话精确商业定义（含产业链位置） | 商业模式一句话 |
| 不是什么（≥3条） | 与易混商业模式的边界 | 排除清单 |
| 收入驱动 | 卖产品、订阅、抽佣还是项目？ | 收入模式判定 |
| 利润驱动 | 靠价、量、周转还是杠杆？ | DuPont 预判 |
| 生命周期 | 导入/成长/成熟/衰退，依据？ | 生命周期定位 |

**生命周期与财务特征映射**：

| 生命周期 | 财务特征 | 分析重点 |
|---------|---------|---------|
| 导入期 | 收入低、亏损或微利、现金流为负 | 收入增速、订单、资金链、烧钱效率 |
| 成长期 | 收入高增、利润率爬坡、CAPEX 扩张 | 增速质量、毛利率趋势、CAPEX 回报 |
| 成熟期 | 收入放缓、利润率稳定、现金流充沛 | 现金流回报、分红、竞争格局 |
| 衰退期 | 收入下滑、利润率压缩 | 转型方向、退出壁垒、清算价值 |

## Part IX: 实战工作流（v3.5 论证驱动版）

### 完整分析流程

```
Step 0: 财务锚定（P0）
  ├── 时间锚定：报告期窗口 + 季节性 + 基期效应
  ├── 预期差判定：财报 vs 一致预期（超/符合/低于）
  ├── 公司定位锚定：是什么/不是什么/收入与利润驱动/生命周期
  └── 三路输入预收集：事实路 + 理论路 + 观点路
       │
Step 1: 数据收集（三路并行）
  ├── 事实路：目标公司近 5 年年报 + 近 8 季度季报
  ├── 事实路：同行业 3-8 家可比公司同期数据（必须！）
  ├── 事实路：非财务数据（运营指标、产能、用户、员工）
  ├── 理论路：行业报告/管理层指引/产业链信息
  └── 观点路：卖方一致预期、分析师分歧、市场反应
       │
Step 2: 数据可信度验证（P0，过关才继续）
  ├── 审计意见 + 关键会计政策审查
  ├── 盈余质量七维检查（含时间维度）
  ├── M-Score 多年趋势计算
  ├── 红旗清单逐条核对（18 条）
  ├── 勾稽校验闸门（BS 平衡/CF 衔接/利润衔接/留存收益）
  ├── 非财务与财务初步交叉验证
  └── 输出：数据可信度评级（高/中/低/不可信）
       │
       ├── 不可信 → 终止分析，报告红旗
       │
Step 3: 财务分析（时间 + 同业双维度 + 正反合）
  ├── DuPont 分解 → 各因子时序 + 行业排名
  ├── 成长性来源分解 → 增速排行 + 质量判断
  ├── 现金流质量 → 多年模式 + 同业对比
  ├── 偿债能力 → 杠杆位置 vs 行业
  ├── 营运效率 → 各项周转 vs 行业
  ├── 正反合：每个核心判断构建最强反向论证
  │   → 替代解释排查：会计操纵/一次性/低基数/行业贝塔
  └── 输出：财务健康多维评级 + 关键判断的"合"
       │
Step 4: 同业深度定位
  ├── 多维度指标在行业中的排列位置
  ├── 与行业龙头的差距分析
  ├── 差距归因（战略选择 vs 竞争劣势）
  ├── 产业链利润分配分析
  └── 输出：行业竞争力定位
       │
Step 5: 非财务数据深度验证
  ├── Step 2 只做快速矛盾检查（"有没有明显的矛盾"）
  ├── Step 5 做系统性验证（"每个财务变化都有非财务支撑吗"）
  ├── 行业特定运营指标趋势分析
  ├── 非财务与财务全面交叉验证
  ├── 矛盾信号深度排查
  └── 输出：基本面综合画像
       │
Step 6: 估值（重要独立模块 · 多模型交叉验证）
  ├── 公司类型判定 → 主模型选择（1 个）+ 验证模型（1-2 个）
  ├── 输入数据时效性检查（估值基准日/报告期/参数日期）
  ├── 各模型独立计算 → 多模型对比表（价值/区间/可信度/分歧点）
  ├── 区间求交集 + 分歧处理 + 敏感性分析（WACC × g 二维表）
  ├── 观点路校准：我的估值 vs 卖方一致预期 vs 市场定价
  └── 输出：内在价值区间 + 安全边际 + 关键假设清单
       （详见 references/valuation-models.md 六步流程）
       │
Step 7: 综合判断（收敛）
  ├── 综合评分卡
  ├── 预期差总结：增量还是存量信息
  ├── 时间维度总结（变好还是变坏）
  ├── 行业维度总结（领先还是落后）
  ├── 置信度判定：高置信/中共识/大分歧（分歧时给出裁决信号）
  ├── 监控变量：领先/同步/滞后指标 + 证伪信号
  ├── 残余不确定性清单（数据冲突/信息真空/推断项）
  └── 最终结论
```

### 综合评分卡（v3.5）

| 维度 | 权重 | 评分依据 |
|------|------|---------|
| 数据可信度 | 20% | 盈余质量七维 + M-Score + 红旗数量 |
| 舞弊风险 | 15% | 红旗数量 + 非财务交叉验证矛盾数 |
| 财务健康 | 15% | 盈利能力 + 偿债 + 现金流（含同业对比） |
| 成长质量 | 10% | 增长来源 + 可持续性 + 行业增速对比 |
| 行业竞争力 | 15% | 多维度行业排名 + 产业链位置 |
| 非财务趋势 | 10% | 运营指标方向 + 与财务数据一致性 |
| 估值吸引力 | 15% | 安全边际 + 行业估值水位 |

**一票否决**：舞弊风险维度评分 < 3 分，直接否决。

### 置信度判定标准（P0）

| 置信度 | 判定条件 | 输出形态 |
|--------|---------|---------|
| 高置信 | 三路同向 + 论证链完整 + 无未化解矛盾 | 明确结论 + 附带监控变量 |
| 中共识 | 方向可信，幅度/节奏不确定 | 结论条件化（什么条件下成立） |
| 大分歧 | 正反未化解，关键数据缺失或冲突 | 分歧图景 + 双方论据 + 裁决信号 |

**假装全知是财务分析的大忌。** 明确说"我不知道，但我知道怎么才能知道"，比含混的"我判断会怎样"专业得多。

## 降级模式（数据不完整时的处理路径，P0）

**真实世界数据永远不完美。降级不是放弃分析，是显式声明"缺了什么、用什么替代、置信度降多少"。禁止在数据缺失时假装完整。**

| 缺失场景 | 降级路径 | 置信度影响 |
|---------|---------|-----------|
| L1 原始 PDF 拿不到 | 用 L2 结构化接口取数，标注 `[L2 来源]`；关键数据仍无法核验时标 `[数据来源待核验]` | 降一档 |
| 无一致预期数据 | 预期差维度退化为"相对管理层指引 / 相对历史趋势"，标注 `[无一致预期数据]` | 降一档 |
| 港股无季报 | 只用半年报+年报，跨期对比强制 TTM | 中期信号缺失，标注 |
| 新股历史短（<3 年） | 时间窗缩为可得年限，显式声明"样本不足"，不做长期趋势断言 | 趋势类结论降级为"方向不明" |
| 找不到可比公司 | 退化为产业链上下游对比或行业均值参照，标注 Peer 缺失 | 同业维度降级 |
| 勾稽数据不全 | 只输出已通过勾稽的模块，未通过部分标注"未验证"，禁止全盘继续 | 未验证部分不得进入结论 |
| 亏损期/无 FCF（估值） | DCF 降级为备用模型，主模型切换（PS/EV-Revenue/rNPV） | 估值区间放宽 |
| 年报未出（时间窗口） | 用业绩预告/快报做区间估计，标注 `[预告/快报口径]`，正式报告出来前不写死 | 数字精确度降级 |

**规则**：每次降级必须显式声明（缺什么 → 用什么替代 → 置信度降几档），并列入"残余不确定性清单"。

## 核心规则速查（P0/P1/P2）

### P0（违反即失控）

- 数据必须可追溯：核心财务数据最终追溯到 L1 交易所披露文件，标注三要素（数据/来源/报告期）
- 勾稽不过即终止：五项勾稽校验，任一失败禁止继续
- 时间红线：禁止无报告期标注的数字、禁止因果倒置、禁止盘后事件当日归因
- 预期差先行：分析前必须完成预期差判定与公司定位锚定
- 舞弊一票否决：舞弊风险 < 3 分直接否决，不看盈利和估值
- 降级必声明：数据缺失时显式声明替代路径和置信度下调

### P1（质量底线）

- 每个核心判断过正反合（最强反方论证 + 收敛）
- 三路输入（事实/理论/观点）齐全，不做单路分析
- 时序分析：每项指标至少 3 年 + 8 季度，不做单期判断
- 同业参照：没有同行业对比的绝对数不算结论
- 结论分级：高置信/中共识/大分歧必须明确标注

### P2（锦上添花）

- 输出带监控变量（领先/同步/滞后 + 证伪信号）和残余不确定性清单
- 估值多模型交叉验证 + 敏感性二维表
- 报告用 HTML 模板输出，审计级排版
