# 估值分析执行模块（专业多模型估值）

> 本文件是 twu-financial-analysis 的独立估值模块，可被主 skill 调用，也可独立执行单一估值任务。
> 与 `valuation-methods.md` 的分工：methods 讲"每个模型怎么算"，本文件讲"一次专业的估值分析怎么组织"。
> 核心要求：多个模型交叉验证、每个参数有理有据、数据可追溯、结论带区间不装精确。

## 一、估值分析标准流程（六步）

```
Step A: 输入准备（数据时效性第一关）
   ├── 确认估值基准日（当前日期 + 最新可用报告期）
   ├── 收集近 3-5 年财务数据（收入/利润/现金流/资产负债，全部标注报告期）
   ├── 收集行业可比数据（同报告期口径，禁止跨期混用）
   └── 收集无风险利率、风险溢价、beta、税率等市场参数（标注取值日期和来源）
       │
Step B: 公司定位与模型选择
   ├── 公司类型判定（成长/价值/周期/金融/重资产/SaaS…）
   ├── 主估值模型选择（1 个）+ 验证模型（1-2 个）
   └── 明确每个模型的适用理由（为什么选它，为什么不选其他）
       │
Step C: 多模型计算
   ├── 每个模型独立计算，互不污染
   ├── 每个输入参数标注来源（财报报告期 / 市场数据日期）
   └── 每个模型输出"合理区间"而非单点（乐观/中性/悲观假设）
       │
Step D: 交叉验证
   ├── 各模型区间求交集 → 交集区 = 高置信价值区
   ├── 无交集 → 检查哪个模型的假设不合理，重设后重算
   ├── 多模型分歧 → 列出分歧原因，标注哪个模型更可信及依据
   └── 与市场当前价对比 → 判断高估/低估/合理
       │
Step E: 敏感性分析
   ├── 主模型的关键假设做敏感性分析（WACC × 永续增长二维表）
   ├── 识别价值对哪个假设最敏感（该假设的论证要最扎实）
   └── 输出价值区间，不输出单点
       │
Step F: 估值结论
   ├── 内在价值区间 + 基准情景价值
   ├── 安全边际（当前价 vs 区间下沿/中值/上沿）
   ├── 关键假设清单（所有影响结果 >10% 的假设）
   └── 与卖方一致预期、市场定价的差异及解释
```

## 二、多模型选择矩阵（P0：选错模型比算错数字更致命）

| 公司类型 | 主模型 | 验证模型 | 禁用 |
|---------|--------|---------|------|
| 盈利稳定成熟（消费/公用） | DCF (FCFF) | DDM / PE 可比 | — |
| 高成长（科技/SaaS 成熟） | DCF (FCFF) | EV/EBITDA 可比、PEG | 单用 PE |
| 高成长亏损期（SaaS 早期/Biotech） | PS / EV-Rev 可比 | rNPV（管线估值） | PE、DCF（利润为负） |
| 强周期（有色/煤炭/化工） | 周期中枢 PE / PB 分位 | 全周期平均利润 DCF | 当期 PE |
| 金融（银行/保险） | PB-ROE / PEV | DDM | EV/EBITDA |
| 重资产（制造/航运/地产） | EV/EBITDA | PB、RNAV | 单用 PE |
| 控股公司/多元化 | SOTP 分部估值 | 各分部可比加总 | 整体法 PE |
| 高杠杆（LBO 标的） | FCFE / APV | 杠杆可比 | FCFF 不加杠杆调整 |

**规则**：
- 每个分析至少 1 个主模型 + 1 个验证模型，两个模型结论背离时必须解释
- 模型选择必须在报告中写明理由（"为什么用 PB-ROE 而不用 PE"），禁止默认选 PE

## 三、核心模型速查（公式与参数来源要求）

### 3.1 DCF 自由现金流折现（主模型，最常用）

**FCFF 公式**：
```
FCFF = EBIT × (1 - 税率) + 折旧摊销 - 资本支出 - 营运资本增加
股权价值 = FCFF 现值之和 + 永续价值现值 - 净负债
每股价值 = 股权价值 / 稀释后总股本
```

**FCFE 公式**（高杠杆公司更适用）：
```
FCFE = 净利润 + 折旧摊销 - 资本支出 - 营运资本增加 + 净借款
```

**关键参数来源要求（P0）**：

| 参数 | 取值来源 | 时效要求 |
|------|---------|---------|
| 历史 FCF | 财报现金流量表（3-5 年） | 标注报告期 |
| 增长率假设 | 历史 CAGR + 行业增速 + 管理层指引交叉 | 三源对比后取值 |
| WACC | Rf（10 年期国债，标注日期）+ β（历史回归或行业） + ERP（6-8% A 股） | 全部标注取值日期 |
| 永续增长率 g | ≤ 名义 GDP 增速，通常 2-3% | 与 WACC 差值 ≥ 2% |
| 税后净负债 | 最新资产负债表 | 标注报告期 |

**强制性**：DCF 必须做敏感性分析（WACC × g 二维表），禁止只给单点结果。

### 3.2 可比估值（验证模型）

**倍数选择矩阵**：

| 倍数 | 适用 | 不适用 | 数据要求 |
|------|------|--------|---------|
| PE | 盈利稳定非周期 | 亏损、周期顶部 | TTM/Forward 标注 |
| PEG | 成长股 | 成熟低增长 | 增速须可持续 |
| PB | 金融/重资产/周期底部 | 轻资产 | LF 口径 |
| PS | 高成长亏损期 | 成熟低利润率 | TTM |
| EV/EBITDA | 资本结构差异大的同业 | 金融 | TTM |
| EV/FCF | 现金流稳定成熟 | CAPEX 波动大 | TTM |

**可比组要求（P0）**：
- 3-8 家，同业 + 相似商业模式 + 相似规模（收入量级差 < 5 倍）
- **全部使用同一报告期口径（TTM/LTM 对齐），禁止跨期对比**
- 每家公司数据标注来源（交易所披露/数据商）和报告期

### 3.3 剩余收益模型 RIM（会计数据可靠性高的验证）

```
股权价值 = 当前账面价值 + Σ 未来剩余收益现值
剩余收益 = 净利润 - 股权成本 × 期初账面价值
```

适用：金融企业、FCF 波动大的公司、账面价值可靠的公司。

### 3.4 股利折现模型 DDM（银行/公用事业）

```
股权价值 = Σ 未来股利现值（分阶段：高增长期 → 稳定期）
```

适用：股利政策稳定的公司。禁用于不分红的高成长公司。

### 3.5 SOTP 分部估值（控股/多元化）

```
股权价值 = Σ(各业务分部独立估值) - 总部费用现值
```

分部估值方法可不同（赚钱的分部用 PE，亏损期用 PS），加总后减净负债。

### 3.6 rNPV 管线估值（Biotech/创新药）

```
rNPV = Σ(管线项目 × 成功率 × 峰值销售 × 折现)
```

## 四、多模型交叉验证协议（P0）

**一次专业的估值必须给出多模型对比表：**

| 模型 | 中性假设价值 | 区间 | 可信度 | 分歧点 |
|------|------------|------|--------|--------|
| DCF (FCFF) | ¥XX | ¥XX-XX | 高（假设扎实） | — |
| 可比 EV/EBITDA | ¥XX | ¥XX-XX | 中（依赖可比组质量） | 可比组增速差异 |
| SOTP | ¥XX | ¥XX-XX | 低（分部划分主观） | 分部估值方法 |

**收敛规则**：
1. 各模型区间求交集，交集区为高置信价值区
2. 无交集 → 检查假设，找出哪个模型的输入最可疑，重设后重算
3. 有分歧 → 列出分歧原因（增速假设？折现率？可比组？），标注哪个模型与基本面最贴合
4. 最终结论 = 交集区（若存在）+ 分歧说明（若存在）
5. **市场价 vs 内在价值区间**：价格低于区间下沿 = 低估；高于区间上沿 = 高估；在区间内 = 合理

## 五、敏感性分析协议（P0）

**主模型必做二维敏感性表**（DCF）：

| WACC \ g | 1.5% | 2.0% | 2.5% | 3.0% | 3.5% |
|---------|------|------|------|------|------|
| 8%  | ¥XX | ¥XX | ¥XX | ¥XX | ¥XX |
| 9%  | ¥XX | ¥XX | ¥XX | ¥XX | ¥XX |
| 10% | ¥XX | ¥XX | ¥XX | ¥XX | ¥XX |
| 11% | ¥XX | ¥XX | ¥XX | ¥XX | ¥XX |
| 12% | ¥XX | ¥XX | ¥XX | ¥XX | ¥XX |

**敏感性排序**：改变每个关键假设 ±1%，记录价值变动幅度，排序识别最敏感假设。**最敏感的假设必须论证最扎实**（如 DCF 里永续价值占比 >50% 时，g 和 WACC 的论证要格外严格）。

## 六、数据时效性与来源要求（P0 · 用户强调）

**估值结果的可靠性 80% 取决于输入数据的时效性和真实性。**

1. **估值基准日**：报告必须标注"估值基准日 = YYYY-MM-DD"，所有市场参数（股价/利率/beta）取该日或最近可用值
2. **财务数据报告期**：所有财报数据标注报告期（YYYY年Q/半年/年报），禁止"最新财报"模糊表述
3. **跨期对齐**：可比组全部用 TTM/LTM 口径，禁止拿 A 公司 Q1 和 B 公司全年对比
4. **参数来源标注**：无风险利率/ERP/beta/税率/市值/股本 全部标注取值日期和来源
5. **数据真实性**：核心财务数据（收入/利润/现金流）必须能追溯到 L1 交易所披露文件；勾稽校验不过的数据禁止进入估值
6. **假设可追溯**：每个关键假设写明"为什么取这个值"（历史均值/行业对标/管理层指引），禁止拍脑袋

## 七、估值报告输出结构（估值模块独立产出）

```
【估值摘要】
  估值基准日 / 主模型 / 验证模型 / 内在价值区间 / 基准价值 / 当前价 / 安全边际

【1. 输入数据清单】
  1.1 财务数据（3-5 年，标注报告期和来源）
  1.2 市场参数（无风险利率/beta/ERP/税率，标注日期）
  1.3 可比组数据（标注报告期和来源）

【2. 公司定位与模型选择】
  2.1 公司类型判定 + 生命周期
  2.2 主模型选择理由 + 验证模型选择理由
  2.3 禁用模型及原因

【3. 多模型计算与交叉验证】
  3.1 各模型计算过程（假设 → 中间结果 → 价值）
  3.2 多模型对比表（价值/区间/可信度/分歧点）
  3.3 交集区判定 / 分歧处理

【4. 敏感性分析】
  4.1 主模型二维敏感性表
  4.2 最敏感假设识别 + 论证

【5. 估值结论】
  5.1 内在价值区间 + 基准价值
  5.2 安全边际（当前价 vs 区间）
  5.3 与卖方一致预期、市场定价的差异
  5.4 关键假设清单（影响 >10% 的假设）
  5.5 残余不确定性（数据冲突/信息真空/推断项）
```
