## Part I: 会计分析 — 盈余质量与报表可信度

### 1.1 核心问题

在开始任何比率计算之前，必须判断**你看到的数字是真的还是被操纵过的**。

### 1.2 六大关键会计政策审查

| 审查项 | 重点关注 | 危险信号 |
|--------|---------|---------|
| 收入确认 | 确认时点/条件，是否符合业务实质 | 完工百分比法滥用、提前确认、渠道压货 |
| 折旧与摊销 | 折旧方法/年限，是否与同行一致 | 突然延长折旧年限以增厚利润 |
| 资产减值 | 减值测试频率和假设合理性 | 该减值不计、集中"洗大澡" |
| 费用资本化 | 研发/借款费用资本化比例 | 资本化率异常高于同行、软件开发全额资本化 |
| 合并范围 | 并表/出表的依据，VIE 结构 | 隐藏负债的 SPV、关联交易未抵消 |
| 预计负债 | 担保/诉讼/退货等或有负债 | 明显不足额计提 |

### 1.3 表外项目与隐性负债

**部分公司通过表外安排隐藏真实负债或夸大盈利能力。** 以下项目必须额外关注：

| 表外风险 | 常见形式 | 排查方法 |
|---------|---------|---------|
| 经营租赁承诺 | 长期租赁合同（租店铺/设备/飞机） | 查看报表附注"承诺事项"，计算未来最低租赁付款额现值 |
| 应收账款保理/贴现 | 将应收款卖给银行但不终止确认，实质是借款 | 查看附注"金融资产转移"，关注有追索权的转让 |
| 对外担保 | 为子公司/关联方/第三方提供担保 | 查看"或有事项"附注，计算担保总额/净资产比 |
| 未决诉讼 | 潜在的赔偿义务 | 查看"或有负债"披露，关注金额和可能性判断 |
| 对赌/业绩承诺 | 并购中的业绩补偿义务 | 查看并购相关附注，评估对赌失败的概率和金额 |
| 特殊目的实体(SPV) | Enron 式表外融资 | 查看"合并范围""结构化主体"附注，关注是否该并表而未并表 |
| 供应链融资/反向保理 | 延迟向供应商付款但实质是借款 | 查看应付账款附注和融资活动披露 |

**判断标准**：有息负债/总资产可能低估真实杠杆。当"（有息负债 + 表外承诺现值）/（总资产 + 表外承诺现值）"明显高于账面资产负债率时，必须标注"负债可能被低估"。

### 1.4 盈余质量七维检查（含时间维度）

| 维度 | 检查方法 | 时间要求 | 质量信号 |
|------|---------|---------|---------|
| **现金支撑度** | 经营现金流 / 净利润（净现比） | 至少看 5 年趋势 | >0.8 优质，连续<0.3 严重警告 |
| **持续性** | 扣非净利润 / 净利润 | 至少 3 年 | >90%，趋势稳定 |
| **可预测性** | 收入/利润年度波动率 | 5 年标准差 | 波动率越低越好，断崖式变化需解释 |
| **保守性** | 会计政策 vs 同行 + 折旧/减值/资本化趋势 | 3 年趋势 | 比同行保守 = 利润更可靠 |
| **应收账款质量** | 应收增速 vs 收入增速、账龄结构 | 季度+年度 | 应收增速 > 收入增速 1.5 倍 = 红旗 |
| **存货质量** | 存货增速 vs 成本增速、跌价充足率 | 季度+年度 | 存货积压+跌价不足 = 利润注水 |
| **关联交易** | 占比和定价公允性 | 年度趋势 | >10% 且定价不透明 = 高度警惕 |

**时间敏感性检查**：以上每个维度不仅要看当前值，还要看 3-5 年的变化方向。一个净现比从 0.9 降到 0.6 的公司，比一个一直稳定在 0.6 的公司更值得警惕。

### 1.5 非经常性项目与利润正常化

**GAAP 净利润可能包含大量非经常性、非现金项目，直接用于估值会严重误导。必须做正常化调整。**

#### 常见需要剔除的项目

| 类型 | 示例 | 处理方式 |
|------|------|---------|
| 投资公允价值变动 | 权益证券未实现浮盈/浮亏（如 GOOGL Q2 的 $990 亿 Anthropic 浮盈） | 全额剔除，不计入经营利润 |
| 资产处置损益 | 卖楼、卖子公司、卖股权的一次性收益 | 剔除 |
| 大额减值/"洗大澡" | 商誉减值、存货跌价、应收账款核销 | 剔除一次性部分，保留正常计提 |
| 重组费用 | 裁员补偿、业务关闭成本 | 剔除（除非是经常性重组） |
| 诉讼和解 | 一次性赔偿收入/支出 | 剔除 |
| 政府补助/退税 | 非经常性补贴或税收返还 | 评估是否具有持续性 |
| 债务重组损益 | 债务减免、债转股收益 | 剔除 |

#### 正常化三步法

```
Step 1: 识别 → 扫描利润表"其他收益""营业外收支""公允价值变动损益"等科目
Step 2: 剔除 → 从净利润中扣除所有一次性项目（税前），并调整相应税费影响
Step 3: 验证 → 正常化后利润增速应与企业经营趋势一致
         如正常化后利润增长与收入增长严重背离，说明还有其他问题
```

**强制披露**：分析中引用的任何 EPS/PE/ROE，必须标注是基于 GAAP 还是正常化口径。两者差距 > 15% 时必须同时列示并解释原因。

### 1.6 关键比率速查（索引）

完整比率公式见 `references/ratio-formulas.md`（盈利能力/DuPont/成长/现金流/偿债/营运/估值/盈余质量 + 银行/保险/SaaS/地产行业特殊比率）。主文件只保留最核心的五个预警指标：

| 比率 | 公式 | 预警阈值 |
|------|------|---------|
| 净现比 | 经营现金流净额 / 净利润 | < 0.5 连续两年 |
| 应收账款周转天数 | 应收 / (收入/365) | 同比上升 > 15 天 |
| 存货周转天数 | 存货 / (成本/365) | 同比上升 > 30 天 |
| 非经常性损益占比 | (净利润-扣非净利润) / 净利润 | > 20% |
| 资本化率 | 资本化金额 / (资本化+费用化) | 同行业比较，异常偏高 |
