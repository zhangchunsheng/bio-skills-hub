# 非财务数据分析框架（按行业）

## 核心原则

非财务数据是财务数据的领先指标。财务数据告诉你"已经发生了什么"，非财务数据告诉你"正在发生什么"和"将要发生什么"。两者矛盾时，相信非财务数据的预警。

---

## 一、非财务数据体系总览

### 通用框架（所有行业适用）

| 类别 | 关键指标 | 与财务数据的对应关系 |
|------|---------|-------------------|
| **人** | 员工总数、人均收入、人均利润、人均薪酬、核心人员流失率、研发人员占比 | 人均收入下降 → 未来营业利润率下降 |
| **产能/设施** | 产能利用率、在建工程进度、固定资产成新率 | 产能利用率过低 → 固定资产周转率恶化 |
| **客户/用户** | 客户数量、客单价、复购率、NPS、投诉率 | 客单价下降 → 毛利率承压 |
| **渠道** | 门店/网点数量、店效、经销商数量、线上占比 | 经销商减少 → 未来收入下降 |
| **研发/创新** | 研发人员数量、专利数量/引用率、在研项目进度 | 研发人员缩减 → 长期竞争力减弱 |
| **治理** | 独董出席率、关联交易次数、问询函/监管处罚次数 | 独董频繁辞职 → 治理重大隐患 |

## 二、行业特定非财务指标

### 2.1 消费/零售

| 指标 | 定义 | 频率 | 重要性 | 财务对应 |
|------|------|------|--------|---------|
| **同店销售增长(SSSG)** | 可比门店销售额同比变化 | 月度/季度 | ⭐⭐⭐⭐⭐ | 收入增长的质量 |
| **坪效** | 销售额/营业面积 | 季度 | ⭐⭐⭐⭐ | 门店经营效率 |
| **客流量** | 进店/下单人次 | 月度 | ⭐⭐⭐⭐ | 品牌吸引力 |
| **客单价** | 销售额/交易笔数 | 月度 | ⭐⭐⭐ | 定价力/消费升级 |
| **会员数** | 注册会员/付费会员总数 | 季度 | ⭐⭐⭐ | 客户粘性 |
| **复购率** | 重复购买客户占比 | 季度 | ⭐⭐⭐⭐ | 产品满意度 |
| **SKU 数量** | 在售品类数 | 季度 | ⭐⭐ | 产品策略 |
| **库存周转天数（运营口径）** | 实际动销速度 | 月度 | ⭐⭐⭐⭐ | 存货周转率 |

**关键判断**：
- SSSG > 5% 且持续 = 品牌力在增强
- 收入增长靠新开店而非同店增长 = 增长质量差，天花板更近
- 客单价增长 + 客流量增长 = 最佳状态

### 2.2 SaaS/互联网/平台

| 指标 | 定义 | 频率 | 重要性 | 财务对应 |
|------|------|------|--------|---------|
| **DAU/MAU** | 日活/月活用户数 | 日/月 | ⭐⭐⭐⭐⭐ | 用户粘性的最直接度量 |
| **DAU/MAU 比率** | 日活/月活 | 月 | ⭐⭐⭐⭐ | >50% 优秀，<20% 粘性弱 |
| **ARPU** | 每用户平均收入 | 季度 | ⭐⭐⭐⭐ | 对应收入增长 |
| **ARPPU** | 每付费用户平均收入 | 季度 | ⭐⭐⭐⭐ | 定价力 + 用户结构 |
| **付费率** | 付费用户/总用户 | 季度 | ⭐⭐⭐ | 变现能力 |
| **CAC（分渠道）** | 获客成本 | 季度 | ⭐⭐⭐⭐ | 对应销售费用效率 |
| **Churn Rate** | 月/年流失率 | 月度 | ⭐⭐⭐⭐⭐ | **最敏感指标** |
| **NPS** | 净推荐值 | 季度 | ⭐⭐⭐ | 未来增长的领先指标 |
| **LTV** | 客户生命周期价值 | 季度 | ⭐⭐⭐⭐ | CAC 回收和盈利判断 |
| **员工人效** | ARR/员工数 | 年度 | ⭐⭐⭐ | 规模效应的运营度量 |
| **服务器/基础设施利用率** | 资源使用率 | 实时 | ⭐⭐ | 对应毛利率中的云成本 |

**关键判断**：
- NRR > 120% = 最优，现有客户在扩大消费
- Churn > 1%/月 = 严重警告，一年流失 > 11%
- DAU/MAU 持续下降 = 用户粘性恶化，收入减速的前兆

### 2.3 制造业

| 指标 | 定义 | 频率 | 重要性 | 财务对应 |
|------|------|------|--------|---------|
| **产能利用率** | 实际产量/设计产能 | 季度 | ⭐⭐⭐⭐⭐ | 固定资产周转率 |
| **良品率** | 合格品/总产出 | 月度 | ⭐⭐⭐⭐ | 毛利率中的制造成本 |
| **订单(Backlog)** | 在手未交付订单 | 季度 | ⭐⭐⭐⭐ | 未来 1-2 季度收入 |
| **订单出货比(B2B)** | 新订单/出货量 | 月度 | ⭐⭐⭐⭐ | >1 = 订单积压，未来收入增长 |
| **原材料库存天数** | 原材料库存/(日耗用量) | 月度 | ⭐⭐⭐ | 存货结构分析 |
| **产成品库存天数** | 产成品库存/(日出货量) | 月度 | ⭐⭐⭐⭐ | 需求是否在走弱 |
| **单位制造成本** | 总制造成本/产量 | 季度 | ⭐⭐⭐ | 规模效应是否释放 |
| **员工人数** | 生产/研发/销售人员 | 季度 | ⭐⭐⭐ | 人效变化 |
| **CAPEX 进度** | 在建工程完工百分比 | 季度 | ⭐⭐⭐ | 产能释放时间表 |
| **设备综合效率(OEE)** | 时间利用率×性能×良品率 | 月度 | ⭐⭐⭐ | 综合生产效率 |

**关键判断**：
- 产能利用率 > 85% = 接近满产，有提价基础
- 产成品库存天数上升 + 原材料库存下降 = 被动减产，需求走弱
- 订单 backlog 增长 = 需求旺盛，未来收入锁定

### 2.4 医药

| 子行业 | 关键非财务指标 | 重要性 | 财务对应 |
|--------|-------------|--------|---------|
| **创新药** | 临床入组人数/进度 | ⭐⭐⭐⭐⭐ | 研发费用资本化合理性 |
| | NDA/BLA 提交时间表 | ⭐⭐⭐⭐⭐ | 未来收入预期 |
| | 专利到期倒计时 | ⭐⭐⭐⭐⭐ | 收入断崖风险 |
| | 竞争格局（同类产品数量） | ⭐⭐⭐⭐ | 峰值销售预期 |
| **CXO** | 在手订单/backlog | ⭐⭐⭐⭐⭐ | 未来 1-2 年收入 |
| | 产能利用率 | ⭐⭐⭐⭐ | 利润率 |
| | 客户数量、前五大客户占比 | ⭐⭐⭐ | 客户集中度风险 |
| | 项目阶段分布（临床前/临床/商业化） | ⭐⭐⭐ | 收入质量 |
| **器械** | 注册证数量（三类>二类>一类） | ⭐⭐⭐⭐ | 竞争壁垒 |
| | 集采中标情况 | ⭐⭐⭐⭐⭐ | 收入和利润率 |
| | 医院覆盖数 | ⭐⭐⭐ | 渠道渗透 |
| **中药** | 原材料种植/采购基地面积 | ⭐⭐⭐ | 成本控制 |
| | 品牌价值榜排名 | ⭐⭐⭐ | 定价权 |

### 2.5 银行

| 指标 | 定义 | 频率 | 重要性 | 财务对应 |
|------|------|------|--------|---------|
| **不良生成率** | 新增不良/贷款总额 | 季度 | ⭐⭐⭐⭐⭐ | 比存量不良率敏感得多 |
| **逾期 30/60/90 天+贷款** | 按逾期天数分层 | 季度 | ⭐⭐⭐⭐⭐ | 不良率的领先指标 |
| **关注类贷款迁徙率** | 关注类→不良的比例 | 季度 | ⭐⭐⭐⭐ | 拨备压力的前置指标 |
| **网点/分支机构数** | 物理渠道变化 | 年度 | ⭐⭐⭐ | 零售战略 |
| **零售客户数/AUM** | 个人客户数和管理资产 | 季度 | ⭐⭐⭐⭐ | 财富管理收入 |
| **手机银行 MAU** | 线上渠道活跃度 | 季度 | ⭐⭐⭐ | 数字化转型 |
| **员工数/人均利润** | 人效 | 年度 | ⭐⭐⭐ | 成本收入比 |

**关键判断**：
- 逾期 30 天+ 贷款开始上升而存量不良率还没变化 = 资产质量恶化前兆
- 关注类贷款迁徙率突然上升 = 下一季度不良率大概率上升

### 2.6 房地产

| 指标 | 定义 | 重要性 | 财务对应 |
|------|------|--------|---------|
| **合约销售额（当月）** | 签约金额/面积 | ⭐⭐⭐⭐⭐ | 未来结算收入 |
| **销售回款率** | 实际回款/合约销售 | ⭐⭐⭐⭐⭐ | 现金流质量 |
| **土储去化周期** | 土储/年销售面积 | ⭐⭐⭐⭐ | 土储是否过剩 |
| **新开工面积** | 当期新开工 | ⭐⭐⭐⭐ | 未来可售货值 |
| **竣工面积** | 当期竣工交付 | ⭐⭐⭐ | 当期结算收入 |
| **平均售价(ASP)变化** | 签约均价 | ⭐⭐⭐⭐ | 毛利率趋势 |
| **拿地强度** | 新增土储金额/合约销售 | ⭐⭐⭐ | 扩张意愿 |

## 三、非财务与财务数据交叉验证矩阵

**这是最有力的分析工具。** 当以下矛盾出现时，优先相信非财务数据的预警：

| 财务数据表现 | 非财务数据表现 | 推断 | 行动 |
|------------|-------------|------|------|
| 收入增长 30% | 员工数下降 5% | 人效被过度挤压，增长不可持续 | 下调未来增速预期 |
| 收入增长 30% | 经销商数量下降 10% | 压货式增长，渠道在萎缩 | 高度警惕 |
| 利润增长 20% | 产能利用率下降至 60% | 利润含水分（可能非经常性） | 核查利润来源 |
| 毛利率提升 5% | ASP 下降 5% | 毛利率提升来自成本端，不可持续 | 核查成本变化原因 |
| 用户数增长 50% | ARPU 下降 40% | 获客质量差，低价值用户稀释 | 下调 LTV 估计 |
| 收入平稳 | 研发人员大幅缩减 | 公司在削减未来投入 | 长期竞争力担忧 |
| 净利润创新高 | 员工满意度/NPS 持续下降 | 内部问题在积累 | 关注离职率和客户流失 |
| 现金流恶化 | 应付账款天数突然延长 | 对供应商开始拖欠，资金紧张 | 流动性风险升级 |

## 四、非财务数据的获取渠道

| 渠道 | 适合获取什么 |
|------|------------|
| 年报/招股说明书 | 员工数、产能、门店数、研发投入、专利、前五大客户/供应商 |
| 季报/月度经营数据公告 | 合约销售（地产）、保费收入（保险）、月度出货/产量（制造业） |
| 行业研究报告 | 市场份额、行业排名、产能对比 |
| 投资者交流纪要/调研 | 管理层披露的运营指标（产能利用率、订单量、客户数等） |
| 第三方数据 | 电商平台销量、APP 下载量/DAU、专利数据库、招聘网站 |
| 监管披露 | 医保准入、药品批签发、生产许可证、环评报告 |
| 新闻/社交媒体 | 消费者评价、员工评价、行业口碑 |
