# 财务比率公式速查表

## 盈利能力

| 比率 | 公式 | 说明 |
|------|------|------|
| 毛利率 | (收入 - 营业成本) / 收入 | 核心竞争力的第一检验 |
| 营业利润率 | 营业利润 / 收入 | 含费用控制能力 |
| EBITDA 利润率 | EBITDA / 收入 | 剔除非现金因素的核心盈利能力 |
| 净利润率 | 净利润 / 收入 | 最终盈利水平 |
| ROE | 净利润 / 平均股东权益 | 股东回报的终极指标 |
| ROA | 净利润 / 平均总资产 | 资产运用效率 |
| ROIC | NOPAT / 投入资本 | 剔除杠杆因素的真实投资回报 |
| 扣非 ROE | 扣非净利润 / 平均股东权益 | 剔除一次性因素的可持续 ROE |
| 经常性 ROE | (净利润 - 非经常性损益) / 平均股东权益 | 核心业务创造的价值 |

## DuPont 分解

```
ROE = 净利润率 × 总资产周转率 × 权益乘数
    = (净利润/收入) × (收入/平均总资产) × (平均总资产/平均股东权益)
```

### 五因子扩展：
```
ROE = 税负因子 × 利息负担因子 × EBIT利润率 × 资产周转率 × 权益乘数
    = (净利润/EBT) × (EBT/EBIT) × (EBIT/收入) × (收入/总资产) × (总资产/权益)
```

## 成长性

| 比率 | 公式 | 说明 |
|------|------|------|
| 收入增长率 | (本期收入-上期收入) / 上期收入 | 看趋势不看单点 |
| 净利润增长率 | (本期净利润-上期净利润) / 上期净利润 | 需剔除非经常性因素 |
| 可持续增长率 | ROE × (1 - 分红率) | 理论最大内生增速 |
| 总资产增长率 | (期末总资产-期初总资产) / 期初总资产 | 扩张速度 |

## 现金流

| 比率 | 公式 | 说明 |
|------|------|------|
| 净现比 | 经营活动现金流净额 / 净利润 | **最重要的单一质量指标** |
| 自由现金流(FCF) | 经营活动现金流净额 - 资本支出 | 真实可支配现金 |
| FCF/收入 | 自由现金流 / 收入 | > 5% 优秀 |
| FCF/净利润 | 自由现金流 / 净利润 | > 0.7 稳健 |
| CAPEX/折旧 | 资本支出 / 折旧摊销 | < 1 维持性，> 1.5 扩张性 |
| 现金流利息覆盖 | 经营现金流 / 利息支出 | > 5x 安全 |

## 偿债能力

| 比率 | 公式 | 安全阈值 | 适用 |
|------|------|---------|------|
| 流动比率 | 流动资产 / 流动负债 | > 1.5 | 通用 |
| 速动比率 | (流动资产 - 存货) / 流动负债 | > 1.0 | 通用 |
| 现金比率 | (货币资金 + 交易性金融资产) / 流动负债 | > 0.3 | 保守检验 |
| 资产负债率 | 总负债 / 总资产 | < 60% | 非金融 |
| 有息负债率 | 有息负债 / 总资产 | < 30% | 关注真实偿债压力 |
| 权益乘数 | 总资产 / 股东权益 | < 3x | 非金融 |
| 利息覆盖倍数 | EBIT / 利息支出 | > 5x | 通用 |
| EBITDA 利息覆盖 | EBITDA / 利息支出 | > 7x | 资本密集行业 |

## 营运效率

| 比率 | 公式 | 说明 |
|------|------|------|
| 应收账款周转率 | 收入 / 平均应收账款 | 越高越好 |
| 应收账款周转天数 | 365 / 应收账款周转率 | 趋势恶化是重要红旗 |
| 存货周转率 | 营业成本 / 平均存货 | 行业差异巨大 |
| 存货周转天数 | 365 / 存货周转率 | 看趋势和同业比较 |
| 应付账款周转天数 | 365 / (营业成本 / 平均应付) | 越高对上游议价力越强 |
| 现金转化周期 | 应收天数 + 存货天数 - 应付天数 | 越短越好，负数为最佳 |
| 固定资产周转率 | 收入 / 平均固定资产 | 越高 = 资本效率越好 |
| 总资产周转率 | 收入 / 平均总资产 | 反映整体资产效率 |

## 估值倍数

| 倍数 | 公式 | 适用场景 |
|------|------|---------|
| PE (TTM) | 股价 / 过去 12 个月 EPS | 盈利稳定企业 |
| PE (Forward) | 股价 / 预测未来 12 个月 EPS | 增长预期已反映 |
| PEG | PE / 盈利增长率(%) | 成长股，PEG < 1 低估 |
| PB | 股价 / 每股净资产 | 金融、重资产、周期底部 |
| PS (TTM) | 总市值 / 过去 12 个月收入 | 高增长亏损期 |
| EV/EBITDA | (市值+净负债) / EBITDA | 资本结构差异大的同业比较 |
| EV/EBIT | (市值+净负债) / EBIT | 含折旧影响 |
| EV/FCF | (市值+净负债) / 自由现金流 | 现金流稳定的成熟企业 |
| 股息率 | 每股股息 / 股价 | 稳定分红企业 |
| PEV | 市值 / 内含价值 | 保险专用 |

## 盈余质量 / 舞弊识别

| 比率 | 公式 | 阈值 |
|------|------|------|
| 应计比率(TATA) | (净利润 - 经营现金流) / 总资产 | > 0.1 警惕 |
| 非经常性损益占比 | (净利润 - 扣非净利润) / 净利润 | > 20% 警惕 |
| 应收账款/收入 | 应收账款 / 收入 | 同行业比较，异常偏高警惕 |
| 存货/收入 | 存货 / 收入 | 同行业比较，异常偏高警惕 |
| 其他应收款/总资产 | 其他应收款 / 总资产 | > 5% 警惕（可能资金占用） |
| 商誉/净资产 | 商誉 / 净资产 | > 30% 警惕（减值风险） |

## 行业特殊比率

### 银行
| 比率 | 公式 |
|------|------|
| 净息差(NIM) | (利息收入 - 利息支出) / 生息资产平均余额 |
| 净利差(NIS) | 生息资产收益率 - 计息负债成本率 |
| 不良贷款率(NPL) | 不良贷款余额 / 贷款总额 |
| 拨备覆盖率 | 贷款损失准备 / 不良贷款余额 |
| 拨贷比 | 贷款损失准备 / 贷款总额 |
| 成本收入比 | 业务及管理费 / 营业收入 |
| ROA | 净利润 / 平均总资产 |
| RORWA | 净利润 / 平均风险加权资产 |
| 存贷比(LTD) | 贷款总额 / 存款总额 |

### 保险
| 比率 | 公式 |
|------|------|
| 综合成本率 | (赔付支出+费用) / 保费收入 |
| NBV Margin | 新业务价值 / 首年保费 |
| 投资收益率 | 投资收益 / 平均投资资产 |

### SaaS/互联网
| 比率 | 公式 |
|------|------|
| ARR | MRR × 12 |
| NRR | (期初 ARR + 升级 - 降级 - 流失) / 期初 ARR |
| Churn Rate | 月度流失 MRR / 期初 MRR |
| LTV | 平均每客户月毛利 × 平均客户生命周期(月) |
| CAC | 销售市场费用 / 新增客户数 |
| LTV/CAC | LTV / CAC |
| CAC Payback | CAC / 月度毛利 |
| Rule of 40 | 收入增长率(%) + FCF 利润率(%) |

### 房地产
| 比率 | 公式 |
|------|------|
| 净负债率 | (有息负债 - 现金) / 股东权益 |
| 合约销售回款率 | 实际回款 / 合约销售额 |
| 土储去化周期 | 土储建面 / 年销售面积 |
