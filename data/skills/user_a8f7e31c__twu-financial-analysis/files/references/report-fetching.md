# 定期报告规范抓取模块（重要独立模块）

> 定位：上市公司财务报告是**监管强制披露的公开数据**，证监/交易所对定期报告有严格的内容与格式要求，格式相对固定。本模块解决"按监管规范怎么抓、抓什么、如何保证真实准确完整 + 时效性"。
> 与 `data-sources.md` 的分工：data-sources 讲**数据源在哪**（URL/API/平台），本模块讲**按规范抓取的标准化动作**（报告制度/标准清单/三性保障/披露时限）。两者配合使用。
> 可独立执行单一任务（"抓取 XX 公司最新财报原始数据"），也是主 skill Step 1 数据收集"事实路"的标准动作。松耦合设计，不依赖主文件其他部分。

---

## 一、三市场定期报告制度总览（P0，监管依据 + 披露时限）

**核心认知：披露时限是监管硬约束，直接决定数据的时效窗口。抓取前先判断目标公司当前处于哪个披露周期，缺哪个报告。**

### 1.1 A 股（证监会 + 沪深交易所）

| 报告类型 | 披露时限（硬性） | 说明 |
|---------|----------------|------|
| 年度报告 | 会计年度结束之日起 **4 个月内**（4 月 30 日前） | 必须含审计报告；格式准则：证监会《年度报告的内容与格式》第 2 号 |
| 半年度报告 | 上半年结束之日起 **2 个月内**（8 月 31 日前） | 格式准则第 3 号 |
| 一季报 | 4 月 30 日前 | 与年报同期披露 |
| 三季报 | 9 个月结束之日起 **1 个月内**（10 月 31 日前） | |
| 业绩预告 | 触发条件时强制（净利为负/扭亏/同比变动 50% 以上等），年度预告须在会计年度结束后 **1 个月内**（1 月 31 日前） | 创业板/科创板自愿披露 |
| 业绩快报 | 自愿披露 | 正式报表前提前给市场 |

- **指定披露平台**：巨潮资讯网（www.cninfo.com.cn，唯一法定披露平台）。上市公司公告 PDF 原文在此，结构化 XBRL 数据辅助。
- **监管依据**：《证券法》《上市公司信息披露管理办法》（证监会令 182 号）、沪深交易所《股票上市规则》及自律监管指引。
- **格式固定性**：年报/半年报有证监会强制内容格式（公司简介/会计数据/管理层讨论/报表/附注顺序固定），抓取时可按固定章节定位。

### 1.2 港股（港交所）

| 报告类型 | 披露时限（硬性） | 说明 |
|---------|----------------|------|
| 年度业绩公告 | 财年结束后 **3 个月内**刊发（《上市规则》13.49(1)） | 须经核数师同意；核数师未同意时须刊发并明确标注"未经审核"业绩 |
| 完整年报 | 股东周年大会前至少 **21 天**派发 | |
| 中期业绩公告 | 财年首 6 个月结束后 **2 个月内**（13.48(1)），12 月财年公司通常 8 月 31 日前 | |
| 季报 | **无强制要求** | 分析港股不要期待 Q1/Q3 详细报表 |

- **指定披露平台**：HKEXnews 披露易（www.hkexnews.hk，唯一官方）。中英双语。
- **监管依据**：港交所《上市规则》第 13 章、香港《公司条例》。
- **会计口径**：HKFRS（与 IFRS 基本一致）。

### 1.3 美股（SEC）

| 报告类型 | 披露时限（硬性） | 说明 |
|---------|----------------|------|
| 10-K（年报） | 财年结束后：大型加速披露人 **60 天** / 加速披露人 **75 天** / 非加速披露人 **90 天** | 内容规范 Regulation S-K，报表格式 Regulation S-X |
| 10-Q（季报） | 财季结束后：大型加速/加速披露人 **40 天** / 非加速披露人 **45 天** | |
| 8-K（重大事件） | 事件发生后 **4 个营业日内** | Exhibit 99.1 通常即业绩新闻稿 |
| 20-F（外国私人发行人年报，中概股适用） | 财年结束后 4-6 个月内（视披露人分类） | 配套 6-K 相当于 8-K |
| 财年差异 | **美国公司财年可与自然年不同** | Apple 9 月 / Nike 5 月 / Microsoft 6 月 / Walmart 1 月，抓取前先确认财年截止日 |

- **指定披露平台**：SEC EDGAR（www.sec.gov/edgar，唯一官方）。免费全文检索。
- **监管依据**：1934 年证券交易法、Regulation S-K/S-X、SAB。
- **格式固定性**：10-K 固定章节顺序（Item 1-16），报表在 "Financial Statements and Supplementary Data"（Item 8）；10-Q 在 Item 1。按章节号定位即准。

## 二、抓取流程（六步标准动作）

```
Step 1 识别目标：报告类型（年报/中报/季报）+ 目标期（最近一期 / 追溯 N 年）
Step 2 定位官方源：巨潮 / HKEXnews / EDGAR，按公司代码检索，锁定原始 PDF
Step 3 标准科目提取：按第四节科目清单逐项取数（三市场科目映射表先行）
Step 4 勾稽校验：三大报表内部 + 报表间衔接 + 与附注核对（不过 → 终止并报告）
Step 5 时效性标注：报告期 + 披露日 + 抓取日，检查有无后续修订/重述
Step 6 完整性核对：标准清单逐项打勾，缺项显式标注"未披露/未获取"
```

## 三、真实准确完整三性保障（P0 硬规则）

### 真实性
- **只从官方源取数**。核心财务数据必须能在原始 PDF 中找到对应行。
- 财经媒体/券商研报的数字只做线索和旁证，禁止直接引用替代报表。
- 转述数据一律标注 `[转述，待原始文件核验]` 并降置信度。

### 准确性
- **科目口径映射先行**：CAS / HKFRS / US GAAP 差异（见 4.2 映射表），防止"营业利润"当"经营利润"、口径错配。
- **单位与币种核对**：人民币/港元/美元，元/千元/百万元/十亿元，A 股财报通常以元列示、摘要以亿元列示；美股以百万美元（$ in millions）为常见列示单位。
- **合并 vs 母公司口径**：默认取合并报表；归母 vs 净利润区分。
- **同比口径一致性**：跨年对比必须同口径（会计准则变更/并表范围变化需显式调整说明）。

### 完整性
- **标准科目清单逐项核对**（第四节），缺项必须显式标注，禁止静默跳过。
- 三大报表 + 附注关键项 + 管理层讨论（MD&A/MDA）+ 审计意见 + 分部数据，五类缺一不可。
- 附注才是完整性的主战场：商誉减值、关联交易、担保、诉讼、会计政策变更往往藏在附注。

## 四、标准抓取清单（科目级，三市场通用）

### 4.1 报表科目清单

| 区块 | 必抓科目 |
|------|---------|
| 利润表 | 营业收入 / 营业成本 / 毛利润 / 研发费用 / 销售+管理费用 / 经营利润(EBIT) / 利息净额 / 税前利润 / 所得税 / 净利润 / **归母净利润** / 扣非净利润（A股） / 稀释 EPS / 加权平均股本 |
| 资产负债表 | 货币资金 / 交易性金融资产 / 应收账款 / 存货 / 固定资产+在建 / 商誉 / 总资产 / 短期借款+一年内到期 / 应付账款 / 合同负债(预收) / 长期借款+债券 / 总负债 / 股东权益 / **归母权益** |
| 现金流量表 | 经营现金流净额 / 投资现金流净额 / 筹资现金流净额 / 资本开支 / 自由现金流(OCF-CapEx) |
| 附注关键项 | 审计意见类型 / 会计政策与估计变更 / 商誉及减值测试 / 关联交易金额 / 对外担保 / 诉讼仲裁 / 分部数据（按业务+按地区）/ 非经常性损益明细（A股） |
| 管理层讨论 | 收入变动归因 / 毛利率变动归因 / 经营展望与指引 / 重大风险提示 |
| 非财务（如适用） | 产能/出货量/订单/用户数/门店数/研发人员占比/管理层指引数字 |

### 4.2 三市场科目映射（格式固定性的利用）

| 概念 | CAS（A股） | HKFRS（港股） | US GAAP（美股） |
|------|-----------|--------------|----------------|
| 收入 | 营业收入 | Revenue | Revenue / Net sales |
| 毛利润 | 营业成本扣减后 | Gross profit | Gross profit |
| 经营利润 | 营业利润 | Operating profit | Operating income / Operating profit |
| 归母净利润 | 归属于母公司所有者的净利润 | Profit attributable to owners of the company | Net income attributable to controlling interests（少见，美股多为单列） |
| 扣非净利润 | 扣除非经常性损益后净利润 | 无直接对应（看 underlying/normalized 口径） | Non-GAAP net income（公司自定义，须与 GAAP 对账） |
| 合同负债 | 合同负债（新收入准则后替代预收款项） | Contract liabilities | Contract liabilities / Deferred revenue |
| 经营现金流 | 经营活动产生的现金流量净额 | Net cash from operating activities | Net cash provided by operating activities |
| 资本开支 | 购建固定资产、无形资产和其他长期资产支付的现金 | Purchase of PP&E etc. | Capital expenditures（CapEx） |

**注意**：非 GAAP/调整后指标（美股 Non-GAAP、港股 underlying profit）是公司自定义口径，必须与 GAAP/准则口径对账后才能用，禁止直接并列。

### 4.3 勾稽校验清单（不过即终止）

- [ ] 资产负债表平衡：总资产 = 总负债 + 股东权益
- [ ] 利润衔接：期末未分配利润 = 期初 + 本期归母净利 − 分红 ± 其他调整
- [ ] 现金流衔接：现金期末余额 = 期初 + 经营 + 投资 + 筹资净额 ± 汇率影响
- [ ] 报表间勾稽：净利润 vs 经营现金流差异可解释（折旧/营运资本/非现金项）
- [ ] 上年同期数核对：本期报告列示的上年同期数 = 上期报告披露数（防追溯调整遗漏）

## 五、时效性保障（P0）

1. **披露时限速查**：见第一节三市场表格。抓取时先判断目标报告是否已过法定披露日；未到披露日的报告不存在，搜索到"预测"要标注 `[预测/非披露]`。
2. **报告期 vs 披露日区分**：报告期是数据覆盖期间（如 FY2025 Q2 截止 2025/6/30），披露日是数据公之于众的日期（如 2025/7/22 盘后）。两者都必须在输出中标注。
3. **重述与修订跟踪**：关注 10-K/A、10-Q/A、8-K、更正公告、会计差错更正（A 股）。公司发布更正后，以**最新版**为准，旧数据标注 `[已修订]`。
4. **抓取日标注**：输出注明"数据抓取日 YYYY-MM-DD"，让读者判断时效。
5. **跨期对齐**：同业对比强制 TTM/LTM 口径；港股无季报，跨市场对比用 TTM 消除频率差异。
6. **数据新鲜度分级**：本披露期数据（最新）/ 上披露期（可对比）/ 超过 2 个披露期（陈旧，仅作趋势参照，不能当"当前"用）。

## 六、与主 skill 的衔接

- 主 skill **Step 1 数据收集**的"事实路"标准动作：按本模块六步流程抓取，输出标准科目清单 + 勾稽结果 + 时效标注。
- 勾稽校验失败或无法追溯到 L1 官方源 → 触发主 skill"数据来源可信性保障"闸门，终止或降置信度。
- 输出报告的"数据来源"章节引用本模块抓取清单，逐项标注 `[科目, 来源文件, 报告期, 披露日]`。
- 舞弊识别阶段（fraud-detection.md）若发现报表数字与附注矛盾，回到本模块复核原始 PDF，禁止用转述数据下结论。
