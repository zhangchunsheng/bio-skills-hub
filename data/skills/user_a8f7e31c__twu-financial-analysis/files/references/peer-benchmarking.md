# 同业对比方法论详解

## 核心原则

**分析一家公司就是分析一个行业。** 没有同行业参照系的财务分析等于没有基准的体检报告。同一组财务数据，在行业内可能优秀、平庸或危险。

---

## 一、Peer Group 选择方法论

### 1.1 选择标准（按优先级排序）

| 优先级 | 标准 | 为什么 |
|--------|------|--------|
| P0 | 同一子行业（GICS 四级/申万三级） | 不同子行业的商业模式差异可能极大 |
| P0 | 相似商业模式 | B2B vs B2C、产品 vs 服务、自有品牌 vs 代工 |
| P1 | 收入规模差距 ≤ 5 倍 | 千亿和十亿级别的公司可比性低 |
| P1 | 相同市场（A/港/美） | 估值体系不同，PE 不能直接比较 |
| P2 | 相似生命周期阶段 | 成长期和成熟期增速不可比 |
| P2 | 上市时间 ≥ 2 年 | 新股财务数据不稳定 |

### 1.2 选择数量

- **3-5 家**：精细对比，深度研究
- **5-8 家**：统计意义更强，适合行业概览
- **超过 8 家**：关注度稀释，建议只取头部

### 1.3 标准 Peer Group 选择模板

```
目标公司：[名称]（[代码]）

核心 Peer：
  1. [公司名]（[代码]）— [为什么选它]（如：行业第一，规模相似，直接竞争）
  2. [公司名]（[代码]）— [理由]
  3. [公司名]（[代码]）— [理由]

扩展 Peer：
  4. [公司名]（[代码]）— [理由]（如：规模较小但同赛道）
  5. [公司名]（[代码]）— [理由]

排除：
  - [公司名] — [排除理由]（如：业务结构差异大 / 刚上市 / 重大重组中）
```

## 二、多维对标指标体系

### 2.1 增长维度

| 指标 | 对标方式 | 解读 |
|------|---------|------|
| 3 年收入 CAGR | 排列 + 差距 | 公司在行业中的增长排名 |
| 最近 8 季度收入增速趋势 | 趋势图对比 | 公司增速在加速（领先）还是减速（落后）？ |
| 增长质量（内生 vs 并购） | 定性对比 | 公司的增长来源比同行更健康吗？ |

### 2.2 盈利维度

| 指标 | 对标方式 | 解读 |
|------|---------|------|
| 毛利率 + 5 年趋势 | 排列 + 趋势对比 | 毛利率更高 = 更强定价权或成本优势 |
| 净利率 + 5 年趋势 | 排列 | 综合考虑费用控制后的竞争力 |
| ROE + 5 年趋势 | 排列 + DuPont 驱动对比 | 公司的 ROE 由什么驱动？和同行一样吗？ |
| 扣非 ROE（剔除非经常性） | 排列 | 核心业务竞争力对比 |
| ROIC | 排列 | 最纯粹的投资回报率对比 |

### 2.3 效率维度

| 指标 | 对标方式 | 解读 |
|------|---------|------|
| 应收账款周转天数 | 排列 + 趋势 | 回款能力对比，差异可能来自客户结构 |
| 存货周转天数 | 排列 + 趋势 | 营运效率对比，差异可能来自产品策略 |
| 总资产周转率 | 排列 | 资本效率的综合对比 |
| 固定资产周转率 | 排列 | 重资产行业的效率对比 |
| 现金转化周期 | 排列 | 综合营运资金效率 |
| 人均收入 | 排列 | 人效对比，轻资产公司更重要 |
| 人均利润 | 排列 | 综合人效对比 |

### 2.4 财务健康维度

| 指标 | 对标方式 | 解读 |
|------|---------|------|
| 资产负债率 | 排列 | 杠杆水平在行业中的位置 |
| 利息覆盖倍数 | 排列 | 偿债安全边际对比 |
| 净现比 | 排列 + 趋势 | 谁的利润含金量更高？ |
| FCF/收入 | 排列 | 谁在真正创造自由现金？ |

### 2.5 投入维度

| 指标 | 对标方式 | 解读 |
|------|---------|------|
| 研发费用率 | 排列 | 技术投入力度对比 |
| CAPEX/收入 | 排列 | 资本投入力度对比 |
| CAPEX/折旧 | 排列 | >1.5 = 扩张中，<1 = 维持性 |

### 2.6 估值维度

| 指标 | 对标方式 | 需注意 |
|------|---------|--------|
| PE (TTM/Forward) | 排列 | 跨市场不可比 |
| PB | 排列 | 轻资产公司不可靠 |
| EV/EBITDA | 排列 | 排除资本结构差异后的对比 |
| PS | 排列 | SaaS/高增长亏损期适用 |
| PEG | 排列 | 考虑增速差异后的估值 |
| 股息率 | 排列 | 分红意愿对比 |

### 2.7 战略与产品维度（吸收 SAP 竞争对手矩阵）

**同业对比不能只看财务，产品力和客户结构往往才是估值分化的主因。** 科技/AI 行业尤其如此：

| 对标维度 | 具体指标 | 对标方式 | 数据来源与时效 |
|---------|---------|---------|--------------|
| 客户群结构 | 客户总数、企业客户数、客户集中度 | 排列：客户基数谁大、结构谁优 | 财报/招股书/官网，标注报告期 |
| 市场份额 | 市占率、份额变化趋势 | 排列：谁在抢份额谁在丢 | 行业报告/SNE 等第三方，标注统计期 |
| 产品竞争力 | 核心产品代际、渗透率（如 AI Agent 渗透率）、产品矩阵完整度 | 定性 + 可量化指标排列 | 产品发布会/行业评测，标注日期 |
| 技术卡位 | 专利数量/引用、技术路线选择、自研 vs 外购 | 定性比较 + 定量佐证 | 专利库/财报研发披露 |
| 商业模式差异 | 收入模式（订阅/一次性/抽佣）、客户生命周期价值 | 定性比较 | 财报分部数据 |

**铁律**：战略维度的对比数据同样必须标注来源和时点。市占率必须标注统计机构和统计期（如"SNE Research，2026 年 1-5 月"），渗透率必须标注产品线和日期。禁止无来源无时点的"市场份额领先"式表述。

## 三、差距归因分析框架

发现差距只是第一步。解释差距才是价值所在。

### 归因逻辑树

```
差距出现（如：公司毛利率比行业均值低 10%）
    │
    ├── 价格端：ASP 比同行低？
    │   ├── 是 → 品牌力不够？产品定位低端？竞争压力大？
    │   └── 否 → 排除价格因素
    │
    ├── 成本端：单位成本比同行高？
    │   ├── 是 → 规模不足？采购价更高？制造效率低？
    │   └── 否 → 排除成本因素
    │
    ├── 产品结构：低毛利产品占比更高？
    │   └── 是 → 战略选择还是被迫？
    │
    └── 客户结构：大客户占比高导致议价力弱？
        └── 是 → 客户集中度是风险还是行业惯例？
```

### 常见差距解读

| 差距 | 良性解释 | 需要警惕的解释 |
|------|---------|-------------|
| 毛利率低 | 中低端定位，走量策略 | 品牌力弱，被迫价格战 |
| 应收天数长 | 做大客户（政府/央企），行业惯例 | 信用政策激进，回款能力差 |
| 研发费用率低 | 技术成熟，规模效应 | 吃老本，未来竞争力弱 |
| 杠杆率高 | 行业特性（如地产） | 盲目扩张，风险控制差 |
| ROE 高 | 真正的竞争优势 | 高杠杆驱动的虚假繁荣 |

## 四、产业链分析

### 4.1 纵向对比：产业链利润分配

分析一家公司时，同时看它的上游和下游：

| 分析步骤 | 做什么 |
|---------|--------|
| 1. 识别产业链 | 原材料 → 零部件 → 制造 → 品牌/渠道 → 终端 |
| 2. 对比毛利率 | 产业链各环节谁的毛利率最高？为什么？ |
| 3. 看应收/应付 | 应收账款天数（客户欠你多久）vs 应付账款天数（你欠供应商多久） |
| 4. 判断地位 | 应收天数降 + 应付天数升 = 产业链地位增强 |

**核心判断**：在产业链中，利润向议价力最强的环节集中。如果一家公司处于产业链利润率最低的环节且没有改善迹象，长期投资价值存疑。

### 4.2 横向对比：竞争格局

| 分析维度 | 数据来源 | 解读 |
|---------|---------|------|
| 行业集中度(CR5/CR10) | 行业报告 | 集中度上升 = 龙头受益；集中度下降 = 竞争加剧 |
| 各家公司毛利率分化 | 年报 | 毛利率拉开 = 品牌/成本分化 |
| 各家公司 CAPEX/收入 | 年报 | 谁在扩产、谁在收缩 |
| 各家公司市场份额变化 | 行业报告 | 谁在抢谁的份额 |

## 五、时间维度的同业对比

### 5.1 数据时间对齐（P0 · 用户强调：同业数据必须有时效性）

**跨公司对比前必须对齐时间窗口，每条同业数据必须标注报告期。禁止无时点对比。**

- 所有对比数据必须标注截止日期/报告期（YYYY年Q/半年/年报）
- 美股公司财年可能与自然年不同（如 Apple 财年截至 9 月、Nike 截至 5 月）
- 统一用 TTM 或 LTM 口径消除财年差异
- 港股 Q1/Q3 无独立季报，只能用半年报和年报
- **禁止拿 A 公司 Q1 数据与 B 公司全年数据对比**
- **禁止使用"最新财报""近期"等无锚定表述**；每一行对比数据后标注报告期

**数据真实性要求**：
- 同业关键数据（收入/利润/估值倍数）必须来自交易所披露文件或权威数据商，标注来源
- 二手来源（媒体/博客）数据禁止直接用于对比表，只能做线索
- 对比数据与公司财报数据口径不一致时（如 A 公司用 CAS、B 公司用 IFRS），标注差异并说明影响

**对比表强制格式**：每行数据后附 `[来源，报告期]`，如"ROE 18% [2025 年报，巨潮资讯网]"。整表无标注 = 数据不可信。

### 5.2 趋势对比（比单期对比更有价值）

不要说"公司 ROE 是 15%，行业均值 12%"，而要说：

**"过去 3 年，公司 ROE 从 18% 降到 15%，而行业均值从 10% 升到 12%。公司的竞争优势在收窄。"**

这是完全不同的结论。

### 5.3 同业对比趋势分析模版

```
[指标名称]：公司 vs 行业
  Y-3: 公司 X% vs 行业 Y%  (差距：+Z%)
  Y-2: 公司 X% vs 行业 Y%  (差距：+Z%)
  Y-1: 公司 X% vs 行业 Y%  (差距：+Z%)
  Y-0: 公司 X% vs 行业 Y%  (差距：+Z%)

趋势判断：
  公司趋势：[上升/下降/横盘]
  行业趋势：[上升/下降/横盘]
  差距趋势：[扩大/收窄/稳定]

解读：[差距为什么在变化？说明什么问题？]
```
