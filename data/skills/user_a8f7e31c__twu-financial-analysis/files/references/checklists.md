# 各阶段检查清单汇总

## 一、十分钟快速筛选（Ten-Minute Test）

来源：Pat Dorsey《股市真规则》。全部通过才进入深度分析。

| # | 问题 | 检验目的 | 判断标准 |
|---|------|---------|---------|
| 1 | 公司一直不断地赚取营业利润吗？ | 盈利持续性 | 连续 5 年营业利润为正 |
| 2 | 公司能从经营活动中持续产生现金流吗？ | 现金流质量 | 连续 5 年经营现金流为正 |
| 3 | ROE 能保持 10% 以上且财务杠杆合理吗？ | 资本效率 | ROE > 10% 连续 5 年 |
| 4 | 盈利增长协调一致还是飘忽不定？ | 增长稳定性 | 无超过 30% 的年度波动 |
| 5 | 资产负债表清白吗？ | 财务风险 | 有息负债率 < 50% |
| 6 | 产生自由现金流吗？ | 真实现金创造 | FCF 连续 3 年为正 |
| 7 | 有多少"其他"？ | 利润质量 | 非经常性损益占比 < 15% |
| 8 | 股票数量明显增长了吗？ | 股本稀释 | 近 5 年稀释 < 15% |
| 9 | DCF 估值大致如何？ | 估值吸引力 | 安全边际 > 15% |

## 二、舞弊红旗排查清单

**每只持仓标的每季度必查。发现 ≥ 3 条进入深度怀疑模式。**

### 收入与利润质量
- [ ] 净现比 < 0.3 连续两年以上
- [ ] 应收账款增速 > 收入增速 1.5 倍以上
- [ ] 毛利率异常高于同行 20% 以上且无壁垒解释
- [ ] 非经常性损益占净利润 > 20%
- [ ] 扣非净利润连续低于净利润

### 资产质量
- [ ] 存贷双高（货币资金高 + 有息负债高）
- [ ] 利息收入/货币资金远低于活期利率
- [ ] 存货增速 > 成本增速，且周转天数持续上升
- [ ] 其他应收款/总资产 > 5%
- [ ] 商誉/净资产 > 30%

### 治理与审计
- [ ] 审计意见非标准无保留
- [ ] 近 3 年更换过审计师（尤其降级更换）
- [ ] CFO 异常离职无合理解释
- [ ] 大股东质押比例 > 60%
- [ ] 关联交易占比 > 10% 且定价不透明
- [ ] 曾被监管问询/处罚/立案

### 业务异常
- [ ] 海外业务占比高但无法验证
- [ ] 收入高度集中于少数不明客户
- [ ] 业绩精准达标无偏差
- [ ] 持续大额资本支出远超同行

### 快速评分：每项 = 1 分
- 0-2 分：正常监控
- 3-5 分：深度排查
- 6+ 分：高度怀疑，考虑退出

## 三、买入前必查清单

### 护城河
- [ ] 历史盈利：FCF/收入 > 5%，ROE > 15%（连续 5 年）
- [ ] 护城河来源清晰（网络效应/转换成本/品牌/成本优势/牌照）
- [ ] 护城河宽度为"宽"或"极宽"（预期持续 > 10 年）

### 财务健康
- [ ] 无红旗清单中的危险信号
- [ ] 有息负债/权益 < 1.0，流动比率 > 1.5
- [ ] 毛利率/净利率稳定或提升
- [ ] 利息覆盖倍数 > 5x

### 管理层
- [ ] 资本配置记录良好（并购理性、分红稳定）
- [ ] 无诚信红旗信号
- [ ] 薪酬结构合理（与长期股东利益一致）

### 估值
- [ ] DCF 计算内在价值（不低于市价 20%）
- [ ] 安全边际 ≥ 20%（好公司）/ ≥ 40%（一般公司）
- [ ] 同行业估值横向比较有吸引力

### 综合
- [ ] 六维评分 ≥ 3.5/5
- [ ] 公司比 3 年前更好（护城河在变宽）

## 四、卖出信号清单

- [ ] 股价 > 内在价值（无安全边际，高估）
- [ ] 护城河被侵蚀（竞争加剧/技术颠覆/政策变化）
- [ ] 财务健康恶化（出现 3+ 项红旗信号）
- [ ] 管理层诚信问题（造假/违规/减持不公告）
- [ ] 发现明显更好的机会（风险调整后）
- [ ] 投资逻辑被证伪（当初买入的理由不再成立）

## 五、季报/年报审查清单

### 利润表
- [ ] 收入增速 vs 预期（超/低预期）
- [ ] 毛利率变化及原因（是结构性还是临时性）
- [ ] 费用率变化（销售/管理/研发/财务）
- [ ] 非经常性项目对利润的影响
- [ ] 稀释 EPS vs 基本 EPS 差距

### 资产负债表
- [ ] 应收/存货/应付的变化趋势
- [ ] 有息负债变化（增还是减）
- [ ] 商誉是否需要减值
- [ ] 资本支出 vs 折旧（判断扩张还是维持）
- [ ] 预收款/合同负债变化（领先指标）

### 现金流量表
- [ ] 经营现金流增速 vs 利润增速
- [ ] 自由现金流是否为正且改善
- [ ] 投资现金流去向（扩产/并购/理财）
- [ ] 筹资现金流反映的资本策略

### 附注
- [ ] 收入确认政策是否有变化
- [ ] 关联交易金额和性质
- [ ] 或有负债/担保/诉讼
- [ ] 会计估计变更

## 六、行业快速匹配表

确定公司属于什么类型，选对分析框架：

| 问 | 如果是 | 用什么框架 |
|---|--------|-----------|
| 公司是否以存贷利差为主要收入？ | 是 | 银行框架 → PB-ROE、CAMELS |
| 是否收取保费并承担风险？ | 是 | 保险框架 → PEV、综合成本率 |
| 产品价格由大宗商品市场决定？ | 是 | 周期框架 → PB 分位、周期中枢 |
| 收入来自订阅/续费？ | 是 | SaaS 框架 → ARR、NRR、Rule of 40 |
| 收入主要是一次性产品销售？ | 是 | → 继续下面判断 |
| 毛利率 > 40% + 品牌知名度高？ | 是 | 消费品框架 |
| 研发投入高 + 产品受专利保护？ | 是 | 医药框架（细分） |
| CAPEX/收入 > 10%？ | 是 | 制造业/重资产框架 |
| 主要资产是土地和在建项目？ | 是 | 房地产框架 |

## 七、时间维度检查清单

**每项分析开始前强制完成：**

- [ ] 明确分析的时间窗口（截止哪个报告期）
- [ ] 明确数据范围（年报 N 年 + 季度 M 期）
- [ ] 识别目标公司季节性模式（哪个季度最强/最弱）
- [ ] 检查基期效应（去年同期是否有特殊事件）
- [ ] 对齐所有对比公司的时间口径（统一 TTM/LTM）
- [ ] 确认美股/港股公司财年是否与自然年一致

**时序分析强制检查（每项指标）：**

- [ ] 方向：过去 3-5 年这个指标在往哪个方向走？
- [ ] 速度：变化在加速还是减速？
- [ ] 波动：稳定趋势还是大幅波动？波动来源？
- [ ] 一致性：这个指标的趋势和相关指标是否一致？
- [ ] 拐点：最近 2-4 个季度是否出现趋势变化？

## 八、同业对比检查清单

- [ ] Peer Group 选择：是否覆盖了 3-8 家直接可比公司？
- [ ] 排除清单：是否有应排除的非可比公司被剔除？
- [ ] 时间对齐：所有对比数据的截止日期是否一致？
- [ ] 增长率对标：公司增速在行业中排第几？
- [ ] 盈利对标：毛利率/净利率/ROE/ROIC 在行业中的位置
- [ ] 效率对标：周转率/人效在行业中的位置
- [ ] 财务健康对标：杠杆/现金流质量在行业中的位置
- [ ] 估值对标：PE/PB/PS/EV-EBITDA + PEG 在行业中的位置
- [ ] 差距归因：每个显著差异都有合理解释吗？
- [ ] 产业链分析：上游供应商和下游客户的议价力变化？
- [ ] 时间维度趋势对比：公司 vs 行业趋势，差距在扩大还是收窄？
- [ ] 行业格局变化：CR5 趋势、各公司市场份额变化？

## 九、非财务数据检查清单

**通用（所有行业）：**

- [ ] 员工人数趋势和人均收入/利润变化
- [ ] 核心人员（高管/核心技术）是否稳定
- [ ] 产能/设施利用率
- [ ] 研发投入力度（人员/专利/项目进度）
- [ ] 监管/处罚/问询记录

**行业特定（选择对应行业）：**

- [ ] 消费/零售：SSSG、坪效、客单价、会员复购率
- [ ] SaaS/互联网：DAU/MAU、ARR、NRR、Churn、LTV/CAC
- [ ] 制造业：产能利用率、良品率、订单 backlog、产成品库存
- [ ] 医药：临床进度、注册证、集采中标、专利倒计时
- [ ] 银行：不良生成率、逾期分层、关注类迁徙率
- [ ] 地产：合约销售、回款率、土储去化、融资成本

**交叉验证：**

- [ ] 财务数据变化是否能在非财务数据中找到对应支撑？
- [ ] 是否存在非财务与财务数据的矛盾？
- [ ] 矛盾是否在 2 个以上独立来源中得到确认？

## 十、预期差检查清单（P0，财报解读第一输入）

- [ ] 是否已获取财报发布前的一致预期数据？（卖方预期/业绩预告/公司指引）
- [ ] 预期差判定：收入/利润相对一致预期是超/符合/低于？
- [ ] 质量预期差：毛利率/现金流/应收质量 vs 市场隐含假设如何？
- [ ] 预期差来源是否已定位？（超在哪个分部/低于哪个项目）
- [ ] 预期是否取自发布前信息？（禁止用发布后反应倒推）
- [ ] 无一致预期数据时，是否已标注"[无一致预期数据]"并降置信度？
- [ ] **管理层指引质量评估**：历史指引兑现率如何？（对比过去 2-3 年指引 vs 实际）
- [ ] **指引 vs 一致预期 vs 我的判断**三方是否已对账？分歧原因是什么？

## 十一、正反合论证检查清单（P0，每个核心判断必过）

**正方论证完成后，强制执行：**

- [ ] 这个判断的最强反面论证是什么？（替代解释）
- [ ] 替代解释排查：会计操纵？一次性项目？低基数效应？行业贝塔？
- [ ] 是否有数据可以区分正反两种解释？数据说了什么？
- [ ] 收敛到"合"了吗？（条件化/时间分层/重构，不是折中）
- [ ] 无法化解的分歧，是否已列入裁决信号清单（等什么数据能定）？

## 十二、监控变量与残余不确定性清单（P0，输出前必填）

**监控变量（按领先/同步/滞后分类）：**

- [ ] 领先指标：什么数据先于业绩变化出现？（订单/预收/产能利用率/客单价）
- [ ] 同步指标：什么数据与业绩同步？（收入增速/毛利率/现金流）
- [ ] 滞后指标：什么数据后验确认？（应收质量/存货消化/审计意见）
- [ ] 证伪信号：什么信号出现表示我的判断错了？（明确列出，不是模糊的"关注风险"）

**残余不确定性：**

- [ ] 数据冲突：哪些关键数据多源不一致？影响如何？
- [ ] 信息真空：哪些重要维度没有数据？（标注"数据暂缺"）
- [ ] 推断项：哪些结论是 [推断] 而非 [已验证]？降置信度了吗？

## 十三、三路输入检查清单（P0，防闭门造车）

- [ ] 事实路：报表数据是否覆盖？（至少 3 年 + 最新期）
- [ ] 理论路：经营机制论证是否完整？（为什么增长/为什么可持续）
- [ ] 观点路：卖方一致预期、分析师分歧、市场反应是否收集？
- [ ] 观点路是否至少含 1 个行为证据？（资金流向/期权定价/市场反应）
- [ ] 三路同向/分歧的判断是否已做出？分歧时拷问重点了吗？

## 十四、数据来源可信性检查清单（P0 · 用户钦定硬规则）

**来源层级（每条关键数据必答）：**

- [ ] 这条数据属于 L1-L5 哪个层级？
- [ ] 涉及收入/净利润/总资产/现金流的最终结论，是否能追溯到 L1（交易所原始披露文件）？
- [ ] 二手数据（L3-L5）与一手数据（L1-L2）冲突时，是否以一手为准？
- [ ] 无法追溯到 L1 的数据，是否标注"[数据来源待核验]"并降置信度？

**强制标注三要素（报告中每条财务数据）：**

- [ ] 数据是什么？（具体科目和数值）
- [ ] 来源？（具体披露文件/接口名称，禁止"据公开信息"）
- [ ] 报告期？（YYYY年Q/半年/年报，禁止"当前""最新"）

**勾稽校验闸门（输出前强制）：**

- [ ] BS 平衡：总资产 = 总负债 + 所有者权益？（误差 < 0.1%）
- [ ] CF 衔接：CF 期末现金 = BS 货币资金？
- [ ] 利润衔接：CF 首行净利 = IS 净利润？
- [ ] 留存收益滚动：期初留存 + 净利 - 分红 ± 调整 = 期末留存？
- [ ] 勾稽不过是否已终止分析？（禁止带病继续）

**科目映射（从原始 PDF 取数时）：**

- [ ] 是否已建立目标公司财报科目与标准科目的映射？
- [ ] 三市场口径差异（CAS/HKFRS/US GAAP）是否已确认？
- [ ] 结构化接口字段名是否与披露口径核对过？（防止"营业利润"当"经营利润"）

## 十五、估值模块检查清单（P0 · 多模型交叉验证）

**模型选择：**

- [ ] 主模型选择是否有明确理由？（为什么选它，为什么不用其他）
- [ ] 是否至少 1 个主模型 + 1 个验证模型？
- [ ] 是否有禁用模型被误用？（如周期顶部用 PE、亏损期用 DCF）

**输入数据：**

- [ ] 估值基准日是否标注？（YYYY-MM-DD）
- [ ] 所有财务数据是否标注报告期？（禁止"最新财报"）
- [ ] 市场参数（无风险利率/beta/ERP/税率）是否标注取值日期和来源？
- [ ] 核心财务数据能否追溯到 L1 交易所披露文件？
- [ ] 可比组是否全部用 TTM/LTM 口径对齐？（禁止跨期对比）

**多模型交叉验证：**

- [ ] 各模型是否独立计算、互不污染？
- [ ] 是否输出了多模型对比表（价值/区间/可信度/分歧点）？
- [ ] 各模型区间是否求交集？无交集时是否排查假设？
- [ ] 分歧是否已列出原因并判定哪个模型更可信？

**敏感性分析：**

- [ ] 主模型是否做了敏感性分析？（DCF 必做 WACC × g 二维表）
- [ ] 是否识别出最敏感假设？该假设论证是否最扎实？
- [ ] 输出的是区间还是单点？（专业估值必须给区间）

**结论：**

- [ ] 安全边际是否计算（当前价 vs 区间下沿/中值/上沿）？
- [ ] 我的估值 vs 卖方一致预期 vs 市场定价三方差异是否解释？
- [ ] 关键假设清单（影响 >10%）是否列出？
- [ ] 估值结论是否与市场定价的差异有正反合论证？
