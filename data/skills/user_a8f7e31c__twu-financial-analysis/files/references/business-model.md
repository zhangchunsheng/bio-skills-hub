# 传统 vs 新兴企业分析详解（从 SKILL.md Part VII 迁移）

> 来源：twu-financial-analysis v1.0.0 SKILL.md Part VII

## Part VII: 传统 vs 新兴企业分析差异

（必须结合行业框架使用，不同商业模式意味着完全不同的分析逻辑）

### 7.1 为什么不能用同一套框架

同是"公司"，但轻资产平台和重资产制造商的财务特征完全不同：

| 维度 | 传统重资产（制造/零售/能源） | 新兴轻资产（SaaS/平台/互联网） |
|------|---------------------------|-------------------------------|
| 核心资产 | 固定资产、存货 | 用户、数据、IP、品牌 |
| 利润特征 | 线性增长、规模效应 | 前期巨亏、爆发式盈利拐点 |
| 关键指标 | ROE/ROIC、存货周转、CAPEX | ARR/MRR、用户增速、LTV/CAC |
| 自由现金流 | 早期即为正 | 前期为负，规模扩张后转正 |
| 资本支出 | 高 CAPEX（维持性） | 低 CAPEX（主要是研发费用） |
| 估值锚 | PE、EV/EBITDA、PB | PS、EV/Revenue、ARR 倍数 |
| 风险点 | 产能过剩、原材料涨价、技术淘汰 | 烧钱不可持续、竞争壁垒弱、监管风险 |
| 财务操纵 | 虚增存货/资产、少计折旧 | 虚增 GMV/用户、渠道造假（瑞幸） |

### 7.2 平台型企业的特殊分析

平台型公司（拼多多/美团/滴滴/Airbnb）的财务报表容易误读：

- **GMV 不等于收入**：GMV 是平台上的交易额，take rate 才是公司的真实收入。分析时必须区分"平台交易额"和"公司确认收入"
- **双边网络效应**：用户越多平台越值钱。但需要验证：边际成本是否真的递减？双边是否存在跨边网络效应？
- **现金流先行**：平台公司通常先有正向现金流再有会计利润（预收款和应付账款提供了大量无息融资）。关注经营现金流何时转正
- **补贴是投资不是费用**：平台早期补贴用户换规模，如果把补贴视为营销费用会低估长期盈利能力

### 7.3 订阅制（SaaS）的特殊分析

SaaS 公司将一次性销售转化为持续性订阅，会计确认滞后于商业实质：

- **递延收入是核心领先指标**：递延收入（已收未确认）的增长势头比当期确认收入更能预示未来
- **NRR > 120% 含金量极高**：说明已有客户在扩大消费，不是靠新客拉增长
- **CAC 回收期必须 < 12 个月**：超过意味着烧钱换来的客户永远无法贡献正向现金流
- **Rule of 40 是健康底线** = 收入增速(%) + FCF 利润率(%) ≥ 40%

### 7.4 传统重资产 vs 轻资产的分野

| 判断维度 | 重资产特征 | 轻资产特征 |
|---------|-----------|-----------|
| 固定资产/总资产 | > 40% | < 15% |
| CAPEX/折旧 | > 1.5（持续扩张） | < 1.0（维持即可） |
| 折旧/收入 | > 5% | < 2% |
| 利润波动 | 受产能利用率影响大 | 受需求波动影响更大 |
| 退出壁垒 | 高（沉没成本大） | 低（可变成本为主） |

**分析陷阱**：重资产公司在周期底部的 PE 可能极高（利润萎缩），但这不是高估的信号，反而是周期底部布局的机会。反之，周期顶部的低 PE 是陷阱。

### 7.5 分析适配决策树

```
公司类型判断
    │
    ├── 固定资产/总资产 > 30%？
    │   ├── 是 → 重资产框架（关注产能利用率、折旧覆盖、CAPEX 节奏）
    │   └── 否 → 继续
    │
    ├── 收入模式是订阅/抽佣/广告？
    │   ├── 是 → 轻资产/平台框架（关注 ARR/GMV/take rate/用户指标）
    │   └── 否 → 继续
    │
    ├── 产品价格由大宗商品市场决定？
    │   ├── 是 → 周期框架（PE 顶部是陷阱，底部看 PB）
    │   └── 否 → 继续
    │
    └── 属于消费品/制造/服务/金融等传统分类 → 行业标准化框架
```
