## Part II: 财务分析 — 五维度系统评估

### 核心要求：所有财务分析必须在时间维度和同业对比中进行

单独一个 ROE 数字没有意义。有意义的是：ROE 连续 5 年是升还是降、行业内排第几、驱动因素是利润率还是杠杆。

### 2.1 盈利能力（DuPont 三层分解 + 时序）

```
ROE = 净利润率 × 资产周转率 × 权益乘数
     (盈利质量)   (运营效率)    (财务杠杆)
```

| 层级 | 分析要点 | 时间维度检查 | 优质标准 |
|------|---------|------------|---------|
| 净利润率 | 毛利率趋势、费用率控制 | 5 年趋势 + 季度边际变化 | 连续 5 年稳定或提升 |
| 资产周转率 | 轻资产 vs 重资产的运营效率 | 趋势：在改善还是恶化？ | 同行中处于什么位置 |
| 权益乘数 | 杠杆是否合理 | 趋势：杠杆在加还是去？ | 金融业外 < 3 倍 |
| ROE 最终 | 综合判断 | 5 年变化：上行/下行/横盘？ | > 15% 优秀，10-15% 一般 |

**DuPont 时序分解**：当 ROE 发生变化时，必须判断是哪个因子驱动的。利润率驱动的 ROE 提升比杠杆驱动的更可持续。

### 2.2 成长性分析

增长来源必须分解，不同来源的质量完全不同：

| 增长来源 | 质量评价 | 可持续性 |
|---------|---------|---------|
| 内生销量增长 | 最优 | 高 |
| 提价驱动 | 次优（需品牌力支撑） | 中-高 |
| 行业自然扩容 | 中性 | 中 |
| 并购并表 | 需验证整合效果 | 低-中 |
| 会计变更/一次性 | 劣质 | 无 |

**时序要求**：区分"加速增长"（好）和"增速放缓但绝对值仍大"（需警惕）、"低基数反弹"（中性）和"结构性突破"（好）。

### 2.3 现金流质量

三条现金流铁律：

1. **经营现金流** 必须持续为正且覆盖资本支出
2. **自由现金流** = 经营现金流 - 维持性资本支出，FCF/收入 > 5% 为优秀
3. **三类现金流组合判断**（需看多年模式，不是单期）：

| 经营 | 投资 | 筹资 | 含义 |
|------|------|------|------|
| + | - | -/+ | 健康成熟企业（最好的状态） |
| + | + | - | 收缩期，变卖资产还债 |
| - | + | + | 危险，靠输血维持 |
| - | - | + | 烧钱扩张，需验证投资回报 |

**时间检查**：一家公司如果连续 3 年处于"烧钱扩张"模式但收入增长没有加速，就是红旗。

### 2.4 偿债能力与流动性

公式详见 `references/ratio-formulas.md`。主文件只保留判断标准：

| 指标 | 安全阈值 | 时序检查 | 行业例外 |
|------|---------|---------|---------|
| 流动比率 | > 1.5 | 趋势：在恶化吗？ | 零售/快消 > 1.0 即可 |
| 速动比率 | > 1.0 | 趋势 | 存货占比高的行业除外 |
| 利息覆盖倍数 | > 5 倍 | 趋势：收窄了吗？ | 公用事业 > 3 倍可接受 |
| 资产负债率 | < 60%（非金融） | 趋势：加杠杆还是去杠杆？ | 银行/保险不适用 |
| 有息负债率 | < 30% | 融资成本趋势 | 重资产行业可适当放宽 |

### 2.5 营运效率

公式详见 `references/ratio-formulas.md`。主文件只保留解读：

| 指标 | 解读 | 时序敏感度 |
|------|------|-----------|
| 应收账款周转天数 | 越短越好 | **极高**——恶化是最早的业绩变脸信号 |
| 存货周转天数 | 行业差异巨大 | 高——积压预示需求走弱或产品过时 |
| 应付账款周转天数 | 越长=对上游议价力越强 | 中——突然延长可能是资金紧张 |
| 现金转化周期 | 越短越好，负数为最佳 | 高——综合效率指标 |
| 固定资产周转率 | 越高=资本效率越好 | 中——注意产能不足风险 |
