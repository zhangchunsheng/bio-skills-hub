# 权威数据源清单与获取方法

## 〇、数据获取优先级体系（P0）

```
第一优先：用户投喂的 PDF/Excel → 直接解析，不做二次获取
第二优先：交易所官网原始披露文件 → 权威性最高，无中介风险（L1）
第三优先：Tushare 等结构化数据接口 → 效率最高，但需验证完整性（L2）
第四优先：财经网站 + 联网搜索 → 补充非结构化信息（L3-L5）
```

**铁律**：涉及财务数据真实性验证时，必须追溯到交易所原始披露文件。二三手数据源的错误率远高于公众认知。

### 用户投喂数据的使用（最高优先）

1. **最高优先级**，直接作为分析输入，不做二次获取
2. 使用 `pdf-image-text-extractor` skill 提取 PDF 中的财务数据
3. 提取后必须做一次勾稽关系校验（BS 是否平衡、CF 期末现金是否等于 BS 现金）
4. 关键数据点（收入、净利润、总资产）与公开来源做一次交叉验证
5. 标注"数据来源：用户提供 [文件名]，截止 [日期]"

### 联网搜索策略

| 场景 | 搜索策略 | 关键词示例 |
|------|---------|-----------|
| 获取最新财务数据 | 搜索"公司名 + 年份 + 年报/季报 + 关键指标" | "贵州茅台 2025 年报 营业收入" |
| 同业对比数据 | 搜索"行业名 + 上市公司 + 财务指标对比" | "白酒行业 ROE 排名 2025" |
| 舞弊/负面信息 | 搜索"公司名 + 造假/处罚/问询/违规" | "康美药业 证监会 处罚" |
| 行业动态 | 搜索"行业名 + 政策/趋势/景气度" | "新能源汽车 补贴政策 2026" |
| 非财务数据 | 搜索"公司名 + 产能/门店/用户数/市场份额" | "宁德时代 产能利用率 2025" |

**局限**：信息碎片化、未经审计、可能有滞后。关键财务数字必须交叉验证两个以上独立来源。

## 一、A 股市场

### 1.1 交易所指定披露平台

| 平台 | URL | 用途 | 是否免费 | 备注 |
|------|-----|------|---------|------|
| **巨潮资讯网** | cninfo.com.cn | 全部 A 股公司定期报告、临时公告、IPO 文件 | 免费 | 证监会指定，最权威 |
| 上交所官网 | sse.com.cn | 沪市公司披露、监管信息公开 | 免费 | — |
| 深交所官网 | szse.cn | 深市公司披露、监管信息公开 | 免费 | — |
| 北交所官网 | bse.cn | 北交所公司披露 | 免费 | — |

**获取年报的标准路径**：
```
巨潮资讯网 → 搜公司代码/名称 → 定期报告 → 选择年份和类型 → 下载 PDF
```

**关键提醒**：
- 巨潮的搜索功能比交易所官网更好用
- PDF 文件通常很大（50MB-200MB），注意下载时间
- 问询函和监管函在"监管信息公开"栏目，不在"定期报告"里

### 1.2 结构化数据 API

#### Tushare Pro

| 接口 | 说明 | 积分要求 |
|------|------|---------|
| `income` | 利润表 | 2000+ |
| `balancesheet` | 资产负债表 | 2000+ |
| `cashflow` | 现金流量表 | 2000+ |
| `forecast` | 业绩预告 | 2000+ |
| `fina_indicator` | 财务指标（ROE/ROA 等） | 2000+ |
| `fina_audit` | 审计意见 | 2000+ |
| `disclosure_date` | 披露日期 | 免费 |
| `stk_holdernumber` | 股东人数 | 5000+ |
| `hk_basic` | 港股通基本信息 | 8000+ |

**Tushare 数据验证**：
- 用 Tushare 获取数据后，抽取 2-3 个关键数字（收入、净利润、总资产）与巨潮原始 PDF 对比
- 如果发现不一致，以巨潮 PDF 为准

#### AKShare（免费替代）

| 接口 | Python 调用 | 说明 |
|------|-----------|------|
| 利润表 | `ak.stock_financial_abstract_ths()` | 同花顺来源，免费但稳定性一般 |
| 财务指标 | `ak.stock_financial_analysis_indicator()` | ROE/ROA 等 |
| 资产负债表 | 通过 `stock_balance_sheet_by_report_em()` | 东方财富来源 |

**AKShare 与 Tushare 的取舍**：
- Tushare 积分 < 2000：只能用 AKShare
- Tushare 积分 2000-8000：A 股财报数据优先用 Tushare，获取不到的用 AKShare 补
- Tushare 积分 8000+：全部用 Tushare，AKShare 仅做交叉验证

## 二、港股市场

### 2.1 官方披露平台

| 平台 | URL | 说明 |
|------|-----|------|
| **港交所披露易** | hkexnews.hk | 唯一指定披露平台，所有公告和财报 |

**获取年报的标准路径**：
```
hkexnews.hk → 搜公司代码或名称 → 选文件类型（年报/中期报告）→ 下载 PDF
```

**港股数据特点**：
- **无 Q1/Q3 季报**。只有年报（全年）和中期报告（半年）。部分公司自愿披露季度经营数据但无正式季报
- 年报格式：香港财务报告准则（HKFRS），与国际财务报告准则（IFRS）基本一致
- 部分公司同时发布中英文版本
- 红筹股（注册在境外但主要业务在内地）的财务数据口径可能与 A 股同行不同

### 2.2 港股数据 API

| 来源 | 可用数据 | 限制 |
|------|---------|------|
| AKShare `stock_hk_financial_indicator_em()` | 主要财务指标 | 免费，数据来自东方财富港股频道 |
| Yahoo Finance | 基本行情和历史数据 | 免费，财务数据较粗略 |
| Wind（付费） | 完整财务数据 | 机构级，个人不易获取 |

**港股分析的实操**：由于免费数据源覆盖有限，港股深度财务分析严重依赖人工从披露易下载 PDF 并提取数据。`pdf-image-text-extractor` skill 可辅助提取。

## 三、美股市场

### 3.1 SEC EDGAR 系统

| 文件类型 | 说明 | 包含内容 |
|---------|------|---------|
| **10-K** | 年度报告 | 完整审计财报 + MD&A + 风险因素，最全面的文档 |
| **10-Q** | 季度报告 | 未经审计的季度财报（Q1/Q2/Q3） |
| **8-K** | 重大事项报告 | 业绩预告、并购、管理层变动、重大合同 |
| **S-1** | IPO 招股书 | 上市前的完整信息披露 |
| **DEF 14A** | Proxy Statement | 高管薪酬、董事会选举、股东提案 |

**EDGAR 搜索**：
```
sec.gov/edgar → Company Filings → 输入 Ticker 或公司名 → 选文件类型
```

**EDGAR Full-Text Search**（最强大的免费财务数据库）：
```
https://www.sec.gov/edgar/search/
支持关键词搜索所有历史披露文件全文
```

**XBRL 数据**：SEC 自 2009 年起要求财报以 XBRL 格式提交，机器可读。适用于需要精确数值对比的场景。可从 EDGAR 直接下载 XBRL 实例文档（`.xml` 格式）。

### 3.2 美股结构化数据

| 来源 | 说明 | 限制 |
|------|------|------|
| Yahoo Finance (`yfinance` Python 库) | 行情 + 简要财务数据 | 免费，财务报表数据较粗 |
| Alpha Vantage | 免费 API，含财报数据 | 免费版 5 次/分钟，25 次/天 |
| Financial Modeling Prep | 财报数据 API | 免费版 250 次/天 |
| SEC EDGAR XBRL | 直接从 SEC 下载结构化数据 | 免费无限制，但解析需要技术 |

**推荐路径**：先用 `yfinance` 快速获取概览数据，再从 SEC EDGAR 下载 10-K/10-Q PDF 做深度分析。

### 3.3 美股财年差异速查

| 公司 | 财年截止月 | 周期 |
|------|-----------|------|
| Apple (AAPL) | 9 月 | FY 截止 9 月最后一个周六 |
| Microsoft (MSFT) | 6 月 | FY 截止 6 月 30 日 |
| Nike (NKE) | 5 月 | FY 截止 5 月 31 日 |
| Walmart (WMT) | 1 月 | FY 截止 1 月 31 日 |
| Tesla (TSLA) | 12 月 | 与自然年一致 |
| Alphabet (GOOGL) | 12 月 | 与自然年一致 |
| Amazon (AMZN) | 12 月 | 与自然年一致 |

**分析适配**：对比跨市场的公司时，必须使用 TTM/LTM 口径而不是单财年口径。Apple 的 FY2025（截止 2025 年 9 月）不能直接和自然年 2025 的数据对比。

## 五、数据质量校验清单

从任何来源获取数据后，必须执行以下校验：

### 勾稽关系必查

- [ ] 资产负债表：总资产 = 总负债 + 所有者权益（误差 < 总资产的 0.1%）
- [ ] 现金流量表：期末现金 = 资产负债表货币资金
- [ ] 利润表→CF 表：CF 表首行净利润 = 利润表净利润
- [ ] 留存收益：期初留存 + 净利润 - 分红 ± 其他 = 期末留存

### 跨源交叉验证

- [ ] 从两个以上独立来源获取营业收入/净利润/总资产，差异 < 1%
- [ ] 如果只有 API 数据，至少抽查一次与原始 PDF 的一致性
- [ ] 非财务数据（如用户数/门店数）对比公司官网和行业报告

### 时效性检查

- [ ] 所有数据标注获取日期和数据截止日期
- [ ] A 股年报：注意 4 月 30 日是截止披露日，部分公司到 4 月底才发布
- [ ] 港股半年报：截止披露日为 9 月 30 日
- [ ] 美股 10-K：大型加速申报者截止 60 天（财年结束后），加速申报者 75 天
