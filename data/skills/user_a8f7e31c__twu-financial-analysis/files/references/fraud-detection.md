## Part V: 财务舞弊识别

### 5.1 舞弊识别三步法（时间维度增强版）

```
第一步：时间序列异常检测 → 多期 M-Score 趋势、净现比历史、Altman Z-Score 趋势
第二步：定性排查 → 红旗清单逐条核对（含时间维度红旗）
第三步：案例比对 → 手法匹配已知造假模式
```

**关键**：M-Score 不能只看一期，要看 3-5 年的趋势。M-Score 从 -2.5 逐年上升到 -1.5，比从 -1.5 跳到 -1.2 更危险。

### 5.2 Beneish M-Score（盈余操纵概率模型）

**适用范围**：制造业、消费、医疗、科技硬件等非金融企业。不适用于银行、保险、REITs。

**公式**：
```
M = -4.84 + 0.920×DSRI + 0.528×GMI + 0.404×AQI + 0.892×SGI
      + 0.115×DEPI - 0.172×SGAI + 4.679×TATA - 0.327×LVGI
```

**8 个变量**：DSRI(应收周转恶化)、GMI(毛利率恶化)、AQI(非流动资产异常)、SGI(销售增长)、DEPI(折旧率下降)、SGAI(费用异常)、LVGI(杠杆上升)、TATA(应计占比)。

**判断标准**：M > -1.78 = 高概率操纵。**时间增强**：M-Score 逐年上升比单期高值更危险。

**历史验证**：Enron(-1.49)、WorldCom(4.61)、Wirecard(2017 年触发)、康美药业(2018 年触发)。

### 5.3 定性红旗清单（15+3 条，新增 3 条时间维度红旗）

| # | 红旗 | 性质 | 典型案例 |
|---|------|------|---------|
| 1 | 净利润持续增长但经营现金流持续恶化 | 盈利质量 | 康得新 |
| 2 | 应收账款增速远超收入增速（>1.5 倍） | 收入质量 | 康美药业 |
| 3 | 存货增速远超成本增速且周转天数持续上升 | 资产质量 | 獐子岛 |
| 4 | 毛利率异常高于同行（>20% 差距无壁垒解释） | 盈利可信度 | 瑞幸咖啡 |
| 5 | 存贷双高 | 资金真实性 | 康美/康得新 |
| 6 | 频繁更换会计师或 CFO 无解释离职 | 治理 | Enron |
| 7 | 持续大额非经常性损益调节利润 | 盈余管理 | 獐子岛 |
| 8 | 关联交易占比高且定价不透明 | 关联交易 | 瑞幸 |
| 9 | 收入集中于少数客户且客户背景不明 | 收入真实 | 越博动力 |
| 10 | 资本支出远超同行，疑似费用资本化 | 费用操纵 | WorldCom |
| 11 | 大股东高比例质押或长期占用资金 | 治理 | 辅仁药业 |
| 12 | 海外业务占比高但难以验证 | 可验证性 | Wirecard |
| 13 | 业绩承诺精准达标（无偏差） | 盈余管理 | 对赌期后变脸 |
| 14 | 销售回款周期异常延长、预收大幅下降 | 渠道 | 压货式增长 |
| 15 | 行政处罚/监管问询/媒体质疑频发 | 外部信号 | — |
| **16** | **财务指标趋势与行业趋势严重背离** | **时间+同业** | 行业下行时声称增长 |
| **17** | **季度数据前后矛盾（Q4 vs Q1-Q3 异常差异）** | **时间** | Q4 突然暴增或"洗大澡" |
| **18** | **非财务指标与财务数据无法对应** | **交叉验证** | 用户大增但 ARPU 维持不变 |

### 5.4 管理层与治理评估

**管理层质量是估值的重要因子，但往往被纯定量分析忽略。** 优秀的公司 + 差的管理层 = 持续的价值毁灭。

#### 四维评估框架

| 维度 | 评估问题 | 正面信号 | 危险信号 |
|------|---------|---------|---------|
| **能力** | 战略眼光和执行记录如何？ | 资本配置决策事后被证明正确；持续超额完成指引 | 频繁修订战略方向；并购后大规模减值 |
| **诚信** | 是否诚实可信？ | 主动披露问题和风险；薪酬合理 | 曾被监管处罚；承诺反复不兑现；关联交易不透明 |
| **股东导向** | 是否以股东利益为先？ | 合理分红/回购；不随意增发稀释；沟通坦诚 | 高额股权激励侵蚀利润；频繁低价增发 |
| **稳定性** | 核心团队是否稳定？ | 管理层任期 > 3 年；有明确的继任计划 | CFO/审计师频繁更换；核心技术人员持续流失 |

#### 实用检查清单

- [ ] 管理层薪酬是否与长期股东回报挂钩（而非短期利润）？
- [ ] 近 3 年是否有 CFO 或审计师变更？（如有，必须找到合理解释）
- [ ] 大股东/管理层是否有高比例股权质押？（> 60% = 红旗）
- [ ] 资本配置记录：并购是否创造价值？（查看商誉减值历史）
- [ ] 管理层在电话会/业绩说明会上的指引是否可靠？（对比历史指引 vs 实际）
- [ ] 公司治理结构：独立董事占比、审计委员会独立性、关联交易审批程序
- [ ] 是否曾被交易所/证监会问询、通报批评或立案调查？

**评级**：优 / 良 / 中 / 差。管理层评级为"差"时，最终评分降一档。

### 5.5 其他定量模型和案例库

- **现金流铁三角检验**：净现比 + FCF + 存贷双高
