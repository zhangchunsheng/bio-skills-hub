# 估值方法详解

## 一、DCF（现金流折现）— 绝对估值的黄金标准

### 1.1 DCF 五步法（晨星/Pat Dorsey 标准）

#### Step 1: 估计当前自由现金流

**无杠杆 FCF（FCFF）：**
```
FCFF = EBIT × (1 - 税率) + 折旧摊销 - 资本支出 - 营运资本增加
```

**杠杆 FCF（FCFE）：**
```
FCFE = 净利润 + 折旧摊销 - 资本支出 - 营运资本增加 + 净借款
```

**简化版（实操最常用）：**
```
FCF = 经营活动现金流净额 - 维持性资本支出
维持性资本支出 ≈ 折旧摊销（粗略）或取历史 CAPEX 的 70-80%
```

**品质判断**：FCF/收入 > 5% = 优秀，FCF 持续为负且非扩张期 = 危险。

#### Step 2: 预测增长率（分阶段）

| 阶段 | 年数 | 增长率设定 | 依据 |
|------|------|-----------|------|
| 高增长期 | 1-3 年 | 略低于历史均值或与行业增速持平 | 近期可见度 |
| 过渡期 | 4-7 年 | 渐进式收敛至永续增速 | 竞争会侵蚀超额收益 |
| 稳定期 | 8-10 年 | 接近永续增长率 | 竞争优势终将回归均值 |

**关键原则**：
- 增长率不能长期超过 GDP 增速（否则公司会变得比经济还大）
- 强护城河可以用历史增速上限；弱护城河必须保守估计
- 周期公司必须纳入完整周期（含低迷年份）

#### Step 3: 确定折现率（WACC）

**WACC 公式：**
```
WACC = E/(E+D) × Re + D/(E+D) × Rd × (1 - t)
```
其中 Re = Rf + β × (Rm - Rf)（CAPM 模型）

**实操简化**（晨星标准）：

| 基准 | 调整因素 | 举例 |
|------|---------|------|
| 强护城河 | 9% | 腾讯、茅台 |
| 一般公司 | 10.5% | 大部分中型公司 |
| 高风险 | 13-15% | 周期股、小盘、高杠杆 |

**六个风险调整因子**（每个 +1-2%）：
1. 公司规模（小市值 +1-2%）
2. 财务杠杆（高负债 +1-2%）
3. 周期性（强周期 +1-2%）
4. 管理层可信度（有争议 +1%）
5. 竞争优势（弱 +1-2%）
6. 业务复杂性（复杂 +1%）

**股权风险溢价(ERP)参考**：A 股 6-8%，美股 4.5-5.5%，港股 5.5-7%

#### Step 4: 计算永续价值

**戈登增长模型：**
```
永续价值 = FCF_Terminal × (1 + g) / (WACC - g)
```

**永续增长率选择**：
- 标准：3%（名义 GDP 增速）
- 成熟行业：2-2.5%
- 衰退行业：1-2%
- 最高不超过 4%（除非在超高速增长的新兴市场）

**多种永续价值方法交叉验证**：
- 退出倍数法：FCF_Terminal × 合理 EV/FCF 倍数（15-20x）
- 永续 ROIC 法：NOPAT_Terminal × (1 - g/ROIC) / (WACC - g)

#### Step 5: 计算内在价值

```
企业价值 = Σ(FCF_t / (1+WACC)^t) + 永续价值现值
股权价值 = 企业价值 - 净负债（总负债 - 现金及等价物）
每股内在价值 = 股权价值 / 稀释后总股本
```

### 1.2 DCF 敏感性分析

**必做维度**：
- WACC 变动 ±1%
- 永续增长率变动 ±0.5%
- 前 5 年增长率的乐观/中性/悲观情景

**输出格式**：
| WACC \ g | 2% | 2.5% | 3% | 3.5% |
|-----------|---|---|---|---|
| 8% | 120 | 135 | 155 | 180 |
| 9% | 100 | 110 | 125 | 145 |
| 10% | 85 | 95 | 105 | 120 |
| 11% | 72 | 80 | 88 | 100 |

### 1.3 DCF 常见错误

| 错误 | 后果 | 纠正 |
|------|------|------|
| 增长率 > WACC 太多年 | 估值虚高 | 增长率必须在 5-7 年内收敛 |
| 永续增长率过高 | 永续价值占比过高 | 不超过 4% |
| 忽略股权稀释 | 每股价值虚高 | 用稀释后股数 |
| 用最近一年的高利润做基期 | 忽略周期性 | 取 3 年平均或正常化利润 |
| 未区分维持性和扩张性 CAPEX | 低估/高估 FCF | 维持性 ≈ 折旧 |

## 二、可比估值

### 2.1 PE（市盈率）

**适用**：盈利稳定、可预测的企业。

**不适用**：亏损企业、强周期顶部（PE 最低反而是最危险的时候）、利润受大量非经常性项目影响的企业。

**解读**：PE 反映的是市场对盈利持续性和增长的预期。高 PE = 市场预期高增长或高质量，低 PE = 市场预期低增长或有风险。

**PEG 扩展**：PEG = PE / 盈利增长率(%)。PEG < 1 可能被低估（但增速必须是可持续的）。

### 2.2 PB（市净率）

**适用**：银行、保险、重资产制造业、周期行业底部。

**不适用**：轻资产企业（品牌/技术/平台价值未体现在账面）、大量商誉的企业。

**PB-ROE 关系**：长期 PB = (ROE - g) / (r - g)。如果 ROE > 股权成本，PB 应该 > 1。

### 2.3 EV/EBITDA

**为什么比 PE 更好**：
- 扣除了资本结构差异（用 EV 而非市值）
- 扣除了折旧政策差异（EBITDA 口径）
- 更适合资本结构差异大的同业比较

**不适用**：金融企业（EV 概念无意义）、高 CAPEX 企业（EBITDA 忽略维护性支出）。

### 2.4 PS（市销率）

**适用**：高增长亏损期企业（SaaS 早期、Biotech、新消费品牌）。

**关键假设**：当前的亏损是战略性投入，未来利润率会改善。如果永远不盈利，PS 毫无意义。

**PS 容忍度**：增速越高，PS 可以给得越高。如增速 50%+ 可接受 PS > 10x。

### 2.5 行业标准估值倍数速查

| 行业 | 首选倍数 | 次选 | 不应使用 |
|------|---------|------|---------|
| 消费 | PE、PEG | DCF | PS |
| 银行 | PB | PE | EV/EBITDA |
| 保险 | PEV | PB | EV/EBITDA |
| 周期（底部） | PB | 周期中枢 PE | 当期 PE |
| SaaS（成长） | EV/Revenue、PS | EV/ARR | PE |
| SaaS（成熟） | EV/FCF、PE | DCF | PS |
| 医药-创新药 | rNPV（管线估值） | PS | PE |
| 医药-CXO | PE、PEG | DCF | — |
| 地产 | P/RNAV、PB | 股息率 | PE |
| 制造业 | EV/EBITDA | PE、PB | — |

## 三、剩余收益模型（Residual Income Model）

### 适用场景

当 DCF 中使用过多假设感到不安时，RIM 提供了基于会计数据的替代方案。特别适用于：
- 不支付股息的公司
- FCF 波动大的公司
- 金融企业（账面价值更可靠）

### 公式

```
股权价值 = BV0 + Σ(RIt / (1+r)^t) + 永续剩余收益现值

RI = EPS - r × BV_{t-1}
```

即：股权价值 = 当前账面价值 + 未来超额收益的现值。

## 四、安全边际框架

### 晨星标准

| 公司类型 | 要求安全边际 | 逻辑 |
|---------|------------|------|
| 强护城河/稳定 | ≥ 20% | 确定性高，20% 足以覆盖误差 |
| 一般竞争优势 | ≥ 30-40% | 需要更大缓冲 |
| 高风险/周期 | ≥ 50-60% | 不确定性极高 |

### 安全边际的来源形式

1. **估值折价**：当前股价远低于内在价值
2. **资产保障**：股价低于清算价值/净现金
3. **分红保障**：股息率高于无风险利率 + 风险溢价
4. **成长保障**：当前估值未包含未来增长

## 五、估值结论的呈现标准

任何估值结论必须包含：
1. **估值方法选择理由**：为什么选这个方法
2. **关键假设清单**：列出所有会影响结果 10%+ 的假设
3. **敏感性分析**：至少 WACC 和增长率两个维度
4. **情景分析**：乐观/中性/悲观三情景
5. **安全边际判断**：当前价格相对内在价值的折扣
6. **估值局限性**：该方法对这家公司的主要盲区
