# PyDESeq2 RNA 差异表达

- 唯一标识：`hub-pydeseq2`
- 显示名称：PyDESeq2 RNA 差异表达
- 能力摘要：使用 PyDESeq2 对 bulk RNA-seq 原始计数进行单因素或多因素差异表达分析，处理设计矩阵、归一化、Wald 检验、多重校正和效应量收缩。

## 案例素材

1. 团队比较处理组与对照组转录变化。该 skill 会从整数 count matrix 和样本元数据构建设计，先检查测序深度、离群样本和重复数，再报告校正后的差异结果。
2. 实验同时包含批次和治疗因素。该 skill 会将批次纳入设计矩阵，明确对比定义，检查混杂是否使效应不可辨识，而不把批次差异误写成治疗反应。
3. 论文需要展示候选基因。该 skill 会使用收缩后的 log fold change、FDR 和表达量过滤制作可复查表格，并将统计显著性与后续生物学验证区分开。
