# Skill Info

## Skill Name
医药专业术语中英互译

## Description
医药专业术语中英互译工具。当用户需要翻译医药领域专业术语（包括药品名称、靶点、不良反应术语、疾病名称、临床试验术语等）时触发此技能。触发词包括：医药术语翻译、中英互译、医学名词翻译、不良反应术语翻译、靶点名称翻译、药品名称翻译、MedDRA翻译、术语对照、medical term translation、pharmaceutical terminology等。内置MedDRA、WHO-Drug、INN、MeSH等权威词库参照，确保输出标准医学术语而非机翻结果。

## Introduction

本技能在医药翻译领域提供专业术语的中英双向标准化互译。

医药专业术语中英互译旨在解决通用翻译工具对医学专有名词翻译不准确的问题，为医药行业全员（医学事务、临床研究、市场准入、产品经理等）提供权威词库驱动的术语翻译支持。

核心能力：

- 术语输入识别与语言方向判断
- 多源权威词库交叉检索（MedDRA/WHO-Drug/INN/MeSH）
- 歧义术语识别与上下文判断
- 标准化详细模式输出（含词源、层级、同义词）
- 合规校验与机翻风险标注

应用场景：

- 不良事件报告中的MedDRA术语翻译
- 临床试验方案及CSR中的医学术语对照
- 药品说明书、标签的术语标准化
- 医学文献阅读与综述撰写
- 监管申报材料中的术语统一
- 科室会PPT及学术推广材料制作
