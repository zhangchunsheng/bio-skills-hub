# 易错词对照表

本文件收录医药翻译中常见的机翻陷阱、多义词及形近词，供翻译时参考避免错误。

## 三、形近词（易混淆）

| 术语 A | 术语 B | 区别 |
|--------|--------|------|
| pharmacokinetics (PK) | pharmacodynamics (PD) | PK=药代动力学（药物在体内的过程）；PD=药效动力学（药物对机体的作用） |
| agonist | antagonist | 激动剂 vs 拮抗剂 |
| efficacy | effectiveness | efficacy=疗效（理想条件下）；effectiveness=效果（真实世界条件下） |
| incidence | prevalence | incidence=发病率（新发）；prevalence=患病率（现存） |
| morbidity | mortality | morbidity=发病率/患病率；mortality=死亡率 |
| sensitivity | specificity | sensitivity=敏感度（真阳性率）；specificity=特异度（真阴性率） |
| adverse event (AE) | adverse drug reaction (ADR) | AE=不良事件（不一定与药物有关）；ADR=药物不良反应（有因果关系） |
| side effect | adverse event | side effect=副作用（可预期）；AE=不良事件（广义） |
| contraindication | precaution | contraindication=禁忌；precaution=注意事项 |
| absolute bioavailability | relative bioavailability | absolute=绝对生物利用度（vs静脉）；relative=相对生物利用度（vs参比制剂） |
| loading dose | maintenance dose | loading=负荷剂量；maintenance=维持剂量 |
| single-blind | double-blind | single-blind=单盲；double-blind=双盲 |
| open-label | blinded | open-label=开放标签；blinded=盲法 |
| primary endpoint | secondary endpoint | primary=主要终点；secondary=次要终点 |
| intent-to-treat (ITT) | per-protocol (PP) | ITT=意向性治疗分析（所有随机化受试者）；PP=符合方案分析（完成方案的受试者） |
| confidence interval (CI) | p-value | CI=置信区间（区间估计）；p-value= p 值（假设检验） |
| hazard ratio (HR) | odds ratio (OR) | HR=风险比（生存分析）；OR=比值比（病例对照） |
| randomization | random sampling | randomization=随机化（分组）；random sampling=随机抽样（抽样） |
| standard deviation (SD) | standard error (SE) | SD=标准差（个体变异）；SE=标准误（样本统计量变异） |

## 四、中文易混淆词

| 中文 A | 中文 B | 区别 |
|--------|--------|------|
| 适应症 | 用途 | 适应症=indication（法规批准的）；用途=use（广泛） |
| 禁忌症 | 注意事项 | 禁忌症=contraindication（绝对不能用）；注意事项=precaution（需谨慎） |
| 副作用 | 不良反应 | 副作用=side effect（可预期）；不良反应=adverse reaction（广义） |
| 药品 | 药物 | 药品=medicinal product（已批准上市）；药物=drug（广义含研发阶段） |
| 通用名 | 商品名 | 通用名=INN（国际标准）；商品名=trade name（企业注册） |
| 仿制药 | 通用名药 | 仿制药=generic drug（与参比制剂等效）；通用名药=以通用名标识的药品 |
| 给药 | 用药 | 给药=administration（强调途径）；用药=medication（强调行为） |
| 缓解 | 治愈 | 缓解=remission（症状减轻）；治愈=cure（完全消除） |
| 预后 | 诊断 | 预后=prognosis（疾病发展预测）；诊断=diagnosis（识别疾病） |
| 适应症 | 适应证 | 同义，但 2020 年药典规范用"适应症" |
| 禁忌症 | 禁忌证 | 同义，但 2020 年药典规范用"禁忌症" |

## 五、CTCAE 常见毒性分级术语

| 英文（PT） | 中文 | Grade 1 | Grade 2 | Grade 3 | Grade 4 |
|------------|------|---------|---------|---------|---------|
| Nausea | 恶心 | 可耐受，无需干预 | 经口进食减少 | 经口摄入热量/液体不足 | 需肠外营养 |
| Vomiting | 呕吐 | 1次/24h | 2-5次/24h | ≥6次/24h或需输液 | 危及生命 |
| Diarrhea | 腹泻 | 比基线增加<4次/日 | 增加4-6次/日 | 增加≥7次/日或需住院 | 危及生命 |
| Fatigue | 疲乏 | 轻度，不影响功能 | 中度，影响工具性日常生活 | 重度，影响自理能力 | — |
| Rash | 皮疹 | <10%体表面积 | 10-30%体表面积 | >30%体表面积 | 危及生命 |
| Neutropenia | 中性粒细胞减少 | <LLN-1500/μL | <1500-1000/μL | <1000-500/μL | <500/μL |
| Thrombocytopenia | 血小板减少 | <LLN-75×10⁹/L | <75-50×10⁹/L | <50-25×10⁹/L | <25×10⁹/L |
| Anemia | 贫血 | <LLN-100 g/L | <100-80 g/L | <80 g/L | 危及生命 |
| Elevated ALT | 丙氨酸氨基转移酶升高 | >ULN-3×ULN | >3-5×ULN | >5-20×ULN | >20×ULN |
