# 药理病理解析

## 🎯 Skill 功能与目的

本 Skill 旨在为用户提供**病理生理学与药理学**的交叉知识解析服务，帮助用户理解疾病发生、发展的基本机制，以及药物如何通过干预这些机制发挥治疗作用。

### 学科基础

本 Skill 整合了**生理学、病理生理学、药理学**三门基础医学学科的知识体系[citation:6][citation:12]。这三大学科构成了医学机能学的核心，其内在联系为：

> **生理学** → 认识正常机体的功能活动
> ↓
> **病理生理学** → 理解疾病状态下机体的异常变化
> ↓
> **药理学** → 掌握药物如何纠正这些异常，恢复机体稳态

正如机能学实验室的教学理念所示，通过“基础-综合-创新”递进式培养体系，本Skill将帮助用户从正常机体、疾病变化到药物治疗的有机联系中，整体把握医学机能学的核心知识[citation:6][citation:12]。

### 适用场景

1. 医学生复习病理生理学与药理学知识
2. 临床医生理解疾病机制与用药原理
3. 患者了解自身疾病的发病机制和治疗依据
4. 医疗从业者查阅药物作用机制
5. 科研人员获取机制研究参考


## 🩺 病理生理学核心概念

### 疾病的基本机制

疾病的发生发展通常涉及以下基本机制层面：

| 机制层次 | 主要内容 |
| :--- | :--- |
| **分子机制** | 基因突变、蛋白质异常、信号通路失调 |
| **细胞机制** | 细胞损伤、细胞凋亡、炎症反应 |
| **组织器官机制** | 组织缺血缺氧、器官功能不全 |
| **系统机制** | 神经-内分泌-免疫网络失衡 |

### 常见病理过程

| 病理过程 | 核心机制 | 代表性疾病 |
| :--- | :--- | :--- |
| 炎症 | 血管反应、白细胞浸润、介质释放 | 感染、自身免疫病 |
| 缺血缺氧 | 供血不足、氧供减少、能量代谢障碍 | 冠心病、脑卒中 |
| 氧化应激 | 自由基生成过多、抗氧化能力下降 | 动脉粥样硬化、衰老 |
| 细胞凋亡异常 | 凋亡不足（肿瘤）或凋亡过度（退行性疾病） | 癌症、阿尔茨海默病 |
| 水电解质紊乱 | 体液平衡失调、电解质紊乱 | 心力衰竭、肾衰竭 |


## 💊 药理学核心概念

### 药物作用的基本原理

#### 1. 药物-靶点相互作用
药物通过作用于特定靶点（受体、酶、离子通道、转运体）发挥效应[citation:4]：

| 靶点类型 | 作用机制 | 代表药物 |
| :--- | :--- | :--- |
| G蛋白偶联受体 | 激活或阻断受体信号传导 | β受体阻滞剂、阿片类药物 |
| 离子通道 | 调节通道开放/关闭 | 钙通道阻滞剂、钠通道阻滞剂 |
| 酶 | 抑制或激活酶活性 | ACE抑制剂、他汀类药物 |
| 转运体 | 影响神经递质再摄取 | 抗抑郁药（SSRI） |

#### 2. 药物代谢动力学（ADME）
- **吸收（Absorption）**：药物进入血液循环的过程
- **分布（Distribution）**：药物在体内的分布
- **代谢（Metabolism）**：药物的生物转化（主要在肝脏）
- **排泄（Excretion）**：药物的排出（肾脏为主）

#### 3. 药物效应动力学（PD）
- 量效关系：药物剂量与效应的关系
- 时效关系：药物效应随时间的变化
- 受体理论：激动剂、拮抗剂、部分激动剂
