# GRADE证据分级 → GEO内容映射规则详解

> 本文件是 medical-evidence-geo-bridge 的参考文件，详细定义GRADE各级证据在GEO内容中的使用规则。

---

## 一、GRADE四级体系标准定义

### A级（高质量）

| 维度 | 标准 |
|------|------|
| 证据类型 | RCT系统综述/Meta分析/官方指南一级推荐 |
| 样本要求 | 系统综述≥3个RCT，总样本量≥500 |
| 偏倚控制 | 充分随机化、盲法、意向性分析 |
| 一致性 | 各研究结果方向一致，异质性I²<50% |
| 直接性 | PICO直接匹配目标人群和终点 |
| 有效期 | 5年内（超过5年降为B级） |

**GEO内容中的使用规则**：
- ✅ 可使用"临床研究证实""循证医学证据表明"等强措辞
- ✅ 可引用具体数据（如"降低XX%"）
- ✅ 可作为FAQ核心回答的依据
- ✅ 可在科普内容中使用
- ⚠️ 仍需标注证据来源和发表年份

### B级（中质量）

| 维度 | 标准 |
|------|------|
| 证据类型 | 单个RCT/队列研究/官方指南二级推荐 |
| 样本要求 | RCT样本量≥100，或队列研究≥300 |
| 偏倚控制 | 基本满足随机化/盲法要求，但可能存在部分偏倚 |
| 一致性 | 结果方向基本一致 |
| 直接性 | PICO基本匹配，可能存在部分间接性 |
| 有效期 | 5年内（超过5年降为C级） |

**GEO内容中的使用规则**：
- ✅ 可使用"研究表明""临床数据显示"等中等措辞
- ✅ 可引用数据但需加限定语（如"在一项研究中显示"）
- ⚠️ 不宜作为核心功效声称的唯一依据
- ⚠️ 需标注"尚需更多研究验证"

### C级（低质量）

| 维度 | 标准 |
|------|------|
| 证据类型 | 观察性研究/病例报告/专家意见/官方指南三级推荐 |
| 样本要求 | 无明确下限要求 |
| 偏倚控制 | 存在明显混杂因素或选择偏倚 |
| 一致性 | 结果可能不一致 |
| 直接性 | 间接证据或部分匹配 |
| 有效期 | 3年内（超过3年降为D级） |

**GEO内容中的使用规则**：
- ⚠️ 只能使用"有报道指出""部分观察发现"等弱措辞
- ❌ 不可引用具体疗效数据
- ❌ 不可作为功效声称的依据
- ✅ 可用于安全性提示、用药注意事项等辅助信息

### D级（极低质量）

| 维度 | 标准 |
|------|------|
| 证据类型 | 体外实验/动物实验/理论推导/个案报道 |
| 样本要求 | 不适用 |
| 偏倚控制 | 无法评估 |
| 一致性 | 不适用或高度不确定 |
| 直接性 | 间接证据，PICO不匹配 |
| 有效期 | 无明确有效期，随时可能被推翻 |

**GEO内容中的使用规则**：
- ❌ 不可用于任何功效声称
- ⚠️ 仅可作为"机制探讨""研究方向"的参考
- ⚠️ 必须标注"尚无临床证据支持"
- ✅ 可用于基础科学科普内容

## 二、证据→内容措辞映射表

| GRADE等级 | 可用措辞 | 禁用措辞 | 数据引用 | 适应症声称 |
|-----------|---------|---------|---------|-----------|
| A级 | 证实/表明/显示 | 保证/治愈/根治 | ✅可引用具体数据 | ✅可在说明书范围内声称 |
| B级 | 研究/数据/提示 | 证实/确证 | ✅需加限定语 | ⚠️需加"尚需验证" |
| C级 | 报道/观察/认为 | 显示/数据 | ❌不可引用数据 | ❌不可声称 |
| D级 | 探讨/推测/理论 | 报道/发现 | ❌ | ❌ |

## 三、证据更新触发规则

### 触发事件分类

| 事件类型 | GRADE变化 | 响应级别 | 响应时限 | 内容动作 |
|---------|-----------|---------|---------|---------|
| 新A级证据发表 | 新增A级 | P1 | 1周 | 评估是否更新/新增内容 |
| 新B级证据发表 | 新增B级 | P2 | 2周 | 评估是否补充现有内容 |
| 证据升级 | C→B或B→A | P1 | 1周 | 升级内容措辞和数据 |
| 证据降级 | A→B或B→C | P2 | 2周 | 降级内容措辞 |
| 证据撤稿 | 任意→无效 | P0 | 48小时 | 下线或紧急修订相关内容 |
| 安全性警告 | 新增安全事件 | P0 | 48小时 | 新增安全提示信息 |
| 指南更新 | 推荐等级变化 | P1 | 1周 | 同步更新内容口径 |
| 证据过期 | 自动降级 | P3 | 月度 | 更新证据标注 |

### 更新评估决策树

```
新证据入库
├── 安全性证据？
│   ├── 是 → P0紧急响应（48小时）
│   └── 否 → 继续判断
├── GRADE等级？
│   ├── A级 → 评估现有内容是否需要升级措辞
│   │   ├── 现有内容已用A级措辞 → 无需更新
│   │   └── 现有内容用B/C级措辞 → 生成升级指令
│   ├── B级 → 评估是否补充现有内容
│   │   ├── 现有内容已有A级支撑 → 无需更新
│   │   └── 现有内容只有C级或无证据 → 生成补充指令
│   └── C/D级 → 记录但不触发更新（除非证据缺口严重）
└── 证据冲突？
    ├── 与现有A级证据冲突 → 标注冲突，建议医学团队裁决
    └── 与现有B/C级证据一致 → 增强现有证据基础
```

## 四、溯源链审计标准

### 完整性评分

| 完整性等级 | 条件 | 分值 |
|-----------|------|------|
| L1-L4完整 | 证据→内容→AI引用→用户可见 全链路通 | 100分 |
| L1-L3完整 | 证据→内容→AI引用（用户可见性未验证） | 75分 |
| L1-L2完整 | 证据→内容（未被AI引用） | 50分 |
| L1仅存在 | 有证据但未转化为内容 | 25分 |
| 全链断裂 | 有语义群需求但无证据 | 0分 |

### 断链修复策略

| 断裂位置 | 修复动作 | 负责技能 |
|---------|---------|---------|
| L1→L2 | 基于证据生成新GEO内容 | S5 geo-content-generator |
| L2→L3 | 调整内容分发策略，增加AI平台触达 | S8 geo-content-distribution |
| L3→L4 | 分析AI展示逻辑，优化内容结构化标记 | S5 + pharma-geo-pjm |
| L1缺失 | 发起文献检索，补充证据库 | 医学团队（人工） |
