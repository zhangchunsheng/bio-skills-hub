# 热敏灸疗法知识库

## 来源
陈日新教授《热敏灸实用读本》及《中医外治疗法治百病丛书——热敏灸疗法》（人民卫生出版社，2014年）

## 热敏灸概念

热敏灸疗法是选择热敏的腧穴，施给消敏的灸量进行悬灸以提高疗效的一种灸疗新技术。**热敏灸，灸在体表，热在体内！**

### 与传统悬灸的四大本质区别

1. **灸感不同**：热敏灸产生6种热敏灸感（透热、扩热、传热、局部不热远部热、表面不热深部热、非热觉），传统悬灸仅有局部和表面的热感
2. **灸位不同**：热敏灸在热敏穴位上施灸，最易激发经气感传；传统悬灸不区分穴位敏化态与静息态
3. **灸量不同**：热敏灸每穴施灸时间以个体化热敏灸感消失为度（10分钟至200分钟不等）；传统悬灸固定10-15分钟
4. **灸效不同**：大幅度提高疗效（如膝关节骨性关节炎显效率从21.05%提高到80.95%）

## 六种热敏灸感

1. **透热**：灸热从施灸穴位皮肤表面直接向深部组织穿透，甚至直达胸腹腔脏器
2. **扩热**：灸热以施灸穴位为中心向周围片状扩散
3. **传热**：灸热从施灸穴位开始循经脉路线向远部传导，甚至到达病所
4. **局部不（微）热远部热**：施灸部位不热，而远离施灸的部位感觉甚热
5. **表面不（微）热深部热**：施灸部位皮肤不热，而皮下深部组织甚至胸腹腔脏器感觉甚热
6. **非热感觉**：施灸部位或远离施灸部位产生酸、胀、压、重、痛、麻、冷等感觉

## 穴位热敏规律

1. **普遍性**：疾病状态下穴位热敏出现率70%（健康人仅10%），寒证、湿证、瘀证、虚证居多
2. **动态性**：热敏穴位随病情变化而变化，与经穴重合率仅48.76%
3. **证候相关性**：过敏性鼻炎热敏常发生在上印堂；便秘热敏常发生在大肠俞；痛经热敏常发生在关元
4. **高效性**：艾灸热敏穴位的经气感传出现率达94.0%（非热敏穴位仅23.5%）

## 操作十六字诀

**探感定位、辨敏施灸、量因人异、敏消量足**

## 艾灸疗法四大作用

1. **温经散寒，行气通络**：气血遇寒则凝，得温则散
2. **扶阳固脱，升阳举陷**：艾叶性属纯阳，火本属阳，两阳相加
3. **泄热拔毒，消瘀散结**："热者灸之，引郁热之气外发"
4. **防病保健，延年益寿**：提高机体免疫能力

## 艾灸四大调节特点

1. **双向调节**：功能低下时可增强，功能亢进时可降低，对正常生理功能无明显影响
2. **整体调节**：可在不同水平上同时对多个器官、系统功能产生影响
3. **品质调节**：提高体内各调节系统品质，增强自身调节能力
4. **自限调节**：调节能力有限度，必须在生理调节范围内

## 适应证原则

- 寒湿入体，灸优于针
- 阳虚病症，灸贵于针
- 瘀血阻络，灸之所宜
- 气阴不足，亦可用灸
- 热毒之证，亦可灸之

## 热敏灸治疗方法（各疾病）

### 1. 颈椎病
**热敏高发部位**：神庭、风府、风池、大椎、颈夹脊、肺俞、肩井、至阳
- 颈型：颈夹脊压痛点单点温和灸 + 肩井压痛点单点温和灸 + 风池/大椎三角温和灸
- 神经根型：颈夹脊压痛点 + 肩井压痛点 + 大椎/肺俞
- 椎动脉型：神庭/大椎双点温和灸
- 疗程：每天1-2次，10次1疗程，共2-3疗程

### 2. 肩周炎
**热敏高发部位**：肩部压痛点、膏肓俞、肩井
- 疗程：每天1次，10次1疗程，共2-3疗程

### 3. 膝骨性关节炎
**热敏高发部位**：局部压痛点、内外膝眼、梁丘、阴陵泉、血海、阳陵泉
- 疗程：每天1次，10次1疗程，共2-3疗程

### 4. 腰椎间盘突出症
**热敏高发部位**：腰俞、命门、至阳、关元俞、腰部压痛点、委中、承扶、阳陵泉、昆仑
- 疗程：每天1次，10次1疗程，共1-2疗程

### 5. 失眠症
**热敏高发部位**：百会、心俞、至阳、神阙、涌泉
- 疗程：每天1次，10次1疗程，共2-3疗程

### 6. 功能性便秘
**热敏高发部位**：天枢、大肠俞、次髎、上巨虚
- 疗程：每天1次，10次1疗程，共2-3疗程

### 7. 原发性痛经
**热敏高发部位**：关元、子宫、次髎、三阴交
- 疗程：每次选2组穴位，每天1次，自月经来前3天开始，连续5天1疗程，共3个月经周期

### 8. 感冒
**热敏高发部位**：上印堂、太阳、风池、风府、大椎、至阳、腰阳关
- 疗程：每天2次，灸至症状消失（一般1-2天）
- 辨证：
  - 流鼻涕/打喷嚏/鼻塞/前额紧痛 → 上印堂单点温和灸 + 太阳双点温和灸
  - 头项强痛 → 大椎/风池三角温和灸
  - 恶风/恶寒发热/全身乏力 → 风府→大椎→至阳→腰阳关循经往返接力灸

### 9. 过敏性鼻炎
**热敏高发部位**：上印堂、通天、风池、肺俞、神阙
- 疗程：每次选2-3组穴位，每天1次，10次1疗程，共2-3疗程

### 10. 慢性前列腺炎
**热敏高发部位**：关元、中极、肾俞、命门、次髎
- 疗程：每天1次，10次1疗程，共2-3疗程
