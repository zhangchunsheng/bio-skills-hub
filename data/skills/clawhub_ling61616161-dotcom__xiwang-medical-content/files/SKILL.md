# 烯旺石墨烯医疗内容智能生成

## Overview

本技能基于烯旺集团全套科研资料，实现"检索资料库 → 提取科研核心信息 → 匹配对应风格 → 输出完整成品文案"全流程自动化处理。

## 资料库结构

所有资料来源均为下方 references/ 目录文件，创作时严格依据这些资料：

| 文件 | 内容 |
|------|------|
| `references/company_overview.md` | 企业概况、创始人、核心技术、产业布局、产品线、合作伙伴、资质荣誉 |
| `references/medical_research.md` | 27项医疗研究（18已发表+4未发表+PPT记载），含完整研究数据、结论 |
| `references/thermal_moxibustion.md` | 热敏灸理论与治疗方法，石墨烯+热敏灸融合 |
| `references/milestones.md` | 企业大事记（2015-2026），含估值变化、重要里程碑 |

## 工作流程

### 第一步：加载资料库

收到用户请求后，首先根据用户关键词判断涉及哪些领域的资料，选择性加载对应的 references/ 文件。不需要每次都加载全部文件，优先加载最相关的1-2个文件。

### 第二步：智能检索与提取

根据用户输入的关键词或主题，在已加载的资料中进行精准检索：

1. **关键词匹配**：在资料中搜索用户输入的关键词和相关同义词
2. **关联扩展**：自动关联相关实验数据、论文出处、合作机构、诺奖关联理论
3. **核心提炼**：从检索结果中提取可用于文案创作的科研要点，包含：
   - 研究机构与发表期刊（增强权威性）
   - 实验方法与样本量（增强可信度）
   - 核心数据与统计显著性（P值等）
   - 结论与应用价值
4. **检索结果呈现**：先向用户展示检索到的核心科研要点摘要，再生成文案

### 第三步：文案类型判断与生成

根据用户指定的文案类型，匹配对应风格模板生成文案。若用户未明确指定类型，应询问用户需要哪种类型。

## 三类文案生成规范

### 类型一：视频号口播文案

**定位**：短视频节奏、悬念开头、通俗科普，适配短视频平台审核规则

**结构模板**：
```
【黄金三秒Hook】用悬念/痛点/反常识开头
【痛点共鸣】用户熟悉的场景/困扰
【科研证据】引用资料库中具体的研究数据（机构+数据）
【原理科普】用大白话解释远红外/石墨烯原理
【产品特性介绍】基于资料介绍产品物理特性（不涉及医疗疗效承诺）
【行动号召】引导点赞/收藏/关注
```

**写作要求**：
- 全文300-500字，适应60-90秒口播时长
- 开头必须在前3秒抓住注意力（可用问句、数据冲击、反差对比）
- 语言口语化、有节奏感，适合真人朗读
- 每段1-2句话，短句为主
- 含1-2句金句（适合截图传播）
- 科研引用格式：「XX医院/大学的研究显示……」
- 涉及产品时用"物理特性""材料科技"等表述，避免"治疗""疗效"等医疗承诺
- 结尾引导互动

**合规红线**（自动执行，不可违反）：
- 不虚构任何实验数据、疗效数据
- 不出现"治愈""根治""保证有效"等承诺性表述
- 区分科研理论科普（可讲）与产品医疗功效宣称（不可做）
- 产品描述使用"辅助""配合""结合"等限定词
- 所有数据必须可在 references/ 中找到出处

### 类型二：小红书科普文案

**定位**：轻量化短句、分段清晰、自带科普吸睛逻辑，适配小红书社区风格

**结构模板**：
```
【标题】吸睛标题（含数字/悬念/对比/热点词）
【封面文字建议】一句话核心卖点
【正文】
  - 开头：一句话戳中痛点/好奇心
  - 分段科普：每段不超过3行，用emoji分隔
  - 科研证据：引用1-2个权威研究
  - 总结/金句
【话题标签】5-8个精准标签
```

**写作要求**：
- 全文400-800字
- 分段用emoji或符号分隔，视觉透气
- 语言亲近、有分享感，像朋友推荐
- 多用短句、问句、感叹句
- 每段之间用空行分隔
- 标签包含#石墨烯 #远红外 #健康科普 #烯旺 等+领域相关标签

**合规红线**：同类型一

### 类型三：公众号深度科普文案

**定位**：逻辑完整、专业严谨、分章节排版，适合企业官方推文发布

**结构模板**：
```
【标题】专业而有吸引力的标题
【导语】150字以内，引出话题+核心观点
【正文分章节】
  第一章：背景/问题引入
  第二章：科研证据详述（多引用资料库研究）
  第三章：原理深度解析
  第四章：应用与展望
【结语】总结升华，回扣主题
【参考文献】列出引用的研究（作者、期刊、年份）
```

**写作要求**：
- 全文1500-3000字
- 章节标题使用数字编号
- 引用研究时标注完整的作者、期刊、年份信息
- 语言专业但不晦涩，面向知识型大众读者
- 适当使用"我们""大家"拉近距离
- 穿插研究数据增强说服力
- 末尾可附企业/产品简介（基于资料库信息）

**合规红线**：同类型一，公众号文案尤其注意数据出处标注

## 内容规范（内置底层，自动执行）

### 论据来源规范
- 所有科学论述必须可在 references/ 中找到对应研究
- 数据引用格式：必须包含研究机构/医院名称 + 期刊名（如适用）
- 不确定的数据不得编造，可标注"据烯旺集团内部研究资料"

### 科研科普 vs 产品介绍区分
- **科研理论科普**（可自由发挥）：远红外原理、石墨烯材料特性、生命光波概念、共振效应、温热效应、热敏灸理论、穴位经络理论
- **产品物理特性介绍**（基于资料可描述）：石墨烯发热膜波长范围（6-14μm）、法向全发射率（0.87）、工作电压、温度范围、CVD制备工艺、产品形态（护腰/护膝/鼻罩/眼罩等）、医疗器械认证编号
- **不可表述**（严格禁止）：产品能"治疗"某疾病、"治愈率"数据、与其他治疗手段的有效性对比（除非资料中有对照实验数据）、未经资料库证实的用户见证/案例

### 敏感表述替换指南
| 避免使用的表述 | 替换为 |
|--------------|--------|
| 治疗XX病 | 辅助/配合/有助于改善XX |
| 治愈率/有效率XX% | 研究中观察到XX改善（P<0.05） |
| XX产品可以治疗 | XX产品基于XX原理，发出6-14μm远红外 |
| 临床证明 | 研究表明/资料显示 |
| 保证效果 | 提供一种选择/方式 |

## 交互逻辑

### 用户输入模式

**模式A：检索+生成**
```
用户：检索鼻炎相关研究，生成小红书文案
→ 技能自动完成：检索资料库→提取鼻炎相关研究→匹配小红书风格→输出成品文案
```

**模式B：仅检索**
```
用户：检索肿瘤治疗相关研究
→ 技能输出检索到的科研要点摘要
```

**模式C：多类型生成**
```
用户：检索甲状腺结节研究，分别生成口播文案和小红书文案
→ 技能检索一次，生成两种风格文案
```

