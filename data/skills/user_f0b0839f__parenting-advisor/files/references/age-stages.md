# 年龄段发展知识库

> 分析行为/心理/发育问题前，按孩子当前年龄加载对应段落作为背景。
> 用途：① 判断"正常发展行为 vs 问题行为"；② 提供理论框架（皮亚杰/埃里克森）定位；③ 生成"你可能忽略的"盲区提醒。

## 发育阶段总览

| 年龄段 | 关键发育特征 | 常见关切 |
|--------|-------------|----------|
| 0-6月 | 原始反射主导、感官发育期、建立依恋 | 喂养、睡眠、肠绞痛、湿疹 |
| 6-12月 | 坐→爬→站、分离焦虑出现、辅食引入 | 夜醒、陌生人焦虑、摔碰 |
| 1-2岁 | 学步期、语言爆发前期、自我意识萌芽 | 扔东西、咬人、情绪崩溃、分离焦虑 |
| 2-3岁 | "可怕的两岁"、语言爆发、规则试探 | 说不、打人、如厕训练、挑食 |
| 3-5岁 | 想象力爆发、社交需求、性别认同 | 撒谎、害怕、社交冲突、入学适应 |
| 6-9岁 | 具体运算思维、同伴关系、自我评价 | 学习习惯、注意力、校园社交、拖延 |
| 9-13岁 | 抽象思维萌芽、同伴压力、身体变化 | 电子产品、青春期前兆、自我认同 |

## 0-6 月（新生儿/婴儿早期）

| 关切 | 常见原因 | 关键参考 |
|------|----------|----------|
| 吐奶 | 生理性胃食管反流（贲门未发育完全）vs 病理性 | AAP/NHS/崔玉涛 |
| 湿疹 | 皮肤屏障未成熟、过敏体质 | 崔玉涛/中华儿科 |
| 肠绞痛 | 原因不明，3周-3月高发，傍晚哭闹 | AAP/NHS |
| 睡眠问题 | 新生儿无昼夜概念、睡眠周期短 | AAP Safe Sleep |
| 大便颜色/性状 | 母乳/配方奶差异大 | AAP/NHS |
| 黄疸 | 生理性 vs 病理性（持续时间、胆红素水平） | 中华儿科/AAP |

## 6-12 月（婴儿晚期）

| 关切 | 常见原因 | 关键参考 |
|------|----------|----------|
| 辅食引入 | 过敏观察、食物性状递进 | WHO/崔玉涛 |
| 分离焦虑 | 物体永存概念建立（8-10月高峰期） | 皮亚杰/AAP |
| 夜醒 | 出牙、分离焦虑、睡眠倒退 | AAP |
| 陌生人焦虑 | 正常发育标志，6-12月出现 | 发展心理学 |
| 不会爬 | 发育节奏个体差异大 | CDC里程碑 |

## 1-2 岁（幼儿早期）

| 关切 | 常见原因 | 关键参考 |
|------|----------|----------|
| 扔东西 | 因果探索、手部技能练习 | 皮亚杰感知运动期 |
| 咬人/打人 | 语言未发展时的沟通方式、情绪表达 | 正面管教 |
| 情绪崩溃 | 前额叶未发育、不会调节情绪 | AAP/发展心理学 |
| 说不 | 自主性发展（埃里克森自主vs羞怯） | 埃里克森 |
| 挑食 | 生长速度放缓、新食物恐惧 | AAP/崔玉涛 |
| 如厕训练 | 生理准备信号（18-24月通常开始） | AAP |

## 2-3 岁（"可怕的两岁"）

| 关切 | 常见原因 | 关键参考 |
|------|----------|----------|
| 秩序敏感 | 认知发展的必经阶段 | 蒙台梭利/皮亚杰 |
| 打人/推人 | 物权意识、冲突解决能力不足 | 正面管教 |
| 语言爆发期的表达困难 | 想说的远超能说的 | 发展心理学 |
| 夜间恐惧 | 想象力发展、分不清现实和幻想 | AAP |
| 拒绝分享 | 物权意识正常发展，非自私 | 发展心理学 |

## 3-5 岁（学龄前）

| 关切 | 常见原因 | 关键参考 |
|------|----------|----------|
| 撒谎 | 想象力与现实的混淆，或逃避惩罚 | 皮亚杰前运算期 |
| 社交冲突 | 观点采择能力不足 | 皮亚杰/塞尔曼 |
| 害怕/恐惧 | 想象力发展+认知能力不足以理解 | AAP |
| 注意力短暂 | 前额叶仍在发育，3岁通常5-10分钟 | 发展心理学 |
| 性别好奇 | 正常的性别认同发展 | AAP |

## 6-9 岁（小学低年级）

| 关切 | 常见原因 | 关键参考 |
|------|----------|----------|
| 拖延 | 时间概念仍在发展、任务太大 | 正面管教 |
| 注意力问题 | 日均注意力约15-20分钟 | 发展心理学 |
| 社交焦虑 | 同伴评价开始影响自我概念 | 埃里克森勤奋vs自卑 |
| 撒谎升级 | 有意识的欺骗——关注背后的动机而非行为 | 正面管教 |
| 屏幕时间冲突 | 自控力不足+内容吸引力强 | AAP屏幕时间建议 |

## 9-13 岁（小学高年级/青春期前）

| 关切 | 常见原因 | 关键参考 |
|------|----------|----------|
| 同伴压力 | 同伴群体取代家庭成为主要参照 | 埃里克森/发展心理学 |
| 情绪波动 | 青春期前激素变化+认知发展 | AAP |
| 身体意识 | 第二性征开始、身体形象焦虑 | AAP |
| 独立需求 | 自主性发展的关键期 | 埃里克森 |
| 电子产品沉迷 | 多巴胺回路+社交需求+逃避现实 | AAP |
