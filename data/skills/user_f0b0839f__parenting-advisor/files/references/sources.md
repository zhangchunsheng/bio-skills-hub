## 崔玉涛信源验证规则

搜索到标称"崔玉涛"的内容时，必须验证真伪后再采信。

**可信来源（可直接采信）**：
- 崔玉涛本人著作：《崔玉涛育儿百科》《崔玉涛图解家庭育儿》系列
- 育学园官方平台（yuxueyuan.com、育学园 App 官方内容）
- 崔玉涛本人认证的微博/公众号（@崔玉涛）
- 正规媒体对崔玉涛的署名专访（新华社、人民日报、央视、北京卫视等）
- 崔玉涛在学术会议/医疗机构的正规讲座记录

**不可信来源（标记为"假借崔玉涛名义"，不采信）**：
- 自媒体账号以"崔玉涛说""崔玉涛推荐"为标题但无原文出处链接
- 电商平台的"崔玉涛推荐"商品宣传（多为营销话术）
- 论坛/社群中引用的"崔玉涛说过……"（无出处）
- 抖音/快手/小红书上的"崔玉涛育儿"搬运号（非本人认证）
- 任何以"崔玉涛"名义但内容风格明显不匹配（如带货、卖课、推荐具体品牌产品）

**三步验证方法**：
1. 找原文出处（来自哪本书/哪篇文章/哪次访谈）→ 无出处或出处模糊 → 降为"未验证来源"，不标注为崔玉涛本人观点
2. 有明确出处 → 交叉搜索"崔玉涛 + 关键词"用 2 个不同搜索词确认一致
3. 内容涉及具体品牌/产品推荐 → 高度警惕，优先判定为假借名义

**结论采用规则**：
- 崔玉涛本人认证内容与其他权威来源一致 → 以崔玉涛为第一引用，其他来源为交叉验证
- 崔玉涛内容与其他权威来源分歧 → 同时呈现两方观点，标注分歧，不做"谁对谁错"的判断
- 只有假借名义的内容而没有本人认证内容 → 不采信，继续搜索其他来源

**引用格式**：
- 本人认证："📚 崔玉涛《育儿百科》P123：……"
- 育学园："📚 育学园（崔玉涛团队）：……"
- 未验证的不引用为崔玉涛观点

## 交叉验证与可信度星级

先做信源真实性验证（崔玉涛按三步验证；AAP/NHS/WHO/CDC 确认官方域名；中文建议确认有无中华医学会或官方卫生机构背书），再做结论交叉比对：

| 情形 | 可信度 |
|------|--------|
| ≥3 个来源一致（含至少 1 个 🥇/🥈 级） | ★★★★★ 高 |
| 2 个来源一致，含至少 1 个 🥇/🥈 级 | ★★★★☆ 中高 |
| 2 个来源一致但均为中级或以下 | ★★★☆☆ 中等 |
| 来源之间互相矛盾 | 降档，同时列出各方观点，标注分歧来源 |
| 找不到 ≥2 个可靠来源 | ★★☆☆☆ 或更低，诚实说明"目前找到的权威信息有限，以下分析仅供参考" |
