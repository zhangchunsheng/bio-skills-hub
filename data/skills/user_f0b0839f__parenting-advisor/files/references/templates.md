# 档案与记录模板

> 所有写入磁盘的文件模板集中在此。写入前替换 `{ }` 占位符。
> 路径根：`{知识库根}/08-全局记忆/L1-画像记忆/{孩子名}/`

## §1 基础档案.md（流程 A 创建 / 流程 D 更新）

```markdown
---
name: {孩子名}-基础档案
description: {孩子名}的基础信息档案，包含身体数据、健康状态、发育里程碑
metadata:
  type: project
  child: {孩子名}
  dob: {出生日期}
last_updated: {当前日期}
---

# {孩子名} 的基础档案

## 基本信息
- 姓名/昵称：{ }
- 出生日期：{ }
- 性别：{ }
- 出生情况：足月/早产（ 周）、出生体重（ kg）、出生身长（ cm）、分娩方式：{ }

## 身体数据（最新测量）
- 测量日期：{ }
- 身高：{ } cm
- 体重：{ } kg
- 头围：{ } cm（如适用）

## 健康状态
- 过敏史：[ ]
- 慢性病：[ ]
- 手术史：[ ]
- 当前用药：[ ]
- 既往重大疾病：[ ]

## 发育里程碑
- 抬头：{ }
- 翻身：{ }
- 独坐：{ }
- 爬行：{ }
- 扶站：{ }
- 独立行走：{ }
- 第一次有意义的词：{ }
- 其他：{ }

## 疫苗接种
- 见 [[疫苗记录/疫苗接种表]]

## 档案更新日志
- {当前日期}：档案创建
```
