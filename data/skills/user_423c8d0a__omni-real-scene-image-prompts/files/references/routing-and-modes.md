# 任务路由与模式

## 1. 先识别四个问题

1. 这张图要让谁看？
2. 看完要理解、感受、相信或行动什么？
3. 画面是现实复现、证据型原创、一般概念还是拟真虚构？
4. 是单图、系列、编辑、多比例还是批量资产？

## 2. 内容目标路由

| 目标 | 首要画面证据 | 典型图位 |
|---|---|---|
| 停留/点击 | 单一强主体、反差、明确标题区 | 封面、缩略图、主视觉 |
| 理解 | 环境+动作+关键道具 | 场景建立、步骤图 |
| 信任 | 过程、细节、使用痕迹、角色分工 | 过程证据、幕后、纪实 |
| 种草 | 产品在真实生活中的作用 | 使用场景、细节、结果 |
| 转化 | 明确对象、明确结果、文案安全区 | 商品主图、服务结果图 |
| 个人IP | 人物身份、工作/生活上下文 | 环境肖像、行动肖像 |
| 地方感 | 微地理、建筑、交通、人群活动 | 街景、生活场景、远近层 |
| 科普 | 对象、步骤、因果、标注区 | 场景化解释、示意图 |
| 纪实 | 时间、地点、角色、事件过程 | 现场建立、动作、细节 |
| 情绪 | 光线、距离、动作、环境声感 | 生活片段、留白、背影 |

## 3. 单图模式

选择一个能同时表达“主体是谁、在哪里、正在做什么、为什么重要”的图位。单图最多承担一个主结论，不把封面、教程、全景、细节和结尾全部塞进一张。

## 4. 轮播/系列模式

推荐镜头角色：

1. 封面：主题与停留点；
2. 场景：地点、人群、问题；
3. 过程：动作与工具；
4. 细节：局部证据；
5. 结果：完成状态；
6. 对比：变化来源；
7. 结尾：留白和承接。

不是所有系列都必须七张，但每张必须承担不同信息任务。

## 5. 编辑模式

任何编辑先拆成：

- `Change only`：唯一需要改变的区域、对象和目标；
- `Keep unchanged`：构图、主体、几何、背景、光线、材质、文字、画幅中的锁定项；
- `Recalculate`：改变后必须重算的阴影、反射、接触、遮挡、透视和动作。

## 6. 多比例模式

保持：主体身份、产品几何、空间关系、时间、光线和叙事事实。

重构：主体占比、前景、上下留白、文字安全区、视线方向、背景信息量和景深。

禁止：把横图机械居中裁成竖图；让文字区压住人物脸、产品标签或关键动作；为填满画幅随意复制建筑、树木或人物。

## 7. 批量模式

先确定覆盖目标：行业、人群、场景、平台、比例、地域、时段、动作、机位和内容角色。生成候选后评分，保留高价值且差异充分的组合。批量提示词中不得出现连续十条同一机位、同一浅木色空间、同一年轻女性、同一桌面俯拍或同一夕阳滤镜。

## 8. 最小输入默认

示例输入：“露营咖啡，小红书”。

内部默认：

- C级原创真实感；
- 中国近郊合法营地；
- 3:4封面；
- 目标人群为城市轻户外用户；
- 内容目标为生活方式种草；
- 画面使用真实搭建、冲煮动作、天气与装备证据；
- 标题采用后期叠字，不让模型承担长中文。

不向用户输出这些默认假设，只输出成品提示词。
