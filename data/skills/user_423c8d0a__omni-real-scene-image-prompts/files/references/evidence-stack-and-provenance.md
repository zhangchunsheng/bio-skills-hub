# 通用证据栈与事实来源

## 1. 证据优先级

1. 用户确认且有权使用的原始资料；
2. 近期现场、产品、人物、空间或流程资料；
3. 官方/专业行业资料、产品手册、平面图和技术文件；
4. 卫星、正射、街景、地图、POI和公共交通；
5. 统计、气候、历史、服饰、材料与工艺资料；
6. 一般知识与类型经验；
7. 明确标记的原创设定。

不同任务使用不同证据：产品图不需要卫星，工业流程不应仅靠广告图，人物造型不应仅靠地域刻板印象。

## 2. 来源字段

内部记录：

- source_id；
- source_type；
- source_name；
- capture_or_publish_date；
- access_date；
- geographic_or_subject_scope；
- resolution_or_detail_level；
- license_or_permission；
- supported_claims；
- unsupported_claims；
- confidence；
- coordinate_system（地理数据适用）。

## 3. 观察、推断与原创

每个关键细节标记为：

- observed：资料直接可见；
- inferred：由多项证据合理推断；
- original：为完成画面而原创，不得写成现实事实；
- unknown：保持不可辨，不强行补全。

## 4. 不同证据的尺度边界

- 卫星/正射：地形、道路、建筑体量、用地、停车和大型设施；
- 街景/地面：首层界面、铺装、交通、公共设施、立面维护；
- 室内照片/平面图：空间、材料、设备、动线；
- 产品资料：几何、材质、接口、包装、使用方式；
- 工艺资料：设备顺序、角色分工、PPE、物料流；
- 人物参考：授权人物的外观和服装，不自动授权背景、其他人物或个人信息；
- 统计资料：群体规律，不支持具体个人画像；
- 社交平台样例：内容形式参考，不支持复制真实用户、文案、构图或品牌资产。

## 5. 冲突处理

1. 近期、有权使用、与目标粒度相匹配的资料优先；
2. 现场资料优先判断当前状态；
3. 技术文件优先判断设备和工艺；
4. 宏观影像优先判断地理和建筑关系；
5. 冲突无法解决时降级真实性模式；
6. 不用“多数图片都这样”覆盖用户的明确资料。

## 6. 时效性

- 快速变化对象：门店、施工、活动、设备版本、交通组织、平台UI，需要近期资料；
- 中速变化对象：街道立面、植被、物业、职业服装，需要检查年份；
- 稳定对象：地形、传统工艺、基础建筑结构，可使用较旧资料但需说明时代；
- 无日期资料不得支持“当前正在发生”的精确主张。

## 7. A/B/C/D 模式证据最低门槛

- A：目标主体的授权近期资料 + 支持环境/流程的证据；
- B：至少一类环境或行业证据 + 一类主体/流程证据；
- C：可无外部资料，但所有细节必须标记为原创概念；
- D：必须区分史实、推断与艺术重建，不能伪装成档案照片。

## 8. 隐私与去标识化

真实资料中的人脸、车牌、电话、住址、屏幕、订单、病历、学校班级、定位和轨迹默认不进入成图。需要保留时必须有明确授权和必要性。
