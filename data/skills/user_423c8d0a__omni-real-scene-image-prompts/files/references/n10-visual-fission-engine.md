# V10 视觉裂变引擎

## 1. 核心规则

视觉裂变不是把十个词随机排列，而是把一个主题拆成能够被观看、理解、相信、保存、转发或转化的不同图像任务。

每个候选必须通过：

`受众是否明确 → 平台是否匹配 → 场景是否可发生 → 画面能否证明内容 → 模型是否能稳定生成 → 是否值得沉淀为资产`

## 2. 十维总表

| 维度 | 核心问题 | 输出 |
|---|---|---|
| 1 行业/主题轴 | 这个主题属于哪些现实世界 | 行业、生活域、知识域 |
| 2 人群轴 | 谁会看、谁在画面中、谁会行动 | 受众、角色、关系 |
| 3 内容目标轴 | 这张图承担什么传播任务 | 停留、解释、证明、种草、转化 |
| 4 平台轴 | 在哪里发布、以什么比例和节奏出现 | 平台、比例、安全区、系列长度 |
| 5 场景时刻轴 | 哪个具体时刻最能表现主题 | 到达、开始、关键步骤、完成、复盘 |
| 6 主体对象轴 | 画面真正围绕谁或什么 | 人、产品、空间、设备、自然对象 |
| 7 行为叙事轴 | 正在发生什么，前后因果是什么 | 主动作、次动作、流程、冲突 |
| 8 情绪证据轴 | 情绪通过什么可见事实产生 | 光线、距离、姿态、秩序、痕迹 |
| 9 视觉语言轴 | 用什么机位、焦段、构图和材料表达 | 摄影语言、镜头角色、版式机制 |
| 10 交付变体轴 | 如何形成可复用资产而不是一张孤图 | 比例、系列、A/B构图、场景迁移 |

## 3. 行业/主题轴

至少从以下大类中选择相关项：

- 人物与关系；家庭与生活；职场与商业；零售与服务；餐饮与食品；教育与成长；医疗与健康科普；运动与户外；旅行与地方生活；产品与电商；家居与空间；工业与制造；农业与乡村；物流与交通；建筑与基础设施；科技与数字生活；文化与活动；自然与环境；历史与未来。

行业必须落到可见的空间、角色、设备、材料和动作，不能只写抽象行业名。

## 4. 人群轴

区分：

- 观看者：内容面向谁；
- 画中人：谁真实出现在场景；
- 决策者：谁可能购买、预约、收藏或咨询；
- 受益者：谁真正获得结果。

四者可以相同，也可以不同。例如母婴内容的观看者可能是父母，画中人是家长与儿童，决策者是家长，受益者是儿童。

## 5. 内容目标轴

- Stop：在信息流中停留；
- Orient：快速理解主题；
- Explain：解释机制或步骤；
- Prove：显示过程和证据；
- Desire：建立向往和使用想象；
- Compare：看见差异和选择；
- Convert：明确对象与下一步；
- Retain：形成系列记忆和账号资产。

每张图最多选择一个主目标和一个次目标。

## 6. 平台轴

平台决定：

- 比例；
- 缩略图可读性；
- 顶部/底部UI避让；
- 标题安全区；
- 主体占比；
- 轮播页之间的信息节奏；
- 是否需要“像用户真实拍摄”或“像品牌广告”。

不得照搬平台UI、点赞数、评论、搜索框或认证标记。

## 7. 场景时刻轴

优先选择动作密度最高或信息价值最高的时刻：

- 到达前；
- 第一次看见；
- 准备；
- 关键动作；
- 交互；
- 完成；
- 使用后；
- 收尾和痕迹；
- 前后对比；
- 复盘。

## 8. 主体对象轴

主体可为：人物、产品、食物、空间、设备、车辆、动物、植物、地理景观、文件/工具、活动或抽象概念的具象载体。

主体必须有：尺寸、数量、状态、材质、位置、视角、与环境的接触关系。

## 9. 行为叙事轴

用结构表达：

`角色 + 目的 + 动作 + 工具/对象 + 阻力/约束 + 可见结果`

例：不是“年轻人做咖啡”，而是“通勤前的租住青年在6㎡开放厨房用手冲壶完成第一杯咖啡，另一只手压住滤纸，旁边是已称重的咖啡豆和未收起的工作电脑”。

## 10. 情绪证据轴

情绪不能只写“温馨、治愈、焦虑、松弛”。必须转为可见证据：

- 温馨：关系距离、身体朝向、共享物、柔和但有来源的光；
- 紧张：时间提示、急促动作、收紧姿态、有限空间；
- 专业：流程秩序、工具摆放、角色分工、适度PPE；
- 松弛：动作节奏、留白、自然光、非摆拍姿态；
- 成就：完成物、使用痕迹、团队反馈，而不是举拳欢呼模板。

## 11. 视觉语言轴

可选择：纪实街拍、环境肖像、产品生活方式、过程特写、空间建立、俯拍步骤、低机位动作、长焦压缩、标准焦段观察、微距材质、自然窗口光、硬光工业、阴天城市、夜间实用灯等。

视觉语言必须服务内容目标，不为“高级感”而电影化。

## 12. 交付变体轴

- 比例变体：1:1、3:4、4:5、9:16、16:9等；
- 叙事变体：封面、场景、过程、细节、结果、对比；
- 人群变体：不同年龄、职业、家庭结构、使用目的；
- 地域变体：同主题在不同真实地域的重建；
- 时间变体：早晚、季节、工作日/周末；
- 摄影变体：同世界不同机位；
- 商业变体：UGC感、品牌感、编辑感，但事实不变。

## 13. 交叉公式

优先使用 4—6 维交叉：

```text
行业 + 人群 + 内容目标 + 场景时刻 + 视觉语言
平台 + 受众 + 主体 + 行为 + 文字安全区
地域 + 时间 + 人群 + 动作 + 机位
产品 + 使用问题 + 过程证据 + 结果状态 + 比例
同一世界 + 系列角色 + 镜头变化 + 连续性锁
```

## 14. 删除规则

删除：

- 没有明确受众；
- 只换颜色、背景、脸或滤镜；
- 没有可见动作或证据；
- 平台与构图不匹配；
- 需要伪造数据、评价、证言或官方身份；
- 依赖模型难以稳定生成的大量细小文字；
- 场景无法在物理世界发生；
- 与已有候选两两差异不足。
