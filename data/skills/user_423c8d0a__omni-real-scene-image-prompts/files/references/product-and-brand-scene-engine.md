# 产品、电商与品牌场景引擎

## 1. 产品身份卡

锁定：

- 类别、版本、尺寸、比例；
- 轮廓、关键曲线、接口、按钮、开口、支撑和接缝；
- 材料、颜色、纹理、透明度和反射；
- 包装、配件和数量；
- 品牌授权、Logo和文字；
- 使用方向、握持和安装关系。

## 2. 六类产品图

1. 纯产品/主视觉；
2. 真实使用场景；
3. 尺度与握持；
4. 材质与结构细节；
5. 开箱、安装或操作过程；
6. 收纳、携带、维护或使用后状态。

## 3. 产品真实感

- 反射与材料一致；
- 重量通过支撑、握持和形变体现；
- 接口、按钮、盖子和配件位置固定；
- 产品不随机变厚、变薄、变色或增减零件；
- 包装能容纳产品；
- 使用动作符合人体与说明书逻辑。

## 4. 生活方式场景

从真实问题出发，而不是装饰：

`用户任务 → 使用前状态 → 产品介入 → 操作 → 可见反馈 → 收纳/结束`

产品必须有用，不是被放在咖啡杯和绿植旁充当摆件。

## 5. 电商主图

- 主体轮廓清楚；
- 背景服务产品；
- 文字、卖点和角标后期叠加；
- 不生成虚假认证、销量、排名、折扣、倒计时和平台徽章；
- 不复制竞品包装、摄影或商标。

## 6. 同产品系列

身份锁至少包含：

- 轮廓比例；
- 关键零件坐标；
- 材质与颜色；
- Logo位置；
- 包装结构；
- 配件数量；
- 尺度参照。

不同图只改变场景、动作、机位、光线和内容角色，不改变产品本体。

## 7. 食品与饮料

- 食物体积、切面、温度、油脂、水汽和容器真实；
- 成分与制作过程一致；
- 不用不可食用装饰制造虚假份量；
- 包装文字准确或不可辨；
- 不夸大健康、减脂、治疗或营养效果。
