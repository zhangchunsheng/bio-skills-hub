# 全域视觉生产合规门禁

## 1. 数据与资料

- 只使用用户有权使用或许可范围内的照片、视频、地图、卫星、街景、产品、人物和品牌资料；
- 不抓取封闭监控、私人场所、敏感设施或受限地理数据；
- 不混用未转换坐标系；
- 不输出不应公开的精确敏感地理或设施细节；
- 资料只支持其实际粒度，不从低分辨率数据推断高粒度事实。

## 2. 个人信息

默认删除或模糊：真实人脸、车牌、电话、住址、门牌、订单、屏幕、聊天、定位、行程、病历、学生信息和其他可识别数据。

真实人物只有在明确授权时可做 A 级身份复现。未成年人保持必要、普通、非识别，不用于商业背书或敏感场景。

## 3. 误导性内容

不得生成或提示：

- 伪新闻、伪监控、伪事故证据；
- 伪病历、处方、检测报告；
- 伪合同、判决、证书、印章、公文；
- 伪银行、支付、收益、订单、销量和评价；
- 伪聊天记录、社交平台互动和媒体采访；
- 伪官方、平台、学校、医院、政府或机构背书。

## 4. 高风险行业

- 医疗：只做一般科普和流程示意，不诊断、不承诺疗效；
- 金融：只做教育、风险和计算示意，不承诺收益；
- 法律：只做一般流程和资料整理，不保证结果；
- 教育：只做学习、练习和规划，不保过/保录取；
- 公共事件：不冒充实时现场，不生成可识别受害者；
- 政治与公共人物：不生成误导性现实事件或伪背书；
- 危险作业与敏感设施：不提供可用于破坏、规避安防或违法操作的细节。

## 5. 品牌与版权

- 真实Logo、包装、角色、作品和设计仅在用户有权使用时保留；
- 参考图迁移抽象视觉DNA，不复制可识别构图、人物、地点和品牌资产；
- 未授权时使用原创、通用或去品牌化设计；
- 不生成假冒商品或仿冒官方视觉。

## 6. AI标识

公开传播时保留适用的显式/隐式AI生成标识。不能通过去水印、伪Exif、伪拍摄信息或新闻版式把生成图伪装成现实证据。

## 7. 尊严与公平

避免贫困猎奇、疾病猎奇、身体羞辱、职业贬低、地域歧视、年龄刻板、性别模板和民族刻板。真实感不等于把某类人群塑造成单一负面形象。
