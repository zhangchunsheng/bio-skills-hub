# 视觉机会评分与筛选

## 1. 八维评分

每个候选按 1—5 分，总分 40。

| 维度 | 5分标准 | 1分信号 |
|---|---|---|
| 受众命中 | 一眼知道为谁而做 | 面向“所有人” |
| 内容效用 | 画面能承担明确传播任务 | 只是好看 |
| 场景真实性 | 时间、空间、人物和动作可发生 | 靠模板和形容词 |
| 视觉清晰 | 缩略图与成片均能读懂 | 主体混乱 |
| 差异化 | 与同批提示词明显不同 | 换皮重复 |
| 生成可行 | 模型能稳定表达核心关系 | 依赖大量细字/复杂穿插 |
| 资产复用 | 可扩为系列、比例或行业模板 | 一次性噱头 |
| 合规安全 | 不伪造、不过度承诺、无侵权 | 高风险误导 |

## 2. 分层

| 等级 | 分数 | 裁决 |
|---|---:|---|
| S | 36—40 | 优先输出或进入首批系列 |
| A | 31—35 | 输出，但需压缩次要元素 |
| B | 25—30 | 作为补充图或备选 |
| C | 24以下 | 删除或重建 |

硬性降级：

- 场景真实性 ≤2：最高 B；
- 生成可行 ≤2：最高 B；
- 合规安全 ≤2：删除；
- 没有内容目标或受众：最高 C；
- 需要伪造事实：删除。

## 3. 系列评分

系列除单图评分外，再评：

- 叙事完整性；
- 镜头角色差异；
- 主体连续性；
- 信息递进；
- 首图停留力；
- 末图承接空间。

## 4. 批量分布门禁

100条以上批次至少检查：

- 行业/主题覆盖；
- 人群年龄、职业、关系覆盖；
- 室内/室外、日/夜、城市/乡村覆盖；
- 机位、焦段、构图和光线分布；
- 平台与比例分布；
- 文字策略分布；
- 完全重复和近似重复；
- 同一模板占比。

任何单一机位、人物模板、色调或空间模板不应支配超过合理比例。数量越大，越应使用审计脚本而不是肉眼判断。
