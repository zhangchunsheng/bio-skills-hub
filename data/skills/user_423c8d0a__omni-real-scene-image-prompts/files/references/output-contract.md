# Prompt-Only 输出契约 V3

## 1. 唯一允许的正式输出

单图：

```text
【主提示词】
<提示词正文>

【负面提示词】
<负面提示词正文>
```

按需追加：

```text
【版式叠字提示词】
<准确标题、层级、位置、安全区、字体与不变项>

【文字定向编辑提示词】
<只修指定文字区域>

【一致性锁定提示词】
<同人物/产品/空间/系列/多比例的身份锁>
```

多图：

```text
【图01｜封面】
【主提示词】
...
【负面提示词】
...

【图02｜过程】
...
```

每张必须独立完整，不得写“同上”“沿用前图”。

## 2. 禁止输出

- 分析、推理、世界卡、证据清单、评分、质检结论；
- 文件路径、工具调用、模型执行说明；
- 图片、下载说明或“已生成”；
- 对用户的连续追问；
- 提示词之后的总结、建议或结语。

## 3. 主提示词必备语义

1. `Use case / 用途`；
2. `Content objective / 内容目标`；
3. `Reality mode / 真实性模式`；
4. `Asset / 平台、比例、图位、系列角色`；
5. `Primary request / 核心画面任务`；
6. `World context / 地域、时代、时间、天气、环境`；
7. `Spatial logic / 空间几何、动线、尺度`；
8. `Subject identity / 主体身份与外观`；
9. `Objects & process / 物体、设备、道具、动作与流程`；
10. `People & relations / 人群、关系、目的和交通`（无人场景可明确无人物）；
11. `Camera & composition / 机位、焦段、构图、留白、安全区`；
12. `Lighting & materials / 光源、曝光、反射、材料与状态`；
13. `Text & brand / 精确文字、品牌与禁区`；
14. `Continuity / 身份锁与允许变化`；
15. `Truth boundary / 事实边界`；
16. `Public-use note / 公开传播说明`（宣传、社媒、新闻感、案例感任务适用）。

## 4. 事实边界固定句

A 级：

`Truth boundary: 依据用户有权使用的近期资料复现同一授权主体或地点；资料未覆盖的细节保持不可辨或明确原创。`

B 级：

`Truth boundary: 基于真实区域、行业与行为证据构建的同类原创场景，不对应具体已存在地点、人物或事件。`

C 级：

`Truth boundary: 符合目标地域、行业与人群逻辑的原创真实感场景，不复刻具体地址、人物或事件。`

D 级：

`Truth boundary: 这是基于已知规律构建的拟真虚构或重建场景，不是现实影像证据。`

## 5. 公开传播固定句

当画面面向营销、自媒体、宣传、案例展示、活动报道或公众传播时加入：

`Public-use note: 成图公开传播时保留适用的“AI生成/概念图/示意图”显式标识及平台要求的隐式标识，不作为真实新闻、用户证言、经营数据、疗效、收益、事故证据或官方材料。`

## 6. 文字触发规则

出现以下任一情况，追加 `【版式叠字提示词】`：

- 小红书、短视频、公众号、电商或课程封面需要标题；
- 标题超过 6 个汉字；
- 需要副标题、角标、步骤序号或多层信息；
- 背景图必须先保持干净无乱码。

出现以下任一情况，追加 `【文字定向编辑提示词】`：

- 画面内现有文字需修复；
- 门头、包装、服装、设备或界面上的文字必须逐字准确；
- 用户要求只改文字不改画面。

## 7. 连续性触发规则

出现以下任一情况，追加 `【一致性锁定提示词】`：

- 同人物、同产品、同空间、同车辆或同活动的多图；
- 参考图编辑、扩图、换背景、换人群、换服装；
- 3:4、9:16、1:1 等多比例版本；
- 轮播系列、分镜、前后对比或同一时间线。

## 8. 禁止伪提示词式事实

即使写在主提示词里也不允许：

- “这是某真实用户”“现场实拍”“媒体报道”；
- 无证据的真实地址、伤亡、疾病、收入、销量、客流、评分和排名；
- “治愈、包过、稳赚、零风险、官方认证”；
- 伪造聊天记录、付款记录、病例、证书、许可证、新闻台标或平台互动数据；
- 用卫星、地图或监控推断其无法支持的人物、门头、室内和事件细节。
