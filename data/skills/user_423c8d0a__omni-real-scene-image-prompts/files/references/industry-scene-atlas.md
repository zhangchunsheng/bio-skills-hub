# 81行业视觉获客最强提问案例库 V1.0

> 基于71行业SOP + 42大私域计划 + V10裂变引擎，为每个行业设计最强的视觉场景提问模板。
> 用户只需复制提问模板，替换括号内容，即可获得可直接生图的提示词。

## 使用说明

1. 找到你的行业分类
2. 选择最适合你当前内容目标的场景类型
3. 复制提问模板，将 `【】` 中的内容替换为你的实际情况
4. 粘贴到对话中，skill 将输出完整提示词
