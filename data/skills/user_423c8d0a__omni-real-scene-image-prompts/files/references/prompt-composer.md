# 全域最少充分提示词编排器 V3

## 1. 原则

内部世界卡可以很详细，最终提示词只保留当前图位的决定性信息。每个句子必须改变模型的空间、主体、动作、摄影、文字或事实行为。

## 2. 标准骨架

```text
Use case: <真实场景/小红书封面/产品使用/纪实/教程等>。
Content objective: <停留/解释/证明/种草/转化/系列角色>。
Reality mode: <A/B/C/D>。
Asset: <平台、比例、图位、系列编号、主体占比、文字安全区>。
Primary request: <一句话说明谁/什么，在何处何时，做什么，画面要证明什么>。
World context: <国家/地域、时代、季节、天气、城市/自然/行业语境>。
Spatial logic: <空间尺寸、功能区、入口/动线、前中后景、人与设备关系>。
Subject identity: <人物/产品/空间/设备的稳定身份与状态>。
Objects & process: <关键道具、设备、材料、主动作、次动作、前后因果>。
People & relations: <角色、目的、关系、数量、交通与方向；无人场景明确无人物>。
Camera & composition: <真实机位、高度、距离、角度、焦段、景深、构图、留白>。
Lighting & materials: <光源、曝光、反射、阴影、材料粗糙度、使用痕迹>。
Text & brand: <P0文字、品牌权限、背景文字策略、禁止项>。
Continuity locks: <锁定项、允许变化、需要重算项>。
Truth boundary: <固定句>。
Public-use note: <适用时>。
```

## 3. 信息预算

单张建议：

- 8—14个硬锚点；
- 1个主动作；
- 1—2个次动作；
- 3—7个行业/生活证据；
- 4—8个地域/空间证据；
- 5—12个任务特定负面约束。

## 4. 封面编排

优先顺序：主体 → 动作/结果 → 标题安全区 → 环境证据 → 光线。删除不影响缩略图理解的小物。

## 5. 过程图编排

优先顺序：手/工具/对象接触 → 当前步骤 → 前后状态 → 机位 → 连续性锁。避免全景导致动作太小。

## 6. 产品图编排

优先顺序：产品几何锁 → 使用动作 → 尺度 → 材质 → 光线 → 品牌文字。任何场景装饰不得改变产品身份。

## 7. 人物图编排

优先顺序：身份 → 目的 → 动作 → 空间关系 → 服装 → 表情/视线 → 机位。表情是动作结果，不是默认“自然微笑”。

## 8. 空间图编排

优先顺序：结构/尺寸 → 动线 → 功能 → 固定设备 → 材料 → 使用状态 → 人物尺度 → 光线。

## 9. 多比例

每个比例重新写 `Asset`、`Camera & composition`、`text_safe_zone` 和 `subject_scale`。其他身份字段保持一致。

## 10. 负面提示词

只写高风险错误：

- 事实/时代/地域串场；
- 物理、接触、动线和尺度错误；
- 行业流程空心化；
- 人物克隆、摆拍、手部粘连；
- 产品/空间身份漂移；
- 光学、反射和透视冲突；
- 中文乱码和多余文字；
- 模板化美学；
- 伪数据、伪证言、伪UI、伪新闻；
- 未授权人物、品牌和隐私。

## 11. 压缩顺序

先删：8K、杰作、史诗、高级感、氛围感等空词；重复真实感形容词；看不见的小物；无关地标；装饰清单；重复负面词。

不可删：内容目标、真实性模式、世界语境、空间、主体身份、动作因果、机位、文字策略、连续性和事实边界。
