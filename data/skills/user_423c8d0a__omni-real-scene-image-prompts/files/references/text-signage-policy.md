# 中文门头、品牌与文字策略

## 1. 文字等级

### P0：必须逐字正确

- 店名；
- 品类词；
- Logo 字；
- 用户指定主广告语。

### P1：按需出现

- 服务项目；
- 营业时间；
- 价格；
- 活动文字。

只有用户明确提供或要求原创时加入。

### P2：不承担信息任务

- 邻店；
- 包装小字；
- 远处招牌；
- 小价签。

应因距离、角度、遮挡和景深自然不可辨，不生成清晰乱码。

## 2. 直接生成模式

只保留 1—2 组 P0 文字，并写明：

- 完整原文；
- 字符顺序；
- 行数；
- 位置；
- 字体形态；
- 材质和颜色；
- 是否允许英文。

示例：

```text
Text verbatim: "沂早早点"，四个汉字，单行，从左到右依次为“沂、早、早、点”，暖白色立体字安装在深蓝色平招中央；不得增加英文、电话、二维码或促销语。
```

## 3. 两阶段模式

满足以下任一条件时默认两阶段：

- 超过 6 个汉字；
- 罕见字、数字、符号、双语；
- 两行以上排版；
- 商业交付要求逐字准确；
- 已出现错字需要修复。

第一阶段：生成无乱码、保留干净文字区域的基础画面。

第二阶段输出：

```text
【文字定向编辑提示词】
只修改门头或指定文字区域。把当前文字替换为完全准确的中文：“<用户原文>”。字符依次为：<逐字列出>。保持原有字重、颜色、立体形式、尺寸、间距、行数、透视、材质、阴影和安装位置。删除多余字符，不新增英文、电话、地址、二维码、价格或广告语。保持建筑、门头比例、入口、橱窗、邻店、人物、车辆、设备、机位、焦段、光线、天气、主色和画幅完全不变。
```

## 4. 真实品牌

- 仅在用户有权使用时保留真实品牌、Logo 和品牌手册；
- 不复制竞品独特门头并伪装成原创；
- 授权不明时使用原创虚构品牌；
- 原创店名应短、可读、不过度模仿知名商标；
- 不虚构官方、医院、银行、政府或大型平台背书。

## 5. 高风险文字

未经用户提供和证据支持，不生成：

- 真实地址、电话、可扫描二维码；
- 许可证号、统一社会信用代码、医保/金融资质；
- “全城第一”“销量冠军”“3000 老客”；
- 医疗疗效、投资收益、官方认证；
- 真实订单号、顾客姓名和会员信息。

## 6. 文字返修验收

- 只改指定区域；
- P0 逐字、字序、行数正确；
- 正确文字不被重写；
- 透视、材质、阴影和安装关系真实；
- 其他人物、建筑、设备、机位、光线和画幅不漂移。

## 7. V3 自媒体标题与版式

标题、步骤、卖点和课程信息默认采用后期叠字：

```text
【版式叠字提示词】
只在<安全区>叠加准确文字：“<主标题>”；副标题：“<副标题>”。说明层级、行数、对齐、字体气质、字号关系、颜色和背景对比。保持主体、人物、产品、空间、光线、材质、机位和画幅完全不变。不得添加平台UI、点赞评论、二维码、认证、销量、倒计时或额外文案。
```

推荐信息预算：

- 主标题：通常≤12个汉字；
- 副标题：通常≤20个汉字；
- 角标：1组；
- 步骤图：每图1个步骤号和1条短说明；
- 长段文字移交设计/排版工具，不交给图像模型自由生成。

## 8. 产品、服装、设备和屏幕文字

- 产品Logo与型号属于P0，仅在授权和必要时逐字生成；
- 包装成分、说明书、屏幕数据、文件正文属于高错误区域，默认不可读或后期合成；
- 不生成真实订单、聊天、病历、财务、身份证件、车票、证书和平台通知；
- 不模拟媒体台标、政府公文、医院/学校/银行/平台官方界面。
