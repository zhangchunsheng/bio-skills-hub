# 物理因果、可供性与接触关系

## 1. 可供性

任何物体都必须支持其动作：椅子能坐、门能开、工具能握、车辆能转弯、货物能搬运、楼梯能通行、设备有电源/管线/排风/排水或通信连接。

## 2. 空间门禁

- 人物、设备、家具、车辆和货物符合真实尺度；
- 通道、门宽、台阶、坡道、转身和作业半径成立；
- 站立、坐下、弯腰、抬举和操作有足够空间；
- 车辆有进入、停靠、装卸和退出路径；
- 镜头没有穿过墙体、玻璃、车辆或封闭区域；
- 室内面积不因超广角被夸大数倍。

## 3. 接触关系

重点检查：

- 手指与杯柄、工具、手机、把手、食物和织物的接触；
- 脚与地面、台阶、踏板的承重；
- 人体与椅子、床、墙、车辆的遮挡；
- 包装与货架、设备与地面、管线与墙体的连接；
- 雨、雪、泥、水和风对衣物、头发、地面与植物的影响。

## 4. 流程因果

动作必须有前置和结果：

- 烹饪：原料、工具、热源、容器、半成品和清洁；
- 制造：物料输入、工位、设备、检测、周转和成品；
- 医疗科普：角色、器材、卫生边界和非诊疗表述；
- 办公：任务、屏幕、文件、沟通对象和结果；
- 户外：装备、地形、天气、体力状态和安全边界；
- 产品使用：打开、握持、连接、操作、反馈和收纳。

## 5. 光学因果

- 光源方向决定阴影和高光；
- 玻璃同时具有反射、透视、污迹和室内外曝光差；
- 金属、木材、织物、塑料、皮肤、石材和液体具有不同反射模型；
- 远处对比度、饱和度和细节自然下降；
- 运动模糊只出现在真正运动的对象和方向；
- 夜景亮度由路灯、招牌、车灯、窗光和环境反射共同决定。

## 6. 真实瑕疵

允许：轻微磨损、折痕、灰尘、划痕、补漆、指纹、使用后的凌乱和不完全对称。

禁止用以下元素机械证明真实：垃圾遍地、破墙、浓重噪点、镜面湿地、无来源烟雾、夸张污渍、过度贫困或安全隐患。
