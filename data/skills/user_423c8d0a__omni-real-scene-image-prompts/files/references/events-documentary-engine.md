# 活动、体育与纪实场景引擎

## 1. 事件时间线

内部建立：准备 → 入场 → 开始 → 核心动作 → 互动 → 收尾。每张图选择一个时间节点。

## 2. 角色

组织者、工作人员、参与者、观众、媒体、安保、志愿者、供应商和场地人员的服装、位置、动作和权限不同。

## 3. 场地与流线

入口、签到、座位、舞台/赛场、后台、设备、消防通道、补给、卫生和离场关系合理。不得为了热闹堵塞所有通道。

## 4. 体育

- 动作符合项目技术和身体力学；
- 场地标线、器材、服装和裁判位置合理；
- 运动模糊方向正确；
- 不复制知名运动员或赛事品牌；
- 不伪造比赛结果、奖牌或新闻照片。

## 5. 会议与展览

屏幕和展板文字以大结构为主，小字不可辨。观众有听、看、记录、交流和移动等差异动作，不排成同一姿势。

## 6. 市集与社区活动

摊位、货品、支付、垃圾、供电、遮阳、天气、家庭和配送关系真实。人群密度由场地和时段决定。

## 7. 纪实边界

原创活动图必须声明为概念/示意，不得生成真实媒体Logo、时间地点角标、新闻字幕、事故现场证据、真实公众人物或可识别参与者。
