# 工业、农业、物流、能源与基础设施场景

## 1. 工业流程

先画流程：

`原料/零件 → 工位/设备 → 操作 → 检测 → 周转 → 包装/成品 → 仓储/发运`

画面选择其中一个关键节点，不能在一个工位同时塞入完整工厂流程。

## 2. 工业证据

- 设备名称和功能；
- 物料状态与方向；
- 夹具、托盘、周转箱、管线和控制；
- 操作者角色和PPE；
- 人机距离、维护空间和安全隔离；
- 灯光、油污、粉尘、蒸汽或噪音来源；
- 成品、半成品和废料区分。

禁止用机器人手臂、蓝色灯带和全息屏自动代表“智能制造”。

## 3. 仓储物流

- 货架、托盘、叉车、笼车、输送、分拣、扫描和装卸逻辑；
- 人车分流、通道宽度、库位和消防通道合理；
- 标签和订单信息不可识别；
- 货物尺寸、重量与搬运方式匹配。

## 4. 农业

根据作物或养殖对象重算：地区、季节、生长阶段、土壤/水体、灌溉、工具、机械、采收、分选、储存和运输。

禁止把所有农业做成金色麦田、夕阳和微笑农民。

## 5. 渔业与水产

考虑潮汐、船型、网具、码头、冰、水箱、分拣、冷链、防滑和天气。人物动作必须符合湿滑环境和重量。

## 6. 建筑与基础设施

道路、桥梁、轨道、水务、能源、通信和市政场景必须有真实尺度、施工/维护阶段、设备、警戒和交通组织。不输出敏感设施的精确结构、位置或安防细节。

## 7. 能源与电力

展示一般性设备和作业流程，不生成可用于破坏、绕过安全或定位敏感设施的细节。工作人员PPE、绝缘、距离和作业许可语境合理，但不声称正式合规。

## 8. 安全真实感

安全不是“所有人都穿全套装备”，而是装备与风险匹配。普通仓库、食品车间、化工、焊接、高处、冷库和农田的PPE不同。
