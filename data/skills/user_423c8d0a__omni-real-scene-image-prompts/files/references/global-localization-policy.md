# 全球地域与文化本地化策略

## 1. 原则

地域真实感来自微观基础设施、气候适应、建筑年代、日常行为和材料，不来自国旗、地标、民族服装和刻板符号堆叠。

## 2. 本地化变量

- 国家、州省、城市、区县、街区或聚落；
- 纬度、地形、气候、季节和日照；
- 城市密度、土地用途、建筑年代和物业；
- 道路侧别、交通工具、停车和步行系统；
- 公共设施、能源、通信、垃圾和排水；
- 当地行业、家庭结构、工作方式、消费习惯和时间节奏；
- 服装、食物、包装、设备和语言；
- 法规、隐私、品牌和文化敏感性。

## 3. 禁止捷径

- 日本=樱花+和服+霓虹；
- 法国=埃菲尔铁塔+咖啡馆；
- 美国=黄色校车+郊区草坪；
- 非洲=荒野+贫困；
- 中东=沙漠+长袍；
- 东南亚=热带市场+摩托车；
- 中国=红灯笼+高楼+拥挤。

这些元素只有在具体地点、季节、人物身份和任务中有因果支持时才能出现。

## 4. 文字与语言

用户未提供准确当地文字时：

- 远处文字保持不可辨；
- 重要文字使用原创短语并单独校对；
- 不拼凑看似当地语言的乱码；
- 不生成真实地址、电话或政府机构名称。

## 5. 全球迁移

把同一产品或主题迁移到另一国家时，重算：

- 插座、电压、包装、计量单位；
- 建筑、气候适应和室内设备；
- 人群、服装、交通和社交距离；
- 店铺/工作流程和支付方式；
- 摄影语境和公开传播边界。

不能把原场景直接贴到新背景。
