# 自媒体视觉内容引擎

## 1. 平台不是滤镜

平台适配包含：目标、比例、缩略图、阅读顺序、标题安全区、系列节奏、UI避让和真实感类型。

用户指定平台规则优先；平台规格可能变化，提示词必须显式写出最终比例和安全区，而不是只写平台名。

## 2. 七种图片角色

1. Hook：封面停留；
2. Context：环境和问题；
3. Process：步骤和动作；
4. Evidence：细节和可信度；
5. Result：完成状态；
6. Compare：对比与选择；
7. Bridge：结尾承接和文案留白。

## 3. 封面

封面必须：

- 1秒内识别主体；
- 主体与标题区不互相遮挡；
- 背景支持主题，不抢信息；
- 避免多个同等强度中心；
- 不依赖小字才能理解；
- 不模拟平台热榜、点赞、评论和搜索结果。

## 4. 图文轮播

每张只讲一个点。视觉递进可采用：

`封面远景 → 场景中景 → 动作近景 → 材质特写 → 结果中景 → 对比同机位 → 结尾留白`

系列色彩和主体身份连续，但机位、动作和信息量要变化。

## 5. UGC感与品牌感

UGC感：可落地手机/相机机位、自然遮挡、非完美构图、真实生活痕迹、普通光线。

品牌感：更精确的构图、光线、材料和品牌控制，但仍保留真实使用和空间因果。

不得把UGC感理解为低清、歪斜、脏乱；不得把品牌感理解为豪华、空旷、强HDR。

## 6. 个人IP

环境肖像优先于纯棚拍。画面应说明：人物是谁、在做什么、服务谁、使用什么工具、处于什么工作/生活空间。

不得通过伪造奖项、媒体采访、客户排队、聊天记录或收入截图建立权威。

## 7. 种草与产品内容

至少选择一种证据：

- 使用前问题；
- 使用动作；
- 产品与身体/空间的尺度关系；
- 细节材质；
- 使用后的可见状态；
- 收纳、携带或维护。

避免只把产品放在奶油色桌面、咖啡杯和绿植旁。

## 8. 教程与知识内容

背景图与文字层分开。图片负责场景、对象、动作和视觉秩序；文字层负责步骤、数字、标题和标注。

## 9. 对比图

对比应控制变量：

- 同机位；
- 同主体；
- 同时间或明确时间变化；
- 同曝光或说明光线差异；
- 改变项清晰；
- 不用夸张“前脏后亮”制造虚假效果。

## 10. 多平台复用

同一主题重构而非裁切：

- 竖图加强人物/主体纵向关系和上下留白；
- 方图强调中心关系和环境平衡；
- 横图建立左右叙事和环境；
- 缩略图需要更高主体占比；
- 详情页可以容纳更多过程与细节。
