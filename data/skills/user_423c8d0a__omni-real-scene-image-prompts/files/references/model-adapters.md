# 模型适配层

## 1. 默认：模型无关版

未指定模型时，输出完整自然语言主提示词、独立负面提示词、按需文字编辑和一致性锁定提示词。不要猜测模型参数、采样器、风格代码、API 字段或版本。

## 2. 自然语言型文生图

适合长句和结构化标签：

- 保留 `Location / Store / Business / People / Camera / Text / Truth boundary`；
- 负面提示词写成自然语言禁项；
- 核心锚点放在前半段；
- 不堆权重括号和逗号标签。

## 3. 关键词/权重型扩散模型

在用户明确指定支持权重语法时：

- 主体、店型、空间、机位和关键文字提高优先级；
- 地域微证据保持简洁；
- 负面提示词单独输出；
- 不使用模型文档未支持的权重格式；
- 不把“真实中国”简化为 `Chinese style`、灯笼或仿古。

## 4. 参考图型模型

明确每张图的角色：

- 环境 DNA；
- 店铺身份；
- 室内拓扑；
- 文字/Logo；
- 编辑目标。

提示词写明允许迁移与禁止复制的内容。模型支持参考强度时，只在用户指定参数体系后给出建议，不自行发明数值。

## 5. 局部编辑/遮罩模型

输出 `Change only / Keep unchanged / Do not add` 三段；准确中文采用两阶段文字编辑。遮罩区域以用户工具为准，不在提示词里声称已创建遮罩。

## 6. 同店一致性模型

- 结构化重复身份锁；
- 先门头和室内两个锚点；
- 每张图明确当前图位；
- 只允许人物、可移动物和指定时段变化；
- 不依赖“same store”一句话。

## 7. 不支持负面提示词的模型

把最关键的 3—5 个禁项改写为正向约束放入主提示词末尾，例如：

- “使用真实街面手持机位，不使用漂浮无人机”；
- “远处非关键文字自然不可辨，不生成清晰乱码”；
- “保持正常维护，不做破败或无尘样板间”；
- “人物各自执行合理动作，不看镜头摆拍”。

仍保留 `【负面提示词】` 作为交付字段，但注明为可选输入，不输出解释性文字。

## 8. 中文文字能力弱的模型

- 基础图先留干净、透视正确的文字区域；
- 使用独立 `【文字定向编辑提示词】`；
- 减少同图 P0 文字组；
- 远处非关键文字模糊不可辨；
- 不删除用户要求的店名来规避文字问题。

## 9. 参数边界

除非用户明确给出模型、版本和参数格式，否则不要输出：

- steps、CFG、sampler、seed；
- 风格 ID、LoRA、ControlNet 权重；
- 参考图强度、denoise 或遮罩羽化数值；
- API JSON。

提示词层只保证语义和结构，不假装了解未指定模型的当前接口。

## 10. V3 通用字段映射

自然语言模型优先保留：

- `Use case / Content objective / Reality mode`；
- `World context / Spatial logic`；
- `Subject identity / Objects & process / People & relations`；
- `Camera & composition / Lighting & materials`；
- `Text & brand / Continuity locks / Truth boundary`。

旧版 `Store / Business` 字段仅用于零售、餐饮和本地生活子模块，不得强行套在人物、产品、自然、工业或知识场景上。

## 11. 多图与参考图模型

- 每张参考图只承担一种主要角色：主体身份、产品几何、空间拓扑、光线、构图或编辑目标；
- 同人物/产品/空间的多图必须重复结构化身份锁；
- 多比例版本要求“重构画面”，不是“裁切原图”；
- 图像模型无法稳定生成长中文时，背景图与文字层分开；
- 模型不支持负面提示词时，把最关键禁项转为正向约束。

## 12. 视频首帧与封面

即使目标平台是视频，当前 skill 仍只生成静态视觉提示词。封面/首帧应说明主体、动作、留白和UI避让，不伪造播放按钮、平台徽章、点赞数或实时字幕。
