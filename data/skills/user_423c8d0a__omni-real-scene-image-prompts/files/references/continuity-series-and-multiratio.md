# 连续性、系列与多比例重构

## 1. 四类身份锁

### 人物锁

脸部结构、年龄、肤色、发型、体型、身高比例、标志性服装/配饰、姿态习惯。

### 产品锁

轮廓、尺寸比例、关键零件、颜色、材质、Logo、包装、配件。

### 空间锁

平面关系、门窗、柱墙、层高、固定家具、设备、材料、入口、邻接关系。

### 事件锁

时间线、参与角色、服装、场地、天气、物体状态和已发生动作。

## 2. 系列镜头角色

同一系列至少改变两项：机位、焦段、主体占比、动作、景深、前景、信息角色。不得通过改变人物脸、产品版本或空间结构制造差异。

## 3. 多比例重构

### 9:16

- 强化纵向层次；
- 保护人物头顶和脚下动作；
- 上下UI安全区；
- 标题与主体分区；
- 必要时扩展环境，不复制元素。

### 3:4 / 4:5

- 适合人物、产品和生活方式；
- 主体与环境平衡；
- 可保留一侧标题区；
- 避免头重脚轻。

### 1:1

- 中心关系清楚；
- 前中后景紧凑；
- 减少无效上下空间；
- 不把竖图粗暴截掉环境因果。

### 16:9 / 横幅

- 左右叙事或环境建立；
- 文字区与主体分开；
- 控制边缘畸变；
- 不用无意义空墙填宽。

## 4. 一致性提示词

必须写：

- `Keep unchanged`：所有身份锚点；
- `Allow change`：当前图允许改变的内容；
- `Recalculate`：阴影、反射、遮挡、动作和构图；
- `Forbidden drift`：不得变化的关键结构。

## 5. 前后对比

锁定：机位、焦段、空间、主体、曝光基准和画幅。明确改变项和时间跨度。若光线或季节不同，必须说明不是纯效果对比。

## 6. 批量连续性

每条提示词重复关键身份签名，不能依赖模型记住上一条。批量文件中的身份签名使用统一字段和顺序，便于自动校验。
