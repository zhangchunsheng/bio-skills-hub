# 官方基线与核验记录

核验日期：2026-07-14。生产使用前应再次确认最新官方文本、标准状态、平台条款和数据许可。

## 1. 人工智能生成合成内容标识

- 《人工智能生成合成内容标识办法》：中国网信网，2025-03-14；自 2025-09-01 起施行，覆盖文本、图片、音频、视频、虚拟场景等生成合成内容，并区分显式标识与隐式标识。
- 官方链接：https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm
- 2025-11-25 官方通报显示，监管已针对未落实显式/隐式标识等问题开展查处。
- 官方链接：https://www.cac.gov.cn/2025-11/25/c_1765795550841819.htm

生产含义：公开传播或平台发布时，不要求移除或规避适用标识；提示词可要求“AI生成/概念效果图”显式说明，并保留平台要求的隐式标识。

## 2. 个人信息保护

- 《中华人民共和国个人信息保护法》：中国网信网转载中国人大网文本，2021-08-20。
- 官方链接：https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm

生产含义：真实现场、摄像头、街景和照片资料执行目的明确、最小必要、授权和去标识化；不复刻可识别个人、车牌、电话、门牌和轨迹。

## 3. 地图与地理信息

- 《地图管理条例》：国务院令第 664 号，自 2016-01-01 起施行。
- 官方链接：https://www.mee.gov.cn/zcwj/gwywj/202001/t20200114_759322.shtml

生产含义：公开地图、互联网地图服务、国家版图表达、审图号和地理信息安全需按适用规则处理；不得伪造审图号或把概念图冒充官方地图。

## 4. 零售业态与行业分类

- GB/T 18106-2021《零售业态分类》：全国标准信息公共服务平台显示状态为“现行”。
- 官方链接：https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=6F1B1AF0FFE8A15119525CCC0E5E3F7F
- GB/T 4754-2017《国民经济行业分类》：全国标准信息公共服务平台显示状态为“现行”，含第 1 号修改单。
- 官方链接：https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=A703F0E23DD165A5A1318679F312D158

生产含义：行业路由优先参考现行业态与行业分类，再结合真实线下/即时零售/服务流程细分，不依赖固定的少量自定义大类。

## 5. 遥感尺度示例

- 国家航天局：高分二号全色空间分辨率 0.8 米、多光谱 3.2 米，主要支持土地利用、城市规划、交通路网等遥感应用。
- 官方链接：https://www.cnsa.gov.cn/n6758823/n6758838/c6770431/content.html
- ESA：Sentinel-2 提供 10 米级空间分辨率，用于土地、植被、水体和土地覆盖等观测。
- 官方链接：https://www.esa.int/Applications/Observing_the_Earth/Copernicus/Sentinel-2

生产含义：10 米级支持城市/土地覆盖；亚米级可观察更细的屋顶、道路和车辆占位，但俯视遥感仍不能独立证明可读门头、人物身份、室内布局或门店营业状态。
