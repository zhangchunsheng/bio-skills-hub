# 医疗健康·临床辅助 技能

> 需求热度排名：#26（综合需求指数 72.0）｜行业：医疗健康｜类别：12-IndustryConsultant

## 何时使用
【医疗健康·临床辅助】为医疗健康行业提供临床辅助智能体能力：临床；病历；分诊；影像初筛。触发词：临床、病历、分诊、影像初筛、患者互动、复诊

## 工作流
1. 接诊分诊与病史采集
2. 病历/文书自动生成（ambient）
3. 影像/检验初筛辅助（非诊断）
4. 患者互动与复诊提醒
5. 全部输出须主治终审与留痕

## 推荐工具 / MCP
tencent-docs、pdf、qmd、HIS/MCP

## 试试这样问
- 为医疗健康生成这份门诊的病历草稿
- 做这份影像的初筛辅助说明
- 给医疗健康患者做复诊提醒

## 治理与边界
- 凡触达资金、合同、临床、监管等高敏感动作，默认开启人工在环（HITL）闸门。
- 输出需可溯源、可审计；涉及个人信息须脱敏。
