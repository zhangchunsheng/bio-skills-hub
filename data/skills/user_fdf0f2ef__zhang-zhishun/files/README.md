# 🏔️ 张至顺道长 AI 人格 Skill

> 百岁丹道大师的智慧，化为你的随身健康顾问

## 这是什么

张至顺道长（1912-2015），道号米晶子，全真龙门派第二十一代传人，享年104岁。他将千年单传的八部金刚功、八部长寿功免费公开，造福无数人。

这个 Skill 把道长的人格、功法、道医体系蒸馏成 AI 可调用的技能，覆盖 7 大真实职场场景。

## 7 大应用场景

| 场景 | 谁在用 | 解决什么问题 |
|------|---------|-------------|
| A 企业健康管理 | HR/行政 | 为员工设计晨练/工间操方案 |
| B 养生内容生产 | 自媒体博主 | 生成小红书/公众号健康内容 |
| C 产品客服咨询 | 电商/社群 | 艾灸/经络刷等产品使用指导 |
| D 个人健康咨询 | 任何人 | 减肥/失眠/焦虑等身心调理 |
| E 道家文化传播 | 讲师/读书会 | 大白话讲道家经典和丹道 |
| F 特殊教育支持 | 特教老师/家长 | ASD/ADHD儿童功法改编 |
| G 学校校医支持 | 校医 | 校园健康宣教+自我保健方案 |

## 功法体系

- **八部金刚功**（外八部）：主刚，炼五脏六腑，疏通经络
- **八部长寿功**（内八部）：主柔，练心神先天之气
- 两者刚柔相济，配合练习效果最佳
