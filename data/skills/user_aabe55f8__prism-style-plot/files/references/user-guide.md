## 0. 这是什么 / 何时用它

当你需要画**科研论文配图**（尤其是生物医学 / 生命科学领域）时，本技能最合适：

- 柱状图、箱线图、小提琴图（带个体散点 + 显著性星号）
- 分组柱状图、意大利面条图（双因素 / 重复测量）
- XY 散点线图、剂量-响应拟合曲线
- Kaplan-Meier 生存曲线
- 计数对比柱状图、占比饼图 / 环形图

**不适合**用本技能的场景：非科研的商业报表、交互式图表（Plotly/Bokeh）、纯探索性数据探查、3D 立体图、以及任何伪造 / 篡改实验数据的行为。

## 2. 三步出图（最快上手）

只要做到下面三件事，剩下的交给技能：

1. **说清数据是什么**（例如「Control、低剂量、高剂量三组的细胞活力」）
2. **说清想要什么图**（例如「带散点的柱状图，标显著性」）
3. **把数据给过来**（上传文件 / 粘贴文本 / 口头说数值均可）

技能会自动：
- 判断数据属于哪种 Prism 表；
- 选择对应的统计图型和统计方法；
- 按期刊规范做 L 形坐标轴、色盲友好配色、叠加散点、标星号；
- 交付 PNG + PDF + 图注。

> 不确定怎么描述？直接把数据发过来，技能会先识别并告诉你「识别为 XX 表，将绘制 XX 图」，你确认后再出图。

## 4. 你的数据属于哪种表（8 种表 + CSV 示例）

GraphPad 的灵魂是**「数据表格式」**——你的数据长什么样，决定了能画什么图、做什么统计。下面先看速查表定位，再看每种表的 CSV 写法。

### 4.0 速查：我的数据属于哪种表？

| 你的数据特征 | 表类型 |
|---|---|
| 只有 1 个分组变量（如处理组） | **Column** |
| 2 个分组变量交叉（时间 × 药物） | **Grouped** |
| 每个点有 X、Y 两个数值 | **XY** |
| 有生存时间 + 事件 / 删失 | **Survival** |
| 单元格是例数 / 人数（计数） | **Contingency** |
| 各部分加起来 = 整体 100% | **Parts of whole** |
| 每行一个样本、每列一个变量 | **Multiple variables** |
| 亚组嵌套在组内（教室在方法内） | **Nested** |

### 4.1 Column 表（单分组变量）—— 最常用

**适用**：比较 1 个因素的不同水平（Control vs 处理组、多剂量组）。
**默认图 / 统计**：带散点柱状图（Mean±SEM）/ 箱线图 / 小提琴图 + t 检验（2 组）或 One-way ANOVA + Tukey（≥3 组）。

**格式 A：宽格式**（每列一组）：

```csv
Control,Drug_Low,Drug_High
98,112,135
103,118,128
95,109,141
101,121,133
99,115,139
105,124,130
```

**格式 B：长格式**（推荐，更通用）：

```csv
group,value
Control,98
Control,103
Drug_Low,112
Drug_High,135
Drug_High,141
```

> 💡 **读表自动 y 轴标签（v2.6.0 起默认）**：上传 CSV/Excel 且未显式指定 y 轴标签时，技能自动用**数值列表头**作为 ylabel 默认（如列名 `Relative LCN2 expression` → 直接当轴标签）。表头会自动清洗（去换行、合并多余空格）。列名常非投稿级（缩写/缺单位），最终标签仍建议你确认/润色（如补 `(fold change)`）。宽格式（每列一组）无单一数值列名，会回退沿用图型模板默认。

### 4.2 Grouped 表（双分组变量）

**适用**：两个因素交叉设计（时间 × 药物、性别 × 处理）。
**默认图 / 统计**：分组柱状图 + 散点 / Two-way ANOVA（主效应 ×2 + 交互效应）。
**格式**：长格式，两个分组列 + 一列数值：

```csv
time,drug,value
0h,Control,100
0h,Drug,98
24h,Control,120
24h,Drug,135
48h,Control,118
48h,Drug,152
```

（也可用宽格式：行 = 第一个因素，列 = 第二个因素，单元格 = 数值）

### 4.3 XY 表（X-Y 坐标数据）

**适用**：剂量-响应、标准曲线、时间进程、相关分析。
**默认图 / 统计**：XY 散点 + 连线 / 非线性回归拟合、相关分析。
**格式**：

```csv
dose,y1,y2
0.1,5.2,5.0
1,12.8,13.1
10,45.3,44.9
100,88.7,89.2
```

### 4.4 Survival 表（生存数据）

**适用**：小鼠生存实验、患者随访。
**默认图 / 统计**：Kaplan-Meier 生存曲线（阶梯状、删失标记）+ log-rank 检验。
**格式**：每行一个受试者，生存时间 + 事件（1=发生，0=删失）+ 组别：

```csv
time,event,group
12,1,Conventional
18,1,Conventional
20,0,Conventional
25,1,Experimental
30,1,Experimental
32,0,Experimental
```

### 4.5 Contingency 表（计数数据）

**适用**：例数 / 人数统计（存活 vs 死亡、阳性 vs 阴性）。
**默认图 / 统计**：分组计数柱状图 / 卡方检验或 Fisher 精确检验。
**格式**：行列交叉的计数矩阵：

```csv
,treatment,control
graft_patent,28,15
graft_obstructed,6,19
```

### 4.6 Parts of whole 表（占比数据）

**适用**：各部分占整体的比例（细胞群体占比、资金构成）。
**默认图 / 统计**：饼图 / 环形图（通常不检验）。
**格式**：

```csv
part,count
Neutrophil,45
Macrophage,28
Lymphocyte,17
Eosinophil,10
```

### 4.7 Multiple variables 表（宽表）

**适用**：每行一个样本、每列一个变量的临床数据表；含协变量分析。
**默认图 / 统计**：按需选择（箱线图分面、散点矩阵、回归、森林图等）。
**格式**：

```csv
subject,age,sex,treatment,biomarker
S01,45,M,Control,102
S02,52,F,Drug,118
S03,38,M,Drug,126
```

### 4.8 Nested 表（嵌套层级数据）

**适用**：层级嵌套设计（方法 → 教室 → 学生）。**注意：嵌套 ≠ 重复测量**。
**默认图 / 统计**：嵌套柱状图 + 嵌套 t 检验 / ANOVA（按亚组均值聚合，防伪重复）。
**格式**：组、亚组、数值三列：

```csv
method,classroom,score
A,class1,78
A,class1,82
A,class2,74
B,class3,90
B,class3,86
B,class4,88
```

### 4.9 通用规则（所有表都适用）

| 规则 | 说明 |
|---|---|
| 第一行是表头 | 每列有名字（组名 / 变量名） |
| 每行一个观测 | 不要合并单元格、不要用标题行分隔 |
| 数值列用数字 | 文本列（如组名）与数值列分开 |
| 缺失值 | 留空或写 `NA`，技能会跳过该样本 |
| **上传原始数据** | **上传每个样本的原始重复测量值，不要只给「均值±SD」**——否则无法叠加个体散点（现代期刊硬性要求） |

## 5. 出图前可指定的可选参数

一句话即可全部指定，例如「画 wide 形态、箱线图、Mean±SD」。

| 参数 | 可选值 | 默认 |
|---|---|---|
| 图形态 | tall（3×5 cm，高瘦）/ square（5×5 cm，方形）/ wide（7×5 cm，宽扁） | **按数据类型自动推荐**（见下） |
| 图形类型 | 散点柱状图 / 箱线图 / 小提琴图 / 分组柱状图 / 生存曲线 / 饼图 / 拟合曲线… | 按表类型自动选 |
| 误差线 | Mean±SEM / Mean±SD | Mean±SEM（柱状图） |
| 显著性标注 | 星号 / 边缘显著 p 值 / 两者 | **混合（v2.0.17-21）：显著→星号；边缘显著 [0.05,0.1)→精确 p 值；p≥0.1→不标；图注含全部精确 p 值** |
| 配色 | 色盲友好 / 灰度 | 色盲友好（Okabe-Ito 8 色方案） |
| 字体 | Arial（缺失自动回退无衬线） | Arial |
| y 轴刻度步长 | 数字（如 0.5）| 自动漂亮步长（小图嫌密时传 `ytick_step=0.5`）|
| 输出格式 | PNG + PDF | PNG 300dpi + PDF 矢量 |

> 你不指定任何参数也没关系——技能会用期刊通用默认值直接出图，之后随时可改。
>
> **图形态默认按数据表类型自动推荐**：Column / Grouped 按总分组数分档（<5 组 → tall、5–8 组 → square、>8 组 → wide）；XY / Survival → square；Contingency → wide。你明确说 "tall / square / wide"（或"高瘦 / 方形 / 宽扁"）时，以你的指定为准。

## 6. 你会得到什么（输出物）

每次出图你会收到三样东西：

1. **PNG 预览版**（300 dpi，看效果用）
2. **PDF 矢量版**（投稿用，期刊普遍要求矢量图）
3. **Figure Legend 图注文字块**（含统计方法、n、每组比较的**具体 p 值**，可直接粘贴进论文）

统计结果同时以文字形式汇报（检验方法、统计量、自由度、精确 p 值、星号）。

> p 值格式：一律输出 scipy 计算出的**实际精确值**，绝不使用 `<` 阈值写法（如 `p<0.001` 禁用）。p≥0.001 写三位小数 `p=0.134`；p<0.001 用科学计数法 `p=2.04e-4`。

## 7. 完整示例：从一句话到交付

**用户说：**
> "我有个 Control、低剂量、高剂量三组的细胞活力数据（CSV 已上传），想画 Prism 那种带散点的柱状图，标显著性。"

**技能自动执行：**

1. **识别** → 一个分组变量、三组独立样本 → Column 表
2. **选图** → 默认带散点柱状图（Mean±SEM），并提示箱线图 / 小提琴图作为备选
3. **统计** → 3 组独立样本 → One-way ANOVA + Tukey 事后检验；生成 Control vs 低剂量、Control vs 高剂量、低 vs 高的星号
4. **美化** → L 形坐标轴 + 色盲友好配色 + 散点叠加 + 星号 bracket
5. **交付** → PNG + PDF + 图注

> 💡 此时 y 轴标签会**自动取自 CSV 的数值列名**（如 `cell_viability`），无需手填；列名不合适可在出图后一句改掉（如"y 轴改成 Cell viability (%)"）。

**你拿到的图注示例：**
> Data are mean ± SEM, n=6 per group. One-way ANOVA + Tukey: Control vs Drug-Low p=0.134 (ns); Control vs Drug-High p=1.0e-5 (****); Drug-High vs Drug-Low p=2.0e-4 (***).

- "去掉显著性星号" / "星号旁边加上具体 p 值"
- "字体换成 Helvetica"

## 9. 进阶玩法

- **多面板图（Figure panel）**：把多张子图拼成 A/B/C/D 面板，适合一组相关结果整体投稿。
- **指定目标期刊**：若你有目标期刊（如 Nature / Cell 子刊），告诉技能，它会按该期刊的星号阈值、字体、配色微调。
- **自带统计结果**：若你已有发表过的 p 值表，直接给技能，它会跳过计算、照用你的数值，并在图注注明统计来源。
- **重复测量 / 配对设计**：在描述里说明「配对设计，同一批样本处理前后」，技能自动改用配对 t 检验 / 重复测量 ANOVA。
- **非正态数据**：技能自动检测，两组小样本非正态 → Mann-Whitney U / Wilcoxon；多组 → Kruskal-Wallis + Dunn，你无需手动判断。

## 10. 常见问题 FAQ

**Q1：我只上传了「均值±SD」的汇总数据，能画散点图吗？**
不能叠加个体散点（没有原始数据）。技能会给出均值±误差的柱状图，并提醒你补原始数据。**强烈建议：论文要求的个体散点需要原始数据，请在实验记录阶段就保留。**

**Q2：多组比较时为什么不直接两两 t 检验？**
≥3 组两两 t 检验会把假阳性率放大到约 14%（α=0.05），必须 One-way ANOVA + 事后检验（Tukey）。这是统计规范，也是审稿人检查点。

**Q3：我的数据每组样本量不同，可以吗？**
可以。技能用调和平均样本量做 Tukey 校正（Prism 同款约定），图上会如实标注每组 n。

**Q4：可以改图吗？**
可以。见第 8 节，对任意已出图说修改要求即可。

**Q5：数据是配对设计（同一批样本前后测）怎么说明？**
在描述里说明「配对设计，同一批样本处理前后」，技能会自动改用配对 t 检验 / 重复测量 ANOVA。

**Q6：非正态分布数据怎么办？**
技能自动检测：两组小样本非正态 → Mann-Whitney U / Wilcoxon；多组 → Kruskal-Wallis + Dunn 事后检验。你无需手动判断。

**Q7：柱状图和小提琴图该选哪个？**
想强调「组间均值差异」用柱状图（Mean±SEM）；想强调「数据分布形态」用箱线图 / 小提琴图。现代期刊普遍要求叠加个体散点，三者技能都默认叠加。

**Q8：生存曲线需要装 lifelines 吗？**
不需要。技能内置 Peto 法实现，无需额外依赖即可出 Kaplan-Meier 曲线 + log-rank 检验；**3 组及以上自动输出整体 χ² 检验 + 两两比较**（报告中注明两两比较未做多重比较校正）。若需要 Cox 比例风险回归（HR + 95% CI），会用到 lifelines，但技能在调用 Cox 时会**自动安装**到当前环境，无需手动处理；仅在无网络/无权限导致自动安装失败时才会提示手动 `pip install lifelines`。

## 11. 避坑清单（务必先看）

- 🚫 **只传「均值±SD」** → 无法叠加个体散点，期刊可能退稿。请传**原始重复测量值**。
- 🚫 **把重复测量当独立样本** → 同一批样本多次测量必须声明「配对 / 重复测量」，否则统计方法用错。
- 🚫 **≥3 组做两两 t 检验** → 假阳性飙升，必须用 ANOVA + 事后检验。
- 🚫 **嵌套说成重复测量** → 教室嵌套于教学方法，要用嵌套检验并先按亚组聚合，避免伪重复。
- 🚫 **忘记标注误差线类型和 n** → 图注必须写清「Mean±SEM / 中位数+IQR」和每组 n，这是审稿人标准检查项。
- ✅ **不确定表类型** → 直接把数据发来，让技能先识别并确认，再出图，省一轮返工。
