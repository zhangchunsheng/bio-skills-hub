# 医疗科普文案生成器

## 功能介绍
输入医学主题，生成专业准确又通俗易懂的医疗科普文章，适合公众号/小红书发布，含常见误区、实用建议、就医指导和免责声明。

## 使用方法
把你想科普的医学主题发给AI，例如：
- 「帮我写一篇关于高血压的科普文章，适合公众号发布」
- 「生成一篇糖尿病饮食的小红书科普」
- 「写一篇关于失眠的科普，要破除常见误区」
- 「科普一下颈椎病，针对上班族的」

可以指定：
- 科普主题（疾病/症状/健康知识）
- 目标平台（公众号/小红书/抖音脚本）
- 目标读者（大众/特定人群）
- 字数要求

## 输出内容
- 吸引人但不标题党的标题
- 通俗易懂的科普正文
- 核心知识点总结
- 常见误区澄清
- 实用建议和就医指导
- 合规免责声明

## 适合人群
医生/护士、医疗自媒体、健康科普博主、公众号运营、医院宣传科、关注健康的普通人
