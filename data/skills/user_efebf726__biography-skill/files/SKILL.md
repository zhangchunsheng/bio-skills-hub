# 专属传记整理技能

## 功能
1. 接收用户提供的纯文本传记内容
2. 智能分析传记主题、人物、时间线、重要事件
3. 自动生成分类目录（早年经历、职业生涯、重要成就、个人生活等）
4. 将传记整理为结构化 Markdown 文档
5. 支持保存为本地文件

## 使用方法
1. 用户说触发词，或直接粘贴传记内容
2. 技能分析内容并展示识别到的分类
3. 用户确认或调整分类方式
4. 生成结构化目录和正文
5. 输出整理后的传记文档，询问是否需要保存

## 分类目录模板
- **人物简介**：姓名、出生年月、身份概述
- **早年经历**：成长背景、家庭环境、教育经历
- **职业生涯**：重要职位、事业发展、关键转折点
- **重要成就**：代表作品、获奖荣誉、重大贡献
- **个人生活**：家庭情况、兴趣爱好、性格特点
- **历史评价**：社会影响力、后人评价、历史地位

## 执行流程

### Step 1：接收内容
- 用户直接粘贴传记文本，或从文件读取
- 检查内容长度，若少于 100 字提示补充细节

### Step 2：智能分析
- 识别人物姓名、出生时间、主要身份
- 提取时间线和关键事件
- 判断内容适合哪些分类目录

### Step 3：分类匹配
- 将内容段落归入对应分类
- 若无某分类内容，则省略该分类
- 支持用户手动调整分类

### Step 4：生成文档
- 输出标准 Markdown 格式
- 包含可点击目录导航
- 保持原文核心信息不丢失

### Step 5：保存输出
- 询问用户是否保存为 .md 文件
- 默认文件名格式：`{姓名}_传记_整理版.md`

## 输出格式示例

**输入**：
> 李四，1990 年出生于上海。2012 年毕业于复旦大学新闻系，同年进入央视工作。2018 年创办自媒体平台"观点"，粉丝超过 500 万。2023 年出版自传《看见》。已婚，热爱摄影和旅行。

**输出**：
```markdown
# 李四传记

## 目录
- [人物简介](#人物简介)
- [早年经历](#早年经历)
- [职业生涯](#职业生涯)
- [重要成就](#重要成就)
- [个人生活](#个人生活)

---

## 人物简介
李四，1990 年出生于上海，知名媒体人、自媒体创业者。

## 早年经历
2012 年毕业于复旦大学新闻系。

## 职业生涯
毕业后进入央视工作。2018 年创办自媒体平台"观点"，粉丝超过 500 万。

## 重要成就
2023 年出版自传《看见》。

## 个人生活
已婚，热爱摄影和旅行。
```

## 依赖
- 无需额外软件依赖，纯 AI 文本处理能力
- 如需保存文件，需要文件系统写入权限

## 异常处理
- **内容过短**（< 100 字）：提示"传记内容较短，建议补充更多细节以便更好分类"
- **无法识别人物**：使用通用分类模板，不强制要求人物简介
- **用户取消**：回复"已取消整理，如需再次整理请重新触发"
- **内容混乱**：先进行段落梳理，再分类

## 优化建议
- 传记越长，分类越精准
- 用户可手动指定分类偏好（如"侧重职业经历"）
- 支持多次迭代调整，用户可说"把 XXX 部分移到YYY分类"
