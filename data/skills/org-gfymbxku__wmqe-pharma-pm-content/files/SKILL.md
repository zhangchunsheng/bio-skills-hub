# 内容与学术支持（产品管理/新药研发 · pharma skill）

## 用途
This skill equips WorkBuddy to act as a specialized assistant for the **产品管理/新药研发** role, specifically the **内容与学术支持** sub-scenario set from the 医药企鹅 WorkBuddy 医药企业AI工作场景案例白皮书. This skill should be used when a product manager needs promotional (DA) copy in multiple versions, labeling revision suggestions, or academic conference slide decks. Covers: DA文案撰写, 说明书修订, 学术会议PPT.

## 触发示例
- "DA文案撰写：描述产品核心卖点，自动生成多版本学术推广文案"
- "说明书修订：提供更新要点，自动生成说明书修订建议"
- "学术会议PPT：一句话需求，自动生成含讲者备注的学术会议幻灯片大纲"

## 多版本 DA 的"版本"指什么
"多版本"不是随意改写，而是按维度生成面向不同对象的文案：
- **受众维度**：临床医生版（机制+循证+临床价值）/ 药师版（用法用量+相互作用+储藏）/ 护士版（给药护理+不良反应观察）
- **适应症维度**：不同适应症 / 不同科室的侧重版本
- **渠道维度**：学术会议口头报告版 / 代表线下拜访版 / 线上推送短文版
- **篇幅维度**：完整版 / 一页纸摘要版 / 要点卡（3×5 要点）
生成前先与用户确认"需要哪些版本"，避免一股脑产出。

## DA 合规必备要素清单（交付前自检）
医药推广材料受《药品管理法》《广告法》及行业合规约束，生成 DA 文案后、交付前必须核对：
1. 显著标明 **"本资料仅供医药专业人士参考"**
2. 标注 **产品批准文号（某药企准字 H/Z/S…）**
3. 含 **不良反应 / 禁忌 / 注意事项** 摘要
4. **不得含绝对化用语**：最佳 / 首选 / 唯一 / 100% / 根治 / 治愈率 / 保证 等
5. **不得含疗效承诺或治愈暗示**（如"包治""断根""无副作用"）
6. 数据、结论须 **标注来源**（文献 / 试验编号 / 说明书条款）
7. 保留 **市场 / 医学 / 合规复核留痕**
可运行 `python scripts/compliance_check.py <生成文件>` 自动初筛违规词与缺失要素（仅提示、不阻塞）。详见下方工作流第 5 步。

## 模糊需求的澄清问句
当用户只给一句话（如"帮我写个 DA"），先确认再写：
- 目标产品 / 核心适应症？
- 受众是谁（医生 / 药师 / 护士 / 患者教育）？
- 用途场景（学术会议 / 代表拜访 / 线上）？
- 需要哪些版本（见"多版本"一节）？
- 篇幅要求（完整 / 一页纸 / 要点卡）？
- 是否已有**核准的关键信息（key message）**与禁忌红线？竞品参照？

## 工作流
1. **明确场景与输入**：定位目标场景；若需求模糊，先用"澄清问句"补全。
2. **组织内容**：基于场景要点与领域知识，撰写/归纳结构化内容（章节、要点、表格）。
3. **产出 spec**：将内容组织为 render.py 所需的 spec JSON（结构见 references/templates.md）。
4. **渲染交付物**：执行 `python scripts/render.py <spec.json> --format <md|html|docx|json> --output <交付文件路径>`。
5. **交付前合规自检**：运行 `python scripts/compliance_check.py <渲染产物>`；对 ⚠️ 项修订（补必备要素 / 替换违禁词），再交付，并提示须经人工复核。

## 端到端示例（DA 文案）
用户："帮我写 XX 肠溶片的 DA，主打肝安全性，给消化科医生，完整版。"
→ 生成 spec（节选）：
```json
{
  "title": "XX肠溶片·肝胆领域学术推广资料",
  "meta": [["适用对象","医药专业人士"],["产品","XX肠溶片（某药企准字 H2023xxxx）"]],
  "sections": [
    {"heading":"本资料仅供医药专业人士参考",
     "paragraphs":["以下内容基于说明书与已发表循证，仅供学术交流，非宣传用途。"],
     "note":"必备合规要素①"},
    {"heading":"临床未满足需求","bullets":["NASH 人群肝功能异常比例高","现有方案肝安全性数据有限"]},
    {"heading":"产品机制与差异化","paragraphs":["XX 肠溶片在…显示 ALT/AST 升高发生率低于对照（文献 L2023-xxx）"],"note":"数据须标注来源⑥"},
    {"heading":"安全性概要","bullets":["常见不良反应：…","禁忌：…","注意事项：肝功能监测"],"note":"必备要素③"},
    {"heading":"小结","bullets":["肝安全性特征支持在目标人群使用"]}
  ],
  "footer":"须经市场/医学/合规复核后方可对外使用"
}
```
→ `python scripts/render.py da_spec.json --format docx --output da_xx.docx`
→ `python scripts/compliance_check.py da_xx.md` 自检 → 修复 ⚠️ 项 → 交付。

## 输入 spec 说明（render.py）
spec 为 JSON，结构：
```json
{
  "title": "报告标题",
  "subtitle": "可选副标题",
  "meta": [["字段", "值"]],
  "sections": [
    {"heading": "章节标题", "paragraphs": ["段落"], "bullets": ["要点"], "table": {"headers": ["列1","列2"], "rows": [["a","b"]]}, "note": "提示"}
  ],
  "footer": "页脚"
}
```
完整字段与示例见 `references/templates.md`。

## 脚本
- `scripts/render.py`：通用文档渲染器（支持 md / html / docx / json）。
- `scripts/compliance_check.py`：DA 合规初筛（违禁词 + 必备要素缺失提示），纯标准库、无外部依赖。

## 常见错误与 FAQ（反模式）
> 评测指出本 skill 此前缺少"常见错误用法清单"与"独立 FAQ 文档"，本节补上。

### 常见错误用法（请避免）
1. **不澄清需求就直接生成**：一句话"帮我写个 DA"直接开写 → 易偏题。先用"模糊需求的澄清问句"补全。
2. **跳过交付前合规自检**：生成后不跑 `compliance_check.py` 就交付 → 可能漏必备要素/含违禁词。
3. **把 .md 大纲当成品 PPT**：学术会议场景交付物是"含讲者备注的幻灯片大纲(.md)"，不是 .pptx 文件（渲染器不生成 .pptx）。
4. **对外材料未走复核**：把 AI 产出直接对外发布 → 违反合规。须经市场/医学/合规复核并留痕。
5. **照搬网络疗效话术**：直接引用未核实的"根治/最佳"类表述 → 触发合规风险，且 `compliance_check.py` 会标红。

### FAQ
- **Q：渲染 docx 报 `python-docx 不可用`？** A：`render.py` 的 docx 格式依赖可选包 `python-docx`。未安装时改用 `--format md` 或 `html`（纯标准库、零依赖）；或 `pip install python-docx` 后重试。注意 `compliance_check.py` 对 .docx 自检也需 python-docx，否则请对 .md 版本自检。
- **Q：多版本怎么选？** A：见"多版本 DA 的版本维度"，按受众/适应症/渠道/篇幅四维度组合，生成前与用户确认。
- **Q：能直接生成 .pptx 吗？** A：不能。渲染器输出 md/html/docx/json；PPT 场景给"含讲者备注的幻灯片大纲"，由用户在 PowerPoint/WPS 中套用。
- **Q：合规检查报 ⚠️ 怎么办？** A：按提示补必备要素（批准文号/仅供医药专业人士/不良反应禁忌）或替换违禁词，重跑至无 ⚠️，再交付。
- **Q：如何接入 Agent 工作流？** A：用对话触发（如"写 XX 的 DA"），或脚本化：`render.py` 接收 spec JSON 产出文档；`compliance_check.py` 做交付前门禁。

## 能力边界（不能做什么）
> 评测指出此前未说明技术限制与"不能做什么"的清单，本节明确边界，避免误用。

- **技术限制**：docx 格式需可选依赖 `python-docx`；超大文档/批量上百份请分批处理。
- **不替代专业终审**：AI 产出仅供内部决策参考，**不替代**医学、法规、市场部门的终审与合规审批。
- **不联网核实最新文献**：不实时检索最新指南/文献，引用数据须由用户核实来源后标注。
- **不生成疗效承诺**：不得产出"包治/根治/无副作用/保证有效"等承诺性或绝对化结论。
- **不处理非 pharma 场景**：仅覆盖 DA 文案 / 说明书修订 / 学术会议幻灯片；其他文种（如合同、招标书、患者直接面向材料）不在范围内。
- **处理能力上限**：单份交付物建议合理篇幅（如 DA ≤ 数千字、PPT ≤ 20 页大纲），超长内容请拆分多次生成。

## 合规提示
医药行业涉及患者隐私、商业合规（反商业贿赂、GSP/GMP、数据合规）与广告宣传限制。所有 AI 产出仅供内部决策参考；对外材料（推广、招投标、注册、合同）须经相应资质人员复核并走合规审批流程，且不得含有未经证实的疗效或合规承诺。
