# 使用 DeepWiki-Open 生成仓库维基

Use DeepWiki-Open to analyze a GitHub, GitLab, or Bitbucket repository and generate a navigable AI-written wiki with code structure explanations and diagrams for onboarding or agent context.

## Prerequisites

DeepWiki-Open/Grok Wiki application, access to the target GitHub, GitLab, or Bitbucket repository, configured supported model provider or local model option where applicable
