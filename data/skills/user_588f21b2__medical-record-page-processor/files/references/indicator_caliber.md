# 指标口径定义

> 对外引用任何一个指标时，**必须连口径一起说**。下表「口径」列就是标准话术。
> 实现见 `scripts/indicators.py`，本文件与之一一对应。

## 一、住院天数

| 项目 | 定义 |
|------|------|
| 计算式 | `住院天数_计算 = 出院日期 − 入院日期`（默认 0 基，可用 `--los-offset 1` 改为首尾日均计） |
| 取值顺序 | 优先用「实际住院天数」填报值（≥0 时），缺失或为负才用计算值 |
| 口径声明 | 「住院天数=出院日期−入院日期，同日入出院记 0 天（或 1 天，全院须统一）」 |
| 陷阱 | ① 各院对同日入出院记 0 还是 1 不统一，跨院比较前必须确认；② 填报值与日期推算值不一致是高频错误（工具规则 Q005 会抓）；③ 均值极易被极少数超长住院拉高，**报均值必须同时报中位数** |

## 二、年龄

| 项目 | 定义 |
|------|------|
| 取值顺序 | 优先「年龄」字段；缺失时用「出生日期」推算（入院日期 − 出生日期，按 365.25 天折年） |
| 单位处理 | 带「年龄单位=月」时 ÷12；=天时 ÷365 |
| 年龄段 | 默认 `0-17 / 18-44 / 45-59 / 60-74 / 75岁及以上`，可用 `--age-bins 0,18,45,60,75,200` 改 |
| 口径声明 | 「年龄为入院时周岁，缺失者按出生日期推算」 |
| 陷阱 | 婴幼儿用月龄填报时若不做单位换算，会出现「0 岁成人」的荒谬结果 |

## 三、费用类

| 指标 | 公式 | 口径与陷阱 |
|------|------|-----------|
| 次均费用 | ∑总费用 ÷ 出院人次 | 分母含无费用记录的病例；建议同时报中位数 |
| 日均费用 | 总费用 ÷ 住院天数（逐例算后取均值） | 住院天数为 0 的病例会置空，不计入 |
| 药占比 | （西药费 + 中药费）÷ 总费用 × 100% | 工具给两个口径：**全院合计口径**（分子分母分别求和）与**按例均值口径**。前者用于院级上报，后者用于描述典型病例；两个数会有差异，报告里标明用的是哪个 |
| 耗占比 | 一次性医用材料费合计 ÷ 总费用 × 100% | 材料费按「检查/治疗/手术用一次性材料费」+「耗材费/卫生材料费」聚合；各院科目归集口径差异大，跨院比较需谨慎 |
| 检查检验费 | 实验室诊断费 + 影像学诊断费 + 病理诊断费 + 临床诊断项目费 | 四项任一存在即计入 |
| 治疗手术费 | 手术治疗费 + 非手术治疗项目费 + 一般治疗操作费 + 护理费 + 一般/综合医疗服务费 + 康复费 + 中医治疗费 | 用于费用结构图 |
| 费用分项偏差率 | \|分项合计 − 总费用\| ÷ 总费用 × 100% | >5% 触发 Q014；常见原因是分项字段不全或总费用含院外购药 |

## 四、手术相关

| 指标 | 公式 | 口径与陷阱 |
|------|------|-----------|
| 有无手术 | 手术操作编码或手术操作名称**任一非空** = 有手术 | 两列都不存在时才退回「手术治疗费 > 0」判定。与 HIS「手术台次」口径不同，**不得混用** |
| 手术率 | 有手术例数 ÷ 出院人次 × 100% | 例数口径（一例多次手术算 1 例） |
| 三四级手术占比 | 手术级别为三/四级例数 ÷ 有手术例数 × 100% | 手术级别为空/未分级的记录不计入分母，因此该比例可能偏高，解读时说明「未填级别者未纳入」 |

## 五、结局与质量类

| 指标 | 公式 | 口径与陷阱 |
|------|------|-----------|
| 死亡率 | 离院方式=死亡 例数 ÷ 出院人次 × 100% | 只反映住院死亡，不等于 30 日死亡率 |
| 非医嘱离院率 | 离院方式=非医嘱离院 ÷ 出院人次 × 100% | 部分医院用「自动出院」表述，工具已归一 |
| 抢救成功率 | ∑抢救成功次数 ÷ ∑抢救次数 × 100% | **次数口径**（不是例数），与院内质控报表的例数口径可能不同，须说明 |
| 31 天再入院率 | 与同患者上一次出院间隔 ≤31 天的入院例数 ÷ 出院人次 × 100% | 需同一患者纵向数据（病案号/研究ID 跨表统一）。多年度分表且 ID 未统一时该指标不可信，必须说明 |

## 六、DRG / 绩效类

| 指标 | 公式 | 口径与陷阱 |
|------|------|-----------|
| CMI | DRG 权重的算术均值 | 权重（RW）需数据里自带；用哪个版本的 DRG 分组器会影响数值，必须注明分组器版本 |
| DRG 组数 | DRG 编码/名称去重数 | 反映病种覆盖广度 |

## 七、基础计数

| 指标 | 口径 |
|------|------|
| 出院人次 | 首页记录条数（未去重）——**上报口径** |
| 患者数 | 病案号/研究ID 去重计数——**人头口径** |
| 人均住院次数 | 出院人次 ÷ 患者数 |

> ⚠️ 「出院人次」与「患者数」是最容易被写错的一对。写「我院 2024 年收治 X 例患者」时，
> 若 X 取的是记录条数，就是人次口径冒充实数口径。报告里两个数都给。

## 八、时间归集

- 所有时间维度（年份/季度/月份/年月）**按出院日期**归集。
- **不完整年度**：当末年记录数 < 其他年度中位数 50%（典型为当年数据导出截止），
  工具会自动识别并在事实卡里加 ⚠ 提示，增幅类结论自动剔除该年。
  解读时**不得**把这种年份写成「业务量下降」。
