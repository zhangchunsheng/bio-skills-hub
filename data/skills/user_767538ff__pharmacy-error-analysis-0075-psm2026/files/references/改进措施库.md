# 西药房差错改进措施知识库（5M1E 维度）

本知识库按"人-机-料-法-环-测"六大维度整理改进措施，供根因分析后制定整改方案时调用。每条措施标注落地难度（★低/★★中/★★★高）与预期效果。

---

## 一、人（Man）—— 人员因素

| 措施编号 | 措施内容 | 落地难度 | 预期效果 |
|---------|---------|---------|---------|
| M-01 | 新入职药师岗前规范化培训 ≥ 40 学时，覆盖处方审核、调剂、核对全流程，考核合格方可独立上岗 | ★★ | 降低新人差错率 30% 以上 |
| M-02 | 高警示药品、麻精药品专项培训与年度复训，建立能力档案 | ★★ | 杜绝高危品种管理违规 |
| M-03 | 合理排班，单人连续调剂不超过 2 小时强制轮换，高峰时段增配人手 | ★★ | 缓解疲劳性差错 |
| M-04 | 实施工作量监测，人均每小时处方调剂量超过阈值（建议 ≤ 40 张）触发预警 | ★★ | 控制超负荷导致的差错 |
| M-05 | 开展职业倦怠评估与心理疏导，建立排班公平与休假保障机制 | ★★ | 长期改善注意力与责任心 |
| M-06 | 推行"差错分享会"非惩罚性文化，每月匿名讨论近差事件 | ★ | 提升团队风险意识与上报率 |
| M-07 | 药师参与临床查房，熟悉科室用药习惯与特殊人群方案 | ★★ | 提升处方审核拦截能力 |
| M-08 | 对易混淆药品、近期差错类型设置"每月一题"专项考核 | ★ | 持续巩固薄弱环节 |

## 二、机（Machine）—— 设备与信息化

| 措施编号 | 措施内容 | 落地难度 | 预期效果 |
|---------|---------|---------|---------|
| E-01 | 部署处方前置审核系统，自动拦截适应证、剂量、相互作用、重复用药、过敏禁忌问题 | ★★★ | 处方差错拦截率 > 90% |
| E-02 | 调剂环节引入条码扫描核对，发药前强制扫码比对处方与药品 | ★★★ | 品种/规格差错下降 70% |
| E-03 | 配置智能药柜/自动发药机，减少人工取药环节 | ★★★ | 调剂差错下降 50% 以上 |
| E-04 | 拆零药品使用独立分装机与条码标签，避免手工分装混药 | ★★ | 拆零差错显著降低 |
| E-05 | 信息系统设置相似药品弹窗警示、高警示药品红色标识、近效期黄灯提醒 | ★★ | 视觉提醒降低误取概率 |
| E-06 | 引入叫号取药 + 人脸/扫码身份核验双因子确认发药对象 | ★★ | 杜绝发药对象差错 |
| E-07 | 温湿度监测物联网化，异常自动告警并记录冷链断链时段 | ★★ | 储存差错可追溯 |
| E-08 | 用药指导由系统生成个性化用药指导单，含用法图示与装置演示二维码 | ★★ | 用药交代标准化 |
| E-09 | 系统强制电子签名与时间戳，审核/调剂/核对签名不可代签 | ★ | 责任可追溯 |

## 三、料（Material）—— 药品与物料

|---------|---------|---------|---------|

## 使用说明

制定整改方案时：
1. 先据根因分析结论，识别差错涉及哪些维度（通常多维度叠加）
2. 优先选取"高预期效果 + 低落地难度"措施快速落地见效
3. 系统性原因（信息化、流程设计）虽难度高但效果持久，列入中长期规划
4. 每条整改措施须明确责任人、完成时限与验证指标
5. 参照 references/法规制度.md 确保措施符合强制性规范要求
