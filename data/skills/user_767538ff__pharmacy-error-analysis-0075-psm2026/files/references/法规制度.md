# 药学法规与制度参考

本参考摘录与西药房差错分析直接相关的法规、规范条款，供分析报告引用与改进措施合规性核对使用。引用时标注条款来源，确保整改建议有据可依。

> 注：以下为要点摘录，正式引用以现行有效版本原文为准。分析报告中引用法规时应注明具体条款编号。

---

## 一、《医疗机构药事管理规定》（卫医政发〔2011〕11 号）

- **第三十六条** 药学专业技术人员应严格执行"四查十对"制度：
  - 查处方，对科别、姓名、年龄
  - 查药品，对药名、剂型、规格、数量
  - 查配伍禁忌，对药品性状、用法用量
  - 查用药合理性，对临床诊断
- **第三十七条** 调剂处方时必须做到"四查十对"，发出药品应注明患者姓名、用法用量，并交待注意事项
- **第四十条** 医疗机构应建立药品不良反应/事件监测与报告制度
- **第四十一条** 医疗机构应建立用药错误监测报告制度，及时发现、收集、分析、上报用药错误

**分析引用要点**：调剂差错分析须对照"四查十对"执行情况，识别哪一"查"环节失效。

## 二、《处方管理办法》（卫生部令第 53 号）

- **第十九条** 处方开具当日有效。特殊情况下需延长有效期的，由开具处方的医师注明有效期限，但最长不得超过 3 天
- **第三十五条** 药师应当对处方用药适宜性进行审核，审核内容包括：
  - 规定必须做皮试的药品，处方医师是否注明过敏试验及结果判定
  - 处方用药与临床诊断的相符性
  - 剂量、用法的正确性
  - 选用剂型与给药途径的合理性
  - 是否有重复给药现象
  - 是否有潜在临床意义的药物相互作用和配伍禁忌
- **第三十六条** 药师经处方审核后，认为存在用药不适宜时，应当告知处方医师，请其确认或者重新开具处方；发现严重不合理用药或用药错误，应当拒绝调剂，及时告知处方医师并记录，按照有关规定报告
- **第三十七条** 药师调剂处方时必须做到"四查十对"
- **第四十二条** 除麻醉药品、精神药品、医疗用毒性药品和儿童处方外，医疗机构不得限制门诊就诊人员持处方到药品零售企业购药

**分析引用要点**：处方审核环节差错须对照第三十五条六项审核内容逐项核查。

## 三、《医疗机构药学服务规范》（国卫医函〔2020〕308 号附件）

### 处方审核
- 药师是处方审核的第一责任人
- 处方审核包括合法性、规范性、适宜性审核
- 审核后应在处方上签名或加盖专用签章
- 不合理处方应当记录并告知医师修改

### 药品调剂
- 调剂应遵循"四查十对"原则
- 调剂后应进行复核，复核合格方可发放
- 调剂过程中发现药品质量问题应立即停止使用并上报
- 特殊管理药品调剂应执行"双人双锁"等规定

### 用药交代与指导
- 发药时应进行用药交代，内容包括药品名称、数量、用法用量、特殊注意事项
- 对特殊剂型（吸入剂、胰岛素笔、栓剂等）应示范使用方法
- 对特殊人群（老人、儿童、孕妇）应强化指导

**分析引用要点**：核发环节差错须对照用药交代规范评估指导是否到位。

## 四、《用药错误管理指导原则》（药事管理专业委员会）

### 用药错误定义与分类
- **用药错误（Medication Error）**：药品在临床使用全过程中出现的、任何可以防范的、导致用药不当或患者损害的事件
- 涵盖环节：处方开具与传递、药品调剂与分发、给药、用药监测

### 用药错误分级（NCC MERP 标准）
采用 A～I 九级分级（详见 references/差错分类.md 开头危害等级定义）

### 根本原因分析要求
- E 级及以上差错须启动正式根本原因分析（RCA）
- RCA 应聚焦系统原因而非个人追责
- 分析应覆盖：事件经过还原、直接原因、潜在原因、系统原因、改进措施

### 非惩罚性上报
- 鼓励主动上报近差事件（A、B 级）
- 上报不以追责为目的，重在系统改进
- 严重差错（E 级及以上）按重大事件处理流程上报

**分析引用要点**：根因分析须遵循"非惩罚性、聚焦系统"原则；分级决定分析深度。

## 五、《医院处方点评管理规范（试行）》（卫医管发〔2010〕28 号）

- 医疗机构应建立处方点评制度，每月抽查门急诊处方 ≥ 100 张
- 点评内容包括：处方书写规范性与用药适宜性
- 不合理处方分为不规范处方、用药不适宜处方、超常处方
- 点评结果纳入科室与医师绩效考核

**分析引用要点**：处方审核差错可结合处方点评数据分析趋势。

## 六、《麻醉药品和精神药品管理条例》（国务院令第 442 号）

- 麻醉药品、第一类精神药品实行"五专"管理：专人负责、专柜加锁、专用账册、专用处方、专册登记
- 处方限量：
  - 门急诊麻醉药品注射剂每次 1 日常用量，控缓释制剂 7 日常用量，其他剂型 3 日常用量
  - 第一类精神药品注射剂每次 1 日常用量，控缓释制剂 7 日常用量，其他剂型 3 日常用量
- 处方留存 3 年备查

**分析引用要点**：麻精药品差错须核查"五专"执行与处方限量合规性。

## 七、《高警示药品管理与用药安全指导原则》（中国药学会）

### 高警示药品目录要点
- 高浓度电解质（10% 氯化钾、10% 氯化钠、浓氯化钠）
- 静脉用胰岛素、皮下用胰岛素（高浓度/预混）
- 神经肌肉阻滞剂
- 静脉用化疗药
- 口服降糖药、抗凝药（华法林）
- 100 ml 以上灭菌注射用水

### 管理要求
- 专区/专柜存放，与非高警示药品物理隔离
- 醒目警示标识（建议红色）
- 调剂与给药双人核对
- 定期盘点，账物相符

**分析引用要点**：高警示药品差错无论等级均按重大事件，须核查专区存放、警示标识、双人核对。

## 使用说明

1. 分析报告"改进建议"部分须标注所依据的法规条款，增强建议权威性
2. 整改措施合规性核对：对照本参考检查措施是否满足强制性要求
3. 涉及法律责任的差错（如麻精药品违规）须在报告中明确提示法律风险
4. 法规版本以现行有效为准，建议每年核对更新本参考
