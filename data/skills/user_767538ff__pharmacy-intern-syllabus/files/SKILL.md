# 药剂科实习生教学大纲生成

## Overview

本技能为医院药剂科生成系统、可落地、可考核的《药剂科实习生教学大纲》Word 文档。按「模块 → 单元 → 知识点」三级结构展开，覆盖三大模块 21 个教学单元，每个模块包含三维教学目标（知识/技能/态度）、知识点清单（表格呈现，★重点、▲难点标注）、建议学时、教学方法与考核方式。

文档基于 4 周实习周期设计（理论 32 + 实操 48 = 80 学时），结合二甲医院药剂科实际，依据《处方管理办法》《医疗机构药事管理规定》《抗菌药物临床应用管理办法》等现行法规。

## 何时使用

- 用户要求生成药剂科实习生教学大纲、岗前培训大纲
- 用户提到「实习生带教大纲」「带教计划」「教学计划表」
- 用户需要为药学专业实习生制定系统化教学文档
- 用户需要可落地、可考核的带教流程与标准

## 三大模块 · 21 个单元

### 模块一：药物基础知识（理论 12 + 实操 6，5 单元）
1.1 药理学核心概念（ADME、半衰期、生物利用度、首过效应、治疗指数）
1.2 药物分类体系（药理作用分类、剂型分类、ATC、处方药/OTC）
1.3 剂型与给药途径（缓释/控释/肠溶/泡腾/舌下/吸入剂）
1.4 药品说明书解读（结构、缩写、贮藏条件、批准文号）
1.5 特殊管理药品（麻醉/精神/毒性/放射性药品、「五专」管理）

### 模块二：药物临床应用（理论 14 + 实操 10，8 单元）
2.1 抗感染药物临床应用（分级管理、围术期预防、PK/PD）
2.2 心脑血管系统药物（降压五大类、他汀、华法林 INR）
2.3 呼吸/消化/内分泌系统用药（吸入剂、PPI、降糖药、胰岛素）
2.4 合理用药基本原则（安全/有效/经济/适当、重复用药、配伍禁忌）
2.5 常见药物相互作用（CYP450 酶、药效学相互作用）
2.6 药品不良反应识别与处理（ADR 分类、Naranjo 评分、上报流程）
2.7 特殊人群用药（老年 Beers、儿童、孕产妇、肝肾功能不全）
2.8 处方审核与点评要点（合法性/规范性/适宜性、三类不合理处方）

### 模块三：药剂科日常工作注意细则（理论 6 + 实操 32，8 单元）
3.1 药品调剂全流程（收方→审核→调配→核对→发药、「四查十对」）
3.2 处方管理办法要点（处方权、有效期、保存期限、处方限量）
3.3 药品储存养护（温湿度、冷链、拆零、近效期、先进先出）
3.4 麻精药品管理细则（五专、双人双锁、逐日登记、空安瓿回收）
3.5 药品盘点与效期管理（盘点制度、账物相符、效期预警、报损）
3.6 发药交代与用药咨询（交代要点、特殊剂型、漏服处理、咨询流程）
3.7 差错防范与上报（差错类型、三重防线、LASA、非惩罚上报）
3.8 医疗安全与院感防控（手卫生、职业暴露、医疗废物）

## 工作流

1. **确认需求**：带教对象（本科/大专）、医院等级、实习周期（默认 4 周）、是否需要定制内容。
2. **运行脚本**：执行 `scripts/gen_syllabus.py` 生成标准 Word 文档。
   ```bash
   python scripts/gen_syllabus.py [输出路径.docx]
   ```
   不带参数时输出到当前工作目录下「药剂科实习生教学大纲.docx」。
3. **按需定制**：若用户需要调整内容（增减单元、修改学时、调整知识点），参考 `references/大纲结构与自定义.md` 修改脚本中的数据常量。
4. **交付验证**：生成后检查表格数量（应为 25 个）、知识点行数（标准 148 条），确认三大模块完整。

## 文档结构

生成的 Word 文档包含以下部分：

| 章节 | 内容 |
|------|------|
| 封面 | 标题、适用对象、实习周期、编制依据 |
| 一、大纲说明 | 适用范围、标注说明（★/▲） |
| 二、总体学时分配 | 三大模块学时汇总表 |
| 三、考核方式与合格标准 | 四项考核（理论/处方审核/技能/平时）占比与合格线 |
| 模块一/二/三 | 三维教学目标 + 各单元知识点表格 |
| 附：教学方法说明 | 五种教学方法适用场景 |
| 附：参考法规与依据 | 8 部现行法规清单 |

## 定制方法

脚本中以下常量可修改以适配不同需求：

- `MODULE1_UNITS` / `MODULE2_UNITS` / `MODULE3_UNITS`：三大模块的单元数据，每条格式为 `(单元号, 单元名, 学时, 教学方法, [(知识点, 标记)])`
- 标记字段：`"★"` 重点、`"▲"` 难点、`"★▲"` 重点+难点、`""` 普通
- 学时分配表、考核标准表：在 `build()` 函数中修改
- 颜色/字体：修改顶部常量（PRIMARY/ACCENT/FONT_CN 等）

详细定制说明见 `references/大纲结构与自定义.md`。

## 约束

- 内容以《处方管理办法》《医疗机构药事管理规定》《抗菌药物临床应用管理办法》《药品管理法》等现行法规为依据。
- 涉及具体药品剂量、适应证须与最新说明书/指南一致；不确定处标注「以最新指南为准」。
- 突出二甲医院药剂科实际（人手、病种、药品种类），不照搬三甲模板。
- 模块三实操占比最高（32 学时），因实习生主要在调剂岗位轮转。
