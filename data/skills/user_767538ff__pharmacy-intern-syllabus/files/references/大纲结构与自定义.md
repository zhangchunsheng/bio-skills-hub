# 大纲结构与自定义

> 本文件说明 `scripts/gen_syllabus.py` 中的数据结构、21 单元完整清单，以及常见定制场景的操作方法。

## 数据结构

脚本中三大模块的数据以 Python 列表常量存储：

```python
MODULE1_UNITS = [
    ("1.1", "药理学核心概念", "理论1.5+实操0.5", "讲授+示教",
     [
        ("药代动力学 ADME 四过程……定义及临床意义", "★"),
        ("消除半衰期（t½）概念……", "★"),
        # ... 更多知识点
     ]),
    # ... 更多单元
]
```

### 字段说明

| 位置 | 字段 | 说明 | 示例 |
|------|------|------|------|
| 0 | 单元号 | 模块号.单元号 | `"1.1"` |
| 1 | 单元名 | 单元标题 | `"药理学核心概念"` |
| 2 | 学时 | 理论+实操学时 | `"理论1.5+实操0.5"` |
| 3 | 教学方法 | 该单元建议的教法组合 | `"讲授+示教"` |
| 4 | 知识点列表 | [(知识点描述, 标记), ...] | 见下 |

### 标记字段取值

| 标记 | 含义 | 渲染效果 |
|------|------|----------|
| `"★"` | 重点（必须掌握） | 表格中显示 ★ |
| `"▲"` | 难点（易错/需突破） | 表格中显示 ▲ |
| `"★▲"` | 重点+难点 | 表格中显示 ★▲ |
| `""` | 普通知识点 | 表格中留空 |

## 常见定制场景

### 场景 1：调整实习周期

修改 `build()` 函数中的学时分配表和封面信息。例如改为 6 周实习：

```python
info_pairs = [
    ("实习周期", "6 周（约 120 学时，理论 48 + 实操 72）"),
    ...
]
```

同步修改各模块的学时汇总表（「二、总体学时分配」章节）。

### 场景 2：增减知识点

在对应单元的列表中添加或删除条目：

```python
# 在 1.1 单元中新增一个知识点
("药时曲线下面积（AUC）的临床意义", ""),
```

### 场景 3：调整医院等级

封面信息表中的「适用对象」字段和 SKILL.md 描述可修改。内容方面：
- 二甲医院：侧重常见病种、基本药物、调剂实操
- 三甲医院：可增加特殊使用级抗菌药、专科用药、临床药学服务内容

### 场景 4：修改考核标准

在 `build()` 函数中找到「三、考核方式与合格标准」的表格，修改占比和合格线。

### 场景 5：修改视觉样式

脚本顶部常量控制全局样式：

```python
PRIMARY = RGBColor(0x18, 0x5F, 0xA5)   # 主色（专业蓝）
ACCENT = RGBColor(0x0F, 0x6E, 0x56)    # 强调色（墨绿）
FONT_CN = "微软雅黑"                    # 中文字体
FILL_HEAD = "185FA5"                    # 表头底色
FILL_ALT = "F4F8FC"                     # 交替行底色
```

## 法规依据

生成内容以以下现行法规为准：
- 《中华人民共和国药品管理法》（2019 修订）
- 《处方管理办法》（卫生部令第 53 号）
- 《医疗机构药事管理规定》（卫医政发〔2011〕11 号）
- 《抗菌药物临床应用管理办法》（卫生部令第 84 号）
- 《麻醉药品和精神药品管理条例》（国务院令第 442 号）
- 《医疗机构麻醉药品、第一类精神药品管理规定》（卫医发〔2005〕438 号）
- 《药品不良反应报告和监测管理办法》（卫生部令第 81 号）

涉及具体药品剂量、适应证以最新说明书与临床指南为准。
