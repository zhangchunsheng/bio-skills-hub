# 分子鉴别应用：判定标准、近缘种/混伪品鉴别与报告模板

## 1. 《中国药典》中药材DNA条形码分子鉴定体系（9107通则）

- **核心条形码**：ITS2（核基因组，220–250 bp）
- **辅助条形码**：psbA-trnH（叶绿体基因组）
- **流程**：药材样本提取 → ITS2（必要时 psbA-trnH）扩增测序 → 与中药材DNA条形码数据库（http://www.tcmbarcode.cn）比对 → 相似度与系统发育判定 → 结合基原核对出结论。
- **适用**：药材及其粉末、饮片、部分炮制品；对多基原药材（如贝母、石斛、秦艽等）尤其重要。
- **局限**：亲缘极近种（如部分栽培品种）可能无法区分；高度炮制样本 DNA 降解时扩增失败——此时需转向显微/理化鉴定。

## 2. 鉴定判定证据链（四重证据）

分子鉴定结论应综合以下证据，**不能只看单一指标**：

| 证据 | 方法 | 判定参考 |
|---|---|---|
| ① BLAST 比对 | 与 GenBank / 药典条形码数据库比对 | 一致率 ≥98–99% 且覆盖全长，首选匹配明确 |
| ② 遗传距离 | K2P 距离（种内 vs 种间） | 目标序列落于该种的种内距离范围，与近缘种间距离大于种内 |
| ③ 系统发育 | NJ/ML 树中与参考序列的单系性 | 与参考序列构成单系群，Bootstrap ≥70% |
| ④ 形态/生药复核 | 性状、显微、理化复核 | 与鉴定结果互证；矛盾时查找原因 |

**结论等级：**
- **确定**：四重证据一致且序列质量高。
- **可能/倾向**：BLAST 高匹配但距离或单系性证据不足（如数据库无该种参考）。
- **无法判定**：无参考序列、亲缘极近、序列质量差——如实说明，不给模糊结论。

## 3. 近缘种鉴别策略

近缘种（姐妹种、复合种）是分子鉴定的难点，策略按序推进：

1. **提高分辨率**：从单条形码升级为**组合条形码**（ITS2 + psbA-trnH + matK 或 rbcL），多个标记联合判别（concatenated alignment 或分别建树看一致性）。
2. **诊断性位点（diagnostic sites）**：比对中寻找目标种**特有**的稳定 SNP/indel——这是比距离更直接的鉴别依据。可通过 `scripts/fasta_toolkit.py align` 逐对定位差异位点。
3. **单倍型网络（haplotype network）**：种内样本多时用 TCS/Network 软件，比树更清晰显示种间单倍型分离。
4. **增加取样**：种内样本越多，种内变异估计越准，误判越少（每种 ≥3 个个体，覆盖地理分布）。
5. **叶绿体全基因组**：单/双条形码无法区分时，考虑质体基因组（组装成本已大幅下降）或 SNP 标记开发（如 SNaPshot）。

## 4. 混伪品与替代品鉴别要点

| 场景 | 常用策略 |
|---|---|
| 药材粉末掺伪（如掺淀粉/杂草粉） | ITS2 扩增后测序，与数据库比对看是否出现非目标序列 |
| 混入近缘伪品（如川贝母中混平贝母/伊贝母） | 组合条形码 + 诊断性位点；药典多基原药材需查对照品序列 |
| 替代品/地方习用品（民族药习用品） | 先确认基原，再对照药典正品序列；结论需注明「习用品与正品非同种」 |
| 掺假比例极低（<5%） | 一代测序灵敏度不足——提示 NGS 宏条形码（metabarcoding）方案 |

**注意事项：**
- 混合样本（粉末中掺伪）一代测序峰图会出现**多套峰**，测序文件中有识别指引；应重新分离纯化或改用克隆/NGS。
- 判定「伪品」需以**正品参考序列**（药典基原凭证样本）为准，不要仅凭 GenBank 未经验证的序列下结论。
- 民族药（藏药等）多基原、地方习用情况复杂，结论中注明参考数据库覆盖范围与证据强度。

## 5. 经典案例参考

### 5.1 川贝母 vs 平贝母（近缘种鉴别）
- 川贝母（Fritillaria cirrhosa）与平贝母（F. ussuriensis）形态相似、性状鉴别困难。
- 分子策略：ITS2 扩增测序，比对药典数据库；二者 ITS2 存在稳定差异位点，可依据诊断性位点区分；数据库比对 K2P 距离通常 >0.03。
- 教训：单靠 BLAST 最高命中（可能都是「贝母属」）不够，须看种级分辨率与单系性。

### 5.2 石斛类（多基原+易混）
- 药典收载铁皮石斛等，市场上金钗石斛、流苏石斛等并存，还有伪品石仙桃。
- 分子策略：ITS2 + psbA-trnH 双条形码；psbA-trnH 在石斛属内变异高，常作为区分关键标记。
- 教训：石斛属 ITS2 种间距离可能不大，需双标记联合判断。

### 5.3 人参 vs 西洋参（粉末鉴别）
- 粉末掺伪鉴定：ITS2 短片段对陈旧粉末扩增成功率高。
- 人参（Panax ginseng）与西洋参（P. quinquefolius）ITS2 存在稳定差异；系统发育树中各自单系。
- 教训：商品粉末建议平行提取多份样品，排除抽检偶然性。

### 5.4 藏药「蒂达」类（龙胆科獐牙菜属多基原）
- 藏药蒂达基原复杂（川西獐牙菜、獐牙菜、印度獐牙菜等），混用普遍。
- 分子策略：ITS2 + psbA-trnH，结合药典/藏药标准参考序列逐种核对；对无参考序列的习用品如实标注「无参考序列，建议补充凭证样本测序」。

## 6. 鉴定报告输出模板

用户需要正式结论时，按以下结构输出：

```
一、样本信息（编号、基原/名称、采集信息、凭证标本号）
二、材料与方法
   1. 样本类型与DNA提取方法（试剂盒/CTAB，试剂与批号可选）
   2. 条形码与引物（引物序列、片段长度）
   3. PCR条件（退火温度、循环数）
   4. 测序与拼接（测序仪、拼接软件、consensus长度）
   5. 分析方法（比对软件与参数、距离模型、建树方法与Bootstrap）
三、结果
   1. 序列信息（长度、GC含量、GenBank/BOLD登录号）
   2. BLAST最佳匹配（物种、覆盖度、一致率）
   3. 遗传距离（种内/种间K2P距离）
   4. 系统发育树（关键分支支持率）
   5. 诊断性位点（如有）
四、鉴定结论（证据链 + 结论等级 + 局限说明）
五、附件（峰图、比对文件、树文件路径/登录号）
```

**报告原则**：每条结论对应证据；证据不足处明确标注；结论含「确定/可能/无法判定」等级；附复核所需全部文件信息。
