# 电泳检测与测序数据处理：判读、拼接、杂合位点与假基因

## 1. 琼脂糖凝胶电泳判读

### 1.1 制胶参数

| 目的 | 凝胶浓度 | 电压 | 时间（约） | 适用片段 |
|---|---|---|---|---|
| DNA完整性检查 | 0.8–1.0% | 5 V/cm | 30–40 min | >20 kb 高分子量 |
| PCR产物检测 | 1.5–2.0% | 5 V/cm | 30–40 min | 200–800 bp |
| 分离/回收相近片段 | 2.0–2.5% | 4–5 V/cm | 40–60 min | <300 bp |

- 1× TAE 或 TBE 缓冲液；1× 上样缓冲液（Loading Buffer）；DNA Marker（100 bp Ladder 或 DL2000）作对照。
- 电压过高（>8 V/cm）会导致小片段分辨率差、条带弯曲；凝胶厚度不均会致条带变形。

### 1.2 判读标准

**基因组DNA电泳：**
| 现象 | 判定 |
|---|---|
| 泳道孔附近单一明亮大分子量条带，无弥散 | 完整性好，可用 |
| 大分子量带下出现连续弥散（smear） | 降解——轻到中度降解仍可扩短片段；重度需重提 |
| 条带弥散至胶底、信号弱 | 严重降解或浓度极低 |
| 孔内残留亮点 | 蛋白/多糖污染，DNA滞留在孔内 |

**PCR产物电泳：**
| 现象 | 判定与处理 |
|---|---|
| 目标大小处单一明亮条带 | 特异性好，可直接测序 |
| 目标带外有引物二聚体（<100 bp 模糊亮带） | 常见，不影响切胶回收；直接测序前建议纯化 |
| 多条带 | 非特异扩增——切胶回收目标带后再测序 |
| 无条带或极弱 | 见 PCR 文件失败排查表 |
| 条带大小与预期明显不符 | 核对 Marker；怀疑假基因/内含子变异，送测序确认 |

### 1.3 质量评估数值参考

- PCR 产物浓度建议 ≥20 ng/μL（测序需要总量 30–100 ng / 反应）。
- 上样电泳目测：条带亮度与 Marker 中 200 bp（约 20–50 ng/带）亮度相当即可测序。

## 2. ABI测序峰图（Chromatogram）解读

### 2.1 峰图质量评估

| 指标 | 合格 | 问题 |
|---|---|---|
| 信号强度 | 主峰高 300–3000 RFU | <100 信号弱（模板不足）；>4000 过饱和（可能平顶/荧光串扰） |
| 背景噪声 | 基线平、峰清晰 | 背景高/波浪底=模板不纯或含盐 |
| 峰形 | 单碱基单峰，峰间距均匀 | 套峰/双峰=杂合或混合模板 |
| 读长 | 一代测序通常 600–900 bp | 尾部信号衰减属正常，截取可信区段 |

### 2.2 常见峰图问题与对策

| 问题 | 可能原因 | 对策 |
|---|---|---|
| 起始端（前 20–40 bp）峰乱 | 引物峰重叠 | 测序时软件裁掉引物区，一般丢弃前段 |
| 末端信号衰减、N增多 | 聚合酶活性下降/模板耗尽 | 只保留可信区段，用反向引物补测 |
| 某一位点双峰（两个等位碱基） | **杂合位点** | 用 IUPAC 简并码标注（见下表），不强行选一个 |
| 连续同碱基重复区（如 AAAAA）后峰乱 | 聚合酶滑移 | 该区段不可靠，比对时注意；可用反向互补校正 |
| 整段双峰/套峰 | 模板不纯（混合样本/双拷贝） | 重新纯化、克隆后测序，或检查是否为假基因混合 |
| 单向测序失败 | 引物结合差/序列结构 | 反向引物重测；换引物组合 |

## 3. 正反向序列拼接（Contig组装）

### 3.1 标准流程

1. **查看峰图**：Chromas / ChromasPro / FinchTV / SnapGene / 4Peaks 打开 `.ab1` 文件，人工目检每个碱基峰。
2. **裁去两端**：删去引物区与低质量端（峰图质量分 Q20 以下区段）。
3. **反向互补**：反向序列（reverse primer 测出）先做反向互补，再与正向序列比对。
4. **拼接**：正反向序列重叠区（overlap）一般 >50 bp 且一致；两序列合并为一条 consensus。
   - 推荐用 `scripts/fasta_toolkit.py consensus` 自动合并（内置 IUPAC 合并规则），再人工复核重叠区。
5. **校正**：以峰图为准逐位核对；正反向不一致处查看两侧峰图裁决（先看正向峰图，再看反向，多数为测序误差）。
6. **输出**：最终序列用 FASTA 格式，标注样本号与条形码（如 `Sample01_ITS2`）。

### 3.2 拼接质量要求

- 重叠区双链一致率 ≥99%（每 100 bp 不超过 1 个不一致，且均能由峰图解释）。
- 最终序列两端各保留 5–10 bp 边界判断余量；提交 GenBank 前建议用 BLAST 复核。

## 4. IUPAC 简并碱基码（杂合位点标注）

| 码 | 含义（碱基组合） | 典型场景 |
|---|---|---|
| R | A/G | 杂合嘌呤 |
| Y | C/T | 杂合嘧啶 |
| S | G/C | |
| W | A/T | |
| K | G/T | |
| M | A/C | |
| B | C/G/T（非A） | 三重峰 |
| D | A/G/T（非C） | |
| H | A/C/T（非G） | |
| V | A/C/G（非T） | |
| N | A/C/G/T 任一/未知 | 无法判读 |

> 杂合位点判读规则：**单一位点出现两个大小相当的双峰 → 记相应简并码**；若一个峰明显高于另一个（>3:1），可能为拷贝数差异或污染，需谨慎，必要时克隆测序确证。

## 5. 杂合位点与假基因识别

### 5.1 杂合位点（Heterozygous site）

- **来源**：二倍体个体两个等位基因差异；ITS 多拷贝间的种内变异；混合模板。
- **识别**：峰图该位点出现等高的双峰；正反向测序在同一位置均呈双峰（排除测序误差的关键证据）。
- **处理**：标注简并码；用于建树时该位点按多态处理或使用单倍型克隆数据。

### 5.2 假基因（Pseudogene）

核基因（尤其 ITS）中常见。识别信号：

| 信号 | 说明 |
|---|---|
| 序列比对中出现**缺失/插入引起移码** | 编码区（如 5.8S、matK 编码区）出现非同义长度的 indel |
| **内部出现终止密码子**（TAA/TAG/TGA） | 编码条形码中强烈提示假基因（但需排除测序错误） |
| GC含量明显偏离同属正常序列 | 假基因漂移（如 ITS 假基因 GC 常下降） |
| 系统发育中异常长枝（长分支吸引） | 假基因序列常聚成异常姐妹支 |
| 峰图单一位点清晰但比对后与其他样本差异过大 | 提示该拷贝为失活拷贝 |

**处理原则：**
1. 编码条形码（matK/rbcL）中见移码/终止密码子：先排除测序错误（重看峰图、重测），确证后删除或标注为假基因，不参与建树或单独分析。
2. ITS 假基因：可借助 5.8S 保守区序列识别（假基因 5.8S 变异大）；确认后从数据集剔除，或单独成组分析并注明。
3. 全证据报告：若怀疑假基因但证据不充分，如实标注「序列质量存疑，建议克隆验证」，不要强行用于鉴定结论。

## 6. 提交与归档建议

- 高质量序列提交 GenBank（BankIt）或 BOLD 时，附峰图文件与引物信息，利于复核与发表。
- 每条序列归档：样本采集信息（GPS/凭证标本号）、DNA编号、引物、峰图文件、consensus 序列——保证「样本→序列→结论」全链可追溯。
