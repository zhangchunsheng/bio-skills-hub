# 序列比对与系统发育分析：MEGA操作、遗传距离、建树方法与参数推荐

## 1. 多序列比对（Alignment）

### 1.1 软件与流程

| 软件 | 用途 | 要点 |
|---|---|---|
| **MEGA**（推荐） | 比对+距离+建树一体化 | 内置 ClustalW/MUSCLE；图形界面友好，教程多 |
| **DNAMAN** | 比对、引物设计 | 常用于小数据集与教学场景 |
| **MAFFT**（命令行/在线） | 大规模比对 | 速度快、准确性高，超100条序列首选 |
| BioEdit / AliView | 比对结果查看与手工校正 | 直观查看保守区与变异位点 |

**标准流程：** 导入FASTA → 校对序列方向（必要时反向互补，可用 `scripts/fasta_toolkit.py revcomp`）→ ClustalW/MUSCLE 自动比对 → **手工校正**（把错位的gap按密码子/保守基序对齐，ITS2看5.8S保守区锚点）→ 截齐两端（trim，删除长度不齐的悬垂端）。

### 1.2 推荐参数

**ClustalW（MEGA内置）：**
| 参数 | 推荐值 |
|---|---|
| Gap Opening Penalty | 15 |
| Gap Extension Penalty | 6.66 |
| Transition Weight | 0.5（DNA） |
| 迭代比对 | 可选打开 |

**MUSCLE：**
| 参数 | 推荐值 |
|---|---|
| 迭代次数 | 16（默认） |
| 最大迭代 | 默认即可 |
| 对齐后修剪 | 手动检查 |

**MAFFT（大数据集）**：`mafft --auto input.fa > output.fa`；或 `--localpair`（L-INS-i）用于<200条高精度比对。

### 1.3 手工校正要点

- 以密码子为单元对齐编码区（matK/rbcL），避免密码子内插入gap。
- ITS2 等非编码区：找保守基序（如 5.8S 末端、保守环区）作锚点。
- 比对后删除两端参差部分（N或gap过多），保证所有序列等长可比较。
- 保留比对记录（.meg / .aln），以便复现与发表。

## 2. 遗传距离计算

### 2.1 模型选择

| 模型 | 适用 | 说明 |
|---|---|---|
| **K2P（Kimura 2-parameter）** | DNA条形码研究**默认** | 区分转换/颠换，条形码文献标准模型（Hebert et al. 2003 建议） |
| p-distance | 序列差异很小、种内比较 | 最简单；序列相似时与K2P差异小 |
| Tamura-Nei / GTR | 碱基频率偏倚、数据较大 | 建树用模型选择确定 |

### 2.2 计算操作（MEGA）

`Distance` → `Compute Pairwise Distances` → 选 K2P，核苷酸替换类型选「Transitions + Transversions」，缺失数据处理选「Pairwise deletion」（位点逐一剔除）或「Complete deletion」。

### 2.3 解读与条形码间隔（barcoding gap）

- 统计所有样本的**种内最大距离**与**种间最小距离**；若种间最小距离 > 种内最大距离，存在清晰的 **barcoding gap**，条形码鉴别能力良好。
- 常见参考：多数植物类群 ITS2 种间 K2P 距离 > 0.03–0.10，种内 <0.02；但**具体阈值因类群而异，不可机械套用**，必须以本类群种内/种间分布为依据。
- 可用 `scripts/fasta_toolkit.py align` 快速计算单对样本的 p 距离与 K2P 距离，作为初步判断。

## 3. 系统发育树构建

### 3.1 方法选择

| 方法 | 适用场景 | 优点 | 局限 |
|---|---|---|---|
| **NJ（邻接法）** | 条形码鉴别、大数据集、快速初判 | 快、无需模型选择、能处理大样本 | 非统计推断、无分支长度优化 |
| **ML（最大似然法）** | 需严谨估计、发表级 | 统计框架完整、有模型支持 | 慢，需选模型 |
| MP（最大简约法） | 形态+分子小数据集 | 概念直观 | 长枝吸引问题 |
| BI（贝叶斯） | 复杂模型、多基因 | 后验概率支持 | 需先验、MCMC耗时长 |

**条形码鉴别场景推荐：NJ + Bootstrap（1000次），必要时以 ML 复核关键分支。**

### 3.2 MEGA 建树参数推荐

**NJ：**
| 参数 | 推荐值 |
|---|---|
| 遗传距离模型 | K2P（与距离计算一致） |
| Bootstrap | **1000 次**复现 |
| 缺失处理 | Pairwise deletion |
| 替换类型 | 转换+颠换 |

**ML：**
| 参数 | 推荐值 |
|---|---|
| 模型 | 先 ModelTest/Find Best DNA Model 选择（常用 GTR+G、K2P+G、T92+G） |
| Bootstrap | 500–1000 次 |
| 初始树 | NJ 树作起始 |
| 启发式搜索 | 默认（NNI/SPR） |

### 3.3 分支可靠性解读

| Bootstrap 支持率 | 解读 |
|---|---|
| ≥90% | 强支持，可作结论 |
| 70–89% | 中等支持，谨慎表述 |
| 50–69% | 弱支持，不能单独作结论 |
| <50% | 视为未解决（polytomy），不可下结论 |

- 内群单系性（monophyly）判定：目标样本与参考序列构成**单系群（同一分支）**，且支持率 ≥70%，方可用于鉴定结论。
- 注意**长枝吸引**：假基因、高度分化序列易聚在一起形成长枝；对异常长枝先查序列质量（见测序处理文件），再决定去留。

## 4. 分析报告输出建议

涉及建树的分析，输出应包含：
1. 数据集组成（样本数、条形码、长度范围）
2. 比对方法与参数
3. 距离模型与计算结果（种内/种间距离范围、是否存在 barcoding gap）
4. 建树方法与支持率
5. 关键分支支持率与鉴别结论
6. 原始文件归档（比对文件、树文件 .nwk）便于复核

## 5. 常见错误与规避

| 错误 | 规避 |
|---|---|
| 序列方向不一致就比对 | 先全部校对为同一方向（5'→3'） |
| 距离与建树模型不一致 | 同一数据集统一用 K2P |
| Bootstrap 次数过少（<500） | 一律 ≥1000 |
| 用单一短片段断言种级结论 | 结合多条形码+形态学，说明证据强度 |
| 忽略假基因/长枝 | 建树前先做序列质控（见测序处理文件） |
