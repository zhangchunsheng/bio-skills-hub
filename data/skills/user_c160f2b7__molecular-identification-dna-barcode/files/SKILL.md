# 分子鉴定与DNA条形码分析

## 技能定位（Purpose）

协助用户完成从**样本到物种鉴别**的全流程分子鉴定工作：DNA提取 → PCR扩增 → 电泳检测 → 测序处理 → 序列比对与系统发育分析 → 分子鉴别判定。技能兼具实验操作指导与生信分析能力，重点服务植物学、中药材（含藏药）基原鉴定、混伪品鉴别、分类疑难解决等场景，并与《中国药典》四部通则9107「中药材DNA条形码分子鉴定指导原则」（ITS2为核心条形码、psbA-trnH为辅助条形码）对接。

## 使用时机（When to Use）

在用户出现以下任一需求时触发本技能：

- 需要从植物/药材样本中提取基因组DNA，或提取失败需排查（多糖多酚、降解、抑制物等）
- 需要选择或设计条形码引物（ITS/ITS2、psbA-trnH、matK、rbcL 等），或 PCR 扩增无产物、非特异
- 需要判读琼脂糖凝胶电泳结果，评估 DNA 质量或 PCR 产物特异性
- 拿到测序结果后需要解读 ABI 峰图、拼接正反向序列、校正碱基、识别杂合位点或假基因
- 需要做多序列比对、遗传距离计算、构建 NJ/ML 系统发育树并解释分支可靠性
- 需要基于分子证据鉴别近缘种、混伪品、替代品，或补充形态学鉴定的不足
- 用户直接提供了 FASTA 格式序列数据要求分析解读

若用户需求仅涉及形态学/显微/理化鉴定，或不属于分子层面，提示其使用相应技能（如显微鉴定、理化色谱分析等），并说明分子鉴定与它们的互补关系。

## 核心工作流（Workflow）

分子鉴定按以下五阶段流水线执行。每一阶段完成后确认结果质量，合格再进入下一阶段；任一阶段失败需按对应章节排查后再继续。

```
阶段1 样本与策略确认 → 阶段2 DNA提取 → 阶段3 PCR扩增
→ 阶段4 电泳检测与测序 → 阶段5 比对建树与鉴别判定
```

### 阶段1：样本与策略确认（先问清再动手）

**必须先确认以下信息，再给出定制化方案：**

1. **样本类型**：新鲜叶片 / 硅胶干燥 / 腊叶标本 / 药材饮片（是否炮制）/ 粉末 / 种子 / 根皮等。药材饮片、粉末类需提示 DNA 降解风险，必要时改用短片段条形码（如 ITS2、mini-barcode）。
2. **鉴定目标**：物种确认 / 近缘种区分 / 混伪品鉴别 / 系统发育位置 / 种质资源评价，不同目标决定条形码与建树策略。
3. **测序策略**：一代 Sanger 测序（常规）还是二代/三代测序（宏条形码、全叶绿体基因组）。
4. **拟用条形码**：单一条形码还是组合（如 ITS2 + psbA-trnH）。

**条形码推荐速查（常规一代测序）：**

| 场景 | 推荐条形码 | 说明 |
|---|---|---|
| 中药材鉴定（药典9107体系） | **ITS2 + psbA-trnH** | ITS2为核心，psbA-trnH辅助；药材粉末/饮片首选 |
| 属内近缘种区分（通用） | ITS / ITS2 + psbA-trnH | ITS 变异高，但部分类群存在假基因与长片段问题 |
| 亲缘关系远、科级以上 | rbcL + matK | 变异保守，易通用扩增，鉴别力有限 |
| 叶绿体单亲遗传验证 | matK、rbcL、trnL-trnF | 母系遗传标记 |
| 标本/降解样本 | 短片段（ITS2、mini-rbcL、trnL 短区） | 扩增成功率优先 |

详细引物序列、体系与条件见 `references/pcr-primer-conditions.md`。

### 阶段2：DNA提取

- 新鲜/硅胶干燥材料：优先 CTAB 法或商业植物基因组 DNA 试剂盒，步骤与配方见 `references/dna-extraction-guide.md`。
- 含多糖多酚药材（如地黄、甘草、黄连、部分藏药根皮类）：CTAB 法中需增加 PVP 用量、高盐沉淀多糖等对策。
- 蜡叶标本/老标本：短片段策略 + 增加裂解时间，必要时使用专用古 DNA 提取方法。
- 提取后必须评估质量：OD260/280（1.8–2.0）、OD260/230（>1.8）或电泳完整性检查。评估标准与阈值见 `references/dna-extraction-guide.md` 问题排查表。

### 阶段3：PCR扩增

- 依据条形码选择引物对（见引物总表），给出 25–50 μL 体系各组分浓度范围、退火温度（推荐梯度 PCR 优化，详见 `references/pcr-primer-conditions.md`）。
- 扩增失败排查按「无条带 → 非特异 → 弱条带 → 阴性对照污染」顺序分析，对应原因与对策见该文件的失败分析表。
- 条码短（ITS2 约 220–250 bp）、Tm 差异大的引物对建议使用 touchdown 程序。

### 阶段4：电泳检测与测序

- 琼脂糖凝胶浓度与 Marker 对照判读、DNA/PCR 产物质量评估标准见 `references/electrophoresis-sequencing.md`。
- 测序结果（ABI 文件）：先看峰图质量（信号强度、单峰、背景噪声），再拼接正反向序列、人工校正，用 IUPAC 简并码标注杂合位点；发现双峰贯穿、单碱基重复区模糊、内部终止密码子时警惕假基因或混合模板。
- 提供拼接建议时，可调用 `scripts/fasta_toolkit.py` 的 `consensus` 命令自动生成正反向 consensus（含 IUPAC 合并规则）。

### 阶段5：比对、建树与鉴别判定

- 多序列比对：MEGA 内置 ClustalW/MUSCLE，参数推荐值与手动校正要点见 `references/alignment-phylogeny.md`。
- 遗传距离：条形码研究推荐 K2P（Kimura 2-parameter）模型；用种内/种间距离分布判断条形码间隔（barcoding gap）。
- 建树：物种/个体数少或条形码单基因数据推荐 NJ（快捷、可处理大样本）；有较好模型支撑或需更严谨估计推荐 ML（如 MEGA 中 GTR+G 或经 ModelTest 选择）。分支可靠性一律报告 Bootstrap 值（≥70% 视为可信）。
- 鉴别判定综合四重证据：BLAST 比对一致率、K2P 遗传距离、系统发育单系性、形态/生药特征复核。判定阈值与完整流程见 `references/identification-application.md`。

## 工作准则（Response Rules）

回答与输出必须遵循以下六条准则：

1. **先确认再定制**：针对用户需求，先确认其样本类型、测序策略或所用条形码，再给出定制化方案；信息不足时明确列出需要补充的 2–3 项关键信息（用清单形式），不要凭空假设。
2. **实验参数要具体**：涉及实验操作时，提供关键试剂配方、参数范围或时间估算（如「CTAB 缓冲液 2% CTAB，65℃ 水浴 30–60 min」），避免只给原则不给数字。
3. **序列数据要解读**：用户提供 FASTA 数据时，用 `scripts/fasta_toolkit.py` 计算长度、GC 含量、双序列差异，解读变异位点、种内/种间遗传距离，并说明建树参数推荐值（模型、Bootstrap 次数等）。
4. **输出条理分明**：重要步骤使用编号或要点；复杂概念（如假基因、barcoding gap、Bootstrap）附简明示例或类比；必要时用表格对比。
5. **坦诚边界**：超出知识边界或不具备实验条件的情况（如无测序仪、无特定数据库访问）要坦诚说明，并提供查阅文献（如《中国药典》9107、GenBank/BOLD 检索路径）或进一步实验的方向。
6. **以可靠鉴定为核心**：所有建议以帮助用户获得可靠、可复核的物种鉴定结果为目标；给出结论时同时给出证据链（引物、序列号、距离、树支持率），方便用户复核与发表。

## 内置脚本（Scripts）

`scripts/fasta_toolkit.py` — 纯 Python 标准库实现的 FASTA 分析工具，无需第三方依赖。四个子命令：

```bash
python3 fasta_toolkit.py stats <fasta文件>          # 统计每条序列：长度、GC%、碱基组成
python3 fasta_toolkit.py revcomp <fasta文件> <id>    # 输出指定序列的反向互补（用于反链测序）
python3 fasta_toolkit.py align <seqA.fa> <seqB.fa>   # 双序列全局比对：差异位点、p距离、K2P距离、一致性%
python3 fasta_toolkit.py consensus <fwd.fa> <rev.fa> # 正反向序列拼接为consensus（IUPAC简并码合并）
```

- 分析用户提供的 FASTA 数据时**优先调用该脚本**获得确定性数值，再结合知识解读。
- 脚本输出可直接引用（如 GC 含量、变异位点位置、K2P 距离），便于用户复核。
- 注意：脚本仅处理标准碱基（A/T/G/C/N 与 IUPAC 简并码）；若序列含缺失、需要三代测序长片段组装，说明限制并建议相应软件。

## 边界与免责（Boundaries）

- 本技能提供实验设计与数据分析指导，**不能替代**实验室实际条件、仪器校准与合规审批（如涉及药用植物采集需遵守《野生药材资源保护管理条例》与采集许可）。
- 鉴定结论需基于高质量序列与可靠数据库比对；单一短片段条形码的鉴定能力有限（如 ITS2 无法区分部分亲缘极近种），应如实说明并建议补充条形码或形态学证据。
- 涉及濒危保护物种的鉴定与贸易，提醒用户遵守 CITES 与国内相关法规。
