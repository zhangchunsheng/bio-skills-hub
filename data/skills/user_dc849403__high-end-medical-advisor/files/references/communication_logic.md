# 中高端医疗险沟通逻辑与建议生成框架

本文件定义 skill 在面对客户资料时，如何组织沟通、分析维度并生成量身建议。配合 comparison_matrix / drg_policy / objection_handling 使用。

## 一、沟通总原则
1. **先听后说**：先摸清客户真实需求与恐惧，再针对性讲，不背稿。
2. **痛点切入，不讲课**：从"排队3小时看病3分钟""想用好药被告知自费""走廊加床"等真实就医体验切入。
3. **用"就医自由度"替代"保额"**：客户关心的是"能不能选医生/病房/药"，不是"保额几百万"。
4. **路径差异，不贬低**：社保/惠民保/百万医疗都有价值，中高端是在其上叠加品质与自由。
5. **先给结论再展开**：客户时间有限，先把"为什么更适合您"说清，再补论证。

## 二、倾听清单（拿到客户资料后先梳理）
- 年龄、性别
- 家庭情况（婚育、子女年龄、父母赡养、配偶）
- 职业与城市（影响就医资源稀缺度）
- 既往病史 / 体况 / 已购保险
- 对医疗险的看法与已有认知（是否有偏差）
- 真实需求（怕什么：花钱多？看不好？排不上号？）
- 异议问题（具体抗拒点）
- 预算区间（用于调节方案价格）

## 三、四维分析框架（必覆盖，按客户关注排序）
针对客户资料，从以下四方面论证中高端医疗险优势：
1. **医疗资源区别**：机构覆盖（特需/国际/私立/全球）、好医生好床位好药的优先获取权。
2. **条款优势**：0免赔可选、不限医保目录、直付网络、门诊可保、保证续保。
3. **DRG 政策解读**：控费导致普通部受限，中高端提供绕开路径（详见 drg_policy.md）。
4. **保险公司服务**：绿通、二次诊疗、海外就医、护工等增值服务价值。

## 四、量身建议生成逻辑
按客户特征给层级与方案建议：

### 按年龄
- **<30**：费率低、健康易核保，建议早锁资格；可用高免赔降保费。
- **30–45**：家庭责任期，关注配偶/子女；有娃可加私立/特需+门诊。
- **45–60**：父母赡养+自身慢病风险，核保趁早，关注保证续保。
- **>60**：核保难，若已早买则保住；新投保选可保高龄/易核保产品。

### 按家庭情况
- **有幼儿**：儿童发热/呼吸疾病多，私立/特需价值高，选含门诊。
- **有老人父母**：关注增值服务（绿通/护工/转诊）。
- **有配偶**：家庭单折扣，一起规划。
- **单身**：以个人就医品质为先。

### 按需求与预算（方案调节旋钮）
- 机构范围：仅国内特需 → 大中华含港澳台 → 全球（价格递增）。
- 免赔额：0 免赔（贵）→ 高免赔（便宜）。
- 门诊责任：含/不含（含则贵）。
- 直付网络：选广网络产品提升体验。

## 五、输出结构（纯文本分析，给代理人/客户看）
按以下顺序产出，便于直接用于沟通：
1. **客户画像小结**：年龄/家庭/体况/认知/需求一句话概括。
2. **核心结论**：为什么中高端医疗险更适合该客户（先给结论）。
3. **四维优势论证**：医疗资源 / 条款 / DRG / 服务，紧扣客户关注点。
4. **异议逐条回应**：对客户提出的每条异议按 objection_handling 结构回应。
5. **量身建议**：推荐产品层级、机构范围、免赔、门诊、预算区间、保证续保要求。
6. **下一步动作**：试算/出方案/锁资格/转介绍。

## 六、IMA 资料库联动
- 输出前先用 ima-mcp 检索用户 IMA 资料库中的中高端医疗险资料（最新产品、保额、免赔、网络医院、续保、保费、真实案例），核对并充实论据。
- 若 IMA 无相关库，则以本 skill references 基线输出，并提示代理人补充最新产品资料。
