# CBL 行为强制闭环 · 四大约束律详解

> 行为强制闭环（Compulsory Behavioral Loop）是 ERC-214-KW 体系的逻辑引擎——它回答"为什么这个行为不可能是别的行为"。

## 一、核心定义

验证行为/技术/文化演进是否符合物理、化学、生物的客观规律。客观约束具有**不可逆性**——一旦某个方向的技术被发明，不可能回去重新发明一遍；一旦某条物理定律成立，不可能在同时代被超越。

## 二、四大约束律

### 2.1 技术渐进律

**核心判断**：技术演进存在渐进性，缺陷率突变指向外部输入。

**逻辑**：任何技术的成熟过程必然经历"低水平试错 → 逐步改进 → 成熟稳定"的渐进曲线。若在某时段突然出现成熟技术，而其前后无低水平试错层，则该技术不可能为独立研发——必然来自外部输入或年代误判。

**应用示例**：三星堆青铜器若铸造缺陷率远低于同时期中原青铜器的早期铸件，且周边无低水平试错遗址，则指向外部技术输入。

### 2.2 热力学熵减律

**核心判断**：人为干预导致文本/器物熵降，可检测。

**逻辑**：自然流传的文本/器物会随时间熵增（破损、散佚、变异），而人为干预（整理、修订、篡改）往往产生局部熵降——有序化的痕迹本身就是"被干预过"的证据。

**应用示例**：程高本后四十回的语言一致性远高于前八十回手抄本的变异度——这种"不正常的有序"本身即人为整理的熵减信号。

### 2.3 地理阻力律

**核心判断**：前工业时代技术传播受地理距离约束。

**逻辑**：在前工业时代，技术的长距离传播需要物质载体（人、工具、原料）的物理移动。运输半径受交通工具、道路条件、政治边界的多重限制。若某技术声称在前工业时代跨越了超出运输半径的地理距离，则需要提供中间传播节点的证据。

### 2.4 行为强制律

**核心判断**：生存压力驱动唯一出路——"挤出去的末路"。

**逻辑**：当多维度环境约束（政治身份、经济通道、表达通道、流通通道）将一个人锁入"没有其他选项"的境地时，其行为不是被"选择"的，而是被"挤压"出来的——不写《红楼梦》他就没有其他方式在这个制度里活下去。这就是"挤出去的末路"：不是"我要写"，而是"除了写我活不下去"。

## 三、CBL 压力闭合检验

| 步骤 | 操作 |
|------|------|
| 1 | 列出行为人面临的全部约束维度 |
| 2 | 逐一检验每个维度是否"闭合"（即该维度是否已经堵死了所有其他出路） |
| 3 | 若多数维度闭合，仅剩唯一通道 → 行为强制闭环成立 |
| 4 | 若多个通道同时开放 → 行为是"选择"而非"强制" |

## 四、CBL 的应用边界

- CBL 不回答"他选择了什么"，只回答"他没得选的那条路是什么"
- CBL 的强度取决于约束维度闭合的数量——闭合越多，强制力越强
- CBL 无法处理"有多个未闭合维度"的情况——此时行为可能是主动选择而非被动强制
