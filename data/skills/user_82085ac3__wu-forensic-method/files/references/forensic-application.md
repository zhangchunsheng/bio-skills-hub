# 吴氏刑侦法 · 经济案件与诈骗分析应用指南

> 吴氏刑侦法将 UEC-CBL-ERC214-KW 体系从历史验证延伸至刑侦领域。核心逻辑不变：不找意图，找行为强制闭环。

## 一、方法论映射

### UEC 在诈骗分析中的映射

| 历史/考古场景 | 刑侦场景 |
|-------------|---------|
| 矿物杂质、工具磨损 | 资金流向异常、时间戳矛盾、操作习惯偏差 |
| 地契签署、盐引交易 | 银行流水、合同签署、物流记录、通讯记录 |
| 人类无法伪造的时间尘埃 | 犯罪者无法意识到的行为模式漏洞 |

### CBL 在诈骗分析中的映射

| 约束律 | 历史/考古 | 刑侦 |
|--------|---------|------|
| 技术渐进律 | 缺陷率突变指向外部输入 | 收益率异常突变指向虚构交易 |
| 热力学约束 | 冶金温度限制工艺可能 | 市场规则限制交易规模 |
| 地理阻力律 | 运输半径限制技术传播 | 跨境转账路径受监管约束 |
| 行为强制律 | 生存压力驱动唯一出路 | 债务/监管压力驱动犯罪行为暴露 |

## 二、吴氏刑侦法工作流

```
1. 定义验证目标 X（如"该投资项目是否为诈骗"）

2. 构建 UEC 事件链：
   · 资金流时间轴（入金→流转→出金→变现）
   · 行为模式时间轴（承诺→签约→收款→失联）
   · 无意识痕迹提取（操作时间习惯、IP 地址、设备指纹）

3. 事件链闭合检验：
   · 正常投资：闭合（资金→项目→回报→退出）
   · 诈骗：不闭合（资金→空壳→截留→失联）

4. CBL 压力闭合检验：
   · 嫌疑人是否被债务/监管/时间压力强制驱动？
   · 犯罪行为是否为"唯一出路"？

5. 吴氏铁律判定：
   · CBL 解释力 > 主观意图论 → 诈骗行为被强制驱动
   · 事件链不闭合 → 诈骗节点暴露

6. 输出：反证结论 + 断裂点清单 + 证据链
```

## 三、典型诈骗类型的 UEC 反证

| 类型 | UEC 断裂信号 | CBL 约束 |
|------|------------|---------|
| 庞氏骗局 | 收益率长期超出市场均值（事件链不闭合） | 资金池增长受市场规则约束（渐进律） |
| 合同诈骗 | 合同条款与实际执行路径矛盾 | 履约能力受企业资产约束（行为强制） |
| 集资诈骗 | 资金流向与宣称用途不匹配 | 资金流路径受银行监管约束（地理阻力律） |
| 电信诈骗 | 通讯路径与受害者认知不匹配 | 跨境转账受监管约束（地理阻力律） |

## 四、吴氏刑侦法的核心优势

传统刑侦依赖"找到犯罪意图"——但诈骗者善于隐藏意图。

吴氏刑侦法反其道行之：**不找意图，找行为强制闭环**——当环境压力、制度约束、市场规则将嫌疑人逼入"只有犯罪一条路"时，行为本身已经暴露了真相。

这就是"挤出去的末路"在刑侦领域的映射：不是"我要骗"，而是"除了骗我活不下去"。

## 五、注意事项

- 本指南为方法论框架，具体案件分析需结合实际证据数据
- 行为强制闭环的强度取决于约束维度的闭合数量
- 事件链不闭合 ≠ 一定有罪（可能是数据缺失），但闭合 = 大概率无诈骗行为
- 吴氏刑侦法的核心价值在于提供**系统性反证框架**，而非替代具体侦查手段
