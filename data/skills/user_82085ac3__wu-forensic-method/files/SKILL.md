# 吴氏刑侦法 · UEC-CBL-ERC214-KW 历史验证体系

## 版本说明

在考辨曹雪芹真实卒年的过程中，一个底层逻辑浮现：人说的话可以被篡改，留下的痕迹却无法被提前设计。碑刻、诗歌、日记——这些是"想让人看到的东西"；但纸张的帘纹、墨迹的渗化率、火漆的同位素比值——这些是制度在执行过程中"无意识"留下的，没有人为了欺骗后世的检测而去调配那一滴墨的 δ¹³C。

这就是无意识事件链（UEC）的起点：不找"他说了什么"，只找"他留下了什么"——那些在时间尘埃里沉淀的、非刻意的、连续的物质痕迹。它们构成一条不能被伪造者预知的证据链。当这条链无法在某个时间节点上闭合——当 1763 年之后仍然存在连续的行政记录、商业交易、司法文书——那个节点就暴露了它的裂缝。

行为强制闭环（CBL）进一步锁死：不是"他要做什么"，而是"他只能做什么"。当政治身份被注销、经济通道被堵死、表达空间只剩下小说可以借"假语村言"之名幸存——写《红楼梦》不是优选，是挤出去的末路。

这两大支柱交汇之处，即是吴氏铁律：当客观环境强制指向唯一出路，行为本身已经暴露了真相，不需要再去追问意图。

从曹雪芹的生命线到三星堆的工艺链，从永乐大典的版本流变到山海经的古文献溯源——这套方法论不回答"这是什么"，它回答"这不可能是你声称的那样的"——反证永远比证实更有力量，因为证明一个东西"存在"需要全部证据，而证明一个东西"不成立"只需要一条裂缝——梦达

## 方法论文本

本技能是 UEC-CBL-ERC214-KW 体系的操作指南。五大模式覆盖从历史反证到行为分析的全场景，核心逻辑链：**LTCVP 时空锚定 → UEC 无意识事件链 → CBL 行为强制闭环 → ERC-214 熵模型 → KW 验证输出 → 吴氏铁律终判**。

与 zhipi-gene-library（脂批基因库）和 yuxi-reconstruction（盐署本重构）互补：前者负责批语级的内证分析，后者负责叙事级的重构方法，本体系负责事件级的宏观反证。

## When to Use

- **模式 A（历史事件反证）**：用户要验证某个历史节点的真伪（卒年、事件时间等）
- **模式 B（考古溯源验证）**：用户要验证技术/文明的独立起源或传播路径
- **模式 C（文献断代与版本鉴定）**：用户要鉴定文献/版本的真实年代，与 zhipi-gene-library 协同
- **模式 D（行为模式分析）**：用户要分析交易行为异常、资金流异常、行为强制闭环反证
- **模式 E（通用反证框架）**：用户自定义验证场景，自由组合 UEC/CBL/ERC-214 模块

## Core Capabilities

### 模块一：LTCVP（长时间轴闭环反证协议）

功能：为历史事件提供时空坐标基准。

- 利用天文历算进行时间锚定
- 利用衰变时钟进行年代校准
- 三轴闭环反证：时间轴 → 事件轴 → 物质轴
- 反证逻辑：若某节点与事件链的连续性发生不可调和的断裂，则该节点可能为误判

### 模块二：UEC（无意识事件链）

定义：追踪人类活动中非刻意遗留的连续性物质痕迹（矿物杂质、工具磨损、工艺缺陷），因其非目的性可规避人为伪造干扰。

核心操作公式（概念级）：外部冲击 I → 制度/生理上限 L → 可观测行为 B。判据：I∩L 交集只能是单选题，B 无同效替代路径。

验证思路：长时间轴 → 提取连续节点无意识痕迹 → 按技术/资源/文化/环境维度串成事件链 → 与自然数据互证形成证据链闭环 → 若X节点与闭环断裂 → CBL强制律 + 吴氏铁律算出伪造概率。

### 模块三：CBL（行为强制闭环）

四大约束律：

| 约束律 | 内容 |
|--------|------|
| 技术渐进律 | 技术演进存在渐进性，缺陷率突变指向外部输入 |
| 热力学熵减律 | 人为干预导致文本/器物熵降，可检测 |
| 地理阻力律 | 前工业时代技术传播受地理距离约束 |
| 行为强制律 | 生存压力驱动唯一出路——"挤出去的末路" |

### 模块四：吴氏铁律（Wu's Law）

核心判定：若关键节点只能用 CBL 解释而无法用主观意图论圆满解释，则符合 UEC 驱动。

反证逻辑：当 UEC+CBL 双重验证指向同一结论，且无法用主观意图论解释时，触发反证判定。

判定参数（概念级）：ΔTec 技术断层值 / Sc 文化熵增率 / Ec 环境冲突系数。

### 四维证据层

| 维度 | 核心方法 | 产出 |
|------|---------|------|
| 生物标识层 | 代谢物、生物残留质谱分析 | 个体追踪证据 |

## Execution Logic

### 模式 A：历史事件反证

1. 定义验证目标 X（虚拟节点，如"某人物某年卒"）
2. 构建 UEC 事件链（连续行为事件、物质痕迹、文献记录）
3. 检验事件链闭合 → 闭合则 X 可能成立，不闭合则进入 CBL
4. CBL 压力闭合检验（自然律约束是否强制指向唯一出路）
5. 吴氏铁律判定（CBL 解释力 > 主观意图论？）
6. 输出：反证结论 + 证据链闭合度

### 模式 B：考古溯源验证

1. 定义溯源目标（如"某文明青铜器独立起源"）
2. UEC 四维证据链：矿料溯源 / 技术演进 / 文化符号 / 环境交互
3. CBL 自然律约束：技术渐进律 / 热力学约束 / 地理阻力律
4. ERC-214 熵模型量化（概念级判定）
5. 吴氏铁律终判
6. 输出：溯源结论 + 断裂维度清单

### 模式 C：文献断代与版本鉴定

1. UEC 物质痕迹：纸张/墨迹/装帧的无意识痕迹
2. CBL 时代约束：该时代技术/政治/经济环境是否允许
3. 事件链闭合检验（文献内容与已知历史事件的时间轴对齐）
4. **与 zhipi-gene-library 协同**：调用五轴对齐断伪 + 九类归因标签
5. 输出：断代区间 + 证据链 + 归因标签

### 模式 D：吴氏刑侦法（经济案件与诈骗分析）

1. 定义验证目标 X（如"该投资项目是否为诈骗"）
2. 构建 UEC 事件链：资金流时间轴 + 行为模式时间轴 + 无意识痕迹（操作习惯/IP/设备指纹）
3. 事件链闭合检验：正常投资闭合（资金→项目→回报→退出），诈骗不闭合（资金→空壳→截留→失联）
4. CBL 压力闭合检验：嫌疑人是否被债务/监管/时间压力强制驱动
5. 吴氏铁律判定：CBL 解释力 > 主观意图论 → 诈骗行为被强制驱动
6. 输出：反证结论 + 断裂点清单 + 证据链

### 模式 E：通用反证框架

用户自定义验证目标 X，自由组合 UEC/CBL/ERC-214 模块，系统引导构建事件链与施加自然律约束，吴氏铁律终判。
