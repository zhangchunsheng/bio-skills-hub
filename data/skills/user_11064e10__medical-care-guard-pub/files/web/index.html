疾病与工伤防护指南

生病工伤最怕垫钱又跑断腿——先搞清哪些能直接结算、哪些要手工报、工伤和医保怎么分，少折腾、不少拿。

能为你做什么

  • 职工医保能报多少门诊/住院起付线、报销比例与封顶线，区分在职/退休、本地/异地
  • 异地看病怎么结算异地就医备案（国家医保 APP / 窗口）一次办，直接结算免垫资
  • 门慢门特怎么办门诊慢特病病种认定与报销倾斜，长处方与定点管理
  • 生育津贴怎么算申领条件与天数：单位上年度月均工资÷30×产假天数，发放主体与时限
  • 摔伤算不算工伤工伤认定情形、劳动能力鉴定与待遇项目（医疗/停工留薪/伤残）
  • 手工报销怎么报未直接结算时的材料清单、时限与经办窗口

行动节奏

D+0确认就诊地与参保地，判断是否需异地就医备案
D+1办理异地备案（国家医保 APP 或参保地窗口），确保直接结算
D+3门慢门特认定（如适用），绑定定点医院与长处方
D+7涉工伤：固定证据、报工伤、申请劳动能力鉴定
D+30复核报销到账与津贴发放，留存结算单与凭证
