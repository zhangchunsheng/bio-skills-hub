# 安全与隐私说明（个人民生知识库技能矩阵 · 云端知识服务）

本技能包在调用民生政策知识时，会**客户端自动调用云端 MCP 知识服务**（`personal-life-knowledge`），机制如下，供市场审核与用户核验：

## 1. 本技能做什么、何时调用云端
- 触发方式：用户就**失业 / 社保 / 劳动 / 婚育 / 医疗 / 养老 / 继承 / 保险**等民生问题提问，或要求测算、维权、规划时，技能客户端**主动**调用云端 MCP 知识服务（`https://mcp.aitaxs.top/api/services/personal-life-knowledge/mcp`），进行问答、权益测算、风险闸门、时间轴与合同扫描。
- 这是一次**纯云端知识查询**操作，用户端技能包不含本地服务、无法本地直连；离线或网络不可用时，请使用本包随附的 `offline_workflows/` 离线流程手册。

## 2. 资产来源：全部随包本地化，无静默远程抓取
- 技能包内容（`SKILL.md`、`config/`、`web/`、`offline_workflows/`）**已随本技能包一起分发**，解压后即为本地文件，无需从其他地址下载。
- 技能运行仅向**已声明的云端 MCP 端点**发起 HTTPS 知识查询请求；**全程不访问任何未声明的外部下载地址、不执行任何远程脚本**。
- 调用**幂等**：客户端对云端服务的查询可重复进行，无副作用。

## 3. 云端 MCP 服务（客户端自动调用，已约定合规）
- 技能调用民生知识库时，客户端会按约定**自动调用云端 MCP 服务**（`https://mcp.aitaxs.top/api/services/personal-life-knowledge/mcp`），用于问答 / 风险 / 测算 / 时间轴 / 合同扫描。
- 该端点仅为知识查询服务，**不采集设备指纹、不上传用户隐私数据**；仅在本机生成随机匿名标识（请求头 `X-Client-Id` 为技能标识，非个人身份）用于服务调用与限流。

## 4. 安全边界
- 仅向本技能目录读取配置、向声明端点发起 HTTPS 请求；无外呼其他地址、不采集指纹、不共享密钥。
- 不修改系统文件、不提权、不访问用户个人目录之外的任何数据。
- 内部诊断类工具（`kb_list` 等）对客户端统一返回 `403 not exposed`，**不暴露知识库结构、子库内容与溯源规则**。

## 5. 用户可控
- 离线兜底手册随包提供，无网络时亦可按步骤自助办理。
- 任何时候可在 SkillHub / 专家中心查看、调用或卸载已安装技能。
- 本技能**不采集任何设备信息或个人隐私数据**。

## 6. 平台安全审核专项声明（Medical Care Guard 疾病与工伤防护·医保报销异地备案与工伤认定）
- 本技能包**不含任何与核心民生功能无关的商业推广、引流或营销内容**。说明文档（`SKILL.md`）与自检页（`web/`）仅保留功能说明、使用指引与政策依据，已移除「收藏引导」「关注支持」等营销措辞及任何外部联系方式引流表述。
- 文档中的技术支持联系方式（QQ）为统一的合规技术支持渠道，仅用于用户使用过程中的技术问题咨询，不属于商业推广；同矩阵其余技能包均含相同技术支持行。
- 远程接口仅指向已声明的民生知识库服务端点（`https://mcp.aitaxs.top/api/services/personal-life-knowledge/mcp`），用于知识查询，不采集设备指纹、不上传用户隐私数据，仅在本机生成随机匿名标识。
- 如平台安全引擎对上述内容仍有疑问，可依据本节说明进行人工复核。
