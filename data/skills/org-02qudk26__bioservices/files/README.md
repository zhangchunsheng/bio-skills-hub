# BioServices 生物数据库集成

- 唯一标识：`hub-bioservices`
- 显示名称：BioServices 生物数据库集成
- 能力摘要：通过 BioServices 在 Python 中访问多种 REST 与 SOAP 生物信息服务，完成序列、通路、蛋白、结构和标识映射的跨库检索与整合。

## 案例素材

1. 项目需要把基因符号映射为 UniProt 与 KEGG 标识。该 skill 会记录物种、数据库版本和一对多映射，输出未匹配项供人工审查，避免默认为唯一对应。
2. 系统生物学团队汇总代谢通路。该 skill 会从多个服务提取基因—蛋白—反应关系，控制调用频率和失败重试，并保留每条记录的来源数据库。
3. 服务端点升级后返回结构变化。该 skill 会对响应 schema 建立验证和缓存，区分暂时网络故障与 API 语义变化，防止悄然产生空或错配结果。
