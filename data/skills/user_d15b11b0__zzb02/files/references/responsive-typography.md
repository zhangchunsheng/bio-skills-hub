# A–G 响应式构图与文字排版

核心模板是“视觉家族”，不是把新文案填进旧案例坐标。每次制作都必须根据本次标题长度、字宽、标点、关键词和图片安全区重新排版，并让文字变化继续传导到卡片、主图和证据布局，同时保留所选模板的构图拓扑与气质。

## 0. 四层联动原则

任何标题变化都按以下顺序向外传导，不能停在字号层：

1. **字形层**：关键词、数字单位、字体、字号与字色。
2. **文字块层**：断句、行数、行距、主次层级与实际占用宽高。
3. **容器层**：根据文字块反算内边距、卡片/色块宽高、对齐方式和位置。
4. **画布层**：重新分配主图比例、人物位置、第二证据卡、渐变范围和安全留白。

上一层变化后必须重新检查下一层。不得出现文字已经变成四五行，卡片却仍沿用两行案例高度；也不得让两三个字占据为长标题准备的巨大空卡片。

## 1. 固定与可变

固定：模板的主图/文字/第二证据关系、阅读顺序、主要色彩气质、留白方式和装饰克制度。

可变：标题行数、每行内容、字号、主次层级、行距、文字块宽高、卡片宽高与内边距、上下区文字分配、主图占比、证据卡大小与位置。案例图中的具体换行、卡片比例和坐标没有继承权。

## 2. 标题处理原则

1. 用户指定的标题逐字保留，只改变视觉换行与层级；不擅自删字、补字、换同义词或重复关键词。
2. 默认把每个 `--line` 当作软语义边界。排版器优先在这些边界换行，但可为可读性重新组合。
3. 高亮词、数字与单位尽量作为不可拆分词组，例如 `180㎡`、`零公摊`、`一线江景`。
4. 避免单字孤行、标点位于行首、左边缘参差失控，以及关键词被切成两行。
5. 只有用户明确要求保留现有换行时才使用 `--keep-lines`；锁行不等于锁字号，字号与行距仍需按空间调整。

## 3. 按长度改变布局

字数档位只用于启动排版搜索，最终必须以实际字宽和可用区域为准。

- 极短标题（约 2–5 个汉字）：1 个主层级，显著放大，保留充足负空间；不为了复刻案例硬拆成两三行。
- 短标题（约 6–10 个汉字）：通常 1–2 行，可使用小前提＋大结论。
- 中标题（约 11–16 个汉字）：通常 2–3 行，建立一个主结论和一到两个辅助层级。
- 长标题（约 17–24 个汉字）：通常 3–5 行，同时扩展文字区、收紧行距或移动第二证据卡；不得只整体缩小。
- 超长标题（24 字以上）：优先使用更宽的文字区、分区排版或开放版。若任何核心模板都无法保持缩略图可读，应明确失败并改用开放布局，而不是输出密集小字。

## 4. 自动层级与分行评分

排版时同时比较多个候选行数与断句方案，按以下顺序选择：

1. 全文是否完整且只出现一次；
2. 最小字号是否满足手机缩略图阅读；
3. 高亮词、数字单位和语义短语是否完整；
4. 各行宽度是否均衡，有无单字孤行和标点行首；
5. 主结论是否形成最大字号，其他行是否退为辅助层级；
6. 文字与人脸、房屋证据、边缘安全区是否冲突；
7. 在以上条件相近时，优先采用用户提供的软语义断句。

没有显式高亮词时，优先把结论行或最后一个完整短语设为主层级；有 `--highlight` 时，包含最重要高亮词的行优先成为主层级。

## 5. 容器与画布联动评分

文字方案确定后不能直接绘制，还要比较多组容器和画布候选：

1. 文字四周是否有稳定内边距，既不碰边也不形成大面积无意义空洞；
2. 卡片宽高是否与文字块密度匹配，而不是沿用案例外框；
3. 卡片扩张后是否仍保留足够的房屋、人物或景观证据；
4. 第二证据卡是否与文字重叠，必要时应缩小、下移、上移或进入主图区；
5. 短标题优先选择更紧凑容器和更大主图，长标题优先选择更宽/更高容器与新的证据位置；
6. 如果容器扩张会破坏主体证据，就换用更合适的核心模板或开放版，不无限压缩文字与图片。

脚本输出中的 `text_box`、`container_box` 和 `evidence_box` 用于核对这三层是否随内容共同改变。

## 6. 各核心模板的响应方式

- A｜香槟金编辑感、C｜深蓝电影感：标题可在上下两个阅读区重新分配。极短标题可只占下区；长标题允许上下各 1–3 行。
- B｜江景画册感：先排文字，再选择能提供舒适内边距的最小浅色标题卡；短、中、长标题使用不同卡高，第二证据随卡片下移或缩小。
- D｜米白楼书感：根据下部文字块密度选择米白区高度；窄文字列拥挤时，第二证据卡移入图片区并把文字区扩为全宽。
- E｜侧栏分割：在缩略图可读与主体可见之间选择最窄可用侧栏；短标题收窄，长标题才逐步扩宽。
- F｜画册窗景：从下部文字块所需高度反推图片窗高度；短标题让大图更高，长标题扩大下部文字区。
- G｜证据卡片：先比较窄标题列与全宽标题区；长标题若在窄列中碎裂或过密，第二证据卡移入上部主图。

## 7. 命令与核验

默认自适应：

```powershell
python scripts/render_real_estate_cover.py <主图> <输出PNG> --template F --line "真正稀缺的不是180㎡是每一间都能看江" --highlight "180㎡" --highlight "每一间都能看江"
```

多个语义块仍允许重排：

```powershell
python scripts/render_real_estate_cover.py <主图> <输出PNG> --template A --line "真正稀缺的" --line "不是180㎡" --line "是每一间都能看江"
```

仅在明确要求时锁定换行：

```powershell
python scripts/render_real_estate_cover.py <主图> <输出PNG> --template A --line "真正稀缺的" --line "不是180㎡" --line "是每一间，都能看江" --keep-lines
```

脚本会输出实际采用的每行文字与字号，以及文字区、外层容器和第二证据坐标。交付前必须核对：原文与渲染文字去除空白后完全相同；文字、卡片、主图和证据之间无溢出、碰撞或失衡；并以缩略图检查主标题仍可一眼读出。
