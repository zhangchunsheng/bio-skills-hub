# A–G 房产封面核心模板目录

A–G 是经过用户确认、可以点名调用的稳定核心模板族，不是固定坐标截图，也不是全部版式或创意上限。案例图来自同一测试项目，只用于展示不同构图结构；模板名称、适配条件和结构可以复用，人物、江景、标题、面积和房源细节不可复用。每次调用都按 [响应式文字排版](responsive-typography.md) 重新计算分行、字号、层级、留白和文字区尺寸。

需要让顾客选择时，优先展示 [核心模板总览图](../assets/template-catalog.jpg)。顾客希望放大查看时，再展示对应单张案例。

## A｜香槟金编辑感

案例：`assets/cases/A-香槟金编辑感.png`

- 结构：全幅人物或场景，标题分布在上下两个阅读区，香槟金只强调数字或结论。
- 适合：强人物、强观点、改善型房源、稀缺卖点、身份感讲解。
- 素材：一张清晰人物/主体帧，顶部和底部有可用文字空间。
- 自动选择：人物表现力强，主标题可以拆成前提与结论时优先。

## B｜江景画册感

案例：`assets/cases/B-江景画册感.png`

- 结构：房屋、景观或城市证据为全幅主图，上方大面积浅色信息卡，右下叠加人物或第二证据小卡。
- 适合：景观、地段、社区环境、城市资源、多个证据共同出现。
- 素材：一张强场景主图，最好另有一张人物或细节图。
- 自动选择：场景证据明显强于人物，同时标题需要稳定浅色阅读区时优先。

## C｜深蓝电影感

案例：`assets/cases/C-深蓝电影感.png`

- 结构：全幅纪实人物/现场，深蓝局部压暗，标题上下分层，情绪和空间同时成立。
- 适合：实地看房、观点、反差、故事、稀缺体验或强手势讲解。
- 素材：一张有动作、方向或现场氛围的原始帧。
- 自动选择：素材具有纪实瞬间、侧身动作或明显环境纵深时优先。

## D｜米白楼书感

案例：`assets/cases/D-米白楼书感.png`

- 结构：上部大场景，下部米白信息区，人物或第二证据以小卡片跨越两个区域。
- 适合：高端改善、户型价值、景观体验、项目介绍、克制可信表达。
- 素材：一张场景主图，加一张人物或细节图效果最佳。
- 自动选择：需要楼书气质、留白和场景证据，但不适合强刺激排版时优先。

## E｜侧栏分割

案例：`assets/cases/E-侧栏分割.png`

- 结构：左侧深色标题栏，右侧人物或房源主图，中间使用细线或色带分隔。
- 适合：真人 IP、知识讲解、单一结论、文字稍长但仍需保留人物。
- 素材：主体位于画面右侧，或原图能安全裁出右侧人物/物体。
- 自动选择：人物在一侧、另一侧缺少天然文字空间，标题需要独立承载区时优先。

## F｜画册窗景

案例：`assets/cases/F-画册窗景.png`

- 结构：上部一张圆角大图，下部大面积浅色排版区，装饰极少。
- 适合：房屋空间、窗景、建筑、家居、人物与环境兼顾的高级表达。
- 素材：一张完成度高、单独就能说明主题的主图。
- 自动选择：只有一张强图，或希望画面安静、清楚、通用时优先。

## G｜证据卡片

案例：`assets/cases/G-证据卡片.png`

- 结构：大面积主证据图，深色标题区，叠加人物或第二证据小卡。
- 适合：景观、户型、数据、现场问题、对比结果、产品证据优先内容。
- 素材：一张必须被看清的证据图，最好另有一张人物/细节图。
- 自动选择：标题承诺需要画面直接证明，证据比人物情绪更重要时优先。

## 与开放扩展层的关系

自动选型不是只在七个模板中轮换：

1. 先判断最可信证据是人物、单场景、多证据、户型、地图、数据、前后对比还是纯文字。
2. 找到最适配的 A–G 候选，同时按 [开放扩展系统](open-extension-system.md)形成至少一个自定义设计向量。
3. 如果核心模板的裁切安全、标题可读和气质都合适，可以直接调用；如果会隐藏证据、硬塞人物、牺牲留白或限制表达，则改用开放版。
4. 用户指定 A–G 时，指定选择始终优先。
5. 用户说“其他版、还有别的版、不限于 A–G”时，必须使用开放层，不把换色当成新模板。

开放版未经用户确认不占用字母编号；被用户明确认可并要求长期固定后，才升级为新的核心模板。
