# 房产短视频封面：A–G 核心＋开放扩展

生成 1200×1600 PNG 房产短视频封面。A–G 是经过用户确认、可直接点名调用的核心模板，不是全部版式，也不是创意上限。没有指定模板时，让本次内容、证据和素材决定使用核心模板还是开放创意版。

## 两层模板系统

### 核心模板库

- **A｜香槟金编辑感**
- **B｜江景画册感**
- **C｜深蓝电影感**
- **D｜米白楼书感**
- **E｜侧栏分割**
- **F｜画册窗景**
- **G｜证据卡片**

A–G 固定的是构图拓扑、信息层级、配色气质和图文关系，不固定案例标题的行数、字号、卡片尺寸或坐标。需要展示、比较、选择或调用 A–G 时，读取 [核心模板目录](references/template-catalog.md) 和 [响应式构图与排版](references/responsive-typography.md)，展示 `assets/template-catalog.jpg` 或对应案例图。案例只用于选型，不能成为新作品的人物、房源或生图素材。

### 开放扩展层

开放层从用户此前 8 组样片及新增参考中提炼高层视觉规律，再按本次房源重组点击动机、证据主体、构图、字体、配色、密度、图形语言和情绪强度。它包括但不限于已有谱系，不要求套入 A–G，也不预设模板数量上限。

出现以下任一情况时，读取 [开放扩展系统](references/open-extension-system.md)：

- 用户说“其他版、还有别的版、不限于 A–G、开放创意、重新设计”；
- 当前证据、标题长度或素材关系不适合任何核心模板；
- 多版输出需要形成真正不同的视觉方向；
- 新样片需要临时提炼视觉 DNA；
- 纯场景、户型图、地图、数据、前后对比、纯字体或其他特殊证据需要自定义构图。

开始任何制作前都读取 [生产与隔离规则](references/production-rules.md)。

## 调用与选型

1. 用户明确选择 A–G 的字母或中文名称时，严格调用对应核心模板；除非素材无法承载，否则不擅自换版。
2. 用户明确要求开放版、新版式或 A–G 之外的方向时，不把 A–G 换色冒充新设计，必须从开放设计向量重新构图。
3. 用户未指定模板时，内部同时评估“最适配的核心模板”和“至少一个开放设计向量”，按一秒理解、证据可信、缩略图可读、素材适配和高级感选择更强者，不强制优先 A–G。
4. 用户要求多版但未指定数量时，默认交付 4 张；至少包含 1 张开放版，并保证各版在构图拓扑、主体比例、信息密度或视觉气质中的至少两项不同。
5. 用户说“还有别的版”时，优先交付尚未展示过的开放版，不重复 A–G 或仅改颜色。
6. 开放版以 `开放版｜中文类型名` 标注，例如“开放版｜户型诊断”“开放版｜全景纪实”。未经用户明确确认，不自动把它编号为 H、I、J 或写入核心模板库。
7. 用户确认某个开放版需要长期固定时，才将它升级为新核心模板并重新打包 Skill。

## 输入路由

文字端分两种：

- 从本次音视频的可靠转写中提炼主题与标题；
- 使用用户本次提供的主题或必须逐字保留的标题。

画面端分三种：

- 没有图片：生成原创、非具体楼盘的房产场景或图解；
- 用户提供图片：以当前图片为编辑底图或证据；
- 用户提供视频：围绕文案相关内容抽取并选择原始帧。

真人 IP 是叠加层：只要用户要求“本人、还是原来的人、脸不能变”，人物必须来自本次原照片或视频帧像素，不能让生成模型重绘脸。

## 制作流程

1. 为本次项目重建素材清单：主题、逐字文案、音视频、图片、人物、已核实事实、模板偏好和数量。旧项目默认全部排除。
2. 确定唯一点击理由和唯一证据主体。用户指定标题时逐字保留；否则从本次内容提炼可信标题。
3. 用户指定 A–G 时按核心目录执行；未指定时比较核心模板与开放设计向量；用户要求其他版时直接进入开放层。
4. 核心模板使用确定性工具：

   ```powershell
   python scripts/render_real_estate_cover.py <主图> <输出PNG> --template A --line "完整标题，可只传一行" --highlight "关键词"
   ```

   默认把多个 `--line` 视为语义断句提示。排版器必须让字形、文字块、承载卡片和整张画面四层联动：重新分行与字号后，同时重算内边距、卡片宽高/位置、主图占比和第二证据位置；只有用户明确要求锁定换行时才加 `--keep-lines`。B、D、G 有第二证据或人物时增加 `--secondary <图片>`。
5. 开放版先形成至少 3 个在两个以上维度不同的内部方向，再选择最强方向执行。真实房源图或真人 IP 优先使用原像素本地排版；无可用画面或允许原创时可调用内置图像生成。生成式结果使用 `scripts/normalize_cover.py` 规范为 1200×1600 PNG。
6. 检查标题、数字、单位、标点、事实、人物身份、房屋证据、缩略图可读性、安全区、原创性和输出尺寸；失败时优先重做结构，而不是只换颜色。
7. 输出到当前项目的 `output/real-estate-covers/`，新建文件，不覆盖旧作品。

## 不可妥协的边界

- 只学习样片的高层视觉语法，不复制任何样片的人物、姿势组合、服装、背景布置、文案、字体字形、品牌、Logo、包装、受保护角色或完整布局。
- 样片截图与 A–G 案例图都是风格/选型参考，不是编辑底图，不传给生图工具。
- 每个新房源独立处理。除非用户明确说“沿用”并点名具体项目，否则不复用旧人物、旧房源、旧文案、旧数字、旧帧、旧中间图或旧输出。
- 不虚构价格、面积、区域、成交、学校、政策、稀缺性、排名、收益或官方背书。
- 不添加 Logo、水印、二维码、平台界面、账号名、播放按钮或无关品牌。
- 真人一致性高于生成式美化；出现变脸立即回到原始照片或原始视频帧。
- “高级感”来自主体比例、留白、局部对比、字体层级和克制装饰，不等同于压黑、金色、粗描边或惊讶脸。
- 不把案例图的行数、卡片尺寸和坐标当作占位框。短标题应收紧卡片并扩大主图，中标题建立 2–3 级层次，长标题应扩展或移动卡片、调整主图/证据占比；不得只把全部文字等比缩小塞进旧版式。
- 最终交付为单张满画幅 3:4 封面，不是手机截图、搜索页或九宫格。

## 交付说明

最终回复直接展示成品并附绝对路径，简短注明 `A–G 字母＋中文名称` 或 `开放版＋中文类型名`。不要把内部候选和分析过程堆给用户。
