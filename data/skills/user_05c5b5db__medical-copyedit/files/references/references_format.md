# 参考文献著录规则（GB/T 7714-2025）

> 现行标准：GB/T 7714-2025 于 2026-07-01 实施，全部代替 GB/T 7714-2015。本文件整理常见著录要点供初筛参考；具体条款（如分隔符、DOI、电子资源格式）以全国信息与文献标准化技术委员会发布的官方文本为准。

医学期刊普遍采用**顺序编码制**：参考文献按在正文中出现的先后次序用阿拉伯数字连续编码，序号用方括号"[1]"；文后参考文献表按序号排列。

## 一、著录总则

- 正文引用：用上标或正文内 `[1]`；同一处引用多篇用 `[1-3]` 或 `[1,3,5]`。
- 文后列表：按序号排列，序号顶格或悬挂缩进。
- 每条文献的要素、标点、顺序须严格一致。
- 责任者（作者）超过 3 人：列前 3 人，后加"，等"（中文）或"， et al"（外文）；3 人以内全列。
- 外文作者：姓前名后，姓全拼（首字母大写或全大写视刊），名用缩写字母（不加点或加点按刊）；如 `Smith J`、`Wang YL`。
- 期刊名：用全称；若用规范缩写，须可被检索且全文一致（多数中文医学刊要求全称）。

## 二、各类型文献格式

### 1. 期刊文章（最常用）
```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页.
```
示例：
```
[1] 张明, 李华, 王强, 等. 某药治疗高血压的随机对照研究[J]. 中华内科杂志, 2023, 62(5): 421-428.
[2] Smith J, Lee K, Brown T, et al. Title of article[J]. J Clin Invest, 2022, 132(3): 1123-1135.
```
注意：卷(期)中括号用圆括号；页码用半字线"-"连接（非浪纹线）；起止页完整写出（`421-428` 非 `421-8`）。

### 2. 专著
```
[序号] 作者. 书名[M]. 出版地: 出版者, 出版年: 引文页码.
```

### 3. 专著中的析出文献
```
[序号] 析出作者. 析出题名[M]// 专著作者. 书名. 版次. 出版地: 出版者, 出版年: 页码.
```

### 4. 学位论文
```
[序号] 作者. 题名[D]. 培养地: 培养单位, 年.
```

### 5. 会议论文
```
[序号] 作者. 题名[C]// 会议名. 出版地: 出版者, 年: 页码.
```

### 6. 报告
```
[序号] 作者. 题名[R]. 出版地: 出版者, 年.
```

### 7. 标准
```
[序号] 标准发布者. 标准名称: 标准编号[S]. 出版地: 出版者, 年.
```

### 8. 专利
```
[序号] 专利申请者. 专利题名: 专利号[P]. 公告日期或公开日期.
```

### 9. 电子资源
```
[序号] 作者. 题名[EB/OL]. (发布日期) [引用日期]. 获取和访问路径. DOI.
```

## 三、常见著录错误（审校重点）

- 缺文献类型标志（[J]/[M] 等）。
- 作者项：超过 3 人未用"等/et al"；外文作者名未缩写或大小写混乱。
- 刊名：用了不规范缩写、中英文刊名混写。
- 年卷期页不全：缺卷或期；页码用"421-8"漏写百位。
- 标点：用了中文句号"。"代替英文点号"."；或相反。顺序编码制通常用"."分隔各要素。
- 范围号：页码间用"-"（半字线），勿用"~"。
- 重复文献：同一文献多次出现应合并为同一序号，正文多处引用同一文献用同一编号。
- 正文引用序号与文后列表不对应、缺号、跳号。
- DOI 著录：建议补充 `DOI: 10.xxxx/xxxxx`（若期刊要求）。
- 内部资料、未公开发表会议摘要、私人通信：一般不得列入参考文献，必要时在正文脚注说明。

## 四、核对方法

1. 逐条核对正文引用序号与文后列表一一对应、连续无缺。
2. 每条按上述格式要素查缺。
3. 用 `scripts/check_manuscript.py --check references` 做格式初筛（**仅**初筛文献类型标志缺失、页码范围误用「～」；作者数、标点一致性、要素齐备性等为人工核对项）。
