# 医学术语规范化对照

依据全国科学技术名词审定委员会（原全国自然科学名词审定委员会）公布的规范名词，以及医学界通用约定。编辑加工时按"规范名优先、全文一致"原则处理。本表列出医学稿件中最常见的"非规范/旧名 → 规范名"对照，供自动审校脚本 `scripts/check_manuscript.py` 直接引用。

> 结构化同步：本表词条已外置为 `scripts/rules/terms.json`（每条带 rule_id、severity、exception_after、example/counter_example），脚本以该 JSON 为唯一真源，二者同步维护。新增/修改术语请编辑 JSON，本表作人读参考。

> 自定义词典（`--dict`）：格式为 `{"非规范": "规范"}`，**方向必须为「非规范词 → 规范词」**。脚本会做方向性校验：① 键==值（无替换意义）或 ② 键已是本技能认定的规范词（出现在内置术语 suggestion 中）的条目会被跳过并给出告警，避免把规范文本反当成非规范误报。正确方向的词条会生成 `CUSTOM-` 规则并入审校。

## 四、使用原则

1. **规范优先**：有全国审定委员会规范名词的，采用规范名。
2. **新旧并存可保留但须统一**：如" aortic 瓣"——"主动脉瓣"，全文只出现一种。
3. **约定俗成可保留**：如"SARS""HIV""CT""MRI"等缩写，以及"早搏"在部分期刊可作通用名，但同一刊物内须统一。
4. **不强行替换导致歧义**：若旧名在特定语境有特指（如"风湿性心脏病"≠"类风湿关节炎"），不得误改。
5. **缩略语管理**：正文首次出现应写全称（英文全称，缩略语），如"聚合酶链反应（polymerase chain reaction，PCR）"，后文可用 PCR。

> 自动审校脚本以 `scripts/rules/terms.json` 为默认词典真源，用户可在调用时通过 `--dict` 自定义补充/覆盖词条（见 SKILL.md 脚本用法）。
