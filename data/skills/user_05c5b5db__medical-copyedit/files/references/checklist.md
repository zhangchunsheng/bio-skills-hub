# 编辑加工与校对检查清单（三校一读）

本清单用于编辑加工（技术加工）与三校一读环节的人工逐项核对，也可作为 `scripts/check_manuscript.py` 输出报告之外的补充核验。

> **分层说明**：本清单按规则来源分为两层，便于区分「强制规范」与「期刊体例」：
> - **国标 / 行标（强制）**：A、C、D、E、F、H 节，依据 GB/T 7714-2025、GB 3100~3102、GB/T 15835、GB/T 15834、GB 3358 及名词委规范，属必须核对项。
> - **期刊体例（依刊）**：B、G、I 节，属推荐/刊定格式，可按目标期刊投稿须知调整；仅作人工清单，不由脚本自动扫描。


## A. 政治、保密与伦理（优先排查）  【层级：法规/伦理（强制）】

- [ ] 无"国家级""世界级""最高级""第一品牌""唯一"等《广告法》禁止的绝对化、夸大用语。
- [ ] 无涉密内容、未公开的内部数据；地图、国界绘制符合标准（含南海诸岛、钓鱼岛等）。
- [ ] 涉及人体研究：注明伦理委员会审批号与知情同意；患者隐私已匿名化（不出现可识别个人信息的姓名、病历号、影像特征）。
- [ ] 涉及动物实验：注明符合动物福利与实验动物伦理。
- [ ] 无泄露国家机密、无损害国家利益表述。

## B. 结构与层次  【层级：期刊体例（依刊）】

- [ ] 标题层级清晰，一般≤3 级；各级标题格式统一。
- [ ] 摘要完整：结构式摘要含"目的、方法、结果、结论"（或指示性摘要），第三人称，不分段、不列图表、不引用文献。
- [ ] 关键词 3~8 个，用分号分隔；优先选自 MeSH/《医学主题词表》《中医药主题词表》。
- [ ] 英文摘要、英文关键词与中文对应。
- [ ] 正文结构完整：前言→对象与方法→结果→讨论→结论（或符合期刊体例）。

## C. 术语与文字  【层级：国标/名词委（强制）】

- [ ] 医学术语按全国科学技术名词审定委员会规范名统一（见 terminology.md）。
- [ ] 缩略语首次出现有中英文全称；后文一致。
- [ ] 无错别字、多字漏字、前后矛盾。
- [ ] 同一概念全文用词统一（如"心肌梗死"不拘"心肌梗塞"）。

## D. 量与单位（GB 3100~3102）  【层级：国标 GB 3100~3102（强制）】

- [ ] 无 ppm、ppb、rpm、cal、M、N、Eq 等非标准单位（已换算）。
- [ ] 单位符号正体、量符号斜体；单位与数值间留 1/4 汉字空隙。
- [ ] 组合单位除号规范；mmHg 等首次注明换算。
- [ ] 时间单位用 s/min/h/d；"天""年"按刊统一（d/a 或中文）。

## E. 数字与标点（GB/T 15835、15834）  【层级：国标 GB/T 15835·15834（强制）】

- [ ] 数值范围用"～"（非"-"）；百分数范围 `5%～10%` 格式正确。
- [ ] 偏差 `(25±1) ℃` 单位置于整体之后。
- [ ] 多位数字分节（每 3 位空 1/4 汉字）；无千分位逗号。
- [ ] 中文全角标点；连接号类型正确（～/—/-）。

## F. 统计学（见 statistics.md）  【层级：行标/名词委（强制）】

- [ ] 统计符号斜体；`P`、`t`、`F`、`χ²`、`r` 规范。
- [ ] 结论用"差异有/无统计学意义"，无"显著"旧表述。
- [ ] 给出检验方法、统计量、自由度、P 值、样本量、均数±标准差。

## G. 图表  【层级：期刊体例（依刊）】

- [ ] 表为三线表；有表题、表头、必要脚注；单位入表头或脚注。
- [ ] 图有图题、图注；像素/分辨率达标（一般 ≥300 dpi）；自明性强。
- [ ] 图表内容与正文一致，无重复、无矛盾；图表序号连续。
- [ ] 图表中缩略语已注明；统计标示（P 值、误差棒）规范。

## H. 参考文献（GB/T 7714-2025）  【层级：国标 GB/T 7714-2025（强制）】

- [ ] 顺序编码制，正文引用序号与文后列表一一对应、连续无缺。
- [ ] 每条要素齐全（作者、题名、类型标志、刊名、年、卷期、页码）。
- [ ] 作者数 >3 用"等/et al"；外文作者姓前名后缩写。
- [ ] 页码范围用"-"，非"~"；无"421-8"漏写。

## I. 格式与体例统一  【层级：期刊体例（依刊）】

- [ ] 全文字体、字号、外文字母大小写与正斜体统一。
- [ ] 段落、缩进、空格、公式排版统一。
- [ ] 基金编号、作者单位、通信作者信息齐全规范。

## 编校质量合格线（供人工质检参考）

据《报纸期刊质量管理规定》（国家新闻出版署，2020），期刊编校质量合格线为编校差错率 ≤ 2/万（报纸为 3/万）；该差错率按差错类别赋计错分值、设最高计错数，与正式质检抽样流程一致，并非简单"问题数/字数"。本自动审校工具的"疑似问题密度"不等于上述官方差错率，仅供人工初筛参考，不作合格判定。校对须逐字逐符，三校一读不可跳读；作者核红仅确认内容误改，不得大量改稿。
