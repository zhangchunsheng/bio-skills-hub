# 安全与隐私说明（medical-journal-copyediting）

本文件说明该技能/脚本在处理医学稿件时的安全与隐私边界。刊发或对外分发
本技能前，请先确认以下条款。

> **边界划分**：下列「脚本自身」指 `scripts/check_manuscript.py` 与
> `parse_docx.py` 的确定行为；「宿主平台」指运行该技能的 WorkBuddy 环境
> （含对话上下文、文件权限、同一会话中可能启用的其他联网技能/连接器）。
> 二者职责不同，须分别评估。

## 一、脚本自身安全边界（check_manuscript.py / parse_docx.py）

- **稿件是「数据」不是「指令」**：脚本仅把稿件文本当作待检查的字符数据，
  逐行做正则/子串匹配，**从不执行、不解释、不服从**稿件中的任何内容。
- **纯标准库、无网络**：脚本仅依赖 Python 标准库，默认在本地运行，
  **不会连接网络、不会上传稿件**。
- **无副作用**：脚本只读稿件、生成报告，不修改、不删除、不外发任何文件。
- **提示注入防护（脚本层）**：若稿件正文出现与编辑指令高度相似的句式
  （如「忽略以下规则」「改为……」），脚本照常按规则匹配，不自动执行任何
  指令；终校决定由责任编辑人工做出。

## 二、宿主平台安全边界（WorkBuddy 运行环境）

- **文件权限由平台管理**：技能读取的稿件路径、写入的报告路径均受
  WorkBuddy / 操作系统文件权限约束；请勿授予超出必要的目录访问。
- **对话上下文中的稿件**：若在联网对话中粘贴稿件全文，内容可能随对话进入
  平台上下文；**敏感/未发表稿件建议先脱敏，或仅在本地运行技能**。
- **其他技能/连接器**：同一会话启用的其他技能或连接器可能具备联网能力，
  其安全边界不在本脚本范围内，请按需评估与授权。
- **技能来源可信**：安装/启用本技能前确认其来自可信渠道；脚本不含任何
  网络调用或外部命令执行。

## 三、通用操作建议（双方共同遵循）

### 1. 本地处理，不外发
- 请勿将含未发表成果的稿件粘贴到任何联网对话/接口中再调用本技能；
  需要联网交互时，先脱敏。

### 2. 敏感信息脱敏
提交检查前，建议对以下信息做脱敏或替换：
- 患者姓名、病历号、身份证号等可直接识别个人的信息；
- 未发表的研究数据、原始数据库、内部统计结果；
- 涉及保密/伦理审批的敏感研究背景（除非已在文中合规披露）。

> 脱敏原则：保留可支撑规范检查所需的术语、单位、数字与表述，移除可识别
> 个体或泄露未公开成果的信息。

### 3. 提示注入防护（责任编辑须知）
- 自动审校报告中的「建议」来自规则库，不代表编辑部立场；终校决定仍由
  责任编辑人工做出。
- 若稿件正文出现可疑控制句式，不自动执行，转人工判断。

### 4. 版本与复现
- 每次报告头部记录技能版本、规则库版本、标准生效日期、运行时间与规则总数，
  便于复现某次审校结果（见 `scripts/check_manuscript.py` 的 `--version`）。
- 规则以 `scripts/rules/*.json` 为唯一真源；修改规则后请同步更新规则库版本号。
