# 数据 JSON 格式（data_schema.md）

`scripts/generate_report.py` 读取如下结构的 JSON，输出单文件 HTML 晨报。

## 顶层字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `report_date` | 否 | `YYYY-MM-DD`，晨报日期（也用于标题与文件名）。缺省取今天。 |
| `title` | 否 | 大标题，默认「临床药学 / 医院药学 晨报」。 |
| `kicker` | 否 | 标题上方小字，默认「临床药学 / 医院药学 · 晨报」。 |
| `source_note` | 否 | 文末数据源说明，缺省为通用口径。 |
| `sections` | 是 | 版块数组，**顺序即渲染顺序**，全局编号按出现顺序连续累加。 |

## 版块（section）两种模型

### A. 平铺版块（flat）

```json
{
  "label": "模型发布/更新",
  "items": [
    {
      "title": "卡片标题",
      "summary": "不超过60字的中文摘要，超出会被脚本截断加省略号。",
      "source": "来源 chip，如 国家卫健委 / 新华网",
      "link": "https://真实原文URL",
      "date": "2026年7月8日"
    }
  ]
}
```

- `items` 为空数组 `[]` 时，渲染「本期暂无相关内容」空态（仍计入版块与导航）。
- `date` 用北京时间人话，可带「（入库）」等后缀，不要写 ISO。

### B. 分组版块（grouped）—— 用于「药事相关专栏」

```json
{
  "label": "药事相关专栏（全国·广东·广州）",
  "groups": [
    ["全国",   [ { "title":..., "summary":..., "source":..., "link":..., "date":... } ]],
    ["广东省", [ ... ]],
    ["广州市", [ ... ]]
  ]
}
```

- `groups` 是「分组名 + 条目数组」的列表；生成器在版块内按分组渲染子标题与计数。

## 条目（item）字段约束

| 字段 | 说明 | 约束 |
|---|---|---|
| `title` | 卡片标题 | 必填；会作为跳转链接文本 |
| `summary` | 摘要 | 必填；脚本保证 ≤60 中文字（超长截断 +「…」） |
| `source` | 来源 chip | 必填；短文本 |
| `link` | 原文 URL | 必填；所有外链自动加 `target="_blank" rel="noopener noreferrer"` |
| `date` | 日期 | 必填；北京时间人话字符串 |

## 校验清单（生成后人工/脚本复核）

- 卡片总数 == 全局编号最大值（#1–#N 连续无跳）。
- 每个 `summary` 的 `len <= 60`。
- 正文 HTML 不含 `YYYY-MM-DD` 这类 ISO 串（日期字段本身是字符串，不会触发）。
- 每个 `link` 对应的 `target`/`rel` 正确。
- 单文件、无 `http(s)://...` 外部 `src`/`href` 引用（除原文跳转链接外）。
