# 临床药学 / 医院药学 晨报生成器

## 作品描述

本技能把**临床药学 / 医院药学**领域近期真实资讯，汇编成一份**单文件 HTML 晨报仪表盘**，
可直接在浏览器打开、可部署到云端生成二维码用微信分享给同事。

产物特征（硬性要求，已内置在生成器，无需每次重述）：

- **单文件**：HTML + 内联 CSS/JS，**零外部资源**，可离线打开、可整页部署。
- **响应式**：PC 多列卡片网格，移动端单列；顶部导航 sticky 锚点。
- **固定版块**（默认 6 个，顺序固定）：模型发布/更新、产品发布/更新、行业动态、
  论文研究、技巧与观点、药事相关专栏（全国·广东·广州，按地理三级分组）。
- **全局连续编号**：跨所有版块 #1、#2… 不重置。
- **每张卡片**：全局序号、标题、来源 chip、≤60 字中文摘要（超出自动截断加「…」）、
  「阅读原文 ↗」跳转。
- **时间格式**：一律北京时间人话（如「2026年8月15日 星期六」），**正文不出现 ISO 字符串**。
- **外链规范**：所有原文跳转 `target="_blank" rel="noopener noreferrer"`。
- **文末**：标注总条数、版块数、数据源与核对提示。

> ⚠️ 内容性质：这是「近期真实资讯汇编」，不是 AI HOT 那种通用 AI 日报。
> 数据需来自**联网真实检索 + ima 医学知识库**（见 references/sources.md），
> 政策/数据务必以官方原文核对，不要编造出处或日期。

## 如何触发技能

满足以下任一情形即调用本技能：

- 用户说「帮我生成一份**临床药学 / 医院药学 晨报**」「出个**药学日报**」「**药师早报**」
- 用户要「**药学资讯仪表盘**」「**医院药学动态**汇总页」「把近期药学资讯做成单页」
- 用户已经有一份 PDF/Word/文本的药学资讯，要「整理成**可分享的晨报网页**」
- 用户想「把这份晨报**发微信给同事**」——本技能产出单文件 HTML，配合云端部署+二维码即可分享
  （部署与二维码不在本技能内，提示用户用 cloudstudio-deploy + qrcode 即可）

**不要在以下情形调用**：用户只要通用 AI 资讯（那是 AI HOT）；用户要的是 Word/PDF 正式报告而非网页仪表盘。

## 工作流

### 1. 确定内容范围与日期

- 与用户确认：晨报日期（默认今天，格式 `YYYY-MM-DD`）、是否需要「药事相关专栏」、是否要发布分享。
- 若用户只是要网页、没指定内容来源，默认采用 **混合方案**（见 references/sources.md）：
  行业动态/论文研究/模型/产品 → 联网真实检索；技巧与观点 → 混合 ima 医学知识库 holdings + 联网经验文。

### 2. 采集真实内容（references/sources.md 给出具体检索式与知识库 id）

- 用 `WebSearch`（freshness: y1）检索全国/省/市三级药事与临床药学动态，保留真实 URL 与日期。
- 用 `ima-mcp` 的 `search_knowledge`（知识库 id `001a71ea38401475`）抽取用药经验/科普类条目填充「技巧与观点」。
  - ima 条目无对外深链，卡片链接统一跳 `https://ima.qq.com`，来源 chip 标「ima 医学知识库」。
- 摘要写 **≤60 字**，日期转北京时间人话（如「2026年7月8日」或「2026年（入库）」）。

### 3. 组装数据 JSON（严格按 references/data_schema.md）

- 把采集结果写成 JSON：平铺版块用 `{"label":..., "items":[...]}`；
  药事专栏用 `{"label":..., "groups":[["全国",[...]],["广东省",[...]],["广州市",[...]]]}`。
- 空版块也要保留 `label` + 空 `items:[]`，生成器会渲染空态。

### 4. 生成 HTML

运行数据驱动生成器：

```bash
python scripts/generate_report.py data.json -o 临床药学日报_YYYY-MM-DD.html
```

- 不传 `-o` 时默认输出 `临床药学日报_<report_date>.html`。
- 校验：卡片数 = 全局编号数；所有摘要 len ≤ 60；正文无 `YYYY-MM-DD` ISO 串；
  所有外链含 `rel="noopener noreferrer"`。

### 5. 分享（可选，不在本技能内）

- 单文件 HTML → 复制到部署目录 → `cloudstudio-deploy` 部署 → 生成二维码 PNG（qrcode[pil]）发微信。
- 或导出腾讯文档（需连接「腾讯文档」）。

## 复用要点

- 换日期 / 换内容，只需改 JSON，重跑生成器即可；模板与编号逻辑已固化在脚本。
- 版块数量可变：生成器按 `sections` 数组长度自适应彩色圆点与编号，不限于 6 个。
- 摘要截断、人话日期、noopener 均由脚本保证，不要让模型在组装 JSON 时手动做这些。
