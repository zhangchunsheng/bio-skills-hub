# 制剂理论基础参考 (Pharmaceutical Theory Reference)

## 1. 相似相溶与介电常数理论

### 溶解度参数 (Hildebrand / Hansen Solubility Parameter)

- **Hildebrand 参数 δ**: δ = (ΔH_v − RT)^0.5 / V_m^0.5，单位 MPa^0.5 或 (cal/cm³)^0.5
- **Hansen 三参数**: δ² = δ_d² + δ_p² + δ_h²（色散力 / 极性 / 氢键组分）
- **相似判据**: |δ_溶剂 − δ_溶质| < 2 MPa^0.5 为良好溶解（Green 区域），> 7 MPa^0.5 通常不溶

### 介电常数 ε

- 溶剂的极性直接影响 API 溶解度: ε 越高，越有利于离子型/极性化合物溶解
- 辅料选择时，ε 接近 API 的辅料往往增溶效果更好

### 应用
- 预测替代辅料对主药增溶能力的变化
- 指导潜溶剂的选择（如 PEG 400 + 水的 ε 混合值计算）

## 2. Fick 定律与扩散释放

### Fick 第一定律
J = −D · (dC / dx)

- J: 扩散通量 (mg·cm⁻²·s⁻¹)
- D: 扩散系数 (cm²·s⁻¹)
- dC/dx: 浓度梯度

### Fick 第二定律（非稳态扩散）
∂C/∂t = D · (∂²C/∂x²)

### 体外溶出扩散边界层模型
- Noyes-Whitney 方程的成熟形式:
  dM/dt = D · A · (C_s − C_t) / h
  - A: 有效表面积
  - C_s: 饱和溶解度
  - C_t: 时间 t 时的介质浓度
  - h: 扩散边界层厚度

### 当膨胀/溶蚀占主导时
用 Fick + 溶蚀混合模型（Peppas-Sahlin 或耦合扩散-溶蚀 PDE）。

## 3. Weibull 释放动力学

### 基本表达式
M_t / M_∞ = 1 − exp(−(t − t₀)^β / τ)

- **τ**: 尺度参数（63.2% 释放所需时间），直接反映释放快慢
- **β (形状参数)**:
  - β < 0.75: Fick 扩散（Higuchi-like）
  - 0.75 < β < 1.0: 混合扩散-溶蚀
  - β > 1.0: 溶蚀主导（Case-II transport）
  - β = 1.0: 一级动力学
- **t₀**: 时滞（迟滞时间），用于有迟滞释放的配方

### 在数字孪生中的应用
- 将多批次溶出数据统一参数化，每个配方表达为 (τ, β, t₀) 三元组
- 用 GPR 代理模型建立 CMA/CPP → (τ, β, t₀) 的映射

## 4. QbD 框架 (Quality by Design)

### 核心概念链
**CMA (关键物料属性)**  →  **CPP (关键工艺参数)**  →  **CQA (关键质量属性)**

### CMA 示例
| 物料属性 | 示例 | 影响 CQA |
| :--- | :--- | :--- |
| 粒径分布 D₅₀ | 10-100 μm | 溶出速度、混合均匀度 |
| 晶型 | 多晶型 I/II/III | 溶解度、稳定性 |
| LogP | 1-5 | 渗透性、载药量 |
| pKa | 2-10 | pH 依赖性溶出 |

### CPP 示例
| 工艺参数 | 影响机制 | 影响 CQA |
| :--- | :--- | :--- |
| 搅拌速度 | 扩散边界层厚度 | 溶出 T80 |
| 干燥温度 | 晶型转化风险 | 稳定性、溶出 |
| 混合时间 | 均匀度 | 含量均匀度 |

### 设计空间 (Design Space)
- 所有 CMA/CPP 联合变化的 n 维超空间中的区域
- 在该区域内操作可确保 CQAs 在预设规格范围内
- 表达: 概率性设计空间（p ≥ 0.9）

## 5. 溶出曲线模型速查表

### 常用数学模型

| 模型 | 方程 | 适用场景 |
| :--- | :--- | :--- |
| **零级** | M_t = k₀ · t | 骨架片、渗透泵 |
| **一级** | ln(M_∞ − M_t) = ln M_∞ − k₁t | 速释制剂 |
| **Higuchi** | M_t = k_H · t^0.5 | 基质扩散 |
| **Korsmeyer-Peppas** | M_t / M_∞ = k · t^n | 机制判断（Fick vs 溶蚀） |
| **Peppas-Sahlin** | M_t / M_∞ = k₁ · t^m + k₂ · t^{2m} | 扩散+溶蚀耦合 |
| **Weibull (推荐)** | M_t / M_∞ = 1 − exp(−(t − t₀)^β / τ) | 通用（推荐用于数字孪生参数化） |
| **Hixson-Crowell** | M₀^{1/3} − M_t^{1/3} = κ · t | 表面积随溶蚀减小的场景 |

### 拟合指标
- R² ≥ 0.95: 良好拟合（数字孪生代理可用）
- 0.85 ≤ R² < 0.95: 中等（标注不确定性）
- R² < 0.85: 不适合该模型，尝试替换

## 7. BCS 分类速查

| 类别 | 溶解度 | 渗透性 | 典型策略 |
| :--- | :--- | :--- | :--- |
| **I** | 高 | 高 | 常规方案 |
| **II** | 低 | 高 | 固体分散体/脂质递送/粒径减小 |
| **III** | 高 | 低 | 吸收增强/前药设计 |
| **IV** | 低 | 低 | 纳米递送/复合策略 |
