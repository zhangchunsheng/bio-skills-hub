# 图片识别规范——化验单与医嘱信息提取指南

## 概述

本文件定义了从检验检查图片、医嘱图片中提取数据的规范流程，包括需提取的字段清单、识别注意事项和数据结构化输出格式。

---

## 二、医嘱信息提取字段

### 1. 抗菌药物医嘱
| 字段名 | 说明 |
|--------|------|
| 药物名称 | 通用名（非商品名） |
| 剂量 | 单次剂量+单位（如1g、0.5g） |
| 频次 | qd/bid/tid/qid/q8h/q12h/q24h等 |
| 给药途径 | ivgtt（静脉滴注）/iv（静脉推注）/im（肌肉注射）/po（口服） |
| 起止时间 | 开始日期-结束日期 |
| 疗效评估 | 有效/无效/不确定 |

### 2. 合并用药
- 提取所有正在使用的药物，特别标注：
  - 可能与抗菌药物产生相互作用的药物
  - 肝毒性药物
  - 肾毒性药物
  - 抗凝/抗血小板药物
  - 抗癫痫药物（特别是丙戊酸钠——与碳青霉烯类禁忌）

### 3. 其他医嘱信息
- 输血史
- 引流管类型及留置时间
- 肾脏替代治疗（CRRT/IHD/PD）参数

## 三、图片识别注意事项

### 1. 数据准确性
- **单位识别**：必须准确识别检验项目的单位（如×10⁹/L vs ×10⁶/L，μmol/L vs mmol/L），单位错误可能导致严重误判
- **参考范围**：不同实验室参考范围可能不同，以图片显示的参考范围为准
- **异常标注**：识别↑（升高）和↓（降低）标注，如图片无标注，需根据参考范围判断

### 2. 完整性检查
- 如图片模糊、被遮挡或不完整，应明确告知用户哪些字段无法识别
- 如关键检验项目（如肝肾功能、血常规）缺失，应提醒用户补充
- 多张图片需分别识别后合并为统一的数据集

### 3. 常见识别难点
- **手写内容**：部分化验单可能含手写补充，需仔细辨认
- **缩写**：医学缩写需正确解读（如"ivd"="静脉滴注"，"qd"="每日一次"）
- **表格对齐**：检验项目、结果、参考范围可能列对齐偏差，需逐行确认
- **多页报告**：如为多页报告，需识别全部页面并合并

### 4. 数据确认流程
识别完成后，必须向用户展示结构化提取结果，请用户：
1. 确认识别是否准确
2. 补充缺失的关键数据
3. 纠正识别错误
4. 确认后方可用于会诊意见生成

## 五、常见检验图片类型与识别要点

### 1. 血常规报告
- 重点关注：WBC、NEU%、NEU、Hb、PLT
- 注意区分WBC单位（×10⁹/L）与腹水WBC单位（×10⁶/L）

### 2. 生化全套报告
- 通常含肝功能、肾功能、电解质、血糖等
- 注意TBIL与DBIL、IBIL的关系（TBIL = DBIL + IBIL）
- ALB降低需关注营养状态和肝功能

### 3. 凝血功能报告
- 重点关注PT、INR、APTT、D-Dimer
- 肝病患者PT延长常见

### 4. 腹水常规+生化报告
- **SBP诊断关键**：腹水多核细胞>250/mm³（即>250×10⁶/L）
- 李凡他试验阳性提示渗出液
- 腹水GLU降低、LDH升高提示细菌感染
- ADA升高提示结核性

### 5. 血气分析报告
- 关注pH、Lac（乳酸），评估组织灌注和酸碱平衡

### 6. 病原学报告
- 培养结果需区分定植vs感染
- 药敏结果需完整识别S/I/R对应药物
- mNGS结果需关注序列数和检出菌种

### 7. 医嘱单/用药记录
- 区分长期医嘱和临时医嘱
- 注意药物名称的通用名vs商品名
- 给药途径缩写：ivgtt=静脉滴注，iv=静脉注射，im=肌肉注射，po=口服
- 频次缩写：qd=每日一次，bid=每日两次，tid=每日三次，q8h=每8小时一次
