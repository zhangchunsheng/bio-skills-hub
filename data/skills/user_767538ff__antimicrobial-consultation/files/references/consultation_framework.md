# 特殊使用级抗菌药物会诊参考文档

## 一、政策法规依据

### 核心法规
2012年《抗菌药物临床应用管理办法》（卫生部令第84号）第二十七条：临床应用特殊使用级抗菌药物应当严格掌握用药指证，经抗菌药物管理工作组指定的专业技术人员会诊同意后，由具有相应处方权医师开具处方。

### 会诊人员资质
- **人员来源**：感染性疾病科、呼吸科、重症医学科、微生物检验科、药学部门等
- **医师资质**：具有高级专业技术职务任职资格
- **药师资质**：具有高级专业技术职务任职资格，或具有高级专业技术职务任职资格的抗菌药物专业临床药师
- **授权方式**：经抗菌药物管理工作组审核认定

### 会诊模式
医师填写会诊申请单，药师审阅病历后提出用药建议，属咨询模式（advisory model）。处方权归属具有相应权限的医师。

## 二、特殊使用级抗菌药物分类

| 药物类别 | 代表药物 | 主要特点与适用场景 |
|---------|---------|------------------|
| 碳青霉烯类 | 美罗培南、亚胺培南/西司他丁、比阿培南、厄他培南 | 广谱，覆盖G⁻菌（含产ESBLs/AmpC酶）、G⁺菌、厌氧菌；重症感染、多重耐药G⁻菌感染；厄他培南不覆盖铜绿 |
| 糖肽类 | 万古霉素、替考拉宁 | 覆盖G⁺菌含MRSA、MRSE、肠球菌；需注意肾毒性，万古霉素需TDM |
| 噁唑烷酮类 | 利奈唑胺、特地唑胺 | 覆盖G⁺菌含MRSA、VRE；组织穿透性好（肺、CSF）；长期使用需监测血小板和乳酸 |
| 多肽类 | 多粘菌素B、多粘菌素E（黏菌素） | 针对碳青霉烯耐药G⁻菌（CRAB、CRPA、CRE）的最后防线；需注意肾毒性和神经毒性 |
| 甘氨酰环类 | 替加环素 | 广谱覆盖G⁺、G⁻（不含铜绿）、厌氧菌及非典型病原；适用于cIAI、cSSTI、HAP/VAP；CRE感染联合用药 |
| 四代头孢 | 头孢吡肟 | 广谱覆盖G⁺和G⁻含铜绿假单胞菌；院内获得性感染、中性粒细胞减少伴发热 |
| 五代头孢 | 头孢洛林酯 | 覆盖MRSA及常见G⁻菌；适用于cSSTI、CAP |
| 新型酶抑制剂复合制剂 | 头孢他啶/阿维巴坦、美罗培南/法硼巴坦、亚胺培南/西司他丁/雷利巴坦 | 针对产KPC等碳青霉烯酶的CRE；头孢他啶/阿维巴坦对OXA-48也有活性 |
| 新型抗真菌药 | 伏立康唑、卡泊芬净、米卡芬净、艾沙康唑 | 侵袭性真菌感染；伏立康唑需TDM |
| 其他 | 达托霉素 | 覆盖G⁺菌含MRSA、VRE；不可用于肺炎（被肺表面活性物质灭活）；需监测CPK |

注：各医疗机构应根据本院《抗菌药物分级管理目录》确认具体药品的分级级别。

## 三、会诊工作流程

1. **接收会诊申请**：明确会诊目的和具体问题
2. **资料收集与评估**：查阅电子病历，收集基本信息、诊断、检验、病原学、影像、用药史、过敏史、合并用药
3. **床旁评估（必要时）**：生命体征、感染部位体征、与主管医师沟通
4. **形成会诊意见**：按规范格式书写
5. **随访与疗效评估**：跟踪治疗反应，评估降阶梯

---

## 四、书写框架：「为什么用 → 如何用 → 用后注意」

### 第一步：为什么用（用药分析）
- 感染诊断与严重程度评估
- 可能致病菌推断
- 耐药风险分析
- 用药指征确认
- 现用方案评估
- 药物选择循证依据

### 第二步：如何用（用药方案）
- 药物名称（通用名）
- 单次剂量 + 给药频次
- 给药途径
- 滴注时间
- 疗程建议
- 联合用药方案
- 特殊人群剂量调整
- 降阶梯策略

### 第三步：用后注意（用药监护）
- 疗效监测指标与节点
- 不良反应监测重点
- TDM建议（如适用）
- 药物相互作用提示
- 特殊注意事项
- 停药/转换指征
- 随访计划

---

## 五、书写基本原则

1. **循证性**：所有用药建议应有循证依据，标注证据来源
2. **个体化**：结合患者具体情况，避免"套模板"
3. **可操作性**：写明通用名、剂量、频次、途径、疗程
4. **完整性**：覆盖"怎么用""用多久""注意什么""何时停/换"
5. **清晰性**：结构清晰，关键建议突出显示
6. **协作性**：咨询模式，语气专业、平等

## 九、常见临床场景

1. **重症感染初始经验治疗**：脓毒症/脓毒症休克、重症HAP/VAP、重症腹腔感染、中枢神经系统感染
2. **多重耐药菌（MDRO）感染**：产ESBLs肠杆菌、CRE、CRAB、CRPA、MRSA、VRE
3. **治疗失败/疗效不佳**：已用抗菌药物48-72h无改善，需分析原因并调整方案
4. **特殊人群剂量调整**：肾功能不全/CRRT、肝功能不全、老年人、儿童、孕妇、肥胖
5. **不良反应处理与方案调整**：肾毒性、肝毒性、血液毒性、CNS反应
6. **联合用药方案优化**：复杂感染的药物选择与相互作用规避
7. **降阶梯治疗策略**：经验转目标、广谱转窄谱、静脉转口服的时机
