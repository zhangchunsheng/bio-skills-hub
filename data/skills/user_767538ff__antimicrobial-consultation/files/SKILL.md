# 临床药师特殊级抗菌药物会诊

## Overview

本技能辅助临床药师完成特殊使用级抗菌药物会诊工作，核心增强能力为**支持图片识别**——药师可直接上传检验检查报告截图、医嘱截图，系统自动识别提取检验数据和用药信息，填充至会诊模板后生成结构化会诊意见。

核心能力：
1. **图片识别提取数据**：识别化验单、医嘱单、检验报告图片，自动提取检验值和用药信息
2. 生成包含学习内容、书写规范、提示词模板的完整Word文档
3. 提供会诊意见的"为什么用 → 如何用 → 用后注意"三步书写框架
4. 根据患者信息（含图片识别结果）生成结构化会诊意见草稿
5. 生成可直接复制到医生工作站的精简会诊意见

## 核心概念

### 会诊模式
医师填写会诊申请单，药师审阅病历后提出用药建议，属咨询模式（advisory model）。处方权归属具有相应权限的医师。

### 书写框架
会诊意见按以下逻辑循序渐进：
- **为什么用**：感染诊断与严重程度评估 → 致病菌推断 → 耐药风险分析 → 用药指征确认 → 药物选择循证依据
- **如何用**：药物通用名 + 剂量 + 频次 + 途径 + 滴注时间 + 疗程 + 联合用药 + 特殊人群调整 + 降阶梯策略
- **用后注意**：疗效监测 + 不良反应监测 + TDM + 药物相互作用 + 停药/转换指征 + 随访计划

### 循证参考资源优先级
最新国内指南/共识 > IDSA指南 > 热病（Sanford Guide）> 国家抗微生物治疗指南 > 药品说明书 > UpToDate

## 工作流程

### 任务一：图片识别提取检验数据与用药信息（核心增强功能）

当用户上传检验检查图片、医嘱图片或化验单截图时，按以下步骤操作：

1. **识别图片内容**：读取 `references/image_extraction_guide.md` 获取图片识别规范
2. **提取检验数据**：从化验单图片中识别以下关键指标（具体提取项见 `references/image_extraction_guide.md`）：
   - 血常规：WBC、NEU%、NEU、Hb、PLT
   - 炎症标志物：CRP、PCT、IL-6
   - 肝功能：ALT、AST、TBIL、DBIL、ALB、ALP、GGT
   - 肾功能：Cr、BUN、eGFR、CysC
   - 凝血功能：PT、APTT、D-Dimer
   - 电解质：Na⁺、K⁺、Cl⁻、Ca²⁺
   - 腹水/体液常规：颜色、李凡他试验、WBC、多核细胞%、RBC
   - 腹水/体液生化：GLU、LDH、ADA、TP
   - 病原学：培养结果、药敏结果、G/GM试验、mNGS
   - 血气分析：pH、PaO₂、Lac
3. **提取用药信息**：从医嘱图片中识别：
   - 药物名称（通用名）、剂量、频次、给药途径
   - 用药起止时间
   - 合并用药
4. **标注异常值**：识别结果中超出正常参考范围的指标，标注↑/↓
5. **结构化输出**：将提取的数据按 `references/consultation_framework.md` 中的模板结构整理
6. **数据确认**：向用户展示提取结果，请用户确认或补充缺失信息
7. **生成会诊意见**：确认数据后，进入任务三生成会诊意见

**图片识别注意事项**：
- 如图片模糊、不完整，应告知用户哪些数据无法识别，请用户补充
- 检验项目单位需准确识别（如×10⁹/L、μmol/L、ng/mL等）
- 参考范围因试剂不同可能有差异，识别时以图片显示的参考范围为准
- 多张图片需分别识别后合并整理
- 识别结果必须向用户确认后再用于会诊意见生成

### 任务二：生成会诊指南与提示词模板Word文档

当用户需要获取完整的会诊指南文档时，执行 `scripts/generate_consultation_doc.py` 生成Word文档：

```bash
C:\Users\Administrator\.workbuddy\binaries\python\versions\3.13.12\python.exe scripts/generate_consultation_doc.py
```

该脚本生成包含学习内容、书写总结、提示词模板的完整Word文档。脚本依赖 python-docx。

### 任务三：根据患者信息（含图片识别结果）生成会诊意见

当用户提供患者信息（文字+图片）并要求撰写会诊意见时，按以下步骤操作：

1. 读取 `references/consultation_framework.md` 获取完整的会诊提示词模板
2. 将提示词中的【】占位符替换为患者实际信息（文字输入 + 图片识别结果）
3. 按提示词中的输出格式框架生成会诊意见
4. 确保会诊意见包含以下完整结构：
   - 病例摘要与分析
   - 抗感染治疗分析（用药指征、病原学分析、循证依据）
   - 会诊建议（药物名称、给药方案、剂量调整、降阶梯策略）
   - 用药监护建议（疗效监测、不良反应监测、TDM、药物相互作用）
   - 核心建议摘要（1-3句话突出显示）
   - 参考文献
5. 如需Word文档输出，执行 `scripts/generate_consultation_opinion.py` 生成格式化Word文档

### 任务四：生成可复制到医生工作站的会诊意见

当用户需要可直接粘贴到医生工作站的精简会诊意见时，按以下格式输出：

1. 患者病情摘要及用药指征评估（支撑使用特殊级的相关内容）
2. 既往用药评估
3. 支持使用特殊级的实验室检查依据
4. 推荐给药方案（药物名称、剂量、频次、途径、滴注时间、疗程）
5. 用药注意事项
6. 后续治疗意见（复查项目、疗效评估节点、降阶梯策略、停药指征）

格式要求：纯文本，适合电子病历系统直接粘贴，无表格，段落简洁。

### 任务五：提供会诊规范咨询

当用户询问会诊书写规范、药物选择依据、剂量调整方法等问题时，参考 `references/consultation_framework.md` 中的相关内容进行解答。

## 书写质量要求

生成会诊意见时须确保：
- 药物使用通用名，剂量、频次、途径、疗程具体明确
- 结合患者个体特征（肝肾功能、体重、年龄）给出调整建议
- 关键建议在末尾以"核心建议"摘要形式突出显示
- 标注循证依据来源（指南/共识/文献）
- 语气专业、平等，体现药学咨询的协作性
- 图片识别数据需经用户确认后方可使用
