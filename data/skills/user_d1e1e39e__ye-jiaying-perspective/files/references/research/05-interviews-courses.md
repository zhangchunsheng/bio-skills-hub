## 一、视频访谈清单与核心回答模式

### 1.1 央视《面对面》：叶嘉莹 · 诗词慰平生（2018，董倩）

- 来源：央视网 `https://m.news.cctv.com/2018/07/15/ARTIDzinuTWOEwR9Ey8nrNzE180715.shtml` 【一手】
- 背景：2018年7月13日恰逢叶嘉莹94岁寿诞，此前她宣布将全部财产捐赠南开大学教育基金会设立「迦陵基金」（初期捐赠1857万元）。该访谈由捐赠事件切入。

**核心回答模式（董倩提问 → 叶嘉莹回答）：**

1. **谈捐赠与金钱（被追问时毫不掩饰对金钱的轻视）**
   - 董倩：「您又不是没有女儿……为什么不给他们留一笔钱？」叶：「我在加拿大的东西都给了他们，所有的都给了他们。不是没有给他们。」
   - 叶对舆论关注捐赠表示：「我觉得这些人很无聊，这些人眼睛里面只有钱，他不懂得学问。我本来要跟你讲学问，看样子你对于学问是没有兴趣的。」
   - 董倩：「您是很有钱的人吗？」叶：「不是。我是辛辛苦苦地教书，而且我早年过很困苦的生活……我就是无家无业，睡在人家走廊上的。」
   - **回答模式特征**：被问及金钱时不回避、不粉饰，直接用《论语》「朝闻道，夕死可矣」「君子谋道不谋食」回击，将「价值不在外财」归结为内心修养的自足。她并非道德说教，而是把个人经历（睡走廊、清苦）作为论据。

2. **谈人生苦难：靠诗与《论语》《孟子》过来**
   - 董倩：「您走到命运特别艰难的关口时，靠什么过来？」叶：「我就靠我的诗。我早年读的四书，《论语》《孟子》的这些修养。当你把你的悲哀、痛苦用诗写下来，这是一件你内心——也可以消解你的悲痛，也可以保存你的纪念。这是非常有价值、有意义的一件事情。」
   - **回答模式特征**：苦难→写诗→消解悲痛+保存纪念。她把"写诗"同时定义为情绪出口与纪念行为，是反复出现的核心叙事。

3. **谈婚姻与爱情（坦诚而克制）**
   - 叶：「我跟我先生结婚，因为他是失业、生病、潦倒，无以为生的时候……我是本来跟他没有任何的婚姻跟恋爱，可是他是对我很好，是在追求我。当他贫困潦倒的时候，我反而嫁给他了。所以我是以一种可以说是善心，一种不是爱情的心，一种善心去做的这件事情……但是我是一个傻瓜，所以这样就做了。」
   - **回答模式特征**：不美化婚姻，用「善心」「傻瓜」自嘲，不渲染委屈，把嫁给对方解释为对落难者的善意。

4. **谈丈夫的暴躁：以王安石诗谅解**
   - 叶引用王安石诗「风吹瓦堕屋，正打破我头。瓦亦自破碎，匪独我血流。众生选众业，各有一机抽。切莫嗔此瓦，此瓦不自由」，说丈夫一生不顺遂，正是"此瓦不自由"，她已谅解。
   - **回答模式特征**：用古诗为现实遭遇提供解释框架，体现"以诗解厄"的一贯策略。

5. **谈"没有完美爱情"：随口引出"不遇天人不目成"**
   - 董倩提及记者问"有婚姻却无完美爱情"，叶嘉莹随口引「不遇天人不目成」。
   - **即兴引诗特征**：在被追问私人情感时，她以典故/诗句替代个人倾诉，既坦诚（承认无完美爱情）又保持距离（用古典语言包裹）。

6. **谈生死与衰老（被直接追问"怕老吗、怕死吗"）**
   - 董倩：「您怕老吗？您九十多岁了……惧怕过衰老、惧怕过死吗？」叶：「没有。我是行乎其所当行，止乎其所不得不止。」「乐天知命。孔子说的『仰不愧于天，下不怍于人。知我者其天乎？』」
   - **回答模式特征**：不展开心理描写，直接用儒家命题收束，把"不怕死"转化为"尽分"与"知命"。

7. **谈"这一辈子遭了不少罪"**
   - 董倩：「您始终能够在诗的世界里找到自己的一个存在。」叶：「因为这就是很美好的事情。」
   - **谈自己这一辈子**：「我觉得自己从20岁教书到现在，教了七十多年的书……以教书时间的长久、数量之多来算，我应该得一个世界上的唯一的奖。」
   - **谈想留下来什么**：「我想留下来就是我对于诗词，我所体会的那么美好的东西。我觉得我如果不把我所理解的东西说出来、传下去，我是上对不起古人、后对不起读者。我能够做到多少，我不知道。但是我是尽力在做。」

### 1.2 央视《朗读者》：叶嘉莹（2017，董卿）

- 来源（超星专题整理）：`https://special.chaoxing.com/special/screen/tocard/124339949?courseId=201609804` 【一手】
- 来源（搜狐全文转载《从漂泊到归来》）：`https://www.sohu.com/a/136094292_407325` 【一手/二手混合，董卿主持词与叶自述均有】
- 来源（搜狐图文）：`https://www.sohu.com/a/136782371_355384` 【二手】

**核心内容：**

- 董卿以「银翼穿云认旧京，遥看灯火动乡情」引入叶嘉莹回国落泪细节。叶自述从香港飞北京，见长街灯火疑为西长安街，确认是家所在处时流泪：「我是一直等到看到北京的灯火才流下泪来……现在的年轻人真的不能够体会我们那一辈人那种去国离乡的悲哀和痛苦。」
- 叶谈1978年诗句「却话当年感不禁，曾悲万马一时喑。如今齐向春郊骋，我亦深怀并辔心」，表示要在离世前把中国传统吟诵留下：「比如说司马迁《报任安书》……（吟诵）吟诵到现在几乎已经失传了，我想在我离开世界以前，我应该把真正的吟诵留下来给爱好诗歌的朋友们。」
- 叶引「柔蚕老去应无憾，要见天孙织锦成」自况：平生离乱微不足道，只要年轻人把丝织成云锦、让传统文化种子留下来。
- **回答模式特征**：以诗入境，用自作诗串联人生节点；把"传承"具象为"柔蚕吐丝""留莲子"，回避宏大口号，落回具体意象。

### 1.3 央视新闻公开课 · 叶嘉莹：我就教大家吟诗，要把它传下去（2020，白岩松）

- 来源：`https://m.news.cctv.com/2020/09/10/ARTIal618RdgRXM0q37P0P8Q200910.shtml` 【一手】

**核心内容：**

- 96岁叶嘉莹在南开大学开学第一课。她最希望做的事："把中国传统的吟诵留给后人"——"原来我们的诗词是吟诵的……现在吟唱的习惯好像断绝了，我就教大家吟诗，要把它传下去。"
- 白岩松请教"弱德之美"缘起，叶以朱彝尊《桂殿秋》「思往事，渡江干，青蛾低映越山看。共眠一舸听秋雨，小簟轻衾各自寒」讲解："对于自己感情的节制，一种约束，一种品德，一种忍耐承受，就是弱德的美。"
- 张伯礼（天津中医药大学校长）在现场将"弱德之美"与抗疫经历结合：不是为自己，是为更高追求与理想，隐忍有更深远目的。
- **回答模式特征**：以一首具体词作承载抽象概念（"弱德之美"通过《桂殿秋》具象化），这是她讲诗的标准方法论——概念必须落到字句与生命体验。

### 1.4 央视网 · 叶嘉莹：红蕖还向月中开（2020，署名文章/自述体）

- 来源：`https://tv.cctv.com/2020/03/20/ARTIn4RyiUJGVwnZB4WdJGgS200320.shtml` 【一手，以叶嘉莹第一人称撰写，央视网发布】

**核心论点（她讲过的）：**

- "我一生以诗词为伴，不是出于对学问的追求，而是古典诗词生发的精神力量对我的感动和召唤……我一生经历很多苦难和挫折，在外人看来，我一直保持乐观、平静的态度，这与我热爱古典诗词实在有很大关系。"
- "读诗、讲诗有三个层次"：
  1. 直觉的、感性的（如李商隐无题诗，不懂意思但觉意象声音美）；
  2. 知性的、理性的（考察历史、背景、思想）；
  3. 读者接受角度（诠释不一定是作者原意，援引意大利学者墨尔加利"创造性背离"）。
- 以王国维借爱情小词说"成大事业大学问三种境界"为例，说明读者可从诗中读出属于自己的兴发。
- "兴"是中国诗歌精华所在，"诗可以兴"即给读者兴发感动。引顾随："中国说'诗教'，不是教作诗，是使做好人。"
- **此文为提炼"如何读一首诗"回答模式的关键一手来源。**

### 1.5 人民政协网 / 中国台湾网访谈：忆往事、"高冷"、首次被问爱情（2014）

- 来源：`https://www.rmzxb.com.cn/c/2014-11-05/403066.shtml` 【一手】
- 来源：`https://www.taiwan.cn/plzhx/wylz/201411/t20141105_7908808_3.htm` 【一手】

**关键坦诚瞬间：**

- 记者拿叶年轻时旗袍照问"有人给您写情诗吗"，叶乐了：「没有……辅仁大学念书是男女分校……真是没有人敢跟我说话。」男同学给她十六字评语：「黜陟不知，理乱不闻，自赏孤芳，我行我素。」
- **首次被问爱情故事（回避/坦诚并存的典型）**：叶回忆几十年前第一次接受媒体访谈，女记者问"叶老师，你能够把你的爱情故事说一说吗？"——"这一句话，一下就把我问倒了，我就是没有这方面的经验。"众人奇怪她讲爱情诗讲得好却无爱情故事。
- 问"过去90年最美好的时光"：叶答是在美国哈佛、密歇根任客座教授那十余年，"图书馆藏书丰富……图书馆下午五点关门，却允许我一个人在里面待到很晚"。
- **回答模式特征**：对私人情感问题，她不虚构、不渲染，坦承"没有经验"，但会迅速把话题拉回学术与读书（"最美好的时光"是图书馆而非情感）。

### 1.7 中国新闻网访谈：曾姓叶赫那兰、旧宅、一辈子没什么爱情故事

- 来源：`https://ku.m.chinanews.com/wapapp/cns/kong/zw/6759581.shtml` 【一手】
- 内容：叶自述姓氏为叶赫那兰（蒙古土默特族，努尔哈赤并吞部落而成蒙古裔满族人），祖父辈民国时改汉姓取"叶赫"首字。
- 谈爱情：「之前有人让我讲爱情故事，可把我问倒了，我就是没有这方面经验。有人给我写过诗，也有人给我写过信，但是我都没有回。我一辈子就是没有什么爱情故事。」

## 二、超星公开课等课程大纲与论点

### 2.1 《中华诗词之美》（超星尔雅 / 南开大学，叶嘉莹主讲）

- 来源（超星慕课节点）：`https://mooc1.chaoxing.com/mooc-ans/nodedetailcontroller/visitnodedetail?courseId=207509471&knowledgeId=224669112` 【一手，课程大纲】

- 来源（B站南开大学公开课全50/41集）：`https://b23.tv/av57539607/p1` 【一手，视频】
- 选课规模：国家平台显示"100万+人选课"。参考书：《叶嘉莹谈词》。

**课程大纲（综合超星节点与智慧平台大纲）：**

1. **从性别文化谈小词中画眉簪花照镜之传统**
   - 1.1 词产生的背景 / 1.2 词的产生 / 1.3 配乐填词与《花间集》 / 1.4 小词与性别文化 / 1.5 性别文化与君臣之道 / 1.6 小词中的《离骚》传统
2. **南唐冯李词对花间温韦词的拓展**
   - 2.1 温庭筠 / 2.2 韦庄 / 2.3 冯延巳其人 / 2.4 冯延巳词 / 2.5 李璟 / 2.6 李煜
3. **王国维之时代及其《人间词话》之主要内容**
   - 含陆游《书愤》、辛弃疾、李清照、叶嘉莹诗词人生、王国维其人、"境界说"、对欧阳修/秦观/周邦彦之词的解读、"三境界"说等（B站41集版更细，含"张惠言与王国维比较""联想式读词""词之美感特质"等）
4. **从西方文论与中国诗学谈李商隐诗的诠释与接受**
   - 中国传统诗学视野下的李商隐、接受美学视角、作品与诠释、诗词品读之境界、"美玉生烟—叶嘉莹讲李商隐"
5. **唐诗鉴赏**
   - 含 BBC《杜甫，中国最伟大的诗人》、莫砺锋讲杜甫/李白、白居易等（此模块疑似平台后期增补，含他人讲座）
6. **中华诗词之特美**
   - 中国语言文字的特质与诗歌传统、中西方诗歌传统比较、赋比兴的创作方法、词的内涵与特质
7. **学诗忆往**
   - 7.1 颠沛中的诗词传承 / 7.2 博弈中的心灵升华
8. **迦陵咏荷**
   - 叶嘉莹的创作生涯
9. **诗歌吟诵示范与答疑**
   - 9.1 诗歌吟诵示范与答疑

**核心论点（课程大纲明确写出 / 她讲过的）：**

- 词本是无心配合燕乐的歌词，却因"幽约怨悱不能自言"透露作者潜意识修养（见2.3/6.4）。
- 以"性别文化"解读小词，再过渡到"君臣之道"与《离骚》比兴寄托传统——这是她独有的词学视角。
- "兴发感动"贯穿全诗教：读词要联想、要文化语码、要从读者接受角度"创造性背离"。

**课程大纲（6讲）：**

1. **小词修养境界之所在——词之缘起与美感特质**：词本配合燕乐、篇幅短小、无言志载道用心，无心创作反而透露男性作者潜意识中"幽约怨悱不能自言"之情，读者可从中看出修养境界。

4. **王国维三层境界说与接受美学**：借词中名句论"成大事业大学问"三境界，既有传统"断章取义"特点，也可用西方接受美学阐释。
5. **词之显微结构与双重特征——南唐二主词之境界探微**（新浪博客版题名）
6. **词之潜能与读者反应——冯延巳、王国维词释例**

**核心论点（她讲过的）：**

- 小词虽"无用"（不言志载道），却最能显作者本真修养——这是反主流的"词体价值"判断。
- 系统引介西方文学理论（语码论、接受美学）观照中国词史，是她学术方法的集中展示。
- "词之雅郑，在神不在貌"——重神韵不重表面题材。

### 2.5 课程方法论总归纳（她讲过的 vs 大纲写的）

**她讲过的核心方法（跨课程一致）：**
1. **从文字训诂与声律入手**（入声字、韵字、平仄），再及意境。
2. **以"兴发感动"为诗歌基本生命力**——不了解感动如何生发，让学生死记硬背是"贻害后人"（见光明日报、北京青年报引述）。
3. **作者生平+时代背景+写作际遇**三位一体，再论诗句如何"承受生命"，最后吟诵一遍。
4. **概念必须落到具体词作**（如"弱德之美"用朱彝尊《桂殿秋》讲）。
5. **宏观文学史视野**：不孤立讲一人，置于传承脉络。
6. **中西理论互证**：用西方文论解释中国词，弥补王国维、张惠言说不通处。

**大纲写的（课程设计层）：** 性别文化→南唐冯李→王国维→李商隐接受→唐诗→特美→学诗忆往→迦陵咏荷→吟诵示范。这是「课程大纲写的」，体现"从文体特质到具体词人，再到个人生命与吟诵实践"的递进逻辑。

- **核心自述句**（学习强国/新华社引述）："天以百凶成就一词人……我确实有经历了人生的忧患。"（引王国维，亦为其人生写照）
- **"弱德之美"自述**（环球网引述）："我的一生不是很顺利，有很多坎坷。我有弱德之美，但是我不是一个弱者。"并说把苦乐"平淡化了，没有哪个会伤害到她"。
- **传承隐喻**："犹如莲花，即使花残零落，我也要留下一颗莲子。"（内心光明必须传下去）

### 3.3 影片如何呈现她的诗词观与生平

- **叙事系统**：以叶嘉莹自述为主，辅以人物访谈、资料照片、文字纪录。其自述是"历经沧桑后的回望"，不再有事发当时的情感波澜，添了劫波渡尽的平静与思考（中国电影报）。
- **述志系统**：展现"以诗为魂"的精神世界；片中她常吟诵，显示人生挫折时的心境与感悟。
- **写意系统**：空镜、雅乐、碑帖墓志、龙门石窟飘雪、庭院竹影等，以影像语言呈现诗词意境。
- **"弱德之美"的影像化**：光明日报指出影片以独特影像质感展现"弱德之美"内涵；"一世多艰，寸心如水"（叶《踏莎行》开篇）可视作一生写照。
- **吟诵的音律之美与意境互文**：叶归国后积极推广吟诵诗教，影片记录了这一点。

### 3.4 亲友/学生视角的二手呈现（纪录片中他人讲过的）

## 四、坦诚与回避模式

### 4.1 坦诚的瞬间（不回避、甚至尖锐）

1. **对金钱的直斥**（《面对面》）：称关注捐赠的舆论"很无聊""眼睛里只有钱"，毫不掩饰清贫与对金钱的轻视。【一手】
2. **坦承婚姻无爱情**（《面对面》《朗读者》多处）：多次说"有婚姻，但爱情并不满意""以一种善心嫁给他""我是一个傻瓜"。【一手】
3. **坦承"没有真正爱情体验"**（鲁豫、中新闻）：不羞涩、不虚构，平静陈述"一辈子没什么爱情故事""有人写诗写信我都没回"。【一手/二手】
4. **对文化衰败的尖锐批评**（中新闻）："如入宝藏空手回""真是堕落、真是败坏"——显示她温和外表下的道德义愤。【一手】
5. **谈丈夫家暴/暴躁**：用王安石诗谅解，不抱怨、不控诉，但客观承认丈夫"性情大变、常发脾气"（多源交叉印证，部分来自搜狐深度文，可信度中等）。【一手+二手混合】
6. **谈女儿女婿车祸**：写十首哭女诗、闭门不出，"眼圈一红就过去了"（刘秉松转述），不渲染但承认"一生劳瘁竟何为"的痛。【二手转述】

### 4.2 回避 / 以古诗包裹的瞬间

1. **首次被问爱情故事"问倒了"**（人民政协网/中新闻）："这一句话一下就把我问倒了，我就是没有这方面的经验。"——既不编故事，也不展开，以"无经验"终结话题。【一手】
2. **用"不遇天人不目成"化解私密追问**（鲁豫/《面对面》）：以吕碧城词、古诗替代个人情感倾诉，保持距离。【一手/二手】
3. **"最美好的时光"答为图书馆而非情感**（人民政协网）：被问90年最美好时光，转向哈佛图书馆读书经历，回避情感维度。【一手】
4. **对政治/敏感历史的回避**：所有访谈中，她对台湾白色恐怖、丈夫入狱等仅作事实陈述（"被牵连受审""失去工作住所"），不评论政治是非，只用"覆盆天莫问，落井世谁援"等诗收束。这是一种**系统性回避**——用诗承担记忆，不进入政治评判。【一手+推测】
5. **对自我成就的"回避式自夸"**：《面对面》中说"以教书时间长久数量之多，我应该得世界上唯一的奖"——表面自谦（"应该得奖"是玩笑式），实则以量化而非质量评价自己，回避直接谈"我多伟大"。【一手】

### 4.3 矛盾与张力（直接记录，不调和）

- **矛盾A**：她一方面说"我一生以诗词为伴，不是出于对学问的追求"（央视自述），另一方面又毕生做极严谨的学术研究（西方文论引介、词学理论建构）。→ 可能是"初心"与"学术成就"两个层面的并存，她自己未必视其为矛盾。
- **矛盾B**：她说诗词让人"乐观平静"，但自作诗满是血泪（"痛哭吾儿躬自悼""风雨逼人一世来"）。→ 平静是"面对"后的结果，非无悲。她本人以"把苦乐平淡化"解释。
- **矛盾C**：她批评年轻人"空守宝藏""堕落败坏"（中新闻），却在《面对面》说"现在的年轻人真的不能够体会我们那一辈人去国离乡的悲哀"——前者是文化批判，后者是代际理解，态度并不统一。
- **矛盾D**：对"爱情"主题，她讲爱情词极精微（学生/记者都惊异），个人却"无爱情体验"——她以"善心""不遇天人"化解，但讲词时的情感细腻与生活的情感空白形成反差，她自己视为"不矛盾"（能感之≠经历过）。
