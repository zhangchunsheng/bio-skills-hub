# 招标文件结构（通用拆解）

> 通用框架，不同地区/行业（工程、货物、服务）章节名称有差异，按实际文件对应。

## 标准六块

### 1. 招标公告 / 采购公告
必读数字：
- 项目名称、采购人、代理、项目编号
- 采购方式、预算、最高限价
- 获取文件起止时间、方式
- 投标截止时间、开标时间地点（线上/现场）
- 对供应商资格的最低要求摘要

### 2. 投标人须知
规定游戏规则：
- 投标有效期长度
- 保证金金额、形式、到账截止
- 投标文件组成、份数（正/副本）、封装
- 评标办法索引
- 废标/否决条款集中处
- 代理服务费由谁承担

### 3. 投标人须知前附表
把第 2 块的「关键数字」浓缩成一页表。**最该精读**，是速读入口。

### 4. 技术 / 服务需求
- 参数清单、设备清单、验收标准
- 带「★」「▲」「必须」「不可偏离」「实质性」的是**否决项**，逐条响应
- 标注「一般」「建议」的属加分或软要求

### 5. 评标办法
算分核心：
- 报价分公式与参数（基准价算法、满分、偏差扣法）
- 技术分细项与分值（方案、工期、人员）
- 商务分细项与分值（业绩、证书、售后）
- 权重合计应为 100%

### 6. 合同草案 + 投标文件格式
- 给定封面、目录、承诺函、报价一览表、法定代表人授权书等格式
- **必须严格套用**，改动格式可能被判不符合性审查
- 合同条款（付款、违约、验收）决定后期风险，商务必读

## 拆解输出模板（助手使用）

```
【项目速读】
项目 / 采购人 / 代理 / 编号
方式 / 预算 / 最高限价
获文件：起—止
截止 / 开标：时间 + 方式
保证金：金额 + 形式 + 到账截止
工期/交付：要求（是否★）

【否决项清单】
1. …（摘★/必须/不可偏离）
2. …

【评分权重】
报价 X% / 技术 X% / 商务 X%
报价公式：基准价算法 + 满分 + 偏差扣法

【格式必交件】
封面 / 报价一览表 / 承诺函 / 授权书 / …
```

## 阅读顺序建议

1. 先读前附表（拿关键数字）
2. 再读技术需求标★项（判能否投）
3. 然后评标办法（判怎么拿分）
4. 最后格式与合同（判怎么交、后期风险）
