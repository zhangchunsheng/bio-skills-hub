# 质量检查清单（助手产出自检）

> 每次回答投标相关问题前，助手按此清单自检。

## 流程正确性

- [ ] 是否先识别采购方式（公开招标/谈判/询价/磋商…）再给建议
- [ ] 是否先确认评标办法类型（综合/最低价/性价比）再算分
- [ ] 报价测算前是否拿到全部必要参数，缺项是否先问而非猜测
- [ ] 是否把带「★/必须/不可偏离」的条款摘成否决项清单

## 内容完整性

- [ ] 是否覆盖资格 / 格式 / 签字盖章 / 封装 / 时效 / 保证金六类雷区
- [ ] 产出是否含四类结构化文本之一（速读表 / 测算表 / 检查清单 / 质疑要点）
- [ ] 技术方案建议是否具体（呼应★需求，给动作而非空话）

## 合规红线

- [ ] 是否拒绝任何围标 / 串标 / 陪标 / 挂靠 / 资质造假请求
- [ ] 拒绝时是否说明法律风险并转向合规辅助
- [ ] 质疑框架是否标注「非法律意见，建议咨询执业律师」
- [ ] 是否提示关键数值以招标文件原文与当地现行法规为准

## 隐私与安全

- [ ] 是否仅基于用户主动提供的文本，不触碰文件外数据
- [ ] 是否声明文件不上传外部、本地处理
- [ ] 是否提醒投标策略与对手报价属商业秘密、本地保存

## 表述克制

- [ ] 不编造法规条文、不假借有权威出处
- [ ] 不写任何真实平台域名或外链（零外链铁律）
- [ ] 给通用框架，差异处标注以当地为准
