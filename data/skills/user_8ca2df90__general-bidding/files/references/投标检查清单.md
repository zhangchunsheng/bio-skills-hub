# 投标检查清单（通用逐项自查）

> 投标前 48 小时做最后一遍。按「必交 / 格式 / 签字盖章 / 封装 / 时效」五类过。可让助手基于你的具体文件生成定制版。

## 一、资格与实质（否决级，最先查）

- [ ] 营业执照范围覆盖采购内容
- [ ] 资质等级 / 证书在有效期内且名称一致
- [ ] 财务、信誉要求满足（无失信、无重大违法）
- [ ] 所有「★ / 必须 / 不可偏离」条款已逐条响应并承诺
- [ ] 报价 ≤ 最高限价（分项限价也查）
- [ ] 无围标/串标/挂靠/造假（违法，红线）

## 二、报价与商务

- [ ] 报价大小写一致、一览表与明细一致
- [ ] 报价币种、单位与文件一致
- [ ] 投标有效期覆盖要求
- [ ] 业绩合同关键页齐全（金额、签章、时间合理）
- [ ] 人员证书 + 社保清晰对应
- [ ] 承诺书、声明函内容填全

## 三、格式与签字盖章（高频废标源）

- [ ] 严格使用给定封面 / 目录 / 格式
- [ ] 法定代表人或授权人签字处已签
- [ ] 公章、法人章位置正确、清晰不糊
- [ ] 授权委托书为原件 / 符合要求
- [ ] 页码连续、装订方式符合（胶装/活页）
- [ ] 正副本数量、标记正确

## 四、封装与递交

- [ ] 正本 / 副本 / 电子盘分装正确
- [ ] 密封袋标识（项目名、编号、正副本）正确
- [ ] 封口盖章 / 骑缝章齐全
- [ ] 线上递交：系统上传完成、回执已存
- [ ] 现场递交：在截止前送达指定地点

## 五、保证金与时效

- [ ] 保证金金额、形式（保函/转账）正确
- [ ] 到账截止前已到账，凭证留存
- [ ] 账户与文件要求一致（不接受个人代付情形按文件）
- [ ] 澄清 / 疑问在截止前提出
- [ ] 开标时间地点已确认，授权人准时

## 六、内容一致性

- [ ] 报价一览表 ≠ 明细表矛盾
- [ ] 业绩时间不穿帮（近 3 年窗口）
- [ ] 技术方案呼应★需求无遗漏
- [ ] 电子版与纸质版内容一致

## 七、收尾

- [ ] 全套扫描留存备份
- [ ] 递交回执 / 上传成功截图保存
- [ ] 内部不留存对手具体报价等敏感信息于公开处
