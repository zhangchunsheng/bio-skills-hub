# 采购术语词典（通用）

> 只做通用解释，具体定义以项目所在地现行法规与招标文件原文为准。本词典不含任何外链。

## 基础概念

- **采购人 / 招标人**：发起采购、出资并接收标的的一方（机关、事业单位、企业等）。
- **投标人 / 供应商**：响应采购、提交投标文件的一方。
- **代理机构**：受采购人委托办理采购事宜的中介（招标代理）。
- **评标委员会**：依法组建、负责评审打分的临时组织，独立评审。
- **中标人 / 成交供应商**：评审后确定的签约对象。

## 价格类

- **预算金额**：采购人计划支出的总金额，通常公开。
- **最高限价 / 拦标价**：报价不得突破的上限，超则废标。可整体限价或分项限价。
- **标底**：部分项目内部控制的预期价（现代招标多已取消，防泄漏）。
- **评标基准价**：用于算报价分的参照价，常见算法：最低有效报价、平均价、复合基准（如平均价下浮系数）、给定值。
- **报价得分**：综合评分法下价格部分的得分，常见低价优先或基准价±偏差。

## 审查类

- **资格性审查**：审查投标人是否具备基本门槛（执照、资质、财务、信誉）。不符即否决。
- **符合性审查**：审查投标文件是否实质响应（格式、签字、★条款、工期）。重大偏离即否决。
- **实质性响应**：投标文件满足招标文件全部关键要求，无重大偏离。
- **细微偏差**：不影响实质响应、可补正的小瑕疵（如个别错别字、非关键格式）。
- **重大偏差 / 否决投标**：导致废标的情形（超限价、★未响应、密封错等）。

## 评分类

- **综合评分法**：报价分 + 技术分 + 商务分，按权重汇总，得分高者中标。
- **最低评标价法**：满足要求的最低报价成交，技术只做符合性审查。
- **性价比法**：得分 = 技术商务分 ÷ 报价 × 价格权重，价低者单位分高。
- **权重**：各评分维度占总分的比例（如报价 30%、技术 50%、商务 20%）。
- **客观分 / 主观分**：客观分凭证据硬性给（业绩数量）；主观分凭评委判断（方案优劣）。

## 文件类

- **招标文件**：采购人发出的全部要求文件（公告、须知、需求、办法、格式）。
- **投标文件**：投标人响应的全部材料（商务、技术、报价）。
- **投标一览表 / 报价一览表**：汇总关键报价的表，常要求单独密封。
- **承诺函**：对合规、工期、质量的书面承诺，常是格式固定必交件。
- **澄清 / 答疑**：投标前采购人对疑问的书面回复，具同等效力。

## 程序类

- **投标有效期**：投标文件保持有效的期限，过期采购人可拒收或要求延长。
- **投标保证金 / 保函**：担保投标诚意，未中标按规定退还；形式可为转账或保函。
- **踏勘**：现场考察，部分项目组织统一踏勘并签到。
- **开标**：公开开启投标文件、唱标的环节（时间与投标截止同一时刻）。
- **质疑 / 投诉**：对文件或结果有异议时的法定救济渠道（有时限）。
- **单一来源**：唯一供应商采购，无竞争，须先公示。

## 风险类

- **围标 / 串标**：多家串通操纵结果，违法，入刑。
- **陪标**：名义参与、实为烘托，属串标一种。
- **挂靠 / 借资质**：无资质者借用有资质单位名义投标，违法。
- **弄虚作假**：伪造业绩、证书、检测报告，违法，列入失信。
