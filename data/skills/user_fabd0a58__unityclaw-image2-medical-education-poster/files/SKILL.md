# Image2 医疗科普海报生成

使用Image2，根据医学主题、已核验要点、目标人群和机构规范制作清楚展示医学知识重点的科普海报。输入文字要求和可选参考图片，输出经过文件校验的本地成图。适合“用Image2帮我做医疗科普海报”“按这些要求用Image2生成医疗科普海报”等请求；不生成诊断结论，医学内容须由专业人员核验。

## 何时使用

用户需要清楚展示医学知识重点的科普海报，并能提供医学主题、已核验要点、目标人群和机构规范时使用。常见说法包括：

- “用Image2帮我做医疗科普海报”
- “按这些要求用Image2生成医疗科普海报”
- “我有参考图，想生成清楚展示医学知识重点的科普海报”

不生成诊断结论，医学内容须由专业人员核验。不得把模型生成结果描述成对真实尺寸、文字、人物身份、历史事实或专业结论的绝对还原；涉及这些内容时，应提醒用户复核。

## 需要的信息

优先从用户输入中提取：

- 必需：医学主题、已核验要点、目标人群和机构规范
- 视觉重点：人体或器官示意、要点层级、风险提示区域和机构识别
- 可选：参考图片、品牌色、目标受众、画面比例、输出分辨率和文件格式
- 文字：必须逐字记录，并在交付时提醒用户核对生成图中的文字
- 禁止项：用户明确不希望出现的人物、物体、标志、颜色或风格

缺失信息不影响主要构图时可做合理视觉选择；会改变主体、真实数据或专业含义时先询问。

## 模型

本 Skill 固定使用 **Image2**。如果用户明确要求其他模型，应选择名称中包含对应模型的 Skill，不在当前任务中静默切换模型。

## 工作流程

1. 确认交付物是清楚展示医学知识重点的科普海报，整理医学主题、已核验要点、目标人群和机构规范。
2. 把提示词按“交付物与主体 → 场景与动作 → 构图与镜头 → 光线与颜色 → 材质与风格 → 必须出现的文字 → 禁止项”组织。
3. 在提示词中明确本场景的检查重点：人体或器官示意、要点层级、风险提示区域和机构识别。
4. 默认比例为 `4:5`、分辨率为 `2K`；预览可用 `1K`，正式交付通常用 `2K`，用户明确需要高清成品时再使用 `4K`。
5. 有参考图时说明每张图用于控制主体、构图、颜色还是风格，并按相同顺序传入。
6. 使用脚本执行一次生成，等待结果并验证每个本地文件存在且大小大于零。
7. 返回本地文件、模型、比例和分辨率。文字、尺寸、人物特征或专业内容需要人工复核时明确指出。
8. 用户要求修改时，只调整相关提示维度；不要因为主观判断自动重复消耗生成次数。

## 使用方式

```bash
node scripts/generate.js \
  --prompt "请根据我提供的医学主题、已核验要点、目标人群和机构规范，生成清楚展示医学知识重点的科普海报，重点处理人体或器官示意、要点层级、风险提示区域和机构识别" \
  --aspect-ratio 4:5 \
  --size 2K \
  --json \
  --output-dir ./tasks
```

需要参考图片时重复使用 `--attachment`：

```bash
node scripts/generate.js --prompt "请根据我提供的医学主题、已核验要点、目标人群和机构规范，生成清楚展示医学知识重点的科普海报，重点处理人体或器官示意、要点层级、风险提示区域和机构识别" \
  --attachment ./reference-1.png --attachment ./reference-2.jpg \
  --aspect-ratio 4:5 --size 2K \
  --json --output-dir ./tasks
```

## 输出要求

成功结果必须包含：

- `success: true`
- 实际使用的 `model`、`aspectRatio`、`size`
- `taskId`、`taskFolder` 和 `outputDir`
- 至少一个 `files` 项，每项包含绝对 `localPath` 与大于零的 `bytes`

交付时展示本地图片文件，不把临时下载地址当成最终交付物。
