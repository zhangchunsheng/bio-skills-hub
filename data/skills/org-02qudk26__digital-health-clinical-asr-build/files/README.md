# 临床语音识别基准构建

- 唯一标识：`digital-health-clinical-asr-build`
- 显示名称：临床语音识别基准构建
- 能力摘要：为特定临床专科整理术语、标注 IPA、合成非 PHI 语音，并生成带术语元数据的 NeMo 评测 manifest，作为临床 ASR 飞轮的构建阶段。

## 案例素材

1. 心内科团队发现药名和手术名经常被误识别；与临床人员确认术语清单，再构建带专科语境的合成评测音频。

2. 某些术语发音存在歧义；按人工覆盖、医学词典、G2P 的顺序生成 IPA，并抽样试听后再大规模合成。

3. 医院要比较两版 ASR；输出含术语类别、音色、噪声等级和发音来源的 manifest，供后续 KER 评分使用。
