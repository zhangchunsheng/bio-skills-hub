# 鉴定与质量评价技术要点库

覆盖"基于XXX技术对甘肃道地药材的鉴定与质量评价"课题常用技术。每种技术给出：原理、适用场景、方法学验证指标、关键控制点、常见坑点。

## 技术选型速查表

| 技术 | 解决什么问题 | 优势 | 局限 | 适合药材 |
|------|-------------|------|------|----------|
| DNA条形码 | 物种鉴定（真伪、混伪品） | 不受加工/储存影响、结果客观 | 无法评价内在质量、近缘种需多标记 | 当归/党参/黄芪（易混淆种多） |
| HPLC指纹图谱 | 整体化学轮廓+多指标含量 | 定量准确、图谱可溯源 | 需标准品、分析时间长 | 大黄/甘草/黄芪 |
| UPLC-MS/MS | 微量/痕量成分定量 | 灵敏度高、多成分同时测定 | 仪器贵、基质效应需评估 | 黄芪甲苷、蒽醌类微量测定 |
| GC-MS | 挥发性成分鉴定与定量 | 挥发油专属、可定性定量 | 需衍生化或针对挥发成分 | 当归（藁本内酯）、川芎 |
| 近红外光谱(NIR) | 快速无损筛查 | 快、无损、可建模 | 需大量建模样品、模型迁移差 | 黄芪/甘草快速真伪判别 |
| 电子鼻/电子舌 | 气味/滋味整体表征 | 客观化感官指标 | 环境敏感、需规范操作 | 当归（香气）、甘草（甜味） |
| 显微鉴定 | 组织/粉末特征鉴别 | 成本低、传统法定方法 | 主观、需经验 | 所有药材（基础手段） |
| 薄层色谱(TLC) | 定性鉴别（药典常法） | 简单快速 | 重现性一般 | 所有药材（与HPLC互补） |

## 一、DNA条形码技术

### 原理
利用基因组中标准片段（如核基因ITS2、叶绿体psbA-trnH/rbcL/matK）的种间差异进行物种鉴定。

### 标记选择
- **ITS2**：核基因，种间变异大、扩增易，中药材鉴定首选（药典通则已收载 ITS2 条形码）。
- **psbA-trnH**：叶绿体间隔区，变异快，适合近缘种区分。
- **rbcL/matK**：通用性强，但种间区分力相对弱，多用于属级。
- 建议：正品与混伪品为同属近缘种时，**双标记/多标记交叉验证**；属间差异单标记即可。

### 方法学验证指标
- DNA提取成功率（>90%为宜）、PCR扩增成功率
- 测序峰图质量（Q值、双峰判定）
- BLAST比对一致性（≥99%）、遗传距离分析（K2P模型）
- 建树：NJ（Neighbor-Joining）/ML 系统发育树，自展值（bootstrap）标注

### 关键控制点
- 药材粉碎后立即提取，防DNA降解；干品需延长裂解时间
- 设阳性对照（已知品种）、阴性对照（水空白，防污染）
- 每批样本设置重复（至少3个重复样本/种）
- 测序产物需检查双峰与套峰，避免混合样本
- 数据库比对注意 GenBank 序列的鉴定凭证（避免"数据库中同名但鉴定错误"）

### 常见坑点
- 硫熏/高温干燥导致 DNA 降解 → 尝试更短片段（mini-barcode）
- 药材粉末混入他种 → 结果解读需结合形态
- 同一物种内个体变异 → 采样量不足导致误判

## 二、HPLC 指纹图谱 + 多指标含量测定

### 原理
高效液相色谱分离，紫外/二极管阵列检测，构建"化学指纹"，与对照指纹图谱比对相似度；同时以对照品定量标志成分。

### 方法学验证指标（含量测定）
- 线性范围与相关系数（r ≥ 0.999）
- 精密度（进样精密度 RSD ≤ 2%）
- 重复性（同批6份 RSD ≤ 2–3%）
- 稳定性（样品溶液不同时间点，RSD ≤ 3%）
- 加样回收率（80–120%，RSD ≤ 3–5%）
- 检出限（LOD）/定量限（LOQ）：信噪比 S/N=3/10

### 指纹图谱验证指标
- 共有峰确认（10批以上样本，共有峰≥70–80%）
- 相似度评价：夹角余弦/相关系数，阈值（如≥0.90）
- 保留时间漂移校正、峰面积归一化
- 方法耐用性：不同色谱柱批次、不同仪器、不同分析员

### 关键控制点
- **色谱柱批次一致性**：不同批次 C18 柱选择性有差异，全实验尽量同批号并预留备用柱
- 流动相 pH 控制（有机酸类成分需酸性流动相抑制解离）
- 柱温恒定（±1℃内），防止保留时间漂移
- 样品前处理（提取溶剂、料液比、超声时间）必须固定并记录
- 梯度洗脱的平衡时间足够，避免下一针基线漂移

### 常见坑点
- 大黄蒽醌：游离与结合态需水解前后对比测定（总蒽醌-游离蒽醌）
- 指纹图谱"相似度达标"不等于"质量等同"——需结合含量与生物活性讨论
- 溶剂峰/鬼峰干扰 → 空白溶剂对照

## 三、UPLC-MS/MS

### 原理
超高效液相色谱与串联质谱联用，MRM 模式多成分同时定量。

### 方法学验证指标
- 标准曲线线性（r ≥ 0.99，加权回归）
- 精密度/准确度（QC样本，RSD/RE ≤ ±15%）
- 基质效应（matrix effect）评估：提取后加标 vs 纯溶剂
- 回收率、稳定性（冻融/短期/长期）
- LOD/LOQ（S/N=3/10）
- 内标校正（同位素内标或结构类似物）

### 关键控制点
- 基质效应必须评估并校正（甘肃土壤/药材基质复杂）
- 离子源参数优化（每个化合物独立优化）
- 进样残留（carryover）检查——高低浓度间加空白针
- 质谱仪定期校准，质量轴漂移检查

### 常见坑点
- 同分异构体（如藁本内酯 E/Z 型）需色谱分离，不能仅靠质谱区分
- 共流出峰离子抑制 → 调整色谱条件或稀释样品

## 四、GC-MS

### 原理
气相色谱分离挥发性/半挥发性成分，质谱定性（NIST库检索）+ 内标/外标定量。

### 方法学验证指标
- 分离度（关键峰对 R ≥ 1.5）
- 线性、精密度、重复性、回收率（同 HPLC）
- 保留指数（RI）计算用于定性佐证
- MS 稳定性（调谐报告、信噪比）

### 关键控制点
- 样品制备：水蒸气蒸馏法（挥发油提取率记录）、顶空进样或溶剂萃取
- 进样口温度与衬管状态（活性成分热降解风险）
- 载气纯度（≥99.999%）
- 色谱柱老化与使用记录
- 定性：保留指数 + 质谱双重确认（避免仅凭谱库检索）

### 常见坑点
- 当归挥发油中藁本内酯不稳定（光/热敏感）→ 避光冷藏、尽快测定
- 谱库检索匹配度低时需人工判读碎片离子
- 含水样品损坏色谱柱 → 充分干燥

## 五、近红外光谱（NIR）

### 原理
近红外区（780–2526 nm）含氢基团（O-H、N-H、C-H）倍频与合频吸收，配合化学计量学建模实现快速定量/定性。

### 方法学流程
- 建模样品收集（覆盖质量范围，一般 50–200 份）
- 光谱采集（样品粒径、装样密度、温湿度控制）
- 预处理：SNV/MSC/一阶导数/二阶导数等
- 建模：PLS（偏最小二乘）、PCA、SIMCA
- 验证：交叉验证 + 独立验证集，R²、RMSEP、预测偏差

### 关键控制点
- 建模集与验证集独立、具代表性（含道地产区与对照区样本）
- 仪器间模型传递（transfer）需校准
- 样本粒径与水分影响大——预处理必须规范
- 模型维护：定期用代表性样本验证，漂移时更新

### 常见坑点
- 过度拟合（样本少、潜变量多）→ 用独立验证集评估
- 水分吸收带干扰 → 干燥后测定或纳入水分校正
- "黑箱"质疑：答辩中需说明模型可解释性与适用范围

## 六、薄层色谱（TLC）

### 原理
固定相（硅胶板）上按极性差异分离，与对照药材/对照品比移值（Rf）比对定性。

### 关键控制点
- 展开剂比例精确配制、饱和缸预饱和
- 温湿度控制（影响 Rf 重现性）
- 显色剂配制新鲜、喷显均匀、加热显色温度时间一致
- 拍照记录（含标尺与日期），供原始记录归档

### 常见坑点
- Rf 值漂移 → 与对照品同板展开、同条件显色
- 假阳性斑点 → 多溶剂系统验证

## 七、显微鉴定

### 原理
利用组织构造与粉末特征（导管、纤维、石细胞、淀粉粒、草酸钙晶体等）鉴别。

### 关键控制点
- 切片方向（横/纵切）与部位规范
- 粉末制片：水合氯醛透化、稀甘油封片
- 特征描述术语规范（药典用语）
- 显微摄影含标尺

## 方法学验证通用框架（适用所有技术）

1. **专属性**：正品与混伪品/干扰物能明确区分
2. **精密度**：仪器精密度 + 方法重复性 + 中间精密度（不同人/天）
3. **准确度**：回收率/参考方法比对/标准品验证
4. **线性与范围**：覆盖实际样品浓度范围
5. **灵敏度**：LOD/LOQ 满足判定需要
6. **耐用性**：微小参数变化（流速/柱温/波长±）不影响结果
7. **稳健性**：不同批次试剂、不同仪器结果一致

## 答辩高频技术追问（答题素材）

- "为什么选这个技术？" → 从对象特征（如易混淆种→分子）、研究目的（定性→DNA；定量→HPLC）、资源条件（仪器可得性）三层回答
- "为什么不用XX技术？" → 对比表：给出被选技术的不可替代性与替代技术的局限（如显微鉴定无法定量、NIR需建库）
- "方法学验证做到了什么程度？" → 列出全部验证指标及实测值
- "数据可靠性怎么保证？" → 双人复核、仪器期间核查、标准品溯源（批号+证书）、留样复测
