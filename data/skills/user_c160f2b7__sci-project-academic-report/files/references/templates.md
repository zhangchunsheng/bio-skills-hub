### 1.4 修改规范（必须遵守）

- **禁止**：涂改液、橡皮擦除、整页撕毁、覆盖重写。
- **正确**：在错误处画单横线（保持原字可辨），旁边写正确值，签修改人姓名 + 日期 + 修改原因。
- 电子记录：修改留痕（审计追踪），保留修改前后值。
- 空白处画"X"或注明"以下空白"，防止事后添加。

## 四、学术PPT大纲模板

### 4.1 通用叙事流

```
背景 → 目的 → 技术路线 → 结果与讨论 → 结论 → 创新点
（开题：背景 → 目的 → 方案 → 预期结果 → 时间安排）
```

### 4.2 逐页大纲表格模板（毕业答辩，约25–30页）

| 页码 | 板块 | 核心内容要点 | 图形化建议 | 讲稿时长 |
|------|------|--------------|------------|----------|
| 1 | 标题页 | 题目、汇报人、学号、导师、日期 | 校徽+题目大字 | 30s |
| 2 | 目录 | 各章节导航 | 结构化列表 | 15s |
| 3 | 研究背景 | 道地药材资源现状、混伪品问题、选题意义 | 资源地图/饼图 | 1min |
| 4 | 药材资源概述 | 道地产区、本草考证、资源分布 | 产区地图标注 | 1min |
| 5 | 技术原理 | 所选技术原理+为什么选它 | 原理示意图 | 1.5min |
| 6 | 技术路线图 | 全流程路线 | 流程框图 | 1min |
| 7–9 | 实验设计 | 样本、方法、对照、方法学验证 | 表格+流程图 | 2min |
| 10–16 | 结果展示 | 鉴定结果→质量评价结果 | 聚类图/电泳图/指纹图谱叠加/含量柱图 | 4–5min |
| 17–20 | 讨论 | 与文献对比、方法优劣、局限性 | 对比表 | 2min |
| 21 | 总结与展望 | 结论、创新点、不足、下一步 | 要点列表 | 1min |
| 22 | 致谢 | 致谢 | 照片 | 15s |

### 4.3 每页"三要素"写作法

每页 PPT 只回答三个问题：**这是什么？（结论句标题）→ 为什么重要？（要点）→ 证据是什么？（图/表/数据）**。标题用结论性短语（如"ITS2条形码可将当归与其3种混伪品明确区分"），不要用纯描述性标题（"实验结果"）。

### 4.4 图形化建议速查

| 数据类型 | 建议图表 |
|----------|----------|
| DNA条形码结果 | NJ系统发育树（bootstrap标注）、凝胶电泳图 |
| 指纹图谱 | 多批样品色谱叠加图、相似度热图/聚类树状图 |
| 含量测定 | 柱状图+误差棒（±SD）、箱线图（不同产区比较） |
| 多指标综合评价 | 雷达图、PCA得分图、层次聚类热图 |
| 产区差异 | 柱状图/箱线图+显著性标注（*、**） |
| 资源分布 | 甘肃地图标注产区（注意使用合规底图） |

### 4.5 题目拆解模板（示例：基于DNA条形码技术对甘肃道地药材当归及其混伪品的鉴定与质量评价）

| 层 | 拆解 | 对应PPT板块 |
|----|------|-------------|
| 技术层 | DNA条形码（ITS2+psbA-trnH） | 技术原理、方法学 |
| 对象层 | 当归及其混伪品（欧当归/独活/硫熏品） | 药材资源概述、实验设计 |
| 目的层 | 鉴定（真伪）→ 质量评价（含量+指纹） | 结果展示、讨论 |
| 空间限定 | 甘肃道地药材（岷县道地产区） | 背景、样本采集 |
