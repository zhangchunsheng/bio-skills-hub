# 甘肃道地药材知识库

面向"基于XXX技术对甘肃道地药材的鉴定与质量评价"课题的药材背景资料。数据为常见文献共识，具体研究引用时务必核对最新版《中国药典》与产地实地资料。

## 常用术语速查

- **道地药材**：特定产区经长期临床验证、质量与疗效优于其他产区的药材，核心是"环境—基因—农艺"三者协同。
- **道地性证明要素**：①本草考证（历代本草记载）；②产区生态因子（海拔/气候/土壤）；③性状与质量特征；④现代化学/分子证据；⑤临床疗效历史。答辩中样品"道地性"需至少给出产区凭证+基原鉴定双证据。
- **基原**：药材来源的植物学名（种）。基原鉴定是鉴定类课题的第一道关卡。
- **混伪品**：与正品同属近缘种或外观相似品的非正品药材（含掺伪）。

## 五大甘肃道地药材档案

### 1. 当归（Angelica sinensis）
- **道地产区**：甘肃岷县（"岷归"）、宕昌、渭源一带，渭河上游高寒阴湿区。
- **采收**：秋末（10月下旬–11月上旬）茎叶枯萎时采挖，过早根条不充实、过晚木质化。
- **质量特征**：主根粗长、油润，断面黄白色、香气浓郁，富含挥发油与阿魏酸。
- **常见混伪品**：欧当归（Levisticum officinale）、独活（Angelica pubescens）等近缘种；硫熏过度品。
- **质量评价常用指标**：挥发油含量、阿魏酸、藁本内酯（Z/E-藁本内酯）、醇溶性浸出物。
- **研究注意**：挥发油类成分易挥发损失，样品干燥与储存需控温避光；DNA条形码建议 ITS2 + psbA-trnH 双标记交叉验证（欧当归为属间差异，单标记即可区分；伪品为近缘种时需多标记）。

### 2. 党参（Codonopsis pilosula）
- **道地产区**：甘肃文县、宕昌（"纹党"）、渭源一带；山西潞党为另一主产区。
- **采收**：秋季（9–10月）采挖，栽培品一般2–3年生。
- **质量特征**：条粗壮、皮松肉紧、有横纹，味甜，富含党参多糖、党参炔苷、苍术内酯。
- **常见伪品/混淆**：素花党参（C. pilosula var. modesta）、川党参（C. tangshen）为法定同用，但商品党参中常混入迷果芹、羊乳等伪品。
- **质量评价常用指标**：党参多糖、党参炔苷（Lobetyolin）、浸出物、水分。
- **研究注意**：多糖含量测定受提取方法影响大，需固定提取条件；栽培年限与多糖积累相关，采样需记录年限。

### 3. 黄芪（Astragalus membranaceus / A. membranaceus var. mongholicus）
- **道地产区**：甘肃陇西、渭源、岷县为黄芪主产区；陇西为全国最大的黄芪集散地。蒙古黄芪与膜荚黄芪均为药典正品。
- **采收**：秋季（10–11月）采挖，栽培品一般2–5年生；野生品年限更长但资源稀缺。
- **质量特征**：根长条顺、粉性足、豆腥味浓，断面纤维性强，富含黄芪多糖、黄芪甲苷、毛蕊异黄酮葡萄糖苷。
- **常见伪品**：紫云英（Astragalus sinicus）、草木樨（Melilotus）、刺果甘草等混入；掺糖增重品。
- **质量评价常用指标**：黄芪甲苷、毛蕊异黄酮葡萄糖苷、黄芪多糖、总灰分、醇浸出物。
- **研究注意**：栽培黄芪存在"三年以下药效成分积累不足"问题，样品需记录生长年限；道地性论证建议补充产地土壤与海拔数据。

### 4. 大黄（Rheum palmatum / R. tanguticum / R. officinale）
- **道地产区**：甘肃礼县、宕昌、武都一带（掌叶大黄/唐古特大黄），西和、礼县为"铨水大黄"主产区。
- **采收**：秋末或早春采挖，栽培品一般3–5年生；挖后刮去外皮。
- **质量特征**：断面红棕色、星点明显（异常维管束），气清香、味苦而微涩，富含蒽醌类（游离+结合）与鞣质。
- **常见伪品**：华北大黄（R. franzenbachii，无星点）、藏边大黄（R. emodi）等，部分伪品不含或极少结合蒽醌。
- **质量评价常用指标**：芦荟大黄素、大黄酸、大黄素、大黄酚、大黄素甲醚（五种蒽醌总量）、土大黄苷（检查项，检出即提示混伪）。
- **研究注意**：游离蒽醌与结合蒽醌需分别测定（药典法水解前后对比）；"土大黄苷"是鉴别大黄真伪的关键检查项，答辩高频考点。

### 5. 甘草（Glycyrrhiza uralensis）
- **道地产区**：甘肃、内蒙古、宁夏、新疆为传统产区；甘肃张掖、民勤、酒泉（河西走廊）为主产区之一。
- **采收**：秋季（9–10月）采挖，栽培品一般3–4年生（药典规定栽培年限≥3年）。
- **质量特征**：外皮红棕色、断面黄白色、味甜，富含甘草酸、甘草苷。
- **常见伪品**：胀果甘草（G. inflata）、光果甘草（G. glabra）为药典同用种；混入豆科其他植物根茎时需警惕。
- **质量评价常用指标**：甘草酸（含量测定）、甘草苷、灰分、水分。
- **研究注意**：栽培年限直接影响甘草酸含量（3年生以下常不达标），采样记录年限至关重要；河西走廊盐碱地种植对甘草酸积累有影响，可作为道地性讨论点。

## 道地药材样本采集通用规范（用于方案设计）

1. **采样点设计**：道地产区选 2–3 个乡镇级采样点，对照区（非道地产区）选 1–2 个点，每点至少 3 个生物学重复样本；记录 GPS 坐标、海拔、土壤类型、伴生植物。
2. **凭证标本**：每批样本压制腊叶标本 1–2 份，编号后存入标本馆；同时拍摄生境照与药材照（含比例尺）。
3. **基原鉴定**：采后立即由生药学专业人员鉴定（性状+显微+分子），出具鉴定记录，注明鉴定人。
4. **加工与保存**：按药典通则干燥（阴干/晒干/烘干温度记录），分装密封，注明采收日期、批次；挥发性药材（当归）需低温避光；多糖类药材防潮防霉。
5. **合法合规**：采集需遵守《野生药材资源保护管理条例》；栽培品注明来源基地与种植年限；跨省调运注意检疫与来源证明。
6. **市场样本**：如含市场药材（用于混伪品调查），注明采购地、商家、批号，保留购买凭证照片。

## 产地成本提示（用于预算）

- 道地产区产地直采通常比市场价低 20–40%，但需承担差旅与凭证采集成本；市场采购价高但便捷。
- 鲜品冷链运输：甘肃山区到实验室一般 1–3 天，冷链物流单次约 300–800 元（视距离与批量）。
- 干燥设备与场地：若量大需租用烘房或购置烘干箱。
- 凭证标本制作：压制、消毒、装订材料费每份约 5–15 元。
- 对照药材（药典级）：每支（约1g）约 30–120 元不等，需按实验用量购买，注意对照药材有有效期。
