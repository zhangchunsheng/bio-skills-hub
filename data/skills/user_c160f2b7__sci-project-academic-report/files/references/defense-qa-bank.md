# 评审专家问题库与应答思路

围绕"基于XXX技术对甘肃道地药材的鉴定与质量评价"课题的五类高频提问维度。每问给出：问题、考察点、应答思路（先结论→再证据链→后限定边界）。

## 维度一：技术选择理由

**Q1. 为什么选择DNA条形码（或HPLC等）技术来研究这个课题？**
- 考察点：技术匹配逻辑、对课题本质的理解
- 应答：三层回答——①对象特征（当归混伪品为同属近缘种，形态鉴定困难→需分子手段）；②研究目的（既要真伪鉴定又要质量评价→分子+化学互补）；③条件可行性（实验室仪器/试剂可得、方法成熟）。最后补充"与显微/TLC对比，本技术的不可替代性在于____"。

**Q2. 为什么不直接用《中国药典》规定的鉴定方法？**
- 考察点：对药典方法局限性的认识
- 应答：药典方法是法定最低要求；本研究追求①高通量（多批量快速筛查）、②定量化（指纹图谱相似度+含量）、③更精细的混伪品区分（药典TLC对近缘种区分不足）。强调"以药典方法为基准、在此基础上提升"。

**Q3. ITS2和psbA-trnH两个条形码选哪个？为什么？**
- 考察点：分子标记知识深度
- 应答：ITS2种间变异大、通用引物成熟，是主流首选；但单标记在近缘种（如当归vs欧当归）可能区分不足，故加psbA-trnH双标记交叉验证；两者结果一致时结论可靠。

**Q4. 指纹图谱相似度阈值为什么定为0.90？**
- 考察点：统计依据与专业判断
- 应答：参考相关指导原则与文献通行做法，并结合本批样本实测分布（正品组内相似度≥0.92，混伪品<0.85，留出安全间隔）；强调阈值依据数据而非拍脑袋。

## 维度二：方法学验证

**Q5. 你的方法学验证做了哪些指标？结果如何？**
- 考察点：验证体系完整性
- 应答：按七项框架作答（专属性、精密度、重复性、稳定性、准确度/回收率、线性范围、LOD/LOQ、耐用性），逐一给出实测值并对照药典要求（如RSD≤2%）。

**Q6. 加样回收率是怎么做的？为什么回收率偏高/偏低？**
- 考察点：实验原理理解
- 应答：说明加样水平（80%/100%/120%）、操作流程（已知含量样品+定量加入对照品）；偏高→基质干扰或本底扣除误差；偏低→提取不完全或降解，给出排查思路（检查提取次数、衍生化效率）。

**Q7. 对照品来源与纯度如何保证？**
- 考察点：溯源性意识
- 应答：中国食品药品检定研究院/权威厂商对照品，附批号与纯度证书（含量≥98%）；进口对照品保留COA；溶液配制记录在案。

**Q8. 色谱柱批次换了会影响结果吗？你怎么控制的？**
- 考察点：易被忽视的细节
- 应答：承认不同批次C18柱选择性存在差异；采取①全实验同批号柱并预留备用柱；②换柱后进行系统适用性试验（理论塔板数、分离度、保留时间漂移校验）；③关键批次间样品加质控样对比。

## 维度三：样品代表性

**Q9. 你的样本量够吗？统计上有依据吗？**
- 考察点：样本量与统计设计
- 应答：说明每产区样本数、生物学重复数；引用同类研究样本量先例；承认局限（如经费限制）并说明数据趋势一致性可弥补。

**Q10. 如何证明你采的样本就是道地药材？**
- 考察点：道地性论证（高频！）
- 应答：证据链三要素——①产区凭证（GPS、县乡级道地产区、本草记载对照）；②基原鉴定（生药学专家鉴定记录+凭证标本号）；③性状/化学特征与药典描述及道地品质特征一致。强调"凭证标本编号"可随时核验。

**Q11. 栽培品和野生品的差异你怎么处理的？**
- 考察点：样本均一性
- 应答：采样时记录来源属性（栽培/野生）与年限，分组比较；如混用，说明对结论影响的评估（如专门比较栽培vs野生含量差异并作为讨论点）。

**Q12. 市场购买的药材如何保证来源可靠？**
- 考察点：市场样本质量控制
- 应答：记录采购地、商家、批号，保留票据照片；购回后立即基原鉴定+对照药材比对；说明市场样本仅用于真伪筛查用途，定量分析以自采有凭证样本为准。

## 维度四：数据可靠性

**Q13. 你的数据有没有做重复性和复核？**
- 考察点：数据质量管理
- 应答：仪器精密度（同针多次）、方法重复性（同批多份）、中间精密度（不同人/不同天）；双人独立计算核对；异常数据剔除有记录（Grubbs检验/手工复核）。

**Q14. 异常数据是怎么处理的？剔除标准是什么？**
- 考察点：数据伦理与统计规范
- 应答：先复核原始记录（排除操作错误），再用统计方法（如Grubbs/Dixon检验）判定离群值；说明剔除比例（<5%为合理）并保留完整记录备查；强调"不预设立场、不选择性报告"。

**Q15. 谱图和原始数据能随时调取吗？**
- 考察点：可追溯性
- 应答：全部原始谱图、称量记录、处理日志已归档编号，与论文图表一一对应；可现场演示调用。这是原始记录规范的直接体现。

## 维度五：创新点与局限性

**Q16. 你的创新点是什么？**
- 考察点：创新性提炼
- 应答：建议三点式——①方法层面（多标记交叉/指纹+含量联用）；②对象层面（首次系统覆盖甘肃道地产区多县乡样本）；③结论层面（发现某混伪品新情况/道地产区化学特征新认识）。避免空泛，落到"别人没做过的具体事"。

**Q17. 你的研究有什么局限性？**
- 考察点：学术诚实
- 应答：主动列出2–3条真实局限（样本量、单一采收年、未做生物活性关联），并给出后续改进方向（扩大样本、多年份追踪、活性-成分关联）。评委最反感"没有问题"的回答。

**Q18. 下一步研究打算怎么做？**
- 考察点：研究规划能力
- 应答：从"纵向深化（同一样本多技术联用）、横向扩展（更多产区/品种）、机制关联（成分-活性-临床）"三方向作答，落到具体可执行计划。

## 答辩模拟模式操作规则

1. 以"评委"身份开场："我是XX方向的评审专家，下面开始提问。第一个问题：____"
2. **一次只问一题**，等待用户作答后再点评。
3. 点评结构：先肯定（"你对____的理解到位/数据支撑充分"）→ 指出漏洞（"但____部分缺少证据，建议补充____"）→ 给出改进（"可以这样完善：____"）。
4. 追问逻辑：从"技术选择→方法学→样品→数据→创新性"逐层深入，同一主题连续追问2–3轮，模拟真实压力。
5. 用户要求结束或答完所有维度时，输出《答辩问题复盘表》（问题/你的回答/评委点评/改进建议/追问可能）。
