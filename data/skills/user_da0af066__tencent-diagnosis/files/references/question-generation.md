# 出题规范（Reasoner 逻辑复刻）

## 1. 一轮出几题、什么题型

> **真相源边界**：每轮题数与每题选项数的唯一定义位置是 `SKILL.md` §4.2，本文件不重复数值。
> 本节只补题型分类与压缩方法。

- 题型只有四种：
  - **单选**：默认首选。绝大多数症状特征、有无类、程度分档都用单选。
  - **多选**：只在「伴随症状筛查」这类天然可多选的场景用。用多选时必须删掉组合冗余项。
  - **数值**：疼痛评分（0-10 分，整数）、体温（35-42℃，一位小数）。**严禁把体温套用 0-10 分制。**
  - **开放填写**：只在答案本就无法枚举时用（如"具体吃的什么药"）。能枚举就不要用开放题。
- 选项数量受平台硬限制（数值见 `SKILL.md` §4.2）。原生诊室常出 5 项，压缩方法见第 4 节。

## 2. 出题优先级

同一轮内把最影响判断的排前面：

1. **红线鉴别点**（最高）。主诉提示可能存在急重症方向、而相应报警点还没问过 → 必须本轮就问，且不许收束。
   - 14 条红线清单与头痛专项等主诉专项规则，唯一真相源是 `SKILL.md` §2，此处不重复。
2. **主症状核心特征**：部位、起病方式（突发/渐起）、病程、性质、程度、变化趋势
3. **鉴别关键伴随症状**：能把两个候选方向分开的那一个
4. **诱因 / 加重缓解因素**
5. **既往史、用药、过敏、家族史、检查结果**

**常见病优先分流**：主诉是流涕/鼻塞/咽痛/咳嗽/发热/头痛/腹泻/腹痛这类高频主诉时，第 1-2 轮优先问「常见病 vs 需排除方向」的分流点（病程、热型、痰涕性状、全身中毒症状、夜间盗汗、体重下降），不要在只有单一线索时就锁定某个少见假设连续追问。**某个少见方向连续 2 轮没拿到支持证据，必须转向常见病分流。** 高危方向作为"需排除项"问一次客观证据就够，不许喧宾夺主。

## 3. 不许出的题（硬过滤）

### 3.1 已知信息不许再问

- 用户已回答的维度（含答"不确定/不清楚/没做过/没量过"的）
- 主诉里已嵌入的属性：`上腹部隐痛两天` → 部位、性质、病程三项全部不许再问
- 可由已知事实直接推导的：既往史有痛风 → 不问"是第一次发作吗"；已知 3 岁 → 不问青春期；用户已说"我有糖尿病" → 不问"是否被诊断过糖尿病"
- 用户明确说过"没做过检查/报告还没出来" → 不许再引导上传或询问该检查结果

### 3.2 性别专属硬过滤

已知**男性**时，以下一律不出：

> 槽位：月经周期/经量/经期不规律/痛经、妊娠、阴道出血、阴道分泌物、哺乳、宫缩
> 文本命中即过滤：月经｜经期｜经量｜经血｜痛经｜例假｜大姨妈｜停经｜绝经｜闭经｜白带｜阴道｜外阴｜阴唇｜宫颈｜子宫｜宫腔｜妊娠｜怀孕｜备孕｜孕期｜流产｜产后｜哺乳｜盆腔｜卵巢｜输卵管｜促排｜试管｜胚胎｜宫腔镜

已知**女性**时，以下一律不出：

> 槽位：前列腺、勃起功能、遗精
> 文本命中即过滤：前列腺｜勃起｜阳痿｜早泄｜遗精｜射精｜龟头｜包皮｜阴茎｜睾丸｜精液｜精子｜阴囊｜附睾

**性别未知时不过滤**，但此时也不要主动出性别专属题——先把性别问清楚（性别本身可以作为一题）。

### 3.3 年龄过滤

- 儿童：不问职业暴露、性生活、饮酒吸烟、更年期
- 老年：不问发育里程碑、青春期
- **年龄未知**：不许出年龄专属题（尤其婴幼儿发育里程碑题），一律按成人口径

### 3.4 隐式否认的处理

用户在多选题里只勾了部分选项时，**未勾选的正向选项视为已否认**：

- 落进 `negatives`（如未勾"有皮疹" → 皮疹=无）
- 后续**任何措辞**都不许再问这些已否认的症状。判定按临床语义而非字面："眼睛干涩/口干" ≡ "眼睛或嘴巴干燥"；"皮疹" ≡ "皮肤疹子/红斑"；"乏力" ≡ "没力气/疲劳"
- **例外**：用户选的是兜底项（"不确定""没量过体温""无法判断"）时，语义是"不清楚"而非"否认"。**绝不许写成 `xxx=无`**（会污染后续判断），但同样不再追问。当作"已问过、结果未知"。

## 4. 选项改写（压到 4 项以内的正确做法）

### 4.1 压缩优先级

1. **合并语义相邻的正向项**（推荐）
   - `基本无痰 / 白痰 / 黄痰 / 痰里带血丝 / 不确定` → `基本无痰 / 白痰 / 黄痰或带血丝 / 不确定痰的性状`
   - `没有 / 偶尔有 / 活动后明显 / 静息时也有 / 不确定` → `没有气短 / 活动后明显 / 静息时也有 / 不确定`
2. **只问有无，细节留下一轮**
   - `没有 / 有 / 不确定`，下一轮再针对"有"追类型
3. **拆成两题**（本轮题数还没到 4 时可用）

**不许**为了压缩丢掉量化信息：`低烧(37.3-38℃)` 压缩后仍要带温度区间。

### 4.2 选项自解释化

组件会把选项和题干分开呈现，孤立的"有/没有/是/否"用户看不懂指什么。

- ❌ `有` / `没有` / `是` / `不确定`
- ✅ `没有发烧` / `有宫外孕史` / `没做过检查` / `不确定检查结果`

兜底项同样要自解释：`不确定` → `不确定是否有性交痛`；`以上都没有` → `没有上述伴随症状`。

### 4.3 必须留兜底

每题必须有一个"用户答不出来时能点"的选项：`不确定X` 或 `都没有X`。
组件本身会自动提供自由输入框，所以不需要额外造"其他，请说明"这种选项。

### 4.4 严禁占位型伪选项

以下形态一律违规——表面是选项，实际强迫用户再打字：

- 以 `…` / `...` / 省略号结尾：`有，具体是…`、`有，诊断是...`、`是，具体…`
- 含 `请填写` / `请说明` / `自行描述` / `详见下文`
- 典型违规：`{"q":"家里其他人有没有类似关节肿痛、风湿病或痛风？","options":["有，具体是…","没有","不确定"]}`

正确改法（按用户负担从小到大）：

1. 列出常见具体答案 + 兜底：`没有 / 有类风湿关节炎 / 有痛风或其他风湿免疫病 / 不确定`
2. 只问有无：`没有 / 有 / 不确定`
3. 改成开放填写题

### 4.5 多选题删组合冗余

已有原子项 A、B 时，任何 A、B 的组合/并集项都必须删——用户直接勾两个就行：

- ❌ `有发红 / 有局部发热 / 两者都有` → ✅ `有发红 / 有局部发热`
- ❌ `有尿频尿急 / 有尿痛 / 有尿频尿急尿痛 / 不确定` → ✅ `有尿频尿急 / 有尿痛 / 排尿没有异常 / 不确定`
- ❌ `头痛 / 头晕 / 头痛和头晕 / 都没有` → ✅ `头痛 / 头晕 / 都没有`

识别形态：显式连接词型（A和B、A与B、既有A又有B）、直白合集型（都有、两者都有、以上都有）、顿号枚举型（`A、B`）、包含型、题干回流型。

### 4.6 删冗余前缀

- ❌ `有，确诊痛风 / 有，确诊高尿酸血症 / 有，但没确诊`
- ✅ `确诊痛风 / 确诊高尿酸血症 / 疑似但未确诊`

## 5. 题干措辞

- 短、口语、好答。像医生面对面问话。
- 不恐吓、不夸张。不要出现"是不是癌""会不会猝死"这类把用户吓住的措辞。
- 不下诊断、不带专业术语。要问"胸口有没有像被压住的感觉"而不是"有无心前区压榨性疼痛"。
- 称呼跟随身份判定：代问诊用"宝宝/孩子/阿姨/叔叔"，本人用"您/你"，判定不了省略主语。**任何情况不用"患者"。**
- 用户用非中文提问时，题干和选项跟随该语言。

## 6. 出题前自检清单（逐条过）

- [ ] 本轮 3-4 题，每题 ≤4 个选项，每题都有兜底项
- [ ] 每题只问一个维度，没有"A或B吗"式的合并题
- [ ] 所有选项脱离题干可读，没有孤立的"有/没有"
- [ ] 没有任何含 `…` / `具体是` / `请说明` 的占位伪选项
- [ ] 多选题里没有组合冗余项
- [ ] 逐题比对已知事实：没有一题问的是主诉里已说过、或能从已知推导出的信息
- [ ] 逐题比对性别年龄：没有一题违反性别/年龄硬过滤
- [ ] 逐题比对上一轮未勾选项：没有一题换个说法重问已否认的症状
- [ ] 主诉提示的红线报警点，如果还没问过，本轮必须有题覆盖
- [ ] 题干里没有"患者"、没有专业术语、没有内部词汇
