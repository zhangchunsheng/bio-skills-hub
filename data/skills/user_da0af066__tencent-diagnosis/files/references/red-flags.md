## 1. 急症（L1）vs 重症（L2）怎么分

**关键看时间敏感性，不是疾病严重度。** 这是最容易判错的一处——严重的病不一定是急症，不严重的暴露反而可能是限期处置。

| | L1 急症 | L2 重症 |
|---|---|---|
| 病程 | 急骤起病，数分钟~1-2 天内突发或快速恶化 | 慢性/亚急性进行，数周~数月逐渐加重 |
| 急性失代偿信号 | 有 | 无 |
| 行动指令 | 立即急诊、必要时 120 | 尽快（数日内）到对应专科，**并说明当前无需挂急诊** |
| 首选科室 | 急诊科（可 + 专科） | 对应专科，可不含急诊科 |
| 开场首句 | "建议现在就前往急诊" | "建议尽快（如数日内）到 XX 专科，不要再拖延" |
| 有无居家护理模块 | **无**，严禁 OTC 替代就医 | 只写就医前注意事项（如避免负重） |
| 收尾 | "别独自硬扛"；严禁"放宽心观察" | "别一直拖着"；也不要强套急症措辞 |

**存疑且偏慢性进展时，优先按 L2 处理**，并在警戒线里写明什么情况需要立即转急诊。

典型 L2 例子：脊柱旁占位合并进行性下肢无力、病程数月、否认大小便失禁 → 首句给"尽快专科就诊"，不是"现在冲急诊"。

## 2. 紧急模式下的鉴别方向纪律（易错）

命中红线**不等于**已确定病因就是那个高危方向。熔断的含义是"时间敏感、需尽快就医"这个**行动建议**——高危方向多数是"须优先排除项"，未必是最可能诊断。

所以 `differential_directions` 里：

- 高危排除方向可以排在前面，但**不许把与本例线索最相符的原发病方向挤出去**，后者至少要留在前三
- **反例**：典型的前庭神经元炎/耳石症表现，却把蛛网膜下腔出血、脑肿瘤排最前，把耳石症挤掉 —— 喧宾夺主，违规

## 3. 模式叠加

- `consult` / `diagnosed` 模式下发现红线 → 升级为 emergency，但**首句仍要衔接用户原本的问题**。
  例："您问用什么药——目前这个情况药物解决不了，建议今天就去急诊。"
- 红线信号**不许写进 `illness_description`**（那里不出现"危险信号：未提供/已否认"这类描述）

## 4. 完整判定示例

**猫抓伤**（consult 但时间敏感 → L2，不是 L3/L4）
> 输入："被家里猫抓破皮了，有点渗血，要怎么处理" / "在手背上" / "没打过狂犬疫苗"
> 判定：未命中急性失代偿信号。首轮即带明确问题"要怎么处理" → consult。但猫抓破皮属狂犬暴露，需尽快冲洗接种，时间敏感 → **L2**。

**普通开放鉴别**（standard → L3）
> 输入："最近总觉得胃有点胀" / "饭后明显" / "没有反酸" / "两周了"
> 判定：未命中红线。全程无具体问题、无既往诊断，属开放式"我这是怎么了" → standard。持续两周、无报警征、程度轻 → L3 择期消化科。

**末轮才出现红线**（补熔断 → emergency/L1）
> 输入："头晕好几天了" / "睡不好" / "血压有点高" / "刚才突然一边胳膊没劲、说话也不利索了"
> 判定：命中清单第 4 条——末轮突发单侧肢体无力 + 言语不清，高血压背景，高度警惕急性卒中。**即使已到最后一轮，仍升级 emergency/L1**。

**已确诊管理**（diagnosed → L3）
> 输入："确诊高血压两年，一直吃氨氯地平，最近控制还行，想问能不能减量" / "没有头晕不适"
> 判定：未命中红线。已明确诊断并在治，诉求是用药调整 → diagnosed。属择期随访、无紧迫性 → L3（减量需医生评估）。
