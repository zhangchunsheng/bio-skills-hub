# 信源检索规范

搜索在本流程里的定位只有一个：**佐证与补充**。它不参与临床判断，也不参与安全分诊。

---

## 0. 四条不可越过的边界

1. **搜索结果不得驱动临床结论。** 鉴别方向、紧急度分级、推荐科室，全部由本地规则 + 你的临床推理产出。搜索只能给已有结论补充可追溯的出处，或补齐你确实不熟的事实性知识（药物、指标、流行病学）。**先有判断，再去找出处；不许反过来。**
2. **红线判定绝不依赖搜索。** `red-flags.md` 的 14 条红线是纯本地规则。搜索失败、超时、无结果，**一律降级继续，不阻塞流程**。任何情况下都不能因为"搜不到"而放过一条红线。
3. **搜索结果与本地规则冲突时，以本地规则为准。** 网页说"这种头痛可以先观察 48 小时"，而本地红线判为 L1 —— **按 L1 走**，并且不引用那条来源。
4. **不得从搜索结果里抄具体药物剂量、给药频次、处方方案**。即使权威站点写了。剂量属于线下医生的处方权范围。

## 2. 首轮：条件触发

**常见主诉一律不搜。** 头痛、腹痛、咳嗽、发热、腹泻、咽痛、腰痛、头晕、失眠、皮疹、便秘、恶心、乏力、关节痛这类高频主诉，你的既有知识足够支撑首轮出题，搜索只会增加延迟和噪音。

**命中以下任一条才搜，最多 1-2 次检索：**

| 触发条件 | 检索方向 | 例 |
|---|---|---|
| 主诉罕见或你确实不熟 | 该病/症状的典型表现与警示征象 | "血卟啉症发作""重症肌无力晨轻暮重" |
| 用户提到具体药名 | 该药常见不良反应、相互作用、慎用人群 | "吃了甲氨蝶呤之后口腔溃疡" |
| 用户提到具体检查指标异常 | 该指标的临床意义与常见成因 | "尿酸 620""TSH 8.5" |
| 涉及时效性 | 当季流行病、新发传染病、新上市药物 | "最近流行的呼吸道病毒" |
| 特殊人群用药安全 | 孕期/哺乳期/婴幼儿的安全性 | "怀孕 8 周能不能吃这个药" |
| 用户自诊猜测涉及具体病名 | 该病的典型表现，用于正面回应猜测 | "我查了说是强直性脊柱炎" |

**首轮搜索结果的用法**：只用来**提升出题准确度**和**校正你不确定的事实**。首轮的文字回答里可以自然融入事实（如某药的常见副作用），**但首轮不展示链接、不列参考资料**——首轮的任务是问出关键信息，不是做文献综述。

## 3. 尾轮：常规执行

报告轮**固定执行**，1-3 次检索。围绕已经定下来的结论去找出处，顺序固定：

1. **前 1-2 个鉴别方向**的诊断要点与处理原则
2. **推荐检查**的适用性（这个检查用来看什么）
3. **该主诉的就医时机与警示症状**（用于交叉验证你写的警戒线没有漏项）

### query 构造

- 用**规范医学术语 + 场景限定**，不要照抄用户口语。"肚子疼" → "acute abdominal pain differential diagnosis" 或 "急性腹痛 鉴别诊断"
- 中英文各试一次通常比只试中文召回更好，国际权威源基本都是英文
- 一次 query 只查一个问题，不要把多个问题串成长句

### 结果消化

- 每条来源必须**实际读到内容**才能引用。搜索返回的标题看起来对但内容不相关 → 丢弃。
- **严禁编造或猜测链接。** 只写检索实际返回的 URL。宁可参考资料区少一条，也不许出现一个打不开的链接。
- 提取的 `note` 是**一句话说清这条来源讲了什么**，不是复述你的结论。
- 如果检索到的内容让你发现自己的判断确实有误 —— 可以修正判断，但要**重新走一遍红线扫描和分级**，不能只改正文不改分级。

### 数量控制

参考资料**最多 5 条**。宁少勿滥，5 条不相关的来源比 2 条精准的更糟。
一条都没搜到（网络失败、白名单内无结果）→ **不写 `references` 字段**，报告照常出。这不是错误。

## 4. 报告里的呈现

写进 `report.json` 的 `references` 数组，由渲染脚本生成底部独立区块：

```json
"references": [
  {
    "title": "Thunderclap headache: diagnostic approach",
    "source": "MSD Manuals",
    "url": "https://www.msdmanuals.com/...",
    "note": "说明突发达峰头痛需优先排除的几类病因与首选影像检查。"
  }
]
```

字段：`title` 必填；`source` 机构名（如"MSD 诊疗手册""国家卫健委""Mayo Clinic"）；`url` 必填且必须是实际检索到的；`note` 一句话要点，可选但建议写。

**渲染时脚本会自动加上这句免责**：

> 以下资料仅供延伸阅读，不作为本次建议的判断依据。具体诊疗请以线下医生意见为准。

这句话是刻意的——用户看到链接容易以为"结论是从这篇文章推出来的"。必须明确划开：结论来自本次问诊信息与临床常规，来源只是让你能自己核对。

## 5. 自检

- [ ] 所有引用域名都在白名单内
- [ ] 每条 URL 都是实际检索返回的，没有一条是拼出来的
- [ ] 参考资料 ≤5 条，且每条都与本例结论直接相关
- [ ] 报告里的鉴别方向、紧急度、科室，都不是被某条搜索结果改出来的
- [ ] 没有从搜索结果里抄任何药物剂量或给药方案
- [ ] 搜索失败时流程照常走完，红线判定未受影响
