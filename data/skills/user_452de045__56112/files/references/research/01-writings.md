## 反复出现≥3次的核心论点（真信念）

1. **复利是非线性的，时间是最大的杠杆。** 增长的关键变量是时间长度和增长率，而非起始资本的绝对值。大多数人对指数增长的威力严重低估——这不仅是投资问题，更是认知问题。

2. **思维模型比努力更重要。** 拥有多元思维模型才能看到别人看不到的机会和风险。引用芒格的"锤子综合征"。

3. **稀缺资产才是真正的资产。** 判断投资价值，首要标准是是否具有真正的、难以复制的稀缺性。

4. **长期主义不是口号，是认知结构的产物。** 无法坚持长期主义不是因为意志力不够，而是认知深度不够——无法真正"看见"远期收益的巨大。

5. **幂律分布是宇宙的基本规律。** 在财富、影响力、互联网效应等领域，结果服从幂律分布，"平均思维"在解释真实世界时往往是错的。

6. **"做对的事"比"把事做对"重要一百倍。** 方向选择是最重要的杠杆，选择比努力重要10倍，这个论点在他那里被放大到极致。

7. **积累势能，等待临界点。** 大量前期积累都是在建造水位，临界点一到，力量不可阻挡。

## 自创术语和概念

| 术语 | 含义 |
|------|------|
| **做题家 vs 出题家** | 做题家是在别人设定的框架内努力优化答案；出题家是能重新定义问题、创造框架的人。财富和影响力的分水岭在于你是哪种人。 |
| **稀缺资产** | 具有真实供给约束、难以被复制的资产类型。不只是投资标的，也是人生战略的核心概念。 |
| **认知密度** | 一个人单位时间内产生的有价值认知判断的数量。高认知密度的人赚钱效率远高于低认知密度的人。 |
| **时间贴现率** | 描述人们对未来收益打折扣的心理倾向。低时间贴现率是长期主义者的核心心理特征。 |
| **势能积累** | 在临界点之前持续投入、等待非线性爆发的过程描述。 |
| **第一流性价比** | 描述优质资产在高增长阶段的"投入产出比"——用极低的机会成本换取极高的潜在回报。 |

- 《巴菲特致股东的信》— 价值投资哲学
- 《从0到1》（Peter Thiel）— 垄断与创业
- 《人类简史》三部曲（Yuval Noah Harari）— 大尺度历史框架

### 新发现核心概念（Agent调研补充）

| 术语 | 定义 |
|------|------|
| **10x思维** | 十倍数增长长期看比两倍更容易——因为10x要求完全不同的思维框架，不是同一路径上的优化 |
| **五年3.2倍红线** | 长期投资回报的最低标准，不去碰红线以外的东西成为一种自觉的自律 |
| **资源贫乏怪圈** | 资源贫乏→落入骗局/过早套现→无法坚守长期机会→继续资源贫乏 |
| **软柿子哲学** | 螺旋式上升，找500个软柿子捏，积累信心和能力后再挑战硬骨头 |
| **移动屁股改变脑袋** | 主动改变立场和环境来更新思维，而非固守已有框架 |
| **出钱最多者视角** | 投资时采用出资最多者的视角，即真正的利益相关方视角 |
| **阈值(临界值)决策** | 从临界值角度看待决策，理解积累到临界点后的非线性变化 |
| **拒绝线下活动** | 线下活动（会议/聚会）人数少、耗时、无法重复、匹配度低、商业密度低 |
| **间歇性断食** | 一日两餐甚至一餐，让大脑更清醒 |
