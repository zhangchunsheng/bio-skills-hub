# 医学文献精读 Skill — 设计说明

## 版本
v1.0.0（2026-08-13）

## 设计目标
对单篇医学文献做"审稿级"深度精读，输出结构化摘录报告。覆盖临床研究与基础研究全场景。

## 双轨制路由设计

| 轨道 | 适用场景 | 核心规范 |
|---|---|---|
| A | 临床研究（RCT/队列/病例对照/横断面/病例系列/临床Meta） | CONSORT / STROBE / PRISMA 2020 |
| B | 动物实验 | ARRIVE 2.0 |
| C | 细胞实验 | rigor & reproducibility |
| D | 分子机制 | 通路验证逻辑链 |
| E | 混合型（临床+基础联动） | 同时走 A+C/D 轨 |

## 7 条质量补丁清单

| 编号 | 补丁内容 | 解决的问题 | 模板位置 |
|---|---|---|---|
| 1 | 数据/材料可及性核查 | 原始数据/代码/试剂信息是否公开，影响复现性与 Meta 纳入判断 | 文献背景区块 |
| 2 | 阳性对照/工具对照缺失判定 | 基础研究无阳性对照的结论可信度问题，前置判定而非隐于不足之处 | 轨道 C/D 方法表 |
| 3 | 统计 reporting 完整性核查 | 效应量+95%CI/多重比较校正/正态性检验/缺失值处理是否完整报告 | 全轨道通用（独立区块） |
| 4 | 伦理与合规双轨 | 人类研究 IRB/赫尔辛基 + 动物实验 ARRIVE 2.0 实际合规比例 | 文献背景区块 |
| 5 | 图表数据可提取性评估 | 从图表反提数值供 Meta 分析使用（WebPlotDigitizer/ImageJ） | 全轨道通用（独立区块） |
| 6 | 生物学重复 vs 技术重复严格区分 | 细胞实验将技术重复当生物学重复的方法学硬伤 | 轨道 C 结果表 |
| 7 | 缺失值处理与数据完整性 | 失访/脱落/缺失数据的处理方法对偏倚方向的影响 | 全轨道通用统计 reporting 区块 |

## 证据质量评估三套并行标准

| 研究类型 | 评估工具 | 关键维度 |
|---|---|---|
| 临床研究 | GRADE | 偏倚风险、不一致性、间接性、不精确性、发表偏倚 |
| 动物实验 | SYRCLE | 10 条目逐条评估（选择/实施/测量/失访/报告/其他） |
| 细胞/机制研究 | rigor 清单 | 随机化/盲法/充分 n/独立重复/预先注册/全部数据报告 |

## 与其他 skill 的关系

| Skill | 职责边界 |
|---|---|
| `medical-paper-reading`（本 skill） | 单篇文献精读、结构化摘录 |
| `nsfc-proposal-generator` | Meta 分析标书撰写、检索策略生成 |

本 skill 是 `nsfc-proposal-generator` 的上游数据加工工具——精读产出的摘录报告可直接作为 Meta 分析数据提取表的来源。

## 使用方式

### 方式一：直接调用
用户说"帮我精读这篇文献"→ 触发本 skill → 加载 `prompt-template.md` → 执行精读 → 输出报告

### 方式二：配合文献使用
用户提供 PDF 文件路径 + 研究方向关键词 → 触发本 skill → Read PDF → 填入模板 → 输出报告

### 方式三：输出文件
用户要求保存 → 写入 `/workspace/` 目录 → Markdown 或 Word 格式
