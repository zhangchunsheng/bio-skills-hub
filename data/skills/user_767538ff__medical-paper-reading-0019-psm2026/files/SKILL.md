# 医学文献精读 Medical Paper Reading

> **Goal**: 对用户提供的一份医学文献（全文 PDF / 文本 / 正文粘贴）做"审稿级"深度精读，按双轨制路由输出结构化摘录报告，覆盖临床研究与基础研究全场景。

## When to Use

**当用户要求对一篇医学文献进行精读、深度阅读、审稿级摘录、结构化拆解时触发**：
- 用户说"帮我精读这篇文献"、"读一下这篇 paper"、"审稿级摘录"
- 用户提供了一份文献全文（PDF / 文本）并要求输出结构化报告
- 用户要求提取文献中的效应量、方法学细节、偏倚评估等可入 Meta 分析的数据
- 用户要求对基础研究文献（动物/细胞/分子机制）做深度摘录

## When NOT to Use

- 用户要求做 **Meta 分析** 本身（检索、筛选、合并）——那是 `nsfc-proposal-generator` 的职责
- 用户要求 **撰写标书** 或 **立项依据**——那是 `nsfc-proposal-generator` 的职责
- 用户只要求 **一句话摘要** 或 **Abstract 翻译**——直接回复即可，无需加载本 skill
- 用户要求 **批量文献筛选**（如从 200 篇摘要中筛合格文献）——这不是单篇精读场景

## 输入要求

- **必需**：一篇医学文献的全文（PDF 文件路径 / 直接粘贴正文文本）
- **可选**：用户指定的研究方向关键词（如"抗 VEGF 药物相关眼内炎的危险因素"），用于"与我研究方向对接价值"栏

## 输出规范

- 输出一份 Markdown 格式的结构化摘录报告
- 全程使用表格 + 列表，禁止使用"探讨/研究/分析"等模糊动词
- 每一栏必须填实数据或标注"原文未报告"
- 不适用的轨道整段标注"本轨道不适用（判定为 X 型）"
- 数值带单位与 95%CI 或 mean±SD/SEM（标注 n）
- 引用原文关键句时使用引号并标注页码/段落

## 执行流程

### Step 1: 加载提示词模板

读取 `references/prompt-template.md` 中的完整提示词模板，将其作为系统级指令加载。

### Step 2: 获取用户文献

- 若用户提供 PDF 文件路径 → 用 Read 工具读取 PDF 内容
- 若用户直接粘贴文献正文 → 直接使用
- 若用户只给了摘要 → 提示"仅基于摘要精读，部分维度将标注'原文未报告'，建议补充全文"

### Step 3: 获取研究方向关键词

询问用户（或从上下文推断）其研究方向关键词，填入 `[此处替换你的方向]` 占位符。若用户未指定，使用"未指定方向，仅做通用精读"。

### Step 4: 按模板执行精读

严格按 `references/prompt-template.md` 的结构执行：

1. 填写文献背景（含数据/材料可及性、伦理与合规）
2. 执行 Step 0 研究类型判别（路由入口）
3. 根据判别结果走对应轨道（A/B/C/D/E）
4. 填写全轨道通用的结论、创新之处、不足之处
5. 填写其他必要信息（证据质量初评、对接价值、可复用性、引用与延伸）

### Step 5: 输出报告

将完整精读报告输出给用户。若用户要求保存为文件，写入 `/workspace/` 目录。

## 提示词模板核心结构

```
文献背景 → 研究类型判别(路由) → 科研问题
  ├─ 轨道A：临床研究（方法+结果）
  ├─ 轨道B：动物实验（方法+结果）
  ├─ 轨道C：细胞实验（方法+结果）
  ├─ 轨道D：分子机制（方法+结果）
  └─ 轨道E：混合型联动判断
→ 结论 → 创新之处 → 不足之处 → 其他必要信息（GRADE/SYRCLE/rigor + 对接价值 + 可复用性 + 引用延伸）
```
