# 各期临床试验运营管理要点速查

## I 期临床试验

| 维度 | 运营要点 |
|------|---------|
| 典型特征 | 健康受试者（少数抗肿瘤药采用患者）；样本量 20-100 例；单中心为主（或 2-3 中心） |
| 重点运营挑战 | 密集的 PK/PD 采样时间点、住院期间受试者管理、SAD/MAD 剂量爬坡决策 |
| 中心选择 | 通常选择 I 期临床研究中心（BE/I 期病房）；需具备密集样本采集与处理能力 |
| CRO 协调要点 | 多需要专业 I 期 CRO；重点在样本管理链（采集 → 处理 → 运输 → 检测）的 SOP 一致 |
| 监查重点 | 剂量爬坡决策点记录、SAE 的及时识别与报告、知情同意过程的合规记录 |
| 预算特点 | 单中心运营成本相对集中；研究者费以观察费 + 样本采集费为主 |

## II 期临床试验

| 维度 | 运营要点 |
|------|---------|
| 典型特征 | 患者受试者；样本量 100-500 例；多中心（通常 5-30 中心） |
| 重点运营挑战 | 概念验证（PoC）目标明确、试验设计可能中途调整（如适应性设计）、剂量选择决策 |
| 中心选择 | 需选择具备目标适应症患者资源的中心；考虑竞争临床试验情况 |
| CRO 协调要点 | CRO 的治疗领域经验至关重要；数据管理需求增加（EDC 配置、CRF 设计） |
| 监查重点 | 入组合格性、方案偏离的早期识别、安全性数据的完整收集 |
| 常见问题 | 入组慢（因患者入排标准严格）、数据质量问题（新增中心的 CRA 培训不足） |

## III 期临床试验（确证性试验）

| 维度 | 运营要点 |
|------|---------|
| 典型特征 | 大样本量（300-3000+ 例）；多中心 / 多国（20-200+ 中心）；时间长（1-5 年） |
| 重点运营挑战 | 入组节奏管控、多中心一致性（多国、跨文化）、数据质量标准化监管递交要求 |
| 中心选择 | 按地域分层选择（考虑各监管机构的申报要求）；全球多区域试验需平衡各地区入组 |
| CRO 协调要点 | 通常采用全球 CRO 或区域性 CRO 组合；Joint Governance Meeting 机制至关重要变更管理最多（方案修订频繁、中心增删、预算变更） |
| 监查重点 | SDV 策略（基于风险的 SDV 比例）、关键数据的完整性、SAE/SUSAR 报告合规、TMF 维护 |
| 入组策略 | 跨国多中心入组竞赛 vs 按区配额控制；常见混合模式：按国家设定目标但允许内部调整 |
| 预算特点 | 成本最高、周期最长；常见预算挑战：试验延长导致的 CRO 费用超支、汇率波动（多国合作） |

## IV 期临床试验 / 上市后研究

| 维度 | 运营要点 |
|------|---------|
| 典型特征 | 已获批上市药物；样本量大（1000+~数万例）；中心多（可覆盖基层医院） |
| 重点运营挑战 | 监管递交后的承诺性研究有时间压力、入组可能因竞争上市而受影响、安全性信号积累 |
| 中心选择 | 可包括社区医院和基层医疗单位；需要考虑受试者可及性和长期随访 |
| 监查策略 | 通常采用轻量级监查（RBM 优先）；数据收集范围有限（主要关注安全性） |
| 常见模式 | 真实世界研究（RWS）设计；简化版 CRF、电子化随访工具、集中化数据处理 |

## 真实世界研究（RWS / RWD）

| 维度 | 运营要点 |
|------|---------|
| 数据来源 | HIS/EMR、医保数据、注册登记数据、患者报告结局（PRO）、可穿戴设备 |
| 研究设计 | 前瞻性/回顾性队列、病例对照、单臂研究 |
| 法规背景 | NMPA《用于产生真实世界证据的真实世界数据指导原则》（2021）；ICH E8(R1) 中 RWD 的讨论 |
| 运营特点 | 无传统意义上的"监查"但需数据质量核查（源数据一致性校验）；伦理审查可简化（回顾性研究）；通常不设 CRF，而是从现有数据系统中提取 |
| CRO 角色 | 数据治理和分析是核心工作；部分 CRO 与大数据公司合作提供 RWS 服务 |

## 医疗器械临床试验

| 维度 | 运营要点 |
|------|---------|
| 法规框架 | 中国：NMPA《医疗器械临床试验质量管理规范》（2022）；美国：21 CFR Part 812；欧盟：MDR 2017/745 |
| 与药物试验差异 | ① 无严格"分期"概念，通常为可行性研究 + 关键研究 + 上市后研究；② 受试者多为患者；③ 终点不同（安全性与性能评价、可用性）；④ 申办方职责涵盖器械维护和培训 |
| 运营要点 | 器械操作培训（研究者/受试者）是启动关键；盲法实施更复杂（假手术/虚假设备）；产品迭代可能发生在研究进行中（需变更管理）；中心选择需考虑器械操作经验 |
| CRO 协调 | 需要具有医疗器械经验的 CRO；器械相关的不良事件报告规范与药物 SAE 不同 |

## 跨期通用运营要点

| 事项 | 运营建议 |
|------|---------|
| TMF 管理 | 无论分期，TMF 是稽查/核查的关注重点。使用 TMF 参考索引（ICH E6 8 章节/中国 GCP 附录）确保完整性 |
| 培训管理 | 所有涉及试验人员均需 GCP 培训、方案培训、特定操作培训（设备/量表/评估方法） |
| 变更管理 | 方案修订 → 伦理重新审批 → 合同变更（如涉及资源变化）→ 所有中心更新文件 → 再培训 |
| 沟通管理 | 建立 Sponsor-CRO-Site 三级沟通矩阵；定期信息同步（周报/月报/治理会议） |
| 应急计划 | 各阶段均需制定应急计划：PI 更换、中心关闭、关键 CRA 离职、数据泄露、严重方案偏离 |
