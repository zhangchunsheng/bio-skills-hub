# 临床药学日常工作助手 · clinical-pharmacy-workflow

## Overview

为临床药师日常四大高频工作场景(用药咨询、ADR 评估与报告、处方/医嘱点评、PIVAS 审核)提供结构化流程模板与输出规范,确保每项产出:结论明确、证据可溯源、人工可复核、隐私已脱敏。可与文献检索、数据分析等技能配合,形成"检索 → 分析 → 决策支持"闭环。

## 工作场景路由

先识别用户请求属于哪个场景,再进入对应流程。多场景混合时逐场景处理。

| 用户输入特征 | 场景 |
|:---|:---|
| 咨询 / 问答 / 能不能用 / 怎么用 / 相互作用 | 场景 1 · 用药咨询应答 |
| ADR / 不良反应 / 怀疑某药引起 / 因果评估 / 上报 | 场景 2 · ADR 评估与报告 |
| 点评 / 处方审核 / 医嘱审核 / 这样用合理吗 | 场景 3 · 处方/医嘱点评 |
| PIVAS / 配置 / 配伍 / 溶媒 / 浓度 / 输注 | 场景 4 · PIVAS 审核 |

## 场景 1 · 用药咨询应答

**流程:**
1. 提取咨询要素:药物、患者特征(年龄/肝肾功能/妊娠哺乳)、疑问类型
2. 调取证据:说明书、指南、相互作用库(见 `references/clinical-notes.md`)
3. 生成结构化应答(7 要素)

**输出模板:**

| 要素 | 内容 |
|:---|:---|
| 答复结论 | 一句话直接回答 |
| 用法用量 | 剂量/频次/疗程(按适应证区分) |
| 相互作用 | 与患者当前用药交叉核对结果 |
| 禁忌/慎用 | 特殊人群要点 |
| 不良反应与监测 | 观察点与复查建议 |
| 患者指导 | 服药时间/漏服处理/生活注意 |
| 证据来源 | 说明书版本/指南/文献 |

**自检:** 剂量具体可执行?证据标注来源?有无虚构?

## 场景 2 · ADR 评估与报告

**流程:**
1. 信息收集:患者(脱敏)、怀疑药品、并用药品、事件时间线、临床与实验室表现、处置转归
2. 因果评估:按 WHO-UMC 六档逐项核对(时间关联/去激发/再激发/生物学合理性/其他原因)
3. 严重性分级:死亡、危及生命、住院、致残、先天异常、重要医学事件
4. 判定上报类别与时限(以现行《药品不良反应报告和监测管理办法》为准)
5. 撰写报告要素

**输出:** 因果评估结论(附六档依据)+ 严重性分级 + 报告要素表 + 上报时限提示。

**自检:** 六档依据逐条列出?时间关联/去激发/再激发均覆盖?未臆断因果?

## 场景 3 · 处方/医嘱点评

**流程:**
1. 提取用药清单与患者信息
2. 逐维度点评(7 维度:适应证/用法用量/相互作用/重复用药/特殊人群/配伍/超说明书)
3. 逐条产出:问题描述 → 依据 → 建议

**输出:** 点评意见表(序号/药品/问题类型/依据/建议/严重程度)。

**自检:** 每条点评都有法规或说明书依据?建议可执行?未遗漏重复用药与相互作用?

## 场景 4 · PIVAS 审核

**流程:**
1. 核对药品与剂量
2. 检查溶媒与浓度(对照说明书,注意浓度上限)
3. 查配伍相容性(同袋/同管)
4. 核对输注条件与稳定性
5. 给出审核结论

**输出:** 审核结论表(医嘱/问题/风险等级/处理建议)。

**自检:** 浓度计算已复核?配伍结论有说明书或配伍表依据?风险等级明确?

## 安全与职业边界(必须遵守)

- 所有输出为 **AI 辅助决策支持**,不替代药师专业判断;对外答复前须经药师复核。
- **禁止虚构**:剂量、相互作用、配伍、不良反应信息;证据不足时标注"待核对"。
- **数据脱敏**:患者信息去标识化(姓名/证件号/联系方式不得出现在输出中)。
- 超说明书用药:标注依据来源,提示按本院规定履行知情同意与备案流程。
- 急危情况(严重过敏、大出血等):先提示立即线下处置,不延误。
