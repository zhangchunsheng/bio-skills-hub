# 临床药学日常工作 · 场景速查要点

生成任何输出前,先读取本文件确定证据来源与检查要点。

## 一、权威证据来源(输出时优先引用,标注版本/日期)

| 用途 | 来源 | 说明 |
|:---|:---|:---|
| 药品说明书 | NMPA 批准的现行说明书 | 用法用量/禁忌/相互作用第一依据,须注明版本 |
| 诊疗指南 | 中华医学会分会指南、ESC/ACC/AHA、NICE 等 | 标注发布年份与版本 |
| 相互作用 | 现行说明书、Lexicomp/Micromedex(机构可用)、NMPA 提示 | 不凭记忆,须查库或说明书 |
| ADR 判定 | WHO-UMC 因果评估方法、《药品不良反应报告和监测管理办法》 | 上报时限与类别以现行办法为准 |
| 处方点评 | 《处方管理办法》《医院处方点评管理规范(试行)》、抗菌药物临床应用指导原则 | 点评意见附条文/规范依据 |

## 二、用药咨询应答要点

**应答结构(7 要素):**
1. 答复结论(一句话直接回答)
2. 用法用量(剂量、频次、疗程,按适应证区分)
3. 相互作用(与患者当前用药交叉核对)
4. 禁忌与慎用(特殊人群:妊娠哺乳、肝肾功能不全、老年、儿童)
5. 不良反应与监测(需观察什么、何时复查)
6. 患者指导(服药时间、漏服处理、饮食生活注意)
7. 证据来源(说明书版本/指南/文献)

**高频咨询类型:** 剂量与用法、相互作用、特殊人群用药、妊娠哺乳期用药、漏服处理、注射剂配伍。

## 三、ADR 评估与报告

**WHO-UMC 因果评估六档:** 肯定 / 很可能 / 可能 / 可能无关 / 待评价 / 无法评价。

评估时逐项核对:
- 时间关联(用药与事件的时间顺序是否合理)
- 去激发(停药后事件是否减轻/消失)
- 再激发(再次用药是否复发)
- 生物学合理性(机制上是否可解释)
- 其他原因(原发病、并用药品能否解释)

**严重性分级(以现行法规为准):** 死亡、危及生命、导致住院或住院时间延长、致残/功能丧失、先天异常/出生缺陷、其他重要医学事件。

**报告要素(ADR 报告表):** 患者信息(脱敏)、怀疑药品(名称/剂型/剂量/疗程)、并用药品、事件描述(时间线/临床表现/实验室指标)、处置经过与转归、因果关系初步评估。

## 四、处方/医嘱点评

**点评维度(7 项):**
1. 适应证与禁忌
2. 用法用量(剂量/频次/疗程;注射剂另查溶媒/浓度/输注速度)
3. 相互作用(药物-药物、药物-食物)
4. 重复用药(同成分、同药理机制)
5. 特殊人群(肝肾功能调整、老年、妊娠哺乳、儿童)
6. 配伍禁忌(注射剂同袋/同管)
7. 超说明书用药(标注依据,提示备案流程)

**意见格式:** 合理 / 不合理(问题类型)→ 依据 → 建议调整方案。

## 五、PIVAS 审核

**审核顺序:**
1. 处方适宜性(适应证、剂量)
2. 溶媒与浓度(按说明书,注意浓度上限)
3. 配伍相容性(同袋/同管,查配伍表)
4. 输注条件(速度、避光、输液器材质)
5. 稳定性(配制后保存时间与条件)

**提示:** 配伍与稳定性结论必须查说明书或配伍表,不凭记忆;pH 敏感药物、高警示药品为审核重点。

## 六、通用原则

- 所有输出为 AI 辅助决策支持,须药师按说明书/指南复核后方可对外使用。
- 不虚构剂量、相互作用、配伍结论;证据不足时显式标注"待核对"。
- 患者信息一律脱敏:姓名→编号,去除身份证号、手机号等可识别信息。
- 急危情况(严重过敏、大出血等)先提示线下紧急处置,不延误。
