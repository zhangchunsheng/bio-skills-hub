# Teaching Plan Generation

Generate a level-appropriate lesson plan. Use the unified 7-section structure; for Level 3 add
the Academic Discussion Section. Fill every section from verified sources — never invent cases,
findings, or citations.

## Unified Structure

```
# Clinical Teaching Rounds Lesson Plan — <Disease> (Level <N>)

## 1. Clinical Case Introduction
- Presenting complaint, context, and a representative (clearly labeled illustrative) case vignette.

## 2. Learning Objectives
- 3–5 measurable objectives matched to Level (e.g., Level 1: "independently initiate first-line therapy").

## 3. Clinical Reasoning Discussion
- Differential diagnosis, reasoning chain, key discriminating features.

## 4. Diagnosis and Management
- Diagnostic workup, treatment strategy, monitoring, prognosis, follow-up. (Level 2+: include guideline comparison.)

## 5. Evidence Review
- Key studies / guidelines supporting management. Cite evidence level (RCT / meta / guideline / RWS).
  Level 2+: include specific RCT/meta and domestic-vs-international guideline comparison.

## 6. Teaching Questions (evidence-anchored — see references/teaching_questions.md)
- 3–6 questions, each **pinned to a specific guideline recommendation or landmark study** already
  presented in the dossier (no generic questions).
- Use the question-item schema: Q → Anchor (citation + GRADE) → Model answer (L1/L2) /
  Appraisal (L3) → Pitfall → Follow-up (L2/L3).
- Level 1 anchors to domestic first-line guidelines; Level 2 to guideline comparisons + key RCTs;
  Level 3 to recent (≤5 yr) RCTs/papers with critical appraisal.
- End the section with a **Question → Source map** table proving traceability to Evidence
  Summary / Guideline Analysis (see references/evidence_format.md §6).

## 7. Summary
- One-paragraph take-home message.
```

## Level 3 — Academic Discussion Section (append after section 7)

```
# Academic Discussion Section

## Current Research Landscape
- State of the field for <Disease> over the last 5 years.

## Key Landmark Studies
- 2–4 landmark papers (last 5 yrs preferred): citation, design, finding, impact, limitations.

## Mechanistic Insights
- Phenotype → cellular → molecular → biomarker → target mapping.

## Controversies
- Unresolved questions and conflicting guideline recommendations.

## Future Research Proposal
- A concrete, feasible research question + suggested design (cohort / RCT / biomarker / multi-omics / translational) and likely publication tier.
```

## Level depth guidance

- **Level 1:** keep management to first-line, routine monitoring; objectives on competence.
- **Level 2:** emphasize complex-case reasoning, EBM, and guideline comparison tables.
- **Level 3:** full academic section; explicit evidence levels; forward-looking research plan.
