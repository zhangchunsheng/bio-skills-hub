### Tips for learners
- Use precise verbs: *complain of, report, deny, endorse, note*.
- State normal findings briefly ("HEENT within normal limits") before abnormal ones.
- Frame uncertainty: *"Most consistent with…", "Less likely but must not miss…"*
- Bedside communication: ask permission, explain steps, use plain-language checks ("Does that make sense?").
