# NGS 信号分析

- 唯一标识：`hub-deeptools`
- 显示名称：NGS 信号分析
- 能力摘要：使用 deepTools 完成 BAM 到 bigWig 转换、覆盖度归一化、样本相关性/PCA/指纹质控及 ChIP-seq、RNA-seq、ATAC-seq 的热图和信号谱图。

## 案例素材

1. ChIP-seq 实验有多个生物学重复。该 skill 会先检查 BAM 索引和文件质量，计算样本相关性、PCA 和富集指纹，再决定是否有样本需排除。
2. 研究者要展示转录起始位点周围的组蛋白修饰。该 skill 会从归一化覆盖轨道计算信号矩阵，生成热图和 profile，并清晰标注参考基因组和窗口参数。
3. RNA-seq 需要输出链特异性覆盖轨道。该 skill 会采用适当的链过滤与归一化，避免错误延伸 reads 跨越剪接位点，供基因组浏览器复核。
