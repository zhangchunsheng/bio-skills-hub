# 陪诊师职业指南 使用指南

## 怎么用
1. 告诉我你的具体场景或想了解的方向（职业入门 / 给家人做照护方案 / 居家改造 / 陪诊引导）。
2. 我按范围给结构化指引、清单或方案框架。
3. 涉及重大医疗/护理/法律事项，提示你咨询持牌专业人士。

## 合规说明
本 Skill 仅提供科普、框架与清单，**非执业医疗/护理/法律专业意见**，不替代医生、护士、执业护理员或持牌专业人士；涉及用药、康复、诊疗、法律文件等重大事项，请务必咨询持牌专业人士。不代办、不承诺疗效/收入/岗位、不落本地文件。

## 关于权限
本 Skill 纯输出（指引/清单/方案框架），不写本地文件，无需开启「允许完全访问」。
