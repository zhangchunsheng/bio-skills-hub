# 上海第二工业大学 · 新生入学指南（快速上手）

> 写给刚踏入二工大的你。本指南把《学生手册》里新生最常遇到的问题整理成一份
> 「开学 Checklist + 十问十答」。具体条款以学校最新官方通知为准。

## 一、开学前 / 报到
- 凭录取通知书按学校规定期限到校办理入学手续；因故不能按期入学须**书面请假，一般不得超过两周**，逾期视为放弃入学资格。
- 新生入学后，学校会在 **3 个月内** 按国家招生规定进行复查（录取手续、资格真实性、身份一致性、身心健康状况等）。
- 患病不宜在校学习者，可**保留入学资格 1 年**（保留期间无学籍）；应征入伍保留至退役后 2 年。

## 二、每学期必做：注册
- 开学 **1 周内**，凭「已交学费记录 + 本人学生证」办理注册。
- 未缴学费或不符注册条件者不予注册；家庭经济困难可申请助学贷款/资助后再注册。
- 无正当理由逾期未注册 → 不能修读当学期课程、不能使用教学资源。

## 三、宿舍生活（最容易踩坑）
- **违章电器红线**：无「3C」认证、输入电压 >36V 的电加热器、功率 >20W 的电加热电器、大功率吹风机都算违章；电炉、电饭锅、电水壶、电熨斗、电热毯等一律禁用。床上不得放交流电源电器，接线板不得串联/并联，铁架床严禁绑接线板。
- **行为分**：每学年初始 100 分。扣满 40 分→通报批评 + 取消当学年各类评优资格；扣满 70 分→原床位试住警告 + 警告处分；扣满 100 分→退宿 + 严重警告。
- 就寝时段 **23:00–5:00**，无特殊情况不得离开生活园区；园区内禁止违规经营性活动、零食销售、打麻将。
- 调床位需书面申请，经辅导员同意、学院批准；退宿后 1 日内搬离物品。

## 四、看病报销
- 生病先到**校卫生所**就诊，凭校园卡/校园码挂号取病史卡；每次配药一般不超过 3 天用量。
- 校内门诊费用**学校付 90%、个人付 10%**。
- 急诊或转诊到校外定点医院，回校报销，起付线 300 元。
- 外省市急诊住院：垫付后 **6 个月内** 由校卫生所统一报销。
- 异地就医：办备案后可持社保卡跨省直接结算。未按年度缴费不享受居民医保待遇。

## 五、学习与考试
- **选课**：开课后 2 周内可试听退选/改选；有先行后续关系的课先选先行课。
- **缺课预警**：无故缺课或缺交作业超过该课学期要求 1/3，不得参加考核。
- **考试纪律**（重中之重）：
  - 违纪 → 该科记 0 分、注明「违纪」，可重修不可补考，视情警告/严重警告。
  - 作弊 → 记 0 分、注明「作弊」，不可补考并处分；代考、替考、组织作弊、用通讯设备作弊、二次作弊 → **开除学籍**。
  - 考试作弊等学术不端 → **取消学士学位授予资格**。
- 成绩异议：发布后 **5 个工作日内** 书面申请查分。
- 绩点：课程成绩绩点 =（成绩−50）/10。

## 六、体育与晨练
- 晨练与课外体育锻炼占体育成绩 **20%**，设及格线；未达线则学期体育成绩「不及格」。
- 适用对象：一、二、三年级学生及体育重修学生。

## 七、奖学金 & 资助（努力就有回报）
- 奖学金分**优秀学生奖学金、单项奖学金**两大类；申请基本条件：热爱祖国、品德优良、学习勤奋、遵纪守法、体育合格。
- 资助体系：国家奖学金 / 励志奖学金 / 上海市奖学金 / 校长奖 / 国家助学金 / 学费减免 / 临时困难补助 / 勤工助学（每周≤8h、每月≤40h）。
- 综合测评成绩是奖学金、优秀评选、就业推荐的重要依据。

## 八、第二课堂（毕业硬指标）
- 第二课堂纳入培养计划 **1 学分（积分制）**：四年制本科须完成 **8 积分**、三年制本科 **6 积分** 方可毕业。
- 含社会实践、报告与讲座、校园文化活动、创新创业活动；其中社会实践、报告讲座、校园文化三类各有最低积分要求。

## 九、转专业（想换赛道看这里）
- 学校优先考虑：**休学创业、退役后复学** 学生。
- 一般**不予转**：特殊招生形式录取、录取前明确约定不能转、中外合作/艺术类专业跨类转、已转过一次专业。
- 办程序公平公示，具体见学生手册「学生转专业实施办法」。

## 十、权益与申诉
- 受处分或对学校决定不服：先向**学生申诉处置工作小组**申诉；不服再向校师生员工申诉委员会提出；仍不服可于接到决定 **15 日内** 向上海市教委书面申诉。
- 申诉书含：基本情况、事项理由要求、证据材料、原处理决定复印件、日期与亲笔签名。

## 开学 Checklist（可逐项打勾）
- [ ] 按时报到 / 请假不超过两周
- [ ] 开学 1 周内完成注册（先缴学费）
- [ ] 熟读宿舍违章电器清单，不带电炉电饭锅等
- [ ] 记住就寝时段 23:00–5:00
- [ ] 保存校卫生所就诊规则，备好校园卡/校园码
- [ ] 开学 2 周内完成试听退改选
- [ ] 严守考试纪律，绝不违纪作弊
- [ ] 规划第二课堂积分（四年制 8 / 三年制 6）
- [ ] 关注奖学金与资助申请时间窗
- [ ] 记住申诉渠道，权益受损依法申诉
