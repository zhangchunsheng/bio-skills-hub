# 药剂科月度工作汇报助手（pharmacy-monthly-report）

## Overview

本技能封装药剂科主任月度科室例会汇报的标准工作流，由药剂科管理视角驱动，解决三大现实痛点：①各业务模块数据散落、口径不一（处方点评、ADR、抗菌药、盘点等来自不同系统/不同人提交）；②每月重新组织格式、重复劳动；③院领导关注层次与科室内部关注层次混在一起，问题分析流于表面、缺 PDCA 闭环。

输入各模块原始数据后，依次执行四个环节：
1. **指标核算与口径统一**（加载 `references/指标体系与核算口径.md`）
2. **结构化撰写九章节**（加载 `references/汇报结构_月度科室例会.md`）
3. **双格式输出 Word + PPT**（加载 `references/双格式输出规范.md`）
4. **自查与交付**（加载 `references/自查与质控清单.md`）

四环节共享全局硬性约束，每环节完成后输出自查报告。

## When to Use

- 药剂科主任准备月度科室例会汇报
- 药剂科季度小结、半年/年度总结（结构可扩展）
- 专项工作汇报（抗菌药专项整治、ADR 季度分析、基药配备等）
- 院领导要求提交的药剂科月度运行材料
- 用户明确要求「药剂科月报」「科室例会汇报」「处方点评汇总」「ADR 上报分析」「药品盘点分析」「用药差错分析」「PDCA」之一或组合

触发关键词：药剂科月报、科室例会汇报、处方点评汇总、ADR 上报分析、抗菌药物使用强度、AUD、药品盘点分析、用药差错、PDCA、药剂科工作汇报、药剂科季度总结、合理用药点评、近效期药品、抗菌药使用率、集采药品执行、国家组织药品集中采购。

## Workflow

### Step 0：信息收集（必做）

启动前确认以下信息，缺失项主动询问用户，不臆造数据：

**汇报基本信息**
- 汇报周期（如「2026 年 7 月」）
- 汇报对象（科室内部例会 / 院领导 / 药事委员会）
- 输出格式偏好（Word 归档 / PPT 演示 / 两者都要）——默认两者都要
- 上月同期数据是否可提供（决定能否计算环比）

**各业务模块原始数据**（按模块逐项收集，用户给多少算多少，缺失模块在汇报中标注「本月暂缺」而非编造）
- 处方点评：点评处方数、不合理处方数及分类（适应证/用法用量/配伍/重复用药等）
- ADR：本月新上报例数、新的/严重 ADR 例数、典型病例
- 抗菌药：门诊/住院抗菌药使用率、AUD、限制级与特殊使用级比例、Ⅰ类切口预防用药情况
- 药品供应：库存金额、周转天数、金额 Top10、近效期药品、缺药记录
- 用药差错：差错例数及分级（A–I 级）、near miss 例数、典型事件
- 人员培训：本月继教/培训场次与人数、排班执行情况、人员异动
- 用药咨询：咨询例数、典型咨询案例

信息齐全后进入 Step 1。对缺失数据，先列出「需补齐数据清单」交用户确认，再继续。

### Step 1：指标核算与口径统一

加载 `references/指标体系与核算口径.md`，按统一国标口径核算各模块核心指标：

1. **处方点评模块**：门诊处方合格率 = (点评处方数 − 不合理处方数) / 点评处方数 × 100%；不合理处方分类占比；环比/同比
2. **ADR 模块**：本月上报例数、新的/严重 ADR 占比、上报及时率（发现至上报时限）
3. **抗菌药模块**：AUD（DDDs/100 人天）、门诊/住院使用率、限制级与特殊使用级占比、Ⅰ类切口预防用药率
4. **药品供应模块**：库存周转天数 = 平均库存金额 / 日均出库金额、近效期药品金额占比、缺药品种数
5. **差错模块**：差错分级分布、near miss 捕获率 = near miss / (差错 + near miss) × 100%

**口径硬约束**：所有率值分子分母必须明示；环比/同比口径固定（与上月同期、上年同期）；指标定义不得自创，必须对应国标或行业规范出处（见 references）。

**输出**：指标核算汇总表（指标名 / 本月值 / 上月值 / 环比 / 目标值 / 是否达标 / 口径出处）。

### Step 2：结构化撰写九章节

加载 `references/汇报结构_月度科室例会.md`，按标准九章节撰写正文（月度版可按需在第 5 章后增设「集采药品执行」独立章，扩为十章节，后续章节顺延）：

1. **本月工作概述**：核心数据一览表（关键指标本月值 + 环比 + 达标情况）
2. **处方点评与合理用药**
3. **ADR 监测与药物警戒**
4. **抗菌药物专项整治**
5. **药品供应与盘点**
6. **用药差错与 near miss 分析**
7. **人员培训与排班**
8. **用药咨询与患者教育**
9. **本月问题与 PDCA 改进 + 下月工作重点**

**结构硬约束**：
- 第 1 章必含「核心数据一览表」，禁止只放文字
- 第 2–7 章每章必含「数据呈现 → 同比环比 → 问题识别」三段式
- 第 8 章（问题与改进）必含 PDCA 四要素（Plan 问题与目标 / Do 措施 / Check 效果 / Act 标准化），禁止只列问题不给措施
- 第 9 章下月重点必与第 8 章问题一一对应

字数控制：正文 2500–3500 字（科室例会版）；季度/年度扩展至 5000–7000 字。

### Step 3：双格式输出（Word + PPT）

加载 `references/双格式输出规范.md`，同步产出两份交付物：

**Word 归档材料**（.docx）：
- 完整九章节正文 + 全部表格
- 适合归档、留痕、上交
- 调用 docx 能力生成，遵循医院公文排版（标题宋体/正文仿宋或按院方规范）

**PPT 演示版**（.pptx）：
- 10–15 页，提炼关键数据 + 图表
- 每章一页核心数据 + 一页问题改进
- 调用 pptx 能力生成，遵循演示排版（大字号、少文字、图表优先）

**双格式映射硬约束**：PPT 每页数据必须能在 Word 正文中找到对应；两份交付物关键数值必须完全一致，禁止 PPT 与 Word 数据打架。

### Step 4：自查与交付

加载 `references/自查与质控清单.md`，逐项自查后交付：

1. **数据口径自查**：所有率值分子分母已明示、环比同比口径一致、指标定义有出处
2. **完整性自查**：九章节齐全（或十章节含集采独立章）、PDCA 四要素齐全、核心数据一览表齐全
3. **一致性自查**：Word 与 PPT 关键数值逐项一致（用三列核对表：校验项/Word值/PPT值/是否一致）、正文与表格数值一致
4. **禁用词与表述自查**：见全局约束
5. **核实事项清单**：列出需用户核实/替换的占位数据（HIS 导出数字、人名、具体日期）
6. **视觉 QA**：PPT 逐页版面检查；Windows 环境下自动转图常不可用（LibreOffice AF_UNIX socket 不兼容、pdftoppm 缺失），改为列出人工核对要点交用户在 PowerPoint 中确认

**输出**：Word + PPT 两份文件 + 自查报告 + 待核实事项清单。

## 硬性约束（全局，四环节共用）

加载 `references/自查与质控清单.md` 全文，全程遵守：

1. **数据真实**：禁止臆造任何数据；缺失数据标注「本月暂缺，待补」而非填零或编造
2. **口径统一**：所有指标必须对应国标或行业规范出处，不得自创定义；率值必写分子/分母
3. **环比同比**：口径固定，上月同期与上年同期并列，便于趋势判断
4. **PDCA 闭环**：问题必给措施，措施必给效果核查节点，禁止「加强管理」「提高意识」等空话
5. **双格式一致**：Word 与 PPT 关键数值完全一致
6. **英文全称**：AUD、DDD、ADR、near miss、PDCA 等首次出现附全称
7. **禁用词**：加强管理/提高认识/高度重视/取得了良好效果/信效度良好/视情况而定/根据经验/按计划推进/采取措施/深入推进/不断完善/卓有成效/成效显著/再上新台阶/圆满完成/顺利开展
8. **自查报告**：每环节必输出

[自查表 + 禁用词核查 + 完整性核查 + 待核实事项]
