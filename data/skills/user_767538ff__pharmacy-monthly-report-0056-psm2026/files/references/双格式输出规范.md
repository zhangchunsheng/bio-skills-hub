# 双格式输出规范（pharmacy-monthly-report）

本文件定义 Word 归档材料与 PPT 演示版两份交付物的排版规范、章节映射、图表要求与一致性校验规则。Step 3 双格式输出必须遵循本规范。

---

## 一、Word 归档材料（.docx）

### 1.1 文档结构
- 封面：标题《XX医院药剂科 2026年X月 工作汇报》+ 汇报人 + 日期
- 目录（自动生成）
- 正文：九章节（按 `汇报结构_月度科室例会.md`）
- 附表：核心数据一览表、指标核算汇总表、PDCA 改进表、近效期清单等
- 落款：药剂科 + 日期

### 1.2 排版规范（医院公文风格，可按院方实际调整）
- 标题：宋体 / 二号 / 加粗 / 居中
- 一级标题：黑体 / 三号 / 加粗
- 二级标题：楷体 / 四号 / 加粗
- 正文：仿宋_GB2312 或 仿宋 / 三号 / 行距 1.5
- 表格：宋体 / 小四 / 表头加粗底纹
- 页边距：上下 2.54cm，左右 3.18cm（或院方公文标准）
- 页码：底部居中

### 1.3 生成方式
调用 docx 能力（python-docx 或内置 docx skill）生成 .docx 文件，保存至工作区 outputs 目录。

### 1.4 内容要求
- 完整九章节正文 + 全部表格（不得省略表格只留文字）
- 数据必须与 Step 1 指标核算汇总表完全一致
- PDCA 改进表完整呈现四要素
- 待核实事项以脚注或文末「⚠️待核实」清单列出

---

## 二、PPT 演示版（.pptx）

### 2.1 页数与结构（10–15 页）
| 页码 | 内容 | 对应 Word 章节 |
|------|------|----------------|
| P1 | 封面（标题+汇报人+日期） | 封面 |
| P2 | 本月核心数据一览表 | 第1章 |
| P3 | 处方点评（合格率+不合理分类图） | 第2章 |
| P4 | ADR 监测（例数+涉及药品TOP10） | 第3章 |
| P5 | 抗菌药专项整治（AUD+使用率+Ⅰ类切口） | 第4章 |
| P6 | 抗菌药重点品种专项 | 第4章 |
| P7 | 药品供应盘点（周转+TOP10+近效期） | 第5章 |
| P8 | 用药差错分析（分级+环节+根因） | 第6章 |
| P9 | 人员培训与排班 | 第7章 |
| P10 | 用药咨询典型案例 | 第7章 |
| P11 | 本月问题与PDCA改进（TOP3） | 第8章 |
| P12 | PDCA 措施与核查节点 | 第8章 |
| P13 | 下月工作重点 | 第9章 |
| P14 | 待核实/待决议事项 | — |

（季度/年度版可扩展至 18–22 页）

### 2.2 排版规范
- 主题：简洁商务（深蓝/医院主色，可按院方模板）
- 字号：标题 36pt / 正文 24pt / 注释 16pt
- 每页正文 ≤ 80 字，数据用图表呈现
- 图表：柱状图（环比/同比）、饼图（分类占比）、帕累托图（问题排序）
- 配色：涨用红、跌用绿（中国股市惯例，仅当涉及金额/数量增减时；达标绿未达标红可用交通灯色）

### 2.3 图表要求
- 合格率/使用率/占比：柱状图 + 目标线（虚线标注目标值）
- 环比趋势：折线图（至少 3 个月）
- 分类占比：饼图或条形图
- 不合理处方：帕累托图（柱+累计折线）
- 差错分级：堆叠柱状图

### 2.4 生成方式
调用 pptx 能力（python-pptx 或内置 pptx skill）生成 .pptx 文件，保存至工作区 outputs 目录。

## 三、双格式一致性校验规则（硬约束）

Step 3 输出前必做以下校验，不一致必须修正后方可交付。校验采用**逐项三列核对表**（校验项 / Word 值 / PPT 值 / 是否一致），将每个关键指标在两份文件中的实际数值并排比对，禁止只勾「是/否」不填值：

| 校验项 | Word 值 | PPT 值 | 一致 |
|--------|---------|--------|------|
| 门诊处方合格率 | | | ✓/✗ |
| 门诊抗菌药处方率 | | | ✓/✗ |
| ADR 上报例数 | | | ✓/✗ |
| 新的/严重 ADR 占比 | | | ✓/✗ |
| AUD（DDD/100人天） | | | ✓/✗ |
| 住院抗菌药使用率 | | | ✓/✗ |
| Ⅰ类切口预防用药率 | | | ✓/✗ |
| 集采各品种完成率（如有独立章） | | | ✓/✗ |
| 库存金额 | | | ✓/✗ |
| 周转天数 | | | ✓/✗ |
| 近效期占比 | | | ✓/✗ |
| 缺药品种数 | | | ✓/✗ |
| 差错例数（A–I 级） | | | ✓/✗ |
| near miss 例数 | | | ✓/✗ |
| near miss 捕获率 | | | ✓/✗ |
| 培训场次/人次 | | | ✓/✗ |
| 排班执行率 | | | ✓/✗ |
| 用药咨询例数 | | | ✓/✗ |
| PPT 每页对应 Word 章节 | — | ✓/✗ | ✓/✗ |
| PDCA 问题 Word 与 PPT 一一对应 | — | ✓/✗ | ✓/✗ |
| 待核实清单两份一致（项数） | | | ✓/✗ |
| PPT 页数 10–15 | — | 实际：__ | ✓/✗ |
| Word 表格完整未省略 | ✓/✗ | — | ✓/✗ |

**结构校验项**（非数值类，单独勾选）：
- 关键数值一致：PPT 每页出现的指标数值必须与 Word 正文/表格一致
- 指标口径一致：PPT 与 Word 使用同一口径（分子/分母/目标值）
- 章节对应：PPT 每页能在 Word 找到对应章节
- PDCA 对应：PPT 问题页与 Word 第 8 章一一对应
- 待核实标注一致：两份文件待核实事项清单一致

不一致处理：以 Step 1 指标核算汇总表为唯一数据源，修正 PPT 或 Word 中偏差方，修正后在表中标注最终一致值。

## 四、文件命名

- Word：`XX医院药剂科_2026年X月_工作汇报.docx`
- PPT：`XX医院药剂科_2026年X月_工作汇报.pptx`
- 自查报告：`XX医院药剂科_2026年X月_工作汇报_自查报告.md`

医院名称、月份、汇报人等信息在 Step 0 收集时确认，缺失用占位符并列入待核实清单。

---

## 五、图表数据源约定

所有图表数据来自 Step 1 指标核算汇总表，禁止在生成图表时重新输入数值（避免数据打架）。PPT 图表建议用 python-pptx 原生图表对象绑定数据，而非插入图片，便于核对。
