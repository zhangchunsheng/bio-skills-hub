# 自查与质控清单（pharmacy-monthly-report）

本文件为四环节共用的全局硬性约束、自查表、禁用词与英文全称规范。Step 1 与 Step 4 必加载本文件，全程遵守。

---

## 一、全局硬性约束

1. **数据真实**：禁止臆造任何数据；缺失数据标注「本月暂缺，待补」，禁止填零或编造
2. **口径统一**：所有指标必须对应国标或行业规范出处（见 `指标体系与核算口径.md`），禁止自创定义；率值必写分子/分母
3. **环比同比**：口径固定（上月同期 + 上年同期），便于趋势判断；缺失同期数据时标注「同期数据暂缺」
4. **PDCA 闭环**：问题必给措施，措施必给「责任人+时限」，措施必给效果核查节点，禁止空话
5. **双格式一致**：Word 与 PPT 关键数值、口径、PDCA、待核实清单完全一致
6. **英文全称**：首次出现附全称（见下表）
7. **禁用词**：见第三节，全程不得出现
8. **自查报告**：每环节必输出

## 三、禁用词清单

以下表述在正文与 PPT 中禁止出现，需替换为具体措施或数据：

**空话类**：加强管理 / 提高认识 / 高度重视 / 提高意识 / 强化培训 / 深入推进 / 不断完善 / 持续改进（无节点）/ 全面提升 / 扎实推进

**套话类**：取得了良好效果 / 成效显著 / 卓有成效 / 再上新台阶 / 圆满完成 / 顺利开展 / 圆满收官

**模糊类**：信效度良好 / 视情况而定 / 根据经验 / 按计划推进 / 采取措施 / 分阶段实施（无节点）

**冗余类**：众所周知 / 值得注意的是 / 综上所述 / 亟待解决 / 具有重要意义 / 深入探讨

**替换原则**：
- 「加强管理」→ 写清具体管理动作（如「每周一由调剂组长抽查 50 张处方核对四查十对执行」）
- 「提高意识」→ 写清培训内容+对象+学时+考核方式
- 「取得良好效果」→ 给出前后数据对比（如合格率从 92%→96%）
- 「持续改进」→ 写清下次核查节点与目标值

## 七、PPT 视觉 QA（逐页版面检查）

PPT 生成后须做逐页视觉检查，确认版面无溢出、图表渲染正常、卡片对齐。

**自动转图的已知限制（Windows 环境）**：
- LibreOffice 的 `soffice --convert-to pdf` wrapper 在部分 Windows 环境使用 AF_UNIX socket，与 Windows 不兼容，转换会失败
- `pdftoppm`（PDF 转图片）在多数 Windows 环境未预装，无法将 PDF 逐页转图供视觉检查
- 因此 Windows 环境下自动逐页视觉检查常不可用，须改为人工核对

**人工核对要点（在 PowerPoint 中打开后逐页确认）**：
- 核心数据一览表页：表格行数完整、未溢出页边
- 含图表页：图表正常渲染、数值标签可读、目标线显示
- 数据卡片页：多个卡片等宽对齐、数值居中
- PDCA 卡片页：卡片内文字未溢出底部
- 封面与各页标题条：配色一致、标题层级统一

**结论标注**：若自动转图不可用，在自查报告「视觉 QA」一节注明「本环境未能自动转图，已列出人工核对要点，建议用户在 PowerPoint 中核对」，不得跳过该节。

## 八、待核实事项模板

每环节产出后，单独列出需用户核实/替换的占位项（⚠️标注）：

```
⚠️ 待核实事项清单
1. 医院正式名称（封面/落款）—— 当前占位「XX医院」
2. 本月点评处方抽样数与制度规定是否一致
3. ADR 新的/严重占比本院年度目标值（当前默认 ≥15%）
4. AUD 本院目标值（当前默认 ≤40，待核实本院级别与目标责任书）
5. 近效期药品具体清单（需盘点系统导出）
6. 碳青霉烯类使用科室分布数据
7. PDCA 措施责任人与时限是否与科室实际排班匹配
8. 上月/上年同期数据（用于环比/同比）
```
