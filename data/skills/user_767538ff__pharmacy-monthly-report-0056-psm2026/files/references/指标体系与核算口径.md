# 指标体系与核算口径（pharmacy-monthly-report）

本文件为药剂科月度汇报各业务模块核心指标的统一定义、公式、分子分母、目标值与出处依据。所有指标核算必须以本文件口径为准，禁止自创定义。

> 说明：标注「待核实」的出处需与本院药事委员会最新 adopted 口径或上级最新文件核对后替换；目标值参照三级综合医院评审标准及抗菌药专项整治要求，具体以本院年度目标责任书为准。

---

## 一、处方点评与合理用药

### 1.1 门诊处方合格率
- **定义**：点评处方中合格处方所占比例
- **公式**：门诊处方合格率 = (点评处方数 − 不合理处方数) / 点评处方数 × 100%
- **分子**：合理处方数；**分母**：点评处方数（随机抽样或全量）
- **抽样要求**：门急诊处方每日随机抽取 ≥ 30 张（或按床位比），每月 ≥ 100 张（具体以本院点评制度为准）
- **目标值**：≥ 95%（抗菌药专项整治要求）/ ≥ 98%（处方点评管理规范高要求）
- **出处**：原卫生部《医院处方点评管理规范（试行）》（卫医管发〔2010〕28号）

### 1.2 不合理处方分类占比
- **分类**：不规范处方、用药不适宜处方、超常处方（三大类，按 28 号文附表分类）
- **常见不适宜子类**：适应证不适宜、用法用量不适宜、遴选药品不适宜、给药途径不适宜、重复用药、配伍禁忌/不良相互作用
- **呈现要求**：本月不合理处方按子类做帕累托图，定位 TOP3 主要问题
- **出处**：同 1.1

### 1.3 抗菌药处方率（门诊）
- **公式**：门诊抗菌药处方率 = 含抗菌药处方数 / 抽样处方数 × 100%
- **目标值**：门诊 ≤ 20%（抗菌药专项整治）
- **出处**：《抗菌药物临床应用指导原则》（2015年版）

### 1.4 注射剂处方率（门诊）
- **公式**：门诊注射剂处方率 = 含注射剂处方数 / 抽样处方数 × 100%
- **目标值**：参考值（无强制国标，做环比趋势）

## 二、ADR 监测与药物警戒

### 2.1 ADR 上报例数
- **定义**：本月新上报的药品不良反应/事件报告例数
- **要求**：含新的/严重/一般 ADR 分类
- **出处**：《药品不良反应报告和监测管理办法》（卫生部令第81号，2011）

### 2.2 新的/严重 ADR 占比
- **公式**：新的或严重 ADR 占比 = (新的 ADR 例数 + 严重 ADR 例数) / ADR 总例数 × 100%
- **目标值**：新的/严重 ADR 报告占比 ≥ 15%（国家中心考核要求，待核实本院年度目标）
- **出处**：国家药品不良反应监测中心年度考核指标

### 2.3 ADR 上报及时率
- **定义**：死亡/严重 ADR 自发现/获知之日起 15 日内上报、新的严重 30 日内、一般 30 日内
- **公式**：及时率 = 规定时限内上报例数 / 应上报总例数 × 100%
- **目标值**：= 100%
- **出处**：卫生部令第81号第二十条

### 2.4 涉及药品分类分析
- **呈现要求**：抗感染药、抗肿瘤药、中药注射剂、生物制品等分类占比；前 10 位涉及药品排序

## 三、抗菌药物专项整治

### 3.1 抗菌药物使用强度 AUD
- **定义**：每 100 个住院人天数消耗的抗菌药物 DDDs
- **公式**：AUD = DDDs / (同期出院人数 × 平均住院天数) × 100
- **分子**：DDDs（限定日剂量数）= 某药消耗量 / 该药 DDD 值，按通用名累加
- **目标值**：≤ 40 DDD/100 人天（综合医院）
- **出处**：《抗菌药物临床应用监测指标》（国卫办医政相关要求）；WHO ATC/DDD Index

### 3.2 住院抗菌药使用率
- **公式**：住院抗菌药使用率 = 使用抗菌药出院人数 / 同期出院总人数 × 100%
- **目标值**：≤ 60%（综合医院，待核实本院目标）
- **出处**：抗菌药专项整治方案

### 3.3 门诊抗菌药使用率
- **公式**：门诊抗菌药使用率 = 使用抗菌药人次 / 同期门诊总人次 × 100%
- **目标值**：≤ 20%
- **出处**：同上

### 3.4 限制使用级 / 特殊使用级占比
- **公式**：特殊使用级占比 = 特殊使用级抗菌药 DDDs / 抗菌药总 DDDs × 100%
- **目标值**：特殊使用级（碳青霉烯类、替加环素等）使用量呈下降或可控趋势
- **出处**：《抗菌药物临床应用管理办法》（2012）

### 3.5 Ⅰ类切口预防用药率
- **公式**：Ⅰ类切口预防用药率 = 预防使用抗菌药例数 / Ⅰ类切口手术例数 × 100%
- **目标值**：≤ 30%（特殊情况除外）
- **用药时限**：术前 0.5–1 小时内给药；预防总疗程 ≤ 24 小时（心脏手术 ≤ 48 小时）
- **出处**：《抗菌药物临床应用指导原则》（2015）

### 3.6 碳青霉烯类/替加环素专项
- **呈现要求**：单独列出使用量、使用科室分布、是否存在超适应证使用

## 四、药品供应与盘点

### 4.1 库存周转天数
- **公式**：周转天数 = 平均库存金额 / 日均出库金额
- **平均库存金额** = (期初库存金额 + 期末库存金额) / 2
- **目标值**：参考值（无强制国标），做环比；一般医院 10–20 天为合理区间，待核实本院目标

### 4.2 库存金额与周转率
- **周转率** = 年出库金额 / 平均库存金额（月度可换算年化）
- **目标值**：做环比趋势

### 4.3 金额 Top10 药品
- **呈现要求**：本月出库金额前 10 位药品排序 + 环比变化；关注异常增长品种（如环比 > 30% 需分析原因）

### 4.4 近效期药品金额占比
- **定义**：效期 ≤ 6 个月药品库存金额占库存总额比例
- **公式**：近效期占比 = 近效期药品库存金额 / 库存总金额 × 100%
- **处置要求**：列出近效期清单 + 处置方案（调拨/促销/退换货/报废）

### 4.5 缺药记录
- **呈现要求**：本月缺药品种数、累计缺药时长、缺药原因分类（断供/招标/配送/其他）、影响科室

### 4.6 基药配备与使用（如本院纳入考核）
- **基药使用金额占比** = 基药出库金额 / 药品总出库金额 × 100%
- **目标值**：基层 ≥ 90% / 二级 ≥ 50% / 三级 ≥ 25%（待核实本院级别与目标）

### 4.7 集采药品执行（独立成章时使用）
- **各品种完成率** = 实际采购量 / 约定采购任务量 × 100%（按中选品种逐个核算）
- **分子**：实际采购量；**分母**：约定采购任务量（来自省级集采平台协议）
- **数据来源**：省级药品集中采购平台导出（任务量、完成量、完成率），需平台导出而非 HIS 估算
- **关注点**：未达进度品种、超量/欠量科室分布、非中选药品限量使用与超限情况、中选药品使用金额占比
- **目标值**：按各批次集采协议约定节点进度（一般要求完成率 ≥ 100% 或按协议考核节点）
- **出处**：国家组织药品集中采购和使用联合采购办公室各批次文件；本院集采执行方案

## 五、用药差错与 near miss

### 5.1 差错分级（NCC MERP 分级）
- **分级**：A–I 级（A 级：环境/事件未到达患者；B 级：到达患者未造成伤害；C–D：需监测/干预；E–F：暂时/永久伤害；G：危及生命；H：需干预救命；I：导致死亡）
- **出处**：美国 NCC MERP 用药差错分级标准；《中国用药错误管理专家共识》
- **near miss**：A + B 级（未造成伤害的潜在差错）

### 5.2 near miss 捕获率
- **公式**：near miss 捕获率 = (A 级 + B 级) / (A–I 级差错总数) × 100%
- **意义**：捕获率越高，说明差错拦截能力越强；但需结合绝对数判断
- **目标值**：趋势上升（鼓励主动上报）

### 5.3 差错环节分布
- **环节**：开方/转抄/调配/发药/给药/监测
- **呈现要求**：按环节做分布图，定位高发环节

### 5.4 差错原因分析
- **分类**：人员（培训不足/疲劳/疏忽）、流程（制度缺失/核对缺位）、系统（HIS 提示缺失/相似包装）、环境（高峰拥堵/相似药名）
- **要求**：每个典型差错必做根因分析（5Why 或鱼骨图）

## 六、人员培训与用药咨询

### 6.1 继教培训
- **指标**：本月培训场次、参训人次、人均学时、考核合格率
- **呈现要求**：培训主题清单 + 下一期计划

### 6.2 排班执行
- **指标**：排班执行率 = 实际到岗人班次 / 计划人班次 × 100%
- **异常**：调班次数、加班人时、值班差错

### 6.3 用药咨询
- **指标**：本月咨询例数、咨询分类（用法用量/相互作用/特殊人群/ADR/其他）、典型咨询案例 2–3 例
- **出处参考**：《医疗机构药学服务规范》
