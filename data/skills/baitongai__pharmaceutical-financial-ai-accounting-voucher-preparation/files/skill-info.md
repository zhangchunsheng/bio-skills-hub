# 医药财务会计凭证AI制证 Skill Info

## Skill Name
医药财务会计凭证AI制证

## Version
1.0.0

## Description
医药行业财务会计凭证自动生成技能。支持金蝶、用友、SAP、Oracle等主流财务软件导入格式。专为医药企业设计，内置药品GSP/GMP合规校验、研发支出资本化判断、两票制价差检查、药品差异化税率（化学药品13%/中药饮片9%/生物制品3%）、学术推广费监控及冷链批次追踪。提供"源数据解析→科目智能映射→分录生成→合规校验→凭证生命周期管理→格式化输出"的完整7步制证流程。

## Core Capabilities

- **智能业务识别**：从源文件列结构和数据内容自动识别药品销售/原料采购/研发支出/学术推广费等20种医药业务类型
- **科目智能映射**：基于医药业务关键词库和配置化规则引擎，自动将源数据字段映射到会计科目
- **医药合规校验**：学术推广费占比监控、CSO供应商资质校验、两票制价差检查、研发资本化条件判断、GSP冷链批次追踪
- **药品差异税率**：自动识别化学药品(13%)、中药饮片(9%)、生物制品(3%)、免税药品，追加税额分录
- **凭证生命周期**：支持草稿→提交→审核→过账→冲销的完整状态流转，按月+按账簿自动编号
- **多ERP输出**：生成金蝶K/3 Cloud、用友U8/U9、SAP ERP、Oracle Fusion标准导入格式Excel文件
- **规则自学习**：从历史明细账/凭证/财务手册自动推断核算规则，支持合并修正和置信度评估
- **制证报告**：输出映射明细、校验结果、合规警报、未匹配项的完整制证追溯报告

## Application Scenarios

- 医药企业日常销售/采购/费用等业务批量制证
- 学术推广费合规凭证处理与费用占比监控
- 研发支出资本化/费用化判断及分录生成
- CSO服务费支付凭证的供应商资质合规校验
- 集采药品销售收入确认与折扣处理
- 冷链药品GSP批次追踪凭证生成
- 多账簿/多ERP系统的凭证格式转换与批量导出
- 财务共享服务中心的医药行业凭证标准化处理
