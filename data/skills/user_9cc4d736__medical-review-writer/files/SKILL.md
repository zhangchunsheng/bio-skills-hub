# Medical Review Writer

## Intake and Style Model

Collect the topic, review type, audience, language, target journal, date range, source literature, and current author guide. Analyse 2-5 recent published reviews from the target journal or field to learn abstract structure, section logic, synthesis density, and scholarly tone. Use structure and rhetorical patterns only; do not copy wording.

## Review Writing Standard

Write as a critical scholarly review, not news, marketing, a public-account post, or a list of studies.

- Organize by concepts, mechanisms, evidence themes, controversies, and gaps.
- Synthesize agreements and conflicts across study designs.
- Distinguish evidence, interpretation, uncertainty, and future directions.
- Avoid promotional claims, slogans, sensational openings, rhetorical questions, and unsupported superlatives.
- Use transitions to connect sections into one argument.

## Abstract Contract

Model the abstract structure on verified published reviews and the target journal requirements. The abstract must contain no reference number, author-year citation, DOI, PMID, footnote, or bibliography hyperlink. Summarize only claims developed and supported in the body.

## Citation and Link Contract

Before drafting, select one target-journal citation style. If unspecified, announce one working numbered style and use it consistently.

1. Start the first in-text citation at `1` and assign every later number by first appearance in the body. Renumber the entire manuscript and bibliography after any insertion, deletion, or move.
2. Use one uninterrupted numeric sequence; never mix raw PMID/DOI markers, author-year, and numeric citations.
3. Link every in-text number to its matching bibliography entry using DOCX bookmarks/internal hyperlinks or Markdown anchors.
4. For every PubMed-indexed reference, link the bibliography entry and its in-text number to the verified PubMed original record at `https://pubmed.ncbi.nlm.nih.gov/<PMID>/`. Do not use search-result URLs or malformed PubMed links.
5. For non-PubMed records, use a verified DOI or publisher original-record link and explicitly label `PubMed未收录`.
6. Use one uniform reference-list format and preserve complete verified metadata.

## Workflow

1. Define scope, eligibility boundaries, evidence map, and review thesis.
2. Approve an outline, then write connected publication-style paragraphs rather than delivering the outline as the article.
3. Synthesize literature by theme and method; critically appraise bias, heterogeneity, causal limits, and applicability.
4. Draft the abstract after the body and remove all citations from it.
5. Normalize and hyperlink citations in a final dedicated pass.

## Deliverables and Gate

Return the review, linked reference list, evidence-to-claim table, reference verification report, `编号连续性检查`, and citation-style check. Block delivery if the abstract contains a citation, the prose reads as promotional/news content, the first body citation is not 1, a body claim lacks a reference number, numbering is inconsistent, a PubMed-indexed record lacks its PubMed original link, or any link points to the wrong reference.
