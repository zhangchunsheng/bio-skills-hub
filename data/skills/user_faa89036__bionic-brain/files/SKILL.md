# 仿生认知大脑 🧠

> **让AI真正「长点心」**

## 它能干啥

| 场景 | 没有它 | 有它之后 |
|------|--------|----------|
| 想删文件 | 「rm -rf /」直接执行 | 先问问你确认没 |
| 写代码 | 一顿操作猛如虎，一看结果全是bug | 先分析复杂度，想好了再动手 |
| 复杂任务 | 眉毛胡子一把抓 | C1到C4，先搞清楚这是多大的事 |
| 重复任务 | 每次都问同样的问题 | 第3次就记住了，下次直接做 |
| 说大话 | 「绝对没问题！」 | 给自己打个85折，留点余地 |

## 快速开始

```bash
# 安装（一行命令）
pip install bionic-brain

# 或者直接用
python -c "from bionic_brain import analyze; print(analyze('帮我写PPT'))"
```

## 核心功能

### 1. 风险守卫 — 危险的活儿我不干
自动拦截：
- `rm -rf` / `del /s` 这类要命的命令
- 往危险路径（C:\Windows）里写的操作
- 密码硬编码、凭据泄露

### 2. 复杂度分类 — 先想后做
```
C1: 你好、天气怎么样      → 简单聊
C2: 写个文件、查个资料    → 直接做
C3: 分析代码、优化SQL     → 仔细想
C4: 设计系统、做架构      → 认真规划
```

### 3. 自我进化 — 越用越懂你
- 记录每次任务的结果
- 成功率高的策略自动记住
- 习惯任务第3次就变「肌肉记忆」

### 4. 认知纠偏 — 别飘，别怂
- 检测过度自信（"绝对没问题" → 置信度-20%）
- 检测过低自信（"大概可能也许吧" → 提醒你别太虚）


1. **零配置** — 解压即用，不用调参数
2. **纯Python** — 标准库，无依赖
3. **可审计** — 自我检查，发现问题自动修复
4. **会进化** — 用得越多，越懂你

## 开发者

