# 临床 ASR 评测环境搭建

- 唯一标识：`digital-health-clinical-asr-setup`
- 显示名称：临床 ASR 评测环境搭建
- 能力摘要：搭建临床 ASR Flywheel 的安全本地工作区、Python/NeMo 清单和合成语音评测前提，验证目录、依赖、凭据和音频格式，为后续构建、评测和微调阶段提供可复现起点。

## 案例素材

1. 新团队在独立目录创建清单、输出、日志和临时音频路径，运行最小依赖和格式检查，确保后续阶段不会把产物散落在用户主目录。
2. 配置 NVIDIA 服务密钥时只验证环境变量是否存在及访问是否成功，不回显密钥；将真实临床录音排除在此工作流外，仅允许合成术语音频。
3. 启动前检查清单所指音频文件、采样率、时长和扩展元数据，发现缺失文件时先修复数据构建而非在评测或训练期间浪费 API/GPU 资源。
