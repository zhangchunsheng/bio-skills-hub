# 药学监护10大工作子类表单模板

> 参照中国医院协会药事管理委员会发布的药学服务相关团体标准，提供标准化表单字段设计。

## PC-01 药学查房记录表

**触发时机：** 每次药学查房时  
**对应标准：** T/CHAA（药学查房服务规范）

### 表单字段

| 字段类别 | 字段名称 | 字段类型 | 说明 |

| 患者信息 | 住院号 | 文本 | |
| 患者信息 | 床位号 | 文本 | |
| 患者信息 | 科室 | 文本 | |

| 查房信息 | 查房时间 | 时间 | |
| 查房信息 | 药师姓名 | 文本 | |
| 主观资料（S） | 患者主诉 | 文本域 | 症状、不适、主要诉求 |
| 主观资料（S） | 患者用药依从性 | 单选 | 好/一般/差 |
| 客观资料（O） | 体温(℃) | 数字 | |
| 客观资料（O） | 血压(mmHg) | 文本 | 格式：收缩压/舒张压 |

## PC-02 患者分组评估表

**适用阶段：** 入院24小时内  
**触发时机：** 入院评估完成后  
**说明：** 基于风险分层决定药学监护强度

### 表单字段

| 字段类别 | 字段名称 | 字段类型 | 评分规则 |
|---------|---------|---------|---------|
| 基本信息 | 患者姓名/住院号 | 文本 | |
| 基本信息 | 入院日期 | 日期 | |
| 基本信息 | 主要诊断 | 文本 | |
| 高风险因素评估 | 多重用药（≥5种/≥10种） | 单选 | <5种=0分；5-9种=1分；≥10种=2分 |
| 高风险因素评估 | 高警示药品使用 | 单选 | 是=2分；否=0分 |
| 高风险因素评估 | 肾功能不全（eGFR） | 单选 | 正常=0；轻中度=1；重度/透析=2 |
| 高风险因素评估 | 肝功能不全 | 单选 | 正常=0；轻中度=1；重度=2 |
| 高风险因素评估 | 年龄≥65岁 | 单选 | 是=1分；否=0分 |
| 高风险因素评估 | 儿童（<18岁） | 单选 | 是=1分；否=0分 |
| 高风险因素评估 | 妊娠/哺乳期 | 单选 | 是=2分；否=0分 |
| 高风险因素评估 | 过敏史 | 单选 | 有药物过敏=1；无=0 |
| 高风险因素评估 | 依从性差（既往史） | 单选 | 是=1；否=0 |
| 高风险因素评估 | 治疗窗窄药物 | 单选 | 是=2；否=0 |
| 总分 | DRP风险总分 | 计算 | 自动求和 |
| 分组结果 | 监护分级 | 自动 | 0-2分=低风险(C组)；3-5分=中风险(B组)；≥6分=高风险(A组) |
| 分组结果 | 推荐监护强度 | 文本 | A组：每日查房；B组：每2天；C组：每3天 |
| 分组结果 | 药师签名 | 文本 | |

## PC-06 处方精简评估表

**适用阶段：** 住院中后期（通常入院3天后）  
**触发时机：** 定期药物治疗评估时

### 表单字段

使用STOPPFrail量表（老年患者）或类似评估工具：

| 序号 | 当前用药 | 适应症是否仍存在 | 药物是否有效 | 不良反应风险 | 患者意愿/目标 | 精简建议 | 医生确认 |
|-----|---------|--------------|-----------|------------|------------|---------|---------|
| 1 | | □是□否□不确定 | □是□否 | □低□中□高 | | □继续□减量□停用□换药 | |

**精简原则清单（勾选适用项）：**
- □ 无明确适应症
- □ 预期获益小于风险
- □ 与治疗目标不符（姑息治疗患者）
- □ 严重药物相互作用
- □ 重复治疗
- □ 患者依从性差且无法改善

| 过敏状态 | 药物/食物过敏史 | 文本 | |
| 认知功能 | 用药管理能力自评 | 单选 | □能自行管理□需协助□完全依赖 |
| 吞咽功能 | 是否存在吞咽障碍 | 单选 | □否□是→建议换剂型 |
| 用药负担 | 每日服药次数/总品种数 | 数字 | |
| 药物依从性 | Morisky量表（8题版） | 0-8分 | □高□中□低依从性 |
