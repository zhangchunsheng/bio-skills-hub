# 中国医院协会药事管理委员会药学服务团体标准要点

> 本文档收录与药学监护路径相关的团体标准核心要素，用于指导表单设计与文档格式规范。

---

## 一、总体规范要求

### 1.1 文档格式规范
- 所有药学服务记录文档须包含**机构名称、文档编号、版本号、制定日期**
- 患者个人信息须采用**双标识符**核对（如姓名+住院号）
- 签名区须包含**执行药师**和**上级药师/负责药师**双签（实习期药师须双签）
- 记录须符合"可追溯、可审计"原则，关键字段不得留空（无对应填"/"或"无"）

### 1.2 风险分级标识
- **高风险项目**：用红色标注，或加粗红色文字
- **需关注项目**：用橙色标注
- **常规项目**：黑色正文

### 1.3 时间记录规范
- 所有时间记录采用**24小时制**（如 2026-05-28 14:30）
- 急会诊须记录**申请时间和完成时间**，计算响应时效

## 二、药学查房服务规范要点

**参照标准要素：**
- 采用**SOAP格式**记录（S主观-O客观-A评估-P计划）
- 评估须包含**药物治疗问题（DTP）分类**（参照PCNE分类系统V9.0）
- DTP分类代码：
  - P1 治疗有效性
  - P2 治疗安全性
  - P3 其他（依从性等）
- 干预须记录**接受率**（临床接受/拒绝）

**DTP分类（PCNE V9.0简化版）：**

| 类别代码 | 类别名称 | 举例 |
|---------|---------|-----|
| P1.1 | 治疗效果不理想 | 血压未达标 |
| P1.2 | 治疗效果过强 | 低血糖 |
| P1.3 | 无适应症用药 | 抗生素预防无指征 |
| P1.4 | 需要额外药物治疗 | 漏用预防性药物 |
| P2.1 | 药物不良反应 | 肌痛（他汀类） |
| P2.2 | 毒性反应 | 地高辛中毒 |
| P3.1 | 依从性问题 | 自行减量 |
| P3.2 | 给药问题 | 注射技术不当 |

## 三、用药重整规范要点

**规范依据：**
- 参照ISMP（用药安全实践研究所）用药重整安全目标
- 与JCI医院评审标准IPSG.3对应

**核心要求：**
1. 入院用药重整须在入院**24小时内**完成
2. BPMH（最佳可能用药史）须核实**至少2个信息来源**
3. 差异类型须区分"**蓄意差异**"（临床有意为之）与"**非蓄意差异**"（意外遗漏/错误）
4. 非蓄意差异须与开医嘱医生沟通并记录处理结果
5. 转科用药重整须在转科**当日**完成

**高风险药品重整特别要求：**
- 抗凝药物（华法林/NOAC/肝素类）：记录末次使用时间、INR/APTT结果
- 胰岛素：记录剂型、规格（如甘精胰岛素U-100 vs U-300）
- 阿片类药物：记录等效吗啡剂量（OME）
- 免疫抑制剂：记录最近一次血药浓度监测结果

## 四、处方审核规范要点

**法规依据：** 《医疗机构处方审核规范》（国卫办医发〔2018〕14号）

**四适宜核查要点：**

| 审核项目 | 核查内容 | 核查工具 |
|---------|---------|---------|
| 适宜性 | 适应症、禁忌症 | 说明书/指南 |
| 有效性 | 剂量、频次、疗程 | 说明书/指南/PK参数 |
| 安全性 | ADR风险、相互作用 | Micromedex/CDSS |
| 经济性 | 是否有更优价比替代 | 医院目录/集采情况 |

**退回原则：**
- 存在配伍禁忌：必须退回
- 存在重大剂量错误（超过安全剂量50%）：必须退回
- 禁忌症明确：必须退回
- 一般适宜性问题：可先与医师沟通，在沟通记录后放行

## 五、处方精简规范要点

**适用工具：**
- **Beers标准（2023版）**：适用于≥65岁老年患者
- **STOPPFrail量表**：适用于衰弱老年患者
- **STOPP/START标准**：欧洲版PIM筛查
- **Polypharmacy Action Tool**：多重用药管理

**精简优先级（从高到低）：**
1. 无适应症药物
2. 存在严重相互作用的药物
3. 重复治疗药物
4. 预期获益不超过风险的预防性药物

---

## 六、用药教育规范要点

**教育效果评价（TEACH-BACK方法）：**
- 教育完毕后请患者**复述**关键信息，评估理解程度
- 理解程度评价：
  - ≥80%内容正确复述 = 良好（Good）
  - 50-79%正确 = 一般（Fair）
  - <50%正确 = 差（Poor），需再次教育

**必须教育的内容（高优先级）：**
- 高警示药品（胰岛素、华法林、抗凝药、化疗药等）的使用方法
- 吸入制剂的正确使用技术
- 需要冷藏保存的药品
- 用药后须监测的症状（如华法林出血症状）
- 禁止联用的药物/食物（如华法林与大量绿叶蔬菜）

## 七、药学会诊规范要点

**会诊类型与时限要求：**
| 会诊类型 | 响应时限 | 完成时限 |
|---------|---------|---------|
| 急会诊 | 10分钟内到达 | 1小时内出具意见 |
| 普通会诊 | 24小时内响应 | 48小时内完成 |
| 多学科会诊（MDT）| 按MDT时间 | 当日完成 |

**会诊意见分级：**
- **强烈推荐（Grade A）**：有高质量证据支持
- **推荐（Grade B）**：有一定证据支持
- **建议（Grade C）**：基于临床经验和专家意见
- **不确定（Grade D）**：证据不足，需进一步评估

---

## 八、药学随访规范要点

**随访时间节点（按病种调整）：**
| 随访节点 | 主要评估内容 |
|---------|-----------|
| 出院后3-7天 | 出院带药使用情况、早期ADR、依从性 |
| 出院后14-30天 | 疗效评估、复查结果、用药调整情况 |
| 出院后3个月 | 长期慢病管理、药物依从性、生活方式 |
| 出院后6/12个月 | 年度随访（慢病患者） |

**随访记录质量要求：**
- 每次随访须记录"**患者是否愿意继续随访**"
- 失访须记录失访原因
- 发现严重问题须在**24小时内**通知临床医师

## 九、HTML文档样式规范

**配色方案（医疗机构适用）：**
```css
:root {
  --primary-color: #0B7A75;      /* 主色调：医疗蓝绿 */
  --primary-light: #F0F9F8;      /* 浅背景色 */
  --primary-dark: #065F5B;       /* 深色标题 */
  --accent-color: #17A89D;       /* 强调色 */
  --warning-color: #E85D04;      /* 警示橙色 */
  --danger-color: #D62828;       /* 危险红色 */
  --text-primary: #1A1A2E;       /* 正文深色 */
  --text-secondary: #4A4A6A;     /* 次级文本 */
  --border-color: #B2DFDB;       /* 边框色 */
  --table-header: #004D40;       /* 表头背景 */
  --table-alt: #E0F2F1;          /* 表格间隔行 */
}
```

**字体规范：**
```css
font-family: "Microsoft YaHei", "微软雅黑", "Heiti SC", "黑体", sans-serif;
```

**表格规范：**
- 表头：深绿/深蓝背景，白色文字，居中对齐
- 数据行：交替行背景（白/浅绿）
- 关键数据列：加粗
- 打印边距：上下各2cm，左右各2.5cm

**中国医院协会表头格式（标准样式）：**
```

│  患者姓名：_______ 性别：__ 年龄：____        │
└─────────────────────────────────────────────┘
```
