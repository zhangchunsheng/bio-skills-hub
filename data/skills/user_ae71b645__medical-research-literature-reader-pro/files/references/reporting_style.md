# 报告风格与解读安全性

本文件定义了所有输出的写作规范和解读安全规则。

---

## 写作规范

**写作应体现：** 精确性 · 医学语言的流畅性 · 分析的敏锐度 · 对因果性语言的谨慎。

**按模式校准语气：**
- 快速阅读：简洁、直接、易懂
- 标准结构化报告：分析性强、精确、具备证据类型意识
- 专家深度评审：严谨、批判、研究级水准；假设读者具备较高素养

**所有模式均应避免：**
- 空洞的赞美（“这是一篇有趣的论文”“作者的工作做得很细致”）
- 通用套话（“需要更多研究”“未来研究应该探索……”）
- 放大论文自身语言的炒作式解读
- 用单一通用摘要格式对待所有研究类型
- 暗示统计学显著性等同于生物学或临床重要性

---

## 解读安全规则

**绝不将以下概念过度等同：**

| 论文展示的内容 | 它并不能证明的内容 |
|---|---|
| 观察性数据中的相关性 | 因果关系 |
| ML模型的预测准确率 | 机制性解释 |
| SHAP/特征重要性排序 | 生物学因果关系或通路证明 |
| 表达验证（qPCR、IHC） | 功能相关性 |
| 体外表型 | 体内或临床相关性 |
| 内部交叉验证AUC | 临床部署就绪 |
| TCGA/GEO中的显著性结果 | 经过验证的治疗靶点 |
| 单纯的生物信息学分析 | 需要实验证据才能证明的任何论点的证明 |

---

## 校准证据语言

使用与研究设计的实际因果强度相匹配的语言：

| 研究设计 | 合适的表述语言 |
|---|---|
| 具备充分把握度和盲法的RCT | “导致”“降低”“预防”（附带适当的限定说明） |
| 前瞻性队列研究 | “与……相关”“预测了……”“是……的危险因素” |
| 回顾性/横断面研究 | “与……相关”“与……相关联” |
| 生物信息学/计算分析 | “被识别为候选”“在数据集X中相关”“可能发挥作用” |
| 细胞实验 | “在[细胞类型]中影响了[表型]”“在体外调节了[通路]” |
| 动物模型 | “在[小鼠模型]中降低了肿瘤生长”“在体内与[表型]相关” |

---

## 标记原文中的过度声称

如果论文本身使用了夸大其证据水平的语言，应在第8节（论文不能声称的内容）中明确指出：

> “作者将其发现描述为[引用或转述内容]。鉴于该研究设计（[设计类型]），这种表述夸大了证据水平。更准确的表述应为[修正后的陈述]。”

需要标记的常见过度声称模式：
- 对相关性或计算性发现使用“证明”/“证实”
- 在没有回复实验的单一通路实验基础上声称“机制就是……”
- 未经前瞻性临床验证就声称“已可用于临床转化”
- 仅凭数据库挖掘就声称“新型治疗靶点”

---

## 处理不完整输入

当输入有限（仅有摘要、仅有标题）时：
- 完成所有可以凭现有信息完成的部分
- 明确标记每个无法评估的部分为：[需要全文]
- 不要用推断或假设来填补空白
- 不要复述无法从所提供输入中验证的内容
