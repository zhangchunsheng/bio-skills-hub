# 插件系统

本文件定义了所有可用的插件。当用户要求特定交付物，或在报告结尾
提供插件建议时，加载本文件。

**激活规则：** 在真正有用时才提供插件。不要在每份报告后都自动激活
所有插件。选择1–3个最贴合论文类型和用户场景的插件。

---

## 插件目录

### 文献思维导图
**用途：** 将论文构建为可视化的知识图谱。
**输出格式：**
```
Background → Research Gap → Research Question
    ↓
Methods → Dataset / Design / Tools
    ↓
Key Findings (3–5 nodes)
    ↓
Interpretation → Strengths / Weaknesses
    ↓
Next Steps → Open Questions
```
**最适合：** 复杂的多章节论文；正在准备研讨会报告的用户；帮助新团队成员
快速了解一个新主题。

---

### 同类对比表
**用途：** 将当前论文与3–5篇相关研究在一张结构化表格中进行对比。
**输出列：** 标题 · 疾病 · 设计 · 数据集/样本 · 关键方法 · 主要结论 ·
验证水平 · 关键优势 · 关键劣势
**最适合：** 资助申请的背景部分；系统性文献定位；理解一篇论文
在证据体系中的位置。

---

### Journal Club讨论素材包
**用途：** 为在journal club上展示这篇论文准备一份完整的结构化素材包。
**输出章节：**
1. 开场背景（2–3句，设定临床/科学背景）
2. 三个关键发现（简明、准确、通俗易懂）
3. 三个优势（针对具体的设计、数据或分析）
4. 三个担忧点（方法学、解读上，或转化层面）
5. 五个讨论问题（真正达到研究级水准，而非泛泛而谈）
6. 一句话的take-home message
**最适合：** journal club的准备；实验室会议报告；教学查房。

---

### PI决策简报
**用途：** 面向PI或团队负责人的简短战略备忘录，用于评估一篇论文
是否对其研究方向具有意义。
**输出章节：**
1. 这篇论文主张什么（一段话）
2. 证据强度如何？（一句话结论）
3. 是否改变了我们的思路？（是/否 + 一句话说明）
4. 我们应该复现它吗？（是/否/部分 + 理由）
5. 它能启发一个新项目吗？（如可以，给出具体角度）
6. 建议采取的行动（阅读/存档/讨论/复现/忽略）
**最适合：** 实验室领导层；资助策略；研究优先级排序。

---

### 后续实验设计器
**用途：** 生成一套具体的下一步实验方案，用以验证、拓展或挑战
论文的发现。
**输出章节：**
1. 当前论文中最薄弱的环节（一句话）
2. 优先级最高、应首先开展的单一实验（附理由）
3. 按影响力排序的3–5个额外实验
4. 针对每个实验：系统、读出指标、假设成立时的预期结果、假设不成立时的预期结果
5. 转化拓展建议（如适用）
**最适合：** 考虑开展后续研究的研究团队；资助申请的构思阶段。

---

### 生物信息学复现启动器
**用途：** 为复现或拓展该计算分析提供一份pipeline规范。
**输出章节：**
1. 数据来源（GEO登录号、TCGA项目ID、获取方式）
2. 按顺序排列的pipeline步骤（工具 → 参数 → 预期的中间输出）
3. 关键检查点（结果应与论文报告的图表相匹配的位置）
4. 可能的失败点（预处理决策、软件包版本敏感性、参数敏感性）
5. 验证优先级（哪些结果最应优先复现）
6. 拓展方向（论文未做但计算上可行的部分）
**最适合：** 复现已发表分析的生物信息学人员；实验室新人培训；方法学章节撰写。

---

### 图表解读模式
**用途：** 对论文的关键图表提供严谨且易懂的解读。
**针对每张图：**
1. 该图展示了什么（一句话）
2. 作者声称该图展示了什么
3. 数据是否支持该主张（以及原因）
4. 任何展示或统计层面的问题（坐标轴处理、挑选代表性图片、
   缺失误差棒、多重比较问题）
5. 该图对论文核心论点的实际贡献
**最适合：** 学习批判性阅读论文的学生；同行评审人；复现规划。

---

### 资助/项目灵感生成器
**用途：** 将一篇论文的发现和不足转化为可行的研究方向。
**输出章节：**
1. 这篇论文引出的最重要的未解决问题（一句话）
2. 三个具体的研究缺口，附简要理由
3. 针对每个缺口最有力的验证路径（设计建议）
4. 转化拓展角度（生物标志物、治疗、诊断）
5. 如适用的治疗方向角度（靶点类别、干预类型、患者人群）
6. 建议的资助申请框架（一段话）
**最适合：** 资助申请撰写；新项目构思；博士课题开发。
