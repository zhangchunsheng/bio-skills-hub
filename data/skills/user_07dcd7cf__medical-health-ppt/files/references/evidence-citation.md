# 证据等级与引用格式规范

> 本文档规范医疗健康 PPT 中的证据等级标注、每页脚注格式与参考文献清单格式。

## 一、证据等级（A/B/C）说明

### 通用等级体系（以 ADA/中华医学会指南常用体系为准）

| 等级 | 含义 | 典型来源 |
|---|---|---|
| **A 级** | 证据充分，来自大型 RCT 的汇总分析或明确执行良好的多中心 RCT，推荐强度高 | 高质量随机对照试验及其 Meta 分析 |
| **B 级** | 证据较充分，来自执行良好的队列研究或单中心 RCT，推荐强度中 | 队列研究、单中心 RCT、非随机对照试验 |
| **C 级** | 证据有限，来自非对照或非随机研究，或专家意见/临床经验，推荐强度弱 | 病例系列、病例报告、专家共识、临床经验 |

### 注意事项

1. **按所引指南自身的标注体系标注**：不同指南的证据分级体系可能不同（如 ADA 使用 A/B/C/E；部分中医指南使用 Ia/IIa/IIb/III 或"强推荐/弱推荐"）。引用哪份指南，就采用哪份指南的等级符号，并在脚注中注明。
2. **不得自行编造等级**：只有指南原文明确给出等级的内容才可标注；指南未给出等级的，不标注，或标注"推荐（来源：XX指南）"。
3. **药物推荐示例**：
   - 正例："二甲双胍为一线首选降糖药（A 级证据，ADA《糖尿病诊疗标准》）"
   - 正例："八段锦可改善 HbA1c（B 级证据，《2型糖尿病病证结合诊疗指南》）"
   - 反例："此药效果很好（推荐）"——无来源、无等级。

## 二、每页脚注格式

### 规则

1. **封面页除外**，每页底部必须标注该页内容引用的指南/共识名称及发布年份。
2. 脚注格式：`来源：《<指南全称>（<发布年份>）》`
3. 一页引用多份指南时逐条列出，用中文分号分隔：
   - `来源：《中国糖尿病防治指南（2024版）》；《国家基层糖尿病防治管理指南（2025）》`
4. 中西医同页出现时，分别标注：
   - `西医来源：《中国糖尿病防治指南（2024版）》；中医来源：《2型糖尿病病证结合诊疗指南（2021）》`
5. 脚注字号：明显小于正文（建议正文 18pt，脚注 10~11pt）；颜色使用辅色或浅灰，置于页底，不喧宾夺主。
6. 警示页脚注同样适用：`警示内容来源：《国家基层糖尿病防治管理指南（2025）》`

### 示例（页面底部排版）

```
─────────────────────────────────────────────
来源：《国家基层糖尿病防治管理指南（2025）》
```

## 三、参考文献清单格式

### 规则

1. 生成 PPT 的同时输出一份参考文献清单（建议同时置于 PPT 末页与单独 Markdown 文档）。
2. 每项包含 4 要素：**文献全称、发布机构、发布年份、发表期刊**（期刊适用时）。
3. 排序：按内容重要性/引用频率排序，或按首次出现顺序编号。

### 模板

```
【参考文献清单】《<主题>》培训课件（基层医生规范化培训）

1. 《中国糖尿病防治指南（2024版）》— 中华医学会糖尿病学分会，2024，发表于《中华糖尿病杂志》
2. 《国家基层糖尿病防治管理指南（2025）》— 基本公共卫生服务项目基层糖尿病防治管理办公室、中华医学会糖尿病学分会，2025，发表于《中华内科杂志》
3. 《糖尿病诊疗标准（Standards of Care in Diabetes）》— 美国糖尿病协会（ADA），2025，发表于 Diabetes Care
4. 《2型糖尿病病证结合诊疗指南》— 中国医师协会中西医结合医师分会内分泌与代谢病专业委员会，2021，发表于《中医杂志》
5. 《2型糖尿病中医防治指南》— 中国医师协会中西医结合医师分会内分泌与代谢病专业委员会等，2024，发表于《环球中医药》
6. 《国家糖尿病基层中医防治管理指南（2022）》— 中华中医药学会糖尿病基层防治专家指导委员会，2022，发表于《中医杂志》
```

## 四、安全警示规范

### 警示内容分级

| 级别 | 呈现方式 | 示例 |
|---|---|---|
| **高危险警示** | 必须独立成页，或页面顶部红色警示框（深色底+白字或红框+红字） | "不可用纯中药替代降糖药停用西药"；"低血糖处理：立即进食 15g 葡萄糖" |
| **一般警示** | 页面内琥珀色/橙色提示框 | 用药监测要点、剂量调整注意 |

### 必含警示（糖尿病主题课件）

1. 不可用纯中药替代降糖药、擅自停药西药（中西医结合内容时必须强调）。
2. 低血糖识别与处理（血糖 <3.9 mmol/L 为低血糖警戒值）。
3. 胰岛素使用中的剂量调整须在医生指导下进行。
4. 合并心肾疾病时降糖药选择须个体化（避免不当用药）。

### 警示框文字规范

- 警示文字须精确、可操作，给出具体数值/单位/步骤。
- 警示内容的来源同样需在脚注标注。
