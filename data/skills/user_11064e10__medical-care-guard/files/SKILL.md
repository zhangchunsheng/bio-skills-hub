# Medical Care Guard 疾病与工伤防护·医保报销异地备案与工伤认定 v1.0.5
**一句话价值**：生病工伤最怕垫钱又跑断腿——先搞清哪些能直接结算、哪些要手工报、工伤和医保怎么分，少折腾、不少拿。

## 能为你做什么

| 你的处境 | 这个技能给你什么 |
|---|---|
| 职工医保能报多少 | 门诊/住院起付线、报销比例与封顶线，区分在职/退休、本地/异地 |
| 异地看病怎么结算 | 异地就医备案（国家医保 APP / 窗口）一次办，直接结算免垫资 |
| 门慢门特怎么办 | 门诊慢特病病种认定与报销倾斜，长处方与定点管理 |
| 生育津贴怎么算 | 申领条件与天数：单位上年度月均工资÷30×产假天数，发放主体与时限 |
| 摔伤算不算工伤 | 工伤认定情形、劳动能力鉴定与待遇项目（医疗/停工留薪/伤残） |
| 手工报销怎么报 | 未直接结算时的材料清单、时限与经办窗口 |

直接把你的情况说出来即可，例如：

## 行动节奏（CW-21-疾病工伤防护流程）

| 时点 | 必做事项 |
|---|---|
| D+0 | 确认就诊地与参保地，判断是否需异地就医备案 |
| D+1 | 办理异地备案（国家医保 APP 或参保地窗口），确保直接结算 |
| D+3 | 门慢门特认定（如适用），绑定定点医院与长处方 |
| D+7 | 涉工伤：固定证据、报工伤、申请劳动能力鉴定 |
| D+30 | 复核报销到账与津贴发放，留存结算单与凭证 |

## 使用成效示例（小白也能直接用）

**示例 1**

> 问：异地看病怎么报销？

> 答：先办异地就医备案，门诊/住院直接结算免垫资；未备案可能降比例或需手工报销。

**示例 2**

> 问：下班路上车祸算工伤吗？

> 答：非本人主要责任的交通事故算工伤，及时报警取证、申报工伤与劳动能力鉴定。
