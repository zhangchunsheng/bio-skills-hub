# 参考文献格式规范（GB/T 7714 与 APA 7）

本文件提供 GB/T 7714-2015（著者-出版年制）与 APA 第7版的参考文献著录规则与示例，覆盖中药文献常见类型（期刊、专著、学位论文、标准、古籍、网络资源、专利）。

## 一、GB/T 7714-2015（中文论文默认）

### 1. 期刊论文
格式：`作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.`

```
王峥涛, 胡之璧. 黄连的基原考证与品质评价研究[J]. 中国中药杂志, 2005, 30(8): 568-571.
Chen J, Wang Y, Liu X. Berberine attenuates inflammation via NF-κB pathway[J]. J Ethnopharmacol, 2015, 160: 123-130.
```

### 2. 专著（含古籍整理本）
格式：`作者. 书名[M]. 版本/卷次. 出版地: 出版社, 出版年: 页码.`

```
李时珍. 本草纲目[M]. 金陵本. 北京: 人民卫生出版社, 1975: 1023-1026.
帝玛尔·丹增彭措. 晶珠本草[M]. 毛继祖, 罗达尚, 王振华, 等译. 上海: 上海科学技术出版社, 2012: 156-160.
国家中医药管理局《中华本草》编委会. 中华本草: 第7卷[M]. 上海: 上海科学技术出版社, 1999: 523-530.
```

### 3. 学位论文
格式：`作者. 题名[D]. 保存地: 保存单位, 年份.`

```
张XX. 黄连饮片质量标准研究[D]. 北京: 北京中医药大学, 2020.
```

### 4. 标准
格式：`标准号 标准名称[S]. 出版地: 出版者, 年.`

```
中华人民共和国药典（一部）[S]. 北京: 中国医药科技出版社, 2020: 313-314.
DB63/T 1287-2014 藏药材质量标准[S]. 西宁: 青海省质量技术监督局, 2014.
```

### 5. 古籍原始文献（未整理本）
格式：`作者. 书名: 卷次[M]. 版本（刊刻/抄本年代）.`

```
李时珍. 本草纲目: 卷十二[M]. 金陵本（万历二十四年, 1596）.
```

### 6. 网络资源
格式：`作者. 题名[EB/OL]. (发布日期)[引用日期]. 网址.`

```
中国科学院中国植物志编辑委员会. 中国植物志: 黄连属[EB/OL]. (2020-05-01)[2026-08-08]. https://www.iplant.cn/info/Coptis.
```

### 7. 专利
格式：`申请者. 专利题名: 专利号[P]. 公告日期.`

```
XX药业有限公司. 一种黄连有效部位提取方法: CN202310123456.7[P]. 2024-06-18.
```

## 二、APA 第7版（英文论文/国际期刊默认）

### 1. 期刊论文
格式：`Author, A. A., & Author, B. B. (Year). Title of article. Journal Name, Volume(Issue), pages. https://doi.org/xxx`

```
Chen, J., Wang, Y., & Liu, X. (2015). Berberine attenuates inflammation via the NF-κB pathway. Journal of Ethnopharmacology, 160, 123-130. https://doi.org/10.1016/j.jep.2014.11.045
```

### 2. 专著
格式：`Author, A. A. (Year). Title of work (edition). Publisher.`

```
Li, S. Z. (1975). Bencao Gangmu (Jinling edition) [Compendium of Materia Medica]. People's Medical Publishing House.
```

### 3. 学位论文
格式：`Author, A. A. (Year). Title of dissertation [Doctoral dissertation / Master's thesis, University]. Repository name. URL`

### 4. 网络资源
格式：`Author, A. A. (Year, Month Day). Title of page. Site Name. URL`

```
Flora of China. (2011). Coptis chinensis. eFloras. http://www.efloras.org/florataxon.aspx?flora_id=2&taxon_id=200007575
```

### 5. 标准（APA 较少用，用其文献类型通用格式）
格式：`Organization. (Year). Title of standard (Standard No. xxx). Publisher.`

```
Chinese Pharmacopoeia Commission. (2020). Pharmacopoeia of the People's Republic of China (Part I). China Medical Science Press.
```

## 三、文内引用格式

### GB/T 7714 著者-出版年制
- 中文：`（王峥涛 等，2005）` 或 `王峥涛等（2005）认为……`
- 英文：`（Chen et al., 2015）` 或 `Chen et al. (2015) reported……`
- 同一作者同年多篇：加 a/b/c 后缀（2005a、2005b）
- 转引：`（李时珍，1596，转引自王峥涛 等，2005）`

### APA 7
- 单作者：`(Li, 1975)`
- 双作者：`(Chen & Wang, 2015)`
- 三作者及以上：`(Chen et al., 2015)`
- 直接引用需加页码：`(Chen et al., 2015, p. 125)`

## 四、格式选择与输出规则

1. 中文稿件默认 GB/T 7714（著者-出版年制或顺序编码制，以目标期刊要求为准）；国际期刊默认 APA 7
2. 输出前确认用户目标期刊/学校的格式要求；未说明时，中文用 GB/T 7714，英文用 APA 7
3. 同一份参考文献列表中所有条目格式必须统一（不可混用两种制度）
4. 无法核实的信息（页码、DOI）留空并提示用户补齐，不得编造
5. 每次输出附格式说明：`（以上按 GB/T 7714-2015 著者-出版年制）`

## 五、常见错误自查

- [ ] 作者超过3位是否规范处理（GB/T: 前3位+等/et al.；APA: 前1位+et al. 文内）？
- [ ] 英文作者姓名大小写与缩写（Given name 用首字母缩写）？
- [ ] 期刊名是否斜体、卷期页码是否齐全？
- [ ] DOI 是否完整（https://doi.org/ 开头）？
- [ ] 古籍是否标注版本/整理者/译者？
- [ ] 网络资源是否含访问日期（GB/T 需 [引用日期]）？
