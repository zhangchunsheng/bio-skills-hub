# 06 落地流程与审计

> 用途：回答「合规怎么落地」「评估到期怎么办」「年度审计要求」。
> 核对基准日：2026-08-27

## 1. 五步落地流程

### 第 1 步：数据地图（1-2 周）
- [ ] 盘点所有跨境数据流（临床试验/云/员工/售后）
- [ ] 数据分类分级（重要数据/敏感个人信息/一般个人信息）
- [ ] 明确"累计数量"口径（当年 1 月 1 日起）

### 第 2 步：路径判定（工具 `path`/`threshold`）
- [ ] 是否重要数据 → 安全评估
- [ ] 数量区间 → 安全评估 / 标准合同+认证 / 豁免
- [ ] 医疗健康数据 → 叠加医疗数据要求（03 模块）

### 第 3 步：合规动作
- [ ] 安全评估：自评估报告 + 申报（或标准合同备案 / 认证申请）
- [ ] 知情同意补全（敏感数据单独同意）
- [ ] 合同条款（CRO/云/供应商数据处理条款）
- [ ] 技术措施（三重加密/MFA/最小化/脱敏）

### 第 4 步：运营落地
- [ ] 出境台账（每笔出境记录）
- [ ] 监控与告警（异常出境）
- [ ] 政策制度（出境管理办法、员工培训）

### 第 5 步：持续合规
- [ ] 年度/定期风险评估（重要数据每年；2026-08-20 办法）
- [ ] 个保合规审计（>1000 万人每两年一次）
- [ ] 路径状态跟踪（评估到期、备案变化）
- [ ] 法规跟踪（中国+目标市场）

## 2. 评估到期处理（2026 集中到期窗口）

- **时间线**：评估结果有效期 3 年；首批（2023 年出具）2026 陆续到期；
- **提前 6 个月**启动自检（出境情况是否有变化）；
- **届满前 60 个工作日**申请延期（六项条件：未来三年增幅 ≤20%、无重大事件等）；
- **若延期失败**：新评估未完成前暂停出境（避免"裸奔"违规）；
- **情况变化**：出境目的/范围/接收方重大变化 → 重新申报。

## 3. 审计与报告义务（2026 新增）

| 义务 | 适用 | 频率 | 依据 |
|---|---|---|---|
| 数据安全风险评估 | 重要数据处理者 | **每年** | 网络数据安全风险评估办法（2026-08-20 施行） |
| 数据安全风险评估（鼓励） | 一般处理者 | 每 3 年 | 同上 |
| 个保合规审计 | 处理 >1000 万人个人信息 | 每 2 年至少一次 | 个保政策问答（2026-04） |

## 4. 常见失败模式

1. **数据地图缺失**：不知道哪些数据在跨境 = 合规无从谈起；
2. **数量口径错**：按"单笔"而非"累计"判断，漏触发申报；
3. **到期裸奔**：评估到期未延期，出境中断或违规；
4. **重路径轻执行**：申报完了台账/监控/审计没跟上；
5. **忽视医疗特殊性**：医疗数据按普通个人信息处理（门槛/要求不同）。
