# 01 数据出境监管体系

> 用途：回答「中国数据出境监管框架是什么」「什么算数据出境」。
> 核对基准日：2026-08-27

## 1. "3+2+4" 监管体系（2026 年定型）

| 层级 | 文件 |
|---|---|
| 3 部法律 | 《网络安全法》《数据安全法》《个人信息保护法》 |
| 2 部行政法规 | 《关键信息基础设施安全保护条例》《网络数据安全管理条例》 |
| 4 部部门规章 | 《数据出境安全评估办法》《个人信息出境标准合同办法》**《个人信息出境认证办法》（2026-01-01 施行）**《促进和规范数据跨境流动规定》 |
| 配套指南 | 《数据出境安全评估申报指南（第三版）》《个人信息出境标准合同备案指南（第二版）》 |

**"上位定框架、中层明规则、下层落操作"**——2026 年三条路径全面落地，制度框架基本定型。

## 2. 什么是数据出境

**数据出境行为**：数据处理者在境内运营中收集和产生的数据，向境外提供的行为。

**数据出境管理对象**：**重要数据和个人信息**（不含一般业务数据）。

**典型出境场景**：
- 将数据提供给境外机构/个人（传输给海外 CRO、总部、供应商）；
- 数据存储到境外（境外云服务器、境外数据库）；
- 境外可访问境内数据（远程运维、境外员工访问）。

## 3. 重要数据识别

- **默认规则**：未被相关部门告知/公开发布为重要数据的，不按重要数据申报（降低企业负担）；
- **行业例外**：汽车、金融、**医药**等行业已出台专门的重要数据判定规则——医械企业需主动完成数据分类分级；
- **识别动作**：对照行业规则 + 数据分类分级 → 确认是否属于重要数据。

## 4. 监管趋势（2026 关键节点）

- **2026-01-01**：《个人信息出境认证办法》施行——第三条路径落地；
- **2026-01/04**：《个人信息保护政策法规问答》两期——敏感信息界定、数量统计口径统一（>1000 万人个保合规审计每两年一次）；
- **2026-08-20**：《网络数据安全风险评估办法》施行（网信办/工信部/公安部第 24 号令）——重要数据处理者每年风险评估、一般处理者鼓励每 3 年一次；
- **2026**：首批数据出境安全评估结果（2023 年出具）集中到期——企业须在届满前 60 个工作日决定延期或重新申报。

## 5. 医械企业适用提醒

- 临床试验受试者个人信息 = 敏感个人信息 → 出境门槛低、要求严；
- 患者/受试者健康数据 = 敏感个人信息 + 医疗数据特殊要求（03 模块）；
- 跨境临床合作、云服务、海外部署均可能触发出境。
