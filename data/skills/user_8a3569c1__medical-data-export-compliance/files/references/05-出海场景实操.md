# 05 出海场景实操

> 用途：回答「临床试验数据/远程诊疗/云服务/员工数据怎么合规」。
> 核对基准日：2026-08-27

## 1. 临床试验数据出境（最高频场景）

**数据**：受试者个人信息（健康数据 = 敏感个人信息）+ 试验数据。

**合规要点**：
- 知情同意：单独同意（中国）+ 目标市场同意要求（GDPR 等）；
- 出境路径：按累计数量判定（敏感 1 万条触发安全评估）；
- 去标识化/匿名化评估：能否在源头减少敏感数据出境；
- 海外 CRO 合同：数据处理条款 + 数据保护义务 + 审计权；
- 数据回传与留存：试验数据保留期限与存储地。

## 2. 远程诊疗/数字疗法

**数据**：患者健康数据（敏感）+ 交互记录。

**合规要点**：
- 医疗数据安全审查（境外合作）；
- 跨境传输路径 + 目标市场合法依据；
- 加密（三重）+ 最小化；
- 设备端/云端数据处理边界明确；
- 未成年人患者数据（如有）特殊保护。

## 3. 境外云服务/数据驻留

**场景**：数据存储境外云、境外可访问境内数据。

**合规要点**：
- 境外存储 = 数据出境 → 按路径合规；
- 数据驻留要求（中国：境内收集数据存储受限；欧盟：GDPR 传输机制；韩国：本地化倾向）；
- 云服务商评估：存储地、加密、合规认证（如 ISO 27001/42001）、数据处理协议（DPA）；
- 多区域部署架构：数据按区域驻留，最小跨境。

## 4. 员工与供应商数据

**数据**：员工个人信息（一般敏感度较低）、供应商联系人。

**合规要点**：
- 人力资源管理豁免（个保法：劳动合同所必需）——注意边界（超出必要即不豁免）；
- 集团内部传输：标准合同/集团约束规则（BCR）；
- 跨境工牌/差旅/薪酬系统：数据出境评估。

## 5. 售后与不良事件数据

**数据**：设备使用数据、可能含患者信息、不良事件报告。

**合规要点**：
- 数据分级：区分设备技术数据 vs 患者数据；
- 脱敏优先：技术数据脱敏后跨境；
- 不良事件报告：法规义务优先于数据出境限制的衔接（明确法定基础）。
