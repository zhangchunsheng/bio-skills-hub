# 03 医疗数据特殊要求

> 用途：回答「医疗健康数据有什么特殊要求」「医疗数据国标是什么」「大湾区通道」。
> 核对基准日：2026-08-27

## 1. 医疗健康数据的双重属性

医疗健康数据 = **个人信息中的敏感个人信息** + **受医疗行业专项监管**：
- 作为敏感个人信息：出境门槛更低（1 万条触发安全评估）、处理限制更严；
- 作为行业监管对象：受医疗数据专项规定、强制性国标约束。

## 2. 首部医疗数据安全强制性国标

已实施，核心要求：
- **三重加密**：存储/传输/处理加密；
- **分级分类**：医疗数据按敏感度分级分类管理；
- **跨境限制**：医疗健康数据出境严格限制；
- **安全评估机制**：涉及出境的须履行安全评估等法定程序。

## 3. 医疗数据安全审查

**境外医疗合作数据传输须通过国家医疗数据安全审查**——国际临床合作、跨境科研、远程医疗等场景均涉及。

## 4. 实操要求（医疗机构/企业通用）

- **一把手负责制**：数据安全纳入考核，压实主体责任；
- **制度建设**：覆盖患者诊疗信息全生命周期的管理制度 + 应急处置机制；
- **技术防护**：加密、认证、分类分级、风险监测；
- **人员培训**：数据安全纳入继续教育与岗前培训；
- **第三方规范**：合作协议明确数据安全义务 + 第三方安全评估；
- **跨境合规**：涉及出境严格履行安全评估/标准合同/认证程序。

## 5. 粤港澳大湾区便利化通道

- 《粤港澳大湾区（内地-香港/内地-澳门）个人信息跨境流动标准合同实施指引》：大湾区内地城市与港澳间个人信息跨境可用**大湾区标准合同**（便利化）；
- **边界**：不得违法向大湾区以外提供个人信息——向大湾区外提供仍需走全国统一的三条路径；
- 适用：注册地/业务在大湾区的数据处理者（含港澳企业在大湾区内地开展业务）。

## 6. 医械企业场景提示

| 场景 | 数据属性 | 关键要求 |
|---|---|---|
| 临床试验数据传海外 CRO | 敏感个人信息（受试者健康） | 出境路径（常触发安全评估）+ 知情同意 |
| 患者数据入境外云 | 敏感个人信息 | 出境路径 + 加密 + 存储地要求 |
| 跨境远程诊疗 | 敏感个人信息 | 医疗数据审查 + 出境合规 |
| 设备售后数据回传 | 可能含患者信息 | 数据分级 + 脱敏评估 |
| 海外员工/供应商数据 | 一般个人信息（多数） | 豁免情形或标准合同 |

## 7. 提示

- 医疗健康数据出境的**知情同意**要求严格（个保法敏感个人信息"单独同意"）；
- 数据出境与数据本地化并存（中国境内收集的医疗数据向境外提供受限，境外市场也有本地化要求——见 04 模块）；
- 2026-08-20 起《网络数据安全风险评估办法》施行：重要数据处理者**每年**风险评估，医械企业若涉及重要医疗数据须落实。
