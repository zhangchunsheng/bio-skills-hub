# API Key 说明与常见问题

本技能 v1.2.0 起**完全零配置**：
- **公共 Key 已内置**在技能脚本中，安装后即可使用基础功能（由服务端限流控制）；
- 如需更强功能与更高配额，可申请**私有 Key**（可选，非必需）。

## 为什么不需要连接器？

旧版技能依赖 WorkBuddy 连接器中的「生物多样性风险助手」。新版将服务调用封装进技能内置脚本 `scripts/mcp_client.py`，通过标准 MCP HTTP 协议直接联网调用，因此**用户无需在连接器管理页面做任何配置**。

## 两级 Key 模式

| 模式 | 获取方式 | 功能 | 配置 |
|------|----------|------|------|
| 公共 Key（默认） | 无需获取，已内置 | 基础功能（服务端限流） | 零配置，自动使用 |
| 私有 Key（可选） | 联系山水自然保护中心获取 | 更强功能与更高配额 | 一次配置，永久复用 |

## 如何升级为私有 Key

1. 请联系山水自然保护中心获取私有 Key。
2. 获得 Key 后，在 WorkBuddy 中直接说："生物多样性，我的 Key 是 xxx"，AI 会自动将其保存到技能目录的 `state/api_key.txt`。
3. 保存一次后永久复用，脚本会自动优先使用私有 Key；删除 `state/api_key.txt` 即回退公共 Key 模式。

## Key 的保存方式（私有 Key，三选一）

| 方式 | 说明 |
|------|------|
| 技能目录 `state/api_key.txt`（推荐） | 由 AI 首次使用时自动写入；也可手动创建，内容为单行 Key |
| 环境变量 `BIODIVERSITY_MCP_TOKEN` | 全局生效，适合多技能复用 |
| 命令行 `--token` 参数 | 临时使用，不持久化 |

优先级：`--token` > 环境变量 > `state/api_key.txt` > 内置公共 Key。

## 常见问题

**Q1：不申请 Key 能直接用吗？**
能。公共 Key 已内置，安装后即可使用基础功能；工具列表会标注"当前模式：公共 Key"。

**Q2：私有 Key 会泄露吗？**
技能内置安全要求：AI 不在对话中明文回显完整私有 Key，不将其写入会被分享/上传的文件。请勿自行将私有 Key 公开发布。

**Q3：Key 失效了怎么办？**
- 公共 Key 失效（401）：公共 Key 可能已被服务端更新或触发限流，请申请私有 Key；
- 私有 Key 失效（401）：重新申请，替换 `state/api_key.txt` 内容即可。

**Q4：没有网络能用吗？**
在线功能（合规核查、TNFD 披露、公益增量建议、专家知识框架）需要联网；其余本地知识类能力不受影响。

**Q5：为什么公共 Key 敢直接写在技能里？**
公共 Key 仅提供基础功能，且由服务端按限流策略控制，即使被公开调用也无法滥用高级能力；服务方可随时在服务端吊销或更换。

## 兼容性说明

- 仍保留旧版连接器「生物多样性风险助手」也无妨，技能会自动优先使用直调脚本；两者互不冲突。
- 若希望完全移除依赖，可删除连接器中的「生物多样性风险助手」条目（可选，非必须）。
