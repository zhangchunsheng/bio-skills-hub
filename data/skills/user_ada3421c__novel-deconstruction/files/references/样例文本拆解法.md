# 样例文本拆解法（升级版：10维框架 + 6步SOP）

拆解的目标不是"复制"，而是"解码"——将一部成功作品的创作逻辑还原为一套可复用的方法论。

---

## 一、10大拆解维度详析

### 维度1：叙事架构

**核心问题**：骨架是否稳固？节奏是否健康？

**分析步骤**：
1. 识别整体结构类型：三幕式/五幕式/英雄之旅/网文分卷式/多线并行
2. 完成幕/卷结构切割：每卷的起止章节、核心冲突主体、主角状态变化
3. 标注高潮节点分布：大高潮（卷末）/中高潮（30-50章）/小高潮（3-5章）坐标与间隔
4. 绘制地图切换线：换地图的触发条件、旧地图资源榨干度、每次换图伴随的身份跃迁

**关键指标**：
- 高潮间隔均值：总章节/高潮次数
- 地图切换周期：约每X万字一次
- 压抑期最长连续章数

### 维度2：世界观与设定

**核心问题**：设定是否自洽？揭露是否自然？

**分析步骤**：
1. 识别设定层级：核心规则（L1/必须定死）→ 表层设定（L2/可留白）→ 深层秘密（L3/逐步揭示）
2. 追踪设定揭露节奏：前50章释放了L2的多少？L3的第一个线索何时出现？
3. 检验自洽性：设定有无内部矛盾？规则例外是否被合理解释？
4. 评估设定利用率：哪些设定只是背景板？哪些设定深度参与了剧情？

**关键指标**：
- 前50章设定暴露率
- 设定矛盾发现数
- 设定参与剧情率

### 维度3：剧情引擎

**核心问题**：剧情是否有发动机？线索是否闭环？

**分析步骤**：
1. 提取主线发动机：核心悬念是什么？每卷推进了什么？
2. 映射支线生态：副本/感情/势力博弈如何与主线交汇？
3. 追踪暗线布局：表面剧情下的隐藏逻辑
4. 建立线索追踪表：每条线索"埋下章节→发展节点→回收章节"全生命周期

**关键指标**：
- 支线交汇频率
- 线索回收率：已回收线索数/总埋设线索数
- 暗线数量与复杂度

### 维度4：人物系统

**核心问题**：人物是否工具人？弧光是否完整？

**分析步骤**：
1. 主角深度分析：外在标签/内在驱动/成长弧光
2. 配角生态检验：每个配角的独立动机和不可替代性
3. 反派阶梯分析：阶段性反派→中期Boss→幕后黑手的动机层次
4. 对话辨识度测试：去人名后能否分辨谁在说话？

**分析模板**：
```
主角深度卡：
  外在标签：身份/能力/外貌/标志性动作
  内在驱动：核心动机/核心恐惧/性格底色/核心缺陷
  成长弧光：起点状态→关键转折→终点状态

配角三元检验：
  - 他想要什么？（独立动机）
  - 没有主角他能独活吗？（独立性）
  - 删除他对主线的影响？（功能必要性）

反派阶梯：
  Lv1 阶段性反派（第X卷退场）：动机/实力/与主角关系
  Lv2 中期Boss（第Y卷退场）：动机/实力/与主角关系
  Lv3 幕后黑手：动机/实力/与主角关系
```

### 维度5：情绪工程

**核心问题**：情绪是否被精准操控？

**分析步骤**：
1. 逐章标注情绪基调（紧张/舒缓/期待/满足/愤怒/悲伤/好奇）
2. 识别爽点类型与分布：打脸/突破/收获/反转/情感/揭秘/绝境逢生
3. 分析压抑-释放周期：压抑手段→蓄势方式→爆发质量
4. 章末钩子分类统计：悬念/危机/新信息/情绪爆点/承诺预告

**关键指标**：
- 爽点间隔：总章节/爽点总数 = X章/次
- 压抑期最长连续：X章
- 钩子类型分布：各类型占比

### 维度6：伏笔与反转

**核心问题**：是否草蛇灰线？反转是否惊艳？

**分析步骤**：
1. 统计伏笔总数与密度（伏笔数/总章节）
2. 追踪每条伏笔的回收周期（短期<3章/中期<30章/长期>30章）
3. 评估回收质量：生硬/自然/惊艳
4. 分析反转手法：反转前的铺垫数量与质量

**关键指标**：
- 伏笔密度：每章X个
- 伏笔回收率：已回收/总埋设 = X%
- 回收质量分布：生硬X%/自然X%/惊艳X%
- 反转前平均铺垫数

### 维度7：文笔与叙事

**核心问题**：文字是否服务于故事？

**分析步骤**：
1. 叙事视角分析：人称/有限or全知/是否切换
2. 句式特征量化：平均句长、长短句比例
3. 描写密度分析（采样5章标注）：
   - 动作描写 / 神态描写 / 环境描写 / 心理描写 / 对话 / 旁白叙述
4. 修辞偏好识别
5. 信息传递方式：设定是通过剧情/对话自然流露，还是旁白灌输？

**关键指标**：
- 平均句长
- 描写密度分布
- 对话占比
- 段落平均行数

### 维度8：主题与内核

**核心问题**：是否有灵魂？

**分析步骤**：
1. 识别表层主题：故事表面在讲什么
2. 提取深层内核：故事真正在探讨什么
3. 分析价值观输出方式：说教式/隐喻式/人物命运式
4. 检测时代映射：是否暗含对现实的反思

### 维度9：商业适配

**核心问题**：商品属性是否清晰？

**分析步骤**：
1. 平台匹配度：这本书的风格和节奏最适合哪个平台？
2. 受众画像：目标读者的年龄/性别/阅读场景/核心诉求
3. 对标竞争：市场上是否有同类作品？差异化在哪里？
4. 传播要素：书名/简介/标签是否有效？

### 维度10：创新与差异化

**核心问题**：为什么是它火？

**分析步骤**：
1. 提炼核心卖点：读者为什么选这本书而不是其他？
2. 识别反套路设计：与传统套路的不同之处
3. 分析类型融合：是否融合了多个类型的元素？
4. 独特标签：这个作者独特在哪里？

## 二、6步拆解SOP

### Step 1：通读与标记

**目标**：建立整体感性+理性认知

**执行动作**：
1. 快速通读全文（或用户提供范围），标记"停不下来"的章节位置
2. 识别并记录情绪高点：最爽、最燃、最虐、最紧张的具体节点
3. 边读边标记以下标签：
   - 🔮 伏笔埋设
   - 🔥 高潮场景
   - 👤 重要人物登场
   - 🗺️ 地图/舞台切换
   - ⚡ 爽点释放
   - 🪝 章末强力钩子
4. 建立「四要素时间轴」：每章用一句话记录"事件-人物-地点-情绪基调"

**交付物**：
- 四要素时间轴简表
- 标签分布热力图（哪些章节标签密度最高）

---

### Step 2：宏观拆解（看骨架）

**目标**：理解全书的结构设计和节奏控制

**执行动作**：
1. 画出整体结构图，标注开端/发展/转折/高潮/结局的章节坐标
2. 完成分卷/分幕切割表：
   - 每卷的起止章节、核心冲突、主角状态变化
   - 卷末钩子设计
3. 标注高潮节点分布：
   - 大高潮（卷末）的章节位置
   - 中高潮（30-50章规模的阶段性高潮）的坐标
   - 小高潮（3-5章内的爽点爆发）的密度
4. 绘制地图切换时间线：
   - 何时换地图？旧地图的资源/冲突是否已耗尽？
   - 每次换地图伴随什么身份跃迁或实力提升？
5. 计算节奏健康指标：
   - 压抑期最长连续章数
   - 爽点间隔均值（总章节/爽点总数）
   - 高潮密度（高潮章数/总章数）

**交付物**：
- 结构总览图
- 分卷切割表
- 高潮节点坐标表
- 地图切换时间线
- 节奏健康指标卡

---

### Step 3：中观拆解（看脉络）

**目标**：追踪全书线索系统和势力格局

**执行动作**：
1. 建立「线索追踪表」：
   ```
   线索编号 | 线索名称 | 埋设章节 | 发展节点 | 回收章节 | 回收状态 | 回收质量
   C001     | XXX      | Ch12     | Ch45,Ch78| Ch120    | ✅已回收  | 自然
   C002     | YYY      | Ch5      | Ch23     | -        | ⏳待回收  | -
   ```
2. 建立「人物登场表」：
   ```
   人物 | 登场章节 | 功能定位 | 弧光触发点 | 退场时机 | 重要度
   张三 | Ch3      | 导师     | Ch45       | Ch200    | ⭐⭐⭐
   ```
3. 完成「势力/关系拓扑图」：
   - 各方势力的地理分布、利益链条
   - 人物之间的情感绑定/利益冲突/血海深仇
4. 抽样章节结构分析：
   - 随机抽取10%的章节（最少10章，最多30章）
   - 分析每章的"起承转合 + 卡点设计"
   - 归纳该书的章节结构模式

**交付物**：
- 线索追踪表（含回收状态标注）
- 人物登场表
- 势力/关系拓扑图
- 章节结构模式归纳

---

### Step 4：微观拆解（看细胞）

**目标**：深入到段落和句子级别，解码写作技法

**执行动作**：

1. **黄金三章逐段切片**：
   - 逐段分析前三章，标注每段功能：引入/展示/冲突/信息/钩子
   - 统计前三章的信息密度（新信息条数/字数）
   - 分析钩子设计：第一章结尾的钩子是什么？第二章？第三章？

2. **高潮场景逐句拆解**：
   - 选择1-2个全书最经典的高潮场景（打脸/决战/身份揭露各选最佳）
   - 逐句分析"铺垫→爆发→余韵"的写作技法
   - 标注情绪递进的节点和手法

3. **对话样本分析**：
   - 抽取5段关键对话（≥8轮）
   - 分析潜台词密度、性格标签、信息传递效率
   - 标注冲突升级的路径
   - 执行"去人名辨识度测试"：去掉角色名后，能否通过对话风格分辨谁在说话？

4. **文笔技法切片**：
   - 复制3段典型描写（战斗/情感/环境各一段，每段300-500字）
   - 逐句标注技法标签：句式、修辞、五感运用、节奏控制、情绪渲染
   - 归纳该书的描写公式

**交付物**：
- 黄金三章逐段分析报告
- 高潮场景逐句拆解
- 对话样本分析报告（含去人名测试结果）
- 文笔技法标注样本

---

### Step 5：交叉验证（看逻辑）

**目标**：检验全书内在一致性和质量水平

**执行动作**：

1. **设定一致性检查**：
   - 战力/力量体系是否前后矛盾？（如：前期说突破境界需要百年，后期一月突破）
   - 规则是否有例外未被解释？
   - 金钱/资源体系是否合理？（如：一个灵石能干什么，是否前后一致）

2. **伏笔回收审计**：
   - 统计前期所有埋设的伏笔
   - 计算回收率 = 已回收伏笔数 / 总埋设伏笔数
   - 评估每条已回收伏笔的回收质量：生硬/自然/惊艳
   - 标记"疑似被遗忘"的伏笔

3. **人物行为逻辑验证**：
   - 抽取5-10个关键决策节点
   - 验证每个决策是否符合人物的既定性格和动机
   - 标记"降智操作"（人物为了剧情需要做出不符合人设的行为）

4. **节奏健康度诊断**：
   - 识别"水章节"：信息增量≈0的章节（只是日常/琐事/无效对话堆砌）
   - 识别"信息过载"章节：同时推进太多线索，读者难以消化
   - 给出问题章节的修复建议

**交付物**：
- 设定一致性审计报告
- 伏笔回收率统计表（含回收质量评级）
- 人物行为逻辑验证报告（含降智操作标记）
- 节奏健康度诊断报告（标注问题章节+修复建议）

---

### Step 6：方法论提炼（出结论）

**目标**：将感性分析转化为可复用的创作模型

**执行动作**：

1. **成功要素提炼**：
   - 这本书为什么火？不是泛泛的"写得好看"
   - 提炼3-5条可复用的核心方法论
   - 每条方法论标注优先级（🔴核心/🟡重要/🟢锦上添花）

2. **缺陷与风险分析**：
   - 这本书有什么缺点？如果模仿需要注意什么？
   - 哪些设定/桥段是独特的，复制可能导致"东施效颦"？
   - 风险等级标注：🔴高风险/🟡中风险/🟢低风险

3. **跨类型迁移方案**：
   - 哪些设计可以从当前类型迁移到其他类型？
   - 迁移时需要做什么适配？
   - 举例说明迁移后的效果

4. **生成方法论卡片**（3-5张）：
   ```
   每张卡片含：
   - 名称（好记的名字）
   - 适用场景（什么类型/什么阶段的创作需要）
   - 核心公式（1-2句话概括这个技法的本质）
   - 操作步骤（具体怎么用）
   - 案例示范（从来源作品中找典型用法）
   - 变体空间（这个技法可以怎么变化）
   - 注意事项（容易踩的坑）
   ```

**交付物**：
- 成功要素清单（含优先级排序）
- 模仿风险警告（含风险等级）
- 跨类型迁移方案
- 方法论卡片（3-5张）

## 三、文风DNA标签系统

从拆解结果中提取3-5个可量化的"文风DNA标签"，每个标签采用五段式结构：

```
━━━━━━━━━━━━━━━━━━━━━━
标签N：[特征名称]
  定义：（一句话精准描述）
  量化支撑：（从拆解数据中引用的具体数字）
  触发条件：（什么场景/情绪/节奏下使用这个特征）
  仿写规则：（在创作中如何复现这个特征的具体操作）
  反例警示：（怎样写就"不像"了）
```

**示例**：
```
标签1：短句驱动 + 高频动作
  定义：以短句为主（平均句长<18字），动作描写占比>40%，叙事节奏快
  量化支撑：采样5章，平均句长15.3字，动作描写占42%，对话占38%
  触发条件：战斗场景、紧张氛围、快节奏推进、爽点释放
  仿写规则：每句≤20字，多用动词少用形容词，段落≤3行，对话独立成段
  反例警示：不要在战斗场景混入>30字长句或大段心理描写

标签2：对话推动剧情
  定义：对话占比>35%，关键信息通过对话而非旁白传递
  量化支撑：采样章节对话占比38%，75%的信息反转出现在对话中
  触发条件：群像场景、智斗、权谋、人物关系推进
  仿写规则：每段对话承担至少一个功能（推进/塑造/传信/冲突），潜台词优先
  反例警示：不要让对话变成"信息告知"，对话要有冲突张力

标签3：双线交叉叙事
  定义：明线+暗线交替推进，每5-8章切换一次叙事焦点
  量化支撑：全书共使用X次视角切换，平均间隔7.2章
  触发条件：悬疑、历史权谋、科幻、多主角群像
  仿写规则：明线推进剧情，暗线提供"另一个视角的真相"，切换时留钩子
  反例警示：切换不能太频繁（<3章），不能让读者混乱
```

## 四、推断标注规则

当基于有限样本（如只拿到样章、只拿到部分章节）进行拆解时：

1. 必须在拆解报告标题标注：`[基于有限样本推断]`
2. 每一步推断性分析必须以 `⚠️推断：` 开头
3. Step 1-3（宏观/中观）基于有限样本时主要做推断并标注
4. Step 4（微观）是基于有限样本最可靠的部分
5. 推断的置信度：高/中/低，必须标注
