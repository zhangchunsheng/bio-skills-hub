# FAQ｜v1.0.1

**Q：功能说明书在哪？**  
A：包根目录 `README.md`。Skill 里只有索引；问「有什么功能」应先按 README 讲。

**Q：有 MD 转番茄 TXT 吗？**  
A：有。`scripts/export_fanqie.py`（从你本地 `AI小说/tools/export_fanqie.py` 适配），说明见 `export-fanqie.md`。标点修复那几个脚本不上架。

**Q：套件里有评审吗？**  
A：有。路径 E，`juzu-reviewer.md`。四十年读者经验已覆盖玄幻/都市/言情/悬疑/历史/科幻/游戏诸天等全品类，不单用悬疑尺子。

**Q：写作和锐评会不会搅在一起？**  
A：锐评时切换毒读者身份，禁止边评边灌下一章；评完再问「改章 / 续写」。

**Q：和番茄章质量清单≥60 什么关系？**  
A：&lt;60 硬拦先改。≥60 可交章，但必须亮完整分表+档位；上架/续改/下一章由作者自选。清单是快检，巨著桌是发前深度锐评。AI 不代言「可以上架了」。

**Q：为什么没有示范书正文？**  
A：已去掉固定示范故事。开箱看 `examples.md` 与 `templates/`。

**Q：女频 / 上架文案？**  
A：`female-channel.md` / `title-blurb-cover.md`。

**Q：保证上榜/过审吗？**  
A：不保证。
