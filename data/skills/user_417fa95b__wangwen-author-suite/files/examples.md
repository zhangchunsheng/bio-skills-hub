# 调用样例｜v1.0.1（写审一体）

> 本文件回答两个问题：**对话怎么走**、**正文大概长什么样**。不附带整本示范书。

---

## 例0｜开箱要示例 / 有什么功能

**用户：** 有没有写出来的例子？这个 skill 能干什么？  

**助手：**  
1. 功能摘要（指向 `README.md`）：开写、番茄专线（进阶）、巨著桌锐评、上架文案、MD→番茄 TXT。  
2. 正文对照：见本文件「范文片段」。  
3. 空白模板：`templates/`。  
4. 接着问：走 **快速开写（推荐新手）** 还是 **番茄专线（进阶）**？

---

## 例1｜模糊指令纠错（可靠性）

**用户：** 帮我写本特别火的小说。  

**助手：**

```

请选一项继续：
1）快速开写（3问，推荐新手）
2）番茄专线（6问，进阶）
3）只要大纲
4）锐评已有正文（请粘贴）
5）导出番茄 TXT

**用户：** 1  

**助手：**（一次一问）先问类型，给选项：玄幻仙侠｜都市｜现代言情｜悬疑｜其他……  
**禁止：** 直接开写、或跳进番茄 6 问。

## 例2b｜范文片段（都市·路径 A 口吻，约 400 字示意）

> 以下仅为**风格与钩子示范**，不是整章交付；正式章须更长并过质量硬标准。

会议室的灯白得刺眼。HR 把解除劳动合同通知书推到林川面前，签字栏空着，像一张没填完的病危通知。

「不是你能力的问题。」HR 说，「是业务线砍了。」

林川没接笔。窗外写字楼玻璃反着晚霞，他想起上周自己还在站会上拍桌子：那个方向没死，死的是你们不敢赌。

手机震了一下。前东家的投资人发来截图——群聊里有人把他裁员通知配了「又一个嘴硬的产品」的表情包。

林川把通知书折好，塞进公文包最底层。出门时前台还在笑：「林哥，保重。」

电梯门合上前，他看见走廊尽头站着自己带过的实习生，手里捏着一份竞品分析，封面标题和他上周被否的方案一字不差。

实习生抬头，对上他的眼睛，慌忙把文件夹扣住。

林川按住电梯开门键，声音很平：「你那份，发我私人邮箱。今晚十二点前。」

门关上。他没有回头。

**章末钩（示范）：** 实习生方案=被否方案，信息差已立；「今晚十二点」把冲突推到下一章。

**硬标准对照：** 有具体欠账钩 ✓｜无空喊下章更精彩 ✓｜品类药=都市打脸/证明自己将至 ✓

## 例3｜番茄专线（进阶，勿对新手默认）

仅当用户说「番茄专线 / 走6问 / 高数据」时：

一次一问：情绪→题材→主角→反差→冲突→章数 →「凭什么不一样」→ 规划 00–03 → **用户确认** → 第1章（2200–2800 目标）→ 质量表打分：

- **&lt;60**：先改  
- **≥60**：交正文 + 贴 10 项分表 + 档位 → 作者自选：改本章 / 下一章 / 上架或导出 / 巨著桌  

**禁止：** 报「62 分可以上架了」。

**错误示范：** 用户只说「帮我写小说」就进 6 问。

```

## 例7｜锐评衔接（内置巨著桌）

章末固定：

```
可选下一步：
1）继续下一章
2）巨著桌锐评（本套件内置）：模式巨著桌锐评。对象：第X–Y章。标准：巨著桌不降档。
3）上架文案：模式上架文案。
```

**用户选 2 或说「锐评这章」** → 路径 E，执行 `juzu-reviewer.md` 七段+分数+P0；**禁止**灌鸡汤代替打分。

---

## 例8｜锐评输出骨架（示意）

**用户：** 审一下上面那段（例2b），巨著桌不降档。  

**助手（节选）：**

- 上瘾度：6.8 / 10  
- 钩：有（实习生方案=被否案 + 十二点deadline）——过  
- 人：林川有动作有压，HR/实习生略薄——可过但人物分不高  
- 价：都市打脸药已埋，尚未兑现——本章可过，下章必须兑现一刀  
- P0：正式交章须扩到平台字数；实习生动机补一句，避免「工具人扔钩」

## 例9｜只要评审 / 导出

**评审：** 用户粘贴正文 +「巨著桌」→ 直接四十年读者输出，不开书 6 问。  

**导出：** 「导出番茄」→ 路径 F，给出 `python scripts/export_fanqie.py --src novels/书名 --as-chapter`，说明输出目录与目录.txt。
