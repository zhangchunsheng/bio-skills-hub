## 新手三步（先看这里）

1. 对 AI 说：`我想写一本××小说`（或 `帮我写个小说`）→ 走 **路径 A 快速开写**  
2. 看输出长什么样：打开 `examples.md`（含范文片段）  
3. 写完一章要毒审：说 `巨著桌锐评这章`  

**番茄专线（6 问）是进阶**：只有你明确说「番茄专线 / 走6问 / 高数据」才用。不要一上来就 6 问。

质量一眼可见：`references/quality-hard-standards.md`（章钩、字数、假好文笔、品类药）。  
番茄交章：`≥60` 亮完整分表，**上架还是继续改由你看分自选**；`&lt;60` 先改。

## 一句话：装完你能做什么

1. **开书 / 写连载**（新手默认快速开写；进阶可走番茄 6 问）  
2. **大纲确认后再逐章写**，落到 `novels/书名/`  
3. **去 AI 味 + 假好文笔 + 章钩检查**  
4. **巨著桌锐评**（四十年读者，全品类）——不必另装锐评包  
5. **起书名 / 写简介 / 封面句**  
6. **MD → 番茄可粘贴 TXT**（很多人不知道：用脚本）  
7. **女频言情**有专章写法

## 路径一览（A–F）

| 路径 | 名称 | 难度 | 干什么 |
|------|------|------|--------|
| **A** | 快速开写 | ★ 默认 | 类型+谁/要什么/谁拦 → 第 1 章 |
| **B** | 全流程通用 | ★★ | 类型/风格/字数/平台 → 大纲确认 → 逐章 |
| **C** | 番茄专线 | ★★★ 进阶 | 情绪标签 6 问 +「凭什么不一样」→ 规划四件套 → 2200–2800 → 五章数据环 |
| **D** | 上架文案 | ★ | 书名 / 简介 / 封面句 |
| **E** | 巨著桌锐评 | ★★ | 四十年读者：钩·人·价·类型毒性打分 + P0 改稿 |
| **F** | 番茄导出 | ★ | `scripts/export_fanqie.py`：MD 去标记、引号转换、目录.txt |

**重要：** 大纲/规划**未确认**，不会一口气灌整本。  
**写 vs 审：** 说「锐评」时走路径 E，不会假装评审却继续灌下一章。  
**模糊指令：** AI 应回【输入未通过】+ 选项，而不是瞎开写。

## 番茄专线多出来的东西（进阶）

- 情绪标签：打脸爽文 / 极致虐恋 / 爆笑反套路 / 悬疑惊悚 / 治愈甜宠 / 脑洞大开  
- 落盘：`00-大纲` `01-人物` `02-情绪曲线` `03-黄金开篇（50 字三版）` + 章节 md  
- 钩子轮换、质量清单（&lt;60 硬拦；≥60 亮表+作者自选上架/改章）、可选字数脚本  
- 每 5 章节奏报告；有完读/追读数据就调纲，没有就跳过

## 番茄导出脚本（路径 F）——请务必知道

番茄后台一般**不能直接传 Markdown**。本包已带导出工具：

```bash
python scripts/export_fanqie.py --src novels/你的书名 --as-chapter
```

- 输出默认：`novels/你的书名/番茄导出/`  
- 每章一个 `.txt`（可粘贴正文）+ `目录.txt`（章节标题）  
- 去掉 `#` `**`、HTML 注释；`「」`→`“”`  
- 跳过大纲/人物等规划文件  
- 默认预警不足 **1000** 字的章（可用 `--min-chars` 改）  

说明：`references/export-fanqie.md`  
字数粗检（番茄专线 2200–2800）：`scripts/check_chapter_wordcount_tomato.py`

无 Python 时：让 AI 按 `export-fanqie.md` 规则手搓去标记，或你本机安装 Python 再跑脚本。

## 推荐工作流

```text
番茄专线开书 → 确认规划 → 逐章写
    →（可选）巨著桌锐评
    →（可选）上架文案
    → 导出番茄 TXT → 粘贴后台
```

番茄交章后：AI 应亮质量分表；≥60 时你自选 改本章 / 下一章 / 上架或导出 / 巨著桌。AI **不**代言「可以上架了」。
