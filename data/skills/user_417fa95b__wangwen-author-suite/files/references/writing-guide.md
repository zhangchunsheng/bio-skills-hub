# 网文写作指南｜writing-guide

配合 `genres.md` / `hit-books.md` 使用。

## 黄金三章

| 章 | 必须交付 |
|----|----------|
| 1 | 冲突进场；人设标签；禁止长说明书 |
| 2 | 规则/金手指/伤口显现；代价或限制露头 |
| 3 | 第一次小兑现或更深欠账；读者决定追不追 |

## 爽点节奏

- 小爽：每 3–5 章（翻盘、打脸、揭一层）  
- 大爽：约每 10 章（阶段胜利，同时埋更大债）  
- 悬疑/黑暗向：用「怕与信息差」代替无脑打脸，仍要有节奏兑现  

## 悬念与伏笔

- 章末钩类型：信息差 / 危机将临 / 关系破裂 / 假通关 / 物件异常  
- 伏笔必须可回收；禁止章章空喊「下章更精彩」  

## 各类型核心（摘要）

详见 `genres.md`。生成时锁定类型再写：玄幻看等级兑现；都市看身份差当场撕开；灵异/规则怪谈看规则互撕；历史看对话权谋；网游看一局一懂的赢。

## 写作禁忌

- 任务栏腔、段段金句、主题字幕、他又想起灌水  
- 无动机反派、工具人女主/男主  
- 抄袭名著标志桥段  
- 章末无钩  

## 单章自检（交卷前）

- [ ] 字数在目标 ±20%  
- [ ] 章末有具体钩  
- [ ] 人物口吻与已写一致  
- [ ] 有事件推进，不是纯回忆  
- [ ] 过红线与去AI快扫
