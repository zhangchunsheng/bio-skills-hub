# 平台闸门｜platform-gate

> 吸收「多平台审核清单」精华；**禁止**对用户说「已保证过审」。

## 红线（生成即避；触线则改写）

- 涉政现实敏感、未成年人色情、详细性描写擦边、无意义虐、违禁违法教学  
- 可识别抄袭/洗稿指定作品  

## 平台风格适配（写作口感，非过审保证）

| 平台 | 适配 |
|------|------|
| 番茄 | 开篇快、章短密、钩狠、口语清楚 |
| 起点 | 长线承诺+小兑现；世界观行动中带出 |
| 晋江 | 关系与动机自洽；语气按频道；仍要章钩 |
| 七猫 | 代入强、对话可偏多、推进直接 |
| 未定 | 按番茄 + 红线最严交集 |

## 章级「过闸」报告（简版，交用户）

```
【章闸】第N章
红线：通过 / 已改写（改了什么）
AI味/假好文笔：通过 / 已改写
章钩：有（类型）/ 已补
字数：xxxx（目标xxxx）
说明：不过审承诺；发前请自审 + 可选用巨著桌。
```

## 与竞品话术差异

竞品常写「按晋江最严过滤即可发」。  
本包写：「按红线+去AI+章钩处理；**平台规则会变，发前你自己再过一遍**。」
