# 番茄章质量清单｜tomato-quality-checklist

每项 0–10，总分 100。

## 闸门与自选（写死）

| 总分 | 动作 |
|------|------|
| **&lt;60** | **硬拦**：先改再交；可不贴全文，但须说明扣分项与改法 |
| **≥60** | 可交章正文 + **必须亮完整分表** + 档位一句；**禁止**说「可以上架了」「过了就能发」 |

**≥60 不等于鼓励上架。** 上架 / 继续改 / 先写下一章，由作者看分后自选。

### 档位话术（交章时必带一句）

| 分档 | 怎么说 |
|------|--------|
| 60–69 | 刚及格：能交章存稿；开篇/卡点章不建议直接上架 |
| 70–84 | 稳交：可续写；上架仍建议你自己点头 |
| 85–100 | 可冲：质量侧较稳；仍不承诺流量与过审 |

### ≥60 交章末尾固定三选一

```
质量表总分：XX/100（档：…）
请看完分表后自选：
1）继续改本章（可指定弱项或冲75+/85+）
2）先这样，写下一章
3）我认了 → 上架文案 / 导出番茄 TXT
```

也可加：`4）巨著桌锐评本章`（深度审，与清单快检分开）。

## 分表（交章时逐项填数，禁止只报总分）

| 项 | 分 |
|----|-----|
| 前50字抓力 | /10 |
| 前20%有冲突 | /10 |
| 情绪标签打到 | /10 |
| 3–5场且有推进 | /10 |
| 对话有个性 | /10 |
| 去AI/假好文笔 | /10 |
| 章末钩有效且类型合规 | /10 |
| 与上文连贯 | /10 |
| 字数区间 | /10 |
| 展示而非讲述 | /10 |
| **总分** | /100 |

备注：金句最多 1 句划线评论位；多了扣假好文笔分。
