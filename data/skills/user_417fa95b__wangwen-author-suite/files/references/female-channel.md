# 女频 / 晋江向写法｜female-channel

> 路径 B 或番茄情绪选「极致虐恋/治愈甜宠」且题材言情时必读。  
> 学节拍与关系钩，不抄热门文情节。

## 读者买什么

情绪价值、拉扯、身份差、甜虐节奏、男主/女主高光轮转、关系每章有进退。

## 章法

| 要点 | 做法 |
|------|------|
| 开篇 | 尽快人物化学反应或错位冲突，禁长背景 |
| 节拍 | 甜/虐/误会可视化；约 3–5 章一小爆发 |
| 对手盘 | 不止情敌，还有家族/职场/旧伤 |
| 章钩 | 关系将破未破、秘密半句、选择死局 |
| 金手指 | 重生记忆等要有代价，禁无脑开挂虐人 |

## 文笔

- 心理戏落到动作与对话  
- 少无事件长独白  
- 晋江向：动机自洽、感情线合理；仍要章钩（本包不加「过审包票」）

## 反差点常用（选项，需配「凭什么不一样」）

虐后反杀｜追妻火葬场｜隐婚身份差｜双向奔赴破误会｜养成系权力翻转  

## 雷

女主无脑、男主无理由暴戾当人设、只有甜没有对手、段段鸡汤。

## 与番茄情绪标签对接

- 极致虐恋 → 每单元一次关系撕裂，须有回收计划  
- 治愈甜宠 → 温馨场也要留钩，禁止三章纯日常  
- 爆笑反套路 → 预期翻转落在关系上  

## 输出时多给

关系节拍表（10 章内甜虐分布）+ 男女主各一句可截图人设钉。
