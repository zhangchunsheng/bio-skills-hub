# 书名 / 简介 / 封面文案｜title-blurb-cover

模式名：`上架文案` 或用户说「起书名」「写简介」「封面文案」。

## 输入

- 一句话卖点或大纲摘要  
- 平台（番茄/起点/晋江）  
- 情绪标签（可选）  

缺则先问，勿空写。

## 输出（一次给全，可直接用）

1. **书名** 5 个（偏搜索词 / 偏意象 / 偏冲突，标推荐 1）  
2. **一句话卖点** 2 个（≤30 字）  
3. **简介** 2 版：  
   - 短版 ≤120 字（故事在前，假动作在后）  
   - 中版 ≤500 字（番茄常见）  
4. **封面文案**（可打在封面上的 1 句 + 忌堆字提醒）  
5. **禁止项**：剧透结局、空喊「震撼大作」、与正文人设不符  

## 简介纪律

- 先场景/冲突，后设定说明书  
- 留钩，不写完结局  
- 对准情绪标签一词即可，勿堆六种情绪  

输出示例结构即可，勿绑定固定示范书名。
