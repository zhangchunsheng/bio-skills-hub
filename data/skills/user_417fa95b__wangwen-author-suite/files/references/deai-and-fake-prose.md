# 去AI化 + 假好文笔｜deai-and-fake-prose

> 竞品强项「去AI化」保留；本包叠加 **假好文笔**（金句病/任务栏/主题字幕）——过「像人」且过「能追」。

## AI 味特征

| 特征 | 表现 |
|------|------|
| 句式规整 | 排比、并列「看到…听到…想到…」 |
| 词汇正确平淡 | 抽象正确、无个性 |
| 无口语 | 对话太礼貌太完整 |
| 情感模板 | 「心中一惊」「热泪盈眶」「涌起暖流」 |
| 五感均匀 | 每段感观摊派 |
| 无留白 | 信息写满 |

## 假好文笔（本包加严）

| 病 | 表现 | 处理 |
|----|------|------|
| 金句病 | 段段升华 | 砍到偶有一句钉人设 |
| 主题字幕 | 「他明白了爱与责任」 | 改动作/对话 |
| 任务栏规则 | 通关/考核/材料已接收 | 改物件告示或人口述且互撕 |
| 回忆灌水 | 「他又想起」凑字 | 改当下摩擦 |

## 改写刀法（摘要）

- 长短句交替；允许「无用」的真实细节（松掉的鞋带、没喝完的酸奶）  
- 对话可打断、答非所问、带口气  
- 情绪用动作压，不说破  
- 物件先行于形容词  

## 输出格式（去AI模式）

1. 检测报告（条目+例句）  
2. 假好文笔条目  
3. 改写版全文  
4. 复检勾选  
5. 下一步  

## 章末流水线用法

逐章生成时：先红线 → 再本文件快扫 → 不通过则改写后再交用户。
