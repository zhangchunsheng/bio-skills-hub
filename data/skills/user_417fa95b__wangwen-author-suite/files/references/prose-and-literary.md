# 文笔与文学技法｜为流量与追更服务

> 原则：**文学性 = 让人记住、上瘾、愿传播**；不是颁奖词，不是辞藻展销会。

---

## 1. 流量文笔的底层（所有品类）

| 优先 | 少用/禁用 |
|------|-----------|
| 物件先于形容词（椅、包、缺翅鹤） | 段段金句、排比抒情 |
| 对话像真人半夜吵 | 主题字幕（「他明白了爱」） |
| 信息差与留白 | 任务栏口吻（通关/考核/材料已接收） |
| 短句推进冲突 | 「他又想起」灌水 |
| 一句可截图的人设/刺点 | 堆「像A像B」撑长 |

**验收句：** 骂着主角还点下一章吗？评论区会不会只夸「文笔好」然后弃书？

---

## 2. 可学的「文学刀」（对标名著级网文）

### 意象钉人（戏神向）

- 用一个反复出现的物件/称呼钉人设。  
- 不解释象征；让读者自己发毛。  
- 练习：给主角写 **一句 15 字内人设钉** + 一个贯穿物件。

### 规则互撕的冷叙述（十日向）

- 句子越冷静，越恐怖。  
- 规则写在告示/纸片/对话里，不要写成作者说教。  
- 练习：两条规则，让遵守 A 必违 B。

### 仪式感信息差（诡秘向）

- 重要行动有「步骤感」与代价。  
- 读者比配角多知道一点，或比主角少一点——形成追更。  
- 练习：同一场面写两版信息差（读者全知 / 读者半知）。

### 对话权谋（庆余年向）

- 每句对话改变权力关系或信息格局。  
- 幽默是刀刃不是气氛组。  
- 练习：删光动作描写，只留对话，剧情仍要前进。

### 气势与顿挫（遮天向）

- 大场面用他人反应与空间尺度，不靠形容词堆「强大」。  
- 练习：写一场胜，主角零台词，全靠环境与旁人。

### 专业结果化（全职向）

- 行话必须翻译成「这局为什么赢」。  
- 练习：用外行听得懂的三句话解释一次翻盘。

## 3. 传统文学技法 → 网文用法

| 技法 | 网文用法 |
|------|----------|
| 留白 | 章末欠一口；怪谈不说破 |
| 反讽 | 主角「我认为我对」与现实互撕 |
| 不可靠叙述 | 信息差追更，慎用到劝退 |
| 母题/意象 | 一条线贯穿（鹤、伞、门）服务主题，不喊主题 |
| 节奏 | 密事后必须小兑现，禁止漂亮疲软 |
| 人物弧 | 变脏、变贵、变贵才是成长，不是觉悟演讲 |

---

## 4. 假好文笔诊断（写作时自检）

出现则砍：

- 每段一个金句  
- 结尾升华人生  
- 日常清单表演当情节  
- 用回忆凑字数  
- 规则像游戏 UI  

---

## 5. 文笔特训模式输出格式

1. 原文问题（具体到句）  
2. 对标刀法（学谁的哪一刀）  
3. 改写示范（保留剧情，换刀法）  
4. 可复用句式模板（2–3 个）  
5. 下一章练习作业（一小段）  

---

## 6. 「写得像名著又有流量」的平衡

- **名著感：** 意象、代价、人设余震、规则毒性。  
- **流量感：** 章钩、冲突密度、人设标签、三章内进戏。  
- 两者冲突时：**先保章钩与冲突，再用文学刀加持**——先能追，再能吹。
