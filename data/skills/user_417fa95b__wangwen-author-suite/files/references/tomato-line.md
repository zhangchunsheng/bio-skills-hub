# 番茄专线详规｜tomato-line

吸收 Tomato Novelist：**情绪标签、规划四件套、开篇50字三版、钩子轮换、五章数据环**。  
放弃：算法保送话术、无差异点开写、脚本硬依赖。

## 情绪标签 → 章内必须打到的戏

| 标签 | 章内至少一场 |
|------|----------------|
| 打脸爽文 | 身份差被当场撕开/马甲压人 |
| 极致虐恋 | 关系撕裂或火葬场级误会（有回收计划） |
| 爆笑反套路 | 预期翻转+吐槽位 |
| 悬疑惊悚 | 细思极恐物件/规则缝/信息差 |
| 治愈甜宠 | 双向小确幸但不消章钩 |
| 脑洞大开 | 金手指规则兑现一场 |

## 黄金开篇 50 字（03-黄金开篇.md）

输出 **A/B/C 三版**，各约 40–60 字：  
- 有冲突或异常物件  
- 能当书架/简介钩  
- 对应情绪标签  
用户选一版写入第1章开头，可改。

## 开头技巧（前20%选用，轮换）

1. 冲突中途进场 2. 一句伤人对白 3. 异常物件 4. 倒计时/期限  
5. 当众羞辱 6. 尸体/失踪信息 7. 系统乱报但禁任务栏腔 8. 误会现场  
9. 背叛当场 10. 规则告示互撕  

## 章末钩子类型（近3章不得重复）

信息差｜危机将临｜关系破裂｜假通关｜身份将揭｜物件异常｜反派多走一步｜选择死局｜真相半句｜倒计时归零  

## 情绪单元（写入 02-情绪曲线.md）

建议每 3 章一单元：`压 → 小扬 → 压 → 爆`（爆可落在单元末章）。  
记录：计划情绪 / 实际钩子 / 是否打到标签。

## 五章节奏报告模板

```
【节奏报告】第X–Y章
情绪标签执行：…

```
