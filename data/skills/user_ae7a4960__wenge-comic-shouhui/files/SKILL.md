# 文哥漫画-手绘 v1.0 · 极简手绘风独立 skill

> 收到任意内容 → 调性适配评估 → 话数/图数计算 → 拆骨架 → 配比喻 → 出图 → 拼配图集 HTML
>
> 输出形态：**长文配图**（公众号/知乎/微信文章内嵌图）+ **PPT 演讲页/课程封面/海报/印刷品**（IP2 商务版）
>
> **v1.0 定位**：从 上一代 v3.0 漫画 skill 拆分出来的**第一条独立线**——极简手绘风。
> 与 `文哥漫画-贱萌` skill 并列，分别承载两种风格。

## 0. 调性适配评估 · 5 维评分（v1.0 核心 · 入口必走）

> **每个新任务开始前，先做调性适配评估**。5 维评分 → 推荐风格 → 调性不匹配时给主动建议。
> 详见 `references/tone-matching.md`

### 5 维度评分

| # | 维度 | 1 分（极端 A） | 3 分（中性） | 5 分（极端 B） |
|---|---|---|---|---|
| 1 | **严肃度** | 学术论文 / 政策解读 | 商业 / 管理 / 方法论 | 娱乐 / 网梗 / 吐槽 |
| 2 | **情绪温度** | 冷峻 / 克制 | 中性 / 自信 | 热情 / 热烈 / 狂欢 |
| 3 | **视觉密度** | 极简 / 留白 60%+ | 适中 / 信息图 | 丰富 / 漫画 4 格 |
| 4 | **受众期待** | 管理者 / 高管 / 学者 | 同行 / 从业者 | 大众 / 年轻人 / 亲子 |
| 5 | **传播场景** | 内部培训 / 演讲 PPT / 印刷品 | 公众号 / 知乎 | 视频号 / 小红书 / 抖音 |

**A 风格（极简手绘）总分最佳区间**：5-13 分（偏严肃 + 偏冷峻 + 偏极简 + 偏专业 + 偏长文场景）

### 调性不匹配时的建议

| 总分 | 适配度 | 建议 |
|---|---|---|
| **5-10 分** | ✅ **高** | 用 A 风格直接干 |
| **11-15 分** | ✅ **中** | 用 A 风格，必要时去掉文哥 chibi 化（更克制） |
| **16-20 分** | ⚠️ **低** | 主动提示用户"该内容偏娱乐/网梗风格，建议用 `文哥漫画-贱萌` skill" |
| **21-25 分** | ❌ **不匹配** | 强制提示"调性完全不匹配，请改用贱萌风" |

### 2.1 三层角色架构

```
第 1 层 · 主 IP 锁 · 文哥 v6 极简手绘
   • 黑短发 + 方框眼镜 + 干净无胡 + 白长袖上衣 + 成人比例

   • 每 ep 按隐喻生成 0-2 个具象角色
   • 识别方式 = 职业符号（厨师帽/听诊器/安全帽）
   • 角色为隐喻服务，不是反过来

第 3 层 · 火柴人 Agent · 抽象执行
   • 矩形身体 + 小圆头 + 小眼睛
   • 永远黑线无色
```

## 4. 6 步管线（v1.0 标准化流程）

> **协作视角速查表**——v1.0 端到端跑一篇，**6 个节点需要你拍板**，每次 5-30 秒：
>
> | 闸门 | 节点 | 你说啥 | 备注 |
> |---|---|---|---|
> | **1** | 调性适配评估（5 维） | "高" / "中" / "低" + 风格选择 | **v1.0 核心** |
> | **2** | 读完内容摘要 | "读到了" / "换源" | 看你上游材料识别对没 |
> | **3** | 图数建议 | "OK" / "调成 N 张" | 按弹性指南 + KB |
> | **4** | shot list | "OK" / 改某张 / "选 X 钩子" | |
> | **5** | 出图（每张 ~30s） | "过" / "哪张重出" | 8 项验图清单；出图密度 85% 必过 |
> | **6** | HTML 终稿 / 配图集 | "OK 部署" / "改这改那" | 浏览器自检截图 |
>
> **耗时**：6 闸门 × 5-30 秒 = 你投入 **5-15 分钟**；机器端到端 15-45 分钟跑完。

### 步骤 1 · 调性适配评估（v1.0 新增）

详见 **第 0 节**。每个任务开始必走。

### 步骤 2 · 读取

**目标**：输出统一格式 `SourceText { title, content, metadata, source_type, raw_path? }`

按 7 种输入格式分支处理（详见 `references/input-formats.md`）。

**确认闸门**：读取成功后展示 `SourceText` 摘要（标题+首 200 字+总字数），等用户确认"读到了，开始下一步"。

### 步骤 3 · 图数计算 + 弹性指南

#### 3.1 按文章长度计算

| 文章长度 | 推荐图数 |
|---|---|
| < 2 KB | 1-2 张 |
| 2-5 KB | 2-3 张 |
| 5-10 KB | 3-5 张 |
| > 10 KB | 5-8 张 |

#### 3.2 按内容性质弹性指南（**v1.0 新增 · 不写死**）

| 内容性质 | 推荐图数 | 案例 |
|---|---|---|
| **单图卡** | 1 张 | 高密度金句、独立概念、卷首 |
| **小串联** | 3-5 张 | 方法论 3 步、4 件套、5 步法 |
| **中等** | 6-10 张 | 完整方法论、教程、案例分析 |
| **大串联** | 10-20 张 | 复杂系统、概念大集合 |
| **上下集** | 20-30+ 张 | 分篇发布 |

**v1.0 重要**：**图数由内容驱动，不写死**。用户/LLM 拿到公式范围（1-30 张）+ 弹性指南，自行决定。

详见 `references/episode-count-formula.md`

### 步骤 4 · 拆骨架 + 配钩子封面 / shot list

**长文配图 SKU**：
- 写 **shot list 13 字段**（详见 `references/shot-list.md`）
- 13 字段 = 图编号/主题/核心意思/视觉模式/结构类型/图类型/信息量/角色架构/角色动作/角色资产/Agent 分工/建议元素/建议中文标注
- **v1.0 新增** `tone_match` 字段（高/中/低 + 不匹配时建议）
- 借鉴小黑 skill 工作流

**PPT 演讲页 SKU**（v1.0 沿用 v3.0）：
- 写页面 card 字段（页码/页型/视觉权重/沟通任务/核心观点/标题/必保留词/IP 角色职责/辅助角色职责/密度/前后衔接）

### 步骤 5 · 配比喻 + 出图

**配比喻**（v1.0 沿用）：
- 每图定一个"接地气比喻"，直接融进正文（不立标签）
- v1.0 跨界比喻库：USB-C 接口/战壕/洋葱剖面/流水线/显微镜/望远镜/手术刀/灯塔

**出图**（v1.0）：

| SKU | 主 IP | 必传主锚图 | 配色 | 风格 |
|---|---|---|---|---|
| 长文配图 | 文哥 v6 | `assets/main_anchor.png` | IP1 三色 | 极简手绘 |
| PPT 演讲页 | IP2 文哥 | `assets/main_anchor_v2.png` | IP2 5 色 | 商务精致 |

**v1.0 出图 9 项硬约束**：

```
1. 主 IP 锚点 5 项（黑短发/方框眼镜/无胡/白上衣/成人比例）
2. 极简手绘眼（文哥 v6 简化眼形）
3. 禁尖耳/精灵耳/翘耳
4. 必带头（不光头）
5. 跨图同角
6. 配色锁（IP1 三色 / IP2 5 色）
7. 角色必参与核心动作
8. 中文短而准
9. 无水印/无英文（AI/USB-C 等保留）
```

详见 `references/brand-constraints.md` + `references/longform-illustration.md`

**确认闸门**：每批出图后肉眼确认：
- 极简手绘在线（黑线/橙红蓝/留白 60%）
- 角色跨图一致
- 中文 100% 清晰可读

**失败兜底**：单张失败 → 单独该图重出（最多 3 次）；整批失败 → 退回步骤 4 重配比喻。

### 步骤 6 · 拼 HTML / 配图集

**v1.0 长文配图 HTML**：
- 简单配图集，按文章章节分组
- 每图 1 个 `<figure>`，含 `<img>` + 短说明（≤ 30 字）

**v1.0 PPT 演讲页 HTML**：
- 16:9 比例页面，每页 1 个 `<img>` + 标题

**确认闸门**：HTML 生成完 → 自动 spawn 浏览器截图，user 拍板"OK 部署"或"改这改那"

## 6. 文案脱口秀化 · 段子手风格（v1.0 升级）

> 完整版见 `references/copywriting-style.md`，此处只列关键。

- **每段字数**：段子段 60-120 / 金句段 30-50 / 兜底段 ≤ 30
- **结构**：长 setup + 短 punch + callback（脱口秀节奏）
- **加粗规则**：每段最多 1 个 `<strong>`（莓红 `#D9304F`，font-weight 900，8-25 字）
- **谐音梗规则**：每段最多 1 个 `<em>`（橙黄底 `#FFE7BC` + 莓红字 + 900 字重）
- **自嘲频率**：每 3-4 话至少 1 次
- **脱口秀 13 手法**：预期违背/制造优越感/归谬/谐音/双关/拆词/比喻/荒谬/Call Back/反转/三段式/观察式/自嘲/角色扮演
