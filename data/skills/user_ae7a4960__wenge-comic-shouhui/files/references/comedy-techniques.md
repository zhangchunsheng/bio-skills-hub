# 脱口秀技法手册 · v1.0

> **文哥style 文案的核心：让每句话像站在台上讲脱口秀。** 不是讲师腔、不是咨询师腔、不是 AI 腔——是"一个有专业底子但故意不端着的中年人"在跟你唠嗑。
>
> **核心理念**：**先让读者笑，再让读者懂。** 笑是入口，懂是出口。

---

## 1. 脱口秀 14 手法字典（v1.0 系统化版）

> v2.4 散落在 layout-hints.md 里 13 手法 → v3.0 升级为正式手册 → **v1.0 沿用 + 加 1 手法（角色扮演）= 14 手法**。

### 手法 1 · 预期违背（Setup → Punch 反转）

**定义**：先按正常逻辑铺垫，让读者心里有个预期 A，最后给完全相反的 B。

**公式**：`{A 是这样} → 但 B 完全不是这样` 或 `{你以为 A} → 其实 B`

**文哥style 示例**：
> setup：学好 prompt 不如有个好模板
> punch：学了 50 个 prompt 模板，不如**知道啥时候该写 prompt**（预期：模板越多越强；反：知道何时不用 prompt）

**禁用**：违背方向太离谱 = 读者 get 不到 = 冷场

---

### 手法 2 · 制造优越感（"你懂但别人不懂"）

**定义**：让读者觉得自己"看穿了"，笑点来自"看穿"本身。

**公式**：`{外行以为 X} → 真相是 Y（看穿这一刻 = 笑）`

**文哥style 示例**：
> setup：隔壁公司"全栈 AI 工程师"招人，月薪 3 万
> punch：但你知道吗——他连 **Context window** 是什么都说不清（读者瞬间"看穿"外行公司）

**禁用**：把"优越感"做成"鄙视链" = 引发反感

---

### 手法 3 · 归谬法（推到极端 = 荒诞）

**定义**：把对方观点的逻辑推到极端，荒诞结果自然 = 笑点。

**公式**：`{观点 A} → 推到底 = {荒诞结果 B}`

**文哥style 示例**：
> setup：客户说"AI 帮我把生意做大做强"
> punch：那 AI 是不是得先**自己注册公司、找员工、搞财务**？开公司又不是点外卖！

**禁用**：归谬歪曲对方原意 = 杠精感

---

### 手法 4 · 谐音梗（双关）

**定义**：用发音相同/相近的两个词制造"啊哈"感。**脱口秀最被吐槽但最出彩的手法**——用得好是点睛，用得多是灾难。

**公式**：`A（字面意）+ B（谐音意）` 在一句话里同时成立

**文哥style 示例**：
> 厨子做饭叫**生成**，不是从<em>冰厢</em>（冰箱）拿现成的。AI 也是——现炒的不是预制菜！

**规则**：
- ✅ 每段**最多 1 个**谐音梗（多了变段子堆砌）
- ✅ 用 `<em>` 标签高亮（橙黄底 #FFE7BC + 莓红字 + 900 字重）
- ❌ 禁用**强制谐音**（为押韵而扭曲原意）

**谐音梗字典**：
- 接龙/接笼、Token/偷肯、冰厢/冰箱、文哥/问哥
- 装修队/装懂队、AI 应用/爱应用、Agent/阿金特
- 通用 Agent/捅用 Agent
- 5 Whys/5 外死
- 根因/根银

---

### 手法 5 · 双关（一词多义）

**定义**：用同一个词的两个意思，制造"读者要反应 0.5 秒才 get 到"的延迟笑点。

**公式**：`{词 A} 在场景 1 是一种意思，在场景 2 是另一种`

**文哥style 示例**：
> setup：项目经理最重要的事是"对齐"
> punch：开会"对齐" = 嘴上对齐（废话）vs **写下来对齐**（落地）。这两种"对齐"差了一个 Excel 表的距离

---

### 手法 6 · 拆词（把熟悉词解构成新意）

**定义**：把一个常用词拆开重读，发现平时没注意的细节。

**公式**：`{词} = {字 1} + {字 2} → 重新解释`

**文哥style 示例**：
> setup：什么是"理解"
> punch：理=道理，解=解开。"理解" = 把道理**解开**。AI "理解" = 把数学解开，**不是真懂**——它没"解开"那一步

---

### 手法 7 · 比喻 / 拟人（让抽象变具体）

**定义**：把抽象概念映射到具体事物（修辞基础，但脱口秀里要用得"反常识"）。

**公式**：`{抽象 A} = {具象 B（出乎意料）}`

**文哥style 示例**：
- 工厂车间 / 装修队 / 健身房 / 厨房 / 流水线 / 城市 / 餐厅 / 学校 / 出租车 / 银行柜台 / 快递分拣 / 流水线工人 / 火坑 / 牌桌 / 江湖草莽
- 跨界比喻（长文配图 SKU 用）：USB-C 接口 / 战壕 / 洋葱剖面 / 显微镜 / 望远镜 / 手术刀 / 灯塔

**文哥style 偏好**：生活化 + 略带江湖气（"江湖草莽"比"高大上"更对路）

---

### 手法 8 · 荒谬法（"荒诞但似乎有道理"）

**定义**：用荒诞的逻辑链，但每一步都对——最后结论荒诞 = 笑点。

**公式**：`{A} → {B} → {C} → {D 荒诞}`，但 ABC 都成立

**文哥style 示例**：
> setup：AI 越强，老板越焦虑
> punch：AI 写代码强 → 程序员慌 → 程序员学 prompt → 写 prompt 比写代码难 → **AI 反而替代了 prompt 工程师**——你看，老板焦虑闭环了

---

### 手法 9 · Call Back（呼应前文梗）

**定义**：在前文埋伏笔，后文再拿出来呼应。笑点来自"原来前面那句是 setup"。

**公式**：`前文 X（看似普通）→ 后文 X'（重新理解 = 笑）`

**文哥style 示例**（多话连载用）：
- 第 1 话：`"AI 还没到能替代人的时候"`（看似普通 setup）
- 第 8 话：`上回说"还没到"——现在看，确实还没到——**但你的岗位可能先没了**`（Call Back 反转）

**收尾话 Call Back 公式**：
- 拿前 7 话的 1-2 个关键词 → 收尾话里改 1-2 个字 → punchline 升级

---

### 手法 10 · 反转（先扬后抑 / 先抑后扬）

**定义**：方向突然反向。Call Back 升级版，但不依赖前文。

**公式**：`{A 方向} → 但实际 B 方向}`

**文哥style 示例**：
> setup：AI 这么强，我是不是该转行当 prompt 工程师
> punch：但你想想，**prompt 工程师的 prompt 是谁写？**——你看，连这条路的尽头都是 AI

---

### 手法 11 · 三段式（1+1+1 升级）

**定义**：三段递进，最后一段反转或拔高。脱口秀经典结构。

**公式**：`{A} → {B} → {C（升级 / 反转）}`

**文哥style 示例**：
> 通用 Agent 干所有事 → 什么都会一点 → **什么都不是专家**。通用不是强，是啥都不会

**砍排比的原因**：4 行排比显得装腔。三段刚好——1 句 + 1 句 + 1 句 punch。

---

### 手法 12 · 观察式（"你也遇到过吧"）

**定义**：从日常观察切入，制造"被冒犯但又认同"的共鸣笑点。

**公式**：`{日常场景} → 你肯定见过 → 真相是 X`

**文哥style 示例**：
> 你见过 PPT 上写"对齐颗粒度"的人吗？他们啥意思？——**他们自己也不知道**。这就是"颗粒度"这个词最大的用处：让所有人都点头

---

### 手法 13 · 自嘲 / 降维（把自己从高位置降下来）

**定义**：文哥 IP 自己吐槽自己——"我以前也不懂 / 我也踩过坑"。制造亲近感 + 拉平知识差。

**公式**：`{专业结论} → 但我学这玩意儿学了 X 年 / 交过 Y 学费`

**文哥style 示例**：
> setup：MCP 是 AI 工具调用的 USB-C 接口
> punch：这概念我第一次听也懵——**我搞 AI 培训 3 年，才把"MCP = 通用接口"想明白**。所以你懵是正常的

**v1.0 重要**：自嘲是文哥 IP 的"亲和力来源"，**每 3-4 话至少 1 次自嘲**，不能让读者觉得文哥是"高高在上的老师"。

---

### 手法 14 · 角色扮演（"我就是 XX"）

**定义**：文哥 IP 切换视角演某个角色（员工/老板/客户/AI），用角色口吻说一段话。

**公式**：`我现在是 {角色} → {角色口吻的吐槽 / 自白} → 切回文哥`

**文哥style 示例**：
> setup：我现在客串一下"老板"
> punch：「这个 AI 项目怎么还没出成果？」——这是我当年当老板时天天问的蠢问题。**老板要的不是结果，是进度可见**。你看，AI 不会汇报 = 老板觉得没干活

## 2. Setup / Punchline 节奏公式（v1.0 沿用）

**脱口秀核心是节奏**。文哥style 节奏 = **"长 setup + 短 punch"**：

### 公式 A · 长 setup（30-60 字铺垫）+ 短 punch（5-15 字反转）

```
[setup：类比 + 场景 + 反问（30-60 字）]
[punch：金句 1 句（5-15 字，加粗）]
[callback：再呼应收尾（10-20 字）]
```

**示例**：
> setup：你有没有发现，开会"对齐"这个词特别好用——老板说"我们要对齐"，产品说"我们已经对齐了"，程序员说"对齐颗粒度"——所有人都在点头，但**没人知道对齐的是啥**。
>
> punch：这就是"对齐"最大的用处——**让所有人同时觉得自己懂了**。
>
> callback：所以下次有人跟你说"对齐"，你就问一句：**"对齐到哪一行的第几个字？"**——看他怎么答。

总长 100 字左右，节奏感拉满。

### 公式 B · 极短版（1 句兜底 + punch）

适用场景：v2.5 文哥说块 14px 灰字兜底。

```
[1 句 setup] · [1 个金句加粗]
```

**示例**：
> 厨子做饭叫**生成**，不是从<em>冰厢</em>（冰箱）拿现成的。AI 也是——现炒的不是预制菜。

总长 ≤ 30 字。

### 公式 C · 段子版（4-6 句 1 段，类似脱口秀小段）

适用场景：v2.4 punchline 升级版（v2.5 砍过，v3.0/v1.0 重新允许但限制"段子段"用）。

```
[1 句引入类比] + [2 句场景展开] + [1 句反转] + [1 句 punchline]
```

**示例**：
> 老板天天问我"AI 项目做到哪了"。前 3 个月我说"在调模型"，老板点头；中间 3 个月说"在训练数据"，老板点头；后 3 个月说"在跑测试"，老板还是点头。
>
> 直到上线那天——**老板问的第一句话还是"能不能再快一点"**。

总长 80-100 字。

## 3. 段子段 vs 兜底段（v1.0 决策表）

| 块类型 | 长度 | 手法数 | 节奏 | 适用 |
|---|---|---|---|---|
| **段子段**（wenge_note 升级） | 60-120 字 | 2-3 手法组合 | 长 setup + 短 punch + callback | 收尾话 / 概念详解话 |
| **金句段**（punchline） | 30-50 字 | 1 手法 + 1 加粗 | 短 setup + punch | 强结论话 / 总结话 |
| **兜底段**（wenge_note 14px） | ≤ 30 字 | 0-1 谐音梗 | 1 句到底 | 通用 / 图自洽的 ep |

**v1.0 决策**：每话 `primary_block` 仍 0-1 选 1（v2.5 保留），但**长度分级**（段子段/金句段/兜底段）按内容选。

## 4. 文哥自嘲词典（v1.0 沿用 · 防"AI 老师"腔）

**5 个自嘲模板**（按场景用）：

1. `我学这玩意儿学了 X 年才明白……`（"我也懵过"）
2. `这概念我第一次听也懵……`（"你懵是正常的"）
3. `我以前也这样……后来交了 X 学费才想通`（"我踩过坑"）
4. `这事儿我们公司以前也踩过……`（"实战经验"）
5. `我当年以为 A，后来才发现 B……`（"我反思过"）

**使用频率**：每 3-4 话至少 1 次自嘲，**避免变成"高高在上的讲师"**。

**v1.0 关键**：文哥 IP 不是"讲台上的老师"，是"工地上的工头 + 过来人"。脱口秀演员叫"**stand-up comedian**"——文哥叫"**stand-up 培训师**"。

---

## 5. 禁用清单（脱口秀式 ≠ 段子堆砌）

❌ **段子堆砌**：一段里塞 3-4 个梗 = 读者没时间 get = 全冷场
❌ **网络烂梗**："我太难了 / 打工人 / yyds / 绝绝子"——文哥是中年人，不用 95 后梗
❌ **冷笑话**："从前有个程序员，挂了"——意义不明的笑点 = 尴尬
❌ **攻击特定群体**："90 后/00 后/老板/程序员都 XX"——引发反感
❌ **政治/宗教/地域梗**——直接掉粉
❌ **骂人/脏话**——与"专业培训师"人设冲突
❌ **AI 自我反思**："作为 AI 我认为"——文哥不是 AI
❌ **空话套话**："综上所述/总而言之"——讲师腔重

## 6. 脱口秀 vs 讲师腔 vs 段子手（v1.0 文案对照表）

| 风格 | 同一概念的 3 种写法 |
|---|---|
| **讲师腔**（禁用） | "MCP（Model Context Protocol）是一个标准化的协议，它定义了 AI 模型与外部工具之间的通信规范，旨在解决不同 AI 系统与各种工具集成时的兼容性问题。" |
| **段子手**（v2.5） | "MCP = AI 工具调用的 USB-C 接口。一次对接，所有工具都通。" |
| **脱口秀**（v1.0） | "MCP 这玩意儿我第一次听也懵——什么 Model Context Protocol，一串英文唬人。**后来我把它想成 USB-C 就行了**——你手机是不是就一个口？AI 工具也是，一次对接全通用。**别问，问就是 USB-C 那一天**。" |

v1.0 偏好 = 脱口秀 > 段子手 > 讲师腔。

## 7. 文案自检 checklist（v1.0）

每段文案写完**自检**：

- [ ] 有没有至少 1 个脱口秀手法？（预期违背/制造优越感/归谬/谐音/双关/拆词/比喻/荒谬/Call Back/反转/三段式/观察式/自嘲/角色扮演）
- [ ] 有没有 1 个加粗金句？（`<strong>` 标签，莓红 #D9304F，8-25 字）
- [ ] punchline ≤ 25 字？金句位置在前 2/3？
- [ ] 有没有"讲师腔"？空话套话？
- [ ] 有没有"网络烂梗"？95 后梗？
- [ ] 段子段字数 60-120？金句段 30-50？兜底段 ≤ 30？
- [ ] 自嘲频率：每 3-4 话至少 1 次？
- [ ] 谐音梗 ≤ 1 个 / 段？

**任一不通过 → 重写**。
