# 角色架构 v1.0 · 文哥 v6 主 IP + 按需配角

> **v1.0 核心简化**：
> 1. **主 IP 100% 固定**——文哥 v6（黑短发+方框眼镜+白上衣+成人比例）永远是主讲解人
> 2. **按需配角**——根据每 ep 隐喻，灵活生成角色（厨师/医生/工人/老板/学生……）
> 3. **5 老 IP 彻底废弃**——无 wenge/xiaoneng/chuzi/banzhang/xiaoq 角色档案，无彩蛋库，无角色轮换
> 4. **火柴人 Agent**——抽象执行者，永远黑线无色，承担"递结果/标风险/反馈"等辅助动作
>
> **核心理念**：**主 IP 唯一（人感） + 配角抽象（灵活） + 隐喻为内容服务（不受限）**。
>
> **v1.0 vs v3.0 关键差异**：v3.0 还保留 5 老 IP 作为彩蛋库（10% 场景），v1.0 **彻底废弃**——主 IP 只有文哥 v6 一个。

## 2. 文哥 v6 主 IP · 详细规格

**主锚图**：`assets/main_anchor.png`（176 KB）

### 2.1 必带锚点（5 项 · 任何图都必出现）

| 锚点 | 描述 | 失败模式 |
|---|---|---|
| **黑短发** | 略刺猬头，中等长度，不贴头皮 | 黄/棕/灰/光头 ❌ |
| **方框眼镜** | 黑/深色细框，**必带** | 圆框/无框/墨镜 ❌ |
| **干净无胡** | 无任何面部毛发 | 小胡子/山羊胡/络腮胡/胡茬 ❌ |
| **白上衣** | 长袖，圆领，可换衬衫/T 恤 | 商务西装/卡通 T 恤/赛博风 ❌ |
| **成人比例** | 头身比 1:6 至 1:7 | 幼态/Q 版/大头小身 ❌ |

### 2.2 6 个标准动作（与 IP 资产 v6 一致）

1. **思考**（手托下巴）—— 概念引入
2. **讲解**（手指向某物）—— 知识传递
3. **记录**（手拿笔记）—— 步骤拆解
4. **举手**（手举起）—— 提问互动
5. **微笑**（双手抱臂或不抱臂）—— 收尾/金句
6. **看白板**（手撑白板）—— 总结/类比

### 2.3 表情规则

- **默认**：自信微笑（嘴角上扬一边）
- **不夸张**：不卖萌、不瞪眼、不哭
- **不呆滞**：不面无表情、不冷漠
- **克制但有生命力**

### 2.4 服装灵活规则

- 基础 = 白长袖上衣（默认）
- **可换**：白卫衣、白 T 恤、衬衫、连帽衫
- **不可换**：商务西装、卡通 T 恤、赛博风、护士服、厨师服（除非按需角色另说）
- 同一 ep 服装一致（不中途换装）

### 2.5 image-to-image 锁形（v1.0 沿用 v6 验证法）

- **主锚图必传** `input_files`
- prompt 写 `MUST use the same character as in reference image, preserve identity anchors`
- 中文细描必带：`BLACK SHORT MESSY HAIR (slightly spiky) + BLACK SQUARE FRAME GLASSES (mandatory) + clean-shaven (NO facial hair) + white long-sleeve top`
- 失败兜底：image-to-image 后若 IP 漂移 → 加 negative prompt 锁 `NO mustache / NO beard / NO suit / NO child / NO bald / NO yellow hair`

### 2.6 主 IP 在画面中的位置规则

- **主讲解图**：文哥占画面 30-50%，居中或偏左
- **小比例场景图**：文哥占画面 15-25%，站在画面对应动作位置（不靠边）
- **概念图**：文哥只在角落，主体是隐喻物
- **收尾话**：文哥占画面 35%（与 v2.4.5 LAYOUT 锁一致：文哥左 35% + 文字右 60%）

## 3. 按需角色规则（v1.0 沿用 · 核心）

### 3.1 按需角色设计原则

**核心公式**：`{职业符号} + {性格暗示} + {手持道具} = 1 个具象角色`

| 职业 | 符号 | 性格暗示 | 道具 |
|---|---|---|---|
| **厨师** | 白帽 + 围裙 | 麻利 / 大嗓门 | 锅铲 / 菜单卷 |
| **医生** | 白大褂 + 口罩 | 冷静 / 严谨 | 听诊器 / 手术刀 |
| **工人** | 安全帽 + 工装 | 踏实 / 直接 | 扳手 / 砖头 |
| **老板** | 西装 + 领带 | 强势 / 急性子 | 公文包 / 茶杯 |
| **学生** | 校服 / 书包 | 好奇 / 迷茫 | 笔记本 / 铅笔 |
| **程序员** | 连帽衫 + 耳机 | 内向 / 较真 | 笔记本电脑 / 咖啡 |
| **客服** | 耳机 + 制服 | 耐心 / 疲惫 | 耳麦 / 投诉单 |
| **财务** | 西装 + 计算器 | 谨慎 / 抠门 | 计算器 / 账本 |
| **销售** | 西装 + 名片夹 | 外向 / 油滑 | 名片 / 话术本 |
| **高管** | 深色西装 + 眼镜 | 权威 / 装 | 笔记本 / 麦克风 |

### 3.2 按需角色 5 锁规则（避免出现"光头尖耳"等 v2.1 bug）

每张含按需角色的图，prompt 必带：

```
1. ROLE: [职业符号] = [白帽 + 围裙]（不要脸识别）
2. HAIR: [黑/黄/棕] + [发型描述] + MUST have visible hair, NOT bald
3. EYES: small expressive eyes, MUST have visible eye structure
4. EARS: ROUND NORMAL HUMAN EARS, NO pointy ears, NO elf ears
5. BODY: chibi or realistic depending on scene, adult proportions
```

### 3.3 按需角色数量限制

| 画幅 | 最多按需角色数 | 备注 |
|---|---|---|
| 9:16 竖图（单话） | 1 个 | 配合文哥 = 2 个具象人物 |
| 16:9 横图（封面/配图） | 2-3 个 | 配合文哥 = 3-4 个具象人物 |
| 21:9 超宽（卷首） | 3-4 个 | 配合文哥 = 4-5 个 |

**规则**：超过 5 个具象人物 = 画面拥挤，**改用火柴人 Agent 替代**。

### 3.4 按需角色跨图一致性（同 ep 内）

- **同 ep 内**，同一按需角色必须**长得一致**（脸/发型/服装/表情）
- **跨 ep** 可以换（每 ep 都是新隐喻）
- **锁方法**：用上一张已确认的按需角色图作 `input_files`（参考 v2.4.5 耳型锁形法）
- **失败兜底**：跨图不一致 → 改 prompt 加 `MUST use the same character as in reference image`

> | wenge（5 老 IP 版） | 彩蛋库 | **废弃**（用文哥 v6 替代） |
> | xiaoneng | 彩蛋库 | **废弃**（用按需医生角色替代） |
> | chuzi | 彩蛋库 | **废弃**（用按需厨师角色替代） |
> | banzhang | 彩蛋库 | **废弃**（用按需工人角色替代） |
> | xiaoq | 彩蛋库 | **废弃**（用按需学生角色替代） |

## 5. 火柴人 Agent · 抽象执行规则

### 5.1 火柴人 Agent 设计原则

- **形状**：矩形身体（不是火柴棍细线） + 圆头 + 小眼睛
- **颜色**：**永远黑线无色**，不上色（保持抽象）
- **目的**：承担"非主角"的辅助动作，不抢戏
- **数量**：1-3 个 / 画，多了画面乱

### 5.2 火柴人 Agent 7 种典型任务

| 任务类型 | 动作 | 道具 |
|---|---|---|
| **递结果** | 双手递一份报告/卡片 | 报告纸/卡片 |
| **标红 X** | 双手举一个红 X 牌 | 红 X 牌 |
| **标绿 ✓** | 双手举绿勾牌 | 绿勾牌 |
| **反馈** | 比划/指/举手 | 反馈牌/问号牌 |
| **失败示范** | 摔东西/蹲地/捂头 | 失败道具 |
| **搬运** | 抬/搬/运 | 箱子/货物 |
| **调度** | 举牌指引方向 | 箭头牌/数字牌 |

### 5.3 火柴人 Agent 锁定法

- **同 ep 内**：所有火柴人统一风格（不混 A 风格和 B 风格）
- **跨 ep**：可以换风格（每 ep 新设计）
- **画法**：4 步法
  1. 圆头（小圆，**有眼睛**——避免 v2.1 bug）
  2. 矩形身体（不是火柴棍，**占身体 60%**）
  3. 4 肢（手 + 脚，可省略脚，但手必带）
  4. 任务道具（手拿/举/背）

### 5.4 火柴人 Agent 错误示范（v1.0 必禁）

❌ 火柴棍细线（不是矩形身体）
❌ 光头（违反 v2.5 4 锁规则）
❌ 尖耳/精灵耳（同上）
❌ 无眼睛（v2.1 bug）
❌ 上色（与"抽象执行"定位冲突）
❌ 太可爱/卖萌（抢戏主角）
