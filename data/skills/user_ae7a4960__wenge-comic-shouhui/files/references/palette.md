# 调色板 · v1.0 两套锁定

> **v1.0 重要规则**：
> 1. **两套配色** = IP1 三色（极简手绘 · 长文配图用）+ IP2 5 色（商务精致 · PPT 演讲页用）
> 2. **同 ep 内选一套**，不可混
> 3. **决策树** = 看主 IP 是文哥 v6（IP1）还是 IP2 文哥（IP2）

---

## 套 1 · IP1 三色（极简手绘风 · 长文配图 SKU · 文哥 v6 用）

> 来源：文哥 v6 IP 资产（`assets/main_anchor.png`），
> 验证场景：2026-07-12 华为文章 3 张长文配图全 A 级。

| 角色 | Hex | 英文 | 说明 |
|---|---|---|---|
| **黑** | `#000000` | black | 主体线稿 + 角色 + 框线 + 主文字 |
| **橙** | `#FF7A45` | orange | 主流程 / 路径 / 箭头 / 改善方向 |
| **红** | `#D9304F` | red | 关键短语 / 警示 / 结果 / 根因 |
| **蓝** | `#4A90E2` | blue | 补充说明 / 反馈 / 系统状态（克制使用） |

**色温**：现代专业 + 极简克制。**底色**：纯白 #FFFFFF。

**使用决策**：
- ✅ 长文配图（公众号/知乎/微信文章内嵌图）
- ✅ 商业/管理/方法论主题
- ✅ 文哥 v6 主 IP 配图
- ✅ 跨界内容（USB-C/战壕/洋葱/任何物理隐喻）
- ❌ 漫画四格连载（改用 `文哥漫画-贱萌` skill）

## 决策树

```
[出图任务]
   │
   ├── 主 IP = 文哥 v6（黑短发+方框眼镜+白上衣，成人比例）？
   │   │
   │   ├── YES → 用 IP1 三色（套 1）
   │   │        长文配图 SKU
   │   │
   │   └── NO ↓
   │
   ├── 主 IP = 文哥 IP2 商务版（白长袖+深灰裤+麦克风+腕表）？
   │   │
   │   ├── YES → 用 IP2 5 色（套 2）
   │   │        PPT 演讲页 SKU
   │   │
   │   └── NO ↓
   │
   └── 罕见主题 → 评估是否需要新建配色（v1.1 再议）
```

**v1.0 规则**：同 ep 内选一套，**不可混**。

## 同套配色 · 比例指南

### IP1 三色比例（建议）

- 黑色（线 + 文字）：60-70%
- 橙色（流程/箭头）：15-20%
- 红色（关键短语）：10-15%
- 蓝色（补充）：≤ 5%（克制）

### IP2 5 色比例（建议）

- 黑白灰肤色（主体）：70-80%
- 红橙蓝（点缀）：合计 20-30%

## v3.0 → v1.0 演变

| 版本 | 套数 | 主色 | 适合 |
|---|---|---|---|
| v3.0 | 3 套（IP1 + B+ 套 6 色 + IP2） | 按主 IP 选套 | 3 SKU 各自配色 |
| **v1.0** | **2 套（IP1 三色 + IP2 5 色）** | **极简手绘 + 商务精致** | **长文配图 + PPT 演讲页** |

**v1.0 重要**：B+ 套 6 色（贱萌 Q 版配色）已**彻底移除**——贱萌配色归到 `文哥漫画-贱萌` skill。
