## 1. Shot List 14 字段（v1.0 = 13 字段 + tone_match）

> 任何图（长文配图 / 知识卡 / 卷首 / PPT 演讲页）出图前，**先填这 14 字段**。填完 = 规划完成 = 可出图。

| # | 字段 | 必填 | 说明 |
|---|---|---|---|
| 1 | **图编号** | ✅ | `S{N}-{分类简写}`，如 S1-COVER / S3-ROOT-CAUSE |
| 2 | **主题** | ✅ | 一句话讲这张图讲啥（≤ 15 字） |
| 3 | **核心意思** | ✅ | 这张图要让读者 get 到的"啊哈"（≤ 30 字） |
| 4 | **视觉模式** | ✅ | 手绘插图（漫画风） / 知识卡（教学风） / 长文配图 / 卷首 |
| 5 | **结构类型** | ✅ | workflow / 概念隐喻 / 前后对比 / 角色状态 / 方法分层 / 路线地图 / 分镜 / 总结 |
| 6 | **图类型 / 尺寸** | ✅ | 9:16（漫画） / 16:9（长文配图） / 21:9（卷首） / 1:1（封面） |
| 7 | **信息量** | ✅ | 画面更空 / 讲清楚重点 / 内容更完整 / 完整海报 |
| 8 | **角色架构** | ✅ | 文哥 v6 + 几个按需角色 + 几个火柴人 |
| 9 | **角色动作** | ✅ | 主 IP + 按需角色分别做什么动作（角色必须参与核心动作，不当装饰） |
| 10 | **角色资产** | ✅ | 必传主锚图路径 + 按需角色是否需 image-to-image |
| 11 | **Agent 分工** | ⬜ | 几个 Agent，分别承担什么任务（递结果/标红 X/反馈/失败示范） |
| 12 | **建议元素 / 隐喻物** | ✅ | 物理道具、场景物件、布局 |
| 13 | **建议中文标注** | ✅ | 必保留词（5-8 字 / 段）+ 可删减词 + 配色 + 字号 |
| 14 | **tone_match**（v1.0 新增） | ✅ | 高/中/低 · 调性适配评估（详见 `references/tone-matching.md`） |

**附加字段**：
- **值得画的理由**（为什么这张值得画 / 跟其他图有什么差异）
- **QA checklist**（出图后自检 5-8 项）

## 2. 5 步工作流（从规划到出图）

```
[Step 1] 读文章 / 拿主题
   ↓
[Step 2] 写 shot list（按图数 · 14 字段全填）
   ↓
[Step 3] 用户审核 / 调整
   ↓
[Step 4] 调 matrix 出图（每张 ~30s，含 image-to-image 锁形）
   ↓
[Step 5] QA + 交付
```

**总耗时**：5-8 张 shot list = 5 分钟写 + 1 分钟审核 + 5 分钟出图 + 5 分钟 QA = **15 分钟完成整套图**。

## 6. 信息量 4 级 · 决策指南

| 级别 | 字数 | 元素 | 留白 | 适用 |
|---|---|---|---|---|
| **画面更空** | 0-5 字标注 | 1 主体 + 1 隐喻物 | 60%+ | 卷首 / 概念图 / 装饰图 |
| **讲清楚重点** | 5-15 字 | 1 主体 + 1 隐喻 + 1-2 标注 | 50% | 知识卡 / 单概念图 |
| **内容更完整** | 15-40 字 | 1 主体 + 2-3 元素 + 3-5 标注 | 30% | 详解图 / 流程图 |
| **完整海报** | 40+ 字 | 1 主体 + 4+ 元素 + 5+ 标注 | 10% | 总结图 / 收尾图 |

**v1.0 规则**：90% 用"画面更空"或"讲清楚重点"——内容不塞，重点突出。

## 10. tone_match 字段 · v1.0 新增

```markdown
| **tone_match** | 高 · A 风格 | （或）| 中 · A 风格 | （或）| 低 · 建议改贱萌 |
```

**详细评估方法**：详见 `references/tone-matching.md`

**3 档评估**：
- **高**：5 维评分 5-10 分，A 风格最佳
- **中**：5 维评分 11-15 分，A 风格可用（克制 chibi 化）
- **低**：5 维评分 16-20 分，**不推荐** A 风格（建议改用 `文哥漫画-贱萌` skill）

## 11. QA Checklist · 出图后自检 8 项

每张图生成后，肉眼 + Read tool 检查：

- [ ] **主 IP 守住**（文哥 v6 = 黑短发+方框眼镜+白上衣+成人比例）
- [ ] **中文正确**（无错字/鬼符/英文/水印）
- [ ] **配色锁**（IP1 三色 / IP2 5 色，不混）
- [ ] **隐喻成立**（物理道具 1 秒可识别）
- [ ] **角色参与核心动作**（不装饰）
- [ ] **信息量合适**（不塞过多概念）
- [ ] **结构清晰**（按 workflow/概念/对比/角色/分层/路线之一组织）
- [ ] **调性合适**（tone_match 评估 + 5 维评分匹配）

**任一不通过 → 重出该图（最多 3 次）**。
