## 3. 上下限约束

- **最低 1 张** —— 1 张图也能讲清 1 个核心概念
- **最高 30 张** —— 超过 30 张说明内容太长，应该拆成上下集 / 砍次要章节
- **超出后**：
  - < 1 张：用户"不需要配图"
  - \> 30 张：拆上下集（如 "Part 1 / Part 2"），或砍掉次要章节

## 4. **v1.0 新增 · 图片数量弹性指南**（核心 · 不写死）

> **v1.0 重要原则**：**图数由内容驱动，不写死**。用户/LLM 拿到公式范围（1-30 图）+ 弹性指南，自行决定。

### 4.1 按内容性质分 5 档

| 内容性质 | 推荐图数 | 案例 |
|---|---|---|
| **单图卡** | 1 张 | 高密度金句、独立概念、卷首 |
| **小串联** | 3-5 张 | 方法论 3 步、4 件套、5 步法 |
| **中等** | 6-10 张 | 完整方法论、教程、案例分析 |
| **大串联** | 10-20 张 | 复杂系统、概念大集合 |
| **上下集** | 20-30+ 张 | 分篇发布 |

### 4.2 按文章长度分 4 档（与 4.1 配合使用）

| 文章长度 | 推荐图数 |
|---|---|
| < 2 KB | 1-2 张（单图卡或小串联） |
| 2-5 KB | 2-3 张（小串联） |
| 5-10 KB | 3-5 张（小串联或中等） |
| > 10 KB | 5-8 张（中等） |
| > 20 KB | 8-15 张（中等或大串联） |
| > 50 KB | 15-30 张（大串联或上下集） |

### 4.3 决策流程

```
[算出图数 X]
   │
   ├── X = 1？→ 单图卡（卷首/概念图）
   ├── X = 2-5？→ 小串联（方法论/列表）
   ├── X = 6-10？→ 中等（完整方法论/教程）
   ├── X = 11-20？→ 大串联（复杂系统/概念集合）
   ├── X = 21-30？→ 大串联或上下集（按用户决策）
   └── X > 30？→ 强制拆上下集
```

## 5. 调整规则

用户随时可说：
- "再加 X 张" → 从内容里再切细
- "砍到 N 张" → 合并次要概念，保留主线
- "上下集" → 拆 2 篇，每篇 ≤30 张

## 6. 图数确认闸门

输出给用户时**必须包含**：
1. 算出的图数（公式结果）
2. 套用的是哪类公式 + 理由
3. 上下限检查（"在 1-30 范围内"或"超出，已建议拆 X"）
4. **v1.0 新增**：弹性指南推荐（哪档 + 理由）
5. **v1.0 新增**：tone_match 评分（5 维）+ 是否调性适配
6. 等用户拍板"OK / 调整成 N 张"
