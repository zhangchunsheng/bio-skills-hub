# 调性适配评估 · 5 维评分 · v1.0 新增核心

> **v1.0 核心创新**。每个新任务开始前必走。给内容打分 → 推荐风格 → 调性不匹配时主动给建议。
>
> **5 维评分模型**：
> 1. 严肃度（学术 > 专业 > 教程 > 娱乐 > 网梗）
> 2. 情绪温度（冷峻 → 中性 → 热情 → 热烈）
> 3. 视觉密度（极简 → 适中 → 丰富）
> 4. 受众期待（管理者 / 同行 / 大众 / 年轻人 / 亲子）
> 5. 传播场景（公众号 / 视频号 / 小红书 / 内部培训 / 演讲 PPT）

---

## 2. A 风格适配区间

| 总分 | 适配度 | 建议 |
|---|---|---|
| **5-10 分** | ✅ **高** | 用 A 风格直接干 |
| **11-15 分** | ✅ **中** | 用 A 风格，必要时去掉文哥 chibi 化（更克制） |
| **16-20 分** | ⚠️ **低** | 主动提示用户"该内容偏娱乐/网梗风格，建议用 `文哥漫画-贱萌` skill" |
| **21-25 分** | ❌ **不匹配** | 强制提示"调性完全不匹配，请改用贱萌风" |

**A 风格最佳区间**：5-13 分（偏严肃 + 偏冷峻 + 偏极简 + 偏专业 + 偏长文场景）

## 3. 调性不匹配时的具体建议

### 评分偏高（16-20）· 偏娱乐

**特征**：内容偏网梗/吐槽/搞笑/段子/95 后梗

**建议**：
1. 改用 `文哥漫画-贱萌` skill（更适合贱萌风格）
2. 如果必须用 A 风格：
   - 去掉"贱兮兮"相关表达
   - 改用"专业但接地气"的口吻
   - 增加专业深度（不只是吐槽）
   - 保持 IP1 三色（不要换成 B+ 套 6 色）

### 评分偏低（5-10）· 极严肃

**特征**：内容偏学术论文/政策法规/严肃政策解读

**建议**：
1. 用 A 风格（极简手绘 = 严肃友好型）
2. **极简手绘适合"严肃但不冷漠"**：
   - 比纯文字更易读
   - 比商业 vector 更有人情味
   - 适合管理/政策解读/学术科普
3. 配色：用 IP1 三色（黑+橙红蓝），黑 70% 主导，橙红蓝 ≤ 30%
4. 文哥说降级：14px 灰字 1 行兜底即可（不要喧宾夺主）

### 单维度极端（任一维 ≥ 5）

**特征**：5 维里某一维极端（如：视觉密度 5 分 = 漫画 4 格 / 传播场景 5 分 = 小红书）

**建议**：
- 视觉密度 5 分（漫画 4 格）→ **必须**改用 `文哥漫画-贱萌` skill
- 传播场景 5 分（小红书/朋友圈）→ 改用 `文哥漫画-贱萌` skill
- 受众期待 5 分（亲子/儿童）→ 改用 `文哥漫画-贱萌` skill（A 风格成人比例不适合儿童）

## 4. tone_match 字段 · shot list 用法

> **v1.0 新增**。每个 shot 必填的字段。

### 字段格式

```markdown
| **tone_match** | 高 · A 风格 | （或）| 中 · A 风格 | （或）| 低 · 建议改贱萌 |
| **理由** | {评估 5 维分数 + 选风格的依据} |
```

### 3 档评估

| tone_match | 含义 | 处理方式 |
|---|---|---|
| **高** | 5 维评分 5-10 分，A 风格最佳 | 直接用 A 风格 |
| **中** | 5 维评分 11-15 分，A 风格可用 | 用 A 风格，克制 chibi 化 |
| **低** | 5 维评分 16-20 分，**不推荐** A 风格 | **主动建议用户改用 `文哥漫画-贱萌` skill** |

### 实战示例

#### 案例 1 · 华为经营分析会（评分 7 分 · 高）

```markdown
| **tone_match** | 高 · A 风格 |
| **理由** | 严肃度 2（管理方法论）+ 情绪温度 1（冷峻克制）+ 视觉密度 2（信息图）+ 受众期待 1（管理者）+ 传播场景 1（内部培训/演讲 PPT）= 7 分。A 风格最佳。 |
```

#### 案例 2 · AI 概念科普（评分 11 分 · 中）

```markdown
| **tone_match** | 中 · A 风格 |
| **理由** | 严肃度 3（专业教程）+ 情绪温度 2（中性）+ 视觉密度 3（较丰富）+ 受众期待 2（同行）+ 传播场景 3（公众号）= 13 分。A 风格可用，但每图减少文哥 chibi 化，IP 占比降到 15-25%。 |
```

#### 案例 3 · 网梗吐槽合集（评分 19 分 · 低）

```markdown
| **tone_match** | 低 · 建议改贱萌 |
| **理由** | 严肃度 5（网梗吐槽）+ 情绪温度 4（鲜活有趣）+ 视觉密度 4（丰富）+ 受众期待 4（年轻人）+ 传播场景 4（视频号）= 21 分。**调性不匹配**，A 风格会显严肃，建议改用 `文哥漫画-贱萌` skill。 |
```

## 5. 调性适配决策树

```
[内容输入]
   │
   ├── 5 维评分 = 5-10 分？
   │   YES → A 风格直接干
   │   NO  ↓
   │
   ├── 5 维评分 = 11-15 分？
   │   YES → A 风格（克制 chibi 化）
   │   NO  ↓
   │
   ├── 5 维评分 = 16-20 分？
   │   YES → 主动建议改用 `文哥漫画-贱萌` skill
   │   NO  ↓
   │
   ├── 5 维评分 = 21-25 分？
   │   YES → 强制提示调性不匹配
   │   NO  ↓
   │
   └── 罕见主题 → 询问用户
```

## 6. 调性评估 · 自检 checklist

每张图生成后必走：

- [ ] **是否做了 5 维评分？**（严肃度/情绪温度/视觉密度/受众期待/传播场景）
- [ ] **是否给了 tone_match 等级？**（高/中/低）
- [ ] **调性不匹配时是否给建议？**（改用贱萌/克制 chibi 化/去掉某些元素）
- [ ] **是否尊重用户决策？**（用户可能"我就要用 A 风格做网梗"——OK 但要给提醒）
