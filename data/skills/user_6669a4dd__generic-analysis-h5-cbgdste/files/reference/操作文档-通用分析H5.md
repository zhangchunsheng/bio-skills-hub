## 二、系统概述

### 功能定位
- **通用商业分析**（McKinsey 风格穿透式分析），非模板合规检查
- 支持 **PPT** 和 **MD/ZIP** 两种格式
- **快速模式**：只做整体分析，跳过逐页/逐章分析（速度快）
- 输出：单一 HTML 文件（含 base64 图片，可离线分享）

### 分析模式配置
- 配置文件：[backend/app/services/prompt_config.json](backend/app/services/prompt_config.json)
- 当前模式：`generic`（通用商业分析）
- 提示词文件：
  - `prompts/generic_overall_analysis_prompt.txt`（整体分析）
  - `prompts/generic_chapter_analysis_prompt.txt`（章节分析）
  - `prompts/generic_page_analysis_prompt.txt`（逐页分析）

### AI 配置
- 模型：`qwen3.7-plus`（阿里云通义千问）
- 配置文件：[backend/.env](backend/.env)
- 超时：300秒（客户端）
- max_tokens：16384（整体分析，避免JSON截断）

## 三、标准操作流程

### 前置条件：启动后端服务

```bash
cd "d:\Python代码源\报告分析系统\backend"
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```
（后台运行即可）

---

### 步骤 1：上传文件

**PPT 格式：**
```bash
cd "d:\Python代码源\报告分析系统"
curl -X POST "http://localhost:8000/api/analyses/upload" \
  -F "file=@<PPT文件完整路径>" \
  2>/dev/null | python -c "import sys, json; data=json.load(sys.stdin); print(f'分析ID: {data[\"id\"]}')"
```

**MD/ZIP 格式：**
```bash
curl -X POST "http://localhost:8000/api/analyses/upload" \
  -F "file=@<ZIP文件完整路径>" \
  2>/dev/null | python -c "import sys, json; data=json.load(sys.stdin); print(f'分析ID: {data[\"id\"]}')"
```

> ⚠️ **重要**：MD 格式必须上传 **ZIP 包**（含 MD 文件 + "图片和附件"文件夹），
> 否则图片无法显示。不要单独上传 .md 文件。

记下返回的 **分析ID**（如 92）。

---

### 步骤 2：运行快速分析（仅整体分析）

```bash
cd "d:\Python代码源\报告分析系统\backend"
python -c "
import asyncio
from app.services.task_runner import run_overall_only_pipeline

async def main():
    print('开始快速分析...')
    await run_overall_only_pipeline(<分析ID>)
    print('分析完成！')

asyncio.run(main())
"
```

**说明：**
- PPT：调用 `analyze_overall_with_images`，传所有页面**高清图片+文本**给AI（消除幻觉）
- MD：调用 `analyze_document`，传Markdown文本+图片给AI
- 分析耗时约 3-4 分钟（22页/26章节）
- 成功标志：日志显示 `AI 返回完成, 长度: 15000+`

---

### 步骤 3：导出 H5 报告

```bash
cd "d:\Python代码源\报告分析系统\backend"
python -c "
import asyncio
import sqlite3
import sys
sys.stdout.reconfigure(encoding='utf-8')

async def main():
    conn = sqlite3.connect('data/analysis.db')
    conn.row_factory = sqlite3.Row
    cursor = conn.cursor()
    cursor.execute('SELECT * FROM analyses WHERE id = <分析ID>')
    row = cursor.fetchone()
    analysis_data = dict(row)

    from app.services.h5_export_generic import generate_generic_h5
    generate_generic_h5(analysis_data)
    print('H5报告已生成')
    conn.close()

asyncio.run(main())
"
```

然后复制到根目录（改成有意义的文件名）：
```bash
cp "data/exports/h5/<分析ID>.html" "../<报告名称>-通用分析.html"
```

## 四、关键技术要点（避免踩坑）

### ⭐ 生成器：只用 `h5_export_generic.py`
- **正确**：`from app.services.h5_export_generic import generate_generic_h5`
- **不要用**：`h5_export.py`（旧版述职规范格式）
- **不要用**：`h5_export_adapter.py`（这是适配器，格式不对）

### ⭐ MD 图片路径要求
- 图片目录结构：`uploads/{分析ID}/{分析ID}/图片和附件/`
- 如果图片没显示，检查是否解压到了正确的双层目录
- 手动修复：
  ```bash
  cd "uploads/<分析ID>"
  # 如果图片在一层目录，移到二层
  mkdir -p <分析ID>
  mv "图片和附件" <分析ID>/
  ```

### ⭐ 数据库文件名（标题来源）
- H5标题来自数据库 `ppt_path` 字段的文件名
- 如果标题显示错误，更新数据库：
  ```bash
  python -c "
  import sqlite3
  conn = sqlite3.connect('data/analysis.db')
  cursor = conn.cursor()
  cursor.execute('UPDATE analyses SET ppt_path = ? WHERE id = <分析ID>',
                ('uploads/<分析ID>/<正确文件名>',))
  conn.commit()
  conn.close()
  "
  ```

### ⭐ JSON 截断问题
- 如果分析结果为空 `{}`，检查是否JSON被截断
- 已通过 max_tokens=16384 解决，一般不会再出现

## 五、H5 报告功能清单

### 通用功能（两种格式都有）
- 左右分栏布局（左侧原文，右侧分析）
- 右侧 10 维度分析：
  1. 📋 执行摘要
  2. 🔍 数据质量检查
  3. ⚠️ 核心经营问题
  4. 🎯 根因综合分析
  5. 🔗 逻辑链审查
  6. 📈 策略有效性评估
  7. ✨ 可复制亮点
  8. 💡 改进建议
  9. ❓ 信息缺口
  10. ✅ 最终评估

### PPT 格式专属
- 左侧：PPT 页面图片预览
- 图片点击全屏放大（ESC关闭）

### MD 格式专属
- 左侧：格式化 Markdown 内容（标题、表格、图片）
- 图片点击放大（ESC关闭）
- 表格点击放大（悬停显示"🔍 点击表格放大查看"）

## 六、常见问题排查

| 问题 | 原因 | 解决 |
|------|------|------|
| 分析结果为空`{}` | JSON被截断 | 检查max_tokens，重新分析 |
| AI数据幻觉 | 只传了文本没传图片 | 确认用的是快速模式（含图片） |
| MD图片不显示 | 图片目录结构错误 | 移到 `{id}/{id}/图片和附件/` |
| 标题显示错误 | ppt_path字段错误 | 更新数据库ppt_path |
| 图片/表格不能放大 | 用了旧生成器 | 确认用 h5_export_generic.py |
| API超时408 | 上游API限制 | 检查.env的BASE_URL |
| 数据一致性误判 | 层级数据混淆 | 提示词已优化，正常现象 |
