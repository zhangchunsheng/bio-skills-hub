# 接入其他工具指南 — 通用分析H5报告 (generic-analysis-h5)

本 skill 的全部行为已收敛成**一条确定性命令**：

```bash
cd <项目>/backend && python generic_run.py "<报告文件路径>"
```

所以接入任何工具（Claude Code / Codex / workbuddy / n8n / CI）只需要三件事：
**① 部署一次环境 → ② 让工具知道何时触发 → ③ 让工具会读输出**。
只要跑的是同一条命令，产出的 H5 与在 Claude Code 里手工三步完全一致。

---

## 零、先做一次性部署（所有工具共用）

```bash
# 1. 拿到"报告分析系统"仓库，装依赖
cd 报告分析系统/backend
pip install -r requirements.txt

# 2. 配 .env（密钥不随 skill 分发，需自己填）
#    BASE_URL / API_KEY / DEFAULT_MODEL=qwen3.7-plus / SOFFICE_PATH
#    注意：DEFAULT_MODEL 必须是多模态模型(支持看图)——generic_run.py 会在分析前自动检测，
#    非多模态直接拦截停下；也可单独跑 python scripts/check_multimodal.py 检测。

# 3. 落位脚本
cp <skill包>/scripts/generic_run.py ./generic_run.py

# 4. 确认 app/services/prompt_config.json 的 active_mode = "generic"

# 5. 冒烟测试（PPT 还需装 LibreOffice）
python generic_run.py "<任意一份报告.zip>"
```

验收：末行出现 `[✓] 完成`，且中间有 `维度命中 10/10`。

## 一、Claude Code

把 `generic-analysis-h5/` 整个目录放进任一 skills 目录：

```
<项目>/.claude/skills/generic-analysis-h5/      # 项目级
~/.claude/skills/generic-analysis-h5/           # 用户级(全局可用)
```

`SKILL.md` 的 YAML frontmatter（`name` / `description`）就是触发依据，用户说"用通用分析系统分析这份报告，快速模式"即可自动命中。

## 二、Codex（及其他读 AGENTS.md 的工具）

Codex 不读 `SKILL.md` 的 frontmatter。两种接法，任选其一：

**接法 A（推荐）**：在仓库根目录 `AGENTS.md` 里加一段：

````markdown
## 技能：通用分析H5报告

当用户要求对**一份**报告（.ppt/.pptx/.md/.zip）做"通用分析 / 快速模式 / 只要整体分析 / 输出H5"时，
执行下面这条命令，不要自己另写分析逻辑、不要改提示词、不要换 H5 生成器：

```bash
cd backend && python generic_run.py "<用户给的文件完整路径>"
```

规则：
- MD 格式必须传 ZIP 包（MD + 图片和附件同级），单独传 .md 会导致 H5 无图。
- 输出的 H5 默认落在项目根目录 `<原文件名>-通用分析.html`；用户指定名字时加 `--out "名字.html"`。
- 命令自带体检：若打印 `维度命中 x/10` 且 x<10 或报 `raw/error`，说明 AI 返回被截断，重跑一次即可。
- 已跑过的记录只想重出 H5（不再花 AI）：`python generic_run.py --id <id> --h5-only`
- 详细说明见 `skill交付/03-通用分析H5报告/generic-analysis-h5/SKILL.md`。
````

**接法 B**：把下面《四、工具无关的技能定义》整段贴进 Codex 的自定义指令/system prompt。

## 三、workbuddy 及其他"技能/工具"平台

这类平台通常要求填「技能名 / 触发描述 / 执行命令 / 参数」四要素，按下表填：

| 字段 | 填写内容 |
|---|---|
| 技能名 | 通用分析H5报告 |
| 触发描述 | 对一份述职/复盘/经营报告(.ppt/.pptx/.md/.zip)做穿透式通用商业分析，快速模式只做整体分析，产出左原文右10维度的离线单文件H5。关键词：通用分析、快速模式、只要整体分析、generic模式、报告分析H5 |
| 执行目录 | `<项目绝对路径>/backend` |
| 执行命令 | `python generic_run.py "{{file_path}}"` |
| 参数 | `file_path`（必填，报告文件绝对路径）；`out`（选填，输出HTML文件名 → 追加 `--out "{{out}}"`）；`model`（选填，覆盖分析模型 → 追加 `--model "{{model}}"`） |
| 超时 | ≥ 600 秒（分析本身 3-5 分钟） |
| 成功判据 | stdout 末行含 `[✓] 完成` |
| 失败判据 | stdout 含 `[✗]`，把该行原文回传给用户（若为"未确认支持多模态"，按提示换多模态模型后重试） |
| 产物 | stdout 末行 `[4/4] 已复制到: <路径>` 里的 HTML 文件 |

## 四、工具无关的技能定义（可直接贴进任意 Agent 的 system prompt）

```text
【技能】通用分析H5报告 (generic-analysis-h5)

用途：对单份述职/复盘/经营报告做 McKinsey 风格穿透式通用商业分析（不是模板合规检查），
产出一个离线单文件 H5：左侧原文、右侧 10 个维度分析，图片 base64 内嵌可直接分享。

何时用：用户给出一份 .ppt/.pptx/.md/.zip 报告，并提到"通用分析 / 快速模式 /
只要整体分析 / generic 模式 / 输出H5"。
何时不用：一批报告汇总成驾驶舱（用 gm-cockpit 或 oms-cockpit）；述职规范打分（用 review 模式）。

怎么做：只执行这一条命令，不要自行实现分析逻辑，不要改提示词，不要换 H5 生成器。
    cd <项目>/backend
    python generic_run.py "<报告文件绝对路径>" [--out "输出名.html"]

命令内部依次完成：建分析记录 → run_overall_only_pipeline(仅整体分析，多模态传图+文本)
→ 结果体检 → h5_export_generic 生成 H5 → 复制到项目根目录。耗时约 3-5 分钟，请耐心等待，
不要中途重复执行。

硬性约束：
1. MD 必须传 ZIP 包（MD 文件 + 图片和附件文件夹同级），单独传 .md 会导致 H5 无图。
2. H5 生成器只能是 h5_export_generic.py；h5_export.py 和 h5_export_adapter.py 格式都不对。
3. app/services/prompt_config.json 的 active_mode 必须是 generic。
4. 不需要启动 uvicorn 后台服务。
5. 多模态硬性要求：分析强依赖读图（图片里的表格/图表是最准确的数据源），模型必须支持图像输入。
   generic_run.py 会在调 AI 前自动检测并拦截非多模态模型；被拦截时按提示处理（--model 覆盖 /
   改 .env 的 DEFAULT_MODEL），不要轻易用 --skip-multimodal-check 跳过，除非确知模型支持看图。

读输出：
- `维度命中 10/10` = 正常。少于 10 或出现 `raw/error` = AI 返回被截断，重跑一次。
- `[✗] ...` = 失败，把该行原文告诉用户。
- `[4/4] 已复制到: <路径>` = 最终交付物路径，回报给用户。

补救命令：
- 只重出 H5（不花 AI）：python generic_run.py --id <分析ID> --h5-only
- 体检某条记录：      python generic_run.py --id <分析ID> --check
- 修 H5 标题：        python generic_run.py --id <分析ID> --title "正确名.pptx" --h5-only
```

## 五、接入后如何确认"和在 Claude Code 里做的一样"

跑同一份报告，对照三点即可：

1. **命令一致** — 都是 `generic_run.py`，内部调的是同一个 `run_overall_only_pipeline` + `generate_generic_h5`。
2. **`维度命中 10/10`** — 说明走的是 generic 提示词、AI 返回完整、H5 十个分区都有内容。
3. **H5 体积与页数** — PPT 版通常 10MB+（含页图），MD 版 3MB+（含内嵌图）；打开后左侧原文完整、图片可点击放大。

三点都对，产出就与 Claude Code 手工三步流程等价。
