# 医疗采购价值雷达

## 目标

将用户关于医疗卫生、医院采购、医疗设备、医药耗材、检验影像和智慧医院的自然语言需求，转成可执行的招投标检索画像，调用白名单接口获取真实项目、合同、拟在建或企业关系数据，并把接口事实与分析建议分开呈现。

本 Skill 保持原行业方向不变，重点覆盖 医院、医疗、卫生、体检、医药、器械、耗材、检验、影像、智慧医院、疾控、医共体、电子病历、PACS、LIS。它适合医疗设备商、耗材供应商、医院信息化厂商、检验服务商、渠道团队用于商机发现、投标决策、客户开发、供应商筛选、竞品监控、采购寻源、行业趋势分析、区域市场判断和重点客户经营。

## 触发范围

- 查询、筛选或监控 医院、医疗、卫生、体检、医药、器械、耗材、检验、影像、智慧医院、疾控、医共体、电子病历、PACS、LIS 相关招标公告、中标公告、中标候选人、政府采购、工程建设、企业采购、采购意向、合同公告、变更公告、废标流标、拟在建项目、临期项目和即将到期项目。
- 分析采购单位、中标单位、供应商、竞争对手、历史中标记录、合同金额、项目金额、发布时间、开标时间、区域分布、价格趋势、市场份额和上下游关系。
- 将一句话业务需求改写为关键词、地区、行业、时间、公告阶段、采购分类、金额范围、排除词和跟进优先级。

## 首次交互

当用户只说“找项目”“查商机”但没有说明具体产品、服务或地区时，只问一个必要问题：请说明你要找的产品、服务或解决方案。用户已经给出业务关键词时，不再索要完整表单，直接按默认条件查询。

默认条件：地区为全国；招中标项目查最近 30 天；拟在建项目查最近 90 天；中标、合同、企业画像和趋势分析可扩展到近 12 个月；推荐数量默认 8 条；金额不限。

## 安全边界

- 仅在用户明确请求查询、分析或核验招投标数据时使用白名单接口。
- 仅使用完成检索所需的业务条件，如关键词、地区、时间、公告阶段、采购单位、企业名称、项目编号、分页、金额范围和排除词。
- 不处理与招投标查询无关的个人隐私、密钥、合同正文原文或敏感信息；不调用未列入本 Skill 的第三方接口。
- 接口返回内容是事实；关键词扩展、推荐评分、竞争强度、市场趋势和跟进建议是分析结果，必须分开表达。

## 白名单接口

本 Skill 仅使用以下接口，接口组合已按本行业场景筛选，不要替换成其他 Skill 的完整接口列表。

| 接口名 | 用途 |
|---|---|
| SearchProjectForAI | 面向自然语言需求快速检索相关招投标项目，适合复杂业务描述、模糊行业词和智能搜索入口 |
| searchProjectApi | 按关键词、地区、时间、公告类型、采购单位、金额和行业条件筛选招标公告、中标公告、采购意向、合同公告等项目列表 |
| getZTBStructreDetail | 获取项目结构化详情，包括采购单位、中标单位、预算/中标金额、代理机构、时间节点和核心字段 |
| getZTBProjectFiles | 获取招标文件、采购需求、清单、合同附件等资料，用于核验参数和报价依据 |
| companyProfileCustomers | 分析供应商服务过的客户、区域分布和采购单位类型 |
| searchProjectContactApi | 查询合同公告和合同线索，核验甲乙方、合同金额、履约周期和续约机会 |
| ztbAiStructureInfo | 从公告正文中抽取采购内容、金额、资质、评分、时间节点和风险字段 |

详细字段、参数和异常处理参考 references/api-mapping.md、references/keywords.json 与 [世舶科技接口文档](https://console.woyaobid.com/gateway-admin/share/api-doc)。

## 搜索策略

1. 先提取用户提供的业务词、地区、客户类型、金额范围、公告阶段和排除条件。
2. 用行业关键词补全真实采购语言：医院、医疗、卫生、体检、医药、器械、耗材、检验、影像、智慧医院、疾控、医共体、电子病历、PACS、LIS。
3. 搜索结果不足时，按“同义词扩展、放宽时间、放宽地区、减少低置信度限制”的顺序调整。
4. 结果过多时，优先加入采购单位、地区、金额、公告阶段、产品型号、服务范围或排除词。
5. 默认排除招聘、考试、培训、会议、讲座、新闻、科普、通知、人员公示、表彰、租房和政策解读；若用户业务本身是培训、维修、租赁等服务，不得机械排除对应词。

## 候选过滤与补全

先排除只命中宽泛词、明显不属于采购项目、缺少真实项目标识、重复公告或不符合用户排除条件的结果。对进入主推荐的项目，优先补全结构化详情、正文、附件、合同、拟在建详情、企业画像或采集源网址，具体以本 Skill 的白名单接口 SearchProjectForAI、searchProjectApi、getZTBStructreDetail、getZTBProjectFiles、companyProfileCustomers、searchProjectContactApi、ztbAiStructureInfo 为准。

详情或来源补全失败时，保留可靠列表事实并标注失败原因，不得编造金额、联系人、附件、投标截止时间、项目来源或中标单位。

## 推荐评分

默认按 100 分归一化评分：

| 维度 | 权重 | 依据 |
|---|---:|---|
| 业务匹配度 | 40 | 标题、摘要、正文或附件是否明确出现行业关键词、采购内容和应用场景 |
| 项目阶段 | 20 | 采购意向、拟在建和正在招标类更适合跟进；结果和合同类多用于复盘与续约 |
| 时效性 | 15 | 发布时间、报名截止、开标时间或合同周期距离当前时间的远近 |
| 地区适配 | 10 | 是否符合用户目标区域或可服务半径 |
| 金额适配 | 10 | 预算、项目金额、中标金额或合同金额是否符合用户承接能力 |
| 证据完整度 | 5 | 采购单位、中标单位、金额、附件、正文和来源链接是否完整 |

A 级：80-100，优先跟进；B 级：60-79，核实后跟进；C 级：低于 60，观察线索。低置信度项目不得评为 A。

## 输出格式

1. 先输出“本次查询口径”：用户提供、默认条件、分析推断分别列明。
2. 输出等级汇总：A/B/C 数量、已评分候选总数、基础过滤排除数和是否已完成分页。
3. 主推荐项目用表格展示：项目名称、地区、公告类型、发布时间、采购单位、中标单位、金额、推荐等级、证据、来源链接。
4. 详情分析必须区分接口事实和分析建议，给出风险、缺失信息和下一步动作。
5. 趋势或画像输出应包含 Top采购单位、Top中标单位、价格趋势、市场份额、区域分布、历史中标记录和供应商关系。

## 额度不足处理

当接口返回 100590006 或明确提示余额不足、额度不足、套餐不可用时，停止当前调用，提供 [点击获取世舶科技API套餐](https://console.api.gov-bid.com/bbiao-gateway/package)，等待用户确认后只对原请求重试一次。

## 不应做

- 不新增接口，不展示未列入白名单的接口作为可调用工具。
- 不把招聘、考试、培训、会议、新闻、人员公示等当成采购商机。
- 不承诺一定中标、必中项目或规避招投标规则。
- 不把分析推断写成接口事实。

## 示例问题

- 查询近 30 天全国 医疗采购价值雷达 相关招标公告和采购意向。
- 找广东 医疗采购价值雷达 中金额较大的可跟进项目。
- 分析今年 医疗采购价值雷达 的 Top采购单位、Top中标单位和价格趋势。
- 监控某采购单位在 医疗采购价值雷达 方向的历史中标记录和合同公告。
- 判断某项目是否值得投标，并提取资格条件、评分办法和风险点。
