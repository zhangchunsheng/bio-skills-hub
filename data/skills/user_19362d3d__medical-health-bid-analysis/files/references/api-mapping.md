## 允许接口清单

| 接口名 | 用途 |
|---|---|
| SearchProjectForAI | 面向自然语言需求快速检索相关招投标项目，适合复杂业务描述、模糊行业词和智能搜索入口 |
| searchProjectApi | 按关键词、地区、时间、公告类型、采购单位、金额和行业条件筛选招标公告、中标公告、采购意向、合同公告等项目列表 |
| getZTBStructreDetail | 获取项目结构化详情，包括采购单位、中标单位、预算/中标金额、代理机构、时间节点和核心字段 |
| getZTBProjectFiles | 获取招标文件、采购需求、清单、合同附件等资料，用于核验参数和报价依据 |
| companyProfileCustomers | 分析供应商服务过的客户、区域分布和采购单位类型 |
| searchProjectContactApi | 查询合同公告和合同线索，核验甲乙方、合同金额、履约周期和续约机会 |
| ztbAiStructureInfo | 从公告正文中抽取采购内容、金额、资质、评分、时间节点和风险字段 |

## 自动补全参数规则

1. 未指定地区：默认全国；用户提到省、市、区县、园区、医院、学校、机关或企业时按指定对象收窄。
2. 未指定时间：商机搜索默认近 30 天；拟在建、趋势、画像、合同和续约分析可扩展到近 90 天、12 个月或 24 个月，并说明原因。
3. 未指定公告阶段：默认覆盖采购意向、公开招标、竞争性磋商、竞争性谈判、单一来源、成交结果、中标结果、合同公告、变更公告、流标废标和拟在建项目。
4. 结果不足：先扩展同义词和上下游词，再放宽时间、地区和公告阶段。
5. 结果过多：增加精确标的、采购单位、金额范围、公告阶段、地区或排除词。

## 安全与事实边界

- 只使用本文件列出的接口。
- 只提交检索必要字段，不处理与招投标查询无关的敏感信息。
- 接口返回内容是事实；推荐分、竞品判断、行业趋势和跟进建议是分析结果。
- 字段缺失时写“公告未披露”或“不详”，不得补写不存在的信息。
