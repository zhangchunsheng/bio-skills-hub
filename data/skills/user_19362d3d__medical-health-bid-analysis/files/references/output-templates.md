# 输出模板

本文件用于在用户要求结构化报告、表格、分析摘要或可复制给业务团队的结果时读取。

## 医疗采购商机列表

输出表格字段：

| 字段 | 说明 |
|---|---|
| 推荐等级 | 高/中/低，依据医疗相关度、金额、采购单位价值、是否有附件判断 |
| 项目标题 | 去除 HTML 高亮标签后的公告标题 |
| 公告类型 | 招标、采购意向、成交结果、合同公告等 |
| 发布时间 | 公告发布时间 |
| 地区 | 省/市/区县，优先展示接口返回名称 |
| 采购单位 | 医院、卫健委、疾控中心等甲方 |
| 预算/项目金额 | 预算金额、中标金额、合同金额或项目金额 |
| 医疗品类 | 设备、耗材、药品、检验、影像、信息化、后勤、工程等 |
| 关键时间 | 报名截止、开标时间、合同周期等 |
| 附件 | 有/无；如有，说明是否建议下载 |
| 原始链接 | collectUrl 或 sbkjBidUrl，有则展示 |
| 跟进建议 | 下载附件、查历史中标、查竞争对手、查合同等 |

## 重点项目详情分析

按以下结构输出：

1. 项目概况：项目名称、编号、地区、公告类型、发布时间、预算/中标金额。
2. 采购主体：采购单位、代理机构、联系人和联系方式，未返回则写“未返回”。
3. 采购内容：标的物、数量、型号、服务范围或建设内容。
4. 关键时间：报名截止、开标时间、合同周期。
5. 资格条件：资质、业绩、认证、授权、人员、财务要求。
6. 技术参数和评分关注：核心参数、评分权重、商务/技术/价格关注点。
7. 风险提示：品牌倾向、排他参数、交付周期、付款条件、附件缺失。
8. 下一步：下载附件、查采购单位历史、查竞争对手、查合同落地。

## 竞争对手中标分析

输出结构：

- 企业概况：企业名称、地区、行业、经营状态、项目统计可用性。
- 中标总览：时间范围、项目数量、金额规模、平均金额。
- 区域分布：省/市分布和强势区域。
- 客户分布：医院、卫健委、疾控中心等客户。
- 品类分布：设备、耗材、药品、信息化、后勤、工程。
- 重点项目：金额高、战略客户、连续中标项目。
- 竞争启示：可切入区域、需要防守客户、潜在合作方。

## 医院客户采购画像

输出结构：

- 医院识别：名称、地区、机构类型线索。
- 采购频率：近 12/24 个月公告数量。
- 品类结构：设备、耗材、药品、信息化、后勤、工程占比。
- 金额结构：预算/中标/合同金额区间。
- 供应商体系：常见供应商、合作频次、合同记录。
- 采购周期：高发月份、续约项目、临期项目。
- 拟在建机会：新建、扩建、改造、公共卫生或实验室项目。
- 经营建议：优先切入品类、关注部门、竞争压力。

## 区域医疗采购趋势分析

输出结构：

- 区域和时间范围。
- 公告量、金额规模、合同量。
- 热门品类和增长品类。
- 高活跃采购单位。
- Top 中标供应商。
- 拟在建项目机会。
- 未来 3-6 个月跟进建议。
