# GeneLLM 范式迁移手册（举一反三落地）

本文档把 GeneLLM 的"read-level 序列基础模型 + 伪生物标志物 + 暗物质挖掘"范式，迁移到类器官药敏、单细胞、靶点挖掘等场景，给出可执行路线。

## 0. 范式的"可复用内核"抽象

抽掉 cfRNA 具体语境，GeneLLM 的内核是：

```
[原始高维信号] → [k-mer / token 化，绕过注释] → [自回归 Transformer 预训练]
  → [冻结 backbone，挖高斯原型 = 伪生物标志物] → [患者/样本级汇总特征]
  → [source/batch 偏倚消除] → [多尺度特征] → [校准多分类/多任务头]
```

关键设计语言：**"不要先做注释依赖的降维（基因计数），要保留别人丢掉的信号（暗物质），再用原型向量做可解释压缩。"**

## 1. 迁移到类器官（PDO）药敏预测

### 现状（你的 OrganoidAI）
- 图像侧：U-Net 分割 + 形态学 + FFT 增强 + IC50 药敏分析
- 96 孔板：6-8 浓度梯度 × 19 药 × 3 通道（B/GFP/RFP），360 图
- 分子侧待补强

### 迁移方案 A：类器官 bulk RNA-seq 的 read-level 药敏建模
1. 对给药前后 / 耐药与敏感的 PDO 做 bulk RNA-seq（或已有数据）
2. **跳过**"比对→基因计数→DESeq2"的标准路，直接对 reads 做 k-mer token 化
3. 用 GeneLLM 同款自回归 Transformer 预训练（或轻量版：降低 token 维度、用更小词表）
4. 冻结 backbone → 挖"耐药/敏感原型伪生物标志物"
5. 样本级汇总 → 用 IC50/AUC 值做回归头或敏感/耐药二分类头
6. 验证：伪生物标志物在敏感/耐药组是否分离，反向 BLASTn 看是否落在未注释区/耐药相关重复元件

### 迁移方案 B：cfRNA 预测药物响应（更贴近原文）
- 类器官培养上清 / 患者血浆 cfRNA → GeneLLM 风格建模 → 预测"该患者 PDO 对某药是否敏感"
- 这是把"癌症检测"换成"药敏预测"的直接迁移，损失函数不变，只换标签

### 落地注意
- 算力门槛：原文 20T reads + 64 A100 无法照搬；**用轻量版（小词表 + 4 层 + 单卡）做 proof-of-concept**，或直接加载其开源权重做下游微调
- 数据量：PDO 队列往往只有几十到几百例，需用冻结 backbone + 轻量头，避免过拟合

## 2. 迁移到单细胞 / 死活状态判读

论文明确提到可迁移到 scRNA-seq，挖细胞类型特异性伪生物标志物。

对应你的场景：
- 类器官死活判读：目前用 YOLOv8 图像侧 + 荧光 GFP/RFP 推导 CTG。可补充**分子侧**——把 alive/dead 细胞群的 scRNA-seq reads 做 k-mer 建模，挖"存活/死亡状态特异性伪生物标志物"，与图像侧结果交叉验证
- 细胞类型识别：挖不同类器官细胞亚型（腺上皮/基质/免疫）的 read 级特征

## 3. 迁移到胆管癌靶点挖掘（CCA-AI 增强）

你的 CCA-AI Module 1 目前用 Welch t-test / Fisher / XGBoost 挖"已知基因差异表达"。

**"暗物质"补充视角（可直接落地，无需大算力）：**
1. 对 TCGA-CHOL 或自有 RNA-seq 数据，不只看 GENCODE 注释基因，额外统计：
   - 基因间区转录片段（intergenic reads）
   - 重复元件来源 reads（LINE/SINE/LTR/ERV）
   - 未注释 lncRNA / 反义转录本
2. 做"注释内 vs 注释外"的差异信号对比（仿原文的 BLASTn 分组消融）
3. 若注释外信号在肿瘤 vs 正常有判别力（AUC 提升），即证明胆管癌也存在可利用的转录组暗物质
4. 用 `references/paper_methods.md` 里的 Eq.(2)-(4) 原型挖掘思路，把 read embedding 聚类成原型，找胆管癌特异原型

**提示：这一步甚至不需要 Transformer 预训练**，用现有表达矩阵之外的 read 层信息 + 简单聚类/统计即可验证假设，是性价比最高的切入点。

## 4. 迁移到计算病理 / 数字病理

你的 TCGA-CHOL 5400 patch + EfficientNet-B0 是"图像 patch 分类"。GeneLLM 的架构可平移为：
- "patch → patch token（类比 read → k-mer）" → Transformer 预训练 → 原型向量（类比伪生物标志物）→ 多分类头
- 伪生物标志物思路可对应"病理图像中的可解释原型 patch"（prototype learning，如 ProtoPNet）

## 5. 通用落地检查清单

复现 / 迁移 GeneLLM 范式时，逐项确认：

- [ ] 是否绕过了注释依赖的降维？（保留暗物质信号）
- [ ] token 化粒度是否合理？（cfRNA 用 7-mer；其他模态需类比选 k）
- [ ] 预训练是否只用训练集？（防数据泄露）
- [ ] backbone 是否冻结、只训轻量下游头？（小样本必做）
- [ ] 原型/伪生物标志物数量是否作为超参在验证集调？（原文 n∈{200..1200}）
- [ ] 是否处理了 source/batch 偏倚？（原文 per-source 均值平移）
- [ ] 多任务/多疾病分类头概率是否校准？（原文 pivot calibration）
- [ ] 是否用换头实验证明"增益来自特征而非分类器"？（原文 RF/SVM 换头）
- [ ] 是否做了"注释内 vs 注释外"消融证明暗物质贡献？（原文 BLASTn 分组）
- [ ] 是否用外部队列 de novo 重训验证泛化？（而非直接迁移权重）

## 6. 一句话总结（给团队讲）

GeneLLM 的启示不是"Transformer 又赢了"，而是：**液体活检/组学建模的竞争焦点，正从"找更多已知基因/扩大 panel"转向"别在预处理阶段丢掉未注释信号"。** 对类器官药敏和胆管癌靶点挖掘，最可操作的下一步是补一个"暗物质视角"——先验证未注释/重复元件 reads 在你要预测的表型里有没有判别力。
