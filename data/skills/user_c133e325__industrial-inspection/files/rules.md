# 工业质检审核规则

## 检测标准范围

优先以表格中"标准要求"列为准，若该列为空则参考以下合理物理范围：

| 检测项目       | 合理范围   | 单位 | 备注         |
|--------------|-----------|-----|-------------|
| 抗拉强度      | 450~650   | MPa |             |
| 屈服强度      | 280~450   | MPa |             |
| 延伸率        | 15~35     | %   | 绝不可为负数 |
| 断面收缩率    | 45~70     | %   | 绝不可为负数 |
| 冲击功(常温)  | 20~50     | J   | 不可为0或负  |
| 布氏硬度(HRB) | 140~220   | HRB |             |
| 化学成分-C含量 | 0.12~0.25 | %   |             |
| 化学成分-S含量 | ≤0.035    | %   | 越低越好     |

## 异常判定规则

### 规则1 — 范围超限
实测值超出标准/合理范围即为异常。标准要求列格式支持：
- `480~620` → 范围区间
- `≥20` → 不小于
- `≤0.035` → 不大于

### 规则2 — 非法数值
- 延伸率、断面收缩率：绝不可为负数
- 冲击功(常温)：不可为 0 或负数
- 强度、硬度类指标：不可为 0 或负数（0 表示设备未采集到有效数据）

### 规则3 — 偏差率异常
偏差率绝对值超过 100%（即 >100 或 <-100）视为录入异常。

### 规则4 — 判定矛盾
实测值已存在异常，但"判定结果"列仍为"合格"，存在判定逻辑矛盾。

## 输出规范

生成的质检报告仅标红有问题的单元格，不标红整行。报告不包含标题行、汇总行和异常分类列。
