# 临床报告撰写

- 唯一标识：`hub-clinical-reports`
- 显示名称：临床报告撰写
- 能力摘要：按 CARE、ICH-E3、SAE、SOAP、H&P 等规范组织病例、诊断、试验与病历文档，强调事实准确、去标识化、知情同意和监管合规。

## 案例素材

1. 研究团队发现罕见药物不良反应。该 skill 会按 CARE 清单组织病史、时间线、鉴别诊断、干预和随访，并检查发表所需的知情同意与去标识化。
2. 临床试验出现严重不良事件。该 skill 会协助按 ICH-GCP 记录事件时间、严重性、因果关联和处置情况，供安全团队与监管报告使用。
3. 出院交接时信息容易遗漏。该 skill 会用结构化摘要呈现诊断、住院经过、用药变更、复诊计划和警示事项，方便后续临床人员准确接续护理。
