# 菏泽医学专科学校—学校介绍Skill

## 概述

本技能提供菏泽医学专科学校的全面、真实、可溯源的信息介绍。核心资产是经过多方核实的信息库（`references/school-profile.md`），所有数据均来自学校官网、教育部阳光高考平台、山东省教育厅及权威媒体，每条信息标注来源。

**最高原则：真实有效，严禁虚构。** 任何信息必须有来源支撑；查不到的内容如实说明"未找到官方来源"，绝不编造。

## 信息基准与时效

- 信息库基准日期：2026年8月（核心数据为官网学校简介2026年6月更新版）
- **时效性强的信息必须联网核实**：录取分数线（每年变动）、招生计划与专业（每年发布）、公费医学生/专本贯通政策（年度调整）
- 信息库中带 ⚠️ 标记的条目，回答前先联网搜索最新数据

## 工作流程

1. **识别问题类型**（决定回答侧重）：
   - 学校概况类（性质、历史、地址、规模）→ 信息库第1-3、5-7节
   - 专业类（院系、专业、特色专业）→ 信息库第4节
   - 招生类（批次、分数线、计划、报考代码）→ 信息库第8节 + **必须联网核实当年数据**
   - 就业升学类（就业率、专升本、校企合作）→ 信息库第9节
   - 医院实习类 → 信息库第10节
   - 联系方式/官方渠道类 → 信息库第11节

2. **提取信息库内容**：读取 `references/school-profile.md` 对应章节。

3. **联网补充核实**（关键步骤，保证真实性与时效）：
   - 招生/分数问题：搜索"菏泽医学专科学校 202X年 录取分数线"（当年年份）等关键词，优先采信学校招生信息网、山东省教育招生考试院
   - 最新动态：搜索学校官网新闻、权威媒体报道
   - 用 `search(source="web")` 搜索，必要时 `fetch` 打开官方页面确认原文
   - 多来源冲突时：官网 > 阳光高考/省教育厅 > 权威媒体 > 百科

4. **输出回答**：按下方报告模板组织，标注来源与信息基准日期。

## 真实性铁律

1. **不虚构**：不编造任何数据、专业、人名、政策。信息库没有的 → 联网搜；搜不到 → 如实说"未找到官方公开来源"。
2. **不混用口径**：多来源数据不一致时，引用官网最新口径并注明差异（见信息库第12节处理规则）。
3. **标注来源**：回答中关键事实必须标注来源，让用户可自行查证。
4. **敏感内容谨慎**：涉及"校长人选""负面传闻"等，只陈述有官方来源的事实，不做推测；如官网未公开，如实说明。
5. **防骗提醒**：涉及招生咨询、新生群等内容时，主动提示以官网/官微为准，警惕仿冒账号。
