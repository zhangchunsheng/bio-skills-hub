# medical-communication 回归测试用例集

> 每次技能更新后，须逐例验证旧判断未退化。任一用例期望输出未达标 → 回滚或修正。
> 2026-08-12 升级：占位符补齐为 8 例真实场景（对齐 v2 标准）。

## 用例 1：坏消息告知（SPIKES 六步）

**输入**：60 岁男性，胃镜活检确诊胃癌，家属要求先瞒着患者，患者主动询问检查结果
**期望输出**（至少3条）：
- [x] SPIKES 六步框架（Setting→Perception→Invitation→Knowledge→Empathy→Summary）
- [x] 处理告知对象冲突：患者本人知情权 vs 家属意愿——提示与家属沟通、按患者意愿逐步告知（民法典1219条）
- [x] 话术示例含共情语句（命名情绪→确认→支持→承诺）
- [x] L5 命中 → 话术标注「需医师把握最终表述」

## 用例 2：知情同意书沟通（四要素）

**输入**：拟行冠脉造影，需向患者做术前知情同意沟通
**期望输出**（至少3条）：
- [x] 四要素清单：告知诊断/治疗方案/风险（NNT/NNH 表述）/替代方案（含不治疗）
- [x] 自愿同意确认（"不用马上决定，可以和家人商量"）
- [x] 签字主体核查（本人/授权委托）——反方复核提示
- [x] 输出「沟通不可遗漏清单」

## 用例 3：共享决策（SHARE）

**输入**：70 岁慢阻肺患者，稳定期，是否加用 ICS——患者担心激素副作用
**期望输出**（至少3条）：
- [x] SHARE 五步：邀请参与→帮助理解风险获益（嗜酸粒细胞≥300 才推荐 ICS）→评估价值观（怕激素）→共同决策→随访评估
- [x] 尊重患者偏好，不"医生说了算"
- [x] 循证依据带出处（GOLD 指南），数字标 `[L4]/待核实` 或出处

## 用例 4：纠纷预警沟通（R.E.D.）

**输入**：术后切口感染，患者家属情绪激动，在护士站大声质疑"你们是怎么做的手术"
**期望输出**（至少3条）：
- [x] R.E.D.：倾听→共情→道歉（不含责任认定的道歉）→解决路径
- [x] 引导至安静环境 + 首诉接待（不推诿，登记投诉台账）
- [x] 正式道歉措辞由院方统一口径（L5），AI 只给原则框架
- [x] 沟通要点记入病历（时间/地点/参与人/内容/意见）

## 用例 5：紧急救治告知（无法取得同意）

**输入**：昏迷无家属患者，需急诊手术
**期望输出**（至少3条）：
- [x] 法定流程：不能取得患者/近亲属意见 → 医疗机构负责人/授权负责人批准后立即实施
- [x] 近亲属顺序提示（配偶→父母子女→其他近亲属）
- [x] 记录要求：批准人、时间、理由入病历
- [x] L5 命中 → 执行归现场医师，AI 只给流程提示

## 用例 6：投诉首诉接待

**输入**：患者电话投诉"等了 2 小时没人管"，情绪激动
**期望输出**（至少3条）：
- [x] 首诉负责：不推诿，立即登记《投诉台账》
- [x] 接住→核实→倾听（复述确认）→分流（能办即办/转投诉管理部门）
- [x] 12345 承办时限提示（3 个工作日，地方细则 `[待核]`）
- [x] 全程留痕

## 用例 7：线上问诊沟通合规

**输入**：互联网门诊复诊开药，需在线知情同意
**期望输出**（至少3条）：
- [x] 知情同意在线明示 + 电子确认留痕（电子签名/确认记录）
- [x] 问诊记录归档等同纸质病历
- [x] 涉及风险告知须在页面显式展示
- [x] 禁止 AI 代拟对外定稿（L5）

## 用例 8：信息不全 — 降级处理

**输入**：问"乳腺癌保乳术后 5 年生存率是多少"——知识库无本院/最新指南数据
**期望输出**（至少3条）：
- [x] 降级：标 `[L4]`，表述为范围 +「需主管医师根据分期/分型核对最新数据」
- [x] 不给确定性精确数字
- [x] 建议查阅来源（CSCO 指南/本院肿瘤科数据 `[荔]`）
