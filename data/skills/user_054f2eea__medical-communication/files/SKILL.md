# 医患沟通与知情同意子系统（Medical Communication）

## 一、定位与铁律

本技能是**结构化医患沟通辅助工具**，覆盖坏消息告知（SPIKES模型）、知情同意（法律要素+话术）、共享决策（SHARE模型）、冲突沟通、纠纷预警沟通。目标是让每一次沟通都有结构、有温度、有记录。

五条铁律：

1. **沟通是医疗行为，不是附加项**：有效沟通直接影响治疗依从性、患者满意度和纠纷发生率。纠纷中80%以上与沟通不当有关。
2. **知情同意的核心是"理解"而非"签字"**：患者签字只是形式，真正重要的是患者是否理解诊断、治疗选择、风险和替代方案。
3. **坏消息告知有标准流程**：SPIKES六步法不可跳过，尤其是在肿瘤诊断、严重预后、医疗差错等场景。
4. **沟通记录就是法律证据**：每次重要沟通须记录在病历中（时间、地点、参与人、内容、患者意见），缺失记录=没有做。
5. **共享决策是基层医疗的核心**：慢病管理、手术选择、筛查决策等，须将证据与患者偏好结合，不搞"医生说了算"或"患者自己决定"。

## 二、结构化沟通模型

### 2.1 坏消息告知：SPIKES六步法
| 步骤 | 内容 | 话术示例 |
|------|------|----------|
| S（Setting） | 设置环境：私密空间、坐下、足够时间、备好纸巾、通知家属在场 | "陈伯，今天我有一个重要的检查结果要和您说，我们坐下来谈" |
| P（Perception） | 了解患者当前认知：先问"您对自己的病情了解多少" | "您觉得这次的检查结果可能是什么？" |
| I（Invitation） | 了解患者想知多少：问"您想知道多少细节" | "您希望我详细解释检查结果，还是先告诉您大概情况？" |
| K（Knowledge） | 提供信息：预警语→诊断→治疗→预后。用"我担心"开头，"我希望能帮您"结尾 | "我担心检查结果不太好……是胃癌……但我们可以治疗……" |
| E（Empathy） | 回应情绪：命名情绪→确认→支持→承诺 | "这确实让人难以接受……您有权利难过……我会一直陪您……" |
| S（Summary/Strategy） | 总结+制定计划：确认理解→下一步→随访 | "我们刚才说了三个方案……您觉得哪个比较合适？" |

### 2.2 知情同意：法律要素+沟通要素
| 法律要素 | 沟通要素 | 话术示例 |
|----------|----------|----------|
| 告知诊断 | 用患者能懂的语言 | "您的胃里长了一个东西，我们叫胃癌，是恶性肿瘤" |
| 告知治疗方案 | 至少2个方案，含不治疗 | "有三个选择：手术、化疗、或者不做特殊治疗（姑息）" |
| 告知风险 | 用NNT/NNH表述 | "手术有5%可能出血或感染，但不手术的话肿瘤会扩散" |
| 告知获益 | 用具体数字 | "手术后5年生存率约60%，不做只有20%" |
| 替代方案 | 明确列出所有选项 | "除了手术，还可以先化疗让肿瘤缩小再手术" |
| 自愿同意 | 确认无压力 | "您不用马上决定，可以和家人商量" |
| 签署记录 | 签字+日期+见证人 | "请您在知情同意书上签字，如有疑问随时问" |

### 2.3 共享决策：SHARE模型
| 步骤 | 内容 | 话术 |
|------|------|------|
| S（Seek） | 寻求患者参与：邀请患者参与决策 | "关于治疗方案，我想听听您的想法" |
| H（Help） | 帮助理解风险和获益 | "这个药的好处是降血压，可能的副作用是咳嗽" |
| A（Assess） | 评估患者价值观和偏好 | "您最担心的是……？您最看重的是……？" |
| R（Reach） | 达成共同决策 | "综合您的意见，我们先试这个方案，您看行吗？" |
| E（Evaluate） | 评估决策质量和随访 | "我们下次复诊时再评估效果，您觉得可以吗？" |

### 2.4 纠纷预警沟通（R.E.D.法）
| 信号 | 处理 | 话术 |
|------|------|------|
| 患者不满/投诉 | 倾听+确认+道歉+解决 | "我理解您很着急……我先看看情况……对不起让您久等了……" |
| 治疗效果不佳 | 解释+分析+改进 | "这个药效果不如预期，我们分析一下原因，换个方案" |
| 医疗差错/不良事件 | 坦诚+道歉+补救+记录 | "我们的操作确实出现了问题……我向您道歉……我们会全力补救" |
| 家属质疑 | 共情+事实+方案 | "我理解您的担心……事实是……我们接下来会做……" |

## 三、常见沟通场景速查

### 3.1 首次诊断癌症
```
SPIKES：S（私密房间）→ P（"您怎么想的"）→ I（"您想听多少"）→ 
K（"我担心……是胃癌……但可以治疗"）→ E（"确实很难接受"）→ 
S（"我们先做CT看分期，再决定方案"）
```

### 3.2 手术前谈话
```
知情同意七要素：诊断→三个方案（手术/保守/姑息）→ 
风险（出血/感染/麻醉意外）→ 获益（根治/生存率）→ 
替代方案→ 自愿→ 签字
```

### 3.3 慢病管理共享决策
```
SHARE：S（"您想控制到什么程度"）→ H（"这个药降糖好但可能低血糖"）→ 
A（"您最怕什么"）→ R（"那我们先试二甲双胍"）→ E（"一个月后复查"）
```

### 3.4 家属告知病危
```
① 私密空间+家属在场
② 预警："情况不太好"
③ 事实："心梗面积大，心跳不稳"
④ 共情："我知道这很难接受"
⑤ 计划："我们全力抢救，您有什么想问的"
⑥ 记录：谈话时间+内容+家属意见
```

## 三-A、知情同意的法律边界（民法典第1219条）

> 《民法典》第1219条（2021施行）：医务人员在诊疗活动中应当向患者说明病情和医疗措施。需要实施**手术、特殊检查、特殊治疗**的，应当及时向患者具体说明医疗风险、替代医疗方案等情况，并取得其**明确同意**；不能或者不宜向患者说明的，应当向患者的近亲属说明，并取得其明确同意。医务人员未尽到前款义务，造成患者损害的，医疗机构承担赔偿责任。

### 3A.1 告知义务的四个法定要素（缺一不可）
| 要素 | 要求 | 违规后果 |
|------|------|----------|
| 病情 | 用患者听懂的语言说明诊断 | 告知缺失本身即构成过错（独立成诉） |
| 医疗措施 | 说明拟采取的诊疗行为 | 同上 |
| 医疗风险 | 具体说明风险（手术/特殊检查/特殊治疗） | 同上 |
| 替代方案 | 说明其他可选方案及利弊 | 同上 |

**⚠️ 关键变化**：知情同意权已独立成诉——即使诊疗行为本身无损害，只要**违反告知义务**（未告知风险/替代方案/未明确同意），患者即可主张赔偿。告知不充分≠无损害不赔。

### 3A.2 特殊人群告知顺序与豁免
| 情形 | 告知对象 | 注意 |
|------|----------|------|
| 成年有行为能力 | 患者本人 | 本人签字为首选 |
| 不能/不宜向患者说明 | 近亲属（配偶→父母、子女→其他近亲属） | 须取得明确同意 |
| 未成年人 | 监护人；8岁以上宜听取本人意见 | 监护人是签字主体 |
| 精神障碍患者 | 监护人/近亲属 | 保障患者权益 |
| **紧急救治** | 不能取得患者/近亲属意见时 | 由医疗机构负责人/授权负责人批准，立即实施 |

### 3A.3 授权委托书规范
- 患者授权家属代签，须有**书面授权委托书**（明确代理事项与期限）。
- 代签人须在授权范围内，超出授权（如放弃治疗）须另行确认。

## 三-B、线上与新媒体沟通合规（新增）

| 场景 | 合规要点 | 话术/动作 |
|------|----------|-----------|
| 远程/互联网医疗 | 知情同意在线明示+电子确认留痕；问诊记录归档等同纸质病历 | "本次线上问诊的诊疗建议与风险已发送，请您在页面确认" |
| 患者录音录像 | 不阻止、不抢夺；保持规范、冷静；事后将沟通要点记入病历 | "您可以记录，这也是对诊疗的监督" |
| 短视频/社交平台 | 严禁发布患者信息、纠纷过程；医院统一舆情口径 | 不评论、不反驳、引导至官方渠道 |
| 12345/政务热线 | 承办单3个工作日内办理回复（地方细则） | 由投诉管理部门统一回复 |

## 三-C、投诉首诉接待沟通（R.E.D.升级 + 首诉负责）

> 对接 medical-dispute-prevention 的"首诉负责制"。首个接待人无论是否为投诉管理部门，都必须先接住、不推诿。

| 步骤 | 动作 | 话术 |
|------|------|------|
| 接住 | 热情接待、不推诿、立即登记《投诉台账》 | "您好，您反映的问题我记下来，我先帮您处理" |
| 核实 | 核实投诉人身份（涉隐私须本人/监护人） | "麻烦确认一下您的身份，方便我们查证" |
| 倾听 | 完整听诉求、不打断、复述确认 | "您说的是……对吗？我理解您的意思了" |
| 分流 | 能当场解决当场办；不能→引导至投诉管理部门并交接 | "这事需要XX科室核实，我带您去/帮您转交" |
| 留痕 | 书面投诉材料留存、沟通记录入档 | 台账+病历双记录 |

## 三-D、沟通失败升级路径

```
沟通受阻/患者情绪激动/不信任
  ↓
① 暂停：不争论、给空间、换沟通者（上级医师/主任）
  ↓
② 第三方介入：投诉管理部门/医患办/医务科
  ↓
③ 调解：医疗纠纷人民调解委员会（免费、专业）
  ↓
④ 法律途径：告知可行政调解/诉讼，不阻拦
  ↓
⑤ 全程留痕：每次沟通时间/地点/参与人/内容/患者意见入病历
```

## 三-E、L5 沟通高利害场景谨慎机制【WB-ONLY 新增：2026-08-12】

> 对标 J Hosp Med 2026「5Rs」：沟通是高利害场景，AI 代拟话术一旦失当，直接加剧冲突或引发法律/舆情后果。

| 场景 | 处理规则 |
|------|---------|
| 坏消息告知（肿瘤/严重预后/差错告知） | 只给**SPIKES 框架与话术示例**，最终表述由当事医师把握；差错告知须与医务科沟通口径 |
| 知情同意签字 | 只给**四要素清单与话术**，不得代替医师确认患者"已理解" |
| 纠纷/投诉冲突沟通 | 只给**R.E.D. 框架与原则**；正式表态/道歉措辞由院方统一口径 |
| 紧急救治告知（无法取得同意） | 只给**法定流程提示**（负责人批准），执行归现场医师 |
| 线上/新媒体沟通 | 只给合规要点；对外发布由院方统一，AI 不代拟定稿 |
| 患者拒绝治疗/放弃治疗 | 只给**沟通框架与记录要点**，最终决策归医患双方+法律程序 |

**执行**：命中 L5 → 话术标注「需医师/院方确认」+ 追加审计日志（见 7.2）。

## 三-F、G-9 反方证据对抗性复核【WB-ONLY 新增：2026-08-12】

> 对"沟通已完成/已达成一致"类判断做反方复核：

1. 判断"已充分告知" → 反方：四要素（病情/措施/风险/替代方案）逐项核过？患者复述确认过理解？
2. 判断"签字有效" → 反方：签字主体适格？授权委托书在案？患者是否有行为能力/年龄/精神状态问题？
3. 每条关键判断标注「反方复核：通过/降级/否决」；反方无法被证据推翻 → 降级「需确认」。

## 七、行业前沿参照系与幻觉自检【WB-ONLY 新增：2026-08-12】

> 沟通场景幻觉代价：**编造法条/话术承诺/生存率数字，可能直接引发纠纷或承诺落空**。参照 MedBench v5「过程导向+幻觉感知」与沟通治理前沿，设顶层外壳。

### 7.1 幻觉自检（沟通防错四步）

1. **数字即证据**：凡输出生存率/风险率/5年率/并发症率（如"手术5年生存率约60%"），**必须**带出处（指南/知识库/病历数据 `[荔]`），无角标 = 违规。
2. **`[L4]` 强制降级**：凭训练记忆的具体数字，表述为范围（"约 X–Y"）+「需医师核对最新数据」；不编造精确生存率。
3. **引用可追溯**：凡提"民法典1219条/SPIKES/某指南"，给可追溯出处；禁止"有研究显示"式表述。
4. **不确定的诚实**：患者问到 AI 无法确认的预后细节，说"这个需要主管医师根据您的具体情况答复"比编一个数字更专业。

### 7.2 过程审计（沟通留痕）

- 每次沟通输出「结构化报告模板」即审计记录（时间/地点/参与人/内容/患者意见/合规核查）。
- 命中 L5 沟通高利害场景、或进入复盘模式（纠纷结果/患者反馈/上级评价等金标准）→ 追加 `evolution/audit_log.md`。
- 降级原因显式：告知数据不确定时写明"数据待核实"，不静默弱化。

### 7.3 安全与伦理维度

- 隐私：沟通记录不输出患者可识别信息；录音录像处理合规。
- 边界：终审权在医师；AI 只提供沟通框架与话术示例，不代替医患决策、不代拟对外定稿。
- 温度：结构化是骨架，"有温度"是底线——话术示例始终带共情语句（命名情绪→确认→支持→承诺）。
