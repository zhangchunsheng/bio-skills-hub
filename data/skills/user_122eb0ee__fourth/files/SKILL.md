# 第四代住宅 · 文案与短视频脚本技能

## 一、技能定位（Purpose）

为**第四代住宅·空中院子**（第四代住宅、信阳改善盘）产出**可落地、有转化、贴调性**的营销文案与短视频/社媒脚本。

不是泛地产套话，而是带着项目真实 DNA 与用户文案偏好工作：
- 与 `fourth-generation housing-marketing-activity`（活动策划）互补：本技能负责"**说什么、怎么写**"，活动技能负责"**做什么动作**"。文案常作为活动的传播物料配套产出。
- 文案核心任务：用**内容密度对抗负面舆论、用真实感建立信任壁垒**；装修期讲"现房确定性"，入住期讲"向往的生活"。
- **服务边界**：本技能聚焦"写什么文案、怎么写"，**不含独立的朋友圈/私域转发语模块**。华信工作台已于 2026-07-31 移除"写转发语"模块，相关短转发需求可并入海报文案或活动传播物料统筹。

> 项目 DNA、破局打法、三层发声矩阵、话题标签库、创意资产见 `fourth-generation housing-marketing-activity/references/project_dna.md`，**动笔前必读**。
> 长文案框架见 `references/copy_frameworks.md`；分渠道规范见 `references/channel_specs.md`；质量三轴见 `references/quality_rubric.md`；交付模板见 `assets/copy_template.md`。

## 三、项目速览（文案必读 · 浓缩 DNA）

- **产品**：第四代住宅 · 空中院子（户户空中庭院、一梯一户、私梯厅双玄关）
- **客群**：改善型——周边老破小/老旧家属院置换、二胎三代同堂、圈层影响型（教师/医生/公务员）、竞品 142–143㎡ 拦截客
- **阶段调性**：
  - 装修期（理性验证）= 用"素颜实景"展示硬核产品力、建立现房确定性
  - 入住期（感性绽放）= 用"烟火气"引爆"向往的生活"、口碑裂变
- **核心标签**：信阳实景四代现房 / 户户空中庭院花园 / 生活就是度假 / 森居生活
- **场景资产（零场地成本，文案可"种"进去）**：挑高露台（约6米）、阳光草坪、下沉庭院（叠水/锦鲤）、风雨连廊、拱形花廊（进深约4.7米）、270°无界云端露台、星空顶车库、酒店式社区大门（环岛落客/迎宾大堂）
- **统一话题标签**： `#户户空中庭院花园` `#第四代住宅空中院子` `#四代住宅` `#森居生活` `#生活就是度假` `#下沉庭院` `#拱形花廊` `#露台改造`

## 四、工作流（How — 5 步）

### Step 1 · 收口 Brief（先问清，不拍脑袋）
用最简方式确认，缺失时用合理默认值并**显式标注假设**：
- **文案类型**：楼书 / 落地页单页 / 海报 / 公众号推文 / 视频号 / 小红书 / 抖音 / 节气脚本 / 业主故事 / KOC文案
- **核心目的**：品牌曝光 / 引流到访 / 留资 / 逼定成交 / 口碑修复 / 老带新
- **主行动 CTA**：到访 / 加企微 / 领一房一价表 / 算首付 / 预约样板间（唯一主行动）
- **目标客群**：置换改善 / 二胎三代 / 业主KOC / 异业客池 / 本地博主
- **渠道与调性**：抖音（高频本地流量）/ 小红书（场景种草）/ 视频号（微信生态）/ 案场物料
- **约束**：是否处于敏感期（福利未兑忌过度承诺、竞品拦截等）

### Step 2 · 选框架与渠道（按类型加载）
- 长文案（楼书/落地页/海报/公众号）→ 加载 `references/copy_frameworks.md`
- 分渠道/分平台细则（含短视频结构、节气脚本、各平台钩子）→ 加载 `references/channel_specs.md`
- 优先使用项目既有创意资产（"名画里的意境生活"AI视频系列、节气脚本结构），勿重复发明。

### Step 3 · 起草（按框架，带 DNA）
- 先读项目 DNA（Step 3 速览 + project_dna.md），确保调性、标签、场景资产一致。
- 套用对应框架：**首屏钩子 → 痛点/共鸣 → 价值证据 → 抗性处理 → CTA**。
- 每处卖点须有支撑（数据/实景/背书），禁用无实指堆砌。
- 统一带话题标签；业主/KOC 文案用第一人称、真实素材、杜绝广告感。

### Step 4 · 三轴自检（质量门槛，必须执行）
按 `references/quality_rubric.md` 的三轴各打 1–5 分：
- **轴一 抓眼×共鸣×记忆点**（权重 0.3）
- **轴二 清晰×具体×可信**（权重 0.4，用户最在意"说人话、有证据"）
- **轴三 调性×第四代改善盘×真实感**（权重 0.3）
- **否决规则**：任一轴 ≤ 2 不输出；轴二偏低尤其致命（"说清楚"是硬要求）；轴三 ≤ 2 一律不推（不降格豪宅调性、不触信任红线）。

### Step 5 · 领导视图交付
按"先结论后展开"输出：
1. **一句话结论**（这篇文案推什么、为什么）；
2. **文案稿**（按模板区块组织）；
3. **批注**：关键处说明用了什么原则、为什么；
4. **备选**：标题/钩子/CTA 给 2–3 个选项各附理由；
5. **合规提示**：标出广告法敏感词（最高级、学区承诺、投资回报、未兑福利包装）需核实处。
格式适合领导快速抓要点：结论前置、关键数字加粗、可复制即用。

## 五、用户的文案偏好（写进每篇文案）

- **标题要抓眼球、表达要场景化**，拒绝"XX盛大启幕"式空话；
- **真实感 > 精致感**：用素颜实景、业主真实素材对抗负面，不造假；
- **利益 > 功能**："二胎也能各自有房" > "建面约128㎡四房"；
- **客户语言**：用业主原话，不用策划自嗨词；
- **可归因**：文案服务转化（活动→留资→案场→成交），设计清晰路径；
- **信任优先**：承诺未兑期，任何文案不得过度承诺，避免放大为"套路"。

## 六、质量红线（Quality Gates）

- 不输出无实指词堆砌（"尊享/奢阔/匠心"须有支撑）；
- 不编造数据/奖项/学区承诺（违反《广告法》且伤信任）；
- 信任受损期不把"未兑福利"包装成新优惠且不标注风险；
- 不输出显廉价感、与第四代价值无关或可能拉低豪宅调性的内容；
- 不强加与"空中院子/现房确定性/户户庭院/森居生活"无关的内容。
