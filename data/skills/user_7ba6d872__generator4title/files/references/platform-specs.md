# 平台标题规范

本文档详细记录视频号和公众号的标题排版规范、字数限制和避坑指南。

---

## 一、视频号标题规范

### 字数限制

| 展示位置 | 完整显示字数 | 超出处理 |
|----------|-------------|----------|
| 推荐流封面 | 12-15 字（含标点） | 超出部分显示「…」 |
| 视频详情页 | 不限 | 全量展示但用户很少看完 |
| 分享卡片 | 约 12 字 | 超出截断 |

**推荐字数：10-15 字**

### 格式要求

- **一句话成题**：不使用「｜」「：」等复杂分隔符
- **口语化优先**：像跟朋友聊天一样，不要书面语
- **画面感强**：让用户能在脑中形成画面
- **短平快**：主语 + 动词 + 核心信息，不做铺垫

### 风格适配优先级

1. **扎心风** ⭐⭐⭐⭐⭐ — 视频号用户对情绪内容共鸣最强
2. **反问风** ⭐⭐⭐⭐ — 互动率高，适合引发评论区讨论
3. **引流风** ⭐⭐⭐ — 效果有但不如前两者自然

### 视频号标题示例

| 风格 | 好标题 | 为什么好 |
|------|--------|----------|
| 扎心 | 「加班到凌晨3点，老婆发来一句离婚吧」 | 场景+结果，12字，画面感极强 |
| 扎心 | 「HR说只要985，我当着她的面撕了简历」 | 冲突+反转，有爽感 |
| 反问 | 「你说AI会取代人类，那你被取代了吗」 | 挑战一个常见论调，有互动欲 |
| 反问 | 「一边说要自由，一边不敢裸辞，你在怕什么」 | 矛盾感十足 |
| 引流 | 「用了3年的微信，今天才发现这个功能」 | 制造「我不会也错过了吧」的焦虑 |
| 引流 | 「视频号7天破万粉，我只用了这一招」 | 结果承诺直接 |

### 避坑指南

- 不要在封面标题里放网址/联系方式（违规风险）
- 不要用「震惊」「紧急通知」等过度标题党词汇
- 标题不要和封面图重复信息（浪费展示空间）
- 情绪不能过于负面（可能被限流）

## 二、公众号标题规范

### 字数限制

| 展示位置 | 完整显示字数 | 超出处理 |
|----------|-------------|----------|
| 订阅列表封面 | 约 30 字（一行半） | 超出部分显示「…」 |
| 分享卡片 | 约 30 字 | 超出折叠 |
| 搜一搜结果 | 约 20 字（一行） | 超出截断 |

**推荐字数：20-28 字（粉丝订阅列表最佳展示）**

### 格式要求

- **可用分隔符**：「｜」「：」「——」用于信息分层
- **结构感强**：前置关键词 + 分隔 + 展开说明
- **信息量大**：标题本身就是内容的「摘要」
- **可以有补充分句**：主标题 + 副标题结构

### 常用标题结构

```
结构1：关键词前置型
「[核心关键词]：[一句话价值承诺/悬念]」
例：「AI副业：2026年最赚钱的5个赛道，第3个零成本」

结构2：观点输出型
「[鲜明观点]——[一句话解释/证据]」
例：「加班文化该结束了——我用数据证明，加班越多效率越低」

结构3：清单指引型
「[数字]个[方法/工具/真相]，[结果承诺]」
例：「7个让公众号阅读量翻倍的小技巧，最后一个很意外」

结构4：叙事悬念型
「[场景/故事开头]：[后续/结果]」
例：「一个32岁裸辞的程序员告诉我：月薪3万不如自由」

结构5：对比冲突型
「[A面] vs [B面]：[一句话结论]」
例：「高薪996 vs 低薪朝九晚五：选择前你必须知道的3件事」
```

### 风格适配优先级

1. **引流风** ⭐⭐⭐⭐⭐ — 公众号用户习惯「信息消费」，最吃这套
2. **反问风** ⭐⭐⭐⭐ — 观点类文章转发率最高的标题类型
3. **扎心风** ⭐⭐⭐ — 适合情感/故事向内容，但需配合封面图

### 公众号标题示例

| 风格 | 好标题 | 为什么好 |
|------|--------|----------|
| 引流 | 「2026年最值得学的5个AI技能｜第3个门槛最低」 | 数字+限定+分隔，23字，结构清晰 |
| 引流 | 「别再学Python了：这3个技能才是大厂2026年最缺的」 | 制造认知落差+信息增量 |
| 反问 | 「天天说AI抢饭碗的人，为什么从没想过自己就是那个AI？」 | 反转逻辑，引发思考 |
| 反问 | 「大家都说要做副业，但你真的准备好每天少睡3小时了吗」 | 戳破美好幻想 |
| 扎心 | 「同学都当合伙人了，我还在纠结简历上的措辞」 | 对比扎心，代入感强 |
| 扎心 | 「拿到大厂offer那天，我妈说『你终于不用让我担心了』」 | 亲情+职场焦虑双重情绪 |

### 避坑指南

- 不要标题超过 35 字（即使不折叠，用户也懒得读完）
- 「｜」「：」不要同时用超过 2 次（显得碎）
- 不要在标题里承诺正文无法兑现的价值
- 不要用「震惊体」「刚刚流出的内部文件」等已被微信打击的套路
- 标题避免出现敏感词（限流风险）

## 三、双平台通用原则

### 共性问题

1. **数字比形容词有力量** — 「很多」不如「7个」，「很快」不如「3分钟」
2. **具体比抽象有代入** — 「月薪2万」不如「月薪21970」
3. **冲突比和谐有关注** — 一个矛盾点 > 十个正确观点
4. **承诺比描述有驱动** — 「学会这个」不如「学会这个每天省2小时」

### 共性问题（避雷）

1. **标题党红线**：正文必须能兑现标题的承诺
2. **敏感词红线**：涉及政治、色情、暴力的擦边词一律不要
3. **情绪红线**：可以制造焦虑但不制造恐慌，可以扎心但不击溃
4. **版权红线**：不冒充官方/名人/平台
