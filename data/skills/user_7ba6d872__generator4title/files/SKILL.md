# 爆款标题生成器

## 概述

本 Skill 根据用户提供的文章/视频核心内容，批量产出扎心、引流、反问三种风格的爆款标题，并自动适配视频号和公众号的字数限制与排版规范。

## 工作流程

### 第一步：接收输入

从用户获取以下信息，缺失项主动询问：

1. **核心内容摘要**（必填）：文章/视频要讲什么？核心观点/结论是什么？
2. **目标受众**（选填）：面向谁？默认「职场人/泛互联网人群」
3. **内容调性**（选填）：偏理性干货 / 偏情绪共鸣 / 偏观点输出？未提供时根据内容自行判断
4. **输出数量**（选填）：每种风格几个？默认每种风格 5 个

### 第二步：加载风格参考

生成标题前，加载 `references/title-styles.md` 获取三种风格的详细技法、爆款公式和典型案例。

同时加载 `references/platform-specs.md` 获取视频号和公众号的字数限制、排版规范和避坑指南。

### 第三步：生成标题

按以下三类风格分别产出标题，每种风格内均匀覆盖「视频号」和「公众号」两种平台场景。

---

## 三种标题风格

### 风格 A：扎心风（情绪共鸣型）

**定位**：直击痛点，触发用户「说的就是我」的共鸣反应。适合情感类、职场焦虑、成长困境等话题。

**核心技法**：
- 用具体数字 + 个人体验制造代入感
- 用反差对比放大情绪张力
- 用「我以为…其实…」的转折结构

**爆款公式**：
- `[具体场景] + [负面结果] + [反转认知]`
- `[数字见证] + [时间跨度] + [扎心结论]`
- `[身份标签]的[困境]：[一句戳中软肋的话]`

**示例**：
- 「月薪3万，不敢告诉爸妈我在大厂被裁了」
- 「拼命卷了5年，升职的却是那个准点下班的人」
- 「32岁裸辞那天，我删掉了所有同事的微信」

### 风格 B：引流风（信息增量型）

**定位**：制造信息差，激发用户「必须点开看看」的好奇心。适合干货教程、行业揭秘、方法论分享等话题。

**核心技法**：
- 用数字制造「稀缺信息」感（N个方法/N条真相/N个工具）
- 用对比制造认知落差（你vs别人、过去vs现在）
- 用限定词制造紧迫感（2026年、最新、只有X%的人知道）

**爆款公式**：
- `[数字] + [限定词] + [高价值命题] + [结果承诺]`
- `别再[低效做法]了，[高效替代方案]才是王道`
- `[时间/平台]上[刚发生的事]，[对受众的影响]`

**示例**：
- 「2026年最暴利的3个AI副业，最后一个零门槛」
- 「别再手动做PPT了，这5个AI工具帮你省90%时间」
- 「抖音刚公开的算法秘密：为什么你的视频总是没流量」

### 风格 C：反问风（认知挑战型）

**定位**：用问题制造认知冲突，引发思考和讨论欲望。适合观点类、趋势判断、行业洞察等话题。

**核心技法**：
- 问题本身包含一个「反常识」或「被忽视」的观点
- 用「你以为…但其实…」的隐含逻辑
- 问题结尾留白，让读者在评论区完成

**爆款公式**：
- `[你以为的常识]，真的吗？`
- `为什么[常见做法]的人，最后都[意外结果]？`
- `[行业趋势出现后]，[某群体]的出路在哪里？`

**示例**：
- 「加班越多越努力？你可能是全公司效率最低的那个人」
- 「AI时代来了，为什么最先被淘汰的不是程序员而是管理者？」
- 「天天喊『做自己』的人，真的知道自己是谁吗？」

## 平台适配规则

### 视频号标题

- **字数上限**：封面行显示约 12-15 字，超出折叠
- **格式要求**：一句话成题，不用冒号分隔，不用多行
- **风格偏好**：偏口语化、短平快、有画面感
- **适合风格**：扎心风 > 反问风 > 引流风

### 公众号标题

- **字数上限**：封面完整显示约 30 字（含标点），推荐 20-28 字
- **格式要求**：可用「｜」分隔感更强，可用「：」做分句
- **风格偏好**：信息量大、结构感强、一眼看出价值
- **适合风格**：引流风 > 反问风 > 扎心风

详见 `references/platform-specs.md`。

## 质量自检清单

生成标题后，逐条检查：

- [ ] 每个标题是否一眼能看出属于哪种风格？
- [ ] 视频号标题是否在 15 字以内？公众号标题是否在 28 字以内？
- [ ] 是否包含具体数字或可感知的细节（避免空泛形容词）？
- [ ] 不同风格的标题之间是否有明显差异化（避免同一句式换词）？
- [ ] 扎心风是否有「代入感」而非「说教感」？
- [ ] 引流风是否有「信息增量」而非「标题党」？
- [ ] 反问风是否有「认知冲突」而非「为问而问」？
- [ ] 每个标题是否都能在原文/视频中找到支撑内容（避免夸大失实）？

## 高级技巧

### 标题情绪强度分级

生成时根据内容调性选择情绪强度：

- **轻度**（适合理性干货）：用数据和逻辑驱动
- **中度**（适合观点输出）：用对比和认知冲突驱动
- **重度**（适合情绪共鸣）：用场景和身份代入驱动

### A/B 测试建议

如用户需要测试，为每个风格额外产出 2 个「变体」：改变数字、变换句式、更换情绪强度，方便用户做 A/B 测试。
