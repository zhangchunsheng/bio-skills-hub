# 医院制剂与新药转化的关系

## 目标

将“医院制剂与新药转化”的宽泛命题压缩为可由医院制剂注册或备案资料检验的研究假设。输出必须包含量化变量、明确分析单位、可执行设计和边界条件；避免将不能从现有资料获得的临床疗效、销售额或上市结局写入主结局。

## 触发场景

在出现下列任一需求时使用本技能：

- 要求生成医院制剂与新药转化相关的研究假设、PICO、国自然式研究方案或标书方法学段落。
- 已明确可获取资料为医院制剂注册资料、备案资料、工艺质量资料或可归档的转化资料。
- 要求识别临床价值、人用经验、质量一致性、注册准备度、真实世界证据或成果转化之间的可检验关系。

## 核心边界

1. 将研究性质界定为“注册资料驱动的品种级资料审查”，除非用户明确可获得病历、随访、企业或监管审批数据。
2. 固定分析单位为“1个医院制剂品种”，而非患者、处方或医院；仅在资料结构支持时改动。
3. 把结局写为能得出数字的评分、比例、时间或事件，不使用“转化潜力高”“促进转化”等不可测表述。
4. 区分“转化申报准备度”与“实际获批/上市”：仅有注册资料时，主结局只能是前者。
5. 不把同一资料条目同时计入暴露、机制和结局；建立互斥评分条目，避免机械相关。
6. 不能从资料中提取的变量，不得以主变量身份进入PICO；必要时列为未来扩展数据源。
7. 不将横断面资料审查解释为严格因果；用“关联路径”“中介路径”表述。只有具备可靠事件日期时，才使用时间因果语言。

## 标准工作流

### 第1步：锁定数据能力

先提取并确认以下事实：

- 资料范围：注册/备案资料、质量资料、工艺资料、病历、随访、转化节点日期、专利或院企协议中哪些实际可调阅。
- 时间范围：资料审查截止日，以及纳入的批准/备案年份。
- 研究对象：中药、化学药或全部医院制剂；有效批准文号或备案状态的定义。
- 样本量：可完整调阅的品种数。

若用户只说明“医院制剂注册资料”，默认采用本技能的注册资料型方案；不得追问已能合理假定的细节。

### 第2步：将空白转换为变量链

默认使用以下三类空白，并根据用户提供内容替换或细化：

| 空白类别 | 可检验缺口 | 对应变量 |
|---|---|---|
| 证据空白 | 缺少注册资料要素与转化准备度的量化关联 | X、Z |
| 方法学空白 | 缺少资料完整性、证据链质量和准备度的独立量表 | X、Y、Z |
| 管理空白 | 缺少可用于优先转化品种排序的工具 | Z及排序输出 |

默认机制链：

```text
注册资料完整性（X） → 可追溯证据链质量（Y） → 新药转化申报准备度（Z）
```

### 第3步：写死PICO

默认PICO定义如下；只有在用户拥有额外数据时才扩展。

| 要素 | 固定定义 | 默认量化方式 |
|---|---|---|
| P | 本院有效批准或备案且注册资料可完整调阅的医院制剂，以一个制剂品种为一个分析单位 | 连续纳入满足条件的所有品种 |
| I/X | 注册资料完整性评分≥80分 | 0–100分连续评分；同时按80分分组 |
| C | 注册资料完整性评分<80分 | 同一评分量表 |
| O/Z | 新药转化申报准备度评分 | 0–100分，分数越高准备度越高 |
| Y | 可追溯证据链质量评分 | 0–100分，作为中介变量 |

#### 评分条目设计

X：注册资料完整性，建议10项、每项10分：

1. 立题依据；2. 处方来源与演变；3. 原辅料标准；4. 工艺验证；5. 质量标准；6. 稳定性；7. 临床使用记录；8. 安全性记录；9. 有效期依据；10. 注册/备案文件。

Y：可追溯证据链质量，建议10项、每项10分：

1. 病例可回溯比例；2. 病例纳排标准明确率；3. 干预暴露记录完整率；4. 主要结局可计算率；5. 不良反应记录率；6. 批号与病例关联率；7. 处方版本与病例关联率；8. 工艺版本留痕率；9. 缺失数据比例反向计分；10. 随访时间窗一致率。

Z：新药转化申报准备度，建议10项、每项10分：

1. 明确目标适应证；2. 临床定位文件；3. 处方稳定性论证；4. 可放大生产方案；5. 关键质量属性界定；6. 三批及以上质量一致性资料；7. 可追溯人用经验数据库；8. 预设临床评价方案；9. 知识产权状态文件；10. 注册沟通或转化立项文件。

**执行互斥检查：** 若某一评分条目同时出现在X、Y、Z中，删除重复或重新定义条目，直至三组评分不存在重复计分。

### 第4步：生成核心假设

用一句话且严格套用以下句式：

> 医院制剂注册资料完整性通过提升可追溯证据链质量影响新药转化申报准备度。

禁止使用“探讨”“研究”“了解”“分析”“具有重要意义”“值得深入研究”。

可附加可检验方向句：

> 注册资料完整性评分每提高10分，可追溯证据链质量评分和新药转化申报准备度评分同步升高。

### 第5步：选择研究设计

#### 首选

选择“单中心回顾性横断面注册资料审查 + 中介路径分析”。

说明理由时必须扣住数据条件：

- 注册资料可以直接形成品种级变量；
- 不需要患者招募或干预分配；
- 能输出资料缺口及优先转化排序；
- 可检验X→Y→Z的关联路径。

默认模型：

```text
Z = β0 + β1X + β2制剂类别 + β3剂型 + β4批准年份
    + β5委托配制 + β6专科使用记录 + ε

Y = α0 + α1X + 协变量 + ε
Z = γ0 + γ1X + γ2Y + 协变量 + ε
```

用5000次Bootstrap计算间接效应的95%CI；间接效应为 α1×γ2。

#### 备选

仅在存在可靠“转化立项/注册沟通/申报资料提交”日期时，选择回顾性纵向档案队列，以“至首次转化事件的时间”为结局，并使用Cox比例风险回归。

### 第6步：输出五段式问题陈述

按以下顺序，每段1–2句：

1. 临床现象：写院内品种多、真正进入新药开发序列少，以及注册资料或证据资料分散的事实。
2. 已有研究：写人用经验、真实世界证据、质量标准化、药学变更与全生命周期管理已被提出。
3. 研究空白：写缺少以注册卷宗为基础的品种级量化验证，无法识别资料缺口与优先级。
4. 本研究做什么：写建立X、Y、Z三套独立量表，并用横断面资料审查及中介模型验证路径。
5. 预期回答什么：写每提高10分X对应Y、Z的变化值、关键缺口和优先排序清单。

### 第7步：执行自查

必须逐条报告以下判断：

| 维度 | 强的标准 | 弱时的直接改法 |
|---|---|---|
| 方向性 | X通过Y影响Z，方向单一 | 删除“相关”“可能”；改为“X通过Y影响Z” |
| 可检验性 | X/Y/Z均能得分、比例、时间或事件 | 把抽象结局换成0–100分或明确事件 |
| 机制性 | Y是独立、可观测的中间变量 | 将与X或Z重复的条目移出Y；重建互斥量表 |
| 具体性 | 对象、单位、阈值、评分和协变量明确 | 写明品种、≥80分、0–100分及资料截止日 |
| 数据适配性 | 每项变量都能从已说明资料提取 | 删除无法提取字段，或明确新增数据源 |
| 因果解释 | 纵向日期完整时可较强 | 横断面时改称关联路径，不写导致或决定 |
| 样本量 | 每个模型参数约需10–15个品种 | 样本<50时减少协变量；样本<30时仅做描述和排序 |

## 最终输出格式

按以下五块输出，保持中文、简洁、可直接用于标书：

1. PICO四要素表格；
2. 一句核心假设；
3. 首选设计、理由、备选设计和统计模型；
4. 五段式研究问题陈述；
5. 自查清单和直接改法。
