# dy运营 — 老吴信息流工具箱

## 一句话简介

专为白癜风/皮肤科信息流推广打造的短视频运营工具箱，内置脚本生成、钩子优化、爆款对标、合规检查、内容诊断六大模块，以老陈IP为核心人设，一条命令出脚本。

---

## 为什么需要这个Skill

信息流推广每天面临三个核心卡点：

1. **写脚本耗时间** — 一天憋不出三条口播，每条都要从零想结构
2. **过审靠运气** — 医疗口播动不动被限流/下架，违禁词记不住
3. **不知道竞品怎么打的** — 看到爆款不知道怎么拆解、怎么复用

dy运营把这些问题固化为六个可复用模块，输入平台+时长+类型，直接出脚本。

---

## 六大模块

| 模块 | 触发命令 | 能力 |
|------|---------|------|
| 脚本生成 | `/dy-script` | 输入母版（A-H）+平台+时长，产出五段式合规口播 |
| 钩子优化 | `/dy-hook` | 三方法（素材提取/素材增补/悬念制造）生成10-15条备选钩子 |
| 爆款对标 | `/dy-benchmark` | 五重过滤法拆解竞品账号，输出模仿颗粒度报告 |
| 合规检查 | `/dy-compliance` | 逐句扫描40+组违禁词，四类检测+强制免责声明 |
| 内容诊断 | `/dy-content` | 五维诊断（钩子/论证/人设/干货/CTA），权重打分+优化方向 |
| 主路由 | `/dy` | 不知道用哪个？入口自动路由+任务后导航 |

## 核心特色

### 8套母版（A-H），一键出脚本
从50篇白癜风爆款反推的结构化模板，每套含钩子×3+论证×3+CTA×3，覆盖科普引流/焦虑转化/信任建立/硬广转化四大场景。

### 老陈IP话术锁定
亲和中年医师人设固化为话术矩阵——开场白、信任锚、干货切换、共情回应、CTA引导——每条脚本读起来就像老陈本人在说话。

### 合规闸门零容忍
断根/根治/永不复发/神医/专治——40+组违禁词逐句扫描，命中即不交付，从源头避免限流/下架。

### 对标到词句级别
不是"大概看看"，拆解到"这个词为什么用「反复」而不是「复发」"这种颗粒度。

## 适用场景

- 需要为白斑/皮肤科产出每日口播脚本的信息流运营
- 需要确保医疗内容通过抖音/快手/视频号/广点通过审
- 需要拆解竞品打法、快速对齐模仿颗粒度
- 已有脚本但需要系统性诊断哪里有问题

## 支持的平台

| 平台 | 适配要点 |
|------|---------|
| 抖音 | 医疗限流最严，CTA引导至评论区/私信 |
| 快手 | 老铁风格更亲和，CTA可直接一些 |
| 视频号 | 中老年用户为主，信任段落略长，CTA用私信/关注 |
| 广点通 | 信息流广告场景，钩子更强，时长30-60s |

## 快速上手

```
/dy-script           # 生成一条口播脚本（默认科普引流+抖音+60s）
/dy-script 焦虑转化   # 生成焦虑转化型脚本
/dy-compliance       # 扫描脚本合规风险
/dy-hook             # 优化钩子，出10-15条备选
/dy-benchmark        # 拆解一个对标账号
/dy                  # 迷路了随时回来
```
