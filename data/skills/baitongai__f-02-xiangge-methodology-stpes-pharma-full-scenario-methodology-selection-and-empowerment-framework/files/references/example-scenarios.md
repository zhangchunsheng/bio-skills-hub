## 示例一：创新药 KOL 教育PPT

**用户输入**：
> "我是医学经理小王，要给KOL准备一个关于我们新药的心血管保护机制的PPT"

### S — 场景扫描与职能画像
- 使用者职能：医学部 | 核心KPI：证据等级、KOL认同度
- 产品成熟度：创新产品（FIC/新机制）
- 任务确定性：探索性任务（新机制教育）
- 合规敏感度：高（超适应症风险）
- 场景判断：创新药KOL教育，需在科学严谨与突破性叙事间平衡

### T — 目标锚定与价值定义
- 效率vs效果：效果（改变主任观念）
- 专家级目标："通过多层证据链展示新药心血管保护机制，使KOL理解该机制的临床获益转化路径，并愿意在合适患者中考虑使用，同时确保所有声明不超适应症。"
- 成功标准：KOL能复述机制要点≥3个 + PPT所有声明均有证据支撑

### P — 原理匹配与动态加权

推荐方法论组合：
1. **GRADE证据分级** — 搭建证据塔 — 高约束
2. **ZMET隐喻诱发** — 挖掘主任对"心血管保护"的潜意识期待 — 中约束
3. **米尔顿模式（学术修辞版）** — 软化语言，避免直接断言 — 中约束
4. **AIDA模型** — 注意-兴趣-欲望-行动的内容结构 — 低约束

动态权重逻辑：以GRADE为刚性骨架，ZMET+米尔顿为弹性血肉，AIDA为探索性外衣

WSR校验：
- 物理：通过 — 所有机制声明需有RCT/RWS数据支撑（Level A/B）
- 事理：通过 — PPT逻辑链：机制→证据→获益→适用人群→安全使用
- 人理：注意 — 需预判主任的"防御性怀疑"心理——新机制容易引发质疑，需设计"先共情后引导"的话术路径

### E — STEPS 2.0 执行指令
```
S: 你是一位资深医学联络官（MSL），精通心血管领域新药机制教育。
   负责通过GRADE证据分级框架与ZMET隐喻洞察，完成新药心血管保护机制
   KOL教育PPT的内容架构设计，以达成KOL观念转变与合理处方意愿提升。

T:
  1. 梳理新药心血管保护机制的核心科学逻辑链（机制→通路→效应→获益）
  2. 按GRADE分级搭建证据塔：Level A（RCT）→ Level B（RWS）→ Level C（共识）
  3. 设计KOL认知冲突点：识别主任现有认知与新机制之间的张力
  4. 用学术修辞（非催眠版米尔顿模式）设计"软化引导"话术
  5. 按AIDA结构组织PPT内容流：注意（机制新在哪）→兴趣（证据多硬）→欲望（患者获益）→行动（如何用）
  6. 信息缺口声明：若某亚组数据不全，必须标注"数据待补充"，严禁编造
  7. 生成合规自查清单：逐条核对是否超适应症、是否有绝对化断言

E:
  - 硬规则：①所有疗效声明必须有GRADE B级以上证据支撑
           ②严禁超适应症表述
           ③严禁"最""第一""唯一"等绝对化用语（广告法第9条）
           ④违反以上任一条=重新生成
  - 软规则：①ZMET洞察为辅助参考，不作为直接内容输出
           ②米尔顿模式降维为"学术修辞学"，核心是"引导思考"而非"植入观念"
           ③偏离时需标注理由

P:
  - 产品：[新药名称]（心血管保护机制）
  - 竞品参照：[同类机制竞品]
  - 目标KOL：三甲医院心内科主任级，学术型，对创新机制持审慎乐观态度
  - 证据偏好：Level A优先，Level B补充，Level C仅作背景
  - 数据源优先级：PubMed > Cochrane > CNKI > 内部数据
  - 合规红线：不超适应症、不对比贬低、不绝对化断言

S:
  输出PPT内容架构（每页标题+核心论点+证据等级标注+话术建议）
  + 合规自查清单
  + 自我审查模块：
    - 信心指数：[高/中/低] — 对KOL观念转变效果的置信度
    - 弱点识别：[分析中最薄弱的环节]
    - 替代视角：[如果主任质疑机制，应如何回应]
```

### S — 标准化与协同建议
- 资产沉淀建议：值得封装为 `medical-kol-edu-ppt` Skill
- 跨部门对齐：市场部共用同一证据链标准，避免市场部物料与医学部PPT口径不一致
- 复盘节奏：每次KOL会议后更新主任认知画像，季度回顾PPT效果

## 示例二：成熟产品竞品阻击策略

**用户输入**：
> "我们的成熟降压药面临仿制药集采冲击，需要制定竞品阻击策略"

### S — 场景扫描与职能画像
- 使用者职能：市场部 | 核心KPI：市场份额保卫、品牌韧性
- 产品成熟度：成熟产品（集采品种）
- 任务确定性：半确定性（市场格局可分析但对手策略不确定）
- 合规敏感度：中（不能直接对比贬低）
- 场景判断：成熟品种防守战，重证据、重客情、重差异化叙事

### T — 目标锚定与价值定义
- 效率vs效果：效果（守住份额）
- 专家级目标："识别仿制药A在未来12个月内对我品在核心区域市场份额的三大威胁路径，针对每条路径设计差异化阻断策略，每条策略需标注预期份额保卫幅度与执行成本。"
- 成功标准：策略覆盖三大威胁路径 + 每条策略有量化预期 + 合规通过率100%

### P — 原理匹配与动态加权

推荐方法论组合：
1. **波特五力** — 分析竞争结构变化（买方议价力↑） — 中约束
2. **SWOT** — 我品vs仿制药的优劣势对比 — 中约束
3. **客户决策中心(DMU)** — 分析处方决策链中的关键影响者 — 中约束
4. **80/20法则** — 聚焦关键客户与关键区域 — 低约束

动态权重逻辑：波特五力+SWOT为分析骨架，DMU为精准打击工具，80/20为资源分配指南

WSR校验：
- 物理：通过 — 需核实集采中标价格、份额数据来源
- 事理：通过 — 阻击策略需形成"识别威胁→锁定节点→差异化打击→效果监测"闭环
- 人理：注意 — 处方医生对仿制药的信任度因人而异，需分层设计话术

### E — STEPS 2.0 执行指令
```
S: 你是一位资深产品经理，精通成熟产品生命周期管理与竞争防御策略。
   负责通过波特五力+SWOT+DMU框架，完成集采冲击下的竞品阻击策略制定，
   以达成核心区域市场份额保卫目标。

T:
  1. 用波特五力分析集采后竞争结构变化（买方议价力、替代品威胁、新进入者）
  2. 用SWOT梳理我品相对仿制药的核心优势（原研品质、医生信任、患者依从）
  3. 用DMU分析处方决策链：识别关键决策者（主任）、影响者（药师/医保办）、执行者（处方医生）
  4. 用80/20法则识别：哪些科室/医生/区域贡献了80%的销量流失风险
  5. 针对三大威胁路径设计差异化阻断策略（品质叙事/客情加固/患者粘性）
  6. 每条策略标注预期份额保卫幅度与执行成本
  7. 生成合规自查：确保不直接对比贬低、不使用绝对化断言

E:
  - 硬规则：①不得直接对比贬低竞品（反不正当竞争法第11条）
           ②市场份额数据需标注来源与时间
           ③违反=重新生成
  - 软规则：①SWOT分析需附量化数据支撑
           ②DMU角色分析需标注信息来源（CRM/访谈/推断）
           ③策略预期效果为模拟测算，需标注"模拟值"标签

P:
  - 产品：[成熟降压药名称]
  - 竞品：[仿制药A]
  - 区域：[核心区域]
  - 时间周期：未来12个月
  - 数据源：内部CRM + 各省招采平台 + 行业报告
  - 合规红线：不对比贬低、不绝对化断言、不暗示仿制药不安全

S:
  输出竞品阻击策略报告（威胁路径分析+差异化策略矩阵+预期效果量化表）
  + 合规自查清单
  + 自我审查模块
```

### S — 标准化与协同建议
- 资产沉淀建议：值得封装为 `market-defense-strategy` Skill
- 跨部门对齐：推广部共用DMU画像，销售部共用客户分级标准
- 复盘节奏：月度跟踪份额变化，季度调整策略权重

## 示例三：医保谈判准入策略

**用户输入**：
> "我们的创新药要参加国家医保谈判，需要制定准入策略"

### S — 场景扫描与职能画像
- 使用者职能：准入部 | 核心KPI：医保谈判成功率、支付价
- 产品成熟度：创新产品（FIC/罕见病）
- 任务确定性：确定性任务（谈判规则明确）
- 合规敏感度：高（涉及价格保密、反垄断）
- 场景判断：创新药国谈准入，重证据、重价值论证、重博弈策略

### T — 目标锚定与价值定义
- 效率vs效果：效果（以合理价格准入）
- 专家级目标："通过HEOR价值论证与竞品价格锚定，推演首次谈判降幅区间，设计8分钟陈述逻辑链与压价应对话术，以达成以[目标支付价]准入国家医保目录。"
- 成功标准：降幅在可接受区间内 + 谈判陈述逻辑完整 + 压价应对有≥3套预案

### P — 原理匹配与动态加权

推荐方法论组合：
1. **HEOR框架** — CEA/CUA/BIA价值论证 — 高约束
2. **PESTEL** — 政策环境分析 — 高约束
3. **波特五力（买方议价力）** — 医保局博弈分析 — 中约束
4. **SCQA** — 8分钟陈述叙事结构 — 低约束

动态权重逻辑：HEOR+PESTEL为刚性价值锚，波特五力为博弈推演工具，SCQA为表达外衣

WSR校验：
- 物理：通过 — CEA数据需有发表研究支撑，BIA需对齐医保局填报要求
- 事理：通过 — 价值论证→价格推演→陈述设计→压价应对，形成完整闭环
- 人理：注意 — 医保局谈判专家关注"性价比"而非"创新性"，需调整叙事重心

### E — STEPS 2.0 执行指令
```
S: 你是一位资深医保准入经理，精通HEOR价值论证与国家医保谈判策略。
   负责通过HEOR框架与博弈分析，完成创新药国谈准入策略制定，
   以达成以合理支付价纳入国家医保目录。

T:
  1. 用PESTEL分析当前医保政策环境（目录调整规则、支付标准、谈判周期）
  2. 用HEOR框架搭建价值论证塔：
     - CEA：成本效果比（vs 现有标准治疗）
     - CUA：质量调整生命年（QALY测算）
     - BIA：预算影响分析（对医保基金的影响）
  3. 锚定竞品价格：识别"邻居品种"（同ATC编码/同适应症），建立价格参照系
  4. 推演首次谈判降幅区间（基于历史谈判数据+竞品价格+价值评分）
  5. 设计8分钟陈述逻辑链（SCQA结构）：
     S(情境)→C(冲突:未满足需求)→Q(问题:本药如何解决)→A(答案:价值证据)
  6. 设计压价应对话术（3套预案：温和降幅/中度降幅/底线降幅）
  7. 生成合规自查：确保价格数据不外泄、不涉及反垄断敏感信息

E:
  - 硬规则：①CEA/CUA/BIA数据需有发表研究或内部研究支撑
           ②价格信息标注"保密"
           ③对标中国HEOR专家共识（3x人均GDP阈值）
           ④违反=重新生成
  - 软规则：①博弈分析为推演性质，需标注置信度
           ②降幅区间为模拟测算
           ③谈判话术需经内部审核后使用

P:
  - 产品：[创新药名称]
  - 适应症：[目标适应症]
  - 竞品参照：[同领域已纳入医保品种]
  - 阈值参考：中国3x人均GDP
  - 数据源：PubMed（疗效）+ 医保局公开数据 + 内部HEOR研究
  - 合规红线：价格保密、不涉及反垄断

S:
  输出国谈准入策略报告（价值论证塔+价格推演+陈述逻辑链+压价应对预案）
  + 合规自查清单
  + 自我审查模块
```

### S — 标准化与协同建议
- 资产沉淀建议：值得封装为 `access-negotiation-strategy` Skill
- 跨部门对齐：市场部共用价值论证框架（确保品牌叙事与谈判口径一致），商务部共用价格策略
- 复盘节奏：谈判后立即复盘，提取经验更新Skill参数
