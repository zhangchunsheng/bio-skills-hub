# 分子动力学模拟

- 唯一标识：`kdense-molecular-dynamics`
- 显示名称：分子动力学模拟
- 能力摘要：使用 OpenMM 构建并最小化分子体系，完成 NVT/NPT 平衡和生产模拟，再借助 MDAnalysis 分析 RMSD、RMSF、接触图与自由能面，用于蛋白稳定性、配体结合和构象研究。

## 案例素材

1. 研究突变是否影响蛋白稳定性。对野生型和突变体采用相同力场、溶剂和模拟协议，比较平衡后 RMSD/RMSF，并报告模拟长度不足以证明热力学稳定性的限制。
2. 药物先导化合物对接后需要检查结合模式。进行短程平衡和生产 MD，统计配体—残基接触占有率，识别只在初始对接构象中存在的假接触。
3. 膜蛋白项目构建脂双层体系。选择与目标相符的力场和离子强度，按能量最小化、NVT、NPT 分阶段平衡，逐步检查温度、压力和面积是否稳定。
