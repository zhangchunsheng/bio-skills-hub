# 大V拆解（Dà V Chāijiě）

## 这是什么

「大V拆解」把一位有公众影响力的内容创作者，从「一堆零散的视频 / 文章 / 语录」提炼成一套**可检索、可传播、可学习的结构化人格图谱**。

核心不是搬运金句，而是还原其 **「认知操作系统」**：
- 他靠哪几个**心智模型**看世界？
- 用哪套**黑话**建立圈层认同？
- 靠哪几句**标志性表达**形成记忆点？
- 用哪些**真实案例**完成说服？

产出物：一份**自包含的单文件 HTML 档案**（含目录导航、CSS 可视化、可一键部署到 CloudStudio 获得在线访问地址）。参照范例：《峰哥浪迹天涯·情感哲学体系与语录大全》。

## 何时使用
- 用户点名要拆某位大V / KOL / 网红 / UP主 / 博主 / 主播（情感、财经、商业、科技、职场、AI、知识区等均可）
- 用户想系统化整理某人的观点、语录、方法论
- 用户想学习某人的表达框架、内容套路、说服逻辑

## 工作流（必须按序执行）

### 阶段 0 · 确认对象与边界
向用户确认（若用户已给足信息可跳过）：
1. 拆解对象是谁（姓名 / 网名 / 平台账号）
2. 所属领域（情感 / 财经 / 科技 / 商业 / 职场 / 其他）
3. 重点关注什么（全貌 / 只拆观点体系 / 只拆表达套路 / 只拆黑话）
4. **当前状态**——是否停更、封禁、去世等，需如实标注（参照峰哥档案的「重要背景」提示）

### 阶段 1 · 资料采集
按领域选择信源，**至少覆盖 3 类**，保证可溯源：
- **视频 / 直播**：B站、抖音、YouTube 实录文字稿、字幕稿
- **文章 / 访谈**：公众号、知乎、头条、36氪、虎嗅、晚点、人物专访
- **第三方整理**：GitHub 语录库、百科 / 维基、公开报道、粉丝整理的合集
- **争议侧**：搜索「XX 翻车 / 争议 / 封禁 / 反驳 / 批判」以获得平衡视角
- 工具：`WebSearch`（多关键词组合，中英文都搜）、`WebFetch`（抓取长文 / 访谈原文）
- 若对象属 AI 圈，可先调用 `aihot` skill 拉取近期资讯

> **关键纪律**：每条语录务必标注出处语境（直播间 / 某篇文章 / 某次连线），**不要编造**。无法核实的内容标「（待核实）」。

### 阶段 2 · 按框架提炼十大维度
严格按下方「拆解框架」十个模块产出内容（可据对象特点微调标题，但结构不丢）。

### 阶段 3 · 生成 HTML 档案
复制 `references/archive_template.html`，将占位符替换为提炼内容，按模块填充。
保持：**单文件、内联 CSS、无外部依赖**（图表用 CSS 实现），确保可直接在浏览器打开、可部署上线。

### 阶段 4 ·（可选）部署上线
若用户要在线访问地址，用 `workbuddy_cloudstudio_deploy` 部署到 CloudStudio，返回访问 URL。

## 拆解框架（十大模块）

1. **人物画像**：本名 / 年龄 / 籍贯、职业轨迹、走红关键节点、代表平台与账号、当前状态（在播 / 停更 / 封禁）、一句定性。
2. **认知操作系统总览（心智模型地图）**：提炼 3–8 个核心心智模型，用「一句话 + 一句作用说明」画成总导图（模板用卡片网格表达）。
3. **核心心智模型详解**：每个模型展开——一句话定义、核心逻辑（输入 → 处理 → 输出）、典型案例、⚠️ 局限 / 副作用。
4. **黑话体系与术语图谱**：列出其独创 / 高频词汇表（词条 + 释义），这是圈层识别符。
5. **标志性表达 DNA**：高频口头禅 / 句式（如「这是个好事儿啊」），标注其出现的语境信号。
6. **语录分类大全（核心）**：按主题归类（爱情 / 婚姻 / 择偶 / 人性 / 行业洞察…），每条带出处。这是档案主体。
7. **经典案例实录**：真实互动 / 连线 / 名场面，用「案例 + 他的拆解逻辑」结构呈现，体现说服力来源。
8. **金句 TOP N 与主题分布**：精选 TOP 30（或用户指定数量）必读金句，配 CSS 条形图展示各主题占比。
9. **理论体系逻辑图**：用竖向流程图串起「观察起点 → 归因 → 解药 → 社会映射 → 方法论底座」的逻辑闭环。
10. **人生时间线 + 争议、局限与结语**：关键年份事件轴；客观列争议点、方法论盲区；以中性结语收尾，并附「素材截止日期与免责声明」。

## 质量红线
- **不神化、不抹黑**：如实标注局限与争议（模板每个心智模型都带 ⚠️）。
- **不编造语录**：每条可溯源；无法核实的标「（待核实）」。
- **注明素材截止时间与账号状态**（封禁 / 停更），避免误导为当下立场。
- 涉及敏感 / 政治内容时，按合规要求处理，不触碰红线。

## 提示：产出节奏建议
- 先用 TaskCreate 把「采集 → 提炼十维度 → 写 HTML → 部署」拆成任务，逐步推进并标记状态。
- 语录量大时，用 Python 脚本把「数据（列表 / 字典）」渲染成 HTML，避免手写长 HTML 出错（见下方示例脚本结构）。
- 模板中所有 `{{占位符}}` 与 `<!-- 提示 -->` 注释在最终产出中删除。

用户：「拆解一下 峰哥浪迹天涯」
→ 产出即本技能所参照的《峰哥浪迹天涯·情感哲学体系与语录大全》结构（情感领域范例）。
