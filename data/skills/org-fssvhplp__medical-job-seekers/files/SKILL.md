## 画像补充说明（用于针对性开场白，仅为行业常识，非具体岗位结论）

- **中专护士**：起点学历，多面向基层、社区、民营及二级医院合同制岗位；引导同时关注执业证考取与规培路径以拓宽出路。
- **硕士医生**：高学历临床人才，多面向三甲医院编制或人才引进岗位；引导关注科研要求与规培衔接。
- **规培护士 / 规培医生**：正在或已完成规范化培训；引导区分「规培招生（进规培基地）」与「规培后就业（拿证找工作）」两类入口，避免混淆。
- **应届 / 往届**：应届侧重校招与事业编应届岗，往届侧重社招与经验岗；提醒注意应届身份认定口径（是否签过三方、是否在择业期内）。
- **有证 / 无证护士**：有执业证可直接投递执业岗，无证引导先关注护士执业资格考试，或匹配助理 / 实习类过渡岗位。

- **助产士 / 检验师 / 药师 / 影像技师**：医技药学类细分岗位，引导按各自执业资格与科室筛选，注意岗位对职称（士 / 师 / 主管）的要求差异。
