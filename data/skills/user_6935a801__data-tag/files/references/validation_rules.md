# 数据标注校验规则参考

## 标注方式说明

校验完成后，**不新增任何列**，直接在结果字段的 cell 上进行标注：

### 颜色标注规则

| 校验结果 | 结果字段 cell 颜色 | 结果字段 cell 批注 | 说明 |
|---------|------------------|------------------|------|
| 准确 | 无特殊颜色 | 无批注 | 正确标注，无需特别关注 |
| 错误 | 红色背景（#FF4444）+ 白色加粗字体 | 添加批注，说明错误原因及正确答案 | 明确错误，需修正 |
| 待确认 | 黄色背景（#FFD966）+ 加粗字体 | 添加批注，说明不确定原因 | 存在歧义，需人工复核 |

**标注范围**：
- 仅对结果字段列的 cell 进行颜色标注和添加批注
- 不新增"校验结果"列或"批示"列
- 批注以 Excel Comment 形式附加在 cell 上，鼠标悬停即可查看

### 批注撰写规范

批注内容直接附加在结果字段的 cell 上，用户在 Excel 中鼠标悬停即可查看。

1. **具体性**：引用数据字段中的具体值作为依据，避免笼统描述
2. **可追溯性**：指明判断依据来自哪些数据字段
3. **简洁性**：用一句话概括判定原因，避免冗长解释
4. **建设性**：对于"错误"的判定，在批注中给出正确答案或修正建议

**批注格式**：
- 错误："[数据字段关键信息]，结果字段标注为[值]，实际应为[正确值]，判定错误"
- 待确认："[原因说明]，需进一步确认"

**批注示例**：
- 错误批注："净利润为 -500 万元，标注为'盈利'，实际应为'亏损'，判定错误"
- 待确认批注："行业分类为'综合'，标注为'科技'，但综合类企业可能涉及科技业务，需进一步确认"

## 校验判定标准

### ⚠️ 核心原则：宁宽勿严

**判定"错误"的门槛应该非常高**。只有当你 **高度确信（>80%）** 标注是错的，才判定为"错误"。其他所有不确定的情况，一律判为"待确认"。

理由：误判"错误"（把正确的标注判成错误）的代价远大于漏检（把错误的标注判成"待确认"让人工复核）。

### 判定为"准确"的条件

结果字段的值满足以下任一条件：
1. 与数据字段推断出的预期结果完全一致
2. 与预期结果**语义等价**（表述不同但含义相同，如"盈利"="有利润"="赚钱"）
3. 在合理范围内与预期结果一致（如数值误差在可接受范围内）
4. 属于数据字段支持的多种正确答案之一（如分类标注中多个类别均可接受）
5. 在实际标签体系下是合理的归类（即使你个人会选择不同的标签）

### 判定为"错误"的条件

结果字段的值**必须同时满足以下全部条件**：
1. 与数据字段推断出的预期结果明显矛盾
2. 已经做过复核（重新阅读原文、考虑语义等价、考虑标签体系差异）
3. 复核后仍然确认无法找到任何合理解释
4. 确信度 >80%

单独满足以下某一条也可判定为"错误"：
- 结果字段的值格式完全不正确（如应为数字却填入无关文字）
- 结果字段的值与数据字段形成逻辑悖论（如"收入 100 万"标注为"无收入"）

### 判定为"待确认"的条件

结果字段的值满足以下任一条件：
1. 结果字段为空值或缺失
2. 数据字段信息不足以唯一确定结果
3. 结果字段的值存在歧义，可能有多种合理解释
4. 数据字段本身存在矛盾或不一致
5. **你的判断和标注不一致，但你不能 100% 确信标注是错的**
6. 数据字段包含噪声（错别字、口语化、转写错误等），影响了你对真实意图的判断
7. 标注的标签不在你的预期范围内，但可能是标签体系定义不同导致的

## 常见校验场景

### 场景一：分类标注校验

数据字段提供描述性信息，结果字段为分类标签。

**校验方法**：
- 先从全量数据中统计所有出现过的分类标签，理解标签体系
- 根据数据字段的描述，判断结果字段的分类标签是否合理
- 若分类标签与描述明显不符（>80% 确信），判定为"错误"
- 若描述模糊可对应多个分类，判定为"待确认"
- **注意**：不同标签体系的粒度可能不同，要用实际标签体系判断，不要自造标签

### 场景二：数值计算校验

数据字段提供原始数值，结果字段为计算或判断结果。

**校验方法**：
- 根据数据字段的数值，重新计算或判断结果
- 若结果字段与重新计算的结果一致，判定为"准确"
- 若存在计算误差，根据误差范围判定（误差 ≤ 5% 可视为准确，5%-10% 视为待确认，>10% 视为错误）

### 场景三：情感/倾向标注校验

数据字段提供文本内容，结果字段为情感或倾向标注（如正面/负面/中性）。

**校验方法**：
- 重新分析数据字段的文本情感
- 若情感判断与结果字段一致，判定为"准确"
- 情感分析具有主观性，对于中性偏正面/中性的边界情况，判定为"待确认"
- **注意**：反讽、双关、隐含情感容易误判，遇到不确定的一律标"待确认"

### 场景四：实体识别标注校验

数据字段提供文本内容，结果字段为识别出的实体。

**校验方法**：
- 检查结果字段中的实体是否确实存在于数据字段的文本中
- 检查实体类型标注是否正确
- 若实体不存在或类型错误，判定为"错误"

### 场景五：语音转写文本校验（重要）

数据字段为语音识别/ASR 转写的文本，结果字段为基于语音内容的标注。

**⚠️ 此场景需要特殊处理策略**：

**语音转写文本的典型噪声**：
- 同音字/谐音替代："带款" → "贷款"，"信用卡" → "新用卡"
- 漏字/多字："我想…款" → "我想贷款"
- 标点缺失/混乱：整段文本没有标点，或标点位置错误
- 口语冗余："嗯…那个…就是说…我想问一下"
- 方言/口音影响："不晓得" → "不知道"
- 断句错误：语句被错误切分

**校验方法**：
1. **通读全文**，先还原说话人的真实意图，再做判断
2. **不要被字面的错别字/噪声干扰**——关注说话人想表达什么，而非 ASR 写出了什么
3. 如果转写质量很差导致你无法确定意图，标为"待确认"，不要猜测
4. 对于模糊/可多种理解的转写文本，倾向于认可原始标注（因为标注员可能听了原始音频）
5. **特别注意**：标注员在标注时可能听了原始音频，拥有比你更多的信息，所以当你基于转写文本的判断与标注不一致时，要考虑这个因素

### 场景六：多字段关联校验

多个数据字段共同决定结果字段的值。

**校验方法**：
- 综合所有数据字段的信息，不能只看其中一个字段就下结论
- 不同数据字段之间可能存在矛盾，此时标为"待确认"
- 如果某个数据字段为空/缺失，判断是否影响结论的可靠性

## 误判防护清单

在输出每一行的校验结果前，用以下清单自检：

- [ ] 我是否通读了数据字段的**完整内容**？（不是只看前几个字）
- [ ] 我的判断是基于**整体语义**还是**关键词匹配**？（应基于语义）
- [ ] 如果我判的是"错误"，我是否做了**复核**？（必须做）
- [ ] 如果数据是语音转写，我是否考虑了**转写噪声**？
- [ ] 我的预期标签是否在**实际标签集合**内？
- [ ] 我是否受到了前几行判定结果的**惯性影响**？（每行应独立判断）
- [ ] 如果不一致，我是否考虑了标注员可能拥有我没有的**额外信息**？
