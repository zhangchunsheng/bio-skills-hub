# 3D打印藏药缓释丸——虚拟演示案例

> ⚠️ **本案例为学术性/教育性虚拟演示，不构成实际药物制备方案。**
> 实际应用需由具备资质的机构在GMP条件下完成并经过系统研究。

## 案例选择：四味土木香散（Se 'bru bzhi pa）

### 方剂背景
四味土木香散为藏医经典方剂，由土木香（Inula helenium L.）、苦参（Sophora flavescens）、珍珠杆（杆形珍珠莲）、山柰（Kaempferia galanga L.）四味药材组成。传统用于感冒、发热、头痛。选择本方作为3D打印案例的原因：
1. 成分明确，药味数量适中（4味），便于分室打印
2. 含挥发性成分（土木香内酯、山柰酚），需低温保护→适合SSE工艺
3. 传统为散剂，3D打印可转化为缓释制剂，改善用药便利性

## 技术选择：半固态挤出（SSE）

**选择理由：**
- 室温/低温操作，保护挥发性/热敏性成分（土木香内酯、山柰酚）
- 可构建多室结构，实现分味控释
- 设备成本相对较低，易于实验室搭建

## 配方设计

### 载药部分

| 组分 | 比例（w/w） | 前处理 |
|------|-----------|--------|
| 土木香提取物（含土木香内酯≥2%） | 10% | 乙醇渗漉提取，50℃减压浓缩，粉碎过100目 |
| 苦参提取物（含苦参碱≥5%） | 8% | 水提醇沉，干燥粉碎 |
| 珍珠杆细粉 | 5% | 粉碎过100目 |
| 山柰挥发油 β-CD包合物 | 5% | 饱和水溶液法制备，冷冻干燥 |

### 打印墨水基质（壳层——胃溶速释部分）

| 组分 | 比例（w/w） | 作用 |
|------|-----------|------|
| 明胶（200 Bloom） | 18% | 室温凝胶基质，胃溶速释 |
| 甘油 | 5% | 增塑剂，防止干燥开裂 |
| 纯化水 | 72% | 溶剂 |

**制法**：明胶加纯化水溶胀30min，60℃水浴溶解，加入甘油搅匀，冷却至35℃加入土木香提取物和山柰包合物，搅匀备用。

### 打印墨水基质（芯层——缓释部分）

| 组分 | 比例（w/w） | 作用 |
|------|-----------|------|
| 海藻酸钠 | 5% | 离子交联缓释骨架 |
| HPMC K4M | 3% | 亲水缓释基质 |
| 甘油 | 3% | 增塑剂 |
| 纯化水 | 89% | 溶剂 |

**制法**：海藻酸钠分散于水中溶胀过夜，加入HPMC搅拌至溶解，加入甘油搅匀，混入苦参提取物和珍珠杆粉，脱气泡备用。

## 打印参数设定

| 参数 | 壳层（速释） | 芯层（缓释） | 说明 |
|------|------------|------------|------|
| 喷嘴直径 | 0.4 mm | 0.4 mm | 统一直径，减少换嘴次数 |
| 打印气压 | 40 kPa | 50 kPa | 壳层黏度较低，气压略小 |
| 打印速度 | 10 mm/s | 8 mm/s | 芯层黏度较高，适当降速 |
| 层厚 | 0.25 mm | 0.2 mm | 壳层稍厚提高速释速率 |
| 平台温度 | 25℃ | 25℃ | 室温平台 |
| 打印头温度 | 30℃ | 25℃ | 壳层明胶需略加热 |

## 打印结构设计

### 芯-壳结构示意图

```
俯视图：                   剖面图：
┌──────────────────┐       ╔══════════════════╗
│  壳层（速释层）    │       ║  壳层（速释）      ║
│  ┌────────────┐  │       ║  ┌────────────┐  ║
│  │ 芯层（缓释层）│  │       ║  │ 芯层（缓释）  │  ║
│  │             │  │       ║  │             │  ║
│  └────────────┘  │       ║  └────────────┘  ║
└──────────────────┘       ╚══════════════════╝
                              ↑
                        先释放 → 壳层含土木香、山柰
                        后释放 → 芯层含苦参、珍珠杆
```

**设计理念：**
- **壳层（速释）**：含土木香提取物+山柰包合物，明胶基质。
  - 口服后胃液中15-30min崩解释放
  - 土木香内酯快速吸收，发挥抗炎解热作用
- **芯层（缓释）**：含苦参提取物+珍珠杆粉，海藻酸钠/HPMC交联骨架。
  - 口服后持续释放4-6小时
  - 苦参碱维持抗炎、抗过敏作用
  - 珍珠杆提供持续的解热效应

### 打印路径规划

```
第1-6层：壳层外围（2圈轮廓 + 20%填充）→ 形成外壳底座
第7-14层：芯层区域（2圈轮廓 + 60%填充）→ 在壳层内部打印
第15-20层：壳层顶盖（2圈轮廓 + 20%填充）→ 封闭顶部
```

## 后处理工艺

| 步骤 | 操作 | 参数 | 目的 |
|------|------|------|------|
| 1 交联固定 | 打印后立即浸入CaCl₂溶液 | 1.5% w/v, 10 min | 海藻酸钠交联形成凝胶骨架 |
| 2 清洗 | 纯化水漂洗表面 | 3次 | 除去表面CaCl₂ |
| 3 低温干燥 | 鼓风干燥箱 | 35℃, 4h | 去除大部分水分 |
| 4 平衡 | 干燥器（硅胶） | 25℃, 12h | 水分平衡至稳定含水量 |

**特征参数（预期）：**
- 壳层：15min释放 ≥ 70%，30min释放 ≥ 85%
- 芯层：1h释放 < 20%，4h释放 50-65%，8h释放 ≥ 80%
- 土木香内酯和山柰酚先释放（1h内达到峰值）
- 苦参碱和苦参氧化碱后释放（3-6h达峰）
