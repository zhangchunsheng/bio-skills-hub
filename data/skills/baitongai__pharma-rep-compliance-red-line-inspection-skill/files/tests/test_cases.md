# 医药代表合规红线检查 - 测试用例集

## 测试用例1：多重违规场景（拜访周计划）

**输入内容：**

```
【XX制药医药代表拜访周计划 - 2026年7月第一周】

一、工作目标
1. 本周完成15家医院拜访，确保Q3季度销售指标达成率不低于85%
2. 重点推进XX降糖药在心内科的处方上量，目标新增处方医生20名
3. 完成8万元回款任务，跟进3家医院的发票流转

二、重点拜访安排
周一：市第一人民医院心内科张主任
- 介绍XX降糖药临床优势，强调"临床治愈率接近100%，几乎无副作用"
- 带上2张500元京东购物卡作为答谢，同时赠送科室2箱咖啡
- 请张主任帮忙统计上季度科室各医生的处方量，便于精准跟进
- 顺便了解一下隔壁肿瘤科主任的联系方式，为下月推广XX靶向药做准备

周二：市中心医院内分泌科
- 该院尚未完成准入登记，但张总说关系到位了可以直接去
- 安排科室聚餐，预计人均200元，费用从市场活动费中列支
- 收集近期使用XX降糖药的患者联系电话，建立患者随访群

周三：区人民医院
- 与药剂科沟通，提出如果全年采购量达500万，公司可赞助一台全自动生化分析仪
- 向李医生支付上季度"临床观察费"3000元（现金），感谢其推荐用药

周四-周五：拜访社区医院和乡镇卫生院
- 推广公司另一款尚未获得授权的心血管中成药（属于OTC品类）
- 收集各院药事委员会近期讨论的进药计划信息
```

**预期结果：** 应触发RL-01~RL-09中至少7条红线，多条高风险

## 测试用例2：隐含/模糊违规场景（学术会议方案）

**输入内容：**

```
【XX降糖药区域学术研讨会方案】

一、会议信息
- 时间：2026年7月20日 14:00-17:30
- 地点：XX市XX酒店会议厅
- 参会对象：区域内20家医院的内分泌科主任及骨干医师共35人
- 会议主题：2型糖尿病管理新进展与XX降糖药临床应用经验分享

二、会议安排
1. 专题报告：邀请市一院王教授分享XX降糖药临床数据
2. 病例讨论：选取3位医生分享各自科室典型病例及用药体会
3. 互动环节：参会医生交流用药经验，讨论处方策略

三、费用预算
1. 讲课费：王教授8000元，3位病例分享医生各2000元（共计14000元）
2. 会议用餐：会后晚宴，人均300元，共约12000元
3. 交通安排：为外地参会医生安排酒店住宿（5间×500元=2500元）
4. 会议资料：制作宣传册和DA，突出XX降糖药"显著优于同类产品"的疗效优势
5. 纪念品：为每位参会医生准备精美笔记本套装一份

四、后续跟进
- 会后由代表分别跟进参会医生的用药情况
- 收集参会医生所在科室的用药变化数据，评估会议效果
- 针对重点医生安排一对一学术拜访，推动处方习惯转变
```

**预期结果：** 应识别出多条中高风险：讲课费支付方式、用药数据收集、夸大疗效表述、纪念品、住宿安排等

## 测试用例3：完全合规场景（标准学术推广方案）

**输入内容：**

```
【XX降糖药学术推广活动方案】

一、活动背景
根据药品上市许可持有人XX制药有限公司的授权，医药代表李某（备案编号：YA2026-00123，授权治疗领域：内分泌，授权区域：XX市）拟在已完成机构登记的市第一人民医院开展学术推广活动。

二、活动信息
- 时间：2026年7月15日 14:00-15:30
- 地点：市第一人民医院学术报告厅（已获医院科教处批准，批准文号：科字[2026]075号）
- 参会对象：内分泌科全体医师（约15人）
- 活动形式：学术讲座+问答交流

三、活动内容
1. 由XX制药医学部高级医学经理介绍XX降糖药的药品说明书内容，包括：
   - 适应症与用法用量（严格按说明书）
   - 临床研究数据（引用已发表的III期临床试验文献）
   - 安全性信息：完整呈现已知不良反应，包括胃肠道反应（发生率约15%）、低血糖风险等
2. 问答环节：解答临床用药疑问，收集不良反应反馈信息

四、费用说明
1. 讲课费：由XX制药通过公司对公账户支付至医院科教处指定账户，已签订正式《学术服务协议》
2. 无餐饮、礼品、交通等额外安排
3. 所有费用均附合规审批单、正式发票及活动记录

五、合规承诺
- 本次活动仅推广XX制药授权的XX降糖药，不涉及其他产品
- 活动内容严格基于药品说明书和公开文献
- 不收集患者个人信息和机构内部信息
- 不涉及任何销售指标、处方量统计
```

**预期结果：** 9条红线均应判定为✅合规或⚠️低风险

## 测试用例5：单项深度违规（推广话术脚本）

**输入内容：**

```
【XX降糖药拜访话术脚本 - 心内科版】

开场白：
"王主任您好！我是XX制药的医药代表小张，今天来跟您分享一个革命性的降糖新药——XX降糖片。这个药可以说是目前市场上最好的降糖药，临床数据显示治愈率高达95%以上，而且几乎没有任何副作用，患者用了都说好。"

核心卖点：
1. "这个药的降糖效果远超二甲双胍和达格列净，是目前唯一能同时控制血糖和保护心血管的药物"
2. "其他降糖药都有各种副作用，但我们这个药绝对安全，老年患者、肾功能不全患者都可以放心使用"
3. "建议您把科室里血糖控制不好的患者都换成我们的药，效果一定让患者满意"
4. "上次李医生用了我们药之后，患者反馈特别好，他已经把这个药作为一线选择了"

异议处理：
- 如果医生提到副作用："王主任您放心，这个药经过了严格的临床试验，完全没有肝肾毒性，您可以放心处方"
- 如果医生提到价格："虽然比二甲双胍贵一些，但效果是它的好几倍，而且能减少并发症，总体性价比更高"
- 如果医生提到指南未推荐："指南更新总是滞后的，我们这个药是最新的，很多专家已经在用了，您先用起来就走在前沿了"

结束语：
"王主任，我下周再来跟您分享更多临床数据，到时候看看科室里哪些患者适合换药，我帮您做个用药方案。"
```

**预期结果：** 应深度触发RL-07（误导疗效、夸大疗效、隐匿不良反应、干预临床合理用药），同时可能触发RL-08（患者信息）、RL-04（处方量暗示）
