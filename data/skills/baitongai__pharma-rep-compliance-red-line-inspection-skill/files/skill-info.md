# Skill Info

## Skill Name
医药代表合规红线检查

## Description
医药代表9项禁止行为智能合规检测工具。基于《医药代表管理办法》第二十四条，对推广计划、拜访记录、活动方案等内容进行逐条合规扫描，标注风险点并给出修改建议。触发场景：代表提交推广材料需合规自检、合规部门审核推广内容、培训场景下学习红线识别。触发词：合规红线、合规检查、合规扫描、红线检查、禁止行为检查、推广合规、拜访合规、活动合规、九项禁令、9项红线、合规自检。

## Introduction

本技能在医药合规领域提供基于《医药代表管理办法》（七部门联合发布，2026年8月1日起施行）第二十四条九项禁止行为的智能合规检测工具。

医药代表合规红线检查旨在简化和自动化医药推广材料的合规审查流程，对推广计划、拜访记录、活动方案等进行逐条合规扫描，标注风险点并提供可操作的修改建议，为医药代表、药企合规部门及培训团队提供全面的合规检测支持。

核心能力：

- 加载合规红线库：基于九项红线（RL-01至RL-09）建立检测基准
- 接收并解析输入内容：支持推广方案、拜访记录、会议策划、话术脚本等多种输入形式
- 逐条合规扫描：关键词匹配+场景判断+实质性分析，四级风险定级（高/中/低/无风险）
- 生成合规扫描报告：包含扫描概要、逐条对照表、风险详细分析、整改优先清单、合规声明

应用场景：

- 医药代表提交推广材料前的合规自检
- 药企合规部门审核推广内容
- 新代表合规培训中的红线识别练习
- 学术会议活动方案的合规预审
- 拜访话术脚本的合规性评估
