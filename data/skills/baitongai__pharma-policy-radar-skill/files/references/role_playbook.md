# 医药政策雷达 — 五岗位行动建议撰写指南

## 通用原则

每条政策为5个岗位分别输出行动建议，采用 **What → So What → Now What** 三段式结构：

- **What**：该政策对该岗位的核心影响是什么？（≤30字）
- **So What**：这个影响的量级/后果是什么？（≤30字）
- **Now What**：现在应立即采取什么动作？（≤40字，含时间窗口）

---

## 岗位1：合规经理（Compliance Manager）

### 关注焦点
- 法规合规义务变化
- GMP/GSP/药物警戒新要求
- 内部SOP更新需求
- 监管报送义务

### 撰写指南
```
What:  聚焦"新义务/新要求/新标准"
So What: 聚焦"现有流程的差距/不合规风险"
Now What: 聚焦"整改动作+责任人+截止日期"

示例：
What:  新版《药品生产监督管理办法》增加年度质量回顾报告提交要求
So What: 现有质量回顾报告模板不满足新增字段要求，存在合规风险
Now What: 2周内更新质量回顾SOP和报告模板，5月1日前完成首次提交
```

### 关键词倾向
合规、SOP、CAPA、偏差、验证、审计、报告、时限

---

## 岗位2：政府事务总监（GA Director）

### 关注焦点
- 政策制定的涉事部门与关键人
- 行业征求意见的机会窗口
- 对企业政企关系的影响
- 省级政策与国家政策的联动

### 撰写指南
```
What:  聚焦"政策窗口+关键部门"
So What: 聚焦"对政企关系的潜在影响+企业话语权"
Now What: 聚焦"沟通策略+材料准备+时间窗口"

示例：
What:  省医保局发布新版DRG分组方案征求意见稿，30天反馈期
So What: 本企业核心产品在现有分组下支付不足，新方案是调整窗口
Now What: 2周内完成分组经济学分析，联合行业协会提交反馈意见
```

### 关键词倾向
征求意见、反馈窗口、行业协会、沟通策略、政策建议

---

## 岗位3：市场准入经理（MA Manager）

### 关注焦点
- 医保目录/基药目录/集采的动态
- 注册审评路径变化
- 进院策略影响
- 定价与支付政策

### 撰写指南
```
What:  聚焦"准入路径变化+时间窗口"
So What: 聚焦"对产品上市/进院/销售额的影响"
Now What: 聚焦"材料准备+路径调整+时间表"

示例：
What:  国家医保局启动2027年医保目录调整工作，申报截止8月30日
So What: 产品A的临床证据包满足"填补空白"条件，有较大概率纳入
Now What: 6月启动药物经济学评价，7月底前完成全套申报材料，8月中提交
```

### 关键词倾向
准入、目录、集采、评价、申报、路径、时间窗

---

## 岗位4：市场/产品经理（Mkt/PM）

### 关注焦点
- 市场竞争格局变化
- 产品定位影响
- 推广策略调整
- 竞品对标分析

### 撰写指南
```
What:  聚焦"市场格局变化+产品策略影响"
So What: 聚焦"市场份额/品牌定位的潜在变化"
Now What: 聚焦"策略调整方案+竞品对标+资源调配"

示例：
What:  竞品B获批新增适应症，覆盖本品的核心治疗人群
So What: 本品在XX治疗领域的差异化优势被削弱，可能影响10-15%市场份额
Now What: 更新竞品情报手册，启动本品新适应症注册沟通，调整Q3推广策略
```

### 关键词倾向
份额、定位、竞品、推广、策略、品牌、差异

---

## 岗位5：高管层（Executive）

### 关注焦点
- 战略级影响
- 业务板块风险
- 资源调配决策
- 行业趋势判断

### 撰写指南
```
What:  一句话核心影响（≤30字）
So What: 战略级别的影响（≤30字）
Now What: 需要高管决策的事项（≤40字）

示例：
What:  国家集采第十批启动，本企业3个核心品种在目录内
So What: 若中选失败，预计年度营收影响8-12亿元，市场份额可能腰斩
Now What: 建议本周召开集采专项会，确定投标策略和备选方案
```

### 关键词倾向
战略、营收、风险、决策、资源、趋势

## 质量检查

每条建议完成后，确认：
- [ ] 三个字段均不超过字数限制
- [ ] What 确实回答了"影响的是什么"
- [ ] So What 确实量化/定性了"影响有多大"
- [ ] Now What 确实给出了"可执行的动作+时间"
- [ ] 无模糊用语（如"关注""重视""考虑"）
- [ ] 每个岗位的建议行业专用、非泛化
