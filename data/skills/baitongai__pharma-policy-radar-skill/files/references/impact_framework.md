# 医药政策雷达 — 四维度影响分析框架

## 使用说明

对每条政策，按以下四个维度逐一评估影响。若某维度无直接关联，标注"无直接影响"。
分析应基于政策原文和行业专业知识，遵循MECE原则（互斥穷尽）。

---

## （A）药监维度

### 分析范围
- GMP/GSP合规影响
- 注册审评路径变化
- 药物警戒新要求
- 药品质量监管强化

### 分析框架
```
1. 合规影响：
   - 是否新增/修改GMP/GSP要求？
   - 是否涉及飞行检查规则变更？
   - 是否有新的质量管理报告义务？

2. 注册路径：
   - 是否影响药品注册审评程序？
   - 是否涉及创新药/仿制药/生物制品的分类调整？
   - 是否有新的注册技术指导原则发布？

3. 药物警戒：
   - 是否新增不良反应报告要求？
   - 是否涉及定期安全性更新报告(PSUR)？
   - 是否有上市后研究的新要求？
```

### 关键提问
- "这项政策改变了企业的哪个合规动作？"
- "需要在多长时间内完成合规调整？"

---

## （B）医保维度

### 分析范围
- 医保目录准入/调出/限定支付范围
- 集采政策信号（带量采购批次、品种、规则）
- 支付方式改革（DRG/DIP、门诊统筹）
- 医保基金监管

### 分析框架
```
1. 目录准入：
   - 是否有医保目录调整信号？（新增/调出/限定支付范围变更）
   - 涉及哪些治疗领域或剂型？
   - 本企业产品是否在潜在影响范围？

2. 集采政策：
   - 是否涉及新一轮带量采购？
   - 是否涉及集采规则变更（中选规则、量价挂钩等）？
   - 是否涉及集采品种扩容？

3. 支付改革：
   - 是否有DRG/DIP支付方案调整？
   - 是否影响门诊用药报销政策？
   - 是否有创新药支付方式新规？
```

### 关键提问
- "这项政策是否影响本品的医保覆盖或支付标准？"
- "集采信号对应的时间窗口是多久？"

---

## （C）中医药维度

### 分析范围
- 中药注册管理变化
- 中医医疗服务价格调整
- 中药饮片/配方颗粒政策
- 中西医结合政策

### 分析框架
```
1. 注册管理：
   - 是否有中药注册分类/审评标准变化？
   - 是否涉及经典名方/院内制剂新规？
   - 中药说明书修订要求？

2. 服务价格：
   - 是否有中医医疗服务项目价格调整？
   - 是否新增中医适宜技术纳入医保？

3. 饮片/配方颗粒：
   - 是否有配方颗粒国标/省标更新？
   - 是否有饮片炮制规范变更？
   - 是否有中药饮片加成政策调整？
```

### 关键提问
- "这项政策是否改变了中药产品的注册/准入/定价路径？"
- "有无可快速响应的政策红利窗口？"

---

## （D）卫健委维度

### 分析范围
- 临床路径与诊疗规范更新
- 基药目录调整信号
- 医院绩效考核指标变化
- 分级诊疗/医联体政策

### 分析框架
```
1. 诊疗规范：
   - 是否有新的临床诊疗指南或路径发布？
   - 是否影响产品在特定治疗领域的推荐地位？

2. 基药目录：
   - 是否有基本药物目录调整信号？
   - 是否涉及基药配备使用比例变化？

3. 医院考核：
   - 是否有三级公立医院绩效考核指标变更？
   - 是否涉及合理用药/药占比/抗菌药物等指标？
   - 是否影响进院/进科室策略？
```

### 关键提问
- "这项政策是否改变了产品在医院的竞争环境？"
- "是否需要调整学术推广策略？"

---

## 分析输出格式

每条政策输出如下JSON结构（供report_renderer.py使用）：

```json
{
  "policy_id": "POL-20260702-001",
  "impact_analysis": {
    "drug_safety": "药监维度分析结论...",
    "medical_insurance": "医保维度分析结论...",
    "tcm": "中医药维度分析结论...",
    "health_commission": "卫健委维度分析结论..."
  }
}
```

若某维度无影响，标注为"无直接影响"而非留空。
