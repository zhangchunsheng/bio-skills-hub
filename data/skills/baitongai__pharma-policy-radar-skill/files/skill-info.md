# Skill Info

## Skill Name
医药政策雷达

## Description
医药政策雷达——从百通数据集获取官方机构URL，访问各政府官网抓取最新政策，自动生成多岗位视角影响分析报告。前置条件：百通MCP已连接且具备VIP权限。覆盖全国31省药监/医保/中医药/卫健委四大领域。触发词：政策雷达、医药政策、政策监控、政策扫描、policy radar、药政监控。

## Introduction

本技能在医药合规与市场准入领域提供自动化的政策情报监控与分析能力。

医药政策雷达旨在为医药企业的合规事务、市场准入、医学事务及战略规划团队，从全国31省药监、医保、中医药、卫健委四大领域实时抓取官方政策原文，生成面向多岗位的结构化影响分析报告，帮助团队快速识别政策变化对业务的影响并采取行动。

核心能力：

- 全国31省多机构覆盖：从百通数据集获取各省.gov.cn官方地址，访问NMPA、国家医保局、国家卫健委、国家中医药管理局及31省对应机构
- 政策原文抓取：直接访问政府官网原文，数据来源可信，无第三方SEO污染
- 智能去重过滤：基于标题相似度和关键词过滤，排除人事、会议等无关通知
- 四维度影响分析：每条政策输出药监/医保/中医药/卫健委四个视角的影响评估
- 分岗位行动建议：为合规、GA、MA、Mkt、高管五类岗位输出 What-So What-Now What 三段式建议
- 风险评分与预警：对政策进行紧迫度评分，识别需要立即行动的高风险政策

应用场景：

- 药监政策监测：NMPA/省级药监局新规对研发注册的影响分析
- 医保目录调整：国家医保目录更新对产品定价和市场准入的影响评估
- 中医药政策追踪：国家及各省中医药管理局政策变化对中医药产品线的业务影响
- 卫健委合规检查：医疗机构监管政策变化对销售行为合规性的影响
- 竞品政策对标：竞争对手所在领域的政策变化监测与战略应对
