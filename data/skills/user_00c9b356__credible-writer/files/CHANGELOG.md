# CHANGELOG - 真笔·写作内核+风格包 (credible-writer)

## v2.1.0 (2026-08-03)
- **新增第三支柱：逻辑一致性检查**。此前只有"去AI味+去幻觉"两支柱，缺逻辑自洽性检查——一个零幻觉、零AI味的文本仍可能自相矛盾（如判定规则说"选后者=共生"但分项把后者标为"寄生"）。
- 新增 `references/consistency-check.md`：七维一致性清单（判定规则-选项/标题-正文/比喻-论点/术语/证据-论断/自检题对称/前后不矛盾）+ 发布前必过流程（PASS/WARN/FAIL 三级）。
- 新增 `scripts/check_consistency.py`（零依赖）：机械扫描脚本，重点抓"判定规则句 vs 选项极性位置"是否自洽 + 术语统一检查；输出 PASS/WARN/FAIL，有 WARN/FAIL 退出码为 1。已用矛盾用例验证 FAIL 正确触发、无矛盾用例 PASS。
- SKILL.md 升级：内核标题/描述由"去AI味+去幻觉"改为"去AI味+去幻觉+一致性检查"；架构图补三支柱互不替代说明；新增「内核能力 3」专节；工作流从七步改为八步（新增 Step 8 一致性检查硬门）；快速检查清单补一致性维度；Troubleshooting 补 3 行；FAQ 补 2 条；新增内核资源文件表。
- 触发词/识别信号补"逻辑一致性""逻辑自洽""前后矛盾"。

## v2.0.0 (2026-07-10)

- 删除旧 `references/style-packs.md`（被 `styles/` 取代）；内核 references（ai-patterns/evidence-system/quality-scoring）保持不变。
- 内核强化「保证数据准确、观点经得起正反辩驳」为核心使命（证据四问 + Devil's Advocate 自检）。
