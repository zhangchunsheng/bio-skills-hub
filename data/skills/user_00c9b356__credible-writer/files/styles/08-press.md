# 风格包：新闻通稿（Press Release）

> 内核对该风格的要求：去AI味 + 去幻觉 + 证据四问 + 正反辩驳 全部生效；本文件只定义「新闻通稿」的表面形态。
> 市场依据（2026-07-10 调研，美通社方法）：倒金字塔结构、标题稳准简突出数据亮点、导语 8 秒抓注意力、人物引言真实具体。

## 适用场景
企业发稿、机构公告、活动预告、产品发布、融资/合作消息。

## 结构骨架（倒金字塔）
```
[标题：稳准简，含核心数据/亮点]
[副标题（可选）：补充关键信息]
[导语：5W1H 浓缩，最重要事实前置，1-2句]
[主体：按重要性递减展开，分2-3段]
  └ 关键数据 → 背景 → 引语（真实人物原话）
[引语：XX负责人表示：「……」（真实、贴合身份）]
[关于XX：机构/企业简介 boilerplate]
[联系方式：媒体联络人]
```

## 语言特征（语域）
- 客观、平实、第三人称；不用第一人称「我们」做主语（用机构名）。
- 不用感叹号、不用 emoji、不用宣传腔夸张词。
- 信息密度高，一句一事实。

## 雷区（内核重点清的AI味）
- 宣传式语言（「令人叹为观止」「划时代」「颠覆性」）→ 删，用事实和数据。
- 模糊归因（「行业专家表示」无具体人）→ 给真名真职，或删。
- 通用积极结论 → 替换为具体成果/数据。

## 与内核衔接（证据要求）
- 数据/事实必须真实可查；引用外部数据标来源（如「据 XX 报告」）。
- 引语必须是真实人物原话，不代拟夸张表态（防幻觉）。
- 正反辩驳：敏感/争议事件给背景与对方立场，不单边叙事。

## 示例片段
❌ AI味：「此次发布具有里程碑意义，将颠覆行业格局，引领未来发展新趋势。」
✅ 通稿：「公司今日发布 X 产品，定价 299 元，较上代续航提升 40%（官方测试）。CEO 李某表示：『我们想先把电池做扎实。』（XX 公司 2026-07-10 公告）」
