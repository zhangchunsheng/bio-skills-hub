# 风格包：小红书笔记（Xiaohongshu Note）

> 内核对该风格的要求：去AI味 + 去幻觉 + 证据四问 + 正反辩驳 全部生效；本文件只定义「小红书」的表面形态。
> 市场依据：短笔记形态，强钩子标题、emoji 节奏、真实体验感优先。

## 适用场景
种草笔记、测评、经验分享、探店、好物推荐。

## 结构骨架
```
[标题：20字内，含数字/反差/悬念/痛点，如「30岁才懂的5个护肤坑」]
[正文：
  🔹 痛点开场（1-2句共鸣）
  🔹 方法/体验（分点，带具体细节）
  🔹 真实对比（前后/踩坑）
  🔹 总结/行动建议]
[标签：3-5个 #话题]
```

## 语言特征（语域）
- 口语化、有画面感、第一人称；允许「真的」「绝了」「救命」等语气词。
- emoji 适度（每段≤2，标题可带 1 个）。
- 短句、短段、多换行（手机竖屏阅读）。

## 雷区（内核重点清的AI味）
- 小红书 AI 腔（套路化种草模板：「宝子们冲」「不得不说」）→ 删，用真实口吻。
- 三段式强列表 → 保留但注入真实细节（不是「很好用」而是「用了三天毛孔肉眼可见变细」）。
- 过度限定、翻译腔 → 删。

## 与内核衔接（证据要求）
- 体验感 > 数据，但**效果描述不夸大、不编造**（如「白一个度」要有前后对比依据）。
- 引用数据简短标注；不需要完整证据系统。
- 正反辩驳：推荐类内容给「适合/不适合谁」，避免「人人都该买」的绝对化。

## 示例片段
❌ AI味：「这款产品凭借卓越的功效，为肌肤提供深层滋养，助力美丽蜕变。」
✅ 小红书：「用空两瓶才敢说：干皮秋冬天救星，但油皮会闷痘。我额角爆皮三天就缓过来了。」
