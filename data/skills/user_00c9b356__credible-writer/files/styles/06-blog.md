# 风格包：博客文章（Blog Post）

> 内核对该风格的要求：去AI味 + 去幻觉 + 证据四问 + 正反辩驳 全部生效；本文件只定义「博客」的表面形态。
> 市场依据：叙事感、个人观点、可破传统结构是博客区别于报告/论文的核心。

## 适用场景
个人博客、技术博客、观点文、随笔、行业观察。

## 结构骨架
```
[标题：有吸引力但不标题党]
[引子：故事/问题/观察，2-4句]
[主体：按叙事节奏走，可破结构]
[收尾：观点/反思/开放问题]
```

## 语言特征（语域）
- 有叙事感、有观点、可读性强；第一人称。
- 允许口语、幽默、个人风格；不用 emoji（技术博客惯例除外）。

## 雷区（内核重点清的AI味）
- 博客是「去 AI 味可最激进」的文体（aggressive 力度，structural scope）。
- 通用积极结论、公式化结尾 → 删，用真实不确定性。
- 三段式、对称结构 → 打破，允许跑题/题外话（人性体现）。
- 节奏一致（2026 #1 tell）→ 刻意混长短句。

## 与内核衔接（证据要求）
- 引用他人观点需注明；自己观点标「判断」。
- 不编造数据；数据简短标注来源。
- 正反辩驳：观点文必须承认反方，不装客观。

## 示例片段
❌ AI味：「总之，持续学习是个人成长的不二法门，让我们共同进步。」
✅ 博客：「我戒了「每天学点新东西」半年，反而懂了更多——因为终于把一件事做透了。可能不是学习错了，是「浅学习」错了。」
