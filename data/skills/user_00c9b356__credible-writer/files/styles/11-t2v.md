# 风格包：短视频文生视频 prompt（Text-to-Video Prompt）

> 内核对该风格的要求：**去AI味在此表现为「去抽象、去笼统」**——用具体物理描述代替「高级感」「电影感」等空词；去幻觉表现为**不写模型做不到的确定性**（如精确秒数、复杂因果）。本文件定义「文生视频 prompt」的表面形态。
> 市场依据（2026-07-10 调研）：即梦 Seedance 2.0 五步公式（主体→动作→运镜→风格→约束）；行业通用「景别/运动/内容/机位」分栏。

## 适用场景
即梦 / 可灵 / 海螺 / Vidu 等文生视频工具的提示词；抖音/视频号短视频素材生成。

## 结构骨架（五步公式）
```
1. 主体（Subject）：人物/产品/场景，明确特征，可用 @引用参考图
2. 动作（Action）：物理可观测的运动，关键动作标英文动词（walk / turn / pour）
3. 运镜（Camera）：景别 + 运镜方式（close-up / pan / push-in / drone shot）
4. 风格（Style）：光线 + 画质 + 艺术风格三项具体参数，不用「高级感」
5. 约束（Constraints）：规避项（no text / no deformed hands / stable lighting）
```
分镜版可加：`[镜头编号] [景别] [运动] [内容] [机位] [时长/备注]`。

## 语言特征（语域）
- 名词 + 动词 + 摄影术语为主；避免形容词堆砌。
- 中文工具可用中文，但专业运镜词建议中英混用（模型更稳）。
- 一句一要素，用逗号/分号分隔，不用长段落。

## 雷区（内核重点清的「AI味」）
- 笼统词（「电影感」「高级感」「唯美」「震撼」）→ 替换为具体：4K、35mm 镜头、自然侧光、暖色调。
- 抽象动作（「展现活力」「表达情绪」）→ 换可观测动作（「奔跑时头发被风吹起」）。
- 过度限定同时多主体复杂互动 → 拆成单镜头，避免崩坏。

## 与内核衔接（证据/准确要求）
- 不编造「模型能精确控制」的内容（如「时长精确 8.3 秒」「角色说 specific 台词」多数模型不稳）→ 标为期望而非保证。
- 事实类（如「厦门鼓浪屿」「1940 年代」）须准确，不张冠李戴。
- 正反辩驳：给一个「若生成崩坏，备选方案」（如换运镜词、降复杂度）。

## 示例片段
❌ 笼统：「一个唯美高级感的女生在漂亮的地方走路，电影感。」
✅ t2v：「一位穿米白风衣的亚裔女性（@ref），沿樱花道慢走，风掀起衣角（walk / hair blows）。镜头：中景平摇跟拍（medium shot, pan follow）。风格：自然侧光、35mm、4K、日系胶片色调。约束：无文字、手部不畸变、光线稳定。」
