# 风格包索引（Style Packs）

> 本目录是「内核 + 风格包」架构的「风格」一侧。
> **内核**（`references/ai-patterns.md` + `references/evidence-system.md` + `references/quality-scoring.md`）负责去AI味、去幻觉、数据准确、正反辩驳——**与文体无关，永远生效**。
> **风格包**只定义每种文体的「表面形态」：语域、结构骨架、雷区、证据要求松紧。写作时由内核自动加载对应风格包。

## 加载规则

1. 用户未指定文体 → 内核根据内容推断并告知用户（见 SKILL.md 文体路由表）。
2. 指定了文体 → 内核先跑「去AI味 + 去幻觉 + 证据四问 + 正反辩驳」，再套用本目录对应文件做语域/结构校准。
3. 跨文体 → 用 SKILL.md 的「文体切换矩阵」在两种风格包之间过渡，**内核规则不变**。

## 新增风格包的做法

1. 在 `styles/` 下新建 `NN-<slug>.md`，严格按现有格式（适用场景/结构骨架/语言特征/雷区/与内核衔接/示例片段）。
2. 在 SKILL.md 的「文体路由表」加一行。
3. 在 examples.md 补一个最小示例（可选）。

> 风格包**不重复**内核规则。若某文体需要特殊「去幻觉」处理（如回忆录的记忆溯源分级），只在「与内核衔接」里说明差异点，细节引用 `references/evidence-system.md`。
