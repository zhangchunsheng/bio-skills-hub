# 风格包：深度报告（Deep Report）

> 内核对该风格的要求：去AI味 + 去幻觉 + 证据四问 + 正反辩驳 全部生效（**所有文体中证据要求最高**）；本文件只定义「报告」的表面形态。
> 市场依据：咨询/研究类报告通用「执行摘要 + 分章论证 + 附录溯源」结构。

## 适用场景
行业研究、竞品分析、尽调报告、内部决策报告、调研报告。

## 结构骨架
```
[标题]
执行摘要：[300-500字，核心发现+关键数据+置信度]
一、背景与目的
二、研究方法（样本、来源、局限）
三、核心发现
   3.1 [发现一]（证据：🥇/🥈，置信度：XX%）
   3.2 [发现二]
四、分析与讨论
五、结论与建议
六、局限性说明
附录A：数据来源  附录B：置信度说明  附录C：验证状态
```

## 语言特征（语域）
- 专业但不晦涩；第三人称，可适度「本报告认为」。
- 不用口语、emoji；不用宣传腔。

## 雷区（内核重点清的AI味）
- 「不断演变的格局」「关键转折点」「赋能行业」→ 删，换具体数据。
- 公式化结尾、通用积极结论 → 删，给具体建议。
- 信息化妆（修辞掩盖信息缺失）→ 补数据或标「证据不足」。

## 与内核衔接（证据要求）
- **强制**完整证据等级系统（🥇🥈🥉❓）。
- **强制**置信度计算（证据链 <50% → 输出「证据不足」，不评分数）。
- **强制**事实 vs 判断分离 + 正反辩驳自检。
- **强制**数据来源附录。
- 这是内核「保证数据准确、观点经得起正反辩驳」的最高标准落地文体。

## 示例片段
❌ AI味：「该市场前景广阔，各玩家争相布局，未来将迎来爆发式增长。」
✅ 报告：「2025 年市场规模约 120 亿元（🥈 艾瑞，2026-03），年增 18%（🥈 同源）。但样本仅覆盖头部 12 家，长尾未计入，置信度 70%；若监管收紧，增速可能腰斩（反方风险已计入局限）。」
