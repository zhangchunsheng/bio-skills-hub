# 风格包：回忆录 / 传记（Memoir / Biography）

> 内核对该风格的要求：去AI味 + 去幻觉 全部生效，但「去幻觉」在此文体制表现为**记忆溯源分级**（领域化）；本文件定义「回忆录」的表面形态与工艺层。
> 来源：原 memoir-writer 的 `memoir-craft.md` 工艺层，现并入内核风格包，消除复制分叉。

## 适用场景
个人回忆录、家族史料、口述史、长辈生平整理、传记体写作。

## 结构骨架
**人生阶段式**（最通用）
```
扉页/献词
第一章 早年（出生–求学）
第二章 闯世界（成家–立业）
第三章 最难的那几年（转折）
第四章 安稳日子（中年–晚年）
尾声（留给子孙的话）
```
**主题式**（素材零散）：以「一双鞋/一张全家福/一碗面」等意象串记忆。
**家族史料式**（编年）：`[年份] [事件] [出处🥇🥈🥉❓]`。

## 语言特征（语域）
- 保留传主**声音**：口头禅、方言词、句式习惯、视角（乐观/耿直/细腻）。
- 第一人称（传主或子女代笔）或第三人称，依声线而定。
- AI 写回忆录最大破绽：**所有人回忆录一个腔调**——去 AI 味 = 把声音还给他。

## 雷区（内核重点清的AI味 + 反煽情）
- 套路化煽情（「那一刻他明白了人生意义」）、伪乡愁（「石板路承载整个童年」）→ 删。
- 无来源景物抒情、通用怀旧（「物质匮乏但人情暖」）→ 删或给素材支撑。
- 金句腔、强行升华 → 删。
- 写成「完人传记」→ 诚实审查补瑕疵。

## 与内核衔接（证据要求 · 领域化）
复用 `references/evidence-system.md`，但来源分级改为**记忆来源**：
- 🥇 日记/文献原文 → 🥈 口述佐证/照片实物 → 🥉 记忆重建 → ❓ 存疑。
- **事实 vs 文学重建分离**：日记无记录的对话/心理/场景，必须标 `[文学重建：…]`。
- 诚实审查（不虚美不隐恶）：补缺点、犹豫、矛盾；作者不跳出来直判「他是个好人」。
- 核心事件仅 ❓ → 标「记忆模糊」，不写成确凿事实。

## 示例片段
❌ AI味：「外公一生勤劳善良，是邻里称颂的好人，那间老屋承载了他全部的爱与坚守。」
✅ 回忆录：「1962 年冬，外公在砖窑里，手冻得握不住锹（🥇日记）。他没吭声，把扁担往肩上一扛——师傅骂他细胳膊干不了活（🥈口述）。他后来跟我说，那是他第一次想争口气（🥉记忆重建）。」
