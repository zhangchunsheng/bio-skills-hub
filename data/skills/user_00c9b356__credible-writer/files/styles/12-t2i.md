# 风格包：短视频文生图 prompt（Text-to-Image Prompt）

> 内核对该风格的要求：**去AI味 = 去笼统、去翻译腔**；用具体视觉参数代替「高级感」「氛围感」；去幻觉 = 不写模型无法稳定实现的细节。本文件定义「文生图 prompt」的表面形态。
> 市场依据（2026-07-10 调研）：通用框架「主体/环境/光线/风格/参数」；主流工具（即梦/MJ/4o/Recraft）建议**中英双版**通用；框架以「增强而非发散」为原则。

## 适用场景
即梦 / Midjourney / GPT-4o / Recraft 等文生图；短视频封面、海报、配图、贴纸生成。

## 结构骨架
```
[主体 Subject]：谁/什么，明确特征（年龄/服饰/材质/姿态）
[环境 Scene]：地点、背景、天气、时代
[光线 Lighting]：自然光/侧光/霓虹/逆光 + 强度
[风格 Style]：艺术流派/画风（水彩/赛博朋克/纪实摄影/3D 渲染）
[参数 Parameters]：画质（8K/4K）、镜头（广角/微距）、比例（--ar 16:9）、渲染器
```
输出建议**中英双版**：中文给理解，英文（或英文关键词）给模型稳定性。

## 语言特征（语域）
- 关键词堆叠 + 逗号分隔，不用完整句子（模型偏好 token 流）。
- 权重符号（:: 或 --weight）按需使用。
- 避免长段描述、避免矛盾指令（「写实又卡通」）。

## 雷区（内核重点清的「AI味」）
- 空洞词（「高级感」「氛围感」「精美绝伦」）→ 替换为：\"matte painting\" / \"soft rim light\" / \"shallow depth of field\"。
- 翻译腔长句 → 拆成关键词。
- 矛盾风格混搭 → 明确主风格，次要作修饰。

## 与内核衔接（准确要求）
- 事实/专有名词准确（「唐代仕女」「包豪斯椅」）不张冠李戴。
- 不承诺模型做不到的（如「精确还原某 Logo 字体」多数不稳）→ 标期望。
- 正反辩驳：给「若出图偏题的修正词」（换风格词/加 negative prompt）。

## 示例片段
❌ 笼统：「画一个很有氛围感的高级美食照片，好看一点。」
✅ t2i：「一碗阳春面，清汤浮着葱花和猪油星光，粗瓷碗，木桌面有水汽（中文）。Steam rising, soft top light, 35mm macro, food photography, muted warm tone, 8k --ar 4:5（英文）。负向：no text, no hands, no plastic。」
