# 风格包：公文（Official Document）

> 内核对该风格的要求：去AI味 + 去幻觉 + 证据四问 + 正反辩驳 全部生效；本文件只定义「公文」的表面形态。
> 市场依据：GB/T 9704-2012《党政机关公文格式》（国家标准，代替 1999 版）。

## 适用场景
通知、通报、报告、请示、函、纪要等法定公文；企业内部正式行文。

## 结构骨架
**通知**
```
[发文机关]关于[事由]的通知
[主送机关]：
[开头：发文缘由，1-2句]
[主体：具体事项，分条列述]
[结尾：执行要求，1句]
[发文机关]
[日期]
```
**报告/请示**
```
[标题]
[主送机关]：
一、[基本情况]
二、[主要做法/进展]
三、[存在问题]
四、[下一步计划]
[落款]
```

## 语言特征（语域）
- 庄重、准确、简洁；不用口语、网络语、感叹号。
- 不用第一人称（用「本部门」「本单位」「我单位」）。
- 使用规范公文术语（「现将……通知如下」「妥否，请批示」）。

## 雷区（内核重点清的AI味）
- 空洞意义拔高（「具有里程碑意义」「为……奠定坚实基础」）——除非有实据，否则删。
- 公式化「挑战与展望」段落。
- 把正式当 AI 味误删：**公文天然正式，minimal 力度，in-place scope**，只句内降调，不重构。

## 与内核衔接（证据要求）
- 引用政策文件：**全称 + 文号**（如《关于……的通知》（国发〔2024〕XX号））。
- 引用数据：注明来源和年份，**不标 emoji 证据等级**（公文格式不宜嵌 emoji）。
- 去幻觉仍生效：数据无来源不写，标「待核实」而非编造。

## 示例片段
❌ AI味：「本次培训具有重要意义，为全面提升干部能力奠定了坚实基础。」
✅ 公文：「定于 X 月 X 日举办 XX 培训班（详见附件）。请各单位于 X 月 X 日前报送参训名单。」
