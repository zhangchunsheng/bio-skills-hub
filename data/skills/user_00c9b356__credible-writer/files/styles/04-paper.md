# 风格包：学术论文（Academic Paper）

> 内核对该风格的要求：去AI味 + 去幻觉 + 证据四问 + 正反辩驳 全部生效（学术是证据要求最严的文体之一）；本文件只定义「论文」的表面形态。
> 市场依据：IMRaD 结构（引言-方法-结果-讨论）；引用 GB/T 7714 或 APA。

## 适用场景
期刊论文、学位论文、会议论文、综述。

## 结构骨架
```
[标题]
摘要：[200-300字，目的/方法/结果/结论]  关键词：[3-5]
1. 引言（背景、问题、目的、研究空白）
2. 文献综述
3. 研究方法（设计、数据来源、分析）
4. 研究结果（分节陈述）
5. 讨论（解释、对比、局限）
6. 结论（发现、贡献、方向）
参考文献（GB/T 7714 或 APA）
```

## 语言特征（语域）
- 客观、中性、术语准确；第三人称或「本研究」「本文」。
- 不用口语、修辞、感叹号、emoji。
- 被动语态可接受，但避免过度（见雷区）。

## 雷区（内核重点清的AI味）
- 学术写作天然正式，**勿把规范当 AI 味删**（minimal 力度，in-place scope）。
- 空洞「意义」段落、公式化「未来展望」→ 删或具体化。
- 过度被动语态、长难句堆砌 → 适度改主动、拆句。
- 伪学术（简单概念包装学术词）→ 删。

## 与内核衔接（证据要求）
- **每个论断必须有引用**；数据必须注明来源。
- 使用完整证据等级系统（🥇🥈🥉❓）于内部自查，正文用规范引用格式。
- 明确标注「事实」vs「作者推断」（讨论部分标「笔者认为」）。
- 正反辩驳：讨论部分必须呈现对立观点并回应，不能只讲支持证据。
- 置信度标注在讨论/局限部分。

## 示例片段
❌ AI味：「这一发现具有重要的理论意义和广泛的应用前景，为相关领域奠定了坚实基础。」
✅ 学术：「本结果与 Zhang 等（2023）一致，但在样本量上扩大了 3 倍；与 Li（2022）的差异可能源于方法不同（见 4.2）。局限：横截面设计无法推断因果。」
