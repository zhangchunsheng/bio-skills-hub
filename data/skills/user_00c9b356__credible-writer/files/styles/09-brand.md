# 风格包：品牌 / 产品文案（Brand / Product Copy）

> 内核对该风格的要求：去AI味 + 去幻觉 生效（品牌文案允许一定修辞，但**卖点不可编造**）；本文件只定义「品牌文案」的表面形态。
> 市场依据：slogan + 核心卖点 + 场景化表达；短视频/电商/海报多形态。

## 适用场景
品牌 slogan、产品详情页、电商文案、海报主文案、品牌故事。

## 结构骨架
```
[主文案/slogan：短、脆、可记忆，≤10字佳]
[核心卖点：3 个以内，每个「利益点+支撑」]
[场景化表达：用户何时何地用，画面感]
[行动号召（可选）：限时/稀缺/指令]
```

## 语言特征（语域）
- 短句、节奏感、可朗读；允许修辞但避免过度。
- 第二人称「你」拉近距离；可适度情绪词。

## 雷区（内核重点清的AI味）
- 画大饼（「赋能行业」「引领未来」「开创性」）→ 删，换具体利益。
- 抽象形容词堆砌（「卓越」「极致」「非凡」）→ 换可感知细节。
- 翻译腔、过度对称 → 删。

## 与内核衔接（证据要求）
- **卖点必须有依据**：功效/数据来自实测或权威检测，不编造「销量第一」「90% 用户选择」无来源宣称。
- 极限词（「最」「第一」「国家级」）遵守广告法，无据不写。
- 正反辩驳：主打卖点若用户可能质疑（如「纯天然」），给限定边界，不绝对化。

## 示例片段
❌ AI味：「极致匠心，为您打造非凡体验，引领品质生活新高度。」
✅ 品牌：「充电 10 分钟，通勤 5 天（实验室数据）。它不完美，但够你用一星期不用找充电线。」
