# 风格包：爆款推文（公众号长文）

> 内核对该风格的要求：去AI味 + 去幻觉 + 证据四问 + 正反辩驳 全部生效；本文件只定义「爆款推文」的表面形态。
> 市场依据（2026-07-10 调研）：标题权重≈70%，内容只需 60 分及格；倒金字塔/情绪 hook；大 V 爆文通用「引言-案例-共鸣-金句」逻辑。

## 适用场景
微信公众号 10w+ 长文、行业深度爆款、知识付费引流文。

## 结构骨架
```
[钩子标题：18-22字，数字/反差/悬念/痛点]
[开场：反预期 or 痛点共鸣，2-3句，不铺垫]
[主体：观点+案例+数据，分节但不机械三段]
  └ 每节：一个扎心观察 → 一个真实案例 → 一点可迁移方法论
[收尾：金句 or 行动号召 or 开放讨论]
[引导：关注/在看/留言钩子]
```

## 语言特征（语域）
- 口语化、有情绪、有观点；第一人称为主。
- 允许适度 emoji（每段≤2）、粗体强调关键句。
- 短句为主，段落短（手机阅读）。

## 雷区（内核重点清的AI味）
- 「赋能」「助力」「引领」「解锁」等 GPT 系方言高频词 → 删。
- 三段式强行列举、公式化「首先其次最后」→ 改为两项或四项，或自然叙述。
- 通用积极结论（「未来可期」）→ 替换为具体下一步。
- 虚假数据感（「据统计」无来源）→ 标来源或删。

## 与内核衔接（证据要求）
- 体验感 > 数据，但**数据仍需真实**，不编造使用效果。
- 引用数据简短标注来源（文末或行内），不需要完整 🥇🥈🥉 系统。
- 正反辩驳：核心观点若可能被反驳（如「XX 方法无效」），文中给最强反例或限定边界，避免绝对化翻车。

## 示例片段
❌ AI味：「综上所述，掌握这些方法将显著提升你的效率，助力个人成长。」
✅ 爆款：「我试了 3 个月，唯一留下来的习惯就一个：每天只列 3 件事。不是 5 件，是 3 件。多一件我都完不成。」
