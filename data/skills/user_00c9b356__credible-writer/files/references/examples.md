> 3 个完整示例，覆盖改写、创作、证据标注三种场景。

## 示例 1：去AI味改写（小红书文体）

**用户输入**："帮我改写这段小红书文案，去AI味：

> 这款面膜真的是不可错过的护肤好物。此外，它富含多种天然成分，能够深入滋养肌肤。值得注意的是，连续使用两周后，肌肤状态显著提升。不仅如此，它还获得了众多美妆博主的大力推荐。"

**处理过程**：
1. 判场景 → 小红书爆款
2. 保护片段 → "两周""多种天然成分"（如果用户确认是真实数据）
3. 力度 → standard，scope → structural
4. 证据标注 → "众多美妆博主推荐"标为❓（无具体来源）
5. 去AI味 → 删"此外""值得注意的是""不仅如此"；删三段式

**改写后**：

> 用了两周，毛孔肉眼可见变细了。成分表干净，没有乱七八糟的添加。价格也实在，回购中。

**修改说明**：
- 识别的AI模式：填充短语（此外、值得注意的是）、否定式排比（不仅如此……还）、模糊归因（众多美妆博主）
- 删除的AI词汇：此外、值得注意的是、不仅如此、显著、大力
- 证据补充："众多美妆博主推荐"标为❓，已删除（无具体来源）
- 质量评分：32/60 → 51/60

## 示例 2：从零创作（公文通知）

**用户输入**："帮我写个通知，下周三部门团建，下午2点出发，去环岛路"

**处理过程**：
1. 判场景 → 公文写作
2. 力度 → minimal（公文不宜大改）
3. 去AI味 → 只删套话，保留正式感
4. 证据标注 → 公文不需要emoji标注

**输出**：

> **关于组织开展部门团建活动的通知**
>
> 各组：
>
> 为增进团队协作，拟于下周三下午组织环岛路团建活动。请各组于当日14:00在公司门口集合出发。
>
> 请提前安排好手头工作，按时参加。
>
> 综合管理部
> 2026年7月9日

## 示例 3：证据标注（报告文体）

**用户输入**："写一段关于说人话skill的分析，要标注证据"

**处理过程**：
1. 判场景 → 深度报告
2. 证据标注 → 查证GitHub数据

**输出片段**：

> 说人话是中文去AI味领域星数最高的开源项目（🥇 GitHub 669 stars，来源：github.com/MrGeDiao/shuorenhua，访问时间 2026-07-09）。其核心方法为六步去AI味流程，包含场景分档和力度分级。
>
> **事实**：该仓库拥有 669 stars 和 80 条评测数据（证据：🥇，置信度：85%）
>
> **判断**：说人话的方法论在中文场景下最为成熟（依据：星数+评测集+社区活跃度，置信度：65%，辩驳风险：星数不完全等于方法论质量）

## 示例 4：博客改写（aggressive 力度）

**用户输入**："帮我把这段博客改自然一点：

> 在当今快速发展的技术环境中，AI 正在深刻地改变着我们的生活方式。值得注意的是，这种变革不仅仅体现在效率的提升上，更重要的是，它正在重新定义人与机器之间的关系。"

**处理过程**：
1. 判场景 → 博客文章
2. 力度 → aggressive，scope → structural（可大改）
3. 去AI味 → 删"在当今……环境中""值得注意的是""不仅仅……更重要的""正在……着"

**改写后**：

> AI 改变的不只是效率，还有人和机器的关系。

**修改说明**：
- 识别的AI模式：时代铺垫（"在当今快速发展的……"）、填充短语（值得注意的是）、否定式排比（不仅仅……更重要的是）、过度限定（正在……着）
- 质量评分：28/60 → 48/60
