# 质量评分系统

> 6维度60分制 + 交付前自查清单

---

## 六维度评分

### 1. 直接性（/10）
**评估**：直接陈述事实还是绕圈宣告？
- 10分：直截了当，不绕弯
- 7分：偶有铺垫但总体直接
- 4分：经常绕弯，有大量"值得注意的是"
- 1分：充满铺垫和客套

### 2. 节奏（/10）
**评估**：句子长度是否变化？是否打破AI的节奏一致性？
- 10分：长短交错自然，有碎片句也有长句
- 7分：有变化但不够明显
- 4分：大部分句子长度一致
- 1分：机械重复，每句都差不多长

### 3. 信任度（/10）
**评估**：是否尊重读者智慧？是否过度解释？
- 10分：简洁明了，相信读者能理解
- 7分：偶尔过度解释
- 4分：经常手把手引导
- 1分：像跟小孩说话

### 4. 真实性（/10）
**评估**：听起来像真人说话吗？有个人声音吗？
- 10分：自然流畅，有温度和个性
- 7分：基本自然，但缺一点个性
- 4分：干净但无灵魂
- 1分：机械生硬

### 5. 精炼度（/10）
**评估**：还有可删减的内容吗？
- 10分：无冗余，每句都有信息量
- 7分：有少量可删内容
- 4分：有大量填充短语
- 1分：废话连篇

### 6. 证据性（/10）
**评估**：数据有据可查吗？观点经得起辩驳吗？
- 10分：每个核心数据有来源，每个观点通过辩驳测试
- 7分：大部分数据有来源，辩驳有记录
- 4分：数据来源不全，辩驳未执行
- 1分：无来源标注，观点经不起追问

### 评分标准

| 总分 | 等级 | 说明 |
|------|------|------|
| 54-60 | 优秀 | 去AI味+去幻觉+文体规范三达标 |
| 45-53 | 良好 | 仍有改进空间，检查低分维度 |
| 36-44 | 及格 | 需要修订，重点关注最低维度 |
| <36 | 不及格 | 需要重写 |

## 交付前自查清单

### 去AI味检查

- [ ] 连续三个句子长度相同？→ 打断一个
- [ ] 段落以简洁单行结尾？→ 变换结尾方式
- [ ] 有破折号？→ 检查是否必要
- [ ] 解释隐喻或比喻？→ 相信读者能理解
- [ ] 有"此外""然而""值得注意的是"？→ 考虑删除
- [ ] 有三段式列举？→ 改为两项或四项
- [ ] 有模糊归因（"专家认为""行业报告显示"）？→ 补来源或删除
- [ ] 有通用积极结论？→ 删除或替换为具体信息
- [ ] 有AI高频词（赋能、助力、打造、引领）？→ 替换为具体动词
- [ ] 有否定式排比（"不仅……而且"）？→ 直接陈述
- [ ] 有宣传性语言？→ 用事实替代
- [ ] 有协作交流痕迹（"希望这对您有帮助"）？→ 删除
- [ ] 节奏一致性检测：相邻句子长度方差是否过小？→ 刻意混合长短

### 去幻觉检查

- [ ] 每个核心数据都有来源标注？
- [ ] 核心判断至少有2个独立来源？
- [ ] 置信度计算是否保守（不夸大）？
- [ ] 事实和判断是否已分离标注？
- [ ] 正反辩驳是否已执行？最强反驳是否已回应？
- [ ] 有无"大概、可能、听说"等模糊表述？→ 删除或标注
- [ ] 附录是否完整（如该文体需要）？
- [ ] 如果有人追问"你怎么知道？"，能立即拿出证据吗？

### 文体规范检查

- [ ] 符合该文体的格式要求？
- [ ] 语域匹配（公文不口语、小红书不学术）？
- [ ] 引用格式正确（如学术引用）？
- [ ] 标题符合该文体惯例？
- [ ] 结构符合该文体的模板？
- [ ] 长度符合该文体的惯例？

## 36项AI味检查清单（扩展自 anti-slop-writing v3.0）

### 基础12项
1. 句子长度方差是否过小？
2. 是否有"此外""然而"等连接词？
3. 是否有三段式列举？
4. 是否有破折号过度使用？
5. 是否有粗体过度使用？
6. 是否有表情符号（非小红书文体）？
7. 是否有模糊归因？
8. 是否有宣传性语言？
9. 是否有通用积极结论？
10. 是否有协作交流痕迹？
11. 是否有知识截止日期免责声明？
12. 是否有谄媚语气？

### 结构12项
13. 是否有否定式排比（"不仅……而且"）？
14. 是否有系动词回避？
15. 是否有刻意换词（同义词循环）？
16. 是否有虚假范围（"从X到Y"）？
17. 是否有内联标题垂直列表？
18. 是否有公式化的"挑战与展望"段落？
19. 是否有提纲式过度对称结构？
20. 是否有过度限定（"可能或许也许"）？
21. 是否有填充短语（"为了实现这一目标"）？
22. 是否有过度的冒号/分号连接？
23. 是否有段落碎片化（过多单句段落）？
24. 是否有Sentence DNA四部分模式（每句都是主谓宾修饰）？

### 深度12项
25. 是否有per-model方言特征（GPT的"赋能"腔/Claude的"微妙"腔）？
26. 是否有burstiness bimodal陷阱（机械的长短交替）？
27. 是否有过度强调意义和遗产？
28. 是否有过度强调知名度？
29. 是否有-ing结尾的肤浅分析（中文：彰显……/反映……）？
30. 是否有AI高频词（210+词表）？
31. 是否有翻译腔（英文结构直译）？
32. 是否有自我拔高（"开创性""革命性"）？
33. 是否有假数据感（"根据研究"但不给来源）？
34. 是否有强行升华（小事上升到"时代意义"）？
35. 是否有伪学术（简单概念用学术语言包装）？
36. 是否有鸡汤式收尾（"让我们一起""共创美好"）？
