# 药事数据清洗规则详解

本文档为药事数据分析技能的数据清洗规则参考，覆盖 5 大维度的检测规则与处置策略。

---

## 一、重复行检测

### 1.1 完全重复行

**规则**：所有列的值完全一致（含空值位置一致）的行视为完全重复行。

**检测方法**：
```python
# pandas 实现
full_duplicates = df.duplicated(keep='first')
duplicate_count = full_duplicates.sum()
```

**处置策略**：
- 保留首次出现的行（`keep='first'`）
- 删除后续重复行
- 在修改日志中记录删除的行号

**药事场景注意**：
- 调剂差错记录中，同一药品同一日期同一差错类型可能为独立事件，需检查是否有唯一标识列（如记录编号、时间戳）
- 若存在唯一标识列，应基于该列去重而非全行匹配

### 1.2 关键字段重复行

**规则**：指定关键字段组合一致的行标记为疑似重复。

**药事场景关键字段组合示例**：

| 数据类型 | 关键字段组合 |
|---------|------------|
| 调剂差错 | [日期, 药品名称, 规格, 差错类型, 差错环节] |
| 盘点数据 | [盘点日期, 药品名称, 规格, 批号, 库房] |
| 前置审方 | [处方号, 药品名称, 用法用量, 审方日期] |

**处置策略**：
- 标记为"疑似重复"，输出供用户确认
- 不自动删除，因可能为合法的独立记录

## 二、缺失值检测

### 2.1 逐列缺失统计

**规则**：对每列统计缺失值数量和占比，按缺失严重程度分级：

| 级别 | 缺失占比 | 处置策略 |
|------|---------|---------|
| 轻微 | < 5% | 非关键字段可用众数/中位数填充；关键字段标记待人工确认 |
| 中度 | 5% - 20% | 输出缺失模式分析（随机缺失 or 单调缺失）；关键字段不填充 |
| 严重 | > 20% | 列级预警，建议用户评估该字段可用性 |

### 2.2 关键字段与非关键字段分类

**关键字段（禁止自动填充）**：

- 药品名称、通用名、商品名
- 规格、剂型
- 批号、有效期
- 差错类型、差错等级、差错环节
- 处方号、医嘱号
- 患者标识（脱敏后）
- 数量、金额
- 审方结论、干预措施

**非关键字段（可填充并标注）**：

- 操作人员（可填充"未知"）
- 备注（可填充空字符串）
- 部门名称（若可从其他字段推断）

### 2.3 缺失模式分析

检测缺失是否为随机（MCAR）、有规律的缺失（MAR）或非随机缺失（MNAR）：

- 检查缺失值与其他字段的相关性
- 如"差错等级"在"节假日"缺失 → 可能系统性漏报
- 输出缺失模式小结，辅助用户判断数据质量

##三、日期与数字格式检测

### 3.1 日期格式

**常见问题**：
- 混合格式："2024/1/5"、"2024-01-05"、"05/01/2024"、"2024年1月5日"
- Excel 序列号："45659"（对应 2024-12-31）
- 文本日期："二〇二四年一月五日"

**标准化规则**：
- 统一输出为 ISO 8601 格式：`YYYY-MM-DD`
- 日期时间字段输出为：`YYYY-MM-DD HH:MM:SS`
- 无法解析的日期标记为"待人工确认"

**药事场景特殊日期**：
- 有效期：可能为"2025.12"或"2025-12"（仅年月），标准化为该月最后一天 "2025-12-31"
- 批号内含日期：如"20241201A"需提取日期部分

### 3.2 数字格式

**常见问题**：
- 数字存为文本："123"（文本型）vs 123（数值型）
- 混入单位文字："500mg"、"2.5ml"、"100片"
- 千分位逗号："1,000"
- 全角数字："１２３"
- 科学计数法："1.5E+3"

**标准化规则**：
- 提取纯数值部分，单位单独存列或附加到字段名
- 去除千分位逗号
- 全角数字转半角
- 统一为 float 或 int 类型

**药事场景特殊数值**：
- 数量字段：必须为非负整数或非负小数（允许 0，不允许负数）
- 金额字段：保留 2 位小数
- 差异率：百分比格式，范围 -100% 到 +∞

## 四、异常值检测

### 4.1 数值越界

**规则**：基于业务规则设定合理范围，超出范围的值标记为异常。

**药事场景常见异常范围**：

| 字段 | 合理范围 | 异常判定 |
|------|---------|---------|
| 调剂数量 | 0 - 10000（依据场景调整） | 负数或超大值 |
| 药品单价 | > 0 | 0 或负数 |
| 盘点差异 | -100% ~ +100% | 差异率绝对值 > 50% 时预警 |
| 处方剂量 | 参照药品说明书极量 | 超极量记录标记 |
| 差错发生到上报天数 | 0 - 365 | 负数或 > 365 |

### 4.2 逻辑矛盾

**检测规则**：
- 结束时间 < 开始时间（如审方完成时间 < 处方开具时间）
- 有效期 < 生产日期
- 实盘数 = 0 但账面数 > 0 且差异率 = 0（可能漏盘）
- 差错等级 = "轻微"但采取了"停药"措施（等级与措施不匹配）
- 药品规格与剂量单位不匹配（如规格"片"但剂量写"ml"）

### 4.3 统计离群点

**方法**：
- IQR 法（四分位距）：值 < Q1 - 1.5×IQR 或 > Q3 + 1.5×IQR
- Z-score 法：|Z| > 3

**适用场景**：
- 盘点差异金额的离群点检测
- 差错频次的异常高值检测

**处置策略**：
- 标记为"统计离群点"，附上统计参数
- 不自动删除，输出供用户判断
- 特别提示：药事数据中离群点可能是真实的高风险事件，不可随意剔除

## 五、字段一致性检测

### 5.1 文本规范

**常见问题**：
- 大小写混用："aspirin" / "Aspirin" / "ASPIRIN"
- 全半角混用："阿司匹林　片"（全角空格）/ "阿司匹林 片"（半角空格）
- 首尾空格：" 阿司匹林 "
- 不可见字符：零宽空格、BOM 等

**标准化规则**：
- 药品名称统一为首字母大写或全大写（参照院内标准）
- 全角字符转半角（数字、字母、空格）
- 去除首尾空格和不可见字符
- 内部连续空格压缩为单个空格

### 5.2 同义异名映射

**常见药事场景**：

| 异名 | 规范名称 | 说明 |
|------|---------|------|
| 阿斯匹灵 / 阿斯匹林 / ASA | 阿司匹林 | 通用名标准化 |
| 普通胰岛素 / 正规胰岛素 | 胰岛素（常规） | 剂型标准化 |
| NS / 生理盐水 | 氯化钠注射液 | 通用名标准化 |
| 头孢三代 / 三代头孢 | 头孢菌素（第三代） | 分类标准化 |

**处置策略**：
- 建立映射表，记录每条替换
- 无法自动映射的输出"待人工确认"清单
- 映射表随修改日志一并交付

### 5.3 枚举值校验

**规则**：对分类字段校验取值是否在预设枚举范围内。

**药事场景常见枚举字段**：

| 字段 | 合法取值示例 |
|------|------------|
| 差错类型 | 调配差错、发药差错、标签差错、数量差错、药品差错 |
| 差错等级 | 轻微、一般、严重、致命 |
| 差错环节 | 收方、调配、核对、发药、运输 |
| 审方结论 | 通过、驳回、修改后通过、转人工审 |
| 盘点类型 | 全盘、抽盘、日盘、月盘 |
| 药品分类 | 西药、中成药、中药饮片、生物制品 |

**处置策略**：
- 不在枚举范围内的值标记为"枚举异常"
- 输出异常值列表及建议映射
- 不自动修改，供用户确认

## 清洗输出文件规范

### 修改日志格式

| 列名 | 说明 |
|------|------|
| 序号 | 自增编号 |
| 原行号 | 数据中的原始行号 |
| 列名 | 被修改的字段 |
| 原值 | 修改前的值 |
| 新值 | 修改后的值 |
| 规则编号 | 对应清洗规则的编号（如 R-DUP-01） |
| 规则描述 | 简述规则内容 |
| 处理时间 | 执行时间戳 |
| 备注 | 额外说明 |

### 无法处理项格式

| 列名 | 说明 |
|------|------|
| 序号 | 自增编号 |
| 原行号 | 数据中的原始行号 |
| 列名 | 相关字段 |
| 问题描述 | 具体问题描述 |
| 问题类型 | 重复/缺失/格式/异常/一致性 |
| 建议处置 | 人工处置建议 |
| 严重程度 | 高/中/低 |

### 规则编号体系

| 前缀 | 维度 |
|------|------|
| R-DUP | 重复行 |
| R-MIS | 缺失值 |
| R-FMT | 日期与数字格式 |
| R-OUT | 异常值 |
| R-CON | 字段一致性 |
