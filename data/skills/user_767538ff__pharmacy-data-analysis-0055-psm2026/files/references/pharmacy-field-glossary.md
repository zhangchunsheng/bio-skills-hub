# 药事数据字段词表与规范格式

本文档汇总药品调剂差错、药房盘点、前置审方回顾点评三类药事数据的常见字段、预期数据类型和规范格式，供数据清洗时参照。

---

## 一、药品调剂差错数据

### 1.1 核心字段

| 字段名 | 英文标识 | 数据类型 | 规范格式 | 示例 |
|--------|---------|---------|---------|------|
| 记录编号 | record_id | 字符串 | 唯一标识，建议格式 CCD-YYYYMMDD-NNN | CCD-20250105-001 |
| 差错发生日期 | error_date | 日期 | YYYY-MM-DD | 2025-01-05 |
| 差错发现日期 | detect_date | 日期 | YYYY-MM-DD | 2025-01-06 |
| 上报日期 | report_date | 日期 | YYYY-MM-DD | 2025-01-07 |
| 药品名称（通用名） | drug_generic_name | 字符串 | 参照《中国药品通用名称》 | 阿司匹林 |
| 药品商品名 | drug_brand_name | 字符串 | 原始商品名 | 拜阿司匹灵 |
| 规格 | specification | 字符串 | 数值+单位，无多余空格 | 100mg |
| 剂型 | dosage_form | 枚举 | 片剂/胶囊剂/注射液/口服液/软膏剂/... | 片剂 |
| 批号 | batch_number | 字符串 | 原始批号 | 20241201A |
| 有效期 | expiry_date | 日期 | YYYY-MM-DD（年月补全为月末） | 2025-12-31 |
| 差错类型 | error_type | 枚举 | 见下方枚举表 | 药品差错 |
| 差错等级 | error_level | 枚举 | 见下方枚举表 | 严重 |
| 差错环节 | error_stage | 枚举 | 见下方枚举表 | 调配 |
| 是否高警示药品 | is_high_alert | 布尔 | 是/否 | 是 |
| 涉及数量 | quantity | 数值 | 正整数或正小数 | 2 |
| 差错描述 | description | 文本 | 自由文本 | 错发为外观相似的氯吡格雷 |
| 原因分析 | root_cause | 文本 | 自由文本 | 药品外观相似、调配时未核对 |
| 改进措施 | corrective_action | 文本 | 自由文本 | 增设高警示药品专区、调配双核对 |
| 操作人员（脱敏） | operator_id | 字符串 | 脱敏编号 | OP-001 |
| 科室/病区 | department | 字符串 | 院内标准科室名称 | 心内科一病区 |

### 1.2 差错类型枚举

| 枚举值 | 定义 |
|--------|------|
| 药品差错 | 发放了错误的药品（不同于处方药品） |
| 数量差错 | 发放数量与处方不符 |
| 剂型差错 | 发放了错误的剂型 |
| 规格差错 | 发放了错误的规格/浓度 |
| 标签差错 | 标签信息错误或缺失 |
| 用法用量差错 | 标注的用法用量与处方不符 |
| 效期差错 | 发放了过期或近效期药品 |
| 漏发差错 | 处方药品未全部发出 |
| 重复发药 | 已发药品重复发出 |

### 1.3 差错等级枚举

| 枚举值 | 定义 | 参照标准 |
|--------|------|---------|
| 轻微 | 未到达患者或未造成影响 | NCC MERP A/B 级 |
| 一般 | 到达患者但未造成伤害 | NCC MERP C 级 |
| 严重 | 需要干预或造成暂时性损害 | NCC MERP D/E 级 |
| 致命 | 导致永久损害或死亡 | NCC MERP F/H/I 级 |

### 1.4 差错环节枚举

| 枚举值 | 定义 |
|--------|------|
| 收方 | 接收处方/医嘱环节 |
| 调配 | 拿药/配药环节 |
| 核对 | 药品发放前核对环节 |
| 发药 | 药品交付患者/病区环节 |
| 运输 | 药品运送至病区环节 |

## 二、药房盘点数据

### 2.1 核心字段

| 字段名 | 英文标识 | 数据类型 | 规范格式 | 示例 |
|--------|---------|---------|---------|------|
| 盘点日期 | inventory_date | 日期 | YYYY-MM-DD | 2025-01-31 |
| 盘点类型 | inventory_type | 枚举 | 全盘/抽盘/日盘/月盘/季盘 | 月盘 |
| 药品名称（通用名） | drug_generic_name | 字符串 | 参照药品字典 | 氯化钠注射液 |
| 规格 | specification | 字符串 | 数值+单位 | 0.9% 250ml |
| 剂型 | dosage_form | 枚举 | 同差错数据 | 注射液 |
| 批号 | batch_number | 字符串 | 原始批号 | 20240615B |
| 有效期 | expiry_date | 日期 | YYYY-MM-DD | 2026-06-30 |
| 库房/药房 | storage_location | 字符串 | 院内标准名称 | 中心药房-西药库 |
| 货位号 | shelf_location | 字符串 | 货架编号 | A-03-12 |
| 账面数量 | book_quantity | 数值 | 非负数 | 150 |
| 实盘数量 | actual_quantity | 数值 | 非负数 | 148 |
| 差异数量 | diff_quantity | 数值 | 实盘 - 账面 | -2 |
| 差异率 | diff_rate | 百分比 | (实盘-账面)/账面 ×100% | -1.33% |
| 账面单价 | unit_price | 数值 | >0，保留2位小数 | 3.50 |
| 差异金额 | diff_amount | 数值 | 差异数量 × 单价 | -7.00 |
| 差异原因 | diff_reason | 枚举 | 见下方枚举表 | 漏发 |
| 盘点人（脱敏） | counter_id | 字符串 | 脱敏编号 | CT-005 |
| 复核人（脱敏） | reviewer_id | 字符串 | 脱敏编号 | RV-002 |

### 2.2 差异原因枚举

| 枚举值 | 定义 |
|--------|------|
| 漏发 | 处方已发但库存未扣减 |
| 多发 | 库存多扣减 |
| 损耗 | 药品破损、过期等非发药原因减少 |
| 入库差错 | 入库数量记录错误 |
| 退药未入 | 退回药品未入库存 |
| 调拨差错 | 科室间调拨记录错误 |
| 初始库存错误 | 期初库存设置错误 |
| 不明原因 | 无法确定具体原因 |

## 三、前置审方回顾点评数据

### 3.1 核心字段

| 字段名 | 英文标识 | 数据类型 | 规范格式 | 示例 |
|--------|---------|---------|---------|------|
| 处方号 | prescription_id | 字符串 | 院内处方编号 | RX20250105001 |
| 医嘱号 | order_id | 字符串 | 院内医嘱编号 | MO20250105001 |
| 处方日期 | rx_date | 日期 | YYYY-MM-DD | 2025-01-05 |
| 审方日期 | review_date | 日期 | YYYY-MM-DD | 2025-01-05 |
| 审方时间 | review_time | 时间 | HH:MM:SS | 14:30:00 |
| 科室 | department | 字符串 | 院内标准名称 | 呼吸内科 |
| 医生（脱敏） | prescriber_id | 字符串 | 脱敏编号 | DR-010 |
| 患者年龄 | patient_age | 数值 | 正整数 | 65 |
| 患者性别 | patient_gender | 枚举 | 男/女 | 男 |
| 是否高警示药品 | is_high_alert | 布尔 | 是/否 | 是 |
| 药品名称 | drug_name | 字符串 | 通用名 | 华法林钠 |
| 规格 | specification | 字符串 | 数值+单位 | 3mg |
| 用法 | usage_route | 枚举 | 口服/静脉注射/静脉滴注/肌肉注射/... | 口服 |
| 用量 | dosage | 字符串 | 数值+单位+频次 | 3mg qd |
| 审方结论 | review_result | 枚举 | 见下方枚举表 | 修改后通过 |
| 不合理类型 | irrational_type | 枚举 | 见下方枚举表 | 用法用量不当 |
| 问题描述 | problem_desc | 文本 | 自由文本 | 华法林剂量超出常规 |
| 干预措施 | intervention | 枚举 | 见下方枚举表 | 联系医生修改 |
| 干预结果 | intervention_result | 枚举 | 已采纳/未采纳/待回复 | 已采纳 |
| 审方药师（脱敏） | pharmacist_id | 字符串 | 脱敏编号 | PH-003 |

### 3.2 审方结论枚举

| 枚举值 | 定义 |
|--------|------|
| 通过 | 医嘱合理，直接通过 |
| 修改后通过 | 医嘱有问题，医生修改后通过 |
| 驳回 | 医嘱不合理，退回医生 |
| 转人工审 | 系统无法判定，转人工审核 |
| 警示后通过 | 存在潜在风险但医生确认后通过 |

### 3.3 不合理类型枚举

| 枚举值 | 定义 |
|--------|------|
| 适应证不适宜 | 药品与诊断不符 |
| 用法用量不当 | 给药途径、剂量、频次不合理 |
| 联合用药不适宜 | 药物相互作用或重复用药 |
| 配伍禁忌 | 溶媒或配伍不合理 |
| 疗程不适宜 | 用药时长不合理 |
| 特殊人群禁忌 | 孕妇、儿童、肝肾功能不全等禁忌 |
| 超量用药 | 超出药品说明书极量 |
| 选药不适宜 | 同类药品中有更优选择 |

### 3.4 干预措施枚举

| 枚举值 | 定义 |
|--------|------|
| 联系医生修改 | 电话或系统消息联系处方医生 |
| 退回处方 | 系统驳回处方 |
| 药师建议 | 发送药师建议供医生参考 |
| 上报药事会 | 严重问题上报药事管理委员会 |
| 无需干预 | 记录备查但无需干预 |

## 四、通用规范

### 4.1 脱敏规则

- 患者姓名：替换为 P-XXXX 格式编号
- 医生/药师姓名：替换为 D-XXXX / PH-XXXX 格式编号
- 患者身份证号：仅保留出生年份和性别位
- 患者联系方式：完全移除

### 4.2 量纲与单位

| 字段类别 | 规范单位 | 说明 |
|---------|---------|------|
| 质量 | mg / g / kg | 不可混用 |
| 容量 | ml / L | 不可混用 |
| 浓度 | % / mg·ml⁻¹ | 统一标注 |
| 金额 | 元 | 保留 2 位小数 |
| 比率 | ‰ / % | 差错率用‰，差异率用% |
| 温度 | °C | 冷链记录 |

### 4.3 空值表示

- 统一用空字符串表示文本型空值
- 数值型空值不填充任何值（不填 0、不填 -1）
- 布尔型空值填"未知"
- 日期型空值不填充任何值
