# 药事数据可视化图表选择指南

本文档为药事数据分析技能的可视化建议参考，覆盖图表选择原则、药事场景推荐图表类型、常见误读防范和仪表盘布局设计。

---

## 一、图表选择决策框架

### 1.1 按分析目标选择图表

| 分析目标 | 适用图表类型 | 典型场景 |
|---------|------------|---------|
| 趋势变化 | 折线图、面积图 | 月度差错数量趋势、盘点差异率月度变化 |
| 对比排序 | 柱状图（竖向/横向）、条形图 | 不同科室差错数对比、不同药品类别差异率排序 |
| 占比构成 | 饼图、环形图、堆叠柱状图 | 差错类型占比、差错环节分布 |
| 关联关系 | 散点图、气泡图 | 差错数与调剂量相关性、药品单价与差异金额关系 |
| 分布特征 | 直方图、箱线图、小提琴图 | 差错金额分布、盘点差异率分布 |
| 流程转化 | 漏斗图 | 处方审核流程各环节通过率 |
| 多维对比 | 雷达图、热力图 | 多科室多维度差错综合评价 |
| 时间-频次 | 日历热力图、日历事件图 | 差错发生的时间规律（日历热力图） |
| 地理分布 | 地图 | 跨院区/跨科室差错分布 |

### 1.2 按数据类型选择图表

| 数据特征 | 推荐图表 |
|---------|---------|
| 时间序列（1个数值维度 + 时间维度） | 折线图 |
| 分类数据（1个分类维度 + 1个数值维度） | 柱状图/条形图 |
| 占比数据（1个分类维度，总占比=100%） | 饼图（分类数 ≤ 7）或条形图（分类数 > 7） |
| 二维分类交叉 | 热力图、堆叠柱状图 |
| 连续数值分布 | 直方图、箱线图 |
| 二维数值关系 | 散点图 |

## 二、药事场景图表推荐模板

### 2.1 药品调剂差错分析

#### 场景一：差错总体趋势

```
图表名称：月度调剂差错数量与差错率双轴趋势图
- 图表类型：组合图（柱状图 + 折线图，双 Y 轴）
- 回答的问题：差错数量和差错率随时间的变化趋势如何？是否有季节性规律？
- 使用字段：X轴=[月份], Y轴左=[差错数量], Y轴右=[差错率(‰)]
- 排序方式：按月份升序
- 筛选条件：全量数据
- 可能误读点：
  - 双 Y 轴可能导致读者错误比较两根线的交叉点，需标注各自刻度
  - 差错率分母（总调剂量）若月度波动大，需在注释中标明
  - 月份变化可能导致"日历月天数不同"的偏差，建议用日均差错率
```

#### 场景二：差错类型分布

```
图表名称：调剂差错类型帕累托图
- 图表类型：帕累托图（柱状图 + 累计百分比折线）
- 回答的问题：哪些差错类型是主要问题？累计 80% 的差错由哪些类型构成？
- 使用字段：X轴=[差错类型], Y轴左=[差错数量], Y轴右=[累计百分比]
- 排序方式：按差错数量降序
- 筛选条件：全量数据
- 可能误读点：
  - 帕累托图的 80% 参考线须标注，否则累计线意义不明确
  - 差错类型分类粒度须一致（不应混用大类和小类）
```

#### 场景三：差错环节与类型交叉

```
图表名称：差错环节 × 差错类型热力图
- 图表类型：热力图
- 回答的问题：哪个环节的哪类差错最集中？是否存在环节-类型交叉热点？
- 使用字段：X轴=[差错类型], Y轴=[差错环节], 颜色深浅=[差错数量]
- 排序方式：按差错总量降序排列坐标轴
- 筛选条件：全量数据
- 可能误读点：
  - 颜色映射须用连续色阶且标注数值范围
  - 若某格数量为 0，需明确区分"0"和"无数据"
  - 颜色深浅的感知差异非线性，建议附数值标签
```

#### 场景四：高风险药品差错

```
图表名称：高警示药品差错占比与严重程度分布
- 图表类型：环形图 + 分组柱状图（组合）
- 回答的问题：高警示药品在总差错中的占比多大？其差错严重程度分布如何？
- 使用字段：
  - 环形图：[是否高警示药品] → 占比
  - 柱状图：X轴=[差错等级], Y轴=[差错数量], 分组=[是否高警示药品]
- 排序方式：差错等级按"致命→严重→一般→轻微"降序
- 筛选条件：全量数据
- 可能误读点：
  - 环形图占比的分母须标明（差错次数 vs 差错涉及药品数）
  - 高警示药品分类标准须注明依据（如参照院内目录或 ISMP 标准）
```

### 2.2 药房盘点数据分析

#### 场景一：盘点差异率分布

```
图表名称：药品类别盘点差异率箱线图
- 图表类型：分组箱线图
- 回答的问题：不同药品类别的盘点差异率分布如何？是否存在系统性偏差的类别？
- 使用字段：X轴=[药品类别], Y轴=[盘点差异率(%)], 分组=[盘盈/盘亏]
- 排序方式：按中位数绝对值降序
- 筛选条件：排除差异率 > 200% 的极端异常值（单独列出）
- 可能误读点：
  - 箱线图隐藏了样本量，须标注每组 N 值
  - 差异率正负方向（盘盈为正、盘亏为负）须在图例中标明
  - 单个极端值可能拉大须线范围，建议同时输出原始散点
```

#### 场景二：差异金额 TOP 药品

```
图表名称：盘点差异金额 TOP 20 药品双向条形图
- 图表类型：双向条形图（盘亏向左，盘盈向右）
- 回答的问题：哪些药品的盘点差异金额最大？盘亏和盘盈的分布如何？
- 使用字段：Y轴=[药品名称], X轴=[差异金额], 颜色=[盘亏/盘盈]
- 排序方式：按差异金额绝对值降序，取 TOP 20
- 筛选条件：全量数据
- 可能误读点：
  - 金额大不等于差错严重，可能是单价高但差异小，须附差异率参考线
  - 药品名称可能过长，须截断或换行处理
  - 正负方向须清晰标注（左为盘亏、右为盘盈，或相反）
```

### 2.3 前置审方回顾点评

#### 场景一：审方结论分布与趋势

```
图表名称：前置审方结论分布与月度趋势
- 图表类型：堆叠面积图
- 回答的问题：审方结论的构成比例如何？各类结论的月度变化趋势如何？
- 使用字段：X轴=[月份], Y轴=[审方结论数量], 堆叠=[审方结论类型]
- 排序方式：按月份升序
- 筛选条件：全量数据
- 可能误读点：
  - 堆叠面积图的总量随时间变化时，各层厚度可能误导比例感知
  - 建议同时提供百分比堆叠版本作为辅助
```

#### 场景二：不合理医嘱类型分析

```
图表名称：不合理医嘱类型与涉及药品类别的交叉气泡图
- 图表类型：气泡图
- 回答的问题：哪类不合理医嘱涉及哪些药品类别最多？严重程度如何？
- 使用字段：X轴=[不合理医嘱类型], Y轴=[药品类别], 气泡大小=[医嘱数量], 颜色=[严重程度]
- 排序方式：按医嘱数量降序
- 筛选条件：审方结论 = 不合理
- 可能误读点：
  - 气泡大小须标注映射规则（面积 vs 半径）
  - 颜色编码严重程度须用有序色阶（如浅黄→深红）
```

## 三、常见误读防范清单

| 图表类型 | 常见误读 | 防范措施 |
|---------|---------|---------|
| 饼图 | 分类过多导致难以比较 | 分类 > 7 时改用条形图 |
| 饼图 | 3D 效果扭曲比例 | 禁用 3D 饼图 |
| 柱状图 | Y 轴不从 0 开始 | 必须从 0 开始，或明确标注截断 |
| 折线图 | 时间轴不等距 | 须等距标注，缺失时段留空 |
| 双轴图 | 两根线交叉点的视觉误导 | 各轴须独立标注刻度 |
| 热力图 | 色盲不友好 | 避免红绿配色，改用蓝白红或 Viridis 色阶 |
| 箱线图 | 忽略样本量 | 每组标注 N 值 |
| 散点图 | 数据点重叠遮挡 | 使用透明度或密度图替代 |
| 地图 | 面积大小影响感知 | 改用气泡地图或分级统计图 |

## 四、仪表盘页面布局设计原则

### 4.1 布局结构

```
┌─────────────────────────────────────────────┐
│              页面标题 + 时间范围              │
├──────────┬──────────┬──────────┬──────────────┤
│ KPI 卡片1 │ KPI 卡片2 │ KPI 卡片3 │ KPI 卡片4   │
├──────────┴──────────┴──────────┴──────────────┤
│                                               │
│              主图1（趋势/分布）                │
│              （占页面宽度的 2/3 或全宽）        │
│                                               │
├───────────────────────┬───────────────────────┤
│                       │                       │
│    辅助图2            │    辅助图3            │
│    （交叉分析）        │    （排名/占比）        │
│                       │                       │
├───────────────────────┴───────────────────────┤
│              明细数据表（可选）                 │
└───────────────────────────────────────────────┘
```

### 4.2 布局原则

1. **Z 型阅读路径**：左上→右上→左下→右下，重要信息放左上
2. **KPI 卡片**：2-4 个核心指标，含同比/环比变化标注
3. **主图**：回答最核心问题的图表，占最大面积
4. **辅助图**：从不同角度补充主图结论
5. **颜色一致性**：同一分类在不同图表中使用相同颜色
6. **留白**：图表之间保留充足间距，避免视觉拥挤
7. **标注**：每张图须有标题、坐标轴标签、数据来源、说明注释

### 4.3 KPI 卡片设计

每个 KPI 卡片包含：
- 指标名称
- 当前值（大字号）
- 同比/环比变化（带方向箭头和颜色）
- 迷你趋势线（sparkline，可选）

**药事场景常用 KPI**：
- 总差错数 / 差错率（‰）
- 高警示药品差错占比
- 盘点差异率（%）
- 盘亏金额（元）
- 审方不合理率（%）
- 干预成功率（%）

## 五、可视化输出 Word 文档结构

```
1. 分析背景概述
   - 数据来源说明
   - 分析时间范围
   - 目标读者

2. 图表推荐清单
   2.1 图表1：[名称]
       - 图表类型
       - 回答的问题
       - 使用字段
       - 排序与筛选
       - 可能误读点
   2.2 图表2：[名称]
       ...
   2.3 图表3：[名称]
       ...
   2.4 图表4：[名称]（可选）
       ...
   2.5 图表5：[名称]（可选）

3. 仪表盘页面结构方案
   - 布局示意图
   - 阅读路径说明
   - KPI 卡片设计

4. 实施注意事项
   - 数据预处理要求
   - 颜色方案建议
   - 交互设计建议（如有）
   - 导出与分享建议
```
