# 医药股 rNPV 估值

> 一句话简介（候选）：输入医药股代码，产出管线 rNPV 估值 Excel 模型，并反推市场隐含成功率。

## 这是什么

一套医药股估值分析工作流（9 阶段流水线，Stage 0–8）。输入任意 A股/港股医药股，自动完成：财务快照 → 管线映射 → 逐管线 rNPV 建模 → 分部加总 → **市场隐含成功率反推**，产出可审计的 Excel 估值模型（6 Sheet）+ 8 章分析报告。

它回答一个普通行情软件回答不了的问题：

> **以当前价格买入这只医药股，我到底押注了什么样的管线成功率？市场是太乐观还是太悲观？**

## 方法论背景（身份展示）

本工作流沉淀自医药/创新药行业投研实践，方法论核心是"双引擎"：

1. **正向估值**——算"值多少"：BIO/BioMedTracker 权威临床试验成功率基准（2011–2020 报告口径，如 Ph2→获批 15.1%、Ph3→获批 52.4%）× 峰值销售漏斗 × 折现，逐管线 rNPV 分部加总；license-out 资产按六件套（首付+里程碑+royalty+供货+海外）逐项建模
2. **⭐市场隐含反推**——算"市场押注了什么"：拆解当前市值 → 反推隐含折扣因子 λ → 与行业 PoS 基准对比 → 判读市场是低估还是高估管线

内置 7 份方法论文档（rNPV 六步法、BIO PoS 基准表、峰值销售 8 层流行病学漏斗、折现率指南、license-out 六件套建模、市场隐含反推方法、方法论总纲），每个关键假设强制标注数值/来源/置信度，Excel 模型专业规范（蓝=输入、黑=公式、绿=跨表引用，全表可审计追溯）。

## 使用方法

1. 安装技能后，直接说："**rNPV分析 恒瑞医药**"（或任意医药股名称/代码，如 "01093.HK"）
2. 这是一个**深度分析任务，通常需要数分钟**（联网搜索财报与管线数据）——技能会逐阶段汇报进度（如「Stage 2 管线映射完成」），请耐心等待
3. 获得三份交付物：
   - `Excel 模型`（6 Sheet：估值汇总/管线总览/逐管线现金流/隐含成功率/假设表/敏感性分析）
   - `分析报告`（8 章，核心是第 6 章"市场隐含视角"）
   - `结构化 JSON`（过 schema 强制校验，PASS 才算交付完成）

## 适用范围与注意事项

- ✅ **适合**：管线驱动型 Biotech（pre-revenue 或早期商业化）、创新药企业、中型 Pharma
- ⚠️ **不适合**：纯 CRO/CDMO（服务收入驱动）、仿制药、医疗器械——这类标的用传统 DCF 更合适
- 数据来自公开信息（财报/IR/ClinicalTrials.gov/CDE），多源交叉验证；不可得数据会显式标注估算
- **本技能是估值分析工具：输出是量化分析依据而非投资结论，仅供研究参考，不构成投资建议**；数据来自公开信息可能滞后或不完整，rNPV 对成功率和峰值销售假设高度敏感，投资决策请咨询持牌专业人士
