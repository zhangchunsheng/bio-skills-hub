# 医药股 rNPV 价值分析流水线

## 概述

本 Skill 定义了一个可复用的医药股估值工作流。当用户输入股票名称或代码时，按以下 9 个 Stage（Stage 0–8）依次执行，最终产出 Excel rNPV 模型 + Markdown 分析报告。

**核心问题：** 如果以当前价格买入这只医药股，我相当于押注了什么样的管线成功率？市场是太乐观还是太悲观？

**方法论体系：** 本系统基于**双引擎哲学**——正向分部估值 + ⭐反向市场隐含反推，两者缺一不可。完整理论框架见 `references/00-methodology-overview.md`（入口文档，首次使用必读）。

> **与普通 rNPV 工具的区别：** 本系统不只是正向算"值多少"，更反推"市场押注了什么"。详见总纲第二章"双引擎哲学"。

## 输入规范

| 参数 | 必填 | 说明 | 示例 |
|---|---|---|---|
| 股票名称或代码 | ✅ | 中文名、A股代码（600276.SH）、港股代码（01093.HK）| "恒瑞医药"、"01093.HK" |
| 市场 | 自动识别 | A股 / 港股，从代码后缀推断 | .SS/.SZ = A股，.HK = 港股 |

## 工作流（9 个 Stage，Stage 0–8）

### Stage 0：输入与初始化
1. 接收股票名称/代码
2. 识别市场（A股 .SS/.SZ / 港股 .HK）
3. 搜索确认：公司全称、交易所、主营业务、行业分类
4. 创建输出目录：`output/[ticker]_[YYYY-MM-DD]/`

### Stage 1：财务快照
**数据获取：** yfinance（Python）或网络搜索

需获取的财务数据：
- 当日股价、总股本、市值
- 最新财报：现金及等价物、短期投资、总有息负债
- 净现金 = 现金 + 短期投资 - 有息负债
- 年度研发费用
- 季度现金消耗（用于计算 cash runway = 净现金 / 季度烧钱）
- 总营收（如已有上市产品）

**输出：** 财务快照表（存入 Excel Summary Sheet + 报告第二章）

### Stage 2：管线映射
**数据来源：**
- 公司年报/中报（Web 搜索 "公司名 annual report pipeline"）
- 公司投资者演示文稿（Web 搜索 "公司名 investor presentation pipeline"）
- ClinicalTrials.gov（搜索公司英文名 + NCT）
- CDE 药品审评中心（中国临床试验）
- 行业数据库（丁香园、医药魔方等公开信息）

**管线拆分原则：**
- 按 **资产 × 适应症 × 地区** 拆分（同一药物不同适应症/不同地区 = 不同管线，因 PoS/峰值/权益结构不同）
- 每条管线需填写以下字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| 药物名/代号 | 国际通用名 | XX012（示例代号） |
| 靶点/机制 | 作用机制 | HER2 双抗 |
| 适应症 | 具体疾病 | HER2 阳性乳腺癌 |
| 当前阶段 | 临床前/Phase 1/2/3/NDA/已上市 | Phase 3 |
| 关键试验 | NCT 编号或试验名 | NCT0xxxxx |
| 预计读出 | 关键数据时间 | 2026H2 |
| 竞争格局 | 同靶点竞品数量/阶段 | 3 个竞品，1 个已上市 |
| 地区 | 中国/全球/美国 | 中国（CDE）|
| **权益结构** | 自营 / license-out / license-in | 中国自营，海外授权 |

**输出：** 管线总览表（存入 Excel Pipeline Sheet + 报告第三章）

### Stage 3：逐管线 rNPV 分析
**对每条管线执行四步（这是核心环节）：**

> ⚠️ **权益分流：** 管线分自营和 partnered 两类。自营走 `references/rNPV-methodology.md` 的标准模型；partnered（license-out）走 `references/partnered-asset-valuation.md` 的六件套模型（首付+里程碑+royalty+供货+海外）。**不可混用费用口径**（royalty 不扣 COGS/SG&A，供货扣 COGS）。

#### 3a. 成功率（PoS）赋值
1. 查 `references/clinical-trial-POS-benchmarks.md` 获取该阶段的行业基准 PoS
2. 按以下因素做 ±微调（每个因素标注依据）：
   - 适应症（肿瘤低、罕见病高、感染病高）
   - 试验设计（开放标签 vs 双盲对照）
   - 生物标志物筛选（加成）
   - 前期数据质量（有 Phase 2 PoC 数据可上调）
   - 监管路径（突破性疗法/孤儿药/加速审批 = 加成）
3. 记录：基准 PoS → 调整因素 → 最终 PoS

**BIO 基准速查（详见 references）：**
- Phase 1 → 获批：~7.9%
- Phase 2 → 获批：~15.1%
- Phase 3 → 获批：~52.4%
- NDA → 获批：~90.6%

#### 3b. 峰值销售额估算
遵循 `references/peak-sales-framework.md` 的漏斗法：

```
峰值销售 = 目标患者数 × 诊断率 × 生物标志物匹配率 × 治疗线适用率
          × 峰值渗透率 × 依从性 × 年治疗费用 × 竞争折价
```

需估算：
- 目标患者人群（流行病学数据，Web 搜索 "适应症 prevalence/incidence"）
- 渗透率（参考竞争格局，独家 20-40%，多竞品 5-15%）
- 年治疗费用（参考已上市同类药，Web 搜索 "药品名 price annual cost"）
- 达峰时间（通常上市后 5-6 年）

#### 3c. 收入曲线与现金流
- 预计上市年份 = 当前年份 + 该阶段标准推进时间
  - Phase 1 → 上市：+6-8 年
  - Phase 2 → 上市：+4-5 年
  - Phase 3 → 上市：+2-3 年
  - NDA → 上市：+1 年
- 爬坡曲线（占峰值 %）：Y1=10%, Y2=25%, Y3=50%, Y4=75%, Y5=90%, Y6=100%
- 专利到期后下降：每年 -20~-30%（仿制药/生物类似药冲击）
- 费用率（**加法口径** `margin = (1-cogs-sga)*(1-tax)`，不用乘法）：
  - COGS：生物药 ~20%，化药 ~15%，细胞/基因治疗 ~30%
  - SG&A：占收入 30-40%（销售峰值后降至 20-25%）
  - 税率：中国 15%（高新技术企业）/ 25%（标准），海外 21%

#### 3d. 折现与 rNPV
- 折现率（WACC）：查 `references/discount-rate-guide.md`
  - Biotech（pre-revenue）：12-15%
  - 商业化阶段 Pharma：8-12%
  - 大型药企：7-9%
- rNPV 计算：
  ```
  rNPV = PoS × Σ [ 年度FCF_t / (1+WACC)^t ]    t = 1 to N
  FCF = 收入 × (1 - COGS率 - SG&A率) × (1 - 税率)    ← 加法口径
  ```

**输出：** 每条管线的 rNPV（存入 Excel rNPV Detail Sheet）

### Stage 4：分部加总估值
```
企业价值 = Σ(各管线 rNPV) + 已上市产品 DCF + 平台/技术价值(可选)
        + partnered 资产（首付+里程碑+royalty+供货）
股权价值 = 企业价值 + 净现金 - 预期稀释
每股内在价值 = 股权价值 / 总股本

溢价/折价 = (每股内在价值 - 当前股价) / 当前股价
```

**预期稀释处理：**
- 若 cash runway < 2 年，预估需增发的股份数（按当前股价的 80% 折价增发）
- 加入稀释后重新计算每股价值

**输出：** 估值汇总（存入 Excel Summary Sheet + 报告第五章）

### Stage 5：⭐市场隐含分析（核心洞察）
**这是本系统独有的最高价值环节。**

遵循 `references/reverse-rnpv-method.md`：

1. **拆解当前市值：**
   ```
   市场隐含管线价值 = 当前市值 - 已上市产品NPV - 净现金（+ 平台价值）
   ```

2. **反推市场隐含折扣因子 λ：**
   - 设各管线的无风险 PV（PoS=100% 时的现值）为 PV_i
   - 求解：λ = 市场隐含管线价值 / Σ PV_i

3. **判读（必须双报 λ 和 λ/加权PoS）：**
   - **λ/加权PoS** < 0.7 → 显著悲观（市场低估管线）
   - 0.7-1.0 → 偏悲观
   - 1.0-1.3 → 合理偏高
   - 1.3-1.5 → 偏乐观
   - **λ/加权PoS** > 1.5 → 显著乐观（市场高估管线）
   - ⚠️ λ 绝对值 < 100% **不代表**市场悲观——研发期管线 PoS 永远 < 100%

4. **结论判断：**
   - 市场 λ/加权PoS **显著低于** 1 → 可能低估（机会）
   - 市场 λ/加权PoS **显著高于** 1 → 可能高估（风险）
   - λ/加权PoS **接近** 1 → 定价合理

**输出：** 市场隐含分析表（存入 Excel Implied PoS Sheet + 报告第六章）

### Stage 6：风险与催化剂分析
- **风险**：临床失败、竞争加剧、监管拒绝、医保降价、增发稀释
- **催化剂**：Phase 3 读出、NDA 递交、医保准入、BD 交易
- 输出填入报告第七/八章

### Stage 7：质量保证（自检 gate）
**报告标"终版"前必须过以下自检：**

#### A. 算术与口径检查
- [ ] 各管线 rNPV 之和 = 企业价值（验证无遗漏）
- [ ] 隐含 PoS 在 0-100% 之间（验证反推合理）
- [ ] 稀释后每股价值为正（验证非破产场景）
- [ ] 所有数字在 Excel 中可用公式追溯（可审计）
- [ ] **费用率用加法** `(1-cogs-sga)*(1-tax)`，确认无乘法残留
- [ ] **partnered 管线** royalty 未误扣 COGS/SG&A

#### B. 方法论纪律检查
- [ ] **λ 双报**：同时报告 λ 和 λ/加权PoS（非仅 λ 绝对值）
- [ ] **区间优先**：关键参数（PoS/峰值/WACC）用区间 + 悲观/基准/乐观三情境，非虚假单点
- [ ] **结论稳健**：估值结论在 WACC ±2% 内不翻转；若翻转则标注"不稳健"用区间表述
- [ ] **卖方共识**：未用卖方目标价作中性标尺反推模型太保守

#### C. 假设标注规范
每个关键假设必须标注：
- **数值**（如：PoS = 52%）
- **来源**（如：BIO 2011-2020 基准 Phase 3 → NDA）
- **置信度**（高/中/低）
- **调整理由**（如：因有 Phase 2 PoC 阳性数据，基准上调 +5%）

### Stage 8：产出文件

#### 8a. Excel 模型
调用 `templates/rNPV_excel_template.py`，传入结构化数据生成 6 个 Sheet：
- Summary / Pipeline / rNPV Detail / Implied PoS / Assumptions / Sensitivity
- 格式规范：蓝色=输入假设、黑色=公式、绿色=跨表引用、关键数字附来源注释

#### 8b. Markdown 报告
按 `templates/report-template.md` 结构生成，8 个章节：
1. 执行摘要（核心结论 + 低估/高估判断 + 一句话观点）
2. 公司概况与财务快照
3. 管线全景（表格 + 阶段分布）
4. 逐管线深度分析
5. 分部加总估值
6. 市场隐含视角（⭐ 核心章节）
7. 关键假设与风险
8. 结论与操作建议

#### 8c. 保存路径
```
output/[ticker]_[YYYY-MM-DD]/
  ├── [ticker]_rNPV_model.xlsx
  └── [ticker]_rNPV_report.md
```

## 执行注意事项

### 数据获取优先级
1. **yfinance（Python）** — 股价、市值、股本（最可靠）
2. **网络搜索** — 财报数据、管线信息、流行病学、定价
3. **公开数据库** — ClinicalTrials.gov、CDE、公司投资者演示文稿
4. **行业知识** — PoS 基准、费用率惯例、爬坡曲线参数

### 5 条核心纪律（不可妥协，详见 `references/00-methodology-overview.md`）
1. **费用率加法** `(1-cogs-sga)*(1-tax)`，不用乘法
2. **λ/加权PoS** 判读，不用 λ 绝对值
3. **partnered 资产** 逐项建模（六件套），不简化为单一 royalty
4. **区间优先**，禁止虚假精度单点
5. **卖方共识** 不能作中性标尺

### 免责声明
每份报告必须包含：
> ⚠️ 本报告仅供研究参考，不构成投资建议。rNPV 估值对 PoS 和峰值销售假设高度敏感，实际结果可能与预测存在重大差异。投资决策请咨询持牌专业人士。

## 适用范围

### 适合本系统的公司类型
- ✅ 管线驱动型 Biotech（pre-revenue 或早期商业化）
- ✅ 创新药企业（有明确临床管线）
- ✅ 中型 Pharma（管线 + 上市产品组合）

### 不太适合的类型
- ⚠️ 纯 CRO/CDMO（如药明康德）— 估值以服务收入为主，非管线驱动
- ⚠️ 仿制药企业 — 无创新管线，用传统 DCF 更合适
- ⚠️ 医疗器械/医疗服务 — 非药品，管线逻辑不适用
