# 峰值销售额估算框架

> 本文件提供 rNPV 计算中峰值销售的估算方法。Stage 3b 查阅。

## 一、核心漏斗模型

峰值销售估算采用**自下而上的流行病学漏斗法**：

```
峰值销售 = 流行病学基数 × 诊断率 × 分型匹配率 × 治疗线适用率
          × 峰值渗透率 × 依从性 × 年治疗费用 × 竞争折价
```

每一层都会缩减可寻址患者数。常见错误是在某一层假设 100%，导致严重高估。

## 二、漏斗各层详解

### Layer 1：流行病学基数

| 疾病类型 | 用患病率还是发病率 | 说明 |
|---|---|---|
| 慢性病（自免、糖尿病、HIV）| **患病率 (prevalence)** | 存量患者，可持续用药 |
| 急性病（感染、部分肿瘤）| **发病率 (incidence)** | 流量患者，每年新发 |
| 治愈性疾病（丙肝、部分 CAR-T）| 发病率 | 一次性治疗 |

**数据来源（Web 搜索关键词）：**
- "疾病名 prevalence China/global epidemiology"
- GLOBOCAN（全球癌症数据）：搜索 "GLOBOCAN [癌症] incidence"
- 中国癌症登记年报
- IQVIA / GlobalData 流行病学报告
- WHO Global Health Observatory

### Layer 2：诊断率

并非所有患者都被确诊。

| 疾病类型 | 典型诊断率 | 备注 |
|---|---|---|
| 常见癌症（乳腺癌、肺癌）| 85-95% | 发达地区高 |
| 罕见病 | 30-50% | 常误诊或延迟诊断 |
| 早期肿瘤 | 40-60% | 筛查覆盖率影响 |
| 自身免疫病 | 60-80% | |
| 神经退行性疾病 | 50-70% | |

### Layer 3：分型/生物标志物匹配率

精准医疗时代，药物常只对特定亚型有效。

```
匹配率 = 目标分型患者 / 总患者数

示例：
  HER2 阳性乳腺癌 = 约 15-20% 的乳腺癌患者
  EGFR 突变非小细胞肺癌 = 约 10-15%（亚洲人可达 40-50%）
  KRAS G12C 突变 = 约 13% 的非小细胞肺癌
```

**查分型比例（Web 搜索）：**
- "靶点/突变名 prevalence in 适应症"
- "HER2 positive breast cancer percentage"
- 相关临床试验的基线特征表

### Layer 4：治疗线适用率

药物在哪个治疗线使用？前线 vs 后线影响患者池大小。

```
适用率 = 该治疗线的患者数 / 总患者数

示例：
  三线+ 治疗：约 30-40% 的患者会进展到后线
  一线治疗：接近 100%（但竞争激烈）
  辅助治疗：约 60-80%（早期患者）
```

### Layer 5：峰值渗透率（市占率）

**这是最主观也最重要的假设。**

```
渗透率 = 该药物占可寻址市场的份额

影响因素：
  - 竞争产品数量（独家 vs 多竞品）
  - 疗效差异化程度（me-too vs best-in-class）
  - 定价策略
  - 销售能力
  - 医保准入
  - 地区覆盖
```

**经验渗透率参考：**

| 竞争格局 | 峰值渗透率 | 备注 |
|---|---|---|
| 独家/First-in-class | 30-50% | 早期垄断 |
| 2-3 个竞品（差异化）| 15-25% | 有特色可瓜分 |
| 5+ 竞品（me-too）| 5-10% | 红海竞争 |
| 生物类似药/仿制药 | 3-8% | 价格驱动 |

### Layer 6：依从性/持续治疗率

```
依从性 = 实际持续用药患者 / 处方患者

慢性病：60-80%（随时间下降）
肿瘤治疗：80-90%（生存期限制）
```

### Layer 7：年治疗费用

**数据来源（Web 搜索）：**
- "药品名 annual cost / price per dose"
- 已上市同类药的定价
- 中国：医保谈判后价格（搜索 "药品名 医保 价格"）
- 美国：WAC (Wholesale Acquisition Cost)
- 注意：用**净价**（gross-to-net 折扣后），非标价

**中国创新药年治疗费用参考：**

| 类型 | 年费用范围（人民币）|
|---|---|
| PD-1/PD-L1 抑制剂 | 5-15 万 |
| HER2/EGFR 靶向药 | 10-20 万 |
| CAR-T 疗法 | 80-120 万（一次性）|
| 罕见病药 | 20-100 万 |
| 常见慢性病药 | 2-8 万 |

**海外创新药参考：**

| 类型 | 年费用（美元）|
|---|---|
| 罕见病/基因治疗 | $200K-$2M+ |
| 肿瘤免疫药 | $100K-$200K |
| 自身免疫生物药 | $30K-$80K |
| 慢性病化药 | $5K-$20K |

### Layer 8：竞争折价

新药相对已上市药物可能有溢价或折价：

| 情况 | 折价/溢价 |
|---|---|
| 疗效显著优于现有标准 | +20~50% 溢价 |
| 同类 me-too | -10~30% 折价 |
| 首仿/生物类似药 | -30~60% 折价 |
| 孤儿药（小群体高定价）| 溢价（高单价补偿小群体）|

## 三、完整计算示例

**案例：某 HER2 双抗（乳腺癌三线治疗，中国市场）**

```
Layer 1: 中国乳腺癌年发病人数 = 42 万（GLOBOCAN）
Layer 2: 诊断率 = 90% → 37.8 万
Layer 3: HER2 阳性比例 = 20% → 7.56 万
Layer 4: 三线+ 适用率 = 35% → 2.65 万
Layer 5: 峰值渗透率 = 25%（2-3 个竞品，有差异化）→ 6,615 人
Layer 6: 依从性 = 85% → 5,623 人
Layer 7: 年治疗费用 = 15 万 RMB
Layer 8: 无折价（first-in-class 双抗优势）

峰值销售 = 5,623 × 15 万 = 8.43 亿 RMB ≈ $117M
```

**交叉验证（top-down）：**
- 参考已上市 HER2 药物（曲妥珠单抗峰值 ~$70 亿全球，中国市场 ~20 亿）
- 三线双抗作为差异化产品，$117M 峰值在合理范围（约占曲妥珠单抗中国市场的 5%）

## 四、达峰曲线

上市后收入爬坡的标准曲线（占峰值百分比）：

| 上市后年份 | 占峰值 % | 说明 |
|---|---|---|
| Y1 | 10% | 上市初期，医生/患者认知建立 |
| Y2 | 25% | 医保准入逐步推进 |
| Y3 | 50% | 进入快速放量期 |
| Y4 | 75% | |
| Y5 | 90% | 接近峰值 |
| Y6 | 100% | 达峰 |
| Y7 | 95% | 专利到期前维持 |
| Y8+ | -20%/年 | 仿制药/生物类似药冲击 |

**调整因素：**
- 有强大销售团队的大药企：达峰更快（Y4-5 达峰）
- 小 Biotech 首个产品：达峰更慢（Y7-8 达峰）
- 孤儿药/罕见病：可能 Y2-3 即达峰（患者群体小，快速覆盖）

## 五、常见错误

1. ❌ **用发病率代替患病率**（慢性病）→ 高估患者池
2. ❌ **忽略分型匹配率**→ 将全人群视为目标
3. ❌ **假设 30%+ 渗透率给 me-too 药**→ 忽略竞争
4. ❌ **用标价而非净价**→ 高估 20-50%
5. ❌ **忽略医保谈判降价**（中国市场尤其重要）→ 中国创新药上市 2-3 年后通常降价 40-60% 进入医保
6. ❌ **不设达峰上限**→ 误以为会无限增长

## 六、中国特有考量

1. **医保谈判（NRDL）：** 创新药上市 2-3 年后通常通过谈判进入国家医保目录，降价 40-60% 但换取渗透率大幅提升。建模时应考虑医保前（高价低量）和医保后（低价高量）两阶段。

2. **集采（VBP）：** 仿制药和部分生物类似药面临集中带量采购，中标价可能降至原来的 10-30%。创新药短期内不受影响。

3. **出海授权（License-out）：** 中国创新药常将海外权益授权给跨国药企，获得首付款 + 里程碑 + 专利使用费（royalty 5-15%）。rNPV 中海外市场应以 royalty 收入计算，非全额销售。

4. **审评加速：** CDE 优先审评、突破性治疗药物、附条件批准等加速通道可缩短上市时间 1-2 年。
