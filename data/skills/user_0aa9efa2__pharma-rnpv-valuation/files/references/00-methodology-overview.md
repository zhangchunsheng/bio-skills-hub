> 本文件是医药股 rNPV 估值系统的**理论入口与体系总纲**。它把 6 篇专题 references 串成一个完整框架。

## 一、为什么用 rNPV

医药股（尤其是创新药 / Biotech）的价值主要由**临床管线**驱动。管线是二元事件——临床试验要么成功、要么失败，这与传统公司的连续性现金流本质不同。rNPV（Risk-Adjusted Net Present Value，风险调整净现值）是处理这种二元风险的标准估值方法。

### 三种估值方法对比

| 维度 | 可比公司（Comps） | 传统 DCF | **rNPV** |
|---|---|---|---|
| 核心逻辑 | 找相似公司，按倍数（PE/PS/EV）定价 | 预测未来现金流，折现求和 | 同 DCF，但**每条管线乘以成功率 PoS** |
| 处理临床风险 | ❌ 无法体现管线成败 | ❌ 用单一折现率粗糙吸收 | ✅ 每条管线独立赋 PoS |
| 适用对象 | 已盈利成熟药企 | 商业化阶段 Pharma | **管线驱动型 Biotech / 创新药** |
| 本系统定位 | 辅助交叉验证 | 已上市产品部分用 DCF | **核心引擎** |

> 本系统采用**混合法**：管线走 rNPV，已上市产品走 DCF，两者分部加总。这不是"纯 rNPV"，而是"rNPV 为主 + DCF 补充"的双结构。

## 二、双引擎哲学（本系统的核心）

本系统**不只是**正向算"这家公司值多少"，更重要的是**反向推"市场当前定价隐含了什么假设"**。这两个引擎必须同时做，缺一不可——这是本系统区别于普通估值工具的根本特征。

### 引擎 A：正向分部估值

```
已知（我们的假设）: PoS + 峰值销售 + WACC
    ↓
计算: 每条管线 rNPV = PoS × Σ[年度FCF / (1+WACC)^t]
    ↓
汇总: 企业价值 = Σ(管线rNPV) + 已上市产品DCF + 净现金
    ↓
输出: 每股内在价值 → 与当前股价比较
```

回答："基于我们的假设，这家公司**应该**值多少？"

### 引擎 B：⭐反向市场隐含反推

```
已知（市场信号）: 当前股价 / 市值
    ↓
拆解: 市场隐含管线价值 = 当前市值 − 已上市产品NPV − 净现金
    ↓
反推: 市场隐含成功率 λ = 市场隐含管线价值 / Σ无风险PV
    ↓
对比: λ/加权PoS → <0.7 市场悲观 / ~1.0 合理 / >1.5 市场乐观
    ↓
输出: 市场是太乐观还是太悲观？隐含假设撞不撞现实天花板？
```

回答："市场当前定价**实际押注了**什么样的管线成功率？"

### 为什么双引擎缺一不可

| 只做正向 | 只做反向 | 双引擎 |
|---|---|---|
| 只知道"我算出来值多少" | 只知道"市场隐含了什么" | **两者交叉验证** |
| 无法判断市场定价是否合理 | 无法判断市场隐含假设是否脱离现实 | 正向给锚点，反向给市场温度 |
| 容易被自己的假设锚定 | 容易被市场共识锚定 | **互相纠偏** |

> 经验教训：历史实战项目中，正向估值经历了 v3→v6.1 六轮迭代，每轮都暴露上轮错误。若没有反向引擎对照"市场到底押注了什么"，正向估值极易在自我假设中打转。

## 五、核心纪律（5 条，不可妥协）

这 5 条是实战中用代价换来的方法论红线。每一条都对应一次具体的翻车经历。

### 1. 费用率用加法，不用乘法
```
❌ margin = (1-cogs) × (1-sga) × (1-tax)    ← 多算交叉项 cogs×sga
✅ margin = (1 - cogs - sga) × (1 - tax)     ← 与利润表一致
```
> 乘法比加法系统性高估 margin（高费用管线高估 ~30%）。详见 `rNPV-methodology.md` 常见错误。

### 2. λ 必须与加权 PoS 比，不能与绝对值 1 比
```
❌ λ < 100% → 市场悲观（错！）
✅ ratio = λ / 加权PoS → <0.7 悲观 / ~1.0 合理 / >1.5 乐观
```
> 研发期管线不可能 100% 成功，λ 永远 < 1。必须双报 λ 和 λ/加权PoS。详见 `reverse-rnpv-method.md`。

### 3. partnered 资产逐项建模，不能简化为单一 royalty
```
❌ license-out 管线 = royalty × 峰值销售
✅ = 首付（已沉）+ 开发里程碑 + 销售里程碑 + royalty（不扣成本）+ 供货利润（扣COGS）+ 海外权益
```
> royalty 是被动分成、近纯利，不扣 COGS/SG&A；供货收入有制造成本，要扣 COGS。详见 `partnered-asset-valuation.md`。

### 4. 区间优先，禁止虚假精度单点
```
❌ PoS = 52.4%，峰值 = 8.43 亿
✅ PoS = 50-55%（基准 52%），峰值 = 7-10 亿（基准 8.4 亿），附敏感性
```
> 关键不确定项（PoS/峰值/上市时间/WACC）一律用区间 + 悲观/基准/乐观三情境。详见 `rNPV-methodology.md` 结果呈现纪律。

### 5. 卖方共识不能作中性标尺
```
❌ "我们的 PoS 比卖方低 → 我们的模型太保守"
✅ 卖方系统性偏乐观（承销/覆盖/生存者偏差），仅作上行情境参考
```
> 用卖方共识反推"模型太保守"是循环论证。详见 `reverse-rnpv-method.md` 交叉验证。

## 六、适用边界

### 适合
- ✅ 管线驱动型 Biotech（pre-revenue 或早期商业化）
- ✅ 创新药企业（有明确临床管线）
- ✅ 中型 Pharma（管线 + 上市产品组合）

### 不适合
- ⚠️ 纯 CRO/CDMO（估值以服务收入为主，非管线驱动）→ 用传统 DCF
- ⚠️ 仿制药企业（无创新管线）→ 用 DCF / P/E
- ⚠️ 医疗器械/医疗服务（非药品，管线逻辑不适用）→ 用 DCF / 可比公司
