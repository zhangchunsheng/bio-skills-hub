# 市场隐含成功率反推方法

> 本文件是本系统**独有的核心方法**。Stage 5 查阅。
> 回答用户的核心问题："以当前价格买入，相当于押注了什么样的管线成功率？"

## 一、方法原理

### 正向 rNPV（我们做的）
```
已知 PoS → 计算 rNPV → 得出每股价值 → 与当前股价比较
```

### 反向 rNPV（市场隐含分析）
```
已知当前股价 → 推算市场隐含的管线价值 → 反推市场隐含的 PoS
→ 对比我们的 PoS → 判断低估/高估
```

### 核心逻辑

市场对一家 Biotech 的定价，本质上是市场对该公司管线成功概率的**集体预期**。如果我们的分析认为 PoS 显著高于市场隐含 PoS，说明市场低估了；反之则高估。

## 二、反推步骤

### Step 1：拆解当前市值

```
当前市值 (Market Cap) = 已上市产品 NPV + 管线隐含价值 + 净现金（± 平台价值）

移项得：
市场隐含管线价值 = 当前市值 - 已上市产品 NPV - 净现金
```

**各组成部分计算：**

| 组成部分 | 计算方法 |
|---|---|
| 当前市值 | 股价 × 总股本（最可靠，直接取数）|
| 已上市产品 NPV | 对已上市产品做传统 DCF（不乘 PoS，因已获批）|
| 净现金 | 现金 + 短期投资 - 有息负债 |
| 平台价值（可选）| 对技术平台估值，通常保守估为 0 或小正值 |

### Step 2：计算各管线的无风险 PV

对每条管线，计算 PoS = 100% 时的现值：

```
PV_i(无风险) = Σ [ FCF_t / (1 + WACC)^t ]    （不乘 PoS）
```

这表示"如果这条管线 100% 成功，它值多少"。

### Step 3：反推市场隐含 PoS

**方法 A：统一折扣因子法（推荐，简洁）**

假设市场对所有管线施加一个**统一的悲观/乐观系数 λ**：

```
市场隐含管线价值 = λ × Σ PV_i(无风险)

求解：
λ = 市场隐含管线价值 / Σ PV_i(无风险)
```

然后将 λ 映射到各管线的隐含 PoS：

```
隐含 PoS_i = λ ×（基准 PoS_i / 加权平均基准 PoS）
```

**简化版（当管线数量少时）：**
```
隐含 PoS_i = λ × 基准 PoS_i / 基准 PoS_i    ← 退化为统一折扣
隐含 PoS_i = λ（所有管线统一）
```

**方法 B：逐管线反推法（当需分析单条管线时）**

固定其他管线的 PoS 为我们的基准值，反推目标管线：
```
市场隐含管线价值 = Σ(其他管线 rNPV) + 隐含 PoS_target × PV_target(无风险)

隐含 PoS_target = [市场隐含管线价值 - Σ(其他管线 rNPV)] / PV_target(无风险)
```

### Step 4：对比分析

将市场隐含 PoS 与我们的基准 PoS 对比：

| 管线 | 我们的 PoS | 市场隐含 PoS | 差异 | 解读 |
|---|---|---|---|---|
| 管线 A | 52% | 35% | -17% | 市场更悲观 → 潜在机会 |
| 管线 B | 15% | 30% | +15% | 市场更乐观 → 潜在风险 |
| 管线 C | 8% | 3% | -5% | 市场极度悲观 → 高风险高回报 |

### Step 5：综合判断（λ 必须与"我们的加权 PoS"比较，而非与绝对值 1 比较）

```
λ 的经济含义 = 市场隐含管线价值 / Σ无风险PV = 市场隐含的"综合成功率"
我们的加权PoS = 我们的rNPV合计 / Σ无风险PV   = 我们认为的"综合成功率"

两者同除以 Σ无风险PV，是平行可比的量。判断悲观/乐观用比值：

  ratio = λ / 加权PoS
    ratio < 0.7   → 显著偏悲观（市场低估管线）
    ratio 0.7-1.0 → 偏悲观
    ratio 1.0-1.3 → 合理偏高
    ratio 1.3-1.5 → 偏乐观
    ratio > 1.5   → 显著偏乐观（市场高估管线）

❌ 错误做法（旧版）：用 λ 的绝对值判断（λ<0.5 悲观 / λ>1.5 乐观）。
   这隐含假设"市场认为管线 100% 成功才合理"——对研发期管线无意义
   （Phase 3 行业 PoS 仅 52%，没人会给 100% 成功率定价）。
   一个加权 PoS=57% 的组合，λ=0.78 恰在"合理乐观"区间，绝非"悲观"。

❌ 错误公式（旧版）：隐含 PoS = λ × 加权PoS（双重计算）。
   λ 本身已是市场隐含综合成功率，再乘加权PoS 没有经济含义，
   会把"市场偏乐观"错误扭转成"市场偏悲观"。

⚠️ 注意：λ/加权PoS > 1 不一定意味着高估——
   市场可能对平台期权、海外权益、被收购溢价等我们未充分定价的资产给了价值。
   λ>100% 时尤其要检视我们的无风险PV 是否过保守（峰值/预测期/折现率）。
```

## 三、完整计算示例

**案例：某港股 Biotech（3 条管线）**

### 已知数据
```
当前市值 = HK$ 80 亿
净现金 = HK$ 25 亿
已上市产品 NPV = HK$ 0（pre-revenue）
平台价值 = HK$ 0（保守不计）
```

### Step 1：市场隐含管线价值
```
市场隐含管线价值 = 80 - 0 - 25 = HK$ 55 亿
```

### Step 2：各管线无风险 PV

| 管线 | 阶段 | 基准 PoS | 无风险 PV (HK$ 亿) |
|---|---|---|---|
| A | Phase 3 | 52% | 120 |
| B | Phase 2 | 15% | 60 |
| C | Phase 1 | 8% | 30 |
| **合计** | | | **210** |

### Step 3：反推折扣因子
```
λ = 市场隐含管线价值 / Σ PV(无风险)
λ = 55 / 210 = 0.262
```

### Step 4：映射到隐含 PoS

使用方法 A（按基准 PoS 加权分配）：

```
加权平均基准 PoS = (52%×120 + 15%×60 + 8%×30) / 210
                 = (62.4 + 9.0 + 2.4) / 210
                 = 73.8 / 210 = 35.1%

隐含 PoS_A = 0.262 × (52% / 35.1%) = 0.262 × 1.48 = 38.8%
隐含 PoS_B = 0.262 × (15% / 35.1%) = 0.262 × 0.43 = 11.2%
隐含 PoS_C = 0.262 × (8% / 35.1%)  = 0.262 × 0.23 = 5.9%
```

**验证：** Σ(隐含 PoS_i × PV_i) = 38.8%×120 + 11.2%×60 + 5.9%×30 = 46.6 + 6.7 + 1.8 = 55.1 ≈ 55 ✓

### Step 5：对比

| 管线 | 我们的 PoS | 隐含 PoS | 比值 | 解读 |
|---|---|---|---|---|
| A | 52% | 38.8% | 0.75 | 市场偏悲观 |
| B | 15% | 11.2% | 0.75 | 市场偏悲观 |
| C | 8% | 5.9% | 0.74 | 市场偏悲观 |

**综合判断：** λ = 0.262，市场隐含 PoS 约为基准的 74%。市场整体偏悲观，可能低估。

**但需注意：** 折扣因子 0.262 也可以解读为市场对整个公司（而非单条管线）打了 26% 的折扣。这可能反映了：
- 流动性折价（港股小盘 Biotech 常见）
- 管理层不信任
- 大股东减持风险
- 地缘政治折价
- 增发稀释预期

## 四、注意事项与局限性

### ⚠️ 局限性 1：市场可能"知道"我们不知道的
市场定价反映了所有公开信息（甚至部分内幕信息）。如果隐含 PoS 很低，可能是市场察觉到了某些风险（如试验设计缺陷、竞争威胁、管理层问题），而非简单的"低估"。

### ⚠️ 局限性 2：折现率假设影响巨大
我们的无风险 PV 用了某个 WACC，但市场可能用不同的折现率。如果市场用的折现率更高，隐含 PoS 的计算会被扭曲。

**缓解方法：** 在 Sensitivity Sheet 中测试不同 WACC 下的隐含 PoS。

### ⚠️ 局限性 3：统一折扣因子假设过于简化
方法 A 假设市场对所有管线施加相同的 λ，但实际上市场可能对不同管线有差异化预期。方法 B 更精确但需要假设其他管线。

### ⚠️ 局限性 4：净现金的计算
如果有大量"非经营性"资产（如投资性房地产、长期股权投资），需考虑是否应计入。

### ⚠️ 局限性 5：不适用于多业务公司
如果公司有 CRO/CDMO 服务收入 + 管线，需先剥离服务业务的价值。

## 五、报告中的呈现方式

在报告第六章（市场隐含视角）中，应包含：

1. **市值拆解表**（当前市值 → 已上市产品 NPV → 净现金 → 隐含管线价值）
2. **隐含 PoS 反推表**（各管线：无风险 PV、基准 PoS、隐含 PoS、差异、解读）
3. **折扣因子 λ 解读**（**双报 λ 和 λ/加权PoS**——λ 是绝对量，λ/加权PoS 是相对我们的乐观度标尺，两者必须同时呈现，缺一不可。λ 单独看无意义，因为研发期管线 PoS 永远 < 100%，λ 永远 < 1）
4. **结论**（低估/合理/高估 + 置信度 + 关键假设敏感性）

**关键表述示例：**
> "以当前 HK$ 80 亿市值计算，市场隐含的核心管线成功率为 38.8%（Phase 3），而我们基于 BIO 行业基准的估算为 52%。市场对这条管线的定价打了约 75% 的折扣。这意味着：如果我们的 PoS 估算合理，当前股价隐含了显著的悲观预期，存在低估机会。但需注意，市场折扣也可能反映了 [流动性/竞争/管理层] 等因素，而非单纯对管线成功的低估。"

## 六、与其他估值方法的交叉验证

隐含 PoS 分析不应孤立使用，应与以下交叉验证：

| 方法 | 交叉验证点 |
|---|---|
| 正向 rNPV | 我们的每股价值 vs 当前股价 → 溢价/折价幅度应与隐含 PoS 分析一致 |
| 可比公司倍数 | 同阶段 Biotech 的 EV/管线数、EV/Phase 3 资产数 |
| 近期 BD 交易 | 同领域 license-out 的首付款/里程碑 → 隐含的资产价值 |
| 卖方目标价 | 覆盖分析师的目标价隐含了什么 PoS |

> ⚠️ **卖方共识偏差警示（P0 级）**：18A 生科卖方分析师**系统性偏乐观**（承销利益 / 覆盖抢占 / 生存者偏差）。当我们的隐含 PoS **低于**卖方时，**不能**据此判定"我们的模型太保守"——那等于用卖方的乐观假设作中性标尺，是循环论证。卖方目标价隐含的 PoS 仅作**上行情境参考**（"如果市场像卖方一样乐观，PoS 需达 X%"），不作中性基准。详见 `discount-rate-guide.md` 卖方惯例章节的 WACC 视角差异表（卖方 10-12% vs 独立 12-15%）。
