# 临床试验成功率（PoS）基准表

> 本文件提供 rNPV 计算所需的各阶段成功率基准。Stage 3a 查阅。

## 一、整体基准（BIO/BioMedTracker 2011-2020）

数据来源：12,728 个临床试验，覆盖 2011-2020 年所有治疗领域。

### 阶段推进概率

| 阶段转换 | 成功率 | 说明 |
|---|---|---|
| Phase 1 → Phase 2 | **52.0%** | Phase 1 主要验证安全性，通过率较高 |
| Phase 2 → Phase 3 | **28.9%** | ⚠️ **死亡之谷** — PoC 验证，淘汰率最高 |
| Phase 3 → NDA/BLA | **57.8%** | Phase 3 验证有效性，投入巨大 |
| NDA/BLA → 获批 | **90.6%** | 递交后通过率很高 |

### 累计获批概率（LOA, Likelihood of Approval）

| 当前阶段 | → 获批 累计概率 | rNPV 中使用的 PoS |
|---|---|---|
| 临床前 | ~1.8% | 1.8% |
| Phase 1 | **~7.9%** | 7.9% |
| Phase 2 | **~15.1%** | 15.1% |
| Phase 3 | **~52.4%** | 52.4% |
| NDA/BLA 递交 | **~90.6%** | 90.6% |
| 已获批 | 100% | 100% |

> **计算验证：** Phase 2 → 获批 = 28.9% × 57.8% × 90.6% = 15.1% ✓

### 按模态分类的 LOA

| 模态 | Phase 1 → 获批 |
|---|---|
| 小分子 | ~7.5% |
| 生物药（抗体/蛋白）| **~9.1%** |
| 细胞与基因治疗 | ~8.7% |

## 三、情境微调因子

在 BIO 基准上，根据以下因素做 ±调整。**每个调整需注明依据。**

### 上调因子（PoS +）

| 因素 | 调整幅度 | 依据 |
|---|---|---|
| 突破性疗法认定（BTD）| +10~15% | FDA 数据：BTD 项目获批率 ~58% vs 整体 ~9% |
| 孤儿药认定（ODD）| +5~10% | 患者群体小，试验设计更聚焦 |
| 加速审批路径 | +8~12% | 可用替代终点 |
| 快速通道（Fast Track）| +3~5% | |
| RMAT（再生医学先进疗法）| +10~15% | 细胞/基因治疗加速通道 |
| 优先审评（Priority Review）| +3~5% | |
| 有 Phase 2 PoC 阳性数据 | +5~10% | 已有人体有效性证据 |
| 生物标志物筛选人群 | +5~8% | 富集策略提高响应率 |
| 双盲对照试验设计 | +3~5% | 比开放标签更可信 |
| 同靶点已上市药物 | +5~10% | 靶点验证已有先例 |

### 下调因子（PoS -）

| 因素 | 调整幅度 | 依据 |
|---|---|---|
| 实体瘤（OS 终点）| -5~10% | OS 达成难度高于 PFS/ORR |
| 精神科/疼痛 | -5~10% | 安慰剂效应强 |
| 开放标签试验 | -3~5% | 偏倚风险 |
| 同靶点多次失败 | -10~20% | 靶点可能有根本性问题 |
| 无生物标志物 | -3~5% | 人群异质性大 |
| 中国创新药出海（FDA）| -5~10% | 仅中国数据获批风险 |
| First-in-class（全新靶点）| -3~8% | 无先例验证 |
| 单中心/小样本试验 | -5~10% | 外部验证性不足 |

## 四、PoS 赋值工作流程

```
Step 1: 确定当前阶段
  → 查"累计获批概率"表，获取基准 PoS

Step 2: 确定治疗领域
  → 查"按治疗领域分类"表，获取领域特定 PoS
  （优先使用领域特定值，而非整体均值）

Step 3: 逐项评估调整因子
  → 监管路径：有 BTD/ODD/加速审批？
  → 试验设计：双盲/开放？有生物标志物？
  → 数据质量：有 Phase 2 PoC 数据？
  → 竞争格局：同靶点有已上市药物还是多次失败？

Step 4: 计算最终 PoS
  → 最终 PoS = 领域基准 PoS + Σ(调整因子)
  → 约束：最终 PoS ∈ [1%, 99%]

Step 5: 记录
  → 基准 PoS = X%（来源：BIO 表 Y）
  → 调整 +A%（因素1）、-B%（因素2）
  → 最终 PoS = Z%
  → 置信度：高/中/低
```

## 五、PoS 赋值示例

**案例：某在研 HER2 双抗（乳腺癌适应症，Phase 3）**

```
Step 1: 当前阶段 = Phase 3
Step 2: 治疗领域 = 实体瘤
  → Phase 3 → 获批基准 = 45%（实体瘤）

Step 3: 调整因子评估
  + 同靶点已上市（曲妥珠单抗、帕妥珠单抗验证 HER2 靶点）→ +8%
  + 有 Phase 2 PoC 阳性数据 → +5%
  - 实体瘤 OS/PFS 终点 → -5%（已在基准中体现，不再重复扣减）

Step 4: 最终 PoS = 45% + 8% + 5% = 58%
  → （置信度：中）

Step 5: 记录到 Assumptions Sheet
```

## 六、数据更新

BIO/BioMedTracker 每隔 2-3 年更新一次成功率报告。下次更新时应：
1. 获取最新报告（搜索 "BIO clinical development success rates [latest year]"）
2. 比较新基准与当前基准的差异
3. 更新本文件的数据表
4. 重新审视历史估值是否需要调整
