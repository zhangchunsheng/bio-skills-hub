# Partnered / License-out 资产估值

> 本文件处理 **license-out（对外授权）管线的 rNPV 建模**——这是自营商业化之外的另一种变现路径。
> Stage 3 遇到 partnered 管线时查阅。`rNPV-methodology.md` 只覆盖自营模型，partnered 模型在此展开。

---

## 一、为什么需要单独一节

大量中国 Biotech 的核心管线采用 license-out 模式——将某个地区（如中国/海外）的权益授权给大药企，换取首付 + 里程碑 + royalty。这与中国创新药"国内自营 + 海外授权"的典型商业模式高度相关。

**实战教训**：某港股 18A Biotech 实战项目证明，partnered 资产的经济权益远比"royalty × 峰值销售"复杂。把它简化为单一 royalty 会系统性低估管线价值（漏计首付/里程碑/供货利润），且把 royalty 当自营收入扣 COGS/SG&A 会进一步扭曲。

---

## 二、完整权益拆解（六件套）

一条典型的 license-out 交易，授方（licensor，通常是 Biotech）获得的经济权益有 **6 层**：

| # | 权益层 | 一次性/持续 | 是否乘 PoS | 费用口径 | 说明 |
|---|---|---|---|---|---|
| 1 | **首付（upfront）** | 一次性 | ❌ 不乘（签约即得） | 纯收入 | 签约时支付，已沉没成本的对价 |
| 2 | **开发里程碑** | 一次性（按节点） | ✅ 乘 PoS | 纯收入 | 每完成一个临床/监管节点触发一笔 |
| 3 | **销售里程碑** | 一次性（按销售额） | ✅ 乘 PoS | 纯收入 | 累计销售额达阈值触发 |
| 4 | **专利使用费（royalty）** | 持续（按销售额 %） | ✅ 乘 PoS | **不扣 COGS/SG&A**（近纯利） | 净销售额 × royalty% (通常 5-15%) |
| 5 | **独家供货利润** | 持续 | ✅ 乘 PoS | **扣 COGS，不扣 SG&A** | 如果授方负责生产供货 |
| 6 | **海外保留权益** | 持续 | ✅ 乘 PoS | 视结构 | 未授权地区的自营权益 |

### 关键口径差异（最常出错的两条）

**① royalty 不扣 COGS/SG&A**
royalty 是按净销售额百分比分成的被动收入，授方不承担生产/销售成本——它是**接近纯利润**的口径。在 rNPV 中：
```
royalty PV = Σ [ 净销售额_t × royalty% × PoS / (1+WACC)^t ]
```
**不要**对 royalty 再扣 COGS 率和 SG&A 率——那是把自营的费用结构错误套到被动分成上。

**② 供货收入扣 COGS，但不扣 SG&A**
如果授方同时是产品的独家生产商（CMC/CDMO 角色），供货利润有制造成本但无销售费用：
```
供货利润 PV = Σ [ 供货收入_t × 供货毛利率 × PoS / (1+WACC)^t ]
```
供货毛利率参照 **CDMO 商业化阶段毛利率**（约 50-55%），而非授方公司的整体毛利率。

> ⚠️ **实战教训**：早期版本模型把 royalty 错扣了 COGS 20% + SG&A 10%，导致 royalty 管线 PV 被严重低估。正确做法是 royalty 近纯利（不扣成本），供货才扣 COGS。详见总纲纪律第 3 条。

## 三、建模步骤

### Step 1：确认授权结构
逐条管线确认：
- 授权地区（全球 / 中国 / 海外 / 美国 / 欧盟……）
- 授权方（partner 是谁）
- 交易公告披露的：首付金额、里程碑总额及节点、royalty 区间

### Step 2：首付（已沉，不折现/不乘 PoS）
首付在签约时已收到，是确定性现金流：
```
首付 PV = 首付金额（直接计入 EV，不折现/不乘 PoS）
```

### Step 3：开发里程碑（乘 PoS，按节点折现）
每个里程碑节点有一个触发条件（如 Phase 2 完成、Phase 3 启动、NDA 递交、获批），对应一个 PoS 概率：
```
开发里程碑 PV = Σ [ 里程碑金额_i × PoS(当前阶段→触发节点_i) / (1+WACC)^t_i ]
```

### Step 4：销售里程碑（乘 PoS，按达峰时间折现）
```
销售里程碑 PV = Σ [ 里程碑金额_j × PoS(获批) × 达到该销售额阈值的概率 / (1+WACC)^t_j ]
```
达到销售额阈值的概率可简化为：峰值销售估算 ≥ 阈值 → 100%，否则按爬坡年份估算。

### Step 5：royalty（乘 PoS，不扣成本）
```
royalty PV = PoS(获批) × Σ [ 净销售额_t × royalty% / (1+WACC)^t ]
```
净销售额 = partner 的峰值销售 × 爬坡曲线。注意：**partner 的峰值可能与我们的 peak-sales-framework 估算不同**（partner 有更强的商业化能力），但保守起见用我们的估算。

### Step 6：独家供货利润（如有，乘 PoS，扣 COGS）
```
供货利润 PV = PoS(获批) × Σ [ 供货收入_t × 供货毛利率 / (1+WACC)^t ]
```
供货收入 = 生产供货的转移价（可能等于 royalty 基数的净销售额，或单独谈判的供货价）。供货毛利率参照 CDMO 商业化阶段 50-55%。

### Step 7：汇总
```
partnered 管线 rNPV = 首付 + 开发里程碑PV + 销售里程碑PV + royalty PV + 供货利润PV
```

## 四、完整计算示例

**场景**：某港股 Biotech 将 HER2 双抗的中国权益授权给国内大药企（license-out），保留海外权益自营。

**交易条款（公告）**：首付 ¥3 亿 + 开发里程碑合计 ¥8 亿（Phase 3 启动 ¥2 亿 / NDA 递交 ¥3 亿 / 获批 ¥3 亿）+ 销售里程碑合计 ¥5 亿（累计销售达 10 亿/20 亿/30 亿）+ royalty 12%（中国净销售额）+ 独家供货（毛利率 52%）。

**假设**：当前 Phase 2，PoS(获批) = 15.1%（BIO 基准）；WACC = 13%；中国峰值销售 = 8 亿/年；预计获批年份 = +5 年。

```
1. 首付 = ¥3.0 亿（已沉，直接计入）

2. 开发里程碑：
   Phase 3 启动（+1年）: PoS(Ph2→Ph3) = 28.9% → 2.0 × 0.289 / 1.13^1 = ¥0.51 亿
   NDA 递交（+3年）:    PoS(Ph2→NDA) = 15.1%×57.8% = 8.7% → 3.0 × 0.087 / 1.13^3 = ¥0.18 亿
   获批（+5年）:        PoS(Ph2→获批) = 15.1% → 3.0 × 0.151 / 1.13^5 = ¥0.25 亿
   小计 ≈ ¥0.94 亿

3. 销售里程碑（峰值 8 亿，爬坡至 30 亿累计约需上市后 5-6 年）：
   达到 10 亿（+7年）:  PoS 15.1% × 100% → 2.0 × 0.151 / 1.13^7 ≈ ¥0.13 亿
   达到 20 亿（+8年）:  PoS 15.1% × 90% → 1.5 × 0.151 × 0.9 / 1.13^8 ≈ ¥0.08 亿
   达到 30 亿（+10年）: PoS 15.1% × 50% → 1.5 × 0.151 × 0.5 / 1.13^10 ≈ ¥0.03 亿
   小计 ≈ ¥0.24 亿

4. royalty（12% × 中国净销售额，不扣成本）：
   爬坡曲线 PV（峰值 8 亿，上市后 Y1-Y15）≈ 8 × 4.2 ≈ ¥33.6 亿（无风险净销售额 PV）
   royalty PV = PoS 15.1% × 12% × 33.6 ≈ ¥0.61 亿

5. 独家供货利润（供货收入≈净销售额，毛利率 52%，扣 COGS 不扣 SG&A）：
   供货利润 PV = PoS 15.1% × 52% × 33.6 ≈ ¥2.64 亿

中国 license-out 权益 rNPV = 3.0 + 0.94 + 0.24 + 0.61 + 2.64 = ¥7.43 亿
```

> 注意：若按"单一 royalty"简化（仅第 4 项），只得 ¥0.61 亿，**低估 92%**。若再错误扣 COGS/SG&A，royalty PV 进一步缩水。这就是 partnered 建模的价值所在。

## 五、常见错误

1. ❌ **把 license-out 简化为单一 royalty** → 漏计首付/里程碑/供货，严重低估
2. ❌ **royalty 扣 COGS/SG&A** → royalty 是被动分成近纯利，不应扣自营费用结构
3. ❌ **供货不扣 COGS** → 供货有制造成本，须扣 COGS（但无 SG&A）
4. ❌ **首付乘 PoS / 折现** → 首付签约即得，是确定性现金流
5. ❌ **用 partner 的乐观峰值** → 保守起见用我们自己的 peak-sales 估算
6. ❌ **海外权益漏建** → 未授权地区若有自营价值，须单独建 rNPV

## 六、与 peak-sales-framework 的衔接

`peak-sales-framework.md` 的 8 层流行病学漏斗估出的是**自营全额销售**。对于 partnered 管线：

- **授方视角（本文件）**：海外市场以 royalty 收入计算（royalty% × partner 的净销售额），**非全额销售**
- **自营地区**：仍用 peak-sales 漏斗的全额销售 → 走 `rNPV-methodology.md` 的自营模型
- **同一药物、不同地区 = 不同管线单元**：中国自营走全套漏斗，海外 license-out 走本文件的六件套
