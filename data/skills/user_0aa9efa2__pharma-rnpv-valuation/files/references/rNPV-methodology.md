# rNPV 完整方法论

> 本文件是医药股 rNPV 估值的核心方法论参考。Stage 3 执行时查阅。

## 一、什么是 rNPV

**rNPV（Risk-Adjusted Net Present Value，风险调整净现值）** 是医药/生物科技行业估值的黄金标准方法。

核心思想：药物研发是一系列二元（成功/失败）的概率事件。每条管线有独立的临床阶段和成功概率。rNPV 将每条管线的预期现金流**按其成功概率加权**后折现求和。

### 与传统 DCF 的区别

| 维度 | 传统 DCF | rNPV |
|---|---|---|
| 适用对象 | 有稳定收入的企业 | 管线驱动型 Biotech / Pharma |
| 风险处理 | 在折现率中笼统加风险溢价 | 逐管线按 PoS 独立调整 |
| 现金流 | 单一收入预测线 | 每条管线独立现金流 × PoS |
| 二元结果 | 不体现 | 核心特征（试验成功=价值释放，失败=价值清零）|

## 二、核心公式

### 单条管线的 rNPV

```
rNPV_i = PoS_i × Σ [ FCF_t / (1 + WACC)^t ]    t = 1 to N

其中：
  PoS_i    = 管线 i 从当前阶段到获批的累计成功率
  FCF_t    = 管线 i 在第 t 年的自由现金流（上市后才有正现金流）
  WACC     = 加权平均资本成本（折现率）
  N        = 预测期（通常到专利到期后 2-3 年）
```

### 公司分部加总估值

```
企业价值 (EV) = Σ(rNPV_i)  +  Σ(已上市产品 DCF)  +  平台价值(可选)

股权价值 = EV + 净现金 - 有息负债 - 预期稀释

每股内在价值 = 股权价值 / 稀释后总股本
```

## 三、完整计算步骤（六步法）

参考 IB Interview Questions 的行业标准流程：

### Step 1：无风险收入预测
对每条管线，先假设 100% 成功，预测上市后的收入曲线：
```
收入_t = 峰值销售 × 爬坡系数_t

爬坡系数（上市后年份）：
  Y1 = 10%, Y2 = 25%, Y3 = 50%, Y4 = 75%, Y5 = 90%, Y6 = 100%
  专利到期后：Y7 = 90%, Y8 = 70%, Y9 = 50% ...（每年 -20~30%）
```

### Step 2：利润构建
```
毛利 = 收入 × (1 - COGS率)
  COGS率：生物药 20%，化药 15%，细胞/基因治疗 30%

营业利润 = 毛利 - SG&A - R&D
  SG&A率：上市初期 40%，成熟期 25%
  R&D：上市后维持较低水平（收入的 5-10%）

税后利润 = 营业利润 × (1 - 税率)
  税率：中国高新企业 15%，标准 25%；海外 21%

FCF = 税后利润 + 折旧 - 资本支出 ± 营运资本变动
  （简化：FCF ≈ 税后利润，医药行业资本支出较小）
```

### Step 3：rNPV 计算
```
PV(无风险) = Σ [ FCF_t / (1 + WACC)^t ]     ← 这是不考虑失败风险的现值

rNPV = PoS × PV(无风险)
```

### Step 4：剩余研发成本
**关键：研发成本也要风险调整！**

```
研发成本 PV = Σ [ DevCost_t × P(到达t年) / (1 + WACC)^t ]

P(到达t年) = 从当前阶段到第 t 年所在阶段的累计推进概率
```

例如：Phase 2 管线，预计还需 3 年完成 Phase 3（每年 $20M）：
```
P(到达 Phase 3 Y1) = P(Ph2→Ph3) = 28.9%
P(到达 Phase 3 Y2) = P(Ph2→Ph3) = 28.9%  （同阶段内持续推进）
P(到达 Phase 3 Y3) = P(Ph2→Ph3) = 28.9%
P(到达 NDA)       = P(Ph2→Ph3) × P(Ph3→NDA) = 28.9% × 57.8% = 16.7%
```

### Step 5：分部加总
```
管线净 rNPV = rNPV(收入端) - rNPV(研发成本端)

企业价值 = Σ(各管线净 rNPV) + 已上市产品 DCF
股权价值 = 企业价值 + 净现金
每股价值 = 股权价值 / 总股本
```

### Step 6：可比验证
将 rNPV 得出的每股价值与以下交叉验证：
- 可比公司估值倍数（EV/Revenue, EV/EBITDA）
- 近期同领域 BD 交易（授权首付款 + 里程碑）
- 卖方目标价（如有覆盖）

## 四、计算示例

**案例：某 Phase 2 双抗管线（乳腺癌适应症）**

假设条件：
- PoS（Phase 2 → 获批）= 15.1%（BIO 基准）
- 峰值销售 = $500M（上市后第 6 年达峰）
- 上市年份 = 当前 + 5 年（2029 年）
- WACC = 12%
- COGS = 20%, SG&A = 30%, R&D = 10.5%, 税率 = 15%
  - 利润率 = (1 - 0.20 - 0.30 - 0.105) × (1 - 0.15) = 0.336（加法口径，与利润表一致）
  - 示例中 FCF/收入恒为 0.336（如 Y5 收入 50 → FCF 16.8），可用此验证

| 年份 | 收入 ($M) | FCF ($M) | 折现因子 | PV ($M) |
|---|---|---|---|---|
| Y1-4 (2025-28) | 0 | 0 (研发中) | - | 0 |
| Y5 (2029 上市) | 50 | 16.8 | 0.567 | 9.5 |
| Y6 (2030) | 125 | 42.0 | 0.507 | 21.3 |
| Y7 (2031) | 250 | 84.0 | 0.452 | 38.0 |
| Y8 (2032) | 375 | 126.0 | 0.404 | 50.9 |
| Y9 (2033) | 450 | 151.2 | 0.361 | 54.5 |
| Y10 (2034 达峰) | 500 | 168.0 | 0.322 | 54.1 |
| Y11 (2035) | 450 | 151.2 | 0.287 | 43.5 |
| Y12 (2036 专利到期) | 315 | 105.8 | 0.257 | 27.1 |
| Y13 (2037) | 220 | 73.9 | 0.229 | 16.9 |
| **PV(无风险) 合计** | | | | **315.8** |

```
rNPV = PoS × PV(无风险) = 15.1% × $315.8M = $47.7M
```

这条 Phase 2 管线的风险调整净现值约 **$47.7M**。

## 五、常见错误

### ❌ 错误 1：只调整收入，不调整成本
> 研发成本也按 PoS 折减。如果管线失败，后续研发成本就不会发生——这部分成本的概率加权值应从 rNPV 中扣除。

### ❌ 错误 2：PoS 选取过于乐观
> BIO 行业基准是 12,728 个临床试验的统计结果。分析师常因看好某管线而大幅上调 PoS，应保持纪律性，只在有明确数据支撑时才调整。

### ❌ 错误 3：峰值销售过度膨胀
> 底层流行病学漏斗每一层都要审慎。常见错误：用发病率代替患病率、忽略诊断率、假设 100% 渗透率、忽略竞争产品。

### ❌ 错误 4：折现率选取不当
> Pre-revenue Biotech 的 WACC 应高于大型 Pharma（12-15% vs 7-9%）。用同一折现率估值所有管线是错误的。

### ❌ 错误 5：忽略稀释
> Cash runway 不足的 Biotech 必然要增发。不计算稀释就给出的每股价值是高估的。

### ❌ 错误 6：费用率用乘法口径（P0 级）
```
❌ margin = (1-cogs) × (1-sga) × (1-tax)      ← 多算交叉项 cogs×sga，系统性高估 margin
✅ margin = (1 - cogs - sga) × (1 - tax)       ← 加法口径，与利润表逐项扣减一致
```
> 乘法比加法多算交叉项 `cogs×sga`：高费用管线（cogs=0.30+sga=0.35）高估 ~30%，低费用管线偏差小故长期不被发现（royalty 管线 cogs/sga=0 时两者相等，掩盖了 bug）。
> 来源：历史实战项目跨模型对抗复核发现。本系统 Step 2 利润构建和 `calc_unrisked_pv` 函数均用加法口径。

### ❌ 错误 7：partnered 资产简化为单一 royalty
> license-out 管线的经济权益有六层（首付+里程碑+royalty+供货+海外），不能简化为"royalty × 峰值销售"。
> 详见 `partnered-asset-valuation.md`。

## 六、方法局限性

1. **PoS 是统计均值**，不反映单一管线的具体风险特征（但情境微调可部分弥补）
2. **峰值销售高度主观**，不同分析师可能得出差异 2-3 倍的结果
3. **二元假设过于简化**，实际中存在部分成功（如获批但标签受限、试验失败但数据有参考价值）
4. **不适用于平台型公司**（如 Modality 平台，单一管线 rNPV 无法体现平台价值）

## 七、结果呈现纪律（区间优先，禁止虚假精度）

rNPV 估值对 PoS、峰值销售、上市年份、WACC 高度敏感。用单点估计会制造虚假的精确感——实际不确定性远大于小数点后的位数。以下纪律适用于**所有关键不确定项**：

### 1. 关键参数用区间 + 三情境
| 参数 | 禁止 | 应该 |
|---|---|---|
| PoS | 52.4% | 50-55%（基准 52%），按置信度标 [高/中/低] |
| 峰值销售 | ¥8.43 亿 | ¥7-10 亿（基准 ¥8.4 亿），附 top-down 交叉验证 |
| 上市年份 | 2029 年 | 2028-2031 年（基准 2029），推迟 1 年 rNPV 下降 ~10% |
| WACC | 13.0% | 12-14%（基准 13%），按公司类型查 `discount-rate-guide.md` |

### 2. 报告必须呈现三情境
```
悲观（PoS×0.7, 峰值×0.7, WACC+2%）→ 每股 X
基准                              → 每股 Y
乐观（PoS×1.3, 峰值×1.3, WACC-2%）→ 每股 Z
```
单点结论只作锚定，最终判断以区间 + 概率为准。

### 3. 结论稳健性检验
> ⚠️ 如果估值结论（低估/高估）在 WACC ±2% 或 PoS ±20% 范围内翻转，说明结论**不稳健**，必须在报告中明确标注不确定性，不可下绝对判断。

> 这条纪律的延伸：敏感性分析不应只做 WACC 专项，应覆盖 PoS/峰值/上市时间/WACC 四个维度。详见 `discount-rate-guide.md`。
