# 医药股折现率选取指南

> 本文件提供 rNPV 计算中折现率（WACC）的选取方法。Stage 3d 查阅。

## 一、为什么折现率很重要

折现率是 rNPV 中**最敏感的单一参数**。折现率从 10% 变为 12%，一个 10 年期现金流的现值会下降约 11%。

```
PV = FCF / (1 + WACC)^t

  WACC = 10%, t = 10:  PV/FCF = 0.386
  WACC = 12%, t = 10:  PV/FCF = 0.322  (-16.6%)
  WACC = 15%, t = 10:  PV/FCF = 0.247  (-36.0%)
```

## 二、CAPM 基本公式

```
WACC = Ke × E/(D+E) + Kd × (1-t) × D/(D+E)

对于医药股（通常低杠杆或零杠杆），简化为：
WACC ≈ Ke = Rf + β × (Rm - Rf)

其中：
  Rf = 无风险利率（10年期国债收益率）
  β  = 公司 Beta（相对市场波动性）
  Rm = 市场预期回报率
  Rm - Rf = 股权风险溢价（ERP）
```

## 三、参数选取

### 无风险利率（Rf）

| 市场 | 基准 | 当前参考值（2026）|
|---|---|---|
| 中国 | 10 年期国债收益率 | ~2.0-2.5% |
| 美国 | 10 年期国债收益率 | ~4.0-4.5% |
| 全球（美元计价）| 美国 10 年期 | ~4.0-4.5% |

### 股权风险溢价（ERP）

| 市场 | ERP | 备注 |
|---|---|---|
| 美国（成熟市场）| 4.5-5.5% | Damodaran 推荐 |
| 中国（新兴市场）| 6.0-7.5% | 含国家风险溢价 |
| 港股（中国公司）| 6.0-7.0% | |

### Beta（β）

医药行业 Beta 参考值：

| 公司类型 | β 范围 | 说明 |
|---|---|---|
| 大型多元化药企（辉瑞、罗氏）| 0.6-0.8 | 现金流稳定，低波动 |
| 中型商业化 Pharma | 0.8-1.1 | 有上市产品但管线驱动 |
| 商业化 Biotech | 1.0-1.3 | 有收入但仍在亏损 |
| **临床期 Biotech（pre-revenue）**| **1.2-1.6** | 二元风险，高波动 |
| 细胞/基因治疗 | 1.4-1.8 | 极高风险 |

## 四、推荐折现率区间

基于行业惯例（卖方分析师、VC、学术文献综合）：

| 公司类型 | WACC 区间 | 中位数 | 典型用例 |
|---|---|---|---|
| 大型药企（收入 >$10B）| 7-9% | **8%** | 辉瑞、罗氏、强生 |
| 中型 Pharma（收入 $1-10B）| 8-10% | **9%** | 恒瑞、百济神州 |
| 商业化 Biotech（有收入但亏损）| 10-12% | **11%** | 信达生物、康方生物 |
| **临床期 Biotech（pre-revenue）**| **12-15%** | **13%** | 多数港股 18A 公司 |
| 早期 Biotech（Phase 1/2）| 14-18% | **15%** | |
| 细胞/基因治疗 | 13-17% | **15%** | |

### 中国/港股特有调整

| 因素 | 调整 | 原因 |
|---|---|---|
| 港股 18A 未盈利生物科技 | 用 13-15% | 监管+二元风险+流动性 |
| 中国 Biotech 出海美国 | +1-2% | FDA 审批不确定性 |
| 有国资背景 | -0.5-1% | 隐含支持 |
| 管线集中在单一资产 | +1-2% | 缺乏分散化 |

## 五、分阶段折现率（进阶）

更严谨的做法是对不同阶段使用不同折现率：

```
研发期（上市前）：WACC = 15-18%（高风险）
商业化期（上市后）：WACC = 10-12%（风险降低）
成熟期（峰值销售）：WACC = 8-10%（接近成熟企业）

rNPV = Σ [ FCF_t × PoS / (1 + WACC_stage)^t ]
```

实践中，**简化为统一折现率**（取中位数）更为常见，避免模型过度复杂。

## 六、折现率选取工作流程

```
Step 1: 确定公司类型
  → 大型药企 / 中型 Pharma / 商业化 Biotech / 临床期 Biotech

Step 2: 查推荐区间
  → 选取中位数作为基准

Step 3: 评估调整因素
  + 单一管线集中 → +1-2%
  + 出海不确定性 → +1-2%
  + 现金充裕/有 BD 收入 → -0.5-1%
  + 多管线分散 → -0.5-1%

Step 4: 确定最终 WACC
  → 记录：基准 X% + 调整 ±Y% = 最终 Z%

Step 5: 在 Sensitivity Sheet 中测试
  → WACC ±2% 的估值变化
```

## 七、折现率选取示例

**案例：某港股 18A Biotech（双抗平台型）**

```
Step 1: 临床期 Biotech（有合作收入但主要价值在管线）
Step 2: 基准 WACC = 13%（临床期 Biotech 中位数）
Step 3: 调整
  + 管线相对聚焦（双抗平台，3-4 条核心管线）→ +0.5%
  - 有合作收入（两条核心管线已 license-out，首付款+里程碑模式）→ -0.5%
  净调整 = 0%
Step 4: 最终 WACC = 13%

Sensitivity: 测试 11% / 13% / 15%
```

### 实际应用差异
| 视角 | 折现率 | 原因 |
|---|---|---|
| 卖方分析师 | 10-12% | 偏乐观（要推荐买入）|
| 独立估值 | 12-15% | 中性 |
| VC/PE | 20-40% | 要求高回报率 |
| 学术研究 | 8-10% | 用 CAPM 纯理论值 |

**建议：** 以 12-15% 为基准（独立估值视角），在报告中明确标注折现率选取依据。

> ⚠️ **卖方共识偏差警示（P0 级）**：18A 生科卖方分析师**系统性偏乐观**——承销利益 / 覆盖抢占 / 生存者偏差（只覆盖能发报告的公司）共同导致卖方目标价和共识 WACC 偏低（10-12%）。**不能用卖方共识作中性标尺、反推自己的模型太保守**——那是循环论证。卖方目标价仅作**上行情境参考**，独立估值口径（12-15%）才是基准。详见 `reverse-rnpv-method.md` 交叉验证章节。

## 九、敏感性分析建议（全参数）

rNPV 估值不仅对 WACC 敏感，也对 PoS、峰值销售、上市年份高度敏感。Excel Sensitivity Sheet 必须覆盖**全部四个关键维度**，而非仅 WACC 专项：

| 敏感性维度 | 测试范围 | 为什么重要 |
|---|---|---|
| **WACC** | 基准 ±2%（如 11% / 13% / 15%） | 10%→12% 现值降 ~11% |
| **WACC × 峰值销售** | 3×3 矩阵 | 峰值是最大单一不确定项（±50% → 估值 ±40-50%） |
| **WACC × PoS** | 3×3 矩阵 | PoS 翻倍 → rNPV 翻倍 |
| **上市年份** | 推迟 0/1/2 年 | 推迟 1 年 rNPV 下降 ~10% |
| **上市年份 × PoS** | 3×3 矩阵 | 早期管线尤其敏感 |

### 结论稳健性判断

> ⚠️ 如果估值结论（低估/高估）在**任意单一参数 ±标准范围**（WACC ±2% / PoS ±20% / 峰值 ±30%）内翻转，说明结论**不稳健**，必须在报告中明确标注不确定性，不可下绝对判断（"严重低估"/"严重高估"）。
>
> 此时改用区间表述（如"每股 4.4-5.7，相对当前价高估 25-45%"），等更多催化剂数据（如 Phase 3 读出）收敛后再定性。

### 与反向引擎的呼应

敏感性分析的结果也用于 `reverse-rnpv-method.md` 的 Stage 5：在反推市场隐含 λ 时，用悲观/基准/乐观三套 WACC 分别反推，观察 λ 的区间——若 λ 在不同 WACC 下从 <1 翻到 >1，说明市场定价对 WACC 假设极度敏感，下结论需格外审慎。
