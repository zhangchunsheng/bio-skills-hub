# RPM 远程患者监测合规

## 1. 什么是 RPM
RPM（Remote Patient Monitoring）远程患者监测：通过联网器械在院外采集患者生理数据并传输给医护端，用于诊断、治疗决策或病情跟踪。

## 2. 常见产品形态
- 可穿戴心电 / 血压 / 血氧监测
- 植入式器械 + 家用遥测器
- 连续血糖监测（CGM）+ APP
- 术后康复远程随访设备

## 3. 合规关注点
| 维度 | 关键问题 |
|---|---|
| 临床证据 | 远程数据能否支持原器械的临床有效性声明？ |
| 数据质量 | 采样频率、传输稳定性、异常值处理 |
| 算法性能 | 报警灵敏度 / 特异度，假阳性率 |
| 受益-风险 | 漏报/误报的临床后果 |
| 网络安全 | 数据在传输与存储中的完整性、保密性 |
| 数据合规 | GDPR / HIPAA / 个保法适用场景 |

## 4. 注册路径提示
- 若 RPM 功能属于原器械的**新增预期用途**，通常需走变更注册或新增注册。
- 若仅为**数据展示/提醒**，不改变原器械预定用途，可作为标签/IFU 补充说明。
- 中国 NMPA 对「远程监测」类器械按风险分级，多数为二类或三类。

## 5. 与数据合规包的衔接
RPM 数据跨境（如中国患者数据传至境外云端分析）涉及数据出境合规，详见 `medical-device-data-privacy-compliance`。
