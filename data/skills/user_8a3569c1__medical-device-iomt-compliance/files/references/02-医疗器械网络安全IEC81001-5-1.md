# 医疗器械网络安全 IEC 81001-5-1

## 1. 为什么必须做
联网医疗器械一旦涉及数据传输、远程升级、云端存储，就必须证明其网络安全（Cybersecurity）。FDA、NMPA、MDR 都已把网络安全作为预市（premarket）必交证据。

## 2. 适用标准
- **IEC 81001-5-1:2021** — 健康软件与医疗器械网络安全，通用要求。
- **IEC 80001-5-1** — 医疗 IT 网络安全风险管理。
- **FDA** — Cybersecurity in Medical Devices: Quality System Considerations and Content of Premarket Submissions。
- **MDCG** — 网络安全指南（MDCG 2019-16 及后续更新）。

## 3. 证据清单
| 文档 | 说明 |
|---|---|
| 网络安全风险管理报告 | 威胁建模（STRIDE）、风险可接受性 |
| 安全需求规格说明 | 身份认证、加密、访问控制、日志审计 |
| 软件物料清单（SBoM） | 第三方组件、开源库、已知漏洞 |
| 漏洞管理程序 | 发现、披露、修补流程与 SLAs |
| 渗透测试 / 代码审计报告 | 静态 + 动态测试摘要 |
| 远程升级与补丁策略 | OTA 安全机制、回滚方案 |
| 上市后网络安全监测计划 | PMS 阶段持续收集漏洞情报 |

## 4. 常见雷区
- 把网络安全当作上市后补救项 → 会被退审。
- SBoM 缺失或版本对不上 → 被认定为质量体系不完整。
- 默认密码 / 硬编码密钥 → 直接触发安全否决。
