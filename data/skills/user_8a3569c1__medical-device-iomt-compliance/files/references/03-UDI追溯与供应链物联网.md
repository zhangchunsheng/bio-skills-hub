# UDI 追溯与供应链物联网

## 1. UDI 核心概念
- **UDI-DI（Device Identifier）**：器械唯一静态标识，关联型号/版本。
- **UDI-PI（Production Identifier）**：生产动态信息（批号、序列号、有效期、生产日期）。
- **载体**：一维码、二维码、RFID（需法规允许）。

## 2. 全球主要数据库
| 市场 | 数据库 | 关键要求 |
|---|---|---|
| 美国 | GUDID | 通过 FDA UDI 门户网站提交 |
| 欧盟 | EUDAMED | 仅对制造商开放，需 SRN |
| 中国 | 国家药品监督管理局 UDI 数据库 | NMPA 医疗器械唯一标识数据库 |

## 3. 与供应链物联网的结合
- 每个包装层级（单品→盒→箱）赋码，实现**一物一码/一批一码**。
- 通过 API 与 ERP/仓储/WMS 打通，实现扫码出入库、召回定位。
- 与物流温控（IoT 传感器）结合，实现冷链全程可追溯。

## 4. 注册资料要点
- UDI 编码规则说明

- 数据库提交流程与责任人
- 追溯系统架构图（若适用）
- 上市后召回模拟演练记录
