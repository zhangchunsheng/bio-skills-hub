# 藏药常用药材的免疫药理活性参考

## 藏药单方免疫活性数据库

### 1. 红景天（Rhodiola rosea / ཤྲུལ་ཤིང་།）

| 项目 | 内容 |
|------|------|
| **三因属性** | 功效"清肺热、活血化瘀"，偏凉性 |
| **活性成分** | 红景天苷(Salidroside)、酪醇(Tyrosol)、洛塞维(Rosavin) |
| **免疫细胞靶点** | 巨噬细胞(M1→M2转向)、T细胞(CD4+/CD8+比例调节) |
| **信号通路** | NF-κB↓, AMPK↑, PI3K/AKT↑, Nrf2/HO-1↑ |
| **已知效应** | 抑制LPS诱导巨噬细胞TNF-α/IL-6/NO释放；促进M2标志物CD206/IL-10表达；抑制NF-κB核转位 |
| **相关文献** | PMID: 29936217, 31253690, 32146933 |

### 2. 雪莲花（Saussurea involucrata / གཡག་མིག།）

| 项目 | 内容 |
|------|------|
| **三因属性** | 功效"清热解毒、祛风湿"，凉性 |
| **活性成分** | 雪莲内酯(Saussureamine)、黄酮类(Hispidulin, Luteolin) |
| **免疫细胞靶点** | T细胞(Th17↓, Treg↑)、巨噬细胞(抗炎) |
| **信号通路** | STAT3↓, RORγt↓, FoxP3↑, NLRP3↓ |
| **已知效应** | 抑制Th17分化和IL-17分泌；促进Treg分化；改善CIA小鼠关节炎症状 |
| **相关文献** | PMID: 27342373, 28972002 |

### 3. 藏红花（Crocus sativus / གུར་གུམ།）

| 项目 | 内容 |
|------|------|
| **三因属性** | 功效"活血、调经、解郁"，平性 |
| **活性成分** | 藏红花素(Crocin)、藏红花醛(Safranal)、番红花苦苷(Picrocrocin) |
| **免疫细胞靶点** | 巨噬细胞(M1↓)、NK细胞(活性↑)、T细胞(增殖调控) |
| **信号通路** | NF-κB↓, MAPK(p38/JNK)↓, NLRP3↓ |
| **已知效应** | 抑制LPS诱导巨噬细胞iNOS/COX-2；抑制TNF-α/IL-1β/IL-6释放；调节肠道免疫 |
| **相关文献** | PMID: 29800926, 30659856 |

### 4. 肉苁蓉（Cistanche deserticola / ཐང་ཤིང་།）

| 项目 | 内容 |
|------|------|
| **三因属性** | 功效"补肾壮阳、益精血"，温性 |

| **信号通路** | PI3K/AKT↑, MAPK/ERK↑, NF-κB (双向调控) |
| **已知效应** | 增强T细胞增殖和IL-2分泌；增强巨噬细胞吞噬功能；免疫抑制模型中恢复免疫力 |
| **相关文献** | PMID: 28774717, 31023271 |

### 5. 冬虫夏草（Cordyceps sinensis / དབྱར་རྩྭ་དགུན་འབུ།）
