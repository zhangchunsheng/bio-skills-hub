# T细胞亚群标志物与功能参考

## T细胞发育与分化概览

```
胸腺选择
   ↓
Naïve CD4+ T（CD45RA+CCR7+）
   ├──→ Th1（T-bet+IFN-γ+）— 细胞免疫，抗胞内病原体
   ├──→ Th2（GATA3+IL-4+IL-5+IL-13+）— 体液免疫，抗寄生虫
   ├──→ Th17（RORγt+IL-17A+IL-22+）— 自身免疫，抗真菌
   ├──→ Treg（FoxP3+CD25+IL-10+TGF-β+）— 免疫抑制
   └──→ Tfh（BCL6+CXCR5+PD-1+）— 辅助B细胞生发中心

Naïve CD8+ T（CD45RA+CCR7+）
   └──→ CTL（GzmB+Perforin+IFN-γ+）— 细胞毒性
           └──→ Exhausted CD8+ T（PD-1+TIM-3+LAG-3+TOX+）— 耗竭
```

## 常用刺激方案（体内细胞因子检测前需要体外再刺激）

### PMA+Ionomycin刺激

**方案：**
- PMA：50 ng/mL
- Ionomycin：1 μg/mL
- Brefeldin A：10 μg/mL（阻断高尔基体运输，4-6 h）
- 或 Monensin：2 μM（GolgiStop）

**时间：** 4-6 h（37°C，5% CO₂）

**注意：** PMA+Ionomycin会导致CD4下调，门控时需注意。

### CD3/CD28激动抗体刺激

**方案：**
- plate-bound anti-CD3 (5 μg/mL)
- soluble anti-CD28 (1-3 μg/mL)
- 或 Dynabeads Human T-Activator (CD3/CD28)

**时间：** 24-72 h（用于增殖实验）
- 胞内因子染色：最后6 h加Brefeldin A

## T细胞亚群与藏药调控的关联

| 亚群 | 藏药传统功效对应 | 潜在调控意义 |
|------|-----------------|-------------|
| Th1 ↑ | 增强正气、抗病毒（如"清热解毒"） | 抗感染免疫增强 |
| Th2 ↑ | 湿热证、过敏反应 | 辅助抗体产生，但也参与过敏 |
| Th17 ↑ | 风湿痹痛（"黄水病"） | 与自身免疫性关节炎相关 |
| Treg ↑ | 调和三因、平衡免疫 | 免疫抑制，减轻过度炎症 |
| CTL ↑ | 肿瘤抑制（"化瘀散结"） | 抗肿瘤免疫增强 |
| Exhausted CD8+ ↓ | 逆转免疫耗竭 | 恢复抗肿瘤/抗病毒免疫 |
