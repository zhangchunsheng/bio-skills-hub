# 医药行业经验传授与教学工具（知识培训场景）

目标：把碎片化的行业知识整理为体系化、场景化、可复用的知识体系，帮助团队成员（尤其是新人）快速建立行业认知。知识主线：**什么是药 → 药怎么卖 → 卖了之后怎么管**，层层递进。

## 一、行业知识体系化

建议的知识地图（可按此设计培训大纲）：

1. **行业版图**：工业（研发/生产）→ 商业（流通/配送）→ 终端（医院/药店/基层/第三终端）→ 患者角色与支付方（医保）
2. **产品维度**：处方药 vs OTC vs 中成药；创新药 vs 仿制药；集采品种 vs 非集采品种
3. **模式维度**：自营 vs 招商 vs 混合；底价 vs 佣金
4. **政策维度**：两票制、集采、医保谈判、DRG/DIP、合规反腐
5. **管理维度**：SFE、流向、费用结算、合规闭环

## 二、场景化教学方法

核心方法：**用真实行业案例和场景讲概念，不念定义。**

示例——讲"两票制"：
- 不念政策文件，而是讲"两票制之前药是怎么从厂家到患者的"（厂家 → 多级过票商 → 商业 → 终端，中间层层加价、票据流转）→"两票制之后变成了什么样"（厂家 → 商业 → 终端，只允许两张发票）→"中间的利益链条怎么变的"（过票空间被压缩，佣金兑付方式被迫转型，CSO 兴起）。
- 每讲完一个政策，补一句"这对你的岗位意味着什么"，把政策和听者的工作连接起来。

其他教学技巧：
- **角色视角切换**：同一问题从厂家、商业公司、终端、患者、监管五个视角各讲一遍，帮助理解各方利益博弈（例：集采对厂家是降价，对患者是省钱，对商业是配送费竞争，对医生是用药习惯被迫改变）
- **数据实例化**：讲流向就给一张真实的（脱敏）流向表，让学员现场找问题，比讲十页 PPT 有效
- **黑话词典**：新人最容易卡在黑话上，随讲随注（进院、上量、动销、协访、底价、高开、过票、冲流、纯销、压货……）

## 三、角色适配的表达深度

| 对象 | 聊什么 | 举例 |
|---|---|---|
| 高层（董事长/总经理） | 战略格局、模式选择、行业方向 | 自营还是招商、要不要布局院外 |
| 中层（大区/地区经理） | 管理抓手、区域策略、团队建设 | KPI 怎么定、辖区怎么调 |
| 一线（代表/流向专员） | 执行动作、具体做法 | 协访路线怎么排、流向异常怎么核对 |

做培训时同样按学员层级裁剪内容深度。

## 四、可复用工具（经验沉淀）

向用户交付方案或培训时，可按以下模板生成配套工具：

1. **流向数据质量自检清单**：到账及时率 / 完整率 / 准确率指标 + 常见异常特征（断链、串货、虚假流向、时间差错位）+ 逐项核查动作
2. **代表协访评估表**：拜访前准备（目标、客户背景）、拜访中观察（开场、需求探询、异议处理、缔结）、拜访后辅导反馈，各维度打分 + 改进建议
3. **代理商选择评分卡**：终端覆盖 / 资金实力 / 合规意识 / 主推意愿 / 产品结构冲突度，加权评分，设定准入线
4. **区域业务计划模板**：现状盘点（潜力、份额、竞品）→ 目标 → 策略 → 资源需求 → 风险与预案

生成工具时遵循：给出可直接使用的表格/清单结构，注明使用场景和评估标准，不虚构具体阈值（阈值需结合企业实际校准）。

## 教学输出要求

- 每个概念都配一个场景或案例，拒绝纯定义
- 政策类内容必须提醒"以最新政策文件为准"
- 培训类输出给出课后检验方式（如让学员复述、做练习题、现场找流向异常）
