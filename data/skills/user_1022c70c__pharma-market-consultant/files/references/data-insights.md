# 医药市场数据洞察知识框架

核心原则：做有业务意义的数据分析，而非简单的数据罗列。每一个数字背后都要回答"这对业务决策意味着什么"。

## 一、流向数据分析

### 流向数据全链路

从商业公司出库 → 终端入库 → 终端销售，每一环都可能出问题。分析流向前先确认数据口径：出库流向（最常用，反映商业公司卖给了谁）vs 纯销流向（终端实际卖给患者，更真实但更难采集）。

### 流向数据常见问题清单

- **数据断链**：某段时间某商业公司/某终端的流向缺失——先查采集方式是否变更（人工收取漏了？邮箱断供？接口故障？）
- **串货（窜货）**：A 省的货出现在 B 省流向里——对照批号、发货记录与流向终端所在区域；重点核查边界区域终端和大型调拨商
- **虚假流向**：商业公司或代理商为完成指标冲量、回冲——特征是期末集中放量、下期初负数冲回、终端进货量与纯销量严重背离
- **时间差错位**：出库日期与终端入库日期错位导致月度对不齐——核对账期与结账日，月环比分析时注意口径
- **终端主数据混乱**：同一终端多个名称/编码导致聚合失真——先做主数据清洗（详见 playbooks.md 流向采集体系）
- **单位与税率口径**：含税/不含税、盒/瓶/最小单位换算错误

### 数据治理建议方向

采集方式分级（人工 < 邮箱 < 接口）、终端主数据标准化（名称、编码、行政区划、终端类型、等级）、异常流向预警规则、流向与发货数据的交叉核对机制。

## 二、销售效能分析（SFE）

- **目标拆解合理性评估**：目标是否按历史基础×增长逻辑拆解？是否脱离区域潜力（医院数量、床位数、门诊量、竞品存量）？拍脑袋目标必然导致年底压货
- **过程指标与结果指标关联分析**：拜访频率、覆盖率、协访质量等过程指标与销量、份额、增长的结果指标做相关性解读——拜访量高但销量不涨，通常是拜访质量或目标客户选择问题
- **代表产能评估与辖区优化**：辖区终端数量与地理分布、拜访路线效率、人均产出 vs 团队中位数；辖区调整要兼顾市场潜力与人员能力

## 三、市场竞争分析

- **品类竞争格局梳理**：明确品类定义（ATC 分类/适应症），梳理主要玩家、份额、增速
- **竞品策略分析**：竞品的定价、渠道、学术投入、团队规模对比；关注竞品核心人员流动带来的市场机会
- **市场份额变化解读**：份额涨跌先拆量价（是销量驱动还是价格驱动），再拆渠道（院内跌院外涨？），最后落到具体动作
- **新品上市对格局的冲击预判**：新机制/新剂型/新适应症对存量品种的替代速度，医保准入节奏的影响

## 四、费用与合规分析

- **费用投入产出比分析**：按区域/终端/代表维度的费用-销量-毛利三维交叉；识别费用高产出低的"出血点"
- **合规风险点识别**：费用真实性（发票流、合同流、业务流三流是否一致）、讲者真实性、会议真实性
- **费用结算闭环设计建议**：从费用申请 → 活动执行 → 结果回传（流向/照片/签到）→ 结算支付的全链路闭环，详见 playbooks.md

## 数据分析输出要求

1. 先给结论（这个数据说明了什么业务问题），再给推导过程
2. 数据异常不要只说"有异常"，要说"可能是哪三种原因、分别怎么验证"
3. 缺数据时明确列出需要用户提供的数据清单及获取方式
4. 涉及预测的场景，给出假设前提，不拍胸脯
