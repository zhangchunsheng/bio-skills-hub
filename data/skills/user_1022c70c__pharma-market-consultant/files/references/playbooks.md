# 医药工作方案指导知识框架

方案输出统一结构：**目标 → 路径 → 关键动作 → 风险提示**。所有建议必须结合用户实际情况给出前提条件和适用边界。

## 一、销售团队管理（自营模式）

- **架构设计**：按区域/产品/终端类型划分的利弊；大区-地区-代表的典型层级与管理幅度（一名地区经理带 6-10 名代表较常见，过多则协访和管理质量下降）
- **KPI 体系设计**：结果指标（销量、份额、回款）与过程指标（拜访量、覆盖率、协访、新客户开发）的配比；纯结果导向逼出压货和造假，纯过程导向养出"苦劳文化"
- **考核与激励机制**：底薪-奖金结构设计、季度 vs 年度考核节奏、加速器/封顶规则对新老市场区别对待
- **代表培训体系**：产品知识 → 拜访技能（协访辅导）→ 区域业务计划的进阶路径
- **地区经理管理能力提升**：协访辅导能力（不是替代表谈，而是观察后辅导）、区域业务计划能力、团队梯队建设

## 二、招商体系管理（代理模式）

- **代理商选择标准**：终端网络覆盖、资金实力、合规意识、主推意愿（代理产品结构与自家产品的竞争关系）
- **招商政策设计**：底价发包（货物风险转移给代理商，厂家毛利锁定但掌控力弱）vs 佣金制（厂家高开票、掌控流向和终端，但税务与管理工作量重）vs 混合模式；保证金规则
- **代理商分级管理**：按合作深度与产出分级的差异化资源投放；核心代理的独家保护与考核退出机制
- **招商团队考核**：从"签商数量"转向"代理商活跃率、终端覆盖、回款质量"的过程管理
- **代理商赋能与管控**：学术赋能（培训、物料、区域会议）+ 数据管控（流向回传作为续约/佣金结算依据）

## 三、流向采集体系

- **采集方案设计**：按商业公司分级选择采集方式——头部商业走接口/API，中小商业走邮箱+模板，长尾靠人工收取；采集频率（月度为基线）
- **数据质量管控机制**：到账及时率、完整率、准确率三个核心指标的监控；异常流向人工复核规则
- **流向分析应用场景**：纯销还原、窜货识别、代理商佣金结算、终端覆盖盘点、市场潜力测算
- **流向与费用结算打通**：以真实流向（而非报量）作为代理商佣金/费用兑付依据，从机制上杜绝虚假流向

## 四、合规转型方案

- **CSO 合规管理架构设计**：CSO 准入尽调（关联方识别、业务真实性）、合同-发票-成果三单匹配、服务成果留痕
- **费用真实性闭环设计**：费用申请 → 活动执行（签到、照片、讲者简历、会议纪要）→ 成果回传 → 审核结算的全链路证据链
- **代表行为合规管控**：拜访行为数字化留痕、敏感场景（带金、统方）红线清单、合规培训与承诺机制
- **学术推广合规化改造**：从"费用驱动"转向"证据驱动"——讲者管理、会议分级、学术内容合规审核

## 五、渠道策略设计

- **等级医院与零售渠道的资源分配**：按产品属性（处方药/OTC、急性/慢病、集采内/外）决定院内院外权重
- **线上线下融合策略**：B2B 平台（第三终端覆盖）、O2O（零售即时配送）、互联网医院（复诊续方、DTP 协同）
- **新渠道布局建议**：DTP 药房（特药）、双通道药店（国谈品种）、私域患者管理（慢病）
