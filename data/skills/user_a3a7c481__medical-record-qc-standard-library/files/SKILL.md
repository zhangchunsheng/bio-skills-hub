# 病历质控（庆安病历质控）

本技能从「庆安病历质控」知识库蒸馏而来，是黑龙江省病历质控的权威标准速查库。用于病历质量检查、缺陷认定、病历分级评定、病案首页填写核对、主要诊断/手术选择、质控指标计算与整改意见出具。

> 使用本技能时，医学/法规类结论必须附依据文件及文号（如"黑卫医发〔2023〕60 号""卫医政发〔2011〕84 号"）。

## 二、病历质量分级评定（核心规则）

### 2.1 百分制评分表结构

| 项目 | 分值 |
|---|---|
| 病案首页 | 10 |
| 入院记录 | 20 |
| 病程记录（含首次病程/日常/查房/围术期/会诊等） | 40 |
| 出院记录 | 10 |
| 辅助检查 | 5 |
| 书写基本要求 | 5 |
| 知情协议签字书 | 10 |
| **合计** | **100** |

扣分采取累加计分，每一书写项目扣分最高不超过该项目总分值。

### 2.2 分级判定规则（评定标准的"说明"）

1. **先做单项否决筛选**（单项否决共 24 条，评分表以「\*」号标注）：
   - 存在任一条单项否决缺陷 → **乙级病历**；
   - 存在**三项**单项否决缺陷，或**缺入院记录、缺手术记录、字迹潦草（含签名）难以辨认三处以上** → **丙级病历**；
   - 存在单项否决缺陷的病历，**不再进行质量评分**。
2. **评分分级**（针对无单项否决的合格病历）：
   - **≥ 90 分 → 甲级病历**；
   - **90 分以下（不含 90）→ 乙级病历**；
   - **< 75 分 → 丙级病历**。

### 2.3 单项否决清单（按项目归类）

**病案首页（乙级）**
1. 首页医疗信息未填写（空白首页）
2. 传染病漏报
3. 血型或 HBsAg、HCV-Ab、HIV-Ab 书写错误

**入院记录**
4. 入院记录未在 24 小时内完成（乙级）
5. 缺入院记录——实习医师、进修医师代替住院医师书写入院记录视为缺入院记录（丙级）

**病程记录**
6. 缺首次病程记录，或首次病程记录中缺病例特点、初步诊断、诊断依据、鉴别诊断和诊疗计划（诊断不明确的患者，缺鉴别诊断视为乙级）
7. 危重病例 24 小时内缺科主任或主任（副主任）医师查房记录
8. 疑难或诊断未确定病例 72 小时内缺科主任或副主任医师以上人员查房记录
9. 新开展的手术及大型手术缺科主任或授权上级医师签名确认
10. 缺术前第一手术者查看病人的记录
11. 缺麻醉记录单
12. 产科无新生儿记录
13. 缺死亡前抢救记录
14. 缺死亡讨论记录
15. 缺手术记录（丙级）

**出院记录**
16. 缺出院（死亡）记录

**辅助检查**
17. 缺住院期间对诊断、治疗有重要价值的辅助检查报告

**书写基本要求**
18. 字迹潦草（包括签名）难以辨认三处以上（丙级）
19. 不正确的涂改病历
20. 病历中摹仿或代替他人书写或签名
21. 计算机书写病历因拷贝行为导致的原则性错误
22. 低年资医师、试用期医务人员、实习医务人员、进修医务人员未按规定内容和要求书写病历
23. 整页病历记录缺失造成病案不完整或记录内容前后矛盾

**知情协议签字书**
24. 缺有创检查（治疗）协议签字书或缺患者（近亲属）签名
25. 缺手术协议签字书或缺患者（近亲属）签名
26. 缺麻醉协议签字书或缺患者（近亲属）签名
27. 输血治疗患者缺患者（近亲属）签名的协议签字书

> 注：上述为从《评定标准》评分表提取的「\*」号单项否决项及丙级项，共 24 条否决 + 丙级专属情形。实践中以"存在一条→乙级、三项/丙级三情形→丙级"为判定口径。

## 四、住院病案检查标准（28 项 + 常见问题分类）

| 序号 | 项目 | 评分要点（简） | 常见问题分类 |
|---|---|---|---|
| 1 | 主诉 | 简明扼要、能导出第一诊断 | 超 20 字；不能导出第一诊断；未说明发病时间；用诊断代替主诉 |
| 2 | 现病史 | 全面清晰反映起病/演变/诊疗，术语准确 | 无演变；与主诉不符；起病时间/诱因不清；症状部位/时间/性质/程度/伴随不清；缺重要阴性症状体征；拷贝 |
| 3 | 体格检查 | 项目齐全、有重点；专科全面正确 | 缺项；相关查体不充分；阳性体征未记；专科不全；鉴别体征未记；拷贝 |
| 4 | 首次病程·病例特点 | 归纳总结、要点清晰、反映鉴别要点 | 照搬现病史；拷贝查体/辅助检查；未归纳 |
| 5 | 首次病程·拟诊讨论 | 分析主要/次要诊断及并发症，体现临床思维 | 无分析/无鉴别；分析不够；重复病例特点；同科同病内容相同 |
| 6 | 首次病程·诊疗计划 | 规范合理、有针对性 | 套话空话；缺乏针对性；不具体 |
| 7 | 病程记录·病情记录 | 及时详记病情变化（不能以检查结果代替病情记录） | 未及时记病情/检查；无分析判断处理；以检查结果代替；二次病程完全相同；间隔超时；拷贝 |
| 8 | 病程记录·分析诊治思路 | 有分析和处理，诊治有依据 | 病情无分析；观察无针对性；危急值无分析处理；诊断无依据；措施无理由 |
| 9 | 查房·首次查房 | 补充病史查体、诊断依据、鉴别，有教学意识 | 未记补充病史/新发现；48h 无上级查房；无分析/鉴别；无评估；无方案 |
| 10 | 查房·日常查房 | 准确详记上级查房意见 | 主治查房无内容/无分析/无处理；副高以上无分析指导；确诊困难病例内容简单；病情恶化未观察记录；间隔超时 |
| 11 | 疑难危重/多学科讨论 | 记各级各科发言，有小结和具体措施 | 记录不规范/内容简单/缺分析；缺讨论意见及主持人总结；缺记录者签名 |
| 12 | 会诊记录 | 申请载明病情/诊疗/理由/目的；会诊意见及依据 | 有医嘱缺会诊单；有记录无医嘱；病程缺执行情况；邀请/会诊时间未记；会诊超时；意见缺陷 |

| 14 | 围术期·术前小结讨论 | 术前诊断/手术指征/术式/麻醉/注意事项/术者查看 | 无术前小结；小结缺漏项；无术前讨论；讨论缺项；指征不明确；指征拷贝病史；讨论拷贝 |
| 15 | 围术期·四级手术术前多学科讨论 | 记录指征/方式/预期效果/风险/预案 | 四级手术无多学科讨论；记录不规范 |

## 五、门诊病案检查标准（7 项）

| 序号 | 项目 | 检查要点 | 常见问题分类 |
|---|---|---|---|
| 1 | 主诉 | 初诊必写，重点突出、简明扼要 | 缺主诉；无时间；超 20 字；不能导出第一诊断；未说明发病时间；用诊断代替 |
| 2 | 现病史 | 与主诉相关相符，反映起病/演变/诊疗，有鉴别资料 | 缺现病史；拷贝主诉；与主诉不符；症状描述不清；缺鉴别资料 |
| 3 | 既往史和其他病史 | 记重要相关既往史、过敏史、个人/生育/家族史 | 缺既往史或用"-"；既往史缺陷；过敏史/个人/生育/家族史缺陷 |
| 4 | 查体 | 记录一般情况，常规/专科查体不漏项，必要的阴性体征 | 缺查体或用"-""无"；记录不准/遗漏；阳性体征未描述 |
| 5 | 处理 | 记检查项目、治疗措施、处方药物名称剂量用法、证明书内容、注意事项 | 缺处理；不全；与诊断不相关或无适应症 |
| 6 | 诊断 | 规范写诊断名称，明确病理分型；未明写待查+可能诊断 | 缺诊断；诊断名称不规范 |
| 7 | 医师签名 | 必须有接诊医师签名 | 缺签名；不全；无法辨认 |

## 六、病案首页填写规范与主要诊断选择原则

### 6.1 主要诊断选择一般原则（国卫办医发〔2016〕24 号）

1. **病因诊断**能包括疾病临床表现 → 选病因诊断。
2. **以手术治疗为目的** → 选与手术一致的疾病。
3. **疑似诊断入院、出院未确诊** → 选临床高度怀疑、倾向性最大的诊断。
4. **以症状/体征/检查异常入院、出院诊断不明** → 以该症状/体征/异常结果为主要诊断。
5. **某种临床表现作为诊治目的** → 选该临床表现（临终状态原则上不作主要诊断）。
6. **仅针对并发症治疗** → 该并发症为主要诊断。

**住院期间出现更严重并发症/疾病时**：
- 手术导致的并发症 → 选原发病为主要诊断；
- 非手术治疗或与手术无直接相关 → 按一般原则选。

### 6.2 特殊情形主要诊断选择

| 情形 | 主要诊断 |
|---|---|
| 肿瘤手术治疗/确诊 | 肿瘤 |
| 继发肿瘤手术治疗/确诊（原发仍在） | 继发肿瘤 |
| 仅放化疗 | 恶性肿瘤放疗/化疗 |
| 肿瘤并发症或肿瘤以外疾病治疗 | 该并发症或该疾病 |
| 产科 | 产科主要并发症/合并症；无则选妊娠、分娩情况（周数、G/P、胎方位等） |
| 多部位损伤 | 危害最大或主要治疗的损伤 |
| 多部位灼伤 | 程度最重部位；程度相同取面积最大部位 |
| 以治疗中毒为主 | 中毒（临床表现为其他诊断） |
| 原诊疗计划未执行、无其他治疗出院 | 拟诊疗的疾病（影响执行的原因写入其他诊断） |

### 6.3 其他诊断填写顺序

先写主要疾病**并发症**，后写**合并症**；先写病情重，后写轻；先写已治疗，后写未治疗。
应写入其他诊断：入院前及住院期间与主要疾病相关的并发症；现病史涉及疾病和临床表现；住院期间新发生/新发现的疾病和异常所见；对本次诊治及预后有影响的既往疾病。

### 6.4 主要手术/操作选择原则

- 主要手术首先选择与主要诊断相对应的手术（技术难度最大、过程最复杂、风险最高），填在首页手术操作名称栏第一行。
- 既有手术又有操作 → 按手术优先，依手术、操作时间顺序逐行填写。
- 仅有操作 → 先填与主要诊断对应的主要治疗性操作（尤其有创操作），后按时间顺序。

### 6.5 关键字段填写口径

| 字段 | 口径 |
|---|---|
| 入院病情 | 1.有 2.临床未确定 3.情况不明 4.无（对照出院诊断与入院时是否已有） |
| 切口愈合等级 | 0 类（无体表切口/腔镜）；Ⅰ无菌、Ⅱ沾染、Ⅲ感染；愈合 甲/乙/丙/其他 |
| 手术级别 | 1 级（低风险简单）~ 4 级（高风险重大） |
| 诊断编码 | ICD-10（临床版）；手术操作编码 ICD-9-CM-3（临床版） |
| 入院时间 | 实际入病房接诊时间；出院时间=离开病房时间（死亡=死亡时间），精确到分钟 |
| 实际住院天数 | 入院日与出院日只算一天 |
| 新生儿 | 出生到满 28 天为新生儿期，出生日为第 0 天；出生/入院体重精确到 10 克 |
| 离院方式 | 1.医嘱离院 2.医嘱转院 3.医嘱转社区/乡镇 4.非医嘱离院 5.死亡 9.其他 |
| 损伤中毒外部原因 | 具体原因，不得笼统写"车祸""外伤"，须填标准编码 |

## 九、病历真实性认定（专家共识要点）

### 9.1 修改/补正规则

- **修改**：纸质用双线划改，保留原记录可辨，注明时间、签名；不得刮、粘、涂、描、盖、贴。电子病历系统保留身份识别+历次痕迹+时间+操作人。
- **补正**：对"已完成/确定"的病历，在原内容旁划线标识+附注纠正，说明原因、签名、日期；归档病历确需改须经管理部门批准。
- **禁止补正情形**：患者已复印；纠纷后已封存；司法机关已调取；已签名打印件不宜改电子档；患者签字后不得单方修改（须患者在场并签字确认）。

### 9.2 伪造 vs 篡改 vs 书写不规范

- **伪造**：虚构诊疗事实、无中生有制作记录（如未做的检查出现报告单）。
- **篡改**：故意改动/歪曲内容，将此事实改为彼事实，逃避责任。
- **书写不规范**（不等于不真实）：缺重要构成文件、缺重要医疗活动记载、刮粘涂改、非本人签名/电子签名密钥非本人使用等。

### 9.3 不真实认定方法

- 全面评价法（病历作为整体，各文件相互印证）
- 局部评价法（刮粘涂、明显不可能信息且无合理解释、电子病历后台无痕迹）
- 合理性解释法（合理解释可采信）
- 其他证据印证法（监控、药房记录等）

### 9.4 法律后果

- 民事：伪造/篡改致真实性难确认 → 推定医疗机构有过错（《民法典》第 1222 条）。
- 行政：《医师法》第 56 条、《医疗纠纷预防和处理条例》第 45/47 条。
- 刑事：意图陷害/隐匿罪证涉嫌伪证罪（《刑法》第 305 条）。

## 十、常见缺陷分类与整改口径

### 10.1 高频缺陷 → 整改建议

| 缺陷类型 | 整改口径 |
|---|---|
| 主诉超 20 字/用诊断代替 | 精简为"症状+部位+持续时间"，一般不用病名（已确诊且为特殊治疗者可例外） |
| 现病史拷贝主诉/无演变 | 按时间顺序写发病、症状发展、伴随症状、诊疗经过、一般情况，补充鉴别阴性资料 |
| 首次病程照搬入院记录 | 高度概括归纳病例特点，禁止复制粘贴，逐条给出诊断依据 |
| 拟诊讨论缺鉴别诊断 | 每诊断给依据；诊断不明须写鉴别诊断及分析 |
| 诊疗计划空话 | 分"检查计划"+"治疗措施"两条，禁写"完善术前检查""对症治疗" |
| 以检查结果代替病情记录 | 病程须记录症状体征变化+对结果的分析判断和处理 |
| 上级查房记录复制现病史 | 只记查房当日情况+病情分析+诊疗意见 |
| 48h 无主治首次查房 | 落实三级查房时限（主治 48h、副高 72h 首次查房） |
| 抗菌药物无病原学依据 | 补记使用指征/变更理由；有病原学依据 |
| 输血缺效果评价 | 补输血前评估、输注观察、输血后评价（实验室+临床） |
| 首页诊断与病历不符 | 核对主要诊断选择原则，补齐多填/漏填，编码员按 ICD 规则纠正 |
| 授权委托书漏项 | 补全患者基本信息、受托人、委托事项、双方签名 |

### 10.2 输出建议格式

质控检查/整改报告建议用表格输出：`缺陷序号 | 项目 | 缺陷内容 | 对应标准条款 | 严重程度（甲/乙/丙级影响） | 整改建议`，并附依据文件文号。
