# 病历质控

基于「庆安病历质控」知识库蒸馏的**黑龙江省病历质控标准速查库**，覆盖 23 份官方规范/标准。用于病历质量检查、缺陷认定、病历分级评定、病案首页填写核对、主要诊断/手术选择、质控指标计算与整改意见出具。

> 本技能输出的医学/法规类结论均附官方依据文号，不臆造未收录的标准条文。

## 能做什么

| 模块 | 内容 |
|---|---|
| 病历分级评定 | 百分制评分结构 + 甲/乙/丙级判定 + 24 条单项否决清单 |
| 住院病案检查 | 28 项检查点 + 每项"常见问题分类" |
| 门诊病案检查 | 7 项检查点 + 常见问题分类 |
| 首页填写规范 | 主要诊断选择 6 大原则 + 肿瘤/产科/损伤/中毒等特殊情形 + 主要手术选择 + 关键字段口径 |
| 质控指标 | 27 个 MER 指标（HR/TL/ME/D&T/TQ 系列）+ 不合理复制病历认定 |
| 书写时限 | 18 项核心时限速查（入院 24h、首程 8h、主治 48h、副高 72h 等） |
| 死亡病案评估 | 手术（8 项）/非手术（7 项）评估要点 |
| 真实性认定 | 修改/补正规则、伪造 vs 篡改 vs 书写不规范、认定方法、法律后果 |
| 整改口径 | 12 类高频缺陷 → 整改建议 + 输出格式模板 |

## 使用示例

- 「按黑龙江省标准评定这份病历是甲级还是乙级？」
- 「这条主诉有哪些缺陷？如何整改？」
- 「这个病例的主要诊断应该怎么选？」
- 「入院记录、首次病程的书写时限要求是什么？」
- 「如何认定这份病历是否伪造或篡改？」
- 「帮我算一下这个科室的甲级病历率（MER-TQ-09）。」
