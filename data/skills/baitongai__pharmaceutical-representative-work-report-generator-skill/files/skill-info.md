# Skill Info

## Skill Name
医药代表工作报告生成器

## Description
医药代表日/周/月报合规生成器。基于拜访记录、学术活动、临床反馈等数据， 自动生成符合《药品管理法》第9条要求的学术推广工作报告， 突出学术价值而非销售数字。 核心能力：(1) 日报/周报/月报三模板，一键生成 .docx / .pdf； (2) 内置合规审查引擎，自动扫描并标记销售导向词汇； (3) 学术价值提炼，AI 辅助生成学术亮点摘要； (4) 支持手动补录和对话上下文两种数据输入方式。 触发词：日报、周报、月报、工作报告、学术报告、工作汇报、生成日报、 生成周报、生成月报、代表报告、拜访报告、合规报告、学术推广报告。

## Introduction

本技能在医药市场与策略管理领域提供一个专为医药代表设计的合规工作报告生成工具。

医药代表工作报告生成器旨在简化和自动化对目标领域进行系统化分析，完成从数据采集到策略建议输出的全链路任务，为医药企业市场部、战略规划部、医学事务部及市场准入团队提供全面的工具支持。

核心能力：

- 确定报告类型与周期
- 收集学术活动数据
- 执行合规审查
- 生成报告文档
- 交付报告

应用场景：

- 用户需要生成本日/本周/本月的学术推广工作报告
- 用户提到"日报"、"周报"、"月报"、"工作报告"、"学术报告"、"工作汇报"
- 用户需要向上级提交合规工作报告
- 用户说"帮我生成一份今天的报告"或类似表述
