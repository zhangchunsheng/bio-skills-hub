# 药学科普作品审核 Skill（Pharma SciReview）

## 简介

以三甲眼科医院临床药师 + 药学科普专家库成员视角，对药学科普作品进行结构化、标准化、可复用的发布前审核。支持图文、短视频、长视频、直播脚本、漫画/图解等多种形式。

## 安装方式

### 方式一：复制到 CodeBuddy Skills 目录

```bash
cp -r pharma-scireview-skill /root/.codebuddy/skills/pharma-scireview
```

安装后在 CodeBuddy 对话中提到"药学科普审核""科普评审"等关键词时自动激活。

### 方式二：直接作为提示词使用

将 `SKILL.md` 全文复制到任意 AI 助手对话框，然后粘贴待审作品即可。

## 使用方法

1. 在对话中输入"帮我审核这篇药学科普作品"
2. 粘贴作品全文/脚本/链接
3. AI 按标准格式输出结构化审核报告

## 文件结构

```
pharma-scireview-skill/
├── SKILL.md       # Skill 定义（含完整审核框架）
└── README.md      # 本说明文件
```

## 评审框架

- 六维度评分（科学性40% + 通俗性20% + 思想性15% + 实用性10% + 新颖性10% + 合规性5%）
- 10条一票否决红线
- 分形式附加审查（图文/短视频/长视频/直播/漫画）
- 眼科专项扩展（7项）
- 标准化输出报告格式
