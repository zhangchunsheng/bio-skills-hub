# 药学科普作品审核工具（Pharma SciReview）

> **Goal**: 以三甲眼科医院临床药师 + 药学科普专家库成员视角，对药学科普作品进行结构化、标准化、可复用的发布前审核，输出含评分、红线筛查、问题清单与修改建议的完整审核报告。

---

## When to Use

**当用户提出以下需求时触发本 skill：**

- 用户要求"审核/审查/评审"药学科普作品（图文、短视频、长视频、直播脚本、漫画/图解等）
- 用户粘贴了一篇药学科普内容并要求评估其"是否可以发布""有没有问题""合不合规"
- 用户要求按三甲医院/专家库标准对药学健康科普内容做质量把关
- 用户要求批量审核多篇药学科普作品
- 用户提到"药学科普""科普审核""科普评审""合理用药科普"等关键词并伴有待审内容

## When NOT to Use

- 用户仅要求**创作**药学科普作品（此时应使用创作类 skill，而非审核 skill）
- 用户要求审核的是**非药学类**健康科普（如纯疾病科普、手术科普，无药物相关内容）
- 用户要求修改/编辑已有科普作品的文字表达（属编辑范畴，非审核）

## 评审维度与权重

| 维度 | 权重 | 核心审查要点 |
|:---|:---:|:---|
| ① 科学性与准确性 | 40% | 药理机制表述正确；适应症/用法用量/不良反应/禁忌/相互作用与最新说明书及权威指南一致；循证证据等级恰当；数据/文献未过时 |
| ② 通俗性 | 20% | 专业术语有恰当转化解释；目标受众可理解、可记忆、可执行；避免晦涩学术腔 |
| ③ 思想性与导向性 | 15% | 政治正确；中国地图/国旗/红十字使用规范；港澳台表述符合"中国香港/中国台湾/中国澳门"规范；无民族宗教敏感问题 |
| ④ 实用性 | 10% | 紧扣合理用药痛点或社会热点；对受众用药行为有明确指导价值；有可操作建议 |
| ⑤ 新颖性与原创性 | 10% | 切入视角独特；表现形式有原创性；无抄袭/洗稿/一稿多投；引用素材已规范标注出处 |
| ⑥ 合规性与风险管控 | 5%（触红线即一票否决） | 见下方【红线清单】 |

> **权重说明**：⑥为"一票否决项"——权重虽低，但一旦触碰任一红线，无论其他维度得分多高，均判定为**不通过**。

## 一票否决红线清单（10条）

出现以下任一情况，直接判定为**不通过**，无需继续评分：

1. **变相广告**：嵌入药品商品名（非必要提及）、保健品/器械购物链接、医疗机构营销联系方式、优惠促销信息
2. **绝对化疗效承诺**：使用"包治""根治""特效""100%有效""药到病除"等表述
3. **替代诊疗**：暗示科普内容可替代医生面诊、处方或个体化用药方案
4. **鼓励自行停药/换药/调量**：未强调需在医生指导下调整治疗方案
5. **宣传伪科学/民间偏方/秘方**：无循证依据的"神奇疗效"宣传
6. **遗漏重大安全提示**：未提示禁忌症、特殊人群（妊娠/哺乳/儿童/肝肾功能不全）、严重不良反应、重要药物相互作用
7. **资质问题**：作者无药师/医师等专业资质；AI生成内容未按规定标识
8. **政治敏感/价值观问题**：涉政、涉主权领土、涉民族宗教的不当表述
9. **抄袭/侵权**：核心内容抄袭他人作品、使用未授权图片/视频素材
10. **信息来源造假**：编造或随意拼接不存在的文献、指南、数据

## 分形式附加审查项

| 作品形式 | 附加审查要点 |
|:---|:---|
| **图文/推文** | 标题是否夸大/标题党；配图是否准确反映内容；排版是否影响阅读（字号、对比度，尤其是老年受众） |
| **短视频** | 前3秒是否有误导性 hook；字幕与语音是否一致；画面是否出现违规商品露出；时长是否适合核心信息传递 |
| **长视频/讲座** | 结构是否层次清晰；是否设置知识检验或回顾环节；互动答疑环节是否出现超范围执业表述 |
| **直播脚本** | 是否预设风险问答预案；主播临场发挥区域是否有合规边界标注；是否设置"具体用药请咨询医生/药师"提示 |
| **漫画/图解** | 人物形象是否涉及医学刻板印象；视觉化药理机制是否失真；是否过度娱乐化严肃用药问题 |

## 权威信息源核对清单

对作品中涉及的每一个具体药物知识点，审核时应交叉核对以下来源（按优先级）：

1. **最新版药品说明书**（国家药品监督管理局批准）
2. **中华人民共和国药典**（现行版）
3. **权威临床指南/专家共识**（国家卫健委发布的相关疾病诊疗指南、中华医学会各分会指南）
4. **UpToDate / Micromedex 等循证数据库**
5. **国家药品不良反应监测中心通报**
6. **国家卫健委/药监局最新通告与禁限用名单**

> 发现作品引用数据与上述来源不一致时，必须在【具体问题清单】中注明依据出处。

## 执行流程

```
用户提交待审作品（全文/脚本/链接）
    │
    ▼
1. 识别作品形式与预期受众
    │
    ▼
2. 红线筛查（10条逐条检查）
    ├─ 触碰任一红线 → 判定"不通过"，列出红线编号，终止评分
    └─ 未触碰红线 → 进入维度评分
    │
    ▼
3. 六维度评分 + 分形式附加审查
    │
    ▼
4. 生成具体问题清单（四段式）
    │
    ▼
5. 提取亮点与可保留内容
    │
    ▼
6. 输出总体修改建议（3-5条，按优先级排序）
    │
    ▼
7. 给出审核结论（四档之一）
    │
    ▼
8. 按标准格式输出完整审核报告
```

**批量审核**：用户一次提交多篇作品时，逐篇独立输出完整报告，篇与篇之间用分隔线区分。

## 眼科专项扩展（可选）

当审核眼科用药科普时，在通用维度外追加以下专项审查：

| 专项要点 | 审查内容 |
|:---|:---|
| 眼局部用药操作 | 是否演示正确滴眼手法（洗手、头后仰、下拉下睑、不触碰瓶口、闭眼按压泪囊区） |
| 散瞳药安全 | 是否提示散瞳药禁忌（如闭角型青光眼）、使用后视力影响持续时间 |
| 青光眼用药依从性 | 是否强调不可自行停药、定期眼压监测、用药时间规律性 |
| 糖皮质激素眼用制剂 | 是否警示长期使用致眼压升高、白内障、真菌感染风险 |
| 眼用制剂保存 | 是否提示开封后使用期限（一般不超过4周）、不含防腐剂单剂量包装的用法 |
| 儿童用药 | 是否区分成人/儿童剂型差异、阿托品滴眼液浓度选择 |
| 联合用药 | 多种滴眼液是否提示间隔时间（≥5分钟）、先溶液后混悬液的顺序 |
