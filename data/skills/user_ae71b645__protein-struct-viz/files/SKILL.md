# 蛋白质结构可视化

生成 PyMOL 命令脚本，用于在分子结构中高亮特定残基。

## 概述

本技能创建 PyMOL 命令脚本，通过多种表示样式（棒状、球状、表面等）可视化蛋白质结构，并高亮指定的残基。

## 用法

本技能生成可直接在 PyMOL 中执行的 `.pml` 脚本文件，用于：
- 加载 PDB 结构
- 应用自定义配色方案
- 用不同的表示样式高亮特定残基
- 创建可发表质量的可视化设置

### 输入参数

| 参数 | 类型 | 说明 |
|-----------|------|-------------|
| `pdb_file` | string | PDB 文件路径或 PDB ID（例如 "1abc"） |
| `residues` | list | 残基规格列表（chain:resnum:resname） |
| `style` | string | 可视化样式："sticks"（棒状）、"spheres"（球状）、"surface"（表面）、"cartoon"（卡通） |
| `color_scheme` | string | 配色方案："rainbow"（彩虹）、"chain"（按链）、"element"（按元素）、自定义十六进制颜色 |
| `output_name` | string | 生成脚本的输出文件名 |

### 残基规格格式

- 格式：`chain:resnum:resname` 或 `resnum`（单链情况下）
- 示例：`A:145:ASP`、`B:23:LYS`、`156`
- 通配符：`A:*`（链 A 中的所有残基）

## 示例

```bash
python scripts/main.py --pdb 1mbn --residues "A:64:HIS,A:93:VAL,A:97:LEU" --style sticks --color_scheme rainbow --output myoglobin_active_site.pml
```

这将生成一个 PyMOL 脚本，高亮肌红蛋白（myoglobin）活性位点中的指定残基。

## 输出

生成的 `.pml` 脚本包含：
1. 结构加载命令
2. 背景与光照设置
3. 全局表示样式设置
4. 特定残基高亮
5. 视角优化命令
6. 可选：用于高质量图像的光线追踪（ray tracing）
