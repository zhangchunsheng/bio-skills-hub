# 直播排品策略｜郭亿易

把商品池、利润、库存和历史表现转换为排品顺序、角色分工和替换规则。

## 工作流程

1. 读取直播证据：围绕“区分引流款、利润款、形象款和承接款”处理，不扩大到无关任务。
2. 定位关键节点：以用户提供的商品池、利润、库存和历史表现为事实边界。
3. 形成运营判断：形成排品顺序、角色分工和替换规则中的对应部分。
4. 输出下一场动作：使用“同时考虑库存、履约与合规风险”作为最终门槛。

## 输入最低要求

- 接收：商品池、利润、库存和历史表现。
- 明确目标平台、时间范围、数量或格式；缺失时列出假设，不静默补造事实。
- 对个人信息、订单信息、商业数据和未公开资料执行最小披露。

## 输出合同

- 首段先给可执行结论，再给排品顺序、角色分工和替换规则。
- 每个判断附输入证据、来源位置或“待确认”标记。
- 同时列出阻断项、风险项和下一步负责人；不把建议伪装成已完成动作。

## 质量门槛

- 区分引流款、利润款、形象款和承接款。
- 同时考虑库存、履约与合规风险。
- 不复制第三方 Skill 的文字、代码或品牌；只解决本 Skill 声明的中文垂直任务。
