# 数据字段说明与维护指南

本技能的全部展馆信息由 `references/` 下的四个 CSV 维护，查询逻辑由
`scripts/museum_guide.py`（纯标准库）提供。**当前数据为基于公开资料整理的示意版本，
展厅数量、标本清单与空间拓扑为近似设计，正式使用前请结合实地核实并替换。**

---

## halls.csv —— 展厅明细

| 字段 | 说明 |
|------|------|
| `id` | 唯一标识（如 `hall_a`），用作路线与标本关联的外键 |
| `name` | 展厅中文名称（含编号如"B 厅 · 植物标本"） |
| `floor` | 所在楼层（1F / 2F / 3F / 4F） |
| `theme` | 展厅主题（如"古生物化石与地质演化"） |
| `specimen_count` | 该厅展出的标本/展品数量（近似值） |
| `description` | 展厅简介，描述主题、特色展品、亮点 |
| `svg_x`, `svg_y` | SVG 示意图中的示意坐标（仅视觉排布，非真实经纬度） |

**新增展厅**：在末尾追加一行，保证 `id` 唯一。需同步在 `routes.csv` 中添加至少一条连通边。

---

## specimens.csv —— 标本清单

| 字段 | 说明 |
|------|------|
| `id` | 唯一标识（如 `a01`），建议以展厅字母开头便于识别 |
| `name` | 标本中文名称（用于展示与模糊匹配） |
| `scientific_name` | 学名（拉丁名），可空 |
| `category` | 标本分类：古生物化石 / 裸子植物 / 被子植物 / 菌类 / 藻类 / 昆虫 / 哺乳动物 / 鸟类 / 爬行动物 / 两栖动物 / 鱼类 / 软体动物 / 腔肠动物 / 节肢动物 / 人体科学 / 生态场景 |
| `hall_id` | 所在展厅 id（须存在于 `halls.csv`） |
| `description` | 标本简介（特征、看点、科普信息），正文使用中文逗号分隔 |
| `conservation_status` | 保护级别：国家一级 / 国家二级 / CITES 附录 I / CITES 附录 II / —— |
| `highlight` | 是否为明星标本/镇馆之宝：`1`=是，`0`=否 |
| `svg_offset_x` | 在展厅 SVG 中的水平示意偏移（用于展厅内布局，可空） |

**新增标本**：在末尾追加一行，保证 `id` 唯一、`hall_id` 有效。

---

## nodes.csv —— 辅助节点（楼梯/电梯/入口/过厅）

路线引擎把本表节点和 `halls.csv` 的展厅合并为完整的图顶点。

| 字段 | 说明 |
|------|------|
| `id` | 唯一标识 |
| `name` | 节点中文名 |
| `type` | 类型：entrance / node / stairs / elevator |
| `floor` | 所在楼层 |
| `svg_x`, `svg_y` | SVG 示意坐标 |

**新增节点**：追加一行，同时在 `routes.csv` 补边以保持连通。

---

## routes.csv —— 通行连接（混合加权）

描述展馆内两个相邻节点（展厅或楼梯/电梯/过厅）之间的通行连接，
引擎据此用 Dijkstra 算法（按混合加权，stairs 加楼层爬升代价）自动拼接任意两点间最短路线。

| 字段 | 说明 |
|------|------|
| `from_id` | 起点节点 id（须存在于 `halls.csv` 或 `nodes.csv`） |
| `to_id` | 终点节点 id（同上） |
| `meters` | 估算步行距离（米），用于最短路径。楼梯按水平投影 + 楼层爬升代价加权 |
| `steps` | 该段的分步指引文字（自然语言，供直接转述给用户） |
| `route_type` | 类型：`same_floor`（同层步行）/ `stairs`（楼梯跨层）/ `elevator`（电梯跨层） |

**新增通行连接**：在末尾追加一行。建议每条边双向添加（或在代码中使用无向图处理）。
保持整张图连通，避免出现孤立节点。

**混合加权规则**（脚本内实现）：
- `same_floor` 与 `elevator`：权重 = `meters`
- `stairs`：权重 = `meters` + 额外爬升惩罚（每层 +30），使引擎在长距离同层绕行与爬楼之间合理平衡

---

## 注意事项

- 涉及展馆示意图时，遵守中国地图与地理信息合规要求：本技能仅使用**示意性坐标**排布
  SVG，不绘制真实地界/行政区划，不代表真实地理坐标。
- 开放时间、预约方式等信息以学校最新通知为准；修改 `halls.csv` 或 `nodes.csv` 坐标后
  立即生效，无需改动 `museum_guide.py`。
- 标本名称与分类信息参考公开科普资料，如有学术争议以校内标注为准。
