# 淮南师范学院 · 生物标本馆 参观导览

## Overview

为淮南师范学院（泉山校区，安徽省淮南市田家庵区洞山西路）的师生、访客和研学团体，提供以
**生物标本馆** 为核心的参观导览服务。生物标本馆为四层独立建筑，馆藏涵盖古生物化石、植物、
昆虫、哺乳动物、鸟类、爬行两栖、水生生物、人体科学及生态场景等九大主题展厅，
陈列标本逾千件，是集教学、科研、科普于一体的综合性标本馆。

覆盖五类核心需求：

1. **浏览**：列出全部展厅（按楼层）、各展厅主题与标本概况；查看镇馆之宝/明星标本。
2. **查找**：按标本名称 / 别名 / 类别 / 展厅 / 楼层模糊查找，返回所在展厅与位置。
3. **路线**：馆内任意展厅之间的步行指引（同层直连、跨层经楼梯/电梯）。
4. **推荐路线**：按时长推荐参观路线（30 分钟速览 / 1 小时精选 / 2 小时深度）。
5. **示意图**：生成示意性展馆楼层分布图（SVG，以楼层为纵轴、展厅为节点）。

知识库由 `references/` 下的 CSV 维护，查询与路线逻辑由 `scripts/museum_guide.py` 提供
（纯标准库，无第三方依赖）。当前数据为基于公开资料整理的**示意版本**，展厅数量、标本
清单与空间拓扑为近似设计，正式使用前请结合实地核实并替换（见 `references/data_schema.md`）。

## When to use

- 用户问标本馆概况（"标本馆有什么""有哪些展区""一共几层"）。
- 用户找某个标本（"蝴蝶标本在哪""有没有恐龙化石""淮南虫化石在哪个展厅"）。
- 用户要路线（"从一楼大厅怎么去鸟类展厅""哺乳动物展厅在几楼怎么走"）。
- 用户想规划参观（"有什么推荐路线""一小时怎么逛""带孩子看什么"）。
- 用户问开放信息（"标本馆几点开门""要不要预约""怎么预约参观"）。
- 用户要一张展馆示意图。

## Workflow

### 1. 确定意图并调用引擎

始终通过 `scripts/museum_guide.py` 获取确定性结果，不要凭记忆编造展厅、标本或路线。
脚本位于技能目录，用 Python 3 运行（标准库即可）：

```
python3 <skill_dir>/scripts/museum_guide.py <子命令> [参数]
```

子命令：

- **halls** — 列出全部展厅（按楼层分组）
  `museum_guide.py halls`
- **floor** — 查看某一层的展厅
  `museum_guide.py floor 1` ｜ `museum_guide.py floor 2`
- **specimens** — 列出标本（可按展厅/类别/楼层筛选）
  `museum_guide.py specimens` ｜ `museum_guide.py specimens --hall hall_b` ｜ `museum_guide.py specimens --category 鸟类`
- **find** — 模糊查找标本
  `museum_guide.py find 蝴蝶` ｜ `museum_guide.py find 朱鹮` ｜ `museum_guide.py find 淮南虫`
- **highlights** — 列出镇馆之宝/明星标本
  `museum_guide.py highlights`
- **route** — 馆内展厅间路线
  `museum_guide.py route --from hall_a --to hall_e` ｜ `museum_guide.py route --from 昆虫 --to 鸟类`
- **tour** — 按时长推荐参观路线
  `museum_guide.py tour 30m` ｜ `museum_guide.py tour 1h` ｜ `museum_guide.py tour 2h`
- **info** — 查询场馆开放/预约信息
  `museum_guide.py info`
- **mapdata** — 导出节点与连线坐标（供生成 SVG 示意图）
  `museum_guide.py mapdata`
- **categories** — 列出全部标本类别
  `museum_guide.py categories`

技能目录可通过 `SKILL.md` 同级定位；若不确定展厅 id 或名称，先用 `halls` 确认。

### 2. 解读并自然回复

- `halls` 输出按楼层分组，已有展厅名、主题、标本数量、简介；整理为中文自然语言，保留展厅编号（如 A 厅）便于指路。
- `floor` 列出该层所有展厅，若层号不存在会提示有效楼层。
- `specimens` 输出含标本名、学名、所在展厅与楼层、简介、保护级别、是否为明星标本。
- `find` 按名称/别名/关键词模糊匹配，返回得分最高的标本及完整信息；得分 < 40 时列出候选建议。
- `highlights` 列出所有 `highlight=1` 的明星标本，适合作为"必看清单"。
- `route` 按最短路径（混合加权：同层按步行、跨层含楼梯/电梯）输出分步指引与估算耗时。
- `tour` 按预设模板输出推荐路线（展厅顺序 + 关键标本），含总耗时与路线说明。
- `info` 输出开放时间、预约方式、注意事项、联系方式。
- `mapdata` 导出 JSON（节点 = 展厅，边 = 通行连接），供生成 SVG 示意图。

### 3. 生成示意性展馆楼层分布图（可选）

当用户想要"地图/示意图/布局图"时，可生成一张 SVG 分布图：

1. 调用 `read_me` 加载 `diagram` 模块，获取当前主题（浅色/深色）的 CSS 变量与设计规范。
2. 运行 `museum_guide.py mapdata` 获取节点坐标（`svg_x` 为展厅在楼层内的水平位置、`svg_y` 对应楼层纵轴）与连线（`edges`）。
3. 生成 SVG（viewBox 起始 `0 0 680`，高度约 700）。画布自上而下：
   标题区 → 各楼层横向分隔区域（标注"4F / 3F / 2F / 1F"）→ 展厅节点（圆角矩形 + 展厅名称）→ 连线（同层实线、跨层虚线标注"楼梯/电梯"）→ 图例。
4. 明星标本展厅用醒目边框/标记（如 ⭐），1F 入口标注"入口"。
5. 在 SVG 下方补充 2-4 行文字：必看明星标本速览与参观贴士。

**合规与可读**：坐标为"示意性布局，不代表真实地理坐标"，仅用于视觉排布，不绘制真实地界/行政区划；所有文字须保证在浅色/深色主题下均清晰可读。

## 数据维护与定制

- 当前 CSV 为基于公开资料整理的**示意版本**（展厅结构与标本说明合理，但具体标本清单、坐标与距离为近似）。正式使用前，请按 `references/data_schema.md` 的字段说明，结合实地核实 `halls.csv` / `specimens.csv` / `routes.csv`。
- 新增标本：在 `specimens.csv` 追加一行（`id` 须唯一，`hall_id` 须存在于 `halls.csv`）。
- 新增展厅：在 `halls.csv` 追加一行，同步在 `routes.csv` 添加至少一条与该展厅的连通边以保持连通。
- 修改数据后立即生效，无需改动 `museum_guide.py`。

## Resources

- `scripts/museum_guide.py` — 查询、路线（Dijkstra 混合加权）与导览引擎（stdlib only）。
- `references/halls.csv` — 展厅明细（id、名称、楼层、主题、标本数量、简介）。
- `references/specimens.csv` — 标本清单（id、名称、学名、类别、所在展厅、简介、保护级别、明星标记）。
- `references/routes.csv` — 展厅间通行连接（含同层步行与跨层楼梯/电梯，含米数与步数/层数）。
- `references/data_schema.md` — 字段说明与维护指南。

## 注意事项

- 涉及展馆示意图时，遵守中国地图与地理信息合规要求：本技能仅使用**示意性坐标**排布 SVG，不绘制真实地界/行政区划，不代表真实地理坐标。
- 标本馆的开放时间、预约方式等以学校最新通知为准；用户反馈信息有误时，优先更新对应 CSV。
- 标本名称与分类信息参考公开科普资料，如有学术争议以校内标注为准。
