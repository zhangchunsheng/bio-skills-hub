# IMA 笔记推送指南

## 笔记命名规则

标题格式：**年份 + 协会/机构 + 指南中文名 + 指南解读**

示例：
- `2024_WHO_中心静脉导管相关感染预防指南解读`
- `2026_NCCN_静脉血栓栓塞症诊疗指南解读`
- `2024_ESVS_下肢动脉疾病诊疗指南解读`
- `2023_中华医学会_深静脉血栓形成诊断和治疗指南解读`

## 标签管理

每篇指南解读笔记至少包含以下标签：
- `指南解读` — 固定标签
- `[指南主题]` — 如"导管相关感染"、"VTE"、"下肢动脉疾病"
- `[发布机构]` — 如"WHO"、"NCCN"、"ESVS"

## 推送流程

1. 将报告写入 `/sandbox/workspace/outputs/指南解读_[机构]_[年份]_[关键词].md`
2. 使用 `ima_cos_util -f <file_path>` 上传至COS
3. 调用 IMA OpenAPI 创建笔记（POST /api/note/create）
4. 验证推送成功（检查返回的 note_id）

## 推送后确认

推送完成后向用户确认：
- 笔记标题
- 笔记ID（如有）
- 是否成功
