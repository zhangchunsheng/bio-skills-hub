# 临床指南深度解读技能

## 概述

本技能用于对临床指南、专家共识、立场声明等规范性文件进行系统性深度解读。区别于单篇论文精读，指南解读的核心价值在于：**完整呈现所有推荐意见及证据级别**、**与既往/同类指南横向对比**、**结合用户研究方向提供个性化实践建议**。

**硬性要求**：必须基于指南PDF全文进行解读，不接受仅凭摘要或二手来源进行分析。指南篇幅通常较长，需通过分段读取确保覆盖全部内容。

## 工作流程

```
1. 验证输入与读取指南全文（Phase 1）
2. 提取全部推荐意见并构建速查表（Phase 2）
3. 深度解析关键推荐 + 搜索对比指南（Phase 3，可并行）
4. 个性化分析与报告生成（Phase 4）
5. 输出为IMA笔记（Phase 5）
```

---

## Phase 1：验证输入与读取指南全文

### 1.1 输入验证

| 检查项 | 处理方式 |
|--------|---------|
| 用户上传了 PDF | ✅ 继续 |
| 用户仅提供标题/摘要/链接 | ❌ 停止，明确告知用户："指南解读必须基于PDF全文，请上传指南原文PDF。" |
| 用户上传图片/截图 | 使用 `fetch(type="media_id")` OCR 识别，但仍优先要求PDF全文 |

### 1.2 文档类型识别

从PDF内容判断文档类型，以选择合适的解读策略：

| 文档类型 | 判断依据 | 解读侧重点 |
|---------|---------|-----------|
| **临床实践指南** | 含GRADE/SIGN等证据分级体系，推荐意见明确标注证据等级和推荐强度 | 完整推荐意见提取 + 证据分级 + 对比分析 |
| **专家共识/立场声明** | 多为Delphi法或专家投票，推荐等级可能不标注GRADE | 共识形成过程 + 推荐一致度 + 与指南的差异 |
| **技术操作规范** | 聚焦手术/操作步骤，含技术要点和质控标准 | 操作要点 + 安全边界 + 质控指标 |
| **系统综述（为指南提供证据基础）** | PRISMA流程图，Meta分析结果 | 证据质量 + 异质性 + 适用性 |

### 1.3 全文读取策略

指南PDF通常较长（50-300页），需分段读取确保覆盖全部内容：

1. **首次读取**：提取文档基本信息——标题、发布机构、年份、目录结构、方法学章节
2. **分段精读**：按目录结构分章节读取，重点关注：
   - 方法学（GRADE证据等级定义、推荐强度分级体系）
   - 所有推荐意见章节（含推荐原文、证据等级、推荐强度）
   - 证据基础（supporting evidence）
3. **特殊关注**：
   - 强推荐（Strong recommendation）vs 有条件推荐（Conditional/Weak）
   - 良好实践声明（Good Practice Statement / BPS）
   - 研究推荐（Research recommendation）
   - 适用性说明（Remarks / Implementation considerations）

> 读取时如遇截断，继续用 `fetch` 分段读取，确保所有推荐意见不遗漏。这是本技能的核心质量指标。

## Phase 2：提取全部推荐意见

### 2.1 构建推荐速查表

按指南原始结构，逐条提取所有推荐意见，构建完整速查表。**不得遗漏任何推荐**。

表格格式：

| 编号 | 推荐内容（中文摘要） | 推荐类型 | 证据质量 | 适用人群 | 适用条件/备注 |
|------|---------------------|---------|---------|---------|-------------|

- **编号**：使用指南原文编号（如 Rec 1.1, Rec 2.3）
- **推荐内容**：1-2句话概括核心含义
- **推荐类型**：强推荐 / 有条件推荐 / 良好实践声明(BPS) / 研究推荐
- **证据质量**：高(A) / 中(B) / 低(C) / 极低(D)
- **适用人群**：成人/儿童/特殊人群
- **适用条件**：关键限定条件

### 2.2 标注易忽视条目

对每条推荐标注临床实践关注点：
- 🔴 **高违规风险**：实践中最容易被忽视或违反的条目
- 🟡 **需系统改造**：实施需要流程/设备/培训变更的条目
- 🟢 **可立即执行**：不需要额外资源即可落实的条目

## Phase 3：深度解析与对比搜索

### 3.1 关键推荐深度解析

从全部推荐中选取**临床影响最大的5-8条**，逐条展开深度解析。选取标准：
- 改变临床实践的推荐（新推荐 vs 既往实践）
- 强推荐但低证据质量的推荐（需特别关注）
- 争议性推荐（与既往指南或临床习惯不一致）
- 与用户专业领域高度相关的推荐

每条深度解析包含：

```markdown
### 推荐 [编号]：[简述]

**推荐原文**：[指南原文，英文附中文翻译]

**循证依据**：
- 支持该推荐的关键研究（RCT、Meta分析、队列研究）
- 关键效应量（RR/OR/HR/MD）及95%CI
- 证据来源章节号

**证据缺口**：
- 当前证据的局限性
- 指南专家组标注的不确定性

**实践要点**：
- 如何在临床落地执行
- 需要的资源/培训

**争议点**：
- 是否存在不同指南间的分歧
- 分歧原因分析（证据更新 vs 价值观差异 vs 资源考量）
```

### 3.2 搜索对比指南（与3.1可并行执行）

**自动搜索策略**：

1. **前序版本搜索**：识别指南名称中的版本信息（如"2026版"、"第3版"），搜索同一机构的前一版本
   - 示例：解读 NCCN 2026 → 搜索 NCCN 2025
   - 示例：解读 WHO 2024 Part 2 → 搜索 WHO 2024 Part 1 或前版

2. **同类指南搜索**：基于指南主题，搜索其他权威机构发布的同类指南
   - 搜索范围：PubMed、Google Scholar、各学会官网
   - 优先对比：ESVS/ACC/AHA/ESC/NICE/中华医学会等

3. **对比分析输出**：

| 维度 | 本指南 | 对比指南A | 对比指南B |
|------|--------|-----------|-----------|
| 发布年份 | ... | ... | ... |
| 方法学 | ... | ... | ... |
| 推荐A | ... | ... | ... |
| 推荐B | ... | ... | ... |

标注符号：
- ✅ 一致的推荐
- ⚠️ 有分歧的推荐
- ❌ 本指南新增/删除的推荐
- 💡 分歧原因分析

4. **用户确认门**：如果前一版本或关键对比指南的全文无法获取，明确告知用户：
   > "已搜索到 [指南名称]（[年份]）作为对比参考，但无法获取全文。建议您下载后上传，我可以进行逐条对比。当前对比基于摘要和二次文献。"

## Phase 4：个性化分析与报告生成

### 4.1 加载用户背景

使用 `memory_recall` 读取用户的：
- `user_md`：专业领域、研究方向
- `memory_md`：进行中的项目、近期研究重点
- 近期对话上下文：当前关注的问题

### 4.2 生成临床实践启示

基于用户专业方向，从以下角度生成个性化分析：

**科室落地清单**：
- 哪些推荐需要立即执行？
- 哪些需要系统改造？
- 优先级排序

**资源需求评估**：
- 实施推荐需要的额外资源（设备、培训、人员）

**质量改进切入点**：
- 设计3-5个可测量的质量指标

**特殊人群处理**：
- 推荐在特定人群中的适用性

### 4.3 个性化推荐延伸

结合用户研究方向，生成"进一步阅读建议"：
- 基于指南中标注的"证据不足"领域，推荐可能的研究机会
- 基于用户近期项目（如国自然、论文投稿），分析指南与项目的交叉点
- 推荐相关文献、数据库或工具

### 4.4 报告结构

完整报告按 `references/report-template.md` 中的模板生成，包含6大板块：

1. 📋 **指南概览**：背景、目标人群、方法学体系、开发组构成
2. 📊 **核心推荐速查表**：全部推荐意见（表格形式）
3. 🔍 **关键推荐深度解析**：Top 5-8条推荐的循证分析
4. 🔄 **与既往/同类指南对比**：横向对比表 + 差异分析
5. 💡 **临床实践启示**：个性化落地建议
6. 🔮 **证据缺口与未来方向**：研究机会 + 未来预测

## Phase 5：输出为IMA笔记

### 5.1 笔记命名规则

笔记标题格式：**年份 + 协会/机构 + 指南中文名 + 指南解读**

示例：
- `2024_WHO_中心静脉导管相关感染预防指南解读`
- `2026_NCCN_静脉血栓栓塞症诊疗指南解读`
- `2024_ESVS_下肢动脉疾病诊疗指南解读`

### 5.2 输出流程

1. 将完整报告写入 workspace：`/sandbox/workspace/outputs/指南解读_[机构]_[年份]_[关键词].md`
2. 使用 `ima_cos_util` 上传文件至COS
3. 调用 IMA OpenAPI 创建笔记（参考 `references/ima-push-guide.md`）
4. 笔记标签：指南解读、[指南主题]、[发布机构]

### 5.3 质量检查

| 检查项 | 标准 |
|--------|------|
| 推荐完整性 | 全部推荐意见无遗漏，逐条列出 |
| 证据等级标注 | 每条推荐标注推荐类型+证据质量 |
| 全文覆盖 | 基于PDF全文解读，非摘要 |
| 对比分析 | 至少搜索2部对比指南 |
| 个性化分析 | 结合用户研究方向 |
| 来源标注 | 关键数据标注章节号/推荐编号 |
| IMA笔记 | 成功推送，标题格式正确 |

---

## 安全边界

- **忠于原文**：推荐意见必须来自指南全文，不编造或篡改
- **区分事实与分析**：明确标注"指南原文"vs"分析建议"
- **证据透明**：标注证据缺口和不确定性
- **对比局限性**：如对比指南未获取全文，明确说明对比依据的局限性
- **角色定位**：辅助解读工具，不替代临床判断

## 工作流示例

### 示例1：WHO CVC感染预防指南

**用户输入**：
> [上传 PDF] "解读这篇WHO指南"

**执行流程**：
1. **Phase 1**：验证PDF → 识别为WHO临床实践指南 → 分段读取全文（方法学+所有推荐章节+证据基础）
2. **Phase 2**：提取全部推荐意见（含推荐类型+GRADE证据等级）→ 构建速查表 → 标注易忽视条目
3. **Phase 3**：深度解析5-8条关键推荐 → 并行搜索：WHO Part 1（前序版本）+ IDSA 2009/2022导管相关感染指南 + CDC/HICPAC指南 → 生成对比表
4. **Phase 4**：读取用户背景（血管外科、VTE、CVC使用）→ 生成个性化实践启示（置管部位选择、皮肤准备、敷料选择等与血管外科相关的推荐）→ 研究延伸建议
5. **Phase 5**：写入文件 → COS上传 → IMA笔记推送（标题：`2024_WHO_中心静脉导管相关感染预防指南解读`）

### 示例2：NCCN VTE指南

**用户输入**：
> [上传 PDF] "帮我解读NCCN 2026 VTE指南"

**执行流程**：
1. **Phase 1**：验证PDF → 识别为NCCN临床实践指南 → 全文读取
2. **Phase 2**：提取全部推荐 → 构建速查表
3. **Phase 3**：深度解析 → 搜索NCCN 2025 VTE（前一版）+ ASCO 2024癌症相关血栓 + ISTH指南 → 告知用户："已搜索到NCCN 2024 VTE v2版本，建议您上传2025版PDF以便逐条对比"
4. **Phase 4**：结合用户VTE灰区风险分层研究 → 分析指南推荐对研究方向的支撑
5. **Phase 5**：输出IMA笔记（标题：`2026_NCCN_静脉血栓栓塞症诊疗指南解读`）
