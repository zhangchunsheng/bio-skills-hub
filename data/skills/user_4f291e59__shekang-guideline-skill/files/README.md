# 📖 临床指南深度解读技能（guideline-deep-reading）

## 技能简介

临床指南深度解读技能是专为医学从业者设计的AI辅助工具，能够对临床实践指南、专家共识和立场声明进行系统性深度解读。上传指南PDF全文后，技能自动完成五阶段解析流程：验证输入与全文分段读取、提取全部推荐意见并构建速查表、深度解析关键推荐意见、多源搜索并横向对比既往版本与同类指南、结合用户研究方向生成个性化分析报告。最终输出涵盖指南概览、核心推荐速查表、关键推荐深度解析、指南间横向对比、临床实践启示、证据缺口与未来方向共六大板块的结构化报告，并自动推送至IMA笔记，方便随时查阅。

本技能的核心优势在于三个方面。一是完整性，基于PDF全文分段精读，逐条提取所有推荐意见及证据级别，确保不遗漏任何关键推荐。二是对比性，自动搜索同一机构的前序版本以及ESVS、ACC/AHA、ESC、NICE、中华医学会等权威机构的同类指南，进行逐条横向对比并标注一致、分歧和新增推荐。三是个性化，通过读取用户的专业背景和研究方向，生成针对性的科室落地清单、资源需求评估和研究机会推荐，将指南推荐真正转化为可执行的临床行动。

技能严格遵循循证医学原则，解读中明确区分指南原文与分析建议，关键结论标注来源。适用于各科室临床医生快速掌握新指南要点、科室质量改进参考、研究选题方向挖掘等场景。不适用于单篇研究论文精读（请使用literature-deep-reading技能）。

## 使用方法

### 第一步：触发技能

说出以下任意指令即可触发：

- "解读这篇指南"
- "帮我精读这个指南"
- "指南分析"
- "guide-deep-reading"
- 或直接上传指南PDF文件并说明意图

### 第二步：上传指南PDF

**必须上传指南PDF全文**。技能不支持仅凭标题、摘要或截图进行解读。上传后技能会自动识别文档类型（临床实践指南、专家共识、技术操作规范等）并选择对应的解读策略。

### 第三步：等待自动解读

技能将自动执行以下五阶段流程：

1. **全文读取**：对长PDF进行分段精读，提取目录结构、方法学体系和全部推荐意见
2. **推荐提取**：逐条提取所有推荐意见，构建核心推荐速查表，标注证据级别和推荐强度
3. **深度解析**：选取临床影响最大的5-8条推荐进行循证分析，同时并行搜索前序版本和同类指南进行横向对比
4. **个性化分析**：结合你的专业领域和研究方向，生成科室落地清单、质量改进指标和研究机会推荐
5. **输出笔记**：自动生成结构化报告并推送至IMA笔记

### 第四步：查阅报告

解读完成后，报告自动推送至IMA笔记，标题格式为：`年份_机构_指南中文名_指南解读`。你也可以在对话中直接查看报告内容。

## 报告结构

每份解读报告包含六大板块：

- 📋 **指南概览**：背景、目标人群、方法学体系、开发组构成
- 📊 **核心推荐速查表**：全部推荐意见的表格化速查，含证据级别和推荐强度
- 🔍 **关键推荐深度解析**：Top推荐的循证依据、证据缺口、实践要点和争议点
- 🔄 **指南间横向对比**：与前序版本和同类指南的逐条对比及差异分析
- 💡 **临床实践启示**：科室落地清单、资源评估、质量改进指标（个性化）
- 🔮 **证据缺口与未来方向**：研究机会推荐、延伸阅读建议（个性化）

---

## 适用场景

- 新指南发布后快速掌握全部推荐要点
- 科室学习讨论会的参考资料准备
- 临床路径更新和质量改进的依据梳理
- 研究选题时挖掘证据缺口和高价值研究方向
- 多版指南更迭间的推荐变化追踪

## 不适用场景

- 单篇研究论文精读 → 请使用 `literature-deep-reading` 技能
- 纯文献检索 → 请使用 `Pubmed论文检索` 技能
- 非指南类文档分析
