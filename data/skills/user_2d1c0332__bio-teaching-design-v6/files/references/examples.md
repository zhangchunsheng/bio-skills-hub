## 示例对话1：高一新授课（光合作用）

**用户**：我要写"光合作用"的教学设计，高一新授课，用人教版，学生迷思概念多，怎么办？

**助手响应流程**：

```
[识别触发]：高中生物教学设计 → 激活技能
[七要素采集]：
  课题：光合作用
  课型：C1 新授课·概念建构
  对象：高一
  教材：人教版
  问题：P1 迷思概念多
  评价：未指定
  AI：未指定

[六轨选型]：
  轨1（P1）→ 论证式教学/DO五步/POE
  轨2（光合作用）→ 5E/POE/模型构建
  轨3（C1）→ 5E/DO五步/概念转变/POE
  轨4（高一）→ 5E权重×1.5
  轨5（生命观念）→ 概念转变/5E
  轨6（人教版）→ 以人教版为基准

[综合排序]：POE（匹配度最高）→ 5E（次高）→ DO五步（第三）
```

**输出示例**：

```markdown
### 教学设计方案：光合作用（第1课时）

**推荐模型**：POE预测-观察-解释模式（匹配度：★★★★★）
**备选模型**：5E教学模式
**实证依据**：POE框架能显著减少"光合作用在光下进行"的迷思概念（后测正确率提升38%）

#### 教学流程（45分钟）

**P（Predict 预测）10分钟**
- 呈现情境：将天竺葵放置暗处24小时后，一半遮光、一半曝光，照光一段时间后滴加碘液
- 学生预测：两部分叶片分别是什么颜色？为什么？
- 记录预测：学生在学习单上写下预测理由

**O（Observe 观察）15分钟**
- 学生动手操作（或观察教师演示）
- 观察现象：遮光部分不变蓝，曝光部分变蓝
- 记录现象：与预测是否一致？

**E（Explain 解释）20分钟**
- 小组讨议：为什么只有曝光部分产生了淀粉？
- 引导学生得出：光合作用需要光，产物有淀粉
- 教师补充：光合作用的完整反应式

**作业设计（认知负荷优化）**
- 基础题：光合作用需要的条件是______（水平1）
- 发展题：分析光照强度对光合速率的影响曲线（水平2）
- 挑战题：设计实验证明光合作用产生的O₂来自水（水平3）

**教材版本适配（人教版）**
- 人教版将"光合作用的探究历程"放在下一课时，本课聚焦于"光合作用的进行条件"
- 若使用苏教版：苏教版在本节含更多实验设计内容，可扩展为2课时
```

## 示例对话2：高三复习课（遗传规律）

**用户**：高三一轮复习"遗传规律"，学生做题错误率高，想快速提分，用什么方法？

**助手响应**：

```markdown
### 教学设计方案：遗传规律复习课

**推荐模型**：模型构建教学（匹配度：★★★★★）
**实证依据**：模型构建组均分比对照班高14分（p<0.01），效果最显著

#### 教学流程（2课时）

**第1课时：模型构建**
1. 呈现问题：孟德尔为什么能发现遗传规律？（引发思考）
2. 构建分离定律模型：
   - 用棋盘法/分支法/配子法分别表征
   - 比较三种方法的适用场景
3. 构建自由组合定律模型：
   - 从分离定律推广到自由组合
   - 用"乘法原理"解释为什么9:3:3:1

**第2课时：模型应用**
1. 用模型解决高考真题（2023年全国甲卷遗传题）
2. 错题归因（SOLO诊断）：
   - 单点结构错误：只记结论，不理解过程
   - 多点结构错误：能分步计算，但不会整合
   - 关联结构达标：能完整推导并解释

**提分训练设计**
- 基础训练：判断基因型（水平1）→ 全体学生
- 提升训练：计算概率（水平2）→ 目标：全员掌握
- 挑战训练：设计杂交实验（水平3）→ 选做

**备注**：本设计对接2025版新课标三级学业质量，水平2题目占比60%，水平3题目占比40%
```

## 示例对话3：高二议题讨论课

**用户**：我要上一节关于"基因编辑"的课，想用议题式教学，怎么设计？

**助手响应**：

```markdown
### 教学设计方案：基因编辑的社会议题讨论

**推荐模型**：SSI社会性科学议题教学 + STSE教育模式（匹配度：★★★★☆）
**课型**：C7 活动课·议题讨论
**教材对接**：选必3《生物技术与工程》第3章

#### 议题设计

**驱动性问题**：基因编辑技术应该被用于"设计婴儿"吗？

**情境呈现（10分钟）**
- 2023年，某科研团队宣布成功用基因编辑技术修正遗传病基因
- 同时，该技术被滥用：有人试图用基因编辑"定制"孩子的眼睛颜色、身高
- 提问：这项技术该鼓励还是禁止？界限在哪里？

**多维分析（20分钟）**
| 维度 | 支持方论点 | 反对方论点 |
|:---|:---|:---|
| 科学 | 可根治遗传病 | 技术不成熟，有脱靶风险 |
| 伦理 | 父母有选择权 | "设计婴儿"加剧社会不平等 |
| 法律 | 需立法规范 | 立法可能阻碍科研 |
| 社会 | 减少遗传病负担 | 基因歧视风险 |

**立场论证（10分钟）**
- 学生选择立场，用科学证据辩护
- 教师引导：科学判断 vs 价值判断的区别

**决策反思（5分钟）**
- 共识：基因编辑用于治疗目的可接受，用于"增强"目的需严格限制
- 联系我国《生物安全法》相关规定

**评价方式**：GRASPS表现性评价
- G：形成关于基因编辑的理性立场
- R：学生扮演"生物伦理委员会委员"
- P：撰写一份"基因编辑技术使用建议书"
```

## 示例对话4：说题课（教研展示）

**用户**：我要参加教学比赛，需要说一道遗传题，说题框架怎么设计？

**助手响应**：

```markdown
### 说题框架：一道高考遗传题的"六步说题"

**推荐模型**：说题六步框架（模型43）

#### 说题流程

**第一步：说命题意图（1分钟）**
- 本题出自2024年全国甲卷第32题
- 考查核心素养：科学思维（演绎推理）+ 科学探究（实验设计）
- 学业质量水平：水平3（评价、创造层级）
- 对接课标：必修2"遗传的细胞学基础"+ "遗传的基本规律"

**第二步：说知识考点（2分钟）**
- 核心概念：基因的自由组合定律、基因型推导、概率计算
- 大概念关联：遗传信息控制生物性状（大概念3）
- 各版本表述对比：
  - 人教版：用"豌豆杂交实验"引入
  - 浙科版：更早引入数学概率

**第三步：说解题思路（2分钟）**
- 正确路径：先判断遗传方式 → 推导亲本基因型 → 计算后代概率
- 学生典型错误路径：
  - 错误1：直接套用"9:3:3:1"，忽略题目条件变化
  - 错误2：概率计算时忽略"至少""最多"等限定词

**第四步：说错误归因（1.5分钟）**
- 认知根源：迷思概念"遗传学题目都是9:3:3:1"
- SOLO层级诊断：多数错误答案处于"多点结构"层级（能分步但不整合）

**第五步：说变式训练（2分钟）**
- 变式1：将常染色体遗传改为伴X遗传（难度↑）
- 变式2：增加"基因突变"条件（综合度↑）
- 变式3：要求设计验证实验（开放度↑）

**第六步：说教学应对（1.5分钟）**
- 基于本题反映的问题：学生"套模式"而非"理解原理"
- 改进策略：用模型构建教学（模型23），让学生理解概率的生物学意义
- 作业设计：分层（基础/发展/挑战）

**说题时间控制**：总时长10分钟（符合比赛要求）
```

## 示例对话5：AI融合课

**用户**：我想用DeepSeek辅助"生态系统"的教学设计，怎么用？

**助手响应**：

```markdown
### AI辅助教学设计：生态系统（选必2）

**推荐模型**：AI辅助教学模块（模型42）
**应用场景**：备课阶段（情境生成+问题设计）

#### AI辅助操作流程

**步骤1：用DeepSeek生成课堂导入情境**
- 提示词：
  "你是一名高中生物学教学专家，请为'生态系统的能量流动'设计一个真实情境导入：
  - 贴近学生生活（食堂剩饭剩菜处理）
  - 含认知冲突（为什么不能直接吃生产者？）
  - 字数：150字以内"
- AI输出 → 教师审核修改 → 用于课堂导入

**步骤2：用DeepSeek生成分层问题序列**
- 提示词：
  "请为'生态系统的能量流动'设计5个递进式问题：
  Q1~Q2：基础理解；Q3：分析应用；Q4：跨概念整合；Q5：开放议题"
- AI输出 → 教师调整难度 → 用于课堂提问

**步骤3：用DeepSeek辅助作业设计**
- 提示词：
  "请为'生态系统的能量流动'设计三级难度作业：
  水平1（基础）：识记能量流动的特点
  水平2（应用）：分析某生态系统能量金字塔
  水平3（探究）：设计一个提高能量利用效率的方案"
- AI输出 → 教师审核 → 用于课后作业

**注意事项**：
1. AI生成内容必须教师审核（科学准确性）
2. AI不替代教师的情境创设和课堂互动
3. 可引导学生使用AI辅助学习（数字素养培育）

**推荐DeepSeek提示词模板**（见references/models-48.md 模型42）
```

## 使用技巧总结

1. **触发词要准确**：说"高中生物教学设计"或"生物教案"即可激活
2. **七要素不必全说**：提供课题名称+课型+对象，助手会自动推荐
3. **要求输出格式**：可以说"输出完整教案"或"只输出模型推荐"
4. **AI辅助**：可以说"用DeepSeek辅助设计"来激活AI辅助教学模块
5. **说题课**：可以说"我要说题"来激活说题六步框架
