## 快速入口

用户说出以下任意触发词即激活本技能：

```
高中生物教学设计 / 生物教案 / 怎么教 / 用什么方法教
ADI教学 / STSE教育 / 认知负荷作业设计 / 混合式教学
差异化教学 / 表现性评价 / GRASPS / AI辅助教学
说题 / 生物安全 / 大概念单元 / 读图说图 / 议题式教学
```

激活后，执行 **七要素采集 → 六轨选型 → 输出方案**。

## 第一步：七要素采集

向用户收集以下信息（可省略已知项）：

| 编号 | 要素 | 说明 |
|:---:|:---|:---|
| ① | 课题名称 | 例："光合作用""基因的表达" |
| ② | 课型 | 见下方课型矩阵（C1~C12） |
| ③ | 上课对象 | 高一/高二/高三 |
| ④ | 教材版本 | 人教版/苏教版/北师大版/浙科版/沪科教版/沪科技版 |
| ⑤ | 教学痛点 | 见下方教学问题（P1~P12） |
| ⑥ | 评价需求 | 作业设计/表现性评价/GRASPS/SOLO/综合 |
| ⑦ | AI工具意向 | 使用DeepSeek辅助 / 不使用 / 仅辅助备课 |

## 第四步：六轨交叉智能选型

```
用户输入
  ├── 轨1：教学问题（P1~P12）→ 模型推荐
  ├── 轨2：课题名称 → 知识库匹配
  ├── 轨3：课型（C1~C12）→ 适应性筛选
  ├── 轨4：学段（高一/高二/高三）→ 策略调整
  ├── 轨5：素养维度 → 路径推荐
  └── 轨6：教材版本 → 内容适配
  ↓
综合排序 + 学段调权 + 素养筛选 + 课型匹配
  ↓
输出：主推方案 + 备选方案 + 实证数据 + 作业建议 + AI融入建议
```

## 第七步：2025版新课标变化

**详细说明见 `references/curriculum-2025.md`**

主要变化：
- 社会责任新增"总体国家安全观"（对接模型44：生物安全教育路径）
- 学业质量重构为三级体系（对接模型47：三级学业质量对标命题）
- 强调真实情境、议题式教学（对接模型45：议题式情境创设）
- 强化生态文明、绿色发展教育
