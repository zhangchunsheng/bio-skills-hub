# ECG Electrode Manufacturing Processes Overview

This document provides an overview of common ECG electrode types, manufacturing processes, material categories, and key technical parameters for patent comparison.

---

## 1. ECG Electrode Types (心电电极类型)

### 1.1 Wet Electrodes (湿电极)

- **Description**: Use conductive gel/hydrogel as the interface between skin and electrode to reduce contact impedance.
- **Common structure**: Substrate + conductive layer (Ag/AgCl) + conductive gel + adhesive ring + connector.
- **Typical applications**: Standard clinical ECG monitoring, Holter monitoring.
- **Manufacturing complexity**: Medium-high (requires gel dispensing and curing).

### 1.2 Dry Electrodes (干电极)

- **Description**: Direct contact with skin without gel. Uses micro-structures, conductive polymers, or metallic contacts.
- **Common structure**: Substrate + conductive contact surface (metal, polymer, or carbon-based) + adhesive/strap.
- **Typical applications**: Wearable ECG devices, sports/fitness monitoring, long-term monitoring.
- **Manufacturing complexity**: Medium (no gel handling, but requires precision surface fabrication).

### 1.3 Solid-State Electrodes (固态电极)

- **Description**: Use solid conductive polymer or conductive rubber as the interface. No liquid gel.
- **Common structure**: Substrate + solid conductive layer (conductive polymer composite) + adhesive.
- **Typical applications**: Long-term wearable monitoring, multi-parameter monitoring.
- **Manufacturing complexity**: Medium (requires polymer blending and molding).

### 1.4 Flexible/Stretchable Electrodes (柔性/可拉伸电极)

- **Description**: Use flexible substrates (polyimide, PDMS, TPU) with embedded conductive materials.
- **Common structure**: Flexible substrate + deposited/printed conductive patterns + skin-compatible adhesive.
- **Typical applications**: Next-generation wearable ECG, e-skin, smart clothing.
- **Manufacturing complexity**: High (requires thin-film deposition, printing, or nanomaterial processing).

### 1.5 Capacitive Electrodes (电容耦合电极)

- **Description**: Non-contact measurement through insulating layer; measures displacement current.
- **Common structure**: Insulated conductive plate + dielectric layer + signal conditioning circuit.
- **Typical applications**: Through-clothing monitoring, non-contact ECG measurement.
- **Manufacturing complexity**: High (requires circuit integration and dielectric engineering).

## 2. Manufacturing Process Categories (制造工艺分类)

### 2.1 Material Preparation (材料制备)

| Process Step | Techniques | Key Parameters |
|---|---|---|
| Ag/AgCl powder preparation | Chemical precipitation, ball milling, spray drying | Particle size (1-10 um), Ag:AgCl ratio (typically 70:30 to 50:50) |
| Conductive polymer compounding | Melt mixing, solution mixing | Filler content (20-60 wt%), dispersion uniformity |
| Hydrogel formulation | Crosslinking reaction, UV/thermal curing | Ionic conductivity, water content, adhesion strength |
| Conductive ink preparation | Dispersion, mixing, viscosity adjustment | Viscosity, solid content, particle dispersion |

### 2.2 Substrate Fabrication (基体制备)

| Process Step | Techniques | Key Parameters |
|---|---|---|
| Film/sheet extrusion | Flat die extrusion, blown film | Thickness (50-500 um), uniformity |
| Injection molding | Precision injection molding | Dimensional accuracy, surface finish |
| Film casting | Solvent casting, spin coating | Thickness uniformity, residual solvent |
| Foam forming | Foam extrusion, foam injection | Density, porosity, compression set |

### 2.3 Conductive Layer Formation (导电层制备)

| Process Step | Techniques | Key Parameters |
|---|---|---|
| Screen printing | Flat bed or rotary screen printing | Print resolution (100-300 um line width), ink transfer |
| Sputtering/deposition | DC sputtering, PVD, CVD | Film thickness (50-500 nm), adhesion strength |
| Conductive ink printing | Inkjet, aerosol jet, dispensing | Pattern resolution, film thickness |
| Foil lamination | Heat lamination, adhesive bonding | Bond strength, surface resistance |
| Electroplating | Ag/AgCl electrochemical deposition | Coating thickness, AgCl conversion ratio |
| Conductive polymer coating | Solution casting, spray coating | Surface resistance, film uniformity |

### 2.4 Gel Application (凝胶涂布)

| Process Step | Techniques | Key Parameters |
|---|---|---|
| Gel dispensing | Precision dispensing, screen printing | Volume accuracy, pattern precision |
| Gel casting | Mold casting, drop-on-demand | Gel thickness, curing uniformity |
| Pre-formed gel lamination | Die-cut gel pad + lamination | Position accuracy, gel-substrate adhesion |
| UV curing | UV exposure | Curing time, crosslink density |
| Thermal curing | Oven heating | Temperature profile, curing time |

### 2.5 Die Cutting and Shaping (模切成型)

| Process Step | Techniques | Key Parameters |
|---|---|---|
| Flatbed die cutting | Steel rule die, rotary die | Cut accuracy (+/-0.1 mm), edge quality |
| Laser cutting | CO2 laser, UV laser | Cut width, thermal damage zone |
| Kiss cutting | Partial-depth cutting | Cut depth control, release liner integrity |

### 2.6 Connector Assembly (连接器组装)

| Process Step | Techniques | Key Parameters |
|---|---|---|
| Snap/button attachment | Ultrasonic welding, heat staking | Pull strength, electrical continuity |
| Soldering/welding | Resistance welding, laser welding | Joint strength, no thermal damage |
| Crimping | Mechanical crimping | Contact resistance, pull strength |

### 2.7 Packaging and Sterilization (包装与灭菌)

| Process Step | Techniques | Key Parameters |
|---|---|---|
| Individual packaging | Blister packaging, pouch sealing | Seal integrity, sterility |
| Sterilization | EO gas, gamma radiation, electron beam | Sterility assurance level (SAL), material compatibility |
| Labeling | Print-and-apply, direct printing | Label accuracy, traceability |

## 5. Process Flow Comparison Reference (工艺流程对比参考)

### 5.1 Typical Wet Electrode Manufacturing Flow

```
Material preparation (Ag/AgCl, gel, substrate)
    → Substrate fabrication (film extrusion or casting)
    → Conductive layer formation (screen printing or lamination)
    → Gel application (dispensing or casting)
    → Gel curing (UV or thermal)
    → Die cutting (electrode shape + adhesive ring)
    → Connector attachment (snap button)
    → Packaging
    → Sterilization (if required)
    → Quality inspection
```

### 5.2 Typical Dry Electrode Manufacturing Flow

```
Material preparation (conductive polymer, substrate)
    → Substrate fabrication (injection molding or film casting)
    → Conductive surface formation (coating, sputtering, or molding)
    → Surface texturing (laser, etching, or molding)
    → Die cutting
    → Adhesive/strap attachment
    → Connector integration
    → Packaging
    → Quality inspection
```

### 5.3 Typical Flexible Electrode Manufacturing Flow

```
Material preparation (nanomaterials, flexible polymer)
    → Flexible substrate preparation (spin coating or casting)
    → Conductive pattern formation (inkjet, screen printing, or deposition)
    → Encapsulation/packaging (thin film lamination)
    → Skin adhesive application
    → Die cutting
    → Connector attachment
    → Final packaging
    → Quality inspection
```

## 6. Notes on Process Comparison

- **Process patents vs. product patents**: Manufacturing process patents protect how the electrode is made. Product patents protect the electrode design itself. Focus on process patents for this analysis.
- **Hybrid processes**: Many modern patents combine elements from multiple process categories (e.g., screen printing + gel dispensing + UV curing). Note these hybrid approaches in the comparison.
- **Scalability**: Evaluate whether a manufacturing process is suitable for mass production or limited to lab-scale fabrication. This affects the commercial relevance of the patent.
- **Cost factors**: Material cost and process complexity directly affect electrode unit cost. Include cost estimates in the comparison where data is available.
- **Environmental impact**: Some processes (e.g., solvent-based coating, chemical waste from electroplating) have environmental implications. Note these for completeness.
