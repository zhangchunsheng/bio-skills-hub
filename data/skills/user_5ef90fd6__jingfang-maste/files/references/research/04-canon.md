## 第一部分：《伤寒论》398条 —— 经方正典之核心

### 1.1 正典定位

| 维度 | 内容 |
|------|------|
| **全称** | 《伤寒杂病论·伤寒论》（张仲景，约公元200-210年） |

《伤寒论》以**六经**为纲组织全部条文。知识库中的「六病知识体系总览」提供了清晰的结构化阐述：

| 六经 | 病位（胡希恕说） | 病位（刘渡舟说） | 病性 | 核心方阵 |
|------|-----------------|------------------|------|---------|
| **太阳病** | 表 | 膀胱/小肠 | 阳证 | 桂枝汤阵、麻黄汤阵 |
| **阳明病** | 里 | 胃/大肠 | 阳证 | 白虎汤阵、承气汤阵 |
| **少阳病** | 半表半里 | 胆/三焦 | 阳证 | 柴胡汤阵 |
| **太阴病** | 里 | 脾/肺 | 阴证 | 四逆汤阵、理中汤阵 |
| **少阴病** | 表 | 心/肾 | 阴证 | 麻黄附子细辛汤、真武汤 |
| **厥阴病** | 半表半里 | 肝/心包 | 阴证 | 乌梅丸、当归四逆汤 |

## 第四部分：经方正典的知识结构模型

基于以上研究，经方Master Skill的正典体系可归纳为**三级金字塔**：

```
                    ┌──────────────┐
                    │  方证对应    │  ← 尖端：精确选方
                    │  (临床操作)  │
                    ├──────────────┤
                    │   六经辨证   │  ← 中层：辨证框架
                    │ (伤寒论398条) │
                    ├──────────────┤
                    │  八纲 + 脏腑  │  ← 底层：基础理论
                    │ + 体质 + 药证 │
                    └──────────────┘
```

这个金字塔覆盖了11位经方家全部辨证体系的交集部分——无论是胡希恕的「八纲→六经→方证」、刘渡舟的「脏腑→六经→方证」还是黄煌的「体质→药证→方证」，其最终操作层都统一在**方证对应**这一核心方法论上。
