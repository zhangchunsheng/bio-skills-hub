## 一、胡希恕（1898—1984）

| 维度 | 内容 |
|------|------|
| **基本信息** | 辽宁省沈阳市人，北京中医学院教授，享年86岁 |
| **师承** | 王祥徵（清末民初经方大家） |
| **代表著作** | 《胡希恕伤寒论讲座》《胡希恕金匮要略讲座》《经方传真》《胡希恕医论医案集》《伤寒论通俗讲话》 |
| **核心贡献** | ①创立**「六经来自八纲」理论**——六经辨证源自阴阳、表里、寒热、虚实八纲；②提出**「方证是辨证的尖端」**；③推动**方证对应**为核心的经方临床体系 |
| **辨证特色** | 方证对应，有是证用是方；以八纲释六经；重视腹诊；排斥五行学说；经方用量遵原方比例 |
| **学派归属** | **胡希恕学派**（现代经方开创性学派） |
| **学术地位** | 被誉为「现代经方第一人」，与刘渡舟并称「北刘南胡」 |

> 📎 来源：`经方家/01_胡希恕/生平学术.md`（一手）

## 二、黄煌（1954—）

| 维度 | 内容 |
|------|------|
| **基本信息** | 江苏江阴人，南京中医药大学教授、博导，江苏省名中医 |
| **师承** | 叶橘泉（中国科学院院士）；受日本汉方医学（吉益东洞、细野史郎、大塚敬节）深刻影响 |
| **代表著作** | 《中医十大类方》《张仲景五十味药证》《经方的魅力》《黄煌经方使用手册》《黄煌经方沙龙》《经方100首》 |
| **核心贡献** | ①创立**「方-病-人」辨证体系**（方人+方病+体质三维对应）；②系统提出**「体质辨证」**（桂枝体质、柴胡体质、半夏体质等）；③提出**「药证」**概念；④推动经方国际化 |
| **辨证特色** | 治病先辨体；以「方人」「方病」匹配为辨证核心；通俗化、可视化经方教学 |
| **学派归属** | **黄煌学派**（「方-病-人」体质经方体系） |
| **学术地位** | 被誉为「当代经方普及第一人」，经方国际化代表人物 |

> 📎 来源：`经方家/02_黄煌/生平学术.md`（一手）

## 三、刘渡舟（1917—2001）

| 维度 | 内容 |
|------|------|
| **基本信息** | 辽宁营口人，北京中医药大学教授、博导，享年84岁 |
| **师承** | 营口名医王志远；学术源头：成无己→柯韵伯→尤在泾 |
| **代表著作** | 《伤寒论通俗讲话》《伤寒论十四讲》《刘渡舟伤寒论讲稿》《伤寒论临证指要》《金匮要略诠解》《肝病证治概要》 |
| **核心贡献** | ①坚持**「六经的实质是经络脏腑」**（与胡希恕「八纲说」形成对照）；②继承**「气化学说」**阐释伤寒（五运六气解六经）；③主编全国统编教材《伤寒论讲义》影响几代人 |
| **辨证特色** | 六经辨证与脏腑辨证相结合；以方类证，以证论治；经方为主、时方为辅，不拘门户 |
| **学派归属** | **脏腑经络学派**（传统伤寒学派的正统传承） |
| **学术地位** | 誉为「伤寒论泰斗」，中国现代《伤寒论》教育奠基人 |

> 📎 来源：`经方家/03_刘渡舟/生平学术.md`（一手）

## 四、冯世纶（1944—）

| 维度 | 内容 |
|------|------|

| **师承** | 胡希恕（嫡传弟子）；学术同道：张长恩、段治钧、陈雁黎 |
| **代表著作** | 整理：五部胡希恕遗著（《胡希恕伤寒论讲座》等）；个人：《解读张仲景医学——经方六经类方证》《冯世纶经方临床带教录》 |
| **核心贡献** | ①**全面整理出版胡希恕遗著**（若无冯世纶，胡老大量思想可能散佚）；②系统化阐释「六经来自八纲」理论；③概括为**「以八纲释六经，以方证统百病」** |
| **辨证特色** | 两步辨证：先辨六经（病位+病性）→ 再辨方证（精确选方）；重视经方原方原量 |
| **学派归属** | **胡希恕学派**（承前启后的关键传承人） |
| **学术地位** | 胡希恕学派最重要的学术整理者和传播者 |

> 📎 来源：`经方家/04_冯世纶/生平学术.md`（一手）

## 五、张庆军（当代）

| 维度 | 内容 |
|------|------|
| **基本信息** | 中医学博士（西大博士），活跃于经方教学与临床一线 |
| **师承** | 深受胡希恕六经辨证思想影响；学术脉络：仲景→胡希恕→病脉证治 |
| **代表著作** | 《打开经方这扇门》《经方讲习录》《经方讲习录（二）》《张庆军经方全集》（套装3册） |
| **核心贡献** | ①创立**「病脉证治」经方教学体系**（病→脉→证→治四步闭环）；②经方入门教育的标杆人物；③通过四君中医、B站、喜马拉雅多媒体矩阵广泛传播 |
| **辨证特色** | 病脉证治一体化：明确疾病诊断→重视脉诊→把握方证对应→据证选方；善用思维导图辅助教学 |
| **学派归属** | **病脉证治学派**（胡希恕六经辨证的延伸与体系化） |
| **学术地位** | 当代经方入门教育标杆人物，经方大众化传播先驱 |

> 📎 来源：`经方家/05_张庆军/生平学术.md`（一手）

| 维度 | 内容 |
|------|------|
| **基本信息** | 北京中医药大学医学博士，首都医科大学附属北京中医医院呼吸科副主任医师 |
| **师承** | 胡希恕经方医学体系正宗传人；北京中医药薪火传承「3+3」工程——胡希恕名家研究室成员 |
| **代表著作** | 《胡希恕经方医学讲座（全集）》《经方医学六经辨证》《马家驹二十方证详解》《六经入门讲记》 |
| **核心贡献** | ①**六经辨证临床规范化**——将胡老理论转化为可操作的四步路径（辨阴阳→辨病位→辨病性→辨方证）；②经方治疗**呼吸系统疾病**专长；③**经方与时方融合**——将时方纳入六经辨证体系 |
| **辨证特色** | 四步辨证法（阴阳→病位→病性→方证）；呼吸专病深耕；方证拆解教学（方剂组成→药证→六经归属→加减变化） |
| **学派归属** | **胡希恕学派**（临床规范化方向） |
| **学术地位** | 胡希恕名家研究室核心成员，经方呼吸病学代表 |

> 📎 来源：`经方家/06_马家驹/生平学术.md`（一手）

## 七、黄仕沛（黄世沛，当代）

| 维度 | 内容 |
|------|------|
| **基本信息** | 广东省名中医，全国名老中医药专家传承工作室指导专家 |
| **师承** | 推崇张仲景原旨，主张回归经典 |
| **代表著作** | 《黄仕沛经方亦步亦趋录》《黄仕沛经方师传录》 |
| **核心贡献** | ①提出**「学经方必须亦步亦趋」**理念——原方原量、原旨原义、方证相对；②经方治疗**Hp相关性胃炎**系统方案（半夏泻心汤类方为核心）；③强调「先继承后发扬」 |
| **辨证特色** | 亦步亦趋：严守原方原量；方证相对为不二法门；重视腹诊和脉诊；善用合方 |
| **学派归属** | **原方原量派**（保守还原主义经方） |
| **学术地位** | 誉为「现代经方奇才」；Hp相关性胃炎经方治疗的权威 |

> 📎 来源：`经方家/07_黄世沛/生平学术.md`（一手）

## 八、许家栋（当代）

| 维度 | 内容 |
|------|------|
| **基本信息** | 北京中医药大学教授、主任医师 |
| **师承** | 兼受胡希恕（「六经来自八纲」）和刘渡舟（「脏腑经络辨证」）双重影响 |
| **代表著作** | 《经方温补学派临床经验集》《经方脾胃病临证备要》《经方消化病学》（参编） |
| **核心贡献** | ①提出**「方证三角」**辨证模式（病—证—方三维对应）；②**经方消化病学**开拓者（功能性消化不良、慢性胃炎、胃食管反流等）；③**泻心汤类方三层次**（半夏→痞之常、生姜→痞兼水、甘草→痞兼虚）；④系统运用腹诊指导消化病辨证 |
| **辨证特色** | 方证三角（西医疾病诊断+中医证候+经方方证）；辛开苦降恢复中焦气机；腹部触诊为方证鉴别关键 |
| **学派归属** | **经方消化病学派**（胡-刘融合创新） |
| **学术地位** | 「经方消化病学」交叉学科开创者 |

> 📎 来源：`经方家/08_许家栋/生平学术.md`（一手）

## 九、曹颖甫（1866—1938）

| 维度 | 内容 |
|------|------|
| **基本信息** | 江苏江阴人，清末民初经方派代表人物，上海中医专门学校教务长。1938年因保护乡民被日军杀害，以身殉国 |
| **师承与传人** | 门人：章次公、秦伯未（均为现代中医名家） |
| **代表著作** | 《伤寒发微》《金匮发微》《经方实验录》（门人姜佐景编纂，经方临床必读之书） |
| **核心贡献** | ①**近代经方复兴的先驱**——以大量真实医案证明经方价值；②力倡**方证对应实证精神**；③善用峻剂（大承气汤、十枣汤等），胆识过人；④影响胡希恕、刘渡舟及日本汉方界 |
| **辨证特色** | 笃信经方，有是证用是方；反对空谈医理；抓主证、辨方证；敢于用峻剂 |
| **学派归属** | **近代经方派**（实证经方先驱） |
| **学术地位** | 20世纪中医经方复兴第一人；《经方实验录》为后世经方家必读 |

> 📎 来源：`经方家/09_曹颖甫/生平学术.md`（一手）

## 十一、欧阳卫权（当代）

| 维度 | 内容 |

| **辨证特色** | 「皮肤病之标在皮肤，本在六经」；六经辨证统摄皮肤诸证；寒温并用、攻补兼施 |
| **学派归属** | **经方皮肤科学派**（开创性专科经方体系） |
| **学术地位** | 「将六经辨证系统引入皮肤科的第一人」 |
