## 一、初诊核心工作流：张庆军「病脉证治」四步法

这是中医经方行业**最系统、最可操作**的初诊标准流程：

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│ 第一步   │ → │ 第二步   │ → │ 第三步   │ → │ 第四步   │
│ 辨「病」 │    │ 察「脉」 │    │ 抓「证」 │    │ 施「治」 │
│ 定六经   │    │ 定虚实   │    │ 锁方证   │    │ 开处方   │
└─────────┘    └─────────┘    └─────────┘    └─────────┘
```

### 第一步：辨「病」——定六经方向

**目标**：确定疾病所在的六经层次，这是治疗的总体方向。

| 关键入口症状 | 六经归属 |
|------------|---------|
| 怕冷、怕风、无汗/汗出异常、头身疼痛 | **太阳病** |
| 怕热、口渴、便秘、舌红苔黄 | **阳明病** |
| 口苦、胸胁苦满、往来寒热、默默不欲饮食 | **少阳病** |
| 吃凉东西难受、腹满、自利不渴 | **太阴病** |
| 精神萎靡、但欲寐、四肢厥冷 | **少阴病** |
| 手足厥冷、寒热错杂（上热下寒） | **厥阴病** |

> **胡希恕核心理念**："有一分恶寒，便有一分表证"——定六经是方向性诊断。

### 第二步：察「脉」——定虚实总纲

**目标**：决定治疗是攻还是补。这是**不可逾越的红线**。

```
         沉取脉诊
        /        \
    有力          无力
   （实证）      （虚证）
    /              \
  三阳病          三阴病
  祛邪为主        扶正为主
```

- **脉有力** → 可使用麻黄剂、承气剂、柴胡剂等攻邪方
- **脉无力** → 必须使用理中、四逆、真武等温补方
- **唯一例外**：完谷不化 → 无论脉象 → 急救回阳

### 第三步：抓「证」——锁定具体方证

**目标**：在六经+虚实框架下，捕捉特异性症状组合（方证），精准锁定方剂。

**常见独证→方证快速锁定**：

| 独证（特异性症状） | 直接锁定方剂 |
|------------------|------------|
| 不汗出而烦躁 | 大青龙汤 |
| 躺在床上翻来覆去睡不着（反复颠倒） | 栀子豉汤 |
| 喉中痰鸣如水鸡声 | 射干麻黄汤 |
| 干噫食臭、腹中雷鸣 | 生姜泻心汤 |
| 咳吐清稀泡沫痰 + 背冷如掌大 | 小青龙汤 |
| 口唇干燥起皮 + 手掌烦热 | 温经汤 |
| 痰中带血/带脓/血脓兼有 | 肺痈大合方 |
| 头痛呕吐清稀涎沫 + 手足冷 | 吴茱萸汤 |
| 白天昏沉、晚上彻夜难眠 | 麻黄附子细辛汤 |
| 暖气多 | 调胃承气汤 |
| 放屁多 | 小承气汤 |
| 不放屁 + 手足心热难忍 | 大承气汤 |

### 第四步：施「治」——精准选方用药

**目标**：严格遵循"有是证用是方"原则，选用对应经方或合方。

- 单经单一病机 → 单方
- 多经合病 → 合方（直接叠加对应方剂）
- 有表证 → 优先解表（有表先解表）
- 剂量：根据脉力强弱动态调整

## 二、冯世纶「三步辨证法」SOP（胡希恕学派标准流程）

冯世纶将胡希恕的辨证体系标准化为三个递进步骤：

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 第一步       │ →  │ 第二步       │ →  │ 第三步       │
│ 辨病位       │     │ 辨病性       │     │ 辨方证       │
│ 表/里/半表半里│     │ 阴/阳        │     │ 具体方剂     │
└──────────────┘     └──────────────┘     └──────────────┘
```

### 2.1 第一步：辨病位

| 病位 | 核心判断标准 |
|------|------------|
| **表证** | 恶寒、发热、头痛、身痛、脉浮（"有一分恶寒，便有一分表证"） |
| **里证** | 口渴、腹胀、便秘或下利、脉不浮 |
| **半表半里证** | 胸胁苦满、口苦咽干、目眩、往来寒热 |

### 2.2 第二步：辨病性

| 病性 | 核心表现 |
|------|---------|
| **阳证** | 发热、烦躁、口渴、面赤、脉数有力 |
| **阴证** | 畏寒、肢冷、不渴、面色苍白、脉沉微无力 |

### 2.3 第三步：辨方证

> **"方证是辨证的尖端"**——辨六经是方向（敌人在哪个方向），辨方证是精确打击（开哪一枪）。

### 2.4 冯世纶标准诊断语格式

```
[六经归属] + [核心病机] + [方证名称]

示例：
- "太阳表虚，营卫不和——桂枝汤证"
- "少阳阳明合病，热结在里——大柴胡汤证"
- "少阴表阴证，阳虚外感——麻黄附子细辛汤证"
```

## 四、许家栋「方证三角」操作流程

```
           病（现代疾病诊断）
          / \
         /   \
        /     \
      证 ————— 方
    （六经+八纲）（经方方证）
```

### 4.1 第一维——病（Disease）

1. 明确现代医学疾病诊断（如：功能性消化不良、胃食管反流病）
2. 了解疾病病理生理学基础
3. 将疾病纳入经方方证群的候选范围

### 4.2 第二维——证（Pattern）

1. 六经辨证：确定病位（表/里/半表半里）和病性（阴/阳/寒/热/虚/实）
2. 八纲辨证：进一步精细化
3. 脏腑辨证：明确涉及的脏腑
4. **腹诊**（望-按-切-叩四步）→ 核心依据
5. 舌诊、脉诊综合判断

### 4.3 第三维——方（Formula）

1. 在疾病和证候双重约束下，精确选定经方
2. 单方或合方取决于病机复杂程度
3. 药物剂量遵循"**原方比例、因证调整**"原则

### 4.4 三条验证标准

1. **病程符合**：所选方证的病程演变与患者实际情况一致
2. **方证对应**：腹证、舌脉证全面支持所选方证
3. **疗效反馈**：服药后2-3天内应有明显疗效反应（"经方三日见功"）

## 五、方证鉴别流程

### 5.1 类方鉴别通用框架

```
同一个主症
    ↓
列出所有可能出现该症的类方
    ↓
逐一用「独证」排除
    ↓
锁定唯一方证
```

### 5.2 关键方证鉴别决策树

#### 5.2.1 失眠方证鉴别

```
失眠
├── 脉有力？
│   ├── 翻来覆去睡不着 → 栀子豉汤（阳明）
│   ├── 怕冷+汗出+口苦+便干 → 柴胡加龙骨牡蛎汤（三阳合病）
│   ├── 噩梦连连+心烦 → 柴胡加龙骨牡蛎汤方向
│   └── 痰热口苦苔腻 → 黄连温胆汤方向
└── 脉无力？
    ├── 白天昏沉+晚上彻夜难眠 → 麻黄附子细辛汤（少阴）
    ├── 多春梦 → 桂枝加龙骨牡蛎汤
    └── 虚烦不得眠 → 酸枣仁汤
```

#### 5.2.2 咳嗽方证鉴别

```
咳嗽
├── 外感急性？
│   ├── 无汗+怕冷+脉浮紧 → 麻黄汤（太阳伤寒）
│   ├── 汗出+怕风+脉浮缓 → 桂枝加厚朴杏子汤（太阳中风）
│   └── 不汗出+烦躁 → 大青龙汤
├── 慢性/迁延？
│   ├── 喉中水鸡声 → 射干麻黄汤（咳嗽上气病）
│   ├── 清稀泡沫痰+背冷 → 小青龙汤（外寒内饮）
│   ├── 痰咸 → 金水六君煎（肺肾虚寒）
│   ├── 闻烟味/异味就咳 → 半夏厚朴汤（梅核气）
│   ├── 一说话就咳 → 补中益气汤（气虚）
│   └── 咳至吐食物后停止 → 保和丸（食积）
└── 躺下加重？
    └── 坐起减轻 → 咳嗽上气病 → 射干麻黄汤方向
```

#### 5.2.3 胁痛/腹痛方证鉴别

```
胁/腹痛
├── 胸胁苦满？
│   ├── +口苦 → 少阳病
│   │   ├── 苔白 → 小柴胡汤
│   │   └── 苔黄+便秘 → 大柴胡汤
│   ├── +怕冷汗出 → 柴胡桂枝汤
│   └── +口苦+便溏+脉无力 → 柴胡桂枝干姜汤
├── 心下痞？
│   ├── 按之濡软+呕而肠鸣 → 半夏泻心汤
│   ├── 按之硬+干噫食臭 → 生姜泻心汤
│   └── 按之硬满+下利日数十行 → 甘草泻心汤
├── 腹满腹胀？
│   ├── 按之硬痛拒按 → 实胀（阳明）
│   │   ├── 暖气多 → 调胃承气汤
│   │   ├── 放屁多 → 小承气汤
│   │   └── 不放屁+手足心热 → 大承气汤
│   └── 按之柔软喜按 → 虚胀（太阴）
│       └── 厚朴生姜半夏甘草人参汤
└── 心下按之痛 → 小陷胸汤
```

#### 5.2.4 头痛方证鉴别

```
头痛
├── 太阳（表）→ 怕冷+脉浮+头项强痛 → 麻黄汤/桂枝汤/葛根汤
├── 少阳（侧头部）→ 口苦+胸胁苦满 → 小柴胡汤
├── 阳明（前额）→ 口渴+便秘+脉大 → 白虎汤/承气汤
├── 太阴（昏沉）→ 头晕重+食不下+脉无力 → 苓桂术甘汤
├── 少阴（虚寒）→ 精神萎靡+脉沉细 → 麻黄附子细辛汤
└── 厥阴（巅顶）→ 吐涎沫+手足冷 → 吴茱萸汤
```

#### 5.2.5 湿热发黄方证鉴别

```
身目发黄
├── 黄色鲜明+齐颈而还汗出+苔黄腻+脉有力 → 茵陈蒿汤（阳明湿热黄疸）
└── 黄色晦暗+无汗出特征+脉无力+手足冷 → 非茵陈蒿汤证，转阴黄方向
```

## 六、合方规律

### 6.1 合方核心原则

> **"合方"不是自创方剂，而是将对应经典方剂直接叠加使用。**
> 当患者同时存在两个或以上明确方证指征时，将对应方剂相合。

### 6.2 张庆军经典合方模式

#### 6.2.1 六经合病合方

| 合病类型 | 合方 | 核心指征 |
|---------|------|---------|
| 太阳少阳合病 | 柴胡桂枝汤 | 怕冷+汗出+口苦+胸胁不适 |
| 少阳阳明合病 | 大柴胡汤 | 口苦+胸胁苦满+便秘+苔黄 |
| 三阳合病 | 柴胡加龙骨牡蛎汤 | 怕冷+汗出+口苦+便干+烦躁惊怯+脉有力 |
| 太阳阳明合病 | 葛根汤合白虎汤 | 高热+无汗+口渴 |
| 太阳太阴合病 | 桂枝人参汤 | 感冒+下利不止+心下痞硬 |
| 厥阴少阳合病 | 柴胡桂枝干姜汤合当归芍药散 | 口苦+手足冷+便溏+脉无力 |

#### 6.2.2 复杂病机大合方

| 合方名称 | 组成 | 主治与辨证金标准 |
|---------|------|----------------|
| **肺痈大合方** | 千金苇茎汤+桔梗汤+葶苈大枣泻肺汤 | 痰中带血/带脓/血脓兼有（符合其一即可） |
| **更年期大合方** | 二仙汤+小柴胡汤+酸枣仁汤+柴胡加龙骨牡蛎汤 | 更年期潮热汗出+烦躁失眠+焦虑 |
| **失眠综合大合方** | 柴胡加龙骨牡蛎汤+黄连温胆汤+栀子厚朴汤+栀子豉汤 | 复杂失眠（多证型覆盖） |
| **肝胆胃肠大病合方** | 柴胡桂枝干姜汤+当归芍药散+厚朴生姜半夏甘草人参汤 | 肝硬化腹水/肝癌术后（虚实夹杂） |
| **短气四方合方** | 茯苓杏仁甘草汤+橘枳姜汤+苓桂术甘汤+肾气丸 | 慢性呼吸困难（慢阻肺/肺心病），三焦分消 |

#### 6.2.3 特色合方

| 合方 | 主治 | 关键辨证点 |
|------|------|----------|
| 葛根汤合桃核承气汤 | 牛皮癣 | 太阳表闭（怕冷无汗冬重夏轻）+ 阳明瘀热（左少腹压痛） |
| 大柴胡汤合桂枝茯苓丸 | 哮喘/高血压/头痛 | 少阳阳明合病+瘀血 |
| 小柴胡汤合当归芍药散 | 月经不调/慢性肝炎 | 少阳+血虚水盛 |
| 四逆散合当归芍药散 | 痛经/乳腺增生 | 少阳郁结+血虚水盛 |
| 半夏泻心汤合旋覆代赭汤 | 慢性胃炎/反流性食管炎 | 心下痞+噫气不除 |

## 七、加减法原则

### 7.1 各大医家加减法总原则对比

| 医家 | 加减原则 | 核心理念 |
|------|---------|---------|
| **张庆军** | 尽量合方不加减 | 合方优于加减，保持原方结构 |
| **黄煌** | 原方为主、有据加减 | 加减必须有明确的药证依据 |
| **胡希恕** | 尽量原方 | 不随意加减 |
| **冯世纶** | 原方为体、加减需谨慎 | 加减不超过3味 |
| **许家栋** | 原方为体、加减为用 | 加减≤3味；有据可依；先原后加 |
| **刘渡舟** | 经方为主、不拘原方 | 可根据临床需要灵活化裁 |

### 7.2 许家栋加减三原则（最具操作性）

1. **不超过3味**：加减药物一般不超过3味，保持原方主体结构不变
2. **有据可依**：加减药物必须有明确的药证依据，不可随意添加
3. **先原后加**：初诊尽量用原方，根据疗效反馈再决定是否加减

### 7.3 常见加减法速查

| 原方 | 加减法 | 适应证 |
|------|--------|--------|
| 小青龙汤 | + 生石膏 | 兼郁热（口渴、咽痛、心烦） |
| 小柴胡汤 | + 生石膏 | 兼里热（烦躁、口渴、舌红） |
| 小柴胡汤 | 去半夏 + 天花粉 | 口渴明显 |
| 小柴胡汤 | 去黄芩 + 茯苓 | 兼水饮 |
| 大柴胡汤 | + 瘀血 → 合桂枝茯苓丸 | 舌暗、唇紫、痛有定处 |
| 半夏泻心汤 | + 枳壳 + 木香 | 痞满胀甚、气滞明显 |
| 半夏泻心汤 | + 蒲公英 | Hp相关性胃炎 |
| 半夏泻心汤 | 合四逆散 | 心情郁闷、气机不畅 |
| 温经汤 | + 附子 | 手足冰冷甚 |
| 温经汤 | + 艾叶、小茴香 | 寒重 |
| 温经汤 | + 桃仁、红花 | 瘀重 |
| 桂枝茯苓丸 | + 大黄 | 便秘（即合桃核承气汤意） |
| 四逆散 | + 当归芍药散 | 血虚水盛 |
| 苓桂术甘汤 | + 泽泻 | 眩晕剧烈（合泽泻汤） |

### 7.4 附子运用指征（综合各家）

- **刘渡舟**：畏寒、肢冷、脉微、舌淡——四字诀。先煎30-60分钟。
- **张庆军**：左手脉沉细无力即为阳虚金标准。
- **黄煌**：附子体质（面苍白晦暗、精神萎靡、畏寒怕冷）。

## 八、专科疾病标准治疗路径

### 8.1 张庆军呼吸系统「三步阶梯法」

这是张庆军处理所有呼吸系统疾病的标准化路径：

```
第一步：解表
    ↓
第二步：排痰（化痰）
    ↓
第三步：补肺→健脾→补肾（善后除根）
```

> **善后巩固**：玉屏风散（补肺脾）+ 金匮肾气丸（补肾）成药组合，以期根治。

### 8.2 腰腿痛经方诊疗十问流程

按胡希恕-冯世纶-许家栋经方遍诊法体系的五层十问：

| 层次 | 问题 | 辨证意义 |
|------|------|---------|
| **第一层：主诉精确定位** | ① 痛在哪里？② 怎么个痛法？ | 刺痛→瘀血；冷痛→寒湿；抽掣→筋脉挛急；重着酸沉→湿邪；麻木→血痹 |
| **第二层：寒热辨证** | ③ 怕冷还是怕热？④ 手足冷吗？⑤ 背部怕冷吗？ | 手足厥冷+脉沉细=少阴病；背恶寒=附子汤核心指征 |
| **第三层：汗出与表虚** | ⑥ 出汗情况？ | 无汗+恶寒=麻黄剂；汗出+恶风=桂枝剂 |
| **第四层：二便与津液** | ⑦ 小便怎样？⑧ 大便怎样？⑨ 口渴吗？ | 小便不利=水饮内停；口不渴=虚寒（用附子安全信号） |
| **第五层：全身状态** | ⑩ 精神体力？伴随症状？ | 但欲寐=少阴；口苦胸胁满=少阳 |

### 8.3 消化系统疾病腹诊优先路径（许家栋）

```
消化系统主诉
    ↓
腹诊（望-按-切-叩四步法）
    ↓
确定腹证类型
    ├── 心下痞按之濡 → 半夏泻心汤
    ├── 心下痞硬 → 生姜泻心汤
    ├── 心下痞硬而满 → 甘草泻心汤
    ├── 胸胁苦满 → 小柴胡汤/大柴胡汤
    ├── 心下按之痛 → 小陷胸汤
    ├── 腹满拒按 → 大柴胡汤/承气汤类
    └── 腹满喜按 → 厚朴生姜半夏甘草人参汤
```

## 九、服药反应判断与方案调整流程

### 9.1 张庆军疗效判断标准

| 服药后反应 | 判断 | 处理 |
|----------|------|------|
| 腹泻后**感觉舒服** | 排病反应（排毒） | 继续服药 |
| 腹泻后**感觉难受、乏力** | 可能药不对证 | 立即重新辨证 |
| 痰量增多、痰变易咳 | **天大好事**——向愈佳兆 | 继续排痰 |
| 无明显变化 | 可能辨证有误 | 重新审视"病→脉→证"三步 |

### 9.2 变更原则

> **"效不更方，不效就更方"**
> - 治疗有效 → 守方
> - 治疗无效 → 不归咎于剂量或体质，立即反思诊断
> - 重新审视：病（六经对吗？）→ 脉（虚实对吗？）→ 证（方证对吗？）

### 9.3 许家栋三日见功标准

> **"经方三日见功——如果三天没有效果，不是病不对，是方不对。"**

### 9.4 危急信号——完谷不化处理流程

```
出现完谷不化（吃什么拉什么）
    ↓
最高警报！立即停用一切攻邪之剂
    ↓
切换为急救回阳模式
    ↓
四逆汤 或 附子理中汤（从小剂量起）
    ↓
（这是"有表先解表"原则的唯一例外）
```

## 十、各学派工作流特征对比总结

| 学派/医家 | 核心工作流 | 特色关键词 | 适用场景 |
|----------|----------|----------|---------|
| **张庆军** | 病→脉→证→治四步 | 脉诊总开关、有表先解表 | 全科疑难病 |
| **胡希恕/冯世纶** | 辨病位→辨病性→辨方证 | 方证对应、腹诊辅助 | 全科 |
| **黄煌** | 望诊定体质→腹诊→问诊→舌脉→方人+方病结合 | 体质辨证、方人对应 | 慢性病、体质调理 |
| **马家驹** | 辨六经→析八纲→定方证 | 六经辨证程序化 | 呼吸专病、经方入门 |
| **刘渡舟** | 六经辨证+脏腑辨证+水证分型 | 以方类证、水证体系 | 水气病 |
| **许家栋** | 病-证-方三角+腹诊四步 | 方证三角、腹诊规范 | 消化专病 |
