## 一、腹诊（腹部按诊法）

腹诊是经方辨证体系中**最具客观性**的诊断工具，胡希恕、许家栋、张庆军均极度重视。

### 1.1 许家栋腹诊操作规范（四步法）

| 步骤 | 操作 | 目的 |
|------|------|------|
| **望腹** | 观察腹部外形、有无膨隆或凹陷、有无胃肠蠕动波 | 初判虚实、气胀/实积 |
| **按腹** | 以手掌轻轻按压，感受腹部温度、湿润度、紧张度 | 感寒热、润燥 |
| **切腹** | 以手指由浅入深按切心下、脐周、少腹 | 辨硬满、抵抗、压痛 |
| **叩腹** | 叩诊判断鼓音/浊音 | 辨气胀还是实积 |

### 1.2 腹证——方证对应速查表

| 腹证 | 对应方剂 | 胡希恕体系归属 | 许家栋现代疾病对应 |
|------|----------|----------------|-------------------|
| **心下痞，按之濡软** | 半夏泻心汤 | 厥阴 | 功能性消化不良、慢性浅表性胃炎 |
| **心下痞硬，按之有抵抗** | 生姜泻心汤 | 厥阴 | 慢性胃炎伴糜烂、Hp相关性胃炎 |
| **心下痞硬而满** | 甘草泻心汤 | 厥阴 | 慢性胃炎伴肠功能紊乱 |
| **心下痞硬，噫气不除** | 旋覆代赭汤 | — | 胃食管反流病 |
| **胸胁苦满** | 小柴胡汤/大柴胡汤 | 少阳 | 功能性消化不良、化疗后反应 |
| **心下按之痛** | 小陷胸汤 | — | 急性胃炎、胃溃疡 |
| **腹满按之痛（拒按）** | 大柴胡汤/大承气汤 | 少阳阳明合病/阳明 | 便秘、肠梗阻倾向 |
| **少腹急结/左少腹压痛** | 桃核承气汤/桂枝茯苓丸 | — | **瘀血证金标准** |
| **心下悸动/腹部动悸** | 苓桂术甘汤/桂枝加龙骨牡蛎汤 | — | 水饮上冲、惊悸 |
| **腹直肌拘挛** | 芍药甘草汤/小建中汤 | — | 筋脉挛急 |
| **少腹不仁（脐下知觉减退）** | 八味肾气丸 | — | 肾气不足 |
| **胃部振水音** | 茯苓饮/苓桂术甘汤 | — | 胃内停水 |
| **腹部膨隆，左下有粪块** | 麻子仁丸 | — | 慢传输型便秘 |
| **腹力软弱（按之松软无力）** | 建中汤类 | — | 虚证，慎用攻伐 |

### 1.3 张庆军瘀血腹诊要点

- **左少腹（左下腹）压痛** = 诊断**瘀血**的关键指征
- 常提示需合用活血化瘀方药（桂枝茯苓丸、下瘀血汤、桃核承气汤）
- 如：葛根汤合桃核承气汤治疗牛皮癣，依据即腹诊左少腹压痛

## 二、脉诊

### 2.1 张庆军「脉诊总开关」体系

张庆军体系中，**脉诊是决定治疗补泻方向的"总开关"**，核心标准极为简明：

| 脉象 | 判定 | 治疗方向 | 适用六经 |
|------|------|---------|---------|
| **沉取有力** | 实证、阳证 | 以祛邪为主 | 三阳病（太阳、阳明、少阳） |
| **沉取无力** | 虚证、阴证 | 以扶正为主 | 三阴病（太阴、少阴、厥阴） |

> 核心原则：脉之有力无力，是选择三阳方与三阴方的**唯一且不可逾越的分水岭**。误用于脉有力者，闭门留寇；该用于脉无力者而不用，虚其虚。

### 2.2 各经特异性脉象

| 六经 | 典型脉象 | 张庆军独特经验 |
|------|---------|---------------|
| **太阳病** | 脉浮紧（麻黄汤）、脉浮缓（桂枝汤） | 前提：脉有力 |
| **阳明病** | 脉洪大有力（白虎汤）、沉实（承气汤） | 脉沉取有力为前提 |
| **少阳病** | 脉弦、弦细、弦数 | 脉有力为前提；若无力则转入厥阴 |
| **太阴病** | 脉沉弱无力 | 吃凉东西难受 + 脉无力 = 太阴 |
| **少阴病** | 脉沉细无力、微细欲绝 | **左手脉沉细无力**是阳虚金标准（右手尚可也按虚证治） |
| **厥阴病** | 沉取无力为主，兼弦/紧/细 | 手足厥冷 + 脉无力 |

### 2.3 心率快慢与方证对应（张庆军）

| 心率特征 | 对应方剂 | 病机 |
|---------|---------|------|
| **心率慢**（窦性心动过缓） | 麻黄附子细辛汤 | 少阴阳虚，表寒郁闭 |
| **心率快**（心动过速）、脉结代 | 炙甘草汤 | 少阴病气血阴阳俱虚 |

### 2.4 冯世纶脉诊框架

| 脉象 | 病机 | 方向 |
|------|------|------|
| 脉浮紧 | 太阳表实 | 麻黄汤/葛根汤 |
| 脉浮缓 | 太阳表虚 | 桂枝汤类 |
| 脉沉细/沉微 | 少阴里虚寒 | 附子剂 |
| 脉沉紧 | 寒实内结 | 大黄附子汤/乌头汤 |
| 脉弦 | 少阳/痛证 | 柴胡剂 |
| 脉滑数 | 湿热 | 麻杏苡甘汤/白虎加桂枝汤 |
| 脉涩 | 瘀血 | 桂枝茯苓丸 |

## 三、舌诊

### 3.1 张庆军「水分证」舌诊金标准

张庆军体系中，**舌诊是辨识"水分证"的首要步骤**，诊断金标准为三条（满足任一即可）：

1. **舌体胖大**
2. **舌苔水滑**
3. **舌体胖大同时又有舌苔水滑**

### 3.2 水分证六经分治速查表

| 六经归属 | 核心脉证 | 代表方剂 |
|---------|---------|---------|
| **太阳病水分证** | 怕冷、脉有力、舌苔水滑 | 五苓散、小青龙汤、桂枝去桂加茯苓白术汤 |
| **阳明病水分证** | 怕热、脉有力、舌红苔水滑 | 猪苓汤 |
| **少阳病水分证** | 口苦/胸胁苦满、脉有力、苔水滑 | 柴胡加龙骨牡蛎汤、四逆散加茯苓 |
| **太阴病水分证** | 脉无力、食不下/怕食凉、苔水滑 | 理中汤加茯苓 |
| **少阴病水分证** | 脉无力、四肢凉、苔水滑 | 真武汤、附子汤、茯苓四逆汤 |
| **厥阴病水分证** | 脉无力、手脚凉、苔水滑 | 茯苓甘草汤、麻黄升麻汤 |

### 3.3 关键方证舌诊鉴别

| 方剂 | 舌象特征 | 鉴别要点 |
|------|---------|---------|
| 五苓散 | 舌苔水滑（舌质不红） | 舌苔水滑 + 口渴 |
| 桂枝去桂加茯苓白术汤 | 舌质红 + 苔水滑 | 与五苓散区别：舌质红 |
| 猪苓汤 | 舌红 + 苔水滑 | 热与水结，已伤阴 |
| 半夏泻心汤 | **舌苔腻**（白腻/黄腻/黄白相兼） | 苔腻是寒热互结的载体 |
| 白虎汤 | 舌质红或老红、苔黄燥 | 阳明气分大热 |
| 茵陈蒿汤 | 苔黄腻 | 湿热黄疸 |
| 大承气汤 | 舌苔黄厚干或焦黑 | 阳明腑实重证 |
| 小柴胡汤 | 舌苔薄白（热象明显可微黄） | 苔白用小柴胡；苔黄转大柴胡 |

### 3.4 腰腿痛舌诊（综合指南）

| 舌象 | 病机 | 方证方向 |
|------|------|---------|
| 舌淡胖苔白滑 | 寒湿 | 肾着汤证 |
| 舌暗红苔白腻 | 寒湿夹瘀 | 综合辨证 |
| 舌红苔黄腻 | 湿热 | 麻杏苡甘汤/白虎加桂枝汤 |
| 舌暗有瘀斑 | 瘀血 | 桂枝茯苓丸 |
| 舌淡苔薄 | 虚证 | 补益为主 |

## 五、体质辨证——黄煌体质说

### 5.1 「方-病-人」三角辨证体系

黄煌创造性地提出"方-病-人"辨证模式，核心是**"方人"概念**——每种经方都有其适用的人群特征（体质类型）。

```
        方（方剂）
        /      \
       /        \
      人（体质）——病（疾病）
```

**诊断流程**：望诊（体型/面色/表情/皮肤/步态）→ 腹诊（触腹辨虚实寒热）→ 问诊（饮食睡眠二便精神）→ 舌脉（辅助参考）

### 5.2 九大体质类型速查表

| 体质类型 | 外观特征 | 好发症状 | 代表方 |
|----------|---------|---------|--------|
| **桂枝汤体质** | 肤白体瘦、腹部扁平、易出汗 | 恶风、自汗、荨麻疹 | 桂枝汤类方 |
| **小柴胡汤体质** | 面色黄暗、体型中等偏瘦 | 口苦咽干、胸胁不适、低热 | 柴胡剂 |
| **大柴胡汤体质** | 体格壮实、面红有油、上腹饱满 | 便秘、高血压、胆囊炎 | 大柴胡汤 |
| **黄芪体质** | 面黄白或黄暗、肌肉松软浮肿 | 疲劳、自汗、易感冒 | 黄芪类方 |
| **半夏体质** | 面色黄暗、双目圆大有光、表情丰富 | 恶心、眩晕、心悸 | 半夏类方 |
| **麻黄体质** | 体格壮实、皮肤粗糙干燥 | 无汗、身痛、喘咳 | 麻黄类方 |
| **当归体质** | 面色萎黄、唇甲苍白、皮肤干燥 | 月经不调、手脚冰冷 | 四物汤类 |
| **黄连体质** | 面红油光、舌红苔黄 | 心烦失眠、口疮、腹泻 | 黄连解毒汤等 |
| **附子体质** | 面色苍白或晦暗、精神萎靡 | 畏寒怕冷、脉沉微 | 四逆汤类 |

### 5.3 体质辨证临床原则

- **同一疾病，不同体质用不同方**：高血压→大柴胡体质用大柴胡汤；黄芪体质用防己黄芪汤；桂枝体质用桂枝加葛根汤
- **同一方剂，不同疾病**：温经汤→不孕、月经不调、皮肤病、失眠，只要体质符合

## 六、六经辨证框架

### 6.1 冯世纶三步辨证法（继承胡希恕）

| 步骤 | 内容 | 判断标准 |
|------|------|---------|
| **第一步：辨病位** | 表/里/半表半里 | 表证：恶寒发热头痛身痛脉浮；里证：口渴腹胀便秘下利；半表半里：胸胁苦满口苦咽干目眩 |
| **第二步：辨病性** | 阴/阳 | 阳证：发热烦躁口渴面赤脉数有力；阴证：畏寒肢冷不渴面苍白脉沉微无力 |
| **第三步：辨方证** | 具体方剂匹配 | 在六经归属基础上，找到确切方证 |

### 6.2 马家驹「辨六经-析八纲-定方证」三步

| 步骤 | 操作 | 产出 |
|------|------|------|
| 辨六经 | 确定表/里/半表半里 + 阴阳 | 六经归属 |
| 析八纲 | 细化寒热虚实 | 八纲定性 |
| 定方证 | 匹配具体方剂 | 处方 |

### 6.3 刘渡舟六经-脏腑结合辨证

刘渡舟将六经辨证与脏腑辨证有机结合，例如眩晕一证：

| 六经归属 | 病机 | 代表方 |
|---------|------|--------|
| 少阳眩晕 | 少阳枢机不利 | 小柴胡汤 |
| 太阴眩晕 | 脾虚水饮上冲 | 苓桂术甘汤 |
| 少阴眩晕 | 肾阳虚水泛 | 真武汤 |

### 6.4 六经辨证口诀（综合整理）

| 六经 | 核心辨证词 | 关键入口症状 |
|------|----------|-------------|
| 太阳 | 脉有力 + 怕冷 | 怕冷、怕风、无汗/汗出、头身痛 |
| 阳明 | 脉有力 + 怕热 | 口渴、便秘、腹胀、舌红苔黄 |
| 少阳 | 脉有力 + 口苦 | 口苦、胸胁苦满、往来寒热 |
| 太阴 | 脉无力 + 吃凉难受 | 吃凉东西难受、腹满、自利不渴 |
| 少阴 | 脉无力 + 精神萎靡 | 但欲寐、四肢厥冷、完谷不化 |
| 厥阴 | 脉无力 + 手足厥冷 | 手足厥冷（铁证）、寒热错杂 |

## 七、病脉证治体系（张庆军）

### 7.1 核心理念

张庆军的"**病脉证治**"体系将诊断、辨证、立法、选方、用药五个环节有机统一，形成"以脉定证、以证选方"的标准化经方运用路径：

| 环节 | 内容 | 作用 |
|------|------|------|
| **病** | 辨六经方向 | 确定太阳/阳明/少阳/太阴/少阴/厥阴，定治疗总体方向 |
| **脉** | 切脉定虚实 | 沉取有力=实证（祛邪）；沉取无力=虚证（扶正） |
| **证** | 抓特异性症状（方证） | 在六经和虚实框架下锁定具体方证 |
| **治** | 精准选方用药 | 有是证用是方，严格方证对应 |

### 7.2 临床大原则：「有表先解表」

- 只要存在表证（怕冷、怕风、无汗、喷嚏、流涕），**无论主诉是失眠、抑郁、胃病、皮肤病还是其他内科杂症**，都必须优先解表
- **唯一例外**：出现严重里阳虚危候——"**完谷不化**"（吃什么拉什么）→ 必须先用四逆汤/附子理中汤回阳救里

### 7.3 三大支柱

| 支柱 | 内容 | 功能 |
|------|------|------|
| 「病脉证治」 | 四步递进诊断 | 精准导航 |
| 「有表先解表」 | 贯穿所有疾病 | 行动纲领 |
| 「合病合方」 | 多经并见时合法使用 | 解决复杂病情 |

## 八、许家栋「方证三角」体系

### 8.1 三维辨证模型

```
         病（现代疾病诊断）
        / \
       /   \
      /     \
    证 ------ 方
  （六经辨证）（经方方证）
```

| 维度 | 内容 | 操作 |
|------|------|------|
| **病（Disease）** | 明确现代医学诊断 | 了解疾病病理生理、纳入方证候选范围 |
| **证（Pattern）** | 六经+八纲+脏腑辨证 | 腹诊、舌诊、脉诊综合判断 |
| **方（Formula）** | 精确选定经方 | 单方或合方，原方比例因证调整 |

### 8.2 方证三角验证标准

1. **病程符合**：所选方证的病程演变与患者实际一致
2. **方证对应**：腹证、舌脉证全面支持所选方证
3. **疗效反馈**：服药后2-3天内应有明显疗效反应（"经方三日见功"）

## 九、工具整合速查：常见症状→辨证工具→对应方证

| 症状/体征 | 优先使用的辨证工具 | 关键判断 |
|----------|-----------------|---------|
| 怕冷 | 问诊+脉诊 | 有表证→优先解表 |
| 口苦 | 问诊+腹诊 | 胸胁苦满→少阳病→柴胡剂 |
| 失眠（翻来覆去） | 问诊 | 反复颠倒→栀子豉汤 |
| 失眠（焦虑怕冷汗出） | 问诊+脉诊 | 脉有力→柴胡加龙骨牡蛎汤 |
| 手足厥冷 | 触诊 | 铁证→厥阴病方向 |
| 腹满腹胀 | 腹诊 | 按之硬痛拒按=实胀（阳明）；按之柔软喜按=虚胀（太阴） |
| 吃凉东西难受 | 问诊+脉诊 | 脉无力→太阴病 |
| 口渴+小便不利 | 舌诊+问诊 | 苔水滑→水分证 |
| 左少腹压痛 | 腹诊 | 瘀血证→合用活血化瘀方 |
| 心率慢 | 脉诊 | 麻黄附子细辛汤；心率快→炙甘草汤 |
| 痰中带血/脓 | 问诊 | 肺痈病→肺痈大合方 |
| 黄疸 | 望诊+问诊 | 汗出齐颈而还→茵陈蒿汤 |
| 咳嗽遇冷/躺下加重 | 问诊 | 咳嗽上气病→射干麻黄汤方向 |
| 完谷不化 | 问诊 | 最高警报→立即停攻邪→四逆汤救里 |

## 十、关键学派工具特色对比

| 学派/医家 | 核心辨证工具 | 最大特色 |
|----------|------------|---------|
| **张庆军** | 病→脉→证→治四步法 | 脉诊为总开关，"有表先解表"纲领 |
| **黄煌** | 体质辨证（方-病-人三角） | 望诊定体质、方人对应 |
| **胡希恕** | 方证对应 + 腹诊 | 有是证用是方，但见一证便是 |
| **冯世纶** | 六经来自八纲三步法 | 辨病位→辨病性→辨方证 |
| **马家驹** | 辨六经-析八纲-定方证 | 六经辨证程序化 |
| **刘渡舟** | 六经+脏腑辨证+水证体系 | 以方类证，水证分五型 |
| **许家栋** | 方证三角 + 腹诊四步 | 病-证-方三维对应 |

---

> **总结**：中医经方行业的辨证工具已形成以"六经辨证"为总框架，以"腹诊/脉诊/舌诊"为三大客观依据，以"方证对应"为最终出口的完整工具体系。张庆军的"病脉证治"提供了最清晰的四步路径，黄煌的"体质辨证"提供了最快捷的"看人选方"入口，许家栋的"方证三角"则打通了传统经方与现代疾病诊断的对接桥梁。
