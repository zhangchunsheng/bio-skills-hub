## 剂量换算方法论（三层递进）

### 第一层：原方剂量考
- 汉代一两 ≈ 15g（经方界主流考证）
- 原方日摄入生药量 = 单味量 × 味数
- 此为"治疗急性病"的剂量，非产品化剂量

### 第二层：产品场景剂量锚定
- 区分：治疗量 vs 预防/辅助量
- 参考：经方临床"减量调养"惯例，取原方1/3~1/6
- 约束：每味药的安全上限（如甘草≤30g生药/日）
- 临床依据：门诊常用量、日本汉方参考量

### 第三层：生药量 → 产品投料量
```
生药量 × 提取物收率(水提约18-22%) = 干浸膏粉量
干浸膏粉量 ÷ 每片载药比例(泡腾片约20-25%) = 每日片数
```
- 调整每日片数到消费体验可接受范围（≤6片/日）
- 反推最终锚定的每日生药量

### 剂型适配度评估维度
| 维度 | 评估要点 |
|------|---------|
| 组方与场景契合 | 方证适应证是否天然匹配产品使用场景 |
| 药食同源合规 | 每味药是否在目录内，不在则需蓝帽子 |
| 剂型载药能力 | 该剂型有效成分承载比例能否支撑起效剂量 |
| 场景消费体验 | 使用场景是否自然融入消费者既有行为 |
| 组方极简度 | 药味数越少，质控越简单、消费者理解门槛越低 |
| 市场空白度 | 是否存在"有需求、没供给"的竞争缺口 |

## docx 生成技术要点

- 使用 `python-docx` 库
- 中文字体统一设"微软雅黑"，需同时设置 `font.name` 和 `rFonts.set(qn('w:eastAsia'), '微软雅黑')`
- 表格：表头深色底白字，数据行隔行浅灰底
- 配色建议：主色调 `#1A3C6D`（深蓝），表格头 `#2D5F8B`
- 封面：大标题32pt粗体 + 副标题22pt + 元信息居中
- 流程图示：用等宽字体的ASCII字符画
- **注意**：中文字符串含特殊引号时可能导致 Python 语法错误，用双引号包裹字符串或简化为普通引号
