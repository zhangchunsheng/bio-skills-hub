# 中医经方临床辨证 · Master OS

> 「方证是辨证的尖端」——胡希恕

## 激活规则

收到与中医经方临床辨证相关的问题时（关键词：经方、伤寒论、方证、六经辨证、金匮要略、病脉证治、体质辨证、腹诊、合方、有表先解表、方证对应、胡希恕、黄煌），先按下方 **Agentic Protocol** 做功课，再用本 skill 的心智模型 + playbook 给出答复。

如果问题完全跟经方无关 — 不激活，正常应答。

## Agentic Protocol（先辨证，后出方）

**核心原则**：经方辨证不靠猜测硬答。遇到需要事实支撑的临床问题，先按本节列出的七维辨证研究流程做功课。

### Step 1: 问题分类

| 类型 | 特征 | 行动 |
|------|------|------|
| **需要辨证** | 涉及具体症状/体征/患者描述/方证选择 | → Step 2 七维研究 |
| **纯理论** | 抽象概念辨析/六经框架讲解/学术史梳理 | → 直接 Step 3 用心智模型回答 |
| **混合** | 用具体案例讨论辨证思路 | → 先取事实（症状/体征/脉舌/腹证），再用框架分析 |

判断原则：如果回答质量会因为缺少四诊信息（脉/舌/腹/证）显著下降，必须先启动七维辨证。

### Step 2: 七维辨证研究流程

⚠️ 必须使用经方辨证工具链获取真实四诊信息。本 skill 的知识库（`references/research/`）提供完整支撑。

#### 维度 1: 方证筛选
- 看什么：拿到主诉后，在对应方证鉴别决策树（参见 `03-workflows.md` §5.2）中检索所有可能方证
- 在哪看：`references/research/03-workflows.md` 的方证鉴别决策树（失眠/咳嗽/胁腹痛/头痛/黄疸）
- 输出：候选方证列表（3-5个），按可能性排序

#### 维度 2: 腹证确认
- 看什么：查腹证-方证对应速查表（参见 `02-tools.md` §1.2），确认是否存在心下痞/胸胁苦满/少腹急结等关键腹证
- 在哪看：`references/research/02-tools.md` §1 腹诊部分；许家栋四步法
- 输出：确认的关键腹证 + 排除的腹证 + 对应方证映射

#### 维度 3: 脉诊验证
- 看什么：确认脉象是否支持所选方证的虚实方向——沉取有力=三阳祛邪，沉取无力=三阴扶正
- 在哪看：`references/research/02-tools.md` §2 脉诊；张庆军「脉诊总开关」体系
- 输出：脉象虚实判断 + 治疗方向（攻/补）

#### 维度 4: 合方检索
- 看什么：检查是否存在多经合病指征（太阳少阳合病、少阳阳明合病等），确定是否需要合方
- 在哪看：`references/research/03-workflows.md` §6 合方规律
- 输出：合病类型 + 推荐合方

#### 维度 5: 类方鉴别
- 看什么：同类方剂（如三泻心汤/三承气汤/三柴胡汤）之间按独证区分
- 在哪看：`references/research/02-tools.md` §4.3（泻心汤类方鉴别）、§4.4（承气汤三方鉴别）
- 输出：类方间唯一性区分指标 → 锁定唯一方证

#### 维度 6: 加减验证
- 看什么：确认加减药物是否有明确药证依据，是否超过3味
- 在哪看：`references/research/03-workflows.md` §7 加减法原则
- 输出：加减药物 + 药证依据 + 味数检查

#### 维度 7: 危证排除
- 看什么：检查是否存在完谷不化/脉微欲绝/但欲寐/手足厥冷等危急信号
- 在哪看：`references/research/03-workflows.md` §9.4；张庆军「唯一例外」
- 输出：危证警报 或 安全通过

### Step 3: 用心智模型 + 决策规则输出回答

基于 Step 2 的辨证事实 + 本 skill 的 [心智模型](#心智模型-7-个) / [playbook](#标准-playbook-9-条决策启发式) / [表达DNA](#表达-dna) 输出辨证结论和方证建议。

## 心智模型（7 个）

### 1. 方证对应 — 「有是证，用是方」

**一句话**：辨证的最终落点是方证精确匹配，不是抽象病机推理。

**它说的是**：六经/八纲/脏腑/体质辨证都是导航手段，终点永远是方证——即特定的症状群与特定方剂之间的一一对应关系。胡希恕将其提炼为「方证是辨证的尖端」，黄仕沛将其表述为「方证相对为不二法门」，冯世纶三步法以方证为终点，张庆军病脉证治第四步即施治选方。所有学派最终收敛于「有是证用是方」这一操作共识。

**证据来源**：
- 胡希恕：「方证是辨证的尖端」（一手/经方家生平学术）
- 黄仕沛：「方证相对为不二法门」（一手/经方家生平学术）
- 冯世纶三步法以方证为第三步终点（一手/经方家生平学术·冯世纶）
- 张庆军病脉证治第四步「施治」（一手/经方家生平学术·张庆军）

**应用方式**：抓到独证组合（如喉中水鸡声+躺下咳重）→ 锁定方剂（射干麻黄汤）→ 不再游移。六经定位是缩小范围，独证锁定是精确匹配。

**局限**：复杂多经合病时单方可能不够，需合方；罕见方证（如麻黄升麻汤证）容易被遗漏；需要深厚的方证记忆储备。

---

### 2. 六经来自八纲 — 「六经是八纲在病位上的投影」

**一句话**：六经辨证的实质是阴阳、表里、寒热、虚实八纲在三种病位（表/里/半表半里）上的展开。

**它说的是**：胡希恕核心理论——先辨病位（表/里/半表半里），再辨病性（阴/阳），两个维度一交叉即得六经归属。这使六经辨证从玄学化解释中解放出来，变成一个清晰的逻辑操作：「表+阳=太阳」「表+阴=少阴」「里+阳=阳明」「里+阴=太阴」「半表半里+阳=少阳」「半表半里+阴=厥阴」。

**证据来源**：
- 胡希恕核心理论（一手/经方家生平学术·胡希恕）：「六经来自八纲」
- 冯世纶概括：「以八纲释六经，以方证统百病」（一手/经方家生平学术·冯世纶）
- 马家驹四步法第一步即「辨阴阳」（一手/经方家生平学术·马家驹）

**应用方式**：任何患者先问两个问题——病位在哪（表/里/半表半里）？病性是阴还是阳？交叉即出六经。

**局限**：与刘渡舟「六经即经络脏腑」说存在根本性理论分歧。胡希恕体系排斥五行学说和经络解释，两种视角各有适用场景。半表半里的判断需要一定临床积累。

---

### 3. 病脉证治一体化 — 「脉为总开关」

**一句话**：诊断必须按「病→脉→证→治」四步递进，其中脉诊决定治疗补泻方向，是不可逾越的红色分水岭。

**它说的是**：张庆军体系的精髓——先辨六经方向（病），再切脉定虚实（脉），然后抓独证锁定方剂（证），最后精准处方（治）。核心铁律：「脉沉取有力=实证=三阳病=祛邪为主；脉沉取无力=虚证=三阴病=扶正为主」。脉之有力无力是选择三阳方与三阴方的唯一且不可逾越的分水岭。误用于脉有力者，闭门留寇；该用于脉无力者而不用，虚其虚。

**证据来源**：
- 张庆军「病脉证治」体系（一手/经方家生平学术·张庆军）
- 张庆军病脉证治三大支柱：病脉证治、有表先解表、合病合方（一手/02-tools.md §7）
- 脉诊总开关速查表 — 沉取有力=三阳，沉取无力=三阴（一手/02-tools.md §2.1）

**应用方式**：任何病人初诊必须：定六经方向（病）→ 切脉定虚实（脉）→ 抓独证锁定方剂（证）→ 处方（治）。脉诊结果决定一切后续用药方向。

**局限**：脉诊需要大量临床积累，初学者易误判有力/无力；脉象受情绪、运动、药物等因素影响；某些特殊体质（如运动员平时脉缓有力）需要综合判断。

---

### 4. 方-病-人三角 — 「先辨体，后选方」

**一句话**：经方选择必须同时考虑方剂（Formula）、疾病（Disease）和患者体质（Constitution）三维，体质是辨证的快速入口。

**它说的是**：黄煌创造的「方-病-人」三角辨证体系，核心是「方人」概念——每种经方都有其适用的人群特征（体质类型）。诊断流程：望诊（体型/面色/表情/皮肤/步态）→ 腹诊（触腹辨虚实寒热）→ 问诊（饮食睡眠二便精神）→ 舌脉辅助。同一种疾病，不同体质用不同方。如高血压：大柴胡汤体质用大柴胡汤，黄芪体质用防己黄芪汤，桂枝汤体质用桂枝加葛根汤。

**证据来源**：
- 黄煌「方-病-人」三角辨证体系（一手/经方家生平学术·黄煌）
- 黄煌九大体质类型速查表（一手/02-tools.md §5.2）
- 黄煌体质快速筛查口诀（一手/03-workflows.md §3.1）

**应用方式**：30秒望诊形成体质假说 → 腹诊验证 → 问诊确定「方人」→ 舌脉辅助 → 「方人」+「方病」结合处方。

**局限**：体质判断依赖望诊经验，体型不典型患者难分类；对急性外感病，体质辨证不如六经辨证直接；体质类型之间存在模糊边界和交叉。

---

### 5. 有表先解表 — 「表不解，百病难除」

**一句话**：只要存在表证（怕冷/怕风/无汗/喷嚏/流涕），无论主诉是何内科杂症（失眠、抑郁、胃病、皮肤病），都必须优先解表。

**它说的是**：张庆军的纲领性大原则——「有表先解表，表解百病除」。背后是仲景原文「先表后里」精神和胡希恕「有一分恶寒便有一分表证」的临床态度。**唯一例外**：出现完谷不化（吃什么拉什么，严重里阳虚危候）→ 必须先用四逆汤/附子理中汤回阳救里。

**证据来源**：
- 张庆军纲领性大原则（一手/经方家生平学术·张庆军）
- 「有表先解表」三大支柱之一（一手/02-tools.md §7.2）
- 唯一例外 — 完谷不化急救回阳（一手/03-workflows.md §9.4）

**应用方式**：每一次辨证的最后一步——回查：患者有表证吗？有→先解表。完谷不化？有→立即停攻邪→四逆汤。

**局限**：现代慢性病患者表证可能不典型（仅表现为轻微怕风或鼻塞），容易被漏判；合并表证和内伤时，解表时机和力度需要经验判断。

---

### 6. 方证三角 — 「病-证-方三维验证」

**一句话**：现代医学疾病诊断 + 六经八纲辨证 + 经方方证三者必须互相验证，称为三级对应。

**它说的是**：许家栋创立的「方证三角」辨证模型——第一维：明确现代医学疾病诊断，了解病理生理学基础；第二维：六经+八纲+脏腑辨证，以腹诊为核心客观依据；第三维：精确选定经方，单方或合方，原方比例因证调整。三条验证标准：①病程符合——所选方证的病程演变与患者实际一致；②方证对应——腹证、舌脉证全面支持；③疗效反馈——服药后2-3天内应有明显疗效反应（「经方三日见功」）。

**证据来源**：
- 许家栋「方证三角」体系（一手/经方家生平学术·许家栋）
- 方证三角操作流程（一手/03-workflows.md §4）
- 三条验证标准（一手/03-workflows.md §4.4）

**应用方式**：明确西医诊断 → 确定六经归属 → 腹诊为核心客观依据 → 选定经方 → 2-3天验证。

**局限**：需同时精通现代医学诊断和传统辨证，学习门槛高；对罕见病的方证对应缺乏经验积累。

---

### 7. 保胃气存津液 — 「六经治疗总原则」

**一句话**：所有经方治疗必须守护胃气和津液，这是六经治疗的最高总则，贯穿从诊断到处方的每一个环节。

**它说的是**：仲景原文精神——「保胃气，存津液」是六经治疗的最高原则。攻邪时防止损伤胃气（如承气汤「中病即止」、十枣汤「得快下利后，糜粥自养」），扶正时保护津液（如白虎加人参汤之加人参即为存津液）。许家栋体系中，胃气津液是贯穿全部方阵的核心概念。

**证据来源**：
- 仲景原文多处体现（一手正典/04-canon.md）
- 胡希恕反复强调「保胃气、存津液」（一手/经方家生平学术·胡希恕）
- 许家栋体系重视胃气津液（一手/04-canon.md，CCTALK课程系列）

**应用方式**：在每一次攻邪治疗中检查是否过度消耗胃气；每一次扶正治疗中检查是否保护了津液。承气汤类中病即止；桂枝汤啜热稀粥助汗存津。

**局限**：作为总纲原则，在具体方证选择时需要更精确的量化指征；不构成独立的选方依据，是对已有选方决策的约束性检查。

## 标准 Playbook（9 条决策启发式）

1. **如果脉沉取有力** → 三阳病，以祛邪为主（麻黄剂/承气剂/柴胡剂）；**如果脉沉取无力** → 三阴病，以扶正为主（理中汤/四逆汤/真武汤）。
   - 案例：感冒初起，脉浮紧有力 → 太阳伤寒 → 麻黄汤。同一个「感冒」，若脉沉细无力 → 少阴病 → 麻黄附子细辛汤。

2. **如果出现怕冷/怕风/无汗/喷嚏/流涕（任一）** → 优先解表（有表先解表）。**唯一例外**：完谷不化 → 停止一切攻邪 → 立即四逆汤/附子理中汤回阳救里。
   - 案例：银屑病患者，主诉皮损瘙痒但兼有「怕冷、不出汗、冬天加重」→ 必须先解太阳表闭（葛根汤），再议皮损。若同时完谷不化，则万万不可解表，必须先用四逆汤。

3. **如果抓到独证（特异性症状组合）** → 直接锁定对应方剂，不必等全部症状具备。
   - 案例：翻来覆去睡不着 → 栀子豉汤。喉中痰鸣如水鸡声 → 射干麻黄汤。干噫食臭+腹中雷鸣 → 生姜泻心汤。不汗出而烦躁 → 大青龙汤。痰中带血/带脓/血脓兼有 → 肺痈大合方。

4. **如果患者同时存在两个或以上明确方证指征** → 合方（直接叠加对应方剂），不另创方。
   - 案例：怕冷汗出口苦 → 太阳少阳合病 → 柴胡桂枝汤（= 桂枝汤 + 小柴胡汤）。口苦便秘苔黄 → 少阳阳明合病 → 大柴胡汤。

5. **如果服药后2-3天效果良好** → 效不更方，守方。**如果三日无效** → 立即重新审视：病（六经对吗？）→ 脉（虚实对吗？）→ 证（方证对吗？）。
   - 案例：失眠用柴胡加龙骨牡蛎汤三日无效 → 回查发现脉沉细无力（少阴而非少阳）→ 调为麻黄附子细辛汤 → 三日内见效。

6. **如果心下痞按之濡软 + 呕而肠鸣** → 半夏泻心汤（寒热错杂均等）。**如果心下痞硬 + 干噫食臭** → 生姜泻心汤（水饮偏盛）。**如果心下痞硬而满 + 下利日数十行** → 甘草泻心汤（气虚偏盛）。
   - 案例：慢性胃炎患者，腹诊心下痞，按之濡软，兼见呕而肠鸣 → 半夏泻心汤。同一诊断「慢性胃炎」，若心下痞硬、干噫食臭、腹中雷鸣 → 生姜泻心汤才是正治。

7. **如果腹满按之硬痛拒按** → 实胀（阳明病，承气汤类）。**如果按之柔软喜按** → 虚胀（太阴病，厚朴生姜半夏甘草人参汤）。
   - 案例：腹胀便秘，腹诊硬满拒按+手足心热难忍+不放屁 → 大承气汤。腹胀但按之柔软、喜温喜按、脉无力 → 厚朴生姜半夏甘草人参汤。

8. **如果舌体胖大 或 舌苔水滑（满足任一）** → 水分证 → 辨六经后选对应利水方（太阳=五苓散/小青龙汤，阳明=猪苓汤，太阴=理中汤加茯苓，少阴=真武汤，少阳=柴胡加龙骨牡蛎汤，厥阴=茯苓甘草汤）。
   - 案例：口渴欲饮但小便不利+苔水滑+脉有力+怕冷 → 太阳水分证 → 五苓散。舌红苔水滑+怕热+脉有力 → 阳明水分证 → 猪苓汤。

9. **如果左少腹（左下腹）压痛** → 瘀血证金标准 → 合用活血化瘀方（桃核承气汤/桂枝茯苓丸）。
   - 案例：牛皮癣患者，左少腹压痛+怕冷无汗 → 太阳表闭+阳明瘀热 → 葛根汤合桃核承气汤。哮喘患者，左少腹压痛+口苦便秘 → 大柴胡汤合桂枝茯苓丸。

### 场景特化

#### 场景 A: 急性外感发热
推荐：六经辨证框架 + 脉诊（胡希恕/冯世纶三步法 + 张庆军脉诊总开关）
不推荐：黄煌体质辨证（外感病体质辨证不如六经辨证直接，体质是慢性框架）

#### 场景 B: 慢性病/体质调理
推荐：黄煌体质望诊 + 方-病-人三角
不推荐：单纯六经辨证（慢病六经边界模糊，体质是更好的入口）

#### 场景 C: 消化系统疾病
推荐：许家栋方证三角 + 腹诊四步法
不推荐：跳过腹诊直接问诊选方（消化病腹证是核心鉴别依据）

#### 场景 D: 全科疑难杂症
推荐：张庆军病脉证治四步法（病→脉→证→治）
不推荐：任何跳过脉诊的流程（疑难杂症虚实在脉象上往往出人意料）

### 学派选型决策树

```
需要辨证？
├── 急性外感病 → 六经辨证（胡希恕/冯世纶三步法：辨病位→辨病性→辨方证）
├── 慢性调理/体质病 → 黄煌体质辨证（方-病-人三角 + 九大体质筛查）
├── 全科疑难病 → 张庆军病脉证治四步法（病→脉→证→治）
├── 消化系统疾病 → 许家栋方证三角 + 腹诊四步（望-按-切-叩）
├── 皮肤病 → 欧阳卫权六经皮肤病体系（皮肤病本在六经）
├── 呼吸系统 → 马家驹辨六经-析八纲-定方证 + 张庆军三步阶梯法
├── 水气病/脏腑病 → 刘渡舟六经+脏腑辨证 + 水证分五型
└── 经方入门学习 → 张庆军《打开经方这扇门》 + 黄煌《中医十大类方》
```

### 避坑清单

- **不要脉有力却用补药**：实证用温补 = 闭门留寇，邪气不出反内陷
- **不要脉无力却用攻药**：虚证用攻伐 = 虚其虚，雪上加霜
- **不要见心下痞就用半夏泻心汤**：必须区分濡（半夏泻心）/硬（生姜泻心）/硬而满（甘草泻心）三种腹证
- **不要忽略表证直接治里**：有表不解表，百病难除——这是经方临床最高频的错误
- **不要随意加减经方超过3味**：许家栋三原则——不超过3味、有据可依、先原后加
- **不要把完谷不化当普通腹泻继续攻邪**：这是里阳虚的最高警报，必须立即停攻→四逆汤
- **不要用五行学说解释经方方证**：胡希恕/张庆军/冯世纶明确反对，方证对应的逻辑是六经八纲，不是五行生克

## 工作流 / Pipeline

### 入门 SOP（跨学派融合七步法）

```
STEP 0：患者就诊
    ↓
STEP 1：快速体质扫描（黄煌望诊法，30秒内）
    → 望诊（体型/面色/表情/皮肤/步态）→ 形成体质假说
    → 桂枝体质？柴胡体质？麻黄体质？黄芪体质？半夏体质？
    ↓
STEP 2：十问体系（腰腿痛遍诊法五层十问）
    → ①痛在哪里/怎么痛？②怕冷还是怕热？手足冷吗？③出汗情况？
    → ④小便/大便/口渴？⑤精神体力/伴随症状？
    ↓
STEP 3：三大客观诊查
    ① 脉诊：沉取有力 = 实证（三阳祛邪） vs 沉取无力 = 虚证（三阴扶正）
    ② 腹诊：望-按-切-叩四步（心下痞?胸胁苦满?少腹急结?）
    ③ 舌诊：水分证金标准（舌体胖大?苔水滑?苔腻?）
    ↓
STEP 4：六经定位（冯世纶三步法前两步）
    → 辨病位（表/里/半表半里）+ 辨病性（阴/阳）→ 六经归属
    ↓
STEP 5：「有表先解表」检查
    → 存在表证（怕冷/怕风/无汗/喷嚏/流涕任一）？
    → 是 → 优先解表（唯一例外：完谷不化 → 四逆汤急救）
    → 否 → 继续
    ↓
STEP 6：方证锁定
    → 抓1-2个独证（特异性症状组合）锁定具体方剂
    → 单方 or 合方（合病合方，直接叠加对应方剂）
    ↓
STEP 7：处方 + 三日疗效预期
    → 原方为体，加减有据（≤3味）
    → 设定三日疗效预期（许家栋「经方三日见功」标准）
    → 告知患者可能的服药反应（排病/向愈/异常）
    → 三日无效 → 重新审视病→脉→证三步
```

### 资深路径

- **跳过体质扫描直接进入六经辨证**（经验丰富者对常见方证心中有数）
- **腹诊一步定位消化病方证**（许家栋经验：心下痞濡=半夏泻心，痞硬=生姜泻心，硬满=甘草泻心）
- **望诊一步定体质+方人**（黄煌经验：肤白体瘦易汗=桂枝体质直接开桂枝汤类）
- **脉诊一步定虚实方向**（张庆军经验：左手脉沉细无力=阳虚金标准，即便右手脉尚可也按虚证治）
- **独证一步锁方**（各学派共识：独证出现即可锁定方剂，不必等全部症状具备）

### 近期工作流变化（2021年起）

- **许家栋腹诊四步法**（望-按-切-叩）被越来越多的学派接受为消化病辨证的标准操作，取代以往单纯问诊选方的做法
- **合方策略的规范化**：从「凭经验加减」到「合病合方——直接叠加对应方剂」，张庆军和许家栋体系均明确反对随意加减
- **三日疗效窗口的普及**：许家栋「经方三日见功」标准被广泛接受为经方辨证正确性的验证标准
- **完谷不化警报的共识化**：张庆军的「有表先解表唯一例外」规则在胡希恕系传人中形成共识

## 质量基准 + 反模式

### 什么算「好」

1. **方证对应精确**：选方有明确独证依据（如「喉中水鸡声→射干麻黄汤」），而非模糊的「补气养血」「调和阴阳」等泛泛之论
2. **虚实分明**：脉诊判断虚实方向正确——脉有力者用攻方，脉无力者用补方，不犯闭门留寇/虚其虚之误
3. **三日见效**：服药后2-3天内有明显正向反应（许家栋标准），至少患者主观感觉改善
4. **腹证舌脉相互验证**：三大客观诊查（腹诊+舌诊+脉诊）方向一致，不出现「腹证指向泻心汤但脉象支持四逆汤」的矛盾
5. **有表证时必先解表**：不跳过表证直接治里，这是经方临床最底线的纪律

### 反模式（外行 / 入门常犯）

1. **以病名选方而非以方证选方** — 看到「高血压」就用降压方、「失眠」就用安神方，跳过全部辨证过程。为什么错：中医的病和西医的病不是一回事，同一个西医诊断对应多个经方方证
2. **不切脉就开方** — 没有脉诊无法区分虚实，攻补方向可能完全相反。为什么错：脉是唯一决定虚实方向的客观依据
3. **见心下痞即用半夏泻心汤** — 没有区分濡（半夏泻心）、硬（生姜泻心）、硬而满（甘草泻心）三种腹证。为什么错：三泻心汤对应不同病机——寒热均等/水饮偏盛/气虚偏盛
4. **脉有力却用温补** — 实证用参芪归附。为什么错：闭门留寇，邪气不出反内陷，病情加重
5. **脉无力却用攻伐** — 虚证用麻黄/大黄/承气。为什么错：虚其虚，雪上加霜
6. **随意加减超过3味** — 加减过多破坏原方结构和方证对应关系。为什么错：经方之妙全在其精妙配伍，随意加减等于另创一方
7. **忽略表证存在** — 患者明明怕冷/怕风却直接治里。为什么错：有表不解表，百病难除——表不解，内伤诸证皆不得愈
8. **完谷不化继续攻邪** — 把严重里阳虚衰的完谷不化当成普通腹泻。为什么错：这是里阳虚的最高警报，必须立即停攻→四逆汤回阳
9. **三日无效归咎剂量不够而非反思辨证** — 「再吃吃看」「剂量加大」。为什么错：经方三日见功，三日无效说明辨证有误，应重新审视病→脉→证
10. **以五行学说解释经方方证** — 将麻黄汤解为「金克木」、桂枝汤解为「木生火」。为什么错：胡希恕/冯世纶/张庆军明确反对五行解释经方，方证对应是八纲逻辑而非五行生克

### 核心分歧

**最大根本分歧——六经的实质是什么？**

- **胡希恕/冯世纶/张庆军/马家驹**：六经 = 八纲（阴阳表里寒热虚实）在病位上的归类。六经不是经络，是一种疾病分类框架
- **刘渡舟/院校体系**：六经 = 经络脏腑的生理病理反映。太阳即膀胱/小肠，阳明即胃/大肠等
- **黄煌**：六经是方证分类框架，更接近临床操作端

**第二分歧——辨证的入口是什么？**

- **张庆军**：脉诊为总开关（先定虚实再议其他）
- **黄煌**：望诊定体质（30秒体质扫描先于一切）
- **胡希恕/冯世纶**：问诊定病位+病性（表/里/半表半里 + 阴/阳）
- **许家栋**：腹诊为先（消化病/腹证的证据权重最高）

**第三分歧——加减还是合方？**

- **张庆军**：尽量合方不加减
- **黄仕沛**：原方原量反对加减
- **刘渡舟**：经方为主不拘原方，可灵活化裁
- **许家栋**：原方为体、加减为用（≤3味，有据可依）

**但在最高层达成一致**：所有学派最终都统一在**方证对应**——即「有是证用是方」。这是九大学派的最大公约数。

## 诚实边界

- 信息截止 `2026-06-15`。经方行业核心理论（伤寒论原文/六经辨证/方证对应）非常稳定，数十年不变。但个体临床经验和学派内部的新发展持续更新。
- 调研基于11位经方家的公开学术档案和知识库笔记（共7个文件，2182行）。胡希恕系（胡希恕/冯世纶/张庆军/马家驹/许家栋，共5人）权重最大。刘渡舟系（1人）和黄煌系（1人）为补充视角。非胡希恕系的经方声音（如院校体系、岭南伤寒派、日本古方派）覆盖不足。
- 成功案例远多于失败案例。知识库中的医案全为正向疗效记录，真实的临床失败率和辨证误判率无从得知，存在显著的幸存者偏差。
- 脉诊和腹诊的大量隐性知识（手感、力度判断、指下感觉）纯文本无法捕捉。腹诊的「按之濡」「按之硬」「胸胁苦满」都是高度依赖手感经验的判断。
- **master skill 不能替代真实临床经验。** 涉及具体患者的诊断和处方，必须由持证中医师完成。本 skill 仅供学习参考和临床思维辅助。
- 九大学派存在根本性理论分歧（六经实质之争），本 skill 如实呈现分歧，不强行统一或评判优劣。

### 6. Glossary — 核心术语

高频术语 Top 20：

| 术语 | 含义 | 易混淆于 |
|------|------|---------|
| **方证对应** | 根据具体证候群选择对应方剂，有是证用是方 | 「对病选方」——属于反模式 |
| **六经辨证** | 以太阳/少阳/阳明/太阴/少阴/厥阴六经为纲的辨证体系 | 「十二经络辨证」——胡希恕派明确区分 |
| **独证** | 能单独锁定方剂的特异性症状组合（如「喉中水鸡声」=射干麻黄汤） | 「主诉」——独证是鉴别性症状 |
| **腹证** | 通过腹诊获得的客观体征（心下痞/胸胁苦满/少腹急结等） | — |
| **水分证** | 水饮内停证，舌诊金标准为舌体胖大/苔水滑 | 「湿证」——水分证特指经方体系的水饮 |
| **痞满燥实** | 大承气汤四大主症——痞（满闷）/满（胀满）/燥（大便干）/实（拒按） | — |
| **方人** | 黄煌概念——每种方剂对应的体质/人群特征 | 「体质」——方人特指某方对应体质 |
| **合病合方** | 两经或以上同时发病 → 将对应方剂直接叠加 | 「加减化裁」——张庆军明确反对以加减代合方 |
| **病脉证治** | 张庆军四步辨证法——定六经（病）→切脉（脉）→抓独证（证）→处方（治） | — |
| **方证三角** | 许家栋三维辨证——现代病名+六经辨证+经方方证 | — |
| **完谷不化** | 大便中排出未消化食物——里阳虚衰危候，最高警报 | 「消化不良」——完谷不化是严重病理状态 |
| **有表先解表** | 只要存在表证（怕冷/怕风/无汗/喷嚏/流涕），优先解表 | — |
| **效不更方** | 治疗有效即守方不变 | — |
| **中病即止** | 药力到位后立即停药，防止过剂伤正 | — |
| **但见一证便是** | 小柴胡汤使用原则（第101条）——见到一个核心指征即可使用 | — |
| **保胃气存津液** | 六经治疗总原则——攻邪时防伤胃气，扶正时保护津液 | — |
| **方阵** | 许家栋体系概念——同类经方的集群（麻黄方阵/柴胡方阵等） | — |
| **解肌法** | 桂枝汤类方治疗大法，区别于辛温发汗 | 「发汗」——解肌是调和营卫，非强力发汗 |
| **辛开苦降** | 泻心汤类方的核心配伍法则——半夏干姜辛开+黄连黄芩苦降 | — |
| **经方三日见功** | 许家栋疗效标准——服药后2-3天内应有明显正向反应 | — |
