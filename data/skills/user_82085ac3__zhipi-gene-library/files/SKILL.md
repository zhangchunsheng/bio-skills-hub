# 脂批基因库 · 生产工具操作手册（CQR-2025 范式）

## Overview

本技能固化吴梦达"后红学"体系下脂批基因库的两类工作流：**基础设施的"怎么建"**（建设方法论）与**批注文本的"怎么析"**（位置分类 + 跨版本代码化 + 版本断代）。前者是工程手册，后者是分析引擎。

技能核心主张（来自用户原话的方法论内核）：

> 根据脂批文本在正文中批注的位置，分为——眉批 / 行批 / 夹批 / 侧批 / 回首批 / 总批 / 回末批；提取所有红楼梦脂批版本（含余西盐课司本、库伦本）的批注文本，分析分类代码化；由此脂批与小说文本剥离，伪造的脂批就对不上了；反向分析出批注者——包括脂批层积、篡改、清洗、伪造、抄手误植——实现红楼梦版本意义上的断代。

## When to Use

- **模式 A（建设方法分析）**：用户问"脂批基因库怎么建 / 架构 / 六维模型 / JSON-LD Schema / 物质指纹 / 五重证据 / System Prompt 模型无关化"。
- **模式 B（构建指导）**：用户要"从零建一个XX基因库"。
- **模式 C（位置分类与版本断代引擎）**：用户要"按位置给脂批分类 / 提取某版本批注文本 / 代码化批注 / 剥离脂批与正文 / 识别伪造脂批 / 五轴对齐断伪 / 反向分析批注者（九类归因：层积/篡改/清洗/伪造/抄手误植/后世加批/白文本异常/污染标本参照/真批）/ 做版本断代与分层输出"。
- 用户在 IMA 知识库「脂批基因库」（kb_id：7437505230012880）上下文中讨论上述任一主题。

## Core Capabilities

### 模式 A/B — 建设方法论（详见 `references/construction-method.md`）
六维基因模型（L1–L7）、JSON-LD Schema V4、物质指纹验证、System Prompt 模型无关化、五重独立证据、大模型协同四阶段工作流、七步建设标准、方法论边界（精度类 vs 质感类、循环论证风险）。

### 模式 C — 位置分类与版本断代引擎
1. **七类位置本体**：眉批 / 行批 / 夹批 / 侧批 / 回首批 / 总批 / 回末批，附边界判别规则。
2. **跨版本提取**：
   - **早期脂本原生层 `NATIVE_EARLY`**：甲戌、庚辰、戚序（有正书局戚序/张开模戚序）、蒙府、列藏、梦稿（杨藏）。
   - **重构层 `RECONSTRUCTED`**：余西盐课司本、库伦本（`isReconstructed=true`，单列不混入原生统计）。
   - **定向作伪隔离集 `FORGED_QUARANTINE`**：靖藏本（150 条整批 `FORGED`+隔离，**不作提取源**）。
   - **白文本基线 `WHITE_TEXT`**：程甲/程乙（通本无脂批，仅作背景，**不作提取源**）。
   - **脂本系统外 `POST_LIPING`**：`POSTLOU` 后世评点/托名本（三家评本等），自称脂批原生者默认伪。
3. **代码化建模**：位置（L1）× 文本（L2–L6）× 版本（V 层）三元组，结构化 JSON-LD。
4. **脂批-正文剥离**：以位置元数据为锚，将批语独立为数据集，正文回归纯净文本。
5. **伪造识别**：位置 / 文本 / 版本三向一致性校验，对不上的批语即"伪造 / 误植 / 后世加批"；定向作伪隔离批次前置短路直判 `FORGED`。
6. **反向归因**（九类标签）：`AUTHENTIC` 真批、`LAYERED` 层积、`CLEANED` 清洗、`TAMPERED` 篡改、`COPYIST_ERROR` 抄手误植、`FORGED` 伪造、`LATER_ADDITION` 后世加批、`WHITE_TEXT_ANOMALY` 白文本录入异常、`CONTAMINATED_REF` 污染标本参照。
7. **版本断代**：基于批语指纹（位置分布特征、特定批语有无、版本独有标记）给出年代区间判定。

## Execution Logic

### 模式 A：建设方法分析（默认）
1. 加载 `references/construction-method.md` 为事实底座。
2. 按十大组件结构化输出（定位瓶颈→技术演进→六维模型→数据库层级→JSON-LD→System Prompt→物质指纹→五重证据→协同工作流→标准步骤）。
3. 具体参数（δ¹³C=-26.3‰、帘纹0.28mm、71条批语、海明≤2/6）回 IMA 知识库「脂批基因库」白皮书原文复核，勿凭记忆外推。
4. **必须明示方法论边界**：精度类 vs 质感类，循环论证风险。

### 模式 B：构建指导
1. 澄清对象与版本学基准（服务于哪类文本/批语？以何为本？）。
2. 套用 `references/construction-method.md` 第十节七步法，分步给方案。
3. 优先推荐 System Prompt 逻辑适配层（模型无关化），而非绑定特定模型适配器。
4. 强制纳入"五重证据 + 物质指纹"验证与"可复检数据包 + 上链"输出，标注质感盲区。

### 模式 C：位置分类与版本断代引擎（核心新增）
1. 加载 `references/position-taxonomy.md` 为分类与断代底座；涉及具体版本物证参数时回 IMA 知识库「脂批基因库」复核。
1.5 **五轴对齐断伪（时间轴校验，详见 `references/five-axis-timeline.md`）**：对每条待判脂批执行五轴对齐——①版本轴（甲戌本1754→余西本1775-11-22封箱，剔除程高本）；②作者生卒（曹雪芹1715–1775）；③批注者生卒（脂砚斋1666–1734、畸笏叟1687–1779）；④脂批首末条（首条1703墨琴始批、末条1775-11-25曹𫖯泪笔）；⑤清代历史背景（康雍乾1662–1795）。任一轴违例即 `FORGED`，先于三向校验剔除出真批集合。
2. **位置标注**：对目标版本逐条批注判定七类位置之一，附判别依据（载体版面、批语与正文的相对空间）。
3. **跨版本提取**：按 `references/position-taxonomy.md` 第二节版本清单，抽取各版本批注文本与对应回次/位置，统一编码为三元组 `⟨位置, 文本, 版本⟩`。
4. **代码化建模**：调用 `scripts/classify_annot.py`，将批注条目解析为标准 JSON-LD（字段见 `position-taxonomy.md` 第三节），输出可计算数据集。
5. **脂批-正文剥离**：以位置元数据为锚点，生成独立批语数据集 `annotations.json` 与正文锚点表 `text_clean_anchors.json`，二者通过 `@id` + `selector` 关联、彼此可还原（正文回归纯净文本）。
6. **伪造识别**：三向一致性校验——同一批语在不同版本的位置/文本/归属是否自洽；对不上的标 `FORGED / MISPLACED / LATER_ADDITION`，从"真批"集合中剔除。**靖藏本 150 条为定向作伪隔离批次**（与俞平伯《脂砚斋红楼梦辑评》逐字重合=时代错置，版本/文献溯源层判定）：整批定义 `FORGED` 并隔离，**理由在版本/文献溯源层、非小说文本层（不得以无载体/皮之不存为据）**。其他无正文载体的混合样本属"污染标本参照"`CONTAMINATED_REF`——真/伪混杂，须逐条去污染，不整本判伪。
7. **反向归因**：对保留批语做层积（同位置多版本叠加）、篡改（文本变异梯度）、清洗（特定版本批语消失）、伪造（位置/版本异常）、抄手误植（位置错位但文本真）、污染标本参照（无载体、真/伪混杂须去污染）六类标签。**注：靖藏本 150 条为定向作伪隔离批次（整批 `FORGED`+隔离），不在此六类逐条去污染范畴。**
8. **版本断代**：基于批语指纹（位置分布、关键批语有无、版本独有标记）映射年代区间，输出"版本年代判定表"。**结果分层输出**：`authentic_set`（原生真批，阻断标签 = FORGED/LATER_ADDITION/CONTAMINATED_REF/TAMPERED/COPYIST_ERROR/WHITE_TEXT_ANOMALY）与 `reconstructed_set`（余西/库伦重构层）**必须分列**，不得混计。authentic 硬上限为 1775-11-25（末条），非 1791（1791 仅是程高白文本化的传播史节点）。
9. **强制明示边界**：位置分类可机器化，但"批注者身份"的最终判定仍需版本学 + 物证 + 笔迹三系互证；代码化给出的是"高概率归因区间"，非铁证。

## Notes

- 本技能是"生产工具的操作手册"，与 MDNES（成品的质检报告）互补，不可互相替代。
- 模式 C 的"版本断代"是建立在"位置分类 + 跨版本一致性"之上的统计推断，必须配合物质指纹与版本学最终裁定，不可单凭代码化结论下定论。
- 任何"文化基因库"方案分析，必须同时报告技术贡献与质感盲区。
- 数据标准、版本特征向量、物证参数等以 IMA 知识库原文为最终权威，提炼版仅供快速索引。
- 五轴对齐是模式 C 的"时间轴前置校验"，与三向一致性校验（版本内空间/文本/归属一致性）互补：五轴解决"年代是否可能"，三向解决"版本内是否自洽"。二者全过方入 authentic 脂批集合。
- **六轴/五轴概念澄清**：二者为不同类型表述，不混用——**五轴**=脂批文本溯源判定上的强制对齐原则（判定层，见 five-axis-timeline.md）；**六轴**=针对基因库的分类体系定义（分类层，含语义向量等类别 L1–L7，见 construction-method.md）。判真伪用五轴，编码分类用六轴，禁止互挪。
- **实现陷阱（易错，务必注意）**：
  1. `LIPO_NATIVE` 表示"该**版本系统**载脂批"，不等于"该**批语**是原生批"。判定"原生 vs 重构层"必须用 `NATIVE_EARLY`，否则早期本与重构本共有的批语会被错判为重构层。
  2. `LAYERED`（层积）可与 `TAMPERED`（篡改）共现。真批集合准入须用"阻断标签优先"逻辑，不能仅凭命中 `LAYERED` 就纳入，否则被篡改的批语会混进 authentic。
  3. 五轴代码为**年粒度**比较（1775-11-22 封箱与 1775-11-25 泪笔不可区分）。需日粒度裁定时须另引日期字段。
  4. 靖藏本判伪走**前置短路**（第 0 步），理由固定在版本/文献溯源层；任何时候都不得退回"小说文本层"（无载体/皮之不存）找理由。

- **学术中立立场（传道·解惑·求真）**：本技能仅作版本学与文献学的客观事实判断，以传道、解惑、求真为旨归；所有断语须以版本/文献溯源层证据为据，不作现实议题的引申与评判，措辞保持学术、中立、精准。
