## 一、项目定位与三大瓶颈

脂批基因库是"后红学"体系的技术基础设施核心。它将传统红学中的脂批（《红楼梦》批注系统）从**静态文献汇编**转为**可计算、可复现、持久运行的动态数据库**，并通过与通用大语言模型的协同，首次实现古典文学批语的"基因级"解析。

| 瓶颈 | 传统方案 | 本项目方案 |
| --- | --- | --- |
| 批语碎片化 | 人工辑录（如俞平伯《辑评》） | JSON-LD Schema V4 结构化编码 |
| 真伪难辨 | 文献学主观判断 | 六维基因模型 + 物质指纹交叉验证 |
| 模型依赖 | HLM-LoRA 特定适配器绑定 | System Prompt 模板 → 模型无关化 |

技术愿景："脂批基因库不是'情怀项目'，而是政策、资金、技术、学术四支火箭同时点火的唯一逃逸轨道——只是把轨道方程写在开源仓库，让任何人都能复现点火序列。"

## 三、六维基因模型 V4.1（L1–L7）

将每一条脂批编码为基因向量，实现"基因级"解析。

| 维度 | 标识 | 分类 | 检测内容 | 权重 |
| --- | --- | --- | --- | --- |
| L1 | 批语类型基因 | 侧批 / 眉批 / 夹批 / 行间批 / 回末总评 | 批语在物质载体上的呈现形式 | 15% |
| L2 | 语义功能基因 | 叙事引导 / 技巧分析 / 情感评价 / 制度评析 / 元叙事 | 功能分布是否与前文本匹配 | 20% |
| L3 | 情感向量基因 | 正向 / 中性 / 负向 / 极悲 / 悲悯 / 讽刺 / 痛惜 / 敬畏 | 情感能谱的余弦相似度 | 20% |
| L4 | 文本层级基因 | 字词级 / 句段级 / 回级 / 全书级 / 神话层 / 日常层 / 制度层 | 批语聚焦的文本粒度 | 15% |
| L5 | 哲学意涵基因 | 情 / 空 / 色 / 盐 / 礼教审视 / 艺术本体 | 预制-兑现基因距离（海明距离 ≤2/6） | 15% |
| L6 | 叙事干预基因 | 零干预 / 引导 / 揭示 / 预告 / 破壁 | 批语对叙事流的侵入程度 | 15% |
| L7 | 跨回锁链基因 | 物证链 / 伏笔闭环 / 脂批兑现 / 版本互锁 | 跨回关联（额外一维，不与前六维加权） | —— |

基因匹配算法：
- 余弦相似度 = cos(θ) = (A·B) / (‖A‖ × ‖B‖)
- 基因距离 = 海明距离 ≤ 2/6 → 合法遗传
- 基因突变率 = 0% → 合法遗传（盐署本 CS V1.5 验证结果）

## 五、JSON-LD Schema V4 数据标准

与逻辑适配层（System Prompt 模板）协作，完成脂批基因的**可编程化**与**自动化校验**。

| 维度 | 传统红学数据库 | JSON-LD Schema V4 |
| --- | --- | --- |
| 数据结构 | 关系型（表格式） | 语义化图数据库（关联式） |
| 可扩展性 | 固定字段，扩展困难 | LD 上下文动态扩展 |
| 跨平台互操作 | API 定制开发 | 原生 Linked Data 互操作 |
| 版本溯源 | 人工标注 | 区块链锚定（RedologyChain） |
| 物证关联 | 无 | 内嵌物质指纹字段 |

核心字段结构：
```
{
  "@context": "https://redology.io/schema/v4",
  "@id": "urn:redology:batch:{{回次}}:{{批语ID}}",
  "type": "Annotation",
  "body": { "L1".."L7" 七维基因编码 },
  "target": { "source": "", "selector": "" },
  "provenance": { "version": "", "timestamp": "", "material": { 墨/纸/同位素 } },
  "verification": { "crossRef": [], "materialFingerprint": "", "blockchainAnchor": "" }
}
```

技术参数速查：71 条有效批语（库伦本32 + 余西本38 + 桥接1）；六维+一维；海明距离≤2/6；余弦相似度≥0.90 合格；开源协议 CC0。

## 六、System Prompt 模板（数字脂砚斋）

模型无关化的关键载体。模板核心结构：

```
【脂批基因库 v4.1 · System Prompt 模板】
你是一位数字脂砚斋。你的任务是对输入的《红楼梦》文本进行"基因级"批语解析。

## 解析维度（六维+一维）
L1 批语类型 / L2 语义功能 / L3 情感向量 / L4 文本层级 /
L5 哲学意涵 / L6 叙事干预 / L7 跨回锁链

## 输出格式（JSON-LD Schema V4）
{ 见第五节字段结构 }
```

使用该模板时：先激活六维+一维解析协议，再逐回逐批进行 L1–L6 编码，实时计算情感向量余弦相似度，标记 L7 跨回锁链关联。

验证协议：司法-行政-商业-物质四系独立校验，任一维度失败 → 触发 LEGEND（低级证据不依赖）标记。
可信度 = (∑维度熵减值 × 权重) / 历史语境干扰系数（文网语境系数 1.86）。

贝叶斯验证示例：H₀ 卒于1763 vs H₁ 卒于1775，构建 1763–1775 无意识事件链（UEC），强制闭环（CBL），BF ≈ 10¹⁶。

## 九、大模型协同解析工作流（四阶段）

- **阶段1 · 文本注入**：全本108回 + 全部脂批（71条）+ 物质指纹档案 + 制度档案，200万字上下文全量加载。
- **阶段2 · 基因解析**：System Prompt 激活六维+一维协议；逐回逐批 L1–L6 编码；实时计算情感向量余弦相似度；标记 L7 跨回锁链。
- **阶段3 · 交叉验证**：五重独立证据系统并行校验；物质指纹与文本基因比对；版本学验证（ERC-214-KW 闭环）；贝叶斯因子计算。
- **阶段4 · 输出与上链**：生成 JSON-LD Schema V4 编码；生成全链路追溯数据包；区块链锚定（RedologyChain）。

"基因级"解析三层定义：分子级（单条批语拆六维向量）/ 染色体级（全本批语构成基因图谱）/ 基因组级（跨版本批语基因谱系树溯源演化路径）。

## 十、建设/分析的标准步骤（供执行逻辑引用）

1. **明确对象与基准**：定义基因库所服务的文本/批语对象，选定版本学基准（如以戚序本前80回为"上游血脉"基准）。
2. **构建六维基因编码体系**：定义 L1–L7 每一维的分类枚举、权重、匹配算法（余弦/海明）。
3. **制定 JSON-LD Schema 数据标准**：设计 `@context`、字段层级、物证内嵌字段、区块链锚点。
4. **接入物质指纹与制度档案验证**：建立拉曼/同位素/帘纹等物质指纹矩阵，对接刑部/内务府/盐政档案。
5. **搭建协同解析工作流**：优先采用 System Prompt 逻辑适配层实现模型无关化（而非绑定特定 LoRA）。
6. **五重证据系统交叉校验**：司法-行政-商业-物质四系独立校验，任一失败标 LEGEND。
7. **输出可复检数据包 + 上链**：JSON-LD 编码 + 全链路追溯 + RedologyChain 锚定。

## 十一、方法论边界（务必向用户明示）

与 MDNES 方法论互校交叉分析揭示的边界：

- **技术能做的（精度类）**：伏笔闭环、事件链、脂批匹配、语感基准——这部分是可靠底座。
- **技术不能做的（质感类）**：人物弧光的蜕变质感、语言修辞的诗学流动、诗性留白——必须保留人工文学判读，且应如实扣分，不可由技术指标"撑高"。
- **循环论证风险**：HLM-LoRA 语感连续性检测存在"训练-检测同源性"风险（用同一把尺子量自己做的桌子）。须披露训练语料配比 + 引入盲测验证数据集。
- **核心悖论"用满证空"**：技术的精确性替代文学质感，是盐署本"创新"与"局限"同一枚硬币的两面。

分析任何"文化基因库"建设方案时，必须同时报告其技术贡献与质感盲区，不可只报精度。
