# 五轴对齐断伪框架 · 参考手册

> 模式 C（位置分类与版本断代引擎）的**时间轴前置校验**专用底座。
> 锚点经用户校正（2026-08-04）：**首条 authentic = 1703 墨琴始批；末条 authentic = 1775-11-25 曹𫖯泪笔；剔除程高本；版本轴 = 甲戌本 1754 → 余西本 1775-11-22 封箱**。
> 凡涉及具体物证参数/版本特征向量，一律回 IMA 知识库「脂批基因库」（kb_id：7437505230012880）白皮书原文复核，勿凭记忆外推。

## 〇、核心命题

一条脂批要成立，必须**同时落进五条时间/身份轴的窗口**。任一轴违例 → 自动出列为 `FORGED`（伪批）。

**靖藏本 150 条 = 定向作伪 · 定义伪批 · 隔离（不属 `CONTAMINATED_REF`）**：其传世 150 条批语经**版本/文献溯源层**判定为定向作伪产物——文本与俞平伯《脂砚斋红楼梦辑评》逐字重合（现代辑评本），构成"时代错置"（anachronism）。故整批定义为 `FORGED`（伪批）并予以**隔离**（quarantine），不进入 authentic 脂批集合、不做逐条去污染。**判定理由在"版本/文献溯源层"（辑评源），绝不在"小说文本层"——不得以"无正文载体 / 皮之不存"作为判伪依据。**

**`CONTAMINATED_REF`（污染标本参照）** 仅用于其他"无正文载体、真/伪混杂、须逐条去污染"的混合样本，**不适用于靖藏本 150 条**。

五轴一拉齐，真伪造批没有藏身缝。

> **伪批必现**：不是"大概率"，而是"结构性必然"——只要伪造批的纪年、版本、批注者署名、指涉事件任一维度与五轴冲突，校验即挡出。

## 一、五轴定义与修正锚点

| 轴 | 名称 | 修正锚点（来自用户 2026-08-04） | 违例含义 |
| --- | --- | --- | --- |
| **轴①** | 文本版本时间轴 | 甲戌本 **1754** → 余西本 **1775-11-22** 封箱；**程高本（程甲1791/程乙1792）为白文本，整体系剔除**出 authentic 脂批源 | 版本落在非脂本系统（程高白文本/后世评点本）、或无正文载体、或纪年 > 余西封箱 → 不 authentic |
| **轴②** | 作者生卒年 | 曹雪芹 **1715–1775**（KB 持 1775 真死说） | 批语纪年或指涉事件晚于作者卒 1775 → 不可能 |
| **轴③** | 批注者生卒年 | 脂砚斋（曹墨琴）**1666–1734**；畸笏叟（曹頫）**1687–1779**；墨香 **1740–1790**（传播节点） | 署名批注者生卒不覆盖该批纪年 → 伪托 |
| **轴④** | 脂批首条 / 末条 | 首条 = **1703 墨琴始批**；末条 = **1775-11-25 曹𫖯泪笔**；终界线 = 余西封箱 1775-11-22 | 纪年 ∉ [1703, 1775-11-25] → 超窗口 |
| **轴⑤** | 清代历史背景 | 康熙(1662–1722) / 雍正(1723–1735) / 乾隆(1736–1795)；两淮盐课亏空案、1775 封箱、文网语境 | 纪年或指涉事件溢出康雍乾三朝（如嘉庆1796+）→ 不可能 |

**关键收口**：末条 1775-11-25 曹𫖯泪笔，压在余西封箱 1775-11-22 之后三日，二者共同构成 authentic 脂批的**硬终界**。此后（1791 程高刊印起）所见的"脂批"（如三家评本等脂本系统外的评点/托名本）一律属商业层 / 后世加批 / 伪托；程高本本身为白文本，不载脂批，故"程高独有批"这一品类在现实里为空集。

## 二、对齐判定逻辑

对每条待判脂批，输入 `{year, version, annotator?, ref_year?, has_carrier?}`。

**第 0 步（前置短路 · 先于五轴）**：若 `version ∈ FORGED_QUARANTINE`（当前 = `JINGZANG`），**立即返回 `FORGED` + 隔离**，不进入五轴逐轴判定。
理由记为「版本/文献溯源层：批语与俞平伯《脂砚斋红楼梦辑评》重合 = 时代错置（定向作伪）」，`axes` 置空、`contaminated=False`。
此设计确保判伪理由**只出自版本/文献溯源层**，从流程上杜绝退回"小说文本层"（无载体/皮之不存）找理由。

**第 1 步（五轴逐轴判定）**：

- **轴①版本轴** = `version ∉ {程甲,程乙}` AND `year ≤ 1775`
  - 注：靖藏本 150 条（JINGZANG）已在"版本/文献溯源层"判定为定向作伪（与俞平伯《脂砚斋红楼梦辑评》重合），整批 `FORGED`+隔离，**不**走 `CONTAMINATED_REF` 分支；其判伪理由非"无正文载体"（小说文本层），而是 辑评源的时代错置。
- **轴②作者生卒** = `year ≤ 1775` AND（`ref_year` 若存在则 `ref_year ≤ 1775`）
- **轴③批注者生卒** = 若指明批注者则其生卒覆盖 `year`；未指明本轴不否决
- **轴④首末条** = `1703 ≤ year ≤ 1775`
- **轴⑤清代历史背景** = `year` 落康雍乾三朝（1662–1795），且 `ref_year` 同约束

**第 2 步（裁定）**：

```
if version ∈ FORGED_QUARANTINE:          # 第0步已短路
    verdict = FORGED/伪批（定向作伪·整批隔离）
failed_axes = [k for k, v in axes if not v]
contaminated = not has_carrier           # 仅对非隔离批次生效
verdict = CONTAMINATED_REF               if contaminated
          else FORGED/伪批               if failed_axes
          else AUTHENTIC/真批
```

> **年粒度限制**：代码以「年」为最小比较单位（`LAST_ANNOT_YEAR = YUXI_SEAL_YEAR = 1775`），故 1775-11-22 封箱与 1775-11-25 泪笔在轴①/轴④中不可区分。若需日粒度裁定（如判断某批是否压在封箱之后），须另引日期字段，不能依赖当前年比较。

代码实现见 `scripts/classify_annot.py` 的 `axis_check()`，运行 `python classify_annot.py --axis-check` 看内置演示。

## 三、实例：伪批必现

| 样本 | 输入 | 违例轴 | 判定 |
| --- | --- | --- | --- |
| 真批·首条 | yr=1703, 甲戌, 脂砚斋 | 无 | AUTHENTIC |
| 真批·末条 | yr=1775, 余西, 畸笏叟, ref=1775 | 无 | AUTHENTIC（曹𫖯泪笔） |
| 伪·三家评本 | yr=1840, 三家评本(王希廉), POSTLOU | ①②④⑤（非脂本系统 + 超作者/末条/朝代） | FORGED |
| 伪·托名 | yr=1740, 庚辰, 脂砚斋 | ③（1740 > 脂砚斋卒1734） | FORGED |
| 定向作伪·靖藏本150条 | yr=1959(转录), 靖藏, 不明 | 版本/文献溯源层违例（批语=俞平伯《脂砚斋红楼梦辑评》重合=时代错置） | FORGED + 隔离（整批，不逐条去污染；理由非小说文本层） |

> **靖藏本 150 条的压力测试（定向作伪·隔离视角）**：判伪理由**不在**小说文本层（不得以"无正文载体 / 皮之不存"为据），而在**版本/文献溯源层**——150 条文本与俞平伯 年《脂砚斋红楼梦辑评》重合，而该辑评为  年现代出版物，构成"时代错置"（anachronism），证其为定向作伪产物。故整批定义为 `FORGED` 并**隔离**（quarantine），不进入 authentic 脂批集合，也不做逐条去污染。`CONTAMINATED_REF`（污染标本参照、须逐条去污染）仅用于其他无载体混合样本，不适用于此批次。

## 四、与模式 C 三向一致性校验的关系

| 维度 | 五轴对齐 | 三向一致性校验 |
| --- | --- | --- |
| 解决的问题 | **年代是否可能**（时间/身份窗口） | **版本内是否自洽**（位置/文本/归属一致性） |
| 锚点来源 | 版本史 + 生卒年 + 封箱/刊印节点 | 同 `annot_id` 跨版本比对 |
| 位置 | 前置（先挡伪） | 后置（再分归因） |
| 输出 | `FORGED`（定向作伪隔离批次前置短路，或任一轴违例）/ `CONTAMINATED_REF`（无载体混合样本，须逐条去污染）/ `AUTHENTIC` | `AUTHENTIC/LAYERED/CLEANED/TAMPERED/COPYIST_ERROR/FORGED/LATER_ADDITION/WHITE_TEXT_ANOMALY/CONTAMINATED_REF` |

**二者互补、不可互相替代**：五轴解决"时间上能不能存在"，三向解决"版本流传中是否自洽"。五轴全过 + 三向全过，方入 authentic 脂批集合。

> **边界声明**：
> 1. 轴③ 批注者生卒是 KB 内假说（墨琴=脂砚斋、曹𫖯=畸笏叟），非学界定论；五轴断代强度取决于你接受这套人物网络的程度。
> 2. 轴④"末条 1775-11-25"是 KB 内锚；若采用"畸笏叟乾隆朝仍在批"异说，轴④窗口后移——**框架不变，锚点可调**。
> 3. 五轴是"时间窗口"校验，不解决"版本自身纪年是否匹配该版本"（如 1703 年却标甲戌本）——那是模式 C 版本断代指纹的职责。
> 4. 代码化给的是"高概率归因区间"，铁证仍须物证（纸墨/帘纹/碳十四）+ 版本学三系互证。
