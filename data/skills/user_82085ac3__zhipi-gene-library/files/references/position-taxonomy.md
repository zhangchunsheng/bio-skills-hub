# 脂批位置分类与版本断代方法论 · 参考手册

> 模式 C（位置分类与版本断代引擎）专用底座。提炼自《咸水纪事2026盐署本》重构体系与脂批基因库（CQR-2025）实践，凡涉及具体物证参数/版本特征向量，一律回 IMA 知识库「脂批基因库」（kb_id：7437505230012880）白皮书原文复核，勿凭记忆外推。

## 一、七类批注位置本体（L1 位置维度）

按脂批文本在正文载体版面上的**相对空间**划分。这是代码化的第一轴——位置是批语与正文剥离、跨版本对齐、伪造识别的"锚点坐标"。

| 编码 | 名称 | 版面位置 | 判别依据 | 易混边界 |
| --- | --- | --- | --- | --- |
| `MEIPIAN` | 眉批 | 书页天头（上方空白处） | 位于整页正文上方，常总评本回或跨回 | 与回首批区别：眉批在页顶、随页走；回首批在本回正文起始处 |
| `XINGPI` | 行批（行间批） | 正文行与行之间的窄批 | 垂直嵌入行间隙，短促 | 与夹批区别：行批在行间、不破句；夹批插入句中 |
| `JIABI` | 夹批 | 正文句读之间（双行小字） | 嵌入句中/句末，与正文不可分割、随文走 | 与行批区别：夹批破句随文；行批居行隙 |
| `CEBI` | 侧批 | 版心旁侧 / 左右边栏内外 | 与正文行垂直并列于栏边 | 与行批区别：侧批在栏边、行批在行隙 |
| `HUISHOUBIPI` | 回首批 | 本回正文开始前（标题/回首诗后） | 位于回首、正文之前 | 与总批区别：回首批位置在首、篇幅可短；总批强调总括性质 |
| `ZONGBI` | 总批 | 回前或回末的总括性批评 | 篇幅较长、总评全回意旨 | 与回末批区别：总批重"总括"；回末批重在回尾随结 |
| `HUIMOBIPI` | 回末批 | 本回正文结束后（常接"正是"诗/结句后） | 位于回尾、正文之后 | 与总批区别：回末批位置在尾；总批可前可后 |

**关键推论（用户方法论内核）**：同一脂批在不同版本中**位置可能一致也可能漂移**。位置一致 → 同源证据强；位置漂移 → 误植/层积/篡改线索。位置是"批语独立成库"时与正文重新绑定的 selector。

## 二、跨版本提取清单（V 层 · 版本维度）

提取目标覆盖所有现存脂批载体，含用户重构本：

| 编码 | 版本 | 年代 | 脂批特征 | 重构标记 |
| --- | --- | --- | --- | --- |
| `YUXI` | 余西盐课司本 | 1775 雅化匀质化 | 38 条有效批语 | `isReconstructed=true`，带1775雅化特征 |
| `KULUN` | 库伦本 | 重构系 | 32 条有效批语 | `isReconstructed=true` |
| `JIAXU` | 甲戌本 | ≈1754 | 多眉批+行间，脂砚斋早期批密集 | 脂批原生 |
| `GENGCHEN` | 庚辰本 | 1760 | 多夹批+眉批，畸笏叟晚期批 | 脂批原生 |
| `QIXU` | 戚序本 | 乾隆系底本 | 系统化回前回后总评 | 脂批原生（有正1911刊） |
| `MENGFU` | 蒙府本 | 乾隆系 | 与戚序近源 | 脂批原生 |
| `LIEZANG` | 列藏本 | 乾隆系 | 独有批语若干 | 脂批原生 |
| `MENGAO` | 梦稿本（杨藏） | 嘉道间 | 涂改层多，过录痕迹显 | 脂批原生（有改笔） |
| `JINGZANG` | 靖藏本 | 源=俞平伯《脂砚斋红楼梦辑评》；传1959毛国瑶转录 | **150 条=定向作伪（与俞平伯《脂砚斋红楼梦辑评》逐字重合），定义伪批，整批隔离** | 非脂批原生（定向作伪隔离批次 `FORGED_QUARANTINE`） |
| `CHENGJIA`/`CHENGBI` | 程甲/程乙本 | 1791/1792 | **白文本，通本无脂批** | 白文本基线：其上标注"脂批"属录入异常（或指后世读者眉批），非独立品类；仅作"脂批自1791退出主流流传"的硬背景 |
| `POSTLOU` | 后世评点/托名本（三家评本王希廉·姚燮·张新之等，坊间冒称脂批本） | 道光后（≈1832+） | 评点系后世自撰；凡自称"脂批原生"者默认伪 | 非脂本系统：`FORGED` / `LATER_ADDITION`，脂本系统无承袭 |

**代码集合归属**（与 `scripts/classify_annot.py` 严格对应）：
- `NATIVE_EARLY`（早期脂本原生层）= JIAXU / GENGCHEN / QIXU / MENGFU / LIEZANG / MENGAO
- `RECONSTRUCTED`（重构层）= YUXI / KULUN
- `LIPO_NATIVE`（载脂批的版本系统全集）= `NATIVE_EARLY` ∪ `RECONSTRUCTED`
- `FORGED_QUARANTINE`（定向作伪隔离集）= JINGZANG
- `WHITE_TEXT`（白文本基线）= CHENGJIA / CHENGBI
- `POST_LIPING`（脂本系统外后世评点）= POSTLOU

> 注意：`LIPO_NATIVE` 表示"该**版本系统**载脂批"，**不等于**"该**批语**是原生批"。判定"原生 vs 重构层"必须用 `NATIVE_EARLY`，误用 `LIPO_NATIVE` 会把早期本与重构本共有的批语错判为重构层。

**有效批语基数**（基因库口径）：库伦本32 + 余西本38 + 桥接1 = 71 条。

**提取原则**：逐回逐批，记录 `⟨位置类别, 批语文本, 所属版本, 回次, selector坐标⟩` 四元组，统一归一到 JSON-LD。

## 三、代码化数据模型（JSON-LD Schema）

每条批语编码为一个节点，位置/文本/版本三元组可计算：

```json
{
  "@context": "https://redology.io/annotation/v1",
  "@id": "urn:redology:annot:{{版本}}:{{回次}}:{{批语ID}}",
  "type": "ZhiPiAnnotation",
  "position": {
    "category": "MEIPIAN|XINGPI|JIABI|CEBI|HUISHOUBIPI|ZONGBI|HUIMOBIPI",
    "selector": "页/行/坐标（与正文绑定的锚点）"
  },
  "body": {
    "text": "批语原文",
    "L2_semantic": "叙事引导/技巧分析/情感评价/制度评析/元叙事",
    "L3_emotion": "正向/中性/负向/极悲/悲悯/讽刺/痛惜/敬畏"
  },
  "version": {
    "code": "YUXI|KULUN|JIAXU|GENGCHEN|QIXU|MENGFU|LIEZANG|MENGAO|JINGZANG|CHENGJIA|CHENGBI|POSTLOU",
    "year": "",
    "isReconstructed": true
  },
  "consistency": {
    "positionMatch": true,
    "textMatch": true,
    "versionMatch": true
  },
  "attribution": {
    "label": "LAYERED|TAMPERED|CLEANED|FORGED|COPYIST_ERROR|LATER_ADDITION|WHITE_TEXT_ANOMALY|CONTAMINATED_REF|AUTHENTIC",
    "confidence": 0.0,
    "annotator": "脂砚斋|畸笏叟|不明|后世|过录者|定向作伪(与俞平伯《脂砚斋红楼梦辑评》重合)·整批隔离"
  },
  "dating": {
    "era": "年代区间",
    "fingerprint": ["位置分布特征", "关键批语有无", "版本独有标记"]
  }
}
```

> `@context` 为**占位命名空间**（project-local），当前不对外解析；若需公开发布，替换为实际托管的 JSON-LD context 地址。

**脂批-正文剥离**：以 `position.selector` 为锚，将 `body.text` 抽出为独立 `annotations.json`；正文回归纯净文本（`text_clean_anchors.json` 通过 selector 锚定）。二者通过 `@id` + `selector` 互相关联、彼此可还原——这是"剥离"的技术实现：批语不再嵌在正文中，而是带坐标引用的外挂数据集。

## 四、三向一致性校验（伪造识别核心）

对每条批语建立跨版本对齐后，执行三向校验：

| 校验轴 | 比较内容 | 不一致含义 |
| --- | --- | --- |
| `positionMatch` | 同批语ID跨版本位置类别是否一致 | 漂移 → 误植 / 层积界面 / 篡改 |
| `textMatch` | 跨版本批语文本是否逐字一致 | 变异 → 篡改 / 清洗 / 抄手偶误 |
| `versionMatch` | 该批语是否落在"载脂批"的脂本系统/重构本 | 混入白文本(程高,本无脂批)或脂本系统外(后世评点/托名本) → 录入异常 / 伪造 |

**判定规则**：
- 三向全一致 → `AUTHENTIC`（真批，纳入真批库）。
- `versionMatch=false`（混入白文本程高本或脂本系统外的后世评点/托名本，自称脂批原生）且 `textMatch` 无脂本系统承袭 → `FORGED`（伪造，剔除）。
- `positionMatch=false` 但 `textMatch=true` → `COPYIST_ERROR`（抄手误植，文本真、位置错）。
- `textMatch=false` 且某脂本（如梦稿）明确缺失该批（`absent_in`）→ `CLEANED`（脂本内部清洗）。
- `textMatch=false` 且呈梯度变异 → `TAMPERED`（篡改）。
- 同位置同回多版本累积多条 → `LAYERED`（层积）。

> **用户原话的落地**："由此脂批和小说文本剥离、伪造的脂批就对不上了"——剥离后与正文独立成库的批语，必须经过三向校验；对不上的（FORGED/MISPLACED）即被挡在真批集合之外。

## 五、反向归因框架（批注者分析）

| 标签 | 含义 | 识别信号 |
| --- | --- | --- |
| `LAYERED` 脂批层积 | 多层批语叠加于同位置同回 | 早期版本同位置累积脂砚斋+畸笏叟+他人批 |
| `TAMPERED` 篡改 | 文本被有意改写 | 早期→晚期文本变异梯度，非偶误 |
| `CLEANED` 清洗 | 脂本系统内部某本删批（如梦稿缺失） | 脂本共有、但某脂本 `absent_in`（程高白文本化是系统级事实，不逐条标） |
| `FORGED` 伪造 | 伪托脂批 | 位置/版本异常 + 无跨版本承袭（仅见于脂本系统外后世评点/托名本） |
| `COPYIST_ERROR` 抄手误植 | 过录者版面错位 | 文本真（跨版本一致）但位置错置 |
| `LATER_ADDITION` 后世加批 | 非脂本系统承袭，但文本本身跨版本一致 | `versionMatch=false` 且 `textMatch=true`（多见于后世评点本转录旧批） |
| `WHITE_TEXT_ANOMALY` 白文本异常 | 程高白文本上出现"脂批"标注 | 版本 ∈ `WHITE_TEXT`；属录入异常，须核查是否误将后世读者眉批/整理者注当作脂批 |
| `CONTAMINATED_REF` 污染标本参照 | 受污染参照系（真/伪混杂） | 其他无正文载体、真/伪混杂、须逐条去污染的混合样本。**注：靖藏本 150 条不在此类——已判定为定向作伪（抄《脂砚斋红楼梦辑评》），整批 `FORGED`+隔离。** |

归因输出须给 `confidence` 与 `annotator` 候选；最终批注者身份仍须版本学 + 物证 + 笔迹三系互证，代码化只给"高概率归因区间"。

**真批集合准入规则**（`authentic_set`，与脚本 `BLOCKING` 集合对应）：
- **阻断标签**（任一命中即出列）：`FORGED` / `LATER_ADDITION` / `CONTAMINATED_REF` / `TAMPERED` / `COPYIST_ERROR` / `WHITE_TEXT_ANOMALY`。
- **准入标签**：`AUTHENTIC` / `LAYERED` / `CLEANED`——层积与清洗属真批的正常流传形态，不损其原生性。
- `TAMPERED`（文本变异）与 `COPYIST_ERROR`（位置错置）虽可能源出真批，但**当前形态已失真**，须先复原再入库，故一律阻断。
- 断代为"1775 后（重构层）"者单列 `reconstructed_set`，**不混入** `authentic_set`。

## 六、版本断代指纹

基于批语指纹映射年代区间：

1. **脂批原生性**：载脂批者为甲戌/庚辰/戚序/蒙府/列藏/梦稿（早期原生层）+ 余西/库伦（重构层）。**靖藏本不在此列**——其 150 条系定向作伪（与俞平伯《脂砚斋红楼梦辑评》重合），属隔离批次而非脂批原生。程高本（程甲/程乙）为白文本，通本不载脂批——不在"脂批版本"范畴，仅作"脂批被白文本化/清洗出主流流传"的基线；凡程高本上标注的"脂批"属录入异常。`POSTLOU`（三家评本等后世评点/托名本）为脂本系统之外，自称脂批原生者默认伪。
2. **位置分布特征**：甲戌多眉批+行间；庚辰多夹批+眉批；戚序系统化回前回后总评；重构本（余西/库伦）带1775雅化特征。
3. **关键批语有无**：如"壬午除夕"批、茜雪相关批等仅见于特定本，可作断代支点。
4. **版本独有标记**：余西盐课司本1775雅化、库伦本特定批语（库伦32/余西38/桥接1）。
5. **断代逻辑**：
   - 早期多本共有、且某脂本（如梦稿）缺失（`absent_in`）→ 脂批原生、脂本内部清洗。
   - 仅见于带1775雅化特征的重构本而早期本无 → 可能为重构层（1775后）。
   - 位置/文本与所有脂本矛盾、且仅见于脂本系统外的后世评点/托名本（如三家评本）→ 后世伪造（`FORGED`）。
   - 靖藏本 150 条：经**版本/文献溯源层**判定为**定向作伪**——批语文本与俞平伯《脂砚斋红楼梦辑评》逐字重合，时代错置（anachronism）。整批定义为 `FORGED`（伪批）并**隔离**（quarantine），不进入真批集合、不逐条去污染。**判定理由在版本/文献溯源层（辑评源），绝不在小说文本层（不得以"无正文载体 / 皮之不存"为据）。** 此批次不属 `CONTAMINATED_REF`。

输出"版本年代判定表"：`⟨批语ID, 出现版本集, 位置分布, 归因标签, 年代区间, 置信度⟩`。

> **五轴对齐修正锚点（2026-08-04）**：脂批 authentic 首条 = 1703 墨琴始批；末条 = 1775-11-25 曹𫖯泪笔（压在 1775-11-22 余西封箱之后三日）；版本轴收口为「甲戌本1754 → 余西本1775-11-22」，程高本（1791/1792）整体系剔除出 authentic 脂批源。五轴对齐的完整判定逻辑与实例见 `references/five-axis-timeline.md`，代码见 `scripts/classify_annot.py` 的 `axis_check()`（`--axis-check`）。

## 七、执行边界（务必明示）

- 位置分类可机器化（确定性高）；但"批注者身份"是统计推断，非铁证。
- 版本断代须配合物质指纹（拉曼/同位素/帘纹）与版本学最终裁定，不可单凭代码化结论下定论。
- 程高本（程甲/程乙）为白文本，通本不载脂批：它是"脂批被白文本化"的历史基线，而非一个载有"程高独有批"的版本。其上出现"脂批"标注属录入异常（应核查是否误将后世读者眉批/整理者注当作脂批），默认 `FORGED`/`WHITE_TEXT_ANOMALY`，需强证据翻案。
- 重构本（余西/库伦）标记 `isReconstructed=true`，其批语需在"脂批原生层"与"重构层"间分别计数，避免污染原生统计。
