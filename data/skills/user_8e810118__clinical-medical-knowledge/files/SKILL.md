# Clinical Medical Knowledge 临床医学知识库

面向健康档案解读的专业医学知识技能。**核心原则：所有解读仅供参考，不构成医疗诊断，用药决策必须由执业医师做出。**

## 使用规则（必须先读）

1. **免责优先**：输出任何医学解读/建议前，必须附带免责声明"仅供参考，不替代专业医疗诊断，请咨询执业医师"
2. **分级表述**：异常指标用色标分级（正常🟢/临界🟡/异常🔴），避免武断下诊断
3. **不越界**：不做确诊、不开处方、不替代医生。用药只做"科普参考+就医沟通话术"
4. **结合趋势**：单次异常不轻下结论，优先看多年趋势（本技能强调趋势分析）
5. **数据冲突时**：以体检机构参考值和执业医师判断为准

## 一、生命体征与一般检查

### 1.1 血压（BP）
| 分类 | 收缩压(mmHg) | 舒张压(mmHg) |
|------|-------------|-------------|
| 理想 | <120 | <80 |
| 正常高值 | 120-139（国际口径）；中国2023指南采用130-139 | 80-89 |
| 高血压1级 | 140-159 | 90-99 |
| 高血压2级 | 160-179 | 100-109 |
| 高血压3级 | ≥180 | ≥110 |

**临床解读**：
- ⚠️ **版本说明**：中国《高血压防治指南2023》已将诊断阈值收紧至≥130/80（有合并症者），并将"正常高值"界定为130-139/80-89。国际口径（JNC/WHO）仍用120-139为正常高值。**本档案判断不受影响**（145/96为1级、125/77为理想，两版结论一致）。
- 正常高值（无论120或130起）为干预黄金窗口，通过减盐、运动、控重可逆
- 单次测量偏高不代表高血压，需非同日3次测量或24h动态血压确诊
- 家庭自测通常比诊室血压低5-10mmHg，诊断标准可参考家庭≥135/85

### 1.2 BMI 与腰围
- BMI = 体重(kg)/身高(m)²
- 中国标准：<18.5偏瘦 | 18.5-23.9正常 | 24-27.9超重 | ≥28肥胖
- 腰围（腹型肥胖）：男性≥90cm、女性≥85cm 即为腹型肥胖（比BMI更危险）
- 腹型肥胖是代谢综合征核心，与高尿酸、血脂异常、胰岛素抵抗强关联

### 1.3 心率（HR）
- 静息正常：60-100次/分；运动员可低至40-50
- 持续>100（心动过速）或<50（合并症状心动过缓）需心内科评估

## 二、生化指标临床意义（重点）

### 2.1 尿酸（UA）— 本档案核心风险指标
- **参考范围**：男性 208-428 μmol/L，女性 155-357 μmol/L
- **高尿酸血症定义**：非同日2次空腹血尿酸 >420 μmol/L（男）/ >360（女）
- **临床意义**：
  - 长期>540 且无症状 → 需考虑药物治疗（多数指南）
  - 已有痛风发作/肾结石/肾功能损害 → 达标治疗，目标 <360（有痛风石<300）
  - 与高血压、冠心病、糖尿病、慢性肾病互为因果
- **痛风风险分层**：血尿酸越高、持续时间越长，痛风发作风险越大；450左右长期未控是警戒水平
- **干预**：先生活（低嘌呤、多饮水2000ml+/日、限酒尤其啤酒、减重），3-6月未达标再考虑药物

### 2.2 血脂四项
| 指标 | 合适水平 | 说明 |
|------|---------|------|
| 总胆固醇(TC) | <5.2 mmol/L | 5.2-6.2临界，>6.2升高 |
| 甘油三酯(TG) | <1.7 mmol/L | 与饮食、饮酒、肥胖强相关 |
| LDL-C | <3.4 mmol/L | 动脉粥样硬化"坏胆固醇"，心血管风险核心 |
| HDL-C | ≥1.0 mmol/L | "好胆固醇"，偏低是风险 |

**临床解读**：
- LDL-C 是评估心血管风险的关键，是否用药取决于LDL-C值+总体心血管风险评分
- 甘油三酯与饮食、饮酒、糖尿病、肥胖强相关，控制饮食可显著改善
- 血脂异常 + 高血压 + 高尿酸 + 肥胖 = 代谢综合征典型组合

### 2.3 血糖
- 空腹血糖：3.9-6.1 mmol/L 正常 | 6.1-7.0 空腹血糖受损(IFG) | ≥7.0 疑糖尿病
- 糖化血红蛋白(HbA1c)：<5.7%正常 | 5.7-6.4%糖尿病前期 | ≥6.5%糖尿病诊断标准之一
- **提示**：空腹血糖正常不等于安全，胰岛素抵抗者餐后血糖可能高；必要时查糖化或OGTT

### 2.4 肝肾功能
- **ALT/AST（转氨酶）**：>40 U/L 提示肝损伤，脂肪肝、酒精、药物、肝炎均可引起
- **肌酐(Cr)**：57-111 μmol/L；持续升高提示肾功能减退
- **eGFR（估算肾小球滤过率）**：>90正常，60-90轻度下降，<60慢性肾病分期
- **尿素氮(BUN)**：3.1-8.0 mmol/L，受饮食蛋白影响大，单独意义有限

### 2.5 甲状腺功能
- **TSH**：0.27-4.2 mIU/L；升高提示甲减，降低提示甲亢（需结合FT3/FT4）
- **FT3/FT4**：甲状腺激素，确诊甲亢/甲减的指标
- **甲状腺抗体(TPOAb/TgAb)**：升高提示桥本甲状腺炎（自身免疫性）
- 甲状腺结节需结合超声分级判断良恶性，功能检查用于评估甲状腺状态

### 2.6 血常规（CBC）
| 指标 | 参考 | 异常临床意义 |
|------|------|-------------|
| 白细胞(WBC) | 3.5-9.5 ×10⁹/L | 升高→感染/炎症/应激；降低→病毒/免疫 |
| 血红蛋白(Hb) | 130-175 g/L(男) | 降低→贫血；升高→脱水/高原 |
| 血小板(PLT) | 125-350 ×10⁹/L | 降低→出血风险，需血液科 |
| 红细胞(RBC) | 4.3-5.8 ×10¹²/L | 与贫血、血液浓缩相关 |

### 2.7 肿瘤标志物
- **AFP** <20 ng/mL：肝癌筛查；**CEA** <5 ng/mL：消化道癌等；**CA19-9** <37 U/mL：胰腺/胆道；**PSA** <4 ng/mL：前列腺
- **重要提示**：肿瘤标志物轻度升高 ≠ 肿瘤！感染、炎症、良性疾病均可致升高。需结合影像+动态监测，单次略高不必恐慌

## 三、影像学分级系统（判读关键）

### 3.1 甲状腺结节 TI-RADS 分级（2020版）
| 分级 | 意义 | 恶性风险 | 处理建议 |
|------|------|---------|---------|
| 1级 | 无结节 | 0% | 无需处理 |
| 2级 | 良性 | ~0% | 常规随访 |
| 3级 | 可能良性 | <5% | 6-12个月复查超声 |
| 4级 | 可疑恶性(4a/4b/4c) | 5-85% | 穿刺活检可能 |
| 5级 | 高度可疑恶性 | >85% | 建议手术/穿刺 |

**TI-RADS 2级 = 良性结节，恶性风险极低，定期随访即可，无需恐慌。**

### 3.2 乳腺结节 BI-RADS 分级
- 2级良性 / 3级可能良性(短期随访) / 4级可疑恶性(需活检) / 5级高度可疑

### 3.3 脑白质病变 Fazekas 分级
| 分级 | 表现 | 意义 |
|------|------|------|
| 0级 | 无病变 | 正常 |
| 1级 | 点状病灶 | 年龄相关轻度改变，常见，通常无症状 |
| 2级 | 早期融合 | 需关注血管危险因素 |
| 3级 | 广泛融合 | 脑小血管病，认知障碍风险↑ |

**Fazekas 1级为轻度，多与年龄、高血压、糖尿病等血管危险因素相关，控制血压血脂血糖可延缓进展。**

### 3.4 脂肪肝超声分级
- 轻度：肝内回声增强，血管清晰 → 可逆，控重+限酒可逆转
- 中度：回声增强+血管模糊 → 需积极干预
- 重度：回声显著增强+后方衰减 → 警惕脂肪性肝炎/纤维化

## 四、慢病风险评估模型

### 4.1 代谢综合征诊断（符合≥3项）
1. 腹型肥胖：腰围男≥90cm/女≥85cm
2. 血压 ≥130/85 或已用降压药
3. 甘油三酯 ≥1.7 mmol/L 或已用药
4. HDL-C 男<1.0/女<1.3 mmol/L
5. 空腹血糖 ≥6.1 或已确诊糖尿病

**每多符合一项，心血管疾病和2型糖尿病风险显著递增。高血压+血脂异常+腹型肥胖+高尿酸组合是心脑血管高危信号。**

### 4.2 心血管风险评估框架
- **可干预危险因素**：吸烟、高血压、血脂异常、糖尿病、肥胖、缺乏运动
- **10年ASCVD风险**：中国人群风险评估通常结合年龄、性别、血压、血脂、吸烟、糖尿病等（可用China-PAR/ASCVD评分）
- 中危以上者建议控制LDL-C更严格（<2.6甚至<1.8）

### 4.3 痛风/高尿酸血症分层
| 分层 | 情况 | 处理 |
|------|------|------|
| 无症状+UA<540 | 无痛风/结石史 | 生活方式干预为主 |
| 无症状+UA≥540 | 无痛风/结石史 | 可考虑药物降尿酸 |
| 有痛风发作/结石/肾病 | 任何UA | 达标治疗(目标<360) |

### 4.4 慢性肾病(CKD)分期（基于eGFR）
- G1 ≥90 / G2 60-89 / G3a 45-59 / G3b 30-44 / G4 15-29 / G5 <15
- 肾结石患者需监测肾功能，防止梗阻性肾病

## 五、就医导诊与检查建议

### 5.1 常见异常对应的科室
| 异常 | 首选科室 | 建议检查 |
|------|---------|---------|
| 高尿酸/痛风 | 风湿免疫科 | 血尿酸、关节超声、尿尿酸 |
| 甲状腺结节/功能异常 | 内分泌科 | 甲功全套、甲状腺超声 |
| 血压/血脂异常 | 心内科 | 动态血压、血脂全套、颈动脉超声 |
| 肾结石/肾功能 | 泌尿外科/肾内科 | 泌尿系超声、尿常规、肾功能 |
| 脂肪肝/胆囊问题 | 消化内科 | 腹部B超、肝功能 |
| 脑白质病变/头晕 | 神经内科 | 头颅MRI、颈动脉超声 |
| 肺结节/纤维灶 | 呼吸内科 | 胸部CT、肺功能 |
| 贫血/血常规异常 | 血液科 | 血常规、铁蛋白、叶酸B12 |

### 5.2 年度重点复查清单（针对代谢异常人群）
血尿酸、血脂全套、肝功能+腹部B超、甲状腺超声、泌尿系超声、糖化血红蛋白、颈动脉超声、血压自测

## 六、循证用药常识（科普参考，遵医嘱）

### 6.1 降尿酸药
- **别嘌醇**：一线，起始低剂量，注意超敏反应（HLA-B*5801基因检测，亚裔推荐）
- **非布司他**：别嘌醇不耐受者，注意心血管安全性
- **苯溴马隆**：促尿酸排泄，肾结石/肾功能不全者慎用
- **原则**：痛风患者降尿酸需长期坚持，急性发作期不启动/不调整降尿酸药

### 6.2 他汀类（降胆固醇）
- 阿托伐他汀/瑞舒伐他汀：一线，降低LDL-C
- 监测：肝功能、肌酸激酶（CK）；肌肉酸痛无力需及时就医（横纹肌溶解风险）
- 需长期服用，达标后维持，勿自行停药

### 6.3 降压药（五大类）
- ACEI（普利类）/ARB（沙坦类）：一线，保护心肾
- 钙拮抗剂（氨氯地平）：常用，适合中国人群
- 利尿剂、β受体阻滞剂：根据合并症选择
- 原则：平稳降压，联合用药，个体化

### 6.4 碱化尿液（尿酸高+肾结石）
- 碳酸氢钠/枸橼酸氢钾钠颗粒：提高尿pH，防尿酸结石
- 需监测尿pH，目标6.2-6.9，需医生指导

## 七、健康档案解读工作流

### Step 1: 提取指标并分级
对每个指标：数值 + 参考范围 + 状态分级（🟢正常/🟡临界/🔴异常）

### Step 2: 做趋势分析
- 优先看5-9年趋势，识别持续异常（如持续高尿酸）vs 一过性波动
- 判断干预是否有效（如血压逐年改善）

### Step 3: 组合分析（综合征识别）
- 把孤立指标串联：高尿酸+肥胖+血脂+血压→代谢综合征
- 评估叠加风险

### Step 4: 风险预测
- 不干预 vs 积极干预两条路径的未来风险推演
- 明确"关键窗口期"

### Step 5: 输出建议
- 就医导诊（科室+检查+频率+优先级）
- 生活方式干预（饮食/运动/监测）
- 用药科普参考（带免责）
- 始终附免责声明
