# 体检异常指标诊断思维清单

> 用于健康档案解读时的系统化诊断思路。**仅作参考，最终判断以执业医师为准。**

## 一、单指标异常 → 可能疾病方向

### 尿酸升高
- 无痛风 → 无症状高尿酸血症
- 关节红肿热痛(尤其大脚趾) → 痛风发作
- 伴腰酸/血尿 → 尿酸性肾病/肾结石
- → 查：血尿酸、尿尿酸、关节超声、泌尿系超声、肾功能(eGFR)

### 血压升高
- 诊室多次高 + 家庭正常 → 白大衣高血压
- 全天持续高 → 原发性高血压
- 伴低血钾/心悸 → 继发性高血压(内分泌)需排查
- → 查：24h动态血压、肾功能、电解质、醛固酮/肾素

### 甲状腺结节
- TI-RADS 2-3级 → 良性可能大，随访
- TI-RADS 4-5级 → 需穿刺/手术评估
- 伴甲功异常 → 需内分泌干预
- → 查：甲功全套、甲状腺超声、必要时细针穿刺(FNA)

### 血脂异常
- 仅TG高 → 多与饮食饮酒肥胖相关，可逆
- LDL-C高 → 评估心血管总体风险
- → 查：血脂全套、颈动脉超声(评估动脉硬化)、心血管风险评估

### 脂肪肝
- 轻度+转氨酶正常 → 单纯性脂肪肝，生活方式干预可逆
- 转氨酶升高 → 脂肪性肝炎，需肝病科
- → 查：肝功能、腹部B超、乙肝丙肝筛查、血糖血脂

### 肾结石
- 无症状小结石(<5mm) → 保守多饮水观察
- 大结石/梗阻/反复感染 → 泌尿外科评估
- → 查：泌尿系超声、尿常规、肾功能、尿酸(结石成分相关)

### 脑白质病变(Fazekas)
- 1级无症状 → 年龄/血管因素，控制危险因素
- 2-3级或进展 → 神经内科，排查脑血管病
- → 查：头颅MRI、颈动脉超声、血压血糖血脂

## 二、多指标组合 → 综合征识别

| 组合 | 提示 |
|------|------|
| 尿酸高+肥胖+血脂+血压 | 代谢综合征 |
| 高血压+颈动脉斑块 | 动脉粥样硬化 |
| 脂肪肝+转氨酶高+TG高 | 代谢相关脂肪肝(MAFLD) |
| 甲状腺结节+TPOAb高 | 桥本甲状腺炎 |
| 空腹血糖临界+腹型肥胖+血脂 | 糖尿病前期/胰岛素抵抗 |

## 三、危险信号（需尽快就医/急诊）

### 急诊指征
- 剧烈胸痛/胸闷 >15分钟（心梗可能）
- 突发口角歪斜/单侧肢体无力/言语不清（脑梗）
- 意识模糊/晕厥
- 严重呼吸困难
- 呕血/黑便（消化道出血）
- 急性关节剧痛红肿（痛风急性发作，可门诊但需处理）

### 需尽快专科（1-2周内）
- 甲状腺结节 TI-RADS 4级以上
- 血尿/腰部剧痛（肾结石梗阻）
- 血压骤升 ≥180/110 伴头痛
- 出血倾向（牙龈/皮肤瘀斑增多，血小板低）
- 持续不明原因体重下降

## 四、随访频率建议（慢病人群）
| 项目 | 频率 |
|------|------|
| 血尿酸 | 3-6个月 |
| 血脂全套 | 6个月 |
| 肝功能+腹部B超 | 6-12个月 |
| 甲状腺超声 | 6-12个月(2-3级) |
| 泌尿系超声 | 6-12个月 |
| 糖化血红蛋白 | 6-12个月 |
| 颈动脉超声 | 1年 |
| 头颅MRI | 1-2年(若有白质病变) |
| 血压自测 | 每周2-3次 |
