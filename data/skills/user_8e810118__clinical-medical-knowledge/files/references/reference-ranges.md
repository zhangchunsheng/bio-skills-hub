> 参考值因实验室和检测方法略有差异，以体检报告/检验科标注为准。
> 用途：健康档案解读快速查表。**所有解读需结合临床，遵医嘱。**

| 指标 | 参考 | 相关肿瘤 |
|------|------|---------|
| AFP | <20 ng/mL | 肝癌 |

## 五、影像分级系统

### 甲状腺 TI-RADS（2020版）
1级无结节 / 2级良性(恶性~0%) / 3级可能良性(<5%) / 4级可疑(5-85%) / 5级高度可疑(>85%)

### 乳腺 BI-RADS
2级良性 / 3级可能良性(短期随访) / 4级可疑(需活检) / 5级高度可疑

### 脑白质 Fazekas
0级无 / 1级点状(年龄相关,常见,无症状) / 2级早期融合(关注血管因素) / 3级广泛融合(认知风险)

### 脂肪肝
轻度(可逆,控重限酒逆转) / 中度(需积极干预) / 重度(警惕纤维化)

## 六、BMI与血压（中国标准）

**BMI**：<18.5偏瘦 / 18.5-23.9正常 / 24-27.9超重 / ≥28肥胖
**腰围**：男≥90cm / 女≥85cm 腹型肥胖
**血压**：理想<120/80 / 正常高值120-139（中国2023指南130-139）/80-89 / 高血压1级140-159/90-99 / 2级160-179/100-109 / 3级≥180/110
> ⚠️ 血压"正常高值"边界有版本差异：国际用120-139，中国2023指南用130-139且诊断阈值收紧至≥130/80（有合并症者）。判断个体时两版结论通常一致。

## 七、代谢综合征（符合≥3项）
1. 腰围男≥90/女≥85cm
2. 血压≥130/85或用降压药
3. TG≥1.7
4. HDL-C男<1.0/女<1.3
5. 空腹血糖≥6.1或糖尿病

## 常用换算
- 血压：1 mmHg = 0.133 kPa
- 血糖：1 mmol/L = 18 mg/dL
- 胆固醇：1 mmol/L = 38.7 mg/dL
