# Skill Info

## Skill Name
医药财务智能助手

## Description
面向医药行业的专业财务处理工具集，支持医药发票识别报销、VBP带量采购财务分析、医药税务计算（含研发加计扣除）、医药财务报表分析（销售费用率对标/药品毛利率）、智能记账（医药科目体系）、医药合规审查（反商业贿赂/HCP FMV/GSP/GMP/CSO/两票制）、会计分录查询、团队协作（研发/生产/销售/合规多部门）。帮助医药企业高效处理行业特有财务事务。

## Introduction

本技能在医药财务领域提供发票处理、税务计算、报表分析、合规审查、智能记账及会计分录查询等一站式工具支持。

医药财务智能助手旨在简化和自动化药企日常财务处理与合规审查工作，为药企财务总监、财务经理、会计及合规官提供从发票报销到合规审查、从税务计算到集采决策的全链路支持。

核心能力：

- 医药发票智能处理（药品采购/器械/临床研究/学术会议 + GSP票据合规检查）
- 医药税务计算（药品三档增值税 + 研发加计扣除 + 两票制VAT流转）
- 医药财务报表分析（药品毛利率/销售费用率对标/VBP集采财务建模）
- 医药智能记账（研发/生产/流通成本归集 + GMP合规核算）
- 医药合规审查（反商业贿赂/HCP FMV/CSO审查/两票制/学术会议合规）
- 会计分录查询（51条分录：29通用 + 22医药专项）

应用场景：

- 药品采购发票报销与GSP合规检查
- 带量采购(VBP)中标后的毛利重算与盈亏平衡分析
- HCP讲者费/咨询费的公允市场价值(FMV)校验与反商业贿赂审查
- CSO推广费占收入比监控与异常波动检测
- 研发费用加计扣除辅助账编制与节税测算
- 两票制流通加价率与票货流向合规自查
- 学术会议费用合规性验证
