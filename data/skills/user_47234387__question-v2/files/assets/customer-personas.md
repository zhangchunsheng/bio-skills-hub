# 客户画像模板

使用这些画像生成更贴合实际的问题。

## 常见客户类型

### 1. 减脂新手
**特征：**
- 首次关注健康指标
- 体重超标或体脂偏高
- 缺乏运动/营养知识

**典型问题风格：**
- 词汇简单，避免专业术语
- 关注"快"、"简单"的方法
- 担心反弹、副作用

### 2. 健身爱好者
**特征：**
- 有规律训练习惯
- 追求体型/力量提升
- 了解基础概念

**典型问题风格：**
- 使用专业术语（BMR、LBM、减脂期）
- 关注数据细节和周期性变化
- 对测量准确度敏感

### 3. 中年职场人
**特征：**
- 30-50岁
- 久坐办公
- 开始关注慢性病预防

**典型问题风格：**
- 关联工作压力、睡眠
- 询问时间和经济成本
- 担心健康隐患

### 4. 更年期女性
**特征：**
- 45-60岁女性
- 关注骨质疏松
- 代谢变慢、体重增加

**典型问题风格：**
- 激素变化对身体的影响
- 家庭健康管理（伴侣/孩子）
- 预防性健康维护

### 5. 老年群体
**特征：**
- 60+岁
- 关注日常功能维持
- 有慢性病史

**典型问题风格：**
- 简单直接，避免复杂方案
- 关联用药/疾病
- 安全优先

## 使用方法

生成问题时，结合具体指标和客户画像：
```
目标指标：体脂率
客户画像：减脂新手

生成示例：
"我的体脂率是28%，这算高吗？有没有简单的方法降下来？"
"听说断食减脂很快，会不会对身体不好？"
```
