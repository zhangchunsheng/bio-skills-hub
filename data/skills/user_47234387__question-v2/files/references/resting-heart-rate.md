# 静态心率 (Resting Heart Rate, RHR)

## 定义

安静状态下的每分钟心跳数，通常在早晨起床后测量。

## 标准范围

| 分类 | 静态心率 (bpm) |
|------|---------------|
| 运动员 | 40-60 |
| 健康 | 60-80 |
| 偏高 | 80-100 |
| 过高 | > 100 |

## 客户常见关注点

1. **数值意义**
   - "静态心率60算好吗？"
   - "为什么我心率总是比同龄人快？"

2. **影响因素**
   - "咖啡会影响静态心率吗？"
   - "压力大时心率会升高多少？"

3. **运动改善**
   - "有氧运动多久能降低静态心率？"
   - "心率带和手环哪个更准？"

4. **健康警示**
   - "静态心率突然升高是危险信号吗？"
   - "我需要去看心脏科吗？"

## 客户画像示例

- 跑步/骑行人群：追踪心率变化、训练效果
- 压力大人群：关注焦虑对心率的影响
- 中老年群体：心脏健康监测、慢性病管理
