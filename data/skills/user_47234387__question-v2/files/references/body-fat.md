# 体脂率 (Body Fat Percentage)

## 定义

体脂占总重量的百分比，反映脂肪组织在身体中的占比。

## 标准范围（男性）

| 分类 | 体脂率 |
|------|--------|
| 偏低 | < 10% |
| 正常 | 10% - 20% |
| 偏高 | 20% - 25% |
| 肥胖 | > 25% |

## 标准范围（女性）

| 分类 | 体脂率 |
|------|--------|
| 偏低 | < 18% |
| 正常 | 18% - 28% |
| 偏高 | 28% - 33% |
| 肥胖 | > 33% |

## 客户常见关注点

1. **数值解读**
   - "体脂率20%，男生算高吗？"
   - "女性体脂率为什么天生比男性高？"

2. **测量方法**
   - "体脂秤准确吗？"
   - "为什么医院测的和体脂秤不一样？"

3. **减脂策略**
   - "有氧运动还是力量训练更降体脂？"
   - "饮食对体脂率的影响有多大？"

4. **误区澄清**
   - "体重没变但体脂率下降，算成功吗？"
   - "局部减脂可能吗？"

## 客户画像示例

- 减脂人群：关心目标体脂率、最佳减脂方法
- 女性群体：担心肌肉线条过粗、追求"微胖"体态
- 中年群体：警惕内脏脂肪堆积、慢性病风险
