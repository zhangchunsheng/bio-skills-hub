# BMI (Body Mass Index) - 身体质量指数

## 定义

BMI = 体重(kg) / 身高²(m²)

## 标准范围

| 分类 | BMI范围 |
|------|---------|
| 偏瘦 | < 18.5 |
| 正常 | 18.5 - 23.9 |
| 超重 | 24.0 - 27.9 |
| 肥胖 | ≥ 28.0 |

## 客户常见关注点

1. **数值意义**
   - "BMI 25 是不是胖了？"
   - "为什么我的BMI正常，但看起来还是胖？"

2. **局限性**
   - "BMI不能区分肌肉和脂肪，对吗？"
   - "健身的人BMI会偏高吗？"

3. **改善方向**
   - "如何把BMI降到正常范围？"
   - "减重对BMI的影响有多大？"

4. **健康关联**
   - "BMI高一定不健康吗？"
   - "BMI正常但体脂率高，需要担心吗？"

## 客户画像示例

- 减肥人群：关心目标BMI、减重速度
- 健身人群：质疑BMI准确性、关注肌肉vs脂肪
- 中老年人：关联慢性病风险、健康管理
