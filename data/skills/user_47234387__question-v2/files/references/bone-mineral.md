# 骨盐量 (Bone Mineral Content, BMC)

## 定义

骨骼中矿物质的总重量，反映骨密度和骨骼健康。

## 标准参考

- 男性：2.5 - 3.5 kg
- 女性：1.8 - 2.8 kg

## 客户常见关注点

1. **骨质疏松**
   - "骨盐量偏低，是骨质疏松吗？"
   - "女性什么年龄开始关注骨量？"

2. **补充钙质**
   - "喝牛奶能提高骨盐量吗？"
   - "钙片需要每天吃吗？"

3. **运动影响**
   - "跑步会增加骨盐量吗？"
   - "游泳对骨骼健康有帮助吗？"

4. **家族遗传**
   - "骨质疏松会遗传吗？"
   - "妈妈有骨质疏松，我该如何预防？"

## 客户画像示例

- 更年期女性：骨量流失高峰、预防策略
- 老年群体：骨折风险、骨骼健康维护
- 年轻女性：奶茶/碳酸饮料对骨骼的影响
