# 骨骼肌量 (Skeletal Muscle Mass)

## 定义

骨骼附着肌肉的总重量，反映肌肉发育和储备。

## 标准参考

- 男性：占体重 35%-45%
- 女性：占体重 30%-40%

## 客户常见关注点

1. **数值意义**
   - "骨骼肌量偏低说明什么？"
   - "肌肉量会影响基础代谢吗？"

2. **增肌方法**
   - "如何快速增加骨骼肌量？"
   - "增肌必须吃蛋白粉吗？"

3. **年龄因素**
   - "年龄增长，肌肉自然流失，能补回来吗？"
   - "50岁后肌肉量下降多少算正常？"

4. **运动关联**
   - "不举铁，骨骼肌量能增加吗？"
   - "跑步会增加骨骼肌量吗？"

## 客户画像示例

- 健身人群：追求最大肌肉量、担心过度训练
- 老年群体：预防肌少症、维持日常功能
- 办公室白领：久坐导致的肌肉流失、日常活动力下降
