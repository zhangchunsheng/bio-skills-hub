# 示例案例 - 医疗口述转写助手

## 示例 1：内科 - 高血压随访

### 输入口述

```
患者为58岁男性，因高血压复诊。他说自己每天服用赖诺普利10毫克，但承认偶尔会漏服。他否认胸痛、气短或头晕。他说家中自测血压大约在140/90左右。体重稳定。他仍每天吸烟约半包。否认头痛或视力变化。

查体：血压148/92，心率78，体温98.6华氏度。精神状态良好。双肺呼吸音清。心律齐，未闻及杂音。腹软，无压痛。四肢无水肿。

评估为高血压控制不佳，目前使用赖诺普利。鉴于其心血管风险因素，血压目标应低于130/80。他有明显的吸烟史，进一步增加了风险。

计划：将赖诺普利增加至每天20毫克。强调按医嘱服药的重要性。讨论了戒烟并提供了相关资源。4周后复诊，携带家中血压记录。调整剂量后1周复查基础代谢检查（BMP），监测肌酐和钾。
```

### 预期 SOAP 输出

```markdown
# 临床记录

## 主观资料 (Subjective)
**主诉：** 高血压复诊

**现病史：**
58岁男性因高血压复诊。服用赖诺普利10mg每日一次，但承认偶尔漏服。否认胸痛、气短、头晕、头痛或视力变化。家中自测血压约140/90 mmHg。体重稳定。仍每日吸烟约0.5包。

**系统回顾：**
- 心血管：否认胸痛、呼吸困难、端坐呼吸
- 神经系统：否认头痛、视力变化、头晕

**社会史：**
吸烟：每日0.5包（现仍吸烟）

**目前用药：**
- 赖诺普利 10mg 每日一次

## 客观资料 (Objective)
**生命体征：**
- 血压：148/92 mmHg
- 心率：78 bpm
- 体温：98.6°F

**体格检查：**
- 一般情况：精神状态良好，营养状况可
- 心血管：心律齐，未闻及杂音
- 呼吸系统：双肺呼吸音清
- 腹部：软，无压痛
- 四肢：无外周水肿

## 评估 (Assessment)
**主要诊断：** 原发性高血压，控制不佳

**临床推理：**
在ACE抑制剂治疗下血压仍高于目标值。促成因素包括用药依从性不佳及持续吸烟。根据ACC/AHA指南，存在心血管风险因素的患者目标血压应<130/80 mmHg。

## 计划 (Plan)
**治疗计划：**
1. 赖诺普利增加至每日20mg
2. 强调用药依从性

**辅助检查：**
- 剂量调整后1周复查基础代谢检查（监测肌酐、钾）

**患者教育：**
- 讨论了按医嘱服药的重要性
- 提供了戒烟资源

**随访：**
4周后复诊，携带家中血压记录
```

## 示例 2：急诊医学 - 胸痛评估

### 输入口述

```
45岁女性因胸痛就诊急诊科。疼痛于2小时前静息时开始。她描述为压榨样疼痛，程度8/10，向左臂放射。伴有恶心和大汗。无气短。既往史包括高血压和高脂血症。服用氨氯地平和阿托伐他汀。青霉素过敏。

生命体征：体温37.2，心率102，血压165/95，呼吸频率18，room air下血氧饱和度97%。患者表现为大汗、痛苦面容。心血管查体心律齐，未闻及杂音。双肺呼吸音清。腹部查体无异常。

心电图显示V2-V4导联ST段抬高。首次肌钙蛋白0.5，呈上升趋势。胸片未见明显异常。

评估为急性ST段抬高型心肌梗死，前壁。已请心内科会诊。给予阿司匹林325mg、替格瑞洛负荷剂量、肝素静脉推注。患者将紧急送往导管室行直接PCI（经皮冠状动脉介入治疗）。
```

### 预期 SOAP 输出

```markdown
# 临床记录

## 主观资料 (Subjective)
**主诉：** 胸痛

**现病史：**
45岁女性，急性起病胸痛2小时。疼痛于静息时开始，描述为压榨样，程度8/10，向左臂放射。伴随症状：恶心、大汗。否认呼吸困难。

**既往史：**
- 高血压
- 高脂血症

**目前用药：**
- 氨氯地平
- 阿托伐他汀

**过敏史：**
- 青霉素

## 客观资料 (Objective)
**生命体征：**
- 体温：37.2°C
- 心率：102 bpm
- 血压：165/95 mmHg
- 呼吸频率：18/min
- 血氧饱和度：97%（room air）

**体格检查：**
- 一般情况：大汗，痛苦面容
- 心血管：心律齐，未闻及杂音
- 呼吸系统：双肺呼吸音清
- 腹部：查体无异常

**辅助检查：**
- 心电图：V2-V4导联ST段抬高（前壁）
- 肌钙蛋白：0.5 ng/mL（升高，呈上升趋势）
- 胸片：未见明显异常

## 评估 (Assessment)
**主要诊断：** 急性ST段抬高型心肌梗死（STEMI），前壁

**ESI 分级：** 1级（需立即抢救干预）

## 计划 (Plan)
**紧急处置：**
- 给予阿司匹林325mg
- 给予替格瑞洛负荷剂量
- 给予肝素静脉推注
- 已请心内科会诊

**去向：**
紧急转入心导管室行直接PCI
```

## 示例 3：儿科 - 健康儿童体检

### 输入口述

```
6个月大男婴，健康体检。足月顺产。出生体重7磅8盎司。疫苗接种按计划进行。家长反馈他进食情况良好，每4小时进食6盎司配方奶。上个月开始添加辅食，耐受良好。夜间可以整夜睡眠。发育里程碑达标——会翻身、能靠支撑坐、会微笑和发出咯咯声。

生命体征：体重17磅4盎司，位于75百分位。身长26英寸，位于50百分位。头围43厘米，位于50百分位。体温98.4华氏度。体格检查正常。神志清醒，反应良好。前囟平软。双眼追视良好。外耳道清洁。心律齐，未闻及杂音。双肺呼吸音清。腹软。髋关节检查正常。皮肤未见异常。

评估为健康6月龄男婴，生长发育正常，发育进程达标。

计划：今日常规接种疫苗——百白破（DTaP）、灰质炎（IPV）、b型流感嗜血杆菌（Hib）、13价肺炎球菌结合疫苗（PCV13）、轮状病毒疫苗。讨论了逐一引入新辅食的方法。就儿童安全（安全座椅、水域安全）进行了指导。9个月后复诊。
```

### 预期 SOAP 输出

**既往史：**

## 客观资料 (Objective)
**生命体征：**

- 身长：26英寸（第50百分位）

- 头颈五官：前囟平软，双眼追视良好，外耳道清洁

## 示例 4：骨科 - 踝关节扭伤

### 输入口述

```
22岁大学运动员在篮球比赛中扭伤右脚踝，约3小时前发生。他踩在另一名球员的脚上，听到"啪"的一声。当即出现疼痛和肿胀，无法负重。既往无踝关节损伤史。

查体见外踝周围肿胀和瘀斑。距腓前韧带处压痛。前抽屉试验阴性。可负重但疼痛剧烈。活动范围因疼痛受限。远端神经血管功能正常。

X光未见骨折或脱位。渥太华踝关节规则提示无需拍片的影像学指征，但因疼痛剧烈仍予以拍片。

评估为右踝外侧2度扭伤。

计划：RICE方案（休息、冰敷、加压包扎、抬高患肢）。予踝关节支具固定。使用拐杖辅助下可耐受负重。布洛芬600mg，每日三次，随餐服用。转诊物理治疗进行康复训练。1周后复诊，若加重则提前就诊。已告知需警惕筋膜间隔综合征或深静脉血栓相关体征。
```

### 预期 SOAP 输出

```markdown
# 临床记录

## 主观资料 (Subjective)
**主诉：** 外伤后右踝疼痛

**现病史：**
22岁男性运动员，3小时前篮球比赛中右踝受伤。受伤机制：踩在对方球员脚上。受伤当时自述听到"啪"的一声。随即出现疼痛和肿胀，无法负重。既往无踝关节损伤史。

**疼痛评估：**
- 部位：右踝外侧
- 性质：锐痛、跳痛
- 程度：剧烈（限制负重）

## 客观资料 (Objective)
**体格检查 - 右踝：**
- 视诊：外踝周围肿胀、瘀斑
- 触诊：距腓前韧带（ATFL）处压痛
- 稳定性：前抽屉试验阴性
- 负重情况：疼痛剧烈，需辅助
- 活动范围：因疼痛受限
- 神经血管：远端功能正常（脉搏可触及，感觉正常）

**辅助检查：**
- 右踝X光：未见骨折或脱位

## 评估 (Assessment)
**主要诊断：** 右踝外侧2度扭伤

## 计划 (Plan)
**保守治疗：**
- RICE方案（休息、冰敷、加压包扎、抬高患肢）
- 予踝关节支具固定
- 负重：拐杖辅助下可耐受负重

**用药：**
- 布洛芬600mg 口服 每日三次 随餐

**转诊：**
- 转诊物理治疗进行踝关节康复

**随访：**
1周后复诊，若加重则提前就诊

**返诊指征：**
- 出现以下情况需立即就诊：疼痛加重、麻木/刺痛、足部苍白/发凉、小腿疼痛/肿胀（深静脉血栓征象）
```

## 示例 5：精神科 - 抑郁症随访

### 输入口述

```
35岁女性因重度抑郁症复诊。4周前开始服用舍曲林50mg。她说情绪有所改善，大约好转30%。睡眠改善，现在能睡6到7小时，之前只有4小时。仍有些兴趣缺乏，工作时注意力难以集中。否认自杀想法。药物无副作用。

精神状态检查：患者穿着得体，态度合作。情绪自述"好一点但不算好"。情感协调，稍显受限。思维过程连贯。无自杀或伤人观念。自知力和判断力完整。

今日PHQ-9评分为12分，较上月的18分有所下降。

评估为重度抑郁症，中度，对舍曲林部分反应。

计划：舍曲林增加至每日100mg。继续每周心理治疗。4周后复诊。已提供危机热线电话号码。患者同意若出现自杀想法立即就医。
```
