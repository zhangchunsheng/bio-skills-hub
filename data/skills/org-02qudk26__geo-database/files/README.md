# GEO 转录组数据检索

- 唯一标识：`hub-geo-database`
- 显示名称：GEO 转录组数据检索
- 能力摘要：访问 NCBI GEO 的 GSE、GSM、GPL、GDS、SOFT 和 Matrix 文件，搜索、下载和整理芯片与 RNA-seq 表达研究及其实验元数据。

## 案例素材

1. 生物学家寻找乳腺癌公开表达数据。该 skill 会按疾病、物种和实验类型检索 GSE，审查样本数、平台和分组后再下载适合的矩阵。
2. 团队复现一项差异表达结论。该 skill 会保存 GSE/GSM/GPL accession、处理文件和元数据版本，明确原作者归一化与自己的处理差异。
3. 多个 GEO 研究要整合。该 skill 会先识别平台、批次和探针注释的不一致，避免直接合并表达值而造成伪差异。
