## 〇、2026 版申请书构成与正文铁律（权威）

面上项目申请书由 **信息表格 + 正文 + 个人简历 + 附件** 构成。

- **信息表格**：含项目基本信息、主要参与者、预算表；摘要、关键词、申请代码、研究属性勾选均在表格内填写（非正文）。
- **正文铁律（模板原话，须遵守）**：
  - "参照以下提纲撰写，要求内容翔实、清晰，层次分明，标题突出。"
  - "申请书正文原则上不超过 **30 页**，鼓励简洁表达。"
  - "**请勿删除或改动下述提纲标题及括号中的文字**。"（即下方（一）（二）（三）（四）一级标题及其括号说明一字不改）
- **2026 改革导向（"瘦身提质"）**：面上/青年(C类) 提纲优化，摒弃"套路/话术"，纠正"篇幅写长一点更容易获得资助"的错误想法，让内容回归科研本质、充分展示创新思路与学术观点。

### 1.3 研究属性（2026 改为"两类"，已废止旧"四类"）
2026 年面上项目 / 青年(C类) **不再使用旧"四类科学问题属性(A/B/C/D)"**，改为 **两类研究属性二选一**（官方原文）：
- **自由探索类基础研究**：选题源于科研人员好奇心或创新性学术灵感，且不以满足现阶段应用需求为目的的原创性、前沿性基础研究。

## 二、学科代码选择决策（关键）

### 2.1 H17 vs H09 评审偏好差异表
| 维度 | H17 创伤 | H09 神经损伤修复 |
|------|----------|------------------|
| **核心科学问题偏好** | 原发性 + 继发性损伤机制；创伤特异性分子事件；急性与亚急性 | 修复再生机制；细胞/生物材料/工程化策略；功能性修复 |
| **优先模型** | 损伤造模（CCI/FPI/CHI/爆炸波）、脊髓损伤（挫伤/横断）、脑出血 | 神经再生（轴突/髓鞘/突触）、神经干细胞、生物材料支架 |
| **关键词切中** | "创伤""挫伤""弥漫性轴索损伤""继发性损伤""胶质瘢痕""程序性细胞死亡表型" | "修复""再生""轴突再生""突触重塑""生物材料""神经干细胞""组织工程" |
| **不喜欢** | 过分偏重综述、慢性退行性病机制（易被打回）；重材料轻机制 | 单纯疾病机制缺修复切入点（易被打回） |
| **典型范式** | 损伤造模 + 机制（胶质细胞亚型/特定死亡表型/铁死亡等） + 干预（药物/基因编辑/材料） | 损伤或体外退化模型 + 修复策略（细胞/材料/电刺激） + 功能学评估 |
| **评审画像** | 临床 + 基础背景，强调创伤研究的转化价值 | 偏细胞/材料/工程方向，强调新方法的修复潜力 |

### 2.2 学科代码选择工作流（自检清单）
1. **课题核心是否落在"损伤机制"？**（机制 = 主要贡献）→ 偏 H17 / H09（神经系统机制）
2. **课题核心是否落在"修复/再生策略"？**（策略 = 主要贡献）→ 偏 H09 / H02（脑血管修复方向）
3. **是否兼具二者？** → 选"机制主导"侧，**勿选模糊代码**，NSFC 双盲评审优先"学科匹配度"
4. **是否需要做跨代码思考**？例如：H17 创伤机制 + 类器官修复 → 主报 H17，方法学部分引类器官即可；H09 神经再生 + 创伤模型 → 主报 H09，"临床情景"框定在创伤
5. **同行对照**：检索近 3 年该代码中标项目关键词分布，若与本课题高频词 ≥ 60% 重叠，可投
6. **评审画像匹配**：查近 3 年该代码下的中标通讯作者背景（H17 多为创伤基础/临床转化；H09 多为干细胞/材料/再生方向）
7. **婉转策略**：若两代码都有论文产出，**正式申报建议选最适配的一项** + 在立项依据"立足点"中说明与另一方向的衔接，避免分散

### 2.3 案例对照（以"某 CNS 损伤模型 + 关键调控分子"课题为例，示意代码适配）
| 维度 | 路径 A（机制主导型投向，例：创伤类代码） | 路径 B（修复主导型投向，例：神经修复类代码） |
|------|-----------------|-----------------|
| 主线 | 细胞A 激活 → 分子X 下调 → 细胞B 死亡表型 → 损伤继发性病理 | 细胞A-因子Y 调控 → 细胞B 死亡表型 → 神经元丢失 → 修复失败 |
| 模型 | 损伤造模（如 CCI/挫伤）| 损伤/缺氧模型 + 修复评估 |
| 关键词适配 | 创伤 / 关键死亡表型 / 细胞B 亚型 / 胶质瘢痕 | 神经元修复 / 突触重塑 / 神经免疫环境 |
| 创新点表达 | "首次证实在损伤中细胞A 通过分子X 调控细胞B 死亡表型的机制" | "首次构建细胞A-因子Y-细胞B 死亡表型调控网络并探索靶向挽救神经元修复的策略" |
| 风险 | 偏机制，转化通路偏窄 | 偏修复策略，需做更多行为学/电生理/环路验证 |

> **建议**：以"机制闭环"为主要贡献 → **路径 A（机制主导型投向）**更适配；若课题组同步有行为学/电生理/环路数据 → **路径 B（修复主导型投向）**有优势。最终决策需结合**预实验丰度**和**团队背景**。（本表为通用示意，代码与分子/细胞/模型均请替换为您课题的真实信息）

## 三、2026 版 正文 4 节提纲（权威结构 + 撰写要点）

> 下列 **（一）（二）（三）（四）为模板原文一级标题，一字不改**；其下"撰写要点"为本技能补充，供填充参考。节内子标题（如 1./2./3.）可按研究自身逻辑调整，但（三）的 4 个子项与（四）的 5 个子项建议保留，因其对应形式审查要点。

### （一）立项依据：（为什么要开展此项研究，研究的科学技术价值如何）
4 段漏斗式（经典且不被禁止，改革反对的是空话套路，不反对清晰逻辑）：
**第一段（领域背景）**（500-700 字）：疾病流行病学 1-2 句；病理过程 1-2 句（继发性损伤/神经炎症）；现有干预局限 1-2 句（无有效治疗靶点）。
**第二段（领域共识与争议）**（800-1200 字）：核心细胞互作；关键死亡表型在 CNS 病理中的角色；相关因子在神经炎症中的角色；标注争议点（用 NR / limited evidence 短语）。
**第三段（关键空白）**（500-800 字）：3-5 条 bullet 总结具体研究空白，每空对应一个拟解决关键科学问题；末句"以上空白构成本课题的科学问题"。
**第四段（研究基础与本课题拟解决关键问题）**（400-600 字）：课题组前期数据（损伤后某细胞死亡表型↑、条件培养基→靶细胞某分子↓ 等）；拟解决 3-4 个关键科学问题（"在 X 模型中，Y 通过 Z 影响 W"句式）；末句点明价值。
- **呼应研究属性**：自由探索类强调原创/前沿价值；目标导向类强调需求牵引与应用前景。
- 引用规范：全文 30-60 条立引，关键支撑用 primary 文献；`[n]` 序号制；不引未发表数据作支撑（可作"初步观察"陈述）。

### （二）研究内容：（提纲不做限制，请按照研究工作的自身逻辑撰写。应提炼出特色与创新点、年度研究计划）
> 2026 改革重点：本节**不再预设**"研究目标/拟解决关键科学问题/研究方案/技术路线"等子标题，按研究自身逻辑自主撰写；但内容须覆盖以下要素，且须**提炼特色与创新点、年度研究计划**。

- **研究目标**（明确/揭示/建立…，2-3 句，与摘要一一对应）
- **拟开展的研究内容**（4-5 个"做什么"）
- **拟解决的关键科学问题**（对关键研究环节科学问题的抽象凝练，2-4 条；如：细胞A 是否/如何通过因子Y 调控细胞B 死亡表型；分子X-细胞B 轴在调控网络中的定位；靶向节点挽救该死亡表型的可行性）
- **拟采取的研究方案及可行性分析**（每个目标独立展开）：
  - 研究思路（200-300 字）
  - 研究方法（详尽可复现，参考 `experiment-design.md`）：模型选择+依据、分组+n（带功效分析）、检测指标+终点、统计方法+软件
  - 关键技术（瓶颈与替代方案）
  - 预期结果（含可量化预测）
  - 可行性：理论/技术/实验条件/研究团队四方面
  - 技术路线图：一张矢量图（SVG/PNG，300 dpi）呈现"目标—方法—成果—反馈环"
- **特色与创新之处**（3 条以内，每条 1-2 句；理论创新/方法创新/应用创新；"首次"在文献未证实前慎用，若用必引证据；杜绝"填补国内空白"等套话）
- **年度研究计划及预期研究结果**（含重要学术交流、国际合作；详见 §四表格）

### （三）研究基础：
1. **研究基础与可行性分析**（与本项目相关的研究工作积累和已取得的研究工作成绩，研究风险的应对措施等）——可并入（二）可行性要点，此处集中展示前期积累、已发表相关论文、前期数据（附 1-2 张关键结果图，展示具体数字；不写"该领域权威/国际领先"等空话）。
2. **工作条件**（已具备的实验条件，尚缺少的实验条件和拟解决的途径，包括利用国家实验室、全国重点实验室和部门重点实验室等研究基地的计划与落实情况）；实验平台/合作单位；数据/样本可及性。
3. **正在承担的与本项目相关的科研项目情况**（申请人和主要参与者正在承担的与本项目相关的科研项目情况，包括国家自然科学基金的项目和国家其他科技计划项目，要注明项目的资助机构、项目类别、批准号、项目名称、获资助金额、起止年月、与本项目的关系及负责的内容等）。
4. **完成国家自然科学基金项目情况**（对申请人负责的前一个已资助期满的科学基金项目（项目名称及批准号）完成情况、后续研究进展及与本申请项目的关系加以详细说明。另附该项目的研究工作总结摘要（限 500 字）和相关成果详细目录）。

### （四）其他需要说明的情况：
1. 申请人同年申请不同类型的国家自然科学基金项目情况（列明同年申请的其他项目的项目类型、项目名称信息，并说明与本项目之间的区别与联系；已收到自然科学基金委不予受理或不予资助决定的，无需列出）。
2. 具有高级专业技术职务（职称）的申请人或者主要参与者是否存在同年申请或者参与申请国家自然科学基金项目的单位不一致的情况；如存在，列明所涉及人员姓名、申请或参与申请的其他项目的项目类型、项目名称、单位名称、上述人员在该项目中是申请人还是参与者，并说明单位不一致原因。
3. 具有高级专业技术职务（职称）的申请人或者主要参与者是否存在与正在承担的国家自然科学基金项目的单位不一致的情况；如存在，列明所涉及人员姓名、正在承担项目的批准号、项目类型、项目名称、单位名称、起止年月，并说明单位不一致原因。
4. 申请人和主要参与者同年以不同专业技术职务（职称）申请或参与申请科学基金项目的情况（应详细说明原因）。
5. 其他。

## 五、经费预算（现行三大类口径，财教〔2021〕177 号）

### 5.1 现行经费科目（三大类直接费用 + 间接费）
- **设备费**：专用设备购置（限额严格）
- **业务费**：材料（试剂/耗材/实验动物/临床样本）、测试化验加工（外送测序/流式/单细胞）、差旅/会议/国际合作、出版/文献/版面等——**通常占大头**
- **劳务费**：研究生、博士后、临时聘用人员（不得发放给 PI 本人）
- **间接费**：依托单位管理费（系统自动计提，无需自行编报）

> **青年科学基金项目（C 类）实行包干制**：不编报预算明细，按资助总额包干使用（以当年指南为准）。
> **面上/重点项目为预算制**：按三大类编制明细。

### 5.2 经费分配技巧与评审常见扣分
- 业务费应占大头（送样测序/流式/单细胞预留明细）；差旅/会议/出版并入业务费；劳务费依规发放；间接费系统自动计提。
- 扣分点：设备费过高；业务费无明细；劳务费违规发放（分散到 PI 名下）；出差金额过大（"旅游基金"警惕）；预算制项目套用包干制/旧 5 大科目口径。

### 5.3 预算编制工作流
1. 列实验清单（按目标拆解）→ 2. 估算人力/材料/测试/设备费 → 3. 套三大类汇总 → 4. 每项写用途+单价+数量+总额 → 5. 校核不超上限（青年包干制跳过明细）→ 6. 依托单位科研处预审（**关键**，避免形式退回）

## 六、写作铁律与红线

### 6.1 立项依据写作铁律
- **漏斗式论证**：领域广 → 共识 → 空白 → 本课题
- **每段一句话主旨**：第一句写"段意"（评审扫读 5 秒能抓）
- **引文密度** 30-60 条，与目标字数匹配；关键支撑用 primary
- **三大空白**：必须找出 3 个清晰空白，每空对应拟解决科学问题
- **避免**："本研究将系统研究""深入探讨""丰富/完善/填补"等套话（2026 改革明确反对）

### 6.2 创新点写作铁律（归于（二）研究内容）
- 3 条以内，每条 1-2 句；可验证/可量化；动词清晰（"首次证明""构建""发现"）
- 与研究内容一一对应
- 禁："首次发现 X 在 Y 中的作用"（除非文献确凿）；"国际领先/国内领先/国际先进"

### 6.3 假说句式（必须可检验）
> "在 **X 模型** 中，**Y 干预** 通过 **Z 机制** 影响 **W 结局**，表现为 **M 指标** 的 **N** 改变（如蛋白水平↑X%、mRNA ↑X 倍、行为学↑X%）。"

### 6.4 红线（不允许）
- ❌ 编造预实验数据 / 文献 / PMID / DOI（学风红线）
- ❌ 虚增经费；抄袭（iThenticate 自检 < 15%）
- ❌ 漏写伦理批号；数据/试剂未注明来源；合作者姓名/单位未事先取得同意
- ❌ 改动正文提纲标题或括号文字（形式审查红线）

## 八、双盲评审策略

### 8.1 何为"双盲"
NSFC 通讯评审一般采取"双盲"（评审不知申请者身份）。申请书应：
- 不写"我们既往在 XXX 发表"——改为"课题组前期研究"
- 引用课题组论文时统一"课题组"，避免"我们/本研究组/本团队"
- 前期数据匿名化标签（Group A/B，避免显示可识别 PI 的细节）

### 8.2 关键词策略
- 关键词 3-5 个，中-英文混合或全英文，避免拼写错
- 必含"代码最适配"关键词（如"创伤""脑损伤""关键死亡表型"等）；1-2 机制词 + 1 模型词 + 1 细胞/分子 + 1 方法/通路；不堆 6-8 个

### 8.3 评审常见"硬扣分"
立项依据逻辑不清；创新点模糊无实质；研究方案不可行（n 不足/模型不可行/统计错误）；缺可行性分析/前期数据；经费不合理；文本格式不合规范（含超页数、改提纲标题）。
