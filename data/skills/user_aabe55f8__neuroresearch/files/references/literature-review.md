# 文献综述与开题工作流

本指南用于系统性文献综述、选题、开题报告和研究背景写作。融合 AutoResearchClaw 的文献发现阶段（Phase B）与 nature-skills 的学术规范。

## 一、文献综述流程（PRISMA 导向）

### Step 0：先冻结研究问题（freeze RQs，先于一切检索）

动手检索前，先把"课题"冻结成 **2–3 个具体可答的研究问题（RQ）+ 角度 + 目标读者**。综述的结论必须逐条回答这些 RQ；漂移不允许。

- 用户只给主题（如"综述一下分子X"）→ 用 1–2 个澄清问题转成 RQ：
  - "分子X 在 TBI 中的表达时序与细胞来源？"（RQ1）
  - "其下游促炎/抗炎转换是否有因果证据（rescue/敲除）？"（RQ2）
  - "跨疾病（卒中/神经退行）保守性如何？"（RQ3）
- **Brief = 主题 + RQ + 角度 + 读者**。后续每步向该 Brief 负责（详见 §七）。

### Step 1: 明确范围（PICO/PECO 框架）
先与用户确认综述的核心维度：
- **P (Population)**：研究对象（患者？动物模型？特定年龄段？特定细胞类型？）
- **I/E (Intervention/Exposure)**：干预或暴露（治疗？药物？损伤类型？基因突变？）
- **C (Comparison)**：对照组（假手术？野生型？健康对照？）
- **O (Outcome)**：结局指标（神经功能？BBB 完整性？生存？炎症因子？认知评分？）

### Step 2: 制定检索策略
1. 从 `references/domain-lexicon.md` 加载专业检索词库（选取相关词条）
2. 构建多维度检索式（疾病 + 机制 + 方法）
3. 多源检索：
   - PubMed（直接用 WebSearch/WebFetch 或 E-utilities API，流程见 `references/litsearch-protocol.md`；若已装 `nature-academic-search` 可优先调用作加速器）
   - arXiv（如有计算/数学建模内容）
   - 预印本（bioRxiv/medRxiv）
   - Europe PMC / Google Scholar（补充）
4. **保存每个检索式**（满足 PRISMA 可复现要求）
   - **检索视角须覆盖对抗式多视角**（主流学派 / 批评者 / 相邻学科 / 方法学 / 转化与政策），每个视角独立检索、宽→窄；具体视角清单与关键词模板见 §七。仅做"主流视角"会系统性漏掉反驳性/阴性结果与测量方法争议，是综述最易犯的确认偏误。

### Step 3: 筛选
- 一轮筛选：标题+摘要（排除明显无关）
- 二轮筛选：全文（纳入标准 + 排除标准）
- 记录流程图：检索数 → 去重 → 初筛 → 全文 → 最终纳入
- 用 PRISMA 流程图呈现

### Step 4: 知识抽取（知识卡片）
对每篇纳入文献建立卡片：
```
# 文献卡片
- 标题：
- 作者/年份/期刊：
- PMID/DOI：
- 研究类型：动物/临床/体外/生信/综述
- 模型/方法：
- 主要发现：
- 机制关键词：
- 证据等级：高/中/低
- 与我的研究的相关性：
- 可借鉴的方法：
```

### Step 5: 综合与空白识别
1. 按主题聚类文献（如：机制 / 模型 / 干预 / 生物标志物）
2. 识别领域共识与争议点
3. **识别研究空白**（gap）：
   - 哪些机制研究不足？
   - 哪些人群/模型未被覆盖？
   - 哪些方法有局限？
4. 生成可检验假设（见下）

### Step 6: 引用验证
- 逐条核验每条引用（流程见 `references/citation-verification.md`；若已装 `nature-ref-verifier` 可优先调用作加速器）
- 随机抽查 PMID 是否真实可查
- 确保无编造引用

## 二、识别研究空白 → 生成假设

### 空白类型（Gap 分类）
| 类型 | 描述 | 示例 |
|------|------|------|
| 机制空白 | 某通路机制不明 | 某疾病中小胶质细胞亚群转变的分子开关 |
| 人群空白 | 某人群未研究 | 老年/女性/特定基因型人群 |
| 方法空白 | 技术局限 | 缺乏活体动态监测方法 |
| 治疗空白 | 无有效干预 | 疾病无靶向药物 |
| 模型空白 | 模型不完善 | 缺乏模拟慢性期的体外模型 |

### 好假设的标准（可检验性）
- **Falsifiable**（可证伪）：有明确预测
- **可测量**：结局能量化
- **有机制依据**：基于文献证据
- **有干预价值**：回答"所以呢"的问题

### 假设句式模板
> "在 [模型] 中，[干预] 通过 [机制] 影响 [结局]，表现为 [可测量指标] 的改变。"

例：在某疾病小鼠模型中，靶向某受体通过调节小胶质细胞从促炎向抗炎表型转变，减轻神经炎症并改善认知功能（用行为学 + 炎症因子定量评估）。

## 三、开题报告结构

```
一、选题背景与研究意义
   - 疾病负担（流行病学）
   - 现有研究进展
   - 拟解决的科学问题
二、国内外研究现状（文献综述部分）
   - 分主题综述
   - 研究空白与争议
三、研究内容与目标
   - 总体目标
   - 具体研究内容（2-3个）
四、研究方案与技术路线
   - 实验设计（参见 experiment-design.md）
   - 技术路线图
五、创新点
   - 理论创新 / 方法创新 / 应用创新
六、预期成果
七、研究基础与条件
八、参考文献
```

## 四、综述文章写作要点（nature-skills 规范）

### 结构
- **Title**：信息量大、含关键词
- **Abstract**：背景→方法→主要发现→结论
- **Introduction**：由宽到窄，引出综述主题与空白
- **Body**：按主题/年代/机制分层，用图/表归纳
- **Research gaps & future directions**：明确空白
- **Conclusion**：总结性判断
- **References**：规范格式，真实可查

### 写作原则
1. **批判性而非描述性**：不只罗列，要比较、评价、指出局限
2. **图表归纳**：用机制图/流程图/汇总表呈现复杂信息
3. **避免"文献堆砌"**：每段有论点，引用为论点服务
4. **术语统一**：全文一致使用标准术语
5. **中文产出**：结构与英文一致；引用格式按目标刊要求（见 manuscript-and-submission.md §4 中文期刊格式），中文稿默认 GB/T 7714 顺序编码制。

## 五、文献管理建议

### 工具
- **Zotero/EndNote**：文献管理 + 引用插入
- **Obsidian**（本地双向链接知识库，无需专用 skill）：建立文献笔记
- **表格**（配合 `tencent sheetagent`，或用 Python pandas/openpyxl 直接读写 .xlsx；内置 fallback）：维护纳入文献清单

### 文献笔记组织（Obsidian 双向链接）
```
[[神经炎症]] ← 文献1, 文献2
[[小胶质细胞极化]] ← 文献1, 文献3
[[血脑屏障]] ← 文献4, 文献5
```
按机制/主题组织笔记，形成可复用的知识网络。

## 七、对抗式检索视角与生物医学证据标准（借鉴 Supervisor-Skills deep-research）

> 把"综述级文献调研"从"搜到什么写什么"升级为"多视角对抗 + 证据分级"。仅做主流视角会落入确认偏误；生物医学证据须按研究设计/证据类型定权重，不能把生信关联与 RCT 同等对待。

### 7.1 先冻结研究问题（freeze RQs）
见 Step 0。Brief 必须含可答 RQ；综述结论逐条回答 RQ，不先宣布结论后补佐证（evidence-first 叙述）。

### 7.2 对抗式检索视角（各独立检索，宽→窄）

| 视角 | 目的 | 关键词模板（神经科学示例） |
|------|------|--------------------------|
| **主流学派** | 谁在推进此方向、用什么 | 疾病×机制×模型（标准检索式，见 `litsearch-protocol.md` §二） |
| **批评者** | 谁质疑、反证据/阴性结果 | 追加 `NOT` + `limitation / controversy / failed / negative / null / refute`；主动检索反驳性/阴性的工作 |
| **相邻学科** | 跨疾病共用机制 | TBI↔卒中↔神经退行 共用机制词（如小胶质细胞、焦亡、溶酶体）；跨物种借词 |
| **方法学** | 谁挑战"怎么测" | `meta-analysis / systematic review / bias / heterogeneity / reproducibility / PRISMA` |
| **转化与政策** | 临床/监管证据 | `clinical trial / FDA / NMPA / guideline / translational / phase` |

每视角先宽（核心词）后窄（首轮返回的方法名/数据集名/术语）。多视角并行（环境支持子代理则每视角一个 agent）；合并后查盲区：某视角几乎无返回（真空白 or 关键词错？）、无视角覆盖的子方向、被纳入文献高频引用却不在池中的工作。

### 7.3 生物医学证据标准（按证据类型定权重）

综述/标书中引用证据时，显式标注证据类型；读者据此权衡。权重：**人 > 非人灵长 > 啮齿/其他**；**RCT/队列 > 病例 > 体外 > 纯生信关联**。

| 证据类型 | 权重参考 | 书写时注意 |
|---------|---------|-----------|
| 随机对照试验（RCT）/ 人队列 | 高 | 报样本量 n、随访时长、效应量+CI |
| 非人灵长/大型动物 | 中高 | 标注物种、n、时间点 |
| 啮齿/小动物体内 | 中 | 标注品系、性别、n、假手术对照 |
| 体外（细胞/类器官） | 中低 | 标注细胞系/原代、重复次数；相关≠因果 |
| 生信（RNA-seq/scRNA-seq/富集） | 低（假说生成级） | **不得**当机制验证；标注为准发现（hypothesis-generating） |
| 综述/meta 分析 | 依纳入研究 | 引原始研究优于二手；meta 优先于叙述性综述 |

> 跨证据类型报告时，分离"模型预测 / 观察性归因 / 田野实验"，并带不确定范围（与 `statistical-analysis.md` 效应量报告一致）。

### 7.4 证据优先叙述（evidence-first）
Introduction 提问题 → Body 发展证据 → Conclusion 回答问题；结论由证据得出，读者随文推导，而非先宣布后补引文。矛盾证据用条件分析呈现（不平均掉），这是综述对自身确认偏误的防御。

### 7.5 六道内部质量门（静默运行）
| 门 | 一句话 | 失败路由 |
|----|--------|---------|
| Angle | 有判断，还是只是罗列？ | CRITICAL → 回 Step 0 |
| Coverage | 关键工作都找到？ | MAJOR → 定向补搜 |
| Citation | 文献真实、诚实引用？ | CRITICAL → 重核验、删编造 |
| Taxonomy | 按主题 MECE 组织？ | MAJOR → 重设轴 |
| Calibration | 声称强度匹配证据？ | MAJOR → 重校准措辞 |
| Weaving | 句内交叉对比存在？ | MAJOR → 重写标红段 |

迭代至全部门 CLEAR、自对抗复查不再纠错；深度由主题复杂度驱动，非固定轮数。
