# 实验设计指南：神经科学通用版

本指南用于神经科学实验方案设计，覆盖常见动物模型选择、体外模型、样本量计算与实验方案模板。借鉴 AutoResearchClaw 的实验设计阶段（Phase D）与 nature-skills 的严谨性规范。使用时按具体研究方向选取相关模型。

## 三、实验设计核心原则

> **⚠️ 最常踩的坑：「常见 n」≠「功效 n」**。领域惯例（行为学 8–12 只、分子 4–6 只）只是**下限参考，并非功效分析结果**。按本节能效公式，大效应量 d=0.8 就需 ≈26/组才达 power=0.8；若效应更小（d=0.5 约 64/组，d=0.2 需 >300/组），8–12 只属**严重欠功效**、极易假阴性。务必先用预实验/文献效应量**算 n** 再定每组数；投稿时审稿人会要求功效分析依据。详细论证见下方 §三.2。

### 1. 分组设计
- **对照完整性**：假手术组（sham）+ 模型组 + 干预组 + 阳性对照
- **随机化**：随机分组（避免偏倚）
- **盲法**：评估者盲（行为学、病理评分）
- **性别因素**：考虑雌雄差异（许多神经系统疾病存在性别二态性）

### 2. 样本量计算（功效分析）
```
公式：n = 2×(Zα/2 + Zβ)² × σ² / δ²
常用软件：G*Power / R pwr 包
参数：α=0.05, power=0.80
效应量：参照文献或预实验
```
参考 R 代码：
```r
library(pwr)
pwr.t.test(d = 0.8, sig.level = 0.05, power = 0.8, type = "two.sample")
# 大效应量 d=0.8 → 每组约 26 只
```
```python
# 本环境（Python）等效实现：
from statsmodels.stats.power import TTestIndPower
n = TTestIndPower().solve_power(effect_size=0.8, alpha=0.05,
                                power=0.8, alternative='two-sided')
print(round(n))   # ≈ 26
```
**常见 n 参考**：行为学每组 8-12 只，分子/生化每组 4-6 只（3 次独立重复）。

> **⚠️ 功效 n 警示**：见本节顶部红框——「常见 n」≠「功效 n」，务必用预实验/文献效应量**先算 n** 再定每组动物数（投稿时审稿人会要求功效分析依据）。

### 3. 时间点设计（急性损伤示例）
| 时间点 | 观察内容 |
|--------|---------|
| 1-6 h | 急性期：兴奋性毒性、氧化应激、急性炎症 |
| 24-72 h | 亚急性：胶质细胞活化、BBB 破坏高峰 |
| 7-14 d | 修复期：星形胶质增生、神经发生 |
| 28-90 d | 慢性期：认知功能、蛋白病理、萎缩 |

### 5. 引用格式（默认顺序编码制，numbered）
- **默认 numbered**：正文引用用方括号序号 `[1]`、`[1,3]`、`[1-5]`，按首次出现顺序连续编号；文末「参考文献」依序号排列。**实验设计/方案文档的参考文献同样遵循此默认**，与 Nature 系及国内中文核心期刊一致。
- **例外**：仅当目标刊明确强制时才用作者-年制 `(Author, Year)`；默认一律不采用。
- 格式细则与冷门类型（预印本/数据集/软件/会议/书章等）见 `references/citation-formatting.md`；引用真实性须经 `references/citation-verification.md` 核验。

## 六、常见陷阱

- ⚠️ **样本量不足**：功效不足导致假阴性
- ⚠️ **无盲法**：评估者偏倚
- ⚠️ **时间点单一**：错过关键动态变化
- ⚠️ **忽略性别**：神经系统疾病存在性别差异
- ⚠️ **模型选择不当**：研究目标与模型病理不匹配
- ⚠️ **无预实验**：效应量估计不准
- ⚠️ **干预时间不合理**：药物给药时间点不当
- ⚠️ **转基因模型品系背景**：确认同窝对照（littermate control）
