# 论文写作、润色与投稿指南

本指南用于科研论文的写作、润色、模拟审稿、引用验证与投稿流程。融合 nature-skills 的写作/润色/审稿/引用验证规范与 AutoResearchClaw 的质量控制阶段（Phase G）。

## 一、论文写作流程

### 1.1 目标期刊定位
先与用户确认投稿目标，决定写作风格与篇幅：
| 期刊类型 | 篇幅 | 结构特点 | 示例 |
|---------|------|---------|------|
| 顶级综合 | 4000-5000词 | 紧凑、摘要突出 | Nature/Cell/Science |
| 专科旗舰 | 5000-7000词 | 标准 IMRaD | J Neurosci, Brain |
| 专业期刊 | 6000-8000词 | 详细方法 | Neurobiol Dis |
| 综述 | 8000-12000词 | 主题分层 | Nat Rev Neurosci |
| 中文核心 | 4000-6000 字 | 标准 IMRaD / 中文结构 | 中华神经科杂志、中国神经精神疾病杂志、中国脑血管病杂志等 |

### 1.2 IMRaD 结构写作要点

#### Title
- 信息量优先，包含关键发现
- 字数限制（多数期刊 ≤15 词）
- 避免夸大（"first evidence" 需谨慎）

#### Abstract
- 结构化（Background/Methods/Results/Conclusions）
- 250 词左右（按期刊要求）
- 结果部分给出具体数值与统计量

#### Introduction（漏斗式）
1. 从疾病/问题的广泛背景开始
2. 收窄到已知机制与未解决问题
3. 明确提出研究假设与目的
4. 最后一段概述主要发现与意义

#### Methods
- 完整可复现：模型、分组、n、时间点、统计
- 动物实验遵循 ARRIVE
- 引用已发表方法（避免全部重写）
- 试剂注明货号/公司

#### Results
- 先结果后解释（避免在 Results 过度讨论）
- 图-表-文对应，不重复
- 报告统计完整性（参见 statistical-analysis.md）
- 按逻辑顺序呈现，每图一个要点

#### Discussion
- 总结主要发现（1段）
- 与既往文献对比（支持与矛盾）
- 机制解释（结合通路图）
- 局限性（诚实的局限）
- 结论与展望（不夸大）

### 1.3 图表组织
- 主图 4-6 张，补充图不限
- 图注完整自足（不读正文也能懂）
- 图内统计标注规范（*p<0.05, **p<0.01, ***p<0.001）
- 机制示意图（graphical abstract 加分）

## 二、学术润色要点（nature-polishing 思路）

### 2.1 语言层面
- **被动语态与主动语态平衡**：方法用被动，结论可用主动
- **动词精确**：demonstrate/suggest/indicate 的使用强度分级
- **避免中式英语**："can be seen from the table" → "Table 1 shows"
- **避免冗余**："in order to" → "to"，"due to the fact that" → "because"
- **时态一致**：结果用过去时，通用真理用现在时

### 2.2 学术表达强度分级（谨慎用词）
| 强度 | 动词/短语 | 适用 |
|------|---------|------|
| 强 | demonstrate, prove, establish | 有直接证据 |
| 中 | suggest, indicate, support | 有间接证据 |
| 弱 | imply, may, could, appear | 推测性 |

### 2.3 润色检查清单
- [ ] 术语统一（全文同一术语同一种写法）
- [ ] 缩写首次出现给出全称
- [ ] 数值精度一致（保留位数统一）
- [ ] 单位规范（SI 单位）
- [ ] 统计描述完整（检验+校正+n）
- [ ] 声称漂移检查（结果 vs 摘要 vs 结论是否一致）

## 三、模拟审稿（nature-reviewer 思路）

以审稿人视角自检论文，输出三份独立审稿意见：

### 3.1 审稿维度
| 维度 | 检查内容 |
|------|---------|
| 创新性 | 是否真正新颖？增量贡献？ |
| 方法严谨性 | 样本量、盲法、对照组、统计方法 |
| 证据一致性 | 结论是否被数据支持 |
| 数据完整性 | 缺失数据、未报道阴性结果 |
| 引用准确性 | 引用是否支持论点、有无遗漏 |
| 可重复性 | 方法是否足够详细 |
| 写作质量 | 逻辑、清晰度、图表 |

### 3.2 常见审稿意见模板
**Major concerns（通常 3-5 条）：**
1. 样本量不足/功效分析缺失
2. 缺少关键对照
3. 统计方法不当（未校正多重比较）
4. 机制证据不足（相关≠因果）
5. 关键实验缺时间点

**Minor concerns：**
1. 图注不完整
2. 缩写未定义
3. 引用格式错误
4. 语言问题

> 上述每条审稿意见**必须**按 §9.5 的 CRITICAL / MAJOR / MINOR 严重度分级标记；≥1 个未解决的 CRITICAL 即禁止"可投稿"结论。

### 3.3 预投稿自检清单
- [ ] 用模拟审稿找出 3 个最可能被拒的理由并提前补实验
- [ ] 统计审查（对照 statistical-analysis.md）
- [ ] 引用验证（见下）
- [ ] 查重（iThenticate 相似度 <15%）
- [ ] 伦理声明完整

## 四、引用规范与验证（正文引用 + 核验，合并处理省返工）

### 4.1 正文引用规范（默认采用序号制，写时即用对）
- **格式：顺序编码制（序号引用）—— 全篇统一标准**。正文用数字序号标注，如 `[1]`、`[1,3]`、`[1-5]` 或上标 ¹；按引用在正文首次出现的先后顺序连续编号，文末参考文献列表依序号顺序排列。这是神经科学绝大多数期刊（Nature、Cell、Science、Neuron、J Neurosci、Brain、Stroke、Neurobiol Dis 等）及国内中文期刊的默认格式。
- **（例外）作者-年制**：仅在目标期刊明确强制时才用 `(Author, Year)` 并按字母序排（如部分 APA 心理学期刊、少量综述刊）；默认不采用，且需在投稿前确认刊方要求。
- **中文期刊（GB/T 7714-2015）**：国内中文核心/科技期刊普遍采用 **顺序编码制**（序号 `[1]`），与上文默认一致；少数社科/心理类用 **著者-出版年制**。投稿前务必查阅目标刊《投稿须知》并以期刊模板为准；中文文献条目格式示例：`[n] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页.`
- **位置**：序号置于所支撑断言的句末标点之前，如 `…观察到小胶质细胞活化[3]。`；多句共用同一结论时置于结论句；图表/公式内引用同样用序号。
- **标点与排版**：序号一般用方括号 `[n]`，可随刊用上标；同句多个文献用逗号或连字符合并（如 `[2,5]`、`[7-9]`），避免重复罗列。
- **何时引**：①支撑事实/数据/方法；②对立或一致观点；③借用图表/量表。不引常识，不引未发表数据作证据。
- **一次一源**：关键结论尽量引 primary，禁止用综述代替原始文献（二手引用）。
- **数量**：研究论文 30–60 条、综述 80–150 条（按刊），重质不重量。
- **标识**：正式稿补齐每条 DOI；预印本标注 bioRxiv/medRxiv 及版本/DOI。

### 4.2 引用验证流程（内置 citation-verification.md 协议，批量做）
1. 抽取全文引用 → 建核验表（序号 | 文中文本 | 期望 作者/年/刊/卷/页 | DOI/PMID | 状态）。
2. 逐条核对字段：作者、年份、期刊、卷期、页码与源一致。
3. 工具核验真实性（见 4.3），标记 ✅一致 / ⚠️待核 / ❌可疑（编造、卷期错、页码偏差、张冠李戴）。
4. 重点查：随机抽查 3–5 条 + 所有"关键支撑"文献。
5. 修正后复验，确保 0 条 ❌ 再投稿。

### 4.3 验证工具与模板
- 内置协议优先：严格按 `references/citation-verification.md` 逐条核验 PMID/DOI（**无需外部技能**即可完成）。若环境已装 `nature-ref-verifier` / `nature-citation`，可调用作加速器提速，但不可因其不可用而跳过核验。
- 兜底：PubMed API（`eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pubmed&term=<PMID>`）或 Europe PMC 按 DOI 查。
- 单条模板：`[序号] 文中(Author YYYY Journal) → PMID/DOI=xxx → 标题✓? 卷期✓? → ✅/❌`。

### 4.4 常见错误（自检清单）
- ❌ 编造文献/PMID/DOI/作者；❌ 作者/年/卷期不匹配
- ❌ 二手引用（引 A 实则来自 B）；❌ 用不相关文献撑论点
- ❌ 正文编号与文末列表错位；❌ 缺 DOI / 预印本未标版本

## 五、投稿流程

### 5.1 投稿前准备
1. Cover letter（投稿信）要点：
   - 研究意义（1-2句亮点）
   - 为什么适合该期刊
   - 声明原创性、未一稿多投
   - 推荐审稿人（可选，含排除名单）
2. 推荐审稿人：选择该领域活跃学者（注意避免利益冲突）
3. 图形摘要（Graphical abstract，如需要）
4. 数据可用性声明（Data Availability）
5. 补充材料整理

### 5.2 投稿系统操作
- 常见系统：Editorial Manager / ScholarOne / eJournalPress
- 逐项核对清单（作者信息、伦理、利益冲突、数据）
- 投稿状态跟踪：Submitted → With Editor → Under Review → Decision

### 5.3 返修回复（nature-response 思路）
**结构：**
```
# Response to Reviewers
## Reviewer 1
### Comment 1:
[审稿意见原文]
### Response:
[逐条回复：做了什么修改 + 修改位置（行号/页码）]
```
**要点：**
- 礼貌、逐条回复、不遗漏
- 修改处标红或注明行号
- 无法修改的给出合理理由
- 每轮返修附 Response Letter 和标记修订稿

### 5.4 常见投稿问题
- 一稿多投（禁止）
- 图片重复使用/篡改（学术不端，需保留原始数据）
- 作者贡献不明确
- 伦理审批缺失
- 数据可用性声明缺失

## 七、标书/基金写作（开题延伸）

### 结构（以国自然/NSF 为例）
1. 摘要（400字内，突出创新）
2. 立项依据（研究现状+科学问题）
3. 研究内容与目标
4. 研究方案与技术路线
5. 可行性分析
6. 创新点（3条以内，具体）
7. 研究基础与工作条件
8. 预期成果

### 标书写作要点
- **立项依据**：逻辑链清晰，从"已知"推"未知"
- **科学问题**：凝练为"研究假说"
- **技术路线图**：一目了然
- **创新点**：具体可验证，不空泛
- **可行性**：预实验数据+团队优势

## 九、五段式编辑审计与声明-证据匹配（anti-overclaim）

> 借鉴 SciWrite（Stanford *Writing in the Sciences* 衍生）的五段式编辑审计，与公开科研 skill 的 zero-hallucination 理念。所有论文与 NSFC 标书在定稿前**必须**过一遍本审计——尤其「声明-证据匹配」，直接决定评审对"过度声称"的扣分。

### 9.1 五段式编辑审计清单
| 段落 | 审计重点 | 检查项 |
|------|---------|--------|
| **Clarity（清晰）** | 无歧义、无 jargon 堆砌 | 每句一个主谓宾；缩写已定义；数值单位明确 |
| **Voice（语气）** | 主动/被动一致、强度一致 | 结果用客观陈述；避免 "we believe" 式主观 |
| **Structure（结构）** | 逻辑链完整 | IMRaD/标书各节衔接无断点；每段有主题句 |
| **Consistency（一致）** | 术语/数据/声称一致 | 全文同一术语同写法；结果/摘要/结论数值一致（见 §2.3） |
| **Integrity（诚信）** | 反过度声称、数据真实 | 每条结论 bind 证据；无编造/无选择性报告 |

### 9.2 声明-证据匹配矩阵（anti-overclaim 核心）
每条结论性陈述落笔前先填下表：
| 声明（claim） | 证据类型 | 强度 | 支撑文献/数据 | 是否过度 |
|---|---|---|---|---|
| "分子X 下调促进细胞B 死亡表型" | 体内 WB + 体外条件培养基实验 | 中（间接因果） | Fig.3, [12] | 否 |
| "细胞A 激活是损伤唯一驱动" | — | — | 缺直接证据 | **是 → 降级** |

**强度分级**（与 §2.2 动词强度对应）：
- 直接证据（敲除/过表达 + rescue）→ 可用 `demonstrate` / `establish`
- 间接证据（相关/抑制）→ `suggest` / `indicate`
- 推测 → `may` / `could`；**禁止**在缺证据时用强动词

### 9.3 过度声称红名单（定稿前逐条排查）
- ❌ "首次证明 / first evidence" —— 除非已做文献排他性检索
- ❌ "揭示机制" —— 相关 ≠ 因果，未做 rescue/过表达则只能说"提示参与"
- ❌ "治疗潜力" —— 仅细胞/动物数据不可称"治疗"，用"潜在干预靶点"
- ❌ 选择性报告阳性、隐去阴性结果
- ❌ 把富集分析（GO/KEGG）当机制验证

> 与 §9.6 禁用 AI 腔词表、§9.7 写作红旗清单联动自检：定稿前逐条扫描全文。

### 9.4 NSFC 标书特化
- **立项依据**：每个"科学问题"前须有文献/预实验支撑，禁止空泛铺垫
- **创新点**：3 条以内、可验证；"新"须对标已有研究说明差异
- **可行性**：预实验数据 → 标注 n 与统计；团队优势 → 用他引审计（`citation-impact-audit.md`）量化
- 标书声称 → 绑定预实验图/表编号，避免把"将开展"当"已证明"

### 9.5 审稿发现严重度分级（CRITICAL / MAJOR / MINOR）

> 借鉴 *Supervisor-Skills · pre-submission-reviewer* 的严重度分级。模拟审稿（§3）与定稿审计（§九）输出的**每条发现须带严重度标签**，便于作者按优先级修；整体结论必须与发现一致（任一未解决 CRITICAL 即禁止"可投稿"）。

| 严重度 | 含义 | 神经科学示例（阻塞/首轮必被提） |
|--------|------|-------------------------------|
| **CRITICAL** | 阻塞投稿，须修后方可投 | 贡献与章节不对应；Introduction 逻辑链断裂；缺关键对照（假手术/野生型/vehicle）；真实结果被自己数据反驳；图用位图而非矢量；缺关键基线；页面超限 |
| **MAJOR** | 审稿人首轮必提 | ≥3 段缺主题句；破折号滥用 ≥5 处；禁用 AI 腔词出现 ≥3 次；Table 1 对比缺失；图类型与数据不匹配；归因未隔离（缺 rescue/ablation） |
| **MINOR** | 润色 | 两句长句可拆；默认 matplotlib 灰底样式；单个冠词错误；图内字号偏小 |

**结论纪律**：列了十几个 MINOR 却漏掉唯一一个 CRITICAL 的审稿，会给作者虚假安全感；把口味问题 inflate 成 CRITICAL 则破坏信任。最终推荐须匹配发现：任一未解决 CRITICAL → "不可投稿"；近可投结论要求 0 CRITICAL 且 ≤2 MAJOR。

### 9.6 禁用 AI 腔词表 + 破折号禁令（全文自检）

> 过度声称与 AI 腔是神经科学稿件头号退稿诱因。定稿前对全文扫描下表词汇与破折号。

**禁用 / 慎用 AI 腔词（出现即标 MAJOR，≥3 次则强制改写）：**

| 类别 | 词（中/英） | 替代（神经科学稳妥写法） |
|------|-----------|------------------------|
| 夸大首创 | 首创、首次证明、first evidence、unprecedented、novel（滥用）、groundbreaking | 有据时写"据我们所知首次在 X 模型中报道"，并附排他检索 |
| 革命性 | 革命性、revolutionary、paradigm shift、transformative、pioneering | 删除或改"改变了 X 的认知" |
|  superiority | superior、surpass、excel、outperforms | "在 X 指标上高于"（给数值与统计） |
| 空洞赞词 | remarkable、breakthrough、comprehensive、general-purpose、profound | 删除，用具体发现替代 |
| 连接滥词 | yet、notably、yielding、at its essence、encompass、underscore、reveal、pave the way for、highlight the potential of、stems from、rigid、impede、differentiate | 删或换具体动词 |
| 神经科学特化过度声称 | "揭示机制"（相关≠因果）、"治疗潜力"（仅细胞/动物）、"唯一驱动"、"根本性解决" | "提示参与"、"潜在干预靶点"、"主要贡献因素之一" |

**破折号（——）禁令**：破折号**不作为句间连接符**（英文 em-dash `—` 同理）。中文用逗号/句号断句，英文用逗号/分号。出现 ≥5 处标 MAJOR，逐处改。

### 9.7 写作时红旗清单（证据等级 L0–L3 门控）

> 借鉴 *Supervisor-Skills · paper-writer* 的"证据门控写作"。落笔前每条事实声明须溯源到 L0–L3 之一；**声明强度不得高于证据强度**；真实结果与计划/预期结果须分开写。

**证据等级（写入时自检）：**

| 等级 | 来源 | 可支撑的声明强度 |
|------|------|----------------|
| **L0** | 领域常识（无数字/名称/对比） | 可直接写，不经检索 |
| **L1** | 用户材料 / 已核验全文（数据、方法、结果） | 支撑任何强度 |
| **L2** | 用户材料 / 检索得到的摘要级结论（方向性） | 仅支撑方向性总结 |
| **L3** | 仅元数据（作者/年/刊，无全文） | 仅支撑"引用级"陈述（"X 等研究了 Y"）；**不得**写具体数字或方法细节 |

**写作时红旗（出现即停手，改检索/改写/删除，绝不编造）：**

| 念头 | 正确动作（神经科学适配） |
|------|------------------------|
| "我记得这个量表有 10 项" | 停。未确认则省略项数 |
| "我记得这篇用了 meta 分析" | 停。无全文则仅引用级 |
| "我记得这个病例/模型的引用号" | 停。一位数字错即错，省略标识符 |
| "这个材料/细胞系的 X 约…" | 停。跨细胞/跨模型对比需用户给数值 |
| "背景应提领域发展" | 停。超 L0 需 L1–L3 来源，检索；无果则不写 |
| "读者期望这里写知情同意" | 停。未提供则省略 |
| "完整表格更专业" | 停。单元格用 `--` 比编造安全百倍 |
| "Discussion 应更充实" | 停。用证据充实，不编造机制；短而准胜长而空 |
| "这方法可用于…（用户未提的场景）" | 停。用户未命名则该场景不写 |
| "因为它通过 X 通路…" | 停。用户未描述此机制则不写 |
| "差异达十倍/数百个…" | 停。用户未给此量级不写 |
| "具体失败案例能说明" | 停。不编领域小故事，用用户自己的描述 |

**通用规则**：① claim strength never exceeds evidence strength（无证据用 may / suggest）；② 真实结果用"we observed / results show"，计划或预期用"preliminary results suggest / the authors report"；③ 同一发现至多出现在 3 个章节；④ 内部规划（证据等级、CER 骨架）绝不泄漏到交付物。
