# neuroresearch 使用文档（速查手册）

> 给使用者的「怎么调、怎么用、产出什么」速查。
> 配合 `SKILL.md`（能力清单）与 `references/`（各模块详细指南）一起看更佳。
> 完整变更历史见 `CHANGELOG.md`。

## 一、什么时候用

**触发关键词**：文献综述/开题/研究背景/选题；生信/组学/差异表达/富集/单细胞；实验设计/动物或细胞模型；统计分析与作图；论文写作/润色/模拟审稿/投稿/返修/标书；提及神经科学、神经元、胶质细胞、突触、脑、CNS 等。

**适用方向**：神经退行（AD/PD/ALS/HD/MS…）、脑血管病（卒中/ICH/CSVD/低灌注）、创伤（TBI/SCI）、神经炎症、神经发育、精神疾病、神经肿瘤等。

## 二、怎么调用

1. **直接说**（推荐）：在对话里描述科研任务，含上述关键词即可触发。
2. **显式指定**：写明"用 neuroresearch"。
3. **多轮协作**：建议分阶段——先定方向 → 出方案 → 分析 → 写作。

**给技能的好上下文**（显著提升产出）：
- 研究方向 / 模型 / 细胞 / 干预（如：CCI 模型、BV2 细胞、某化合物）
- 想回答的**科学问题**或**假设**
- 已有数据形态（RNA-seq FASTQ、WB 灰度值表等）
- 目标产物（综述 Word / 实验设计 Word / 图+统计报告 / 投稿稿）
- 投稿或开题的目标期刊 / 基金类型

## 三、典型任务流程

技能按 7 阶段组织任务（不必一次走完）：

| 阶段 | 名称 | 关键产出 |
|------|------|---------|
| 1 | 定位 | 明确研究问题、模型、目标产物 |
| 2 | 文献发现 | 多源检索 + 保存检索式 |
| 3 | 知识综合 | 文献卡片 + gap 识别 + 可检验假设 |
| 4 | 实验设计 | 模型/分组/功效分析/ARRIVE |
| 5 | 执行与分析 | 生信流程 + 统计分析（脚本可复现） |
| 6 | 写作 | IMRaD + 润色 + 模拟审稿 |
| 7 | 质量与投稿 | 引用验证 + 查重 + Cover letter + 返修 + 标书 |

> 完整 7 阶段说明 + 每阶段对应 `references/` 文件见 `SKILL.md`「模块导航」。

## 五、关键规范（详见 `SKILL.md`「核心原则」「严格禁止」）

- **真实可验证**：引用必有真实 PMID / DOI，**禁止编造**任何文献。
- **可复现**：脚本须含版本 / 参数 / 随机种子；必须实际跑通出结果。
- **统计严谨**：检验方法 + n + 统计量 + df + 精确 p + 效应量 + 多重比较校正——一起出。
- **正式交付默认 .docx**：综述/开题/标书/论文/审稿回复一律按 `academic-word-template.md` 出 Word。
- **文件命名具体化**：`{项目名}_{具体产出}_{YYYY-MM-DD}.ext`，禁笼统命名（如"实验设计.docx"）。
- **引用格式默认序号制 `[1]`**（Vancouver），与 Nature 系 / 国内核心通用；作者-年制仅刊方强制时用。
- **Python 出图走 `prism-style-plot.md`**（内建 `prism_theme.py`），不手搓；纯 matplotlib 兜底见 `plotting-protocol.md`。
- **Python 脚本开头按 `python-runtime.md` 自检依赖**——`sys.executable -m pip` 自动安装，禁"声称跑通而实际未执行"。
- **R 用于生信分析**——本地 R / RStudio 运行 `scripts/bioinfo_rna_seq.R`（DESeq2 + 富集）；绘图统一走 Python 引擎。

## 六、依赖与自包含性

**本技能不依赖任何外部 skill 即可工作**。下列能力已内置实现：

| 能力 | 内置实现 | 可选加速器（装了更好） |
|------|---------|----------------------|
| 文献检索 | `litsearch-protocol.md`（PubMed E-utilities API） | `nature-academic-search` |
| 引用核验 | `citation-verification.md`（E-utilities/Europe PMC/Crossref） | `nature-ref-verifier` |
| 引用格式 | `citation-formatting.md`（Nature + GB/T 7714） | `nature-citation` |
| 投稿级绘图 | `prism-style-plot.md`（内建 `prism_theme.py` 引擎） | —（已内建，无需外部） |
| .docx 文稿 | `academic-word-template.md` + python-docx 兜底 | `tencent-docx` / `html-to-docx` |
| .xlsx 表格 | pandas / openpyxl 直接读写 | `tencent-sheetagent` |

> 若环境提示"缺少某 skill"——无需安装，按内置协议继续即可。

## 七、常见问题（FAQ）

**Q：能做 Meta 分析 / 系统综述吗？**
A：能。走 PRISMA 2020，用 ROBINS-I / Cochrane RoB 2 评估偏倚，输出森林图、漏斗图、亚组与敏感性分析（见 `literature-review.md §六`）。

**Q：检索词 / marker / 期刊清单去哪找？**
A：`references/domain-lexicon.md`（疾病/机制/方法检索词 + 核心期刊 + 数据库 URL）。单细胞 marker 见 `bioinformatics.md §三`。

**Q：怎么保证引用不编造？**
A：按 `citation-verification.md` 协议，用 PubMed E-utilities / Europe PMC / Crossref 逐条核验 PMID/DOI（无需外部 skill），重点查「关键支撑」文献 + 随机抽查 3–5 条，确保 0 条 ❌ 再投稿。

**Q：出图什么格式？**
A：投稿级优先 Python（`prism_theme.py`，本环境预装），输出 PNG/PDF、≥300 dpi、色盲友好配色；图尺寸按 `get_figsize` 预设：tall 3×5 cm / square 5×5 cm / wide 7×5 cm（单栏/双栏按期刊要求缩放到 ≤85/170 mm）。

**Q：中文稿还是英文稿？**
A：都可。综述/开题/标书按中文规范出 .docx；论文按目标期刊英文规范。引用格式默认序号制，与语种无关。

**Q：结果能直接投稿吗？**
A：技能产出"可发表的初稿/分析"；正式投稿前须人工复核统计、引用、伦理声明，并用模拟审稿 + 查重（iThenticate <15%）做最终检查。

**Q：生信数据在哪台机器上跑？**
A：Python 流程在 WorkBuddy 环境（`ensure_env.py` 自动引导 venv）；R 流程在用户本地 R / RStudio（`bioinfo_rna_seq.R`），纯本地运行、**无任何联网上传代码**。

**Q：改了技能怎么自查有没有弄坏？**
A：跑 `scripts/selfcheck.py`——校验版本号 / 文档与磁盘是否一致 + 引擎冒烟回归，退出码 0 即全绿（详见 `references/python-runtime.md` §七）。
