# 成本结算与审计 · 节点详解（references）

> 配套 `cleanroom-cost-settlement` 技能。12 节点，每节点含：目的 / 输入 / 步骤要点 / 审核清单 / 实战经验。
> 全文脱敏，不出现真实项目名、商号、合同成交价、内部额度；责任方仅写通用部门名（成本部 / 采购部 / 工程部 / 资料部门），不写具体职务。

---

## 节点 1 · 结算资料策划与清单

**目的**：竣工前梳理结算所需全部资料，明确每份资料的提供部门与截止节点，避免结算时因缺资料返工、被审计核减。

**输入**：合同、中标通知书、招标文件、图纸（三版）、BOM（三版）、采购合同、到货签收、变更签证、隐蔽验收记录、检测报告、竣工图。

**步骤要点**
- 列**结算资料需求清单**，按资料类别分组：合同类 / 图纸 BOM 类 / 采购类 / 变更签证类 / 隐蔽验收类 / 检测类 / 竣工图类。
- 明确每份资料的**提供部门**（通用部门级）：
  - 成本部：合同、中标通知书、目标成本测算。
  - 采购部：采购合同、到货签收、付款台账、质保金台账。
  - 工程部：设计变更单、现场签证、隐蔽验收记录、施工日志。
  - 资料部门：检测报告（CMA/CNAS）、竣工图、组卷目录。
- 设**资料收集截止节点**（如竣工后若干周内），建立跟踪表。
- **缺项预警**：列出高风险缺项（隐蔽验收记录、变更签字版、合格证原件），提前跟踪。

**实战经验（结算滞后的主因）**
- 结算拖期，八成以上是资料不齐，而非算不准。最易缺的三类：隐蔽工程验收记录、设计变更签字版、材料设备合格证原件。
- 建议**施工过程中即按结算口径预归档**，而非竣工后集中补——事后补签往往不被审计认可（"倒签"风险）。
- 资料提供部门应在施工过程中同步留痕；成本部在节点 1 就把清单发下去，比竣工后催要高效得多。

**审核清单**
- [ ] 资料需求清单是否覆盖合同 / 图纸 BOM / 采购 / 变更 / 隐蔽 / 检测 / 竣工图七类？
- [ ] 每份资料提供部门是否明确（通用部门级）？
- [ ] 是否设收集截止节点并跟踪？
- [ ] 高风险缺项（隐蔽 / 变更签字 / 合格证原件）是否提前预警？

## 节点 2 · 合同价与目标成本基线建立

**目的**：建立结算的"双基线"——对外结算口径（合同价）与对内成本控制口径（目标成本）。

**输入**：中标通知书、施工合同、投标报价、企业成本测算。

**步骤要点**
- **合同价基线**：中标价分解为分部分项 / 措施项目 / 其他项目，形成对外结算对照基准。
- **目标成本基线**：中标价 − 计划毛利 = 目标成本；按专业分解（暖通 / 装饰 / 医疗设备 / 电气 / 给排水 / 医气）作过程管控与最终复盘的共同基准。
- **两线并存**：对外结算（合同价）vs 对内成本（目标成本），二者之差即利润空间，须全程可勾稽。

**实战经验（基线须早锁）**
- 目标成本须在中标后尽早锁定，作为过程成本管控与节点 12 复盘的共同基准；拖到结算再算就失去管控意义。
- 专业占比匡算（洁净手术部通用）：暖通 25%–35% / 医疗设备 20%–30% / 装饰 15%–20% / 电气 10%–15% / 给排水 5%–8% / 医气 5%–8%——作目标成本分解参考，按项目须重确认。
- 口径一致：合同价是否含税、是否含暂列金额，须与投标口径一致，否则结算勾稽错乱。

**审核清单**
- [ ] 合同价是否分解到分部分项 / 措施 / 其他？
- [ ] 目标成本 = 中标价 − 计划毛利 是否分解到专业？
- [ ] 税 / 暂列金额口径是否与投标一致？

## 节点 3 · 量价核对

**目的**：把"量"（BOM 量差）与"价"（采购合同价 / 协议价）核对，形成结算量价基础。

**输入**：BOM 三版及量差分析（物料 BOM 技能节点 12）、采购合同价（采购生命周期技能节点 5）、协议价 / 战略价（供应商评估技能）、到货签收量。

**步骤要点**
- **量**：以 BOM V3（变更后）净用量 + 量差签证为准。
- **价**：以采购合同价 / 协议价 / 战略价为准；无合同价项按同期市场价或信息价。
- **量价交叉**：量 × 价 = 合价，与**设计量 / 清单量 / 合同量**三维勾稽。
- **量差归因**：设计 / 施工 / 供应三分因（与物料 BOM 技能节点 12 同一口径）。

**实战经验（价的主依据）**
- 采购合同价是结算"价"的主依据；协议价 / 战略价（供应商评估技能）优先于临时询价。
- BOM 量差分析（物料 BOM 技能节点 12）已分五类成因（正常调量 / 班组 / 项目 / 预算 / 图纸），结算量价核对沿用同一口径，避免两套标准。
- 到货签收量是"实收量"基准，与采购合同量核对可发现短装 / 超装（供应差）。

**审核清单**
- [ ] 量是否基于 BOM V3 + 签证？
- [ ] 价是否基于合同价 / 协议价？
- [ ] 量价合价是否与设计量 / 清单量 / 合同量三维一致？
- [ ] 量差是否按 设计 / 施工 / 供应 三分因？

## 节点 4 · 变更签证管理与计价

**目的**：把施工过程的设计变更、现场签证转化为结算价款。

**输入**：设计变更单、现场签证单、隐蔽验收记录（施工竣工资料技能节点 4）、BOM 版本链（物料 BOM 技能节点 10）。

**步骤要点**
- **签证收集**：汇总所有经签认的变更 / 签证（含图号 / 指令号）。
- **计价口径**：合同有单价按合同 → 无则按类似项目单价 → 市场价 → 信息价 → 组价（新增项）。
- **量**：以变更后 BOM 量差（物料 BOM 技能节点 10 / 12）为准。
- **时效**：签证须在合同约定期限内报送，逾期可能不被认可。

**实战经验（最大波动源）**
- 变更签证是结算金额波动的最大来源之一，须全过程留痕（图号 / 指令号 / 量 / 价 / 签字）。
- 隐蔽工程签证最易争议——须有隐蔽验收记录（施工竣工资料技能）+ 影像支撑，否则审计易按"无依据"核减。
- 计价顺序严格遵守：合同单价优先，避免"无合同就高套"。

**审核清单**
- [ ] 签证是否全部经签认且在时效内？
- [ ] 计价口径是否一致（合同 → 类似 → 市场 → 组价）？
- [ ] 隐蔽项是否有验收记录 + 影像？
- [ ] 是否关联原图号 / 指令号？

## 节点 5 · 材料设备价款结算

**目的**：与供应商 / 分包办理材料设备价款结算，对账付款、释放质保金。

**输入**：采购合同（采购生命周期技能节点 5）、到货签收（节点 8）、请购 / 验收记录（物料 BOM 技能节点 7）、付款台账（节点 6）。

**步骤要点**
- **对账**：合同量 vs 到货签收量 vs 验收合格量，剔除退换 / 不合格。
- **计价**：合同单价 × 合格量 + 变更增补 − 扣款（违约 / 质量）= 应付。
- **付款**：按合同节奏（预付款 / 发货款 / 验收款 / 质保金），质保金期满释放。
- **质保金**：留 3%–5%，期满无争议释放；可约定阶段释放。

**实战经验（以合格量为准）**
- 材料设备结算以"合格量"为准（到货 − 退换 − 不合格），到货量 ≠ 结算量。
- 付款台账（采购生命周期技能节点 6）是质保金释放与争议对账的依据。
- 甲供材料结算界面：甲供超供 / 损耗责任按合同书面界定（参考物料 BOM 技能节点 4）。

**审核清单**
- [ ] 结算量是否为合格量（到货 − 退换 − 不合格）？
- [ ] 付款节奏 / 质保金是否按合同？
- [ ] 甲供界面责任是否清晰书面界定？

## 节点 6 · 索赔与反索赔

**目的**：处理工期 / 费用索赔，维护企业权益。

**输入**：合同工期条款、业主指令、不可抗力证明、停工通知、费用支出凭证。

**步骤要点**
- **索赔识别**：业主原因（变更 / 延期 / 指令）导致的费用 / 工期损失。
- **证据链**：指令 + 影响 + 费用计算，闭环可追溯。
- **反索赔**：对分包 / 供应商的违约（延期 / 质量）扣款，须合同依据。
- **时限**：按合同索赔时效报送，逾期失权。

**实战经验（证据链是命）**
- 索赔成功关键在证据链完整（指令 → 影响 → 费用）与时效内报送。
- 对下游（分包 / 供应商）的反索赔须在合同明确违约条款，结算时直接扣减。
- 避免"只催不记"——口头索赔无书面等于无索赔。

**审核清单**
- [ ] 索赔是否有完整证据链且在时效内？
- [ ] 反索赔扣款是否有合同依据？
- [ ] 费用计算是否可追溯到凭证？

## 节点 7 · 竣工结算书编制

**目的**：汇总形成对外竣工结算书。

**输入**：前述所有（合同价 / 量价 / 签证 / 材料结算 / 索赔）。

**步骤要点**
- **结构**：编制说明 + 汇总表 + 分部分项结算表 + 措施项目 + 变更签证 + 材料调差 + 索赔 + 其他。
- **数据勾稽**：各表合计数一致；与合同价 / 目标成本勾稽。
- **附件**：全套支撑资料索引（指向施工竣工资料技能组卷）。

**实战经验（数出有据）**
- 结算书须"数出有据"——每项金额对应支撑资料（合同 / 签证 / 签收 / 检测）。
- 编制说明写清口径（含税 / 暂列 / 风险包干），减少核对争议。
- 与对内目标成本勾稽，标注利润空间与偏差项。

**审核清单**
- [ ] 各表合计数是否一致？
- [ ] 每项金额是否有支撑资料？
- [ ] 编制说明口径是否清晰？

## 节点 8 · 内部一审与量价复核

**目的**：对外报送前，成本部内部复核量价，降低核减风险。

**输入**：竣工结算书（节点 7）。

**步骤要点**
- **一审**：量价复核（抽核高风险项）、资料完整性、计价口径。
- **交叉复核**：编制人与复核人分离；重大项集体评审。
- **风险预判**：标注可能被审计核减的高风险项，准备答辩依据。

**实战经验（审计视角自审）**
- 内部一审应"以审计视角自审"，提前暴露量价矛盾与资料缺口。
- 高风险项：变更签证量价、隐蔽工程、材料调差、暂列金额使用。
- 一审须留痕（复核意见 + 修改记录），形成质量闭环。

**审核清单**
- [ ] 是否编制人与复核人分离？
- [ ] 高风险项是否预判并备答辩？
- [ ] 一审意见是否留痕？

## 节点 9 · 审计应对与答疑

**目的**：配合外部审计 / 财评，答疑质证，守住结算金额。

**输入**：竣工结算书 + 全套支撑资料（施工竣工资料技能）。

**步骤要点**
- **资料提供**：按审计清单提供原件 / 复印件，索引清晰。
- **答疑**：对核减项举证（合同 / 签证 / 检测 / 影像），有理有据。
- **质证**：争议项协商 / 复核，必要时第三方鉴定。
- **闭环**：形成审定单，双方签认。

**实战经验（资料可追溯是核心）**
- 资料可追溯性（施工竣工资料技能）是审计应对的核心——资料齐则核减少。
- 隐蔽工程须有验收记录 + 影像，否则审计通常按"无依据"核减。
- 答疑"以合同为准、以资料为证"，避免口头争辩。
- 审计常见核减点：量算重复、单价偏高、签证无依据、材料价差无约定、隐蔽无影像。

**审核清单**
- [ ] 资料是否按审计清单完整提供且索引清晰？
- [ ] 核减项是否有合同 / 签证 / 检测举证？
- [ ] 审定单是否双方签认？

## 节点 10 · 成本数据库沉淀

**目的**：把本项目单价 / 损耗 / 指标沉淀，反哺后续项目与目标成本。

**输入**：结算单价、实际损耗率（物料 BOM 技能节点 12）、专业占比、量差归因。

**步骤要点**
- **单价库**：分专业 / 分材料设备结算单价（脱敏为区间 / 档次），回流物料 BOM 损耗率基线。
- **损耗复盘**：实际损耗率 vs 模板基准（物料 BOM 技能节点 3），校准损耗率区间表。
- **指标**：平米造价、专业占比、量差成因分布。
- **复用**：作为新项目目标成本与投标测算基准。

**实战经验（复利资产）**
- 成本数据库是"越做越准"的复利资产——每个项目回填即校准。
- 损耗率复盘（物料 BOM 技能节点 12）直接校准损耗率经验区间表，形成闭环。
- 单价须脱敏为区间 / 档次，不承载具体项目商号与成交价。

**审核清单**
- [ ] 单价是否脱敏为区间 / 档次？
- [ ] 损耗率是否回灌校准模板？
- [ ] 指标是否归集可复用？

## 节点 11 · 结算争议处理

**目的**：对结算 / 审计争议走合规解决路径。

**输入**：争议事项、合同争议条款、往来函件。

**步骤要点**
- **协商**：成本部牵头与业主 / 审计协商。
- **调解**：第三方（造价咨询 / 行业协会）调解。
- **仲裁 / 诉讼**：按合同争议解决条款（仲裁 / 诉讼）启动。
- **留痕**：全过程函件 / 纪要留痕。

**实战经验（成本递增）**
- 争议解决优先级：协商 > 调解 > 仲裁 > 诉讼，成本递增。
- 合同争议条款（管辖 / 鉴定）须提前核对，避免程序瑕疵。
- 所有争议沟通须书面留痕，口头约定无效。

**审核清单**
- [ ] 是否优先协商 / 调解？
- [ ] 仲裁 / 诉讼是否符合合同管辖？
- [ ] 是否全程书面留痕？

## 节点 12 · 项目成本复盘与指标归集

**目的**：项目结束做成本复盘，归集指标，改进管理。

**输入**：结算书 / 目标成本 / 量差 / 数据库。

**步骤要点**
- **复盘会**：成本部牵头，采购 / 工程 / 资料参与，复盘量价 / 签证 / 索赔 / 损耗。
- **指标归集**：实际平米造价 / 专业占比 / 毛利率 / 量差成因分布 / 采购节超。
- **改进**：形成管理改进项（提量精度 / 签证时效 / 损耗控制 / 供应商管理）。
- **归档**：复盘报告 + 指标卡，入成本数据库（节点 10）。

**实战经验（对标杆）**
- 复盘须"对标杆"——实际 vs 目标成本，偏差项逐条归因。
- 采购节超（采购价 vs 目标成本）直接反映采购管理成效（采购生命周期 / 供应商评估技能）。
- 复盘改进项须落实到制度 / 模板，而非一次性会议。

**审核清单**
- [ ] 是否对比目标成本逐条归因？
- [ ] 指标卡是否归集入数据库？
- [ ] 改进项是否落实到制度？

- `reconcile.rows[]`：节点 3 量价核对，合同 / 设计 / 清单 / 实际四维；`contract_price` 为脱敏占位（实际填区间或留 0）。
- `variation.rows[].basis`：计价口径，填 合同单价 / 类似单价 / 市场价 / 信息价 / 组价 之一。
- `database.rows[].settle_price_range`：脱敏单价区间；`actual_loss`：实际损耗率（小数）。
