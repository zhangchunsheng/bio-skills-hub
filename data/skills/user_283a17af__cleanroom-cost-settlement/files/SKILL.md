# 医疗净化成本结算与审计

把"医疗净化工程的成本结算与审计"从结算资料策划到项目成本复盘的链路，转化为可复用的**结构化交付物与节点 SOP**。覆盖六个专业（暖通、装饰、给排水、电气、医气、医疗设备），聚焦"量、价、签证、结算、审计、数据库"，由**成本部**牵头，采购部 / 工程部 / 资料部门作数据输入与协同，与 `cleanroom-procurement-lifecycle`（采购执行）、`cleanroom-material-bom`（物料量差）、`cleanroom-construction-docs`（资料留痕）、`cleanroom-supplier-eval`（协议价）、`cleanroom-procurement-team`（团队绩效）互补成"采购 + 成本 + 资料"交付闭环。

## 何时使用

- 用户要生成：**结算资料策划清单 / 量价核对表 / 变更签证计价表 / 成本数据库沉淀表**。
- 用户描述成本结算场景，需要按节点给出流程与产出：结算资料策划、合同价与目标成本、量价核对、变更签证计价、材料设备结算、索赔反索赔、竣工结算书、内部一审、审计应对、成本数据库、争议处理、成本复盘。
- 触发词参考：`成本结算`、`竣工结算`、`量价核对`、`变更签证`、`索赔`、`审计应对`、`成本数据库`、`结算资料`、`目标成本`、`结算复盘`、`洁净工程结算`。

## 成本结算与审计节点 SOP（资料策划 → 成本复盘）

本技能盯"结账"本身——"量从哪来、价按什么、变更多少、审计怎么过、经验怎么留"。采购在该链路里是**上游数据提供方**（给 BOM 量、采购合同价、到货签收量、变更指令），真正的结算编制、量价复核、审计应对、数据库沉淀均在成本部：

1. **结算资料策划与清单**：竣工前梳理结算所需资料清单，明确每份资料的提供部门（成本部 / 采购部 / 工程部 / 资料），设收集截止节点与缺项预警。
2. **合同价与目标成本基线建立**：对外结算基准（合同价分解）+ 对内成本基准（中标价 − 计划毛利，按专业分解），两线并存。
3. **量价核对**：量以 BOM 变更后净用量 + 量差签证为准；价以采购合同价 / 协议价为准；量 × 价做三维（设计 / 清单 / 合同）勾稽。
4. **变更签证管理与计价**：汇总经签认的变更 / 签证，按"合同单价 → 类似单价 → 市场价 → 信息价 → 组价"口径计价，隐蔽项须有验收记录 + 影像。
5. **材料设备价款结算**：以合格量（到货 − 退换 − 不合格）对账，按合同节奏付款、释放质保金；甲供界面责任书面界定。
6. **索赔与反索赔**：业主原因的费用 / 工期索赔须证据链完整且在时效内；对下游违约扣款须有合同依据。
7. **竣工结算书编制**：汇总成书，数出有据、各表勾稽，附全套支撑资料索引。
8. **内部一审与量价复核**：对外报送前以"审计视角"自审，编制人与复核人分离，预判高风险核减项。
9. **审计应对与答疑**：按审计清单提供可追溯资料，对核减项举证（合同 / 签证 / 检测 / 影像），形成双方签认审定单。
10. **成本数据库沉淀**：结算单价 / 实际损耗率 / 专业占比脱敏为区间与档次，回流物料损耗率基线，复利反哺后续项目。
11. **结算争议处理**：协商 > 调解 > 仲裁 > 诉讼，全过程书面留痕，符合合同争议条款。
12. **项目成本复盘与指标归集**：对比目标成本逐条归因，归集平米造价 / 专业占比 / 量差成因 / 采购节超，改进项落实到制度。

> 各节点深入检查清单、审核要点与决策逻辑见 `references/settlement_detail.md`。

## 程序化生成

`scripts/generate.py` 从一份 JSON 项目简述生成上述 4 类文档，并做勾稽与脱敏校验：

```bash
python3 scripts/generate.py --demo --out output_demo
python3 scripts/generate.py --spec my_project.json --out output
python3 scripts/generate.py --validate my_project.json
```

## 使用步骤

1. 先问清项目画像（医院等级、科室、洁净度、合同界面、工期、结算阶段），不凭空填数。
2. 按用户需要选择交付物：要资料清单 → 填 `plan`；要量价 → 填 `reconcile`；要签证 → 填 `variation`；要数据库 → 填 `database`。
3. 用 `generate.py` 产出，或指导用户直接复写 `templates/` 空白表。
4. 金额、合同、供应商具体信息以实际项目数据为准；输出中**仅用档次与区间、不写成交价、不写真实商号与联系人**。

## 实战方法论速查（节选自 settlement_detail）

> 全节点一句话结论速查；完整检查清单、审核要点与决策逻辑见 `references/settlement_detail.md`。

| 节点 | 一句话方法论 |
|------|--------------|
| 1 资料策划 | 竣工前拉结算资料清单，按部门分责、设截止节点、缺项预警 |
| 2 基线建立 | 对外合同价分解 + 对内目标成本(中标价−毛利)按专业分解，两线并存 |
| 3 量价核对 | 量取BOM变更后净用量+签证；价取合同价/协议价；量×价三维勾稽 |
| 4 变更签证 | 经签认签证汇总；计价按合同→类似→市场→信息价→组价；隐蔽须验收+影像 |
| 5 材料结算 | 合格量(到货−退换−不合格)对账；按合同付进度款、释放质保金 |
| 6 索赔反索 | 业主索赔证据链+时效；对下游违约扣款须合同依据 |
| 7 结算书 | 数出有据、各表勾稽、附资料索引；编制说明写清含税/暂列口径 |
| 8 内部一审 | 审计视角自审；编制/复核分离；预判高风险核减项备答辩 |
| 9 审计应对 | 资料可追溯是核心；核减项举证合同/签证/检测/影像；审定单双签 |
| 10 数据库 | 单价/损耗/占比脱敏为区间档次，回流物料损耗基线，复利反哺 |
| 11 争议处理 | 协商>调解>仲裁>诉讼；全程书面留痕；符合合同管辖 |
| 12 成本复盘 | 对比目标成本逐条归因；归集平米造价/专业占比/采购节超；改进入制度 |

- **专业占比（洁净手术部通用匡算）**：暖通 25%–35% / 医疗设备 20%–30% / 装饰 15%–20% / 电气 10%–15% / 给排水 5%–8% / 医气 5%–8%——作目标成本分解与平米造价对标参考，按项目须重确认。
- **结算资料高风险缺项**：隐蔽工程验收记录、设计变更签字版、材料设备合格证原件、检测报告（CMA/CNAS）、竣工图——建议施工过程即按结算口径预归档（联动 `cleanroom-construction-docs`）。
- **审计常见核减点**：量算重复、单价偏高、签证无依据、材料价差无约定、隐蔽无影像——内部一审须前置排查。
- **数据库复利**：每个项目回填即校准损耗率区间与单价区间，越做越准；单价须脱敏为区间/档次，不承载具体商号与成交价。

## 与既有技能的关系（数据输入视角）

- `cleanroom-material-bom`（物料 BOM）：节点 12 量差分析（量）+ 节点 3 损耗率区间（价基准）→ 本技能节点 3 量价核对、节点 10 数据库回流。
- `cleanroom-procurement-lifecycle`（采购执行）：节点 5 合同价、节点 6 付款台账、节点 8 到货签收 → 本技能节点 3 价、节点 5 材料结算。
- `cleanroom-supplier-eval`（供应商评估）：协议价 / 战略价 → 本技能节点 3 价优先依据。
- `cleanroom-construction-docs`（施工竣工资料）：隐蔽验收、变更签证、检测报告、竣工图 → 本技能节点 1 资料策划、节点 4 计价、节点 9 审计应对。
- `cleanroom-procurement-team`（采购团队）：采购节超反映采购管理成效 → 本技能节点 12 成本复盘指标之一。

## 合规边界（必守）

- **脱敏**：项目名用"某 X 级医院净化项目"等；单价 / 损耗 / 占比脱敏为区间与档次；不写真实商号、联系人、合同成交价、内部额度。
- **不提供违规方案**：串标、围标、虚增结算量价、伪造签证套取价款等一律不生成。
- **国标依据**：引用 GB50500（建设工程工程量清单计价规范）、GB50854（房屋建筑与装饰工程工程量计算规范）、GB50333（医院洁净手术部）等时注明版本年号。
- **资质与验收**：医疗净化强依赖净化工程专业承包 / 机电安装资质与验收规范，决策前建议核对当地住建 / 卫健要求。
- 本技能内容均为脱敏后的行业通用方法论，不承载任何原任职单位的专有商业数据。
