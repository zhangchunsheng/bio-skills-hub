# 方法学验证（ICH Q2(R2) + 中国药典 9101/0512）

> 验证项目按「方法用途」裁剪：鉴别只需专属性；含量需 1/线性/准确度/精密度/耐用性/系统适用性；有关物质需全部 + LOD/LOQ。

## 1. 各项目做法与可接受标准（速查）

| 项目 | 做法 | 可接受标准（一般） | 备注 |
|---|---|---|---|
| **专属性** | 空白/辅料/降解物/相邻峰分离 | 主峰与杂质 R≥1.5；空白无干扰 | 强制降解证明稳定性指示 |
| **线性** | 至少 5 浓度点（含量 50–150%，杂质 LOQ–150%） | r≥0.999（含量）；r≥0.990（杂质） | 回算残差≤2% |
| **范围** | 线性两端外延 | 含量 80–120%；杂质 LOQ–150% | 覆盖质量标准上下限 |
| **准确度** | 加标回收（3 浓度×3 重复） | 含量 98–102%；杂质 80–120% | RSD 见精密度 |
| **重复性** | 同人同仪 6 针 | RSD≤2.0%（含量）；≤15%（LOQ 附近 ≤20%） | 系统适用性同源 |
| **中间精密度** | 不同人/日/仪 | RSD≤2.0–3.0%（含量） | 与重复性合并评估 |
| **LOD** | S/N≥3 或信噪外推 | 报告即可 | 杂质用 |
| **LOQ** | S/N≥10；准确度 80–120%、RSD≤15% | 定量下限可信 | 有关物质报告阈值下限 |
| **耐用性** | 微调动相比例/pH/柱温/流速 | 系统适用性仍合格、结果无漂移 | 证明方法稳健 |
| **系统适用性** | 进样前/中 | 理论塔板数、R、拖尾达标 | 每批必做（ChP 0512） |

## 2. 中国药典/NMPA 差异提示
- ChP 2025 四部 0512（HPLC）、0521（GC）、0513（CE）为法定方法框架；9101 为验证指导原则。
- 国内申报：分析方法须与质量标准一致；方法学验证资料按 CDE《化学药物质量控制分析方法验证技术指导原则》。
- 强制降解对「稳定性指示」为必需；NMPA 审评常要求提供 mass balance。

## 3. 计算工具
- `scripts/method_metrics.py`：输入线性点（浓度、响应）、加标回收（测得/理论）、精密度重复（多针结果），输出 r、斜率、截距、平均回收%、RSD% 与可接受判定（红/绿）。
- 注意：LOD/LOQ 若用斜率/标准差法（LOD=3.3σ/S，LOQ=10σ/S），脚本亦支持传入 σ 与 S。

## 4. 眼科/耳科局部制剂额外验证
- 抑菌剂方法须配套**重复性 + 稳定性指示**（防腐剂可能降解）。
- 混悬粒度方法需做**精密度（D10/D50/D90 RSD）**与**回收率**（再分散代表性）。
- 植入剂释放方法须做**释放介质稳定性 + 取样回收**。
