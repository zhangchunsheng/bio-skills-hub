# 分析方法开发（method development）

## 1. 待测项 → 技术选型

| 待测项 | 首选技术 | 备选 | 关键点 |
|---|---|---|---|
| API 含量（主成分） | RP-HPLC (UV) | 滴定/CE | λmax 处检测；线性覆盖 80–120% |
| 有关物质（降解/工艺杂质） | RP-HPLC (PDA) | UHPLC | 梯度洗脱，柱温 30–40℃，主峰拖尾因子≤2.0 |
| 残留溶剂 | GC (HS/FID/MS) | — | ICH Q3C 三类分级；顶空进样 |
| 元素杂质 | ICP-MS | AAS | ICH Q3D 四类；内标法 |
| 手性杂质 | 手性 HPLC / SFC / CE | — |  chiral 柱或衍生化 |
| 抑菌剂/防腐剂（苯扎氯铵等） | RP-HPLC (UV/CDAD) | 阳离子 CE | 须单独方法 + 抑菌效力（USP<51>/ChP9206） |
| 渗透压 / 黏度 / pH | 渗透压仪 / 黏度计 / pH 计 | — | 物理常数，非色谱 |
| 无紫外吸收 API（如部分肽/糖） | HPLC-CAD/ELSD 或 LC-MS | 示差 | CAD 普适但线性窄 |

## 2. 液相色谱条件要点
- 柱：C18（2.1–4.6 mm id，3–5 μm）；亲水/极性化合物用 HILIC 或 C8/AQ。
- 流动相：0.1% 磷酸/甲酸 + 乙腈或甲醇；缓冲盐（磷酸盐/醋酸铵）控 pH。
- 梯度：有关物质常用 5%→95% 有机相 30 min；含量用等度。
- 系统适用性（ChP 0512）：理论塔板数、分离度（R≥1.5 相邻杂质）、拖尾因子、重复性（RSD≤2.0%）。

## 3. 眼科/耳科专项
- **混悬液**：含量须测「再分散后全混悬相」API，不能只测上清；粒度（ChP 0982）与再分散性需专属方法。
- **凝胶/乳剂**：基质干扰大，须做回收率与基质效应（尤其 MS 检测）。
- **植入剂**：释放介质中 API 与降解物方法；取样点（1/4/8 h，1/2/4/8/12 周）须稳定。
- **抑菌剂**：眼用多剂量制剂必检；单剂量（BFS）可豁免抑菌剂但需无菌（ChP 0105/0112）。

## 4. 稳定性指示（stability-indicating）判定
- 强制降解后，主峰与降解峰**完全分离**（R≥2.0 更佳）；降解产物可被定量。
- 计算 mass balance（降解前后总回收 90–110%），证明无「隐形」降解物。
- 降解产物须用 PDA 峰纯度 +（必要时）LC-MS 确证结构以溯源（联动 synthesis-route-assistant）。
