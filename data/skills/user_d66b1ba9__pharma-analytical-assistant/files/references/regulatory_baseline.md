# 药典与法规基线（离线基线，须定期刷新）

> **最后刷新日期**：2026-07-30
> **刷新机制**：本文件为离线基线，**不写死版本号**。每次涉及注册/合规任务，先调用 `regulatory-monitor` 检索 CDE/NMPA/FDA/EMA/ICH 最新动态，再对照本基线。若距上次刷新 >6 个月，必须提示用户刷新。

## 1. 国内（NMPA / CDE / ChP）
- **中国药典 2025**（现行版）：四部通则
  - 0512 HPLC、0521 GC、0513 CE（法定色谱方法框架）
  - 0941 释放度、0931 溶出度、0982 粒度和粒度分布、0633 黏度
  - 0105 眼用制剂、0112 耳用制剂（无菌、渗透压、pH、黏度、粒度、抑菌效力）
  - 9001 原料药与制剂稳定性试验指导原则、9012 药物引湿性
  - 9206 抑菌剂效力检查、0861/2321 元素杂质、残留溶剂相关
- **CDE 指导原则**（化学药）：质量标准建立、杂质研究、残留溶剂、元素杂质、稳定性、溶出/释放、包装材料相容性、局部/眼用制剂质量研究。
- 申报路径：境内上市许可（NDA/ANDA）、补充申请；眼用/耳用局部制剂多走 3 类/4 类化学药。

## 2. 国际（USP / EP / JP / FDA / EMA / ICH）
- **USP-NF**：<51> 抑菌效力、<621> 色谱、<711> 溶出、<1724> 半固体释放（IVRT）、<905> 含量均匀度。
- **EP / JP**：对应通则，欧盟/日本申报依从。
- **FDA / EMA**：ANDA/NDA 化学药 CMC；眼用局部制剂 Guidance（如 ophthalmic drug products 仿制指南）。
- **ICH**：Q2(R2) 分析方法论证、Q3A/B 杂质、Q3C 残留溶剂、Q3D 元素杂质、M7 遗传毒性、Q1A-E 稳定性、Q6A 质量标准、Q8-Q11 制药开发/质量/风险/原料药。

## 3. 眼科/耳科专项要点
- 无菌是硬要求（终端灭菌或无菌工艺 + 容器密封性 CCIT）。
- 多剂量须含抑菌剂 + 抑菌效力（ChP 9206 / USP<51>）；单剂量（BFS）可无抑菌剂但须无菌（联动 RL009 放置方式研究）。
- 局部作用制剂一般**不要求全身 BA/BE**，注册以**质量一致性**（含量、杂质、粒度、流变、IVRT/IVPT、无菌）为主；改规格/改剂型须论证。
- 包装浸出物/可提取物（E&L）：塑料瓶/LDPE/BFS 须按 YBB/ChP 9624 + 包材相容性指导原则评估（联动 RL009）。
