# 复杂基质前处理（混悬/凝胶/乳剂/植入剂）

> 核心原则：前处理必须把「剂型真实状态」转化为均一、可进样的溶液，并验证**回收率**与**基质效应**。

## 1. 混悬液（suspension）
- 再分散：涡旋 ≥1 min + 超声（注意 API 热敏感）→ 取全量匀浆。
- 提取：溶剂（甲醇/乙腈/缓冲液）溶解 API；不溶辅料（如增稠剂）离心（≥10000 g，10 min）取上清。
- 陷阱：① 只取上清会低估 API（API 吸附在固体上）→ 必须全混悬相；② 粒度影响溶解度 → 方法须与粒度状态关联。
- 验证：加标回收 90–110%（高/中/低）；基质效应（MS 法）≤±15%。

## 2. 凝胶（gel）
- 破胶：依基质——温和水浴（≤40℃，热可逆凝胶）、剪切稀释、或加破胶溶剂（如含醇/酸）。
- 提取：涡旋+超声 → 离心取上清；注意黏度导致滤过困难（用 0.45 μm 前先稀释）。
- 陷阱：高分子辅料（卡波姆/HPMC）吸附 API 或堵塞色谱柱 → 验证回收 + 在线保护柱。

## 3. 乳剂（emulsion）
- 破乳：有机溶剂（乙腈/异丙醇）破乳 + 涡旋/离心分层；或低温冻融。
- 提取：取油相或合并水/油相用溶剂萃取 API；乳化剂（吐温/司盘）可能干扰 MS。
- 陷阱：API 分配在水/油相约 1:1 → 必须两相合并提取，否则低估。

## 4. 植入剂（implant）
- 含量/均匀度：剪碎/研磨 → 溶剂提取（超声）→ 定容进样。
- 体外释放取样：释放介质（多为 PBS/含表面活性）中 API 已溶出，可直接进样或经适当稀释；注意**取样针不扰动植入体**。
- 陷阱：释放介质含表面活性剂 → 进样前滤过/稀释避免柱污染；降解物（如酯水解）须同步监测。

## 5. 通用回收率/基质效应验证模板
- 回收率：空白基质 + 低/中/高加标，每个 3 重复；接受 80–120%（LOQ 附近 70–130%）。
- 基质效应（LC-MS）：纯溶剂标曲 vs 基质后加标标曲斜率比（IS-normalized ME 85–115%）。
- 稳定性：提取后溶液室温/auto-sampler 稳定性（通常 24–72 h）。
