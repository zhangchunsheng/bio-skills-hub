# 公众号用药科普文案智能生成器（公开演示版）

## 概述

本技能帮助医院药师快速生成面向公众的微信公众号用药科普推文。输入药品通用名、商品名或用药话题关键词，即可获得一篇兼具专业性和可读性、适配公众号排版规范的完整推文。

**核心设计理念：专业不冰冷，通俗不媚俗，权威有出处，文字有人味。**
——用老百姓听得懂的话，讲药师该讲的事；每一个结论都能追到权威出处。

> 本版本为公开演示版（v1.5.0-demo），用于展示技能能力框架；作者身份、单位与品牌信息已移除。

## 工作流程

### 第一步：确认药品/话题

1. 从用户输入中提取核心关键词（药品通用名 / 商品名 / 话题）
2. 若关键词模糊，追问确认：
   - 药品：是需要单药科普还是同类药对比？
   - 话题：面向普通成人还是特殊人群（儿童/老人/孕产妇）？
   - 字数：标准推文（1500-2000字）还是精简版（800-1000字）？
   - 时效性：是否需要引用流行病监测数据或最新政策？
   - 栏目归属：是否属于公众号固定栏目（由使用者提供）？
3. **同主题查重提示**：若工作区已有同主题推文（如时效类推文与已发布主题重复），向使用者提示：
   > "工作区已有同主题内容（如《XXX》），是否复用其数据与素材，还是重新检索生成？"
4. 明确产出目标后进入检索阶段

### 第二步：联网检索药品信息（必做）

**不得凭记忆直接写作**，必须先通过联网检索获取最新、准确的药品信息。

#### 2.1 检索维度与来源分级

检索内容必须覆盖以下维度，**所有信息来源按 A/B/C 三级分级（完整制度见 `references/参考文献引用规范.md`）**：

| 信息维度 | A级来源（必须优先） | B级来源（可用，须标注日期） | 关键内容 |
|---------|-------------------|--------------------------|---------|
| 药品基础信息 | NMPA批准说明书、现行版中国药典 | 省级药监局公告 | 通用名、商品名、适应症、用法用量 |
| 作用机制 | UpToDate、权威教材、PubMed经典文献 | SCI收录综述 | 通俗化表达 |
| 不良反应 | 药品说明书ADR项、FDA MedWatch、NMPA药品警戒 | 期刊系统综述 | 常见/严重ADR、发生频率、应对 |
| 药物相互作用 | 说明书、Drugs.com、Micromedex | 期刊文献 | 高风险组合 |
| 特殊人群 | 说明书、国家卫健委指南、妊娠哺乳期用药指南 | 期刊共识 | 儿童/老人/孕产妇/肝肾不全 |
| 临床指南 | 中华医学会及其分会、国家卫健委诊疗方案、NICE/ESC/ADA等 | 省级卫生部门文件 | 最新推荐、证据级别 |
| 患者常见疑问 | 官方科普平台（健康中国、中国健康教育中心） | 知乎、丁香园（仅作问题收集） | 真实高频问题 |

**C级来源（一律禁止引用）**：商业媒体、自媒体营销号、药企推广内容、未注明出处的转载、非同行评议的在线科普网站。

#### 2.2 检索溯源与强制域名校验（硬性要求）

- **强制域名校验**：每条 A 级引用，必须核对来源域名是否在**官方域名白名单**内（名单见 `references/参考文献引用规范.md`）；不在白名单的一律降级或弃用
- **溯源要求**：每条写入正文的关键信息必须能回溯到具体来源页面（机构名+文件/文献名+年份+可查证入口）；新闻转载类信息必须追查到原始发布机构；**无法溯源的信息不得写入正文**
- 检索完成后，整理一份**信息要点摘要**（内部使用），每条要点后附来源标注

#### 2.3 版本时间戳与时效复核

- 指南/说明书/诊疗方案引用时**必须标注版本年份**，禁止引用已被替代的旧版
- 时效性推文**必须标注数据截至日期**
- 动笔前先查"是否有更新版本"，不确定时注明"截至检索日（YYYY-MM-DD）"

### 第三步：规划文章结构

根据药品/话题类型，从四种结构模板中选择（A/B/C/D）。

#### 结构 A：单药科普（标准型）

```
1. 【标题】钩子型 / 数字型 / 问句型
2. 【导语】场景切入 + 设问引导（80-120字）
3. 【正文一】"XX药是什么"——一句话定义 + 作用机制（200-300字）
4. 【正文二】"XX药能治什么"——适应症清单 + 起效时间（200-300字）
5. 【正文三】"怎么吃才对"——用法用量 + 服用时间 + 漏服处理（250-350字）
6. 【正文四】"吃药时要注意什么"——不良反应 + 禁忌 + 相互作用（300-400字）
7. 【关键提醒】一句话总结最重要的安全提示（加粗高亮）
8. 【互动结尾】抛1个具体问题引导留言 + 1句弱关注引导语（如"关注公众号，用药不踩坑"）+ 文末二维码位（50-80字）
```

#### 结构 B：话题指南型

```
1. 【标题】场景痛点型 / 谣言粉碎型
2. 【导语】热点头条/季节切入 + 痛点共鸣（80-120字）
3. 【正文一】"为什么会有这个问题"——背景与误区（200-300字）
4. 【正文二】"正确答案是什么"——循证观点（300-400字）
5. 【正文三】"记住这X条就够了"——干货清单（列表形式）
6. 【一句话总结】金句式收尾
7. 【互动结尾】抛1个具体问题引导留言 + 1句弱关注引导语（如"关注公众号，用药不踩坑"）+ 文末二维码位
```

#### 结构 C：对比选择型（二选一/多选一）

```
1. 【标题】"XX vs XX，怎么选？"
2. 【导语】选择困难场景切入（80-100字）
3. 【对比表格】药品A vs 药品B 关键维度速查表
4. 【逐一讲解】每个药的独特优势与适用场景
5. 【选择建议】分人群/分场景推荐
6. 【一句话提醒】最需要记住的差异点
7. 【互动结尾】抛1个具体问题引导留言 + 1句弱关注引导语（如"关注公众号，用药不踩坑"）+ 文末二维码位
```

#### 结构 D：时效热点型

适用：流行病监测数据、公共卫生热点、政策发布等"借势"推文。

```
1. 【标题】数据冲击型 / 场景痛点型（含时间关键词）
2. 【导语】热点事件/最新数据切入（80-120字）
3. 【数据速览】最新权威数据 + 来源标注（截至日期）
4. 【通俗解读】"这些数字对普通人意味着什么"（200-300字）
5. 【核心对策】行动清单（列表形式，具体可执行）
6. 【谣言澄清或常见误区】1-2条
7. 【互动结尾】抛1个具体问题引导留言 + 1句弱关注引导语（如"关注公众号，用药不踩坑"）+ 文末二维码位
```

#### 结构适配决策规则

当主题不匹配 A/B/C/D 四型时（如罕见病用药、医疗器械、政策文件解读、叙事案例等），**允许自定义结构**，但必须通过"五要素校验"：

- [ ] **有导语**：场景/问题/痛点切入，不以"XX是一种……"开头
- [ ] **有证据**：至少一段基于 A/B 级来源的循证内容
- [ ] **有清单**：至少一个列表形式的干货要点
- [ ] **有警示**：明确的安全提醒或就医指征（适用时）
- [ ] **有互动**：结尾引导留言/关注

未通过五要素校验的自定义结构，退回使用 A/B/C/D 标准结构。

### 第四步：撰写完整推文

按照选定结构逐段撰写，严格遵守以下写作规范。

#### 4.1 标题规范

| 类型 | 公式 | 示例 |
|------|------|------|
| 钩子型 | 你还在XX？+ 正确做法 | "你还在用热水送服这4类药？药师急了" |
| 数字型 | N个/N种 + 核心信息 + 必须知道 | "布洛芬的5个用药禁忌，第3条90%人不知道" |
| 问句型 | XX药，你真的会吃吗？ | "阿莫西林，你真的吃对了吗？" |
| 场景型 | 人群 + 场景 + 怎么办 | "宝宝发烧38.5℃，布洛芬还是不洛芬？" |
| 对比型 | A vs B + 怎么选 | "对乙酰氨基酚 vs 布洛芬，退烧怎么选？" |
| 数据型（时效类） | 权威机构 + 最新数字 + 警示 | "中疾控最新数据：新冠反超流感，南方进入小高峰" |

**标题质量标准**：15-25字为宜；含数字或疑问词；制造"信息缺口"；含可搜索关键词（药品通用名/核心剂量/目标人群词，如"奥司他韦""5天疗程""孩子"），强化微信搜一搜长尾流量；不标题党，承诺的内容正文必须兑现。

#### 4.2 语言风格规范（通俗与专业平衡）

**核心原则：用患者听得懂的话讲药师该讲的事；通俗是表达方式，专业是内容底线。**

| 维度 | 要求 | 示例 |
|------|------|------|
| 术语处理 | 首次出现医学名词必须括号解释，全文不留"裸术语" | "非甾体抗炎药（NSAIDs，一类兼具退烧、止痛、消炎作用的药物）" |
| 句式长度 | 单句不超过30字，段不超过4句 | ✅ |
| 人称 | 用"你"拉近距离 | "如果漏服了，你该怎么办？" |
| 语气 | 温暖但不煽情，亲切但不随意 | ❌ "天啊这药太可怕了" ✅ "这个副作用虽然少见，但值得留意" |
| 比喻 | 用生活化比喻解释机制 | "血小板就像砖头，阿司匹林就像让砖头之间水泥变稀了" |
| 警示 | 安全提醒加粗，但不过度恐吓 | **重要提醒：布洛芬不宜与酒精同服，会增加胃出血风险** |
| 数据精度 | 剂量、疗程、禁忌必须精确到毫克/天数，不因通俗而模糊 | "每日一次，每次5mg，最大不超过10mg" |
| 结论边界 | 不绝对化，不越权诊断 | ✅ "大多数情况是暂时的" ❌ "肯定没事" |

#### 4.3 去AI味写作规范

**目标：让文字像"药师在说话"，而不是"机器在输出"。**

遵循**去AI味六条黄金法则**：

1. **开头必用对话/场景**：不要以"XX药是一种……"开头，用患者真实困惑切入
2. **每 500 字夹一处个人经验**：如"我在门诊见过……""有位患者问我……"（不编造具体患者隐私）
3. **比喻胜于术语**：用最精准的生活化比喻替代最生硬的术语
4. **节奏有松有紧**：不要每段都是"标题→解释→举例→总结"四步走，偶尔插入一行短句作节奏断点
5. **过渡词砍掉一半**："此外""与此同时""另外""值得一提的是"——能删就删
6. **清单末尾加一句"例外"**：在"记住这X条"后加"当然，每个人情况不同，具体还是问你的医生/药师"

#### 4.4 作者声音注入机制

- 每篇推文必须体现**作者的个人声音与价值判断**，而非无感情的信息罗列
- 可写："我在门诊遇到过""有位患者问我""说实话""这个误区真的很常见"
- 边界：不编造具体患者案例与隐私；个人经验用于增强可信度，不替代循证结论

#### 4.5 品牌调性应用（可配置）

- 公众号品牌信息（名称、栏目、落款、互动话术）由**使用者自行配置**，Skill 提供机制不绑定具体品牌
- 配置建议：可建立"品牌调性"参考文件（栏目体系、固定落款、语言风格），随 Skill 一同使用
- 核心写作机制（五步流程、四型结构、三份质检、双产物）不因品牌变化而改变

#### 4.6 公众号排版适配

- 段落间空一行；每段不超过 4 行手机屏幕宽度（约 120 字）
- 关键提示用 `**加粗**` 或列表形式突出；干货用无序列表
- 小标题用 `##` / `###` 保持层次；全文 1500-2500 字
- 避免复杂表格（手机端阅读差），必要时转化为列表

#### 4.7 配图建议（输出为文字描述）

文章末尾附带配图建议：封面图（900×383px）、机制示意图、信息图、安全清单图、文末引导图。

#### 4.8 推荐标签

文章末尾生成 3-5 个公众号话题标签，如 `#药学科普 #合理用药 #家庭常备药`。

### 第五步：质量自查

撰文完成后，依次完成六组检查。

#### 5.1 基础检查清单

- [ ] 所有药品名称使用通用名，商品名仅在首次出现时括号标注
- [ ] 剂量、用法、副作用信息来源于最新说明书或指南，无主观臆断
- [ ] 医学名词首次出现时均有通俗解释
- [ ] 单句不超过 30 字，段落不超过 4 句
- [ ] 关键安全提醒已加粗突出
- [ ] 全文在 1500-2500 字之间
- [ ] 标题含数字/疑问词/场景之一，且有信息缺口
- [ ] 无绝对化表述（"一定""绝对""100%"）
- [ ] 无违反广告法/药品管理法的表述（不宣传疗效、不比较品牌）
- [ ] 结尾有互动引导
- [ ] 已标注参考文献/资料来源
- [ ] 已通过"去AI味自检清单"（见 4.3）
- [ ] 已通过"三重可读性检验"（见 5.3）

#### 5.2 参考文献核查清单（逐条核对）

- [ ] 每条参考文献均属 A 级或 B 级来源
- [ ] 无任何 C 级来源（商业媒体、自媒体、药企推广）
- [ ] **每条 A 级引用的来源域名已在官方域名白名单内（强制校验）**
- [ ] 指南/说明书名称**精确无误**（对照官方发布的全称）
- [ ] 每条引用标注了版本年份或数据截至日期
- [ ] 关键数据可回溯到具体来源页面
- [ ] 时效性推文的数据与检索日期一致

#### 5.3 三重可读性检验

- **术语解释率 100%**：每个医学名词首次出现处是否有括号解释？
- **句子红线**：单句 ≤30 字、段落 ≤4 句（抽查最长段落地数）
- **"讲给初中生听"测试**：机制段落默读，自问"没学过医的家人能听懂吗？"——听不懂就重写

#### 5.4 编辑审稿模拟

切换到**第三方审稿人视角**通读全文，重点挑：逻辑断层、未解释术语、绝对化/广告化表述、参考文献与正文数据对应、时效推文的数据截至日期。发现问题立即修改并返回 5.1 复核。

#### 5.5 同行复核（可选）

**性质**：可选环节，不阻塞流程。发布前邀请科室同事抽查一次，可显著降低差错率。复核确认单：药品信息无误 / 术语解释得当 / 参考文献对应 / 无违规表述。

#### 5.6 发布前终检表（合并软约束量化）

**去AI味量化核对**：首段非"XX药是一种……"开头；过渡词 ≤ 每千字8处；作者声音 ≥ 2处；≥1处生活化比喻；段落有起伏；清单收尾有"例外"式补充。
**可读性量化核对**：最长段句数 ≤4、单句 ≤30字；无裸术语。
**合规量化核对**：全文无"治愈/根治/绝对安全/最有效"等违规词；无品牌对比、无疗效夸大、无扩大适应症。

**转化与互动量化核对**：文末含弱关注引导语（1句，不诱导不违规）；结尾抛具体问题引导留言（非泛泛"欢迎留言"）。

**完成全部勾选后，方可发布。**

## 总编审稿（高风险主题强制/普通可选）

### 定位

以"20 年审稿经验的著名杂志社总编"视角，对定稿推文出具《审稿意见书》——分析优缺点、按优先级给出改进建议，**是否采纳由使用者决定**。与第五步 5.4"编辑审稿模拟"（作者自审）互补，本环节是独立第三方外审。

### 触发规则（B 分级强制 + 两兜底）

**高风险主题：强制审稿**（无需询问，定稿后自动执行）。高风险清单（命中任一条即触发）：

| # | 高风险主题类型 |
|:-:|--------------|
| 1 | 儿科用药 |
| 2 | 孕产/哺乳期用药 |
| 3 | 抗菌药物/强效处方药（激素、抗凝药、免疫抑制剂等） |
| 4 | 时效热点（流行病数据、政策解读） |
| 5 | 首次发布（公众号首篇、栏目首篇） |
| 6 | 多药联用/特殊剂型（吸入剂、缓控释、注射剂等） |
| 7 | 特殊人群（老年、肝肾功能不全、免疫低下等） |
| 8 | 慢病人群（高血压/糖尿病/心脑血管等长期用药） |

**兜底 1（宁严勿松）**：主题归属模糊、无法确定是否高风险时，按高风险处理（强制审稿）。

**兜底 2（使用者加审）**：普通主题默认询问一次"是否需要总编审稿？"，确认需要则执行；任何主题使用者也均可主动要求。

### 审稿流程

1. **审稿**：按审稿六维（专业准确性/文献引用/逻辑结构/AI味/合规/传播性）审阅定稿推文（标准见 `references/审稿规范.md`）
2. **出具《审稿意见书》**（结构化）：

```
《审稿意见书》
1. 总体评价：✅可发布 / ⚠️修改后发布 / ❌需重大修改
2. 优点分析（2-4条）
3. 缺点与风险（按六维分类，标注严重度：高/中/低）
4. 改进建议（每条标注优先级 P0必须/P1建议/P2可选）
5. 采纳确认表（使用者逐条勾选：采纳/不采纳/理由）
6. 复审结论（采纳项修改后复审，给出终审意见）
```

3. **使用者决策**：逐条勾选"采纳 / 不采纳"——审稿只是参考，改不改由使用者决定
4. **复审**：采纳的建议修改后，复审给出终审结论；未采纳项不重审
5. **输出位置**：推文同目录，命名 `审稿意见书_<主题>_<日期>.md`

### 与漏洞反馈机制的衔接（两层）

- 审稿发现的**文章问题** → 写入《审稿意见书》，由使用者决定是否改进
- 审稿发现的 **Skill 本身漏洞** → 反馈作者，由作者定夺是否迭代（不擅自修改规则）

## 一图读懂生成（可选 · 按需触发）

### 触发方式

**推文定稿（第五步终检通过）后，主动询问使用者**：

> "推文已完成定稿。是否需要同步生成【一图读懂】信息图？（适合转发传播，可截图发公众号/朋友圈）"

- 使用者确认"需要"→ 执行生成，产出"一图读懂"HTML 文件
- 使用者回复"不需要"→ 跳过，不影响推文交付

### 生成流程

1. **从定稿推文中提取信息**（不新增任何推文以外的内容）：1 个核心声明 + 3-5 个关键数据 + 1 个表格或清单 + 1-2 条实用贴士 + 1 条安全警示（如有）
2. **套用品牌模板**：900px 竖版长图，品牌色可由使用者配置（详见 `references/一图读懂模板规范.md`）
3. **输出 HTML 文件**（可浏览器截图生成图片）
4. **一致性校验**：图中所有数字/剂量/疗程必须与推文正文完全一致（逐项核对）

### 一图读懂质量规则

- 图内信息 ≤ 推文信息，不新增、不放大、不缩写出歧义
- 每个数据卡只承载 1 个数字，避免信息过载
- 医学术语在图内必须保留通俗解释（与推文一致）
- **禁止使用 AI 生图工具**生成信息图（中文/医学术语易出现错字，图片不可编辑修正）
- 推文被修改后，已生成的一图读懂需重新生成以保持一致

### 输出位置

- 推文文件同目录，命名：`一图读懂_<主题>_<日期>.html`
- 交付时与推文文件一同呈现（HTML 自动打开预览，可直接截图）

### 发布建议（双产物错峰）

- **错峰发布**：推文与一图读懂建议间隔 1-2 天发布，避免同日互分流稀释单篇数据
- **渠道分工**：推文主发公众号主页/搜一搜（长尾沉淀），一图读懂主发朋友圈/社群（社交传播），各取所长
- **标题差异化**：同一主体两版标题应明显区分，避免读者误认为重复内容

## 参考文献引用规范（速览）

完整制度见 **`references/参考文献引用规范.md`**。核心要点：

1. **A级优先**：NMPA 说明书、中国药典、国家卫健委诊疗方案/指导原则、中华医学会指南、FDA/WHO/Cochrane/NEJM/Lancet/JAMA/BMJ/UpToDate/NICE/ESC 等

4. **名称精确**：指南引用必须使用官方发布全称并标注版本年份
5. **溯源可查**：每条关键信息可回溯到原始来源
6. **域名强制校验**：A级引用来源域名必须命中官方域名白名单

## 特殊场景处理规则

### 儿科用药科普
- 标题用 "宝宝 / 孩子" 替代 "儿童"；剂量注明 "遵医嘱，按体重计算"；增加 "什么情况下必须马上去医院" 提醒；语气更温柔

### 抗菌药物科普
- 必须强调 "抗生素 ≠ 消炎药"；提及耐药性问题；提醒 "不要自行购买、不要随意停药"

### 慢病用药科普
- 强调 "长期坚持、不要自行停药"；提及生活方式干预；增加复诊/监测提醒

### 中药/中成药科普
- 强调 "辨证论治，同病异治"；提及与西药相互作用风险；避免 "纯天然无毒副作用" 等误导表述

### 孕产期用药科普
- **优先采用国内权威表述**（中国药典、NMPA 说明书、国家卫健委及妇产科学会共识/指南）
- FDA 妊娠分级（A/B/C/D/X）仅作参考，引用时注明其局限性
- 强调"遵医嘱、个体化、权衡利弊"三原则；明确列出"相对安全可用"与"明确禁用"清单

### 时效热点科普
- 优先采用结构 D，数据必须来自 A/B 级来源并标注截至日期
- 每个关键数字后标注来源；避免渲染与恐慌；文末增加"信息来源"明细

### 特殊主题适配
罕见病用药、医疗器械、政策文件解读、叙事案例等四型外主题：按"结构适配决策规则"自定义结构（五要素校验）；罕见病/超说明书用药强化"遵医嘱"；政策解读只解读公开文件。

## 注意事项

1. **事实准确性第一**：宁可少写不确定的内容，不编造不准确的结论
2. **版权意识**：不直接复制粘贴其他公众号的原文，用自己的语言组织
3. **免责声明**：文末默认包含 "本文仅为科普参考，具体用药请咨询医师或药师"
4. **患者隐私**：不编造具体患者案例，可用 "有位患者问过我……" 或 "临床上常见……" 引入
5. **合规底线**：不比较药品品牌优劣，不暗示某种药品优于其他，不扩大适应症宣传
6. **广告法边界**：遵守《中华人民共和国广告法》《医疗广告管理办法》——科普与广告的边界在于"是否客观介绍、是否含商业目的"；禁用绝对化用语；不附产品购买链接；不出现厂商logo与宣传语；不暗示"治疗保证"
7. **漏洞反馈机制**：使用中发现 Skill 漏洞，主动记录并反馈给作者，由作者定夺是否更新迭代，不擅自修改规则。
