# 参考文献引用规范

> 适用范围：`pharma-wechat-science-writer` Skill 生成的所有科普推文
> 版本：v1.2.0 · 2026-08-12

本文件是 Skill 第二步检索、第五步参考文献核查的依据。核心原则：**A级优先、B级可用、C级禁用、名称精确、溯源可查、域名强制校验。**

---

## 一、来源三级分级制度

### A 级来源（必须优先，首选引用）

| 类别 | 具体来源 | 备注 |
|------|---------|------|
| 药品说明书 | NMPA 批准的最新版说明书 | 以通用名为准检索 |
| 药典 | 现行版《中国药典》（2025年版） | 每5年更新，注意版本 |
| 国家诊疗文件 | 国家卫健委诊疗方案、临床路径、合理用药指导原则 | 如《流行性感冒诊疗方案》《质子泵抑制剂临床应用指导原则（2020年版）》 |
| 权威指南 | 中华医学会及分会发布的指南/共识 | 如《中国高血压防治指南（2024年修订版）》 |
| 国际权威 | FDA、EMA、WHO、Cochrane、NEJM、Lancet、JAMA、BMJ、UpToDate、NICE、ESC、ADA 等 | 含其官方发布文件与数据库（DailyMed、PubMed） |

### B 级来源（可用，但必须标注日期）

| 类别 | 具体来源 | 使用条件 |
|------|---------|---------|
| 省级官方公告 | 省级疾控中心/药监局/卫健委文件 | 标注发布机构与日期 |
| 学术文献 | PubMed 索引期刊、SCI 收录综述 | 标注完整出处（作者. 题目. 期刊. 年份;卷(期):页码） |
| 国家级监测 | 中国疾控中心监测周报等 | 标注具体周次/期号与发布日期 |
| 专业工具书 | Micromedex、Drugs.com 药物数据库 | 仅作交叉核对，不单独引用 |

### C 级来源（一律禁止引用）

- 商业媒体（新浪、搜狐、腾讯新闻等平台稿件）
- 自媒体与营销号（微信公众号、百家号、头条号等非官方账号）
- 药企宣传内容、带推广性质的稿件
- 未注明出处的转载、二手转述
- 非同行评议的在线科普网站

> **注意**：C 级内容不是完全不能用——如"患者常见疑问"维度，可参考知乎、丁香园讨论**收集患者真实高频问题**，但**不得作为科学结论的引用来源**。收集问题≠引用结论。

## 二、官方域名白名单（强制校验）

**v1.2 升级：本白名单为强制校验标准，不再是"建议优先"。** 每条 A 级引用必须核对来源域名命中白名单；未命中的一律降级或弃用。

检索时优先在以下域名内取证（域名后缀为准，含其子域名）：

| 类别 | 域名 |
|------|------|
| 国家卫健委 | nhc.gov.cn |
| 国家药监局 | nmpa.gov.cn |
| 中国疾控中心 | chinacdc.cn |
| 国家流感中心 | ivdc.chinacdc.cn |
| 药典委员会 | chp.org.cn |
| 美国FDA | fda.gov、dailymed.nlm.nih.gov |
| 世界卫生组织 | who.int |
| 美国国立卫生研究院 | nih.gov、pubmed.ncbi.nlm.nih.gov、pmc.ncbi.nlm.nih.gov |
| 欧洲药监局 | ema.europa.eu |
| 其他 | 省级 gov.cn 卫生/药监/疾控站点 |

**强制校验规则**：
- 引用前：核对来源域名 → 命中白名单 → 允许作为 A 级引用；未命中 → 降为 B 级核查或弃用
- 引用后：在第五步参考文献核查清单中**逐条复验**
- 例外处理：若权威文献通过正规学术渠道（如知名大学官网、出版社官网）发布且可查证，可申请 B 级使用并注明理由；不得绕过校验升级为 A 级

## 三、四种引用格式模板

### 1. 指南/共识类

```
《中国高血压防治指南（2024年修订版）》. 中华高血压杂志. 2024.
```

### 2. 药品说明书类

```
苯磺酸氨氯地平片说明书. 国家药品监督管理局批准（国药准字H10950224）.
```

### 3. 期刊文献类（B级）

```
McConnell JD, et al. The long-term effect of doxazosin, finasteride, and combination therapy on the clinical progression of benign prostatic hyperplasia. N Engl J Med. 2003;349(25):2387-2398.
```

### 4. 监测数据/政策文件类

```
中国疾病预防控制中心. 全国急性呼吸道传染病哨点监测情况（2026年第30周）. 2026-07-30发布.
```

## 四、引用名称精确性自查

引用任何指南/方案/文件前，核对以下四项：

1. **全称精确**：使用官方发布的全称，如"《质子泵抑制剂临床应用指导原则（2020年版）》"，不写简称或口语化名称
2. **版本明确**：标注版本年份，如"2024年修订版""2020年版"
3. **发布机构**：标注制定/发布机构，如"国家卫健委合理用药专家委员会""中华医学会心血管病学分会"
4. **可查证**：名称应能通过官方渠道检索到，检索不到 = 名称不精确 = 需修正

**典型错误示范（审稿真实案例）**：
- ❌ "中国良性前列腺增生诊治指南"（名称不精确，应为《良性前列腺增生诊断治疗指南》，中华医学会泌尿外科学分会发布）
- ❌ "Science Insights, clinical evidence review"（非同行评议来源，应替换为 MTOPS/CombAT 研究原始文献）
- ❌ "新浪新闻《流感用什么药？》"（商业媒体，应替换为国家卫健委《流行性感冒诊疗方案》）

## 五、溯源记录模板（信息要点摘要用）

每篇推文检索阶段，按以下模板整理溯源记录：

```
【信息要点摘要】药品/话题：________  检索日期：________

1. 结论：________________
   来源级别：A/B
   来源名称：________________（全称）
   版本/日期：________________
   可查证入口：________________（官网URL或刊名+卷期）
   写入位置：推文第__部分

2. （逐条填写……）

★ 无法溯源的待定信息（不得写入正文）：
- ________
```
