# 测试用例集

> 版本：v1.3.0 · 2026-08-12（新增：用例6 双产物）
> 用途：验证 Skill 在各类主题下的输出质量与稳定性；比赛演示时可选用

---

## 使用说明

- 每个用例给出"输入 → 预期结构 → 验收标准"
- 验收标准引用 SKILL.md 第五步的检查清单（5.1-5.6）
- 运行用例后，对照验收标准逐项勾选，全部通过即视为该用例合格
- 建议：Skill 每次版本迭代后，用全部 5 个用例回归测试

---

## 用例 1：单药科普（结构 A）

**输入**："写一篇布洛芬的科普"

**预期产出**：
- 结构 A 八段式（标题/导语/是什么/能治什么/怎么吃/注意事项/关键提醒/互动结尾）
- 标题含数字或疑问词
- 参考文献 ≥4 条，全部 A/B 级，标注版本

**验收标准**：
- [ ] 结构 A 要素齐全
- [ ] 5.1 基础清单全部通过
- [ ] 5.2 参考文献核查通过（含域名强制校验）
- [ ] 5.3 三重可读性检验通过
- [ ] 5.6 终检表通过（去AI味量化核对达标）

## 用例 2：同类药对比（结构 C）

**输入**："ACEI 和 ARB 类降压药怎么选，写篇科普"

**预期产出**：
- 结构 C（对比表格 + 逐一讲解 + 分人群建议）
- 对比维度 ≥5 项（机制/适用人群/副作用/禁忌/相互作用）
- 无明显偏向性表述（合规）

**验收标准**：
- [ ] 结构 C 要素齐全
- [ ] 对比维度 ≥5 项
- [ ] 无品牌比较、无"哪个更好"绝对化表述
- [ ] 5.1/5.2/5.3/5.6 通过

## 用例 3：用药话题（结构 B）

**输入**："儿童退烧药怎么选"

**预期产出**：

**验收标准**：
- [ ] 结构 B 要素齐全
- [ ] 儿科特殊规则全部启用
- [ ] 有"什么情况必须马上去医院"提醒
- [ ] 5.1/5.2/5.3/5.6 通过

## 用例 4：时效热点（结构 D）

**输入**："根据最新流感监测数据写一篇科普"

**预期产出**：
- 结构 D（数据速览 + 通俗解读 + 对策清单 + 误区澄清）
- 数据来自 A 级来源（中疾控/国家流感中心），标注周次与发布日期
- 明确标注"数据截至日期"

**验收标准**：
- [ ] 结构 D 要素齐全
- [ ] 数据可溯源至官方（域名白名单命中）
- [ ] 有"数据截至日期"标注
- [ ] 无恐慌渲染、无未经证实的数据
- [ ] 5.1/5.2/5.3/5.6 通过

## 用例 5：特殊人群/特殊主题（自定义结构）

**输入**："孕期感冒药怎么吃" 或 "写一篇关于吸入剂的科普"

**预期产出**：
- 若使用标准结构：孕期用 A/B 型；吸入剂用 A 型
- 若自定义结构：必须通过"五要素校验"（导语/证据/清单/警示/互动）
- 孕期主题：强化"遵医嘱"、涉及 FDA 妊娠分级或国内指南表述

**验收标准**：
- [ ] 结构适配决策正确（标准结构或自定义五要素通过）
- [ ] 特殊人群规则启用
- [ ] 孕期主题：**优先采用国内指南/说明书表述；FDA 妊娠分级仅作参考并注明局限（v1.4 规则）**
- [ ] 5.1/5.2/5.3/5.6 通过

## 用例 6：双产物（推文 + 一图读懂，v1.3 新增）

**输入**："写一篇奥司他韦的用药科普，要配一图读懂"

**预期产出**：
- 产物①：完整推文（Markdown，按结构 A/B 撰写）
- 产物②：一图读懂（900px 竖版 HTML 信息图，按品牌模板）

**触发验证**：
- [ ] 推文定稿后，Skill 主动询问"是否需要生成一图读懂"（按需触发）
- [ ] 使用者确认"需要"后，才生成一图读懂（不默认附带）

**一图读懂验收标准**：
- [ ] 信息 ≤ 推文信息：核心声明1 + 关键数据3-5 + 表格/清单1 + 贴士1-2 + 警示0-1
- [ ] 品牌模板正确（公众号头尾、栏目/落款一致）
- [ ] **一致性校验**：图中每个数字/剂量/疗程与推文正文逐字一致
- [ ] 无新增内容、无夸大表述
- [ ] 无 AI 生图痕迹（HTML 结构清晰可编辑）

**双产物验收标准**：
- [ ] 两个产物同主题、同数据、同品牌调性
- [ ] 推文修改后，一图读懂可同步重新生成

**已验证样例（通用示例）**：
- 推文：`发布稿_奥司他韦用药科普.md`
- 一图读懂：`一图读懂_奥司他韦.html`

## 用例 7：总编审稿（v1.5 新增）

**输入**：一篇含已知缺点的推文（预设问题：① 1 处剂量表述模糊"一次1-2粒"；② 2 处过渡词"此外"；③ 标题无数字钩子）

**触发验证**：
- [ ] 高风险主题（如儿科/孕产/抗菌/时效/首次发布）→ **强制审稿**，无需询问
- [ ] 普通主题 → 询问一次"是否需要总编审稿"，使用者确认后执行
- [ ] 兜底1：主题归属模糊 → 按高风险处理
- [ ] 兜底2：使用者主动要求 → 任何主题都执行

**《审稿意见书》验收标准**：
- [ ] 总体评价正确判定（⚠️修改后发布）
- [ ] 优点分析 2-4 条
- [ ] 能识别全部预设问题（剂量模糊/过渡词/标题钩子）
- [ ] 每条问题标注严重度（高/中/低）
- [ ] 每条建议标注优先级（P0/P1/P2），且剂量问题为 P0
- [ ] 采纳确认表结构完整（使用者可逐条勾选）
- [ ] 复审规则可用（采纳项修改后复审）

**决策权验证**：
- [ ] 使用者可"不采纳"建议且不影响交付
- [ ] 审稿发现的 Skill 漏洞反馈作者（不擅自改规则）

### 用例 7b：合规变体子用例（v1.5 新增）

**输入**：一篇含违规表述的推文（预设：①"根治" ②"最有效" ③"绝对安全，没有任何副作用" ④"医生首选"暗示背书 ⑤"药到病除"疗效断言 ⑥"赶紧买来试试"诱导购买 ⑦缺免责声明）

**合规维度验收标准**：
- [ ] 总体评价判定为"❌需重大修改"（多P0）
- [ ] 识别全部预设违规点（根治/最/绝对安全/背书/疗效断言/诱导购买/缺免责声明）
- [ ] 每条违规标注严重度，且涉违规项为"高"
- [ ] 建议含 P0（删除绝对化用语/删诱导购买/补免责声明）
- [ ] 合规维度未被遗漏（六维全覆盖验证）

**已验证（2026-08-13）**：6类违规表述全部识别，判定"需重大修改"；六维全覆盖验证完成。
