# 一图读懂 · 模板规范

> 版本：v1.3.0 · 2026-08-12
> 归属：`pharma-wechat-science-writer` Skill 的一图读懂配置模块
> 用途：推文定稿后按需生成 900px 竖版品牌信息图

---

## 一、信息提取规则（从推文自动提炼，不新增内容）

| 模块 | 内容 | 数量 | 来源 |
|------|------|:---:|------|
| 核心声明 | 全文最重要的一句话 | 1 | 推文"关键提醒/记住这X条" |
| 关键数据 | 剂量/疗程/窗口期/发生率等数字 | 3-5 | 推文正文 |
| 表格/清单 | 儿童体重表、对比表、误区清单等 | 1 | 推文中的表格或列表 |
| 实用贴士 | 提升用药体验的小细节 | 1-2 | 推文"小贴士"类内容 |
| 安全警示 | 需加粗的警示语（如有） | 0-1 | 推文加粗警示 |

**铁律**：图中信息 **≤ 推文信息**。不新增内容、不放大程度、不缩写出歧义。图中数字必须与推文逐字一致。

---

## 二、品牌模板（900px 竖版）

### 整体结构（自上而下）

```
┌─────────────────────┐
│ ① 品牌头部           │ 渐变主色底，白字
│   公众号名·栏目名     │   "{公众号名} · {栏目名}"
│   主标题（≤18字）     │
│   数据副题（来源+日期） │
├─────────────────────┤
│ ② 核心声明区          │ 浅底+主色描边卡
│   大字号一句话         │
├─────────────────────┤
│ ③ 关键数据卡（3-5张）  │ 网格排列，每卡1个数字
├─────────────────────┤
│ ④ 表格/清单区         │ 主色表头表格 或 编号清单
├─────────────────────┤
│ ⑤ 实用贴士区          │ 勾选图标+短句
├─────────────────────┤
│ ⑥ 安全警示条          │ 深红底白字（如无警示则省略）
├─────────────────────┤
│ ⑦ 品牌尾部            │ 副色底
│   公众号slogan        │
│   落款+免责声明        │
└─────────────────────┘
```

### 品牌色（示例配置）

以下为**示例配色**，使用者可按公众号品牌自行配置（保持一致即可）：

| 用途 | 色值（示例） |
|------|------|
| 主色（暖橙） | #e8a33d / 深 #d9822b |
| 副色（青绿） | #2e8b8b |
| 警示（深红） | #b8433c |
| 背景（米白） | #fffdf9 |
| 正文（深灰） | #333 |

### 字体与尺寸

- 主标题：38-42px，加粗
- 区块标题：28-32px，加粗
- 数字：38-42px，加粗，杏黄
- 正文：18-20px
- 行距：1.5-1.6

## 三、生成与交付规范

1. **输出格式**：HTML 文件（内联 CSS，无外部依赖），宽 900px，浏览器打开即可截图
2. **命名**：`一图读懂_<主题>_<日期>.html`
3. **禁止 AI 生图**：不得用 AI 生图工具生成信息图（中文/医学术语易错字、不可编辑）
4. **一致性校验**（生成后逐项核对）：
   - [ ] 图中每个数字与推文正文逐字一致
   - [ ] 术语通俗解释与推文一致
   - [ ] 无新增内容、无夸大表述
   - [ ] 品牌头尾/栏目/落款正确
5. **同步更新**：推文后续修改后，一图读懂需重新生成以保持一致

## 四、HTML 模板骨架（参考）

```html
<div class="card" style="width:900px; background:#fffdf9;">
  <!-- 品牌头部：渐变杏黄 -->
  <div style="background:linear-gradient(135deg,#e8a33d,#d98a2b); color:#fff; padding:48px 56px;">
    <div>{公众号名} · {栏目名}</div>
    <h1>{主标题}</h1>
    <div>{数据副题：来源+截至日期}</div>
  </div>
  <!-- 核心声明：浅杏卡 -->
  <div style="margin:36px 56px; background:#fdf3e0; border:2px solid #e8a33d; border-radius:16px; padding:28px 32px; text-align:center;">
    <div style="font-size:34px; font-weight:800; color:#d9822b;">{核心声明}</div>
  </div>
  <!-- 关键数据卡（grid 3列） -->
  <div style="display:grid; grid-template-columns:1fr 1fr 1fr; gap:20px; margin:0 56px;">
    <!-- 每卡：1个数字 + 说明 -->
  </div>
  <!-- 表格/清单 -->
  <!-- 实用贴士 -->
  <!-- 安全警示条：深红底白字 -->
  <!-- 品牌尾部：水乡青 -->
</div>
```
