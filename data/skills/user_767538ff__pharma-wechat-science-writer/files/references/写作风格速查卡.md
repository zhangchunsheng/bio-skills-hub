# 写作风格速查卡

> 每次写作时快速对照，确保风格统一
> 版本：v1.2.0 · 2026-08-12（新增：软约束量化核对、广告法边界速查）

---

## 一、语言温度计：冷 → 暖

| 温度 | 表达方式 | 适用场景 |
|------|---------|---------|
| ❄️ 冷 | "本品适用于……禁忌症包括……" | 说明书原文引用（仅限必要引用） |
| 🧊 偏冷 | "该药物主要用于治疗……" | 标准科普正文 |
| 🌤️ 温暖 | "这个药能帮你解决……" | 开头/结尾/患者互动段落 |
| 🔥 过热 | "这药太神奇了！赶紧吃！" | ❌ 禁止 |

## 二、常见医学术语的通俗表达

| 专业术语 | 患者友好表达 |
|---------|------------|
| 非甾体抗炎药 | 一类兼具退烧、止痛、消炎作用的药 |
| 生物利用度 | 吃进去的药有多少真正被身体吸收利用 |
| 半衰期 | 药在体内浓度降一半需要的时间 |
| 首过效应 | 口服的药经过肝脏时被"拦截"代谢掉一部分 |
| 治疗窗 | 药量既够用又安全的范围 |
| 超敏反应 | 身体对药物产生的过度敏感反应，像"警报器太灵敏" |
| 禁忌症 | 这种情况不能用这个药 |
| 肝药酶诱导剂/抑制剂 | 让肝脏"加速/减速"分解药物的物质 |
| 钙通道阻滞剂 | 堵住血管壁细胞上"钙离子通道"，让血管放松的药 |
| 质子泵抑制剂 | 拧紧胃酸"水龙头"的一类抑酸药 |
| α受体阻滞剂 | 放松前列腺和尿道平滑肌、让尿路通畅的药 |
| 5α-还原酶抑制剂 | 减少雄激素刺激、让前列腺慢慢缩小的药 |
| 逼尿肌 | 负责收缩、把尿"挤"出去的膀胱肌肉 |
| 残余尿 | 每次排尿后没排干净、留在膀胱里的尿 |
| 体位性低血压 | 突然站起来时血压下降、头晕眼黑 |
| 输液/补液 | 通过静脉把水分和电解质补进身体 |
| 肾素-血管紧张素系统 | 身体里一套"升血压"的调节系统 |
| 肠溶包衣 | 药片外层的保护衣，只在肠道碱性环境才溶解 |

## 三、绝对不能用的表述

- ❌ "治愈"、"根治"、"药到病除"
- ❌ "没有副作用"、"绝对安全"
- ❌ "某品牌更好"、"比XX药强"
- ❌ "建议大家都吃"、"可以长期服用"（不注明条件）
- ❌ "最新研究证明……"（不注明出处）
- ❌ "我推荐……"（药师个人推荐某品牌）

## 四、应该多用的句式

- ✅ "根据《中国XX指南（20XX年版）》……"（注明版本）
- ✅ "临床研究显示……"
- ✅ "需要提醒大家的是……"
- ✅ "如果出现……建议及时就医"
- ✅ "每个人的情况不同，具体用药请咨询您的医师或药师"

**作者声音句式（v1.1 新增，每篇至少用1处）：**

- ✅ "我在门诊遇到过一位患者……"
- ✅ "有位患者问我……"
- ✅ "说实话，这个误区真的很常见"
- ✅ "作为药师，我最想提醒的是……"
- ✅ "（写完核心清单后）当然，每个人情况不同，具体还是要问你的医生"

## 五、段落节奏控制

```
标准科普段 = 1个核心观点 + 1句解释 + 1个例子 + 1句提醒

例：
布洛芬退烧通常需要30-60分钟才能开始起效。（核心观点）
也就是说，吃完药不会马上退烧，要等半小时到一小时。（解释）
很多家长看到孩子吃完药没退烧就急着换药，其实需要耐心等待。（例子）
不过，如果服药2小时后体温仍然不降，建议及时就医。（提醒）
```

**节奏变化原则（v1.1 新增）：** 不要每段都按上面四步走。
- 长段（3-4句）之后，允许插入一句一行短句作"呼吸点"——如"这件事，真没那么简单。"
- 全文段落长短应有起伏，避免均质化。

## 六、去AI味自检清单（v1.1 新增）

写作完成后逐项核对：

- [ ] 第一段是否以对话/场景开头？（以"XX药是一种……"开头 → 不合格，重写导语）
- [ ] 全文"首先/其次/此外/同时/综上/值得一提"等过渡词 ≤ 每千字8处？
- [ ] 是否每 500 字有一处"我/我的/我在门诊"的个人表达？
- [ ] 是否至少有一处生活化比喻？
- [ ] 段落长短是否有起伏（不全是3-4句的均质段落）？
- [ ] 清单收尾是否有一句"例外"式补充（如"当然，每个人情况不同……"）？

**高频过渡词"黑名单"（能删就删）：**

此外、与此同时、另外、值得一提的是、值得注意的是、需要指出的是、综上所述、总而言之、首先/其次/最后（每篇最多用一组）

**软约束量化核对法（v1.2 新增，把"软约束"变成可数指标）：**

| 软约束 | 量化方法 | 合格线 |
|--------|---------|--------|
| 过渡词控制 | 全文逐段扫描，圈出黑名单过渡词并计数 | ≤ 每千字8处 |
| 作者声音 | 数"我在门诊/有位患者/说实话/作为药师"出现次数 | ≥ 2处/篇 |
| 对话式开头 | 检查首段是否有对话引语或场景叙述 | 必须有 |
| 段落起伏 | 扫描是否出现连续3段均为3-4句的均质段 | 不得出现 |
| 例外式收尾 | 检查"记住这X条"后是否有"当然/具体还是问医生"句 | 必须有 |
| 比喻密度 | 数生活化比喻数量 | ≥ 1处/篇 |

## 七、三重可读性检验（v1.1 新增）

1. **术语解释率 100%**：全文扫描，每个医学名词首次出现处必须有括号解释
2. **句子红线**：单句 ≤30 字、段落 ≤4 句（抽查最长段落地实数一遍）
3. **"讲给初中生听"测试**：把机制段落默读一遍，自问"没学过医的家人能听懂吗？"——听不懂就重写叙述部分（专业数据保留，表达必须通俗）

## 八、专业性与通俗性的平衡红线（v1.1 新增）

| 内容类型 | 通俗化要求 | 不可妥协项 |
|---------|-----------|-----------|
| 作用机制 | 用生活比喻讲"大概怎么起效" | 不把机制讲错、不编造机制 |
| 适应症 | 说人话解释"什么情况下用" | 适应症范围严格照说明书/指南 |
| 用法用量 | 用"每天几次、每次几片"说清楚 | 剂量精确到mg、疗程精确到天数 |
| 副作用 | 用"可能出现的反应"温和表达 | 发生频率、严重反应不能弱化 |
| 禁忌 | 说清"哪些人不能用" | 禁忌清单一条都不能漏 |

## 九、广告法边界速查（v1.2 新增）

依据《中华人民共和国广告法》《医疗广告管理办法》，科普内容与广告的边界判断：

| 允许（科普） | 禁止（涉广告） |
|-------------|--------------|
| 客观介绍药品机制、用法、禁忌 | 绝对化用语：最、第一、根治、特效、100% |
| 引用说明书/指南原文结论 | 疗效承诺："保证痊愈""无效退款" |
| 提醒就医指征、引导咨询药师 | 诱导购买：附购买链接、厂商logo、宣传语 |
| 用"你"与读者对话 | 使用"医生推荐""专家首选"等暗示性背书 |
| 文末免责声明 | 暗示"治疗保证"、夸大适应症 |

**判断口诀**：这篇内容让读者"更懂药"，还是"想买药"？——后者即越界。

## 十、品牌调性速查（可配置）

品牌信息（公众号名称、栏目、落款、互动话术）由使用者自行配置。速查要点（示例）：
- 固定落款：按公众号设定（如"——XX · 门诊药师"）
- 栏目归属：主题匹配对应栏目名
- 互动话术：以药师身份收尾（如"药师在窗口等您"）
- 风格基调：专业 + 温度 + 人文关怀（可融入本地文化意象，形成差异化）
