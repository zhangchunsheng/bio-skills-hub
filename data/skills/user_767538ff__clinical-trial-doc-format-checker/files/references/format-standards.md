# 罗定市人民医院药物临床试验机构体系文件格式标准

> 依据《制定标准操作规程的操作规程（SOP-SOP）》V1.0 强制执行。
> 本文件为格式审核专员的唯一格式依据，**不得凭经验或常识改动**。
> 业务内容（条款、职责、流程文字）一律不在格式审核范围内。

---

## 一、适用文件类型

五大类体系文件，每类文件类型仅影响第 1 页主标题与表格表头结构：

| 类型代码 | 中文名称 | 第 1 页主标题前缀 |
|---------|---------|------------------|
| `JOB`    | 岗位职责       | 岗位职责/修订记录 |
| `MGT`    | 管理制度       | 管理制度/修订记录 |
| `SOP`    | 标准操作规程   | 标准操作规程/修订记录 |
| `DSN`    | 设计规范       | 设计规范/修订记录 |
| `EMR`    | 应急预案       | 应急预案/修订记录 |

## 三、页眉

| 项目 | 标准 |
|-----|------|
| 左侧文字 | 罗定市人民医院药物临床试验机构 |
| 右侧文字 | 文件编码本身（如 HX-ZZ-001-2.0），**不带"文件编码："前缀** |
| 字体 | 宋体 |
| 字号 | 小四（12pt） |
| 对齐 | 左侧左对齐，右侧右对齐 |

> 文件编码缺漏或两侧文字写反，记为重点风险。

## 五、第 1 页格式

### 5.0 首页结构

首页仅包含以下内容，按顺序排列：

1. **主标题**（如"岗位职责"）
2. **表头表格 1**（制/修订信息：制/修订人签名、审核人签名、批准人签名、发布日期、生效日期）
3. **主标题**（"修订记录"）
4. **表头表格 2**（版本与修订记录：版本及修订号、修订内容、修订人、审核人、批准人、生效日期）
5. **分页符** —— 正文从第 2 页开始

> 首页不得包含正文内容（目的、范围等）。正文一律从第 2 页开始。

### 5.1 主标题

| 项目 | 标准 |
|-----|------|
| 文字 | 标准操作规程 / 岗位职责 / 管理制度 / 设计规范 / 应急预案 |
| 对齐 | 居中 |
| 字体 | 华文中宋 |
| 字号 | 三号（16pt） |
| 加粗 | 是 |
| 段前 | 1.5 行 |
| 段后 | 0.5 行 |
| 行距 | 固定值 24 磅 |

> **主标题结构保持原文，不合并、不拆分。** 若原文档第 1 页主标题分为多段（如"岗位职责"一段、"修订记录"一段），应保持原文分段结构，不强行合并为"岗位职责/修订记录"。第 2 页若有重复主标题，同样保持原文结构。

### 5.2 表头表格（仅第 1 页）

#### 表格 1：制/修订信息

| 字段 | 必填 |
|-----|------|
| 制/修订人 | 是 |
| 审核人 | 是 |
| 批准人 | 是 |
| 发布日期 | 是 |
| 生效日期 | 是 |

#### 表格 2：版本与修订记录

| 字段 | 必填 |
|-----|------|
| 版本及修订号 | 是 |
| 修订内容 | 是 |
| 修订人 | 是 |
| 审核人 | 是 |
| 批准人 | 是 |
| 生效日期 | 是 |

**表头表格格式：**

| 项目 | 标准 |
|-----|------|
| 水平对齐 | 居中 |
| 垂直对齐 | 居中（单元格上下居中） |
| 字体 | 宋体 |
| 字号 | 11 号（11pt） |
| 加粗 | 是 |
| 行高 | 固定值 1.2 厘米 |

> 表头表格所有单元格必须同时满足左右居中与上下居中。

### 5.3 表格内容（除表头表格外的其他表格）

| 项目 | 标准 |
|-----|------|
| 字体 | 宋体 |
| 字号 | 11 号（11pt） |
| 段前/段后 | 0 行 |
| 对齐 | 两端对齐 |

## 六、第 2 页及以后格式

### 6.1 主标题（同 5.1）

每个分页后的第一行若出现文件主标题，应与第 1 页主标题保持一致格式。

### 6.2 正文

| 项目 | 标准 |
|-----|------|
| 字体 | 宋体 |
| 字号 | 小四（12pt） |
| 行距 | 固定值 24 磅 |
| 段前/段后 | 0 行 |
| 首行缩进 | 2 字符 |
| 对齐 | 两端对齐 |

### 6.3 一级标题

固定六大一级标题（如有缺失或顺序错误，记为重点风险）：

1. 一、目的
2. 二、范围
3. 三、内容
4. 四、附加
5. 五、参考依据

> 注：根据机构实务，常见五大一级标题（一、目的 / 二、范围 / 三、内容 / 四、附加 / 五、参考依据）。SOP-SOP V1.0 默认五项；若文档存在"四、附加""五、参考依据"以外的额外标题需提示用户确认。

**一级标题格式：**

| 项目 | 标准 |
|-----|------|
| 字体 | 宋体 |
| 字号 | 小四（12pt） |
| 加粗 | 是 |
| 行距 | 固定值 24 磅 |
| 段前/段后 | 0 行 |
| 首行缩进 | 2 字符 |
| 对齐 | 两端对齐 |

> 一级标题必须加粗，但**不得**改变字号或字体；不得使用"1. 目的"等阿拉伯编号替代"一、"。

### 6.4 编号层级（6 级）

**强制层级，不得跳级、不得混用、不得改变符号：**

| 层级 | 格式 | 示例 |
|-----|------|------|
| 第一层 | 汉字数字 + 顿号 | `一、` `二、` `三、` |
| 第二层 | 汉字括号包裹 | `（一）` `（二）` `（三）` |
| 第三层 | 阿拉伯数字 + 点 | `1.` `2.` `3.` |
| 第四层 | 阿拉伯数字括号 | `（1）` `（2）` `（3）` |
| 第五层 | 带圈数字 | `①` `②` `③` |
| 第六层 | 数字 + 右括号 | `1)` `2)` `3)` |

**常见错误（必须提示）：**

- 第一层误用 `1.` 或 `一.` 或 `（一）`
- 第二层误用 `1)` 或 `一、`
- 第三层误用 `（1）` 或 `1)` 或 `一、`
- 第四层误用 `1)` 或 `1.`
- 第五层误用 `1.` 或 `1)` 或文字"第一"
- 第六层误用 `（6）` 或 `1.`
- 层级倒序（如直接从第四层跳到第二层）
- 一份文件中同一层级混用两种符号

> 注：第二层"（一）"与第四层"（1）"外型相似但含义不同——汉字括号必须用汉字数字，阿拉伯括号必须用阿拉伯数字。

### 6.5 正文表格

| 表格部位 | 字体 | 字号 | 加粗 |
|---------|-----|------|------|
| 表头（第一行） | 宋体 | 小四（12pt） | 是 |
| 表格内容 | 宋体 | 小四（12pt） | 否 |

> 表头表格（第 1 页制修订信息）的格式见 5.2，**不**适用本条。

### 6.6 附件

| 项目 | 标准 |
|-----|------|
| 附件标题对齐 | 居中 |
| 附件标题字体 | 黑体 |
| 附件标题字号 | 三号（16pt） |
| 附件正文字体 | 宋体 |
| 附件正文字号 | 小四（12pt） |

> 附件标题与正文标题（华文中宋）字体不同，**严禁混用**。

## 八、核对工作流（专员执行顺序）

1. **识别文件类型**：根据用户输入的"文档类型"，匹配 §一 中类型代码。
2. **结构核验**：检查第 1 页主标题、表头表格字段是否齐全。
3. **页面核验**：检查页边距、页眉页脚（无法从纯文本完全判定时，标记为"需在 Word 中复核"）。
4. **正文章节核验**：检查一级标题是否齐全、顺序正确。
5. **编号层级核验**：按 §6.4 逐层比对，记录任何符号混用、跳级、倒序。
6. **表格格式核验**：区分表头表格（5.2）与正文表格（6.5）。
7. **附件核验**：检查附件标题字体（黑体）与正文标题字体（华文中宋）是否区分。
8. **生成报告**：按"检查项｜标准要求｜存在问题｜修改建议"四列表格输出。
9. **生成修正文本**：仅调整格式，业务内容一字不改，调用 `scripts/generate_docx.py` 输出 .docx。
10. **风险提示**：将编号错误、标题错误、表格错误、页眉页脚缺失、层级混乱列入【二、重点风险提示】。

## 九、绝对禁止事项

1. ❌ 修改任何业务条款、职责、流程文字。
2. ❌ 自行增删章节（如"目的""范围"等内容）。
3. ❌ 推测文档未提供的格式参数（如页边距缺失时只能提示，不得填默认值）。
4. ❌ 将"11 号"等同于"小四"。
5. ❌ 用阿拉伯数字编号替代汉字数字编号（或反之）。
6. ❌ 修改文件编码、生效日期、批准人等表头字段的内容。
7. ❌ 在附件标题使用华文中宋，或在正文主标题使用黑体。
