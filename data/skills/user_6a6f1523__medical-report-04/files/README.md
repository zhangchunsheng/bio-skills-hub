# 健身计划定制助手

## 功能介绍
输入你的身体数据和健身目标，生成专属个性化健身计划，包含每周训练安排、具体动作组数次数、饮食建议，科学高效不踩坑。

## 使用方法
把你的情况发给AI，例如：
- 「我170cm，70kg，想减脂，零基础，每周能练3次，在家练」
- 「身高180，体重65kg，想增肌，有一定基础，健身房训练，每周4次」
- 「帮我制定一个塑形计划，女生，体重55kg，想练臀腿和核心」

需要提供的信息：
- 身高、体重、年龄、性别
- 健身目标（减脂/增肌/塑形/提升体能）
- 健身基础（零基础/入门/中级/高级）
- 每周可训练次数和时间
- 训练场地（家/健身房/户外）
- 有无器械

## 输出内容
- 个性化周训练计划（每天训练内容）
- 具体动作+组数+次数+休息时间
- 饮食建议（热量/三大营养素/饮食示例）
- 训练注意事项
- 进阶建议

## 适合人群
健身新手、想减肥/增肌的人、上班族、居家健身者、需要科学训练方案的人
