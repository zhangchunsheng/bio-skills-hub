# 剧荒推荐 · Anime Recommender

一个把「剧荒」变成好玩人格测试 + 精准动漫推荐的 Skill。输入你最爱的几部动漫，它会分析你的**观影 DNA**，把你匹配到 **12 种观影人格**之一，再从约 **2975 部动画库**里生成一份专属片单（五档推荐，每部带简介和推荐理由），还能生成带卡通形象的可分享图。

> 只推动画（TV 番 + 动画电影），不推荐任何真人影视。

---

## 一、它能做什么

1. **测观影人格**：暗夜造梦师 / 温暖治愈系 / 智性探索者 / 情感深渊潜行者 / 冒险浪漫派 / 世界观建筑师 / 纯粹感受者 / 暗黑实验家 / 现实凝视者 / 复杂共情者 / 热忱群像派 / 多元观影者。
2. **出专属片单**：每个人格 20 部，按「你的本命 → 上头预警 → 开个盲盒 → 宝藏冷门 → 意外惊喜」五档排好，每部有标签、一句话简介、带人格视角的推荐理由。
3. **听懂反馈**：说「这几部不喜欢」或「都看过了」，它会换一批，而不是简单地删掉。
4. **出分享图**（可选）：人格卡 + 片单长图，自带统一卡通形象，适合发朋友圈。

---

## 二、怎么用（对话即可，无需敲命令）

直接对搭载本 Skill 的助手说：

- 「帮我测测我的观影人格」
- 「我剧荒了，推荐点动漫。我最爱 排球少年!!、灌篮高手、蜂蜜与四叶草、灵能百分百」
- 「我是热忱群像派，给我出片单」
- 「这几部不喜欢：排球少年!!、灌篮高手，避开运动题材」→ 换一批
- 「这些都看过了」→ 换没看过的

助手会在对话里完成 DNA 分析、人格匹配、片单生成和反馈迭代。如需分享图，让它「生成分享图」即可。

## 三、开发者 / 自部署（可选）

本 Skill 的引擎是纯 Python（无需联网、无需 API key）。

### 1. 安装依赖
```bash
pip install -r requirements.txt
# Pillow   —— 仅渲染分享图时需要，只想拿文字片单可跳过
# opencc-python-reimplemented —— 繁简归一化（缺了不报错，但会残留日文异体字标题）
```

### 2. 直接在命令行试跑引擎
```bash
cd skills/juhuang-tuijian/scripts
python works_pool.py            # 打印作品库统计 + 两个示例人格片单
python dna_analyzer.py          # 跑一遍完整 DNA 分析 → 人格裁决 → 片单 的演示
python build_share.py --persona "热忱群像派" --out-dir output   # 生成分享图
python apply_feedback.py --seen "排球少年!!" "灌篮高手"          # 反馈：看过了→重推
python apply_feedback.py --dislike "排球少年!!" --tags "运动"    # 反馈：不喜欢→重推
```

### 3. 字体
渲染图片需要中文字体。脚本会自动回退到系统字体（macOS 的 PingFang、Windows 的微软雅黑、Linux 的 Noto CJK）。若你的机器没有可用 CJK 字体，把一个开源字体（如 `NotoSansCJK-Regular.ttc`）放进 `assets/fonts/` 即可。**本 Skill 不打包专有商业字体**。

## 四、常见问题

- **Q：为什么推荐的都是日漫？**
  A：动画产量上日本一家独大。但助手会根据你提到的作品**自动推断地区偏好**——你多聊国漫/欧美番，片单里对应地区就会靠前，不会永远日本第一。**即使只报 2–3 部国漫也会被采信**，地区偏好不会因为"说得少"就被丢掉。
- **Q：为什么片单只有「你的本命」和「上头预警」两档？**
  A：片单本应五档齐全（本命 6 / 上头 5 / 盲盒 4 / 冷门 3 / 惊喜 2）。若只出两档，说明检索逻辑的五档配额保底被破坏了，请检查 `works_pool.py` 中标注 `FIX-A` / `FIX-B` / `FIX-D` 的三处改动是否还在。
- **Q：片单能个性化吗？**
  A：能。同样的人格，不同 DNA 画像会拿到不同的 20 部（同人格内按与你口味的相似度重排）。
- **Q：作品库会更新吗？**
  A：当前约 2975 部。后续扩充可参考 `references/扩库提示词.md` 的提示词模板，用 LLM 批量补标新作品。
- **Q：我的数据会被保存吗？**
  A：不会。反馈循环只在当轮对话里进行，不落盘、不持久化。
