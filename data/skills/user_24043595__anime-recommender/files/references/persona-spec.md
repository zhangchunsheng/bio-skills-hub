# 剧荒推荐 · 12 观影人格规范（标注 & 匹配用）

本文件是「观影人格」的权威定义，供 LLM 在对话中做 DNA 匹配、以及未来做作品库扩标时统一口径。

## 一、六维模型（沉浸 / 情感 / 智识 / 暗度 / 群像 / 冒险，0–100）

人格即六维空间里的「目标向量」。用户同样被映射为六维得分向量 `U`，匹配分：

```
Score_p = 100 - mean(|U_i - T_p,i|)      # 0–100，越高越匹配
主人格 = argmax(Score_p)                  # 12 选 1，天然唯一
```

## 三、tier 分层（相对该人格的契合度）

| tier | 命名（片单展示） | 含义 |
|---|---|---|
| `like` | 你的本命 | 与 DNA 严丝合缝的标杆级作品 |
| `expand` | 上头预警 | 契合度稍次的拓展推荐 |
| `try` | 开个盲盒 | 风格相近但更偏、更冒险的选择 |
| `niche` | 宝藏冷门 | 冷门但对特定人格有独特价值 |
| `neighbor` | 意外惊喜 | 相邻人格 / 跨区同人格的突破补位 |

## 四、cat 标签规范

`cat` 为「大类·小类」两词组用 `·` 连接，例：`奇幻·暗黑`、`热血·校园`、`治愈·日常`、`悬疑·推理`。
题材词表（动漫域）见 `references/观影DNA分析框架.md` 元维度，常用：运动/热血/群像/治愈/青春/成长/喜剧/日常/奇幻/科幻/悬疑/推理/冒险/暗黑/战斗/史诗/职场/爱情/催泪/音乐/武侠/仙侠/权谋/魔幻/搞笑/现实/历史/异界/怪兽。

## 五、作品字段规范（9 字段全中文）

`name / year / direction(动漫|动画电影) / region(日本|中国|韩国|台湾|欧美|法国|加拿大|俄罗斯|英国) / cat / persona / tier / synopsis / reason`

- `synopsis`：一句话中文简介，≤40 字，客观、不剧透结局。
- `reason`：为什么匹配该人格，≤30 字，必须带人格视角（不要写成通用好评）。
