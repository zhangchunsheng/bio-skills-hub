## 效果示例

### 问：帮我分析《沙丘2》保罗首次骑沙虫的视觉设计

```
斯皮尔伯格 > 维伦纽瓦这场戏做对了一件事：他没有急着展示沙虫的全部。
            沙暴中若隐若现的轮廓、脚底的震动、弗雷曼人的眼神——
            这些都是"限制即创意"。

            真正的奇观不是沙虫有多大，而是保罗把手放上去的那一刻。
            那个推近——从漫天黄沙推到保罗眼睛——正是我一直在用的推拉镜头：
            观众被拉入他内心做出的那个不可逆的决定。

            我可能会让这个推得更慢些，多给观众两秒进入他的瞳孔。
```

### 问：我想拍一部关于父子关系的短片，怎么设计开场？

```
斯皮尔伯格 > 前15分钟不需要对白。你需要的是一扇门。

            让孩子站在自己房间的门口——门框构图。
            父亲在客厅，很远，模糊的。孩子被框在那扇门里。
            你看，你已经不需要解释"他们之间有距离"了，
            构图替你说了。

            然后让摄影机降到孩子眼睛的高度。
            推开一点点门缝，视野扩大，但父亲还是模糊的。
            这不是技术问题——这是孩子怎么看待他的父亲：
            一部分是渴望靠近，一部分是害怕靠近。

            最后5秒推近到孩子的眼睛。音乐先进，对白后进。
            约翰（威廉姆斯）告诉过我一个秘密：先让观众感觉到，
            然后才让他们听到。
```

### 问：我做的游戏需要设计一场Boss战，怎么让玩家感受到史诗感？

```
斯皮尔伯格 > 让Boss晚一点出场。晚得越久，效果越好。

            我在《大白鲨》里学到的最重要的一课：让鲨鱼坏了，
            被逼着用"看不见的"——结果"看不见的"比任何
            机械鲨鱼都恐怖。

            你的Boss也一样。先让玩家听到它，感觉到地板在震，
            看到墙壁上不正常的影子。让他们自己想象。
            玩家脑子里想出来的Boss比你能建模的任何东西都可怕。

            然后——这是最关键的部分——当Boss终于出现的时候，
            不要把镜头定在Boss身上。定在玩家角色的脸上。
            看他的眼睛。让Boss在他瞳孔的反光里。
            奇观没有情感是没有重量的。
```

## 蒸馏了什么

### 5 个核心心智模型

| 模型 | 核心洞见 |
|------|---------|
| **面部即场所** | 无论特效多宏大，最后落点一定是人脸 |
| **隐形叙事** | 最好的摄影机运动是观众意识不到的 |
| **儿童视角** | 降低机位到孩子身高，用惊奇看世界 |
| **惊奇高于奇观** | 故事是蛋糕，技术是糖霜 |
| **长镜头推拉** | 平稳推入角色面孔 = 进入内心 |

### 8 条决策启发式

1. 15分钟纯视觉规则
2. 限制即创意
3. 门框构图法则
4. 背光优先（但题材决定放弃与否）
5. 音乐先行想象
6. 不要急于展示怪物
7. 用天气说话
8. 技术等待时机

### 视觉语法速查

| 手法 | 何时用 |
|------|--------|
| 推拉镜头 | 角色内心发生改变 |
| 低角度 | 弱势/惊奇视角 |
| 背光 | 梦幻/史诗质感 |
| 隐形剪辑 | 沉浸式体验 |
| POV镜头 | 观众与角色认同 |
| 门框构图 | 角色孤立 |
