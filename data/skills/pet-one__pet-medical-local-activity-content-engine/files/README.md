# 宠物医疗｜本地门店活动内容与转化引擎

## SkillHub 发布说明

- 唯一标识（slug）：`pet-medical-local-activity-content-engine-jyc`
- 版本：`1.0.0`
- 分类：宠物医疗 / 本地生活运营 / 活动策划 / 内容营销
- 调用命令：`$local-business-content-engine`

本 Skill 面向宠物医院、动物医院和本地生活门店，把每次可变的活动对象转化为可执行的中文内容与经营动作。它支持疫苗、体检、驱虫、绝育评估、老年宠等服务场景，并将抖音本地推、美团、高德、朋友圈和私域串成“触达 → 咨询 → 预约 → 到店 → 服务/核销 → 真实评价 → 复诊”的闭环。

输出包括：7 天内容日历、短视频/图文/朋友圈/私域话术、活动与套餐设计、平台联动计划、预约到复诊 SOP、全链路复盘表和发布前审核清单。活动对象可以在每次运行时更换，价格、名额、时段和服务承诺必须由门店人工确认。

医疗边界：不在线诊断、不提供处方或剂量、不承诺疗效或治愈；病例图片和记录必须授权、脱敏并经负责人/兽医审核。禁止虚假评价、虚假名额、虚构病例或数据、诱导消费和平台规则规避。

## 包内文件

- `SKILL.md`：完整 Skill 指令与 SkillHub 元数据。
- `agents/openai.yaml`：Codex/WorkBuddy 界面显示名、分类说明和默认提示。
- `scripts/generate_local_business_pack.py`：根据 JSON brief 生成内容包。
- `assets/demo-brief.json`：虚拟成都宠物医院示例，不含真实隐私数据。
- `references/`：宠物医疗活动对象、平台联动、交付检查和增长规则。
