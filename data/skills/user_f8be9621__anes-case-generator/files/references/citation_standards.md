# 病例报告参考文献标注规范

> 本规范确保病例报告初稿中所有非用户病例数据的陈述均可溯源，同时保持简洁易操作。

---

## 一、标注体系概览

### 1.1 引用类型与标识符

| 类型 | 标识符 | 含义 | 示例 |
|:---|:---|:---|:---|
| 用户文献 | `[1]`, `[2]`... | 来自用户提供的参考文献库 | `[3]` 表示用户库第3篇 |
| LLM补充文献 | `[L1]`, `[L2]`... | LLM检索补充的外源文献 | `[L2]` 表示第2篇补充文献 |
| 术语/标准 | `[T1]`, `[T2]`... | 术语库、指南、标准引用 | `[T1]` 表示CARE指南 |
| 待验证 | `[需验证]` | 无法找到匹配来源的陈述 | 需用户人工核实 |

### 1.2 标注格式

**正文标注**：使用方括号上标，置于标点符号之前

```
正确：SPS患者对吸入麻醉药敏感性增高[1]，建议采用TIVA方案[L1]。
错误：SPS患者对吸入麻醉药敏感性增高[1]，建议采用TIVA方案 [L1]。
```

## 二、分类标注规则

### 2.1 用户文献 `[n]`

**适用场景**：
- 用户提供了参考文献库（ima知识库/Excel/EndNote/PDF等）
- 从该库中检索并引用的具体文献

**编号规则**：
- 按文中出现顺序编号
- 同一文献多次引用使用同一编号

**文末列表格式**：
```
References
[1] Author A, Author B. Title of the article. Journal Name. Year;Volume(Issue):Pages.
[2] Author C. Title of the book. City: Publisher; Year.
```

### 2.2 LLM补充文献 `[Ln]`

**适用场景**：
- 用户未提供参考文献库，或库中无匹配文献
- LLM通过**实时检索**补充的文献
- LLM使用**训练数据中的高置信度医学常识**（见2.2.1）

#### 2.2.1 关于模型记忆知识（Parametric Knowledge）的使用规范

**允许使用的情况**（标注 `[Ln]`，置信度：高）：
- 基础医学常识：药物分类、作用机制、解剖结构等
- 通用临床概念：疾病定义、诊断标准、治疗原则等
- 示例："丙泊酚通过GABA_A受体发挥镇静作用[L1]"

**必须检索确认的情况**（禁止直接使用模型记忆）：
- 具体统计数据：发病率、患病率、并发症发生率等
- 具体数值：药物剂量、生理参数阈值、样本量等
- 特定研究结论：某药物的有效率、某术式的预后数据等
- 示例：❌ "SPS发病率约1/100万"（模型记忆，可能过时或不准确）→ ✅ 必须检索确认后标注 `[Ln]`

**标注要求**：
```
[L1] 内容描述（来源：模型知识/实时检索，置信度：高/中/低，检索策略：如适用）
```

**强制要求**：
1. **主动说明**：首次出现 `[Ln]` 时，必须在脚注或文末说明：
   ```
   [L1] 本引用由LLM检索补充，检索策略：PubMed检索词"Stiff Person Syndrome anesthesia"
   置信度：高（摘要明确提及）/中（仅标题相关）/低（推测相关）
   ```

2. **诚实标注**：若检索后仍无法确认，标注 `[需验证]` 而非编造

**编号规则**：
- 独立于用户文献编号
- 按文中出现顺序编号

### 2.3 术语/标准引用 `[Tn]`

**适用场景**：
- 引用术语库定义
- 引用CARE/ACRE等报告指南
- 引用医学标准或共识

**预设引用**：
| 标识符 | 引用内容 | 完整引用 |
|:---|:---|:---|
| `[T1]` | CARE指南 | Gagnier JJ, et al. The CARE Guidelines. J Clin Epidemiol. 2013;67(1). |
| `[T2]` | ACRE清单 | Shelton CL, et al. The Anaesthesia Case Report (ACRE) Checklist. Anaesthesia Reports. 2021. |
| `[T3]` | 本技能术语库 | AnesCaseGenerator内置术语库，Part A/Part B |

## 三、必须标注的陈述类型

### 3.1 必须标注（非用户病例数据）

| 陈述类型 | 示例 | 标注要求 |
|:---|:---|:---|
| 疾病流行病学 | "SPS发病率约1/100万" | `[1]` 或 `[L1]` 或 `[需验证]` |
| 病理生理机制 | "GAD65抗体导致GABA能神经元功能障碍" | `[2]` 或 `[L2]` |
| 药物作用机制 | "丙泊酚通过GABA_A受体发挥镇静作用" | `[T3]`（术语库）或 `[L3]` |
| 麻醉技术原理 | "TIVA可避免吸入药诱发的肌强直" | `[3]` 或 `[L4]` |
| 并发症发生率 | "文献报告术后并发症率约30%" | `[4]` 或 `[L5]` |
| 指南推荐 | "ACRE指南建议包含患者视角" | `[T2]` |
| 对比分析结论 | "与文献相比，本病例麻醉方案更保守" | 必须引用具体文献 `[5]` |

### 3.2 无需标注

| 陈述类型 | 示例 | 原因 |
|:---|:---|:---|
| 用户病例数据 | "患者女性，45岁，诊断为SPS" | 原始数据来源 |
| 纯描述性内容 | "患者于2024年1月入院" | 病例事实 |
| 逻辑推理 | "因此，我们选择了TIVA方案" | 基于病例的临床决策 |
| 通用医学常识 | "血压单位mmHg" | 无需引用 |

## 四、操作流程（供AI执行）

### Step 1: 识别需标注陈述

生成初稿时，逐句判断：
1. 是否为用户病例数据？→ 否，继续
2. 是否为通用常识？→ 否，继续
3. → **需要标注**

### Step 2: 选择引用来源

优先级：
1. 用户提供参考文献库 → 使用 `[n]`
2. LLM检索确认 → 使用 `[Ln]` + 主动说明
3. 术语库/指南 → 使用 `[Tn]`
4. 无法确认 → `[需验证]`

### Step 3: 文末列表生成

按类型分三部分列出：
```
References
[1] ...
[2] ...

LLM-Supplemented References
[L1] ... (检索策略：...，置信度：...)
[L2] ... (检索策略：...，置信度：...)

Terminology & Standards
[T1] Gagnier JJ, et al. The CARE Guidelines...
[T2] Shelton CL, et al. The ACRE Checklist...
```

## 五、诚实性原则

### 5.1 禁止行为

- ❌ 编造不存在的文献
- ❌ 将推测性内容标注为用户文献
- ❌ 使用模糊的"文献报道"而不给出具体引用

### 5.2 正确做法

- ✅ 无法确认时标注 `[需验证]`
- ✅ LLM补充文献主动说明检索策略和置信度
- ✅ 区分"有文献支持"和"基于病例的临床推断"

## 六、中英双语稿件的特殊处理

### 6.1 引用编号统一

英文版和中文版使用**同一套引用编号**，文末参考文献列表相同。

### 6.2 引用位置可能不同

由于中英文表达差异，同一引用在两种语言版本中的位置可能不同，但编号一致。

### 6.3 示例

```
英文版：
Stiff-person syndrome (SPS) is a rare autoimmune disorder with an incidence of approximately 1 per million [1].

中文版：
僵人综合征（Stiff-person syndrome, SPS）是一种罕见的自身免疫性疾病，发病率约1/100万[1]。

References
[1] Ciccacci F, et al. Stiff-person syndrome: a review. Front Neurol. 2023;14:1191234.
```

## 七、快速检查清单

交付前核对：
- [ ] 所有非病例数据陈述均有引用标注
- [ ] 用户文献 `[n]`、LLM补充 `[Ln]`、术语 `[Tn]` 分类正确
- [ ] LLM补充文献有检索策略和置信度说明
- [ ] 文末参考文献列表完整，编号连续
- [ ] 无 `[需验证]` 遗漏（或已明确告知用户）
- [ ] 中英文版本引用编号一致
