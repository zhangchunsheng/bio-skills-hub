# 麻醉病例报告学术写作模式库

> 基于33篇SPS麻醉病例报告系统提取

## 1. 论文结构套路

### 标准IMRaD + 麻醉特异性扩展

```
Title: [Disease] in a Patient Undergoing [Surgery]: A Case Report
       or: Anesthetic Management of [Disease] for [Surgery]: A Case Report

Abstract: Background → Case Summary → Conclusion
Introduction: Disease background (2-3 sentences) → Why anesthetic management is challenging (2-3 sentences) → What this case adds
Case Report:
  - Patient demographics + comorbidities
  - Preoperative status & medications
  - Anesthetic plan rationale
  - Induction (agents, doses, airway)
  - Maintenance (agents, infusions, monitoring)
  - Intraoperative events
  - Emergence & extubation
  - Postoperative course & outcome
Discussion:
  - Interpretation of key findings
  - Comparison with existing literature (with summary table if >5 cases)
  - Clinical implications → practice recommendations
  - Limitations
Conclusion: 2-3 actionable recommendations
```

## 2. 高频句式模板

### 2.1 病例引入

| 句式 | 使用场景 |
|:---|:---|
| "We present the case of a [age]-year-old [male/female] with [disease] who underwent [surgery]." | 标准病例引入 |
| "We describe the anesthetic management of a [age]-year-old patient with [disease] scheduled for [surgery]." | 麻醉管理焦点引入 |
| "This case report describes..." | 第三人称引入 |
| "Herein, we report a case of..." | 正式学术引入 |

### 2.2 麻醉过程描述

| 句式 | 使用场景 |
|:---|:---|
| "Anesthesia was induced with [drug] [dose] and [drug] [dose]." | 诱导描述 |
| "Tracheal intubation was performed [with/without] neuromuscular blocking agents." | 插管描述 |
| "Anesthesia was maintained with [continuous infusion/intermittent bolus] of [drug(s)]." | 维持描述 |
| "The patient remained hemodynamically stable throughout the procedure." | 术中稳定性 |
| "The intraoperative course was uneventful." | 顺利手术 |
| "No adverse events were noted during the procedure." | 无不良事件 |
| "Emergence from anesthesia was smooth and uneventful." | 苏醒顺利 |
| "The patient was extubated [in the operating room / after [time]] and transferred to PACU." | 拔管与转运 |
| "The postoperative course was uncomplicated." | 术后平稳 |

### 2.3 讨论论证逻辑

| 逻辑路径 | 句式模板 |
|:---|:---|
| 提出矛盾 | "There is conflicting evidence regarding [topic] in patients with [disease]." |
| 引证前人 | "[Author] et al. reported [finding] in a similar case." |
| 对比差异 | "In contrast to previous reports, our case demonstrates..." |
| 解释机制 | "This may be attributed to [mechanism] because [rationale]." |
| 提炼建议 | "We suggest that [recommendation]. Furthermore, [additional advice]." |
| 指出局限 | "This case report has several limitations. First, ... Second, ..." |
| 总结贡献 | "To the best of our knowledge, this is the first case report to [novel contribution]." |
| 呼吁研究 | "Further prospective studies are warranted to [research goal]." |

| 句式 |

## 3. Discussion写作路径（4种常见模式）

### 模式A：个案→汇总表→提炼建议
适用：病例+文献综述（case report and literature review）
1. 提出本病例核心发现 → 2. 汇总表对比文献中同类病例 → 3. 归纳共识/矛盾 → 4. 给出实践建议

### 模式B：个案→逐点论证→建议
适用：单一案例，聚焦1-2个麻醉决策
1. 解读本病例的关键决策点 → 2. 每个决策点引文献支持 → 3. 综合建议

### 模式C：新药/新技术→首报→机制解释
适用：首次使用某药物/技术的case report
1. 为何选择该药/技术 → 2. 文献中类似应用的空白 → 3. 机制层面解释效果 → 4. 展望

### 模式D：并发症→因果链→预防策略
适用：报告不良事件的case report
1. 描述事件 → 2. 排除其他原因 → 3. 建立因果链 → 4. 提出预防策略

### 模式E：文献数据提取表驱动的Discussion（★★★★★ 核心新增）

适用：有参考文献库 → 生成了数据提取表 → 需要专业Discussion

**步骤**：
1. **表格嵌入** → 将Step 5生成的Table 1置于Discussion第二段
2. **定性分析** → 逐维度（麻醉方式/肌松药/吸入药/拮抗策略/并发症）系统对比，每段主题句+表格数据引用
3. **定量建议** → 识别可量化变量 → 推荐统计方法 → 估算样本量 → 明确标注"方向性建议"
4. **文献定位** → 本病例在已报告文献中的独特贡献
5. **实践建议** → 3-5条表格数据支撑的可操作建议

**Discussion标准段落模板（文献增强版）**：


## 4. 术语使用原则

- 首次出现全称+缩写，后续统一用缩写
- 药物名称使用国际非专利名（INN），可选附商品名
- 麻醉深度描述避免"adequate/sufficient"，使用具体数值（BIS, MAC值）
- 术后时间使用精确描述（"postoperative day 3" > "after surgery"）
