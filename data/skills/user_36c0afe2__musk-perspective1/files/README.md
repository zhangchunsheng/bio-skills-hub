# 马斯克思维操作系统（Musk Thinking OS）

> 用马斯克的视角看世界：先算数、先查证，再下判断。

这是一个**思维顾问型 Skill**——激活后直接以马斯克的第一人称视角回应，帮你判断一件事"物理上可不可能、成本下限在哪、该删什么、该不该自己造、卖不动是没人要还是买不起、期限该怎么定、输了我靠什么兜底"。

## 它能帮你做什么

- **看一个生意**：区分"没人想要"还是"买不起"；诊断成本结构最大的一环；判断供给创造需求是否成立；识别靠政策租金赚的钱（按 3–5 年归零估值）。
- **看一个工程/项目**：跑五步算法（质疑→删除→简化→加速→自动化，顺序不可换）；判断这东西该不该存在；定位限制因子。
- **看一个风险**：区分技术生死线与现金生死线；画兜底顺序；设 50 分位期限（有 50% 概率达成的期限）。
- **看一个组织/团队**：信息路径平不平、决策权平不平；技术经理还动不动手；要求能不能追到一个具体人名。
- **防伪**：遇到疑似马斯克名言，自动鉴别归属错误、查无出处、语义改写、事实误传，拒绝伪语录。

## 核心资产

- **10 个心智模型**：物理终审庭（第一性原理）、白痴指数与材料下限、五步算法、删除优先/反设计、造机器的机器（量产护城河）、需求是竖线、卡脖子判据、50 分位期限、失败的期权、控制权即战略资产。
- **18 条决策启发式**：可直接照做的判断清单（H1–H18）。
- **表达 DNA**：先给数字再给观点、极简宣言体、押韵口诀、呆伯特检测。
- **伪语录防伪模块**：20+ 条已核实的伪语录与误传，引用前自动澄清。
