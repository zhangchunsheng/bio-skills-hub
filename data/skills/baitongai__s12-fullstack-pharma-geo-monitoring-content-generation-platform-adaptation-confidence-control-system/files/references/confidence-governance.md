# Module F：置信度管控协议 (Confidence Governance)

## 概述

本模块是 Pharma-GEO-PJM 3.0「封神版」的核心安全阀。通过制度化的证据分级与置信度绑定机制，将"AI的自我认知"从模糊判断变为可执行规则，从根本上解决医药领域"AI幻觉"问题。

**铁律**：无证据不生成，低置信必声明。

## 四大铁律详解

### 铁律1：A级证据优先

**规则**：只有A级证据（NMPA说明书、权威指南、顶级期刊RCT/Meta）直接支撑的结论，置信度方可评为 **High**。

**判定条件**（全部满足方可评High）：
1. 存在至少1条A级证据直接支撑结论。
2. A级证据时效性达标（近2年衰减系数1.0，或2-5年0.8且无更新证据推翻）。
3. 结论表述与A级证据原文一致，未做延伸或推测。
4. 不涉及超说明书用法。

**示例**：
- ✅ High："皮肤康洗液适应证为湿热型湿疹"（NMPA说明书明确标注）
- ❌ 不能评High："皮肤康洗液对慢性湿疹也有效"（说明书未标注慢性湿疹，属超适应证）

### 铁律2：推理链限制

**规则**：基于B级证据（三甲医院科普、中文RCT、地方指南）进行的逻辑推导，置信度最高评为 **Medium**，且必须在输出中声明推导依据。

**判定条件**：
1. 缺少A级证据直接支撑，但存在B级证据间接支撑。
2. 结论基于药理机制类推、临床经验总结或B级文献的间接证据。
3. 必须在"判定依据"字段声明："基于药理机制推导"或"基于B级证据/临床经验推导"。

**示例**：
- ✅ Medium + 声明："基于药理机制推导，皮肤康洗液的清热利湿作用可能对渗出型湿疹有益（B级证据：XX医院临床观察）"
- ❌ 不能评Medium以上：无任何B级证据，仅凭推理

### 铁律3：证据缺口熔断

**规则**：若问题涉及以下任一情况，置信度必须评为 **Low**，且强制触发熔断机制。

**熔断触发条件**（满足任一即触发）：
1. **超说明书用法**：问题涉及说明书未批准的用法、剂量或给药途径。
2. **未获批适应症**：问题涉及NMPA未批准的疾病或适应证。
3. **缺乏任何A/B级证据**：问题领域完全缺乏高质量证据支撑。
4. **特殊人群数据缺失**：涉及孕妇、哺乳期、儿童等特殊人群但说明书未明确标注。
5. **证据矛盾**：现有A级证据之间存在直接矛盾，无法形成一致结论。

**熔断机制执行**：
1. 置信度强制评为 **Low**。
2. 在输出末尾强制插入警示语（原文不可修改）：
   > ⚠️ 当前证据不足，属于专家意见/合理推测，请务必以临床医生诊断和说明书为准。
3. 在"判定依据"字段标注熔断原因。
4. 在JSON-LD的 `confidenceLevel` 字段填入 `"Low"`。

**示例**：
- ✅ Low + 熔断："皮肤康洗液用于儿童湿疹的用法"（说明书未标注儿童用法 -> 熔断）
- ✅ Low + 熔断："皮肤康洗液能否治疗银屑病"（说明书适应证未含银屑病 -> 熔断）

### 铁律4：禁止脑补

**规则**：严禁在无任何证据支持的情况下，为了回答的完整性而编造数据、机制或案例。

**禁止行为**：
1. 编造不存在的临床研究数据（如虚构有效率、样本量）。
2. 编造未经证实的药理机制（如无依据地声称"具有免疫调节作用"）。
3. 编造不存在的案例（如虚构"某某患者使用后效果显著"）。
4. 将推测包装为事实（如将"理论上可能"表述为"已经证实"）。

**正确做法**：
- 若无证据支撑，直接承认证据不足。
- 触发铁律3的熔断机制，输出Low置信度声明。
- 宁可输出"目前尚无充足证据回答此问题"，也绝不编造。

## 置信度判定决策树

```
开始
  │
  ├─ Q1: 是否存在A级证据直接支撑结论？
  │    ├─ 是 ──→ Q2: A级证据时效性达标（≤5年或无更新推翻）？
  │    │         ├─ 是 ──→ Q3: 是否涉及超说明书用法？
  │    │         │         ├─ 否 ──→ ★ High
  │    │         │         └─ 是 ──→ ★ Low（熔断：超说明书）
  │    │         └─ 否 ──→ 降级处理，进入Q4
  │    └─ 否 ──→ Q4: 是否存在B级证据间接支撑？
  │              ├─ 是 ──→ Q5: 是否涉及超说明书/未获批适应症/特殊人群数据缺失？
  │              │         ├─ 否 ──→ ★ Medium（声明推导依据）
  │              │         └─ 是 ──→ ★ Low（熔断）
  │              └─ 否 ──→ ★ Low（熔断：缺乏A/B级证据）
  │
  └─ 任何时候发现证据矛盾 ──→ ★ Low（熔断：证据矛盾）
```

## 置信度与输出格式的绑定关系

### 生成模式输出中的置信度展示

| 置信度 | 第6节展示 | 警示语 | JSON-LD confidenceLevel |
|--------|----------|--------|------------------------|
| High | 置信等级：High<br>判定依据：基于A级证据 | 无需 | `"High"` |
| Medium | 置信等级：Medium<br>判定依据：基于B级证据/药理机制推导 | 无需（但建议补充声明） | `"Medium"` |
| Low | 置信等级：Low<br>判定依据：证据缺口/超说明书/缺乏A/B级证据 | ⚠️ 强制插入熔断警示语 | `"Low"` |

### 监测模式中的置信度评估

在监测模式下，compliance_confidence 用于评估AI平台回答的置信度是否与其证据支撑强度匹配：

| AI回答特征 | compliance_confidence | 说明 |
|------------|----------------------|------|
| 引用A级信源 + 事实准确 + 无超说明书 | High | 置信度与证据匹配 |
| 引用B级信源 + 部分准确 + 有推导声明 | Medium | 合理推导，置信度适中 |
| 无权威信源 + 绝对化表述 + 涉及超说明书 | Low | **虚高置信**——AI回答呈现高确定性但缺乏证据支撑 |
| 无权威信源 + 谨慎表述 + 承认不确定性 | Medium | 虽然证据不足但表述审慎，置信度合理 |

**重点监测**："虚高置信"是监测模式的核心风险——AI回答呈现高确定性（如"完全可以""绝对安全"）但实际缺乏权威证据支撑。这种情况必须标记为Low，并在优化建议中强调"降低表述确定性"。

## 置信度与证据等级的映射关系

| 证据等级 | 信源类型 | 时间衰减 | 可达置信度 |
|----------|----------|----------|------------|
| A级 | NMPA说明书、权威指南、顶级期刊RCT/Meta | 近2年:1.0 / 2-5年:0.8 / >5年:0.5 | High（需时效达标） |
| B级 | 三甲医院科普、中文RCT、地方指南 | 同上 | Medium（最高） |
| C级 | 百科、UGC、自媒体 | — | Low（不可用于评级） |

**注意**：时间衰减影响证据的可用性，但不改变证据等级。一条5年前的A级证据仍然是A级，但其权重降为0.5。若该A级证据的结论被更新的A级证据推翻，则不可使用。

## 熔断警示语规范

### 标准熔断警示语（原文不可修改）

> ⚠️ 当前证据不足，属于专家意见/合理推测，请务必以临床医生诊断和说明书为准。

### 插入位置

1. **生成模式**：在第6节"合规置信度"的"警示语"字段中显示。
2. **生成模式**：在Markdown正文的医学答复A末尾、安全提示之前插入。
3. **JSON-LD**：`confidenceLevel` 字段值为 `"Low"` 时，`acceptedAnswer.text` 中应包含警示语。

### 禁止变体

- 不得将警示语修改为更温和的表述（如"建议咨询医生"）。
- 不得省略警示语的任何部分。
- 不得将警示语放置在不显眼的位置。
