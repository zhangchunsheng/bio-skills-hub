# Module A：平台感知信源筛选与加权

## 概述

根据目标AI平台的信源偏好，自动切换证据权重，确保生成的内容能被目标平台优先采信。三大平台偏好类型覆盖中国主流AI搜索引擎的不同信源采信逻辑。

## 平台偏好分类

### CN-primary（中文优先平台）

**适用平台**：元宝、豆包、文心一言、千问

**平台特性**：以中文语料为主，优先采信国内权威医学信源，对纯英文文献的采信度较低（尤其无中文摘要的PubMed文献）。

| 权重等级 | 信源类型 | 具体来源 | 说明 |
|----------|----------|----------|------|
| **A级（高权重）** | 监管批件 | NMPA批件/药品说明书 | 法律效力最高，必引 |
| **A级（高权重）** | 权威期刊 | 中华系列杂志（CNKI核心） | 中华医学杂志、中华皮肤科杂志等 |
| **A级（高权重）** | 教材规范 | 人卫出版社教材 | 《内科学》《药理学》等统编教材 |
| **A级（高权重）** | 官方规范 | 卫健委诊疗规范/临床路径 | 国家级诊疗规范文件 |
| **B级（中权重）** | 医院科普 | 三甲医院官方科普 | 华西医院、协和医院等官方科普文章 |
| **B级（中权重）** | 中文RCT | 大型RCT（中文发表） | 国内多中心随机对照试验 |
| **B级（中权重）** | 地方指南 | 省市级诊疗指南 | 地方学会发布的指南文件 |
| **低权重/过滤** | 纯英文文献 | PubMed（纯英文无中文摘要） | 采信度低，建议补充中文摘要 |
| **低权重/过滤** | 百科类 | 百度百科、搜狗百科 | UGC内容，可信度低 |
| **低权重/过滤** | 用户生成 | 知乎、小红书等UGC | 非权威信源，仅做语义参考 |

### EN-primary（英文优先平台）

**适用平台**：DeepSeek、学术搜索引擎

**平台特性**：以英文语料为主，优先采信国际权威医学信源，对中文企业PR稿和非核心期刊采信度低。

| 权重等级 | 信源类型 | 具体来源 | 说明 |
|----------|----------|----------|------|
| **A级（高权重）** | 国际文献 | PubMed（RCT/Meta） | 随机对照试验与Meta分析 |
| **A级（高权重）** | 系统评价 | Cochrane系统评价 | 循证医学金标准 |
| **A级（高权重）** | 监管批件 | FDA/EMA Label | 国际监管机构批准的说明书 |
| **A级（高权重）** | 国际顶刊 | NEJM、Lancet、JAMA、BMJ | 四大医学顶刊 |
| **B级（中权重）** | 国际指南 | ESC/ADA/NCCN等国际指南 | 国际学会诊疗指南 |
| **B级（中权重）** | 英文综述 | 高质量综述文章 | 系统性文献综述 |
| **低权重/过滤** | 中文PR稿 | 中文企业新闻稿 | 采信度低，可能被视为商业宣传 |
| **低权重/过滤** | 非核心期刊 | 中文非核心期刊 | 影响力低，证据质量不确定 |

### Mixed（跨平台投放）

**适用平台**：需同时覆盖CN-primary和EN-primary平台的场景

**平台特性**：中英文信源并重，以NMPA说明书为法律兜底，确保内容在两类平台均能被采信。

| 权重等级 | 信源类型 | 具体来源 | 说明 |
|----------|----------|----------|------|
| **A级（高权重）** | 中英并列 | 中英文顶级指南并列 | 如中国指南 + 对应国际指南 |
| **A级（高权重）** | 法律兜底 | NMPA说明书 | 以中国监管批件为法律底线 |
| **B级（中权重）** | 双语文献 | 双语发表的文献 | 中英文对照的研究文献 |
| **B级（中权重）** | 跨国试验 | 跨国多中心试验数据 | 国际多中心RCT的中国亚组数据 |
| **低权重/过滤** | 自媒体 | 医药自媒体内容 | 非权威信源 |
| **低权重/过滤** | 无源数据 | 未标注来源的数据 | 不可追溯，不可采信 |

## 信源筛选执行规则

1. **强制A级信源**：每份生成内容必须至少引用1条A级信源，否则标注"证据缺口-平台不匹配"。
2. **信源数量**：建议A级2-3条，B级1-2条，低权重信源不引用。
3. **信源标注格式**：`[来源名称] - [具体文献/文件名] - [年份]`
4. **跨平台适配**：若用户未指定平台偏好，默认使用CN-primary（因中文AI平台覆盖最广）。
5. **信源冲突处理**：若中英文信源结论冲突，以NMPA说明书为最终裁决标准。

## 平台偏好快速判定

| 用户指定 | 平台偏好 | 说明 |
|----------|----------|------|
| 元宝 / 豆包 / 文心 / 千问 | CN-primary | 中文优先 |
| DeepSeek / 学术搜索 | EN-primary | 英文优先 |
| 全平台 / 跨平台 / 不确定 | Mixed | 跨平台适配 |
| 未指定 | CN-primary | 默认中文优先 |
