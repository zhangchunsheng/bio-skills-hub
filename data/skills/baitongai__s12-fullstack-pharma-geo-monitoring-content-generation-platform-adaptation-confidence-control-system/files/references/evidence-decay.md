# Module B：动态证据与时效性衰减

## 概述

所有证据必须经过时间衰减加权，确保GEO内容不会因引用过期研究而降低AI采信度。本模块定义衰减系数计算规则与证据缺口声明标准。

## 时间衰减系数

| 发表时间 | 衰减系数 | 权重说明 | 适用场景 |
|----------|----------|----------|----------|
| 近2年（当年及前1年） | 1.0 | 满权重 | 优先引用，代表最新研究进展 |
| 2-5年 | 0.8 | 高权重 | 可引用，需注意是否有更新版本 |
| 5年以上 | 0.5 | 低权重 | 谨慎引用，仅作为历史背景或缺乏新证据时使用 |
| 10年以上 | 0.3 | 极低权重 | 不建议引用，除非为经典奠基性研究 |

### 衰减系数应用规则

1. **计算基准年**：以当前年份为基准计算文献年龄。
2. **多版本取新**：若同一指南/共识有多个版本，取最新版本，旧版本不再引用。
3. **加权展示**：在证据列表中标注"权重:X.X | 年份:YYYY"格式。
4. **A级优先**：即使A级证据年份较旧（5年以上），其权重仍高于B级新证据——衰减系数应用于信源等级内部排序，不改变信源等级本身。

### 衰减系数示例

```
案例：2026年生成内容，引用以下3条证据

1. NMPA药品说明书（2024年修订版）→ 2年内 → 衰减系数 1.0 → A级 满权重
2. 中华皮肤科杂志 RCT（2022年）→ 2-5年 → 衰减系数 0.8 → A级 高权重
3. 国内多中心观察性研究（2018年）→ 5年以上 → 衰减系数 0.5 → B级 低权重

输出标注：
• A级证据（权重:1.0｜年份:2024）NMPA药品说明书：[结论]
• A级证据（权重:0.8｜年份:2022）中华皮肤科杂志RCT：[结论]
• B级证据（权重:0.5｜年份:2018）多中心观察性研究：[结论]
```

## 证据缺口声明

### 触发条件

当以下任一情况出现时，必须输出证据缺口声明：

1. **平台不匹配缺口**：目标平台偏好下缺失A级证据。
   - 示例：CN-primary平台，但仅有PubMed英文A级证据，无中文A级证据。
   - 声明格式：`证据缺口-平台不匹配：目标平台[CN-primary]偏好中文A级信源，当前仅有[英文A级信源]，建议补充[本地化共识/中文RCT]。`

2. **时效性缺口**：所有A级证据均在5年以上。
   - 声明格式：`证据缺口-时效性不足：当前A级证据均为[X]年前发表，建议关注[最新研究进展/即将发布的指南更新]。`

3. **人群缺口**：缺乏特定人群（孕妇/儿童/老年）的安全性数据。
   - 声明格式：`证据缺口-特殊人群：缺乏[孕妇/儿童/老年]人群的安全性数据，建议标注"该人群安全性数据不足，请咨询专科医生"。`

4. **对比缺口**：缺乏与指定竞品的头对头研究。
   - 声明格式：`证据缺口-竞品对比：缺乏与[竞品名]的头对头研究数据，竞品差异化说明基于各自独立研究的间接比较，需谨慎解读。`

### 证据缺口严重度分级

| 严重度 | 定义 | 处理方式 |
|--------|------|----------|
| 严重 | A级证据完全缺失 | 强制标注缺口声明，建议暂缓发布或补充证据 |
| 中等 | A级证据存在但不匹配平台偏好 | 标注缺口声明，建议补充本地化内容 |
| 轻微 | B级或C级证据有缺口 | 标注缺口声明，不影响发布 |

## 证据新鲜度评估

在GEO优化字段中输出"证据新鲜度"标签：

- **高**：全部A级证据均在2年内（衰减系数>=0.8的A级证据占主体）
- **中**：A级证据在2-5年内（存在衰减系数0.8的A级证据）
- **低**：A级证据在5年以上或存在严重缺口
