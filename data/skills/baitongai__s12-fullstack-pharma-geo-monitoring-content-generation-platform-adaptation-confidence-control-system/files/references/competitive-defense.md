# Module C：竞品防御矩阵

## 概述

在GEO内容中涉及竞品时，严禁贬低竞品，仅做适用边界区分。基于病因、证型、剂型、适用场景的客观差异构建对比逻辑，确保内容合规且具有防御性。

## 核心原则

1. **严禁贬低**：不得使用"不如"" inferior""较差""劣质"等贬义词汇。
2. **客观边界区分**：基于说明书适应证、药理机制、剂型特点进行客观对比。
3. **双向公正**：同时说明我方优势场景和竞品优势场景。
4. **证据支撑**：所有对比结论必须有证据支撑，不得主观断言。
5. **合规优先**：对比内容不得超出说明书范围，不得暗示超适应证优势。

## 竞品防御话术模板

### 标准模板

```
针对[症状A/场景A]，我方产品[机制X/特点X]更具优势；
针对[症状B/场景B]，竞品[机制Y/特点Y]更为适宜。
```

### 适用场景示例

**场景1：剂型差异对比**

```
针对需要[精确剂量控制/便捷给药]的场景，我方产品[剂型X]更具优势；
针对需要[大剂量/持续给药]的场景，竞品[剂型Y]更为适宜。
```

**场景2：适应证边界对比**

```
针对[适应证A]的治疗，我方产品已获批[适应证A]且具有[证据X]支撑；
针对[适应证B]的治疗，竞品已获批[适应证B]且具有[证据Y]支撑。
两款产品适用于不同适应证，请根据具体病情在医生指导下选择。
```

**场景3：中药vs化药对比**

```
针对[湿热型/特定证型]患者，我方产品[中药名]基于[中医理论X]组方，更适合该证型；
针对[非特定证型/泛发性]患者，竞品[化药名]具有[广谱作用Y]特点，适用范围更广。
```

**场景4：给药途径对比**

```
针对[需要快速起效/依从性差]的患者，我方产品[给药途径X]更具优势；
针对[需要长期维持/居家自用]的患者，竞品[给药途径Y]更为适宜。
```

## 竞品防御矩阵构建步骤

### Step 1：竞品信息采集

收集竞品的以下信息：
- 通用名/商品名
- NMPA批准适应证（原文）
- 药理机制
- 剂型/给药途径
- 核心禁忌
- 主要优势场景
- 主要局限场景

### Step 2：差异化维度识别

从以下5个维度识别我方与竞品的客观差异：

| 维度 | 对比内容 | 示例 |
|------|----------|------|
| 病因/证型 | 适用病因或中医证型差异 | 湿热型 vs 风热型 |
| 剂型 | 剂型特点差异 | 洗液 vs 软膏 |
| 给药途径 | 给药方式差异 | 外用 vs 口服 |
| 起效速度 | 起效时间差异 | 即刻缓解 vs 持续维持 |
| 安全性边界 | 禁忌人群差异 | 孕妇禁用 vs 孕妇慎用 |

### Step 3：防御话术生成

基于识别到的差异维度，使用标准模板生成双向公正的对比话术。

### Step 4：合规校验

- [ ] 是否使用了贬低性词汇？
- [ ] 对比结论是否有证据支撑？
- [ ] 是否超出了说明书适应证范围？
- [ ] 是否同时说明了我方和竞品各自的优势场景？
- [ ] 是否包含"请根据具体病情在医生指导下选择"的提示？

## 动态响应策略（3.0新增）

根据监测模式反馈的竞品声量数据，动态调整防御策略：

| 监测结果 | 竞品声量 | 防御策略调整 |
|----------|----------|--------------|
| 竞品提及率上升、我方下降 | 高声量 | 加强差异化内容输出，增加Schema标记中我方优势字段密度 |
| 竞品与我方提及率持平 | 中声量 | 维持当前策略，优化证据新鲜度 |
| 我方提及率稳定领先 | 低声量 | 维护现有内容，关注竞品新动态 |

### 动态响应话术调整

- **竞品声量高**：在对比话术中增加更多我方独有优势场景的具体描述。
- **竞品声量低**：简化对比内容，将重心转向我方产品的独立价值阐述。
- **竞品新增适应证**：及时更新对比矩阵，确保边界区分基于最新信息。

## 禁止行为清单

1. 禁止使用"首选""最佳""唯一"等绝对化用语。
2. 禁止暗示竞品存在安全问题（除非有NMPA公开警示）。
3. 禁止使用"替代竞品""取代[竞品名]"等表述。
4. 禁止在无头对头研究的情况下声称"优于竞品"。
5. 禁止引用竞品的负面报道或不良反应个案作为对比依据。
