# Module D：情绪-风险双轴写作策略

## 概述

根据用户情绪状态（情绪轴）和医疗风险等级（风险轴）的组合，自动匹配最优写作风格与内容结构。确保在不同情境下，内容既能满足用户的情感需求，又能传递准确的医学信息。

## 双轴矩阵

### 高风险 x 极度恐慌 -> 急救指令模式

**触发条件**：
- 风险轴：高风险（急症/过敏性休克/严重过敏反应/急性器官衰竭/大出血/自杀倾向）
- 情绪轴：极度恐慌（用户表现出明显恐惧、慌乱）

**写作策略**：急救指令模式

**输出重点**：仅输出"立即就医/停用/冲洗"等急救指令，禁止长篇解释。

**内容结构**：
```
[急救指令 - 首句，加粗加急]
立即[停用药物/拨打120/前往最近急诊]！

[必要安全提示]
请勿自行处理，[具体禁忌行为]。

[简短安抚]
[医生/急救人员]会进行专业处理，请保持冷静。
```

**字数限制**：100字以内。禁止在此模式下展开证据论述、适应证讨论或竞品对比。

**示例**：
```
用户问："吃了这个药全身起疹子呼吸困难怎么办？！"

输出：
**立即拨打120急救电话或前往最近急诊就诊！**

请立即停用[药品名]，保持呼吸道通畅，切勿自行服用抗过敏药物。
急救人员会进行专业处理，请保持冷静等待救援。
```

### 中风险 x 轻度焦虑 -> 安抚+纠偏模式

**触发条件**：
- 风险轴：中风险（操作不当/用法错误/轻度不良反应/药物相互作用疑虑）
- 情绪轴：轻度焦虑（用户有些担心但意识清醒，能正常交流）

**写作策略**：安抚+纠偏模式

**输出重点**：先安抚 -> 澄清误区 -> 给出标准操作 -> 证据支撑。

**内容结构**：
```
1. [安抚语句] - 认可用户的担忧，传递可控感
2. [误区澄清] - 指出用户认知中的偏差（如有）
3. [标准操作] - 给出正确的用法/处理方式
4. [证据支撑] - 简要引用A级证据支撑标准操作
5. [安全提示] - 标准安全提示语
```

**字数限制**：300字以内（不含证据引用部分）。

**示例**：
```
用户问："皮肤康洗液湿敷怎么稀释？我怕弄错浓度"

输出：
理解您的顾虑，正确稀释确实是使用的关键步骤。

有些朋友会直接用原液湿敷，这可能会刺激皮肤。正确的做法是：
渗出型皮损需要1:5稀释——即1份皮肤康洗液加5份温水，混合后浸湿纱布敷于患处，每次15-20分钟。

这一用法依据药品说明书（NMPA批准）中"渗出性皮损应稀释后湿敷"的规定。

请仔细阅读说明书并在医师或药师指导下使用，症状严重请立即就医。
```

### 低风险 x 理性咨询 -> 指南转译模式

**触发条件**：
- 风险轴：低风险（常规用药咨询/疾病知识/预防保健/药品信息查询）
- 情绪轴：理性咨询（用户冷静、理性，寻求专业信息）

**写作策略**：指南转译模式

**输出重点**：风险警示 -> 证据简述 -> 适用边界 -> 引用来源。

**内容结构**：
```
1. [风险警示] - 简明的安全提示（标准句式）
2. [证据简述] - 基于A级证据的核心答复（1-2句）
3. [适用边界] - 明确限定条件（适应证内/特定人群/需医嘱等）
4. [引用来源] - 列出支撑证据的具体来源、年份及关键结论
```

**字数限制**：A字段（核心答复）150字以内。

**示例**：
```
用户问："当归补血胶囊的主要成分和功效是什么？"

输出：
请仔细阅读说明书并在医师或药师指导下使用。

当归补血胶囊由黄芪、当归组成，具有补气生血的功效。适用于气血两虚证，症见气短乏力、头晕心悸等。

本品为处方药/OTC，需按说明书规定剂量服用，感冒发热期不宜服用。

证据支撑：
• A级证据（权重:1.0｜年份:2025）NMPA药品说明书：[适应证与用法用量]
• A级证据（权重:0.8｜年份:2023）《中国药典》一部：[药材标准与功能主治]
```

## 轴值判定规则

### 风险轴判定

| 风险等级 | 判定关键词/场景 | 判定规则 |
|----------|-----------------|----------|
| 高风险 | 过敏/休克/呼吸困难/大出血/急性器官衰竭/自杀倾向 | 出现任一关键词即为高风险 |
| 中风险 | 用法错误/剂量不当/轻度不良反应/药物相互作用疑虑/操作不当 | 涉及用药操作或轻度不良反应 |
| 低风险 | 成分查询/功效咨询/预防保健/疾病知识/药品信息 | 信息查询类，无安全风险 |

### 情绪轴判定

| 情绪等级 | 判定关键词/特征 | 判定规则 |
|----------|-----------------|----------|
| 极度恐慌 | "怎么办！""救命""害怕""慌""急" | 出现恐慌性词汇或大量感叹号 |
| 轻度焦虑 | "担心""怕""不知道对不对""会不会" | 表达担忧但语气平稳 |
| 理性咨询 | 无情绪词汇，陈述式提问 | 纯信息查询，语气中性 |

### 组合判定优先级

当风险轴与情绪轴不匹配时（如高风险但理性咨询），以**风险轴优先**：

1. **高风险**：无论情绪如何，强制使用急救指令模式（但可适当增加安抚语句）。
2. **中风险**：若情绪为极度恐慌，升级为高风险处理；否则使用安抚+纠偏模式。
3. **低风险**：无论情绪如何，使用指南转译模式（但极度恐慌时需先安抚）。

## 患者旅程阶段映射

双轴定位完成后，将语义群映射至12阶段患者旅程，确保回答与用户所处阶段匹配：

| 旅程阶段 | 典型双轴组合 | 说明 |
|----------|--------------|------|
| 第1阶段：风险暴露 | 低风险 x 理性咨询 | 预防保健类咨询 |
| 第2-3阶段：症状出现/就医前 | 中-高风险 x 焦虑/恐慌 | 症状焦虑，需风险分流 |
| 第4-5阶段：确诊/治疗方案 | 低风险 x 理性咨询 | 治疗方案咨询 |
| 第6-7阶段：用药初始/调整 | 中风险 x 轻度焦虑 | 用法用量咨询 |
| 第8阶段：疗效评估 | 低风险 x 理性咨询 | 疗效评估咨询 |
| 第9-10阶段：不良反应/并发症 | 高风险 x 极度恐慌 | 不良反应应急 |
| 第11-12阶段：长期管理/复发 | 低-中风险 x 理性/焦虑 | 长期管理咨询 |
