# 静脉用药的配伍禁忌与联用注意事项

## 目标与适用范围

为单个静脉用药生成可用于静脉用药调配中心医嘱审核、临床用药咨询或合理用药点评的配伍禁忌与联用注意事项清单。

适用于以下请求：

- 查询某注射剂的推荐、慎用和禁用溶媒。
- 查询某注射剂能否与其他药物同袋、Y 型管或同通路给药。
- 梳理某抗肿瘤药、抗感染药或其他静脉药物的联合用药风险和监测要求。
- 编写静配中心审核要点、输注顺序和管路冲洗规则。

不将药代动力学无相互作用、血浆蛋白结合试验结果、同日给药或同方案使用，错误外推为同袋或同通路物理兼容。

## 证据原则

按以下顺序检索、交叉核验并在每条结论后标注依据：

1. 本院实际使用制剂的最新版核准药品说明书。
2. 《中华人民共和国药典》及药典相关标准资料。
3. 权威药学专著，例如《临床用药须知》《注射药物配伍变化》及公认的注射剂相容性工具书。
4. 核心期刊药学文献、稳定性研究或权威肿瘤药物专论。
5. 海外监管机构处方信息或原研药厂医学信息，可用于交叉核验，但不得替代在用国产制剂的核准说明书。

优先检索制剂名称、厂家、规格、辅料、复溶步骤、稀释液、最终浓度、输注时间、稳定性、给药器械和配伍禁忌。涉及具体调配操作时，明确要求使用者以本院在用批次的最新版说明书和静配中心 SOP 最终放行。

## 工作流

### 1. 界定问题与制剂

1. 确认通用名、剂型、给药途径和临床用途。
2. 优先确认本院使用的厂家、商品名、规格和辅料；未知时，明确以代表性制剂说明书作初步判断，不能泛化至所有厂家。
3. 明确用户需要的是溶媒选择、同袋配伍、Y 型管同步输注、序贯给药、治疗性联用，还是全部内容。
4. 在结果开头固定声明：

> “可同日或同方案联用”不等于“可在同一输液袋配伍”或“可经同一通路同时输注”。

### 2. 核验溶媒和调配条件

从说明书提取并分类：

- 复溶用溶媒：是否允许注射用水、葡萄糖溶液或其他溶媒；复溶浓度和复溶体积。
- 最终稀释用溶媒：允许的输液种类、体积、终浓度、输注时间、避光和贮存期限。
- 明确禁用溶媒：含氯离子、盐溶液、碱性或酸性溶液，以及其他已知不相容介质。
- 证据不足溶媒：说明书或权威稳定性资料未证实者，列为“不作为常规选择”，不称为“慎用后可用”。

对每个溶媒项目写明“复溶”或“最终稀释”的具体阶段，避免混淆。

### 3. 核验药物物理配伍和输注线路

逐项区分下列四种结论，不得混用：

| 分类 | 判定标准 | 输出用语 |
|---|---|---|
| 同袋兼容 | 有说明书或高质量稳定性证据支持混入同一输液袋 | 可同袋配伍 |
| 条件性 Y 型管兼容 | 明确允许独立袋、特定溶媒和限定位置的同步输注 | 可经 Y 型管同步输注，但不得混袋 |
| 仅可序贯或同方案联用 | 可共同治疗，但无物理同步输注依据，或说明书规定先后顺序 | 可方案联用；须序贯输注/冲管 |
| 不相容或禁用 | 说明书明确禁忌，或有可靠物理化学不相容依据 | 不得混袋；不得同线同步给药 |

核对以下细节：

1. 是否规定两药使用独立输液袋。
2. 是否规定 Y 型管位置、特定稀释液或特殊辅料限制。
3. 是否规定先后输注顺序和冲管溶媒。
4. 是否明确禁止与碱性药物、特定辅料或其他药物混合。
5. 是否存在器械限制，例如含铝部件、特定滤器、PVC 或避光要求。

药物仅有“无药代动力学相互作用”或“体外不影响蛋白结合”的资料时，标注为“不能据此推定输液配伍相容”，不列入可配伍药物。

### 4. 评估治疗性联用风险

将治疗性联用与物理配伍分开成表。按说明书和权威资料筛查：

- 重叠毒性：骨髓抑制、肾毒性、肝毒性、神经毒性、耳毒性、心脏毒性、胃肠道毒性、黏膜炎和出血。
- 心电风险：QT 间期延长、尖端扭转型室性心动过速和电解质异常。
- 清除与暴露：肾毒性药物、酶抑制/诱导剂、转运体相关影响。
- 抗凝或抗血小板治疗：PT/INR、出血征象与监测频率。
- 特定方案：给药顺序、剂量调整原则、疗程前实验室监测和症状监测。

写清“避免合用”“谨慎合用并监测”或“可方案联用但需监测”的临床处置，并避免无依据地罗列整个药物类别。

### 5. 形成可执行交付物

按以下固定顺序输出：

1. **适用范围与关键边界**：注明制剂来源、说明书版本或核验限制。
2. **溶媒配伍分级表**：推荐、证据不足/不作为常规选择、严禁；列明阶段、操作与来源。
3. **其他药物物理配伍分级表**：同袋兼容、条件性 Y 型管、仅序贯/方案联用、不相容；明确是否可混袋、是否可同线、冲管与顺序。
4. **联合用药注意事项表**：联用场景、风险、监测和处理建议、来源。
5. **静配中心审核要点**：用 4-6 条写出可直接用于审核的规则。
6. **参考依据**：按证据优先级列出处方信息章节、药典/专著章节或文献题录；链接只能作为定位辅助，不替代来源名称和章节。

使用“严禁”仅限说明书或高等级证据明确禁止的情形；使用“证据不足”而非含糊的“慎用”，除非说明书确有慎用表述或可执行的风险控制方案。

## 质量控制清单

交付前逐项检查：

- 是否明确了具体制剂和说明书版本，或说明了制剂差异限制。
- 是否把复溶溶媒与最终稀释溶媒分开。
- 是否把同袋、Y 型管、同线序贯和同方案联用分开。
- 是否对所有“可配伍”结论给出直接物理相容性依据。
- 是否写明冲管溶媒、给药顺序、器械或辅料限制。
- 是否让每个关键结论都可追溯到证据来源和章节。
- 是否避免把低等级证据包装为说明书级结论。

## 风险边界

不依据单篇低质量文献、药品聚合网站的摘要或推测性机制，直接改变静配中心标准操作。对说明书不一致、具体辅料未知、存在高危输注风险或需要跨机构执行的情形，提示药师复核在用制剂说明书、院内相容性数据库和 SOP，必要时向药品生产企业医学信息部门核实。
