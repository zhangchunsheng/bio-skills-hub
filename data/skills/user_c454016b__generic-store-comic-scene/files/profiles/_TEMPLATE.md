# 品牌档案模板 · `<brand-slug>.md`

> 用法：复制本文件为 `<brand-slug>.md`（如 `hanabi.md`），逐项填写。
> 铁律：**未填的字段不得进入 prompt**；字段缺失时先向用户索要，不要自行编造。
> 档案更新后请顺带检查 `SKILL.md` 的 prompt 模板占位符是否仍能覆盖你的字段。

## 2. 主角色参考图（→ 优先占 image1）

| 项 | 值 |
|----|-----|
| 参考图绝对路径 | `C:/path/to/your/brand/<character-ref>.png` |
| 角色身份 | `{{导购 / 顾问 / 店员 ...}}` |
| 角色外貌规格 | `{{年龄、性别、发型、着装，用于核验}}` |
| **非对称特征** | `{{哪一侧、什么颜色、什么材质。例：仅单侧佩戴某配饰 / 仅单侧长袖 / 单侧徽章}}` |
| 方位确认方式 | `{{填前必须放大基准图目视确认是哪一侧，把结论写在这里}}` |
| 非对称特征 prompt 片段 | 填好后贴在这里，供直接复制：<br>`EXACTLY ONE {{feature}} on the hand on the viewer's {{LEFT|RIGHT}} side of her body only...` |

> ⚠️ **方位填写铁律**：
> 1. 必须**放大基准图目视确认**——纯像素统计会被深色裤装、发色干扰，不可靠。
> 2. 用**观众视角**描述（`the hand on the viewer's LEFT/RIGHT side of her body`），不用裸的 `her left hand`——后者在"人物自身左右"与"观众左右"之间存在歧义。
> 3. 🚫 **禁止**用「与参考图同一只手 / the same hand as in the reference image」类抽象表述替代方位描述——实测导致**双手漂移**（见 `references/ERROR-LOG.md` 错误 8）。

> ⚠️ 有非对称特征的角色**永远只作 image1**。对手方角色的参考图（若有）**不得**占用 image1 槽位——会让主角色失去锚定，直接引发非对称特征漂移。

## 4. 对手方角色形象规格（有参考图则双重约束，无则仅文字）

```
{{脸型}}，{{表情基调}}，{{发型 — 长度/卷直/颜色}} with NO bangs, NO ponytail,
NO bun, NO hairclip；{{上装 — 材质/领型/袖型}}；{{下装}}；{{鞋}}；
{{包 — 颜色/款式/拎在哪只手}}；{{配饰 — 耳饰/手链等，注明在哪一侧}}。
```

**禁止发型变化负面项**：`NO bangs, NO ponytail, NO bun, NO hairclip`（按实际规格调整）

> 发型与头部是最易出现"看着像另一个人"的区域。只写"要什么"不够，**必须同时写"不要什么"**。
> 对手方角色**不占 image1**——该槽位留给有非对称特征的角色。这是实测权衡结论：非对称特征最难约束，优先锚定它。
