# generic-store-comic-scene · 技能包说明

## 这是什么

线下零售门店「**员工 + 顾客**」同框漫画场景生成技能。用于服务标准分镜、业务讲解、培训漫画、新人手册插图等。**不限品牌、不限零售品类**。

品牌专属资产（角色参考图路径、锁定场景背景、品类材质规则、角色形象规格）全部外置在 `profiles/`，技能主体只承载方法论。

---

## 独立性声明

本技能包**完全自包含**：

| 项 | 状态 |
|----|------|
| 引用其他技能的文件 | ❌ 无 |
| 依赖其他技能的路径 | ❌ 无 |
| 与其他技能同名文件 | ❌ 无 |
| 可单独复制/迁移 | ✅ 整个目录拿走即可用 |

与其他任何技能（含品牌专属技能）**互不可见、各自独立演进**——不共享文件，也不引用其路径。

## 目录结构

```
generic-store-comic-scene/
├── SKILL.md                      # 主文档：四条机制 + 约束模板 + 工作流 + 检查清单
├── GETTING-STARTED.md            # 初次使用指引（面向使用者）
├── README.md                     # 本文件
├── references/
│   └── ERROR-LOG.md              # 10 类错误记录与防错手册 + 6 步提炼元方法
├── profiles/
│   └── _TEMPLATE.md              # 品牌档案空白模板（7 组字段 + 填写指南）
└── scripts/
    ├── watermark.py              # 清除 ImageGen 右下角水印（v2：羽化 + 可调参数）
```

> 技能包内**不预置任何具体品牌的档案**——目标品牌档案由使用者按 `_TEMPLATE.md` 建立。
> 品牌专属资产（角色参考图、锁定背景图、材质规则）一律存放在各品牌自己的位置，本技能只登记路径。

## 快速开始

> 📖 **第一次使用？** 请先看 [`GETTING-STARTED.md`](GETTING-STARTED.md) —— 含「零素材跑通第一张图」的完整示例、品牌档案建法、常见问题。
> 以下流程面向模型与开发者。

### 1. 确认品牌档案

```bash
ls profiles/            # 没有目标品牌档案 → 见下方分支
```

- **有档案** → 直接加载，按其内容组装 prompt。
- **没有档案（首次使用 / 新品牌）** → 走「**零素材模式**」：用纯文字约束生成，并告知用户人物形象会变化。**不要自行编造参考图路径**。若用户要求形象固定，引导其按 `_TEMPLATE.md` 建档案（见 `GETTING-STARTED.md` 第三节）。

### 2. 按槽位规则分配输入图

| 场景 | image1 | image2 | image3 |
|------|--------|--------|--------|
| 单角色 | 主角色参考图 | 锁定背景图 | — |
| 双角色 | 有非对称特征者 | 第二角色 | 锁定背景图 |

### 3. 组装 prompt

顺序固定：`风格 → 背景强制复用 → 主角色（含非对称锁定）→ 对手方角色 → 品类材质锁定 → 通用负面约束`

### 4. 生成后核验

读图核验 → 清除水印 → 重命名 → （若改 HTML）跑 div 校验。

详见 `SKILL.md` 的 Pre-generation checklist。

## 依赖

| 项 | 说明 |
|----|------|
| 图片生成 | ImageGen 工具（调用消耗额度） |
| `watermark.py` | 需 **Pillow + numpy**，使用本机已装这两个依赖的 Python 解释器 |
| `check_html_divs.py` | 纯标准库，任何 Python 均可 |

> ⚠️ 若报 `ModuleNotFoundError`，说明当前解释器缺少依赖，换一个解释器或先安装依赖即可。
