# 初次使用指引 · 门店漫画场景生成器

> 面向第一次使用本技能的人。目标：**5 分钟内产出第一张门店漫画场景图**。
> 你不需要提前准备任何素材——先跑通一张，再决定要不要精细化。

---

## 一、它做什么

| | 说明 |
|---|---|
| **你给什么** | 一段场景描述（谁、在哪、做什么）+ 可选的角色 / 门店参考图 |
| **它给什么** | 一张「员工 + 顾客」同框的线下门店漫画分镜图（16:9 或 9:16） |
| **用在哪** | 服务标准分镜、业务讲解图、培训漫画、新人手册插图 |

不限品牌、不限零售品类。服装店、美妆店、餐饮店、珠宝店都可以用。

---

## 二、先跑通一张（零素材）

**第一次使用不需要任何参考图或配置文件。** 直接把下面这段交给 AI，把中文部分换成你的场景即可：

```
用门店漫画场景技能生成一张 16:9 的图：

【场景】一家服装店，明亮整洁，原木色货架、米白色墙面、暖色射灯。
【员工】年轻女性店员，米色针织开衫、白色内搭、深色长裤，
        扎低马尾，左胸一枚小工牌。
【顾客】年轻女性顾客，浅色风衣、长裤、单肩包，自然微笑。
【动作】店员在货架旁向顾客展示一件上衣，顾客侧身倾听；
        两人全身可见，店员在画面左、顾客在画面右。
【商品】画面中只出现本店的服装，不要出现其他品牌的 Logo 或文字。
【画风】扁平 2D 漫画风，干净柔和，黑色描边，赛璐璐上色，明亮暖光。
```

**如果画面里有"只在一侧"的元素**（例如只在一只手上戴手套、只背单肩包），
必须额外说明是哪一侧，例如：

```
她只在【画面左侧】的那只手上戴手套，另一只手完全裸露。
```

> ⚠️ 这是本技能最高频的翻车点。原因与解法见第五节。

## 三、想让形象每次都一致？建立品牌档案

零素材模式每次生成的人物长相会**随机变化**。如果你需要固定形象（例如连锁门店统一物料），就得建立「品牌档案」。

### 3.1 档案是什么

`profiles/` 目录下每个 `.md` 文件 = 一个品牌档案，记录该品牌的角色参考图、门店背景图、商品材质规则。技能在生成前会读取对应档案。

### 3.2 怎么建

1. 复制 `profiles/_TEMPLATE.md`，改名为你的品牌（例如 `acme.md`）
2. 按模板填 7 组字段
3. 生图时说明「用 acme 品牌的档案」

### 3.3 最少要填什么

7 组字段里，**前 3 组是核心**，其余可以留空后补：

| 优先级 | 字段 | 没有会怎样 |
|--------|------|-----------|
| ★★★ | 角色参考图路径 | 人物长相每次随机 |
| ★★★ | 门店背景图路径 + 场景映射 | 每次生成的门店不一样 |
| ★★★ | 商品品类 / 材质规则 | 画面里混入不想展示的商品 |
| ★★ | 角色形象规格 | 细节（发型、配饰）不稳定 |
| ★ | 命名规范、归档目录 | 产物管理混乱 |

> **参考图从哪来**：用 AI 先生成一张满意的角色全身图和一张门店环境图，存到本地，再把路径填进档案即可。参考图不需要很精美，关键是**每次都用同一张**。

## 四、三个决定成败的约束

这三条是本技能的核心经验，直接决定了图能不能用。

### 1. 单侧特征必须锁死（最高频问题）

模型会把「只有一侧」的元素**对称化**——你要求左手戴手套，它给你双手都戴上。

**有效写法**（三个要素缺一不可）：
- **计数词**：明确「恰好一只」
- **视角侧位置**：「在画面左侧的那只手上」，不要只写「左手」（会被理解成人物自身的左手，产生歧义）
- **三重否定**：「另一只手不戴、两只手都不戴、没有第二只」

### 2. 背景必须绑定参考图

只写「一家门店」→ 模型会自由发挥，每次都是不同的店。

有门店参考图时，必须在提示里写「**背景必须完全使用参考图里的门店环境**」，并说明「不要另创一家店」。

### 3. 商品品类要写死

模型默认会画混合商品。要写清「**只展示 X 类商品，不要出现 Y、Z**」，**允许项和禁止项都要写**，只写允许项不够。

## 五、常见问题

**Q：人物每次长得都不一样？**
没用参考图。见第三节——建立品牌档案并填入角色参考图。

**Q：要求单侧特征，结果两侧都有？**
看第四节第 1 条，检查三点：「恰好一个」计数词、视角侧位置描述、三重否定。

**Q：背景不是我指定的门店？**
有参考图时加一句「背景必须完全使用参考图的门店环境，不要另创一家店」。

**Q：画面里出现了不该有的商品？**
补上品类锁定的**禁止项**（例如「不要出现银饰、钻石、彩色宝石」）。

**Q：图右下角有水印？**
用技能自带的 `scripts/watermark.py` 清除（需 Pillow + numpy）。水印若落在花纹密集处可能留下轻微痕迹，可调整脚本参数。

**Q：同框两个角色的配饰串了？**
两人的约束方向相反时（一方戴、一方禁戴），需要在各自段落**明确限定对象**，并加上双向的互斥声明。详见 `references/ERROR-LOG.md` 错误 10。

## 六、进阶

- **多角色同框**（员工 + 店长 + 顾客）：图像槽位有限，谁占哪个槽位有讲究，见 `SKILL.md` 的槽位分配规则。
- **改图而不是重生成**：用户说「只改 X、其他不变」时，重生成往往会改动构图。改用局部修补更稳。
- **完整错误库**：`references/ERROR-LOG.md` 收录 10 类失败模式，每次生成前建议对照一遍。
- **建档案**：`profiles/_TEMPLATE.md` 是空白模板，含 7 组字段的填写说明。
