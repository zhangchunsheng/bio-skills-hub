# 渠道合规熔断机制与话术转换规则（代理商MSL专属）

## 一、渠道合规熔断机制

### 1.1 熔断触发条件

当生成拜访脚本或输出内容时，若出现以下任一情况，**立即停止生成并输出《合规警示》**：

| 序号 | 熔断触发条件 | 严重等级 | 处置流程 |
|------|------------|---------|---------|
| M1 | 涉及任何商业数字（价格、返点、销量目标、市场份额、进货量） | P0-致命 | 立即熔断→删除相关内容→重新生成合规版本→上报厂家合规部 |
| M2 | 涉及未经厂家医学部审核的临床数据或专家观点 | P0-致命 | 立即熔断→标注"未经审核"→删除→仅使用厂家审核数据 |
| M3 | 涉及对竞品的任何主观负面评价 | P1-高危 | 立即熔断→替换为客观公开数据或删除→标注引用来源 |
| M4 | 医生提出超出基层处理能力的复杂病例，且未启动"厂家专家会诊"流程 | P1-高危 | 立即熔断→启动转诊流程→记录并上报厂家MSL→等待专家反馈 |
| M5 | 暗示或承诺医院进院结果、医保报销比例 | P0-致命 | 立即熔断→删除承诺→替换为"以医院正式通知为准" |
| M6 | 拜访脚本中出现任何形式的礼品、宴请、娱乐活动暗示 | P0-致命 | 立即熔断→删除全部相关内容→上报厂家合规部 |

### 1.2 合规警示输出格式

当熔断触发时，输出以下格式：

```
【合规警示·第M[X]号】
触发条件：[具体描述]
严重等级：[P0-致命 / P1-高危]
已执行操作：[删除/替换/上报]
建议处理：[具体建议]
上报要求：[是否需要上报厂家合规部]
```

### 1.3 合规铁律详解

#### 铁律1：严禁触碰商业贿赂

**绝对禁止**的行为清单：
- 谈论回扣、返点、销量返利、阶梯奖励
- 赠送任何形式的礼品（含看似无害的纪念品、日历、笔）
- 以"学术会议"为名行旅游/宴请之实
- 承诺为医生个人提供任何形式的利益

**合规替代**：所有拜访目的必须表述为"学术支持""医学信息分享""工具赋能"，聚焦患者获益。

#### 铁律2：严禁越权承诺

**不得承诺的事项**：
- 医院进院时间表或结果
- 医保报销比例或覆盖范围
- 患者使用人数或处方量预期
- 产品供应优先级（除非厂家正式授权）

**合规替代**：
- 进院问题："以医院正式采购通知为准，我可以帮您了解所需资质材料"
- 医保问题："以当地医保局正式公告为准，我这里有厂家发布的政策解读供参考"
- 使用量问题："我们关注的是规范使用，让合适的患者用上合适的产品"

#### 铁律3：严禁独立医学解释

**边界判定**：
- 可回答：标准化拜访脚本覆盖的内容（适应症、用法用量、禁忌症、常见不良反应）
- 不可回答：超适应症使用、特殊人群（孕妇/儿童）安全性、严重不良事件处理、与其他药物相互作用
- 处置：明确告知医生"这个问题需要厂家医学部专家给您准确答复，我记录下来马上上报"

#### 铁律4：身份明示义务

**标准明示话术**（每次沟通开场必用）：
> "[医生姓氏]主任/医生您好，我是创尔生物的授权渠道医学专员[你的姓名]，这是我的授权证（出示）。今天主要是来进行合规的学术信息分享，顺便看看咱们科在创面修复方面有没有需要我们支持的学术资源。"

#### 铁律5：数据来源唯一

**允许使用的数据来源**：
- 厂家医学部审核发布的《渠道合规话术库》
- 厂家提供的PMID编号文献数据
- 厂家提供的产品注册证、集采中选通知书
- 厂家提供的RWE（真实世界证据）数据（需标注"经厂家医学部审核"）

**严禁使用的数据来源**：
- 自行搜索的网络文献（如百度学术、知乎回答）
- 竞品资料或竞品官网信息
- 未经验证的临床经验分享
- 行业自媒体或非权威来源的数据

## 二、去商业化话术转换表

### 2.1 核心话术转换规则

| 错误表述（商业导向） | 合规表述（医学/患者导向） | 设计意图 | 合规依据 |
|---|---|---|---|
| "主任，这个月任务差一点，多开点吧。" | "主任，最近天气干燥，糖尿病足高发，我们备了适量的胶原敷料，万一有急症患者可以避免断货。" | 从"压货"转为"患者保障" | RDPAC第3.2条 |
| "我们这个比XX牌子效果好。" | "根据发表在《中华烧伤杂志》的头对头研究（PMID XXXX），重组胶原在促进肉芽生长方面有显著优势。" | 从"主观贬低"转为"客观循证" | RDPAC第5.1条 |
| "用了这个，患者好得快，您有业绩。" | "规范使用胶原能缩短患者住院日，降低科室平均住院费用，符合DRG控费导向。" | 从"个人利益"转为"科室/政策获益" | RDPAC第3.1条 |
| "主任，您开得多，我们可以申请学术会议赞助。" | "如果您科室有学术需求，我可以向厂家申请学术会议支持，流程是提交申请、厂家审核后统一安排。" | 从"利益交换"转为"合规流程" | RDPAC第7.1条 |
| "这个产品进医保了，报销比例高，好卖。" | "重组胶原已纳入医保目录，患者自付比例下降，可及性提升。具体报销比例以当地医保局公告为准。" | 从"好卖"转为"患者可及性" | RDPAC第4.2条 |
| "集采中标了，价格便宜了，您放心用。" | "集采中选产品经过质量一致性评价，供应有保障。这是中选通知书和质量评价报告。" | 从"价格便宜"转为"质量保障" | NMPA器械管理 |

### 2.2 去商业化三原则

1. **主语转换**：将"我们/我/厂家"替换为"患者/医生/科室"
   - 错误："我们的产品效果好"
   - 合规："患者使用后创面愈合加快"

2. **动词转换**：将"卖/推销/任务"替换为"分享/支持/赋能"
   - 错误："今天来推销新产品"
   - 合规："今天来分享规范的创面修复方案"

3. **结果导向转换**：将"销量/市场份额/利润"替换为"患者获益/住院日缩短/医疗成本降低"
   - 错误："用了能提高科室耗材使用量"
   - 合规："规范使用能缩短患者住院日，降低平均住院费用"

## 三、厂家-渠道协同SOP

### 3.1 信息传递SOP

```
厂家医学部
  ↓ 发布《渠道合规话术库》《标准化拜访脚本》
代理商MSL
  ↓ 逐字传递，不增减不修改
基层医生
  ↓ 反馈与疑问
代理商MSL
  ↓ 记录并上报（24h内）
厂家医学部
  ↓ 专家解答
代理商MSL
  ↓ 准确传达（48h内回访）
基层医生
```

### 3.2 问题上报SOP

| 问题类型 | 上报时限 | 上报路径 | 反馈时限 |
|---------|---------|---------|---------|
| 医学疑问（用法用量/特殊人群） | 24h内 | 代理商MSL→厂家MSL→医学部专家 | 48h内反馈 |
| 不良事件 | 2h内 | 代理商MSL→厂家医学部+药物警戒部 | 立即响应 |
| 合规风险（医生暗示回扣等） | 12h内 | 代理商MSL→厂家合规部 | 按合规流程处理 |
| 资源申请（学术会议/专家会诊） | 3个工作日 | 代理商MSL→厂家渠道管理部 | 5个工作日内审批 |

### 3.3 资源申请SOP

代理商MSL可向厂家申请的资源类型：
- **学术会议支持**：科室会/院级学术活动（需提前3周申请，提交会议方案）
- **专家会诊支持**：复杂病例的上级医院专家远程会诊或现场会诊
- **学术工具补发**：《红旗征速查卡》《过敏筛查问诊表》等标准化工具的补充
- **培训认证**：基层医生的胶原规范使用培训（由厂家医学部统一组织）

**注意**：代理商MSL不得擅自承诺任何资源，所有资源申请须经厂家审批后方可告知基层医生。

### 3.4 合规监督SOP

代理商MSL有义务监督以下合规风险：
- 基层医生是否将胶原用于非适应症场景（如化妆品级用途）
- 是否存在"代开处方"或"引导患者到指定药店购买"的行为
- 是否有科室将胶原使用与医生绩效直接挂钩

发现上述风险时：
1. 记录详细情况（时间、科室、行为描述，不含个人身份信息）
2. 12小时内上报厂家合规部
3. 在下次拜访时以"学术纠正"方式引导（如分享适应症规范的微课PPT）
4. 不得直接指责医生，以"提供最新指南信息"的方式委婉纠正

## 四、渠道合规话术库索引

代理商MSL仅可使用厂家医学部审核发布的话术库内容。本技能内置的话术均为框架性指引，具体医学数据（如PMID编号、过敏率数值）以厂家最新发布版本为准。

| 话术场景 | 话术库编号 | 关键内容 | 更新频率 |
|---------|----------|---------|---------|
| 慢性创面胶原应用 | DS-CW-01 | 糖尿病足/压力性损伤的胶原敷料使用规范 | 每年更新 |
| 瘢痕防治胶原应用 | DS-SC-01 | 术后瘢痕预防的胶原植入材料使用规范 | 每年更新 |
| 过敏筛查与预防 | DS-AL-01 | 基层胶原过敏筛查问诊流程 | 每年更新 |
| 集采政策解读 | DS-PC-01 | 集采中选产品质量一致性评价解读 | 每批次更新 |
| DRG合规申报 | DS-DR-01 | 胶原类耗材DRG特例单议申报模板 | 每年更新 |
| 不良事件处理 | DS-AE-01 | 不良事件识别、记录、上报标准流程 | 每年更新 |
