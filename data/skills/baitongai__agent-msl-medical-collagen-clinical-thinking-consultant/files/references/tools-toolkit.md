# 代理商MSL专属工具包（内置）

## 工具1：《基层胶原应用5分钟微课PPT》（标准化）

### 概述
7张标准化幻灯片，用于基层科室查房或午休时间的5-10分钟"微学术"分享。必须使用厂家标准化版本，不得自行修改内容。

### 幻灯片清单

| 序号 | 标题 | 核心内容 | 合规要点 |
|------|------|---------|---------|
| 1 | 封面 | 厂家LOGO + 授权专员姓名 + 合规声明（"本内容由创尔生物医学部审核，仅用于合规学术分享"） | 必须包含合规声明 |
| 2 | 慢性创面的危害与负担 | 慢性创面发病率、住院日延长风险、医疗成本负担（数据来源：卫健委公开数据） | 数据须标注来源 |
| 3 | 胶原修复的机制 | 胶原促进肉芽生长、上皮化的简单易懂图示（避免过于专业的分子机制） | 图示化为主，文字精简 |
| 4 | 重组胶原的优势 | 低致敏性（过敏率数据，PMID编号）、促进愈合（愈合率数据） | 数据须标注PMID编号 |
| 5 | 《过敏筛查速查卡》使用演示 | 3步筛查流程的图示化演示（问诊→观察→首次使用后观察） | 演示操作方法，不只展示 |
| 6 | 《双向转诊联络单》填写指南 | 转诊指征清单 + 填写流程 + 上级医院信息（脱敏） | 专家信息须脱敏 |
| 7 | 合规声明与厂家联系方式 | 合规声明 + 厂家医学部联系方式 + 不良事件上报电话 | 必须包含合规声明和联系方式 |

### 使用规范
- **使用前**：确认使用的是厂家最新版本（每年更新一次）
- **使用中**：明示"厂家授权学术分享"，演示时聚焦操作方法
- **使用后**：留下电子版（U盘或微信传输），鼓励医生反复学习
- **严禁**：自行修改PPT内容、添加竞品对比、添加商业数据

## 工具2：《不良事件处理SOP（渠道版）》

### 概述
5步标准处理流程，用于基层使用胶原类材料后出现疑似不良事件时的合规处理。

### 处理流程

```
步骤1：立即停药，安抚患者
  ↓
步骤2：详细记录，拍照留存
  ↓
步骤3：专员2小时内上报厂家医学部
  ↓
步骤4：配合厂家医学部调查处理
  ↓
步骤5：定期随访患者预后
```

### 各步骤详细操作

#### 步骤1：立即停药，安抚患者
- **动作**：立即停止使用胶原类材料，更换为生理盐水纱布等基础处理
- **话术**（对医生）："主任，先停用胶原，我来记录情况并上报厂家医学部，专家会尽快给出处理建议。"
- **话术**（对患者，由医生执行）："您先别担心，我们换了基础处理方案，同时联系了厂家专家帮您看看。"
- **注意**：代理商MSL不直接与患者沟通，仅协助医生

#### 步骤2：详细记录，拍照留存
- **记录模板**：

```
不良事件记录表（渠道版）
报告编号：[日期]-[序号]
报告人：[专员姓名]
报告时间：[日期时间]

患者信息（脱敏）：
- 年龄段：[如：60-70岁]
- 性别：[男/女]
- 基础疾病：[如：糖尿病]
- 过敏史：[有/无，详情]

产品信息：
- 产品名称（通用名）：[如：重组人源化胶原蛋白敷料]
- 批号：[批号]
- 生产日期：[日期]
- 使用日期：[日期]

不良事件详情：
- 发生时间：[日期时间]
- 使用后多久出现：[如：使用后30分钟]
- 症状描述：[如：局部红肿、皮疹、瘙痒]
- 严重程度：[轻度/中度/重度]
- 已采取措施：[如：停用、抗过敏治疗]

照片：[ ] 已拍照留存（局部症状 + 全身状况）
```

- **拍照规范**：拍摄局部症状（红肿/皮疹部位）+ 全身状况，不含患者面部

#### 步骤3：专员2小时内上报厂家医学部
- **上报路径**：代理商MSL → 厂家医学部 + 药物警戒部
- **上报方式**：电话（紧急）+ 邮件/系统（正式记录）
- **上报内容**：步骤2的完整记录表 + 照片
- **注意**：严禁瞒报、迟报（超过2小时视为违规）

#### 步骤4：配合厂家医学部调查处理
- **角色**：代理商MSL是"现场信息提供者"，不是"处理决策者"
- **配合事项**：提供现场记录、协助厂家专家与基层医生沟通、跟踪处理方案执行
- **严禁**：擅自向医生或患者承诺赔偿方案、擅自发布事件结论

#### 步骤5：定期随访患者预后
- **随访频率**：事件发生后第3天、第7天、第14天
- **随访内容**：症状是否缓解、创面是否恢复、是否需要进一步处理
- **随访记录**：纳入《不良事件跟踪记录表》，上报厂家医学部
- **注意**：随访由基层医生执行，代理商MSL负责记录和上报

### 代理商MSL在不良事件中的角色边界

| 可以做 | 不可以做 |
|--------|--------|
| 协助医生记录事件详情 | 擅自决定处理方案 |
| 2小时内上报厂家医学部 | 向患者承诺赔偿 |
| 提供厂家不良事件SOP | 直接与患者沟通病情 |
| 协助厂家专家与医生沟通 | 擅自发布事件结论 |
| 定期跟踪并记录预后 | 瞒报、迟报、修改记录 |

## 工具4：《基层胶原过敏筛查速查卡》

### 概述
3步筛查流程的塑幅卡片，用于基层医生快速排除高风险过敏患者。

### 筛查流程

```
步骤1：问诊过敏史
  ↓ 有胶原/动物蛋白过敏史 → 禁用，转诊
  ↓ 无过敏史 → 进入步骤2

步骤2：肉眼观察皮肤状态
  ↓ 有活动性湿疹/皮炎/皮肤感染 → 暂缓使用，先治疗皮肤问题
  ↓ 皮肤正常 → 进入步骤3

步骤3：首次使用后30分钟内观察
  ↓ 出现红肿/皮疹/瘙痒/呼吸困难 → 立即停用，启动不良事件SOP
  ↓ 无异常 → 可继续使用，按标准方案换药
```

### 合规声明（卡片底部）
> "本速查卡可排除95%以上的高风险患者，首次使用后仍需观察。不构成绝对安全保证。最终判断请结合临床实际情况。"

## 工具5：《双向转诊联络单》

### 概述
用于基层与上级医院之间的转诊协调表单。

### 联络单内容

```
双向转诊联络单
编号：[日期]-[序号]

【基层医院信息】
医院名称：______
科室：______
联系人：______（脱敏，仅标注职称）
联系电话：______

【患者信息（脱敏）】
年龄段：______
性别：______
基础疾病：______
创面/病变描述：______（面积、深度、病程）

【转诊指征】
□ 感染创面（脓性分泌物/红肿热痛/白细胞升高）
□ 过敏体质（有胶原过敏史/首次使用后出现皮疹）
□ 复杂创面（面积≥5%TBSA/深度达真皮深层/病程≥4周无愈合）
□ 功能部位创面（面部/手部/关节）
□ 基础疾病未控制（血糖≥11.1mmol/L/免疫功能低下）

【上级医院信息】
医院名称：______
科室：______
会诊时间：______
联系方式：______（由代理商MSL填写）

【转诊类型】
□ 远程会诊
□ 上转治疗
□ 回转康复

【备注】
______
```

### 使用规范
- 填写时脱敏处理，不含患者全名和身份证号
- 上级医院专家信息由代理商MSL填写（厂家提供）
- 转诊结果不做承诺，仅提供"协助联系"服务
- 联络单留存一份在基层科室，一份由代理商MSL带回备案

## 工具6：《产品合规资质文件夹》

### 概述
用于展示产品合规资质的文件夹，展示后收回，不留存医院。

### 文件夹内容

| 序号 | 文件名称 | 用途 | 来源 |
|------|---------|------|------|
| 1 | NMPA医疗器械注册证复印件 | 证明产品合法上市 | 厂家提供 |
| 2 | 集采中选通知书 | 证明产品纳入集采 | 国家/省级医保局公示 |
| 3 | 质量一致性评价报告 | 证明集采产品质量 | 国家药监局公示 |
| 4 | 厂家《合规使用声明》 | 声明产品合规使用范围 | 厂家医学部 |
| 5 | RWE数据摘要 | 真实世界有效性证据 | 厂家医学部审核 |

### 使用规范
- **展示时**：聚焦"合规保障"，不谈价格
- **展示后**：全部收回，不留存医院
- **更新频率**：随厂家/政策更新及时更换
- **严禁**：自行添加非厂家审核的文件
