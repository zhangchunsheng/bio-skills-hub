# 基层资源适配模型（代理商MSL专属）

## 核心理念

基层医疗机构面临资源受限的客观现实：缺乏专科检测能力、MDT机制不完善、学术培训覆盖不足、合规意识薄弱。代理商MSL不能简单照搬三甲医院的学术推广模式，必须根据基层资源缺口，提供"够得着、用得上、学得会"的适配工具。

---

## 一、四种基层资源缺口与适配策略

### 缺口1：无病理科/检测难

| 维度 | 内容 |
|------|------|
| **公允研究洞察** | 基层医生因无法筛查过敏而拒绝使用胶原，表现为保守偏倚 |
| **代理商MSL合规解码策略** | 提供最简筛查路径：仅需问诊+肉眼观察，替代复杂检测。强调重组胶原的低致敏性。 |
| **输出工具** | 《基层胶原过敏筛查速查卡》 |
| **工具内容** | 3步筛查流程：①问诊过敏史（药物/食物/胶原蛋白类）→ ②肉眼观察皮肤状态（有无湿疹/皮炎）→ ③首次使用后30分钟内观察反应 |
| **合规要点** | 不得承诺"绝对不过敏"，必须标注"筛查可排除95%以上高风险患者，首次使用后仍需观察" |
| **数据引用** | 重组人源化胶原过敏率（以厂家最新PMID数据为准） |

### 缺口2：MDT缺位

| 维度 | 内容 |
|------|------|
| **公允研究洞察** | 复杂创面无法多学科会诊，延误转诊，表现为系统结构性偏倚 |
| **代理商MSL合规解码策略** | 建立绿色通道：提供厂家合作的上级医院专家联系方式，协助远程会诊或转诊 |
| **输出工具** | 《双向转诊联络单》 |
| **工具内容** | 联络单包含：①转诊指征清单（5项红旗征阈值）→ ②上级医院专家信息（脱敏：仅标注科室+职称+会诊时间）→ ③转诊流程图（基层→上级→回流）→ ④回转条件清单 |
| **合规要点** | 不得承诺转诊结果，仅提供"协助联系"服务；专家信息须脱敏，不含个人联系方式 |
| **数据引用** | 5项红旗征阈值（感染创面/过敏体质/复杂创面/功能部位/基础疾病未控制） |

### 缺口3：合规顾虑重

| 维度 | 内容 |
|------|------|
| **公允研究洞察** | 防御性处方，不敢用新产品，表现为政策耦合偏倚 |
| **代理商MSL合规解码策略** | 提供合规背书：出示产品的权威认证（NMPA注册证）、集采中选证明、RWE数据 |
| **输出工具** | 《产品合规资质文件夹》 |
| **工具内容** | 文件夹包含：①NMPA医疗器械注册证复印件 → ②集采中选通知书 → ③质量一致性评价报告 → ④厂家《合规使用声明》→ ⑤RWE数据摘要（经厂家医学部审核） |
| **合规要点** | 资质文件仅用于"展示背书"，不得留存在医院（涉及商业信息）；展示时聚焦"合规保障"，不谈价格 |
| **数据引用** | 集采质量一致性评价数据（以国家医保局公示为准） |

### 缺口4：学术氛围弱

| 维度 | 内容 |
|------|------|
| **公允研究洞察** | 对胶原认知停留在"传统敷料"阶段，表现为系统结构性偏倚 |
| **代理商MSL合规解码策略** | 微讲座赋能：利用查房或午休时间，进行5-10分钟的"微学术"分享（标准化PPT） |
| **输出工具** | 《基层胶原应用5分钟微课PPT》 |
| **工具内容** | 7张标准化幻灯片：①封面（合规声明）→ ②慢性创面危害与负担 → ③胶原修复机制（图示）→ ④重组胶原优势 → ⑤过敏筛查演示 → ⑥转诊流程指南 → ⑦合规声明与联系方式 |
| **合规要点** | PPT须使用厂家标准化版本，不得自行修改内容；分享时须明示"厂家授权学术分享" |
| **数据引用** | 慢性创面发病率（卫健委数据）、重组胶原临床数据（PMID编号） |

## 二、工具调用规则

### 2.1 匹配逻辑

```
Step2探需 → 识别痛点 → 匹配资源缺口 → 调用对应工具 → Step3传递
```

| Step2识别的痛点关键词 | 匹配的资源缺口 | 调用工具 | 调用时机 |
|---------------------|-------------|---------|---------|
| "过敏""不敢用""怕出事" | 缺口1：无病理科/检测难 | 《过敏筛查速查卡》 | Step3[工具赋能] |
| "没人会诊""转不了""只能等着" | 缺口2：MDT缺位 | 《双向转诊联络单》 | Step3[资源链接] |
| "不敢用新的""飞检""合规" | 缺口3：合规顾虑重 | 《产品合规资质文件夹》 | Step3[政策合规] |
| "没听过""不会用""传统敷料就行" | 缺口4：学术氛围弱 | 《5分钟微课PPT》 | Step3[工具赋能]或单独安排 |
| "DRG超支""科室亏钱""控费" | 缺口3+政策耦合偏倚 | 《DRG合规申报模板》 | Step3[政策合规] |

### 2.2 多工具组合策略

当基层同时面临多个资源缺口时（常见于县域医院），按以下优先级组合：

1. **第一优先**：《过敏筛查速查卡》— 消除使用顾虑是先决条件
2. **第二优先**：《双向转诊联络单》— 建立安全网，增强信心
3. **第三优先**：《5分钟微课PPT》— 系统性提升认知
4. **第四优先**：《产品合规资质文件夹》— 合规背书，消除政策顾虑

### 2.3 工具交付方式

| 工具 | 交付方式 | 注意事项 |
|------|---------|---------|
| 《过敏筛查速查卡》 | 塑幅卡片，当面演示使用方法 | 演示后留存在科室，供多医生使用 |
| 《双向转诊联络单》 | 纸质表单+电子版二维码 | 填写时脱敏处理，不留存患者信息 |
| 《产品合规资质文件夹》 | 展示后收回，不留存医院 | 展示时聚焦"合规保障"，不谈价格 |
| 《5分钟微课PPT》 | 电子版（U盘/微信传输）+ 纸质版 | 使用厂家标准化版本，不修改内容 |
| 《DRG合规申报模板》 | 纸质模板+电子版 | 标注"仅供参考，以医院DRG管理部门要求为准" |

## 三、基层医生认知偏倚与适配策略

### 3.1 保守偏倚（不敢用）

**特征**：即使符合适应症也拒绝使用胶原，对不良反应过度担忧

**适配策略**：
- 提供量化的安全性数据（过敏率、不良反应发生率）
- 展示同级别医院的成功案例（县域案例，非三甲案例）
- 提供《不良事件处理SOP》，建立安全网
- 以"先试用1-2例"的方式降低心理门槛

**话术示例**：
> "主任，理解您的顾虑。这个过敏筛查速查卡可以帮您排除95%以上的高风险患者。要不咱们先从一例明确的慢性创面患者开始试用？我会全程跟踪，有任何问题第一时间帮您对接厂家专家。"

### 3.2 系统结构性偏倚（不会用）

**特征**：因缺乏相关知识，无法识别适应症，或使用方法不规范

**适配策略**：
- 以5分钟微课PPT进行系统化科普
- 提供操作流程图（傻瓜式指引）
- 约定查房时现场演示
- 推荐厂家线上培训认证课程

**话术示例**：
> "主任，胶原的使用其实不复杂。这份流程图把每一步都写清楚了：什么样的创面选什么剂型、换药频率怎么定、什么时候该转诊。您先用着，有问题随时找我。"

### 3.3 确认偏倚（不愿改）

**特征**：坚持使用传统敷料，即使效果不佳也不愿尝试胶原

**适配策略**：
- 用数据对比（传统敷料vs胶原的愈合率差异）
- 用同级别医院案例引发"同行压力"（正面表述）
- 强调卫生经济学价值（缩短住院日=降低总成本）
- 以"患者获益"为切入口，而非"技术先进性"

**话术示例**：
> "主任，传统换药当然有效，但对于4周不愈合的慢性创面，加用胶原敷料可以把愈合率从10%提升到[厂家数据]。隔壁县医院李主任之前也是用传统方法，后来试了胶原，现在反馈很好。关键是患者少受罪、早出院。"

### 3.4 政策耦合偏倚（不敢用新的）

**特征**：因DRG控费、飞检压力，对新耗材使用过度谨慎

**适配策略**：
- 提供DRG特例单议申报模板
- 展示集采中选产品的质量一致性评价数据
- 强调"规范使用"而非"多用"
- 提供《产品合规资质文件夹》作为合规背书

**话术示例**：
> "主任，DRG确实有压力，但复杂创面可以走特例单议。这是申报模板，按这个流程操作，合理使用是可以获得偿付的。而且从整体看，缩短住院日反而能帮科室控费。集采产品的质量评价报告我也带了，您看看。"
