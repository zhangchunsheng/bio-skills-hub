# 渠道合规输出模板（代理商MSL专属）

## 模板1：访前情报简报（渠道版）

```markdown
# 访前简报：[医生姓名]（[医院名称][科室]）

## 核心画像
- **身份**：[医院层级] [科室] [职称]，[资源状况描述]，存在"[偏倚类型]"的认知偏倚。
- **痛点**：[核心临床痛点描述，如：糖尿病足患者住院时间长，缺乏有效的活性敷料和上级专家支持。]
- **沟通策略**：**[策略类型]**。[策略描述，如：赋能为主。提供《红旗征速查卡》和《过敏筛查问诊表》，消除使用顾虑。]
- **合规红线**：[本次拜访的合规注意点，如：严禁谈论进货量，聚焦患者治疗需求。]

## 关键弹药（厂家提供）
- **工具**：[匹配的工具清单，如：《基层胶原应用5分钟微课PPT》、《双向转诊联络单》]
- **数据**：[厂家审核的关键数据，如：重组胶原过敏率0.4%（PMID XXXX）]
- **资质**：[合规背书文件，如：集采中选通知书、NMPA注册证复印件]

## 假设清单（VL1待确认）
1. [假设1：如——主任主要顾虑是过敏风险和操作复杂性。]
2. [假设2：如——主任需要明确的转诊路径来处理复杂创面。]
3. [假设3：如——主任对DRG控费有压力，需要卫生经济学证据。]

## 拜访计划
- **预计时长**：5-7分钟
- **核心步骤**：Step1明示→Step2探需→Step3传递（工具+资源+政策）→Step4印证→Step5异议处理→Step6收尾
- **工具交付**：[交付工具清单及方式]
- **下次拜访主题预设**：[如：案例复盘 / 微课PPT分享 / DRG申报模板指导]
```

## 模板2：合规拜访脚本（渠道版）

```markdown
# 拜访脚本：[医生姓名]（[医院名称][科室]）

## Step1 身份明示与破冰（30s）

> "[医生姓氏]主任/医生您好，我是创尔生物的授权渠道医学专员[你的姓名]，这是我的授权证（出示）。今天主要是来进行合规的学术信息分享，顺便看看咱们科在创面修复方面有没有需要我们支持的学术资源。"

**[合规检查]**
- [x] 主动明示厂家授权身份
- [x] 出示授权证明
- [x] 声明"合规学术信息分享"

---

## Step2 探需（60s）

> "主任，最近咱们科[疾病类型]的患者多吗？在处理这类[疾病/创面]时，您觉得最大的挑战是什么？是[痛点A]，还是[痛点B]，或者是[痛点C]？"

**[探需记录]**
- 医生反馈的核心痛点：______
- 判断的认知偏倚类型：______
- 匹配的资源缺口：______
- 匹配的工具：______

---

## Step3 传递（3min）

### [工具赋能]
> "[回应医生痛点]。我们为基层医生准备了这份[工具名称]，[工具价值描述]。[关键数据引用（PMID编号/指南版本/政策文号）]。"

### [资源链接]
> "如果遇到超出咱们处理能力的[情况描述]，我们有合作的上级医院专家团队，可以通过这张[工具名称]快速启动远程会诊或转诊，不耽误患者病情。"

### [政策合规]
> "另外，[政策相关描述，如：咱们省刚把重组胶原纳入集采，咱们医院也是中选单位]。这是中选通知书，质量和供应都有保障，符合DRG控费要求。"

**[合规检查]**
- [x] 数据来源标注完整（PMID/指南/政策文号）
- [x] 仅使用厂家审核数据
- [x] 工具当面演示使用方法
- [x] 无商业词汇（价格/销量/返点）

---

## Step4 印证（30s）

> "这是[地区]县医院[医生姓氏]主任的一个病例，一位[年龄]岁的[疾病]患者，用传统敷料[时长]没长好，后来按这个筛查流程用了胶原，[时长]就上皮化了。[医生姓氏]主任反馈说[工具名称]特别实用。"

**[合规检查]**
- [x] 使用厂家审核案例
- [x] 医院和医生信息脱敏
- [x] 包含量化指标
- [x] 案例层级与目标医生匹配

---

## Step5 异议处理（LASS模型）

**L（倾听）**："[复述医生异议]"
**A（认可）**："[认可医生顾虑的合理性]"
**S（方案）**："[提供合规解决方案，引用工具/SOP/数据]"
**S（安全网）**："[承诺后续跟进与上报机制]"

**[异常处理记录]**
- 是否有超出标准脚本的问题：[是/否]
- 如是，是否启动上报流程：[是/否]
- 承诺反馈时限：[24h/48h]

**[合规检查]**
- [x] 未擅自回答超出授权范围的医学问题
- [x] 对无法回答的问题承诺上报
- [x] 无绝对化承诺

---

## Step6 收尾（30s）

> "主任，今天我们分享了[核心主题]和[工具名称]。我先把这套《基层胶原应用工具包》（含[工具清单]）留给您。下周[具体时间]我再来拜访，看看有没有合适的病例我们可以一起讨论，或者需要我协调上级专家会诊的？"

**[合规检查]**
- [x] 总结核心，无商业话题
- [x] 工具当面交接
- [x] 约定下次学术主题
- [x] 开放提问通道
```

## 模板3：访后CRM记录（渠道版）

```markdown
# 访后记录：[医生姓名]（[日期]）

## 沟通核心
- [一句话总结本次拜访的核心内容]
- [传递了哪些工具，重点解决了什么问题]
- [建立了哪些机制/通道]
- [明确了哪些合规依据]

## 医生反馈
- **积极反馈**：[医生认可的内容，如：认可筛查工具的简便性，愿意在有合适患者时试用。]
- **中性反馈**：[医生持观望态度的内容，如：对转诊通道表示欢迎，但希望先看到实际效果。]
- **消极反馈/异议**：[医生提出的顾虑或拒绝点，如：对DRG控费仍有顾虑，担心特例单议流程太复杂。]
- **商业话题**：[是否提及商业话题，如：未提及任何商业利益相关问题。]

## 合规自检
- [x] 主动明示了厂家授权身份
- [x] 未提及任何销量、返点、库存压力等商业词汇
- [x] 所有医学数据均来自厂家提供的PMID文献
- [x] 对无法回答的问题，承诺上报厂家医学部
- [x] 提供了标准化的学术工具包
- [x] 未出现绝对化承诺
- [x] 未涉及竞品主观评价
- [x] 案例引用为厂家审核案例，信息已脱敏

## 待上报事项
| 序号 | 事项类型 | 具体内容 | 上报时限 | 状态 |
|------|---------|---------|---------|------|
| 1 | [医学疑问/不良事件/合规风险/资源申请] | [具体描述] | [24h/48h/12h] | [待上报/已上报/已反馈] |

## 下一步行动
- [ ] 专员：[行动描述，如：每周跟进工具包使用情况，收集反馈]
- [ ] 专员：[行动描述，如：如遇复杂病例，立即启动《双向转诊联络单》流程]
- [ ] 专员：[行动描述，如：每月向厂家医学部汇报基层应用情况和合规风险]
- [ ] 厂家MSL：[行动描述，如：解答医生提出的[具体问题]，48h内反馈]

## 合规风险评估
- **本次拜访合规风险等级**：[低/中/高]
- **风险描述**（如有）：[具体描述]
- **已采取的规避措施**：[具体措施]
- **是否需要上报厂家合规部**：[是/否]
```

## 模板4：合规培训简报（渠道版）

适用于代理商MSL入职培训或定期合规复训时使用。

```markdown
# 渠道合规培训简报

## 培训基本信息
- **培训日期**：[日期]
- **参训人员**：[专员姓名列表]
- **培训模块**：[模块名称]
- **培训时长**：[时长]

## 核心知识点
1. **合规铁律**：5条渠道专属红线的含义与边界
2. **熔断机制**：6种熔断触发条件与处置流程
3. **话术转换**：去商业化三原则与转换表
4. **工具使用**：4种工具的正确使用方法
5. **上报流程**：4类问题的上报路径与时限

## 案例演练
- **场景1**：医生暗示回扣 → 熔断M1处置演练
- **场景2**：医生询问超适应症使用 → 上报流程演练
- **场景3**：基层过敏筛查 → 工具使用演练
- **场景4**：DRG控费异议 → LASS模型应对演练

## 考核标准
| 考核项 | 通过标准 | 权重 |
|--------|---------|------|
| 合规铁律理解 | 5条全部正确复述 | 30% |
| 熔断机制判定 | 6种触发条件正确识别 | 25% |
| 话术转换能力 | 3/4场景正确转换 | 20% |
| 工具使用 | 4种工具正确演示 | 15% |
| 上报流程 | 4类问题上报路径正确 | 10% |

## 培训结论
- **通过人数**：[X/Y]
- **需补考人数**：[X]
- **下次复训日期**：[日期]
- **培训师签字**：______
```
