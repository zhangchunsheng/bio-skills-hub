## 二、快速开始

### 2.1 模板生成（新手推荐）

```bash
# 电商产品展示
python3 seedance.py --template T1 --subject "白色运动鞋"

# 科幻史诗场景
python3 seedance.py --template T3 --subject "宇航员" --duration 15

# 国风古风
python3 seedance.py --template T8 --subject "古装女子"
```

### 2.2 自定义生成（老手推荐）

```bash
python3 seedance.py --custom \
    --subject "古装女子白衣长发" \
    --scene "沙漠戈壁、下三分之一为沙漠" \
    --style "西部电影质感" \
    --emotion "苍凉孤寂" \
    --aspect "2.35:1" \
    --duration 10 \
    --motion "缓慢向前推进" \
    --lighting "左侧45°橙红主光"
```

### 2.3 问题诊断

```bash
python3 seedance.py --diagnose "人物变脸"
python3 seedance.py --diagnose "运镜混乱"
python3 seedance.py --diagnose "无电影感"
```

### 2.4 反模式检查

```bash
python3 seedance.py --check "很科幻的画面，静止且冲刺"
# 输出：❌ 抽象词：很科幻 · ❌ 冲突指令：静止+冲刺
```

### 2.5 多模态绑定

```bash
python3 seedance.py --custom \
    --subject "美女模特" --scene "都市街头" --style "时尚广告" \
    --character-ref "reference.jpg" \
    --style-ref "style_ref.jpg" \
    --audio-ref "音频 3秒鼓点"
```

### 2.6 列表查询

```bash
python3 seedance.py --list-templates      # 列出所有模板
python3 seedance.py --list-diagnostics    # 列出所有诊断项
```

## 四、核心算法

### 4.1 四层建筑法组装

```python
prompt = " | ".join([
    L1_technical,      # 画幅、帧率、质感（必写）
    L2_spatial,        # 前中后景、构图
    L3_lighting,       # 光源、色温、光质
    subject,           # 主体细节
    L4_motion,         # 镜头运动
    style,             # 风格
    emotion,           # 情绪
])
```

### 4.2 反模式过滤器

**智能抽象词检测**（跳过复合词误报）：
```python
# "高级极简风" 不会误判为"高级"
# "很治愈" 会准确命中
safe_compounds = ["高级极简", "高级质感", ...]
```

**冲突指令检测**：
```python
CONFLICT_PAIRS = [
    ("静止", "冲刺"),
    ("昏暗", "高亮"),
    ("特写", "远景"),
    ...
]
```

**多动作叠加检测**：≥ 3 个运动词判为超载

### 4.3 诊断引擎

```python
症状关键词 → 模糊匹配 → 返回：
  症状描述 + 根本原因 + 修复方案 + 止损兜底
```

## 五、Python API 集成

```python
from seedance import (
    generate_from_template,
    generate_custom,
    Bindings,
    diagnose,
    run_risk_check,
)

# 模板生成
output = generate_from_template("T3", subject="宇航员", duration=15)
print(output.prompt)               # 完整提示词
print(output.risk.is_safe)         # 反模式检查
print(output.creation_logic)       # 创作逻辑说明

# 自定义生成 + 多模态绑定
bindings = Bindings(
    character_ref="hero.jpg",
    style_ref="cyberpunk.jpg",
)
output = generate_custom(
    subject="赛博朋克战士",
    scene="霓虹夜市",
    style="赛博朋克电影",
    emotion="孤独反叛",
    aspect="2.35:1",
    duration=10,
    bindings=bindings,
)

# 问题诊断
result = diagnose("人物变脸")
print(result["fix"])  # 修复方案

# 反模式检查
risk = run_risk_check("很科幻的画面，静止且冲刺")
print(risk.conflicts)  # ['静止 + 冲刺']
```

## 九、实战案例库

### 案例 1：宇航员迷失太空（科幻史诗 · T3 模板）

**场景描述**：一个宇航员在太空中检修设备，安全绳断裂后迷失在浩瀚太空中。

**最终提示词**（直接复制使用）：

```
2.35:1宽银幕、24fps、电影质感、胶片颗粒 | 远景深邃星空与远处蓝色地球弧线、中景银白色卫星太阳能板阵列、前景宇航员身影 | 右侧地球反光蓝冷主光、左侧星光微弱补光、强明暗对比 | 宇航员身穿白色宇航服、头盔金色面罩倒映蓝色地球弧光，手持检修工具漂浮在深黑太空中，安全绳断裂端头飘散 | 镜头极缓匀速向前推进长镜头，宇航员身体随惯性缓缓旋转远离镜头、时长15秒 | 科幻电影质感、类似《地心引力》视觉风格 | 孤独、渺小、无助
```

**四层结构拆解**：

| 层级 | 内容 | 作用 |
|------|------|------|
| L1 技术层 | 2.35:1宽银幕、24fps、电影质感、胶片颗粒 | 宽银幕+胶片颗粒 = 立刻有电影感 |
| L2 空间层 | 远景星空地球弧线 → 中景卫星太阳能板 → 前景宇航员 | 三层纵深，画面有立体空间感 |
| L3 光照层 | 右侧地球反光蓝冷主光 + 左侧星光微弱补光 | 双光源体系，冷色调渲染太空的冰冷与孤寂 |
| L4 运动层 | 极缓匀速向前推进 + 宇航员随惯性缓缓旋转远离 | 单一匀速运动，成功率最高；旋转远离强化"迷失"主题 |

**创作逻辑**：
- 模板基础：T3 科幻史诗场景
- 画幅选择：2.35:1 宽银幕，科幻片的经典比例
- 时长：15 秒，足够展开叙事但不超 Seedance 2.0 的 60 秒上限
- 运动策略：极缓匀速推进长镜头，单一运动方向确保画面稳定
- 情绪定位：孤独、渺小、无助 — 通过"缓缓旋转远离"的物理运动具象化

**反模式检查**：✅ 通过检查，无明显反模式
- 无抽象词堆砌
- 无冲突指令
- 无多动作叠加
- 无违背物理

**关键设计点**：
1. **运动策略**只用了"极缓匀速推进+缓慢旋转远离"一个方向，单一匀速运动成功率最高（~90%）
2. **双光源**走的是地球反光蓝冷主光 + 星光微弱补光，冷色调天然渲染太空的孤寂感
3. **"旋转远离"**这个动作把"迷失"主题具象化了——不是停在那喊救命，而是身体不受控地飘走
4. 强烈建议绑定 @图片作为主角参考，保证宇航员形象一致
