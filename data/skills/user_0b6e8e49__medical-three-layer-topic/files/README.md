# medical-three-layer-topic

面向医生 IP 的三层选题 Skill。用户只需提供科室或专业方向，Skill 会：

1. 建立或复用本地三层关键词库；
2. 按"内容对象 × 使用语境 × 提问角度"生成并筛选选题；
3. 执行医疗内容安全过滤与历史去重；
4. 导出带 UTF-8 BOM、可直接用 Excel 打开的 CSV。

最终结果固定为八列：

`序号,科室/专业方向,选题标题,第一层关键词,第二层关键词,第三层关键词,生成模式,生成日期`

## 产出示例

| 序号 | 科室/专业方向 | 选题标题 | 第一层关键词 | 第二层关键词 | 第三层关键词 | 生成模式 | 生成日期 |
|------|-------------|---------|------------|------------|------------|---------|---------|
| 1 | 内分泌科 | 体检发现血糖偏高，复查时要看哪些指标？ | 血糖异常 | 体检后 | 指标解读 | mixed | 2026-07-20 |
| 2 | 内分泌科 | 刚开始服用二甲双胍，日常需要注意什么？ | 二甲双胍 | 开始用药后 | 日常注意 | newbie | 2026-07-20 |
| 3 | 内分泌科 | 糖化血红蛋白偏高，复诊时应关注哪些变化？ | 糖化血红蛋白 | 复诊前 | 指标变化 | compare | 2026-07-20 |

## 兼容性

- **运行时**：纯 Python 标准库，Python 3.8+ 即可运行，无需 pip install
- **平台**：适配 agent-skills 规范，可在 WorkBuddy / CodeBuddy / OpenAI / 通用平台使用
- **输出**：UTF-8 BOM CSV，macOS / Windows 中文版下双击直接打开

## 快速开始

1. 确保本机已安装 Python 3（`python3 --version`）
2. 向 Skill 提供科室/专业方向，例如："帮我为内分泌科生成 30 个医生 IP 选题"
3. 选题自动生成并导出到 `outputs/medical-three-layer-topic/` 目录

详细使用说明和常见问题见 [使用指南](GUIDE.md)。完整工作流见 [SKILL.md](SKILL.md)。
