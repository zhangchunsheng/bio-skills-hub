# 医疗三层选题方法

## 核心公式

`内容对象 × 使用语境 × 提问角度 = 候选选题`

三层是三个功能变量，不是三套医学分类。关键词可以专业，最终标题必须让普通患者看得懂。

## L1：内容对象

回答“具体讲什么”。只收录与科室直接相关的具体对象：

- 疾病、症状和体征
- 检查、报告项目和健康指标
- 药物类别或患者常见药名
- 诊疗流程、复查事项和健康管理动作

不收录“知识、科普、方法、经验、干货、健康”这类孤立抽象词。尽量保持同一粒度。建议 80–100 个，软底线 50 个。

## L2：使用语境

回答“与谁、在什么情况下有关”。可收录：

- 人群：儿童、老人、孕妇、上班族等
- 生活场景：熬夜后、运动期间、节假日饮食等
- 就医场景：体检发现、第一次就诊、复诊等
- 阶段：刚确诊、长期用药、术后、恢复期等

关键词保持简短，避免写成完整问题。建议 60–80 个，软底线 30 个。

## L3：提问角度

回答“患者围绕它最想问什么”。主要类别：

- 选择与判断：怎么判断、适不适合、要不要
- 原因与变化：为什么、可能和什么有关
- 方法与准备：怎么做、就诊前准备什么
- 时间：什么时候复查、多久关注一次
- 比较：有什么区别、分别适合什么情况
- 误区：常见误区、哪些做法不可靠
- 必要性：有没有必要、哪些情况需要就医

问题词应口语化，但不能预设诊断或治疗结论。建议 80–100 个，软底线 50 个。

## 组合与筛选

1. 先按 `目标数量 × 4` 生成候选组合。
2. 优先使用历史中较少出现的 **L1×L2 组合**，避免同批连续重复 L1。
3. 组合不成立时直接舍弃，不为凑数强行解释。
4. 将组合润色为一个明确、可拍摄的标题，保留三层含义。
5. 按以下顺序检查：组合合理性、标题具体度、患者可理解性、科室相关度、历史新颖度。
6. **组合去重**：同一 L1×L2×L3 的三层组合只出一条；同一 L1×L2 且 L3 提问角度高度相似（如同属「判断」类且指向同一问题）的，只保留一条。不满足标题钩子标准的直接淘汰。

## 生成策略：广度 + 深度矩阵

53 个 L1 × 34 个 L2 × 53 个 L3 = 95,000+ 理论组合。即使只有 10% 有医学意义，也超过 9,000 条选题。因此必须改变「每个 L1 出一条就换」的浅层策略。

### 策略原则

1. **广度层**：首轮确保每个 L1 至少覆盖 1 条选题，建立底线覆盖。
2. **深度层**：对高价值 L1（高频疾病、患者痛点集中、平台数据反馈好的对象），系统性地配对不同 L2 场景。每个 L1×L2 组合从 L3 中选最合适的提问角度。
3. **去重硬约束**：同一 L1×L2×L3 组合不重复；L1×L2 相同但 L3 语义高度相似的只出一条。不看标题字面，看三层关键词组合是否撞车。

### 覆盖度计算

- 覆盖度 = 已使用的 L1×L2 组合数 ÷ 有医学意义的 L1×L2 组合数。
- 当某个 L1 的 L2 组合覆盖率 >60% 时，提示该方向即将饱和。
- 当覆盖率 >80% 时，必须建议扩充 L2 场景或转战其他 L1，不接受语义换壳的内容。

## 模式映射

- `mixed`：各类问题角度混合。
- `newbie`：怎么判断、先了解什么、注意什么。
- `pitfall`：常见误区、哪些做法不可靠、如何避免。
- `compare`：有什么区别、分别适合什么情况、选择时看什么。
- `live`：为什么、怎么办、要不要、什么时候就医。

模式只筛选 L3；L1 和 L2 继续使用完整词库。

## 标题合格标准

- 一眼能看出具体讲什么。
- 普通患者无需专业背景也能理解。
- 不制造恐慌，不暗示确定诊断。
- 不为吸引点击编造数字、病例或结论。
- 能从结果表追溯到 L1、L2、L3。
- 必须满足下方「标题钩子标准（口播化）」的原则和检查清单。

## 标题钩子标准（口播化）

好的医疗选题标题 = 医学准确 + 患者口语 + 听完第一句就想知道答案。

### 原则

- 像面对面跟患者聊天，不像写科普文章标题。
- 用具体场景代替抽象提问——「什么人 + 什么情况下 + 什么感觉/什么困惑」。
- 听完第一句就让观众产生「然后呢？」的冲动。
- 可以带患者原话的表达方式，但医学内容必须准确。

### 对比示例

| 书面科普标题（❌） | 口播化钩子标题（✅） |
|---|---|
| 甲状腺结节4A类患者的诊疗建议 | 报告上写甲状腺结节4A，医生说先别慌，重点看这几样 |
| 痔疮术后坐浴的注意事项 | 痔疮手术做完，泡错水这一样等于白受罪 |
| 长期便秘患者的饮食管理 | 长期便秘的人，碗里这3样东西比开塞露还管用 |
| 肛门指检的临床意义与操作规范 | 为什么看肛肠科，医生总要伸手指？很多人因为不好意思跳过了 |
| 妊娠期痔疮的发病机制与防治 | 怀孕后痔疮突然掉出来一大坨，怎么回事？ |

### 口播化检查清单

生成每个标题后自查：

- [ ] 这个标题是不是我当面跟患者聊天时会说的话？（不是朗读科普文章标题）
- [ ] 听完第一句，会不会想继续听下去？（有没有信息缺口或悬念）
- [ ] 能不能一句话复述给别人听？（不绕弯子、不要长从句）
- [ ] 有没有具体场景？（什么人/什么情况下/什么感觉）
- [ ] 是否避免了空洞编号式？（❌「3个方法」「5个误区」→ ✅ 用实际内容代替数字模板）
