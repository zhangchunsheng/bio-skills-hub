# 使用指南

## 首次使用 30 秒检查

在生成第一批选题之前，先确认这三件事：

- [ ] `python3 --version` 输出 3.8+（两个都没有就去 python.org 下载安装）
- [ ] 输出目录不在 iCloud/OneDrive/Dropbox 等云同步目录中（避免文件锁冲突）
- [ ] 科室名称用全称（如「内分泌科」而非「内分泌」，「心血管内科」而非「心内科」）

## 首次使用

### 1. 检查 Python 环境

本 Skill 的核心脚本 (`csv_store.py`) 只用了 Python 标准库，Python 3.8 及以上版本即可运行，**不需要 pip install 任何东西**。

```bash
python3 --version
# 期望输出类似：Python 3.13.x
```

如果提示 `command not found: python3`，试试 `python --version`。两个都没有则需要先安装 Python 3。

### 2. 选择输出目录

默认输出到当前工作区的 `outputs/medical-three-layer-topic/` 目录。你可以指定任意本地目录，但注意：

- 目录需要有写入权限
- 不推荐放在网络驱动器或云同步目录（如 iCloud、OneDrive），避免文件锁冲突

### 3. 第一次生成选题

只需告诉 Skill 你的科室，例如：

> "帮我为内分泌科生成 30 个医生 IP 选题"

Skill 会自动完成以下步骤：
1. 建立三层关键词库（约 100+ 个关键词）
2. 生成 4 倍候选组合（120 个）
3. 医疗安全过滤
4. 历史去重
5. 导出 CSV

第一次生成耗时较长（建立关键词库），后续复用词库会快很多。

### 4. 后续复用

第二次使用时，Skill 会自动检测已有的关键词库并复用：

> "继续用心内科关键词库生成一批避坑类选题"

关键词库路径为 `outputs/medical-three-layer-topic/关键词库_<科室>.csv`，选题历史路径为同目录下的 `选题历史.csv`。

## 注意事项

### 选题生成

- **数量可以调整**：默认 30 个，可以在提问时指定，如"生成 50 个"
- **模式可以指定**：支持 mixed（混合）、newbie（入门）、pitfall（避坑）、compare（对比）、live（直播）。不指定默认 mixed
- **关键词库低于软底线会提示**：L1 低于 50、L2 低于 30、L3 低于 50 时会提示是否扩充，不会强行用稀疏词库生成

### 医疗安全

- Skill 内置了基于卫健委 2025 年通知、抖音社区公约、视频号运营规范的过滤规则
- 会主动舍弃以下类型的选题：疗效承诺、个体诊断、处方建议、手术替代判断、虚构数据、恐吓式表达、变相广告
- 安全过滤由 AI 执行，不是程序化硬拦截——如果你发现漏网之鱼，可以直接在 CSV 里删掉那行
- 最终发布前仍需人工复核，Skill 不能替代医生和平台的正式审核

### 数据安全

- 所有数据（关键词库、选题结果、选题历史）都保存在你指定的本地目录
- 不上传任何数据到云端，不连接外部服务
- 不读取真实病历或患者信息

## 常见踩坑与排查

遇到报错别慌，按症状找对应行：

| 你遇到的症状 | 可能原因 | 解决方法 |
|-------------|---------|---------|
| `Error: 没有可写入的新选题` | 当前批次候选与历史全部重复 | ① 换 `burst` 模式试试 ② 减少目标数量 ③ 扩充关键词库 |
| CSV 在 Excel 里打开是乱码 | 系统编码问题 | 用「数据 → 自文本/CSV」导入，选 UTF-8 |
| `python3: command not found` | 没装 Python 3 | macOS: `brew install python3` / Windows: python.org 下载 |
| `无法写入文件：目录权限不足` | 输出目录无权限或云同步锁冲突 | 换到本地目录（如 `~/Documents/选题输出/`），关闭云同步 |
| 生成到一半没反应 | Python 正常但 AI 部分超时 | 减少选题数量，或换 `burst` 模式跳过精细润色 |
| `选题历史表头不符合预期` | 手动编辑搞坏了表头 | 恢复正确表头，或删除 `选题历史.csv` 重来（会丢失去重记录） |
| 文件名中文在 CI 环境报错 | 系统不支持中文路径 | 告诉 Skill「用英文文件名」 |
| `System.IO 错误，已重试 3 次仍失败` | 磁盘空间不足或文件系统异常 | 检查磁盘剩余空间，清理后重试 |
| 选题标题看起来不够抓人 | 安全合规优先，标题偏克制 | 基于 CSV 二次润色，但发布前再过一遍安全规则 |

> 如果以上都找不到你的问题，直接把报错原文发给我。

## 常见问题

### Q: 选题标题看起来不够"爆款"？

A: 三层选题法优先保证**安全合规 + 可追溯**，标题偏克制、不制造焦虑。如果你需要更吸引眼球的标题，可以基于导出的 CSV 自行二次润色——但请确保通过平台审核。

### Q: 生成过程中报错"没有可写入的新选题"

A: 说明当前批次生成的候选与历史选题全部重复。可以尝试：
- 扩充关键词库（特别是 L1 层）
- 换个生成模式（如从 mixed 换成 pitfall）
- 减少目标数量

### Q: 选题历史文件损坏了怎么办？

A: 脚本检测到损坏会自动拒绝写入并保留原文件。你需要手动检查 `选题历史.csv`：
- 如果是手动编辑导致的表头错乱，恢复正确表头即可
- 如果是编码问题，用 UTF-8 BOM 重新保存
- 也可以直接删除 `选题历史.csv`（会丢失历史去重能力，但不影响本次生成）

### Q: 输出 CSV 在 Excel 里打开是乱码？

A: 本 Skill 输出的 CSV 已带 UTF-8 BOM，macOS 和 Windows 中文版 Excel 都能直接打开。如果仍乱码：
- Windows：用"数据 → 自文本/CSV"导入，选择 UTF-8 编码
- WPS：直接打开通常没问题

### Q: 文件名包含中文，在 CI 环境或英文系统上能行吗？

A: 输出文件名默认使用中文（如 `医生IP选题_内分泌科_20260720.csv`），方便在中文 Excel/WPS 中直接识别。如果运行环境的文件系统对中文支持不好（如某些 CI 容器），可以告诉 Skill 使用英文文件名。

### Q: 关键词库可以手动编辑吗？

A: 可以。`关键词库_<科室>.csv` 就是普通 CSV，用 Excel 打开后可以增删关键词、调整权重。注意：
- 保留表头结构（层级、关键词、分类、权重、状态）
- 编辑后用 UTF-8 BOM 保存

### Q: python3 命令不存在怎么办？

A: Skill 会自动降级尝试 `python`。如果两个都不存在，请在终端安装 Python 3：
- macOS: `brew install python3`
- Windows: 从 python.org 下载安装，勾选"Add Python to PATH"

### Q: 能把选题导入到飞书多维表格或其他平台吗？

A: 导出的 CSV 可以直接导入飞书多维表格、Notion、Airtable 等平台。导入时选择 UTF-8 编码即可。
