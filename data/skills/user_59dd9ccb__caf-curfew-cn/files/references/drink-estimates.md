# Generic caffeine estimates

Use these only when the user cannot provide a package label or official value. Say "约" and preserve uncertainty because brand, cup size, bean dose, tea base, and preparation vary substantially.

| Drink | Working estimate | Practical range |
| --- | ---: | ---: |
| Single espresso | 65 mg | 60–75 mg |
| Medium Americano | 150 mg | 100–220 mg |
| Medium latte | 120 mg | 75–170 mg |
| Medium cold brew | 180 mg | 120–250 mg |
| Medium milk tea | 80 mg | 40–160 mg |
| Brewed black or green tea | 40 mg | 30–60 mg |
| Cola, 330 ml | 35 mg | 30–40 mg |
| Energy drink, 250 ml | 80 mg | 75–85 mg |

## Estimation rules

- Prefer a range when cup size is unclear.
- If the user says only "coffee," ask the type and size once.
- If the user supplies milligrams, use that value instead of this table.
- Do not present cafe drinks as standardized measurements.
- Do not use this table to calculate a personalized medical limit.
