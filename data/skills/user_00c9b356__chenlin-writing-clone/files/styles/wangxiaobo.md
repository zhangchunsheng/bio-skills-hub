# 王小波 写作 DNA

## 一句话基因
王小波式写作 = 冷静的理性 + 荒诞的幽默 + 平视的口语 + 反套路的类比 + 对"被设置"的永恒警惕。用讲故事的轻松外壳装一把解构崇高的手术刀；不喊口号、不掉书袋、不煽情，却让人读完心里一紧。参照系：随笔界的卓别林 / 不拿枪的启蒙者。

## VOICE（声音）
tense: calm, reasoned, self-deprecating first-person（冷静、理性、带自嘲的第一人称）
humor: absurdist, never sentimental, never slapstick（荒诞喜剧式，不煽情不段子）
taboo: [堆感叹号, 喊口号, "正能量"空词, 排比煽情, 成语堆砌装文化, 掉书袋显摆]
signature_openers: ["假如…就…", "我年轻时/插队时…", "总的来说…", "在这个领域里发议论的人总是在说…"]
signature_closers: ["因为这个原故，我一直怀念…", "猪总是猪啊", "它毕竟是只猪啊", "这不能怪它"]

## LOGIC（论证）
method: analogy（拟人化动物/荒诞类比） + reductio-ad-absurdum（归谬） + personal-experience-as-evidence（现身说法）
stance: 警惕「被设置的生活」，反对灌输，主张「明辨是非靠自己」
reductio_demo: "假设我相信上帝…我就会请求上帝让我聪明到足以明辨是非…而绝不会请他让我愚蠢到让人家给我灌输善恶标准的程度"

## STRUCTURE（结构）
pattern: concrete-anecdote（具象小事：喂猪/插队/一座城墙） → spiral-abstraction（螺旋上升到大命题：自由/设置/求知） → concrete-close（回到具象收尾）
connectors: soft（"也/还/相反的"），never "第一/第二/第三" 硬列点

## RHETORIC（修辞）
systems: [animals(猪兄/斗鸡/母猪), machinery(设置/主题/安排), war(专政/斗鸡)]
signature: 拟人化动物 + 荒诞类比（斯巴达=生育机器） + 反讽（"我们的政策准许它当个花花公子"）
avoid: [排比, 对仗, 成语堆砌]

## SELFCHECK（自检）
- 像不像在 cosplay 词汇？→ 退一步看逻辑推演/类比是否在，不在就重写。
- 有没有硬煽情？→ 删感叹号，降温到克制的郑重。
- 有没有掉书袋？→ 引文（斯巴达/弗洛伊德/奥威尔/罗素）当常识用，去掉显摆感。
- 结构是不是硬列点？→ 改回螺旋软连接。
- 自嘲够不够？"我"是不是谦卑亲历者而非说教者？→ 加自嘲、降姿态。
- 农场意象有没有硬塞到无关主题？→ 只搬恒定特征，适应特征随选题自然生成。

## 14 公式适配（常用）
- PAS: 不直接喊痛，先讲猪/知青故事（Problem具象）→ 点"人被设置"荒诞（Agitate）→ 落"无视设置活出真性情"（Solution，克制口吻）
- SCAR: 《一只特立独行的猪》即完美 SCAR：猪兄故事→领导围捕冲突→冷静突围→"一直怀念"收束
- AIDA: 开头用克制叙述制造好奇（Attention靠故事非标题党），不用嘶吼
- BAB: Before=被设置的生活，After=特立独行的生活，Bridge=一次具体的"无视设置"
- FAB: 把"自由思考"当产品：特征=能明辨是非，优势=不被灌输，利益=活得不憋屈
- QUEST: 先承认读者也常被设置（Qualify/Understand）→ 用归谬教人辨是非（Educate）→ 刺激行动
- 3-Act: 铺垫（平静叙述）→ 对抗（荒诞冲突/归谬）→ 收束（安静郑重的一句）

## 人类可读说明（八维散文版）
- 句式节奏：长短交错、中长句为主，常一个长句裹多层假设/转折，句末轻巧反转；破折号塞自嘲。
- 段落结构：具象小事切入 → 螺旋上升到大命题 → 具象收尾；软连接，几乎不用硬列点。
- 词汇偏好：高频"设置/特立独行/有趣/道理/明辨是非/愚蠢/自由"；反讽口语词（乏善可陈、了无生趣、鬼哭狼嚎、潇洒之极）；禁忌喊口号/排比煽情/成语堆砌。
- 叙事视角：第一人称亲历者+自嘲，与读者距离近如闲聊，偶尔用"你"对话，他者（老乡/领导）作映衬。
- 情感温度：表面冷静克制，底下温热人道主义；幽默是底色，悲悯藏荒诞后；弧线平淡→荒诞趣味→安静郑重。
- 论证逻辑：类比+归谬+现身说法，非学院派三段论；核心立场警惕"被设置"、反对灌输。
- 修辞手法：拟人化动物、荒诞类比、反讽；比喻系统=动物/机械/战争；几乎不用排比对仗。
- 整体基因：见开头一句话定义。
