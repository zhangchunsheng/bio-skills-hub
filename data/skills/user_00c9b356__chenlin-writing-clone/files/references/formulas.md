# 14 种写作公式 · 详细定义与适配说明

> 公式只决定「骨架」，风格 DNA 决定「皮肉」。同一位作者的声音，可以套进任意公式写不同文章类型。

| # | 公式 | 全称 / 骨架 | 适配文章类型 | 关键动作 |
|---|------|------------|--------------|----------|
| 1 | **PAS** | Problem 问题 → Agitate 激化 → Solution 解决 | 痛点文、干货文、教程 | 先具象化痛点，再激化痛苦，最后给解法 |
| 2 | **AIDA** | Attention 注意 → Interest 兴趣 → Desire 渴望 → Action 行动 | 营销文、转化文、产品文 | 抓注意（靠故事非嘶吼）→ 建兴趣 → 激发渴望 → 明确行动 |
| 3 | **BAB** | Before 前 → After 后 → Bridge 桥 | 案例文、改造文、对比文 | 展示"前"的窘境，"后"的愿景，用"桥"连接 |
| 4 | **FAB** | Features 特征 → Advantages 优势 → Benefits 利益 | 产品文案、功能介绍 | 从"有什么"到"所以好"到"对你有什么用" |
| 5 | **QUEST** | Qualify 筛选 → Understand 共情 → Educate 教育 → Stimulate 刺激 → Transition 转化 | 长文说服、课程售卖 | 先认同读者处境，再教育，最后推行动 |
| 6 | **SCAR** | Story 故事 → Conflict 冲突 → Action 行动 → Resolution 结局 | 叙事文、品牌故事、随笔 | 用故事承载观点，冲突制造张力 |
| 7 | **4Ps** | Picture 画面 → Promise 承诺 → Prove 证明 → Push 推动 | 销售页、募资文 | 画面感开头，承诺结果，证据支撑，临门一脚 |
| 8 | **4Cs** | Clear 清晰 → Concise 简洁 → Compelling 抓人 → Credible 可信 | 通用自检标准（非结构） | 写完用四标尺量一遍 |
| 9 | **4Us** | Urgent 紧迫 → Unique 独特 → Useful 有用 → Ultra-specific 极具体 | 标题、钩子、社媒 | 标题/开头用极具体钩子，不夸张 |
| 10 | **STAR** | Situation 情境 → Task 任务 → Action 行动 → Result 结果 | 简历、复盘、经验文 | 用亲历经历作情境，行动导出结果 |
| 11 | **PASTOR** | Problem 问题 → Amplify 放大 → Story 故事 → Transformation 转变 → Offer 提议 → Response 回应 | 长销售信、募捐文 | 问题放大后，用故事带出转变，再提议 |
| 12 | **ACCA** | Awareness 认知 → Comprehension 理解 → Conviction 确信 → Action 行动 | 白皮书、深度报告 | 先建立认知，再促成确信与行动 |
| 13 | **SLAP** | Stop 停 → Look 看 → Act 行动 → Purchase 购买 | 广告、短钩子 | 一针见血停下滑动，直接行动 |
| 14 | **3-Act** | Setup 铺垫 → Confrontation 对抗 → Resolution 收束 | 小说、长叙事、演讲稿 | 平静铺垫 → 冲突对抗 → 安静收束 |

## 选择建议

- 不知道选哪个 → 默认 **SCAR**（故事承载，最稳）或 **PAS**（痛点直达）。
- 叙事/随笔类作者 → **SCAR / 3-Act**。
- 说服/干货类 → **PAS / QUEST / ACCA**。
- 产品/转化类 → **AIDA / BAB / FAB / 4Ps / PASTOR / SLAP**。
- 标题/开头 → **4Us** 做钩子。
- 写完自评 → **4Cs** 当标尺。

## 与 DNA 协同示例（以王小波为例）

- PAS + 王小波：先讲猪的故事（Problem 具象）→ 点"人被设置"（Agitate）→ 落"无视设置活出真性情"（Solution，克制口吻）。
- SCAR + 王小波：《一只特立独行的猪》即完美 SCAR。
