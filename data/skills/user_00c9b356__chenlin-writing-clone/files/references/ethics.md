# 伦理与版权边界（强制）

本技能用于**风格研究、学习、个人写作资产沉淀**。使用时必须遵守：

## 红线（不可为）

1. **不得冒充作者本人**：仿写文本不得让人误以为是原作者亲笔。
2. **不得误导读者**：不得用分身伪造名人言论、观点、背书。
3. **不得搬运原文**：不得复制原作者受版权保护的全文作为"产出"；素材仅用于风格分析。
4. **不得用于欺诈/侵权**：不得生成用于诈骗、诽谤、侵权的文本。

## 强制标注

每一篇克隆产出，文末必须注明：

> 「本文为基于 <作者> 风格的模拟写作，非原作者作品。」

若作为可分发的分身 skill 发布，README/说明中须声明：
- 本 skill 仅模仿写作**风格**，不复制原文表达；
- 使用时尊重原创，避免冒名或抄袭；
- 所有改写内容标注"基于 <风格名> 风格改写 / 模拟风格，非原作者创作"。

## 素材合规

- 蒸馏用素材应为用户有权使用的文本（自己写的、已授权、或仅作风格分析的合理使用片段）。
- 开源/共享的分身仓库**不应包含未经授权的原文语料**；可放目录模板、字段模板、说明文档、自己拥有版权的示例文本。

## 引用 vs 抄袭

- 分析中引用**短句片段**作风格示例 = 正常引用（fair use）。
- 大段复述原作者文章 = 侵权，禁止。
- 克隆产出应是**新写的内容**，只是"用他的声音说新话"。

## 一句话

**学他的声音，说自己的话；标注模拟，绝不冒充。**
