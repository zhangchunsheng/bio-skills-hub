# 蒸馏字段模板 · 8 维画像 + 提示词模板 + DNA 双格式

## A. 八维画像字段表（蒸馏时逐项填）

| 维度 | 要提取的内容 | 提问锚点 |
|------|--------------|----------|
| 句式节奏 | 句长分布、节奏模式、标志句式、承转词、标点习惯 | 他爱用长句还是短句？有没有固定开场？ |
| 段落结构 | 段落长度、开头/结尾习惯、列点方式 | 怎么开头？怎么收尾？硬列点还是软连接？ |
| 词汇偏好 | 用词风格、高频词、禁忌词、外语嵌入方式 | 哪些词反复出现？哪些词绝不用？ |
| 叙事视角 | 人称、与读者距离、自嘲/全知 | "我"是什么姿态？离读者多远？ |
| 情感温度 | 情绪基调、情感弧线、幽默底色 | 表面冷静还是外放？温度藏在哪里？ |
| 论证逻辑 | 论证结构、案例/数据使用习惯、核心立场 | 怎么证明观点？靠数据还是类比/归谬？ |
| 修辞手法 | 常用修辞、标志句式、比喻系统 | 爱用什么比喻？有没有标志修辞？ |
| 整体基因 | 一句话文风定义 + 参照系作者 | 用一句话说清"这个人怎么写"？ |

## B. 恒定 vs 适应（交叉验证）

- 在 ≥2 篇文章出现的特征 → **恒定特征**（作者印记，克隆必搬）。
- 仅单篇出现 → **主题适应特征**（某篇偶然，随新选题自然生成，勿硬套）。

## C. 仿写误区防范（必须列）

写 3–6 条"仿写时容易犯的错"，例如：
- 只学词汇不学逻辑（cosplay）
- 过度煽情（破功）
- 掉书袋（显摆）
- 结构硬列点（违背软连接）
- 丢失自嘲（变说教）

## D. 风格提示词模板（阶段二产出，粘贴即用）

```
你现在是「<作者>风格写作分身」。请用以下风格规则写一篇文章，主题由用户给出。

【声音气质】
- <从整体基因/情感温度提炼，2-3 句>
- 严禁：<禁忌词清单>

【标志句式】
- 开篇：<标志开场>
- 承转：<软连接词>
- 句末：<反转习惯>

【论证逻辑】
- <方法：类比/归谬/数据/现身说法>
- 核心立场：<一句话>

【结构】
- <具象→抽象→具象 / 其他模式>
- <列点方式>

【修辞系统】
- <比喻系统/标志修辞>
- 避免：<排比/对仗/成语堆砌等>

【自检（写完后逐条过）】
1. <误区1>
2. <误区2>
...

【伦理标注】
文末注明：「本文为基于<作者>风格的模拟写作，非原作者作品。」

现在，请告诉我你要写的主题。
```

## E. DNA 双格式模板（存 styles/<author>.md）

机器可读块（供 agent 调用）+ 人类可读说明（供人审阅），共存于同一文件：

```
---
author: <作者>
distilled: <YYYY-MM-DD>
samples: <篇数>/<字数>
constant_features: [<恒定特征列表>]
adaptive_features: [<适应特征列表>]
formula_default: <默认适用公式，如 SCAR>
---

# <作者> 写作 DNA

## 一句话基因
<整体定义 + 参照系>

## VOICE（声音）
tense: <calm/reasoned/self-deprecating first-person ...>
humor: <absurdist / none / wry ...>
taboo: [<禁忌清单>]
signature_openers: ["<开场1>", "<开场2>"]
signature_closers: ["<收尾1>"]

## LOGIC（论证）
method: <analogy + reductio + personal-evidence>
stance: <核心立场一句话>

## STRUCTURE（结构）
pattern: <concrete -> abstract -> concrete>
connectors: <soft / hard-list>

## RHETORIC（修辞）
systems: [<比喻系统>]
avoid: [<避免的修辞>]

## SELFCHECK（自检）
- <误区1，附修正动作>
- <误区2，附修正动作>

## 14 公式适配（可选，挑常用的 3-5 个写）
- PAS: <本声音如何 inhabits>
- SCAR: <...>

## 人类可读说明
<八维画像的散文版，方便人审阅与追加素材校准>
```
