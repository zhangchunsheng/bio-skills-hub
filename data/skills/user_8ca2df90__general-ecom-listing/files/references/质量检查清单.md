# 质量检查清单（合规体检）

发布前逐条过。任一红项未处理，不得交付「可发布」结论。

## 一、极限词 / 绝对化用语（红，必须改）

以下词一律不写，写了对转化无益且违规：

- 最类：最、最佳、最优、最强、最大、最美、最省
- 第一：第一、No.1、TOP1、销量第一、行业第一
- 顶级：顶级、极品、极致、王牌、冠军
- 国家级：国家级、国字号、国家免检
- 绝对：绝对、百分百、 guaranteed、一定、 guaranteed 有效
- 唯一：唯一、独家、仅有
- 全网：全网最低、全网首发（无依据时）
- 永久：永久、终生、永远有效

**合规替代**：「长效」替代「最保温」、「高性价比」替代「最便宜」、「广受好评」替代「销量第一」（须有真实依据）。

## 二、功效夸大 / 虚假背书（红，必须改）

- 非药品/非特妆不得宣称治疗、防癌、减肥 guaranteed、生发 guaranteed 等
- 保健/美妆/食品类目话术受《广告法》《化妆品监督管理条例》等约束
- 不得伪造销量、盗用检测报告、冒用品牌或授权
- 「正品」「原装」等需有依据，否则改「全新」「正规渠道」

## 三、标题体检（黄，建议改）

- [ ] 字数 ≤ 平台上限（淘宝/京东/抖音 30，拼多多 60，小红书 20）
- [ ] 核心品类词在标题前 1/3
- [ ] 同词（含近义）出现 < 3 次（无堆砌）
- [ ] 无极限词、无虚假背书
- [ ] 手机端前 12~16 字能看懂卖什么

## 四、五点体检（黄，建议改）

- [ ] 每条一个利益点，不混
- [ ] 利益点后有证据/机制
- [ ] 至少 1 条配具体场景
- [ ] 无极限词、无夸大功效
- [ ] 第 5 条有信任/保障

## 五、关键词体检（黄，建议改）

- [ ] 核心词、属性词、场景词、人群词四层都有
- [ ] 长尾问题词进详情/问答
- [ ] 未堆砌他人品牌词
- [ ] 竞品反推仅学布局不抄文案

## 六、种草文案体检（黄，建议改）

- [ ] 小红书/抖音体，非硬广腔
- [ ] 有情绪词、有细节、有场景
- [ ] 无导流外链话术（平台限流）
- [ ] 功效类以资质为准

## 七、平台特殊项

- [ ] 抖音小店：标题与短视频内容一致
- [ ] 京东：自营/正品话术有资质
- [ ] 拼多多：无「最低价」类绝对化低价表述
- [ ] 小红书：过度营销话术已软化

## 交付口径

- 红项：必须改，改完再交付
- 黄项：建议改，交付时标注「建议优化点」
- 类目敏感（保健/美妆/食品/医疗）：明确提示「以商品资质为准，无资质不写功效」
- 最终提示：「发布前以各平台最新规则复核」
