# 卖点提炼框架

五点卖点最大的误区：把参数当卖点。用户不关心「316 不锈钢」，用户关心「下午茶还烫嘴」。

卖点 = **用户利益**，不是规格。每条结构：

```
[利益点] + [支撑证据/机制] + [对比/场景]
```

## 四步提炼法

### 1. 列参数（原料）
从商品信息里扒出所有可说的：材质、容量、功能、工艺、认证。

### 2. 转利益（翻译成人话）
每个参数问一句：「这对用户有什么用？」
- 316 不锈钢 → 耐腐蚀、装咖啡奶茶不串味
- 500ml → 一天喝的量够了，不用老接水
- 弹盖 → 单手开，开车抱娃腾不出手也能喝

### 3. 加证据（让人信）
利益点后面跟一个机制或证据，否则像吹。
- 「长效保温」→ 「316 内胆锁温，12 小时还烫嘴」（量化+机制）
- 「真防漏」→ 「硅胶圈+双卡扣，倒放包里也不漏」（结构+场景验证）

### 4. 配场景（让人代入）
给利益点一个使用画面，读者自动对号入座。
- 「单手开盖」→ 「开车/抱娃腾不出手也能喝」

## 五点结构模板

```
1. [最强利益]——[机制/证据]，[场景]
2. [第二利益]——[机制/证据]，[场景]
3. [第三利益]——[机制/证据]，[场景]
4. [第四利益]——[机制/证据]，[场景]
5. [第五利益/信任]——[机制/证据]，[场景/保障]
```

第 5 条通常放信任或保障（质保、退换、发货），降低决策风险。

## 示例：保温杯

1. 12 小时长效保温——316 不锈钢内胆锁温，早上倒的茶下午还烫嘴
2. 单手一秒开盖——弹盖设计，开车抱娃腾不出手也能喝
3. 不串味好清洗——广口直筒，抹布一转到底，咖啡奶茶不留痕
4. 真防漏不尴尬——硅胶圈+双卡扣，倒放进包也不漏
5. 一杯顶三杯——茶水分离仓，泡咖泡果饮一壶搞定；破损包退

## 卖点撰写纪律

1. **一条一利益**，不混。一条写「保温+防漏+好看」等于没写。
2. **量化优先**：「12 小时」「500ml」比「长效」「大容量」可信。
3. **证据可证**：说「食品级」要有材质依据，说「销量高」要有真实数据，不编。
4. **场景具体**：「通勤」「健身」「带娃」比「日常使用」有画面。
5. **不碰极限词**：「最保温」「第一好用」一律不写（见质量检查清单）。
6. **差异化挑强的写**：5 条里至少 2 条是竞品没说清的，才有记忆点。

## 不同品类卖点侧重

- **工具/数码**：功能+参数+兼容性（能不能用）
- **家居/日用**：场景+省事+材质安全（好不好用）
- **美妆/个护**：成分+肤感+效果边界（合规宣称）
- **食品**：原料+口味+规格（如实，不宣称功效）
- **服饰**：版型+面料+场景（上身效果）
