# 标题公式库

标题的本质：在平台字数上限内，塞进「最多被搜到 + 最想点」的词，按权重排序。

## 通用骨架

```
[品牌] + [核心品类词] + [核心属性词×2~3] + [使用场景] + [人群] + [差异化卖点] + [规格/数量]
```

品牌可选（无品牌或白牌不强行加）。核心品类词可省则省，但必须保留。

## 分平台裁剪

### 淘宝 / 天猫（30 字）
```
品类 + 属性1 + 属性2 + 场景 + 人群 + 卖点
```
示例：保温杯 316不锈钢 500ml 车载 办公室 长效保温
（28 字，核心词前置，场景人群在后）

### 京东（30 字 + 广告词）
```
品牌 + 品类 + 参数 + 正品/服务词
```
示例：XX 保温杯 316不锈钢 500ml 一键开盖 京东物流
（品牌+参数+服务，不写无依据「第一」）

### 拼多多（60 字内，前 30 关键）
```
品类 + 低价锚词 + 量大词 + 口语属性 + 场景
```
示例：保温杯大容量 316不锈钢 便宜实惠 买一送一 车载办公室水杯
（口语化、低价锚词在前 30 字）

### 抖音小店（30 字）
```
人群 + 痛点场景 + 品类 + 强卖点
```
示例：女生通勤必备 不漏水的保温杯 316内胆长效保温
（人群+痛点+卖点，与短视频一致）

### 小红书（20 字内笔记标题）
```
情绪词 + 人群 + 场景 + 品类
```
示例：被问爆的保温杯 通勤党真爱
（笔记体、有情绪、有细节）

## 标题写法纪律

1. **核心词前置**：品类大词放标题前 1/3，决定搜素命中。
2. **不堆同义词**：「杯子 杯 保温杯 保温杯」算堆砌，系统降权。
3. **属性词撑转化**：材质/容量/功能让人一眼判断「是不是我要的」。
4. **场景/人群拉点击**：「车载」「宝妈」「通勤」比「优质」具体。
5. **卖点只放 1 个最强**：标题塞太多卖点反而稀释，详情里展开。
6. **字数卡死**：先按平台上限写，再用 validator 复核，超了砍修饰词保核心词。

## 反推竞品标题词

用户提供 3~5 条竞品爆款标题 → 分词 → 统计高频词 → 按核心/属性/场景/人群分层 → 剔除品牌词 → 取交集高频词进自己标题。

> 反推是「学布局」不是「抄文案」，不直接复制竞品标题，避免同质化与侵权。
