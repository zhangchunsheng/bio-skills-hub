# 关键词策略

关键词不是「想到啥写啥」，是分层覆盖搜索路径。用户搜一个商品，会从不同角度搜，我们要都接住。

## 六层关键词模型

### 1. 核心词（品类大词）
用户最泛的搜法。
- 例：保温杯、水杯、咖啡杯
- 作用：标题必含，决定基础曝光
- 风险：竞争大、转化低，不能只靠它

### 2. 属性词（材质/容量/功能/颜色）
缩小意图、提高精准度。
- 例：316不锈钢、500ml、弹盖、大容量
- 作用：过滤非目标人群，提高点击率
- 写法：挑 2~3 个最能区分的，不堆全部

### 3. 场景词（使用情境）
捕获「在特定场合需要」的搜素。
- 例：车载、办公室、健身、户外、学生宿舍
- 作用：场景词转化高，因为意图明确

### 4. 人群词（给谁用）
捕获「特定身份」的搜素。
- 例：女生、男生、宝妈、学生、送礼
- 作用：人群词点击率高，有代入感

### 5. 长尾词（问题型/具体型）
捕获「有明确问题」的搜素，竞争小转化高。
- 例：保温杯哪个牌子好、316不锈钢保温杯推荐、通勤保温杯不漏水
- 作用：详情页/问答区布局，截精准流量

### 6. 竞品反推词（非品牌堆砌）
从竞品爆款标题高频词里反推布局思路。
- 做法：分词→统计→取高频非品牌词
- 禁止：直接堆砌他人品牌词（侵权+降权）

## 布局原则

| 位置 | 放什么词 | 理由 |
|---|---|---|
| 标题前 2/3 | 核心词 + 1~2 属性词 | 决定搜素命中 |
| 标题后段 | 场景词 + 人群词 + 1 卖点 | 提高点击 |
| 五点 | 场景词 + 人群词 + 利益点 | 详情区承接 |
| 详情/问答 | 长尾词（问题型） | 截精准流量 |
| 种草文案 | 场景词 + 情绪词 + 话题词 | 软搜素覆盖 |

## 关键词挖掘流程

1. 让用户给品类 + 3~5 个竞品标题（可选）
2. 自己列核心词（品类大词）
3. 列属性词（从商品参数取）
4. 列场景词/人群词（从使用情境反推）
5. 竞品标题分词反推高频词，补属性/场景层
6. 生成长尾问题词（用户会怎么问）
7. 用 validator 看标题有没有堆砌，去掉重复

## 堆砌红线

同一词在标题里出现 ≥3 次（含近义反复），算堆砌，系统降权。validator 会标出。

例：「保温杯 保温杯 杯子 316保温杯」→ 保温杯×3，必须砍到 1 次。
