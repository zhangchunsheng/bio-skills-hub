# 通用电商 Listing 生成器

把一件商品，变成多个平台都能直接上架的 Listing：标题、五点卖点、搜索关键词、详情页结构、种草短文。

不是「给一段描述」就完事——而是按平台规则、类目属性、搜索逻辑，把商品信息重组成**能被搜到、能被点、能转化**的货架表达。

## 何时使用

- 商家/运营要上架新品，但不会写标题、不会铺关键词、不知道各平台格式差异
- 同一件商品要铺淘宝、京东、拼多多、抖音小店、小红书，需要差异化表达
- 写好的 Listing 想做合规体检：有没有极限词、有没有堆砌、长度超没超
- 想从竞品标题里反推关键词布局

## 核心能力

1. **标题生成**：按平台字数上限与权重顺序，拼出高搜素覆盖的标题
2. **五点卖点**：提炼 5 条差异化利益点（不是参数罗列）
3. **关键词矩阵**：核心词 / 属性词 / 场景词 / 长尾词 / 竞品词分层
4. **详情页结构**：首屏钩子 → 痛点 → 卖点展开 → 信任背书 → 规格参数 → 售后保障
5. **种草文案**：适配小红书/抖音的短文案（非硬广口吻）
6. **合规体检**：极限词、违禁词、功效夸大、绝对化用语检测

## 多平台差异速查

| 平台 | 标题上限 | 风格倾向 | 关键词权重 | 特殊注意 |
|---|---|---|---|---|
| 淘宝 | 30 字 | 叠词+属性+场景 | 两头高、中间低 | 避免堆砌同义词；手机端截断 |
| 京东 | 30 字（主标题）+ 广告词 | 参数+品牌+正品 | 品牌权重高 | 自营/正品话术敏感，需有依据 |
| 拼多多 | 60 字内 | 低价+量大+口语 | 低价词权重高 | 避免过度承诺「最低」类表述 |
| 抖音小店 | 30 字 | 痛点+人群+场景 | 短视频关联词重要 | 标题与短视频内容需一致 |
| 小红书 | 20 字内（笔记标题） | 情绪+人群+场景 | 搜索词+话题词 | 笔记体，避免硬广腔 |

> 字数上限以各平台当前规则为准，生成后务必用 `scripts/listing_validator.py` 复核。

## 标题公式库（详见 references/标题公式库.md）

通用结构：

```
[品牌] + [核心品类词] + [核心属性词] + [使用场景词] + [人群词] + [差异化卖点] + [规格/数量]
```

按平台裁剪：
- **淘宝/京东**：品牌(可选) + 品类 + 2~3 个属性 + 场景 + 人群 + 1 个卖点
- **拼多多**：品类 + 低价锚词 + 量大词 + 口语属性 + 场景
- **抖音小店**：人群 + 痛点场景 + 品类 + 1 个强卖点
- **小红书**：情绪词 + 人群 + 场景 + 品类（笔记体）

## 五点卖点框架（详见 references/卖点提炼框架.md）

每条卖点 = **一个用户利益**，不是参数。结构：

```
[利益点] + [支撑证据/机制] + [对比/场景]
```

示例（保温杯）：
1. 12 小时长效保温——316 不锈钢内胆锁温，早上倒的茶下午还烫嘴
2. 单手一秒开盖——弹盖设计，开车/抱娃腾不出手也能喝
3. 不串味好清洗——广口直筒，抹布一转到底，咖啡奶茶不留痕
4. 真防漏不尴尬——硅胶密封圈+双重卡扣，倒放进包也不漏
5. 一杯顶三杯——茶水分离仓，泡茶泡咖啡泡果饮一壶搞定

## 关键词策略（详见 references/关键词策略.md）

分层采集，不要一把抓：

1. **核心词**：品类大词（如「保温杯」）
2. **属性词**：材质/容量/颜色/功能（「316不锈钢」「500ml」）
3. **场景词**：使用情境（「车载」「办公室」「健身」）
4. **人群词**：给谁用（「女生」「学生」「宝妈」）
5. **长尾词**：问题型（「保温杯哪个牌子好」）
6. **竞品词**：同行爆款标题里反复出现的高频词（反推，不碰品牌词堆砌）

布局原则：核心词放标题前 2/3，长尾词进详情与问答，场景/人群词进五点与种草。

## 详情页结构

```
首屏钩子：1 句话戳痛点/给向往（配主图）
  ↓
痛点场景：用户现在麻烦在哪
  ↓
卖点展开：对应五点，每条配图说明
  ↓
信任背书：材质检测/销量反馈/品牌故事（须真实可证）
  ↓
规格参数：尺寸/重量/材质/适配（表格）
  ↓
售后保障：退换/质保/发货（降低决策风险）
```

## 合规底线（硬性，详见 references/质量检查清单.md）

以下**一律不写**，写了对转化没帮助还惹事：

- 极限词：最/第一/顶级/国家级/全网最低/绝对/100%有效
- 功效夸大：治病/防癌/减肥 guaranteed/生发 guaranteed（非特妆/非药品不得宣称）
- 虚假背书：伪造销量、盗用检测报告、冒用品牌
- 绝对化承诺： guaranteed 无效/ guaranteed 不死/ 永久

> 涉及保健、美妆、食品、医疗器械等类目，话术受《广告法》《化妆品监督管理条例》等约束，本技能只做**合规提示**，具体宣称以商品资质为准。无资质不写功效。

## 命令模板

生成单平台 Listing：

```
读取用户商品信息 → 调用本技能 → 指定平台=淘宝 → 输出标题+五点+关键词+详情+种草
```

做合规体检（独立运行脚本）：

```
python scripts/listing_validator.py --title "<标题>" --bullets "<五点,换行分隔>" --platform 淘宝
```

从竞品标题反推关键词：

```
用户提供 3~5 条竞品标题 → 提取高频词 → 按核心/属性/场景/人群分层 → 排除品牌词
```

## 异常处理

- **商品信息太少**：先列「必填清单」（品类、核心卖点、目标人群、价格带、有无资质），不要瞎编参数。
- **跨平台字数冲突**：以最短平台（小红书 20 字）为硬约束先出，再向长平台扩展。
- **类目敏感（保健/美妆/食品）**：主动提示合规边界，缺资质不写功效宣称。
- **用户要求写极限词/虚假背书**：拒绝并给合规替代写法。

## 隐私与数据

- 仅读取本次对话提供的商品信息，不读取本地其他文件
- 不上传任何商品、店铺、运营数据到外部地址
- 生成结果留在对话与本地输出，由用户自行决定是否发布

## 工作流建议

1. 先收齐商品信息（缺啥问啥）
2. 定平台与目标（铺几个、主推哪个）
3. 出标题 + 五点 + 关键词（先用 validator 体检）
4. 出详情结构 + 种草文案
5. 整体合规复核，标出需用户自证的部分
6. 交付可复制文本，提示「发布前以平台最新规则为准」
