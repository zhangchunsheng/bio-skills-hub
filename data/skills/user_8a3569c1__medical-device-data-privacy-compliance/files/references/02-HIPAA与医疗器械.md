# HIPAA 与医疗器械

## 1. HIPAA 适用范围
- 仅约束美国的 **Covered Entity（CE，医疗服务机构/保险/清算所）** 和 **Business Associate（BA，受托处理 PHI 的第三方）**。
- 消费级医疗器械（ wellness / 健康追踪）若不向 CE/BA 提供数据，通常不直接受 HIPAA 约束，但仍受 FDA 网络安全 / 州隐私法约束。

## 2. PHI 是什么
Protected Health Information（受保护健康信息）：能识别个人身份且与医疗健康相关的信息。去标识化后不再属于 PHI。

## 3. 安全规则（Security Rule）要点
| 领域 | 关键要求 |
|---|---|
| 行政保障 | 安全管理制度、人员培训、风险管理、业务连续性 |
| 物理保障 | 设备/设施访问控制、工作站安全 |
| 技术保障 | 访问控制、审计日志、完整性验证、传输加密 |

## 4. 医疗器械与 BA 协议
- 若器械厂商受 CE 委托处理 PHI，须签署 **BAA（Business Associate Agreement）**。
- BAA 须约定：允许用途、安全措施、分包商责任、泄露通知、数据返还/销毁。

## 5. 与 GDPR 的差异
| 维度 | HIPAA | GDPR |
|---|---|---|
| 适用主体 | CE/BA | 任何处理欧盟居民数据的组织 |
| 同意机制 | 披露授权（更偏医疗流程） | 须明示同意或法定基础 |
| 数据主体权利 | 有访问/更正权 | 更全面（删除、可携带、反对画像等） |
| 违规处罚 | OCR 罚款 | 全球营收 4% 或 2000 万欧元 |

- "HIPAA 和 GDPR 都要满足怎么做"
- "PHI 去标识化标准"
