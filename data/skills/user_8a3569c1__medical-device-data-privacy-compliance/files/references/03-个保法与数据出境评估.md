# 中国个保法与数据出境安全评估

## 1. 适用场景
中国《个人信息保护法》（PIPL）下，若医疗器械业务涉及以下情形，须进行数据出境合规审查：
- 向境外提供**个人信息**。
- 向境外提供**重要数据**。
- 处理**敏感个人信息**（健康、生物识别、行踪轨迹等）。

## 2. 个人信息出境的三条路径
| 路径 | 适用条件 |
|---|---|
| 数据出境安全评估 | 关键信息基础设施运营者 / 处理 100 万人以上个人信息 / 累计出境敏感个人信息 1 万人 / 累计出境一般个人信息 10 万人 |
| 个人信息出境标准合同 | 未触发安全评估门槛，但与境外接收方签订合同 |
| 个人信息保护认证 | 经专业机构认证，适用中小企业出境场景 |

## 3. 安全评估核心材料
1. 出境数据处理者情况说明。
2. 境外接收者情况与承诺。
3. 出境数据种类、规模、敏感程度。
4. 出境目的、方式、保留期限。
5. 数据安全保护措施（技术 + 管理）。
6. 境外接收者所在国/地区法律环境与数据保护水平。
7. 用户告知与单独同意证明材料。
8. 个人信息权益救济渠道。

## 4. 医械典型出境场景
- 中国患者数据传至境外云端做 AI 训练 / 数据分析。
- 可穿戴设备在中国收集健康数据，同步至海外服务器。
- 跨国多中心临床研究中，中国受试者数据出境。

## 5. 合规动作清单
- [ ] 盘点数据资产（哪些数据、在哪里、谁在处理）。
- [ ] 判断触发门槛（人数、数据类型）。
- [ ] 准备安全评估 / 标准合同 / 认证。
- [ ] 更新隐私政策（单独同意、出境目的、接收方）。
- [ ] 建立 DPO 或合规责任人机制。
- [ ] 数据跨境日志与审计。
