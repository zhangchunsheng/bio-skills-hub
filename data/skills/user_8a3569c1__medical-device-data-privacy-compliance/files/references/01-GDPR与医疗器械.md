# GDPR 与医疗器械

## 1. 核心概念
GDPR（General Data Protection Regulation，欧盟通用数据保护条例）适用于向欧盟居民提供产品或服务的组织。联网医疗器械若收集、处理欧盟用户数据，即受约束。

## 2. 健康数据的特殊地位
- 健康数据属于 **Special Category Data**（第 9 条），原则上禁止处理。
- 合法基础通常依赖：**明示同意**、**重大公共利益**、**医疗/社会保护目的**等。
- 需做 **Data Protection Impact Assessment（DPIA）**。

## 3. 医疗器械常见合规项
| 合规项 | 要求 |
|---|---|
| 法律依据 | 明确处理 health data 的法律基础 |
| 透明性 | 提供清晰隐私政策，说明数据用途、留存期、第三方共享 |
| 数据最小化 | 只收集实现医疗功能所必需的数据 |
| 数据主体权利 | 访问、更正、删除、可携带、反对处理 |
| DPO | 大规模处理特殊类别数据时须任命数据保护官 |
| 跨境传输 | 向欧盟境外传输须用 SCC / BCR / 充分性认定 |
| 安全事件 | 72 小时内向监管机构报告重大泄露 |

## 4. 欧盟 MDR 与 GDPR 的交叉
- MDR Annex I GSPR 要求制造商保护患者数据（保密、完整、可用）。
- GDPR 负责数据保护，MDR 负责器械安全与性能；两套都要满足。
