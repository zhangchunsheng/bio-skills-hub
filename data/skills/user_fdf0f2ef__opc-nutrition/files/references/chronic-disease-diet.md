# 常见慢病饮食管理方案

> 来源：中华医学会相关指南 + 《临床营养学》教材整理
> 声明：以下内容仅供参考，具体治疗方案请遵医嘱

---

## 一、甲状腺疾病

### 1.1 桥本甲状腺炎/甲减

**疾病概述**：自身免疫性疾病，甲状腺被免疫系统攻击，功能逐渐减退。是甲减最常见的病因。

**饮食核心原则**：
- **碘摄入**：适量即可，不极端忌碘也不补碘过量。正常饮食（加碘盐+普通食物）即可满足需求
- **硒元素**：有研究显示硒可能降低桥本抗体滴度
  - 每日推荐硒摄入量：60μg
  - 食物来源：巴西坚果（1颗≈68-91μg）、深海鱼、鸡蛋
  - 不建议过量补硒（每日>400μg有中毒风险）
- **大豆异黄酮**：豆浆每天1杯没问题，不建议大量摄入大豆蛋白粉
- **十字花科蔬菜**：生吃少量可，大量生吃可能影响甲状腺功能。煮熟后食用无影响
  - 包括：西兰花、卷心菜、花椰菜、白菜、萝卜
- **药物与食物相互作用**：
  - 左甲状腺素钠（优甲乐/雷替斯）：**空腹服用**，用半杯温水送服
  - 与食物间隔：至少30-60分钟后再吃早餐
  - 与补充剂间隔：钙片、铁剂、豆制品需间隔4小时
  - 咖啡影响吸收：服药后至少30分钟再喝咖啡

**推荐食物**：
| 食物 | 理由 |
|------|------|
| 巴西坚果 | 硒含量最高（每日1-2颗） |
| 鸡蛋 | 优质蛋白+硒+胆碱 |
| 深海鱼 | Omega-3+硒+维生素D |
| 菌菇类 | 富含硒和多糖 |
| 全谷物 | B族维生素，帮助能量代谢 |

**需要限制的食物**：
| 食物 | 原因 |
|------|------|
| 大量海带/紫菜 | 碘过量可能加重自身免疫反应 |
| 大豆蛋白粉 | 大量大豆异黄酮可能干扰甲状腺功能 |
| 高度加工食品 | 促炎，加重自身免疫反应 |
| 过量酒精 | 影响甲状腺激素代谢 |

### 1.2 甲亢

**饮食核心原则**：
- **严格限碘**：改用无碘盐，避免海带紫菜海鱼海虾
- **高能量高蛋白**：甲亢时代谢率增高50-100%，需要额外能量
- **补钙补磷**：甲亢加速骨钙流失
- **避免刺激性食物**：咖啡、浓茶、辛辣

## 二、脂肪肝

**疾病概述**：肝细胞内脂肪过度沉积。我国成人患病率约30%。轻度脂肪肝可逆转。

**饮食核心原则**：
1. **减重是第一要务**：减重5-10%可显著改善脂肪肝
2. **果糖是最大杀手**：果糖在肝脏直接转化为脂肪
   - 严格限制：含糖饮料（可乐、奶茶、果汁饮料）、果汁、蜂蜜过量
   - 水果可以吃，但不要榨汁（榨汁=去纤维留果糖）
3. **精制碳水要控制**：白米饭、白面条、面包控制在适量
4. **增加膳食纤维**：每天25-30g以上
5. **优质蛋白**：鱼、鸡胸、豆制品为主

**推荐食物**：
- 燕麦（β-葡聚糖有助于降低肝脂肪）
- 绿茶（儿茶素有护肝作用，每日3-4杯）
- 咖啡（黑咖啡，每日2-3杯，与降低肝纤维化风险相关）
- 深海鱼（Omega-3抗炎）
- 十字花科蔬菜（西兰花、卷心菜，有助肝脏解毒）

**需要避免**：
- 含糖饮料（**最该戒的**）
- 酒精（脂肪肝+酒精=火上浇油）
- 反式脂肪（人造奶油、酥皮糕点）
- 精制碳水过量

## 三、高尿酸血症/痛风

**疾病概述**：尿酸生成过多或排泄减少。高尿酸≠痛风，但痛风患者一定高尿酸。

**饮食核心原则**：
1. **严格避免高嘌呤食物**：动物内脏、浓肉汤/鱼汤、部分海鲜
2. **限制饮酒**：尤其是啤酒（啤酒+高嘌呤食物=痛风发作经典组合）
3. **多喝水**：每日2000ml以上，促进尿酸排泄
4. **低脂乳制品**：有促进尿酸排泄的作用
5. **樱桃**：有临床研究显示樱桃可降低痛风发作风险

**嘌呤含量分级**：
| 级别 | 嘌呤含量 | 食物 | 建议 |
|------|---------|------|------|
| 高 | >150mg/100g | 动物内脏、浓汤、凤尾鱼、沙丁鱼、带鱼、蛤蜊 | ❌ 避免 |
| 中 | 50-150mg/100g | 猪牛羊肉、鸡肉、鱼（普通）、豆类 | ⚠️ 适量 |
| 低 | <50mg/100g | 蔬菜、水果、鸡蛋、牛奶、米饭、面条 | ✅ 放心吃 |

**重要更新（2018年后研究）**：
- 植物嘌呤（豆类、菠菜）**不增加**痛风风险
- 维生素C（每日500mg）可能有助于降低尿酸
- 乳制品的蛋白质反而有助于尿酸排泄

## 四、高血压

**饮食核心原则**：DASH饮食模式
1. **限钠**：每日盐摄入<5g（约一啤酒瓶盖）
2. **增钾**：钾有助于对抗钠的升压作用
   - 富钾食物：香蕉、土豆、菠菜、红薯、番茄、豆类
3. **多蔬果**：每天5份蔬果以上
4. **低脂乳制品**：每日2-3份
5. **限制饱和脂肪和胆固醇**

**实操建议**：
- 烹饪少放盐，用柠檬汁、醋、香料代替
- 少吃腌制食品（榨菜、泡菜、腊肉）
- 酱油、蚝油也含钠，用了就少放盐
- 外卖普遍高盐，要求"少盐"很重要

## 五、糖尿病前期/胰岛素抵抗

**饮食核心原则**：
1. **低GI饮食**：选择低血糖生成指数食物
   - 低GI（<55）：燕麦、糙米、豆类、大多数蔬果
   - 中GI（55-70）：全麦面包、糙米白米混合
   - 高GI（>70）：白米饭、白面包、土豆泥、西瓜
2. **控制总碳水**：每餐碳水占1/4餐盘即可
3. **增加膳食纤维**：延缓血糖上升
4. **蛋白质搭配碳水**：每餐都有蛋白质，降低整餐的GI
5. **餐后运动**：餐后15分钟散步有助于降低餐后血糖峰值

**碳水替换指南**：
| 用这些代替 | 代替这些 |
|-----------|---------|
| 糙米饭/杂粮饭 | 白米饭 |
| 燕麦片 | 白粥 |
| 全麦面包 | 白面包 |
| 红薯/玉米 | 土豆泥 |
| 荞麦面 | 白面条 |

## 六、贫血

**饮食核心原则**：
1. **明确贫血类型**（缺铁性最常见，但不是唯一类型）
2. **补铁+维C**：维C促进铁吸收（饭后吃一个橙子或猕猴桃）
3. **铁来源排序**：动物性铁（血红素铁）吸收率远高于植物性铁
   - 猪肝（每100g含铁22mg）> 瘦肉（2-3mg）> 菠菜（2.9mg，但吸收率仅1.3%）
4. **避免影响铁吸收的食物**：浓茶和咖啡在餐后1小时内不要喝（鞣酸抑制铁吸收）

## 七、慢性胃炎/胃病

**饮食核心原则**：
1. **规律进餐**：定时定量，不暴饮暴食
2. **细嚼慢咽**：减轻胃的消化负担
3. **避免刺激**：辛辣、过酸、过烫、过冷、酒精
4. **养胃食物**：山药、南瓜、小米、猴头菇
5. **少食多餐**：症状明显时可改为每日5-6餐
