# OPC一人食快手营养餐食谱库

> 核心原则：10-15分钟备料，营养均衡，一人份量，厨艺小白友好

---

## 一、早餐系列（5分钟）

### 1.1 营养早餐公式
```
蛋白质 + 主食 + 蔬果 = 完美早餐
例：鸡蛋 + 全麦面包 + 香蕉/小番茄
```

### 1.2 快手早餐清单

| 食谱 | 用时 | 食材（一人份） | 做法 |
|------|------|---------------|------|
| 牛奶燕麦粥 | 3min | 牛奶250ml + 即食燕麦50g + 蓝莓/香蕉 | 燕麦+牛奶微波炉2分钟，加水果 |
| 鸡蛋三明治 | 5min | 全麦面包2片 + 鸡蛋1个 + 生菜 | 煎蛋夹面包，加生菜 |
| 小米红枣粥 | 5min(电饭煲预约) | 小米50g + 红枣5颗 | 前晚预约，早上直接吃 |
| 希腊酸奶碗 | 2min | 希腊酸奶200g + 坚果20g + 水果 | 全部拌匀 |
| 豆浆+包子 | 0min(买) | 无糖豆浆1杯 + 菜包/肉包1个 | 便利店搞定 |

## 二、午餐系列（10-15分钟）

### 2.1 电饭煲一锅出系列

#### 杂粮排骨蔬菜锅
- **用时**：备料10分钟 + 烹饪40分钟（可以先备料按开关，然后工作）
- **食材**（一人份）：
  - 杂粮米 80g（糙米+小米+藜麦）
  - 排骨 150g
  - 胡萝卜 1根（切块）
  - 西兰花 半个
  - 姜片 3片
  - 生抽 1勺、料酒 1勺
- **做法**：
  1. 排骨冷水下锅焯水去血沫
  2. 杂粮米洗净放入电饭煲
  3. 排骨+胡萝卜+姜片放在米饭上面
  4. 加水（比平时煮饭稍多一点），按煮饭键
  5. 煮好后最后10分钟放西兰花

#### 番茄豆腐鱼锅
- **用时**：备料10分钟 + 烹饪20分钟
- **食材**：
  - 番茄 2个
  - 嫩豆腐 1盒
  - 龙利鱼/巴沙鱼 150g
  - 金针菇 1小把
  - 鸡蛋 1个
  - 葱花、盐、白胡椒
- **做法**：
  1. 番茄切块，豆腐切块，鱼肉切小块
  2. 电饭煲放少许油，番茄炒出汁
  3. 加水放入豆腐、金针菇
  4. 水开后放入鱼肉块
  5. 打入鸡蛋，加盐和白胡椒调味

#### 山药养生锅（亚健康调理专用）
- **用时**：备料10分钟 + 烹饪45分钟
- **食材**：
  - 山药 200g
  - 排骨/鸡块 150g
  - 莲子 20g
  - 枸杞 10g
  - 红枣 5颗
  - 生姜 3片
- **做法**：
  1. 山药去皮切块（戴手套！）
  2. 排骨焯水
  3. 所有食材放入电饭煲，加水
  4. 煮45分钟，最后5分钟放枸杞

### 2.2 炒菜系列（10分钟）

#### 西兰花鸡胸
- 鸡胸肉 150g 切片（用料酒+生抽+淀粉腌制5分钟）
- 西兰花 半个 掰小朵 焯水
- 少油快炒，加盐和蒜末

#### 番茄炒蛋（加虾仁升级版）
- 番茄 2个切块
- 鸡蛋 2个
- 虾仁 100g（冷冻虾仁提前解冻）
- 先炒蛋盛出，炒番茄至软，放虾仁，最后倒回鸡蛋

#### 蒜蓉菠菜
- 菠菜 300g 焯水
- 蒜末爆香，快炒加盐
- 3分钟搞定

### 2.3 汤面系列（15分钟）

#### 鸡汤面
- 鸡腿 1个（可前一晚炖好鸡汤冷藏）
- 面条 100g
- 青菜 2把
- 鸡汤加热，下面条和青菜，加蛋

#### 番茄鸡蛋面
- 番茄 1个 + 鸡蛋 1个 + 面条 100g + 青菜
- 番茄炒出汁加水煮开，下面条和青菜，打入荷包蛋

## 三、晚餐系列（15分钟以内）

### 3.1 轻食沙拉类

#### 地中海风格沙拉
- 混合生菜 100g
- 三文鱼罐头 1罐 或 烟熏三文鱼 50g
- 樱桃番茄 5-6个
- 黄瓜 半根
- 橄榄油1勺 + 柠檬汁 + 黑胡椒
- 搭配全麦面包 1片

#### 鸡胸肉牛油果碗
- 即食鸡胸肉 100g（撕成丝）
- 牛油果 半个
- 糙米饭 1小碗
- 紫甘蓝丝 + 胡萝卜丝
- 日式焙煎芝麻酱 1勺

### 3.2 热食类

#### 虾仁蒸蛋
- 鸡蛋 2个 + 温水（蛋:水=1:1.5）打匀过滤
- 虾仁 100g 放在蛋液上
- 蒸锅大火蒸10分钟
- 蒸好后淋生抽+香油

#### 豆腐菌菇汤
- 嫩豆腐 1盒切小块
- 菌菇（金针菇/香菇/蟹味菇）150g
- 鸡蛋 1个打散
- 水煮开后放菌菇和豆腐，煮5分钟，倒入蛋液，加盐和香油

## 四、加餐/零食推荐

| 种类 | 推荐 | 避免 |
|------|------|------|
| 坚果 | 每日一小把（约25g）= 6颗杏仁 或 2个核桃 | 盐焗、糖渍、油炸 |
| 水果 | 苹果、香蕉、蓝莓、猕猴桃 | 蜜饯、果干（糖太多） |
| 饮品 | 无糖茶、黑咖啡、柠檬水 | 奶茶、果汁、含糖饮料 |
| 酸奶 | 无糖希腊酸奶 | 风味酸奶（含糖量高） |
| 巧克力 | ≥70%黑巧克力（每日1-2小块） | 牛奶巧克力、白巧克力 |

## 五、周末备餐指南

### 周日3小时 = 3-5天午餐

**备餐原则**：
1. 选2-3个主菜 + 1个主食
2. 一次做多份，分装到保鲜盒冷藏
3. 蔬菜类保存2-3天，肉类可冷冻保存5天

**推荐备餐组合**：

| 备餐 | 保存天数 | 搭配 |
|------|---------|------|
| 番茄炖牛腩 | 冷冻5天 | 搭配米饭/面条/馒头 |
| 照烧鸡腿（去骨） | 冷藏3天 | 搭配糙米饭+蔬菜 |
| 麻婆豆腐 | 冷藏3天 | 搭配米饭 |
| 杂粮饭（一次煮5人份） | 冷冻7天 | 每天取一份加热 |
| 蒸蔬菜包（西兰花+胡萝卜+玉米） | 冷藏2天 | 任意搭配主菜 |

**冷冻保存Tips**：
- 用保鲜盒分装，不要用保鲜袋（容易串味）
- 标注日期
- 解冻方法：前一天晚上移到冷藏室自然解冻
