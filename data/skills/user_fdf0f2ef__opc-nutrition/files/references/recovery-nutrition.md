# 病后/术后康复营养方案

> 来源：中华医学会肠外肠内营养学分会指南 + 临床营养实践整理
> 声明：严重术后患者请遵临床营养师指导

---

## 一、康复营养总原则

### 1.1 营养需求变化

术后/病后身体的营养需求显著增加：

| 营养素 | 正常需求 | 康复期需求 | 增幅 |
|--------|---------|-----------|------|
| 蛋白质 | 0.8-1.0g/kg/天 | 1.2-1.5g/kg/天 | +50% |
| 维生素C | 100mg/天 | 200mg/天 | +100% |
| 维生素A | 800μg/天 | 1000μg/天 | +25% |
| 锌 | 12.5mg/天 | 15-20mg/天 | +50% |
| 总能量 | 正常 | +10-20% | — |

### 1.2 康复三阶段

| 阶段 | 时间 | 饮食特点 | 核心食物 |
|------|------|---------|---------|
| **急性期** | 术后1-3天 | 流质→半流质，易消化 | 米汤、藕粉、蒸蛋羹 |
| **恢复期** | 术后3-14天 | 高蛋白、高维C、充足热量 | 蒸蛋、鱼肉泥、豆腐汤 |
| **巩固期** | 术后2周-2月 | 接近正常饮食，重点补蛋白和铁 | 瘦肉、鱼类、深色蔬菜 |

## 二、常见手术类型康复方案

### 2.1 普通外科手术（阑尾、胆囊、疝气等）

**术后第1-2天**：
- 清流质：米汤、藕粉、清汤
- 少量多次，每次100-200ml
- 不喝牛奶（术后肠功能恢复前可能胀气）

**术后第3-5天**：
- 半流质：蒸蛋羹、豆腐脑、烂面条、白粥
- 加入软烂的蔬菜（煮烂的胡萝卜、南瓜）

**术后1周后**：
- 逐步过渡到正常饮食
- 增加蛋白质：蒸鱼、煮鸡胸、豆腐
- 多吃富含维C的食物促进伤口愈合

### 2.2 骨科手术（骨折、关节置换等）

**核心营养重点**：
- **钙+维生素D**：促进骨愈合
  - 牛奶、豆腐、小鱼干（连骨吃）
  - 维生素D：晒太阳+补充剂
- **蛋白质**：骨骼修复的基础
  - 每日蛋白质需求：体重(kg)×1.5g
- **维生素C**：促进胶原蛋白合成
  - 猕猴桃、橙子、西兰花

**推荐食谱**：
| 餐次 | 推荐 |
|------|------|
| 早餐 | 牛奶燕麦粥 + 鸡蛋 |
| 加餐 | 猕猴桃1个 |
| 午餐 | 豆腐鱼汤 + 糙米饭 + 蔬菜 |
| 加餐 | 酸奶 + 坚果 |
| 晚餐 | 瘦肉粥 + 蒸蛋羹 + 蔬菜 |

### 2.3 胃肠道手术

**特殊注意**：
- 严格遵医嘱的饮食过渡方案
- 少食多餐（每日6-8餐）
- 避免高糖食物（倾倒综合征风险）
- 细嚼慢咽，每餐20-30分钟
- 饭后不要立即喝大量水

### 2.4 口腔/咽喉手术

**饮食调整**：
- 流质或半流质饮食
- 温度适宜（不烫不冷）
- 通过吸管进食
- 高能量密度的流食：奶昔、营养浓汤

## 三、常见疾病康复方案

### 3.1 感冒/流感后调理

**持续时间**：通常1-2周

**饮食方案**：
1. **补水第一**：多喝温水、淡盐水、柠檬水
2. **优质蛋白**：鸡蛋、鱼肉、豆腐（帮助免疫恢复）
3. **维C丰富食物**：猕猴桃、橙子、彩椒
4. **生姜葱白汤**：初期驱寒，不适用于发烧期
5. **冰糖炖梨**：后期润肺止咳

**避雷**：
- ❌ 油腻食物（消化负担重）
- ❌ 甜食（糖会抑制免疫功能）
- ❌ 辛辣刺激

### 3.2 新冠康复后调理

**常见后遗症**：乏力、咳嗽、味觉减退、脑雾

**针对性饮食**：
| 后遗症 | 饮食建议 |
|--------|---------|
| 乏力 | 增加蛋白质和B族维生素；铁元素检查 |
| 咳嗽 | 百合银耳羹、梨汁、蜂蜜水 |
| 味觉减退 | 少量多次进食，用酸味刺激味觉（柠檬、番茄） |
| 脑雾 | Omega-3脂肪酸（深海鱼）、充足睡眠 |

### 3.3 化疗后营养支持

**核心问题**：食欲差、恶心、味觉改变、白细胞降低

**应对策略**：
1. **食欲差**：
   - 少食多餐（每日5-6小餐）
   - 餐前30分钟散步（轻微活动促进食欲）
   - 在食欲最好的时候吃最重要的食物
2. **恶心**：
   - 生姜有帮助（生姜茶、含姜片）
   - 避免油腻和强烈气味
   - 饭后不要立刻躺下
3. **白细胞降低**：
   - 优质蛋白（鸡蛋、鱼肉、大豆）
   - 维生素C和锌
   - 鲜枣、猕猴桃、牡蛎

**推荐流质食物**：
- 营养奶昔：牛奶+香蕉+花生酱+蛋白粉
- 浓汤：南瓜浓汤、番茄浓汤（用料理机打成泥）
- 酸奶水果杯

## 四、康复期饮食禁忌

### 4.1 通用禁忌

| 禁忌 | 原因 |
|------|------|
| 酒精 | 影响伤口愈合和药物代谢 |
| 高糖食物 | 抑制免疫，促进炎症 |
| 过于辛辣 | 刺激消化系统 |
| 油炸食品 | 消化负担重，促炎 |
| 加工食品 | 添加剂和防腐剂不利于恢复 |

### 4.2 需要就医的信号

- 术后持续呕吐或无法进食超过24小时
- 体重持续下降（每周超过1kg）
- 伤口不愈合或出现红肿渗液
- 持续低热
- 严重腹泻或便秘

## 五、康复期营养补充剂参考

> 注意：食补优先，补剂为辅。具体剂量遵医嘱。

| 营养素 | 食物来源 | 补充剂适用情况 |
|--------|---------|--------------|
| 蛋白质 | 肉蛋奶豆 | 食欲差、进食不足时 |
| 维生素C | 水果蔬菜 | 术后恢复、化疗后 |
| 维生素D | 阳光、鱼类 | 室内恢复、冬季 |
| 钙 | 牛奶、豆腐 | 骨科术后、老年人 |
| 铁 | 红肉、动物肝脏 | 失血术后、贫血 |
| 锌 | 牡蛎、坚果 | 伤口愈合慢 |
| Omega-3 | 深海鱼、亚麻籽 | 抗炎需求 |
| 益生菌 | 酸奶、泡菜 | 抗生素治疗后 |
